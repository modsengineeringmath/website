    Solving Linear Systems Numerically: Gauss, LU, Jacobi or Gauss–Seidel — Which Should You Use?

    Circuit simulators, structural software and heat models must solve Ax=bA\mathbf x = \mathbf bAx=b with thousands to millions of unknowns, where classroom methods are not enough. This article compares all the main methods at a glance: how each works, how fast it is, and when to choose it.

    By Ajarn ModUpdated 25 Oct 2026
    The 30-second summary
    • Direct methods (Gauss, LU, Cholesky, Thomas) finish in a fixed number of steps; best for dense, moderate-size systems; always pivot
    • Iterative methods (Jacobi, Gauss–Seidel, SOR) refine a guess each sweep; best for large sparse systems
    • Gauss–Seidel is usually about twice as fast as Jacobi; SOR with a good ω\omegaω is several times faster still
    • Before trusting an answer, check the condition number κ(A)\kappa(A)κ(A): about log⁡10κ\log_{10}\kappalog10​κ digits may be lost

    The big picture: direct versus iterative

    Cramer's rule is not on this map because its cost grows factorially: a 20-unknown system needs about 5×10195\times10^{19}5×1019 multiplications against about 2,700 for Gaussian elimination (see the Cramer's rule article).

    Direct methods: Gauss, LU, Cholesky and Thomas

    Gaussian elimination zeroes everything below the diagonal and then back-substitutes, using about 23n3\tfrac23n^332​n3 flops. The crucial detail is partial pivoting: use the largest entry in the column as the pivot. On a machine keeping 3 significant digits:

    0.0001x+y=1x+y=2no pivoting: x=0 (wrong),pivoting: x=1.00 (right)\begin{aligned} 0.0001x + y &= 1 \\ x + y &= 2 \end{aligned} \qquad \text{no pivoting: } x = 0\ (\text{wrong}),\qquad \text{pivoting: } x = 1.00\ (\text{right})0.0001x+yx+y​=1=2​no pivoting: x=0 (wrong),pivoting: x=1.00 (right)

    The multiplier 1/0.0001=1041/0.0001 = 10^41/0.0001=104 makes 1−1041 - 10^41−104 round to −1.00×104-1.00\times10^4−1.00×104, wiping out the information in the first equation. Try other digit counts in the pivoting lab (in Thai).

    • LU factorisation is Gaussian elimination that keeps the multipliers in LLL. Factor once, then each new b\mathbf bb costs only ≈2n2\approx 2n^2≈2n2 — ideal for a circuit whose sources change but whose structure does not.
    • Cholesky A=LLTA = LL^TA=LLT is for symmetric positive definite matrices such as the conductance matrix of a resistor network: twice as fast as LU and no pivoting.
    • Thomas handles tridiagonal matrices (heat rods, ladder networks) in O(n)O(n)O(n); a rod held at 100 °C and 0 °C with 4 interior nodes gives T=(80,60,40,20)T = (80, 60, 40, 20)T=(80,60,40,20) °C.

    When they converge, and how SOR speeds things up

    • Strict diagonal dominance ∣aii∣>∑j≠i∣aij∣|a_{ii}| \gt \sum_{j\ne i}|a_{ij}|∣aii​∣>∑j=i​∣aij​∣ in every row → guaranteed convergence. If it fails, try reordering the equations first.
    • The exact condition is a spectral radius ρ(T)<1\rho(T) \lt 1ρ(T)<1, and about d/(−log⁡10ρ)d/(-\log_{10}\rho)d/(−log10​ρ) sweeps are needed to gain ddd digits.
    • SOR overshoots the Gauss–Seidel value by a factor 1<ω<21 \lt \omega \lt 21<ω<2. A 10-unknown heat rod needs about 334 sweeps (Jacobi) and 167 (Gauss–Seidel), but SOR with ω≈1.56\omega \approx 1.56ω≈1.56 needs only about 24.

    Frequently asked questions

    What is the difference between Jacobi and Gauss–Seidel?

    Jacobi computes every unknown of the new sweep from the previous sweep's values, while Gauss–Seidel uses each newly computed value immediately within the same sweep. Gauss–Seidel therefore usually converges about twice as fast and needs less memory, while Jacobi is easier to parallelise.

    When should an iterative method be used instead of LU?

    When the system is very large and the matrix is mostly zeros (sparse), as in heat, electric-field or finite-element simulations with tens of thousands to millions of unknowns. Iterative methods need no full matrix storage and cause no fill-in. For dense systems of moderate size, use LU with partial pivoting.

    Why pivot in Gaussian elimination?

    Choosing the largest entry in the column as the pivot keeps every multiplier at most 1, so round-off errors are not amplified. With a tiny pivot such as 0.0001, a machine that keeps 3 significant digits returns a completely wrong answer.

    When does an iterative method converge?

    If the matrix is strictly diagonally dominant, Jacobi and Gauss–Seidel are guaranteed to converge. The exact condition is that the spectral radius of the iteration matrix is less than 1, and the number of sweeps needed is roughly the number of digits wanted divided by −log₁₀ of the spectral radius.
