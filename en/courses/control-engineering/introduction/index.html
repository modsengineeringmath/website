    What Is a Control System? Open Loop, Closed Loop and Feedback

    The first unit of control engineering: the parts of a control system, open loop versus closed loop, the closed-loop transfer function, and worked examples showing by what factor feedback reduces the effect of plant variations, with electrical engineering examples.

    Taught by Ajarn ModUpdated 12 Nov 2026About 25 min readฉบับภาษาไทย →

    What you can do after this unit

    • Name the parts of a feedback control system and what each one does
    • Explain the difference between open-loop and closed-loop control, with examples
    • Find the closed-loop transfer function of the standard feedback block diagram
    • Calculate how much feedback reduces the effect of a change in the plant
    • Identify the controller, plant and sensor in familiar electrical systems (contactors, PLCs, inverters, AVRs, op-amps)

    Control systems are all around us

    An air conditioner holding room temperature, cruise control holding a car's speed, an inverter holding a motor's speed and a rice cooker that switches off when the rice is done all do the same thing: they make a quantity take the value we want without a person adjusting it.

    Control engineering is the subject that answers three questions.

    1. How does the system to be controlled behave? Answered by a mathematical model.
    2. After a command, how does the output change with time? Answered by the response.
    3. How do we design a controller that gives the result we want without oscillating out of control? Answered by stability analysis and design.

    The whole course answers these three questions in more depth, unit by unit.

    Open loop and closed loop

    An open-loop control system works out the command in advance and applies it, without checking the result. A toaster with a timer is a clear example: set two minutes and it toasts for two minutes. Whether the bread burns or stays pale, the toaster does not know.

    A closed-loop control system measures the actual output, compares it with the reference and uses the error to correct the command continuously. Bringing the output back for comparison is called feedback.

    Open loop Closed loop
    Uses a sensor on the output No Yes
    When the plant changes or is disturbed The output is wrong by the full amount The controller corrects it
    Stability risk Not increased A poor design can oscillate or go unstable
    Cost and complexity Low Higher

    The product around the loop, L(s)=C(s)G(s)H(s)L(s) = C(s)G(s)H(s)L(s)=C(s)G(s)H(s), is called the loop transfer function, and 1+L(s)=01 + L(s) = 01+L(s)=0 is the characteristic equation. Its roots decide whether the closed-loop system is stable, which is the subject of Unit 8.

    Remember it in this form

    Closed-loop transfer function = forward path ÷ (1 + product around the loop), for negative feedback.

    Example: by what factor does feedback help?

    Example 1.1 Motor speed control

    In steady state a motor gives 10 rpm per volt, so G=10G = 10G=10. We want 100 rpm. Later the motor warms up and its gain drops by 20 % to G=8G = 8G=8. Compare the speed obtained in open loop with closed loop using a controller gain K=10K = 10K=10 and a sensor H=1H = 1H=1.

    Open loop. Set the voltage to u=100/10=10u = 100/10 = 10u=100/10=10 V.

    • Normal gain: y=10×10=100y = 10 \times 10 = 100y=10×10=100 rpm
    • Reduced gain: y=8×10=80y = 8 \times 10 = 80y=8×10=80 rpm, wrong by 20 %, the same as the change in the plant

    Closed loop. Use T=KG1+KGT = \dfrac{KG}{1 + KG}T=1+KGKG​ with a reference of 100 rpm.

    • Normal gain: T=100101=0.9901T = \dfrac{100}{101} = 0.9901T=101100​=0.9901, so y=99.01y = 99.01y=99.01 rpm
    • Reduced gain: T=8081=0.9877T = \dfrac{80}{81} = 0.9877T=8180​=0.9877, so y=98.77y = 98.77y=98.77 rpm

    The speed changes from 99.01 to 98.77 rpm, a drop of only 0.25 %, although the plant changed by 20 %.

    This number is no accident. The ratio of the relative change in TTT to the relative change in GGG is called the sensitivity.

    S=dT/TdG/G=11+LS = \frac{dT/T}{dG/G} = \frac{1}{1 + L}S=dG/GdT/T​=1+L1​

    Here L=KG=100L = KG = 100L=KG=100, so S=1/101≈0.01S = 1/101 \approx 0.01S=1/101≈0.01. Feedback cuts the effect of plant errors to about one hundredth. The higher the loop gain, the more the system tolerates change.

    Nothing is free in control

    Notice that the closed loop in the example gives 99.01 rpm, not exactly 100. The shortfall is the steady-state error (Unit 7). And if we keep raising KKK to shrink that error, a real system with dynamics starts to oscillate and may become unstable (Unit 8). Control design is the search for a balance between these effects.

    Is a protection relay a control system?

    An overcurrent relay measures current, compares it with a setting and trips a breaker. It has a sensor (CT), a comparison and an actuator (the breaker). But its job is to make a single decision that isolates the faulty part, not to adjust continuously so that an output follows a reference. It is therefore classed as protection, which works as logic one layer above the control system.

    Example 1.2 An op-amp is a feedback system

    A non-inverting amplifier uses an op-amp with open-loop gain A=105A = 10^5A=105 and feedback through a voltage divider β=R1R1+R2=0.1\beta = \dfrac{R_1}{R_1 + R_2} = 0.1β=R1​+R2​R1​​=0.1. Find the gain of the circuit, and the new gain when AAA falls by half because of temperature.

    With A=5×104A = 5 \times 10^4A=5×104: 5×1041+5×103=9.9980\dfrac{5 \times 10^4}{1 + 5 \times 10^3} = 9.99801+5×1035×104​=9.9980

    The open-loop gain changed by 50 % but the circuit gain changed by only 0.01 %, and it stays close to 1/β=101/\beta = 101/β=10, which is set by two resistors alone. This is why every op-amp circuit uses negative feedback.

    Summary of Unit 1

    • A closed-loop system measures the output and uses the error to correct the command; an open-loop system only commands.
    • T(s)=CG1+CGHT(s) = \dfrac{C G}{1 + C G H}T(s)=1+CGHCG​, and the characteristic equation is 1+L(s)=01 + L(s) = 01+L(s)=0.
    • Feedback reduces the effect of plant changes by the factor 1+L1 + L1+L, at the cost of a sensor and a stability risk.
