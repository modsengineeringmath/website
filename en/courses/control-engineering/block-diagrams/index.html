    Block Diagrams and Signal-Flow Graphs

    The rules for reducing series, parallel and feedback blocks, the transfer function from a disturbance, and Mason's gain formula, with worked examples of a motor speed loop with a tachometer and a system with nested loops.

    Taught by Ajarn ModUpdated 12 Nov 2026About 35 min readฉบับภาษาไทย →

    What you can do after this unit

    • Reduce series, parallel and feedback blocks to a single transfer function
    • Find the transfer function from a disturbance to the output
    • Apply Mason's gain formula to a system with several loops
    • Explain how feedback changes the gain and time constant of a first-order system

    The picture to keep in mind: a block diagram is a wiring diagram for signals

    An electrician reads a motor control circuit from the single-line and control drawings. A control engineer reads a system from its block diagram. The difference is that the lines are not wires but signals flowing one way, along the arrow. Each block multiplies its incoming signal by its transfer function.

    There are only three symbols.

    Symbol Function
    Block Output = transfer function × input
    Summing point Adds or subtracts signals according to the signs marked
    Pickoff point Sends the same signal several ways; its value is not reduced

    Three basic rules

    Connection Overall transfer function Circuit analogy
    Series (cascade) G1G2G_1G_2G1​G2​ Gain of two amplifier stages that do not load each other
    Parallel G1+G2G_1 + G_2G1​+G2​ Summing amplifier
    Negative feedback G1+GH\dfrac{G}{1 + GH}1+GHG​ Feedback amplifier

    Series blocks multiply only when they do not load each other

    Two RC sections connected directly do not have a transfer function equal to the product of the two, because the second draws current from the first. A buffer (voltage follower) must separate them before they multiply. In real control systems power amplifiers and op-amps already provide this isolation.

    For more complicated structures, move a summing or pickoff point to reach a basic form, keeping to the principle that every signal must keep its original value.

    Move What must be added
    Pickoff point from after block GGG to before it A block GGG in the branch
    Pickoff point from before block GGG to after it A block 1/G1/G1/G in the branch
    Summing point from after block GGG to before it A block 1/G1/G1/G in the incoming line
    Summing point from before block GGG to after it A block GGG in the incoming line

    How feedback changes a first-order system

    Example 4.1 Motor speed loop with a tachometer

    A motor with its load has G(s)=200.1s+1G(s) = \dfrac{20}{0.1s + 1}G(s)=0.1s+120​ (rad/s per V). It is driven by an amplifier of gain K=5K = 5K=5, and the speed is fed back by a tachometer with H=0.05H = 0.05H=0.05 V per rad/s. Find the closed-loop transfer function.

    Step 1. The forward path is KG=1000.1s+1KG = \dfrac{100}{0.1s + 1}KG=0.1s+1100​ and the loop product is KGH=50.1s+1KGH = \dfrac{5}{0.1s + 1}KGH=0.1s+15​.

    Step 2. Feedback formula.

    T(s)=KG1+KGH=1000.1s+1+5=1000.1s+6T(s) = \frac{KG}{1 + KGH} = \frac{100}{0.1s + 1 + 5} = \frac{100}{0.1s + 6}T(s)=1+KGHKG​=0.1s+1+5100​=0.1s+6100​

    Step 3. Divide by 6 to reach standard form.

    T(s)=16.670.0167s+1T(s) = \frac{16.67}{0.0167s + 1}T(s)=0.0167s+116.67​

    The time constant falls from 100 ms to 16.7 ms, 6 times faster, which is exactly 1+KGH(0)=61 + KGH(0) = 61+KGH(0)=6.

    Effect of feedback on a first-order system

    Closing a loop of DC loop gain L0L_0L0​ around K0τs+1\dfrac{K_0}{\tau s + 1}τs+1K0​​ divides both the gain and the time constant by 1+L01 + L_01+L0​. The system responds faster in exchange for less gain, just as an op-amp circuit gives up gain to gain bandwidth.

    A real motor is disturbed by load torque. In the block diagram the disturbance D(s)D(s)D(s) enters at a summing point between the controller C(s)C(s)C(s) and the plant G(s)G(s)G(s). Because the system is linear, superposition applies: find the effect of RRR and of DDD separately and add them.

When the controller gain CCC is high, the first term approaches 1/H1/H1/H and the second approaches zero, so the system tracks the reference and rejects the disturbance at the same time.

    Mason's gain formula

    With several nested loops, moving blocks one step at a time is slow. Mason's gain formula gives the answer in one step.

    T=1Δ∑kPk ΔkT = \frac{1}{\Delta}\sum_k P_k\,\Delta_kT=Δ1​k∑​Pk​Δk​

    • PkP_kPk​ is the gain of the kkk-th forward path
    • Δ=1−∑(individual loop gains)+∑(products of gains of two non-touching loops)−⋯\Delta = 1 - \sum(\text{individual loop gains}) + \sum(\text{products of gains of two non-touching loops}) - \cdotsΔ=1−∑(individual loop gains)+∑(products of gains of two non-touching loops)−⋯
    • Δk\Delta_kΔk​ is Δ\DeltaΔ evaluated with only the loops that do not touch the kkk-th forward path

    Loops are "non-touching" when they share no signal or block at all.

    Nested loops in motor drives

    Industrial drives use a cascade structure: the current (torque) loop is innermost and fastest, the speed loop is in the middle and the position loop is outermost. When each inner loop is about 5–10 times faster than the loop outside it, the outer loop can treat the inner one as a constant gain, so the loops are designed one layer at a time without applying Mason's formula to the whole system.
