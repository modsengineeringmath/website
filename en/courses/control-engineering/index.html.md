# Control Engineering: From Complex Variables and Laplace Transforms to State Space

// Online classroom · Control Engineering


This classroom follows the order of the standard international control textbooks, from complex variables and the Laplace transform through physical models, response, stability, root locus, frequency response, PID and state space. Every unit is written from scratch with its own examples and interactive labs, deep enough for a master's course without leaving beginners behind.

## How this classroom differs from the reference library

The control systems library is a reference for looking up formulas and using single-topic labs. This classroom is a continuous path, one unit at a time, with theory, step-by-step examples, an interactive lab, exercises and answers. Units that are not open yet show a "coming soon" tag and open one by one in order.

## Using it with the standard textbooks

The order of topics and the notation follow the standard control textbooks, such as K. Ogata's Modern Control Engineering and System Dynamics, so you can read them side by side. The explanations, examples, problems and figures here are all written from scratch and are not copied or translated from any book. The exercises are of the same kinds you meet at the end of textbook chapters, but they use our own systems and numbers.

## How to use each unit

- Read the outcomes at the top to know what you will be able to do.

- Work the examples step by step with pencil and paper.

- Play with the lab: change a value and watch what follows.

- Try the exercises before opening the answers, which are folded away.

- Press Mark as learned. Progress is kept only in your own browser.

## Prerequisites

- Calculus and ordinary differential equations

- Basic linear algebra (for Part 7)

- Basic circuit analysis (see the DC circuits lessons)

Later units build the complex variables you need from the start, so no prior course in complex analysis is required.
