    Steady-State Error and System Type

    Use the final value theorem to find steady-state error, define system type and the error constants Kp, Kv, Ka, and summarise the errors for step, ramp and parabolic inputs, with examples of an AVR, droop frequency control and a position servo.

    Taught by Ajarn ModUpdated 12 Nov 2026About 35 min readฉบับภาษาไทย →

    What you can do after this unit

    • Use the final value theorem to find the steady-state error of a unity-feedback system
    • State the system type from the number of integrators in the loop
    • Calculate the error constants and the errors for step, ramp and parabolic inputs
    • Explain why the integral part of a controller removes the error from constant inputs and constant disturbances

    The picture to keep in mind: no error, no drive

    A proportional controller drives the plant in proportion to the error. If the error is zero, the command is zero. But a motor that is turning needs some voltage to keep turning. The system therefore has to tolerate a small remaining error to produce that voltage. That remainder is the steady-state error.

    The way out is to give the controller a memory. An integrator accumulates the error. When the error has become zero, the integrator output stays at exactly the value needed. This unit turns that idea into numbers.

    The final value theorem

    For a unity-feedback system with loop transfer function L(s)=C(s)G(s)L(s) = C(s)G(s)L(s)=C(s)G(s), the error is

    E(s)=R(s)−Y(s)=R(s)1+L(s)E(s) = R(s) - Y(s) = \frac{R(s)}{1 + L(s)}E(s)=R(s)−Y(s)=1+L(s)R(s)​

    The final value theorem gives its value after a long time without inverting the transform.

    ess=lim⁡t→∞e(t)=lim⁡s→0sE(s)=lim⁡s→0sR(s)1+L(s)e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} sE(s) = \lim_{s \to 0} \frac{sR(s)}{1 + L(s)}ess​=t→∞lim​e(t)=s→0lim​sE(s)=s→0lim​1+L(s)sR(s)​

    Valid only when the closed loop is stable

    If the system is unstable the error grows without bound, yet the formula may still return a number, which is meaningless. Always check stability first. Unit 8 shows how.

    The table in one sentence

    Each integrator in the loop lets the system follow an input that is "one step harder" with no error. But each integrator also adds 90° of phase lag and makes the loop harder to stabilise, so use only as many as are needed.

    A gain this high makes the response very oscillatory, and once the other time constants in the loop are counted the system is unstable (see Example 8.2). A real AVR therefore uses integral action or a compensator instead of raising the gain alone.

    Example 7.2 A position servo following a ramp

    A servo has L(s)=8.4s(s+4)L(s) = \dfrac{8.4}{s(s + 4)}L(s)=s(s+4)8.4​ (from Example 6.3). Find the error for a constant position command and for a command moving at a constant 2 rad/s.

    The loop has one integrator: type 1.

    • Constant position (step): ess=0e_{ss} = 0ess​=0
    • Constant speed (ramp, A=2A = 2A=2): Kv=lim⁡s→0s 8.4s(s+4)=2.1K_v = \lim\limits_{s \to 0} s\,\dfrac{8.4}{s(s + 4)} = 2.1Kv​=s→0lim​ss(s+4)8.4​=2.1 s⁻¹, so ess=22.1=0.95e_{ss} = \dfrac{2}{2.1} = 0.95ess​=2.12​=0.95 rad

    The machine axis lags the commanded position by 0.95 rad throughout the move. Servo drive manuals call this the following error.

    Error caused by a disturbance

    When a constant disturbance D0D_0D0​ enters between the controller C(s)C(s)C(s) and the plant G(s)G(s)G(s), the resulting error is

    ess=−lim⁡s→0G(s)1+C(s)G(s) D0e_{ss} = -\lim_{s \to 0}\frac{G(s)}{1 + C(s)G(s)}\,D_0ess​=−s→0lim​1+C(s)G(s)G(s)​D0​

    If C(s)C(s)C(s) contains an integrator, the denominator grows without bound as s→0s \to 0s→0 and ess=0e_{ss} = 0ess​=0. The important point is that the integrator must come before the point where the disturbance enters. An integrator in the plant after that point does not reject the disturbance.

    Example 7.3 Governor droop and frequency control

    In a power system, when the load rises by ΔPL\Delta P_LΔPL​ the frequency falls. A governor with regulation (droop) RRR and a load with damping DDD give the steady-state frequency deviation

    Δfss=−ΔPLD+1/R\Delta f_{ss} = -\frac{\Delta P_L}{D + 1/R}Δfss​=−D+1/RΔPL​​

    Take R=0.05R = 0.05R=0.05 pu (5 % droop), D=1D = 1D=1 pu and a load rise of 0.1 pu on a 50 Hz system.

    Δfss=−0.11+20=−0.00476 pu=−0.238 Hz\Delta f_{ss} = -\frac{0.1}{1 + 20} = -0.00476\ \text{pu} = -0.238\ \text{Hz}Δfss​=−1+200.1​=−0.00476 pu=−0.238 Hz

    The frequency rests at 49.76 Hz. A droop governor is a proportional controller, so an error remains. That is intended, because it lets several generators share load in proportion. Secondary control (AGC), which is an integral controller, then slowly adjusts generation until the frequency is back at 50 Hz.
