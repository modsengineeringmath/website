# Online LaTeX Equation Editor: Type an Equation, Download It as PNG or SVG

Type an equation as plain text, such as y = x^2*sin(3x)/(1+x), or write LaTeX directly. It is typeset the way a textbook would print it, and you can download a PNG with a transparent background or a vector SVG. Useful for slides, worksheets, exam papers and social posts.

## Calculator

This calculator needs JavaScript.

## How to use it

- Choose how to type. New to LaTeX? Pick “Type plain maths” and use the ordinary keyboard: ^ for powers, / for division, sqrt( ) for roots, pi for π. The LaTeX appears in the box below and can be edited further.

- Use the symbol palette. Buttons insert fractions, roots, integrals, sums, limits, Greek letters, matrices and piecewise functions. A □ marks a slot to fill in. Select some text first and it goes into the first slot.

- Style the image. Set the font size, colour, background (transparent, white, black, cream), padding and PNG resolution (3× suits slides, 4× suits print).

- Take it away. Download PNG or SVG, or press “Copy image” and paste straight into Word, PowerPoint or Google Docs. “Copy link to this equation” gives a link that reopens the same equation, handy for sharing or editing later.

| Fraction | \frac{a}{b} | $\frac{a}{b}$ |

| Power / subscript | x^{2} · a_{n} | $x^{2},\ a_{n}$ |

| Root | \sqrt{x} · \sqrt[3]{x} | $\sqrt{x},\ \sqrt[3]{x}$ |

| Definite integral | \int_{0}^{1} x^2\,dx | $\int_{0}^{1} x^2\,dx$ |

| Sum | \sum_{n=1}^{\infty} \frac{1}{n^2} | $\sum_{n=1}^{\infty} \frac{1}{n^2}$ |

| Limit | \lim_{x \to 0} \frac{\sin x}{x} | $\lim_{x \to 0} \frac{\sin x}{x}$ |

| Partial derivative | \frac{\partial f}{\partial x} | $\frac{\partial f}{\partial x}$ |

| Greek letters | \alpha \beta \omega \Omega | $\alpha\ \beta\ \omega\ \Omega$ |

| Auto-sized brackets | \left( \frac{a}{b} \right) | $\left( \frac{a}{b} \right)$ |

| Text inside maths | \text{power} = VI | $\text{power} = VI$ |

| Laplace transform | \mathcal{L}\{f(t)\} | $\mathcal{L}\{f(t)\}$ |

| Spacing | \, thin · \quad wide | $a\,b \quad c$ |

Matrices, piecewise functions and multi-line equations aligned at the equals sign are one click away in the “Structures” row, so there is nothing to memorise.

## PNG or SVG?

PNG is a pixel format that opens everywhere. It suits posts, chat apps and ordinary documents. If the image will be enlarged, choose 3× or 4× resolution when you download.

SVG is a vector format: it stays sharp at any size, the file is small, and the colour can still be changed. Word and PowerPoint 2019 or later, Google Slides, Canva, Figma and Inkscape accept SVG directly. It suits textbooks, academic posters and print.

For a dark slide background, choose the “Transparent” background and set the text colour to white.

## Privacy

Typesetting and image creation happen entirely in your browser. The equation is never sent to a server, so the tool is safe for unpublished exams and documents. The typesetter is MathJax 3, the same engine many academic journals use.

## Frequently asked questions

Do I need to know LaTeX?
No. Choose “Type plain maths” and enter something like x^2/(1+x) or sqrt(x^2+1); it is converted to LaTeX for you. The palette adds fractions, integrals and matrices with one click.

Can I use the images commercially?
Yes. The equation is yours. Images carry no watermark and need no attribution.

Why does “Copy image” not work in my browser?
Copying images to the clipboard needs a recent browser (Chrome, Edge, Safari 13.1 or later) on an https page. If it fails, download the PNG instead.
