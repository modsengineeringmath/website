# เครื่องคำนวณปริพันธ์ (Integral Calculator): อินทิเกรตไม่จำกัดเขตและจำกัดเขต พร้อมการตรวจคำตอบ

THภาษาไทยENEnglish
// เครื่องมือ · Integral Calculator


พิมพ์ตัวถูกอินทิเกรต $f(x)$ แล้วรับปฏิยานุพันธ์ $F(x) + C$ ถ้าใส่ขีดจำกัด $a$ และ $b$ จะได้ค่าปริพันธ์จำกัดเขตทั้งรูปแม่นตรงและทศนิยม พร้อมกราฟแรเงาพื้นที่ คำตอบจะแสดงก็ต่อเมื่อหาอนุพันธ์ย้อนกลับแล้วได้ฟังก์ชันเดิม

## เครื่องมือ

ต้องเปิด JavaScript เพื่อใช้เครื่องมือนี้

## วิธีใช้งาน

- พิมพ์ฟังก์ชันแบบเดียวกับเครื่องคำนวณอนุพันธ์: x^2*e^(3x), 1/(x^2+4), sin(x)^2

- เว้นช่อง $a$ และ $b$ ไว้ถ้าต้องการเฉพาะปริพันธ์ไม่จำกัดเขต

- ขีดจำกัดพิมพ์เป็นนิพจน์ได้: pi/2, sqrt(2), e

- ถ้าไม่มีสูตรปิด (เช่น $\dfrac{\sin x}{x}$) ให้ใส่ขีดจำกัดเพื่อรับค่าเชิงตัวเลขที่แม่นยำ

## เทคนิคการอินทิเกรตที่รองรับ

| เทคนิค | ตัวอย่าง | ผลลัพธ์ |

| สูตรพื้นฐานและการแทนเชิงเส้น | $\int (3x+1)^{4}dx$ | $\frac{1}{15}(3x+1)^{5} + C$ |

| การแทนค่าตัวแปร $u = g(x)$ | $\int x e^{x^{2}}dx$ | $\frac{1}{2}e^{x^{2}} + C$ |

| อินทิเกรตทีละส่วน | $\int x\cos x\,dx$ | $x\sin x + \cos x + C$ |

| เศษส่วนย่อย | $\int \dfrac{dx}{x^{2}-1}$ | $\frac{1}{2}\ln\left|\dfrac{x-1}{x+1}\right| + C$ |

| กำลังของตรีโกณมิติ | $\int \sin^{2}x\,dx$ | $\frac{x}{2} - \frac{1}{4}\sin 2x + C$ |

| รูปกำลังสองในราก | $\int \sqrt{1-x^{2}}\,dx$ | $\frac{1}{2}x\sqrt{1-x^{2}} + \frac{1}{2}\arcsin x + C$ |

| เอกซ์โพเนนเชียลคูณตรีโกณ | $\int e^{x}\sin x\,dx$ | $\frac{1}{2}e^{x}(\sin x - \cos x) + C$ |

โจทย์ที่กฎในตารางทำไม่ได้ ระบบจะเรียกไลบรารีพีชคณิตเชิงสัญลักษณ์ nerdamer มาช่วย แล้วตรวจคำตอบด้วยวิธีเดียวกันก่อนแสดงผล

## ทฤษฎีบทมูลฐานของแคลคูลัส

ถ้า $F'(x) = f(x)$ และ $f$ ต่อเนื่องบน $[a, b]$ แล้ว

$$\int_{a}^{b} f(x)\,dx = F(b) - F(a)$$

ตัวอย่าง: $\displaystyle\int_{0}^{\pi}\sin x\,dx = \left[-\cos x\right]_{0}^{\pi} = 1 - (-1) = 2$ ค่าปริพันธ์จำกัดเขตคือพื้นที่แบบมีเครื่องหมาย ส่วนที่อยู่ใต้แกน $x$ นับเป็นลบ ถ้าต้องการพื้นที่จริงให้ใช้เครื่องคำนวณพื้นที่

## การตรวจคำตอบและข้อควรระวัง

ระบบหาอนุพันธ์ของ $F(x)$ ที่ได้แล้วเทียบกับ $f(x)$ เชิงตัวเลข 10 จุด ถ้าไม่ตรงจะไม่แสดงคำตอบ สำหรับปริพันธ์จำกัดเขต ระบบคำนวณทั้ง $F(b) - F(a)$ และค่าเชิงตัวเลขแบบเกาส์–ครอนรอด ถ้าสองค่าต่างกัน (เช่น ปฏิยานุพันธ์ไม่ต่อเนื่องในช่วง หรือมีจุดที่ฟังก์ชันไม่นิยาม) จะแสดงค่าเชิงตัวเลขพร้อมคำเตือน ปริพันธ์ไม่ตรงแบบที่ลู่ออกจะแจ้งว่าเชื่อถือไม่ได้

## เรียนทฤษฎีต่อ

- บทเรียนสูตรอินทิเกรตและวิธีทำ

- การประยุกต์อินทิกรัลทางวิศวกรรม

- เครื่องคำนวณอนุพันธ์

- เฉลยโจทย์อินทิเกรตทีละขั้น

## คำถามที่พบบ่อย

ทำไมต้องมี + C?
อนุพันธ์ของค่าคงที่เป็นศูนย์ ฟังก์ชันที่ต่างกันเพียงค่าคงที่จึงมีอนุพันธ์เดียวกัน ปฏิยานุพันธ์ทั่วไปจึงต้องบวกค่าคงที่ C ไว้เสมอ

คำตอบต่างจากเฉลยในหนังสือ ผิดหรือไม่?
ปฏิยานุพันธ์สองรูปอาจต่างกันเพียงค่าคงที่ เช่น −¼cos 2x กับ ½sin²x วิธีตรวจที่แน่นอนคือหาอนุพันธ์ของคำตอบแล้วดูว่าได้ตัวถูกอินทิเกรตเดิม ซึ่งเครื่องมือทำให้แล้ว

ฟังก์ชันใดอินทิเกรตเป็นสูตรปิดไม่ได้?
เช่น sin(x)/x, e^(x²), 1/ln(x) และ √(1 + x³) ไม่มีปฏิยานุพันธ์ในรูปฟังก์ชันมูลฐาน แต่ยังหาค่าปริพันธ์จำกัดเขตเชิงตัวเลขได้

ค่าเชิงตัวเลขแม่นยำแค่ไหน?
ใช้วิธีเกาส์–ครอนรอด 15 จุดแบบปรับช่วงอัตโนมัติ สำหรับฟังก์ชันที่เรียบโดยทั่วไปถูกต้องถึง 10 หลักขึ้นไป และแสดงค่าคลาดเคลื่อนโดยประมาณให้ด้วย
