    วิธีใช้งาน

    1. เลือกวิธีพิมพ์ ถ้ายังไม่เคยใช้ LaTeX ให้เลือก “พิมพ์สมการแบบธรรมดา” แล้วพิมพ์ด้วยเครื่องหมายบนแป้นพิมพ์ปกติ: ^ คือยกกำลัง / คือหาร sqrt( ) คือราก pi คือ π ระบบจะแปลงเป็น LaTeX ให้ในช่องด้านล่าง และแก้ต่อได้
    2. ใช้แผงสัญลักษณ์ กดปุ่มเศษส่วน ราก อินทิกรัล ซิกมา ลิมิต อักษรกรีก เมทริกซ์ หรือฟังก์ชันเป็นช่วง ช่อง □ คือที่ว่างให้พิมพ์ต่อ ถ้าลากคลุมข้อความไว้ก่อนกด ข้อความนั้นจะถูกใส่ลงในช่องแรก
    3. ปรับรูป เลือกขนาดตัวอักษร สี พื้นหลัง (โปร่งใส ขาว ดำ ครีม) ระยะขอบ และความละเอียดของ PNG (3× เหมาะกับสไลด์ 4× เหมาะกับงานพิมพ์)
    4. นำไปใช้ กดดาวน์โหลด PNG หรือ SVG หรือกด “คัดลอกรูปไปวาง” แล้ววางใน Word PowerPoint Google Docs LINE ได้ทันที ปุ่ม “คัดลอกลิงก์สมการนี้” ให้ลิงก์ที่เปิดมาแล้วเห็นสมการเดิม ใช้ส่งต่อให้เพื่อนหรือเก็บไว้แก้ภายหลัง

    ควรเลือก PNG หรือ SVG

    PNG เป็นรูปแบบจุดภาพ เปิดได้ทุกโปรแกรมและทุกแอป เหมาะกับการโพสต์ ส่งทาง LINE และวางในเอกสารทั่วไป ถ้าจะขยายรูปให้ใหญ่ ให้เลือกความละเอียด 3× หรือ 4× ตั้งแต่ตอนดาวน์โหลด

    SVG เป็นรูปแบบเวกเตอร์ ขยายเท่าใดก็ไม่แตก ไฟล์เล็ก และแก้สีต่อได้ Word และ PowerPoint รุ่น 2019 ขึ้นไป Google Slides Canva Figma และ Inkscape วางไฟล์ SVG ได้โดยตรง เหมาะกับตำรา โปสเตอร์วิชาการ และงานพิมพ์

    ถ้าพื้นหลังของสไลด์เป็นสีเข้ม ให้เลือกพื้นหลัง “โปร่งใส” แล้วเปลี่ยนสีตัวอักษรเป็นสีขาว

    ความเป็นส่วนตัวและการทำงานแบบออฟไลน์

    การจัดเรียงสมการและการสร้างรูปทำในเบราว์เซอร์ของคุณทั้งหมด สมการไม่ถูกส่งขึ้นเซิร์ฟเวอร์ จึงใช้กับข้อสอบหรือเอกสารที่ยังไม่เผยแพร่ได้ ตัวจัดเรียงที่ใช้คือ MathJax 3 ซึ่งให้ผลลัพธ์แบบเดียวกับที่วารสารวิชาการใช้

    คำถามที่พบบ่อย

    ต้องรู้ LaTeX ก่อนไหม?

    ไม่ต้อง เลือกโหมด “พิมพ์สมการแบบธรรมดา” แล้วพิมพ์เช่น x^2/(1+x) หรือ sqrt(x^2+1) ระบบจะแปลงเป็น LaTeX ให้ และยังกดแผงสัญลักษณ์เพิ่มเศษส่วน อินทิกรัล หรือเมทริกซ์ได้

    รูปที่ได้นำไปใช้เชิงพาณิชย์ได้ไหม?

    ได้ สมการเป็นของผู้พิมพ์ รูปที่สร้างไม่มีลายน้ำและไม่ต้องอ้างอิงเว็บไซต์นี้

    พิมพ์ภาษาไทยในสมการได้ไหม?

    ได้ ให้ใส่ข้อความไทยไว้ใน \text{ } เช่น \text{แรงดัน} = IR ข้อความจะแสดงด้วยฟอนต์ไทยของเครื่อง

    ทำไมกดคัดลอกรูปแล้ววางไม่ได้?

    การคัดลอกรูปลงคลิปบอร์ดต้องใช้เบราว์เซอร์รุ่นใหม่ (Chrome, Edge, Safari 13.1 ขึ้นไป) และเปิดเว็บผ่าน https ถ้าใช้ไม่ได้ให้กดดาวน์โหลด PNG แทน

    เครื่องมืออื่น

    เครื่องคำนวณการแปลงลาปลาซ เครื่องคำนวณการแปลงลาปลาซผกผัน เครื่องคำนวณอนุกรมฟูเรียร์ เครื่องคำนวณอนุพันธ์ เครื่องคำนวณปริพันธ์ (อินทิเกรต) เครื่องคำนวณพื้นที่ เครื่องคำนวณเพาเวอร์แฟกเตอร์ เครื่องคำนวณค่าไฟฟ้า กฟน. กฟภ. ดูเครื่องมือทั้งหมด →

    คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

    เว็บไซต์ หน้าแรก คลังความรู้ อัปเดตล่าสุด · บันทึกการปรับปรุง บทความแยกหมวด: Python ยุค AI เมทริกซ์ ลำดับและอนุกรม Laplace ฯลฯ Articles in English เฉลยโจทย์ทีละขั้น: อินทิเกรต อนุพันธ์ ลาปลาซ ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม เครื่องคิดเลขลำดับและอนุกรม พร้อมวิธีทำ อุปนัยเชิงคณิตศาสตร์ อุปนัยแบบเข้ม (Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ แรงก์ (ค่าลำดับขั้น) ของเมทริกซ์ ผลเฉลยเชิงตัวเลข: LU จาโคบี เกาส์-ไซเดล แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ คราเมอร์ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือคำนวณ: อนุพันธ์ ปริพันธ์ ลาปลาซ ฟูเรียร์ พื้นที่ คำนวณค่าไฟฟ้า กฟน. กฟภ.
