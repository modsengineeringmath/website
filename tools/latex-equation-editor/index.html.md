# เครื่องมือเขียนสมการ LaTeX ออนไลน์: พิมพ์สมการแล้วดาวน์โหลดเป็นรูป PNG หรือ SVG

THภาษาไทยENEnglish
// เครื่องมือ · LaTeX Equation Editor


พิมพ์สมการเป็นข้อความธรรมดา เช่น y = x^2*sin(3x)/(1+x) หรือพิมพ์ LaTeX โดยตรง ระบบจะจัดเรียงสมการให้สวยแบบตำรา แล้วให้ดาวน์โหลดเป็นรูป PNG พื้นหลังโปร่งใสหรือไฟล์ SVG แบบเวกเตอร์ เหมาะกับการทำสไลด์ ใบงาน ข้อสอบ และภาพประกอบโพสต์

## เครื่องมือ

ต้องเปิด JavaScript เพื่อใช้เครื่องมือนี้

## วิธีใช้งาน

- เลือกวิธีพิมพ์ ถ้ายังไม่เคยใช้ LaTeX ให้เลือก “พิมพ์สมการแบบธรรมดา” แล้วพิมพ์ด้วยเครื่องหมายบนแป้นพิมพ์ปกติ: ^ คือยกกำลัง / คือหาร sqrt( ) คือราก pi คือ π ระบบจะแปลงเป็น LaTeX ให้ในช่องด้านล่าง และแก้ต่อได้

- ใช้แผงสัญลักษณ์ กดปุ่มเศษส่วน ราก อินทิกรัล ซิกมา ลิมิต อักษรกรีก เมทริกซ์ หรือฟังก์ชันเป็นช่วง ช่อง □ คือที่ว่างให้พิมพ์ต่อ ถ้าลากคลุมข้อความไว้ก่อนกด ข้อความนั้นจะถูกใส่ลงในช่องแรก

- ปรับรูป เลือกขนาดตัวอักษร สี พื้นหลัง (โปร่งใส ขาว ดำ ครีม) ระยะขอบ และความละเอียดของ PNG (3× เหมาะกับสไลด์ 4× เหมาะกับงานพิมพ์)

- นำไปใช้ กดดาวน์โหลด PNG หรือ SVG หรือกด “คัดลอกรูปไปวาง” แล้ววางใน Word PowerPoint Google Docs LINE ได้ทันที ปุ่ม “คัดลอกลิงก์สมการนี้” ให้ลิงก์ที่เปิดมาแล้วเห็นสมการเดิม ใช้ส่งต่อให้เพื่อนหรือเก็บไว้แก้ภายหลัง

## ตารางคำสั่ง LaTeX ที่ใช้บ่อย

| ต้องการ | พิมพ์ | ผลลัพธ์ |

| เศษส่วน | \frac{a}{b} | $\frac{a}{b}$ |

| ยกกำลัง / ตัวห้อย | x^{2} · a_{n} | $x^{2},\ a_{n}$ |

| ราก | \sqrt{x} · \sqrt[3]{x} | $\sqrt{x},\ \sqrt[3]{x}$ |

| อินทิกรัลจำกัดเขต | \int_{0}^{1} x^2\,dx | $\int_{0}^{1} x^2\,dx$ |

| ผลรวม | \sum_{n=1}^{\infty} \frac{1}{n^2} | $\sum_{n=1}^{\infty} \frac{1}{n^2}$ |

| ลิมิต | \lim_{x \to 0} \frac{\sin x}{x} | $\lim_{x \to 0} \frac{\sin x}{x}$ |

| อนุพันธ์ย่อย | \frac{\partial f}{\partial x} | $\frac{\partial f}{\partial x}$ |

| อักษรกรีก | \alpha \beta \omega \Omega | $\alpha\ \beta\ \omega\ \Omega$ |

| วงเล็บปรับขนาด | \left( \frac{a}{b} \right) | $\left( \frac{a}{b} \right)$ |

| ข้อความในสมการ | \text{กำลัง} = VI | $\text{กำลัง} = VI$ |

| การแปลงลาปลาซ | \mathcal{L}\{f(t)\} | $\mathcal{L}\{f(t)\}$ |

| เว้นวรรค | \, แคบ · \quad กว้าง | $a\,b \quad c$ |

เมทริกซ์ ฟังก์ชันเป็นช่วง และสมการหลายบรรทัดที่จัดเครื่องหมายเท่ากับให้ตรงกัน กดจากแผง “โครงสร้าง” ได้เลย ไม่ต้องจำคำสั่ง

## ควรเลือก PNG หรือ SVG

PNG เป็นรูปแบบจุดภาพ เปิดได้ทุกโปรแกรมและทุกแอป เหมาะกับการโพสต์ ส่งทาง LINE และวางในเอกสารทั่วไป ถ้าจะขยายรูปให้ใหญ่ ให้เลือกความละเอียด 3× หรือ 4× ตั้งแต่ตอนดาวน์โหลด

SVG เป็นรูปแบบเวกเตอร์ ขยายเท่าใดก็ไม่แตก ไฟล์เล็ก และแก้สีต่อได้ Word และ PowerPoint รุ่น 2019 ขึ้นไป Google Slides Canva Figma และ Inkscape วางไฟล์ SVG ได้โดยตรง เหมาะกับตำรา โปสเตอร์วิชาการ และงานพิมพ์

ถ้าพื้นหลังของสไลด์เป็นสีเข้ม ให้เลือกพื้นหลัง “โปร่งใส” แล้วเปลี่ยนสีตัวอักษรเป็นสีขาว

## ความเป็นส่วนตัวและการทำงานแบบออฟไลน์

การจัดเรียงสมการและการสร้างรูปทำในเบราว์เซอร์ของคุณทั้งหมด สมการไม่ถูกส่งขึ้นเซิร์ฟเวอร์ จึงใช้กับข้อสอบหรือเอกสารที่ยังไม่เผยแพร่ได้ ตัวจัดเรียงที่ใช้คือ MathJax 3 ซึ่งให้ผลลัพธ์แบบเดียวกับที่วารสารวิชาการใช้

## คำถามที่พบบ่อย

ต้องรู้ LaTeX ก่อนไหม?
ไม่ต้อง เลือกโหมด “พิมพ์สมการแบบธรรมดา” แล้วพิมพ์เช่น x^2/(1+x) หรือ sqrt(x^2+1) ระบบจะแปลงเป็น LaTeX ให้ และยังกดแผงสัญลักษณ์เพิ่มเศษส่วน อินทิกรัล หรือเมทริกซ์ได้

รูปที่ได้นำไปใช้เชิงพาณิชย์ได้ไหม?
ได้ สมการเป็นของผู้พิมพ์ รูปที่สร้างไม่มีลายน้ำและไม่ต้องอ้างอิงเว็บไซต์นี้

พิมพ์ภาษาไทยในสมการได้ไหม?
ได้ ให้ใส่ข้อความไทยไว้ใน \text{ } เช่น \text{แรงดัน} = IR ข้อความจะแสดงด้วยฟอนต์ไทยของเครื่อง

ทำไมกดคัดลอกรูปแล้ววางไม่ได้?
การคัดลอกรูปลงคลิปบอร์ดต้องใช้เบราว์เซอร์รุ่นใหม่ (Chrome, Edge, Safari 13.1 ขึ้นไป) และเปิดเว็บผ่าน https ถ้าใช้ไม่ได้ให้กดดาวน์โหลด PNG แทน
