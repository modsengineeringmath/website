    วิธีพิมพ์ F(s)

    • ใช้ตัวแปร s และวงเล็บครอบทั้งเศษและส่วน: (s+3)/((s+1)(s+2)^2)
    • ตัวส่วนเขียนแบบกระจายก็ได้: 1/(s^2+2s+5) ระบบจะหาโพลให้
    • ตัวหน่วงเวลาเขียน e^(-2s) คูณไว้ด้านหน้า: e^(-2s)/(s(s+1))

    โพลเชิงซ้อนให้คำตอบเป็นรูปใด?

    ถ้าดีกรีของเศษมากกว่าหรือเท่ากับส่วนต้องทำอย่างไร?

    ต้องหารยาวก่อน ผลหารที่เป็นค่าคงที่จะให้ δ(t) และผลหารที่มี s จะให้อนุพันธ์ของ δ(t) เครื่องมือทำขั้นนี้ให้อัตโนมัติและแสดงในวิธีทำ

    e^{-2s} ในโจทย์หมายถึงอะไร?

    คือการหน่วงเวลา 2 วินาที ให้แปลงส่วนที่เหลือเป็น g(t) แล้วแทน t ด้วย t − 2 และคูณด้วย u(t − 2)

    ทำไมคำตอบมีเงื่อนไข t ≥ 0?

    การแปลงลาปลาซด้านเดียวนิยามจาก t = 0 ถึงอนันต์ คำตอบจึงใช้ได้เมื่อ t ≥ 0 และถือว่า f(t) = 0 เมื่อ t < 0
