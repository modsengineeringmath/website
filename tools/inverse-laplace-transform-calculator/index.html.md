# เครื่องคำนวณการแปลงลาปลาซผกผัน (Inverse Laplace Transform) ด้วยเศษส่วนย่อย พร้อมวิธีทำ

พิมพ์ $F(s)$ ในรูปเศษส่วนของพหุนาม แล้วรับ $f(t)$ พร้อมวิธีทำด้วยเศษส่วนย่อย: หารยาว (ถ้าจำเป็น) แยกตัวประกอบตัวส่วน หาสัมประสิทธิ์ และแปลงกลับทีละพจน์ ผลลัพธ์ถูกตรวจโดยแปลงลาปลาซของคำตอบเชิงตัวเลขแล้วเทียบกับ $F(s)$

## วิธีพิมพ์ F(s)

- ใช้ตัวแปร s และวงเล็บครอบทั้งเศษและส่วน: (s+3)/((s+1)(s+2)^2)

- ตัวส่วนเขียนแบบกระจายก็ได้: 1/(s^2+2s+5) ระบบจะหาโพลให้

- ตัวหน่วงเวลาเขียน e^(-2s) คูณไว้ด้านหน้า: e^(-2s)/(s(s+1))

- บวกหลายพจน์ได้: 1/s - e^(-s)/s

## หลักการแยกเศษส่วนย่อย

ถ้าดีกรีของเศษไม่น้อยกว่าดีกรีของส่วน ให้หารยาวก่อน จากนั้นแยกตัวประกอบตัวส่วนแล้วเขียนรูปของเศษส่วนย่อยตามชนิดของโพล

| ชนิดของโพล | พจน์ใน $F(s)$ | พจน์ใน $f(t)$ |

| โพลจริงไม่ซ้ำที่ $s = p$ | $\dfrac{A}{s-p}$ | $Ae^{pt}$ |

| โพลจริงซ้ำ $m$ ครั้ง | $\dfrac{A_k}{(s-p)^{k}}$, $k = 1,\dots,m$ | $\dfrac{A_k}{(k-1)!}\,t^{k-1}e^{pt}$ |

| โพลเชิงซ้อนสังยุค $\sigma \pm j\omega$ | $\dfrac{B(s-\sigma) + C\omega}{(s-\sigma)^{2}+\omega^{2}}$ | $e^{\sigma t}(B\cos\omega t + C\sin\omega t)$ |

| ตัวหน่วง $e^{-as}$ | $e^{-as}G(s)$ | $g(t-a)\,u(t-a)$ |

สัมประสิทธิ์ของโพลไม่ซ้ำหาด้วยวิธีปิดทับ (cover-up): $A = \left[(s-p)F(s)\right]_{s=p}$ ส่วนโพลซ้ำใช้อนุพันธ์: $A_k = \dfrac{1}{(m-k)!}\dfrac{d^{\,m-k}}{ds^{\,m-k}}\left[(s-p)^{m}F(s)\right]_{s=p}$

## ตัวอย่างคิดมือ

หา $\mathcal{L}^{-1}\left\{\dfrac{s+3}{(s+1)(s+2)^{2}}\right\}$ เขียนรูปเศษส่วนย่อย

$$\frac{s+3}{(s+1)(s+2)^{2}} = \frac{A}{s+1} + \frac{B_1}{s+2} + \frac{B_2}{(s+2)^{2}}$$

$A = \left[\dfrac{s+3}{(s+2)^{2}}\right]_{s=-1} = 2$, $B_2 = \left[\dfrac{s+3}{s+1}\right]_{s=-2} = -1$, $B_1 = \left[\dfrac{d}{ds}\dfrac{s+3}{s+1}\right]_{s=-2} = \left[\dfrac{-2}{(s+1)^{2}}\right]_{s=-2} = -2$

$$f(t) = 2e^{-t} - 2e^{-2t} - te^{-2t}, \quad t \ge 0$$

## ความแม่นยำและข้อจำกัด

โพลหาด้วยวิธีเชิงตัวเลขแล้วปัดเป็นเศษส่วนอย่างง่ายเมื่อค่าตรงกัน ตัวส่วนที่มีรากไม่ลงตัวจะแสดงเป็นทศนิยม 4 ตำแหน่ง หลังได้ $f(t)$ ระบบจะคำนวณ $\int_0^\infty f(t)e^{-st}\,dt$ เชิงตัวเลขแล้วเทียบกับ $F(s)$ ถ้าไม่ตรงจะไม่แสดงคำตอบ เครื่องมือนี้รับเฉพาะ $F(s)$ ที่เป็นเศษส่วนของพหุนาม (คูณด้วย $e^{-as}$ ได้) ฟังก์ชันอย่าง $\dfrac{1}{\sqrt{s}}$ หรือ $\ln s$ อยู่นอกขอบเขต

## เรียนทฤษฎีต่อ

- บทเรียนการแปลงลาปลาซผกผัน

- บทความ: ลาปลาซผกผันด้วยเศษส่วนย่อย

- เครื่องคำนวณการแปลงลาปลาซ (ไปข้างหน้า)

- ผลตอบสนองเชิงเวลาของระบบควบคุม

## คำถามที่พบบ่อย

โพลเชิงซ้อนให้คำตอบเป็นรูปใด?
โพลคู่สังยุค σ ± jω ให้พจน์ e^{σt}(B cos ωt + C sin ωt) และเครื่องมือยังเขียนในรูปแอมพลิจูดกับมุมเฟส M e^{σt} cos(ωt + φ) ให้ด้วย

ถ้าดีกรีของเศษมากกว่าหรือเท่ากับส่วนต้องทำอย่างไร?
ต้องหารยาวก่อน ผลหารที่เป็นค่าคงที่จะให้ δ(t) และผลหารที่มี s จะให้อนุพันธ์ของ δ(t) เครื่องมือทำขั้นนี้ให้อัตโนมัติและแสดงในวิธีทำ

e^{-2s} ในโจทย์หมายถึงอะไร?
คือการหน่วงเวลา 2 วินาที ให้แปลงส่วนที่เหลือเป็น g(t) แล้วแทน t ด้วย t − 2 และคูณด้วย u(t − 2)

ทำไมคำตอบมีเงื่อนไข t ≥ 0?
การแปลงลาปลาซด้านเดียวนิยามจาก t = 0 ถึงอนันต์ คำตอบจึงใช้ได้เมื่อ t ≥ 0 และถือว่า f(t) = 0 เมื่อ t
