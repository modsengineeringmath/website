# เครื่องคำนวณอนุพันธ์ (Derivative Calculator): หา f′(x) พร้อมวิธีทำ กฎที่ใช้ และกราฟ

พิมพ์ $f(x)$ แล้วรับ $f'(x)$ ที่จัดรูปแล้ว พร้อมวิธีทำทีละพจน์ว่าใช้กฎใด เลือกอันดับของอนุพันธ์ได้ถึงอันดับ 4 แทนค่าที่จุดเพื่อหาความชันและสมการเส้นสัมผัส และดูกราฟ $f$ กับอนุพันธ์บนแกนเดียวกัน

## วิธีพิมพ์ฟังก์ชัน

- คูณเขียนติดกันได้: 3x, x sin(x), (x+1)(x-2) · ยกกำลัง x^3 · หาร (x^2+1)/(x-1)

- ฟังก์ชันที่รองรับ: sin cos tan sec csc cot, asin acos atan, sinh cosh tanh, exp หรือ e^x, ln, log (ฐาน 10), sqrt, abs

- ตัวอักษรอื่นนอกจากตัวแปรถือเป็นค่าคงที่ เช่น a*x^2 + b*x ได้ $2ax + b$

- ถ้าต้องการหาอนุพันธ์เทียบกับตัวแปรอื่น ให้พิมพ์ชื่อตัวแปรในช่อง “ตัวแปร”

## กฎการหาอนุพันธ์ที่เครื่องมือใช้

| กฎ | สูตร |

| กฎยกกำลัง | $\dfrac{d}{dx}x^{n} = nx^{n-1}$ |

| กฎผลคูณ | $(uv)' = u'v + uv'$ |

| กฎผลหาร | $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^{2}}$ |

| กฎลูกโซ่ | $\dfrac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$ |

| เอกซ์โพเนนเชียลและลอการิทึม | $(e^{x})' = e^{x}$, $(a^{x})' = a^{x}\ln a$, $(\ln x)' = \dfrac{1}{x}$ |

| ตรีโกณมิติ | $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$, $(\tan x)' = \sec^{2}x$ |

| ตรีโกณมิติผกผัน | $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^{2}}}$, $(\arctan x)' = \dfrac{1}{1+x^{2}}$ |

| ฐานและเลขชี้กำลังเป็นฟังก์ชัน | $\left(u^{v}\right)' = u^{v}\left(v'\ln u + \dfrac{v\,u'}{u}\right)$ |

## ตัวอย่างคิดมือ

หาอนุพันธ์ของ $f(x) = x^{3}\sin 2x$ เป็นผลคูณของ $u = x^{3}$ กับ $v = \sin 2x$ โดย $u' = 3x^{2}$ และ $v' = 2\cos 2x$ (กฎลูกโซ่)

$$f'(x) = u'v + uv' = 3x^{2}\sin 2x + 2x^{3}\cos 2x$$

ที่ $x = 1$: $f'(1) = 3\sin 2 + 2\cos 2 \approx 1.8956$ คือความชันของเส้นสัมผัสกราฟที่จุดนั้น

## การตรวจคำตอบ

อนุพันธ์คำนวณด้วยกฎเชิงสัญลักษณ์โดยตรง จึงเป็นคำตอบแม่นตรง ไม่ใช่ค่าประมาณ จากนั้นระบบตรวจซ้ำด้วยอนุพันธ์เชิงตัวเลขแบบผลต่างสืบเนื่องอันดับ 4 ที่จุดทดสอบ 10 จุด รูปของคำตอบอาจต่างจากเฉลยในตำรา (เช่น ยังไม่ดึงตัวร่วม) แต่มีค่าเท่ากัน

## เรียนทฤษฎีต่อ

- บทเรียนอนุพันธ์: สูตรและวิธีทำ

- การประยุกต์อนุพันธ์ทางวิศวกรรม

- เครื่องคำนวณปริพันธ์

- เฉลยโจทย์ทีละขั้น

## คำถามที่พบบ่อย

คำตอบไม่เหมือนเฉลยในหนังสือ ผิดหรือไม่?
ส่วนใหญ่ไม่ผิด อนุพันธ์เขียนได้หลายรูป เช่น 2 sin x cos x กับ sin 2x เท่ากัน ลองแทนค่า x สักค่าในทั้งสองรูปเพื่อตรวจ เครื่องมือนี้ตรวจเชิงตัวเลขให้แล้วทุกครั้ง

หาอนุพันธ์ย่อยได้ไหม?
ได้ พิมพ์ฟังก์ชันหลายตัวแปร เช่น x^2*y + sin(y) แล้วระบุตัวแปรที่ต้องการในช่อง “ตัวแปร” ตัวอักษรอื่นจะถือเป็นค่าคงที่ ซึ่งก็คืออนุพันธ์ย่อย

log หมายถึงฐานใด?
log คือลอการิทึมฐาน 10 ส่วน ln คือลอการิทึมธรรมชาติ ตามที่ใช้ในหลักสูตรไทย

หาอนุพันธ์อันดับสูงได้ถึงอันดับใด?
เลือกได้ถึงอันดับ 4 และระบบแสดงอนุพันธ์ทุกอันดับระหว่างทางให้ด้วย
