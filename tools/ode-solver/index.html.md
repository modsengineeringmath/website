# เครื่องแก้สมการเชิงอนุพันธ์ (ODE Solver): อันดับหนึ่งและอันดับสอง แสดงวิธีทำทุกขั้น

THภาษาไทยENEnglish
// เครื่องมือ · Differential Equation Solver


กรอกสัมประสิทธิ์ a, b, c เลือกรูปแรงบังคับ f(t) ใส่เงื่อนไขเริ่มต้น แล้วกดแก้สมการ เครื่องมือจะเขียนสมการลักษณะเฉพาะ หาราก เลือกรูปคำตอบ หาคำตอบเฉพาะ แทนเงื่อนไขเริ่มต้น และวาดกราฟให้ครบ คำตอบทุกครั้งถูกตรวจซ้ำด้วยวิธีเชิงตัวเลข RK4 ก่อนแสดง ใช้ได้กับโจทย์วงจร RC RL RLC สปริง และเรโซแนนซ์

## เครื่องมือ

ต้องเปิด JavaScript เพื่อใช้เครื่องมือนี้

## วิธีใช้งาน

- เลือกอันดับของสมการ หรือกดปุ่มตัวอย่างด้านบนเพื่อเริ่มจากโจทย์สำเร็จรูป

- กรอก a, b, c ใช้เศษส่วนและค่าคงที่ได้ เช่น 1/2, pi, sqrt(2)

- เลือก f(t) แล้วกรอก A และ ω (หรือ k สำหรับเอกซ์โพเนนเชียล)

- กรอก y(0) และ y′(0) แล้วกดแก้สมการ ลิงก์ของหน้าจะเปลี่ยนตามค่าที่กรอก คัดลอกไปแชร์ได้ทันที

## เครื่องมือแก้สมการอย่างไร

ขั้นตอนเดียวกับที่สอนในบทสมการเชิงอนุพันธ์ แบ่งเป็นสามท่อน

- ส่วนเอกพันธ์: แทน $y = e^{rt}$ ได้สมการลักษณะเฉพาะ $ar^2 + br + c = 0$ รากจริง รากซ้ำ หรือรากเชิงซ้อนบอกรูปของ $y_h$

- คำตอบเฉพาะ: เดารูปตามชนิดของ f(t) (วิธีเดาสัมประสิทธิ์) ถ้ารูปที่เดาซ้ำกับ $y_h$ ให้คูณ t (กรณีเรโซแนนซ์)

- เงื่อนไขเริ่มต้น: แทน y(0) และ y′(0) ลงใน $y = y_h + y_p$ แก้หาค่าคงที่ C₁ C₂

| รากของ $ar^2 + br + c = 0$ | รูปของ $y_h$ | ระบบจริง |

| จริงสองค่า $r_1, r_2$ | $C_1e^{r_1t} + C_2e^{r_2t}$ | หน่วงเกิน ไม่แกว่ง |

| ซ้ำ $r$ | $(C_1 + C_2t)e^{rt}$ | หน่วงวิกฤต เข้าเร็วที่สุดโดยไม่แกว่ง |

| เชิงซ้อน $\alpha \pm j\beta$ | $e^{\alpha t}(C_1\cos\beta t + C_2\sin\beta t)$ สูตรออยเลอร์ | หน่วงน้อย แกว่งแล้วค่อย ๆ หยุด |

| f(t) | รูปที่เดา $y_p$ | ถ้าซ้ำกับ $y_h$ |

| ค่าคงที่ K | $A$ | คูณ t |

| $Ae^{kt}$ | $Be^{kt}$ | คูณ t หรือ t² (ถ้า k เป็นรากซ้ำ) |

| $A\cos\omega t$ หรือ $A\sin\omega t$ | $P\cos\omega t + Q\sin\omega t$ เลื่อนเฟส 90° (โคฟังก์ชัน) | คูณ t (เรโซแนนซ์) |

## ตัวอย่าง: สปริงหน่วงน้อย

$y'' + 2y' + 5y = 0$, $y(0) = 1$, $y'(0) = 0$ คือค่าเริ่มต้นของเครื่องมือ

- $r^2 + 2r + 5 = 0 \Rightarrow r = -1 \pm 2j$ จึงได้ $y = e^{-t}(C_1\cos2t + C_2\sin2t)$ สูตรออยเลอร์

- $y(0) = C_1 = 1$ และ $y'(0) = -C_1 + 2C_2 = 0 \Rightarrow C_2 = \tfrac12$

- รวมเป็นคลื่นเดียว รวมเป็นคลื่นเดียว $R = \sqrt{1 + \tfrac14} = \tfrac{\sqrt5}{2} \approx 1.118$, $\tan\varphi = \tfrac12 \Rightarrow \varphi \approx 26.57^\circ$

$y = e^{-t}\big(\cos2t + \tfrac12\sin2t\big) = 1.118\,e^{-t}\cos(2t - 26.57^\circ)$ · ζ = 1/√5 ≈ 0.447, ωₙ = √5

ตัวอย่างที่สอง กดปุ่ม "RLC รับไฟ DC": $y'' + 4y' + 3y = 3$ เริ่มจากศูนย์ ได้ $y_p = 1$, ราก −1 และ −3 แทนเงื่อนไขเริ่มต้นได้ $y = 1 - \tfrac32e^{-t} + \tfrac12e^{-3t}$ เข้าสู่ 1 โดยไม่แกว่ง (หน่วงเกิน ζ ≈ 1.155)

## เรียนทฤษฎีต่อ

- สมการอันดับหนึ่ง: แยกตัวแปร ตัวประกอบอินทิเกรต แม่นตรง

- สมการอันดับสอง: สามกรณีของราก และทำไมรากเชิงซ้อนให้ cos sin

- สมการไม่เอกพันธ์: เดาสัมประสิทธิ์ เรโซแนนซ์ บีต

- การประยุกต์: สปริง RLC ไฟ AC

- โจทย์สมการเชิงอนุพันธ์พร้อมเฉลย 32 ข้อ

- แก้สมการเชิงอนุพันธ์ด้วยการแปลงลาปลาซ

## คำถามที่พบบ่อย

เครื่องแก้สมการเชิงอนุพันธ์นี้แก้สมการแบบไหนได้?
สมการเชิงเส้นสัมประสิทธิ์คงที่อันดับหนึ่ง ay′ + by = f(t) และอันดับสอง ay″ + by′ + cy = f(t) เมื่อ f(t) เป็นศูนย์ ค่าคงที่ เอกซ์โพเนนเชียล Ae^{kt} หรือไซน์ A cos ωt และ A sin ωt พร้อมเงื่อนไขเริ่มต้น ครอบคลุมโจทย์วงจร RC RL RLC มวล-สปริง และเรโซแนนซ์

เชื่อคำตอบได้แค่ไหน?
ทุกครั้งที่แก้ เครื่องมือจะแก้สมการเดียวกันซ้ำด้วยวิธีเชิงตัวเลข Runge–Kutta อันดับ 4 แล้วเทียบกับสูตรรูปปิดตลอดช่วงเวลา ถ้าต่างกันเกินเกณฑ์ จะไม่แสดงสูตรและแสดงเฉพาะกราฟเชิงตัวเลข จุดวงกลมบนกราฟคือค่าจาก RK4

ทำไมรากเชิงซ้อนให้คำตอบเป็น cos กับ sin?
รากเชิงซ้อน α ± jβ ให้ e^{(α+jβ)t} = e^{αt}(cos βt + j sin βt) ตามสูตรออยเลอร์ สมการมีสัมประสิทธิ์จริง ส่วนจริงและส่วนจินตภาพจึงเป็นคำตอบแยกกันได้ ได้ e^{αt}(C₁ cos βt + C₂ sin βt)

เรโซแนนซ์คืออะไรในเครื่องมือนี้?
ถ้าแรงบังคับมีความถี่เท่ากับความถี่ธรรมชาติพอดีและไม่มีการหน่วง (b = 0) คำตอบเฉพาะต้องคูณ t ทำให้ขนาดโตขึ้นเป็นเส้นตรงตามเวลา ลองกดปุ่มตัวอย่างเรโซแนนซ์เพื่อดูกราฟ

แชร์ผลลัพธ์ให้คนอื่นได้ไหม?
ได้ ทุกครั้งที่กดแก้สมการ ค่าที่กรอกจะถูกเก็บไว้ในลิงก์ของหน้า คัดลอก URL จากแถบที่อยู่แล้วส่งต่อ คนที่เปิดจะเห็นสมการเดียวกันพร้อมวิธีทำ
