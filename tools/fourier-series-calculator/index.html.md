# เครื่องคำนวณอนุกรมฟูเรียร์ (Fourier Series Calculator): หา a₀ aₙ bₙ พร้อมกราฟผลรวมบางส่วน

กำหนดฟังก์ชันหนึ่งคาบเป็นช่วง ๆ หรือเลือกรูปคลื่นสำเร็จรูป แล้วรับสัมประสิทธิ์ $a_0$, $a_n$, $b_n$ ในรูปปิด (เช่น $\frac{4}{\pi}$) พร้อมตารางฮาร์มอนิก ค่า RMS ค่า THD และกราฟเปรียบเทียบ $f(t)$ กับผลรวมบางส่วนที่เลื่อนจำนวนพจน์ได้

## เครื่องมือ

ต้องเปิด JavaScript เพื่อใช้เครื่องมือนี้

## วิธีใช้งาน

- เลือกรูปคลื่นสำเร็จรูป หรือพิมพ์ $f(t)$ เองทีละช่วง เช่น ช่วงที่ 1: 1 ตั้งแต่ 0 ถึง pi ช่วงที่ 2: -1 ตั้งแต่ pi ถึง 2*pi

- ใส่คาบ $T$ ให้เท่ากับความยาวรวมของทุกช่วง ใช้ pi ได้ เช่น 2*pi

- เลือกจำนวนฮาร์มอนิก $N$ แล้วกดคำนวณ จากนั้นเลื่อนแถบใต้กราฟเพื่อดูว่าผลรวมบางส่วนเข้าใกล้ $f(t)$ อย่างไร

## สูตรสัมประสิทธิ์ฟูเรียร์

ฟังก์ชันคาบ $f(t)$ ที่มีคาบ $T$ และความถี่เชิงมุมมูลฐาน $\omega_0 = \dfrac{2\pi}{T}$ เขียนเป็นอนุกรมฟูเรียร์ได้ว่า

$$f(t) = a_0 + \sum_{n=1}^{\infty}\left(a_n\cos n\omega_0 t + b_n\sin n\omega_0 t\right)$$

$$a_0 = \frac{1}{T}\int_{T} f(t)\,dt, \qquad a_n = \frac{2}{T}\int_{T} f(t)\cos n\omega_0 t\,dt, \qquad b_n = \frac{2}{T}\int_{T} f(t)\sin n\omega_0 t\,dt$$

หน้านี้ใช้ $a_0$ เป็นค่าเฉลี่ยของสัญญาณโดยตรง ตำราบางเล่มเขียน $\dfrac{a_0}{2}$ ซึ่งทำให้ $a_0$ ของตำรานั้นมีค่าเป็นสองเท่าของค่าในหน้านี้

## สมมาตรช่วยลดงาน

| สมมาตร | เงื่อนไข | ผล |

| ฟังก์ชันคู่ | $f(-t) = f(t)$ | $b_n = 0$ มีเฉพาะพจน์โคไซน์ |

| ฟังก์ชันคี่ | $f(-t) = -f(t)$ | $a_0 = a_n = 0$ มีเฉพาะพจน์ไซน์ |

| สมมาตรครึ่งคลื่น | $f(t + T/2) = -f(t)$ | มีเฉพาะฮาร์มอนิกคี่ |

เครื่องมือตรวจสมมาตรจากสัมประสิทธิ์ที่คำนวณได้แล้วแจ้งให้ ใช้ตรวจคำตอบที่คิดด้วยมือได้ทันที

## ตัวอย่าง: คลื่นสี่เหลี่ยม

คลื่นสี่เหลี่ยม $f(t) = 1$ เมื่อ $0 \le t ค่า THD ของคลื่นสี่เหลี่ยมคือร้อยละ 48.34 ตรงกับที่เครื่องมือแสดง ยอดเกินใกล้จุดกระโดดประมาณร้อยละ 9 ของขนาดการกระโดดคือปรากฏการณ์กิบส์ ซึ่งไม่หายไปแม้เพิ่มจำนวนฮาร์มอนิก

- ตารางอนุกรมฟูเรียร์ของรูปคลื่นมาตรฐาน
