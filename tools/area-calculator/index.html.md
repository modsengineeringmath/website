# เครื่องคำนวณพื้นที่: รูปทรงเรขาคณิต พื้นที่ใต้กราฟ รูปหลายเหลี่ยมจากพิกัด และหน่วย ไร่ งาน ตารางวา

เครื่องมือเดียวสำหรับงานหาพื้นที่ทุกแบบ: เลือกรูปทรงแล้วใส่ขนาด หาพื้นที่ใต้กราฟหรือระหว่างสองเส้นโค้งด้วยปริพันธ์ (หาจุดตัดให้อัตโนมัติ) หาพื้นที่แปลงที่ดินจากพิกัดจุดยอด และแปลงหน่วยระหว่างไร่ งาน ตารางวา กับตารางเมตร

## สูตรหาพื้นที่รูปทรงเรขาคณิต

| รูปทรง | สูตรพื้นที่ |

| สี่เหลี่ยมผืนผ้า | $A = ab$ |

| สามเหลี่ยม | $A = \tfrac{1}{2}bh$ |

| สามเหลี่ยม รู้ 3 ด้าน (สูตรเฮรอน) | $A = \sqrt{s(s-a)(s-b)(s-c)}$, $s = \tfrac{a+b+c}{2}$ |

| สามเหลี่ยม รู้ 2 ด้านกับมุมระหว่างด้าน | $A = \tfrac{1}{2}ab\sin C$ |

| วงกลม | $A = \pi r^{2}$ |

| เซกเตอร์ มุม $\theta$ องศา | $A = \dfrac{\theta}{360^{\circ}}\pi r^{2}$ |

| วงรี | $A = \pi ab$ |

| สี่เหลี่ยมคางหมู | $A = \tfrac{1}{2}(a+b)h$ |

| สี่เหลี่ยมด้านขนาน | $A = bh$ |

| สี่เหลี่ยมขนมเปียกปูน | $A = \tfrac{1}{2}pq$ |

| รูป $n$ เหลี่ยมด้านเท่ามุมเท่า | $A = \dfrac{na^{2}}{4\tan(\pi/n)}$ |

| วงแหวน | $A = \pi(R^{2} - r^{2})$ |

## พื้นที่ใต้กราฟและระหว่างสองเส้นโค้ง

พื้นที่ระหว่าง $y = f(x)$ กับ $y = g(x)$ จาก $x = a$ ถึง $x = b$ คือ

$$A = \int_{a}^{b}\left|f(x) - g(x)\right|dx$$

ถ้าเส้นโค้งตัดกันภายในช่วง ต้องแบ่งคิดทีละช่วงแล้วรวมค่าสัมบูรณ์ เครื่องมือหาจุดตัดและแบ่งช่วงให้อัตโนมัติ ตัวอย่าง: พื้นที่ระหว่าง $y = x$ กับ $y = x^{2}$ ตัดกันที่ $x = 0$ และ $x = 1$

$$A = \int_{0}^{1}(x - x^{2})\,dx = \left[\frac{x^{2}}{2} - \frac{x^{3}}{3}\right]_{0}^{1} = \frac{1}{6}$$

## หน่วยวัดที่ดินของไทย

| หน่วย | เท่ากับ | ตารางเมตร |

| 1 ตารางวา | 2 เมตร × 2 เมตร | 4 ตร.ม. |

| 1 งาน | 100 ตารางวา | 400 ตร.ม. |

| 1 ไร่ | 4 งาน = 400 ตารางวา | 1,600 ตร.ม. |

| 1 เฮกตาร์ | 6 ไร่ 1 งาน | 10,000 ตร.ม. |

| 1 เอเคอร์ | ประมาณ 2 ไร่ 2 งาน 12 ตารางวา | 4,046.86 ตร.ม. |

ตัวอย่าง: ที่ดิน 1 ไร่ 2 งาน 50 ตารางวา = $1{,}600 + 800 + 200 = 2{,}600$ ตารางเมตร

## พื้นที่รูปหลายเหลี่ยมจากพิกัด

ถ้ารู้พิกัดจุดยอด $(x_i, y_i)$ เรียงตามขอบรูป พื้นที่หาได้จากสูตรเชือกผูกรองเท้า (shoelace formula) ซึ่งเป็นวิธีที่ช่างรังวัดใช้คำนวณเนื้อที่จากค่าพิกัดหมุดหลักเขต

$$A = \frac{1}{2}\left|\sum_{i=1}^{n}\left(x_i y_{i+1} - x_{i+1} y_i\right)\right|, \qquad (x_{n+1}, y_{n+1}) = (x_1, y_1)$$

ใส่พิกัดเป็นเมตรหรือวาก็ได้ ผลลัพธ์จะแสดงเป็นไร่ งาน ตารางวาให้ด้วย ค่าที่ได้ใช้ประมาณการเท่านั้น เนื้อที่ตามกฎหมายต้องยึดตามโฉนดและการรังวัดของกรมที่ดิน

## เรียนทฤษฎีต่อ

- เครื่องคำนวณปริพันธ์

- การประยุกต์อินทิกรัล: พื้นที่ ปริมาตร จุดเซนทรอยด์

- กฎไซน์ กฎโคไซน์ และเครื่องแก้สามเหลี่ยม

- สูตรตรีโกณมิติทั้งหมด

## คำถามที่พบบ่อย

1 ไร่เท่ากับกี่ตารางเมตร?
1 ไร่ = 4 งาน = 400 ตารางวา = 1,600 ตารางเมตร เพราะ 1 ตารางวาคือพื้นที่ 2 เมตร × 2 เมตร = 4 ตารางเมตร

พื้นที่ใต้กราฟต่างจากปริพันธ์จำกัดเขตอย่างไร?
ปริพันธ์จำกัดเขตนับส่วนใต้แกน x เป็นลบ ส่วนพื้นที่นับเป็นบวกทั้งหมด เช่น ∫ sin x dx จาก 0 ถึง 2π เท่ากับ 0 แต่พื้นที่เท่ากับ 4

หาพื้นที่ที่ดินรูปร่างไม่ปกติได้อย่างไร?
วัดพิกัดของหมุดแต่ละมุมเทียบกับจุดอ้างอิงเดียวกัน แล้วใส่ในแท็บ “รูปหลายเหลี่ยมจากพิกัด” เรียงตามลำดับรอบแปลง หรือแบ่งแปลงเป็นสามเหลี่ยมแล้วใช้สูตรเฮรอนกับความยาวด้านที่วัดได้

สูตรเฮรอนใช้เมื่อใด?
ใช้เมื่อรู้ความยาวทั้งสามด้านของสามเหลี่ยมแต่ไม่รู้ความสูง ซึ่งพบบ่อยในงานวัดพื้นที่จริงเพราะวัดด้านง่ายกว่าวัดความสูง
