How these calculators are built

  • Checked before shown. A derivative is compared with a numerical derivative, an antiderivative is differentiated back, and a Laplace transform is compared with the defining integral. An answer that fails its check is not displayed.
  • Working, not just a result. Each tool shows the rule or table entry used, so the page can be used to learn the method and to mark hand calculations.
  • Private. Calculations run in your browser. What you type is not sent to a server.
  • Linkable results. “Copy link to this result” gives a URL that reopens the same calculation, useful for assignments and discussion.
  • Maintained data. The Thai electricity tariff and Ft are compared with the official MEA, PEA and ERC announcements, and the date of the last comparison is shown under the result.
