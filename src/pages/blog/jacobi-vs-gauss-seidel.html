// บทความ · วิธีเชิงตัวเลข

แก้ระบบสมการเชิงเส้นด้วยวิธีเชิงตัวเลข: เกาส์ LU จาโคบี หรือเกาส์-ไซเดล เลือกวิธีไหนดี

โปรแกรมจำลองวงจร วิเคราะห์โครงสร้าง และคำนวณความร้อนต้องแก้ \(A\mathbf x = \mathbf b\) ที่มีตัวแปรนับพันถึงนับล้าน วิธีที่ใช้ในห้องเรียนจึงไม่พอ บทความนี้เปรียบเทียบวิธีหลักทั้งหมดแบบเห็นภาพรวม ว่าแต่ละวิธีทำงานอย่างไร เร็วแค่ไหน และควรเลือกเมื่อไร

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • วิธีตรง (เกาส์ LU โชเลสกี โทมัส) จบในจำนวนขั้นที่แน่นอน เหมาะกับระบบหนาแน่นขนาดกลาง ต้องสลับแถวเสมอ
  • วิธีทำซ้ำ (จาโคบี เกาส์-ไซเดล SOR) ปรับค่าเดาทีละรอบ เหมาะกับระบบใหญ่และเบาบาง
  • เกาส์-ไซเดลมักเร็วกว่าจาโคบีราวสองเท่า SOR ที่ \(\omega\) เหมาะสมเร็วกว่าอีกหลายเท่า
  • ก่อนเชื่อคำตอบ ดูเลขเงื่อนไข \(\kappa(A)\) ซึ่งบอกว่าอาจเสียความแม่นยำราว \(\log_{10}\kappa\) หลัก

ภาพรวม: วิธีตรงกับวิธีทำซ้ำ

กฎของคราเมอร์ไม่อยู่ในแผนที่นี้ เพราะต้นทุนโตแบบแฟกทอเรียล ระบบ 20 ตัวแปรต้องคูณราว \(5\times10^{19}\) ครั้ง ขณะที่การกำจัดแบบเกาส์ใช้ราว 2,700 ครั้ง (ดูเหตุผลใน บทความกฎของคราเมอร์)

วิธีตรง: เกาส์ LU โชเลสกี และโทมัส

การกำจัดแบบเกาส์ ทำให้ใต้แนวทแยงเป็นศูนย์แล้วแทนค่าย้อนกลับ ใช้ราว \(\tfrac23n^3\) flops จุดสำคัญคือการสลับแถว (partial pivoting) ให้ตัวหลักใหญ่ที่สุดในหลัก ตัวอย่างบนเครื่องที่เก็บ 3 หลักนัยสำคัญ

\[ \begin{aligned} 0.0001x + y &= 1 \\ x + y &= 2 \end{aligned} \qquad \text{ไม่สลับ: } x = 0\ (\text{ผิด}),\qquad \text{สลับแถว: } x = 1.00\ (\text{ถูก}) \]

เพราะตัวคูณ \(1/0.0001 = 10^4\) ทำให้ \(1 - 10^4\) ปัดเป็น \(-1.00\times10^4\) ข้อมูลของสมการแรกหายไปหมด ลองปรับจำนวนหลักเองได้ใน แล็บการสลับแถว

  • การแยก LU คือเกาส์ที่เก็บตัวคูณไว้ใน \(L\) แยกครั้งเดียวแล้วแก้ \(\mathbf b\) ใหม่ได้ด้วยต้นทุนแค่ \(\approx 2n^2\) เหมาะกับวงจรที่แหล่งจ่ายเปลี่ยนแต่โครงสร้างเดิม
  • โชเลสกี \(A = LL^T\) สำหรับเมทริกซ์สมมาตรบวกแน่นอน เช่น เมทริกซ์ความนำของวงจรตัวต้านทาน เร็วกว่า LU สองเท่าและไม่ต้องสลับแถว
  • โทมัส สำหรับเมทริกซ์สามแนวทแยง (แท่งความร้อน สายส่งแบบขั้นบันได) ใช้เวลา \(O(n)\) เช่น แท่งที่ปลาย 100 °C กับ 0 °C แบ่ง 4 โหนดได้ \(T = (80, 60, 40, 20)\) °C

วิธีทำซ้ำ: จาโคบีเทียบเกาส์-ไซเดล

ทั้งสองวิธีแก้สมการที่ \(i\) หา \(x_i\) โดยใช้ค่าประมาณของตัวแปรอื่น ต่างกันแค่ว่าใช้ค่า “เก่า” หรือค่า “ใหม่”

\[ \text{จาโคบี: } x_i^{(k+1)} = \frac{b_i - \sum_{j\ne i}a_{ij}x_j^{(k)}}{a_{ii}},\qquad \text{เกาส์-ไซเดล: ใช้ } x_j^{(k+1)} \text{ ทันทีสำหรับ } j \lt i \]

ระบบ \(4x - y + z = 7,\ 4x - 8y + z = -21,\ -2x + y + 5z = 15\) มีคำตอบ \((2, 4, 3)\) เริ่มที่ \((1, 2, 2)\)

รอบจาโคบีเกาส์-ไซเดล
1(1.750, 3.375, 3.000)(1.750, 3.750, 2.950)
2(1.844, 3.875, 3.025)(1.950, 3.969, 2.986)
3(1.963, 3.925, 2.963)(1.996, 3.996, 2.999)

ลู่เข้าเมื่อไร และ SOR เร่งได้อย่างไร

  • ทแยงเด่นแท้ \(|a_{ii}| \gt \sum_{j\ne i}|a_{ij}|\) ทุกแถว → ลู่เข้าแน่นอน ถ้าไม่ทแยงเด่นให้ลองสลับลำดับสมการก่อน
  • เงื่อนไขแท้คือรัศมีสเปกตรัม \(\rho(T) \lt 1\) และต้องใช้ราว \(d/(-\log_{10}\rho)\) รอบเพื่อเพิ่มความแม่น \(d\) หลัก
  • SOR ก้าวเลยค่าของเกาส์-ไซเดลด้วยตัวประกอบ \(1 \lt \omega \lt 2\) ระบบแท่งความร้อน 10 ตัวแปรต้องใช้ราว 334 รอบ (จาโคบี) 167 รอบ (เกาส์-ไซเดล) แต่ SOR ที่ \(\omega \approx 1.56\) ใช้เพียงราว 24 รอบ

เปรียบเทียบทั้งสามวิธีพร้อมกันได้ใน ซิมูเลเตอร์จาโคบี · เกาส์-ไซเดล · SOR และดูความร้อนแผ่ในแผ่นโลหะทีละรอบใน แล็บแผ่นความร้อน

เลขเงื่อนไข: คำตอบเชื่อได้แค่ไหน

ระบบที่สมการเกือบขนานกัน ข้อมูลผิดนิดเดียวคำตอบเปลี่ยนมาก เช่น \(x + y = 2,\ x + 1.0001y = 2.0001\) มีคำตอบ \((1, 1)\) แต่ถ้าค่าทางขวาเป็น \(2.0002\) คำตอบกลายเป็น \((0, 2)\) เลขเงื่อนไข \(\kappa_\infty \approx 4\times10^4\) จึงอาจเสียความแม่นราว 4–5 หลัก

\[ \frac{\lVert\delta\mathbf x\rVert}{\lVert\mathbf x\rVert} \le \kappa(A)\,\frac{\lVert\delta\mathbf b\rVert}{\lVert\mathbf b\rVert} \]
