// บทความ · ลำดับและอนุกรม

อนุกรมโลรองต์คืออะไร ต่างจากอนุกรมเทย์เลอร์อย่างไร (อธิบายด้วยภาพ)

อนุกรมเทย์เลอร์เขียนฟังก์ชันเป็นพหุนามยาวไม่สิ้นสุดรอบจุดที่ฟังก์ชัน “ปกติดี” แต่ในงานวิศวกรรมเรามักสนใจจุดที่ฟังก์ชันระเบิด เช่น โพลของฟังก์ชันถ่ายโอน อนุกรมโลรองต์แก้ปัญหานี้ด้วยไอเดียเดียว: ยอมให้มีกำลังลบ บทความนี้เทียบสองอนุกรมแบบเห็นภาพ และพาไปถึงเหตุผลที่วิศวกรไฟฟ้าใช้มันทุกวันผ่านการแปลง Z

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • เทย์เลอร์: \(\sum_{n\ge0} a_n(z-c)^n\) ลู่เข้าในดิสก์ · โลรองต์: \(\sum_{n=-\infty}^{\infty} a_n(z-c)^n\) ลู่เข้าในวงแหวน
  • ฟังก์ชันเดียวมีอนุกรมโลรองต์ได้หลายแบบ หนึ่งแบบต่อหนึ่งวงแหวน
  • สัมประสิทธิ์ \(a_{-1}\) คือเรซิดิว · การแปลง Z คืออนุกรมโลรองต์รอบ 0

เทียบกันตรง ๆ

อนุกรมเทย์เลอร์อนุกรมโลรองต์
รูป\(\sum_{n=0}^{\infty} a_n(z-c)^n\)\(\sum_{n=-\infty}^{\infty} a_n(z-c)^n\)
บริเวณที่ลู่เข้าดิสก์ \(|z - c| < R\)วงแหวน \(r_1 < |z - c| < r_2\)
ต้องการf วิเคราะห์ที่ cf วิเคราะห์ในวงแหวน (ที่ c จะเป็นอะไรก็ได้)
สัมประสิทธิ์\(a_n = f^{(n)}(c)/n!\)\(a_n = \frac{1}{2\pi i}\oint\frac{f(z)}{(z-c)^{n+1}}dz\)
จำนวนแบบต่อฟังก์ชันหนึ่งแบบต่อจุด cหนึ่งแบบต่อวงแหวน
ใช้ทำอะไรประมาณค่า ลิมิต ทำให้เป็นเชิงเส้นจำแนกจุดเอกฐาน เรซิดิว อินทิกรัล การแปลง Z

ทำไมต้องมีกำลังลบ

ลองกระจาย \(\dfrac{e^z}{z^2}\) รอบ 0 ด้วยเทย์เลอร์ ทำไม่ได้เพราะ \(f(0)\) ไม่นิยาม แต่ถ้าเอาอนุกรม \(e^z = 1 + z + \tfrac{z^2}{2} + \cdots\) มาหารด้วย \(z^2\) จะได้ทันที

\[ \frac{e^z}{z^2} = \underbrace{\frac{1}{z^2} + \frac{1}{z}}_{\text{ส่วนหลัก}} + \underbrace{\frac12 + \frac{z}{6} + \frac{z^2}{24} + \cdots}_{\text{ส่วนที่เหมือนเทย์เลอร์}},\qquad 0 < |z| < \infty \]

พจน์กำลังลบสองตัวแรกบอกพฤติกรรมใกล้ 0 ทั้งหมด: ฟังก์ชันระเบิดแบบ \(1/z^2\) (โพลอันดับ 2) และพจน์ \(1/z\) มีสัมประสิทธิ์ 1 ซึ่งคือเรซิดิว ส่วนที่เหลือเป็นพหุนามธรรมดาที่ไม่มีปัญหา

ฟังก์ชันเดียว หลายอนุกรม: เรื่องของวงแหวน

นี่คือจุดที่ทำให้นักศึกษาสับสนมากที่สุด \(f(z) = \dfrac{1}{(z-1)(z-2)}\) มีโพลที่ 1 และ 2 วงกลมที่ผ่านโพลแบ่งระนาบรอบ 0 ออกเป็นสามบริเวณ และแต่ละบริเวณมีอนุกรมของตัวเอง

เคล็ดลับมีข้อเดียว: แยกเศษส่วนย่อย \(f = \dfrac{1}{z-2} - \dfrac{1}{z-1}\) แล้วกระจายแต่ละตัวด้วยอนุกรมเรขาคณิต โดยโพลที่อยู่ข้างในบริเวณให้กำลังลบ โพลที่อยู่ข้างนอกให้กำลังบวก

  • (ก) \(|z| < 1\): \(f = \tfrac12 + \tfrac34 z + \tfrac78 z^2 + \cdots\) (ไม่มีกำลังลบ = เทย์เลอร์)
  • (ข) \(1 < |z| < 2\): \(f = \cdots - \tfrac{1}{z^2} - \tfrac{1}{z} - \tfrac12 - \tfrac{z}{4} - \tfrac{z^2}{8} - \cdots\) (มีทั้งสองทิศ)
  • (ค) \(|z| > 2\): \(f = \tfrac{1}{z^2} + \tfrac{3}{z^3} + \tfrac{7}{z^4} + \cdots\) (มีแต่กำลังลบ)

ตรวจด้วยการแทนค่าก็ได้: ที่ \(z = 1.5\) อนุกรม (ข) ลู่เข้าสู่ \(f(1.5) = -4\) แต่ถ้าใช้อนุกรม (ก) ที่ \(z = 1.5\) จะลู่ออก ทั้งที่ f(1.5) มีค่าปกติ ลองลากจุดดูเองในแล็บวงแหวนโลรองต์

อ่านชนิดจุดเอกฐานจากส่วนหลัก

  • ไม่มีกำลังลบ → ถอดได้ เช่น \(\tfrac{\sin z}{z} = 1 - \tfrac{z^2}{6} + \cdots\)
  • กำลังลบจำนวนจำกัด สูงสุด m → โพลอันดับ m เช่น \(\tfrac{\sin z}{z^4} = \tfrac{1}{z^3} - \tfrac{1}{6z} + \cdots\) (อันดับ 3)
  • กำลังลบอนันต์พจน์ → เอกฐานแท้ เช่น \(e^{1/z} = 1 + \tfrac1z + \tfrac{1}{2z^2} + \cdots\)

เรซิดิว: ตัวเลขตัวเดียวที่เหลือจากอินทิกรัล

เมื่ออินทิเกรตอนุกรมโลรองต์รอบวงกลมในวงแหวน ทุกพจน์ \((z-c)^n\) ให้ศูนย์ ยกเว้น \(n = -1\) ที่ให้ \(2\pi i\) ดังนั้น \(\oint f\,dz = 2\pi i\,a_{-1}\) ตัวเลข \(a_{-1}\) จึงชื่อเรซิดิว (ส่วนที่เหลือ) และนี่คือที่มาของเทคนิค “cover-up” ในการแยกเศษส่วนย่อยเพื่อหาการแปลงลาปลาซผกผัน ซึ่งแท้จริงคือการหาเรซิดิวที่แต่ละโพล

ทำไมวิศวกรไฟฟ้าต้องรู้: การแปลง Z

การแปลง Z ของสัญญาณดิจิทัล \(X(z) = \sum x[n]z^{-n}\) คืออนุกรมโลรองต์รอบ 0 โดยตรง สัญญาณ x[n] คือสัมประสิทธิ์ของ \(z^{-n}\) เรื่องที่ตำราระบบสัญญาณเรียก “ROC” ก็คือวงแหวนการลู่เข้า ตัวอย่าง \(X(z) = \dfrac{z}{z - 0.5}\):

  • ROC \(|z| > 0.5\) (นอกโพล): \(X = 1 + 0.5z^{-1} + 0.25z^{-2} + \cdots\) ⇒ \(x[n] = 0.5^n u[n]\) สัญญาณข้างขวา
  • ROC \(|z| < 0.5\) (ในโพล): กระจายเป็นกำลังบวก ⇒ \(x[n] = -0.5^n u[-n-1]\) สัญญาณข้างซ้าย

สูตรเดียวกัน สองสัญญาณ ต่างกันที่วงแหวน และระบบเสถียรเมื่อวงแหวนครอบวงกลมหนึ่งหน่วย ซึ่งคือเงื่อนไขการลู่เข้าแบบสัมบูรณ์ \(\sum|h[n]| < \infty\) ดูตัวอย่างสามบริเวณแบบเต็มในหัวข้อการแปลง Z

สรุป: ใช้ตัวไหนเมื่อไร

  • ต้องการประมาณค่า ทำให้เป็นเชิงเส้น หาลิมิต → เทย์เลอร์
  • ต้องการรู้พฤติกรรมใกล้โพล หาเรซิดิว อินทิกรัลเส้นปิด การแปลงผกผัน → โลรองต์
  • ถ้าบริเวณที่สนใจไม่มีจุดเอกฐานเลย สองอย่างคืออนุกรมเดียวกัน

เรียนต่อในคลังความรู้

  • อนุกรมโลรองต์ฉบับเต็ม: วงแหวน ชนิดจุดเอกฐาน เรซิดิว อินทิกรัลจริง การแปลง Z
  • อนุกรมเทย์เลอร์และแมคลอริน: ตาราง เศษเหลือ เทคนิคลัด
  • จำนวนเชิงซ้อน ฟังก์ชันวิเคราะห์ และทฤษฎีบทเรซิดิว
  • แนวข้อสอบคณิตศาสตร์วิศวกรรมชุด C
