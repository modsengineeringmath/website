// บทความ · Inverse Laplace Transform

Inverse Laplace Transform ทำอย่างไร: วิธีเศษส่วนย่อย 3 กรณีพร้อมตัวอย่าง

หลังแก้สมการในโดเมน \(s\) ได้ \(Y(s)\) เป็นเศษส่วนของพหุนาม ขั้นสุดท้ายคือแปลงกลับเป็น \(y(t)\) วิธีมาตรฐานที่ใช้ได้เกือบทุกโจทย์คือแยกเป็นเศษส่วนย่อยแล้วเปิดตาราง บทความนี้แยกเป็น 3 กรณีตามชนิดของโพล

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • แยกตัวส่วนเป็นตัวประกอบ → ดูชนิดโพล → เขียนเศษส่วนย่อย → หาสัมประสิทธิ์ → เปิดตาราง
  • โพลเดี่ยว: ใช้ cover-up · โพลซ้ำ: ต้องมีเทอม \((s+p)^k\) ครบทุกกำลัง · โพลเชิงซ้อน: เติมกำลังสอง
  • ถ้าดีกรีตัวเศษ ≥ ตัวส่วน ให้หารยากก่อน

คู่การแปลงที่ต้องใช้

ทั้งสามกรณีใช้คู่การแปลงชุดเล็ก ๆ นี้ (ชุดเต็มดู ตารางการแปลงลาปลาซ)

\(F(s)\)\(f(t)\), \(t \ge 0\)
\(\dfrac{1}{s}\)\(1\)
\(\dfrac{1}{s+a}\)\(e^{-at}\)
\(\dfrac{1}{(s+a)^2}\)\(t\,e^{-at}\)
\(\dfrac{\omega}{(s+a)^2+\omega^2}\)\(e^{-at}\sin\omega t\)
\(\dfrac{s+a}{(s+a)^2+\omega^2}\)\(e^{-at}\cos\omega t\)

กรณีที่ 1: โพลเดี่ยว (รากจริงไม่ซ้ำ)

ถ้า \(F(s)=\dfrac{N(s)}{(s+p_1)(s+p_2)}\) เขียนได้เป็น \(\dfrac{A}{s+p_1}+\dfrac{B}{s+p_2}\) โดย \(A = \left[(s+p_1)F(s)\right]_{s=-p_1}\) นี่คือวิธี cover-up: ปิดตัวประกอบที่สนใจ แล้วแทนค่า \(s\) ลงในส่วนที่เหลือ

ตัวอย่าง 1

หา \(\mathcal{L}^{-1}\left\{\dfrac{3s+5}{(s+1)(s+2)}\right\}\)

  1. หา \(A\) ที่โพล \(s=-1\): ปิด \((s+1)\) แล้วแทน \(s=-1\)

    \[ A = \frac{3(-1)+5}{(-1)+2} = \frac{2}{1} = 2 \]

  2. หา \(B\) ที่โพล \(s=-2\)

    \[ B = \frac{3(-2)+5}{(-2)+1} = \frac{-1}{-1} = 1 \]

  3. เปิดตาราง

    \[ F(s)=\frac{2}{s+1}+\frac{1}{s+2} \;\Rightarrow\; f(t) = 2e^{-t} + e^{-2t} \]

ตรวจ: \(\dfrac{2}{s+1}+\dfrac{1}{s+2} = \dfrac{2(s+2)+(s+1)}{(s+1)(s+2)} = \dfrac{3s+5}{(s+1)(s+2)}\) ✓

กรณีที่ 2: โพลซ้ำ

โพลที่ซ้ำ \(k\) ครั้งต้องมีเทอมครบทุกกำลังตั้งแต่ 1 ถึง \(k\) เช่น \((s+1)^2\) ต้องเขียนเป็น \(\dfrac{B}{s+1}+\dfrac{C}{(s+1)^2}\) ถ้าเขียนแค่เทอมกำลังสองจะหาสัมประสิทธิ์ไม่ลงตัว สัมประสิทธิ์ของกำลังสูงสุดหาด้วย cover-up ได้ ส่วนเทอมที่เหลือหาจากอนุพันธ์

\[ \text{ถ้า } F(s)=\frac{G(s)}{(s+p)^2}: \quad C = G(-p), \quad B = \left.\frac{dG}{ds}\right|_{s=-p} \]
ตัวอย่าง 2

หา \(\mathcal{L}^{-1}\left\{\dfrac{1}{s(s+1)^2}\right\}\)

  1. เขียนรูปเศษส่วนย่อย

    \[ \frac{1}{s(s+1)^2} = \frac{A}{s}+\frac{B}{s+1}+\frac{C}{(s+1)^2} \]

  2. โพลเดี่ยวที่ \(s=0\): \(A = \dfrac{1}{(0+1)^2}=1\)

  3. โพลซ้ำที่ \(s=-1\): ให้ \(G(s)=1/s\) จะได้ \(C=G(-1)=-1\) และ \(B=G'(-1)=-\dfrac{1}{s^2}\Big|_{s=-1}=-1\)

  4. เปิดตาราง

    \[ F(s)=\frac{1}{s}-\frac{1}{s+1}-\frac{1}{(s+1)^2} \;\Rightarrow\; f(t)=1-e^{-t}-t\,e^{-t} \]

ตรวจค่าเริ่มต้น: \(f(0)=1-1-0=0\) ตรงกับทฤษฎีบทค่าเริ่มต้น \(\lim_{s\to\infty} sF(s)=\lim \dfrac{1}{(s+1)^2}=0\) ✓

กรณีที่ 3: โพลเชิงซ้อน (เติมกำลังสอง)

ถ้าส่วนเป็นกำลังสองที่แยกเป็นรากจริงไม่ได้ อย่าแยกเป็นจำนวนเชิงซ้อน ให้เติมกำลังสองให้เป็น \((s+a)^2+\omega^2\) แล้วจัดตัวเศษให้อยู่ในรูป \((s+a)\) กับค่าคงที่ จะตรงกับคู่ cos และ sin ที่มีตัวคูณ \(e^{-at}\)

ตัวอย่าง 3

หา \(\mathcal{L}^{-1}\left\{\dfrac{s+3}{s^2+2s+5}\right\}\)

  1. เติมกำลังสองที่ตัวส่วน: \(s^2+2s+5=(s+1)^2+2^2\)

  2. จัดตัวเศษ: \(s+3=(s+1)+2\) แล้วแยก

    \[ F(s)=\frac{s+1}{(s+1)^2+2^2}+\frac{2}{(s+1)^2+2^2} \]

  3. เปิดตาราง ด้วย \(a=1\), \(\omega=2\)

    \[ f(t)=e^{-t}\cos 2t + e^{-t}\sin 2t = e^{-t}(\cos 2t+\sin 2t) \]

โพลอยู่ที่ \(s=-1\pm j2\) ผลตอบสนองจึงเป็นการแกว่งที่ความถี่ 2 rad/s ซึ่งแอมพลิจูดลดลงด้วย \(e^{-t}\) และเนื่องจากโพลอยู่ซีกซ้าย ระบบเสถียร

เมื่อตัวเศษดีกรีสูงเกินไป

เศษส่วนย่อยใช้ได้กับเศษส่วนแท้เท่านั้น ถ้าดีกรีตัวเศษ ≥ ตัวส่วน ให้หารยาวก่อน ผลหารที่เป็นค่าคงที่คือแรงกระตุ้น \(\delta(t)\) ส่วนผลหารที่เป็นพหุนามของ \(s\) คืออนุพันธ์ของแรงกระตุ้น ซึ่งมักบ่งบอกว่าแบบจำลองมีการหาอนุพันธ์อินพุตที่ไม่เป็นจริงในทางกายภาพ ควรตรวจโจทย์อีกครั้ง

เช็กลิสต์ก่อนส่งคำตอบ

  • แทน \(t=0\) เทียบกับทฤษฎีบทค่าเริ่มต้น: \(f(0^+)=\lim_{s\to\infty}sF(s)\)
  • ถ้าโพลของ \(sF(s)\) อยู่ซีกซ้ายทั้งหมด (โพลเดี่ยวที่ \(s=0\) ใน \(F(s)\) ใช้ได้) ลองเทียบ \(f(\infty)\) กับ \(\lim_{s\to0}sF(s)\)
  • รวมเศษส่วนย่อยกลับ ต้องได้ตัวเศษเดิม

เรียนต่อในคลังความรู้

  • แผนภาพโพล-ซีโร่ และ ROC
  • คุณสมบัติของการแปลงลาปลาซ (เลื่อนเวลา คอนโวลูชัน ฯลฯ)
