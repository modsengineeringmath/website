อนุกรมเรขาคณิต (Geometric Series): สูตร ตัวอย่าง และวิธีหาผลบวก

อนุกรมเรขาคณิตคือการบวกตัวเลขที่คูณด้วยค่าเดิมทุกครั้ง เช่น \(2 + 6 + 18 + 54\) มีสูตรเดียวที่ต้องจำ และมีเงื่อนไขเดียวที่ต้องดูเมื่อบวกไม่สิ้นสุด บทความนี้สรุปสูตร ที่มา และตัวอย่างที่ออกสอบบ่อย

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • พจน์ทั่วไป: \(a_n = a_1 r^{n-1}\) โดย \(r\) คืออัตราส่วนร่วม (common ratio) \(= a_{n+1}/a_n\)
  • ผลบวก n พจน์: \(S_n = a_1\dfrac{1 - r^n}{1 - r}\) เมื่อ \(r \ne 1\)
  • อนุกรมอนันต์: \(S_\infty = \dfrac{a_1}{1 - r}\) ใช้ได้เฉพาะ \(|r| < 1\)

อนุกรมเรขาคณิตคืออะไร

ลำดับเรขาคณิต (geometric sequence) คือลำดับที่พจน์ถัดไปได้จากการคูณพจน์ก่อนหน้าด้วยค่าคงที่ \(r\) เช่น \(2, 6, 18, 54, \dots\) มี \(r = 3\) ส่วนอนุกรมเรขาคณิต (geometric series) คือผลบวกของพจน์เหล่านั้น \(2 + 6 + 18 + 54 + \cdots\)

วิธีหา \(r\): เอาพจน์ใดหารด้วยพจน์ก่อนหน้า ถ้าได้ค่าเท่ากันทุกคู่ก็เป็นเรขาคณิต \(r\) เป็นลบได้ (เครื่องหมายสลับ) และเป็นเศษส่วนได้ (ค่าลดลง)

สูตรผลบวก n พจน์ และที่มา

\[ S_n = a_1 + a_1r + a_1r^2 + \cdots + a_1r^{n-1} = a_1\,\frac{1 - r^n}{1 - r},\quad r \ne 1 \]

ที่มาใช้แค่สองบรรทัด: เขียน \(S_n\) แล้วคูณด้วย \(r\) จะได้พจน์ชุดเดียวกันที่เลื่อนไปหนึ่งตำแหน่ง

\[ \begin{aligned} S_n &= a_1 + a_1r + \cdots + a_1r^{n-1} \\ rS_n &= \phantom{a_1 + {}} a_1r + \cdots + a_1r^{n-1} + a_1r^n \end{aligned} \]

ลบกัน พจน์กลางหายหมด เหลือ \(S_n - rS_n = a_1 - a_1r^n\) จึงได้สูตรข้างบน ถ้า \(r > 1\) จะเขียนเป็น \(a_1\dfrac{r^n - 1}{r - 1}\) ก็ได้ (ค่าเท่ากัน แต่ไม่ต้องจัดการเครื่องหมายลบ)

ตัวอย่าง 1

ลำดับเรขาคณิตมี \(a_2 = 6\) และ \(a_5 = 162\) หา \(S_6\)

  1. \(\dfrac{a_5}{a_2} = r^3 = \dfrac{162}{6} = 27\) จึงได้ \(r = 3\) และ \(a_1 = a_2/r = 2\)

  2. \(S_6 = 2\cdot\dfrac{3^6 - 1}{3 - 1} = 2\cdot\dfrac{728}{2} = 728\)

\(S_6 = 728\) ตรวจ: \(2 + 6 + 18 + 54 + 162 + 486 = 728\) ✓

ตัวอย่าง 2 · หาจำนวนพจน์ก่อน

หาผลบวก \(3 + 6 + 12 + \cdots + 768\)

  1. \(a_1 = 3,\ r = 2\) พจน์สุดท้าย \(3\cdot 2^{n-1} = 768 \Rightarrow 2^{n-1} = 256 = 2^8\) จึงมี \(n = 9\) พจน์

  2. \(S_9 = 3\cdot\dfrac{2^9 - 1}{2 - 1} = 3(511) = 1533\)

\(1533\) · ความผิดพลาดที่พบบ่อยคือนับ n ผิด ต้องหาจาก \(a_n = a_1r^{n-1}\) ทุกครั้ง

อนุกรมเรขาคณิตอนันต์ (Infinite Geometric Series)

เมื่อบวกไม่สิ้นสุด ให้ดูว่า \(r^n\) ในสูตร \(S_n\) ไปทางไหนเมื่อ \(n \to \infty\) ถ้า \(|r| < 1\) แล้ว \(r^n \to 0\) ผลบวกจึงเข้าใกล้ค่าจำกัด

\[ S_\infty = a_1 + a_1r + a_1r^2 + \cdots = \frac{a_1}{1 - r},\qquad |r| < 1 \]
ค่า rพฤติกรรมของอนุกรมอนันต์
\(|r| < 1\)ลู่เข้า (convergent) ผลบวก \(a_1/(1 - r)\)
\(r = 1\)ลู่ออก ผลบวกโตแบบ \(na_1\)
\(r = -1\)ลู่ออก ผลบวกย่อยแกว่ง \(a_1, 0, a_1, 0, \dots\)
\(|r| > 1\)ลู่ออก พจน์โตไม่มีขอบเขต
ตัวอย่าง 3 · ทศนิยมซ้ำและ r ติดลบ

(ก) เขียน \(0.\overline{36}\) เป็นเศษส่วน (ข) หา \(8 - 4 + 2 - 1 + \cdots\)

  1. (ก) \(0.3636\ldots = 0.36 + 0.0036 + \cdots\) มี \(a_1 = 0.36,\ r = 0.01\): \(\dfrac{0.36}{1 - 0.01} = \dfrac{36}{99} = \dfrac{4}{11}\)

  2. (ข) \(a_1 = 8,\ r = -\tfrac12\) และ \(|r| < 1\): \(S_\infty = \dfrac{8}{1 + \frac12} = \dfrac{16}{3}\)

(ก) \(\tfrac{4}{11}\) (ข) \(\tfrac{16}{3}\) · ด้วยเหตุผลเดียวกัน \(0.999\ldots = \tfrac{0.9}{1 - 0.1} = 1\) พอดี

ตัวอย่าง 4 · ลูกบอลเด้ง

ปล่อยลูกบอลจากความสูง 10 m ทุกครั้งที่กระทบพื้นเด้งขึ้น 60% ของความสูงเดิม หาระยะทางรวมทั้งหมด

  1. ขาลงครั้งแรก 10 m จากนั้นทุกการเด้งมีขาขึ้นและขาลงเท่ากัน: \(6 + 3.6 + 2.16 + \cdots\) เป็นอนุกรมเรขาคณิต \(a_1 = 6,\ r = 0.6\)

  2. ระยะรวม \(= 10 + 2\cdot\dfrac{6}{1 - 0.6} = 10 + 30 = 40\ \text{m}\)

\(40\ \text{m}\) · เด้งนับครั้งไม่ถ้วน แต่ระยะทางรวมมีค่าจำกัด

ใช้ในงานวิศวกรรม

  • ตัวกรองดิจิทัล (EMA) \(y[n] = 0.8\,y[n-1] + 0.2\,x[n]\) ป้อนขั้นบันได 1 ได้ \(y[n] = 0.2(1 + 0.8 + \cdots + 0.8^n) = 1 - 0.8^{n+1}\) ถึง 95% ที่ตัวอย่างที่ 14 และเสถียรเพราะ \(|0.8| < 1\)
  • มูลค่าปัจจุบัน โซลาร์รูฟท็อปประหยัดปีละ 12,000 บาท นาน 20 ปี อัตราคิดลด 5%: \(PV = 12000\cdot\dfrac{1 - 1.05^{-20}}{0.05} \approx 149{,}547\) บาท
  • อนุกรมกำลัง \(\dfrac{1}{1 - x} = 1 + x + x^2 + \cdots\) (\(|x| < 1\)) เป็นจุดตั้งต้นของอนุกรม \(\ln(1 + x)\) และ \(\arctan x\) ในอนุกรมเทย์เลอร์

ข้อผิดพลาดที่พบบ่อย

  • ใช้ \(a_1/(1 - r)\) ทั้งที่ \(|r| \ge 1\) เช่น \(1 + 2 + 4 + \cdots\) ไม่ได้เท่ากับ \(\tfrac{1}{1 - 2} = -1\) แต่ลู่ออก
  • ใช้สูตรตอน \(r = 1\) (หารด้วยศูนย์) กรณีนี้ \(S_n = na_1\)
  • นับจำนวนพจน์ผิด โดยเฉพาะเมื่อเริ่มที่ \(r^0\) หรือเริ่มที่ \(r^1\)
  • ลืมว่า \(r\) ติดลบได้: ลำดับที่เครื่องหมายสลับก็เป็นเรขาคณิต

เรียนต่อในคลังความรู้

  • ลำดับและอนุกรมเรขาคณิตฉบับเต็ม พร้อมบทพิสูจน์ด้วยภาพ
  • แล็บลำดับ: ดูพจน์ ผลบวกย่อย และลิมิตแบบโต้ตอบ
  • อนุกรมอนันต์ฉบับเต็ม: เรขาคณิต กล้องส่องทางไกล ฮาร์มอนิก และอนุกรม p
  • การทดสอบการลู่เข้าของอนุกรมทุกแบบ พร้อมผังเลือกใช้และเกมฝึก
  • บทความต่อ: เลือกการทดสอบการลู่เข้าอย่างไร
  • พิสูจน์สูตรอนุกรมเรขาคณิตด้วยอุปนัยเชิงคณิตศาสตร์
