เลือกการทดสอบการลู่เข้าอย่างไร: ผังตัดสินใจ 8 ขั้น พร้อมตัวอย่างทุกขั้น

ในข้อสอบแคลคูลัส 2 คนที่ทำข้ออนุกรมได้เร็วไม่ใช่คนที่จำทฤษฎีบทได้มากที่สุด แต่เป็นคนที่มองพจน์แล้วรู้ทันทีว่าควรใช้เครื่องมือไหน บทความนี้รวมประสบการณ์นั้นเป็นผังตัดสินใจ 8 ขั้น เรียงจากเร็วที่สุดไปถึงที่ใช้แรงมากที่สุด พร้อมตัวอย่างหนึ่งข้อต่อขั้น

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • เช็กพจน์ที่ n ก่อนเสมอ (5 วินาที) แล้วดูว่าเป็นเรขาคณิตหรืออนุกรม p
  • เศษส่วนพหุนาม → เปรียบเทียบลิมิต · แฟกทอเรียล/เลขยกกำลัง → อัตราส่วน · ยกกำลัง n ทั้งก้อน → ราก · มี ln → ปริพันธ์
  • เครื่องหมายสลับ: ทดสอบ Σ|aₙ| ก่อน แล้วค่อยใช้ไลบ์นิซ

ผังตัดสินใจ

8 ขั้นพร้อมตัวอย่าง

ขั้น 1 · พจน์เข้าใกล้ศูนย์ไหม

\(\sum\dfrac{n}{n+1}\): พจน์ → 1 ≠ 0 จึงลู่ออกทันที ข้อนี้ใช้ได้ทางเดียว ถ้าพจน์ → 0 ให้ไปขั้นถัดไป

ขั้น 2 · เป็นเรขาคณิตหรืออนุกรม p ไหม

\(\sum\dfrac{5}{4^n}\) เรขาคณิต \(r = \tfrac14\) ลู่เข้า · \(\sum\dfrac{1}{\sqrt n}\) อนุกรม p ที่ \(p = \tfrac12 \le 1\) ลู่ออก — จำผลได้ ไม่ต้องคำนวณ

ขั้น 3 · แยกเศษส่วนย่อยได้ไหม

\(\sum\dfrac{1}{n(n+1)} = \sum\left(\dfrac1n - \dfrac{1}{n+1}\right) = 1\) กล้องส่องทางไกลให้ทั้งคำตอบลู่เข้าและค่าผลบวก

ขั้น 4 · เป็นเศษส่วนของพหุนามหรือรากไหม

\(\sum\dfrac{3n+5}{n^3-2}\): ตัวเด่น \(\tfrac{3n}{n^3} = \tfrac{3}{n^2}\) เทียบลิมิตกับ \(\tfrac{1}{n^2}\) ได้ 3 (บวกและจำกัด) จึงลู่เข้า · สูตรลัด: ลู่เข้า ⇔ ดีกรีล่าง − ดีกรีบน > 1

ขั้น 5 · มีแฟกทอเรียลหรือเลขยกกำลังไหม

\(\sum\dfrac{n!}{n^n}\): \(\dfrac{a_{n+1}}{a_n} = \left(\dfrac{n}{n+1}\right)^n \to \dfrac1e < 1\) ลู่เข้า · ถ้าได้ 1 พอดี ratio test สรุปไม่ได้

ขั้น 6 · ยกกำลัง n ทั้งก้อนไหม

\(\sum\left(\dfrac{n}{2n+1}\right)^n\): \(\sqrt[n]{a_n} = \dfrac{n}{2n+1} \to \tfrac12\) ลู่เข้า รากตัดเลขชี้กำลังทิ้งให้ทันที

ขั้น 7 · มี ln หรืออินทิเกรตได้ง่ายไหม

\(\sum\dfrac{1}{n\ln n}\): \(\int_2^\infty\dfrac{dx}{x\ln x} = [\ln\ln x]_2^\infty = \infty\) ลู่ออก (แม้ตัวเลขจากคอมพิวเตอร์จะดูนิ่ง) · ส่วน \(\sum\dfrac{1}{n(\ln n)^2}\) ลู่เข้า

ขั้น 8 · เครื่องหมายสลับไหม

\(\sum\dfrac{(-1)^n}{\sqrt n}\): ค่าสัมบูรณ์ \(\sum\tfrac{1}{\sqrt n}\) ลู่ออก แต่ \(\tfrac{1}{\sqrt n}\) ลดลง → 0 ไลบ์นิซบอกว่าลู่เข้า จึงเป็นลู่เข้าแบบมีเงื่อนไข

ตารางสรุปสำหรับทบทวนก่อนสอบ

การทดสอบใช้เมื่อสรุปไม่ได้เมื่อ
พจน์ที่ nทุกข้อ (ด่านแรก)พจน์ → 0
เปรียบเทียบลิมิตเศษส่วนพหุนาม ราก sin(1/n)ลิมิตเป็น 0 หรือ ∞ ในทิศที่ผิด
อัตราส่วนn!, cⁿ, nⁿρ = 1
ราก(…)ⁿ ทั้งก้อนρ = 1
ปริพันธ์ln n, ฟังก์ชันที่อินทิเกรตได้f ไม่ลดลง
อนุกรมสลับ(−1)ⁿ bₙbₙ ไม่ลดลง

กับดักสามข้อที่ทำให้เสียคะแนน

  • \(\sum\dfrac{1}{n^{1 + 1/n}}\) ดูเหมือนอนุกรม p ที่ p > 1 แต่เลขชี้กำลังเข้าใกล้ 1 เทียบลิมิตกับ \(\tfrac1n\) ได้ 1 จึงลู่ออก
  • \(\sum\left(1 + \tfrac1n\right)^n\) ไม่ต้องใช้ราก พจน์ → e ≠ 0 จึงลู่ออกด้วยพจน์ที่ n
  • \(\sum\dfrac{1}{3^n - n}\) เปรียบเทียบตรงกับ \(\tfrac{1}{3^n}\) ใช้ไม่ได้เพราะพจน์ใหญ่กว่า ต้องใช้เปรียบเทียบลิมิต

ฝึกให้มองเป็นอัตโนมัติด้วยเกมเลือกการทดสอบ 40 ข้อ ที่ตรวจทั้งการทดสอบและผลสรุป

  • อนุกรมสลับ: ไลบ์นิซ ความคลาดเคลื่อน การจัดเรียงใหม่
