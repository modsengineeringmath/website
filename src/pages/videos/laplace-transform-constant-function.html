สรุปสูตรอ่านประกอบคลิป

\[ \mathcal{L}\{c\} = \int_{0}^{\infty} c\,e^{-st}\,dt = \frac{c}{s}, \qquad \operatorname{Re}(s) > 0 \]
ขั้นตอนจากนิยาม ด้วยการเปลี่ยนตัวแปร \(u = -st\)
  • นิยาม: \(\mathcal{L}\{f(t)\} = F(s) = \int_0^\infty f(t)\,e^{-st}\,dt\) แทน \(f(t) = c\) แล้วดึงค่าคงที่ออกนอกอินทิกรัล ได้ \(c\int_0^\infty e^{-st}\,dt\)
  • ให้ \(u = -st\) จะได้ \(du = -s\,dt\) หรือ \(dt = -\dfrac{du}{s}\)
  • เปลี่ยนขอบเขต: \(t = 0 \Rightarrow u = 0\) และ \(t \to \infty \Rightarrow u \to -\infty\) (เมื่อ \(s > 0\))
  • แทนค่า: \(c\displaystyle\int_0^{-\infty} e^{u}\left(-\frac{du}{s}\right) = \frac{c}{s}\int_{-\infty}^{0} e^{u}\,du = \frac{c}{s}\Big[e^{u}\Big]_{-\infty}^{0} = \frac{c}{s}\,(1 - 0) = \frac{c}{s}\)

เงื่อนไข \(\operatorname{Re}(s) > 0\) สำคัญ เพราะถ้า \(s \le 0\) พจน์ \(e^{-st}\) จะไม่ลดลงเป็นศูนย์ และอินทิกรัลลู่ออก ช่วงค่า \(s\) ที่อินทิกรัลลู่เข้านี้เรียกว่า region of convergence (ROC)

ตัวอย่างฝึกเพิ่ม

  1. \(\mathcal{L}\{5\} = \dfrac{5}{s}\) และ \(\mathcal{L}\{1\} = \dfrac{1}{s}\) ซึ่งเท่ากับลาปลาซของฟังก์ชันขั้นบันไดหนึ่งหน่วย \(u(t)\)
  2. แปลงกลับ: \(\mathcal{L}^{-1}\left\{\dfrac{12}{s}\right\} = 12\) สำหรับ \(t \ge 0\)
  3. ต่อแหล่งจ่ายไฟตรง 24 V เข้าวงจรที่เวลา \(t = 0\) อินพุตในโดเมน \(s\) คือ \(V_{in}(s) = \dfrac{24}{s}\) ถ้าวงจรมีฟังก์ชันถ่ายโอน \(G(s) = \dfrac{1}{RCs+1}\) เอาต์พุตคือ \(V_C(s) = \dfrac{24}{s\,(RCs+1)}\) ซึ่งเป็นจุดเริ่มของการหาผลตอบสนองเชิงเวลาในวิชาระบบควบคุม
