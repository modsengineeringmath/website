ออกแบบสตริงและจับคู่อินเวอร์เตอร์: Voc ตอนหนาว ช่วง MPPT กระแส และ DC/AC ratio

อินเวอร์เตอร์รับแรงดันได้ในหน้าต่างหนึ่ง และรับกระแสได้ไม่เกินค่าหนึ่ง ส่วนแรงดันของสตริงเปลี่ยนตามอุณหภูมิทุกวัน การออกแบบสตริงคือการเลือก “แผงกี่แผงต่ออนุกรม และกี่สตริงต่อขนาน” ให้สตริงอยู่ในหน้าต่างนั้น ทั้งในเช้าที่หนาวที่สุดและเที่ยงที่ร้อนที่สุดของปี — พลาดด้านบนอินเวอร์เตอร์พัง พลาดด้านล่างเสียพลังงานทุกบ่าย

เขียนโดย อาจารย์มดอัปเดต
เครื่องคำนวณสตริง ขีดจำกัดแรงดัน ขีดจำกัดกระแส DC/AC ratio ตัวอย่าง 3 ขนาด
สรุปใน 30 วินาที
  • ขีดบน: \(N_s V_{oc}(T_{min}) \le V_{dc,max}\) — ห้ามเกินเด็ดขาด
  • ขีดล่าง: \(N_s V_{mp}(T_{c,max}) \ge V_{MPPT,min}\) — ต่ำกว่านี้เสียพลังงานช่วงร้อน
  • กระแส: \(N_p I_{mp} \le I_{MPPT,max}\) และ \(1.25 N_p I_{sc} \le I_{sc,max}\)
  • DC/AC 1.1–1.3 · สตริงต่างทิศแยก MPPT · สตริงขนานต้องจำนวนแผงเท่ากัน

ขีดจำกัดแรงดัน: หนาวสุดและร้อนสุด พื้นฐาน

แรงดันของแผงขึ้นกับอุณหภูมิเซลล์เป็นหลัก (P6) แรงดันสูงสุดเกิดในเช้าที่อากาศหนาวที่สุด เมื่อแสงพอให้แรงดันขึ้นเต็มแต่แผงยังไม่ร้อน จึงใช้ อุณหภูมิอากาศต่ำสุดเป็นอุณหภูมิเซลล์ ส่วนแรงดันต่ำสุดขณะทำงานเกิดตอนเที่ยงที่แผงร้อนที่สุด

D1 Maximum module voltage (coldest morning) แรงดันสูงสุดของแผงตอนหนาวสุด

\[ V_{oc,max} = V_{oc,STC}\left[1 + \beta_{V_{oc}}\,(T_{min} - 25)\right] \]

D2 Maximum modules per string จำนวนแผงต่อสตริงสูงสุด

\[ N_{s,max} = \left\lfloor \frac{V_{dc,max}}{V_{oc,max}} \right\rfloor \quad \text{(และต้องไม่เกิน } V_{sys,max}\text{ ของแผงด้วย)} \]

D3 Minimum MPP voltage (hottest noon) แรงดัน MPP ต่ำสุดตอนร้อนสุด

\[ V_{mp,min} = V_{mp,STC}\left[1 + \beta_{V_{mp}}(T_{c,max} - 25)\right] \qquad \beta_{V_{mp}} \approx \gamma - \alpha \]

D4 Minimum modules per string จำนวนแผงต่อสตริงต่ำสุด

\[ N_{s,min} = \left\lceil \frac{V_{MPPT,min}}{V_{mp,min}} \right\rceil \]

D5 MPPT upper limit ขอบบนของช่วง MPPT

\[ N_{s} \le \left\lfloor \frac{V_{MPPT,max}}{V_{mp}(T_{min})} \right\rfloor \]

เลือก \(T_{min}\) และ \(T_{c,max}\) อย่างไร

  • \(T_{min}\): อุณหภูมิต่ำสุดที่เคยบันทึกของพื้นที่ (จากกรมอุตุนิยมวิทยา) กรุงเทพฯ และภาคใต้ใช้ 10–15 °C ภาคกลางและอีสาน 5–10 °C ภาคเหนือและพื้นที่สูง 0–5 °C ถ้าไม่แน่ใจใช้ค่าต่ำไว้ก่อน (ปลอดภัยกว่า)
  • \(T_{c,max}\): อุณหภูมิเซลล์สูงสุด ≈ อากาศสูงสุด + 30–35 °C (P7) ในไทยใช้ 70–75 °C สำหรับแผงยกลอย และ 75–80 °C สำหรับแผงติดชิดหลังคา
  • ผลของ \(T_{min}\) ไม่น้อย: ถ้าเปลี่ยนจาก 10 °C เป็น 0 °C แผงตัวอย่างมี \(V_{oc,max}\) 55.5 V และอินเวอร์เตอร์ 600 V ยังรับได้ 10 แผง (จาก 11) — ในภาคเหนือต้องคิดค่านี้จริงจัง
อย่าเผื่อด้านบนน้อยเกินไป แรงดันเกิน \(V_{dc,max}\) แม้เพียงไม่กี่นาทีตอนเช้าก็ทำให้ตัวเก็บประจุหรือสวิตช์ด้านเข้าเสียหายได้ และผู้ผลิตจะไม่รับประกัน บางรายแนะนำให้เผื่ออีก 2–3 % สำหรับ tolerance และแสงที่สูงกว่า 1,000 W/m² จากเมฆสะท้อน (cloud enhancement)

ขีดจำกัดกระแส: สตริงขนานต่อ MPPT พื้นฐาน

D6 Parallel strings per MPPT จำนวนสตริงขนานต่อ MPPT

\[ N_p \le \left\lfloor \frac{I_{MPPT,max}}{I_{mp}} \right\rfloor \qquad 1.25\,N_p\,I_{sc} \le I_{sc,max} \]

ตัวคูณ 1.25 เผื่อแสงที่สูงกว่า STC (cloud enhancement, albedo) และกระแสด้านหลังของแผงสองหน้า ข้อกำหนดของ IEC 62548 ใช้ตัวคูณนี้กับการเลือกสายและฟิวส์ด้วย ถ้า \(N_p I_{mp}\) เกิน \(I_{MPPT,max}\) เล็กน้อย อินเวอร์เตอร์จะจำกัดกระแสเอง (เสียพลังงานแต่ไม่พัง) แต่ถ้า \(I_{sc}\) เกิน \(I_{sc,max}\) อาจเสียหายเมื่อเกิดความผิดพร่องภายใน

แผงกระแสสูงกับอินเวอร์เตอร์รุ่นเก่า: แผง 182/210 mm มี \(I_{mp}\) 13–18 A อินเวอร์เตอร์รุ่นเก่ารับได้ 11–13 A ต่อ MPPT จึงต้องตรวจทุกครั้ง อินเวอร์เตอร์รุ่นปัจจุบันจำนวนมากรองรับ 16–20 A ต่อสตริงแล้ว

DC/AC ratio และ clipping กลาง

D7 DC/AC ratio อัตราส่วนกำลังแผงต่อพิกัดอินเวอร์เตอร์

\[ r_{DC/AC} = \frac{N_s N_p P_{STC}}{P_{AC,rated}} \]

แผงในไทยแทบไม่เคยจ่ายกำลังถึง STC เพราะอุณหภูมิ ฝุ่น และการสูญเสียในสาย กำลังสูงสุดจริงช่วงเที่ยงจึงอยู่ราว 75–85 % ของ \(P_{STC}\) การใช้แผงมากกว่าพิกัดอินเวอร์เตอร์ (oversizing) ทำให้อินเวอร์เตอร์ทำงานใกล้พิกัดนานขึ้น ได้พลังงานเช้าเย็นมากขึ้น และต้นทุนต่อหน่วยลดลง เมื่อกำลัง DC เกินพิกัด อินเวอร์เตอร์จะเลื่อนจุดทำงานออกจาก MPP เพื่อจำกัดกำลัง (clipping)

DC/ACclipping ต่อปีในไทย (ประมาณ)ใช้เมื่อ
1.0–1.1~0 %สัญญาจำกัดกำลังส่งออกตามพิกัด kW แผง
1.1–1.30.2–2 %บ้านและอาคารทั่วไป (แนะนำ)
1.3–1.52–6 %หลังคาตะวันออก-ตะวันตก ระบบที่ขนาดอินเวอร์เตอร์ถูกจำกัดด้วยสัญญาหรือหม้อแปลง

D8 Minimum voltage for full power แรงดันต่ำสุดที่ยังจ่ายเต็มพิกัด

\[ V_{full,min} \approx \frac{P_{AC,rated}}{\eta_{inv}\,\sum I_{MPPT,max}} \]

ถ้าแรงดันสตริงตอนร้อนต่ำกว่า \(V_{full,min}\) อินเวอร์เตอร์ถูกจำกัดด้วยกระแส ไม่สามารถจ่ายเต็มพิกัด แม้แสงมาก — เกิดบ่อยในระบบที่สตริงสั้นเกินไป

กฎการจัดสตริงที่ใช้จริง

  1. แผงในสตริงเดียวกัน: รุ่นเดียวกัน ทิศเดียวกัน มุมเอียงเดียวกัน เงาใกล้เคียงกัน
  2. สตริงที่ขนานใน MPPT เดียวกัน: จำนวนแผงเท่ากันและทิศเดียวกัน
  3. สตริงต่างทิศหรือต่างความยาว: แยก MPPT
  4. เงาบังบางแผงเป็นประจำ: รวมแผงที่มีเงาไว้ในสตริงเดียว อย่ากระจายไปทุกสตริง หรือใช้ optimizer เฉพาะแผงนั้น
  5. เดินสาย + และ − ของสตริงคู่กันไป (leap-frog / ไม่ให้เกิดวงรอบ) ลดพื้นที่วงลูปเพื่อลดแรงดันเหนี่ยวนำจากฟ้าผ่า
  6. ระบบใหญ่: ออกแบบให้สตริงยาวเท่ากันทั้งโครงการ ใช้ combiner box หรือ string inverter กระจายตามโซน

ประเด็นระดับปริญญาโท ขั้นสูง

  • Clipping loss แบบรายชั่วโมง คำนวณจากข้อมูล POA รายชั่วโมงหรือราย 1–5 นาที (ข้อมูลรายชั่วโมงประเมิน clipping ต่ำเกินจริงเมื่อเมฆผ่านเร็ว)
  • Optimal DC/AC ratio แก้ปัญหาเชิงเศรษฐศาสตร์: ต้นทุนแผงส่วนเพิ่มเทียบพลังงานส่วนเพิ่ม โดยมีข้อจำกัดของสัญญาและ grid code
  • สายยาวกับแรงดันสูง 1,500 V ในโซลาร์ฟาร์ม ลดจำนวน combiner และต้นทุนสาย แต่ต้องออกแบบฉนวนและ PID
  • ผลของ \(I_{sc}\) ที่เพิ่มจากด้านหลังของแผงสองหน้า และ cloud enhancement ที่วัดได้ถึง 1,400–1,600 W/m² ในเขตร้อนช่วงสั้น ๆ ต่อการเลือกฟิวส์และอินเวอร์เตอร์
