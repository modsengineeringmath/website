ความคุ้มค่าของโซลาร์เซลล์: ระยะคืนทุน NPV IRR LCOE และการวิเคราะห์ความไว

“คืนทุนกี่ปี” เป็นคำถามที่ดีแต่ไม่พอ ระบบโซลาร์ใช้งาน 25–30 ปี มีค่าใช้จ่ายระหว่างทาง (ล้างแผง เปลี่ยนอินเวอร์เตอร์) พลังงานลดลงทุกปี และค่าไฟเปลี่ยน หน้านี้สร้างกระแสเงินสดรายปีแล้วคำนวณตัวชี้วัดมาตรฐาน 4 ตัว พร้อมวิเคราะห์ว่าตัวแปรไหนกระทบผลมากที่สุด

เขียนโดย อาจารย์มดอัปเดต
เครื่องคำนวณความคุ้มค่า กระแสเงินสด NPV IRR LCOE ความไว สินเชื่อและภาษี
สรุปใน 30 วินาที
  • ตัวแปรที่กระทบมากที่สุด: ราคาติดตั้ง สัดส่วนใช้เอง และค่าไฟ — ไม่ใช่ยี่ห้อแผง
  • ระบบบ้านตัวอย่าง 5 kWp: คืนทุน ≈ 6 ปี IRR ≈ 16 % LCOE ≈ 2 บาท/kWh
  • คิดค่าเปลี่ยนอินเวอร์เตอร์ (ปี 10–15) และการเสื่อม 0.4–0.5 %/ปีเสมอ
  • ถ้ากู้เงินมาติด ค่างวดอาจสูงกว่าผลประหยัดในปีแรก ๆ — ดูกระแสเงินสดรายปี

สร้างกระแสเงินสดรายปี พื้นฐาน

F1 Investment เงินลงทุนเริ่มต้น

\[ CAPEX = P_{STC}\times c_{kWp} \quad (+\ \text{แบตเตอรี่ ค่าขออนุญาต ปรับปรุงตู้ไฟ หลังคา}) \]

F2 Net saving in year y ผลประหยัดสุทธิในปีที่ y

\[ S_y = E_1(1-d)^{y-1}\left[SCR\cdot c_{buy}(1+e)^{y-1} + (1-SCR)\,c_{sell}\right] - C_{O\&M} - C_{repl,y} \]

\(d\) = การเสื่อมต่อปี \(e\) = อัตราค่าไฟที่เพิ่มต่อปี \(c_{sell}\) = ราคาขายไฟส่วนเกิน (คงที่ตามสัญญา) \(C_{O\&M}\) = ค่าล้าง ตรวจ ประกัน (≈ 0.5–1.5 % ของ CAPEX ต่อปี) \(C_{repl,y}\) = ค่าเปลี่ยนอุปกรณ์ในปีนั้น (อินเวอร์เตอร์ราวปีที่ 10–15)

F3 Simple payback ระยะคืนทุนอย่างง่าย

\[ PB \approx \frac{CAPEX}{S_1} \quad \text{(หรือปีที่เงินสดสะสม } -CAPEX + \textstyle\sum S_y \text{ เป็นบวก)} \]
ตัวอย่าง F-1

บ้าน 5 kWp: ปีแรก

ราคาติดตั้ง 30,000 บาท/kWp ผลผลิต 1,350 kWh/kWp ใช้เอง 80 % ค่าไฟ 4.2 บาท ขายไฟ 2.2 บาท O&M 1 %/ปี

  1. F1: CAPEX = 5 × 30,000 = 150,000 บาท · \(E_1\) = 6,750 kWh

  2. ใช้เอง 5,400 kWh × 4.2 = 22,680 บาท · ขาย 1,350 kWh × 2.2 = 2,970 บาท

  3. O&M = 1,500 บาท → \(S_1\) = 22,680 + 2,970 − 1,500 = 24,150 บาท

  4. F3: PB ≈ 150,000/24,150 = 6.2 ปี (เมื่อนับค่าไฟที่เพิ่มปีละ 1.5 % จากเงินสดสะสมจริง ได้ 6.1 ปี)

NPV IRR LCOE และระยะคืนทุนคิดลด กลาง

F4 Net present value มูลค่าปัจจุบันสุทธิ

\[ NPV = -CAPEX + \sum_{y=1}^{N}\frac{S_y}{(1+r)^y} \]

F5 Levelized cost of electricity ต้นทุนพลังงานเฉลี่ยตลอดอายุ

\[ LCOE = \frac{CAPEX + \sum_{y=1}^{N}\dfrac{C_{O\&M,y} + C_{repl,y}}{(1+r)^y}}{\sum_{y=1}^{N}\dfrac{E_y}{(1+r)^y}} \]

F6 Internal rate of return อัตราผลตอบแทนภายใน

\[ 0 = -CAPEX + \sum_{y=1}^{N}\frac{S_y}{(1+IRR)^y} \]

F7 Discounted payback ระยะคืนทุนแบบคิดลด

\[ \min\Big\{ Y : -CAPEX + \sum_{y=1}^{Y}\frac{S_y}{(1+r)^y} \ge 0 \Big\} \]
  • NPV > 0 โครงการเพิ่มความมั่งคั่งเมื่อเทียบกับการเอาเงินไปลงทุนที่ผลตอบแทน \(r\)
  • IRR เทียบกับดอกเบี้ยเงินฝาก/พันธบัตร (ทางเลือกของเงินเย็น) หรือต้นทุนเงินกู้ — ระบบโซลาร์ที่ดีมี IRR 12–20 % ซึ่งสูงกว่าทางเลือกปลอดภัยส่วนใหญ่
  • LCOE ไม่ขึ้นกับค่าไฟ ใช้เทียบเทคโนโลยีหรือเทียบกับค่าไฟที่จะซื้อ ถ้า LCOE < ค่าไฟ ทุกหน่วยที่ใช้เองคือกำไร
  • IRR หาด้วยการลองค่าหรือ bisection (เครื่องคำนวณด้านล่างใช้ bisection) ใน Excel ใช้ =IRR(ช่วงกระแสเงินสด) และ =NPV(r, ช่วงปี 1..N) - CAPEX

เครื่องคำนวณความคุ้มค่า

ค่าเริ่มต้นคือตัวอย่าง F-1 อายุ 25 ปี เปลี่ยนอินเวอร์เตอร์ปีที่ 12 (12 % ของเงินลงทุน) อัตราคิดลด 5 % กราฟคือเงินสดสะสม จุดที่ตัดแกนศูนย์คือระยะคืนทุน

สินเชื่อ ภาษี และรูปแบบการลงทุน กลาง

F8 Loan payment (annuity) ค่างวดเงินกู้รายปี

\[ A = P\,\frac{i(1+i)^n}{(1+i)^n - 1} \]
ตัวอย่าง F-2

กู้ 150,000 บาท ดอกเบี้ย 5 % 5 ปี

  1. \(A = 150{,}000 \dfrac{0.05(1.05)^5}{(1.05)^5 - 1} = 34{,}646\) บาท/ปี (≈ 2,890 บาท/เดือน)

  2. ผลประหยัดปีแรก 24,150 บาท → เงินสดสุทธิ −10,500 บาท/ปี ช่วง 5 ปีแรก

  3. ถ้ายืดเป็น 8 ปี ค่างวด ≈ 23,200 บาท/ปี ใกล้ผลประหยัด → ผ่อนแทนค่าไฟได้พอดี (cash-flow neutral)

  • รูปแบบการลงทุน: ซื้อขาด (CAPEX) · ผ่อนกับธนาคาร (สินเชื่อสีเขียว) · เช่าระบบ · Private PPA (ผู้ลงทุนติดตั้งและขายไฟให้ในราคาต่ำกว่าการไฟฟ้า ส่วนลด 10–30 % สัญญา 10–25 ปี เหมาะกับกิจการที่ไม่อยากลงทุนเอง)
  • ภาษีและสิทธิประโยชน์: นิติบุคคลหักค่าเสื่อมราคาของระบบได้ และอาจได้สิทธิประโยชน์จากมาตรการส่งเสริมการลงทุนด้านการประหยัดพลังงานและพลังงานทดแทน บุคคลธรรมดาให้ติดตามมาตรการลดหย่อนที่รัฐประกาศในแต่ละปี ตรวจเงื่อนไขกับหน่วยงานที่เกี่ยวข้องก่อนนำมาคิดในงบประมาณ
  • ประกันภัย: เพิ่มระบบโซลาร์ในกรมธรรม์ที่อยู่อาศัยหรืออัคคีภัย (บางบริษัทกำหนดให้มีวิศวกรรับรอง)

ข้อผิดพลาดที่ทำให้ตัวเลขสวยเกินจริง

  1. คิดว่าใช้เองได้ 100 % ทั้งที่โหลดกลางวันน้อยกว่าการผลิต
  2. ใช้ค่าไฟเฉลี่ยทั้งบิล แทนค่าไฟส่วนเพิ่มของหน่วยที่ถูกแทนจริง (บางกรณีกลับกัน: TOU on-peak แพงกว่าเฉลี่ย)
  3. ไม่หักการเสื่อม ค่าล้างแผง ค่าเปลี่ยนอินเวอร์เตอร์
  4. สมมติค่าไฟขึ้นปีละ 3–5 % ตลอด 25 ปี
  5. ใช้ผลผลิตของภาคที่แดดดีที่สุด หรือจากระบบที่ไม่มีเงา ทั้งที่หลังคาของตัวเองมีเงา
  6. ไม่นับค่าใช้จ่ายแฝง: ปรับปรุงตู้ไฟ ซ่อมหลังคา ค่าขออนุญาต ค่าวิศวกร

ประเด็นระดับปริญญาโท ขั้นสูง

  • Monte Carlo สุ่มตัวแปร (แสงรายปี ค่าไฟ การเสื่อม ความพร้อมใช้) หา distribution ของ NPV และความน่าจะเป็นที่จะขาดทุน
  • Real options มูลค่าของการรอซื้อแบตเตอรี่ภายหลังเมื่อราคาลด หรือขยายระบบเมื่อมีรถไฟฟ้า
  • Project finance ของโซลาร์ฟาร์ม: DSCR, P90 debt sizing, tariff structure ของ PPA, CAPEX/OPEX ของ MW และ WACC
  • ต้นทุนภายนอก มูลค่าคาร์บอน (REC/I-REC, Thailand Voluntary Emission Reduction) และผลต่อการตัดสินใจลงทุน
