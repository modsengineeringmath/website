// บทที่ 14.8 · ออกแบบระบบโซลาร์เซลล์ · Energy Yield Prediction

คาดการณ์พลังงานที่ผลิตได้: Performance Ratio ห่วงโซ่การสูญเสีย และ kWh/kWp ในไทย

ก่อนลงทุนต้องตอบให้ได้ว่า “ระบบนี้จะผลิตไฟได้ปีละกี่หน่วย และมั่นใจแค่ไหน” คำตอบไม่ใช่กำลังบนป้ายคูณชั่วโมงแดด แต่ต้องหักการสูญเสียทีละรายการ ตั้งแต่ความร้อนของแผงจนถึงสาย AC แล้วบอกความไม่แน่นอนด้วย หน้านี้สร้างการคาดการณ์แบบที่วิศวกรใช้ ตั้งแต่สูตรบรรทัดเดียวจนถึง P50/P90

เขียนโดย อาจารย์มดอัปเดต
เครื่องคำนวณพลังงาน ห่วงโซ่การสูญเสีย รายเดือนและรายปี P50 · P90 ซอฟต์แวร์
สรุปใน 30 วินาที
  • \(E = P_{STC}\times H_{POA}\times PR\) · ไทย: 1 kWp ≈ 1,300–1,450 kWh/ปี ≈ 3.6–4.0 kWh/วัน
  • PR = ผลคูณของ (1 − การสูญเสีย) ทุกรายการ การสูญเสียที่ใหญ่ที่สุดในไทยคืออุณหภูมิ (8–12 %)
  • มี.ค.–เม.ย. ผลิตมากสุด ส.ค.–ก.ย. น้อยสุด ต่างกันราว 25 %
  • รายงานเป็น P50 และ P90 เสมอเมื่อใช้ตัดสินใจลงทุน

สมการพลังงานบรรทัดเดียว พื้นฐาน

E1 Energy yield พลังงานที่ผลิตได้

\[ E_{day} = P_{STC}\times PSH_{POA}\times PR \qquad E_{year} = P_{STC}\times H_{POA,year}\times PR \]

E2 Yields and PR (IEC 61724) ผลผลิตจำเพาะและ performance ratio

\[ Y_f = \frac{E_{AC}}{P_{STC}}\ \left[\tfrac{\text{kWh}}{\text{kWp}}\right] \qquad Y_r = \frac{H_{POA}}{1\ \text{kW/m}^2}\ [\text{h}] \qquad PR = \frac{Y_f}{Y_r} \]

\(Y_f\) (specific yield) ใช้เทียบระบบต่างขนาดในพื้นที่เดียวกัน \(PR\) ใช้เทียบระบบต่างพื้นที่ เพราะหักผลของแสงออกแล้ว ทั้งสองค่าคือภาษากลางระหว่างผู้ออกแบบ ผู้ลงทุน และผู้ดูแลระบบ

ห่วงโซ่การสูญเสีย กลาง

E3 PR as a loss chain PR จากห่วงโซ่การสูญเสีย

\[ PR = \prod_i (1 - L_i) \]

E4 Temperature loss การสูญเสียจากอุณหภูมิ

\[ L_T \approx |\gamma|\,(\bar T_{c} - 25) \qquad \bar T_c \approx \bar T_{a,day} + \Delta T_{mount} \]

\(\bar T_c\) คืออุณหภูมิเซลล์เฉลี่ยถ่วงน้ำหนักด้วยพลังงาน (ช่วงที่แสงมากมีน้ำหนักมาก) \(\Delta T_{mount}\) ประมาณ 18–32 °C ตามวิธีติดตั้ง (ลอยน้ำต่ำสุด ติดชิดหลังคาสูงสุด)

ตัวอย่าง E-1

ระบบ 5.8 kWp กรุงเทพฯ หลังคาทิศใต้ 15°

  1. GHI 4.8 kWh/m²/วัน × ตัวประกอบระนาบเอียง 1.04 → \(H_{POA}\) = 4.99 kWh/m²/วัน

  2. E4: อากาศกลางวันเฉลี่ย 33 °C + ยกลอยบนหลังคา 25 °C → \(\bar T_c\) = 58 °C → \(L_T = 0.29(58-25) = 9.6\ \%\)

  3. E3: \(PR = (1-0.096)(1-0.03)(1-0.02)(1-0.015)(1-0.025)(1-0.005)(1-0.03)(1-0.01) = 0.789\)

  4. E1: \(E_{year} = 5.8 \times 4.99 \times 365 \times 0.789 \approx 8{,}340\) kWh/ปี → \(Y_f\) ≈ 1,437 kWh/kWp ≈ 22.8 kWh/วัน

  5. ถ้าหลังคาร้อนไม่มีช่องลม (+7 °C) ฝุ่น 5 % และมีเงาเช้า 3 % → PR ลดเหลือ ≈ 0.73 และ \(Y_f\) ≈ 1,330 — นี่คือเหตุผลที่ค่าในไทยมีช่วงกว้าง 1,300–1,450

เครื่องคำนวณพลังงานและ PR

เปลี่ยนพื้นที่ ทิศ การติดตั้ง และการสูญเสียแต่ละรายการ กราฟแท่งแสดงพลังงานรายเดือนตามรูปแบบแสงของภาคกลาง (ค่าประมาณ)

รายเดือน รายปี และการเสื่อม กลาง

ผลผลิตรายเดือนตามรูปแบบแสงของภาคกลาง (ค่าสัมพัทธ์ มี.ค. 1.13 · เม.ย. 1.16 · ส.ค. 0.93 · ก.ย. 0.92) ระบบในตัวอย่าง E-1 ผลิตเดือนมีนาคม ≈ 800 kWh และกันยายน ≈ 630 kWh การวางแผนการเงินรายเดือนจึงควรเผื่อช่วงฝน

E5 Energy with yearly degradation พลังงานเมื่อแผงเสื่อมทุกปี

\[ E_y = E_1\,(1-d)^{y-1} \qquad \sum_{y=1}^{N}E_y = E_1\,\frac{1-(1-d)^N}{d} \]

ตัวอย่าง: \(d\) = 0.4 %/ปี \(N\) = 25 ปี → ผลรวมเท่ากับ \(E_1 \times 23.8\) ไม่ใช่ \(E_1 \times 25\) (ใช้ในหน้า ความคุ้มค่า)

E6 Capacity factor ตัวประกอบกำลังการผลิต

\[ CF = \frac{E_{year}}{P_{rated}\times 8760\ \text{h}} \]

โซลาร์ในไทยมี CF ราว 15–17 % เทียบ kWp (สูงขึ้นถ้าเทียบพิกัด AC ของระบบที่ DC/AC > 1) ใช้เทียบกับโรงไฟฟ้าชนิดอื่นและคำนวณขนาดที่ต้องการต่อพลังงาน

ความไม่แน่นอน P50 และ P90 ขั้นสูง

E7 P90 from combined uncertainty P90 จากความไม่แน่นอนรวม

\[ \sigma_{tot} = \sqrt{\sum_i \sigma_i^2} \qquad P_{90} = P_{50}\,(1 - 1.282\,\sigma_{tot}) \qquad \sigma_{IAV,N\text{ yr}} = \frac{\sigma_{IAV}}{\sqrt N} \]

1.282 มาจากการแจกแจงปกติ (โอกาสเกิน 90 %) แหล่งความไม่แน่นอนหลัก: ความแปรปรวนของแสงระหว่างปี (inter-annual variability) ความแม่นของข้อมูลแสง แบบจำลองการแปลงเป็นระนาบเอียงและแบบจำลองระบบ การสูญเสียที่ประมาณ (ฝุ่น การเสื่อม ความพร้อมใช้)

ตัวอย่าง E-2

P90 ของโครงการ

ความแปรปรวนรายปี 4 % ข้อมูลแสง 5 % แบบจำลอง 3 % การสูญเสียอื่น 3 %

  1. \(\sigma_{tot} = \sqrt{4^2+5^2+3^2+3^2} = 7.7\ \%\)

  2. P90 หนึ่งปี \(= P_{50}(1 - 1.282 \times 0.077) = 0.90\,P_{50}\)

  3. P90 เฉลี่ย 10 ปี: ความแปรปรวนรายปีลดเหลือ \(4/\sqrt{10} = 1.26\ \%\) → \(\sigma_{tot}\) = 6.7 % → P90 = 0.91 \(P_{50}\)

  4. ความหมาย: ส่วนที่ลดไม่ได้ด้วยเวลาคือข้อมูลแสงและแบบจำลอง — การวัดแสงหน้างานจริง 1 ปีช่วยลดความไม่แน่นอนได้มากที่สุด

คำนวณรายชั่วโมงด้วยตัวเอง ขั้นสูง

ซอฟต์แวร์ทุกตัวทำสิ่งเดียวกันในหลักการ: ทุกชั่วโมงของปีตัวแทน (8,760 ค่า) คำนวณตำแหน่งดวงอาทิตย์ แปลงแสงเป็นบนระนาบแผง หักเงาและ IAM คำนวณอุณหภูมิเซลล์ คำนวณกำลัง DC หักการสูญเสีย DC ผ่านแบบจำลองอินเวอร์เตอร์ (รวม clipping) แล้วรวมเป็นพลังงาน โค้ดแบบย่อ (Python/NumPy) เพื่อให้เห็นโครงสร้าง:

import numpy as np
# poa: W/m2 บนระนาบแผง (8760 ค่า), ta: อุณหภูมิอากาศ °C, จากข้อมูลรายชั่วโมงของพื้นที่
P_stc, gamma, noct = 5800.0, -0.0029, 43.0     # W, 1/°C, °C
p_ac_max, eta_inv = 5000.0, 0.975
dc_loss = (1-0.03)*(1-0.02)*(1-0.015)*(1-0.03)  # ฝุ่น, mismatch, สาย DC, IAM/แสงน้อย

tc   = ta + (noct - 20) / 800 * poa              # P7
p_dc = P_stc * poa / 1000 * (1 + gamma * (tc - 25)) * dc_loss
p_ac = np.minimum(p_dc * eta_inv, p_ac_max)      # clipping ที่พิกัด AC
E_kwh = p_ac.sum() / 1000                         # ข้อมูลรายชั่วโมง → Wh ต่อชั่วโมง
PR = E_kwh / (P_stc / 1000 * poa.sum() / 1000)

สำหรับงานวิจัยใช้ไลบรารี pvlib python ซึ่งมีแบบจำลองตำแหน่งดวงอาทิตย์ (SPA) การแปลงแสง (Perez, Hay-Davies) อุณหภูมิเซลล์ (SAPM, Faiman) แบบจำลองไดโอดเดี่ยว (CEC, De Soto) และ PVWatts ครบ และดึงข้อมูลจาก PVGIS/NSRDB ได้
