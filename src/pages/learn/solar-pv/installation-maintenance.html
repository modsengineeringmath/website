ติดตั้ง ทดสอบ ส่งมอบ และบำรุงรักษาระบบโซลาร์: IEC 62446 I-V tracer ภาพความร้อน และวิเคราะห์อาการเสีย

การออกแบบที่ดีพังได้ด้วยการติดตั้งที่ไม่ดี: ขั้วต่อย้ำไม่แน่น สายถูกบาดใต้แผง น็อตยึดหลังคารั่ว หรือไม่เคยวัดค่าจริงเทียบกับที่ออกแบบ หน้านี้รวมงานภาคสนามตั้งแต่วันติดตั้งจนถึงปีที่ 25: ขั้นตอนที่ปลอดภัย การทดสอบก่อนจ่ายไฟพร้อมวิธีตีความตัวเลข ตารางบำรุงรักษา และตารางวิเคราะห์อาการเสีย

เขียนโดย อาจารย์มดอัปเดต
ทดสอบก่อนจ่ายไฟ ติดตั้ง ตารางบำรุงรักษา รอบล้างแผง อาการเสีย 20 แบบ
สรุปใน 30 วินาที
  • ทุกสตริง: วัดขั้ว \(V_{oc}\) \(I_{sc}\) และฉนวน แล้วเทียบกับค่าที่ปรับตามแสงและอุณหภูมิขณะวัด
  • \(V_{oc}\) ต่ำไป 1/3 แผง = ไดโอดลัด · ต่ำไปหนึ่งแผง = ต่อข้าม/แผงหาย · ฉนวนต่ำ = สายถลอกหรือความชื้น
  • ภาพความร้อนและ I-V curve หาปัญหาที่ตาเปล่ามองไม่เห็น
  • ล้างแผงเมื่อมูลค่าไฟที่เสียไปเท่ากับค่าล้าง ไม่ใช่ตามปฏิทินอย่างเดียว

ความปลอดภัยต้องมาก่อน พื้นฐาน

  • ทำงานบนที่สูง: เข็มขัดนิรภัยแบบเต็มตัวพร้อมจุดยึด บันไดยึดแน่น ห้ามเดินบนแผ่นหลังคาโปร่งแสงหรือกระเบื้องที่ไม่ได้รับน้ำหนัก หยุดงานเมื่อลมแรงหรือฝนฟ้าคะนอง
  • ไฟ DC มีตลอดเวลาที่มีแสง: ใช้เครื่องมือหุ้มฉนวน ถุงมือ แว่นตา ห้ามถอดขั้ว MC4 ขณะมีกระแส (ตัด DC isolator หรือหยุดอินเวอร์เตอร์ก่อน) ปิดแผงด้วยผ้าทึบเมื่อต้องทำงานกับขั้วที่เปิดอยู่
  • ล็อกและติดป้าย (LOTO) ทั้งฝั่ง AC และ DC ก่อนทำงานกับอินเวอร์เตอร์และแบตเตอรี่
  • ผู้ปฏิบัติงาน มีความรู้และใบอนุญาตตามข้อกำหนด งานต่อเข้าระบบไฟฟ้าทำโดยช่าง/วิศวกรไฟฟ้าที่มีคุณสมบัติ

ขั้นตอนติดตั้ง พื้นฐาน

  1. สำรวจโครงสร้าง: แป จันทัน ระยะห่าง สภาพสนิม แผ่นหลังคาเดิม ให้วิศวกรโยธาประเมินน้ำหนักเพิ่ม (ระบบหลังคาทั่วไป 12–20 kg/m²) และแรงลมยก ตามมาตรฐานการคำนวณแรงลมของกรมโยธาธิการและผังเมือง (มยผ. 1311)
  2. เลือกอุปกรณ์ยึดให้ตรงชนิดหลังคา: เมทัลชีต (แคลมป์ยึดลอนหรือ L-foot พร้อมยางกันซึม) กระเบื้องลอน/CPAC (ตะขอใต้กระเบื้อง) ดาดฟ้าคอนกรีต (ฐานถ่วงน้ำหนักหรือพุกเคมีพร้อมกันซึม) — วัสดุอะลูมิเนียมและสแตนเลส น็อตกันคลาย
  3. วางราง จัดแนว เว้นระยะขอบหลังคา (ลมแรงที่ขอบและมุม) และช่องลมใต้แผง ≥ 10 cm
  4. ยกและวางแผง ตามจุดจับยึดในคู่มือแผง ขันด้วยแรงบิดที่กำหนด (torque wrench) ห้ามเหยียบ ห้ามวางของทับ
  5. เดินสาย DC ตาม หน้าสายไฟ ย้ำขั้วด้วยเครื่องมือที่ถูกต้อง ทดสอบดึง ยึดสายด้วยคลิปสแตนเลส/เคเบิลไทร์ทน UV ติดฉลากสตริงที่ปลายสายทั้งสองด้าน
  6. ติดตั้งอินเวอร์เตอร์ ในที่ร่ม อากาศถ่ายเท เว้นระยะรอบตัวเครื่องตามคู่มือ ต่อสายดิน SPD สวิตช์ตัดตอน เบรกเกอร์
  7. ทดสอบตามหัวข้อถัดไปก่อนเชื่อมกริด แล้วตั้งค่าประเทศ/มาตรฐาน (country code) ให้ตรงกับข้อกำหนดของการไฟฟ้า

การทดสอบก่อนจ่ายไฟ (IEC 62446-1) กลาง

การทดสอบเครื่องมือเกณฑ์/สิ่งที่ดู
ตรวจด้วยตาเช็กลิสต์สายยึดแน่น ไม่ห้อย ขั้วต่อยี่ห้อเดียวกัน ป้ายครบ ไม่มีแผงแตก
ความต่อเนื่องของสายดิน/ประสานศักย์มิเตอร์ความต้านทานต่ำทุกโครงและกรอบแผงต่อถึงขั้วดินหลัก
ขั้ว (polarity)มัลติมิเตอร์ DCถูกขั้วทุกสตริงก่อนเสียบเข้าอินเวอร์เตอร์ (กลับขั้วอาจทำให้อินเวอร์เตอร์เสียหาย)
\(V_{oc}\) ทุกสตริงมัลติมิเตอร์ DC CAT III 1000 V ขึ้นไปเทียบค่าคาดหมาย (I1) และเทียบสตริงกันเอง ต่างกันไม่เกิน ~2–3 %
\(I_{sc}\) หรือกระแสใช้งานแคลมป์มิเตอร์ DC / I-V tracerเทียบค่าคาดหมายที่แสงขณะวัด (≥ 400–600 W/m²)
ความต้านทานฉนวนเครื่องทดสอบฉนวน 500/1,000 V DC≥ 1 MΩ ตามเกณฑ์ของมาตรฐาน (ทดสอบ + และ − ลงดิน โดยใช้วิธีที่ปลอดภัยตามคู่มือเครื่องมือ)
การทำงาน—สวิตช์ตัดตอน การตัดเมื่อไฟดับ (anti-islanding) การสื่อสาร monitoring
(ระดับ 2) I-V curve ทุกสตริงI-V curve tracer + เซนเซอร์แสง/อุณหภูมิรูปร่างเส้นโค้ง FF กำลังที่ปรับเป็น STC
(ระดับ 2) ภาพถ่ายความร้อนกล้องอินฟราเรด/โดรน (IEC 62446-3)แสงบนแผง ≥ 600 W/m² หา hot spot ไดโอด ขั้วต่อร้อน

I1 Expected string values at test conditions ค่าคาดหมายของสตริงขณะทดสอบ

\[ V_{oc,exp} = N_s V_{oc,STC}\left[1+\beta(T_c-25)\right] \qquad I_{sc,exp} = I_{sc,STC}\,\frac{G}{1000}\left[1+\alpha(T_c-25)\right] \]

ตารางบำรุงรักษา พื้นฐาน

ความถี่บ้าน/อาคารเพิ่มสำหรับระบบใหญ่
รายวัน/รายสัปดาห์ดูพลังงานในแอป เทียบวันที่แดดคล้ายกันระบบแจ้งเตือนอัตโนมัติ PI รายสตริง (A6)
ทุก 3–6 เดือนล้างแผงตามความสกปรก ตรวจด้วยตาจากพื้นตัดหญ้า ตรวจรั้ว ระบายน้ำ
ทุก 6–12 เดือนทำความสะอาดอินเวอร์เตอร์ (ไส้กรอง ช่องลม) ตรวจ SPD ตรวจขั้วต่อในตู้ภาพความร้อน combiner/หม้อแปลง ขันขั้วตามแรงบิด
ปีละครั้งตรวจโครงยึด สนิม กันซึม สายใต้แผง วัด \(V_{oc}\)/กระแสสตริงเทียบวันส่งมอบI-V curve ตัวอย่างสตริง ภาพความร้อนทั้งฟาร์มด้วยโดรน ทดสอบฉนวน
หลังพายุ/ฟ้าผ่าตรวจแผงแตก สายหลุด SPDตรวจตัวติดตามและรั้ว
ปีที่ 10–15วางแผนเปลี่ยนอินเวอร์เตอร์ พัดลม ตัวเก็บประจุretrofit อุปกรณ์รุ่นใหม่

ล้างแผงเมื่อไรจึงคุ้ม กลาง

I2 Soiling ratio อัตราส่วนความสกปรก

\[ SR = \frac{P_{dirty}}{P_{clean}}\ \text{(ที่แสงและอุณหภูมิเดียวกัน)} \qquad L_{soil} = 1 - SR \]

I3 Optimal cleaning interval (linear soiling) รอบล้างที่คุ้มที่สุด

\[ \text{มูลค่าที่เสียใน } n \text{ วัน} \approx \frac{s\,n^2}{2}\,E_{day}\,c \qquad n^* = \sqrt{\frac{2\,C_{clean}}{s\,E_{day}\,c}} \]

\(s\) = อัตราสะสมฝุ่น (สัดส่วนต่อวัน เช่น 0.001 = 0.1 %/วัน ในหน้าแล้ง) \(E_{day}\) = พลังงานต่อวัน \(c\) = มูลค่าต่อหน่วย \(C_{clean}\) = ค่าล้างต่อครั้ง ล้างเมื่อครบ \(n^*\) วัน หรือก่อนหน้านั้นถ้าฝนไม่ตก

ตัวอย่าง I-2

บ้าน 5.8 kWp ค่าล้างครั้งละ 800 บาท

  1. \(E_{day}\) = 22.8 kWh, \(c\) = 4.2 บาท, \(s\) = 0.1 %/วัน (หน้าแล้ง ไม่มีฝน)

  2. \(n^* = \sqrt{\dfrac{2(800)}{0.001(22.8)(4.2)}} = \sqrt{16{,}700} \approx 129\) วัน

  3. ที่ 129 วัน แผงสกปรกสะสม ≈ 6.5 % (เฉลี่ยช่วงนั้น ≈ 3 %) → ล้างราว 2–3 ครั้งต่อปีเฉพาะช่วงแล้ง ฝนช่วยล้างหน้าฝน

  4. ถ้าใกล้ไร่อ้อยช่วงเผาหรือฟาร์มไก่ \(s\) อาจเป็น 0.3–0.5 %/วัน → \(n^*\) ≈ 60–75 วัน

#อาการสาเหตุที่น่าจะเป็นวิธีตรวจ/แก้
1อินเวอร์เตอร์ไม่ทำงานเลยตอนเช้าแรงดันสตริงต่ำกว่า start-up, DC isolator ปิด, ฟิวส์ขาดวัด \(V_{oc}\) ที่ขั้วอินเวอร์เตอร์
2Error “Isolation fault / Riso low” ตอนเช้าหลังฝนตกสายถลอกที่ขอบราง ขั้วต่อเปียก กล่องแยกสายมีน้ำทดสอบฉนวนทีละสตริง ตรวจขั้วต่อ
3ตัดช่วงเที่ยง “Grid overvoltage”แรงดันสายจำหน่ายสูง สาย AC เล็ก/ยาววัดแรงดันที่มิเตอร์และขั้วอินเวอร์เตอร์ แก้สาย AC แจ้งการไฟฟ้า เปิด Volt-VAR ตามที่อนุญาต
4กำลังแบนเรียบช่วงเที่ยงclipping ตาม DC/AC, export limit, derating ความร้อนดูอุณหภูมิอินเวอร์เตอร์ การตั้งค่า
5สตริงหนึ่งกระแสต่ำกว่าเพื่อนเงาใหม่ ฝุ่นเฉพาะจุด แผงเสีย ขั้วต่อหลวมเทียบ δ (A7) ภาพความร้อน
6แรงดันสตริงต่ำ 1/3 แผงบายพาสไดโอดลัดวัด \(V_{oc}\) รายแผง เปลี่ยนกล่องต่อสาย/แผง
7จุดร้อนบนแผง (hot spot)เซลล์ร้าว เงาถาวร สิ่งสกปรกเกาะ (มูลนก)ภาพความร้อน ทำความสะอาด เคลมแผง
8ขั้วต่อ MC4 ร้อน ไหม้ต่างยี่ห้อ ย้ำไม่ดี น้ำเข้าตัดออกเปลี่ยนคู่ใหม่ยี่ห้อเดียวกัน
9พลังงานลดลงทีละน้อยทุกปีมากกว่าการเสื่อมPID ฝุ่นสะสม เงาต้นไม้ที่โตขึ้นI-V curve ดูความชัน PID recovery ตัดแต่งต้นไม้
10อินเวอร์เตอร์หยุดเป็นพัก ๆ ช่วงบ่ายร้อนระบายความร้อนไม่พอ พัดลมเสีย ติดตั้งกลางแดดย้ายที่/ทำร่มเงา ทำความสะอาดพัดลม
11RCD ทริปบ่อยกระแสรั่วผ่านความจุแผงในอากาศชื้น RCD ไม่ตรงชนิด/พิกัดใช้ชนิดและพิกัดที่ผู้ผลิตกำหนด ตรวจฉนวน
12Hybrid ไม่ชาร์จแบต/แบตหยุดกะทันหันการสื่อสาร BMS ขาด โปรโตคอลไม่ตรง แบตร้อนตรวจสาย CAN/RS485 ตั้งค่ายี่ห้อแบต
13ไฟสำรองไม่ทำงานตอนไฟดับโหลดสำรองเกิน ไม่ได้เดินสายตู้สำรอง ตั้งค่า EPS ปิดทดสอบตัดไฟเมนเป็นระยะ

19พลังงานต่ำทั้งระบบแต่ไม่มี errorฝุ่นทั่วทั้งระบบ ปีฝนชุก (เทียบด้วยแสงจริง)คำนวณ PI จากแสงจริง ล้างแผง
20อินเวอร์เตอร์เสียงหึ่ง/ร้อนผิดปกติตัวเก็บประจุเสื่อม ฮาร์มอนิก ภาระเกินติดต่อผู้ผลิต ตรวจคุณภาพไฟฟ้า (แล็บฮาร์มอนิก)

วิธีคิดแบบเป็นระบบเหมือนงานซ่อมคอนเวอร์เตอร์ (วิเคราะห์อาการเสียของคอนเวอร์เตอร์): เริ่มจากข้อมูล → แยกส่วน (สตริง/อินเวอร์เตอร์/กริด) → วัดค่าที่เทียบได้ → เปลี่ยนทีละอย่าง → บันทึก

ประเด็นระดับปริญญาโท ขั้นสูง

  • EL (electroluminescence) และ UVF (UV fluorescence) ภาคสนามเพื่อหารอยร้าวเซลล์ในฟาร์มขนาดใหญ่ (ทำกลางคืนหรือด้วยกล้องที่กรองแสง)
  • การวิเคราะห์ภาพความร้อนจากโดรนด้วย AI จำแนกชนิดความผิดปกติอัตโนมัติ และหาตำแหน่งบนผังด้วย GPS
  • Reliability-centered maintenance และการวางแผนอะไหล่จากอัตราความเสียหาย (FIT) ของอินเวอร์เตอร์ ขั้วต่อ และแผง
  • การรีไซเคิลแผงหมดอายุ และการซ่อมแผง (repowering) เมื่อแผงรุ่นเดิมหาไม่ได้
