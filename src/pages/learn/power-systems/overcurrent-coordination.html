// บทที่ 16.8 · ระบบไฟฟ้ากำลังและระบบป้องกัน · Overcurrent Protection & Coordination

รีเลย์กระแสเกินและการประสานการป้องกัน: กราฟ IDMT, TMS, CTI, ฟิวส์ และเบรกเกอร์

รีเลย์กระแสเกินคือการป้องกันที่พบมากที่สุดในระบบจำหน่ายและโรงงาน หลักง่ายมาก — กระแสยิ่งมากยิ่งตัดเร็ว — แต่ศิลปะอยู่ที่การประสาน: รีเลย์ที่ใกล้ฟอลต์ที่สุดต้องตัดก่อนเสมอ และรีเลย์ต้นทางต้องรอพอดี ๆ เพื่อเป็นสำรอง หน้านี้ตั้งค่ารีเลย์สามระดับทีละขั้น แล้วให้คุณลองเองบนกราฟ TCC

เขียนโดย อาจารย์มดอัปเดต
แล็บกราฟ TCC กราฟ IDMT ตั้ง pickup · TMS CTI · ประสาน 3 ระดับ ฟิวส์ · MCB
สรุปใน 30 วินาที
  • \(t = TMS\cdot k/((I/I_s)^\alpha - 1)\) · SI (0.14, 0.02) · VI (13.5, 1) · EI (80, 2)
  • Pickup: เหนือกระแสโหลดสูงสุด 1.2–1.5 เท่า ต่ำกว่ากระแสฟอลต์ต่ำสุด 1.5 เท่า
  • CTI ≈ 0.2–0.4 s ที่กระแสฟอลต์สูงสุดที่ทั้งคู่มองเห็น
  • ค่าทันที (50) ตั้งเหนือกระแสฟอลต์สูงสุดที่บัสปลายทาง เพื่อไม่ตัดแทนตัวปลายทาง

กราฟเวลาผกผัน IDMT ตาม IEC 60255-151 พื้นฐาน

R2 IEC inverse-time characteristic สมการเวลาทำงาน

\[ t = TMS \cdot \frac{k}{\left(I/I_s\right)^{\alpha} - 1} \]

R3 Curve constants ค่าคงที่ของกราฟมาตรฐาน

\[ \text{SI: } (0.14,\ 0.02) \quad \text{VI: } (13.5,\ 1) \quad \text{EI: } (80,\ 2) \quad \text{LTI: } (120,\ 1) \]

R4 Plug setting multiplier ตัวคูณกระแส

\[ PSM = \frac{I_{fault}}{I_s} = \frac{I_{fault}}{CT_{ratio}\times PS} \]

กราฟ SI แทบแบนเมื่อ PSM เกิน 10 (เวลาเปลี่ยนน้อย) ส่วน EI ชันมาก: เวลาลดลงตามกำลังสองของกระแส คล้ายกราฟการหลอมของฟิวส์ (\(I^2t\) คงที่) จึงประสานกับฟิวส์ได้ดี

ตัวอย่าง R-1

CT 400/5 PS 1.0 TMS 0.1 SI กระแสฟอลต์ 6,000 A

  1. R4: \(I_s = 400\) A → \(PSM = 15\)

  2. R2: \(t = 0.1 \times 0.14/(15^{0.02} - 1) = 0.014/0.0557 = 0.25\) s

  3. ถ้าเป็น EI: \(t = 0.1 \times 80/(15^2 - 1) = 8/224 = 0.036\) s — เร็วกว่ามากที่กระแสสูง

ตั้งค่า pickup และค่าทันที กลาง

R1 Pickup setting กระแสตั้ง

\[ 1.2\text{–}1.5\,I_{load,max} \;\le\; I_s \;\le\; \frac{I_{fault,min,end\ of\ backup\ zone}}{1.5} \]

R7 Instantaneous (50) setting ค่าตั้งทันที

\[ I_{>>} \ge 1.25\text{–}1.3 \times I_{fault,max}\ \text{at the next downstream bus} \]

ค่าทันทีช่วยตัดฟอลต์ใกล้ตัวรีเลย์ (กระแสสูงมาก) โดยไม่ต้องรอกราฟ แต่ต้องไม่เห็นฟอลต์ในโซนถัดไป สำหรับรีเลย์ที่ต้นทางหม้อแปลง ให้ตั้งเหนือกระแสลัดวงจรที่ฝั่งแรงต่ำ (อ้างอิงฝั่งแรงสูง) และเหนือ inrush ของหม้อแปลง (≈ 8–12 เท่าพิกัด ช่วง 0.1 s)

ช่วงเวลาประสาน (CTI) และการประสาน 3 ระดับ กลาง

R5 Coordination time interval ช่วงเวลาประสาน

\[ t_{upstream}(I_{f}) - t_{downstream}(I_{f}) \ge CTI = t_{CB} + t_{overshoot} + t_{errors} + t_{safety} \approx 0.2\text{–}0.4\ \text{s} \]

R6 Required TMS TMS ที่ต้องการเพื่อได้ CTI

\[ TMS_{req} = \frac{\left(t_{down} + CTI\right)\left[(I_f/I_s)^{\alpha} - 1\right]}{k} \quad (\text{ปัดขึ้นเป็นขั้นที่รีเลย์ตั้งได้}) \]
ตัวอย่าง R-2

รีเลย์ 3 ระดับ SI ทั้งหมด ฟอลต์สูงสุดที่บัสปลายทาง 10 kA CTI 0.3 s

  1. R1 (ป้อนโหลด): \(I_s = 200\) A, TMS 0.1 → PSM 50 → \(t_1 = 0.1(0.14)/(50^{0.02}-1) = 0.172\) s

  2. R2 (เมนแรงต่ำ): \(I_s = 600\) A → PSM 16.67 → ต่อ TMS 1: \(0.14/(16.67^{0.02}-1) = 2.419\) s · R6: \(TMS = (0.172+0.3)/2.419 = 0.195\) → ตั้ง 0.20 → \(t_2 = 0.484\) s

  3. R3 (ต้นทาง): \(I_s = 1200\) A → PSM 8.33 → ต่อ TMS 1: 3.232 s · \(TMS = (0.484+0.3)/3.232 = 0.243\) → ตั้ง 0.25 → \(t_3 = 0.808\) s

  4. ตรวจ CTI: \(0.484 - 0.172 = 0.31\) ✓ · \(0.808 - 0.484 = 0.32\) ✓ — ราคาของการเลือกตัด: ฟอลต์ใกล้ต้นทางใช้เวลาเกือบ 1 วินาที จึงมักเพิ่มค่าทันที (R7) ให้ R3

แล็บกราฟ TCC: ลองประสานรีเลย์เอง

ค่าตั้งต้นคือตัวอย่าง R-2 ลองเปลี่ยน R1 เป็น EI แล้วดูว่า CTI ที่กระแสต่ำเสียไปหรือไม่ ลองตั้งค่าทันทีให้ R3 (เช่น 15,000 A) หรือกดปุ่มคำนวณ TMS อัตโนมัติ เส้นสีแดงแนวตั้งคือกระแสฟอลต์ที่ใช้ตรวจ

ฟิวส์และเบรกเกอร์แรงต่ำในการประสาน พื้นฐาน

R8 MCB instantaneous (magnetic) trip bands ช่วงตัดทันทีของ MCB (IEC 60898)

\[ \text{B: } 3\text{–}5\,I_n \qquad \text{C: } 5\text{–}10\,I_n \qquad \text{D: } 10\text{–}20\,I_n \]
อุปกรณ์ลักษณะกราฟข้อควรรู้ในการประสาน
ฟิวส์ HRC (gG)ชันแบบ \(I^2t\) คงที่ จำกัดกระแสได้ประสานฟิวส์ต่อฟิวส์ด้วยอัตราส่วนพิกัด ≈ 1.6:1 ขึ้นไป
MCB B / C / Dส่วนความร้อน (bimetal) + ส่วนแม่เหล็ก (ทันที)ในช่วงทันทีประสานด้วยเวลาไม่ได้ ต้องใช้ระดับกระแสหรือตารางของผู้ผลิต
MCCB / ACB electronic tripLSI: Long (L) Short (S) Instantaneous (I) ปรับได้ตั้งช่วง S หน่วงเวลา 0.1–0.4 s เพื่อประสานกับตัวปลายทาง
รีโคลสเซอร์ (ระบบจำหน่าย)กราฟเร็วและช้า ต่อกลับหลายครั้ง“fuse saving”: ตัดเร็วก่อนฟิวส์ขาด ถ้าฟอลต์ยังอยู่ปล่อยให้ฟิวส์ขาด

การประสานกับ MCB ปลายทางใช้หลักเดียวกัน: ที่กระแสฟอลต์สูงสุด ณ ตำแหน่ง MCB เส้นของอุปกรณ์ต้นทางต้องอยู่สูงกว่าเส้นบนสุดของ MCB (เวลาตัดรวม clearing) อย่างน้อย CTI ที่เหมาะกับชนิดอุปกรณ์
