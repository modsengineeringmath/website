// บทที่ 18.3 · ระบบไฟฟ้ากำลังและระบบป้องกัน · Per-Unit System

ระบบต่อหน่วย (Per-Unit System): ค่าฐาน การเปลี่ยนฐาน หม้อแปลง และไดอะแกรมอิมพีแดนซ์

ระบบไฟฟ้าจริงมีแรงดันหลายระดับต่อกันด้วยหม้อแปลง ถ้าคิดเป็นโวลต์และโอห์ม ต้องแปลงค่าข้ามหม้อแปลงทุกครั้ง ระบบต่อหน่วยแก้ปัญหานี้ด้วยการหารทุกค่าด้วย “ค่าฐาน” ที่เลือกอย่างฉลาด ผลคือหม้อแปลงอุดมคติหายไป และค่าทุกตัวอยู่ในช่วงที่ตรวจด้วยสามัญสำนึกได้

เขียนโดย อาจารย์มดอัปเดต
ค่าฐาน เปลี่ยนฐาน หม้อแปลงหายไป ตัวอย่างระบบเต็ม เครื่องคำนวณ
สรุปใน 30 วินาที
  • ค่า pu = ค่าจริง ÷ ค่าฐาน · เลือก S_base (ทั้งระบบ) และ V_base (ต่อโซนแรงดัน)
  • \(Z_{base} = V_{base}^2/S_{base}\) · \(I_{base} = S_{base}/(\sqrt3 V_{base})\) (ค่าสามเฟส แรงดันสาย)
  • เปลี่ยนฐาน: \(Z_{new} = Z_{old}(S_{new}/S_{old})(V_{old}/V_{new})^2\)
  • V_base ข้ามหม้อแปลงตามอัตราส่วนรอบ → หม้อแปลงเหลือแค่ \(Z_{pu}\)

ทำไมต้องใช้ per-unit พื้นฐาน

  • หม้อแปลงหายไป จากวงจรเมื่อเลือกฐานถูก (เหลือแค่อิมพีแดนซ์รั่ว)
  • ค่าอยู่ในช่วงแคบ: หม้อแปลง 0.04–0.15 pu เครื่องกำเนิด \(X_d''\) 0.12–0.25 pu แรงดันปกติ 0.95–1.05 pu — ตัวเลขแปลกตาแปลว่าคำนวณผิด
  • ดาต้าชีตให้ค่าเป็น % หรือ pu อยู่แล้ว (%Z ของหม้อแปลง \(X_d''\) ของเครื่องกำเนิด)
  • ไม่มี √3 กวนใจ: ในระบบสามเฟสสมดุล ค่า pu ของแรงดันสายเท่ากับแรงดันเฟส และกำลังสามเฟสเท่ากับกำลังต่อเฟส

ค่าฐานและค่าต่อหน่วย พื้นฐาน

U1 Per-unit value ค่าต่อหน่วย

\[ x_{pu} = \frac{x_{actual}}{x_{base}} \qquad \%x = 100\,x_{pu} \]

U2 Base impedance อิมพีแดนซ์ฐาน (S สามเฟส, V แรงดันสาย)

\[ Z_{base} = \frac{V_{base,LL}^2}{S_{base,3\varphi}} \qquad (\text{kV}^2/\text{MVA} = \Omega) \]

U3 Base current กระแสฐาน

\[ I_{base} = \frac{S_{base,3\varphi}}{\sqrt3\,V_{base,LL}} \]
ตัวอย่าง U-1

ฐาน 100 MVA 22 kV

  1. U2: \(Z_{base} = 22^2/100 = 4.84\ \Omega\) · U3: \(I_{base} = 100\text{e}6/(\sqrt3 \cdot 22\text{e}3) = 2{,}624\) A

  2. สาย \(Z = 4.84\ \Omega\) → 1.0 pu · กระแส 1,000 A → 0.381 pu · แรงดัน 21.5 kV → 0.977 pu

เปลี่ยนฐานอิมพีแดนซ์ กลาง

U5 Change of base เปลี่ยนฐานอิมพีแดนซ์

\[ Z_{pu,new} = Z_{pu,old}\,\frac{S_{base,new}}{S_{base,old}}\left(\frac{V_{base,old}}{V_{base,new}}\right)^2 \]

ที่มา: ค่าโอห์มจริงต้องเท่าเดิม \(Z_{pu,old}Z_{base,old} = Z_{pu,new}Z_{base,new}\) แทน U2 ได้ U5 ทันที

ตัวอย่าง U-2

หม้อแปลง 1 MVA 22 kV %Z = 6 % บนฐานระบบ 100 MVA

  1. U5: \(0.06 \times (100/1) \times 1^2 = 6.0\) pu

  2. ตรวจเป็นโอห์ม: ฐานเดิม \(0.06 \times 22^2/1 = 29.04\ \Omega\) · ฐานใหม่ \(6 \times 4.84 = 29.04\ \Omega\) ✓

  3. ค่า 6 pu ดูใหญ่ แต่สมเหตุสมผล: หม้อแปลงเล็กมากเทียบกับฐาน 100 MVA จึง “แข็ง” น้อย (จำกัดกระแสได้มาก)

ทำไมหม้อแปลงหายไปจากวงจร pu กลาง

U4 Voltage bases across a transformer ฐานแรงดันสองด้านของหม้อแปลง

\[ \frac{V_{base,HV}}{V_{base,LV}} = \frac{V_{rated,HV}}{V_{rated,LV}} \quad\Rightarrow\quad \frac{Z_{base,HV}}{Z_{base,LV}} = \left(\frac{V_{HV}}{V_{LV}}\right)^2 \]

U6 Transformer impedance is the same in pu on both sides ค่า pu เท่ากันสองด้าน

\[ Z_{\Omega,HV} = a^2 Z_{\Omega,LV} \ \text{และ}\ Z_{base,HV} = a^2 Z_{base,LV} \;\Rightarrow\; Z_{pu,HV} = Z_{pu,LV} \]
ตัวอย่าง U-3

หม้อแปลง 1 MVA 22/0.4 kV Z = 6 %

  1. ด้านแรงสูง: \(0.06 \times 22^2/1 = 29.04\ \Omega\) · ด้านแรงต่ำ: \(0.06 \times 0.4^2/1 = 9.6\ \text{m}\Omega\)

  2. อัตราส่วน \(29.04/0.0096 = 3025 = (22/0.4)^2\) ✓ — โอห์มต่างกัน 3,025 เท่า แต่ pu = 0.06 เท่ากัน

ตัวอย่างระบบเต็ม: เครื่องกำเนิด–หม้อแปลง–สายส่ง–หม้อแปลง กลาง

ตัวอย่าง U-4

ลัดวงจรสามเฟสที่บัส F (แรงดันก่อนเกิดเหตุ 1.0 pu)

  1. อุปกรณ์มีพิกัดตรงฐานทุกตัว ใช้ค่าเดิม: G 0.20 · T1 0.10 · T2 0.10

  2. สายส่ง: \(Z_{base} = 138^2/100 = 190.44\ \Omega\) → \(j50/190.44 = j0.2626\) pu

  3. รวม \(X = 0.20 + 0.10 + 0.2626 + 0.10 = 0.6626\) pu → \(I_f = 1/0.6626 = 1.509\) pu

  4. U3 ที่ 13.8 kV: \(I_{base} = 100\text{e}6/(\sqrt3 \cdot 13.8\text{e}3) = 4{,}184\) A → \(I_f = 1.509 \times 4184 = 6.31\) kA

  5. ในสายส่ง (ฐาน 138 kV, \(I_{base} = 418.4\) A): กระแสเดียวกัน 1.509 pu = 631 A — pu ไม่สนว่าอยู่ด้านไหนของหม้อแปลง

เครื่องคำนวณ per-unit และเปลี่ยนฐาน
