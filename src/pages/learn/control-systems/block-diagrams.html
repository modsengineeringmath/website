// บทที่ 11.3 · ระบบควบคุม · Block Diagrams & Signal-Flow Graphs

บล็อกไดอะแกรม แผนภาพสัญญาณ และฟังก์ชันถ่ายโอนวงปิด

ระบบจริงประกอบด้วยตัวควบคุม ตัวขับ พลานต์ เซนเซอร์ และฟิลเตอร์ ต่อกันเป็นลูปซ้อนลูป บล็อกไดอะแกรมคือภาษาภาพที่วิศวกรควบคุมใช้คุยกัน และการลดรูปให้เหลือฟังก์ชันถ่ายโอนเดียวคือทักษะที่ต้องคล่องก่อนวิเคราะห์อะไรต่อ หน้านี้มีกฎลดรูปครบชุด กฎของเมสัน และตัวอย่างลูปซ้อนจากเซอร์โวมอเตอร์ สูตรใช้รหัส B

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • อนุกรม: คูณ · ขนาน: บวก · ป้อนกลับลบ: \(\dfrac{G}{1 + GH}\)
  • ย้ายจุดรวม/จุดแยกข้ามบล็อก ต้องใส่บล็อกชดเชย \(G\) หรือ \(1/G\)
  • เมสัน: \(T = \dfrac{\sum P_k\Delta_k}{\Delta}\), \(\Delta = 1 - \sum L_i + \sum L_iL_j - \cdots\) (คู่ที่ไม่สัมผัสกัน)
  • ลูปในเร็ว (ความเร็ว กระแส) ทำให้ลูปนอก (ตำแหน่ง) ออกแบบง่ายและหน่วงดีขึ้น

กฎลดรูปพื้นฐาน พื้นฐาน

B1 Series (cascade) อนุกรม

\[ G_1 \to G_2 \ \equiv\ G_1G_2 \]

ใช้ได้เมื่อบล็อกหลังไม่ “โหลด” บล็อกหน้า (วงจรจริงต้องมีบัฟเฟอร์ เช่น ออปแอมป์)

B2 Parallel ขนาน

\[ G_1 \parallel G_2 \ \equiv\ G_1 \pm G_2 \]

ตามเครื่องหมายที่จุดรวม · PID แบบขนานคือ \(K_P + K_I/s + K_Ds\)

B3 Feedback loop วงป้อนกลับ

\[ \frac{Y}{R} = \frac{G}{1 \pm GH} \qquad (+\ \text{สำหรับป้อนกลับลบ},\ -\ \text{สำหรับป้อนกลับบวก}) \]

จำแบบคำพูด: “ไปข้างหน้า ส่วน หนึ่งบวกรอบลูป” · ป้อนกลับหนึ่งหน่วย (\(H = 1\)): \(\frac{G}{1 + G}\)

B4 Moving junctions ย้ายจุดรวมและจุดแยก

\[ \begin{array}{l|l} \text{ย้ายจุดรวมไปหลังบล็อก } G & \text{ใส่ } G \text{ ในเส้นที่เข้ามารวม} \\ \text{ย้ายจุดรวมไปหน้าบล็อก } G & \text{ใส่ } 1/G \\ \text{ย้ายจุดแยกไปหลังบล็อก } G & \text{ใส่ } 1/G \text{ ในเส้นที่แยกออก} \\ \text{ย้ายจุดแยกไปหน้าบล็อก } G & \text{ใส่ } G \end{array} \]

หลักการ: สัญญาณทุกเส้นต้องเหมือนเดิมหลังย้าย · ใช้แยกลูปที่พันกันให้เป็นลูปซ้อนกันได้

B5 Equivalent unity feedback แปลงเป็นป้อนกลับหนึ่งหน่วย

\[ G_e = \frac{G}{1 + GH - G} \]

ใช้หาชนิดของระบบและความผิดพลาดอยู่ตัวเมื่อ \(H \ne 1\)

B6 Multiple inputs หลายอินพุต

\[ Y = T_R(s)R + T_D(s)D \]

ระบบเชิงเส้นใช้การซ้อนทับ: หาทีละอินพุตโดยตั้งอินพุตอื่นเป็นศูนย์ แล้วบวก

ลดรูปทีละขั้น: สามลูปซ้อน พื้นฐาน

ตัวอย่าง B-1 · ลดรูปจากในออกนอก

หา \(Y/R\) ของระบบในรูปด้านบน

  1. ลูปในสุด \(G_2\) กับ \(H_1\) B3: \(\dfrac{G_2}{1 + G_2H_1}\) แล้วอนุกรมกับ \(G_3\) B1

    \[ X = \frac{G_2G_3}{1 + G_2H_1} \]

  2. ลูปกลาง \(X\) กับ \(H_2\)

    \[ \frac{X}{1 + XH_2} = \frac{G_2G_3}{1 + G_2H_1 + G_2G_3H_2} \]

  3. อนุกรม \(G_1\) แล้วปิดลูปนอกหนึ่งหน่วย

    \[ \frac{Y}{R} = \hlC{\frac{G_1G_2G_3}{1 + G_2H_1 + G_2G_3H_2 + G_1G_2G_3}} \]

ตรวจด้วย sympy ✓ · สังเกตตัวส่วน = 1 + ผลรวมลูปเกนทุกลูป (เพราะทุกลูปสัมผัสกัน) ตรงกับกฎของเมสันด้านล่าง

กฎของเมสัน (Mason's Gain Formula) กลาง

แปลงบล็อกไดอะแกรมเป็นแผนภาพการไหลของสัญญาณ (signal-flow graph): สัญญาณเป็นโนด บล็อกเป็นกิ่งที่มีเกน แล้วใช้สูตรเดียวได้คำตอบทันที แม้ลูปจะพันกันซับซ้อน (Samuel Mason, 1953)

B7 Mason's gain formula กฎของเมสัน

\[ T = \frac{1}{\Delta}\sum_k P_k\Delta_k, \qquad \Delta = 1 - \sum L_i + \sum L_iL_j - \sum L_iL_jL_k + \cdots \]

\(P_k\) = เกนของเส้นทางไปข้างหน้าที่ \(k\) · \(L_i\) = ลูปเกน (รวมเครื่องหมายลบของป้อนกลับลบ) · \(L_iL_j\) = ผลคูณของคู่ลูปที่ไม่สัมผัสกัน · \(\Delta_k\) = \(\Delta\) ที่ตัดลูปซึ่งสัมผัสเส้นทาง \(k\) ทิ้ง

ตัวอย่าง B-2 · ลูปที่ไม่สัมผัสกัน

เส้นทางไปข้างหน้า \(G_1G_2G_3G_4\) มีลูป \(-G_2H_1\) (รอบ \(G_2\)) \(-G_4H_2\) (รอบ \(G_4\)) และลูปนอก \(-G_1G_2G_3G_4H_3\) หา \(Y/R\)

  1. \(P_1 = G_1G_2G_3G_4\) · ลูป: \(L_1 = -G_2H_1\), \(L_2 = -G_4H_2\), \(L_3 = -G_1G_2G_3G_4H_3\)

  2. \(L_1\) กับ \(L_2\) ไม่สัมผัสกัน (\(G_2\) กับ \(G_4\) ไม่มีโนดร่วม คั่นด้วย \(G_3\)) · \(L_3\) สัมผัสทุกลูป

    \[ \Delta = 1 + G_2H_1 + G_4H_2 + G_1G_2G_3G_4H_3 + G_2H_1G_4H_2 \]

  3. ทุกลูปสัมผัสเส้นทาง \(P_1\): \(\Delta_1 = 1\) B7

\[ \frac{Y}{R} = \frac{G_1G_2G_3G_4}{1 + G_2H_1 + G_4H_2 + G_1G_2G_3G_4H_3 + G_2G_4H_1H_2} \]

ลดรูปแบบบล็อกตรวจ: ลูปใน \(\frac{G_2}{1 + G_2H_1}\) และ \(\frac{G_4}{1 + G_4H_2}\) คูณกันได้ตัวส่วน \((1 + G_2H_1)(1 + G_4H_2)\) ซึ่งกระจายแล้วมีพจน์ \(G_2H_1G_4H_2\) พอดี ✓

ลูปซ้อน: ป้อนกลับความเร็วด้วยแทโคมิเตอร์ กลาง

เซอร์โวตำแหน่งที่ใช้ P อย่างเดียวมักแกว่งมาก วิธีคลาสสิกคือวัดความเร็วด้วยแทโคมิเตอร์ (หรือเอนโค้ดเดอร์) ป้อนกลับเป็นลูปใน ทำหน้าที่เหมือนแดมเปอร์ไฟฟ้า หลักเดียวกับลูปกระแส–ความเร็ว–ตำแหน่งของไดรฟ์ทุกตัวในเมคาทรอนิกส์

ตัวอย่าง B-3 · เลือกเกนแทโค

ในรูปด้านบน ให้ \(K = 1\) หา \(K_t\) ที่ทำให้วงปิดมี \(\zeta = 0.5\) และเทียบกับกรณีไม่มีแทโค

  1. ลูปใน B3: \(\dfrac{\Omega}{U} = \dfrac{10/(s+1)}{1 + 10K_t/(s+1)} = \dfrac{10}{s + 1 + 10K_t}\)

  2. อนุกรม \(K\) และ \(1/s\) แล้วปิดลูปนอก

    \[ \frac{\Theta}{\Theta_r} = \frac{10K}{s^2 + (1 + 10K_t)s + 10K} \]

  3. \(K = 1\): \(\omega_n = \sqrt{10} = 3.162\) · \(2\zeta\omega_n = 1 + 10K_t = 3.162 \Rightarrow K_t = 0.216\)

  4. ไม่มีแทโค: \(\zeta = \dfrac{1}{2(3.162)} = 0.158\) overshoot 60%

\(K_t = 0.216\) ลด overshoot จาก 60% เหลือ 16.3% โดย \(\omega_n\) เท่าเดิม ลูปในเพิ่มการหน่วงโดยไม่เพิ่มศูนย์ (ต่างจาก PD) จึงไม่มี overshoot ส่วนเกินจากศูนย์

ข้อผิดพลาดที่พบบ่อย

  • เครื่องหมายป้อนกลับ → ดูเครื่องหมายที่จุดรวมทุกครั้ง ป้อนกลับบวกตัวส่วนเป็น \(1 - GH\)
  • ย้ายจุดแยกแล้วลืมบล็อกชดเชย → ตรวจว่าสัญญาณในเส้นที่ย้ายยังเหมือนเดิม B4
  • เมสัน: นับคู่ลูปที่สัมผัสกัน → นับเฉพาะคู่ที่ไม่มีโนดร่วมเลย
  • ลืม \(\Delta_k\) → ถ้ามีลูปที่ไม่แตะเส้นทาง \(k\) \(\Delta_k \ne 1\)

ต่อยอดไปหน้าถัดไป

ได้ฟังก์ชันถ่ายโอนวงปิดแล้ว ขั้นต่อไปคือดูว่ามันตอบสนองอย่างไร เร็วแค่ไหน พุ่งเกินเท่าไร ไปที่ผลตอบสนองเวลาและสเปกการออกแบบ
