// บทที่ 13.6 · ระบบควบคุม · Stability

เสถียรภาพของระบบควบคุม: ขั้วบนระนาบ s

ระบบควบคุมที่ไม่เสถียรไม่ใช่แค่ทำงานไม่ดี แต่อันตราย: มอเตอร์หมุนเร่งจนพัง แขนกลสะบัด พาวเวอร์ซัพพลายแกว่งจนไหม้ เสถียรภาพจึงเป็นเงื่อนไขแรกที่ต้องผ่านก่อนสเปกอื่นทั้งหมด หน้านี้วางนิยามให้ชัด ผูกเข้ากับตำแหน่งขั้ว แล้วชี้ทางไปเครื่องมือแต่ละตัวที่จะใช้ตลอดส่วนที่ 3 ถึง 5 สูตรใช้รหัส S

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • ระบบเชิงเส้นเสถียร \(\iff\) ขั้วทุกตัวมี \(\operatorname{Re} \lt 0\)
  • ขั้วเดี่ยวบนแกน \(j\omega\): เสถียรวิกฤต (แกว่งค้าง) · ซ้ำบนแกน หรือ \(\operatorname{Re} \gt 0\): ไม่เสถียร
  • ขั้ววงปิดคือรากของ \(1 + L(s) = 0\) การป้อนกลับย้ายขั้วได้ทั้งไปทางดีและทางร้าย
  • ห้ามหักล้างขั้วฝั่งขวาด้วยศูนย์ของตัวควบคุม

นิยามเสถียรภาพ พื้นฐาน

S1 BIBO stability อินพุตมีขอบเขต เอาต์พุตมีขอบเขต

\[ |u(t)| \le M \Rightarrow |y(t)| \le N \ \ \forall t \quad \iff \quad \int_0^\infty |g(t)|\,dt \lt \infty \]

\(g(t)\) คือผลตอบสนองอิมพัลส์ · มุมมองจากภายนอก (อินพุต-เอาต์พุต)

S2 Pole-location criterion เกณฑ์ตำแหน่งขั้ว

\[ \begin{cases} \operatorname{Re}(p_i) \lt 0\ \ \forall i & \text{เสถียร (เชิงอาการและ BIBO)} \\ \text{ขั้วเดี่ยวบนแกน } j\omega,\ \text{ที่เหลือฝั่งซ้าย} & \text{เสถียรวิกฤต} \\ \operatorname{Re}(p_i) \gt 0 \ \text{หรือขั้วซ้ำบนแกน } j\omega & \text{ไม่เสถียร} \end{cases} \]

เหตุผล: ขั้ว \(p\) ให้พจน์ \(e^{pt}\) · ขั้วซ้ำบนแกนให้ \(t\cos\omega t\) ซึ่งโตตามเวลา · เสถียรภาพขึ้นกับขั้วเท่านั้น ไม่ขึ้นกับศูนย์

ตัวอย่าง S-1 · จำแนกเสถียรภาพ

จำแนก (ก) \(\frac{1}{(s+1)(s+2)}\) (ข) \(\frac{s - 3}{s^2 + 2s + 5}\) (ค) \(\frac{1}{s(s+1)}\) (ง) \(\frac{1}{(s^2 + 4)^2}\) (จ) \(\frac{1}{s^2 - s + 1}\)

  1. (ก) ขั้ว −1, −2 → เสถียร · (ข) ขั้ว \(-1 \pm j2\) → เสถียร (ศูนย์ฝั่งขวาไม่มีผลต่อเสถียรภาพ) S2

  2. (ค) ขั้ว 0 (เดี่ยว), −1 → เสถียรวิกฤต (อินพุตขั้นบันได เอาต์พุตเป็นแรมป์ ไม่ BIBO)

  3. (ง) ขั้ว \(\pm j2\) ซ้ำสองครั้ง → ไม่เสถียร · (จ) ขั้ว \(0.5 \pm j0.866\) → ไม่เสถียร

เสถียร: (ก) (ข) · เสถียรวิกฤต: (ค) · ไม่เสถียร: (ง) (จ)

การป้อนกลับ: ทำให้เสถียรก็ได้ ไม่เสถียรก็ได้ พื้นฐาน

S3 Closed-loop characteristic equation สมการลักษณะเฉพาะวงปิด

\[ 1 + K\frac{N(s)}{D(s)} = 0 \iff D(s) + KN(s) = 0 \]

ขั้ววงปิดต่างจากขั้ววงเปิด และเปลี่ยนตาม \(K\) · วงเปิดไม่เสถียรอาจเสถียรเมื่อปิดวง และกลับกัน

ตัวอย่าง S-2 · ป้อนกลับช่วยและป้อนกลับทำร้าย

(ก) พลานต์ไม่เสถียร \(\frac{1}{s - 1}\) กับตัวควบคุม \(K\) · (ข) พลานต์เสถียร \(\frac{1}{(s+1)^3}\) กับ \(K\)

  1. (ก) \(s - 1 + K = 0 \Rightarrow s = 1 - K\) เสถียรเมื่อ \(K \gt 1\) การป้อนกลับทำให้เสถียร

  2. (ข) \((s + 1)^3 + K = 0\) เสถียรเมื่อ \(K \lt 8\) (เราท์) การป้อนกลับที่แรงเกินทำให้ไม่เสถียร แม้พลานต์จะเสถียร

ไม่มีการป้อนกลับที่ “ปลอดภัยเสมอ” ต้องตรวจทุกครั้ง · ทุกพลานต์ที่มี \(n - m \ge 3\) จะไม่เสถียรเมื่อเกนสูงพอ (เส้นกำกับ ±60° ข้ามไปฝั่งขวา)

เสถียรภาพภายในและกับดักการหักล้างขั้ว กลาง

S4 Internal stability เสถียรภาพภายใน

\[ \text{ต้องเสถียรทั้ง 4 ฟังก์ชัน:}\quad \frac{1}{1 + CG},\quad \frac{G}{1 + CG},\quad \frac{C}{1 + CG},\quad \frac{CG}{1 + CG} \]

ถ้า \(C\) มีศูนย์หักล้างขั้วฝั่งขวาของ \(G\) (หรือกลับกัน) \(T = \frac{CG}{1 + CG}\) อาจดูเสถียร แต่ \(\frac{G}{1 + CG}\) (ผลของการรบกวน) ไม่เสถียร

ตัวอย่าง S-3 · หักล้างแล้วพัง

พลานต์ \(G = \frac{1}{s - 1}\) ตัวควบคุม \(C = \frac{s - 1}{s(s + 2)}\) ดูเหมือน \(L = \frac{1}{s(s+2)}\) ระบบเสถียรจริงไหม

  1. \(T = \dfrac{L}{1 + L} = \dfrac{1}{s^2 + 2s + 1}\) ขั้ว −1, −1 ดูเสถียร

  2. จากการรบกวนที่อินพุตพลานต์ไปเอาต์พุต: \(\dfrac{G}{1 + CG} = \dfrac{s(s + 2)}{(s - 1)(s^2 + 2s + 1)}\) มีขั้วที่ \(+1\) S4

ไม่มีเสถียรภาพภายใน การรบกวนเพียงเล็กน้อยทำให้เอาต์พุตโตแบบ \(e^t\) แม้ค่าอ้างอิงจะตอบสนองดี บทเรียน: ขั้วฝั่งขวาต้องถูกย้ายด้วยการป้อนกลับ ไม่ใช่ซ่อนด้วยศูนย์
