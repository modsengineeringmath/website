แบบจำลองทางคณิตศาสตร์: วงจรไฟฟ้า มอเตอร์ กลไก ความร้อน

ตัวควบคุมจะดีได้เท่ากับแบบจำลองที่ใช้ออกแบบ หน้านี้เปลี่ยนกฎฟิสิกส์ (KVL, KCL, นิวตัน, สมดุลพลังงาน) ให้เป็นฟังก์ชันถ่ายโอน เริ่มจากวงจรไฟฟ้าที่นักศึกษาไฟฟ้าถนัดที่สุด แล้วใช้ความคล้ายเชิงอุปมาข้ามไปกลไก ความร้อน และของไหล จนถึงมอเตอร์ DC ซึ่งเป็นหัวใจของเมคาทรอนิกส์และหุ่นยนต์ สูตรใช้รหัส M

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • ฟังก์ชันถ่ายโอน = \(Y(s)/U(s)\) ที่เงื่อนไขเริ่มต้นเป็นศูนย์ · วงจรใช้อิมพีแดนซ์ \(R,\ sL,\ 1/(sC)\) แล้ววิเคราะห์เหมือน DC
  • RLC อนุกรม: \(\omega_n = 1/\sqrt{LC}\), \(\zeta = \frac R2\sqrt{C/L}\) · มอเตอร์ DC (ความเร็ว): \(\frac{K}{\tau s + 1}\) · (ตำแหน่ง): \(\frac{K}{s(\tau s + 1)}\)
  • มวล ↔ ตัวเหนี่ยวนำ, สปริง ↔ ตัวเก็บประจุ, แดมเปอร์ ↔ ตัวต้านทาน
  • ระบบไม่เชิงเส้น: ทำให้เป็นเชิงเส้นรอบจุดทำงานด้วยอนุกรมเทย์เลอร์

ฟังก์ชันถ่ายโอนและวิธีอิมพีแดนซ์ พื้นฐาน

M1 Transfer function ฟังก์ชันถ่ายโอน

\[ a_n y^{(n)} + \cdots + a_1\dot y + a_0y = b_mu^{(m)} + \cdots + b_0u \ \xrightarrow{\ \mathcal L,\ \text{IC} = 0\ }\ G(s) = \frac{Y(s)}{U(s)} = \frac{b_ms^m + \cdots + b_0}{a_ns^n + \cdots + a_0} \]

รากตัวส่วน = ขั้ว (poles) · รากตัวเศษ = ศูนย์ (zeros) · \(n\) = อันดับของระบบ · ระบบจริงเกือบทั้งหมด proper (\(m \le n\))

M2 Impedance method วิธีอิมพีแดนซ์ในโดเมน s

\[ Z_R = R, \quad Z_L = sL, \quad Z_C = \frac{1}{sC}, \qquad \frac{V_o}{V_i} = \frac{Z_2}{Z_1 + Z_2} \ \text{(ตัวแบ่งแรงดัน)} \]

ใช้ KVL KCL โนด เมช เหมือนวงจร DC ทุกประการ (ดูประยุกต์พีชคณิตเชิงเส้นกับวงจร) · ไม่ต้องเขียนสมการเชิงอนุพันธ์

วงจรไฟฟ้า พื้นฐาน

M3 RC low-pass วงจร RC

\[ \frac{V_C}{V_i} = \frac{1/(sC)}{R + 1/(sC)} = \frac{1}{RCs + 1} \]

ระบบอันดับหนึ่ง \(\tau = RC\) ขั้วที่ \(-1/RC\) · ดูแล็บระบบอันดับหนึ่ง

M4 Series RLC วงจร RLC อนุกรม (เอาต์พุตที่ C)

\[ \frac{V_C}{V_i} = \frac{1}{LCs^2 + RCs + 1}, \quad \omega_n = \frac{1}{\sqrt{LC}}, \quad \zeta = \frac R2\sqrt{\frac CL} \]

ดูแล็บระบบอันดับสอง · LC ฟิลเตอร์ของบั๊กคอนเวอร์เตอร์คือวงจรนี้

M5 Inverting op-amp ออปแอมป์อินเวอร์ติง

\[ \frac{V_o}{V_i} = -\frac{Z_f(s)}{Z_i(s)} \qquad \text{เช่น } Z_f = \frac{1}{sC},\ Z_i = R:\ -\frac{1}{RCs} \ (\text{อินทิเกรเตอร์}) \]

เครื่องมือสร้างตัวควบคุมแบบแอนะล็อก: PID, lead/lag · ดูแล็บออปแอมป์

ตัวอย่าง M-1 · RLC จริง

วงจร RLC อนุกรม \(R = 10\ \Omega,\ L = 10\ \text{mH},\ C = 100\ \mu\text{F}\) หาฟังก์ชันถ่ายโอนไปที่แรงดันตัวเก็บประจุ \(\omega_n\) และ \(\zeta\)

  1. \(LC = 10^{-2} \times 10^{-4} = 10^{-6}\), \(RC = 10^{-3}\) M4

    \[ G(s) = \frac{1}{10^{-6}s^2 + 10^{-3}s + 1} = \frac{10^6}{s^2 + 1000s + 10^6} \]

  2. \(\omega_n = 1/\sqrt{10^{-6}} = 1000\) rad/s (159 Hz) · \(\zeta = 5\sqrt{10^{-4}/10^{-2}} = 0.5\)

\(\omega_n = 1000\) rad/s, \(\zeta = 0.5\): ตอบสนองขั้นบันไดพุ่งเกิน 16.3% ที่เวลา \(t_p = \pi/(1000\sqrt{0.75}) = 3.6\) ms

มอเตอร์ไฟฟ้ากระแสตรง: หัวใจของเมคาทรอนิกส์ กลาง

มอเตอร์ DC ที่ควบคุมด้วยแรงดันอาร์เมเจอร์ \(v\) มีสองโลกเชื่อมกัน: วงจรไฟฟ้า (\(R, L\), แรงเคลื่อนไฟฟ้าต้าน \(K_e\omega\)) และกลไก (\(J, b\), แรงบิด \(K_ti\)) ในหน่วย SI \(K_t = K_e = K\)

M6 DC motor equations สมการมอเตอร์ DC

\[ v = Ri + L\frac{di}{dt} + K_e\omega, \qquad J\frac{d\omega}{dt} + b\omega = K_ti - T_L \ \Rightarrow\ \frac{\Omega(s)}{V(s)} = \frac{K_t}{(Js + b)(Ls + R) + K_tK_e} \]

\(T_L\) = แรงบิดโหลด (การรบกวน) · ตำแหน่ง \(\theta = \omega/s\) จึงมีอินทิเกรเตอร์เพิ่มหนึ่งตัว

M7 Simplified motor model แบบจำลองอย่างง่าย (\(L/R \ll \tau_m\))

\[ \frac{\Omega}{V} \approx \frac{K_m}{\tau_ms + 1}, \qquad \frac{\Theta}{V} \approx \frac{K_m}{s(\tau_ms + 1)}, \qquad K_m = \frac{K_t}{Rb + K_tK_e}, \quad \tau_m = \frac{RJ}{Rb + K_tK_e} \]

นี่คือพลานต์ \(\frac{K}{s(s+a)}\) ที่เห็นในรูทโลคัสและ PD ทั้งชุด · ใส่เกียร์ \(N\): ความเฉื่อยโหลดสะท้อนมาเป็น \(J_L/N^2\) M10

ตัวอย่าง M-2 · มอเตอร์ DC ขนาดเล็ก

มอเตอร์มี \(R = 2\ \Omega,\ L = 1\ \text{mH},\ J = 10^{-5}\ \text{kg\,m}^2,\ b = 10^{-6}\ \text{N\,m\,s},\ K_t = K_e = 0.02\) หาแบบจำลองความเร็ว

  1. แบบเต็ม M6: \((10^{-5}s + 10^{-6})(10^{-3}s + 2) + 4\times10^{-4} = 10^{-8}s^2 + 2.0\times10^{-5}s + 4.02\times10^{-4}\)

    ขั้วที่ \(-20.3\) (กลไก) และ \(-1980\) (ไฟฟ้า) ห่างกันเกือบ 100 เท่า

  2. แบบย่อ M7: \(Rb + K^2 = 2\times10^{-6} + 4\times10^{-4} = 4.02\times10^{-4}\)

    \[ K_m = \frac{0.02}{4.02\times10^{-4}} = 49.8\ \tfrac{\text{rad/s}}{\text{V}}, \quad \tau_m = \frac{2\times10^{-5}}{4.02\times10^{-4}} = 0.0498\ \text{s} \]

\(\dfrac{\Omega}{V} \approx \dfrac{49.8}{0.0498s + 1}\) (ประมาณ 475 rpm ต่อโวลต์ ถึง 63% ของความเร็วสุดท้ายใน 50 ms) · ขั้วไฟฟ้าที่ −1980 ตัดทิ้งได้สำหรับลูปความเร็ว แต่ต้องใช้เมื่อออกแบบลูปกระแส

กลไก ความร้อน ของไหล และความคล้ายเชิงอุปมา พื้นฐาน

M8 Mass–spring–damper มวล-สปริง-ดัมเปอร์

\[ m\ddot x + b\dot x + kx = f \ \Rightarrow\ \frac{X}{F} = \frac{1}{ms^2 + bs + k} \]

\(\omega_n = \sqrt{k/m}\), \(\zeta = \frac{b}{2\sqrt{km}}\) · ระบบหมุน: \(J\ddot\theta + b\dot\theta + k\theta = T\)

M9 Thermal system ระบบความร้อน

\[ C_t\frac{d\theta}{dt} = q - \frac{\theta}{R_t} \ \Rightarrow\ \frac{\Theta}{Q} = \frac{R_t}{R_tC_ts + 1} \]

\(\theta\) = อุณหภูมิเหนือแวดล้อม · \(C_t\) (J/K) \(R_t\) (K/W) · วงจร RC เป๊ะ · ระดับน้ำในถัง: \(A\dot h = q_{in} - h/R\) รูปเดียวกัน

M10 Gear train ชุดเกียร์ทด \(N\) (มอเตอร์หมุนเร็วกว่า \(N\) เท่า)

\[ \omega_L = \frac{\omega_m}{N}, \quad T_L = NT_m, \quad J_{eq} = J_m + \frac{J_L}{N^2}, \quad b_{eq} = b_m + \frac{b_L}{N^2} \]

เกียร์ทดสูงทำให้โหลดหนัก ๆ “ดูเบา” สำหรับมอเตอร์ เหตุผลที่หุ่นยนต์ใช้ harmonic drive

M11 Force–voltage analogy ความคล้ายแรง-แรงดัน

\[ \begin{array}{c|c|c|c|c|c} \text{ไฟฟ้า} & v & i & L & R & \tfrac1C \\ \hline \text{กลไกเลื่อนที่} & f & \dot x & m & b & k \\ \text{กลไกหมุน} & T & \omega & J & b & k \\ \text{ความร้อน} & \theta & q & - & R_t & \tfrac{1}{C_t} \end{array} \]

\(L\frac{di}{dt} + Ri + \frac1C\int i\,dt = v\) ↔ \(m\ddot x + b\dot x + kx = f\) · ทุกอย่างที่รู้เรื่องวงจร RLC ใช้กับกลไกได้ทันที

ตัวอย่าง M-3 · เตาอบ

เตาอบมีความจุความร้อน \(C_t = 500\) J/K ความต้านทานความร้อนต่อห้อง \(R_t = 0.2\) K/W ฮีตเตอร์ 1 kW จะร้อนขึ้นเท่าไร และใช้เวลานานเท่าไร

  1. M9: \(G(s) = \dfrac{0.2}{100s + 1}\) (K/W) · \(\tau = 0.2 \times 500 = 100\) s

  2. สุดท้าย: \(0.2 \times 1000 = 200\) K เหนือห้อง · ถึง 98% ใน \(4\tau = 400\) s

ร้อนขึ้น 200 °C ใช้เวลาเกือบ 7 นาที · เตาจริงมีหน่วงเวลาจากตำแหน่งเซนเซอร์ด้วย จึงนิยมประมาณเป็น \(\frac{Ke^{-Ls}}{Ts + 1}\) ในการจูน PID

ทำให้เป็นเชิงเส้น: ลูกตุ้มกลับหัว กลาง

M12 Linearization การทำให้เป็นเชิงเส้นรอบจุดทำงาน

\[ \dot x = f(x, u) \ \Rightarrow\ \delta\dot x \approx \left.\frac{\partial f}{\partial x}\right|_{0}\delta x + \left.\frac{\partial f}{\partial u}\right|_{0}\delta u \]

ใช้ได้รอบจุดสมดุล \((x_0, u_0)\) ที่ \(f(x_0, u_0) = 0\) · หลักเดียวกับ “แบบจำลองสัญญาณเล็ก” ของทรานซิสเตอร์และตัวแปลงกำลัง

ตัวอย่าง M-4 · ลูกตุ้มกลับหัว

ลูกตุ้มยาว \(l = 0.5\) m ตั้งตรงบนข้อต่อที่มีมอเตอร์ \(ml^2\ddot\theta = mgl\sin\theta + \tau\) หาแบบจำลองเชิงเส้นรอบ \(\theta = 0\) (ตั้งตรง)

  1. รอบ \(\theta = 0\): \(\sin\theta \approx \theta\) M12 ได้ \(\ddot\theta = \frac gl\theta + \frac{\tau}{ml^2}\)

  2. \(\dfrac{\Theta}{T} = \dfrac{1/(ml^2)}{s^2 - g/l}\) ขั้วที่ \(s = \pm\sqrt{g/l} = \pm\sqrt{19.62} = \pm4.43\)

มีขั้วฝั่งขวาที่ \(+4.43\): ล้มเองด้วยค่าคงเวลา ~0.23 s ต้องใช้การป้อนกลับที่เร็วกว่านั้นมาก (ดู R-6 ในเราท์ และหุ่นยนต์ทรงตัวในโรโบติกส์) · ไม้ยาวทรงตัวบนมือง่ายกว่าไม้สั้น เพราะ \(\sqrt{g/l}\) เล็กกว่า

ต่อยอดไปหน้าถัดไป

ระบบจริงประกอบจากหลายบล็อก (ตัวขับ พลานต์ เซนเซอร์ ตัวควบคุม) ไปต่อที่บล็อกไดอะแกรมเพื่อรวมทั้งหมดเป็นฟังก์ชันเดียว ส่วนแบบจำลองหลายตัวแปรในรูปเมทริกซ์อยู่ที่ปริภูมิสถานะ
