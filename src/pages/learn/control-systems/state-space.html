ปริภูมิสถานะ (State-Space): สมการสถานะ รูปแบบมาตรฐาน และ e^{At}

ปี 1960 รูดอล์ฟ คาลมาน (Rudolf Kalman) เปลี่ยนมุมมองระบบควบคุมจาก “อินพุต-เอาต์พุต” เป็น “สถานะภายใน” เขียนระบบอันดับ \(n\) ใด ๆ เป็นสมการเชิงอนุพันธ์อันดับหนึ่ง \(n\) สมการในรูปเมทริกซ์ ทำให้พีชคณิตเชิงเส้นทั้งหมดใช้ได้ทันที: ค่าเฉพาะคือขั้ว \(e^{At}\) คือคำตอบ และระบบหลายอินพุตหลายเอาต์พุตไม่ยากกว่าระบบเดียว นี่คือประตูสู่ modern control ที่ใช้ในหุ่นยนต์ โดรน และยานอวกาศ สูตรใช้รหัส X

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • \(\dot{\mathbf x} = A\mathbf x + B\mathbf u,\ \ \mathbf y = C\mathbf x + D\mathbf u\) · สถานะ = ตัวเก็บพลังงาน (\(i_L,\ v_C\), ตำแหน่ง, ความเร็ว)
  • \(G(s) = C(sI - A)^{-1}B + D\) · ขั้ว = ค่าเฉพาะของ \(A\)
  • \(\mathbf x(t) = e^{At}\mathbf x(0) + \int_0^te^{A(t-\tau)}B\mathbf u(\tau)\,d\tau\) · \(e^{At} = \mathcal L^{-1}\{(sI - A)^{-1}\}\)
  • ฟังก์ชันเดียวมีได้หลายแบบจำลอง (รูปแบบควบคุมได้ สังเกตได้ โมดัล) เชื่อมกันด้วย \(T\)

แบบจำลองปริภูมิสถานะ กลาง

X1 State-space model แบบจำลองปริภูมิสถานะ

\[ \dot{\mathbf x}(t) = A\mathbf x(t) + B\mathbf u(t), \qquad \mathbf y(t) = C\mathbf x(t) + D\mathbf u(t) \]

\(\mathbf x \in \mathbb R^n\) สถานะ · \(\mathbf u \in \mathbb R^m\) อินพุต · \(\mathbf y \in \mathbb R^p\) เอาต์พุต · \(A_{n\times n}\) (พลวัต) \(B_{n\times m}\) \(C_{p\times n}\) \(D_{p\times m}\) (มักเป็นศูนย์)

X2 Controllable canonical form รูปแบบมาตรฐานควบคุมได้

\[ G(s) = \frac{b_{n-1}s^{n-1} + \cdots + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_0}:\quad A = \begin{pmatrix} 0 & 1 & & \\ & \ddots & \ddots & \\ & & 0 & 1 \\ -a_0 & -a_1 & \cdots & -a_{n-1} \end{pmatrix},\ B = \begin{pmatrix} 0 \\ \vdots \\ 0 \\ 1 \end{pmatrix},\ C = (b_0\ \ b_1\ \cdots\ b_{n-1}) \]

เขียนได้ทันทีจากสัมประสิทธิ์ · ใช้ในการวางขั้ว (ป้อนกลับสถานะ) · รูปแบบสังเกตได้ (observable) คือทรานสโพส: \(A^T, C^T, B^T\)

ตัวอย่าง X-1 · วงจร RLC

เขียนแบบจำลองปริภูมิสถานะของวงจร RLC อนุกรม \(R = 10\ \Omega,\ L = 10\) mH, \(C = 100\ \mu\)F เอาต์พุตคือ \(v_C\)

  1. สถานะ \(x_1 = i_L,\ x_2 = v_C\) · KVL: \(L\dot i = v_{in} - Ri - v_C\) · ตัวเก็บประจุ: \(C\dot v_C = i\)

  2. เขียนเป็นเมทริกซ์ X1

    \[ \begin{pmatrix} \dot i \\ \dot v_C \end{pmatrix} = \begin{pmatrix} -R/L & -1/L \\ 1/C & 0 \end{pmatrix}\begin{pmatrix} i \\ v_C \end{pmatrix} + \begin{pmatrix} 1/L \\ 0 \end{pmatrix}v_{in} = \begin{pmatrix} -1000 & -100 \\ 10^4 & 0 \end{pmatrix}\mathbf x + \begin{pmatrix} 100 \\ 0 \end{pmatrix}v_{in} \]

    \(y = v_C = (0\ \ 1)\,\mathbf x\)

ค่าเฉพาะของ \(A\): \(\lambda^2 + 1000\lambda + 10^6 = 0\) ตรงกับตัวส่วนของตัวอย่าง M-1 ✓ (\(\omega_n = 1000,\ \zeta = 0.5\))

python-control ss2tf: \(\dfrac{10^6}{s^2 + 1000s + 10^6}\) ✓ · ดูวงจรอื่นในประยุกต์พีชคณิตเชิงเส้น

จากปริภูมิสถานะสู่ฟังก์ชันถ่ายโอน กลาง

X3 Transfer function ฟังก์ชันถ่ายโอน

\[ G(s) = C(sI - A)^{-1}B + D = \frac{C\,\operatorname{adj}(sI - A)\,B}{\det(sI - A)} + D \]

ใช้อินเวอร์สแบบแอดจอยต์ (อินเวอร์ส) · ตัวส่วน \(\det(sI - A)\) = พหุนามลักษณะเฉพาะ

X4 Poles = eigenvalues ขั้ว = ค่าเฉพาะของ A

\[ \det(sI - A) = 0 \]

เสถียร \(\iff\) \(\operatorname{Re}\lambda_i(A) \lt 0\) ทุกตัว (ค่าเฉพาะ)

X5 Similarity transformation เปลี่ยนตัวแปรสถานะ

\[ \mathbf x = T\mathbf z:\ \ \hat A = T^{-1}AT,\ \hat B = T^{-1}B,\ \hat C = CT \]

ค่าเฉพาะและฟังก์ชันถ่ายโอนไม่เปลี่ยน · \(T\) = เวกเตอร์เฉพาะ ได้รูปแบบโมดัล (ทแยงมุม)

ตัวอย่าง X-2 · ไปและกลับ

เขียน \(G(s) = \dfrac{s + 3}{s^2 + 3s + 2}\) ในรูปแบบควบคุมได้ แล้วตรวจกลับด้วย X3

  1. X2: \(a_0 = 2,\ a_1 = 3,\ b_0 = 3,\ b_1 = 1\)

    \[ A = \begin{pmatrix} 0 & 1 \\ -2 & -3 \end{pmatrix},\quad B = \begin{pmatrix} 0 \\ 1 \end{pmatrix},\quad C = (3\ \ 1) \]

  2. X3: \((sI - A)^{-1} = \dfrac{1}{s^2 + 3s + 2}\begin{pmatrix} s + 3 & 1 \\ -2 & s \end{pmatrix}\) ได้ \((sI - A)^{-1}B = \dfrac{1}{s^2 + 3s + 2}\begin{pmatrix} 1 \\ s \end{pmatrix}\)

    \[ C(sI - A)^{-1}B = \frac{3 + s}{s^2 + 3s + 2} \ \checkmark \]

คำตอบของสมการสถานะ: e^{At} ขั้นสูง

X6 State solution คำตอบของสมการสถานะ

\[ \mathbf x(t) = \underbrace{e^{At}\mathbf x(0)}_{\text{ผลตอบสนองอิสระ}} + \underbrace{\int_0^te^{A(t - \tau)}B\mathbf u(\tau)\,d\tau}_{\text{ผลตอบสนองบังคับ}}, \qquad e^{At} = \mathcal L^{-1}\big\{(sI - A)^{-1}\big\} = Pe^{\Lambda t}P^{-1} \]

\(e^{At}\) เรียกว่าเมทริกซ์ทรานซิชันสถานะ \(\Phi(t)\) · คำนวณได้ทั้งด้วยลาปลาซและด้วยการทำเป็นทแยงมุม (ค่าเฉพาะ) · คือแกนของการแปลงเป็นดิจิทัลแบบ ZOH \(A_d = e^{AT}\)

ตัวอย่าง X-3 · หา e^{At}

หา \(e^{At}\) ของ \(A = \begin{pmatrix} 0 & 1 \\ -2 & -3 \end{pmatrix}\)

  1. \((sI - A)^{-1} = \dfrac{1}{(s+1)(s+2)}\begin{pmatrix} s + 3 & 1 \\ -2 & s \end{pmatrix}\)

  2. เศษส่วนย่อยทีละช่อง เช่น \(\dfrac{s+3}{(s+1)(s+2)} = \dfrac{2}{s+1} - \dfrac{1}{s+2}\)

\(e^{At} = \begin{pmatrix} 2e^{-t} - e^{-2t} & e^{-t} - e^{-2t} \\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t} \end{pmatrix}\)

ตรวจ \(t = 0\): ได้ \(I\) ✓ · เทียบ scipy expm ที่ \(t = 0.5\): ทุกช่องตรง ✓

รูปแบบมาตรฐานต่าง ๆ ใช้ทำอะไร ขั้นสูง

รูปแบบลักษณะใช้เมื่อ
ฟิสิกส์ (physical)สถานะมีความหมายจริง (\(i_L\), \(v_C\), ตำแหน่ง)วัดได้ ออกแบบตัวสังเกต จำกัดสถานะ
ควบคุมได้ (controllable)แถวล่างคือสัมประสิทธิ์ตัวส่วนวางขั้ว (เทียบสัมประสิทธิ์ตรง ๆ)
สังเกตได้ (observable)ทรานสโพสของแบบควบคุมได้ออกแบบตัวสังเกต
โมดัล / จอร์แดน\(A\) ทแยงมุม (หรือบล็อก)แยกโหมดอิสระ วิเคราะห์การสั่นของโครงสร้าง

ต่อยอดไปหน้าถัดไป

มีแบบจำลองแล้ว คำถามคือ “ขับสถานะไปที่ไหนก็ได้หรือไม่” และ “ดูสถานะทั้งหมดจากเอาต์พุตได้หรือไม่” ไปที่ความสามารถควบคุมได้และสังเกตได้
