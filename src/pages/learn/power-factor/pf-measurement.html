// บทที่ 19.7 · เพาเวอร์แฟกเตอร์ · Measuring Power Factor

วัดเพาเวอร์แฟกเตอร์: แคลมป์มิเตอร์ เพาเวอร์อนาไลเซอร์ วิธีวัตต์มิเตอร์สองตัว และการอ่านมิเตอร์ของการไฟฟ้า

การออกแบบตู้คาปาซิเตอร์ที่ดีเริ่มจากตัวเลขที่วัดถูก ไม่ใช่ค่าที่คาดเดา หน้านี้อธิบายเครื่องมือที่ใช้จริงหน้างาน วิธีต่อให้ถูกทิศ ความผิดพลาดที่พบบ่อย และวิธีคลาสสิกที่ยังออกสอบเสมอ: วัตต์มิเตอร์สองตัว

เขียนโดย อาจารย์มดอัปเดต
เครื่องมือ วัตต์มิเตอร์สองตัว ความผิดพลาดที่พบบ่อย บันทึกโหลด
สรุปใน 30 วินาที
  • วัด P ต้องวัดแรงดันและกระแสพร้อมกัน — แคลมป์มิเตอร์วัดกระแสอย่างเดียวบอก PF ไม่ได้
  • 3 สาย: \(P = W_1 + W_2\) · โหลดสมดุล \(\tan\varphi = \sqrt3(W_1 - W_2)/(W_1 + W_2)\)
  • ลูกศร CT ชี้ไปทางโหลด และ CT ต้องอยู่เฟสเดียวกับสายแรงดันที่จับคู่
  • ออกแบบตู้จากการบันทึกอย่างน้อย 7 วัน ไม่ใช่ค่าที่อ่านครั้งเดียว

เครื่องมือวัด พื้นฐาน

เครื่องมือวัดได้ข้อจำกัด
แคลมป์มิเตอร์ธรรมดากระแส rmsไม่รู้มุม → ไม่รู้ P หรือ PF
แคลมป์มิเตอร์วัดกำลัง (power clamp)V I P Q S PF 1 เฟส / 3 เฟสสมดุล3 เฟสไม่สมดุลต้องวัดทีละเฟส บางรุ่นแสดงแค่ DPF
เพาเวอร์อนาไลเซอร์ / เครื่องบันทึก (logger)ทุกค่าทุกเฟส ฮาร์มอนิก บันทึกต่อเนื่องราคาสูง ต้องตั้งค่า CT และระบบไฟให้ถูก
มิเตอร์ดิจิทัลในตู้ (multifunction meter)ค่าทันทีและสะสม kWh kvarhขึ้นกับการต่อ CT ตอนติดตั้ง
มิเตอร์ของการไฟฟ้าkWh kvarh kW สูงสุด kvar สูงสุดอ่านรายเดือน — ดูในบิลหรือขอข้อมูลโหลดโปรไฟล์

M1 What a wattmeter measures สิ่งที่วัตต์มิเตอร์วัด

\[ W = \frac1T\int_0^T v(t)\,i(t)\,dt = V I\cos(\angle V - \angle I)\ \ (\text{ไซน์}) \]

M2 PF from measurements PF จากค่าที่วัดได้

\[ PF = \frac{P}{V_{rms}\,I_{rms}} \quad (1\varphi) \qquad PF_{3\varphi} = \frac{P_a + P_b + P_c}{S_a + S_b + S_c}\ \ (\text{แบบเลขคณิต}) \]

เครื่องวัดดิจิทัลสุ่ม v และ i พร้อมกันหลายพันครั้งต่อวินาที แล้วคำนวณ M1 ด้วยผลรวมเชิงตัวเลข จึงได้ PF จริงที่รวมฮาร์มอนิก ส่วนค่า “cos φ” หรือ DPF ได้จากการแยกความถี่พื้นฐานด้วย DFT ถ้าสองค่านี้ต่างกันมาก แปลว่ามีฮาร์มอนิกสูง (H2)

วิธีวัตต์มิเตอร์สองตัว (Two-wattmeter method) กลาง

ต่อขดกระแสของ W₁ ที่สาย a ขดแรงดันคร่อม a–c และ W₂ ที่สาย b ขดแรงดันคร่อม b–c (สาย c เป็นจุดอ้างอิงร่วม) ทฤษฎีบทของ Blondel บอกว่าระบบ n สายใช้วัตต์มิเตอร์ n − 1 ตัวก็วัดกำลังรวมได้

M3 Total power กำลังรวม (ใช้ได้เสมอในระบบ 3 สาย)

\[ P = W_1 + W_2 \qquad W_1 = V_L I_L\cos(30^\circ - \varphi),\ \ W_2 = V_L I_L\cos(30^\circ + \varphi) \]

M4 Reactive power (balanced) กำลังรีแอกทีฟ (โหลดสมดุล)

\[ Q = \sqrt3\,(W_1 - W_2) \]

M5 Power factor (balanced) เพาเวอร์แฟกเตอร์ (โหลดสมดุล)

\[ \tan\varphi = \frac{\sqrt3\,(W_1 - W_2)}{W_1 + W_2} \qquad PF = \cos\!\left[\tan^{-1}\frac{\sqrt3\,(W_1 - W_2)}{W_1 + W_2}\right] \]
สิ่งที่อ่านได้ความหมาย
\(W_1 = W_2\)PF = 1 (φ = 0°)
\(W_2 = 0\)PF = 0.5 (φ = 60°)
\(W_2 < 0\) (เข็มตีกลับ)PF < 0.5 — กลับขั้วขดแรงดันแล้วอ่านเป็นลบ
\(W_1 = -W_2\)PF = 0 (โหลดรีแอกทีฟล้วน)
ตัวอย่าง M-1

W₁ = 30 kW, W₂ = 12 kW

  1. M3: \(P = 42\) kW · M4: \(Q = \sqrt3(18) = 31.2\) kvar

  2. M5: \(\tan\varphi = 31.2/42 = 0.742\) → \(\varphi = 36.6^\circ\) → PF = 0.803

  3. ตรวจด้วย M3: \(V_LI_L = S/\sqrt3 = 52.3/1.732 = 30.2\) kVA → \(W_1 = 30.2\cos(30 - 36.6)^\circ = 30.0\) ✓ \(W_2 = 30.2\cos 66.6^\circ = 12.0\) ✓

PF เฉลี่ยจากมิเตอร์ kWh และ kvarh พื้นฐาน

M6 Average power factor PF เฉลี่ยจากพลังงาน

\[ \overline{PF} = \frac{E_{kWh}}{\sqrt{E_{kWh}^2 + E_{kvarh}^2}} \]

ระวัง: PF เฉลี่ยรายเดือนอาจดูดี (เช่น 0.9) แต่ค่าปรับคิดจาก kvar สูงสุด ช่วงที่มอเตอร์เบาโหลดหรือกะกลางคืนที่มีแต่ไฟส่องสว่างบัลลาสต์อาจมี PF ต่ำมาก ต้องดูข้อมูลรายช่วง 15 นาที

ความผิดพลาดในการวัดที่พบบ่อย กลาง

อาการบนเครื่องวัดสาเหตุแก้
P ติดลบCT/แคลมป์กลับทิศหันลูกศรไปทางโหลด หรือกลับ k-l
PF ต่ำผิดปกติ (เช่น 0.2) ทั้งที่โหลดเป็นฮีตเตอร์CT ไม่ตรงเฟสกับสายแรงดัน (เลื่อน 120°)ไล่จับคู่ L1-CT1, L2-CT2, L3-CT3
เฟสหนึ่ง PF นำหน้า อีกสองเฟสตามหลังผิดปกติลำดับเฟสสลับตรวจ phase rotation
กำลังเพี้ยน 1/1000 หรือ 1000 เท่าตั้งอัตราส่วน CT/VT ในเครื่องผิดตั้งค่า CT ratio ให้ตรง
PF แกว่งมากโหลดเปลี่ยนเร็ว (เครื่องเชื่อม ลิฟต์ เครื่องปั๊ม)บันทึกค่าเฉลี่ย 1 วินาที–1 นาที แทนค่าทันที

บันทึกโหลดก่อนออกแบบตู้คาปาซิเตอร์ กลาง

  1. บันทึกที่ตู้ MDB อย่างน้อย 7 วัน รวมวันทำงานและวันหยุด ช่วงเวลา 1–15 นาที
  2. เก็บ P Q S PF DPF แรงดัน THD-U THD-I และสเปกตรัมฮาร์มอนิก
  3. หา Q สูงสุดที่ต้องชดเชย (T4) และ Q ต่ำสุด (กำหนดขั้นเล็กสุด ไม่ให้ชดเชยเกินตอนโหลดเบา)
  4. ถ้า THD-I > 10–15 % หรือมี VFD มาก พิจารณาตู้ detuned
  5. เปรียบเทียบกับบิล 12 เดือน (kW kvar สูงสุดรายเดือน)
  6. หลังติดตั้ง วัดซ้ำเพื่อยืนยัน PF และตรวจว่าไม่มีเรโซแนนซ์ (THD-U ไม่เพิ่ม)
