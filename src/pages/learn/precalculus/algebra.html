// บทที่ 27.1 · พรีแคลคูลัส · Algebra Review

พีชคณิตสำหรับพรีแคลคูลัส: เลขยกกำลัง กรณฑ์ การแยกตัวประกอบ สมการและอสมการกำลังสอง และค่าสัมบูรณ์

นักเรียนที่ทำโจทย์ฟังก์ชันหรือลิมิตแล้วติด ส่วนใหญ่ไม่ได้ติดที่แนวคิดใหม่ แต่ติดตรงที่ต้องจัดรูปพีชคณิตให้ได้ก่อนจะคิดต่อ เช่น แยกตัวประกอบไม่ออก ลืมว่า \(\sqrt{x^2}\) เท่ากับ \(|x|\) หรือคูณตัวส่วนในอสมการแล้วเครื่องหมายกลับโดยไม่รู้ตัว หน้านี้รวบรวมเครื่องมือพีชคณิตที่จะถูกเรียกใช้ซ้ำในทุกหน้าของบทพรีแคลคูลัส โดยเรียงจากกฎเลขยกกำลัง กรณฑ์ การแยกตัวประกอบ ไปจนถึงสมการ-อสมการกำลังสองและค่าสัมบูรณ์ แต่ละหัวข้ออธิบายว่าทำไมสูตรเป็นแบบนั้น ไม่ได้ให้จำอย่างเดียว

  • \(a^2 - b^2 = (a - b)(a + b)\) · \(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
  • \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\) · \(D > 0\) สองราก · \(D = 0\) รากซ้ำ · \(D < 0\) ไม่มีรากจริง
  • อสมการ: ย้ายมาข้างเดียวให้อีกข้างเป็นศูนย์ แล้วใช้เส้นจำนวน ห้ามคูณตัวที่ไม่รู้เครื่องหมาย
  • \(|x| < a \iff -a < x < a\) · \(|x| > a \iff x < -a\) หรือ \(x > a\)

เลขยกกำลังและกรณฑ์ (Exponents & Radicals)

เลขยกกำลังจำนวนเต็มบวกคือการคูณซ้ำ เช่น \(2^5\) คือ 2 คูณกันห้าตัว กฎทุกข้อในกรอบด้านล่างจึงมาจากการนับจำนวนตัวคูณ เช่น \(a^3 \cdot a^2\) มี a คูณกัน 3 + 2 = 5 ตัว เมื่อขยายไปเลขชี้กำลังเป็นศูนย์ ลบ และเศษส่วน เราเลือกนิยามให้กฎเดิมยังใช้ได้ทุกข้อ นั่นคือที่มาของ \(a^0 = 1\) และ \(a^{-n} = 1/a^n\) ส่วนเลขชี้กำลังเศษส่วนคือรากของเลขยกกำลัง ซึ่งเป็นสะพานไปสู่ฟังก์ชันเอกซ์โพเนนเชียลในหน้า 27.7

A1 Laws of exponents กฎเลขยกกำลัง

\[ a^m a^n = a^{m+n},\quad \frac{a^m}{a^n} = a^{m-n},\quad (a^m)^n = a^{mn},\quad (ab)^n = a^n b^n \]

\(a^0 = 1\ (a \ne 0)\) · \(a^{-n} = \dfrac{1}{a^n}\) · \(\left(\tfrac{a}{b}\right)^{-n} = \left(\tfrac{b}{a}\right)^{n}\)

A2 Rational exponents เลขชี้กำลังเศษส่วน

\[ a^{1/n} = \sqrt[n]{a},\qquad a^{m/n} = \sqrt[n]{a^m} = \left(\sqrt[n]{a}\right)^m \]

ถ้า n คู่ ต้องมี \(a \ge 0\) · ถ้า n คี่ a เป็นลบได้ เช่น \(\sqrt[3]{-8} = -2\)

A3 Radical rules สมบัติของราก

\[ \sqrt{ab} = \sqrt{a}\sqrt{b},\quad \sqrt{\tfrac{a}{b}} = \tfrac{\sqrt a}{\sqrt b}\ \ (a, b \ge 0),\qquad \sqrt{x^2} = |x| \]

\(\sqrt{a + b} \ne \sqrt a + \sqrt b\) เช่น \(\sqrt{9 + 16} = 5\) แต่ \(3 + 4 = 7\)

A4 Rationalizing ทำส่วนไม่ให้ติดราก

\[ \frac{1}{\sqrt a} = \frac{\sqrt a}{a},\qquad \frac{1}{\sqrt a \pm \sqrt b} = \frac{\sqrt a \mp \sqrt b}{a - b} \]

คูณด้วยสังยุค (conjugate) เพื่อใช้ผลต่างกำลังสอง เทคนิคเดียวกันใช้หาลิมิต 0/0 ที่มีราก

ตัวอย่าง A-1 · จัดรูปเลขยกกำลัง

จัดรูป \(\dfrac{\left(8x^6y^{-3}\right)^{2/3}}{4x^{-2}y}\) ให้เลขชี้กำลังเป็นบวก

  1. ยกกำลัง 2/3 ทีละตัวตาม A1: \(8^{2/3} = \left(\sqrt[3]{8}\right)^2 = 4\), \(\left(x^6\right)^{2/3} = x^4\), \(\left(y^{-3}\right)^{2/3} = y^{-2}\)

  2. ตัวเศษจึงเป็น \(4x^4y^{-2}\) แล้วหารด้วย \(4x^{-2}y\): \(\dfrac{4}{4}\cdot x^{4-(-2)}\cdot y^{-2-1} = x^6y^{-3}\)

  3. เขียนเลขชี้กำลังลบเป็นส่วน: \(y^{-3} = 1/y^3\)

\(\dfrac{x^6}{y^3}\)

ตัวอย่าง A-2 · ทำส่วนให้ไม่ติดราก

เขียน \(\dfrac{6}{\sqrt5 - \sqrt2}\) ให้ตัวส่วนไม่มีราก

  1. คูณทั้งเศษและส่วนด้วยสังยุค \(\sqrt5 + \sqrt2\) (A4)

  2. ตัวส่วน: \((\sqrt5 - \sqrt2)(\sqrt5 + \sqrt2) = 5 - 2 = 3\)

  3. ได้ \(\dfrac{6(\sqrt5 + \sqrt2)}{3} = 2(\sqrt5 + \sqrt2)\)

\(2\sqrt5 + 2\sqrt2\)

การแยกตัวประกอบ (Factoring)

การแยกตัวประกอบคือการเขียนพหุนามเป็นผลคูณ ซึ่งมีประโยชน์ตรงที่ผลคูณจะเป็นศูนย์ก็ต่อเมื่อตัวใดตัวหนึ่งเป็นศูนย์ เราจึงหารากได้ทันที และดูเครื่องหมายของพหุนามทีละตัวประกอบได้ ลำดับการลองที่ใช้ได้ผลแทบทุกข้อคือ ดึงตัวร่วมออกก่อน จากนั้นดูว่าเป็นรูปแบบพิเศษหรือไม่ (ผลต่างกำลังสอง กำลังสองสมบูรณ์ ผลบวกหรือผลต่างกำลังสาม) ถ้าไม่ใช่ค่อยใช้วิธี ac หรือจับกลุ่ม

A5 Special products ผลคูณพิเศษ

\[ a^2 - b^2 = (a - b)(a + b),\qquad a^2 \pm 2ab + b^2 = (a \pm b)^2 \]

A6 Sum & difference of cubes กำลังสาม

\[ a^3 + b^3 = (a + b)(a^2 - ab + b^2),\qquad a^3 - b^3 = (a - b)(a^2 + ab + b^2) \]

วงเล็บที่สองแยกต่อในจำนวนจริงไม่ได้ (ดิสคริมิแนนต์ติดลบ)

A7 ac method แยก \(ax^2 + bx + c\)

\[ \text{หา } p, q:\ pq = ac,\ p + q = b \ \Rightarrow\ ax^2 + px + qx + c \ \text{แล้วจับกลุ่ม} \]
ตัวอย่าง A-3 · แยกตัวประกอบ

แยกตัวประกอบ (ก) \(x^3 - 27\) (ข) \(2x^2 + 7x + 3\)

  1. (ก) \(27 = 3^3\) จึงเป็นผลต่างกำลังสาม A6 กับ \(a = x,\ b = 3\): \((x - 3)(x^2 + 3x + 9)\)

  2. (ข) \(ac = 6\) หาสองจำนวนที่คูณได้ 6 บวกได้ 7 คือ 6 กับ 1 จึงเขียน \(2x^2 + 6x + x + 3\)

  3. จับกลุ่ม: \(2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)\) ตรวจโดยคูณกลับได้ \(2x^2 + 7x + 3\)

(ก) \((x - 3)(x^2 + 3x + 9)\) · (ข) \((2x + 1)(x + 3)\)

สมการกำลังสองและดิสคริมิแนนต์ (Quadratic Equations)

สูตรกำลังสองไม่ได้เป็นสิ่งที่ต้องท่องเฉย ๆ มันได้มาจากการทำให้เป็นกำลังสองสมบูรณ์ (completing the square) ซึ่งเป็นเทคนิคเดียวกับที่ใช้หาจุดยอดของพาราโบลา เมื่อเขียน \(ax^2 + bx + c\) เป็น \(a(x - h)^2 + k\) ได้แล้ว จะรู้ทั้งรากและจุดยอดพร้อมกัน ค่า \(b^2 - 4ac\) ที่อยู่ใต้รากบอกจำนวนรากจริงโดยไม่ต้องแก้สมการ และบอกว่ากราฟตัดแกน x กี่จุด

A8 Quadratic formula สูตรสมการกำลังสอง

\[ ax^2 + bx + c = 0\ (a \ne 0) \ \Rightarrow\ x = \frac{-b \pm \sqrt{D}}{2a},\qquad D = b^2 - 4ac \]

\(D > 0\) รากจริงสองค่า · \(D = 0\) รากซ้ำ \(x = -\tfrac{b}{2a}\) · \(D < 0\) รากเป็นจำนวนเชิงซ้อนสังยุคกัน

A9 Vertex form รูปจุดยอด

\[ ax^2 + bx + c = a(x - h)^2 + k,\quad h = -\frac{b}{2a},\ k = c - \frac{b^2}{4a} \]

A10 Sum & product of roots ผลบวก-ผลคูณราก

\[ x_1 + x_2 = -\frac{b}{a},\qquad x_1 x_2 = \frac{c}{a} \]

สมการที่มีราก r, s คือ \(x^2 - (r + s)x + rs = 0\)

ตัวอย่าง A-4 · ใช้สูตร

แก้สมการ \(2x^2 - 4x - 3 = 0\)

  1. \(a = 2,\ b = -4,\ c = -3\) ได้ \(D = 16 - 4(2)(-3) = 16 + 24 = 40 > 0\) จึงมีรากจริงสองค่า

  2. \(x = \dfrac{4 \pm \sqrt{40}}{4} = \dfrac{4 \pm 2\sqrt{10}}{4}\) เพราะ \(\sqrt{40} = \sqrt{4\cdot10} = 2\sqrt{10}\)

  3. ตัดตัวร่วม 2: \(x = \dfrac{2 \pm \sqrt{10}}{2} = 1 \pm \dfrac{\sqrt{10}}{2}\)

\(x = 1 \pm \tfrac{\sqrt{10}}{2} \approx 2.581,\ -0.581\)

ตัวอย่าง A-5 · ผลบวกและผลคูณราก

ถ้า α และ β เป็นรากของ \(x^2 - 5x + 3 = 0\) จงหา \(\alpha^2 + \beta^2\) และ \(\dfrac{1}{\alpha} + \dfrac{1}{\beta}\)

  1. จาก A10: \(\alpha + \beta = 5,\ \alpha\beta = 3\) ไม่ต้องหาค่ารากจริง ๆ

  2. \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 25 - 6 = 19\)

  3. \(\dfrac1\alpha + \dfrac1\beta = \dfrac{\alpha + \beta}{\alpha\beta} = \dfrac53\)

\(\alpha^2 + \beta^2 = 19,\quad \tfrac1\alpha + \tfrac1\beta = \tfrac53\)

แล็บพาราโบลา: ราก จุดยอด และอสมการในภาพเดียว

ลากสไลเดอร์ a, b, c แล้วสังเกตสามอย่างพร้อมกัน: ค่าดิสคริมิแนนต์กับจำนวนจุดตัดแกน x, จุดยอดที่ขยับตาม \(h = -b/2a\), และเมื่อเลือกอสมการ แถบสีเขียวคือช่วงของ x ที่ทำให้อสมการเป็นจริง ลองตั้ง a เป็นลบแล้วดูว่าคำตอบของ \(\le 0\) เปลี่ยนจาก “ระหว่างราก” เป็น “นอกราก” อย่างไร

อสมการกำลังสองและอสมการเศษส่วน (Inequalities)

หลักที่ใช้ได้กับอสมการพหุนามและเศษส่วนทุกแบบคือ “ทำให้ข้างหนึ่งเป็นศูนย์แล้วดูเครื่องหมาย” เครื่องหมายของพหุนามเปลี่ยนได้เฉพาะที่ราก และเครื่องหมายของเศษส่วนเปลี่ยนได้เฉพาะที่รากของตัวเศษหรือตัวส่วน จุดเหล่านี้แบ่งเส้นจำนวนเป็นช่วง ๆ ในแต่ละช่วงเครื่องหมายคงที่ เลือกเลขหนึ่งตัวในช่วงมาแทนก็รู้ทั้งช่วง วิธีนี้เรียกว่าตารางเครื่องหมาย (sign chart) และจะใช้อีกครั้งในหน้าพหุนาม ตรรกยะ และลอการิทึม

A11 Quadratic inequality อสมการกำลังสอง (a > 0)

\[ a(x - r_1)(x - r_2) < 0 \iff r_1 < x < r_2,\qquad > 0 \iff x < r_1 \ \text{หรือ}\ x > r_2 \]

พาราโบลาหงายจะอยู่ใต้แกน x เฉพาะช่วงระหว่างราก · ถ้า a < 0 ให้คูณ −1 ก่อนแล้วกลับเครื่องหมาย

A12 Sign chart ตารางเครื่องหมาย

\[ \frac{P(x)}{Q(x)} \ge 0:\ \text{จุดวิกฤต} = \{P = 0\} \cup \{Q = 0\},\quad Q = 0 \text{ ใช้จุดโปร่งเสมอ} \]
ตัวอย่าง A-6 · อสมการเศษส่วน

แก้อสมการ \(\dfrac{x^2 - x - 6}{x - 1} \ge 0\)

  1. แยกตัวเศษ: \(\dfrac{(x - 3)(x + 2)}{x - 1} \ge 0\) จุดวิกฤตคือ −2, 1, 3 (จุด 1 มาจากตัวส่วน จึงห้ามรวม)

  2. ทดสอบแต่ละช่วง: \(x < -2\): \(\tfrac{(-)(-)}{(-)} = -\) · \(-2 < x < 1\): \(\tfrac{(-)(+)}{(-)} = +\) · \(1 < x < 3\): \(\tfrac{(-)(+)}{(+)} = -\) · \(x > 3\): \(+\)

  3. เลือกช่วงที่เป็นบวกและรวมจุดที่ตัวเศษเป็นศูนย์ (−2 และ 3) เพราะอสมการเป็น \(\ge\)

\(x \in [-2,\ 1) \cup [3,\ \infty)\)

กับดักที่พบบ่อยเขียน \(x^2 - x - 6 \ge 0\) โดยคูณ \((x - 1)\) ทั้งสองข้างไปเลย คำตอบจะผิดทั้งช่วง \(x < 1\) เพราะตรงนั้น \(x - 1\) เป็นลบและเครื่องหมายต้องกลับ อีกจุดที่เสียคะแนนบ่อยคือใส่วงเล็บเหลี่ยมที่ x = 1 ทั้งที่ตัวส่วนเป็นศูนย์

ค่าสัมบูรณ์ (Absolute Value)

ค่าสัมบูรณ์ \(|x|\) คือระยะทางจากจุด x ถึง 0 บนเส้นจำนวน ส่วน \(|x - c|\) คือระยะจาก x ถึง c การคิดแบบระยะทางทำให้อสมการค่าสัมบูรณ์แทบไม่ต้องคำนวณ เช่น \(|x - 1| \ge 2\) แปลว่า “x อยู่ห่างจาก 1 ตั้งแต่ 2 หน่วยขึ้นไป” จึงได้ \(x \le -1\) หรือ \(x \ge 3\) ทันที ในบทฟังก์ชัน \(|x|\) คือฟังก์ชันเป็นช่วงที่มีกราฟรูปตัว V

A13 Absolute value ค่าสัมบูรณ์

\[ |x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}\qquad |ab| = |a||b|,\quad |a + b| \le |a| + |b| \]

A14 Absolute value inequalities อสมการค่าสัมบูรณ์ (a > 0)

\[ |u| = a \iff u = \pm a,\quad |u| < a \iff -a < u < a,\quad |u| > a \iff u < -a \ \text{หรือ}\ u > a \]
ตัวอย่าง A-7 · อสมการค่าสัมบูรณ์

แก้ (ก) \(|2x - 3| < 5\) (ข) \(|x - 1| \ge 2\)

  1. (ก) ใช้ A14: \(-5 < 2x - 3 < 5\) บวก 3 ทุกส่วน: \(-2 < 2x < 8\) หารด้วย 2: \(-1 < x < 4\)

  2. (ข) ระยะจาก x ถึง 1 อย่างน้อย 2: \(x - 1 \le -2\) หรือ \(x - 1 \ge 2\)

(ก) \((-1,\ 4)\) · (ข) \((-\infty,\ -1] \cup [3,\ \infty)\)

ฝึกทำ (มีเฉลย)

1จัดรูป \(\left(\dfrac{27a^{-6}}{b^{3}}\right)^{-1/3}\)

\(27^{-1/3} = \tfrac13\), \(a^{(-6)(-1/3)} = a^2\), \(b^{(-3)(-1/3)}\) อยู่ส่วนจึงกลายเป็นตัวเศษ \(b\)

\(\dfrac{a^2 b}{3}\)

2แยกตัวประกอบ \(x^4 - 16\)

\((x^2 - 4)(x^2 + 4) = (x - 2)(x + 2)(x^2 + 4)\)

\((x - 2)(x + 2)(x^2 + 4)\)

3หาค่า k ที่ทำให้ \(x^2 + kx + 9 = 0\) มีรากซ้ำ

\(D = k^2 - 36 = 0\)

\(k = \pm 6\)

4แก้ \(x^2 - 2x - 8 < 0\)

\((x - 4)(x + 2) < 0\) พาราโบลาหงาย อยู่ใต้แกนระหว่างราก

\(-2 < x < 4\)

5แก้ \(\dfrac{x + 1}{x - 2} \le 0\)

จุดวิกฤต −1 (รวมได้) และ 2 (ห้ามรวม) · ช่วงกลางเป็นลบ

\([-1,\ 2)\)

6แก้ \(|3 - x| \le 4\)

\(-4 \le 3 - x \le 4 \Rightarrow -7 \le -x \le 1 \Rightarrow -1 \le x \le 7\)

\([-1,\ 7]\)

7เขียน \(x^2 + 6x + 2\) ในรูป \((x - h)^2 + k\)

\(x^2 + 6x + 9 - 9 + 2 = (x + 3)^2 - 7\)

\((x + 3)^2 - 7\) จุดยอด \((-3, -7)\)

8สมการกำลังสองที่มีราก \(2 + \sqrt3\) และ \(2 - \sqrt3\)

ผลบวก 4 ผลคูณ \(4 - 3 = 1\) ใช้ A10
