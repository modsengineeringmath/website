อนุกรมในพรีแคลคูลัส: สัญลักษณ์ซิกมา อนุกรมเลขคณิต อนุกรมเรขาคณิต อนุกรมอนันต์ และเงินออม-เงินผ่อนรายงวด

อนุกรมคือการบวกพจน์ของลำดับเข้าด้วยกัน เรื่องเล่าที่คนชอบเล่าคือเกาส์ตอนเด็กบวก 1 ถึง 100 เสร็จในไม่กี่วินาทีด้วยการจับคู่หัวท้าย ความคิดเดียวกันนี้ให้สูตรผลบวกของอนุกรมเลขคณิตทั้งหมด ส่วนอนุกรมเรขาคณิตมีเทคนิค “คูณด้วย r แล้วลบ” ที่ทำให้พจน์กลางหายไปเกือบหมด หน้านี้ฝึกใช้สัญลักษณ์ซิกมา สูตรผลบวกมาตรฐาน อนุกรมเรขาคณิตอนันต์ที่บวกไม่สิ้นสุดแต่ได้ค่าจำกัด และนำไปคำนวณเงินออมกับค่างวดผ่อนบ้านผ่อนรถซึ่งเป็นการใช้งานอนุกรมที่พบในชีวิตจริงที่สุด

แล็บอนุกรม ซิกมา อนุกรมเลขคณิต อนุกรมเรขาคณิต เงินออม · เงินผ่อน

สัญลักษณ์ซิกมาและสมบัติ

\(\sum\limits_{k=1}^{n} f(k)\) อ่านว่า “ผลบวกของ f(k) เมื่อ k ตั้งแต่ 1 ถึง n” ตัวแปร k เป็นเพียงตัวนับ จะใช้ i หรือ j ก็ได้ผลเท่ากัน สมบัติของซิกมาทำให้แยกผลบวกที่ซับซ้อนเป็นชิ้นส่วนที่ใช้สูตรมาตรฐานได้ เช่น \(\sum(3k - 2)\) แยกเป็น \(3\sum k - \sum 2\) ข้อควรระวังคือซิกมาของผลคูณไม่เท่ากับผลคูณของซิกมา

S1 Sigma properties สมบัติของซิกมา

\[ \sum_{k=1}^{n} c = nc,\quad \sum (a_k \pm b_k) = \sum a_k \pm \sum b_k,\quad \sum c\,a_k = c\sum a_k \]

\(\sum a_k b_k \ne \left(\sum a_k\right)\left(\sum b_k\right)\)

S2 Power sums ผลบวกกำลัง

\[ \sum_{k=1}^{n} k = \frac{n(n+1)}{2},\quad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6},\quad \sum_{k=1}^{n} k^3 = \left[\frac{n(n+1)}{2}\right]^2 \]
ตัวอย่าง S-1 · ใช้สมบัติซิกมา

หา (ก) \(\sum\limits_{k=1}^{20}(3k - 2)\) (ข) \(\sum\limits_{k=1}^{10}k(k + 1)\)

  1. (ก) \(3\sum k - 2\cdot20 = 3\cdot\dfrac{20\cdot21}{2} - 40 = 630 - 40\)

  2. (ข) \(\sum(k^2 + k) = \dfrac{10\cdot11\cdot21}{6} + \dfrac{10\cdot11}{2} = 385 + 55\)

(ก) 590 · (ข) 440

อนุกรมเลขคณิต

เขียนผลบวกสองครั้ง ครั้งหนึ่งเรียงจากหน้าไปหลัง อีกครั้งเรียงจากหลังมาหน้า แล้วบวกแนวตั้ง ทุกคู่จะได้ \(a_1 + a_n\) เท่ากันหมด มีทั้งหมด n คู่ ผลบวกสองเท่าจึงเป็น \(n(a_1 + a_n)\) นี่คือที่มาของสูตร ซึ่งตีความได้ว่า “จำนวนพจน์คูณค่าเฉลี่ยของพจน์แรกกับพจน์สุดท้าย”

S3 Arithmetic series อนุกรมเลขคณิต

\[ S_n = \frac{n}{2}\left(a_1 + a_n\right) = \frac{n}{2}\big(2a_1 + (n - 1)d\big) \]
ตัวอย่าง S-2 · ที่นั่งโรงละคร

โรงละครแถวแรกมี 20 ที่ แถวถัดไปเพิ่มทีละ 2 ที่ มี 25 แถว รวมกี่ที่

  1. \(a_1 = 20,\ d = 2,\ n = 25\) · \(a_{25} = 20 + 24(2) = 68\)

  2. \(S_{25} = \tfrac{25}{2}(20 + 68) = \tfrac{25}{2}\cdot88\)

1,100 ที่นั่ง

อนุกรมเรขาคณิตและอนุกรมอนันต์

ให้ \(S_n = a_1 + a_1r + \cdots + a_1r^{n-1}\) คูณทั้งสองข้างด้วย r ได้ \(rS_n = a_1r + \cdots + a_1r^n\) ลบกันแล้วพจน์กลางหายหมด เหลือ \(S_n - rS_n = a_1 - a_1r^n\) จึงได้สูตร เมื่อ \(|r| < 1\) และ n ใหญ่ขึ้นไม่สิ้นสุด \(r^n\) หายไป ผลบวกอนันต์จึงเป็นค่าจำกัด \(\tfrac{a_1}{1 - r}\) แนวคิดที่ว่าบวกจำนวนไม่สิ้นสุดแล้วได้ค่าจำกัดคือหัวใจของแคลคูลัส และอธิบายปริศนาของซีโนได้

S4 Geometric series อนุกรมเรขาคณิต

\[ S_n = a_1\frac{1 - r^n}{1 - r} = a_1\frac{r^n - 1}{r - 1}\quad (r \ne 1) \]

S5 Infinite geometric อนุกรมเรขาคณิตอนันต์

\[ \sum_{n=1}^{\infty} a_1 r^{n-1} = \frac{a_1}{1 - r}\quad \iff\ |r| < 1 \]

S6 Telescoping อนุกรมกล้องส่องทางไกล

\[ \sum_{k=1}^{n}\frac{1}{k(k+1)} = \sum_{k=1}^{n}\left(\frac1k - \frac{1}{k+1}\right) = 1 - \frac{1}{n+1} \]
ตัวอย่าง S-3 · เรขาคณิตจำกัดและอนันต์

(ก) \(3 + 6 + 12 + \cdots + 3\cdot2^9\) (ข) \(8 + 4 + 2 + 1 + \cdots\)

  1. (ก) \(a_1 = 3,\ r = 2,\ n = 10\): \(S_{10} = 3\cdot\dfrac{2^{10} - 1}{2 - 1} = 3\cdot1023\)

  2. (ข) \(a_1 = 8,\ r = \tfrac12\): \(S_\infty = \dfrac{8}{1 - 1/2}\)

(ก) 3,069 · (ข) 16

ตัวอย่าง S-4 · ทศนิยมซ้ำ

เขียน \(0.\overline{45}\) และ \(0.1\overline{2}\) เป็นเศษส่วน

  1. \(0.\overline{45} = \tfrac{45}{100} + \tfrac{45}{100^2} + \cdots = \dfrac{45/100}{1 - 1/100} = \dfrac{45}{99}\)

  2. \(0.1\overline{2} = \tfrac{1}{10} + \left(\tfrac{2}{100} + \tfrac{2}{1000} + \cdots\right) = \tfrac{1}{10} + \dfrac{2/100}{1 - 1/10} = \tfrac{1}{10} + \tfrac{2}{90}\)

\(\tfrac{5}{11}\) และ \(\tfrac{11}{90}\)

ตัวอย่าง S-5 · ลูกบอลกระดอน

ปล่อยลูกบอลจากความสูง 10 m ทุกครั้งที่กระทบพื้นกระดอนขึ้น ¾ ของความสูงเดิม ลูกบอลเคลื่อนที่ทั้งหมดกี่เมตรจนหยุด

  1. ขาลงครั้งแรก 10 m จากนั้นทุกการกระดอนมีขาขึ้นและขาลงเท่ากัน

  2. ความสูงการกระดอน: \(7.5 + 5.625 + \cdots = \dfrac{7.5}{1 - 3/4} = 30\)

  3. ระยะรวม \(10 + 2(30)\)

เงินออมและเงินผ่อนรายงวด

ถ้าฝากเงินเท่ากันทุกงวด เงินงวดแรกได้ดอกเบี้ยทบต้นนานที่สุด งวดสุดท้ายไม่ได้ดอกเลย เงินรวมจึงเป็นอนุกรมเรขาคณิตที่มีอัตราส่วน \(1 + i\) เมื่อ i คืออัตราดอกเบี้ยต่องวด ส่วนการกู้เงินคิดกลับด้าน: ยอดกู้ต้องเท่ากับมูลค่าปัจจุบันของค่างวดทุกงวดรวมกัน สูตรสองข้อนี้ใช้ทั้งกับเงินผ่อนบ้าน ผ่อนรถ และแผนเกษียณ

S7 Savings (future value) เงินออมรายงวด

\[ FV = R\left[1 + (1+i) + \cdots + (1+i)^{N-1}\right] = R\,\frac{(1 + i)^N - 1}{i} \]

S8 Loan payment ค่างวดเงินกู้

\[ PV = R\,\frac{1 - (1 + i)^{-N}}{i}\quad\Rightarrow\quad R = \frac{PV\cdot i}{1 - (1 + i)^{-N}} \]

i = อัตราต่อปี ÷ จำนวนงวดต่อปี · N = จำนวนงวดทั้งหมด

ตัวอย่าง S-6 · ออมทุกเดือน

ฝากเดือนละ 1,000 บาท ดอกเบี้ย 3% ต่อปีทบต้นรายเดือน นาน 5 ปี ได้เงินรวมเท่าใด

  1. \(i = 0.03/12 = 0.0025,\ N = 60\)

  2. \(FV = 1000\cdot\dfrac{1.0025^{60} - 1}{0.0025}\)

≈ 64,646.71 บาท (ฝากเอง 60,000 บาท ดอกเบี้ย ≈ 4,646.71 บาท)

ตัวอย่าง S-7 · ผ่อนรถ

กู้ 500,000 บาท ดอกเบี้ย 6% ต่อปี ผ่อนรายเดือน 5 ปี ค่างวดเดือนละเท่าใด

  1. \(i = 0.005,\ N = 60\)

  2. \(R = \dfrac{500000\cdot0.005}{1 - 1.005^{-60}}\)

≈ 9,666.40 บาทต่อเดือน (จ่ายรวม ≈ 579,984 บาท)

แล็บอนุกรม: พจน์ ผลบวกย่อย ซิกมา และเงินผ่อน

แท่งสีน้ำเงินคือแต่ละพจน์ เส้นสีส้มคือผลบวกย่อย \(S_k\) ในโหมดอนุกรมเรขาคณิตลอง r = 0.5 แล้วเปลี่ยนเป็น 1.05 เพื่อดูความต่างระหว่างอนุกรมที่ลู่เข้ากับลู่ออก โหมดซิกมาพิมพ์ f(k) ได้อิสระ เช่น 1/(k(k+1)) หรือ 2^k และให้ผลบวกเป็นเศษส่วนแม่นตรงเมื่อทำได้

กับดักที่พบบ่อยใช้ \(S_\infty = \tfrac{a_1}{1 - r}\) กับ r = 2 แล้วได้ −a₁ ซึ่งไม่มีความหมาย · นับจำนวนพจน์ผิดเมื่อซิกมาไม่ได้เริ่มที่ 1 (จาก k = m ถึง n มี n − m + 1 พจน์) · และใช้อัตราดอกเบี้ยต่อปีแทนต่องวดในสูตรเงินผ่อน
