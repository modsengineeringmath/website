ตารางสถิติ: ตาราง z พื้นที่ใต้โค้งปกติ ตาราง t ตารางไคกำลังสอง ตาราง F และเครื่องคิดค่า p

ตารางสถิติคือเครื่องมือที่ทำให้คำถาม “ค่านี้หายากแค่ไหน” ตอบได้โดยไม่ต้องอินทิเกรตฟังก์ชันความหนาแน่นเอง หน้านี้รวบรวมตารางที่ใช้บ่อยที่สุดตั้งแต่ ม.6 จนถึงสถิติวิศวกรรมในมหาวิทยาลัย ได้แก่ ตาราง z สองแบบ ตาราง t ตารางไคกำลังสอง และตาราง F ที่สองระดับนัยสำคัญ ทุกตารางมีวิธีอ่าน ตัวอย่างที่ใช้จริง และช่องค้นหาที่ไฮไลต์ค่าที่ต้องการ หัวตารางค้างอยู่เมื่อเลื่อนบนโทรศัพท์ และด้านบนมีเครื่องคิดค่า p กับค่าวิกฤตสำหรับค่าที่ไม่มีในตาราง

  • ตาราง Φ(z): พื้นที่ทางซ้ายของ z · \(\Phi(-z) = 1 - \Phi(z)\)
  • ตาราง 0 ถึง z (แบบ ม.6) = \(\Phi(z) - 0.5\)
  • t: ใช้เมื่อประมาณ σ ด้วย s, df = n − 1 · แถว ∞ = ค่า z
  • χ²: ทดสอบภาวะสารูปสนิทดีและความเป็นอิสระ · F: เทียบความแปรปรวนและ ANOVA
  • ค่าวิกฤตที่ใช้บ่อย: \(z_{0.025} = 1.96\), \(z_{0.05} = 1.645\), \(z_{0.005} = 2.576\)

เครื่องคิดค่า p และค่าวิกฤต

เลือกการแจกแจงและองศาอิสระ แล้วใส่ค่าสถิติเพื่อหาพื้นที่ทางซ้าย ทางขวา และค่า p หรือใส่ α เพื่อหาค่าวิกฤตแบบหางเดียวหรือสองหาง ส่วนที่ระบายสีบนกราฟคือพื้นที่ที่เป็นคำตอบ ใช้ตรวจการเปิดตาราง หรือใช้กับองศาอิสระที่ตารางไม่มี เช่น df = 37

สูตรที่ใช้คู่กับตาราง

Z1 Standard normal ปกติมาตรฐาน

\[ Z = \frac{X - \mu}{\sigma},\quad \Phi(z) = P(Z \le z),\quad \Phi(-z) = 1 - \Phi(z) \]

Z2 Areas พื้นที่ระหว่างสองค่า

\[ P(a < Z < b) = \Phi(b) - \Phi(a),\qquad A_{0\to z} = \Phi(z) - 0.5 \]

Z3 t statistic · CI ค่า t และช่วงความเชื่อมั่น

\[ t = \frac{\bar x - \mu_0}{s/\sqrt n},\ df = n - 1,\qquad \bar x \pm t_{\alpha/2}\,\frac{s}{\sqrt n} \]

Z4 Chi-square ไคกำลังสอง

\[ \chi^2 = \sum\frac{(O - E)^2}{E},\qquad df = k - 1\ \ (\text{ภาวะสารูปสนิทดี}) \]

Z5 F ratio อัตราส่วนความแปรปรวน

\[ F = \frac{s_1^2}{s_2^2},\quad df = (n_1 - 1,\ n_2 - 1),\quad F_{1-\alpha}(d_1, d_2) = \frac{1}{F_{\alpha}(d_2, d_1)} \]

ตาราง z: พื้นที่ทางซ้าย Φ(z) = P(Z ≤ z)

แถวคือ z ถึงทศนิยมตำแหน่งแรก คอลัมน์คือทศนิยมตำแหน่งที่สอง สำหรับ z ลบ คอลัมน์หมายถึงส่วนที่ลบเพิ่ม เช่น แถว −1.2 คอลัมน์ 0.03 คือ z = −1.23 พิมพ์ค่า z ในช่องด้านล่างเพื่อไฮไลต์ช่องที่ตรงกันในตารางทั้งสอง
