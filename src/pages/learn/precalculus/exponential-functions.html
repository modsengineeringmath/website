// บทที่ 27.7 · พรีแคลคูลัส · Exponential Functions

ฟังก์ชันเอกซ์โพเนนเชียล: กราฟ การเติบโตและการสลาย ดอกเบี้ยทบต้น จำนวน e ครึ่งชีวิต และสมการเลขชี้กำลัง

ฟังก์ชันเชิงเส้นเพิ่มขึ้นด้วยการบวกค่าเดิมซ้ำ ๆ แต่ฟังก์ชันเอกซ์โพเนนเชียลเพิ่มขึ้นด้วยการคูณค่าเดิมซ้ำ ๆ ช่วงแรกสองแบบนี้อาจดูใกล้กัน แต่ไม่นานแบบคูณจะทิ้งแบบบวกไปไกลมาก นี่คือคณิตศาสตร์ของดอกเบี้ยทบต้น การแพร่ของเชื้อ จำนวนประชากร และการคายประจุของตัวเก็บประจุในวงจร RC หน้านี้เริ่มจากรูปกราฟสองแบบของ \(b^x\) อธิบายว่าจำนวน e มาจากไหน แล้วนำไปคำนวณดอกเบี้ย ครึ่งชีวิต และแก้สมการที่ตัวแปรอยู่บนเลขชี้กำลัง

เขียนโดย อาจารย์มดอัปเดต
แล็บเอกซ์โพเนนเชียล กราฟ bˣ ดอกเบี้ยทบต้น ครึ่งชีวิต สมการ
สรุปใน 30 วินาที
  • \(f(x) = b^x\), \(b > 0,\ b \ne 1\) · โดเมน \(\mathbb R\) · เรนจ์ \((0, \infty)\) · ผ่าน (0, 1) และ (1, b)
  • \(b > 1\) เติบโต · \(0 < b < 1\) สลาย · เส้นกำกับ \(y = 0\)
  • ดอกเบี้ยทบต้น \(A = P(1 + r/n)^{nt}\) · ต่อเนื่อง \(A = Pe^{rt}\)
  • ครึ่งชีวิต \(N = N_0(1/2)^{t/T}\) · เวลาเพิ่มเป็นสองเท่า \(t_2 = \ln 2 / \ln(1 + r)\)
  • \(b^u = b^v \iff u = v\) · อสมการ: ฐานน้อยกว่า 1 ต้องกลับเครื่องหมาย

นิยามและกราฟของ bˣ

ทุกครั้งที่ x เพิ่มขึ้นหนึ่งหน่วย ค่า \(b^x\) ถูกคูณด้วย b นี่คือคุณสมบัติที่แยกเอกซ์โพเนนเชียลออกจากพหุนาม ถ้า b มากกว่า 1 กราฟจะเริ่มแนบแกน x ทางซ้ายแล้วพุ่งขึ้นทางขวา ถ้า b อยู่ระหว่าง 0 กับ 1 กราฟจะกลับด้าน ทั้งสองแบบผ่านจุด (0, 1) เพราะ \(b^0 = 1\) และไม่มีวันแตะแกน x เพราะเลขยกกำลังของฐานบวกเป็นบวกเสมอ สังเกตว่า \(\left(\tfrac12\right)^x = 2^{-x}\) กราฟของฐาน ½ จึงเป็นภาพสะท้อนของฐาน 2 ในแกน y

E1 Exponential function ฟังก์ชันเอกซ์โพเนนเชียล

\[ f(x) = b^x,\ b > 0,\ b \ne 1:\quad D = \mathbb R,\ \ R = (0, \infty),\ \ \text{HA } y = 0 \]

E2 Growth vs decay เติบโต · สลาย

\[ b > 1:\ \text{เพิ่ม},\qquad 0 < b < 1:\ \text{ลด},\qquad b^{-x} = \left(\tfrac1b\right)^x \]

E3 Transformed รูปทั่วไป

\[ y = a\,b^{\,x - h} + k:\quad \text{HA } y = k,\ \ R = (k, \infty) \text{ ถ้า } a > 0 \]
ตัวอย่าง E-1 · อ่านกราฟจากสมการ

บอกเส้นกำกับ จุดตัดแกน y และเรนจ์ของ \(y = 3\cdot2^{x+1} - 4\)

  1. เทียบ E3: \(a = 3,\ b = 2,\ h = -1,\ k = -4\)

  2. เส้นกำกับ \(y = -4\) และเพราะ \(a > 0\) กราฟอยู่เหนือเส้นนี้

  3. จุดตัดแกน y: \(3\cdot2^{1} - 4 = 2\)

HA \(y = -4\) · ผ่าน (0, 2) · เรนจ์ \((-4, \infty)\)

การเติบโต ดอกเบี้ยทบต้น และจำนวน e

ถ้าปริมาณหนึ่งเพิ่มขึ้น r เปอร์เซ็นต์ต่อช่วงเวลา หลัง t ช่วงจะเป็น \(A_0(1 + r)^t\) ดอกเบี้ยทบต้นเป็นกรณีพิเศษที่แบ่งอัตราต่อปีออกเป็น n งวดต่อปี ยิ่งทบต้นถี่ ดอกเบี้ยยิ่งไปงอกดอกเร็วขึ้น แต่ผลลัพธ์ไม่ได้โตไม่สิ้นสุด มันเข้าใกล้ \(Pe^{rt}\) ซึ่งเป็นที่มาของจำนวน e ในชีวิตจริง

E4 Growth model แบบจำลองร้อยละคงที่

\[ A(t) = A_0(1 + r)^t\ \ (\text{เพิ่ม}),\qquad A(t) = A_0(1 - r)^t\ \ (\text{ลด}) \]

E5 Compound interest ดอกเบี้ยทบต้น

\[ A = P\left(1 + \frac{r}{n}\right)^{nt} \]

P เงินต้น · r อัตราต่อปี (ทศนิยม) · n งวดต่อปี · t จำนวนปี

E6 The number e จำนวน e และทบต้นต่อเนื่อง

\[ e = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \approx 2.71828,\qquad A = Pe^{rt} \]
ตัวอย่าง E-2 · ทบต้นสามแบบ

ฝากเงิน 10,000 บาท ดอกเบี้ย 5% ต่อปี นาน 10 ปี เปรียบเทียบทบต้นรายปี รายเดือน และต่อเนื่อง

  1. รายปี: \(10000(1.05)^{10} \approx 16{,}288.95\)

  2. รายเดือน: \(10000\left(1 + \tfrac{0.05}{12}\right)^{120} \approx 16{,}470.09\)

  3. ต่อเนื่อง: \(10000e^{0.05\times10} = 10000e^{0.5} \approx 16{,}487.21\)

16,288.95 · 16,470.09 · 16,487.21 บาท — ทบต้นถี่ขึ้นได้เพิ่ม แต่เข้าใกล้เพดาน \(Pe^{rt}\)

ตัวอย่าง E-3 · เวลาเพิ่มเป็นสองเท่า

ประชากรเมืองหนึ่ง 1.2 ล้านคน เพิ่มปีละ 3% จะเป็นสองเท่าเมื่อใด

  1. \(1.2(1.03)^t = 2.4 \Rightarrow 1.03^t = 2\)

  2. ใช้ลอการิทึม (หน้า 27.8): \(t = \dfrac{\ln 2}{\ln 1.03} \approx 23.45\) ปี

  3. เทียบกฎ 72: \(72/3 = 24\) ปี ใกล้เคียง

ประมาณ 23.4 ปี (คำตอบไม่ขึ้นกับจำนวนเริ่มต้น)

การสลายและครึ่งชีวิต

การสลายแบบเอกซ์โพเนนเชียลเกิดเมื่ออัตราการลดแปรผันตามปริมาณที่เหลือ เช่น สารกัมมันตรังสี ยาในกระแสเลือด หรือแรงดันของตัวเก็บประจุที่คายประจุผ่านตัวต้านทาน ครึ่งชีวิตคือเวลาที่ใช้ลดลงครึ่งหนึ่ง ซึ่งเท่ากันทุกครั้ง ไม่ว่าจะเริ่มจากปริมาณเท่าไร ในวงจรไฟฟ้าใช้ค่าคงตัวเวลา τ แทน โดยครึ่งชีวิตเท่ากับ \(\tau\ln 2 \approx 0.693\tau\)

E7 Half-life ครึ่งชีวิต

\[ N(t) = N_0\left(\tfrac12\right)^{t/T_{1/2}} = N_0 e^{-kt},\qquad k = \frac{\ln 2}{T_{1/2}} \]

E8 RC discharge คายประจุผ่าน R

\[ v(t) = V_0 e^{-t/\tau},\quad \tau = RC,\quad v(\tau) \approx 0.368\,V_0 \]
ตัวอย่าง E-4 · คาร์บอน-14

คาร์บอน-14 มีครึ่งชีวิตประมาณ 5,730 ปี (ก) หลัง 10,000 ปีเหลือกี่เปอร์เซ็นต์ (ข) ซากที่เหลือ 25% มีอายุเท่าใด

  1. (ก) \(\left(\tfrac12\right)^{10000/5730} = 0.5^{1.7452} \approx 0.2983\)

  2. (ข) \(25\% = \left(\tfrac12\right)^2\) จึงผ่านไปสองครึ่งชีวิต: \(2 \times 5730\)

(ก) ประมาณ 29.8% · (ข) ประมาณ 11,460 ปี

สมการและอสมการเลขชี้กำลัง

ถ้าทำให้ทั้งสองข้างมีฐานเดียวกันได้ ก็เทียบเลขชี้กำลังได้ทันทีเพราะ \(b^x\) เป็นหนึ่งต่อหนึ่ง ถ้าทำไม่ได้ให้ใส่ลอการิทึมทั้งสองข้างตามหน้า 27.8 สมการที่มีพจน์ \(b^{2x}\) กับ \(b^x\) ปนกันให้แทน \(u = b^x\) แล้วจะกลายเป็นสมการกำลังสอง ส่วนอสมการต้องดูฐาน: ฐานมากกว่า 1 ทิศทางคงเดิม ฐานระหว่าง 0 กับ 1 ต้องกลับทิศ

E9 Same base สมการฐานเดียวกัน

\[ b^u = b^v \iff u = v \]

E10 Inequalities อสมการเลขชี้กำลัง

\[ b > 1:\ b^u > b^v \iff u > v,\qquad 0 < b < 1:\ b^u > b^v \iff u < v \]
ตัวอย่าง E-5 · ทำฐานให้เท่ากัน

แก้ \(4^{x+1} = 8^{2x-1}\)

  1. เขียนเป็นฐาน 2: \(2^{2(x+1)} = 2^{3(2x-1)}\)

  2. \(2x + 2 = 6x - 3 \Rightarrow 4x = 5\)

\(x = \tfrac54\)

ตัวอย่าง E-6 · แทนตัวแปร

แก้ \(9^x - 4\cdot3^x + 3 = 0\)

  1. \(9^x = (3^x)^2\) ให้ \(u = 3^x > 0\): \(u^2 - 4u + 3 = 0 \Rightarrow (u - 1)(u - 3) = 0\)

  2. \(3^x = 1 \Rightarrow x = 0\) · \(3^x = 3 \Rightarrow x = 1\)

\(x = 0\) หรือ \(x = 1\)

ตัวอย่าง E-7 · อสมการฐานน้อยกว่า 1

แก้ \(\left(\tfrac12\right)^{x-1} > 8\)

  1. \(8 = \left(\tfrac12\right)^{-3}\) จึงได้ \(\left(\tfrac12\right)^{x-1} > \left(\tfrac12\right)^{-3}\)

  2. ฐาน ½ น้อยกว่า 1 กลับทิศ: \(x - 1 < -3\)

\(x < -2\)

แล็บเอกซ์โพเนนเชียล: กราฟ · ดอกเบี้ย · ครึ่งชีวิต

โหมดกราฟให้ลาก a, b, k แล้วเทียบกับ \(e^x\) ที่เป็นเส้นประ สังเกตว่าเมื่อ b ข้าม 1 กราฟเปลี่ยนจากสลายเป็นเติบโต โหมดดอกเบี้ยเปรียบเทียบดอกเบี้ยเชิงเดียว ทบต้นตามงวดที่เลือก และทบต้นต่อเนื่องบนกราฟเดียว พร้อมอัตราผลตอบแทนที่แท้จริง (EAR) และเวลาเพิ่มเป็นสองเท่า โหมดครึ่งชีวิตแสดงจุดที่เหลือ ½, ¼, ⅛, 1/16

กับดักที่พบบ่อยใส่ r = 5 แทน 0.05 ในสูตรดอกเบี้ย · คิดว่า \(2^{x+3} = 2^x + 2^3\) (ที่ถูกคือ \(2^x \cdot 2^3\)) · ลืมกลับทิศอสมการเมื่อฐานน้อยกว่า 1 · และตอบ \(u = 3^x\) ที่เป็นลบ ซึ่งเป็นไปไม่ได้

ฝึกทำ (มีเฉลย)

1แก้ \(27^{x} = 9^{x + 2}\)

\(3^{3x} = 3^{2x + 4}\)

\(x = 4\)

2แก้ \(2^{2x} - 6\cdot2^x + 8 = 0\)

\(u^2 - 6u + 8 = 0 \Rightarrow u = 2, 4\)

\(x = 1,\ 2\)

3รถยนต์ราคา 800,000 บาท ค่าเสื่อม 15% ต่อปี หลัง 4 ปีเหลือเท่าใด

\(800000(0.85)^4\)

ประมาณ 417,605 บาท

4แก้ \(3^{x^2 - 2x} \le 27\)

\(x^2 - 2x \le 3 \Rightarrow (x - 3)(x + 1) \le 0\)

\(-1 \le x \le 3\)

5สารหนึ่งเหลือ 1/8 ของเดิมใน 30 วัน ครึ่งชีวิตเท่าใด

\(1/8 = (1/2)^3\) จึงผ่านไป 3 ครึ่งชีวิต
