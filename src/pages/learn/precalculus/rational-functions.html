// บทที่ 27.5 · พรีแคลคูลัส · Rational Functions

ฟังก์ชันตรรกยะ: เส้นกำกับแนวดิ่ง แนวนอน แนวเฉียง จุดเว้น และขั้นตอนวาดกราฟ

ฟังก์ชันตรรกยะคือพหุนามหารด้วยพหุนาม ดูเหมือนเป็นแค่เศษส่วนธรรมดา แต่กราฟของมันมีสิ่งที่พหุนามไม่มี คือเส้นกำกับที่กราฟเข้าใกล้ไม่สิ้นสุด และจุดเว้นที่กราฟขาดไปเพียงจุดเดียว ในงานจริงเราเจอฟังก์ชันแบบนี้บ่อย เช่น ต้นทุนเฉลี่ยต่อชิ้นที่ลดลงเมื่อผลิตมากขึ้น ความเข้มของแสงที่ลดลงตามระยะทาง หรือฟังก์ชันถ่ายโอนของวงจรไฟฟ้าในวิชาระบบควบคุม หน้านี้ให้ขั้นตอนวาดกราฟเจ็ดขั้นที่ใช้ได้กับทุกโจทย์ พร้อมเครื่องวิเคราะห์ที่ตรวจคำตอบได้ทันที

เขียนโดย อาจารย์มดอัปเดต
เครื่องวิเคราะห์ กราฟ 1/x เส้นกำกับ ขั้นตอนวาด อสมการ
สรุปใน 30 วินาที
  • ตัดตัวประกอบร่วมก่อน: ตัวที่ตัดหมด → จุดเว้น · ตัวที่เหลือในส่วน → เส้นกำกับแนวดิ่ง
  • เส้นกำกับแนวนอน: ดีกรีเศษ < ส่วน → y = 0 · เท่ากัน → อัตราส่วนสัมประสิทธิ์นำ
  • ดีกรีเศษมากกว่าส่วน 1 → เส้นกำกับแนวเฉียง = ผลหารจากการหารยาว
  • \(y = \dfrac{a}{x - h} + k\) คือกราฟ \(1/x\) ที่ยืดและเลื่อน มีเส้นกำกับ \(x = h,\ y = k\)

ฟังก์ชันส่วนกลับ 1/x และการแปลง

กราฟ \(y = 1/x\) เป็นไฮเพอร์โบลาสองกิ่งในจตุภาคที่ 1 และ 3 เมื่อ x ใกล้ศูนย์ ค่า \(1/x\) ใหญ่ขึ้นไม่มีขีดจำกัด ส่วนเมื่อ x ใหญ่มาก \(1/x\) เล็กลงจนเกือบเป็นศูนย์ แกนทั้งสองจึงเป็นเส้นกำกับ ฟังก์ชันตรรกยะดีกรีหนึ่งต่อหนึ่งทุกตัวเขียนเป็นการแปลงของ \(1/x\) ได้ด้วยการหาร ซึ่งทำให้รู้เส้นกำกับและรูปร่างทันที ส่วน \(1/x^2\) ให้ค่าบวกทั้งสองข้างของศูนย์ กิ่งทั้งสองจึงอยู่เหนือแกน x

R1 Rational function ฟังก์ชันตรรกยะ

\[ f(x) = \frac{p(x)}{q(x)},\qquad D_f = \{x : q(x) \ne 0\} \]

R2 Transformed reciprocal การแปลงของ 1/x

\[ y = \frac{a}{x - h} + k:\quad \text{VA } x = h,\ \ \text{HA } y = k \]

\(\dfrac{ax + b}{cx + d} = \dfrac{a}{c} + \dfrac{b - ad/c}{cx + d}\) จึงมี HA \(y = a/c\), VA \(x = -d/c\)

ตัวอย่าง R-1 · เขียนเป็นการแปลงของ 1/x

เขียน \(f(x) = \dfrac{2x - 3}{x + 1}\) ในรูป \(\dfrac{a}{x - h} + k\) แล้วบอกเส้นกำกับ

  1. เขียนตัวเศษให้มี \(x + 1\): \(2x - 3 = 2(x + 1) - 5\)

  2. \(f(x) = \dfrac{2(x + 1) - 5}{x + 1} = 2 - \dfrac{5}{x + 1}\)

  3. คือ \(1/x\) ยืด 5 เท่า สะท้อนแกน x เลื่อนซ้าย 1 ขึ้น 2

VA \(x = -1\), HA \(y = 2\) · กิ่งอยู่ในบริเวณซ้ายบนและขวาล่างของจุดตัดเส้นกำกับ

จุดเว้นและเส้นกำกับทั้งสามแบบ

ก่อนหาเส้นกำกับต้องแยกตัวประกอบทั้งเศษและส่วนแล้วตัดตัวร่วมเสมอ ตัวประกอบที่ถูกตัดหมดจะทิ้งรอยไว้เป็นจุดเว้น ซึ่งหาพิกัด y ได้จากสูตรหลังตัด ส่วนตัวประกอบที่ยังอยู่ในส่วนจะให้เส้นกำกับแนวดิ่ง สำหรับปลายกราฟเมื่อ x ไปอนันต์ ให้เทียบดีกรีเหมือนที่ทำกับพหุนาม เพราะพจน์ดีกรีสูงสุดเป็นตัวควบคุม

R3 Hole จุดเว้น

\[ f(x) = \frac{(x - c)\,g(x)}{(x - c)\,h(x)},\ h(c) \ne 0 \ \Rightarrow\ \text{hole at } \left(c,\ \tfrac{g(c)}{h(c)}\right) \]

R4 Vertical asymptote เส้นกำกับแนวดิ่ง

\[ \text{หลังตัดตัวร่วม: } q(c) = 0,\ p(c) \ne 0 \ \Rightarrow\ x = c \]

R5 Horizontal asymptote เส้นกำกับแนวนอน

\[ \deg p < \deg q:\ y = 0,\qquad \deg p = \deg q:\ y = \frac{a_n}{b_m} \]

R6 Slant asymptote เส้นกำกับแนวเฉียง

\[ \deg p = \deg q + 1:\ \frac{p}{q} = (mx + c) + \frac{r(x)}{q(x)} \Rightarrow y = mx + c \]
ตัวอย่าง R-2 · จุดเว้นและเส้นกำกับ

วิเคราะห์ \(f(x) = \dfrac{x^2 - 4}{x^2 - x - 2}\)

  1. แยกตัวประกอบ: \(\dfrac{(x - 2)(x + 2)}{(x - 2)(x + 1)}\) ตัด \(x - 2\) ได้ \(\dfrac{x + 2}{x + 1}\) เมื่อ \(x \ne 2\)

  2. จุดเว้นที่ x = 2: \(y = \dfrac{2 + 2}{2 + 1} = \dfrac43\) · VA จากตัวที่เหลือ: \(x = -1\)

  3. ดีกรีเท่ากัน (2 ต่อ 2) HA \(y = \tfrac11 = 1\)

  4. จุดตัดแกน x จากตัวเศษหลังตัด: \(x = -2\) · จุดตัดแกน y: \(f(0) = \tfrac{-4}{-2} = 2\)

จุดเว้น \((2, \tfrac43)\) · VA \(x = -1\) · HA \(y = 1\) · ตัดแกนที่ \((-2, 0)\), \((0, 2)\)

ตัวอย่าง R-3 · เส้นกำกับแนวเฉียง

หาเส้นกำกับของ \(f(x) = \dfrac{x^2 + 1}{x - 1}\)

  1. ดีกรีเศษ 2 มากกว่าส่วน 1 อยู่หนึ่ง ⇒ มีเส้นกำกับแนวเฉียง ไม่มีแนวนอน

  2. หารยาว: \(x^2 + 1 = (x - 1)(x + 1) + 2\) จึง \(f(x) = x + 1 + \dfrac{2}{x - 1}\)

  3. เมื่อ \(|x|\) ใหญ่ \(\tfrac{2}{x - 1} \to 0\) กราฟจึงเข้าใกล้ \(y = x + 1\)

VA \(x = 1\) · เส้นกำกับแนวเฉียง \(y = x + 1\) · ไม่ตัดแกน x · \(f(0) = -1\)

ตัวอย่าง R-4 · กราฟตัดเส้นกำกับแนวนอน

กราฟ \(f(x) = \dfrac{2x^2 - 3x}{x^2 + 1}\) ตัดเส้นกำกับแนวนอนที่ใด

  1. HA: ดีกรีเท่ากัน \(y = 2\) · ตัวส่วนไม่เป็นศูนย์เลย จึงไม่มี VA

  2. แก้ \(\dfrac{2x^2 - 3x}{x^2 + 1} = 2 \Rightarrow 2x^2 - 3x = 2x^2 + 2 \Rightarrow x = -\tfrac23\)

ตัดที่ \(\left(-\tfrac23,\ 2\right)\) แล้วเข้าหา y = 2 จากด้านบนทางซ้าย

ขั้นตอนวาดกราฟฟังก์ชันตรรกยะ 7 ขั้น

  1. แยกตัวประกอบเศษและส่วน เขียนโดเมน
  2. ตัดตัวประกอบร่วม บันทึกจุดเว้นพร้อมพิกัด y
  3. หาเส้นกำกับแนวดิ่งจากรากของตัวส่วนที่เหลือ
  4. หาเส้นกำกับแนวนอนหรือแนวเฉียงด้วยการเทียบดีกรี
  5. หาจุดตัดแกน x (รากของตัวเศษที่เหลือ) และแกน y (ถ้า 0 อยู่ในโดเมน)
  6. ทำตารางเครื่องหมายจากรากเศษและรากส่วน เพื่อรู้ว่ากราฟอยู่เหนือหรือใต้แกนในแต่ละช่วง
  7. ร่างกราฟตามเส้นกำกับ ใส่จุดโปร่งที่จุดเว้น

R7 Sign chart ตารางเครื่องหมาย

\[ \text{จุดแบ่ง} = \{p = 0\} \cup \{q = 0\},\ \text{เครื่องหมายคงที่ในแต่ละช่วง} \]

ตัวประกอบที่มีกำลังคู่ไม่ทำให้เครื่องหมายเปลี่ยน ทั้งในเศษและในส่วน

เครื่องวิเคราะห์ฟังก์ชันตรรกยะ

พิมพ์ตัวเศษและตัวส่วนในรูปพหุนามหรือรูปแยกตัวประกอบ เช่น (x-1)(x+2) หรือใส่สัมประสิทธิ์ 1, 0, -4 เครื่องจะตัดตัวร่วม หาจุดเว้น เส้นกำกับทั้งสามแบบ จุดตัดแกน และตารางเครื่องหมาย แล้ววาดกราฟแยกกิ่งที่เส้นกำกับแนวดิ่งเพื่อไม่ให้เกิดเส้นแนวตั้งหลอกตา ซึ่งเป็นปัญหาที่พบบ่อยในโปรแกรมวาดกราฟทั่วไป

อสมการตรรกยะและงานประยุกต์

ตัวอย่าง R-5 · อสมการตรรกยะ

แก้ \(\dfrac{x - 3}{x + 2} \le 1\)

  1. ย้ายข้าง: \(\dfrac{x - 3}{x + 2} - 1 \le 0 \Rightarrow \dfrac{x - 3 - (x + 2)}{x + 2} \le 0 \Rightarrow \dfrac{-5}{x + 2} \le 0\)

  2. ตัวเศษ −5 เป็นลบเสมอ เศษส่วนจะ \(\le 0\) เมื่อตัวส่วนเป็นบวก: \(x + 2 > 0\)

\(x > -2\) — ถ้าคูณ \(x + 2\) ไขว้ตั้งแต่แรกจะได้ \(-3 \le 2\) ซึ่งเป็นจริงเสมอและตอบผิดว่า “ทุกจำนวนจริงยกเว้น −2”

ตัวอย่าง R-6 · ต้นทุนเฉลี่ย

โรงงานมีต้นทุนคงที่ 5,000 บาท และต้นทุนผันแปรชิ้นละ 20 บาท ต้นทุนเฉลี่ยต่อชิ้นเมื่อผลิต x ชิ้นคือเท่าใด และเข้าใกล้ค่าใด

  1. ต้นทุนรวม \(5000 + 20x\) ต้นทุนเฉลี่ย \(\bar C(x) = \dfrac{5000 + 20x}{x} = 20 + \dfrac{5000}{x}\)

  2. เส้นกำกับแนวนอน \(y = 20\) แปลว่าผลิตมากเท่าไรต้นทุนเฉลี่ยก็ไม่ต่ำกว่า 20 บาท

  3. ที่ 1,000 ชิ้น ต้นทุนเฉลี่ย \(20 + 5 = 25\) บาท

\(\bar C(x) = 20 + \tfrac{5000}{x}\) เข้าใกล้ 20 บาทต่อชิ้น

กับดักที่พบบ่อยหาเส้นกำกับแนวดิ่งจากตัวส่วนก่อนตัดตัวร่วม ทำให้นับจุดเว้นเป็นเส้นกำกับ และตอบว่าเส้นกำกับแนวนอนคือ “ไม่มี” ทุกครั้งที่ดีกรีเศษมากกว่า โดยลืมหาเส้นกำกับแนวเฉียง

ฝึกทำ (มีเฉลย)

1เส้นกำกับของ \(f(x) = \dfrac{3x + 1}{x - 4}\)

VA จากตัวส่วน · ดีกรีเท่ากัน

\(x = 4\), \(y = 3\)

2จุดเว้นของ \(f(x) = \dfrac{x^2 - 9}{x - 3}\)

\(f(x) = x + 3,\ x \ne 3\)

\((3, 6)\) และไม่มีเส้นกำกับ (กราฟคือเส้นตรงที่ขาดจุดเดียว)

3เส้นกำกับแนวนอนของ \(\dfrac{5x^2}{2x^3 + 1}\)

ดีกรีเศษน้อยกว่า

\(y = 0\)

4เส้นกำกับแนวเฉียงของ \(\dfrac{2x^2 + 3x - 1}{x + 2}\)

หารสังเคราะห์ด้วย c = −2: 2 | −1 | เศษ 1 ⇒ \(2x - 1 + \tfrac{1}{x + 2}\)

\(y = 2x - 1\)

5แก้ \(\dfrac{x + 4}{x - 1} > 0\)

จุดแบ่ง −4, 1 · ช่วงนอกเป็นบวก

\(x < -4\) หรือ \(x > 1\)

6เขียนฟังก์ชันตรรกยะที่มี VA \(x = 2\), HA \(y = -1\) และผ่านจุดกำเนิด

รูป \(\tfrac{a}{x - 2} - 1\) แทน (0, 0): \(-\tfrac a2 - 1 = 0 \Rightarrow a = -2\)

\(f(x) = -\dfrac{2}{x - 2} - 1 = \dfrac{-x}{x - 2}\)
