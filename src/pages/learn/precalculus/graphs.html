// บทที่ 27.3 · พรีแคลคูลัส · Graphs & Transformations

กราฟของฟังก์ชันและการแปลงกราฟ: เลื่อน ยืด หด สะท้อน สมมาตร ฟังก์ชันคู่-คี่ และเส้นตรง

ถ้าจำหน้าตากราฟต้นแบบได้สิบแบบ และเข้าใจว่าตัวเลข a, b, h, k ในสมการ \(y = a\,f\big(b(x - h)\big) + k\) ทำอะไรกับกราฟ ก็จะวาดกราฟของฟังก์ชันได้อีกหลายร้อยแบบโดยไม่ต้องจุดจุดทีละจุด หน้านี้เริ่มจากการอ่านกราฟให้ได้ข้อมูลครบ ทบทวนเส้นตรงและวงกลมซึ่งเป็นกราฟที่ใช้บ่อยที่สุด แล้วจึงไล่การเลื่อน การยืด-หด และการสะท้อนทีละขั้น พร้อมแล็บที่ลากสไลเดอร์แล้วเห็นจุดบนกราฟย้ายที่จริง ๆ

เขียนโดย อาจารย์มดอัปเดต
แล็บแปลงกราฟ เส้นตรง กราฟต้นแบบ การแปลง คู่ · คี่
สรุปใน 30 วินาที
  • \(f(x) + k\) ขึ้น k · \(f(x - h)\) ขวา h · \(a f(x)\) ยืดแนวตั้ง a เท่า · \(f(bx)\) หดแนวนอน 1/b เท่า
  • \(-f(x)\) สะท้อนแกน x · \(f(-x)\) สะท้อนแกน y
  • จุด \((x, y)\) ของกราฟต้นแบบไปอยู่ที่ \(\left(\tfrac{x}{b} + h,\ a y + k\right)\)
  • คู่: \(f(-x) = f(x)\) สมมาตรแกน y · คี่: \(f(-x) = -f(x)\) สมมาตรจุดกำเนิด
  • ขนาน: \(m_1 = m_2\) · ตั้งฉาก: \(m_1 m_2 = -1\)

อ่านกราฟให้ได้ข้อมูลครบ

กราฟหนึ่งรูปตอบคำถามได้หลายข้อพร้อมกัน: โดเมนคือเงาของกราฟที่ตกลงบนแกน x เรนจ์คือเงาบนแกน y จุดตัดแกน x คือคำตอบของสมการ \(f(x) = 0\) จุดตัดแกน y คือ \(f(0)\) ช่วงที่กราฟไต่ขึ้นเมื่ออ่านจากซ้ายไปขวาคือช่วงที่ฟังก์ชันเพิ่ม และจุดสูงสุดหรือต่ำสุดเฉพาะที่คือตำแหน่งที่กราฟเปลี่ยนจากขึ้นเป็นลงหรือลงเป็นขึ้น ทักษะนี้สำคัญกว่าการคำนวณ เพราะในแคลคูลัสเราจะใช้อนุพันธ์หาจุดเหล่านี้ และต้องรู้ก่อนว่ากำลังหาอะไรบนกราฟ

G1 Reading a graph อ่านกราฟ

\[ x\text{-int}: f(x) = 0,\quad y\text{-int}: (0, f(0)),\quad x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\ \text{(เพิ่ม)} \]

เส้นตรง ความชัน และวงกลม

ความชัน (slope) คืออัตราส่วนระหว่างการขึ้นลงกับการเดินไปทางขวา \(m = \Delta y/\Delta x\) ซึ่งก็คืออัตราการเปลี่ยนแปลงเฉลี่ยที่คงที่ทุกช่วงของเส้นตรง สมการเส้นตรงมีหลายรูป แต่ละรูปเหมาะกับข้อมูลที่โจทย์ให้มาต่างกัน ถ้ารู้ความชันกับจุดหนึ่งจุดให้ใช้รูปจุด-ความชัน ถ้าต้องการอ่านจุดตัดแกน y ให้ใช้รูป \(y = mx + c\) วงกลมเป็นตัวอย่างของกราฟที่ไม่ใช่ฟังก์ชัน แต่ใช้บ่อยในเรขาคณิตวิเคราะห์และในวงกลมหนึ่งหน่วยของตรีโกณมิติ

G2 Lines เส้นตรง

\[ m = \frac{y_2 - y_1}{x_2 - x_1},\quad y - y_1 = m(x - x_1),\quad y = mx + c,\quad Ax + By = C \]

G3 Parallel & perpendicular ขนาน · ตั้งฉาก

\[ \ell_1 \parallel \ell_2 \iff m_1 = m_2,\qquad \ell_1 \perp \ell_2 \iff m_1 m_2 = -1 \]

G4 Distance & midpoint ระยะ · จุดกึ่งกลาง

\[ d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2},\quad M = \left(\tfrac{x_1 + x_2}{2},\ \tfrac{y_1 + y_2}{2}\right) \]

G5 Circle วงกลม

\[ (x - h)^2 + (y - k)^2 = r^2 \]

รูปกระจาย \(x^2 + y^2 + Dx + Ey + F = 0\) ทำเป็นกำลังสองสมบูรณ์ทั้ง x และ y

ตัวอย่าง G-1 · เส้นตั้งฉาก

หาสมการเส้นตรงผ่าน \((2, -1)\) และตั้งฉากกับ \(3x - 4y = 12\)

  1. เขียนเส้นที่ให้มาเป็น \(y = \tfrac34 x - 3\) ความชัน \(m_1 = \tfrac34\)

  2. ตั้งฉาก: \(m_2 = -\tfrac43\) (G3)

  3. รูปจุด-ความชัน: \(y + 1 = -\tfrac43(x - 2) \Rightarrow y = -\tfrac43 x + \tfrac53\)

\(y = -\tfrac43x + \tfrac53\) หรือ \(4x + 3y = 5\) (ตรวจ: \(4(2) + 3(-1) = 5\))

ตัวอย่าง G-2 · วงกลมจากรูปกระจาย

หาจุดศูนย์กลางและรัศมีของ \(x^2 + y^2 - 6x + 4y - 12 = 0\)

  1. จัดกลุ่ม: \((x^2 - 6x) + (y^2 + 4y) = 12\)

  2. เติมกำลังสองสมบูรณ์: \((x^2 - 6x + 9) + (y^2 + 4y + 4) = 12 + 9 + 4\)

  3. ได้ \((x - 3)^2 + (y + 2)^2 = 25\)

จุดศูนย์กลาง \((3, -2)\) รัศมี 5

กราฟฟังก์ชันต้นแบบที่ต้องจำหน้าตาได้

การเลื่อน ยืด หด และสะท้อน (Transformations)

การแปลงแบ่งเป็นสองพวก พวกที่ทำ “นอกฟังก์ชัน” คือ a และ k ทำกับค่า y โดยตรงจึงเปลี่ยนกราฟในแนวตั้งตามที่ตาคาดไว้ ส่วนพวกที่ทำ “ในฟังก์ชัน” คือ b และ h ทำกับ x ก่อนส่งเข้า f จึงเปลี่ยนกราฟในแนวนอนแบบกลับด้าน: ลบ h แต่ไปทางขวา คูณ b แต่กราฟหดลง เหตุผลคือกราฟใหม่ต้องรอให้ \(b(x - h)\) มีค่าเท่ากับ x เดิมก่อนจึงจะได้ค่า y เดิม

G6 Shifts การเลื่อน

\[ y = f(x) + k\ \ (\uparrow k),\qquad y = f(x - h)\ \ (\rightarrow h) \]

G7 Stretches การยืด-หด

\[ y = a f(x):\ \text{ยืดแนวตั้ง } |a| \text{ เท่า},\qquad y = f(bx):\ \text{หดแนวนอน } \tfrac{1}{|b|} \text{ เท่า} \]

G8 Reflections การสะท้อน

\[ y = -f(x):\ \text{สะท้อนแกน } x,\qquad y = f(-x):\ \text{สะท้อนแกน } y \]

G9 Combined รวมทุกการแปลง

\[ y = a\,f\big(b(x - h)\big) + k:\qquad (x,\ y) \ \longmapsto\ \left(\frac{x}{b} + h,\ \ a y + k\right) \]

ถ้าเจอ \(f(bx - c)\) ให้ดึง b ออกก่อน: \(f\big(b(x - \tfrac{c}{b})\big)\) จึงเลื่อน \(\tfrac{c}{b}\) ไม่ใช่ c

ตัวอย่าง G-3 · บรรยายการแปลง

บรรยายการแปลงจาก \(y = \sqrt x\) ไป \(y = -2\sqrt{x + 3} + 1\) พร้อมจุด โดเมน และเรนจ์

  1. เทียบกับ G9: \(a = -2,\ b = 1,\ h = -3,\ k = 1\)

  2. ลำดับ: เลื่อนซ้าย 3 → ยืดแนวตั้ง 2 เท่า → สะท้อนแกน x → เลื่อนขึ้น 1

  3. ย้ายจุด \((x, y) \mapsto (x - 3,\ -2y + 1)\): \((0, 0) \mapsto (-3, 1)\), \((1, 1) \mapsto (-2, -1)\), \((4, 2) \mapsto (1, -3)\)

  4. โดเมนเริ่มที่ −3 · เรนจ์กลับหัวจากจุดเริ่ม \(y = 1\) ลงไป

โดเมน \([-3, \infty)\) เรนจ์ \((-\infty, 1]\)

ตัวอย่าง G-4 · กับดักการหดแนวนอน

กราฟ \(y = |2x - 4|\) ได้จาก \(y = |x|\) อย่างไร จุดยอดอยู่ที่ใด

  1. ดึง 2 ออก: \(|2x - 4| = |2(x - 2)|\) จึง \(b = 2,\ h = 2\)

  2. หดแนวนอนเหลือครึ่งหนึ่ง แล้วเลื่อนขวา 2 (ไม่ใช่ 4)

  3. จุดยอด \((0, 0) \mapsto (0/2 + 2,\ 0) = (2, 0)\) ตรวจ: \(|2(2) - 4| = 0\)

จุดยอด \((2, 0)\) และกราฟชันขึ้นเป็นสองเท่า (เพราะ \(|2(x-2)| = 2|x - 2|\))

ตัวอย่าง G-5 · ย้ายจุดเดียว

จุด \((4, 1)\) อยู่บนกราฟ \(y = f(x)\) จุดใดต้องอยู่บนกราฟ \(y = f(2x) - 3\)

  1. \(b = 2,\ k = -3\): \((x, y) \mapsto (x/2,\ y - 3)\)

  2. ตรวจ: ที่ \(x = 2\) ได้ \(f(2\cdot2) - 3 = f(4) - 3 = 1 - 3 = -2\)

\((2, -2)\)

แล็บแปลงกราฟ: ลากแล้วดูจุดย้ายที่

จุดโปร่งสีเทาคือจุดสำคัญของกราฟต้นแบบ จุดทึบสีส้มคือตำแหน่งใหม่ของจุดเดียวกัน ตารางใต้กราฟบอกพิกัดก่อนและหลัง ลองตั้ง b เป็นลบเพื่อดูการสะท้อนแกน y และเลือกฟังก์ชัน 1/x, 2ˣ หรือ log₂x เพื่อดูว่าเส้นกำกับย้ายตาม h และ k อย่างไร

กับดักที่พบบ่อย(1) อ่าน \(f(x + 3)\) ว่าเลื่อนขวา 3 · (2) อ่าน \(f(2x - 4)\) ว่าเลื่อน 4 ทั้งที่ต้องดึง 2 ออกก่อนจึงเลื่อน 2 · (3) ทำการเลื่อนแนวตั้งก่อนการยืด เช่นใน \(2f(x) + 1\) ถ้าเลื่อนก่อนแล้วค่อยยืดจะได้ \(2(f(x) + 1) = 2f(x) + 2\) ซึ่งเป็นคนละกราฟ

สมมาตร ฟังก์ชันคู่ และฟังก์ชันคี่

การรู้ว่ากราฟสมมาตรช่วยลดงานไปครึ่งหนึ่ง เพราะวาดครึ่งขวาแล้วสะท้อนได้เลย ในแคลคูลัส สมมาตรยังช่วยคำนวณอินทิกรัลบนช่วงสมมาตรได้ทันที เช่นอินทิกรัลของฟังก์ชันคี่จาก −a ถึง a เท่ากับศูนย์ การตรวจทำได้ด้วยการแทน x ด้วย −x แล้วเทียบกับสูตรเดิม

G10 Even & odd ฟังก์ชันคู่-คี่

\[ \text{คู่: } f(-x) = f(x)\ \ \text{(แกน } y\text{)},\qquad \text{คี่: } f(-x) = -f(x)\ \ \text{(จุดกำเนิด)} \]

คู่ × คู่ = คู่ · คี่ × คี่ = คู่ · คู่ × คี่ = คี่ · ฟังก์ชันคี่ที่นิยามที่ 0 ต้องผ่าน (0, 0)

G11 Symmetry tests ทดสอบสมมาตรของสมการ

\[ y \to -y:\ \text{แกน } x,\quad x \to -x:\ \text{แกน } y,\quad (x, y) \to (-x, -y):\ \text{จุดกำเนิด} \]
ตัวอย่าง G-6 · คู่ คี่ หรือไม่ใช่ทั้งสอง

ตรวจ \(f(x) = x^4 - 3x^2\), \(g(x) = x^3 + x\), \(h(x) = x^2 + x\)

  1. \(f(-x) = x^4 - 3x^2 = f(x)\) จึงเป็นฟังก์ชันคู่

  2. \(g(-x) = -x^3 - x = -g(x)\) จึงเป็นฟังก์ชันคี่

  3. \(h(-x) = x^2 - x\) ไม่เท่ากับ \(h(x)\) และไม่เท่ากับ \(-h(x) = -x^2 - x\)
