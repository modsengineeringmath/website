// บทที่ 27.2 · พรีแคลคูลัส · Functions

ฟังก์ชันในพรีแคลคูลัส: ความสัมพันธ์ โดเมน เรนจ์ สัญกรณ์ f(x) การดำเนินการ และฟังก์ชันประกอบ

ฟังก์ชันคือกฎที่รับค่าเข้าหนึ่งค่าแล้วให้ค่าออกหนึ่งค่าเสมอ เหมือนตู้กดน้ำที่กดปุ่มเดิมกี่ครั้งก็ได้เครื่องดื่มเดิม ถ้าวันหนึ่งกดปุ่มเดียวกันแล้วได้สองแบบ ตู้นั้นจะไม่ใช่ฟังก์ชันอีกต่อไป หน้านี้วางรากฐานที่ทุกหน้าต่อจากนี้ใช้ ได้แก่ การอ่านสัญกรณ์ \(f(x)\) การหาว่าใส่ค่าอะไรเข้าไปได้บ้าง (โดเมน) และได้ค่าอะไรออกมาบ้าง (เรนจ์) การรวมฟังก์ชันเข้าด้วยกัน และการต่อฟังก์ชันเป็นสายด้วยฟังก์ชันประกอบ ท้ายหน้ามีอัตราการเปลี่ยนแปลงเฉลี่ยซึ่งเป็นประตูไปสู่อนุพันธ์

เขียนโดย อาจารย์มดอัปเดต
แล็บฟังก์ชัน หาโดเมน หาเรนจ์ ฟังก์ชันประกอบ อัตราการเปลี่ยนแปลง
สรุปใน 30 วินาที
  • ฟังก์ชัน: x หนึ่งค่าได้ y ค่าเดียว · กราฟผ่านการทดสอบเส้นแนวตั้ง
  • โดเมนตัดค่าที่ทำให้ตัวส่วนเป็นศูนย์ รากคู่ติดลบ และ log ไม่เป็นบวก
  • เรนจ์: แก้หา x ในรูปของ y หรือใช้จุดยอดและกราฟ
  • \((f \circ g)(x) = f(g(x))\) ทำ g ก่อน · โดยทั่วไป \(f \circ g \ne g \circ f\)
  • อัตราการเปลี่ยนแปลงเฉลี่ย = ความชันเส้นตัดโค้ง \(\dfrac{f(b) - f(a)}{b - a}\)

ฟังก์ชันคืออะไร: ความสัมพันธ์ที่ x หนึ่งค่าให้ y ค่าเดียว

ในทางคณิตศาสตร์ ความสัมพันธ์คือเซตของคู่อันดับ \((x, y)\) เช่น {(1, 2), (2, 4), (3, 6)} ความสัมพันธ์จะเป็นฟังก์ชันก็ต่อเมื่อไม่มี x ตัวไหนจับคู่กับ y สองค่า บนกราฟ เงื่อนไขนี้ตรวจได้ด้วยการลากเส้นแนวตั้ง ถ้าเส้นแนวตั้งเส้นใดตัดกราฟมากกว่าหนึ่งจุด แสดงว่ามี x ค่าหนึ่งที่ให้ y มากกว่าหนึ่งค่า วงกลม \(x^2 + y^2 = 25\) จึงไม่เป็นฟังก์ชันของ x แต่ครึ่งบน \(y = \sqrt{25 - x^2}\) เป็นฟังก์ชัน สัญกรณ์ \(f(x)\) อ่านว่า “f ของ x” หมายถึงค่าที่ได้เมื่อใส่ x เข้าไปในกฎ f ไม่ใช่ f คูณ x

F1 Function นิยามฟังก์ชัน

\[ f: A \to B,\qquad (x, y_1) \in f \ \text{และ}\ (x, y_2) \in f \ \Rightarrow\ y_1 = y_2 \]

A คือโดเมน · ค่าที่ได้จริงทั้งหมด \(\{f(x) : x \in A\}\) คือเรนจ์

F2 Function notation การแทนค่า

\[ f(x) = x^2 - 3x \ \Rightarrow\ f(a + 1) = (a + 1)^2 - 3(a + 1) = a^2 - a - 2 \]

แทนทั้งก้อนลงในทุกตำแหน่งของ x เสมอ และใส่วงเล็บไว้ก่อน

วิธีหาโดเมน (Domain)

ถ้าโจทย์ไม่ได้กำหนดโดเมนมาให้ ให้ถือว่าโดเมนคือจำนวนจริงทุกตัวที่ทำให้สูตรคำนวณได้เป็นจำนวนจริง ในระดับนี้มีเพียงสามสาเหตุที่ทำให้คำนวณไม่ได้ ไล่ตรวจทีละข้อแล้วนำเงื่อนไขมาซ้อนกัน คำตอบเขียนเป็นช่วง (interval) จะอ่านง่ายที่สุด

F3 Domain rules กฎหาโดเมน

\[ \frac{p(x)}{q(x)}:\ q(x) \ne 0,\qquad \sqrt{u(x)}:\ u(x) \ge 0,\qquad \log u(x):\ u(x) > 0 \]

ถ้ามีหลายเงื่อนไข ให้หาอินเตอร์เซกชัน · \(\sqrt{u}\) อยู่ในตัวส่วน ต้องใช้ \(u > 0\)

ตัวอย่าง F-1 · โดเมนที่มีรากและตัวส่วน

หาโดเมนของ \(f(x) = \dfrac{\sqrt{x + 2}}{x - 3}\)

  1. รากที่สอง: \(x + 2 \ge 0 \Rightarrow x \ge -2\)

  2. ตัวส่วน: \(x - 3 \ne 0 \Rightarrow x \ne 3\)

  3. รวมเงื่อนไข: ทุก \(x \ge -2\) ยกเว้น 3

\(D_f = [-2,\ 3) \cup (3,\ \infty)\)

ตัวอย่าง F-2 · โดเมนของลอการิทึม

หาโดเมนของ \(g(x) = \log\left(4 - x^2\right)\)

  1. สิ่งที่อยู่ใน log ต้องเป็นบวก: \(4 - x^2 > 0 \Rightarrow x^2 < 4\)

  2. \((2 - x)(2 + x) > 0\) เป็นจริงเมื่อ \(-2 < x < 2\) (ดู A11)

\(D_g = (-2,\ 2)\)

วิธีหาเรนจ์ (Range)

เรนจ์ยากกว่าโดเมนเพราะต้องถามย้อนกลับว่า “y ค่าไหนบ้างที่มี x มาส่งให้” วิธีที่ใช้บ่อยมีสามวิธี: (1) แก้สมการ \(y = f(x)\) หา x ในรูปของ y แล้วดูว่า y ใดทำให้ x หาได้ (2) สำหรับกำลังสอง ใช้จุดยอด (3) ใช้กราฟที่รู้จัก เช่น \(\sqrt{x} \ge 0\) และ \(b^x > 0\) แล้วแปลงตามการเลื่อนและยืด

F4 Finding the range วิธีหาเรนจ์

\[ y = f(x) \ \Rightarrow\ x = g(y) \ \Rightarrow\ R_f = \{\,y : g(y) \text{ นิยามและอยู่ใน } D_f\,\} \]

กำลังสอง \(a(x - h)^2 + k\): \(a > 0\) ได้ \([k, \infty)\) · \(a < 0\) ได้ \((-\infty, k]\)

ตัวอย่าง F-3 · เรนจ์สองแบบ

หาเรนจ์ของ (ก) \(f(x) = x^2 - 4x + 7\) (ข) \(h(x) = \dfrac{2x}{x + 1}\)

  1. (ก) ทำเป็นกำลังสองสมบูรณ์: \(x^2 - 4x + 4 + 3 = (x - 2)^2 + 3\) ค่าน้อยที่สุดคือ 3 ที่ x = 2

  2. (ข) ให้ \(y = \dfrac{2x}{x + 1}\) คูณไขว้: \(y(x + 1) = 2x \Rightarrow x(y - 2) = -y \Rightarrow x = \dfrac{y}{2 - y}\)

  3. x หาได้ทุกกรณียกเว้น \(y = 2\) (ตัวส่วนเป็นศูนย์) และไม่มี y ใดทำให้ x = −1 จึงไม่ต้องตัดเพิ่ม

(ก) \([3,\ \infty)\) · (ข) \(\mathbb{R} \setminus \{2\}\) ซึ่งตรงกับเส้นกำกับแนวนอน \(y = 2\) ในหน้า ฟังก์ชันตรรกยะ

ฟังก์ชันเป็นช่วง (Piecewise Functions)

ฟังก์ชันเป็นช่วงใช้สูตรต่างกันในแต่ละช่วงของ x พบได้ในชีวิตจริงบ่อยมาก เช่น ค่าไฟฟ้าแบบขั้นบันได ค่าส่งพัสดุตามน้ำหนัก หรือภาษีเงินได้ เวลาแทนค่าต้องดูก่อนเสมอว่า x อยู่ช่วงไหน และระวังเครื่องหมาย < กับ ≤ ที่จุดรอยต่อ ค่าสัมบูรณ์ \(|x|\) และฟังก์ชันจำนวนเต็มมากสุด \(\lfloor x \rfloor\) ก็เป็นฟังก์ชันเป็นช่วงเช่นกัน

F5 Piecewise & floor ฟังก์ชันเป็นช่วง

\[ f(x) = \begin{cases} f_1(x), & x < c \\ f_2(x), & x \ge c \end{cases}\qquad \lfloor x \rfloor = \max\{n \in \mathbb Z : n \le x\} \]

\(\lfloor 2.7 \rfloor = 2\) · \(\lfloor -2.7 \rfloor = -3\) (ไม่ใช่ −2)

ตัวอย่าง F-4 · แทนค่าฟังก์ชันเป็นช่วง

\(f(x) = \begin{cases} x^2, & x < 1 \\ 2x - 1, & 1 \le x \le 3 \\ 5, & x > 3 \end{cases}\) จงหา \(f(-2), f(1), f(3), f(4)\) และบอกว่ากราฟต่อกันที่รอยต่อหรือไม่

  1. \(f(-2)\): −2 < 1 ใช้ \(x^2\) ได้ 4 · \(f(1)\): ใช้บรรทัดที่สอง ได้ \(2(1) - 1 = 1\)

  2. \(f(3) = 2(3) - 1 = 5\) · \(f(4) = 5\)

  3. รอยต่อ x = 1: ด้านซ้ายเข้าใกล้ \(1^2 = 1\) เท่ากับ \(f(1)\) · รอยต่อ x = 3: ด้านขวาเป็น 5 เท่ากับ \(f(3)\) กราฟจึงต่อกันทั้งสองจุด

\(4,\ 1,\ 5,\ 5\) และต่อเนื่องทั้งสองรอยต่อ (หัวข้อความต่อเนื่องอยู่ใน บทลิมิต)

การบวก ลบ คูณ หารฟังก์ชัน (Operations)

ฟังก์ชันสองตัวรวมกันได้ด้วยการบวก ลบ คูณ หารค่าที่จุดเดียวกัน ข้อที่ต้องระวังคือโดเมน เพราะผลลัพธ์จะคำนวณได้ก็ต่อเมื่อทั้ง f และ g คำนวณได้ที่ x นั้น ส่วนการหารต้องตัดจุดที่ g เป็นศูนย์ออกเพิ่ม แม้สูตรที่จัดรูปแล้วจะดูเหมือนไม่มีตัวส่วนก็ตาม

F6 Operations พีชคณิตของฟังก์ชัน

\[ (f \pm g)(x) = f(x) \pm g(x),\quad (fg)(x) = f(x)g(x),\quad \left(\tfrac{f}{g}\right)(x) = \tfrac{f(x)}{g(x)} \]

โดเมน \(= D_f \cap D_g\) และสำหรับ \(f/g\) ตัด \(\{x : g(x) = 0\}\) ออก

ฟังก์ชันประกอบ (Composite Functions)

ฟังก์ชันประกอบคือการต่อเครื่องจักรสองเครื่อง ผลผลิตของเครื่องแรกกลายเป็นวัตถุดิบของเครื่องที่สอง \((f \circ g)(x)\) อ่านว่า “f ประกอบ g” และหมายถึง \(f(g(x))\) คือทำ g ก่อนแล้วจึงทำ f แม้สัญลักษณ์จะเขียน f ไว้หน้า การหาโดเมนของฟังก์ชันประกอบต้องดูสองชั้น: x ต้องเข้า g ได้ และค่า g(x) ที่ออกมาต้องเข้า f ได้ การจัดรูปสูตรจนเรียบร้อยอาจทำให้เงื่อนไขชั้นแรกหายไปจากสายตา ซึ่งเป็นจุดที่ข้อสอบชอบหลอก

F7 Composition ฟังก์ชันประกอบ

\[ (f \circ g)(x) = f\big(g(x)\big),\qquad D_{f\circ g} = \{\,x \in D_g : g(x) \in D_f\,\} \]

โดยทั่วไป \(f \circ g \ne g \circ f\) · แต่ \((f \circ g) \circ h = f \circ (g \circ h)\) เสมอ

ตัวอย่าง F-5 · f∘g และ g∘f

ให้ \(f(x) = \sqrt{x + 2}\) และ \(g(x) = x^2 - 1\) จงหา \(f \circ g\), \(g \circ f\) พร้อมโดเมน

  1. \((f \circ g)(x) = f(x^2 - 1) = \sqrt{x^2 - 1 + 2} = \sqrt{x^2 + 1}\) ซึ่ง \(x^2 + 1 > 0\) เสมอ โดเมนจึงเป็น \(\mathbb R\)

  2. \((g \circ f)(x) = g\big(\sqrt{x + 2}\big) = \left(\sqrt{x + 2}\right)^2 - 1 = x + 1\)

  3. แต่ x ต้องเข้า f ได้ก่อน จึงต้องมี \(x \ge -2\) แม้สูตร \(x + 1\) จะคำนวณได้ทุก x

\(f \circ g = \sqrt{x^2 + 1},\ x \in \mathbb R\) · \(g \circ f = x + 1,\ x \ge -2\)

ตัวอย่าง F-6 · แยกฟังก์ชันประกอบ

เขียน \(H(x) = (3x - 1)^5\) ในรูป \(f(g(x))\)

  1. มองหา “สิ่งที่ทำก่อน” คือ \(3x - 1\) ตั้งเป็น \(g(x) = 3x - 1\)

  2. สิ่งที่ทำทีหลังคือยกกำลังห้า: \(f(x) = x^5\)

\(g(x) = 3x - 1,\ f(x) = x^5\) — การมองแบบนี้คือหัวใจของกฎลูกโซ่ใน บทอนุพันธ์

อัตราการเปลี่ยนแปลงเฉลี่ยและผลหารเชิงผลต่าง

อัตราการเปลี่ยนแปลงเฉลี่ยบอกว่าเมื่อ x เปลี่ยนไปหนึ่งหน่วย y เปลี่ยนไปโดยเฉลี่ยเท่าใด ถ้า f คือระยะทางตามเวลา ค่านี้ก็คือความเร็วเฉลี่ย ในเชิงกราฟคือความชันของเส้นตรงที่ลากผ่านสองจุด (เส้นตัดโค้ง) ผลหารเชิงผลต่างคือสูตรเดียวกันที่เขียนด้วยระยะห่าง h ซึ่งจะกลายเป็นนิยามของอนุพันธ์เมื่อให้ h เข้าใกล้ศูนย์

F8 Average rate of change อัตราการเปลี่ยนแปลงเฉลี่ย

\[ \frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a} \]

F9 Difference quotient ผลหารเชิงผลต่าง

\[ \frac{f(x + h) - f(x)}{h},\quad h \ne 0 \ \xrightarrow{\ h \to 0\ }\ f'(x) \]
ตัวอย่าง F-7 · ผลหารเชิงผลต่าง

หาผลหารเชิงผลต่างของ \(f(x) = x^2 - 3x\) และอัตราการเปลี่ยนแปลงเฉลี่ยของ \(\sqrt{x + 2}\) จาก x = −1 ถึง x = 2

  1. \(f(x + h) = x^2 + 2xh + h^2 - 3x - 3h\) ลบด้วย \(f(x)\) เหลือ \(2xh + h^2 - 3h\)

  2. หารด้วย h: \(2x + h - 3\) (เมื่อ h → 0 จะได้ \(2x - 3\) ซึ่งคืออนุพันธ์)

  3. \(\sqrt{-1 + 2} = 1\), \(\sqrt{2 + 2} = 2\) ได้ \(\dfrac{2 - 1}{2 - (-1)} = \dfrac13\)

\(2x + h - 3\) · \(\tfrac13\)

แล็บฟังก์ชัน: พิมพ์ f และ g แล้วดูผล

พิมพ์ฟังก์ชันด้วยรูปแบบที่คุ้นเคย เช่น 2x^2-3, 1/(x-1), sqrt(4-x^2), |x| หรือ log(x) (ฐาน 10) แล้วเลือกว่าจะวาด f, g, ผลบวก ผลคูณ หรือฟังก์ชันประกอบ ช่วงที่ระบายสีเทาคือค่าของ x ที่ฟังก์ชันไม่นิยาม ซึ่งช่วยตรวจคำตอบเรื่องโดเมนได้ทันที เลื่อน x₁ และ x₂ เพื่อดูเส้นตัดโค้งและอัตราการเปลี่ยนแปลงเฉลี่ย

กับดักที่พบบ่อยหาโดเมนของ \(g \circ f\) จากสูตรสุดท้ายอย่างเดียว เช่นในตัวอย่าง F-5 ได้สูตร \(x + 1\) แล้วตอบว่าโดเมนคือจำนวนจริงทั้งหมด ซึ่งผิด เพราะ x ต้องผ่าน \(\sqrt{x + 2}\) ก่อน อีกข้อคือเขียน \(f(x + h) = f(x) + h\) ซึ่งจริงเฉพาะฟังก์ชันบางตัวเท่านั้น

ฝึกทำ (มีเฉลย)

1{(1, 2), (2, 3), (1, 4)} เป็นฟังก์ชันหรือไม่

x = 1 คู่กับทั้ง 2 และ 4

ไม่เป็นฟังก์ชัน

รากอยู่ในตัวส่วน ต้องเป็นบวกแท้: \(5 - x > 0\)

\((-\infty,\ 5)\)

\(\sqrt{x - 1} \ge 0\) จึง \(f(x) \le 3\)

\((-\infty,\ 3]\)

\(f(9) = 19\) · \(g(7) = 49\)

19 และ 49

5ถ้า \(f(x) = 3x - 2\) และ \(f(g(x)) = 6x + 7\) จงหา \(g(x)\)

\(3g(x) - 2 = 6x + 7 \Rightarrow g(x) = 2x + 3\)

\(g(x) = 2x + 3\)
