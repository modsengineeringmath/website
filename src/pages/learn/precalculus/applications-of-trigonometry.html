// บทที่ 27.10 · พรีแคลคูลัส · Applications of Trigonometry

การประยุกต์ของฟังก์ชันตรีโกณมิติ: กฎของไซน์ กฎของโคไซน์ พื้นที่สามเหลี่ยม มุมก้ม-มุมเงย ทิศ และสมการตรีโกณมิติ

ช่างสำรวจที่วัดความกว้างของแม่น้ำโดยไม่ต้องข้าม วิศวกรที่หาแรงลัพธ์ของสายเคเบิลสองเส้น และนักเดินเรือที่บอกตำแหน่งจากทิศกับระยะทาง ล้วนใช้เครื่องมือชุดเดียวกัน คือการแก้สามเหลี่ยมจากข้อมูลบางส่วน หน้านี้เริ่มจากสามเหลี่ยมมุมฉากกับมุมก้ม-มุมเงย ขยายไปสามเหลี่ยมใด ๆ ด้วยกฎของไซน์และโคไซน์ รวมถึงกรณีกำกวมที่ข้อสอบชอบออก แล้วจบด้วยการแก้สมการตรีโกณมิติและการรวมคลื่นไซน์สองคลื่นเป็นคลื่นเดียว มีเครื่องแก้สามเหลี่ยมที่วาดรูปให้ทั้งกรณีที่ได้สองคำตอบ

เขียนโดย อาจารย์มดอัปเดต
เครื่องแก้สามเหลี่ยม มุมก้ม-มุมเงย กฎของไซน์ กฎของโคไซน์ สมการตรีโกณ
สรุปใน 30 วินาที
  • กฎของไซน์ \(\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R\) ใช้เมื่อรู้คู่ด้าน-มุมตรงข้าม
  • กฎของโคไซน์ \(c^2 = a^2 + b^2 - 2ab\cos C\) ใช้กับ SSS และ SAS
  • SSA อาจได้ 0, 1 หรือ 2 สามเหลี่ยม: เทียบ a กับ \(h = b\sin A\)
  • พื้นที่ \(\tfrac12 ab\sin C\) · เฮรอน \(\sqrt{s(s-a)(s-b)(s-c)}\)
  • \(a\sin x + b\cos x = R\sin(x + \varphi)\), \(R = \sqrt{a^2 + b^2}\)

สามเหลี่ยมมุมฉาก มุมเงย และมุมก้ม

โจทย์มุมเงยและมุมก้มทุกข้อลดเหลือสามเหลี่ยมมุมฉากเมื่อวาดรูปให้ถูก หลักสำคัญคือวัดมุมจากแนวระดับ และสังเกตว่ามุมก้มจากจุดสูงกับมุมเงยจากจุดต่ำเป็นมุมแย้งของเส้นขนาน จึงเท่ากัน จากนั้นเลือกฟังก์ชันที่เชื่อมด้านที่รู้กับด้านที่ต้องการ ส่วนใหญ่เป็น tan เพราะโจทย์มักรู้ระยะแนวราบและต้องการความสูง

K1 Elevation & depression มุมเงย · มุมก้ม

\[ h = d\tan\theta,\qquad d = \frac{h}{\tan\theta},\qquad \text{มุมก้ม} = \text{มุมเงย (มุมแย้ง)} \]
ตัวอย่าง K-1 · มุมเงย

ยืนห่างตึก 50 m มองยอดตึกด้วยมุมเงย 32° (ระดับสายตาเท่าพื้น) ตึกสูงเท่าใด

  1. ด้านประชิดมุม 32° คือ 50 m ด้านตรงข้ามคือความสูง h ⇒ ใช้ tan

  2. \(h = 50\tan 32^\circ = 50(0.62487)\)

\(h \approx 31.24\) m (ถ้าตาสูง 1.6 m ให้บวกเพิ่มเป็น 32.84 m)

ตัวอย่าง K-2 · มุมก้ม

จากยอดประภาคารสูง 60 m เหนือระดับน้ำ มองเรือด้วยมุมก้ม 12° เรืออยู่ห่างฐานประภาคารเท่าใด

  1. มุมก้ม 12° เท่ากับมุมเงยจากเรือขึ้นไปยังยอด

  2. \(d = \dfrac{60}{\tan 12^\circ} = \dfrac{60}{0.21256}\)

\(d \approx 282.28\) m

กฎของไซน์และกรณีกำกวม

ลากความสูงจากจุดยอด C ลงมาที่ฐาน ความสูงนั้นเขียนได้สองแบบคือ \(b\sin A\) และ \(a\sin B\) เมื่อจับมาเท่ากันก็ได้กฎของไซน์ทันที กฎนี้ใช้ได้เมื่อรู้ด้านหนึ่งพร้อมมุมตรงข้ามของมัน ปัญหาเกิดในกรณี SSA เพราะการหามุมจาก \(\sin B = k\) ให้มุมแหลม B และมุมป้าน \(180^\circ - B\) ซึ่งอาจเป็นคำตอบได้ทั้งคู่ ภาพในเครื่องแก้สามเหลี่ยมด้านล่างแสดงให้เห็นว่าด้าน a ที่สั้นกว่า b สามารถ “แกว่ง” ไปแตะฐานได้สองตำแหน่ง

K2 Law of sines กฎของไซน์

\[ \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R \]

R คือรัศมีวงกลมล้อมรอบสามเหลี่ยม · ด้านยาวที่สุดอยู่ตรงข้ามมุมใหญ่ที่สุดเสมอ

K3 Ambiguous case (SSA, A แหลม) กรณีกำกวม

\[ h = b\sin A:\quad a < h:\ 0,\quad a = h:\ 1,\quad h < a < b:\ 2,\quad a \ge b:\ 1 \]

ถ้า A เป็นมุมป้านหรือมุมฉาก: \(a \le b\) ไม่มีสามเหลี่ยม · \(a > b\) ได้หนึ่งรูป

ตัวอย่าง K-3 · AAS

สามเหลี่ยม ABC มี \(A = 40^\circ,\ B = 60^\circ,\ a = 10\) จงหา b และ c

  1. \(C = 180^\circ - 40^\circ - 60^\circ = 80^\circ\)

  2. \(b = \dfrac{a\sin B}{\sin A} = \dfrac{10\sin60^\circ}{\sin40^\circ} = \dfrac{8.6603}{0.6428}\)

  3. \(c = \dfrac{10\sin80^\circ}{\sin40^\circ} = \dfrac{9.8481}{0.6428}\)

\(b \approx 13.47,\ c \approx 15.32\)

ตัวอย่าง K-4 · กรณีกำกวม SSA

\(a = 7,\ b = 10,\ A = 40^\circ\) มีสามเหลี่ยมกี่รูป หาด้าน c ทุกกรณี

  1. \(h = b\sin A = 10\sin40^\circ \approx 6.43\) และ \(h < a = 7 < b = 10\) ⇒ ได้สองรูป (K3)

  2. \(\sin B = \dfrac{10\sin40^\circ}{7} \approx 0.9183\) ⇒ \(B_1 \approx 66.67^\circ\) หรือ \(B_2 \approx 113.33^\circ\)

  3. \(C_1 \approx 73.33^\circ\), \(C_2 \approx 26.67^\circ\) · \(c = \dfrac{a\sin C}{\sin A}\)

สองรูป: \(c_1 \approx 10.43\) และ \(c_2 \approx 4.89\)

กฎของโคไซน์ พื้นที่ และสูตรเฮรอน

กฎของโคไซน์คือทฤษฎีบทพีทาโกรัสที่มีพจน์แก้ไขสำหรับมุมที่ไม่ใช่มุมฉาก ถ้า \(C = 90^\circ\) พจน์ \(-2ab\cos C\) หายไปและได้ \(c^2 = a^2 + b^2\) พจน์นี้เป็นลบเมื่อ C แหลม (ด้าน c สั้นลง) และเป็นบวกเมื่อ C ป้าน (ด้าน c ยาวขึ้น) การหามุมจากกฎของโคไซน์ไม่มีปัญหากำกวมเพราะ arccos ให้ค่าในช่วง 0° ถึง 180° พอดี

K4 Law of cosines กฎของโคไซน์

\[ c^2 = a^2 + b^2 - 2ab\cos C,\qquad \cos C = \frac{a^2 + b^2 - c^2}{2ab} \]

K5 Area พื้นที่สามเหลี่ยม

\[ \text{พื้นที่} = \tfrac12 ab\sin C = \sqrt{s(s - a)(s - b)(s - c)},\quad s = \tfrac{a + b + c}{2} \]
ตัวอย่าง K-5 · SAS วัดระยะข้ามบึง

จากจุด P วัดระยะถึงจุด A ได้ 8 km และถึงจุด B ได้ 11 km มุม APB เท่ากับ 52° ระยะ AB เท่าใด

  1. กฎของโคไซน์: \(AB^2 = 8^2 + 11^2 - 2(8)(11)\cos52^\circ\)

  2. \(= 64 + 121 - 176(0.61566) = 185 - 108.36 = 76.64\)

\(AB \approx 8.75\) km

ตัวอย่าง K-6 · SSS และเฮรอน

สามเหลี่ยมด้าน 7, 8, 9 จงหาพื้นที่และมุมที่ใหญ่ที่สุด

  1. \(s = \tfrac{7 + 8 + 9}{2} = 12\) · พื้นที่ \(= \sqrt{12\cdot5\cdot4\cdot3} = \sqrt{720} = 12\sqrt5\)

  2. มุมใหญ่สุดอยู่ตรงข้ามด้าน 9: \(\cos C = \dfrac{49 + 64 - 81}{2\cdot7\cdot8} = \dfrac{32}{112} = \dfrac27\)

พื้นที่ \(12\sqrt5 \approx 26.83\) · มุมใหญ่สุด \(\arccos\tfrac27 \approx 73.40^\circ\)

ทิศและแบริ่ง

ทิศในงานเดินเรือและสำรวจมีสองแบบ แบบแรกเขียนเป็น N30°E หมายถึงหันไปทางเหนือแล้วเบนไปทางตะวันออก 30° แบบที่สองเป็นแบริ่งสามหลัก วัดตามเข็มนาฬิกาจากทิศเหนือ เช่น 060° โจทย์ทิศเกือบทุกข้อจบด้วยการวาดเส้นทิศเหนือที่แต่ละจุด หามุมภายในสามเหลี่ยม แล้วใช้กฎของไซน์หรือโคไซน์

K6 Bearings แบริ่ง

\[ \text{แบริ่ง } \beta:\ (x, y) = (d\sin\beta,\ d\cos\beta)\ \ \text{(x ตะวันออก, y เหนือ)} \]
ตัวอย่าง K-7 · เรือสองช่วง

เรือแล่น 30 km ทางแบริ่ง 060° แล้วแล่นต่อ 40 km ทางแบริ่ง 150° เรืออยู่ห่างจุดเริ่มเท่าใด และอยู่ที่แบริ่งใดจากจุดเริ่ม

  1. เปลี่ยนทิศ 150° − 60° = 90° มุมที่จุดเลี้ยวจึงเป็นมุมฉาก

  2. ระยะ \(\sqrt{30^2 + 40^2} = 50\) km

  3. มุมระหว่างเส้นทางแรกกับเส้นตรงไปจุดปลาย \(\arctan\tfrac{40}{30} \approx 53.13^\circ\) แบริ่ง \(60^\circ + 53.13^\circ\)

50 km ที่แบริ่งประมาณ 113.13°

สมการตรีโกณมิติและการรวมคลื่น

สมการตรีโกณมิติมีคำตอบไม่จำกัดเพราะฟังก์ชันเป็นคาบ โจทย์จึงมักกำหนดช่วง เช่น \(0 \le x < 2\pi\) ขั้นตอนคือจัดให้เหลือฟังก์ชันเดียว (ใช้เอกลักษณ์พีทาโกรัสหรือมุมสองเท่า) แยกตัวประกอบเหมือนสมการพีชคณิต แล้วหามุมจากแต่ละตัวประกอบด้วยมุมอ้างอิงและ ASTC ส่วนผลบวก \(a\sin x + b\cos x\) รวมเป็นคลื่นไซน์คลื่นเดียวได้ ซึ่งเป็นพื้นฐานของการบวกแรงดันไฟฟ้ากระแสสลับด้วยเฟสเซอร์

K7 General solutions คำตอบทั่วไป

\[ \sin x = \sin\alpha \iff x = \alpha + 2k\pi \ \text{หรือ}\ \pi - \alpha + 2k\pi,\quad \cos x = \cos\alpha \iff x = \pm\alpha + 2k\pi,\quad \tan x = \tan\alpha \iff x = \alpha + k\pi \]

K8 Double angle มุมสองเท่า

\[ \sin2x = 2\sin x\cos x,\quad \cos2x = \cos^2x - \sin^2x = 1 - 2\sin^2x = 2\cos^2x - 1 \]

K9 Harmonic addition รวมเป็นคลื่นเดียว

\[ a\sin x + b\cos x = R\sin(x + \varphi),\quad R = \sqrt{a^2 + b^2},\ \tan\varphi = \tfrac{b}{a} \]
ตัวอย่าง K-8 · สมการกำลังสองของ sin

แก้ \(2\sin^2x - \sin x - 1 = 0\) เมื่อ \(0 \le x < 2\pi\)

  1. ให้ \(u = \sin x\): \(2u^2 - u - 1 = (2u + 1)(u - 1) = 0\)

  2. \(\sin x = 1 \Rightarrow x = \tfrac{\pi}{2}\)

  3. \(\sin x = -\tfrac12\): มุมอ้างอิง \(\tfrac{\pi}{6}\) ในจตุภาค III, IV ⇒ \(x = \tfrac{7\pi}{6},\ \tfrac{11\pi}{6}\)

\(x = \tfrac{\pi}{2},\ \tfrac{7\pi}{6},\ \tfrac{11\pi}{6}\)

ตัวอย่าง K-9 · ใช้มุมสองเท่า

แก้ \(\cos2x = \cos x\) เมื่อ \(0 \le x < 2\pi\)

  1. แทน \(\cos2x = 2\cos^2x - 1\): \(2\cos^2x - \cos x - 1 = 0 \Rightarrow (2\cos x + 1)(\cos x - 1) = 0\)

  2. \(\cos x = 1 \Rightarrow x = 0\) · \(\cos x = -\tfrac12 \Rightarrow x = \tfrac{2\pi}{3},\ \tfrac{4\pi}{3}\)

\(x = 0,\ \tfrac{2\pi}{3},\ \tfrac{4\pi}{3}\)

ตัวอย่าง K-10 · รวมคลื่น

เขียน \(3\sin x + 4\cos x\) เป็น \(R\sin(x + \varphi)\) และหาค่าสูงสุด

  1. \(R = \sqrt{9 + 16} = 5\) · \(\tan\varphi = \tfrac43\) ⇒ \(\varphi \approx 53.13^\circ\)

\(5\sin(x + 53.13^\circ)\) ค่าสูงสุด 5 — ตรงกับการบวกเฟสเซอร์ใน พื้นฐานเฟสเซอร์

เครื่องแก้สามเหลี่ยมทุกกรณี

เลือกชนิดข้อมูลที่รู้ ใส่ตัวเลข แล้วเครื่องจะบอกขั้นตอนตามกฎที่ใช้ วาดรูปสามเหลี่ยมตามสัดส่วนจริง และคำนวณพื้นที่ เส้นรอบรูป และรัศมีวงกลมล้อมรอบ ในกรณี SSA ที่ได้สองคำตอบ รูปที่ 2 จะเป็นเส้นประ ทำให้เห็นว่าทำไมจึงเรียกว่ากรณีกำกวม ลองเปลี่ยน a ให้ต่ำกว่าความสูง h เพื่อดูกรณีไม่มีสามเหลี่ยม

กับดักที่พบบ่อยใช้กฎของไซน์หามุมที่อาจเป็นมุมป้านแล้วตอบแค่มุมแหลม · วัดมุมก้มจากแนวดิ่งแทนแนวระดับ · และแก้สมการตรีโกณแล้วหารด้วย \(\sin x\) ทั้งสองข้าง ทำให้คำตอบ \(\sin x = 0\) หายไป ให้แยกตัวประกอบแทนการหาร
