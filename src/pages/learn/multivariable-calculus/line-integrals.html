อินทิกรัลตามเส้น (Line Integrals) งานของแรง และทฤษฎีบทกรีน (Green's Theorem)

งานที่แรงทำกับวัตถุที่เคลื่อนไปตามเส้นทางโค้ง มวลของลวดที่ความหนาแน่นไม่คงที่ แรงเคลื่อนไฟฟ้าเหนี่ยวนำรอบขดลวด และพื้นที่แปลงที่ดินจากพิกัดจุดยอด ทั้งหมดคืออินทิกรัลตามเส้น (line integral) หน้านี้สอนทั้งสองแบบ คือแบบสเกลาร์ที่รวมตามความยาว และแบบเวกเตอร์ที่รวมองค์ประกอบสัมผัส (งาน) แล้วเชื่อมกับสนามอนุรักษ์ด้วยทฤษฎีบทมูลฐานของอินทิกรัลตามเส้น ปิดท้ายด้วยทฤษฎีบทกรีน (Green's theorem) ที่แปลงอินทิกรัลรอบวงปิดเป็นอินทิกรัลสองชั้นของ curl และ div พร้อมแล็บเปรียบเทียบงานตามสองเส้นทางและแล็บวัดการหมุนวนบนวงกลม

อินทิกรัลตามเส้นของฟังก์ชันสเกลาร์ ∫ f ds กลาง

ลวดโค้ง \(C\) มีความหนาแน่นเชิงเส้น (มวลต่อความยาว) \(\rho(x, y, z)\) แบ่งลวดเป็นชิ้นสั้น \(ds\) มวลแต่ละชิ้น \(\rho\,ds\) รวมกันได้ \(M = \int_C\rho\,ds\) นั่นคืออินทิกรัลตามเส้นของฟังก์ชันสเกลาร์ ซึ่งรวมตามความยาวส่วนโค้ง และไม่ขึ้นกับทิศที่เดิน เมื่อ \(f = 1\) ได้ความยาวเส้นโค้ง (บทฟังก์ชันเวกเตอร์)

L1 Line integral of a scalar function อินทิกรัลตามเส้นของฟังก์ชันสเกลาร์

\[ \int_C f\,ds = \int_a^b f\big(\mathbf r(t)\big)\,|\mathbf r'(t)|\,dt,\qquad M = \int_C\rho\,ds,\qquad \bar x = \frac1M\int_C x\rho\,ds \]

\(ds = |\mathbf r'(t)|\,dt\) · ผลไม่ขึ้นกับทิศการเดินและไม่ขึ้นกับพารามิเตอร์ (ต่างจากแบบเวกเตอร์ซึ่งเปลี่ยนเครื่องหมายเมื่อกลับทิศ) · ในระนาบ \(y = g(x)\): \(ds = \sqrt{1 + g'^2}\,dx\)

ตัวอย่าง L-1 · มวลของลวดเกลียว (เครื่องกล)

ลวดเกลียว \(\mathbf r(t) = \langle\cos t,\ \sin t,\ t\rangle\) \(0 \le t \le 2\pi\) (หน่วย cm) มีความหนาแน่นเชิงเส้น \(\rho = x^2 + y^2 + z^2\) g/cm จงหามวล

  1. บนเส้นโค้ง \(x^2 + y^2 + z^2 = \cos^2t + \sin^2t + t^2 = 1 + t^2\) · \(|\mathbf r'| = \sqrt2\)

  2. \(M = \displaystyle\int_0^{2\pi}(1 + t^2)\sqrt2\,dt = \sqrt2\left[t + \dfrac{t^3}{3}\right]_0^{2\pi} = \sqrt2\left(2\pi + \dfrac{8\pi^3}{3}\right)\)

  3. ตัวเลข: \(2\pi = 6.283,\ \dfrac{8\pi^3}{3} = 82.68\) → \(M = 1.4142\times88.96 = 125.8\) g

\(M = \sqrt2\left(2\pi + \tfrac{8\pi^3}{3}\right) \approx 125.8\) g

ตัวอย่าง L-2 · ความยาวลวดโซลินอยด์ (ไฟฟ้า)

ขดลวดทองแดงเส้นผ่านศูนย์กลาง 0.5 mm พัน 200 รอบรอบแกนรัศมี 2 cm ระยะพิตช์ 0.5 mm ต่อรอบ หาความยาวลวดและความต้านทาน (\(\rho_{Cu} = 1.72\times10^{-8}\) Ω·m)

  1. หนึ่งรอบ: \(\mathbf r(t) = \langle R\cos t, R\sin t, ct\rangle\) โดย \(c = p/2\pi\) · \(|\mathbf r'| = \sqrt{R^2 + c^2}\) ความยาวต่อรอบ \(= \sqrt{(2\pi R)^2 + p^2}\)

  2. \(2\pi R = 0.12566\) m · \(p = 0.0005\) m → \(\sqrt{0.12566^2 + 0.0005^2} = 0.125664\) m (พิตช์แทบไม่มีผล)

  3. ความยาวรวม \(= 200\times0.125664 = 25.13\) m

  4. พื้นที่หน้าตัด \(A = \pi(0.25\times10^{-3})^2 = 1.9635\times10^{-7}\) m² · \(R_{wire} = \dfrac{\rho L}{A} = \dfrac{1.72\times10^{-8}\times25.13}{1.9635\times10^{-7}} = 2.20\) Ω

\(L = 25.13\) m · \(R_{wire} \approx 2.20\) Ω

อินทิกรัลตามเส้นของสนามเวกเตอร์ ∫ F·dr (งาน) กลาง

วัตถุเคลื่อนไปตามเส้นทาง \(C\) ในสนามแรง \(\mathbf F\) งานในช่วงเล็ก \(d\mathbf r\) คือ \(\mathbf F\cdot d\mathbf r\) (เฉพาะองค์ประกอบของแรงตามแนวเคลื่อนที่ทำงาน) รวมตลอดเส้นทางได้ \(W = \int_C\mathbf F\cdot d\mathbf r\) ต่างจากแบบสเกลาร์ตรงที่ ทิศการเดินมีผล: กลับทิศแล้วงานเปลี่ยนเครื่องหมาย \(\int_{-C}\mathbf F\cdot d\mathbf r = -\int_C\mathbf F\cdot d\mathbf r\)

L2 Line integral of a vector field (work) อินทิกรัลตามเส้นของสนามเวกเตอร์ (งาน)

\[ W = \int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F\big(\mathbf r(t)\big)\cdot\mathbf r'(t)\,dt = \int_C P\,dx + Q\,dy + R\,dz \]

ขั้นตอน: (1) กำหนดพารามิเตอร์เส้นทาง \(x(t), y(t), z(t)\) (2) หา \(\mathbf r'(t)\) (3) แทน \(\mathbf F\) ด้วยพิกัดของ \(\mathbf r(t)\) (4) ดอต แล้วอินทิเกรต \(t\) จาก \(a\) ถึง \(b\) · กลับทิศ = เครื่องหมายสลับ · วงปิด เขียน \(\oint\)

L3 Work–energy theorem ทฤษฎีบทงาน–พลังงาน

\[ \int_C\mathbf F\cdot d\mathbf r = \tfrac12 m\,|\mathbf v_B|^2 - \tfrac12 m\,|\mathbf v_A|^2 \]

จากกฎของนิวตัน \(\mathbf F = m\mathbf r''\) แล้วอินทิเกรต \(m\mathbf r''\cdot\mathbf r'\) · งานรวมคือการเปลี่ยนพลังงานจลน์

แล็บเปรียบเทียบงานตามสองเส้นทาง

เลือกพรีเซ็ตหรือพิมพ์สนามและเส้นทางเอง (พารามิเตอร์ \(t\) จาก 0 ถึง 1) โปรแกรมคำนวณงานตามเส้นทาง A (ส้ม) และเส้นทาง B (ฟ้า) แล้วตรวจ \(Q_x - P_y\) สำหรับสนามอนุรักษ์ ค่าตามสองเส้นทางต้องเท่ากัน ลองพรีเซ็ตสุดท้าย \(\langle -y, x\rangle/(x^2 + y^2)\) ที่ curl เป็นศูนย์แต่ค่าต่างกัน เพราะบริเวณมีรู

ตัวอย่าง L-3 · งานตามสองเส้นทางที่ต่างกัน

\(\mathbf F = \langle x^2,\ xy\rangle\) หางานจาก \((0, 0)\) ถึง \((1, 1)\) ตาม (ก) พาราโบลา \(y = x^2\) (ข) เส้นตรง \(y = x\)

  1. (ก) \(\mathbf r(t) = \langle t, t^2\rangle,\ 0 \le t \le 1\) · \(\mathbf r' = \langle 1, 2t\rangle\) · \(\mathbf F(\mathbf r(t)) = \langle t^2,\ t\cdot t^2\rangle = \langle t^2, t^3\rangle\)

  2. \(\mathbf F\cdot\mathbf r' = t^2 + 2t^4\) → \(W_{ก} = \displaystyle\int_0^1(t^2 + 2t^4)\,dt = \dfrac13 + \dfrac25 = \dfrac{11}{15}\)

  3. (ข) \(\mathbf r(t) = \langle t, t\rangle\) · \(\mathbf r' = \langle1, 1\rangle\) · \(\mathbf F = \langle t^2, t^2\rangle\) → \(\mathbf F\cdot\mathbf r' = 2t^2\) → \(W_{ข} = \displaystyle\int_0^1 2t^2\,dt = \dfrac23\)

  4. \(11/15 = 0.7333 \ne 2/3 = 0.6667\) → งานขึ้นกับเส้นทาง · ตรวจ \(Q_x - P_y = y - 0 = y \ne 0\) สนามไม่อนุรักษ์ ✓

\(W_{ก} = \tfrac{11}{15}\) · \(W_{ข} = \tfrac{2}{3}\) · ต่างกัน เพราะ \(\nabla\times\mathbf F \ne 0\)

ทฤษฎีบทมูลฐานของอินทิกรัลตามเส้น และความไม่ขึ้นกับเส้นทาง กลาง

ตัวแปรเดียว: \(\int_a^b F'(x)\,dx = F(b) - F(a)\) ใช้เพียงค่าที่ปลาย ทฤษฎีบทมูลฐานของอินทิกรัลตามเส้นเป็นรูปทั่วไป: ถ้า \(\mathbf F = \nabla f\) งานตามเส้นทางใดก็ได้เท่ากับผลต่างของ \(f\) ที่ปลายทั้งสอง ผลคือ “ไม่ต้องหาเส้นทาง” — นี่คือเหตุผลที่แรงดันระหว่างสองจุดในวงจร DC ไม่ขึ้นกับว่าวัดตามสายไหน และที่พลังงานศักย์โน้มถ่วงขึ้นกับความสูงอย่างเดียว

L4 Fundamental theorem for line integrals ทฤษฎีบทมูลฐานของอินทิกรัลตามเส้น

\[ \mathbf F = \nabla f \ \Rightarrow\ \int_C\mathbf F\cdot d\mathbf r = f\big(\mathbf r(b)\big) - f\big(\mathbf r(a)\big) \]

ใช้เมื่อพบว่า \(\mathbf F\) อนุรักษ์ (curl = 0) แล้วหา \(f\) (วิธีหาศักย์) · ไฟฟ้า: \(\int_A^B\mathbf E\cdot d\mathbf r = V(A) - V(B)\) เมื่อ \(\mathbf E = -\nabla V\)

L5 Equivalent conditions เงื่อนไขที่สมมูลกัน

\[ \mathbf F = \nabla f \iff \int_C\mathbf F\cdot d\mathbf r \text{ ไม่ขึ้นกับเส้นทาง} \iff \oint\mathbf F\cdot d\mathbf r = 0\ \text{ทุกวงปิด} \iff \nabla\times\mathbf F = \mathbf 0\ \ (\text{บริเวณไม่มีรู}) \]

เหตุผลที่สองข้อแรกสมมูล: วงปิด = เส้นทาง A ตามด้วยเส้นทาง B ย้อนกลับ \(\oint = \int_A - \int_B\) · ข้อสุดท้ายต้องการ “เชื่อมต่อแบบง่าย”

ตัวอย่าง L-4 · ใช้ศักย์แทนการอินทิเกรตตามเส้น

\(\mathbf F = \langle 2xy + z^3,\ x^2,\ 3xz^2\rangle\) หางานจาก \((0,0,0)\) ถึง \((1,2,1)\)

  1. จากบทสนามเวกเตอร์ (ตัวอย่าง D-5) \(\mathbf F\) อนุรักษ์ และ \(f = x^2y + xz^3\)

  2. \(W = f(1, 2, 1) - f(0, 0, 0) = (1\cdot2 + 1\cdot1) - 0 = 3\)

  3. ตรวจด้วยเส้นตรง \(\mathbf r(t) = \langle t, 2t, t\rangle\): \(\mathbf F = \langle 4t^2 + t^3,\ t^2,\ 3t^3\rangle\) และ \(\mathbf r' = \langle 1, 2, 1\rangle\) → \(\mathbf F\cdot\mathbf r' = 4t^2 + t^3 + 2t^2 + 3t^3 = 6t^2 + 4t^3\)

  4. \(\displaystyle\int_0^1(6t^2 + 4t^3)\,dt = 2 + 1 = 3\) ✓ ตรงกัน และเส้นทางอื่นใดก็ให้ 3

\(W = 3\) (ไม่ขึ้นกับเส้นทาง)

ตัวอย่าง L-5 · สนามอนุรักษ์ 2 มิติ

\(\mathbf F = \langle y, x\rangle\) หางานจาก \((0,0)\) ถึง \((2,3)\) ตามเส้นตรง และตาม \(\mathbf r(t) = \langle 2t^2, 3t\rangle\)

  1. \(P_y = 1 = Q_x\) → อนุรักษ์ · ศักย์ \(f = xy\) (\(f_x = y,\ f_y = x\) ✓)

  2. ตามเส้นตรง \(\langle 2t, 3t\rangle\): \(\mathbf F = \langle 3t, 2t\rangle\), \(\mathbf r' = \langle 2, 3\rangle\) → \(\mathbf F\cdot\mathbf r' = 6t + 6t = 12t\) → \(\int_0^1 12t\,dt = 6\)

  3. ตาม \(\langle 2t^2, 3t\rangle\): \(\mathbf F = \langle 3t, 2t^2\rangle\), \(\mathbf r' = \langle 4t, 3\rangle\) → \(\mathbf F\cdot\mathbf r' = 12t^2 + 6t^2 = 18t^2\) → \(\int_0^1 18t^2\,dt = 6\)

  4. ตรวจด้วยศักย์ \(f(2, 3) - f(0, 0) = 6 - 0 = 6\) ✓ ทั้งสามวิธีเท่ากัน

\(W = 6\) ทุกเส้นทาง

ทฤษฎีบทของกรีน (Green's Theorem) ขั้นสูง

ทฤษฎีบทของกรีนเชื่อมอินทิกรัลตามเส้นปิดรอบบริเวณ \(R\) ในระนาบกับอินทิกรัลสองชั้นของบริเวณนั้น แนวคิด: แบ่ง \(R\) เป็นช่องเล็ก ๆ ที่แต่ละช่องมีการหมุนวนเล็ก ๆ เท่ากับ \((Q_x - P_y)\,dA\) ตอนรวมช่องทั้งหมด ขอบที่ใช้ร่วมกันของช่องข้างเคียงถูกเดินสองครั้งในทิศตรงข้ามจึงหักล้างกัน เหลือเฉพาะขอบนอกสุด นี่คือ “การหมุนวนทั้งหมดรอบวง = ผลรวมการหมุนวนเล็ก ๆ ข้างใน”

L6 Green's theorem (circulation form) ทฤษฎีบทกรีน (รูปการหมุนวน)

\[ \oint_C P\,dx + Q\,dy = \oint_C\mathbf F\cdot d\mathbf r = \iint_R\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA \]

\(C\) = ขอบเขตปิดเรียบเป็นช่วง ๆ วนทวนเข็มนาฬิกา (บริเวณอยู่ทางซ้ายมือเสมอ) · \(P, Q\) มีอนุพันธ์ย่อยต่อเนื่องบน \(R\) · ถ้าวนตามเข็มนาฬิกา เพิ่มเครื่องหมายลบ · บริเวณมีรู: ขอบในวนตามเข็ม

L7 Green's theorem (flux form) ทฤษฎีบทกรีน (รูปฟลักซ์)

\[ \oint_C\mathbf F\cdot\mathbf n\,ds = \oint_C P\,dy - Q\,dx = \iint_R\left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y}\right)dA = \iint_R\nabla\cdot\mathbf F\,dA \]

\(\mathbf n\) = เวกเตอร์ปกติชี้ออกนอกบริเวณ · เป็นทฤษฎีบทดีเวอร์เจนซ์ในสองมิติ (บทผิว)

L8 Area by a line integral · shoelace พื้นที่ด้วยอินทิกรัลเส้นและสูตร shoelace

\[ A = \oint_C x\,dy = -\oint_C y\,dx = \tfrac12\oint_C x\,dy - y\,dx,\qquad A_{\text{polygon}} = \tfrac12\Big|\sum_{i=1}^{n}\big(x_iy_{i+1} - x_{i+1}y_i\big)\Big| \]

เลือก \(P, Q\) ให้ \(Q_x - P_y = 1\) (เช่น \(Q = x, P = 0\) หรือ \(Q = x/2, P = -y/2\)) · รูปหลายเหลี่ยมคำนวณทีละด้าน (เส้นตรง) จึงได้ผลรวม · \((x_{n+1}, y_{n+1}) = (x_1, y_1)\) · วนทวนเข็มได้พื้นที่บวก

ในแล็บสนามเวกเตอร์ (บทสนามเวกเตอร์) วงกลมทดสอบวัด \(\oint\mathbf F\cdot d\mathbf r\) และ \(\oint\mathbf F\cdot\mathbf n\,ds\) เทียบกับ \(\iint\) ของ curl และ div ซึ่งคือทฤษฎีบทกรีนในรูปเชิงตัวเลข ลองอีกครั้งที่นี่กับสนามที่ curl ไม่คงที่ แล้วดูว่า \(\oint\) ตรงกับ \(\iint(Q_x - P_y)\,dA\) โดยประมาณ (ตรงเมื่อ \(\rho\) เล็ก) ค่าสองบรรทัดสุดท้ายในกล่องคำตอบเป็นการเทียบโดยตรงกับค่าที่ทฤษฎีบทกรีนทำนาย

ตัวอย่าง L-6 · ใช้กรีนแทนการอินทิเกรตเส้นที่ยาก

คำนวณ \(\displaystyle\oint_C\big(3y - e^{\sin x}\big)dx + \big(7x + \sqrt{y^4 + 1}\big)dy\) เมื่อ \(C\) คือวงกลม \(x^2 + y^2 = 9\) วนทวนเข็ม

  1. อินทิกรัลเส้นตรง ๆ ทำยาก (มี \(e^{\sin x}\) และ \(\sqrt{y^4 + 1}\) ที่ไม่มีปฏิยานุพันธ์แบบปิด) ใช้ทฤษฎีบทกรีน

  2. \(P = 3y - e^{\sin x}\) → \(P_y = 3\) · \(Q = 7x + \sqrt{y^4 + 1}\) → \(Q_x = 7\) · \(Q_x - P_y = 4\) (ค่าคงที่!)

  3. \(\displaystyle\oint_C = \iint_R 4\,dA = 4\times\text{พื้นที่วงกลมรัศมี }3 = 4\times9\pi = 36\pi\)

\(36\pi \approx 113.1\) (พจน์ที่ซับซ้อนหายไปหมดเมื่ออนุพันธ์ย่อยหักล้างกัน)

ตัวอย่าง L-7 · พื้นที่วงรีด้วยกรีน

หาพื้นที่ภายในวงรี \(x = a\cos t,\ y = b\sin t\) ด้วย \(A = \tfrac12\oint x\,dy - y\,dx\)

  1. \(dx = -a\sin t\,dt\) และ \(dy = b\cos t\,dt\) · \(x\,dy - y\,dx = ab\cos^2t\,dt + ab\sin^2t\,dt = ab\,dt\)

  2. \(A = \dfrac12\displaystyle\int_0^{2\pi}ab\,dt = \dfrac12\cdot ab\cdot2\pi = \pi ab\)

  3. ตรงกับผลของบทอินทิกรัลหลายชั้น (เปลี่ยนตัวแปรด้วย Jacobian \(ab\)) ✓

\(A = \pi ab\)

ตัวอย่าง L-8 · พื้นที่แปลงที่ดินจากพิกัดจุดยอด (โยธา / สำรวจ)

แปลงที่ดินห้าเหลี่ยมมีพิกัด (เมตร): \((0, 0),\ (40, 0),\ (55, 30),\ (20, 45),\ (-5, 25)\) เรียงทวนเข็ม หาพื้นที่

  1. คำนวณ \(x_iy_{i+1} - x_{i+1}y_i\) ทีละด้าน: \(0\cdot0 - 40\cdot0 = 0\) · \(40\cdot30 - 55\cdot0 = 1200\) · \(55\cdot45 - 20\cdot30 = 2475 - 600 = 1875\) · \(20\cdot25 - (-5)\cdot45 = 500 + 225 = 725\) · \((-5)\cdot0 - 0\cdot25 = 0\)

  2. ผลรวม \(= 0 + 1200 + 1875 + 725 + 0 = 3800\)

  3. \(A = \tfrac12\times3800 = 1900\) ตารางเมตร · หน่วยไทย: 1 ตารางวา = 4 ตร.ม. ดังนั้น \(1900/4 = 475\) ตารางวา = 1 ไร่ 75 ตารางวา (1 ไร่ = 400 ตร.ว. = 1600 ตร.ม.)

  4. ถ้าเรียงจุดตามเข็มนาฬิกาจะได้ผลรวมเป็น \(-3800\) จึงต้องใส่ค่าสัมบูรณ์ · วิธีนี้ใช้ในโปรแกรมสำรวจและ GIS ทุกชนิด

\(A = 1900\) m² \(\approx 1.19\) ไร่ (ใช้ทฤษฎีบทกรีนกับเส้นขอบที่เป็นเส้นตรงทีละด้าน)

ตัวอย่าง L-9 · รูปฟลักซ์ของกรีน

\(\mathbf F = \langle x, y\rangle\) หาฟลักซ์ออกจากวงกลมรัศมี \(R\) ด้วยสองวิธี

  1. วิธีตรง: บนวงกลม \(\mathbf n = \langle x, y\rangle/R\) → \(\mathbf F\cdot\mathbf n = (x^2 + y^2)/R = R\) คงที่ · \(\oint\mathbf F\cdot\mathbf n\,ds = R\times2\pi R = 2\pi R^2\)

  2. วิธีกรีน: \(\nabla\cdot\mathbf F = 1 + 1 = 2\) → \(\iint 2\,dA = 2\times\pi R^2 = 2\pi R^2\) ✓

  3. ในแล็บ: วงกลมรัศมี 1 ที่จุดกำเนิดให้ flux \(= 2\pi = 6.2832\) และ flux ÷ พื้นที่ \(= 2\) ตรงกับ \(\nabla\cdot\mathbf F\)

\(\oint\mathbf F\cdot\mathbf n\,ds = 2\pi R^2\) ทั้งสองวิธี

นำไปใช้ในงานวิศวกรรม พื้นฐาน

สาขาอินทิกรัลตามเส้นความหมาย
ไฟฟ้า\(V_{AB} = -\int_A^B\mathbf E\cdot d\mathbf r\)แรงดันระหว่างสองจุด ไม่ขึ้นกับเส้นทางในสนามสถิต (L4)
ไฟฟ้า\(\oint\mathbf B\cdot d\mathbf l = \mu_0 I_{enc}\)กฎของแอมแปร์ · สนามรอบลวดเส้นตรง \(B = \mu_0I/2\pi r\) (บทผิว)
ไฟฟ้า\(\mathcal E = \oint\mathbf E\cdot d\mathbf l = -d\Phi_B/dt\)แรงเคลื่อนไฟฟ้าเหนี่ยวนำ (กฎฟาราเดย์) — สนามไม่อนุรักษ์
เครื่องกล\(W = \int\mathbf F\cdot d\mathbf r\)งานของแรงตามเส้นทางโค้ง งานของแรงเสียดทานขึ้นกับเส้นทาง
เครื่องกล\(\Gamma = \oint\mathbf v\cdot d\mathbf l\)ไหลเวียน (circulation) ของของไหล · ทฤษฎีบท Kutta–Joukowski \(L' = \rho U\Gamma\) ของแรงยกปีก
โยธา\(A = \tfrac12\oint x\,dy - y\,dx\)พื้นที่แปลงที่ดินจากพิกัด (shoelace) · เครื่องมือ planimeter วัดพื้นที่บนแผนที่ (ตัวอย่าง L-8)
โยธา\(\int_C\rho\,ds\)น้ำหนักของสายเคเบิลที่น้ำหนักต่อความยาวไม่คงที่

ข้อผิดพลาดที่พบบ่อย พื้นฐาน

  1. ลืมคูณ \(|\mathbf r'|\) ในแบบสเกลาร์ · \(\int f\,ds\) ใช้ \(|\mathbf r'(t)|\,dt\) (ต่างจาก \(\int\mathbf F\cdot d\mathbf r\) ที่ใช้ \(\mathbf r'\,dt\) ในผลดอต)
  2. ลืมกลับเครื่องหมายเมื่อเดินย้อนทิศ ในแบบเวกเตอร์ · แบบสเกลาร์ไม่เปลี่ยนเครื่องหมาย
  3. ใช้กรีนกับขอบที่ไม่วนทวนเข็ม · วนตามเข็มได้ผลลบ · และต้องเป็นเส้นปิดที่ไม่ตัดตัวเอง
  4. ใช้ทฤษฎีบทกรีนเมื่อ \(\mathbf F\) ไม่นิยามภายในวง · เช่น \(\langle -y, x\rangle/(x^2 + y^2)\) รอบจุดกำเนิดให้ \(2\pi\) แม้ curl เป็นศูนย์ (มีรูที่จุดกำเนิด)
  5. เข้าใจว่า curl = 0 แล้วอนุรักษ์เสมอ · ต้องบริเวณเชื่อมต่อแบบง่าย
