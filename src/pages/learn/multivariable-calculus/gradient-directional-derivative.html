// บทที่ 24.3 · แคลคูลัสหลายตัวแปร · Gradient & Directional Derivative

เกรเดียนต์ (Gradient) และอนุพันธ์ตามทิศ (Directional Derivative): ความหมาย สูตร และตัวอย่าง

ยืนบนเนินเขา อยากรู้ว่า “เดินไปทางไหนชันที่สุด” และ “ถ้าเดินไปทางตะวันออกเฉียงเหนือจะชันเท่าไร” คำตอบทั้งสองมาจากเวกเตอร์ตัวเดียวที่เรียกว่าเกรเดียนต์ (gradient) \(\nabla f\) ซึ่งเป็นหัวใจของแคลคูลัสหลายตัวแปร และปรากฏทุกที่ในงานวิศวกรรม: สนามไฟฟ้า \(\mathbf E = -\nabla V\) ฟลักซ์ความร้อน \(\mathbf q = -k\nabla T\) การไหลของน้ำบนผิวดิน และอัลกอริทึม gradient descent ที่ปรับพารามิเตอร์ตัวควบคุมหรือโมเดล หน้านี้มีแล็บหมุนทิศ \(\mathbf u\) แล้วดูค่า \(D_{\mathbf u}f\) บนกราฟขั้ว และปล่อยจุดลงเขาด้วย gradient descent

เขียนโดย อาจารย์มดอัปเดต
แล็บ gradient อนุพันธ์ตามทิศ ทิศชันที่สุด ตั้งฉากกับเส้นชั้น gradient descent
สรุปใน 30 วินาที
  • \(\nabla f = \langle f_x, f_y\rangle\) (หรือ \(\langle f_x, f_y, f_z\rangle\)) · ชี้ทาง \(f\) เพิ่มเร็วสุด · ขนาด \(|\nabla f|\) = อัตราเพิ่มสูงสุด
  • อนุพันธ์ตามทิศ \(D_{\mathbf u}f = \nabla f\cdot\mathbf u = |\nabla f|\cos\theta\) เมื่อ \(\mathbf u\) เป็นเวกเตอร์หนึ่งหน่วย
  • \(\nabla f\) ตั้งฉากกับเส้นชั้น \(f = c\) · ใน 3 มิติ \(\nabla F\) คือเวกเตอร์ปกติของผิวระดับ \(F = c\)
  • gradient descent: \(\mathbf x \leftarrow \mathbf x - \alpha\nabla f\) ลงเขาทีละก้าว
ระดับพื้นฐาน ปี 1 · แคลคูลัส 1กลาง แคลคูลัส 3 · คณิตศาสตร์วิศวกรรมขั้นสูง พิสูจน์ · ทฤษฎี

เกรเดียนต์คืออะไร พื้นฐาน

อนุพันธ์ย่อยให้ความชันตามแกน \(x\) และแกน \(y\) แต่ผิวมีทิศให้เดินได้ไม่จำกัด ทำไมความรู้เรื่องสองแกนจึงพอทำนายทิศไหนก็ได้? เพราะผิวเรียบเมื่อซูมเข้าจะเป็นระนาบ (บทระนาบสัมผัส) และระนาบถูกกำหนดด้วยความชันสองค่า การรวมสองค่าเป็นเวกเตอร์เดียวคือเกรเดียนต์ ซึ่งเขียนด้วยสัญลักษณ์ \(\nabla\) (อ่านว่า “เดล” หรือ “นาบลา”)

G1 Gradient เกรเดียนต์

\[ \nabla f = \left\langle \frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y}\right\rangle = f_x\,\mathbf i + f_y\,\mathbf j,\qquad \nabla f = \left\langle f_x, f_y, f_z\right\rangle \ \text{(3 ตัวแปร)} \]

ฟังก์ชันสเกลาร์ → สนามเวกเตอร์ · ตัวดำเนินการ \(\nabla = \left\langle \dfrac{\partial}{\partial x}, \dfrac{\partial}{\partial y}, \dfrac{\partial}{\partial z}\right\rangle\) (grad) · บางตำราเขียน \(\operatorname{grad} f\)

ตัวอย่าง G-1 · หา gradient

หา \(\nabla f\) ของ \(f(x, y) = x^2 y^3 - 4y\) แล้วคำนวณที่ \((2, -1)\)

  1. \(f_x = 2xy^3\) · \(f_y = 3x^2y^2 - 4\)

  2. แทน \((2, -1)\): \(f_x = 2(2)(-1)^3 = -4\) · \(f_y = 3(4)(1) - 4 = 8\)

  3. ดังนั้น \(\nabla f(2, -1) = \langle -4, 8\rangle\) · ขนาด \(|\nabla f| = \sqrt{16 + 64} = \sqrt{80} = 8.94\)

\(\nabla f = \langle 2xy^3,\ 3x^2y^2 - 4\rangle\) · ที่ \((2,-1)\) คือ \(\langle -4, 8\rangle\)

อนุพันธ์ตามทิศ (Directional Derivative) พื้นฐาน

อนุพันธ์ตามทิศคืออัตราเปลี่ยนของ \(f\) เมื่อเดินจากจุดหนึ่งตรงไปตามทิศที่กำหนด ด้วยความเร็วหนึ่งหน่วยต่อหน่วยระยะ ทิศถูกระบุด้วยเวกเตอร์หนึ่งหน่วย \(\mathbf u = \langle \cos\theta, \sin\theta\rangle\) อนุพันธ์ย่อย \(f_x\) และ \(f_y\) คือกรณีพิเศษของ \(D_{\mathbf u}f\) ที่ทิศ \(\mathbf u = \mathbf i\) และ \(\mathbf u = \mathbf j\)

G2 Directional derivative (definition) อนุพันธ์ตามทิศ (นิยาม)

\[ D_{\mathbf u} f(a, b) = \lim_{h\to 0} \frac{f(a + h u_1,\ b + h u_2) - f(a, b)}{h} = \left.\frac{d}{dh} f(\mathbf x_0 + h\mathbf u)\right|_{h=0} \]

เดินเป็นเส้นตรง \(\mathbf x_0 + h\mathbf u\) แล้วหาอนุพันธ์ของ \(f\) ตามระยะ \(h\) · \(\mathbf u\) ต้องหนึ่งหน่วย (\(|\mathbf u| = 1\)) จึงให้หน่วยเป็น “ต่อหน่วยระยะ”

G3 Computing formula สูตรคำนวณ

\[ D_{\mathbf u} f = \nabla f \cdot \mathbf u = f_x u_1 + f_y u_2 = |\nabla f|\cos\theta,\qquad \mathbf u = \frac{\mathbf v}{|\mathbf v|} \]

\(\theta\) = มุมระหว่าง \(\nabla f\) กับ \(\mathbf u\) · ถ้าโจทย์ให้ทิศเป็นเวกเตอร์ \(\mathbf v\) ใด ๆ ให้ทำเป็นหนึ่งหน่วยก่อนเสมอ (ข้อผิดพลาดอันดับหนึ่ง) · พิสูจน์ด้วยกฎลูกโซ่ \(\dfrac{d}{dh}f(a + hu_1, b + hu_2) = f_x u_1 + f_y u_2\)

ตัวอย่าง G-2 · อนุพันธ์ตามทิศที่กำหนดด้วยเวกเตอร์

ต่อจาก G-1: หา \(D_{\mathbf u}f\) ที่ \((2, -1)\) ในทิศ \(\mathbf v = \langle 2, 5\rangle\)

  1. \(|\mathbf v| = \sqrt{4 + 25} = \sqrt{29}\) จึง \(\mathbf u = \dfrac{\langle 2, 5\rangle}{\sqrt{29}}\) (ทำเป็นหนึ่งหน่วยก่อน!)

  2. \(\nabla f(2,-1) = \langle -4, 8\rangle\) จาก G-1

  3. \(D_{\mathbf u} f = \langle -4, 8\rangle\cdot\dfrac{\langle 2, 5\rangle}{\sqrt{29}} = \dfrac{-8 + 40}{\sqrt{29}} = \dfrac{32}{\sqrt{29}} \approx 5.94\)

  4. เทียบกับขนาดสูงสุด \(|\nabla f| = 8.94\): ทิศนี้ทำมุม \(\theta\) กับ \(\nabla f\) โดย \(\cos\theta = 5.94/8.94 = 0.665\) → \(\theta \approx 48.4^\circ\)

\(D_{\mathbf u}f = 32/\sqrt{29} \approx 5.94\) (ถ้าลืมทำเป็นหนึ่งหน่วยจะได้ 32 ซึ่งผิด)

แล็บ: หมุนทิศ u ดู Duf และปล่อยจุดลงเขา พื้นฐาน

ลูกศรดำคือ \(\nabla f\) (ชี้ขึ้นเขาชันสุด ตั้งฉากกับเส้นชั้นที่ผ่านจุด) ลูกศรฟ้าคือทิศ \(\mathbf u\) ที่คุณเลือกด้วยแถบมุม \(\theta\) กราฟขั้วด้านขวาแสดงค่า \(D_{\mathbf u}f\) ทุกทิศ เป็นวงกลมที่ผ่านจุดกำเนิด (เพราะ \(D_{\mathbf u}f = |\nabla f|\cos(\theta - \theta_g)\)) ยอดวงกลมอยู่ในทิศ \(\nabla f\) ส่วนจุดที่ผ่านจุดกำเนิดคือทิศตั้งฉาก ซึ่ง \(D_{\mathbf u}f = 0\) นั่นคือเดินไปตามเส้นชั้น

ทิศที่ชันที่สุด และอัตราสูงสุด พื้นฐาน

จาก \(D_{\mathbf u}f = |\nabla f|\cos\theta\) ค่านี้ใหญ่สุดเมื่อ \(\cos\theta = 1\) (\(\mathbf u\) ทิศเดียวกับ \(\nabla f\)) เล็กสุดเมื่อ \(\cos\theta = -1\) และเป็นศูนย์เมื่อ \(\cos\theta = 0\) (ตั้งฉาก)

G4 Direction of steepest ascent ทิศขึ้นชันที่สุด

\[ \max_{|\mathbf u|=1} D_{\mathbf u}f = |\nabla f|\ \ (\mathbf u = \tfrac{\nabla f}{|\nabla f|}),\qquad \min D_{\mathbf u}f = -|\nabla f|\ \ (\mathbf u = -\tfrac{\nabla f}{|\nabla f|}),\qquad D_{\mathbf u}f = 0\ \ (\mathbf u \perp \nabla f) \]

ขึ้นชันสุด \(+\nabla f\) · ลงชันสุด \(-\nabla f\) · เดินตามเส้นชั้น \(\perp\nabla f\) · ถ้า \(\nabla f = \mathbf 0\) (จุดวิกฤต) ทุกทิศได้ \(D_{\mathbf u}f = 0\)

ตัวอย่าง G-3 · อุณหภูมิบนแผ่นโลหะ (เครื่องกล)

อุณหภูมิบนแผ่นโลหะ \(T(x, y) = \dfrac{80}{1 + x^2 + 2y^2}\) °C (x, y เป็นเมตร) แมลงที่ \((3, -1)\) ต้องการหนีร้อนให้เร็วที่สุด ควรเดินไปทิศใด และอุณหภูมิลดเร็วเพียงใด

  1. ที่ \((3, -1)\): ตัวส่วน \(1 + 9 + 2 = 12\) · \(T = 80/12 = 6.67\) °C

  2. \(T_x = \dfrac{-80(2x)}{(1 + x^2 + 2y^2)^2} = \dfrac{-480}{144} = -\dfrac{10}{3}\) · \(T_y = \dfrac{-80(4y)}{(1 + x^2 + 2y^2)^2} = \dfrac{320}{144} = \dfrac{20}{9}\)

  3. \(\nabla T = \left\langle -\tfrac{10}{3},\ \tfrac{20}{9}\right\rangle \propto \langle -3, 2\rangle\) ชี้ทางที่ร้อนขึ้นเร็วสุด (ไปทางจุดกำเนิดที่ร้อนสุด)

  4. แมลงต้องการเย็นลงเร็วสุด จึงเดินสวนทาง \(-\nabla T\) คือทิศ \(\langle 3, -2\rangle/\sqrt{13}\) (ห่างออกจากจุดกำเนิด)

  5. อัตราลดสูงสุด \(= |\nabla T| = \sqrt{\tfrac{100}{9} + \tfrac{400}{81}} = \sqrt{\tfrac{1300}{81}} = \tfrac{\sqrt{1300}}{9} \approx 4.006\) °C/m

เดินทิศ \(-\nabla T \propto \langle 3, -2\rangle\) · อุณหภูมิลดเร็วสุด 4.006 °C ต่อเมตร

เกรเดียนต์ตั้งฉากกับเส้นชั้น และผิวระดับ กลาง

ตามเส้นชั้น \(f(x, y) = c\) ค่าของ \(f\) คงที่ ดังนั้นถ้าเดินเล็กน้อยตามทิศสัมผัสเส้นชั้น \(\mathbf T\) จะได้ \(D_{\mathbf T}f = \nabla f\cdot\mathbf T = 0\) ผลดอตเป็นศูนย์แปลว่า \(\nabla f \perp \mathbf T\) ผลเดียวกันใช้กับผิวระดับ: เวกเตอร์ปกติของผิว \(F(x, y, z) = c\) คือ \(\nabla F\) ซึ่งให้วิธีเขียนระนาบสัมผัสและเส้นปกติทันที

G5 Gradient ⟂ level curve gradient ตั้งฉากเส้นชั้น

\[ \mathbf r(t) \in \{f = c\} \ \Rightarrow\ \frac{d}{dt}f(\mathbf r(t)) = \nabla f\cdot\mathbf r'(t) = 0 \]

เส้นสัมผัสของเส้นชั้นที่ \((a,b)\) มีสมการ \(f_x(x - a) + f_y(y - b) = 0\)

G6 Tangent plane and normal line of F = c ระนาบสัมผัสและเส้นปกติของผิวระดับ

\[ F_x(P)(x - x_0) + F_y(P)(y - y_0) + F_z(P)(z - z_0) = 0,\qquad \mathbf r(t) = \mathbf r_0 + t\,\nabla F(P) \]

ถ้าผิวให้ในรูป \(z = f(x, y)\) ให้ตั้ง \(F = f(x,y) - z\) จะได้ \(\nabla F = \langle f_x, f_y, -1\rangle\) ตรงกับระนาบสัมผัสในบทอนุพันธ์ย่อย

ตัวอย่าง G-4 · ระนาบสัมผัสของทรงรี

หาระนาบสัมผัสและเส้นปกติของ \(\dfrac{x^2}{4} + y^2 + \dfrac{z^2}{4} = 3\) ที่ \((-2, 1, 2)\)

  1. ตั้ง \(F = \dfrac{x^2}{4} + y^2 + \dfrac{z^2}{4} - 3\) ตรวจจุด: \(1 + 1 + 1 - 3 = 0\) ✓

  2. \(\nabla F = \left\langle \dfrac{x}{2},\ 2y,\ \dfrac{z}{2}\right\rangle\) ที่ \((-2, 1, 2)\): \(\langle -1,\ 2,\ 1\rangle\)

  3. ระนาบสัมผัส: \(-1(x + 2) + 2(y - 1) + 1(z - 2) = 0\) → \(-x + 2y + z = 6\)

  4. เส้นปกติ: \(x = -2 - t,\ y = 1 + 2t,\ z = 2 + t\)

  5. ตรวจ: แทนจุด \((-2,1,2)\): \(2 + 2 + 2 = 6\) ✓

ระนาบสัมผัส \(-x + 2y + z = 6\) · เส้นปกติ \(\langle -2, 1, 2\rangle + t\langle -1, 2, 1\rangle\)

ในงานวิศวกรรม: ผิวตัวนำไฟฟ้าเป็นผิวศักย์เท่ากัน (\(V\) คงที่) สนาม \(\mathbf E = -\nabla V\) จึงตั้งฉากกับผิวตัวนำเสมอ (เงื่อนไขขอบเขตที่ใช้ในการออกแบบอิเล็กโทรด) น้ำบนผิวดินไหลตามทิศ \(-\nabla h\) ซึ่งตั้งฉากกับเส้นชั้นความสูง จึงวางแนวร่องระบายน้ำตั้งฉากกับเส้นชั้น และความร้อนไหลตั้งฉากกับ isotherm

กฎของเกรเดียนต์และสูตรที่ใช้บ่อย กลาง

G7 Gradient rules กฎของเกรเดียนต์

\[ \nabla(f \pm g) = \nabla f \pm \nabla g,\quad \nabla(fg) = f\nabla g + g\nabla f,\quad \nabla\,h(f) = h'(f)\,\nabla f \]

เป็นกฎของตัวแปรเดียวทุกข้อ ใส่ \(\nabla\) แทน \(d/dx\)

G8 Gradient of radial functions เกรเดียนต์ของฟังก์ชันรัศมี

\[ r = \sqrt{x^2 + y^2 + z^2}:\quad \nabla r = \frac{\mathbf r}{r},\qquad \nabla\!\left(\frac1r\right) = -\frac{\mathbf r}{r^3},\qquad \nabla r^n = n\,r^{n-2}\mathbf r \]

สูตรสามข้อนี้ใช้บ่อยมากในไฟฟ้า (ศักย์จากประจุจุด) และแรงโน้มถ่วง · ทิศ \(\mathbf r/r\) คือเวกเตอร์หนึ่งหน่วยตามรัศมี

ตัวอย่าง G-5 · ได้กฎของคูลอมบ์จากศักย์ (ไฟฟ้า)

ศักย์ของประจุจุด \(q\) คือ \(V = \dfrac{kq}{r}\) จงหา \(\mathbf E = -\nabla V\)

  1. \(V = kq\cdot r^{-1}\) จากสูตร G8: \(\nabla\left(\dfrac1r\right) = -\dfrac{\mathbf r}{r^3}\)

  2. \(\mathbf E = -\nabla V = -kq\left(-\dfrac{\mathbf r}{r^3}\right) = \dfrac{kq\,\mathbf r}{r^3} = \dfrac{kq}{r^2}\,\hat{\mathbf r}\)

  3. นี่คือกฎของคูลอมบ์ — ขนาด \(kq/r^2\) พุ่งออกตามรัศมี และเมื่อ \(q < 0\) พุ่งเข้า

  4. สรุป: คำนวณศักย์ (สเกลาร์ ง่ายกว่า) แล้วหา gradient ได้สนามเวกเตอร์ทั้ง 3 องค์ประกอบในครั้งเดียว

\(\mathbf E = \dfrac{kq}{r^2}\hat{\mathbf r}\) · ใช้ได้กับผลรวมของหลายประจุโดยรวม \(V\) ก่อนแล้วหา gradient (ดูแล็บประจุจุด)

Gradient Descent: ลงเขาทีละก้าว กลาง

ถ้าต้องการจุดต่ำสุดของ \(f\) แต่แก้ \(\nabla f = \mathbf 0\) ตรง ๆ ไม่ได้ (ฟังก์ชันซับซ้อน มีพารามิเตอร์นับพัน) ให้เริ่มจากจุดหนึ่งแล้วเดินสวนทางเกรเดียนต์ซ้ำ ๆ ทีละก้าวเล็ก ๆ นี่คือ gradient descent ซึ่งเป็นแกนของการฝึกโครงข่ายประสาทเทียม การจูนพารามิเตอร์ตัวควบคุม และการแก้ปัญหากำลังสองน้อยสุดขนาดใหญ่ ส่วนการไต่ขึ้น (gradient ascent) ใช้หาค่ามากสุด เช่น วิธี perturb & observe ที่ตามจุดกำลังสูงสุดของแผงโซลาร์เซลล์ก็คือการไต่เขา \(P(V)\) ในมิติเดียว

G9 Gradient descent วิธีลงเขาตามเกรเดียนต์

\[ \mathbf x_{k+1} = \mathbf x_k - \alpha\,\nabla f(\mathbf x_k),\qquad \text{ฟังก์ชันกำลังสอง } f = \tfrac12\mathbf x^{\top}\mathbf A\mathbf x:\ \text{ลู่เข้า} \iff 0 < \alpha < \frac{2}{\lambda_{\max}(\mathbf A)} \]

\(\alpha\) = ขนาดก้าว (learning rate) · เล็กเกิน = ช้า ใหญ่เกิน = แกว่งแล้วแตกออก · เส้นชั้นเป็นวงรียาว (\(\lambda_{\max}/\lambda_{\min}\) มาก) = ลู่เข้าช้าเป็นรูปซิกแซก

ตัวอย่าง G-6 · ทำสองก้าวด้วยมือ

\(f(x, y) = x^2 + 3y^2\) เริ่มที่ \((2, 1)\) ใช้ \(\alpha = 0.1\) ทำ gradient descent สองก้าว

  1. \(\nabla f = \langle 2x, 6y\rangle\) · เริ่ม \(f(2, 1) = 4 + 3 = 7\)

  2. ก้าวที่ 1: \(\nabla f(2,1) = \langle 4, 6\rangle\) · \((x, y) = (2, 1) - 0.1\langle 4, 6\rangle = (1.6,\ 0.4)\) · \(f = 2.56 + 0.48 = 3.04\)

  3. ก้าวที่ 2: \(\nabla f(1.6, 0.4) = \langle 3.2, 2.4\rangle\) · \((x, y) = (1.28,\ 0.16)\) · \(f = 1.638 + 0.077 = 1.715\)

  4. ค่า \(f\) ลดลงทุกก้าว (7 → 3.04 → 1.715) และเข้าใกล้จุดต่ำสุด \((0, 0)\) ซึ่ง \(f = 0\)

\((2,1) \to (1.6, 0.4) \to (1.28, 0.16)\) · \(f: 7 \to 3.04 \to 1.715\)

ตัวอย่าง G-7 · เลือกขนาดก้าวไม่ได้ถ้าไม่รู้ความโค้ง

\(f = x^2 + 10y^2\) ต้องใช้ \(\alpha\) น้อยกว่าเท่าไรจึงลู่เข้า

  1. \(\nabla f = \langle 2x, 20y\rangle\) แต่ละก้าวคูณแต่ละพิกัดด้วย \((1 - 2\alpha)\) และ \((1 - 20\alpha)\)

  2. ลู่เข้าเมื่อทั้งสองตัวคูณมีขนาดน้อยกว่า 1: \(|1 - 2\alpha| < 1\) ได้ \(\alpha < 1\) และ \(|1 - 20\alpha| < 1\) ได้ \(\alpha < 0.1\)

  3. ข้อจำกัดคือ \(\alpha < 0.1 = 2/\lambda_{\max}\) เมื่อ \(\lambda_{\max} = 20\) (ค่าเฉพาะที่ใหญ่สุดของ Hessian)

  4. ทดสอบ 30 ก้าวจาก \((2, 1)\): \(\alpha = 0.09\) → \((0.005, 0.001)\) ลู่เข้า · \(\alpha = 0.1\) → \(y\) สลับ \(\pm 1\) ตลอด (ขอบเขต) · \(\alpha = 0.11\) → \(y \approx 237\) แตกออก

  5. ปัญหาของวงรียาว: \(x\) ต้องการก้าวใหญ่ (ความโค้งน้อย) แต่ \(y\) ต้องการก้าวเล็ก (ความโค้งมาก) ทำให้ช้า จึงมีวิธีขั้นสูง เช่น momentum, Newton, conjugate gradient

ลู่เข้าเมื่อ \(0 < \alpha < 0.1\) · \(\alpha = 0.11\) แตกออก

สาขาเกรเดียนต์ของใช้ทำอะไร
ไฟฟ้าศักย์ไฟฟ้า \(V\)\(\mathbf E = -\nabla V\) · สนามตั้งฉากกับผิวตัวนำ (บทไฟฟ้า)
ไฟฟ้ากำลัง \(P(V_{pv})\) ของแผงโซลาร์MPPT แบบ perturb & observe คือการไต่เขา (MPPT)
เครื่องกลอุณหภูมิ \(T\)\(\mathbf q = -k\nabla T\) ฟลักซ์ความร้อนตั้งฉาก isotherm (บทเครื่องกล)
เครื่องกลความดัน \(p\)แรงสุทธิต่อหน่วยปริมาตรของของไหล \(-\nabla p\)
โยธาความสูงภูมิประเทศ \(h\)ความชัน \(|\nabla h|\) และทิศน้ำไหล \(-\nabla h\) (บทโยธา)
โยธา / ธรณีระดับน้ำใต้ดิน \(h\)กฎของดาร์ซี \(\mathbf v = -K\nabla h\) ความเร็วซึมตั้งฉากเส้นระดับ
ทุกสาขาฟังก์ชันค่าความผิดพลาด \(J(\theta)\)gradient descent ปรับพารามิเตอร์ (บทค่าสุดขีด)

ข้อผิดพลาดที่พบบ่อย พื้นฐาน

  1. ลืมทำเวกเตอร์ทิศให้เป็นหนึ่งหน่วย ก่อนดอต · \(D_{\mathbf u}f\) ต้องใช้ \(\mathbf u\) ที่ \(|\mathbf u| = 1\) เสมอ
  2. คิดว่า gradient เป็นสเกลาร์ · \(\nabla f\) เป็นเวกเตอร์ (ชี้ทิศ) ส่วน \(D_{\mathbf u}f\) เป็นสเกลาร์
  3. คิดว่า \(\nabla f\) อยู่บนผิว 3 มิติ · \(\nabla f\) ของ \(f(x,y)\) เป็นเวกเตอร์ 2 มิติในระนาบ \(xy\) (ทิศบนแผนที่) ไม่ใช่เวกเตอร์ชี้ขึ้นบนผิว
  4. ใช้ gradient descent โดยไม่ตรวจขนาดก้าว · ถ้า \(f\) ไม่ลดลงเลยหลังหลายก้าวให้ลด \(\alpha\) ลงครึ่งหนึ่ง
  5. สับสนทิศลงเขา · ลงเขาชันสุดคือ \(-\nabla f\) (น้ำไหล) ไม่ใช่ \(+\nabla f\)

ไปต่อที่ค่าสูงสุด-ต่ำสุดและตัวคูณลากรองจ์ ที่ใช้เงื่อนไข \(\nabla f = \mathbf 0\) และ \(\nabla f \parallel \nabla g\) หาจุดเหมาะสมที่สุด
