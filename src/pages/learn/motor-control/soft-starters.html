// บทที่ 21.9 · ควบคุมมอเตอร์ AC · Soft Starters & Autotransformers

ซอฟต์สตาร์ทเตอร์ ออโต้ทรานส์ฟอร์เมอร์ และการเปรียบเทียบวิธีสตาร์ทมอเตอร์: กระแส แรงบิด แรงดันตก และราคา

ทุกวิธีที่ลดแรงดันตอนสตาร์ทมีกฎเดียวกันอยู่เบื้องหลัง: กระแสลดตามแรงดัน แต่แรงบิดลดตามกำลังสองของแรงดัน หน้านี้ใช้กฎนั้นเปรียบเทียบวิธีสตาร์ทแบบตัวเลข และอธิบายซอฟต์สตาร์ทเตอร์ซึ่งเป็นตัวเลือกยอดนิยมของงานปั๊มยุคใหม่

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • ลดแรงดันเป็น \(k\) เท่า → กระแส \(k\) เท่า แรงบิด \(k^2\) เท่า
  • ซอฟต์สตาร์ท: ไทริสเตอร์ตัดคลื่น ramp แรงดัน จำกัดกระแส 2–4 In แล้วบายพาส
  • ออโต้ทรานส์ tap \(a\): กระแสมอเตอร์ \(a\) เท่า กระแสสาย \(a^2\) เท่า แรงบิด \(a^2\) เท่า
  • หยุดนุ่ม (soft stop) ลดค้อนน้ำในท่อปั๊ม — จุดเด่นที่สตาร์-เดลต้าทำไม่ได้

กฎของการสตาร์ทด้วยแรงดันลด กลาง

T1 Reduced-voltage starting การสตาร์ทด้วยแรงดันลด

\[ \frac{V}{V_n} = k \;\Rightarrow\; I_{st} = k\,I_{st,DOL} \qquad T_{st} = k^2\,T_{st,DOL} \]

T2 Torque at a current limit แรงบิดเมื่อจำกัดกระแส

\[ T_{st} = T_{st,DOL}\left(\frac{I_{lim}}{I_{st,DOL}}\right)^2 \]
ตัวอย่าง T-1

มอเตอร์ Ia/In = 6.5 Ta/Tn = 2.2 จำกัดกระแสที่ 3 In

  1. \(k = 3/6.5 = 0.46\) → แรงดันเริ่มต้นราว 46 %

  2. T2: \(T_{st} = 2.2(0.46)^2 = 0.47\) Tn — พอสำหรับปั๊มหอยโข่ง (~0.15 Tn) แต่ไม่พอสำหรับสายพานที่มีของ (~1.0–1.5 Tn)

  3. เทียบสตาร์-เดลต้า: กระแส \(6.5/3 = 2.2\) In แต่แรงบิด \(2.2/3 = 0.73\) Tn — กระแสต่ำกว่าแต่แรงบิดสูงกว่า เพราะแรงดันขดลวดลดเพียง \(1/\sqrt3\) ขณะที่กระแสสายลดถึง 1/3 (ทำงานเหมือนออโต้ทรานส์ \(a = 0.58\) ในตัวอย่าง T-2)

ซอฟต์สตาร์ทเตอร์ทำงานอย่างไร กลาง

ในแต่ละเฟสมีไทริสเตอร์ (SCR) สองตัวต่อแบบกลับหลังขนาน ตัวควบคุมจุดชนวนไทริสเตอร์ช้ากว่าจุดตัดศูนย์ของแรงดันไปเป็นมุม α ทำให้มอเตอร์ได้รับเพียงส่วนท้ายของแต่ละครึ่งคลื่น ลด α ลงเรื่อย ๆ แรงดัน rms ที่มอเตอร์ก็เพิ่มขึ้นเรื่อย ๆ เมื่อถึงแรงดันเต็ม คอนแทกเตอร์บายพาสภายในปิด ไทริสเตอร์หยุดนำ จึงไม่มีความร้อนสูญเสียขณะเดินปกติ

T3 RMS voltage vs firing angle (resistive approximation) แรงดัน rms กับมุมจุดชนวน

\[ \frac{V_{rms}}{V} = \sqrt{1 - \frac{\alpha}{\pi} + \frac{\sin 2\alpha}{2\pi}} \]

สูตร T3 ใช้กับโหลดความต้านทานเพื่อให้เห็นแนวโน้ม มอเตอร์เป็นโหลดเหนี่ยวนำที่กระแสตามหลัง ช่วงนำกระแสจึงยาวกว่านี้ ซอฟต์สตาร์ทเตอร์จริงวัดกระแสแล้วปรับ α แบบป้อนกลับ

โหมดสตาร์ทที่พบ

  • Voltage ramp: เริ่มที่แรงดันตั้งต้น (30–60 %) แล้วเพิ่มเป็นเส้นตรงในเวลาที่ตั้ง (5–30 s)
  • Current limit: ปรับแรงดันให้กระแสไม่เกิน k·In (2–4 In) ตลอดการเร่ง
  • Torque control: คุมแรงบิดให้เพิ่มเรียบ ความเร็วเพิ่มแทบเป็นเส้นตรง เหมาะกับปั๊มและสายพาน
  • Kick start: จ่ายแรงดันสูงสั้น ๆ ตอนเริ่ม เพื่อเอาชนะแรงเสียดทานสถิต
  • Soft stop / pump stop: ลดแรงดันช้า ๆ ตอนหยุด ให้น้ำในท่อชะลอตัวไม่กระแทกวาล์วกันกลับ (ค้อนน้ำ)

การต่อและข้อควรระวัง

  • ต้องมีอุปกรณ์ป้องกันลัดวงจรต้นทาง: เบรกเกอร์สำหรับ Type 1 หรือฟิวส์เซมิคอนดักเตอร์สำหรับ Type 2 ตามตารางผู้ผลิต
  • ห้ามต่อคาปาซิเตอร์ปรับ PF ระหว่างซอฟต์สตาร์ทเตอร์กับมอเตอร์ — ต่อด้านไฟเข้า และตัดออกขณะ ramp
  • ตั้งกระแสพิกัดมอเตอร์ คลาสโอเวอร์โหลด จำนวนสตาร์ทต่อชั่วโมงตามที่ผู้ผลิตกำหนด (ไทริสเตอร์ร้อนขณะสตาร์ท)
  • ต้องมีคอนแทกเตอร์หรือสวิตช์ตัดตอนด้านไฟเข้าสำหรับการแยกไฟเพื่อซ่อม (ไทริสเตอร์ปิดไม่ถือเป็นการแยกไฟ)

สตาร์ทด้วยออโต้ทรานส์ฟอร์เมอร์ ขั้นสูง

ออโต้ทรานส์ฟอร์เมอร์สามเฟสมีแท็ป เช่น 50 % 65 % 80 % มอเตอร์ได้แรงดัน \(aV\) กระแสมอเตอร์ลดเป็น \(a\) เท่า แต่เพราะหม้อแปลงแปลงกระแส กระแสในสายเมนลดเป็น \(a^2\) เท่า — ลดกระแสสายได้ดีกว่าวิธีความต้านทานหรือซอฟต์สตาร์ทที่แรงบิดเท่ากัน ใช้กับมอเตอร์ใหญ่ เช่น ปั๊มสูบน้ำดิบ คอมเพรสเซอร์ใหญ่ (มักทำเป็นแบบ Korndorfer ที่เปลี่ยนจังหวะแบบปิดวงจร)

T4 Autotransformer starter สตาร์ทด้วยออโต้ทรานส์ฟอร์เมอร์ แท็ป \(a\)

\[ I_{motor} = a\,I_{st,DOL} \qquad I_{line} = a^2\,I_{st,DOL} \qquad T_{st} = a^2\,T_{st,DOL} \]
ตัวอย่าง T-2

แท็ป 65 % กับมอเตอร์ Ia/In = 7 Ta/Tn = 2.3

  1. \(a^2 = 0.4225\) → กระแสสาย \(0.4225 \times 7 = 2.96\) In · แรงบิด \(0.4225 \times 2.3 = 0.97\) Tn

  2. เทียบซอฟต์สตาร์ทที่กระแสสายเท่ากัน 2.96 In: T2 → \(2.3(2.96/7)^2 = 0.41\) Tn เท่านั้น

  3. ออโต้ทรานส์ให้แรงบิดมากกว่าเกือบสองเท่าที่กระแสสายเท่ากัน แลกกับขนาด น้ำหนัก และราคา
