// บทที่ 21.1 · ควบคุมมอเตอร์ AC · Induction Motor

หลักการมอเตอร์เหนี่ยวนำสามเฟสสำหรับอุตสาหกรรม: สนามแม่เหล็กหมุน สลิป แรงบิด-ความเร็ว กระแสสตาร์ท และแผ่นป้าย

ก่อนจะเลือกคอนแทกเตอร์หรือออกแบบวงจรสตาร์ท ต้องรู้ว่ามอเตอร์ “ต้องการ” อะไรจากวงจร: ตอนสตาร์ทมันดึงกระแสเท่าไร ให้แรงบิดเท่าไร และแรงดันที่ตกลงมีผลอย่างไร หน้านี้อธิบายจากฟิสิกส์ถึงตัวเลขบนแผ่นป้าย โดยใช้มอเตอร์ 7.5 kW 4 ขั้ว 400 V 50 Hz ตัวเดียวกันทั้งชุด

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • กระแสสามเฟสห่างกัน 120° สร้างสนามแม่เหล็กหมุนด้วย \(n_s = 120f/p\)
  • โรเตอร์หมุนช้ากว่าเล็กน้อย สลิป \(s\) 1–5 % ที่พิกัด · แรงบิดพิกัด \(T = 9550P/n\)
  • ตอนสตาร์ท (\(s = 1\)) กระแส 6–8 In แต่แรงบิดเพียง 1.5–2.5 Tn
  • แรงบิดแปรตามกำลังสองของแรงดัน: แรงดันตก 10 % แรงบิดหาย 19 %
  • kW บนป้าย = กำลังกลที่เพลา · กระแสพิกัด \(I_n = P/(\sqrt3 V \eta \cos\varphi)\) ≈ 2 A/kW ที่ 400 V

ส่วนประกอบ พื้นฐาน

มอเตอร์เหนี่ยวนำกรงกระรอก (squirrel-cage) ที่ใช้มากที่สุดในโรงงานมีสองส่วน: สเตเตอร์ แกนเหล็กแผ่นบางที่มีขดลวดสามชุดวางห่างกัน 120° ทางไฟฟ้า และ โรเตอร์ ที่เป็นแท่งอะลูมิเนียมหรือทองแดงหล่อเข้ากับแหวนลัดวงจรทั้งสองปลาย ไม่มีแปรงถ่าน ไม่มีคอมมิวเตเตอร์ จึงทนทานและบำรุงรักษาน้อย แบบที่พบบ่อยคือ TEFC (Totally Enclosed Fan Cooled, รหัส IC411) มีพัดลมบนเพลาเป่าลมผ่านครีบ

สนามแม่เหล็กหมุนและความเร็วซิงโครนัส พื้นฐาน

เมื่อป้อนกระแสสามเฟสที่ห่างกัน 120° ทางเวลา เข้าขดลวดที่วางห่างกัน 120° ทางพื้นที่ ผลรวมเวกเตอร์ของสนามทั้งสามมีขนาดคงที่เท่ากับ 1.5 เท่าของสนามสูงสุดของเฟสเดียว และ หมุน ไปรอบสเตเตอร์ด้วยความเร็วคงที่ นี่คือหัวใจของมอเตอร์ AC สามเฟส: สร้างการหมุนได้โดยไม่มีชิ้นส่วนเคลื่อนที่

สลิปและแรงบิด กลาง

สนามหมุนตัดผ่านแท่งโรเตอร์ เหนี่ยวนำแรงดันและกระแสในโรเตอร์ (กฎของฟาราเดย์) กระแสนี้อยู่ในสนามแม่เหล็กจึงเกิดแรง \(F = BIL\) ผลักโรเตอร์ให้หมุนตามสนาม แต่ถ้าโรเตอร์ทันสนามพอดี การตัดเส้นแรงจะหายไป แรงบิดเป็นศูนย์ โรเตอร์จึงหมุนช้ากว่าเสมอ — ชื่อ “มอเตอร์อะซิงโครนัส”

M2 Slip สลิป

\[ s = \frac{n_s - n}{n_s} \qquad n = n_s(1 - s) \]

M3 Rotor frequency ความถี่กระแสในโรเตอร์

\[ f_r = s\, f \]

M4 Torque from power and speed แรงบิดจากกำลังและความเร็ว

\[ T = \frac{P}{\omega} = \frac{60\,P}{2\pi n} \;\;\Rightarrow\;\; T\,[\text{N}{\cdot}\text{m}] = \frac{9550\, P\,[\text{kW}]}{n\,[\text{rpm}]} \]
ตัวอย่าง M-1

มอเตอร์ 7.5 kW 4 ขั้ว 50 Hz แผ่นป้าย 1470 rpm

  1. M1: \(n_s = 120(50)/4 = 1500\) rpm

  2. M2: \(s = (1500 - 1470)/1500 = 0.02 = 2\,\%\) · M3: \(f_r = 0.02 \times 50 = 1\) Hz (กระแสโรเตอร์เปลี่ยนทิศช้ามาก)

  3. M4: \(T_n = 9550(7.5)/1470 = 48.7\) N·m — ค่านี้ใช้เทียบกับแรงบิดโหลดและแรงบิดสตาร์ท

วงจรสมมูลและการไหลของกำลัง ขั้นสูง

มอเตอร์เหนี่ยวนำคือหม้อแปลงที่ขดทุติยภูมิ (โรเตอร์) หมุนได้ เมื่ออ้างอิงค่าโรเตอร์มาด้านสเตเตอร์ จะได้วงจรต่อเฟสในรูป 3 ความต้านทานโรเตอร์ปรากฏเป็น \(R_2'/s\) ซึ่งแยกเป็นการสูญเสียทองแดงโรเตอร์ \(R_2'\) กับ “ตัวต้านทานโหลด” \(R_2'(1-s)/s\) ที่แทนกำลังกล

M5 Power split in the rotor การแบ่งกำลังในโรเตอร์

\[ P_{ag} = 3 I_2'^2 \frac{R_2'}{s} \qquad P_{cu2} = s\,P_{ag} \qquad P_{mech} = (1 - s)\,P_{ag} \qquad T = \frac{P_{ag}}{\omega_s} \]

ผลสำคัญเชิงปฏิบัติ: การสูญเสียในโรเตอร์ = สลิป × กำลังช่องอากาศ มอเตอร์ที่เดินด้วยสลิปสูง (แรงดันต่ำ โหลดเกิน ต่อสตาร์ผิด) จึงร้อนทันที และการลดความเร็วด้วยการเพิ่มสลิปเป็นวิธีที่สิ้นเปลือง — ต่างจากการลดความถี่ด้วยอินเวอร์เตอร์ที่สลิปยังเล็ก

ตัวอย่าง M-2

กำลังที่ไหลผ่านโรเตอร์ของมอเตอร์ 7.5 kW s = 2 %

  1. กำลังกลรวมแรงเสียดทานและพัดลม ≈ 7.5 + 0.1 = 7.6 kW

  2. M5: \(P_{ag} = P_{mech}/(1-s) = 7.6/0.98 = 7.76\) kW · \(P_{cu2} = 0.02(7.76) = 0.155\) kW

  3. ถ้ามอเตอร์ถูกบังคับให้เดินที่ s = 10 % ด้วยแรงบิดเท่าเดิม \(P_{cu2}\) จะเพิ่มเป็นราว 0.78 kW — ความร้อนในโรเตอร์เพิ่มห้าเท่า

กราฟแรงบิด-ความเร็ว และกระแสสตาร์ท กลาง

กราฟในรูป 4 คำนวณจากวงจรสมมูลของมอเตอร์ตัวอย่าง (โรเตอร์กรงคู่ ปรับค่าให้ตรงข้อมูลแคตตาล็อกทั่วไป) จุดที่ต้องรู้จัก:

  • แรงบิดเริ่ม (locked-rotor torque) Ts ≈ 2.2 Tn ที่ n = 0 — ต้องมากกว่าแรงบิดเริ่มของโหลดพอสมควร
  • แรงบิดสูงสุด (breakdown) Tk ≈ 3 Tn ใกล้ 85–90 % ความเร็ว — ถ้าโหลดเกินจุดนี้มอเตอร์จะหยุด (stall)
  • ย่านทำงาน ด้านขวาของจุดแรงบิดสูงสุด กราฟเกือบเป็นเส้นตรง แรงบิดแปรตามสลิป
  • กระแสสตาร์ท ≈ 6.5 In แทบไม่ลดลงจนความเร็วถึง 80 % — ช่วงเร่งทั้งหมดจึงเป็นช่วงกระแสสูง

M6 Rated current กระแสพิกัดมอเตอร์สามเฟส

\[ I_n = \frac{P_{out}}{\sqrt{3}\,V_L\,\eta\,\cos\varphi} \qquad P_{in} = \frac{P_{out}}{\eta} \]

M7 Starting current กระแสสตาร์ทจากอัตราส่วนบนแผ่นป้าย

\[ I_{st} = \left(\frac{I_a}{I_n}\right) I_n \qquad \frac{I_a}{I_n} \approx 6\text{–}8 \]

M8 Torque versus voltage แรงบิดแปรตามกำลังสองของแรงดัน

\[ T(s) \propto V^2 \qquad \frac{T_2}{T_1} = \left(\frac{V_2}{V_1}\right)^2 \qquad I(s) \propto V \]
ตัวอย่าง M-3

กระแสพิกัด กระแสสตาร์ท และผลของแรงดันตก

  1. M6: \(I_n = 7500/(\sqrt3 \times 400 \times 0.904 \times 0.82) = 7500/513.6 = 14.6\) A — ตรงกับแผ่นป้าย

  2. \(P_{in} = 7.5/0.904 = 8.30\) kW · \(S = \sqrt3(400)(14.6) = 10.1\) kVA · \(Q = \sqrt{10.1^2 - 8.30^2} = 5.8\) kvar

  3. M7: \(I_{st} = 6.5 \times 14.6 = 95\) A ถ้าสตาร์ทตรง

  4. M8: ถ้าแรงดันขณะสตาร์ทตกเหลือ 90 % แรงบิดเริ่ม \(2.2 \times 0.9^2 = 1.78\) Tn และกระแส \(95 \times 0.9 = 86\) A

สิ่งที่ช่างต้องจำหน้างาน

  • ดูแผ่นป้ายก่อนต่อทุกครั้ง: แรงดันกับการต่อ (Δ/Y) ต้องตรงกับระบบ 400 V
  • กระแสขณะเดินตัวเปล่า (no-load) ของมอเตอร์ 4 ขั้วประมาณ 30–50 % ของ In — ไม่ได้แปลว่ามอเตอร์ผิดปกติ
  • วัดกระแสทั้งสามเฟส ความต่างเกิน ~10 % ให้ตรวจแรงดันไม่สมดุล หน้าสัมผัสคอนแทกเตอร์ และขั้วต่อหลวม
  • มอเตอร์ทำงานปกติร้อนจนจับไม่ได้ (60–80 °C ที่โครง) เป็นเรื่องปกติของคลาส F วัดด้วยเทอร์โมมิเตอร์แทนการจับ
