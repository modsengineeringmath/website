// เวกเตอร์ · ส่วนที่ 1 · Direction cosines & 3D force components

ทิศทางโคไซน์และการแตกแรงสามมิติ

ในสองมิติ มุมเดียวบอกทิศของแรงได้ครบ แต่ในสามมิติ สายเคเบิลของเสาอากาศ แรงบนข้อต่อแขนกล หรือสนามแม่เหล็กที่เซนเซอร์อ่านได้ ต้องบอกทิศด้วยมุมกับสามแกน บทนี้สร้างเครื่องมือหลักของสแตติกส์สามมิติ: มุม α β γ ทิศทางโคไซน์ เวกเตอร์หนึ่งหน่วย การแตกแรงสองขั้น และการเขียนแรงตามแนวเส้นจากพิกัด พร้อมฉาก 3 มิติที่ลากหมุนดูได้ทุกมุม

เขียนโดย อาจารย์มดอัปเดต
นิยาม α β γมุมราบ-มุมเงยแรงตามสายเคเบิลฉาก 3 มิติ
สรุปใน 30 วินาที
  • \(\cos\alpha=F_x/F,\ \cos\beta=F_y/F,\ \cos\gamma=F_z/F\) และ \(\mathbf u_F=(\cos\alpha,\cos\beta,\cos\gamma)\)
  • เอกลักษณ์ \(\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1\) ทำให้รู้สองมุมแล้วหามุมที่สามได้ (มีสองคำตอบ)
  • แตกแรงสองขั้น: \(F_h=F\cos\varphi\), \(F_z=F\sin\varphi\), แล้ว \(F_x=F_h\cos\theta\), \(F_y=F_h\sin\theta\)
  • แรงตามสาย: \(\mathbf F=F\,\dfrac{\mathbf r_B-\mathbf r_A}{\lVert\mathbf r_B-\mathbf r_A\rVert}\) ไม่ต้องหามุมเลย

1. ทำไมสามมิติต้องใช้มุมกับสามแกน พื้นฐาน

แรง 500 N ที่ “เอียง 60° จากแกน x” ในสามมิติยังไม่ได้บอกอะไรมากนัก เพราะเวกเตอร์ทุกเส้นบนผิวกรวยรอบแกน x ที่มีมุมยอด 60° ทำมุม 60° กับแกน x เหมือนกันหมด เราจึงต้องระบุเพิ่มว่าเวกเตอร์ทำมุมกับแกน y และแกน z เท่าใด หรือใช้มุมสองมุมแบบอื่น เช่น มุมราบกับมุมเงยแบบที่ใช้หันจานดาวเทียม

ทางวิศวกรรม ทิศของแรงสามมิติมักมาจากสามแหล่ง ซึ่งบทนี้จะสอนให้แปลงไปมาได้ทั้งหมด:

แบบ ①

มุมกับสามแกน α β γ

ตำราสแตติกส์และแบบงานโครงสร้าง เช่น “แรงทำมุม 60°, 45° และ 120° กับแกน x, y, z”

แบบ ②

มุมราบ θ + มุมเงย φ

เสาอากาศ จานดาวเทียม แผงโซลาร์ ทิศของลมหรือแสงอาทิตย์ บอกเป็นทิศบนพื้นแล้วเงยขึ้น

แบบ ③

พิกัดสองจุดบนแนวแรง

สายเคเบิล สายยึดเสา โซ่รอก แขนกล รู้ว่าสายวิ่งจากจุดไหนไปจุดไหน

2. นิยามมุม α β γ และทิศทางโคไซน์ พื้นฐาน

วางหางของเวกเตอร์ \(\mathbf F\) ที่จุดกำเนิด มุม α คือมุมระหว่าง \(\mathbf F\) กับแกน +x, β คือมุมกับ +y และ γ คือมุมกับ +z ทุกมุมอยู่ในช่วง 0° ถึง 180° (ไม่ใช้มุมติดลบ เพราะเป็นมุมระหว่างสองทิศในอวกาศ ไม่ใช่การหมุนในระนาบ) เมื่อฉายเวกเตอร์ลงบนแกน x จะได้ \(F_x=F\cos\alpha\) ซึ่งก็คือ dot product กับเวกเตอร์ฐาน \(\mathbf F\cdot\mathbf i=F(1)\cos\alpha\)

K1 Direction cosines ทิศทางโคไซน์

\[ \cos\alpha=\frac{F_x}{F},\qquad \cos\beta=\frac{F_y}{F},\qquad \cos\gamma=\frac{F_z}{F},\qquad F=\lVert\mathbf F\rVert=\sqrt{F_x^2+F_y^2+F_z^2} \]

เครื่องหมายของโคไซน์ตรงกับเครื่องหมายขององค์ประกอบ: \(F_x<0\) แปลว่า \(\alpha>90^\circ\) ใช้ \(\arccos\) ได้ตรง ๆ เพราะผลลัพธ์อยู่ในช่วง 0°–180° พอดี ไม่มีปัญหาควอดแรนต์แบบ arctan

K2 Unit vector from direction cosines เวกเตอร์หนึ่งหน่วยคือชุดทิศทางโคไซน์

\[ \mathbf u_F=\frac{\mathbf F}{F}=\cos\alpha\,\mathbf i+\cos\beta\,\mathbf j+\cos\gamma\,\mathbf k,\qquad \mathbf F=F\,\mathbf u_F \]

นี่คือการแยก “ขนาด” ออกจาก “ทิศ” ให้ชัด: ทิศเก็บใน \(\mathbf u_F\) ที่ไม่มีหน่วย ขนาดเก็บใน \(F\) ที่มีหน่วยนิวตัน

K3 Fundamental identity ผลบวกกำลังสองของทิศทางโคไซน์

\[ \cos^2\alpha+\cos^2\beta+\cos^2\gamma=1 \]

พิสูจน์: \(\lVert\mathbf u_F\rVert^2=1\) และ \(\lVert\mathbf u_F\rVert^2=\cos^2\alpha+\cos^2\beta+\cos^2\gamma\) จึงเท่ากัน ในสองมิติจะลดรูปเป็น \(\cos^2\theta+\sin^2\theta=1\) เพราะมุมกับแกน y เท่ากับ \(90^\circ-\theta\)

ตัวอย่าง K-0 · จากองค์ประกอบสู่มุม

แรง \(\mathbf F=(300,400,500)\) N จงหาขนาด ทิศทางโคไซน์ และมุม α β γ

  1. ขนาด \(F=\sqrt{300^2+400^2+500^2}=\sqrt{500{,}000}=707.11\) N

  2. \(\cos\alpha=300/707.11=0.4243\Rightarrow\alpha=64.90^\circ\); \(\cos\beta=0.5657\Rightarrow\beta=55.55^\circ\); \(\cos\gamma=0.7071\Rightarrow\gamma=45.00^\circ\)

  3. ตรวจ \(0.18+0.32+0.50=1\) ✓ และ \(\mathbf u_F=(0.4243,0.5657,0.7071)\)

\(F=707.1\) N · \(\alpha=64.9^\circ,\ \beta=55.6^\circ,\ \gamma=45.0^\circ\) — ค่าเริ่มต้นในแล็บ 3 มิติด้านล่าง ลองลากหมุนดูว่ามุม γ อยู่ระหว่างลูกศรกับแกน z จริง

3. จากมุมสู่องค์ประกอบ และการหามุมที่สาม กลาง

K4 Components from magnitude and direction angles องค์ประกอบจากขนาดและมุม

\[ \mathbf F=F\cos\alpha\,\mathbf i+F\cos\beta\,\mathbf j+F\cos\gamma\,\mathbf k \]

K5 The third angle มุมที่สามมีสองคำตอบ

\[ \cos\gamma=\pm\sqrt{1-\cos^2\alpha-\cos^2\beta},\qquad \gamma_2=180^\circ-\gamma_1 \]

เครื่องหมาย + เมื่อแรงชี้ขึ้น (\(F_z\ge0\)) และ − เมื่อชี้ลง ถ้า \(\cos^2\alpha+\cos^2\beta>1\) ชุดมุมนั้นเป็นไปไม่ได้ทางเรขาคณิต เช่น α = β = 30° (เพราะ 0.75 + 0.75 = 1.5)

ตัวอย่าง K-1 · โจทย์คลาสสิกของสแตติกส์

แรง 500 N ทำมุม α = 60° กับแกน x และ β = 45° กับแกน y แรงชี้ขึ้น จงหา γ และเขียนเวกเตอร์แรง

  1. \(\cos^2\gamma=1-\cos^2 60^\circ-\cos^2 45^\circ=1-0.25-0.5=0.25\Rightarrow\cos\gamma=\pm0.5\)

  2. แรงชี้ขึ้น เลือก \(\cos\gamma=+0.5\Rightarrow\gamma=60^\circ\) (ถ้าชี้ลงจะได้ \(\gamma=120^\circ\))

  3. \(\mathbf F=500(\cos60^\circ,\cos45^\circ,\cos60^\circ)=(250,\ 353.6,\ 250)\) N

  4. ตรวจขนาด \(\sqrt{250^2+353.6^2+250^2}=500\) N ✓

\(\gamma=60^\circ\) · \(\mathbf F=250\mathbf i+353.6\mathbf j+250\mathbf k\) N

4. แตกแรงสองขั้นด้วยมุมราบ θ และมุมเงย φ กลาง

เมื่อโจทย์บอกทิศเป็น “หันไปทาง 30° จากแกน x บนพื้น แล้วเงยขึ้น 50°” ให้แตกสองครั้ง: ครั้งแรกแยกแรงเป็นส่วนตั้ง \(F_z\) กับส่วนนอน \(F_h\) ในระนาบแนวดิ่งที่มีแรงอยู่ ครั้งที่สองแยก \(F_h\) บนพื้นเป็น \(F_x\) และ \(F_y\) เหมือนโจทย์สองมิติ ภาพในใจคือ “เงาของแรงบนพื้น” \(F_h\) แล้วค่อยแตกเงานั้น

K6 Two-step resolution (azimuth θ, elevation φ) แตกแรงสองขั้น

\[ F_h=F\cos\varphi,\quad F_z=F\sin\varphi,\quad F_x=F_h\cos\theta=F\cos\varphi\cos\theta,\quad F_y=F\cos\varphi\sin\theta \]

กลับทาง: \(F_h=\sqrt{F_x^2+F_y^2}\), \(\theta=\operatorname{atan2}(F_y,F_x)\), \(\varphi=\operatorname{atan2}(F_z,F_h)\) บางตำราใช้มุมจากแกน z (zenith) \(\phi_z=90^\circ-\varphi\) แทน ซึ่งก็คือ γ ของ K1 นั่นเอง

ตัวอย่าง K-2 · สายยึดเสาอากาศ

แรงดึงในสาย 700 N หันไปทาง θ = 30° จากแกน +x บนพื้น และเงยขึ้น φ = 50° จากพื้น จงหาองค์ประกอบและมุม α β γ

  1. แยกตั้ง-นอน: \(F_z=700\sin50^\circ=536.2\) N, \(F_h=700\cos50^\circ=450.0\) N

  2. แยกเงาบนพื้น: \(F_x=450.0\cos30^\circ=389.7\) N, \(F_y=450.0\sin30^\circ=225.0\) N

  3. มุมกับแกน: \(\alpha=\arccos(389.7/700)=56.17^\circ\), \(\beta=\arccos(225.0/700)=71.25^\circ\), \(\gamma=\arccos(536.2/700)=40.00^\circ\)

  4. สังเกต \(\gamma=90^\circ-\varphi\) เสมอ แต่ \(\alpha\ne\theta\) เพราะ α วัดในอวกาศ ไม่ใช่บนพื้น

\(\mathbf F=(389.7,\ 225.0,\ 536.2)\) N · α = 56.2°, β = 71.3°, γ = 40.0°

ข้อผิดพลาดยอดนิยม

ใช้ \(F_x=F\cos\theta\) ตรง ๆ โดยลืมคูณ \(\cos\varphi\) ก่อน ตัวเลข \(700\cos30^\circ=606\) N ใหญ่เกินจริง ตรวจได้ทันทีว่า \(F_x^2+F_y^2+F_z^2\) จะมากกว่า \(F^2\)

5. แรงตามแนวเส้น: จากพิกัดสองจุดเป็นเวกเตอร์แรง กลาง

สายเคเบิลรับแรงดึงได้ในแนวสายเท่านั้น ถ้ารู้พิกัดจุดยึด A และจุด B ที่สายวิ่งไปหา เราได้ทิศของแรงทันทีจากเวกเตอร์ตำแหน่ง \(\mathbf r_{AB}=\mathbf r_B-\mathbf r_A\) วิธีนี้เป็นวิธีที่วิศวกรใช้จริงมากที่สุด เพราะแบบงานบอกพิกัด ไม่ได้บอกมุม

K7 Force directed along a line แรงตามแนวเส้นจาก A ไป B

\[ \mathbf r_{AB}=(x_B-x_A)\mathbf i+(y_B-y_A)\mathbf j+(z_B-z_A)\mathbf k,\qquad \mathbf u_{AB}=\frac{\mathbf r_{AB}}{\lVert\mathbf r_{AB}\rVert},\qquad \mathbf F=F\,\mathbf u_{AB} \]

ทิศทางโคไซน์ของแรงคือองค์ประกอบของ \(\mathbf u_{AB}\) ระวังทิศ: แรงที่สายกระทำต่อจุด A ชี้จาก A ไป B (สายดึง A เข้าหา B) ส่วนแรงที่กระทำต่อ B ชี้กลับจาก B ไป A

ตัวอย่าง K-3 · สายยึดจากฐานถึงยอดเสา

สายวิ่งจาก A(0, 0, 0) m ไป B(2, −3, 6) m มีแรงดึง 840 N จงเขียนแรงที่สายกระทำต่อ A เป็นเวกเตอร์ และหามุม α β γ

  1. \(\mathbf r_{AB}=(2,-3,6)\) m ความยาว \(\sqrt{4+9+36}=7\) m (ชุดตัวเลข 2-3-6-7 จำง่าย)

  2. \(\mathbf u_{AB}=(2/7,\ -3/7,\ 6/7)=(0.2857,\ -0.4286,\ 0.8571)\)

  3. \(\mathbf F=840\,\mathbf u_{AB}=(240,\ -360,\ 720)\) N

  4. \(\alpha=\arccos(2/7)=73.40^\circ\), \(\beta=\arccos(-3/7)=115.38^\circ\) (เกิน 90° เพราะ \(F_y<0\)), \(\gamma=\arccos(6/7)=31.00^\circ\)

\(\mathbf F=240\mathbf i-360\mathbf j+720\mathbf k\) N · ตรวจ \(\sqrt{240^2+360^2+720^2}=840\) N ✓

6. รวมแรงสามมิติ: องค์ประกอบก่อน ขนาดทีหลัง กลาง

K8 Resultant of 3D forces แรงลัพธ์สามมิติและทิศของมัน

\[ \mathbf R=\Big(\sum F_x\Big)\mathbf i+\Big(\sum F_y\Big)\mathbf j+\Big(\sum F_z\Big)\mathbf k,\qquad \cos\alpha_R=\frac{R_x}{R},\ \cos\beta_R=\frac{R_y}{R},\ \cos\gamma_R=\frac{R_z}{R} \]
ตัวอย่าง K-4 · เสาไฟฟ้ากับสายยึดสองเส้น

ยอดเสาอยู่ที่ P(0, 0, 12) m สาย PA ไปสมอ A(4, −3, 0) m มีแรงดึง 650 N สาย PB ไป B(−3, 4, 0) m มีแรงดึง 390 N จงหาแรงลัพธ์ที่สายทั้งสองกระทำต่อยอดเสา

  1. \(\mathbf r_{PA}=(4,-3,-12)\), \(\lVert\mathbf r_{PA}\rVert=13\) m → \(\mathbf F_A=650(4,-3,-12)/13=(200,-150,-600)\) N

  2. \(\mathbf r_{PB}=(-3,4,-12)\), \(\lVert\mathbf r_{PB}\rVert=13\) m → \(\mathbf F_B=390(-3,4,-12)/13=(-90,120,-360)\) N

  3. รวมองค์ประกอบ \(\mathbf R=(110,\ -30,\ -960)\) N, \(R=\sqrt{110^2+30^2+960^2}=966.7\) N

  4. \(\alpha_R=83.47^\circ,\ \beta_R=91.78^\circ,\ \gamma_R=173.23^\circ\): แรงลัพธ์เกือบดิ่งลง กดเสาเป็นแรงอัด 960 N

  5. อ่านผลเชิงวิศวกรรม: ยังมีส่วนแนวนอน \((110,-30)\) N ทำให้ยอดเสาถูกดัด ต้องเพิ่มสายเส้นที่สามหรือปรับแรงดึงให้ส่วนแนวนอนหักล้างกันเป็นศูนย์

\(\mathbf R=(110,-30,-960)\) N · \(R=966.7\) N · ส่วนแนวนอน 114.0 N ต้องจัดการต่อ

7. ฉาก 3 มิติ: หมุนดูมุม α β γ ให้เห็นจริง พื้นฐาน

ลากภาพเพื่อหมุนกล้องรอบเวกเตอร์ ปุ่ม xy · xz · yz ให้มุมมองจากบน หน้า และข้าง ลองสามการทดลองนี้:

  1. เลือก “ขนาด + มุม α β” ตั้ง α = β = 30° ระบบจะเตือนว่าเป็นไปไม่ได้ อธิบายด้วย K3
  2. เปลี่ยน Fz ให้ติดลบ แล้วดูว่า γ ข้าม 90° ขณะที่ α β ไม่เปลี่ยนเครื่องหมาย
  3. มองจากบน (ปุ่ม xy) แล้วสังเกตว่า “เงา” F_h บนพื้นคือสิ่งที่ใช้กับมุมราบ θ ในตัวอย่าง K-2

8. ทิศทางโคไซน์กับการหมุนแกน: เมทริกซ์โคไซน์ทิศทาง ขั้นสูง

ถ้ามีกรอบพิกัดใหม่ \(x'y'z'\) ที่เอียงจากกรอบเดิม แกนใหม่แต่ละแกนก็มีทิศทางโคไซน์สามค่าเทียบกับแกนเดิม เก้าค่านี้จัดเป็นเมทริกซ์ที่เรียกว่า direction cosine matrix (DCM) ซึ่งเป็นเมทริกซ์หมุนนั่นเอง องค์ประกอบของเวกเตอร์ในกรอบใหม่คือ dot product กับแกนใหม่แต่ละแกน

K9 Direction cosine matrix เมทริกซ์โคไซน์ทิศทาง

\[ \begin{bmatrix}F_{x'}\\F_{y'}\\F_{z'}\end{bmatrix}=\begin{bmatrix}\cos\theta_{x'x}&\cos\theta_{x'y}&\cos\theta_{x'z}\\\cos\theta_{y'x}&\cos\theta_{y'y}&\cos\theta_{y'z}\\\cos\theta_{z'x}&\cos\theta_{z'y}&\cos\theta_{z'z}\end{bmatrix}\begin{bmatrix}F_x\\F_y\\F_z\end{bmatrix} \]

แต่ละแถวคือเวกเตอร์หนึ่งหน่วยของแกนใหม่ เขียนในกรอบเดิม ทุกแถวยาว 1 และตั้งฉากกัน (K3 ใช้กับทุกแถว) รายละเอียดการหมุนอยู่ในบท การหมุนแกนพิกัด

9. ใช้กับงานไฟฟ้า: สนามแม่เหล็กจากเซนเซอร์และทิศของสนาม กลาง

แมกนีโตมิเตอร์สามแกนในโทรศัพท์ โดรน และมิเตอร์อัจฉริยะ อ่านค่าสนามแม่เหล็กออกมาเป็นสามองค์ประกอบ ทิศทางโคไซน์บอกว่าสนามชี้ไปทางใดเทียบกับตัวเครื่อง ส่วนมุมกับระนาบนอน (มุมจุ่ม) และมุมบนพื้น (heading) คือมุมเงยและมุมราบของ K6 แบบเดียวกับการหาทิศของสนามไฟฟ้าลัพธ์จากประจุหลายตัว

ตัวอย่าง K-5 · แมกนีโตมิเตอร์สามแกน (ตัวเลขสมมติ)

เซนเซอร์วางราบอ่าน \(\mathbf B=(30,\ -10,\ -15)\ \mu\)T จงหาขนาด ทิศทางโคไซน์ มุมกดลงจากแนวนอน และมุมบนพื้นจากแกน x

  1. \(B=\sqrt{30^2+10^2+15^2}=\sqrt{1225}=35\ \mu\)T

  2. \(\mathbf u_B=(0.8571,\ -0.2857,\ -0.4286)\) → α = 31.00°, β = 106.60°, γ = 115.38°

  3. ส่วนแนวนอน \(B_h=\sqrt{30^2+10^2}=31.62\ \mu\)T มุมกดลง \(\arctan(15/31.62)=25.38^\circ\) (เท่ากับ \(\gamma-90^\circ\))

  4. มุมบนพื้น \(\operatorname{atan2}(-10,30)=-18.43^\circ\) คือสนามแนวนอนเบนไปทาง −y จากแกน x ของเครื่อง

\(B=35\ \mu\)T · กดลง 25.4° · เบน −18.4° จากแกน x (เครื่องเข็มทิศจริงต้องชดเชยความเอียงของเครื่องด้วยการหมุนแกน)

สนามไฟฟ้าลัพธ์จากประจุสามตัวในสามมิติ ใช้ขั้นตอนเดียวกัน: รวมองค์ประกอบ แล้วหาทิศด้วย K8 ทดลองได้ใน บทสนามไฟฟ้าและแม่เหล็ก
