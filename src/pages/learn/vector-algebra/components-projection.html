องค์ประกอบและการฉายเวกเตอร์ (Components & Projection)

แรงหนึ่งแรงอาจทั้งดึงตามแนวคานและผลักด้านข้าง การแยกองค์ประกอบช่วยเขียนแรงในแกนที่คำนวณได้ ส่วนการฉายเวกเตอร์ช่วยตอบว่า “เวกเตอร์นี้มีส่วนไปตามทิศที่เราสนใจเท่าไร” เริ่มจากแกน x–y ที่คุ้นเคย แล้วขยายไปยังแกนเอียงและสามมิติ โดยแยกให้ชัดว่าคำตอบเป็นตัวเลขหรือเป็นลูกศร

เขียนโดย อาจารย์มดอัปเดต
ตัวอย่าง (3,4) ฉายบน (2,1)แรงสามมิติสรุปสูตรทดลองเวกเตอร์
สรุปใน 30 วินาที
  • ในแกนตั้งฉากมาตรฐาน \(\mathbf a=a_x\mathbf i+a_y\mathbf j+a_z\mathbf k\) ตัวเลข \(a_x,a_y,a_z\) มีเครื่องหมายได้
  • เมื่อ \(\mathbf b\ne\mathbf0\), scalar projection คือ \((\mathbf a\cdot\mathbf b)/\|\mathbf b\|\) และ vector projection คือ \([(\mathbf a\cdot\mathbf b)/(\mathbf b\cdot\mathbf b)]\mathbf b\)
  • ส่วนที่ตั้งฉากคือ \(\mathbf a_\perp=\mathbf a-\operatorname{proj}_{\mathbf b}\mathbf a\) ตรวจด้วย \(\mathbf a_\perp\cdot\mathbf b=0\)
  • ค่าฉายติดลบบอกว่าชี้สวนทางกับทิศที่เลือก ไม่ใช่ “ความยาวติดลบ”

1. Component คืออะไร: แยกลูกศรเป็นแกน พื้นฐาน

เลือกแกน x ไปทางขวาและแกน y ขึ้นบน เวกเตอร์ \(\mathbf a=(3,4)\) หมายถึงไปทาง x เป็นระยะ 3 หน่วย และทาง y เป็นระยะ 4 หน่วย ค่าทั้งสองเรียก องค์ประกอบสเกลาร์ (scalar components) ส่วนลูกศร \(3\mathbf i=(3,0)\) และ \(4\mathbf j=(0,4)\) เรียกองค์ประกอบเวกเตอร์ (vector components) เมื่อบวกกันจึงได้ลูกศรเดิม

P1 Cartesian components องค์ประกอบในฐานตั้งฉากมาตรฐาน

\[ \mathbf a=a_x\mathbf i+a_y\mathbf j\quad(2D),\qquad \mathbf a=a_x\mathbf i+a_y\mathbf j+a_z\mathbf k\quad(3D) \] \[ a_x=\mathbf a\cdot\mathbf i,\quad a_y=\mathbf a\cdot\mathbf j,\quad a_z=\mathbf a\cdot\mathbf k \]

\(\mathbf i=(1,0,0),\mathbf j=(0,1,0),\mathbf k=(0,0,1)\) แต่ละตัวขนาด 1 และตั้งฉากกัน สูตรดอทเพื่ออ่าน component ใช้คุณสมบัติทั้งสองนี้ หน่วยของ component เท่ากับหน่วยของเวกเตอร์

P2 Resolving a 2D vector เมื่อรู้ขนาดและมุม

\[ a_x=A\cos\theta,\qquad a_y=A\sin\theta,\qquad A=\sqrt{a_x^2+a_y^2} \]

\(A=\|\mathbf a\|\ge0\) และ \(\theta\) วัดทวนเข็มจากแกน +x ถ้าวัดจาก +y ต้องปรับตำแหน่ง sin/cos ให้ตรงรูป หามุมจาก component ด้วย \(\operatorname{atan2}(a_y,a_x)\) เพื่อรักษาควอดแรนต์

P3 Unit direction vector แยกขนาดออกจากทิศ

\[ \widehat{\mathbf b}=\frac{\mathbf b}{\|\mathbf b\|},\qquad \|\widehat{\mathbf b}\|=1,\qquad\mathbf b\ne\mathbf0 \]

เช่น \(\mathbf b=(2,1)\) ได้ \(\widehat{\mathbf b}=(2/\sqrt5,1/\sqrt5)\) ใช้บอกทิศเดียวกันโดยไม่มีขนาดมาปน เวกเตอร์ทิศทางนี้ไม่มีหน่วยเมื่อ component ของ b มีหน่วยเดียวกัน

ตัวอย่าง P-1 · แยกแรงที่ชี้ขึ้นทางซ้าย

แรงขนาด 100 N ทำมุม 120° จากแกน +x มีองค์ประกอบเท่าไร?

  1. วาดลูกศรในควอดแรนต์ที่ 2 จึงคาดว่า x ติดลบ แต่ y เป็นบวก

  2. ใช้ P2: \(F_x=100\cos120^\circ=-50\,\mathrm N\), \(F_y=100\sin120^\circ=50\sqrt3\,\mathrm N\)

  3. ตรวจขนาด: \(\sqrt{(-50)^2+(50\sqrt3)^2}=100\,\mathrm N\) ตรงกับโจทย์

\(\mathbf F=(-50,50\sqrt3)\,\mathrm N\approx(-50,86.60)\,\mathrm N\)

2. จาก 2D ไป 3D: มุมกับสามแกนและฐานที่เลือก กลาง

ในสามมิติ การบอกเพียง “ทำมุม 30°” ยังไม่พอระบุทิศ ต้องบอกว่ามุมกับแกนใด และมีข้อมูลอิสระเพียงพอ เช่น ให้สองมุมพร้อมเครื่องหมายของ component ที่เหลือ หรือให้พิกัดปลายทาง เวกเตอร์ \((2,-3,6)\) ขนาด 7 จึงมีเวกเตอร์หน่วย \((2/7,-3/7,6/7)\) ค่า y ติดลบบอกทิศสวนแกน +y

P4 Direction cosines มุมกับแกน +x, +y, +z

\[ \cos\alpha=\frac{a_x}{A},\quad\cos\beta=\frac{a_y}{A},\quad\cos\gamma=\frac{a_z}{A},\qquad \cos^2\alpha+\cos^2\beta+\cos^2\gamma=1 \]

\(A=\|\mathbf a\|\gt0\) และมุมทั้งสามอยู่ในช่วง 0°–180° ถ้า component ของแกนหนึ่งติดลบ มุมกับแกนบวกนั้นเป็นมุมป้าน เวกเตอร์ศูนย์ไม่มีมุมทิศทาง

P5 Components in an orthonormal basis เปลี่ยนเป็นแกนที่หมุนแล้ว

\[ a_r=\mathbf a\cdot\mathbf e_r,\qquad\mathbf a=\sum_{r=1}^{n}a_r\mathbf e_r\quad\text{เมื่อ }\mathbf e_r\cdot\mathbf e_s=\delta_{rs} \]

ฐานต้องยาวหนึ่งและตั้งฉากกันครบ n ทิศใน \(\mathbb R^n\) ถ้าใช้ฐานไม่ตั้งฉาก ค่าสัมประสิทธิ์ที่ประกอบเวกเตอร์ไม่เท่ากับดอทกับเวกเตอร์ฐานโดยทั่วไป ต้องแก้ระบบสมการแทน

เห็นความต่างของฐานทั่วไป: ให้ \(\mathbf e_1=(1,0)\), \(\mathbf e_2=(1,1)\) และ \(\mathbf a=(3,4)\) เขียนได้ \(\mathbf a=-\mathbf e_1+4\mathbf e_2\) แต่ \(\mathbf a\cdot\mathbf e_1=3\ne-1\) ค่าสัมประสิทธิ์ในฐานกับค่าฉายจึงเป็นคนละเรื่องเมื่อฐานไม่ตั้งฉาก

3. Scalar projection: “ไปตามทิศนี้เท่าไร” พร้อมเครื่องหมาย พื้นฐาน

สมมติเปิดไฟให้เงาของลูกศรตกตั้งฉากบนเส้นตามทิศ \(\mathbf b\) ความยาวแบบมีเครื่องหมายของเงานั้นคือ scalar projection หรือ scalar component of a along b เลือกทิศบวกตามลูกศร b ถ้าเงาชี้สวนทิศ b ค่าจะติดลบ การคำนวณใช้ dot product ซึ่งวัดความสอดคล้องของสองทิศ

P6 Signed scalar projection ค่าฉายสเกลาร์ที่มีเครื่องหมาย

\[ \operatorname{comp}_{\mathbf b}\mathbf a=\mathbf a\cdot\widehat{\mathbf b}=\frac{\mathbf a\cdot\mathbf b}{\|\mathbf b\|}=\|\mathbf a\|\cos\theta,\qquad\mathbf b\ne\mathbf0 \]

สมการที่มี \(\theta\) ใช้เมื่อ a และ b ไม่เป็นศูนย์ ส่วนสูตรดอทใช้ได้เมื่อ a เป็นศูนย์ โดยให้ค่าฉาย 0 ผลเป็นสเกลาร์ หน่วยเดียวกับ a

มุมระหว่างเวกเตอร์ที่ไม่เป็นศูนย์ค่าฉายความหมาย
\(0^\circ\le\theta\lt90^\circ\)เป็นบวกมีส่วนไปตามทิศ b
\(\theta=90^\circ\)0ไม่มีส่วนตามทิศ b
\(90^\circ\lt\theta\le180^\circ\)เป็นลบมีส่วนสวนทิศ b

ถ้า \(\mathbf a=(-3,4)\) และเลือก \(\mathbf b=(1,0)\) จะได้ค่าฉาย −3 แต่ความยาวเงาเท่ากับ 3 ถ้ากลับทิศเป้าหมายเป็น \((-1,0)\) ค่าฉายจะเป็น +3 นี่คือเหตุผลที่ต้องระบุทิศบวกก่อนอ่านเครื่องหมาย

4. Vector projection: คืนค่าฉายให้เป็นลูกศร พื้นฐาน

เมื่อรู้ค่าฉายสเกลาร์แล้ว คูณด้วยเวกเตอร์หน่วยของทิศเป้าหมายเพื่อได้ vector projection หรือเวกเตอร์ฉาย คำตอบอยู่บนเส้นที่ผ่านจุดกำเนิดตามแนว b เสมอ แม้ b จะยาวไม่เท่ากับหนึ่งก็ตาม

P7 Vector projection ฉาย a ลงบนแนว b

\[ \operatorname{proj}_{\mathbf b}\mathbf a=\left(\operatorname{comp}_{\mathbf b}\mathbf a\right)\widehat{\mathbf b}=\frac{\mathbf a\cdot\mathbf b}{\|\mathbf b\|^2}\mathbf b=\frac{\mathbf a\cdot\mathbf b}{\mathbf b\cdot\mathbf b}\mathbf b \]

เงื่อนไข \(\mathbf b\ne\mathbf0\) ผลเป็นเวกเตอร์ในมิติเดียวกับ a ความยาว \(\|\operatorname{proj}_{\mathbf b}\mathbf a\|=|\operatorname{comp}_{\mathbf b}\mathbf a|\) ใช้ a กับ b ในพิกัดและฐานเดียวกัน

P8 Parallel–perpendicular decomposition แยกขนานและตั้งฉาก

\[ \mathbf a_\parallel=\operatorname{proj}_{\mathbf b}\mathbf a,\quad\mathbf a_\perp=\mathbf a-\mathbf a_\parallel,\quad\mathbf a=\mathbf a_\parallel+\mathbf a_\perp \] \[ \mathbf a_\perp\cdot\mathbf b=0,\qquad\|\mathbf a\|^2=\|\mathbf a_\parallel\|^2+\|\mathbf a_\perp\|^2 \]

ส่วนเหลือเรียก rejection หรือ orthogonal residual การตรวจดอทเป็นศูนย์และตรวจผลบวกช่วยจับความผิดพลาดได้โดยไม่ต้องวาดรูปสามมิติ

ทำไมตัวส่วนต้องเป็น b·b?

ให้เวกเตอร์ฉายเป็น \(t\mathbf b\) เพราะต้องขนาน b ต้องการให้ส่วนที่เหลือ \(\mathbf a-t\mathbf b\) ตั้งฉาก b จึงตั้ง \((\mathbf a-t\mathbf b)\cdot\mathbf b=0\) กระจายได้ \(\mathbf a\cdot\mathbf b-t(\mathbf b\cdot\mathbf b)=0\) แล้วแก้ \(t=(\mathbf a\cdot\mathbf b)/(\mathbf b\cdot\mathbf b)\) ไม่ใช่หารด้วยความยาวเพียงครั้งเดียว เพราะเราจะคูณกลับด้วย b ที่ยังมีขนาดเดิม

5. ตัวอย่างหลัก: a = (3,4) ฉายบน b = (2,1) พื้นฐาน

ตัวอย่าง P-2 · เป้าหมายไม่ใช่เวกเตอร์หน่วย

หาค่าฉายสเกลาร์ เวกเตอร์ฉาย และส่วนตั้งฉากของ \(\mathbf a=(3,4)\) ตามแนว \(\mathbf b=(2,1)\)

  1. เตรียมดอทและความยาว: \(\mathbf a\cdot\mathbf b=3(2)+4(1)=10\), \(\mathbf b\cdot\mathbf b=2^2+1^2=5\), \(\|\mathbf b\|=\sqrt5\)

  2. ค่าฉายสเกลาร์ตาม P6: \(\operatorname{comp}_{\mathbf b}\mathbf a=10/\sqrt5=2\sqrt5\approx4.472\) เป็นบวก จึงไปตามทิศ b

  3. เวกเตอร์ฉายตาม P7: \(\mathbf a_\parallel=(10/5)(2,1)=(4,2)\) ตัวเลข \(10/5=2\) เป็นตัวคูณ b ไม่ใช่ความยาวเงา

  4. ส่วนตั้งฉากตาม P8: \(\mathbf a_\perp=(3,4)-(4,2)=(-1,2)\)

  5. ตรวจ: \((-1,2)\cdot(2,1)=-2+2=0\), \((4,2)+(-1,2)=(3,4)\) และ \(25=20+5\) ตามพีทาโกรัส

Scalar projection \(=2\sqrt5\) · Vector projection \(=(4,2)\) · ส่วนตั้งฉาก \(=(-1,2)\)

กลับทิศเป้าหมายแล้วเกิดอะไร? เปลี่ยน b เป็น −b ค่าฉายสเกลาร์กลับเครื่องหมาย แต่เวกเตอร์ฉายยังเป็น (4,2) เพราะเส้นที่ฉายยังเป็นเส้นเดิม โดยทั่วไป \(\operatorname{proj}_{c\mathbf b}\mathbf a=\operatorname{proj}_{\mathbf b}\mathbf a\) สำหรับ \(c\ne0\)

6. วิศวกรรมสามมิติ: แรงตามแนวคานและแรงด้านข้าง กลาง

สมมติแกนของคานยื่นไปตามทิศ \(\mathbf b=(2,1,2)\) และมีแรง \(\mathbf F=(120,60,-30)\,\mathrm N\) กระทำที่ปลาย เราแยกแรงเป็นส่วนตามแกนกับส่วนขวางแกน เพื่อเริ่มวิเคราะห์แรงตามแนวแกนและการดัด ก่อนใช้สมดุลและรูปแบบจุดรองรับต่อไป

ตัวอย่าง P-3 · แยกแรง 3D

หาค่าแรงแบบมีเครื่องหมายตามแกนคาน และเวกเตอร์แรงทั้งสองส่วน

  1. หาเวกเตอร์หน่วยแกนคาน: \(\|\mathbf b\|=\sqrt{4+1+4}=3\), \(\widehat{\mathbf b}=(2/3,1/3,2/3)\)

  2. แรงตามแกนแบบสเกลาร์: \(F_\parallel=\mathbf F\cdot\widehat{\mathbf b}=120(2/3)+60(1/3)-30(2/3)=80\,\mathrm N\)

  3. แรงตามแกนแบบเวกเตอร์: \(\mathbf F_\parallel=80(2/3,1/3,2/3)=(160/3,80/3,160/3)\,\mathrm N\)

  4. แรงขวางแกน: \(\mathbf F_\perp=\mathbf F-\mathbf F_\parallel=(200/3,100/3,-250/3)\,\mathrm N\)

  5. ตรวจตั้งฉาก: \(\mathbf F_\perp\cdot\mathbf b=(400+100-500)/3=0\) ขนาดแรงขวางคือ \(50\sqrt5\,\mathrm N\approx111.80\,\mathrm N\)

  6. ตรวจเอกลักษณ์พีทาโกรัสของขนาดแรง: \(\|\mathbf F\|^2=18900\,\mathrm N^2=[80^2+(50\sqrt5)^2]\,\mathrm N^2\) หน่วยทั้งสองข้างตรงกัน

แรงตามแกน +80 N · แรงขวางแกนขนาด \(50\sqrt5\) N · ต้องใช้สมดุลเพิ่มเติมเพื่อหาแรงปฏิกิริยาที่จุดรองรับ

การฉายเดียวกันใช้กับความเร็วของยานพาหนะตามแนวเส้นทาง องค์ประกอบสนามแม่เหล็กที่ตั้งฉากกับพื้นผิว และแรงที่ก่อให้เกิดงานตามการเคลื่อนที่ ดูกรณีที่รวม cross product สำหรับโมเมนต์และพื้นที่ในหน้า ประยุกต์ทางวิศวกรรม

สองเรื่องที่มักสับสน

องค์ประกอบตามแนวเฉียงสองแนว (ใช้กฎไซน์ R5) ไม่เท่ากับการฉาย (dot product) เว้นแต่สองแนวตั้งฉากกัน ส่วนแรงตามสายเคเบิลจากพิกัดสองจุดอยู่ใน K7 และการอ่านองค์ประกอบในกรอบเอียงอยู่ใน การหมุนแกน

7. การฉายหาระยะใกล้ที่สุดถึงเส้นและระนาบ กลาง

เส้นตรงที่ไม่จำกัดความยาวเขียนเป็น \(\mathbf x(t)=\mathbf q+t\mathbf b\) โดย q เป็นจุดบนเส้นและ b ไม่เป็นศูนย์ ถ้าต้องการจุดบนเส้นที่ใกล้ p ที่สุด ให้ฉาย เวกเตอร์จาก q ไป p คือ \(\mathbf p-\mathbf q\) ไม่ใช่ฉายพิกัด p โดยไม่สนจุดเริ่มต้น

P9 Nearest point on an infinite line เท้าฉากและระยะถึงเส้น

\[ t_* =\frac{(\mathbf p-\mathbf q)\cdot\mathbf b}{\mathbf b\cdot\mathbf b},\quad \mathbf h=\mathbf q+t_*\mathbf b,\quad d=\|\mathbf p-\mathbf h\| \]

\(\mathbf b\ne\mathbf0\) ถ้าเป็น “ช่วงเส้นตรง” จาก q ถึง q+b ต้องจำกัด \(t_*\) ให้อยู่ใน [0,1] จุดใกล้ที่สุดอาจเป็นปลายช่วง ไม่ใช่เท้าฉากบนเส้นที่ต่อออกไป

P10 Projection onto a plane ฉายจุดลงระนาบ

\[ \mathbf n\cdot(\mathbf x-\mathbf q)=0,\quad\mathbf h=\mathbf p-\frac{(\mathbf p-\mathbf q)\cdot\mathbf n}{\mathbf n\cdot\mathbf n}\mathbf n,\quad d=\frac{|(\mathbf p-\mathbf q)\cdot\mathbf n|}{\|\mathbf n\|} \]

q เป็นจุดบนระนาบ และ n เป็นเวกเตอร์ปกติที่ไม่เป็นศูนย์ ลบส่วนที่ขนาน n ออก จึงเหลือจุดบนระนาบ ค่าสัมบูรณ์ทำให้ระยะไม่ติดลบ

ตัวอย่าง P-4 · ระยะจุดถึงเส้นในสามมิติ

หาเท้าฉากจาก \(\mathbf p=(4,4,4)\) ลงเส้น \(\mathbf x=(-1,2,1)+t(1,2,2)\)

  1. เลือก \(\mathbf q=(-1,2,1)\), \(\mathbf b=(1,2,2)\), \(\mathbf a=\mathbf p-\mathbf q=(5,2,3)\)

  2. หา \(t_*=(5+4+6)/(1+4+4)=15/9=5/3\)

  3. เท้าฉาก \(\mathbf h=(-1,2,1)+(5/3)(1,2,2)=(2/3,16/3,13/3)\)

  4. เวกเตอร์จากเท้าฉากถึง p คือ \((10/3,-4/3,-1/3)\) ดอท b ได้ \((10-8-2)/3=0\)

  5. ระยะ \(d=\sqrt{(100+16+1)/9}=\sqrt{13}\approx3.606\) หน่วยตามพิกัด

เท้าฉาก \((2/3,16/3,13/3)\) · ระยะถึงเส้น \(\sqrt{13}\)

ตัวอย่าง P-5 · ฉายลงพื้นเอียง

ฉายจุด \((4,1,1)\) ลงระนาบ \(x+y+z=3\)

  1. เวกเตอร์ปกติ \(\mathbf n=(1,1,1)\) เลือกจุดบนระนาบ \(\mathbf q=(3,0,0)\)

  2. \((\mathbf p-\mathbf q)\cdot\mathbf n=(1,1,1)\cdot(1,1,1)=3\), \(\mathbf n\cdot\mathbf n=3\) ส่วนที่ต้องลบคือ (1,1,1)

  3. \(\mathbf h=(4,1,1)-(1,1,1)=(3,0,0)\) ตรวจผลรวมพิกัดได้ 3 อยู่บนระนาบจริง ระยะคือ \(\sqrt3\)

จุดฉาย (3,0,0) · ระยะ \(\sqrt3\)

8. เชื่อมกับเมทริกซ์และ least squares ต่อยอด

เมื่อเขียน b เป็นเวกเตอร์หลัก สูตรฉายเปลี่ยนเป็นเมทริกซ์ขนาด n×n ที่รับเวกเตอร์ n มิติและคืนเวกเตอร์ n มิติ การฉายอาจลดความยาวของเวกเตอร์ แต่ฉายซ้ำแล้วไม่เปลี่ยนผล เพราะเวกเตอร์ที่อยู่บนเส้นนั้นอยู่แล้วไม่ต้องย้ายอีก

P11 Orthogonal projection matrix ตัวดำเนินการฉายลงหนึ่งทิศ

\[ P=\frac{\mathbf b\mathbf b^T}{\mathbf b^T\mathbf b},\quad\mathbf a_\parallel=P\mathbf a,\quad P^T=P,\quad P^2=P,\quad \mathbf b\ne\mathbf0 \]

สำหรับ \(\mathbf b=(2,1)^T\): \(P=\frac15\begin{pmatrix}4&2\\2&1\end{pmatrix}\) จึงได้ \(P(3,4)^T=(4,2)^T\) การเลือกตัวคูณ t ให้ \(\|\mathbf a-t\mathbf b\|^2\) น้อยที่สุดให้ค่า t เดียวกับ P7

ขยายไปหลายทิศได้ด้วยฐานตั้งฉาก: รวมการฉายลงแต่ละฐาน ถ้าเมทริกซ์ A มีหลักอิสระแต่ไม่ตั้งฉาก การฉายลง column space คือ \(A(A^TA)^{-1}A^T\) ใช้ได้เมื่อหลักของ A อิสระเชิงเส้น หากไม่อิสระต้องใช้ pseudoinverse หรือการแยก QR/SVD ที่เหมาะสม อ่านต่อที่ ระบบสมการและวิธีกำลังสองน้อยสุด

9. จุดที่สับสนและกรณีขอบ

  • ใช้ \((\mathbf a\cdot\mathbf b)\mathbf b\) ทั้งที่ b ไม่ยาวหนึ่ง: ต้องหารด้วย \(\mathbf b\cdot\mathbf b\) ตาม P7 มิฉะนั้นขนาดผิด
  • ใช้ตัวส่วนเดียวกันทั้ง scalar และ vector projection: scalar หาร \(\|\mathbf b\|\), vector หาร \(\|\mathbf b\|^2\) แล้วคูณ b
  • ลบค่าสเกลาร์ออกจากเวกเตอร์: ส่วนตั้งฉากต้องใช้ \(\mathbf a-\operatorname{proj}_{\mathbf b}\mathbf a\) ไม่ใช่ a ลบ scalar projection
  • ลืมกรณี b = 0: ไม่มีทิศให้ฉาย สูตรจึงไม่นิยาม ถ้า a = 0 แต่ b ≠ 0 ทั้งสองค่าฉายเป็นศูนย์
  • คิดว่าฉาย a บน b เท่ากับฉาย b บน a: โดยทั่วไปไม่เท่ากัน เวกเตอร์เป้าหมายเป็นตัวกำหนดเส้น
  • ผสมหน่วยหรือพิกัดคนละกรอบ: แปลงหน่วยและกรอบอ้างอิงให้ตรงกันก่อน เช่น หน่วยเมตรกับมิลลิเมตร หรือกรอบกล้องกับกรอบหุ่นยนต์
  • คิดว่าค่าฉายติดลบเป็นความยาวติดลบ: ค่ามีเครื่องหมายบอกทิศ ความยาวต้องใช้ค่าสัมบูรณ์
  • อ่านแรงตามแกนเป็นแรงปฏิกิริยาโดยทันที: ต้องมีสมดุล แบบจำลองวัสดุ และเงื่อนไขจุดรองรับตามโจทย์

การฉายตามทิศเวกเตอร์ศูนย์กับการฉายลงปริภูมิ \(\{\mathbf0\}\) เป็นคนละนิยาม กรณีหลังมีจุดเดียวจึงให้ศูนย์เสมอ ในการคำนวณเชิงตัวเลข หาก b เล็กมาก ให้ปรับสเกลด้วยวิธีที่รักษาทิศและใช้การคำนวณ norm ที่เสถียร; อย่าหารด้วยค่าที่ระบบถือว่าเป็นศูนย์โดยไม่แจ้งผล

10. ฝึกทำพร้อมเฉลย: ตรวจทั้งขนาดและทิศ

ลองทำก่อนเปิดเฉลย หรือใช้ปุ่มโหมดฝึกทำด้านบน คำตอบของการฉายควรตรวจได้สองข้อเสมอ: ฉายขนานทิศเป้าหมาย และส่วนเหลือตั้งฉากกับทิศนั้น

แบบฝึก P-A · ค่าฉายติดลบ

ให้ \(\mathbf a=(-3,4),\ \mathbf b=(1,0)\) จงหา scalar projection, vector projection และส่วนเหลือ

  1. \(\mathbf a\cdot\mathbf b=-3\), \(\|\mathbf b\|=1\) ดังนั้นค่าฉายสเกลาร์คือ −3

  2. เวกเตอร์ฉาย = \(-3(1,0)=(-3,0)\), ส่วนเหลือ = \((-3,4)-(-3,0)=(0,4)\)

  3. ส่วนเหลือดอท b ได้ 0 และความยาวเวกเตอร์ฉายคือ 3 ไม่ใช่ −3

−3 · (−3,0) · (0,4)

แบบฝึก P-B · สามมิติ

ฉาย \(\mathbf a=(1,2,3)\) ลงบนแนว \(\mathbf b=(1,1,0)\)

  1. ดอท = 3, norm b = \(\sqrt2\), และ b·b = 2

  2. Scalar projection = \(3/\sqrt2\); vector projection = \((3/2,3/2,0)\)

  3. ส่วนเหลือ = \((-1/2,1/2,3)\), ดอท b = 0 และ \(14=9/2+19/2\)

\(\operatorname{comp}_{\mathbf b}\mathbf a=3/\sqrt2\), \(\mathbf a_\parallel=(3/2,3/2,0)\), \(\mathbf a_\perp=(-1/2,1/2,3)\)

แบบฝึก P-C · แกนที่หมุน

ใช้ฐาน \(\mathbf e_1=(1,1)/\sqrt2,\ \mathbf e_2=(-1,1)/\sqrt2\) จงหาพิกัดใหม่ของ \(\mathbf a=(4,2)\)

  1. ตรวจ e₁ และ e₂ ยาวหนึ่งและดอทกันได้ 0 จึงใช้ P5 ได้

  2. \(a_1=(4+2)/\sqrt2=3\sqrt2\), \(a_2=(-4+2)/\sqrt2=-\sqrt2\)

  3. ตรวจประกอบกลับ: \(3\sqrt2\mathbf e_1-\sqrt2\mathbf e_2=(3,3)+(1,-1)=(4,2)\)

พิกัดในฐานใหม่ \((3\sqrt2,-\sqrt2)\) และขนาดยังเป็น \(\sqrt{20}\)
