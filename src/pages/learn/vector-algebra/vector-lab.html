สตูดิโอเวกเตอร์ 2D / 3D: วาด หมุนแกน วิเคราะห์ และส่งออก

เครื่องมือเดียวสำหรับทุกบทของชุดเวกเตอร์: ใส่เวกเตอร์ได้สูงสุด 8 ตัว ลากหมุนมุมมองสามมิติ ดูผลรวมแบบหัวต่อหาง กล่ององค์ประกอบ มุม α β γ การฉาย ผลคูณไขว้ และกรอบพิกัดที่หมุนด้วยมุมออยเลอร์ ทุกอย่างคำนวณให้เห็นทีละขั้นในแท็บด้านล่าง แล้วส่งออกไป GeoGebra MATLAB หรือ Python ได้ในคลิกเดียว ลิงก์ของหน้าเก็บชุดเวกเตอร์ไว้ให้แชร์ได้ทันที

สตูดิโอเวกเตอร์ 3 มิติ

เริ่มจากตัวอย่าง “แรงจากสายเคเบิล 3 เส้น” ลากภาพเพื่อหมุน กด xy xz yz เพื่อมองจากบน หน้า ข้าง ปุ่ม ★ เลือกเวกเตอร์หลัก ☆ เลือกตัวที่สอง สำหรับ projection และ cross ติ๊ก ✓ เพื่อรวมในผลรวม R

ภารกิจในสตูดิโอ

  1. สมดุลสามมิติ — เลือกตัวอย่าง “สมดุล” ติ๊ก “ต่อหัวต่อหาง” รูปหลายเหลี่ยมแรงปิดพอดี แท็บแรงลัพธ์ต้องได้ R = 0
  2. ทิศทางโคไซน์ — ตัวอย่าง “ทิศทางโคไซน์” ติ๊กมุม α β γ แล้วกดมุมมอง xz: มุม γ อยู่ระหว่างลูกศรกับแกน z จริงหรือไม่
  3. กรอบหมุน — ติ๊ก “กรอบหมุน” ปรับ ψ = 90° ดูในแท็บกรอบหมุนว่า x′ ของ i กลายเป็นเท่าไร (คำตอบ: i′ = (0, −1, 0)) อธิบายด้วย T2
  4. แรงบิด — ตัวอย่าง “Cross product · แรงบิด” ★ = r ☆ = F ติ๊ก “★ × ☆” ได้ M = r × F ตั้งฉากกับระนาบสีเหลือง
  5. เฟสเซอร์ — ตัวอย่าง “เฟสเซอร์เป็นเวกเตอร์ 2 มิติ” V_R + V_L + V_C ต่อหัวต่อหางเป็น KVL ของวงจร RLC (Z3)

เครื่องคิดเลขเวกเตอร์แบบแสดงวิธีทำ

เครื่องคิดเลขสองเวกเตอร์ที่เขียนวิธีแทนค่าทุกบรรทัด เหมาะสำหรับตรวจการบ้านเรื่องบวก ลบ คูณสเกลาร์ Dot Cross และ projection

โหมด 2D ใช้เฉพาะองค์ประกอบ x,y ส่วน Cross product ของเวกเตอร์บนระนาบคิดโดยเติม z=0 แล้วแสดงองค์ประกอบตั้งฉากกับระนาบ โหมด 3D ของเครื่องคิดเลขนี้เป็นภาพฉายคงที่ ถ้าต้องการหมุนดูมุมจริงให้ใช้สตูดิโอด้านบน

ใบงานทดลอง: ทำนายก่อนกดคำนวณ

การทดลอง 1 · Projection

ส่วนขนานที่ยาวกว่าองค์ประกอบ x ของ A

ตั้ง A=(3,4), B=(2,1) เลือก projection คำถาม: เหตุใดองค์ประกอบ x ของส่วนฉายเป็น 4 มากกว่า x ของ A ที่เป็น 3?

  1. คำนวณ \(A\cdot B=3(2)+4(1)=10\) และ \(B\cdot B=5\)
  2. ส่วนขนาน \(A_\parallel=(10/5)(2,1)=(4,2)\)
  3. ส่วนตั้งฉาก \(A_\perp=(3,4)-(4,2)=(-1,2)\) ตรวจ \((-1,2)\cdot(2,1)=0\)

การฉายบนเส้นเอียงไม่ใช่การเก็บ x อย่างเดียว ส่วนตั้งฉากมี x ติดลบ จึงรวมกลับเป็น 3 ได้ แม้ x ของส่วนขนานเท่ากับ 4

เปลี่ยน B เป็น (−2,−1): scalar projection จาก \(2\sqrt5\) กลายเป็น \(-2\sqrt5\) แต่เวกเตอร์ฉายยังเป็น (4,2) เพราะเส้นที่ฉายเป็นเส้นเดิม

การทดลอง 2 · Dot product

ตั้งฉาก ทิศเดียว และทิศตรงข้าม

  1. A=(3,4), B=(−4,3) ให้ dot = −12+12=0 และมุม 90°
  2. เปลี่ยน B=(6,8) ให้ dot=50 และมุม 0° ขนาด B เป็นสองเท่า A
  3. เปลี่ยน B=(−6,−8) ให้ dot=−50 และมุม 180°

เครื่องหมาย dot บอกมุมแหลม ศูนย์ หรือมุมป้านได้เมื่อเวกเตอร์ทั้งคู่ไม่เป็นศูนย์ ลอง A=(0,0): dot ยังคำนวณเป็น 0 แต่มุมไม่กำหนด

การทดลอง 3 · Cross product

สลับลำดับแล้วทิศกลับ

  1. เลือก 3D ให้ A=(1,2,2), B=(3,0,4)
  2. คำนวณ \(A\times B=(8,2,-6)\); ขนาด \(\sqrt{104}\approx10.1980\)
  3. ตรวจ \((8,2,-6)\cdot A=8+4-12=0\), \((8,2,-6)\cdot B=24-24=0\)
  4. สลับ A และ B จะได้ (−8,−2,6) ขนาดเท่าเดิมแต่ทิศตรงข้าม

Cross ให้ทิศตั้งฉากและพื้นที่ ห้ามแทน cross ด้วยการคูณองค์ประกอบทีละตัว

ทดลองจากโจทย์วิศวกรรม

  • แรงลัพธ์: โหมดบวก A=(30,40) N และ B=(−10,20) N ให้ (20,60) N ขนาด \(20\sqrt{10}\approx63.246\) N
  • งาน: โหมด dot ให้ A=(30,40) N และ B=(2,0) m ได้ 60 J ไม่ใช่ 100 J เพราะแรงแนวตั้งไม่ทำงานในการเคลื่อนที่แนวนอนนี้
  • แรงบิด: โหมด cross 3D ให้ A=(0.2,0,0) m และ B=(0,50,0) N ได้ (0,0,10) N·m ตาม +z

แล็บรับเฉพาะตัวเลขและไม่ทราบหน่วยโดยอัตโนมัติ ผู้ใช้ต้องกำหนดหน่วยให้สอดคล้องกันก่อนแทนค่า อ่านข้อสมมติของระบบจริงใน หน้าการประยุกต์ทางวิศวกรรม

ขอบเขตและการตรวจคำตอบ

ภาพและผลลัพธ์ใช้ฐานคาร์ทีเซียนตั้งฉากหนึ่งหน่วย ไม่รองรับฐานเฉียงหรือพิกัดโค้งโดยตรง การคำนวณใช้ floating point; ค่าที่เล็กมากอาจคลาดเคลื่อนจากการปัด อย่าใช้ภาพฉายสามมิติพิสูจน์ความตั้งฉาก ให้ตรวจ dot เป็นศูนย์แทน

กลับไปค้น สรุปสูตร หรืออ่านที่มาใน Component / Projection, Dot product และ Cross product
