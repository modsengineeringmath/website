ลิมิตและความต่อเนื่อง (Limits & Continuity)

ลิมิตคือเครื่องมือที่ให้เราพูดถึง “ค่าที่เข้าใกล้” ได้อย่างแม่นยำ แม้ฟังก์ชันจะไม่นิยามที่จุดนั้น อนุพันธ์ อินทิกรัล อนุกรม และทฤษฎีบทค่าเริ่มต้น-ค่าสุดท้ายของลาปลาซ ล้วนนิยามด้วยลิมิต หน้านี้เริ่มจากสัญชาตญาณ ไปสู่นิยาม ε–δ ที่ลากดูได้ เทคนิคหาลิมิตทุกแบบที่ออกสอบ และจบที่กฎของโลปิตาล

เขียนโดย อาจารย์มดอัปเดต
แล็บ ε–δ เทคนิค 0/0 ลิมิตที่อนันต์ ความต่อเนื่อง โลปิตาล ลำดับและอนุกรม → อุปนัยเชิงคณิตศาสตร์ →
สรุปใน 30 วินาที
  • \(\lim_{x\to a}f(x) = L\): ทำให้ \(f(x)\) ใกล้ \(L\) เท่าไรก็ได้ ด้วยการเอา \(x\) ไปใกล้ \(a\) มากพอ
  • ลิมิตมี ⇔ ลิมิตซ้าย = ลิมิตขวา · แทนค่าได้เลยถ้าฟังก์ชันต่อเนื่อง
  • 0/0: แยกตัวประกอบ · คอนจูเกต · \(\sin x/x \to 1\) · โลปิตาล
  • ต่อเนื่อง ⇔ \(f(a)\) มีค่า + ลิมิตมี + สองค่าเท่ากัน
ระดับพื้นฐาน ม.ปลาย · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง พิสูจน์

ลิมิตคืออะไร: ดูจากตารางและกราฟ พื้นฐาน

ลองถามว่า \(f(x) = \dfrac{x^2 - 4}{x - 2}\) มีค่าเท่าไรที่ \(x = 2\) แทนตรง ๆ ได้ \(0/0\) ซึ่งไม่มีความหมาย แต่ถ้าแทน \(x = 1.9,\ 1.99,\ 1.999\) จะได้ \(3.9,\ 3.99,\ 3.999\) และจากอีกด้าน \(2.1,\ 2.01\) ได้ \(4.1,\ 4.01\) ค่าเข้าใกล้ 4 อย่างชัดเจน กราฟเป็นเส้นตรง \(y = x + 2\) ที่มี “รูโหว่” ที่ \((2, 4)\)

L1 Limit (informal) ลิมิต

\[ \lim_{x\to a}f(x) = L \]

อ่านว่า “ลิมิตของ f(x) เมื่อ x เข้าใกล้ a เท่ากับ L” · ไม่สนค่า \(f(a)\) สนเฉพาะค่ารอบ ๆ a

นิยาม ε–δ (แบบลากดูได้) กลาง

คำว่า “ใกล้” ต้องวัดเป็นตัวเลขได้ นิยามของโคชีบอกว่า: ใครก็ตามท้าเรามาด้วยความคลาดเคลื่อน \(\varepsilon\) ของเอาต์พุต เราต้องหาความคลาดเคลื่อน \(\delta\) ของอินพุตที่รับประกันได้เสมอ

L2 ε–δ definition นิยามเชิงรูปนัย

\[ \lim_{x\to a}f(x) = L \iff \forall\varepsilon > 0\ \exists\delta > 0:\ 0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon \]

ในแล็บ แถบสีน้ำเงินคือ \(L \pm \varepsilon\) แถบสีเขียวคือ \(\delta\) ที่ใหญ่ที่สุดที่ยังทำให้กราฟอยู่ในแถบน้ำเงินทั้งหมด ลองลด ε แล้วดู δ เล็กลงตาม ซูมเข้าเพื่อดูว่ารูโหว่ไม่เคยหายไป และลองตัวอย่าง “ซ้าย ≠ ขวา” กับ “แกว่ง” เพื่อดูกรณีที่หา δ ไม่ได้

ตัวอย่าง L-1 · พิสูจน์ด้วย ε–δ

พิสูจน์ว่า \(\lim_{x\to 3}(2x - 1) = 5\)

  1. ร่าง: ต้องการ \(|(2x - 1) - 5| = 2|x - 3| < \varepsilon\) ซึ่งเป็นจริงเมื่อ \(|x - 3| < \varepsilon/2\)

  2. พิสูจน์: ให้ \(\varepsilon > 0\) ใด ๆ เลือก \(\delta = \varepsilon/2\) ถ้า \(0 < |x - 3| < \delta\) แล้ว \(|f(x) - 5| = 2|x - 3| < 2\delta = \varepsilon\) ∎

\(\delta = \varepsilon/2\): ฟังก์ชันชันเท่ากับ 2 จึงต้องคุมอินพุตแคบกว่าเอาต์พุตครึ่งหนึ่ง ความชันคือสิ่งที่อนุพันธ์จะวัด

ลิมิตทางเดียว: ซ้ายและขวา พื้นฐาน

L3 One-sided limits ลิมิตซ้าย ขวา

\[ \lim_{x\to a^-}f(x),\qquad \lim_{x\to a^+}f(x) \]

L4 Existence ลิมิตสองด้านมีค่า

\[ \lim_{x\to a}f(x) = L \iff \lim_{x\to a^-}f = \lim_{x\to a^+}f = L \]
ตัวอย่าง L-2

(ก) \(\lim_{x\to 0}\dfrac{|x|}{x}\) (ข) \(f(x) = x + 1\) เมื่อ \(x < 3\) และ \(7 - x\) เมื่อ \(x \ge 3\) หา \(\lim_{x\to3}f(x)\)

  1. (ก) \(x < 0\): \(|x|/x = -1\) · \(x > 0\): \(= 1\) ลิมิตซ้าย −1 ≠ ลิมิตขวา 1

  2. (ข) ซ้าย: \(3 + 1 = 4\) · ขวา: \(7 - 3 = 4\) เท่ากัน

(ก) ไม่มีลิมิต (กระโดด) · (ข) \(\lim = 4\) และ \(f(3) = 4\) จึงต่อเนื่องที่ x = 3 ด้วย

สมบัติของลิมิต พื้นฐาน

L5 Limit laws ถ้า \(\lim f = A,\ \lim g = B\)

\[ \lim(f \pm g) = A \pm B,\quad \lim(fg) = AB,\quad \lim\frac fg = \frac AB\ (B \ne 0),\quad \lim f^n = A^n,\quad \lim\sqrt[n]{f} = \sqrt[n]{A} \]

L6 Direct substitution แทนค่าได้ทันที

\[ \lim_{x\to a}f(x) = f(a) \quad\text{ถ้า } f \text{ ต่อเนื่องที่ } a \]

พหุนาม ตรรกยะ (ส่วนไม่เป็นศูนย์) ราก ตรีโกณ เอกซ์โพเนนเชียล ลอการิทึม ต่อเนื่องบนโดเมนทั้งหมด

L7 Squeeze theorem ทฤษฎีบทแซนด์วิช

\[ g \le f \le h,\ \lim g = \lim h = L \Rightarrow \lim f = L \]
ตัวอย่าง L-3 · แซนด์วิช

\(\lim_{x\to 0}x^2\sin\dfrac{1}{x}\)

  1. \(\sin(1/x)\) แกว่งไม่มีลิมิต ใช้กฎผลคูณไม่ได้ แต่ \(-1 \le \sin(1/x) \le 1\)

    \[ -x^2 \le x^2\sin\frac1x \le x^2 \]

  2. ทั้ง \(-x^2\) และ \(x^2\) เข้าหา 0 L7

\(\lim = 0\)

รูปแบบ 0/0: แยกตัวประกอบ คอนจูเกต และจัดรูป พื้นฐาน

ถ้าแทนค่าแล้วได้ \(0/0\) แปลว่าเศษกับส่วนมีตัวประกอบ \((x - a)\) ร่วมกันซ่อนอยู่ งานของเราคือดึงมันออกมาตัดทิ้ง

ตัวอย่าง L-4 · แยกตัวประกอบ

\(\lim_{x\to 2}\dfrac{x^2 - 4}{x - 2}\) และ \(\lim_{x\to 1}\dfrac{x^3 - 1}{x^2 - 1}\)

  1. \[ \frac{(x-2)(x+2)}{x-2} = x + 2 \to 4 \]
  2. \[ \frac{(x-1)(x^2+x+1)}{(x-1)(x+1)} = \frac{x^2 + x + 1}{x + 1} \to \frac{3}{2} \]

\(4\) และ \(\tfrac32\) · ตัดได้เพราะขณะ “เข้าใกล้” \(x \ne a\)

ตัวอย่าง L-5 · คูณคอนจูเกต

\(\lim_{x\to 0}\dfrac{\sqrt{x + 4} - 2}{x}\)

  1. \[ \frac{\sqrt{x+4} - 2}{x}\cdot\frac{\sqrt{x+4} + 2}{\sqrt{x+4} + 2} = \frac{(x + 4) - 4}{x(\sqrt{x+4} + 2)} = \frac{1}{\sqrt{x+4} + 2} \]
  2. \[ \to \frac{1}{2 + 2} = \frac14 \]

\(\tfrac14\) ซึ่งคือความชันของ \(\sqrt{x}\) ที่ \(x = 4\) (ผลหารผลต่างของอนุพันธ์)

ลิมิตตรีโกณมิติและค่า e กลาง

L8 Fundamental trig limit ลิมิตพื้นฐาน

\[ \lim_{x\to 0}\frac{\sin x}{x} = 1,\qquad \lim_{x\to 0}\frac{1 - \cos x}{x} = 0,\qquad \lim_{x\to0}\frac{1-\cos x}{x^2} = \frac12 \]

พิสูจน์ด้วยแซนด์วิช: \(\cos x \le \frac{\sin x}{x} \le 1\) จากพื้นที่สามเหลี่ยมกับเซกเตอร์ในวงกลมหนึ่งหน่วย · x ต้องเป็นเรเดียน · ฟังก์ชัน \(\operatorname{sinc}\) ในสัญญาณมาจากลิมิตนี้

L9 The number e ค่า e

\[ e = \lim_{n\to\infty}\left(1 + \frac1n\right)^n = \lim_{x\to 0}(1 + x)^{1/x} \approx 2.71828 \] \[ \lim_{x\to0}\frac{e^x - 1}{x} = 1,\qquad \lim_{x\to 0}\frac{\ln(1+x)}{x} = 1 \]
ตัวอย่าง L-6

(ก) \(\lim_{x\to0}\dfrac{\sin 3x}{x}\) (ข) \(\lim_{x\to0}\dfrac{\tan x}{x}\) (ค) \(\lim_{x\to\infty}\left(1 + \dfrac2x\right)^x\)

  1. (ก) คูณและหารด้วย 3: \(3\cdot\dfrac{\sin 3x}{3x} \to 3\cdot 1 = 3\)

  2. (ข) \(\dfrac{\sin x}{x}\cdot\dfrac{1}{\cos x} \to 1\cdot 1 = 1\)

  3. (ค) ให้ \(n = x/2\): \(\left(1 + \dfrac1n\right)^{2n} = \left[\left(1 + \dfrac1n\right)^n\right]^2 \to e^2\)

\(3,\ 1,\ e^2\)

ลิมิตที่อนันต์ ลิมิตอนันต์ และเส้นกำกับ พื้นฐาน

L10 Rational functions at ∞ ฟังก์ชันตรรกยะเมื่อ x → ∞

\[ \lim_{x\to\infty}\frac{a_nx^n + \cdots}{b_mx^m + \cdots} = \begin{cases} 0, & n < m \\ a_n/b_m, & n = m \\ \pm\infty, & n > m \end{cases} \]

วิธีทำ: หารทั้งเศษและส่วนด้วยกำลังสูงสุดของตัวส่วน ค่าที่ได้คือเส้นกำกับแนวนอน

L11 Vertical asymptote เส้นกำกับแนวตั้ง

\[ \lim_{x\to a^\pm}f(x) = \pm\infty \Rightarrow x = a \text{ เป็นเส้นกำกับแนวตั้ง} \]

L12 Oblique asymptote เส้นกำกับเฉียง

\[ f(x) = mx + b + r(x),\ r(x)\to 0 \Rightarrow y = mx + b \]

เกิดเมื่อดีกรีเศษมากกว่าส่วนหนึ่งพอดี หาด้วยการหารยาว

ตัวอย่าง L-7 · เส้นกำกับทั้งสามแบบ

(ก) \(\lim_{x\to\infty}\dfrac{3x^2 + 2x}{5x^2 - 1}\) (ข) เส้นกำกับของ \(\dfrac{x+1}{x-2}\) (ค) เส้นกำกับของ \(\dfrac{x^2+1}{x-1}\)

  1. (ก) หารด้วย \(x^2\): \(\dfrac{3 + 2/x}{5 - 1/x^2} \to \dfrac35\)

  2. (ข) แนวตั้ง \(x = 2\) (ส่วนเป็นศูนย์ เศษไม่เป็นศูนย์) · แนวนอน \(y = 1\) (ดีกรีเท่ากัน 1/1)

  3. (ค) หารยาว \(\dfrac{x^2+1}{x-1} = x + 1 + \dfrac{2}{x-1}\) → แนวเฉียง \(y = x + 1\) และแนวตั้ง \(x = 1\)

\(\tfrac35\) · \(x = 2,\ y = 1\) · \(y = x + 1,\ x = 1\)

ความต่อเนื่องและทฤษฎีบทค่าระหว่างกลาง กลาง

L13 Continuity at a point ต่อเนื่องที่ x = a

\[ \text{(1) } f(a) \text{ มีค่า}\quad \text{(2) } \lim_{x\to a}f(x) \text{ มีค่า}\quad \text{(3) } \lim_{x\to a}f(x) = f(a) \]

ผิดข้อใดข้อหนึ่ง = ไม่ต่อเนื่อง: ถอดได้ (รู · แก้ได้ด้วยการนิยามค่าใหม่) · กระโดด (ซ้าย ≠ ขวา) · อนันต์ (เส้นกำกับแนวตั้ง) · แกว่ง (\(\sin(1/x)\))

L14 Intermediate value theorem ทฤษฎีบทค่าระหว่างกลาง

\[ f \text{ ต่อเนื่องบน } [a, b],\ f(a) < N < f(b) \Rightarrow \exists c \in (a, b):\ f(c) = N \]

ถ้า \(f(a)\) กับ \(f(b)\) ต่างเครื่องหมาย ต้องมีรากระหว่างนั้น เป็นหลักของวิธีแบ่งครึ่งช่วง (bisection) ที่ใช้หาจุดทำงานของวงจรไม่เชิงเส้น

ตัวอย่าง L-8 · ทำให้ต่อเนื่อง

หา \(k\) ที่ทำให้ \(f(x) = kx + 1\) เมื่อ \(x \le 2\) และ \(x^2 - k\) เมื่อ \(x > 2\) ต่อเนื่องทุกจุด

  1. แต่ละช่วงเป็นพหุนาม ต่อเนื่องอยู่แล้ว ต้องตรวจที่รอยต่อ x = 2 เท่านั้น

    \[ \lim_{x\to2^-}f = 2k + 1,\qquad \lim_{x\to2^+}f = 4 - k \]
  2. \[ 2k + 1 = 4 - k \Rightarrow k = 1 \]

\(k = 1\) (ทั้งสองข้างเท่ากับ 3 และ \(f(2) = 3\))

ตัวอย่าง L-9 · แบ่งครึ่งช่วงหาราก

แสดงว่า \(x^3 - x - 1 = 0\) มีรากใน \([1, 2]\) แล้วประมาณค่า

  1. \(f(1) = -1 < 0\), \(f(2) = 5 > 0\) และ f ต่อเนื่อง → มีรากใน \((1, 2)\) L14

  2. \(f(1.5) = 0.875 > 0\) → ราก ∈ \((1, 1.5)\) · \(f(1.25) = -0.297 < 0\) → ∈ \((1.25, 1.5)\) · \(f(1.375) = 0.225\) → ∈ \((1.25, 1.375)\) …

ลู่เข้าสู่ \(x \approx 1.3247\) (ทุกรอบช่วงแคบลงครึ่งหนึ่ง) วิธีนิวตัน-ราฟสันเร็วกว่ามากแต่ต้องใช้อนุพันธ์

กฎของโลปิตาล (L'Hôpital's Rule) กลาง

L15 L'Hôpital's rule กฎของโลปิตาล

\[ \frac{f(x)}{g(x)} \to \frac00 \text{ หรือ } \frac{\infty}{\infty} \ \Rightarrow\ \lim\frac{f(x)}{g(x)} = \lim\frac{f'(x)}{g'(x)} \]

หาอนุพันธ์เศษและส่วนแยกกัน ไม่ใช่กฎผลหาร · ใช้ซ้ำได้ถ้ายังเป็น 0/0 · ต้องการสูตรอนุพันธ์

L16 Other indeterminate forms แปลงรูปก่อนใช้

\[ 0\cdot\infty \to \frac{f}{1/g} \qquad \infty - \infty \to \text{รวมเศษส่วน} \qquad 1^\infty,\ 0^0,\ \infty^0 \to e^{\lim g\ln f} \]
ตัวอย่าง L-10 · โลปิตาลทุกรูปแบบ

(ก) \(\lim_{x\to0}\dfrac{e^x - 1 - x}{x^2}\) (ข) \(\lim_{x\to\infty}xe^{-x}\) (ค) \(\lim_{x\to0^+}x\ln x\) (ง) \(\lim_{x\to0^+}x^x\)

  1. (ก) 0/0 สองครั้ง: \(\dfrac{e^x - 1}{2x} \to \dfrac{e^x}{2} \to \dfrac12\)

  2. (ข) \(\infty\cdot0\) → \(\dfrac{x}{e^x}\) (∞/∞) → \(\dfrac{1}{e^x} \to 0\) · เอกซ์โพเนนเชียลชนะพหุนามเสมอ

  3. (ค) \(0\cdot(-\infty)\) → \(\dfrac{\ln x}{1/x}\) → \(\dfrac{1/x}{-1/x^2} = -x \to 0\)

  4. (ง) \(0^0\) → \(x^x = e^{x\ln x} \to e^0 = 1\) (ใช้ผล (ค))

\(\tfrac12,\ 0,\ 0,\ 1\)

ลิมิตในงานวิศวกรรมไฟฟ้า กลาง

ลิมิตความหมายทางวิศวกรรม
\(\lim_{t\to\infty}V\left(1 - e^{-t/\tau}\right) = V\)ค่าสุดท้ายของการชาร์จ (สถานะคงตัว) ใช้ทฤษฎีบทค่าสุดท้ายของลาปลาซหาได้โดยไม่แปลงกลับ P16
\(\lim_{\Delta t\to0}\dfrac{\Delta q}{\Delta t} = \dfrac{dq}{dt} = i\)นิยามกระแสไฟฟ้าคืออนุพันธ์ของประจุ
\(v_C(0^-) = v_C(0^+)\)แรงดันตัวเก็บประจุต่อเนื่องเสมอ (ไม่กระโดด) เพราะต้องใช้กระแสอนันต์
\(\lim_{\omega\to\infty}\left|\dfrac{1}{1 + j\omega RC}\right| = 0\)วงจร RC ตัดความถี่สูง (low-pass)
\(\lim_{x\to 0}\dfrac{\sin\pi x}{\pi x} = 1\)ฟังก์ชัน sinc มีค่า 1 ที่ศูนย์ เป็นสเปกตรัมของพัลส์สี่เหลี่ยม
\(\lim_{n\to\infty}\left(1 + \dfrac{r}{n}\right)^{n} = e^{r}\)การเติบโตต่อเนื่อง ที่มาของ \(e\) ในสมการประจุ-คายประจุ

ต่อยอดจากลิมิต: ลิมิตของลำดับและผลบวกย่อยคือหัวใจของ ลำดับและอนุกรมครบชุด 10 หน้า ตั้งแต่ ลิมิตของลำดับ ε–N ไปจนถึง อนุกรมเทย์เลอร์ และ อนุกรมโลรองต์

บทต่อไป: อนุพันธ์ คือลิมิตของผลหารผลต่าง \(\lim_{h\to0}\frac{f(x+h) - f(x)}{h}\)

ต่อยอด: ลำดับ อนุกรม และอุปนัยเชิงคณิตศาสตร์

ลิมิตเมื่อ \(x \to \infty\) มีคู่แฝดในโลกไม่ต่อเนื่อง คือ ลิมิตของลำดับ \(\lim_{n\to\infty} a_n\) และ อนุกรมอนันต์ ซึ่งก็คือลิมิตของผลบวกย่อย \(\lim_{N\to\infty}\sum_{n=1}^{N} a_n\) ส่วน อุปนัยเชิงคณิตศาสตร์ คือเครื่องมือพิสูจน์สูตรที่ใช้ได้กับ “ทุก n” เช่นสูตรผลบวก \(\sum k^2\) ที่ใช้หาอินทิกรัลด้วยผลบวกรีมันน์ ทั้งสองหน้าใช้เทคนิคลิมิตจากหน้านี้ (0/0, ∞/∞, โลปิตาล, ค่า e) โดยตรง
