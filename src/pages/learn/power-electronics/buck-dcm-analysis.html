// บทที่ 15.3 · อิเล็กทรอนิกส์กำลัง · Buck in DCM — Three-Interval Analysis & Duty Cycle

บั๊กคอนเวอร์เตอร์โหมด DCM: ไล่วงจรสามช่วงเวลาเพื่อหาดิวตี้ไซเคิลจากโหลด M = 2/(1+√(1+4K/D²))

เมื่อโหลดเบาจนกระแสตัวเหนี่ยวนำลงถึงศูนย์ ดิวตี้ไม่ใช่ Vo/Vg อีกต่อไป แต่ขึ้นกับโหลด หน้านี้ไล่วงจรทีละช่วง D₁ D₂ D₃ จนได้สูตรอัตราส่วนแปลงผัน สูตรดิวตี้ที่ต้องใช้ กระแสพีกและ RMS พร้อมกราฟแล็บเทียบกับการจำลองสวิตชิ่ง

เขียนโดย อาจารย์มดอัปเดต
สามช่วงเวลา สูตร M(D,K) ดิวตี้ที่ต้องใช้ กระแส RMS แล็บ
สรุปใน 30 วินาที
  • ช่วง \(D_1\): iL ขึ้นถึง \(i_{pk}\) · \(D_2\): iL ลงถึง 0 · \(D_3\): iL = 0 (ว่าง) เป็นเงื่อนไขของ DCM
  • volt-second: \(D_2 = D_1(1-M)/M\) · กระแสเฉลี่ย: \(I_o = \tfrac12 i_{pk}(D_1 + D_2)\)
  • ได้ \(M = \dfrac{2}{1+\sqrt{1+4K/D^2}}\) เมื่อ \(K = \dfrac{2L}{RT_s}\) และดิวตี้ที่ต้องใช้ \(D = M\sqrt{\dfrac{K}{1-M}}\)
  • ที่ดิวตี้คงที่ \(V_o\) เพิ่มเมื่อโหลดเบา สูงสุดที่ \(V_g\) ที่ไม่มีโหลด → ต้องใช้วงป้อนกลับ

ทำไมถึงเกิด DCM พื้นฐาน

จากหน้า CCM กระแสตัวเหนี่ยวนำเป็นสามเหลี่ยมที่มีค่าเฉลี่ยเท่ากับกระแสโหลด \(I_o\) ถ้า \(I_o\) น้อยกว่าครึ่งหนึ่งของริปเปิล \(\Delta i_L/2\) ปลายสามเหลี่ยมจะต่ำกว่าศูนย์ แต่ไดโอดกันกระแสย้อน \(i_L\) จึงหยุดที่ศูนย์แล้วค้างไว้จนกว่าสวิตช์จะปิดวงจรรอบใหม่ เรียกว่า โหมดกระแสไม่ต่อเนื่อง (DCM)

  • โหลดเบา (R ใหญ่) เช่นอุปกรณ์ที่อยู่ในโหมดรอ (standby)
  • L เล็ก หรือ fs ต่ำ ทำให้ริปเปิลใหญ่เมื่อเทียบกับกระแสโหลด
  • Vg สูง (D ต่ำ) ริปเปิลมาก ขอบเขต CCM แย่ลง

บางงานเลือก DCM โดยตั้งใจ: ใช้ L เล็ก ไดโอดไม่มี reverse recovery (กระแสเป็นศูนย์ก่อนไดโอดปิด) และประสิทธิภาพตอนเบาดี แลกกับกระแสพีกและ RMS ที่สูงกว่า

ขั้นที่ 1: สามช่วงเวลาในหนึ่งคาบ พื้นฐาน

แยกเป็นสามช่วง เขียนดิวตี้ของแต่ละช่วงเป็น \(D_1, D_2, D_3\) โดย \(D_1 + D_2 + D_3 = 1\) เฉพาะ \(D_1\) เท่านั้นที่ตัวควบคุมกำหนด (\(D_1 = D\)) ส่วน \(D_2\) ขึ้นกับวงจรและ \(D_3\) คือเวลาที่เหลือ

ช่วงสถานะ\(v_L\)\(i_L\)
\(D_1T_s\)Q นำ ไดโอดไม่นำ\(V_g - V_o\)เพิ่มจาก 0 ถึง \(i_{pk}\)
\(D_2T_s\)Q ไม่นำ ไดโอดนำ\(-V_o\)ลดจาก \(i_{pk}\) ถึง 0
\(D_3T_s\)ทั้งคู่ไม่นำ (ช่วงว่าง)00

ช่วงว่าง (\(D_3\)) ไม่มีกระแสผ่านตัวเหนี่ยวนำ จึงไม่มีแรงดันคร่อม \(v_L = 0\) โหนด SW ลอยอยู่ที่แรงดันขาออก (ในวงจรจริงมันสั่นด้วย L กับ \(C_{oss}\) ของสวิตช์ที่ความถี่ \(\approx 1/(2\pi\sqrt{LC_{oss}})\) ซึ่งไม่ได้อยู่ในแบบจำลองอุดมคตินี้) ส่วนโหลดได้รับพลังงานจากตัวเก็บประจุ C เพียงอย่างเดียว

J1 Three intervals of DCM สามช่วงเวลาของ DCM

\[ D_1 + D_2 + D_3 = 1,\qquad D_1 = D,\qquad D_3 > 0 \;\Leftrightarrow\; \text{DCM} \]

ขั้นที่ 2–4: หาอัตราส่วนแปลงผัน M = Vo/Vg กลาง

ขั้นที่ 2: กระแสพีกจากช่วง D₁

ในช่วง \(D_1\) กระแสเริ่มที่ศูนย์ เพิ่มด้วยความชัน \((V_g - V_o)/L\) นาน \(D_1T_s\):

J2 Peak inductor current กระแสพีกตัวเหนี่ยวนำ

\[ i_{pk} = \frac{(V_g - V_o)\,D_1T_s}{L} = \frac{V_g(1-M)\,D_1}{Lf_s} \]

ขั้นที่ 3: volt-second balance หา D₂

กระแสเริ่มและจบที่ศูนย์ ดังนั้นพื้นที่ \(v_L\cdot t\) ของช่วง \(D_1\) ต้องหักล้างช่วง \(D_2\) (ช่วง \(D_3\) ไม่มีส่วนร่วมเพราะ \(v_L = 0\)):

\[ (V_g - V_o)D_1 - V_oD_2 = 0 \;\Rightarrow\; D_2 = D_1\,\frac{V_g - V_o}{V_o} = D_1\,\frac{1-M}{M} \]

J3 Interval lengths D₂ and D₃ ความยาวช่วง D₂ และ D₃

\[ D_2 = D_1\,\frac{1-M}{M},\qquad D_3 = 1 - D_1 - D_2 = 1 - \frac{D_1}{M} \] \[ \text{DCM } (D_3>0) \Leftrightarrow M > D_1 \]

ข้อสังเกต: เงื่อนไขของ DCM คือ \(M > D\) นั่นคือ ใน DCM แรงดันขาออกสูงกว่าที่ \(D\) บอกไว้เสมอ (ในอุดมคติ CCM เท่ากับ \(M = D\) พอดี)

ขั้นที่ 4: charge balance — กระแสเฉลี่ยของสามเหลี่ยม

กระแสเฉลี่ยของ \(i_L\) ต้องเท่ากับกระแสโหลด \(I_o = V_o/R\) พื้นที่สามเหลี่ยมฐาน \((D_1 + D_2)T_s\) สูง \(i_{pk}\) หารด้วย \(T_s\):

J4 Average current in DCM กระแสเฉลี่ยใน DCM

\[ I_o = \frac{V_o}{R} = \frac{1}{2}\,i_{pk}\,(D_1 + D_2) = \frac{1}{2}\,i_{pk}\,\frac{D_1}{M} \]

แทน \(i_{pk}\) จาก J2 และ \(V_o = MV_g\):

\[ \frac{MV_g}{R} = \frac{1}{2}\cdot\frac{V_g(1-M)D_1T_s}{L}\cdot\frac{D_1}{M} \;\Rightarrow\; M^2 = (1-M)\,\frac{D_1^2RT_s}{2L} = \frac{(1-M)D^2}{K} \]

โดยนิยาม \(K \equiv \dfrac{2L}{RT_s}\) (พารามิเตอร์ไร้หน่วยที่รวม L โหลด และความถี่สวิตช์)

จัดเป็นสมการกำลังสองของ \(M\): \(K M^2 + D^2 M - D^2 = 0\) ได้รากที่เป็นบวก

\[ M = \frac{-D^2 + \sqrt{D^4 + 4KD^2}}{2K} = \frac{D^2\left(\sqrt{1+4K/D^2}-1\right)}{2K} \]

คูณบนและล่างด้วย \(\sqrt{1+4K/D^2}+1\) ส่วนบนกลายเป็น \(D^2\cdot 4K/D^2 = 4K\) จึงตัด \(K\) ได้:

J5 DCM conversion ratio อัตราส่วนแปลงผันใน DCM

\[ \boxed{M = \frac{V_o}{V_g} = \frac{2}{1+\sqrt{1+4K/D^2}}},\qquad K = \frac{2L}{RT_s} \]

ตรวจที่ขอบเขต \(D_3 = 0\) (\(M = D\)): แทน \(M = D\) ได้ \(\sqrt{1+4K/D^2} = 2/D - 1\) ยกกำลังสองและจัดรูปได้ \(K = 1-D\) ตรงกับขอบเขต CCM ในหน้าก่อน ✓ นี่คือ ความต่อเนื่อง ของสองโหมด: สูตร DCM ลู่เข้าสู่ \(M = D\) ที่ขอบ

ขั้นที่ 5: ดิวตี้ที่ต้องใช้ใน DCM กลาง

ในทางปฏิบัติเรารู้ \(V_o\) ที่ต้องการและโหลด จึงต้องการ \(D\) ย้อนจาก \(M\) ใช้สมการก่อนแก้กำลังสอง \(KM^2 = (1-M)D^2\):

J6 Required duty in DCM ดิวตี้ที่ต้องใช้ใน DCM

\[ \boxed{D = M\sqrt{\frac{K}{1-M}}} = \sqrt{\frac{2L\,I_o\,V_o}{T_s\,V_g\,(V_g - V_o)}} \]

รูปที่สองได้โดยแทน \(K = 2L/(RT_s)\) และ \(R = V_o/I_o\) ผลที่ได้สำคัญมาก: ดิวตี้ที่ต้องใช้ใน DCM แปรตาม \(\sqrt{I_o}\) (โหลดเบาลง 4 เท่า ดิวตี้ลดเหลือครึ่งเดียว) ต่างจาก CCM ที่ดิวตี้คงที่ไม่ขึ้นกับโหลด นี่คือเหตุผลที่คอนเวอร์เตอร์ที่ตั้งดิวตี้คงที่มีแรงดันขาออกลอยเมื่อโหลดเบา และเป็นเหตุผลที่ตัวชดเชยต้องรองรับสองโหมด (ดูหน้าฟังก์ชันถ่ายโอนใน DCM)

J7 Boundary between CCM and DCM ขอบเขตระหว่าง CCM และ DCM

\[ K = 1-D \;\Leftrightarrow\; I_{o,crit} = \frac{V_o(1-V_o/V_g)}{2Lf_s} \qquad \text{DCM เมื่อ } I_o < I_{o,crit} \]

กราฟในแล็บด้านล่างแสดงเส้นนี้: ดิวตี้ที่ต้องใช้เป็นเส้นราบ (CCM) แล้วโค้งลงตามรากที่สองเมื่อ \(I_o < I_{o,crit}\)

แรงดันขาออกลอยเมื่อไร้โหลด (open loop) พื้นฐาน

ตั้ง \(D\) คงที่แล้วให้โหลดเบาลง (\(R \to \infty\), \(K \to 0\)): ในสูตร J5 \(4K/D^2 \to 0\) จึงได้ \(M \to \dfrac{2}{1+1} = 1\) คือ \(V_o \to V_g\) ไม่ว่าดิวตี้เล็กแค่ไหน (ตัวเก็บประจุถูกชาร์จทีละพัลส์โดยไม่มีอะไรดึงพลังงานออก จนแรงดันสูงถึงระดับอินพุต) ตัวอย่าง J-4 ใช้ตัวเลขจริง ตรงนี้เป็นสาเหตุที่แหล่งจ่ายแบบ open-loop ที่ไม่มีโหลดขั้นต่ำ (dummy load) อาจทำให้แรงดันสูงเกินพิกัดวงจรที่ต่อกับมัน

J8 No-load limit ขีดจำกัดเมื่อไร้โหลด

\[ R\to\infty \;\Rightarrow\; K\to 0 \;\Rightarrow\; M \to 1 \qquad \left(\text{ประมาณ } M \approx 1 - \frac{K}{2D^2}\ \text{เมื่อ } K \ll D^2\right) \]

กระแส RMS ริปเปิลแรงดัน และความเค้นใน DCM กลาง

รูปคลื่นเป็นสามเหลี่ยมที่รู้ทั้งความสูง \(i_{pk}\) และความกว้าง จึงคำนวณค่า RMS ได้จาก \(\langle i^2\rangle\) ของสามเหลี่ยม: ความชันเชิงเส้นจาก 0 ถึง \(i_{pk}\) ตลอดช่วงกว้าง \(D\) มีค่า \(\langle i^2\rangle = i_{pk}^2 D/3\)

J9 Currents in DCM กระแสต่างๆ ใน DCM

\[ I_{Q,rms} = i_{pk}\sqrt{\frac{D_1}{3}},\qquad I_{D,rms} = i_{pk}\sqrt{\frac{D_2}{3}},\qquad I_{L,rms} = i_{pk}\sqrt{\frac{D_1+D_2}{3}} \] \[ I_{g} = \frac{1}{2}i_{pk}D_1,\qquad I_{D,avg} = \frac{1}{2}i_{pk}D_2 \]

ริปเปิลแรงดัน (ESR = 0): กระแสเข้า C คือ \(i_L - I_o\) เฉพาะส่วนที่ \(i_L > I_o\) ทำให้ประจุเพิ่ม พื้นที่สามเหลี่ยมเล็กที่อยู่เหนือระดับ \(I_o\) ฐานกว้าง \((i_{pk}-I_o)(D_1+D_2)T_s/i_{pk}\):

J10 Output ripple in DCM (ESR = 0) ริปเปิลแรงดันใน DCM

\[ \Delta v_o = \frac{\Delta Q}{C} = \frac{(i_{pk} - I_o)^2\,(D_1+D_2)\,T_s}{2\,C\,i_{pk}} \]

เมื่อเทียบกับ CCM ที่โหลดเท่ากัน DCM มี \(i_{pk}\) สูงกว่า \(I_o\) หลายเท่า จึงมีกระแส RMS ในสวิตช์และตัวเหนี่ยวนำสูงกว่าสัดส่วนกับกระแสโหลด สูญเสียการนำ \(I^2R\) จึงเพิ่มขึ้นที่โหลดเบา แต่สูญเสียสวิตช์ลดเพราะ turn-on ที่กระแสศูนย์ ไม่มี reverse recovery ของไดโอด

ในทางปฏิบัติ ขั้นสูง

  • ควบคุมแบบป้อนกลับ ปรับ D ตาม J6 เองเมื่อโหลดเปลี่ยน แต่ตัวชดเชยที่ออกแบบสำหรับ CCM (ขั้วคู่) จะผิดทันทีที่เข้า DCM (ขั้วเดียว) ดูหน้า ฟังก์ชันถ่ายโอน และ การออกแบบตัวชดเชย
  • Synchronous rectifier ถ้าไม่ปิด MOSFET ตัวล่างเมื่อกระแสถึงศูนย์ → forced CCM ไม่เกิด DCM แต่มีกระแสวน ชิปสมัยใหม่จึงมี diode emulation (ปิดที่กระแสศูนย์) หรือ pulse-skipping / burst mode ที่โหลดเบามาก เพื่อรักษาประสิทธิภาพ
  • เสียงรบกวน: ช่วงว่างทำให้โหนด SW สั่นด้วย L–Coss ซึ่งแผ่ EMI และบางครั้งเกิดเสียงหอนเมื่อความถี่สวิตช์ลดลงเข้าย่านเสียง (burst) — ดู วิเคราะห์อาการเสีย
  • ค่าแฝงใน DCM: ตัวแบบที่เสนอเป็นแบบอุดมคติ ค่าแฝงขยับ \(M\) เล็กน้อย การจำลองสวิตชิ่งในแล็บรวมค่าแฝงให้ดูผลได้

ตัวอย่างวิธีทำ (ตรวจตัวเลขด้วยซิมูเลเตอร์แล้ว)

โจทย์ฐาน: \(V_g = 24\) V, \(L = 300\ \mu\)H, \(C = 100\ \mu\)F, \(f_s = 50\) kHz (\(T_s = 20\ \mu\)s) ไม่มีค่าแฝง (เหมือนหน้า CCM แต่เปลี่ยนโหลด)

ตัวอย่าง J-1

ตั้ง D = 0.5 คงที่ แล้วโหลดเบาลงเป็น R = 100 Ω: Vo เป็นเท่าไร

  1. \(K = \dfrac{2L}{RT_s} = \dfrac{2(300\mu)}{100(20\mu)} = 0.3\) เทียบ \(1-D = 0.5\): \(K < 1-D\) → DCM

  2. J5: \(M = \dfrac{2}{1+\sqrt{1+4(0.3)/0.25}} = \dfrac{2}{1+\sqrt{5.8}} = \dfrac{2}{3.4083} = 0.5868\) → \(V_o = 24\times0.5868 = \mathbf{14.08}\) V (สูงกว่า 12 V ของ CCM!)

  3. J3: \(D_2 = 0.5\times\dfrac{1-0.5868}{0.5868} = 0.3521\) และ \(D_3 = 1 - 0.5 - 0.3521 = 0.1479\) (ช่วงว่าง 14.8 %)

  4. J2: \(i_{pk} = \dfrac{(24 - 14.08)(0.5)(20\mu)}{300\mu} = 0.3306\) A · J4: \(I_o = \tfrac12(0.3306)(0.5 + 0.3521) = 0.1408\) A \(= V_o/R = 14.08/100\) ✓

  5. ตรวจด้วยซิมูเลเตอร์สวิตชิ่ง: \(V_o = 14.08\) V, \(i_{pk} = 0.331\) A ✓

ตัวอย่าง J-2

ต้องการ 12 V ที่โหลด R = 100 Ω (0.12 A) ตั้ง D เท่าไร

  1. \(M = 12/24 = 0.5\), \(K = 0.3\) (ข้างต้น) ตรวจโหมด: ขอบเขต \(1-D\) ที่ดิวตี้ CCM คือ 0.5 > 0.3 → DCM

  2. J6: \(D = M\sqrt{\dfrac{K}{1-M}} = 0.5\sqrt{\dfrac{0.3}{0.5}} = 0.5\times0.7746 = \mathbf{0.3873}\) (ไม่ใช่ 0.5!)

  3. ตรวจอีกรูป: \(D = \sqrt{\dfrac{2(300\mu)(0.12)(12)}{(20\mu)(24)(12)}} = \sqrt{0.15} = 0.3873\) ✓

  4. รายละเอียดรูปคลื่น: \(D_2 = D_1(1-M)/M = 0.3873\) และ \(D_3 = 1 - 0.7746 = 0.2254\) · \(i_{pk} = \dfrac{12(0.3873)(20\mu)}{300\mu} = 0.3098\) A · \(I_{Q,rms} = 0.3098\sqrt{0.3873/3} = 0.1113\) A · \(I_{L,rms} = 0.3098\sqrt{0.7746/3} = 0.1574\) A · \(I_g = \tfrac12(0.3098)(0.3873) = 0.0600\) A → \(P_{in} = 24\times0.06 = 1.44\) W \(= 12\times0.12\) ✓

  5. ริปเปิลแรงดัน (J10): \(\Delta v_o = \dfrac{(0.3098-0.12)^2(0.7746)(20\mu)}{2(100\mu)(0.3098)} = 9.0\) mV ซิมูเลเตอร์ให้ 9.02 mV ✓ และซิมที่ \(D = 0.3873\) ให้ \(V_o = 12.001\) V

เลือก L ให้ยังเป็น CCM ถึง 10 % ของโหลดเต็ม

  1. โหลดเต็ม 1.2 A → 10 % คือ \(I_{o,\min} = 0.12\) A

  2. ขอบเขต: \(I_{o,crit} = \dfrac{V_o(1-D)}{2Lf_s} \le I_{o,\min}\) → \(L \ge \dfrac{V_o(1-D)}{2f_sI_{o,\min}}\)

  3. ที่ \(V_g = 24\) V (D = 0.5): \(L \ge \dfrac{12(0.5)}{2(50k)(0.12)} = 500\ \mu\)H

  4. ที่ \(V_g = 30\) V (D = 0.4) แย่กว่า: \(L \ge \dfrac{12(0.6)}{2(50k)(0.12)} = \mathbf{600}\ \mu\)H → เลือก 680 µH (ใหญ่กว่าเดิมที่ใช้ 300 µH สองเท่าเศษ) หรือเพิ่ม \(f_s\) เป็น 100 kHz ใช้ 300–330 µH ได้

ตัวอย่าง J-4

ตั้ง D = 0.5 แล้วถอดโหลดเกือบหมด (open loop)

  1. R = 1 kΩ: \(K = 0.03\), \(4K/D^2 = 0.48\) → \(M = \dfrac{2}{1+\sqrt{1.48}} = 0.9023\) → \(V_o = 21.7\) V

  2. R = 10 kΩ: \(K = 0.003\), \(4K/D^2 = 0.048\) → \(M = 0.9883\) → \(V_o = 23.7\) V (ใกล้ 24 V ของอินพุต)

  3. บทเรียน: ตัวเก็บประจุและวงจรปลายทางต้องทนแรงดันอินพุตทั้งหมดแม้ตั้ง D ไว้ที่แรงดันครึ่งหนึ่ง เมื่อไม่มีวงป้อนกลับ

แล็บ: ดิวตี้ที่ต้องใช้เทียบโหลด และ M(D,K) พื้นฐาน

กราฟที่ 1: ดิวตี้ที่ต้องใช้ให้ได้ Vo เมื่อโหลดเปลี่ยน

เลื่อนแถบ Io ดูจุดบนเส้น แล้วเปลี่ยน L หรือ fs เพื่อดูว่าจุดแบ่ง CCM/DCM ขยับไปที่ไหน ติ๊ก "รวมค่าแฝง" เพื่อดูเส้น CCM ยกสูงขึ้นเล็กน้อยตามกระแส (H9)

กราฟที่ 2: อัตราส่วนแปลงผัน M เทียบกับ D สำหรับค่า K ต่างๆ

เส้นเฉียงคือ CCM (\(M = D\)) เส้นโค้งสูงกว่าคือ DCM แต่ละ K จะแตกออกจากเส้นเฉียงที่ \(D = 1-K\) ตามสูตร J5 ยิ่ง K เล็ก (โหลดเบา) เส้นยิ่งสูง

รูปคลื่นจริงจากการจำลองสวิตชิ่ง

กดตัวอย่าง "DCM โหลดเบา" (D = 0.5, R = 100 Ω → 14.08 V) และ "DCM: หา D ให้ได้ 12 V" (D = 0.3873) แล้วเทียบตารางทฤษฎี–จำลอง

ใบงานทดลอง

ใบงาน B1 — ปีนขึ้นของแรงดันตอนโหลดเบา: ตั้ง D = 0.5 คงที่ เพิ่ม R จาก 60 → 100 → 300 → 1000 Ω บันทึก \(V_o\) เทียบ J5 (12.0 ที่ขอบเขต, 14.08, 18.37, 21.66 V ตามลำดับ) ดูรูปคลื่น iL ที่ช่วงราบ D₃ ยาวขึ้น

ใบงาน B2 — หา D สำหรับ 12 V: เลือกโหมดคำนวณ D จาก Vo เป้าหมาย 12 V ที่ R = 100 Ω ได้ D = 0.3873 เปลี่ยน R เป็น 80, 70, 60 Ω จะได้ D = 0.433, 0.463, 0.500 ตามลำดับ และคงที่ 0.5 เมื่อ R ≤ 60 Ω (เข้า CCM)

ใบงาน B3 — ผลของ L: ที่ R = 100 Ω ตั้ง D = 0.5 เพิ่ม L จาก 300 → 450 → 600 µH ดูว่า \(V_o\) ลดลงเข้าใกล้ 12 V เมื่อ K โตขึ้น ที่ 600 µH ได้ K = 0.6 > 0.5 กลับเป็น CCM และ \(V_o = 12\) V แล้วลองใช้ L = 100 µH ดูว่า \(V_o\) สูงขึ้นเท่าไร

ใบงาน B4 — Synchronous: เปิด Synchronous ที่ R = 100 Ω, D = 0.5 แล้วดู \(V_o\) (12 V แม้โหลดเบา) และ iL ที่ติดลบ (กระแสวนกลับ) สังเกตว่า \(V_o = DV_g\) กลับมาเป็นจริงทุกโหลด

ใบงาน B5 — เส้นดิวตี้เทียบโหลด: ที่กราฟที่ 1 เลื่อน \(I_o\) แล้วจดค่า D ที่ 0.05, 0.1, 0.2, 0.5, 1 A ควรได้ 0.250, 0.354, 0.500, 0.500, 0.500 เพราะต่ำกว่า \(I_{o,crit}\) = 0.2 A ใช้ \(D = \sqrt{1.25\,I_o}\) (J6) แล้วคงที่ที่ 0.5 ใน CCM
