บั๊กคอนเวอร์เตอร์โหมด CCM: ไล่วงจรทีละขั้นเพื่อหาดิวตี้ไซเคิล D = Vo/Vin พร้อมค่าแฝงและแล็บรูปคลื่น

หน้านี้พาไล่วงจรบั๊กด้วยกฎของเคอร์ชอฟฟ์ทีละช่วงสวิตช์ แล้วสรุปเป็น volt-second balance และ charge balance จนได้ดิวตี้ที่ต้องตั้ง ทั้งแบบอุดมคติและแบบมี Rds(on) DCR VF พร้อมแล็บที่เทียบสูตรกับการจำลองสวิตชิ่งจริง

เขียนโดย อาจารย์มดอัปเดต
วงจรแต่ละช่วง หา D = Vo/Vin ขอบเขต CCM ดิวตี้เมื่อมีค่าแฝง แล็บรูปคลื่น
สรุปใน 30 วินาที
  • ช่วง ON: \(v_L = V_g - V_o\) กระแสชันขึ้น · ช่วง OFF: \(v_L = -V_o\) กระแสชันลง
  • กระแสต้องกลับที่เดิมเมื่อสิ้นคาบ → พื้นที่ \(v_L\cdot t\) สองช่วงเท่ากัน → \(V_o = DV_g\)
  • \(\langle i_C\rangle = 0\) → \(I_L = I_o\) และ \(I_g = D\,I_o\) · ripple \(\Delta i_L = V_o(1-D)/(Lf_s)\)
  • เป็น CCM เมื่อ \(K = 2L/(RT_s) > 1-D\) · มีค่าแฝงต้องใช้ \(D = \dfrac{V_o + V_F + I_L(r_L+R_d)}{V_g + V_F - I_L(R_{on}-R_d)}\)
ระดับพื้นฐาน ปวส. · ป.ตรี ปี 2–3กลาง ป.ตรี ปี 3–4ขั้นสูง ป.โท · งานวิจัย

เป้าหมาย: ตั้งดิวตี้เท่าไรจึงได้แรงดันที่ต้องการ พื้นฐาน

หน้า บั๊กคอนเวอร์เตอร์ สรุปผลไว้แล้วว่า \(V_o = DV_g\) หน้านี้ตอบคำถามที่ลึกกว่า: สูตรนี้มาจากไหน ใช้ได้เมื่อไร และเมื่อวงจรมีความสูญเสียจริงต้องตั้ง \(D\) เป็นเท่าไร ทุกขั้นเขียนจากวงจรจริงด้วย KVL/KCL ไม่ใช่การท่องสูตร และทุกตัวเลขในตัวอย่างตรวจกับซิมูเลเตอร์ระดับการสวิตช์ในแล็บด้านล่าง

ข้อตกลงที่ใช้ทั้งชุด: แรงดันอินพุตเขียนเป็น \(V_g\) (เหมือน \(V_{in}\)) · ตัวพิมพ์ใหญ่ = ค่าคงตัวของสถานะคงตัว ตัวพิมพ์เล็ก = ค่าขณะใดขณะหนึ่ง · \(D' = 1-D\) · คาบสวิตช์ \(T_s = 1/f_s\)

ข้อสมมติความหมายเมื่อไรไม่จริง
สถานะคงตัวเป็นคาบปริมาณทุกตัวกลับมาเท่าเดิมเมื่อครบคาบช่วงสตาร์ท เปลี่ยนโหลด (ดูหน้าแบบจำลองเฉลี่ย)
ริปเปิลแรงดันขาออกเล็ก\(v_o(t)\approx V_o\) คงที่ภายในหนึ่งคาบC เล็กเกินไป ESR สูง
สวิตช์และไดโอดอุดมคติไม่มีแรงดันตกขณะนำ ไม่มีเวลาสวิตช์หัวข้อค่าแฝงแก้ข้อนี้
กระแส \(i_L\) ไม่ลงถึงศูนย์โหมดกระแสต่อเนื่อง (CCM)โหลดเบา → DCM

ขั้นที่ 1–2: วงจรในแต่ละช่วงของสวิตช์ พื้นฐาน

สวิตช์ Q เปิด–ปิดสลับกันด้วยคาบ \(T_s\) ช่วงแรก (\(0 \le t < DT_s\)) ปิดวงจร ช่วงที่สอง (\(DT_s \le t < T_s\)) เปิดวงจร เกิดวงจรเชิงเส้นสองแบบสลับกัน เราจึงเขียนสมการทีละแบบ แล้วค่อยต่อกันตามเวลา

ช่วง ON (สวิตช์ Q นำ)

แรงดันที่โหนด SW เท่ากับ \(V_g\) ไดโอดมีแคโทดสูงกว่าแอโนดจึงถูกไบแอสย้อนและไม่นำ วงจรเหลือวงเดียว: \(V_g\) → L → (C ∥ R) → กลับ KVL รอบวงให้ \(V_g - v_L - v_o = 0\) และเมื่อ \(v_L = L\,\dfrac{di_L}{dt}\) จะได้

H1 Inductor equation in each interval สมการตัวเหนี่ยวนำแต่ละช่วง

\[ \text{ON: } L\frac{di_L}{dt} = V_g - v_o \approx V_g - V_o \qquad\qquad \text{OFF: } L\frac{di_L}{dt} = -v_o \approx -V_o \]

ที่โหนดเอาต์พุต KCL ให้กระแสตัวเก็บประจุ \(i_C = i_L - v_o/R\) เสมอทั้งสองช่วง (กระแสที่เหลือจาก \(i_L\) หลังโหลดใช้ไปคือกระแสที่ชาร์จ C)

ช่วง OFF (สวิตช์ Q เปิดวงจร)

กระแสในตัวเหนี่ยวนำเปลี่ยนทันทีไม่ได้ (ถ้าเปลี่ยนทันที \(v_L = L\,di/dt\) จะเป็นอนันต์) เมื่อ Q เปิด ตัวเหนี่ยวนำจึงกลับขั้วแรงดันเองจนโหนด SW ต่ำกว่าศูนย์ ไดโอดถูกไบแอสตรงและนำกระแสเดิมต่อไป โหนด SW ≈ 0 (ในอุดมคติ) ดังนั้น \(v_L = -v_o\) กระแสเริ่ม ลดลง ผ่านไดโอดไปยัง C ∥ R

จุดที่นักศึกษามักสับสน: ในช่วง OFF พลังงานไม่ได้มาจากแหล่งจ่ายอีกต่อไป แต่มาจากพลังงานแม่เหล็ก \(\tfrac12 Li_L^2\) ที่เก็บไว้ในช่วง ON ตัวเหนี่ยวนำจึงเป็น "แหล่งกระแส" ที่ไดโอดคอยส่งต่อให้โหลด

ขั้นที่ 3: กระแสตัวเหนี่ยวนำในหนึ่งคาบ พื้นฐาน

เมื่อ \(v_o \approx V_o\) คงที่ ความชันของ \(i_L\) ในแต่ละช่วงคงที่ → กระแสเป็นเส้นตรงสองท่อนต่อกัน (สามเหลี่ยม) กระแสเพิ่มในช่วง ON และลดในช่วง OFF

H2 Inductor current ripple ริปเปิลกระแสตัวเหนี่ยวนำ

\[ \Delta i_L^{\text{(ON)}} = \frac{V_g - V_o}{L}\,DT_s \qquad \Delta i_L^{\text{(OFF)}} = -\frac{V_o}{L}\,D'T_s \]

กระแสเฉลี่ยของสามเหลี่ยมคือค่ากลางระหว่างจุดสูงสุดและต่ำสุด \(I_L = \dfrac{I_{L,\min} + I_{L,\max}}{2}\) และผลต่างคือริปเปิล \(\Delta i_L = I_{L,\max} - I_{L,\min}\) ถ้าสิ้นคาบกระแสไม่กลับมาที่ \(I_{L,\min}\) แสดงว่ายังไม่ถึงสถานะคงตัว (กระแสจะไล่ขึ้นหรือลงต่อไปทุกคาบ)

ขั้นที่ 4: หาอัตราส่วนแปลงผัน Vo/Vg และดิวตี้ พื้นฐาน

เงื่อนไขสถานะคงตัวคือ กระแสสิ้นคาบ = กระแสต้นคาบ ดังนั้นการเพิ่มของกระแสในช่วง ON ต้องถูกลดลงเท่ากันในช่วง OFF พอดี แสดงได้สามวิธีที่ได้ผลเดียวกัน

วิธี ก: ให้ผลรวมการเปลี่ยนกระแสเป็นศูนย์

\(\Delta i_L^{(ON)} + \Delta i_L^{(OFF)} = 0\) จาก H2:

\[ \begin{aligned} \frac{(V_g - V_o)DT_s}{L} - \frac{V_o D'T_s}{L} &= 0 \\ (V_g - V_o)D &= V_o(1-D) \\ V_gD - V_oD &= V_o - V_oD \\ V_o &= DV_g \end{aligned} \]

วิธี ข: volt-second balance (พื้นที่ใต้กราฟ \(v_L\))

คูณทั้งสองข้างด้วย \(L\): การเปลี่ยนกระแสทุกช่วงคือ \(\int v_L\,dt\) ผลรวมต้องเป็นศูนย์ เรียกว่า volt-second balance ในรูปคือพื้นที่สี่เหลี่ยมสองก้อนต้องเท่ากัน \(A_1 = A_2\):

H3 Volt-second balance → conversion ratio (CCM) อัตราส่วนแปลงผันและดิวตี้

\[ \underbrace{(V_g - V_o)\,DT_s}_{A_1} + \underbrace{(-V_o)\,D'T_s}_{-A_2} = 0 \;\Rightarrow\; \boxed{\frac{V_o}{V_g} = D} \qquad \boxed{D = \frac{V_o}{V_g}} \]

วิธี ค: เฉลี่ยแรงดันที่โหนด SW (เห็นภาพที่สุด)

แรงดันที่โหนด SW เป็นคลื่นสี่เหลี่ยมสูง \(V_g\) นาน \(D\) ของคาบ ค่าเฉลี่ยคือ \(\langle v_{sw}\rangle = DV_g\) ตัวกรอง LC ปล่อยผ่านเฉพาะค่าเฉลี่ยนี้ และที่ DC ตัวเหนี่ยวนำเป็นสายลัด (แรงดันเฉลี่ยคร่อม L เป็นศูนย์) จึงได้ \(V_o = \langle v_{sw}\rangle = DV_g\) บั๊กจึงเป็น "ตัวเฉลี่ยแรงดันที่ควบคุมด้วยความกว้างพัลส์"

ผลที่ควรจำ: \(V_o\) ขึ้นกับ \(D\) และ \(V_g\) เท่านั้น ไม่ขึ้นกับ L, C, fs หรือโหลด (ตราบใดที่ยังเป็น CCM และไม่มีค่าแฝง) นั่นคือแหล่งจ่ายแรงดันในอุดมคติ ต่างจาก DCM ที่ \(V_o\) ขึ้นกับโหลดอย่างแรง ดูหน้า DCM

ขั้นที่ 5: charge balance กระแสเฉลี่ย และกำลัง พื้นฐาน

ในสถานะคงตัวแรงดันตัวเก็บประจุกลับมาเท่าเดิมทุกคาบ ประจุสุทธิที่เข้า C ต้องเป็นศูนย์: \(\langle i_C\rangle = 0\) จาก KCL \(i_C = i_L - v_o/R\) ได้ค่าเฉลี่ยของ \(i_L\) เท่ากับกระแสโหลดทันที ส่วนกระแสอินพุต \(i_g\) ไหลเฉพาะช่วง ON (เท่ากับ \(i_L\)) จึงมีค่าเฉลี่ย \(D\,I_L\)

H4 Charge balance and currents สมดุลประจุและกระแสเฉลี่ย

\[ \langle i_C\rangle = 0 \;\Rightarrow\; I_L = I_o = \frac{V_o}{R},\qquad I_g = D\,I_L \] \[ P_{in} = V_gI_g = V_g\,D\,I_o = V_oI_o = P_{out} \]

บรรทัดสุดท้ายแสดงว่าแบบจำลองอุดมคติไม่มีการสูญเสีย (\(\eta = 100\%\)) และเทียบเท่าหม้อแปลง DC อัตราส่วน \(1:D\) ที่ลดแรงดันได้ \(D\) เท่าและเพิ่มกระแสได้ \(1/D\) เท่า — มุมมองนี้ใช้ต่อในหน้าแบบจำลองวงจรเฉลี่ย

ขั้นที่ 6: ค่าสูงสุด–ต่ำสุดของกระแส และริปเปิลแรงดันขาออก กลาง

รวมค่าเฉลี่ย (ขั้นที่ 5) กับความชัน (ขั้นที่ 3) จะได้ขอบของสามเหลี่ยม แทน \(V_o = DV_g\) ใน H2 ได้ริปเปิลที่นิยมใช้ออกแบบ

H5 Current extremes and ripple ค่าสูงสุด–ต่ำสุดของกระแสและริปเปิล

\[ \Delta i_L = \frac{V_o(1-D)}{L f_s} = \frac{(V_g - V_o)D}{Lf_s},\qquad I_{L,\max/\min} = I_o \pm \frac{\Delta i_L}{2} \]

ริปเปิลกระแสไหลเข้าตัวเก็บประจุ (ส่วนที่เกิน \(I_o\)) ประจุสะสมคือพื้นที่สามเหลี่ยมเล็กที่ระดับเหนือ \(I_o\): \(\Delta Q = \tfrac12\cdot\dfrac{T_s}{2}\cdot\dfrac{\Delta i_L}{2} = \dfrac{\Delta i_LT_s}{8}\) จึงเกิดแรงดันขึ้นลง \(\Delta Q/C\) ส่วน ESR ทำให้เกิดแรงดัน \(\Delta i_L\cdot r_C\) ซ้อนทับ

H6 Output voltage ripple ริปเปิลแรงดันขาออก

\[ \Delta v_{o}^{(C)} = \frac{\Delta i_L}{8\,C f_s}, \qquad \Delta v_o^{(ESR)} = \Delta i_L\, r_C, \qquad \Delta v_{o,pp} \le \Delta v_o^{(C)} + \Delta v_o^{(ESR)} \]

การบวกตรงๆ เป็น ขอบบน เพราะจุดสูงสุดของสองส่วนไม่เกิดพร้อมกัน ค่าจริงจากรูปคลื่นมักต่ำกว่า (ดูตัวอย่าง H-1 และเทียบในแล็บ) ถ้า ESR ใหญ่กว่า \(\dfrac{1}{8Cf_s}\) ริปเปิลแรงดันถูกกำหนดโดย ESR เป็นหลัก ซึ่งเป็นเหตุผลที่ตัวเก็บประจุอิเล็กโทรไลต์ธรรมดาให้ริปเปิลสูงกว่าโพลิเมอร์หรือเซรามิกมาก

ออกแบบที่ Vg สูงสุด: \(\Delta i_L = V_o(1-D)/(Lf_s)\) มากที่สุดเมื่อ \(D\) ต่ำสุด คือเมื่อ \(V_g\) สูงสุด ดังนั้นคำนวณ L ที่ \(V_{g,\max}\) เสมอ (ตัวอย่าง H-3)

ขั้นที่ 7: ขอบเขตของ CCM — สูตรข้างบนใช้ได้เมื่อใด พื้นฐาน

ทุกสูตรข้างต้นสมมติว่า \(i_L\) ไม่ลงถึงศูนย์ ถ้า \(I_{L,\min} = I_o - \Delta i_L/2 \le 0\) ไดโอดจะหยุดนำกลางคาบ (วงจรเข้า DCM) เงื่อนไขขอบเขตคือ \(I_o = \Delta i_L/2\):

\[ \frac{V_o}{R} > \frac{V_o(1-D)}{2Lf_s} \;\Longleftrightarrow\; \frac{2L}{RT_s} > 1-D \]

H7 CCM/DCM boundary ขอบเขตโหมดกระแสต่อเนื่อง

\[ K \equiv \frac{2L}{RT_s} > K_{crit}(D) = 1-D \] \[ I_{o,crit} = \frac{V_o(1-D)}{2Lf_s},\qquad R_{crit} = \frac{2L}{(1-D)T_s},\qquad L_{crit} = \frac{(1-D)RT_s}{2} \]

ตีความ: โหลดเบาลง (R ใหญ่ขึ้น) หรือ L เล็กลง หรือ fs ต่ำลง ทำให้ K ลดลงและเข้าใกล้ DCM ขอบเขตแย่ที่สุดเมื่อ \(D\) ต่ำสุด (\(V_g\) สูงสุด) เพราะ \(1-D\) ใหญ่สุด ถ้าต้องการ CCM ถึงกระแสโหลดต่ำสุด \(I_{o,\min}\) ให้เลือก \(L \ge \dfrac{V_o(1-D_{\min})}{2f_sI_{o,\min}}\)

บั๊กแบบ synchronous (ใช้ MOSFET ตัวล่างแทนไดโอด) ไม่มีขอบเขตนี้ เพราะ MOSFET นำกระแสย้อนกลับได้ \(i_L\) จึงติดลบและเป็น CCM เสมอ (เรียก forced CCM) แลกกับกระแสหมุนวนที่เพิ่มการสูญเสียตอนเบา — ลองในแล็บด้วยปุ่ม Synchronous

ขั้นที่ 8: ดิวตี้ที่ต้องใช้จริงเมื่อมี Rds(on) DCR และ VF กลาง

วงจรจริงมีความต้านทานแฝงสี่ตัวที่ทำให้แรงดันขาออกต่ำกว่า \(DV_g\): \(R_{on}\) ของสวิตช์ (ช่วง ON) \(V_F\) และ \(R_d\) ของไดโอด (ช่วง OFF) และ DCR \(r_L\) ของตัวเหนี่ยวนำ (ทั้งสองช่วง) ทำ volt-second balance ใหม่โดยใส่ตัวแฝงลงในสมการช่วงละบรรทัด (ใช้ \(I_L = V_o/R\) เป็นกระแสเฉลี่ย):

\[ \text{ON: } v_L = V_g - R_{on}I_L - r_LI_L - V_o,\qquad \text{OFF: } v_L = -V_F - R_dI_L - r_LI_L - V_o \]

เฉลี่ยตลอดคาบให้เป็นศูนย์ \(D\,v_L^{(ON)} + D'\,v_L^{(OFF)} = 0\):

\[ D(V_g - R_{on}I_L) - D'(V_F + R_dI_L) - r_LI_L - V_o = 0 \]

H8 Output voltage with parasitics แรงดันขาออกเมื่อมีความต้านทานแฝง

\[ V_o = \frac{D V_g - D' V_F}{1 + R_s/R},\qquad R_s = r_L + D\,R_{on} + D'\,R_d \]

แก้สมการข้างต้นหา \(D\) ตรงๆ ได้เพราะ \(D\) ปรากฏเป็นเชิงเส้น (\(R_s\) มี \(D\) แต่คูณกับ \(I_L\) ที่ทราบ):

H9 Required duty cycle with parasitics ดิวตี้ที่ต้องใช้เมื่อมีค่าแฝง

\[ \boxed{D = \frac{V_o + V_F + I_L\,(r_L + R_d)}{V_g + V_F - I_L\,(R_{on} - R_d)}},\qquad I_L = \frac{V_o}{R} \]

กรณี synchronous แทน \(V_F = 0\) และ \(R_d = R_{on,\text{ตัวล่าง}}\) ผลคือค่าแฝงเหลือเพียง \(r_L\) และ \(R_{on}\) ของ FET ทั้งสอง ทำให้ \(D\) ใกล้ \(V_o/V_g\) มากกว่าแบบไดโอด สังเกตว่า \(D\) ที่ต้องใช้ขึ้นกับกระแสโหลด (ผ่าน \(I_L\)) ต่างจากอุดมคติ ตัวควบคุมแบบป้อนกลับจึงจำเป็นเพื่อรักษา \(V_o\) เมื่อโหลดเปลี่ยน

ข้อควรระวัง: H8 และ H9 ใช้ได้เฉพาะ CCM และไม่รวมการสูญเสียจากการสวิตช์ (ซึ่งกินพลังงานแต่แทบไม่เปลี่ยน \(D\)) ถ้าวงจรเข้า DCM ให้ใช้สูตรในหน้า DCM

ตัวอย่างวิธีทำ (ตรวจตัวเลขด้วยซิมูเลเตอร์แล้ว)

โจทย์ฐาน: \(V_g = 24\) V, \(V_o = 12\) V, \(R = 10\ \Omega\) (\(I_o = 1.2\) A), \(L = 300\ \mu\)H, \(C = 100\ \mu\)F, \(f_s = 50\) kHz (\(T_s = 20\ \mu\)s)

ตัวอย่าง H-1

วงจรอุดมคติ: หา D ริปเปิล และตรวจว่าเป็น CCM

  1. ดิวตี้: \(D = V_o/V_g = 12/24 = 0.5\)

  2. กระแสเฉลี่ย (H4): \(I_L = V_o/R = 12/10 = 1.2\) A และ \(I_g = D\,I_L = 0.6\) A ตรวจกำลัง \(P_{in} = 24\times0.6 = 14.4\) W \(= P_{out} = 12\times1.2\) ✓

  3. ริปเปิลกระแส (H5): \(\Delta i_L = \dfrac{12(1-0.5)}{300\mu\cdot 50k} = \dfrac{6}{15} = 0.4\) A → \(I_{L,\max} = 1.4\) A, \(I_{L,\min} = 1.0\) A

  4. ตรวจ CCM (H7): \(K = \dfrac{2(300\mu)}{10\,(20\mu)} = 3 > 1-D = 0.5\) ✓ เป็น CCM (\(I_{L,\min} = 1.0 > 0\)) ขอบเขตคือ \(R_{crit} = \dfrac{2(300\mu)}{0.5\,(20\mu)} = 60\ \Omega\) ตรงกับ \(I_{o,crit} = \Delta i_L/2 = 0.2\) A

  5. ริปเปิลแรงดัน (H6) ถ้า ESR = 0: \(\Delta v_o = \dfrac{0.4}{8(100\mu)(50k)} = 10\) mV · ถ้า ESR = 50 mΩ: ขอบบน \(10 + 0.4\times0.05\times 1000 = 30\) mV แต่รูปคลื่นจริงที่ซิมูเลเตอร์วัดได้ \(\approx 20\) mV (สองส่วนไม่พีคพร้อมกัน)

ตัวอย่าง H-2

มีค่าแฝงจริง: ตั้ง D เท่าไรจึงได้ 12 V ที่ 1.2 A

  1. ค่าแฝง: \(R_{on} = 0.05\ \Omega\), \(r_L = 0.1\ \Omega\), \(V_F = 0.4\) V, \(R_d = 0\), ESR \(= 0.05\ \Omega\)

  2. ถ้ายังตั้ง \(D = 0.5\): \(R_s = 0.1 + 0.5(0.05) = 0.125\ \Omega\) → \(V_o = \dfrac{0.5(24) - 0.5(0.4)}{1 + 0.125/10} = \dfrac{11.8}{1.0125} = 11.654\) V (ต่ำกว่าเป้าไป 0.35 V และกระแสโหลดลดเป็น 1.165 A)

  3. ใช้ H9 หา D ที่ถูกต้อง: \(D = \dfrac{12 + 0.4 + 1.2(0.1+0)}{24 + 0.4 - 1.2(0.05 - 0)} = \dfrac{12.52}{24.34} = \mathbf{0.5144}\)

  4. ตรวจด้วยการจำลองสวิตชิ่งที่ \(D = 0.5144\): \(V_o = 12.000\) V, \(I_L = 1.200\) A, \(\Delta i_L = 0.405\) A ✓ (สูตร H5 แบบอุดมคติให้ 0.389 A เพราะไม่รวม \(V_F\) และ DCR ในช่วง OFF · ใช้ความชันช่วง OFF จริง \((V_o + V_F + r_LI_L)/L\) จะได้ \(12.52\times0.4856\times20\mu/300\mu = 0.405\) A)

  5. ความสูญเสียที่ \(D = 0.5144\): \(P_{R_{on}} = R_{on}\,D(I_L^2 + \Delta i_L^2/12) = 0.05(0.5144)(1.4537) = 0.0374\) W · \(P_{diode} = V_F(1-D)I_L = 0.4(0.4856)(1.2) = 0.2331\) W · \(P_{Cu} = r_L(I_L^2 + \Delta i_L^2/12) = 0.1454\) W รวม \(0.416\) W → \(\eta = \dfrac{14.4}{14.4 + 0.416} = 97.2\%\) (ซิมูเลเตอร์ให้ 97.19%; ยังไม่รวมการสูญเสียจากการสวิตช์)

  6. บทเรียน: ไดโอดกินมากที่สุด (56 % ของความสูญเสีย) เพราะ \(V_F\) คงที่คูณกระแส — นี่คือเหตุผลที่แหล่งจ่าย 5 V หรือ 3.3 V ใช้ synchronous (แทน \(V_F = 0.4\) V ด้วย MOSFET \(R_{on}\) ไม่กี่ mΩ)

ตัวอย่าง H-3

แหล่งจ่ายอินพุตเปลี่ยนค่า: 18–30 V → 12 V

  1. ช่วงดิวตี้ (อุดมคติ): \(D = 12/18 = 0.667\) (Vin ต่ำสุด) ถึง \(D = 12/30 = 0.4\) (Vin สูงสุด)

  2. ริปเปิลที่ \(V_g = 18, 24, 30\) V (H5): \(\Delta i_L = 0.267,\ 0.40,\ 0.48\) A ตามลำดับ — ริปเปิลสูงสุดที่ 30 V ใช้ที่นี่ออกแบบ L และกระแสพีก \(I_{L,\max} = 1.2 + 0.24 = 1.44\) A

  3. ตรวจ CCM ที่โหลด 0.2 A: ขอบ \(I_{o,crit} = \Delta i_L/2 = 0.133,\ 0.2,\ 0.24\) A — ที่ 30 V ต้องมีโหลด ≥ 0.24 A จึงยังเป็น CCM ถ้าต้องการ CCM ถึง 0.12 A (10 % ของโหลด) ต้องใช้ \(L \ge \dfrac{12(1-0.4)}{2(50k)(0.12)} = 600\ \mu\)H

  4. ตัวควบคุมต้องเปลี่ยน D เองเมื่อ Vin เปลี่ยน — แบบ open-loop จะได้ \(V_o\) แปรตาม \(V_g\) ตรงๆ (\(V_o = DV_g\)) ซึ่งเป็นเหตุผลของวงป้อนกลับและ ฟังก์ชันถ่ายโอน \(G_{vg}\)

แล็บ: รูปคลื่นบั๊ก CCM/DCM เทียบสูตรกับซิมูเลชันสวิตชิ่ง พื้นฐาน

เลือก ตั้งดิวตี้ D เอง เพื่อดูว่า \(V_o\) เป็นเท่าไร หรือเลือก ให้คำนวณ D จาก Vo เป้าหมาย เพื่อดูว่าสูตรให้ \(D\) เท่าไร แล้วดูว่า \(V_o\) จากการจำลองตรงเป้าหรือไม่ กราฟใช้สีพื้นหลังแยกช่วง ON (ฟ้า) และ OFF (ส้ม) ตารางด้านล่างเทียบสูตรกับการจำลองทีละตัวเลข

ใบงานทดลอง

ใบงาน A1 — ตรวจ \(V_o = DV_g\): เริ่มจาก CCM ตั้ง D = 0.3, 0.5, 0.7 บันทึก \(V_o\) เทียบ \(D\cdot24\) ความต่างเท่ากับ 0 ใช่ไหม ทำไม \(V_o\) ไม่ขึ้นกับ R, L, C

ใบงาน A2 — ริปเปิลกับ L: ลด L เหลือครึ่งหนึ่ง (150 µH) ΔiL ต้องเพิ่มเป็น 2 เท่า (0.8 A) ตรวจ \(I_{L,\min}\) ว่ายังบวกอยู่ไหม แล้วลอง L = 47 µH ที่ fs = 20 kHz

ใบงาน A3 — หาขอบเขต CCM: เริ่มที่ R = 60 Ω (ขอบพอดี \(I_{L,\min}\) ≈ 0) เพิ่ม R ทีละน้อยแล้วดูว่ารูปคลื่น iL เริ่มมีช่วงราบเมื่อใด เปลี่ยนมาเป็น Synchronous แล้วเปรียบเทียบ

ใบงาน A4 — ค่าแฝงกับดิวตี้: โหลดตัวอย่าง "ค่าแฝงจริง" ซึ่งตั้งโหมดคำนวณ D จาก Vo เป้าหมาย 12 V บันทึก D (ต้องได้ 0.5144 ตามตัวอย่าง H-2) แล้วสลับไปโหมดตั้ง D เอง ใส่ D = 0.5 ดูว่า \(V_o\) ตกเท่าไร (11.65 V)

ใบงาน A5 — Vin เปลี่ยน: โหลด Vin = 48 V ในโหมดคำนวณ D (ต้องได้ 0.25) เปรียบเทียบ ΔiL กับกรณี 24 V ที่ L เท่าเดิม ว่าเพิ่มขึ้นกี่เท่า (สูตร H5: \(\propto (1-D)\))

ข้อผิดพลาดที่พบบ่อย

  • ใช้ \(D\) แทน \(D'\) ตอนคิดไดโอด: กระแสไดโอดเฉลี่ยคือ \((1-D)I_o\) ไม่ใช่ \(D I_o\) · กระแสสวิตช์เฉลี่ยคือ \(D I_o\)
  • ออกแบบ L ที่ \(V_{g,nom}\): ริปเปิลสูงสุดและขอบ CCM แย่สุดที่ \(V_{g,\max}\)
  • ลืมว่า H9 ขึ้นกับกระแสโหลด: ตั้ง D คงที่ตามสูตรอุดมคติแล้วแรงดันตกเมื่อโหลดหนัก → ต้องมีวงป้อนกลับ
  • ใช้สูตร CCM กับวงจรที่เข้า DCM: \(V_o\) จริงจะสูงกว่า \(DV_g\) มาก ตรวจ \(K > 1-D\) ก่อนทุกครั้ง
  • บวกริปเปิลแรงดันสองส่วนตรงๆ แล้วถือเป็นค่าจริง: เป็นขอบบน ใช้เป็นเกณฑ์ออกแบบปลอดภัยได้ แต่ค่าวัดจริงต่ำกว่า

สรุปผลและก้าวต่อไป

ปริมาณCCM อุดมคติมีค่าแฝง
ดิวตี้ที่ต้องใช้\(D = V_o/V_g\)\(D = \dfrac{V_o + V_F + I_L(r_L+R_d)}{V_g + V_F - I_L(R_{on}-R_d)}\)
กระแสตัวเหนี่ยวนำเฉลี่ย\(I_L = V_o/R\)เท่ากัน (charge balance)
ริปเปิลกระแส\(\Delta i_L = V_o(1-D)/(Lf_s)\)ใกล้เคียง (ผิดไม่กี่ %)
เงื่อนไข CCM\(2L/(RT_s) > 1-D\)ตรวจ \(I_{L,\min} > 0\)
กระแสอินพุตเฉลี่ย\(I_g = D\,I_L\)\(I_g = D\,I_L\) (รวมความสูญเสียแล้ว \(P_{in} = P_{out} + P_{loss}\))

ต่อไป: โหลดเบาจนกระแสลงถึงศูนย์ → บั๊กโหมด DCM · เมื่อต้องการให้เครื่องตอบสนองต่อการเปลี่ยนค่า → แบบจำลองเฉลี่ย → ฟังก์ชันถ่ายโอน → ออกแบบและทดสอบโหลดหลายสภาวะ
