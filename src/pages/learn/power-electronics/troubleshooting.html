// บทที่ 15.16 · อิเล็กทรอนิกส์กำลัง · Troubleshooting

วิเคราะห์อาการเสียของคอนเวอร์เตอร์และแหล่งจ่ายไฟสวิตชิ่ง: อาการ สาเหตุ วิธีตรวจ

วิธีคิดแบบเป็นระบบ ตาราง 17 อาการ เช่น ไม่มีเอาต์พุต hiccup แกว่ง เสียงหอน MOSFET ระเบิด แกนอิ่มตัว ริปเปิลสูง EMI และวิธีฝึกด้วยซิมูเลเตอร์

เขียนโดย อาจารย์มดอัปเดต
วิธีคิดแบบเป็นระบบ ตารางอาการ → สาเหตุ → วิธีตร ใช้ซิมูเลเตอร์ฝึกวิเคราะห์
สรุปใน 30 วินาที
  • สังเกตก่อนแตะ แยกส่วน วัดเทียบค่าที่คาด หาสาเหตุราก
  • MOSFET ไหม้มักเป็นผล ไม่ใช่เหตุ
  • แกว่งที่ \(f_s/2\) = subharmonic → เพิ่ม slope comp
  • iL หางยกขึ้น = แกนอิ่มตัว

วิธีคิดแบบเป็นระบบ

  1. สังเกตก่อนแตะ — อาการ เสียง กลิ่น รอยไหม้ เกิดเมื่อไร (เปิดเครื่อง/โหลดเปลี่ยน/ร้อน)
  2. แยกส่วน: ไฟเลี้ยงคอนโทรลเลอร์ → สัญญาณเกต → ภาคกำลัง → ลูปป้อนกลับ
  3. วัดเทียบค่าที่คาด (คำนวณจากสูตรในแต่ละบท) — ความต่างคือเบาะแส
  4. หาสาเหตุราก ไม่ใช่แค่เปลี่ยนชิ้นที่ไหม้ (MOSFET ไหม้มักเป็น ผล ไม่ใช่ เหตุ)

ตารางอาการ → สาเหตุ → วิธีตรวจ

อาการ สาเหตุที่เป็นไปได้ ตรวจ/แก้
ไม่มีเอาต์พุตเลย ไม่มีไฟเลี้ยง IC/UVLO, EN ไม่ถูกดึง, ฟิวส์ขาด, soft-start cap ลัด วัด VCC, EN, SS; ดูเกตมีพัลส์หรือไม่
สตาร์ทแล้วดับ วนซ้ำ (hiccup) OCP ทำงาน: โหลดลัด, C ขาออกใหญ่เกิน soft-start, L อิ่มตัว ลดโหลด, เพิ่มเวลา soft-start, ดู iL ช่วงสตาร์ท
Vout ต่ำกว่าค่าตั้ง ตัวแบ่งผิด, ถึง Dmax (Vin ต่ำเกิน), จำกัดกระแส, ความต้านทานแฝงสูง (boost) ดู duty ว่าชน Dmax ไหม; เทียบสูตร \(M\) ที่รวม \(r_L\)
Vout สูงเกิน/ไม่คุม สายป้อนกลับหลุด/ขาดตัวต้านทานล่าง, DCM ที่โหลดเบา (open loop), op-amp อิ่มตัว ตรวจ FB pin; ต้องมี OVP เสมอ (โดยเฉพาะ boost)
แรงดันแกว่งความถี่ต่ำ (Hz–kHz) Phase margin ต่ำ, input filter โต้ตอบ (Middlebrook), สายแหล่งจ่ายยาว วัด Bode, step load ดู overshoot; หน่วง input filter
Jitter/แกว่งที่ \(f_s/2\) (คาบเว้นคาบ) Subharmonic ใน PCMC ที่ D > 0.5 เพิ่ม slope compensation ≥ 0.5 m2 (ลองในซิม)
เสียงหอน/วี้ดได้ยิน ลูปแกว่งในช่วงเสียง, burst/skip mode ที่โหลดเบา, ขดลวด/เซรามิกสั่น (piezo) ดูว่าเปลี่ยนตามโหลดไหม; เคลือบวาร์นิชขด, ใช้ C ต่างชนิด
MOSFET ระเบิดตอนเปิดเครื่อง Shoot-through (dead-time ไม่พอ), เกตลอย, แรงดัน spike เกินพิกัด, V_GS เกิน ตรวจ dead-time, ตัวต้านทาน pull-down เกต 10 kΩ, snubber, TVS
MOSFET ร้อนผิดปกติ V_GS ต่ำ (Rds(on) สูง), สวิตช์ช้า (เกตไดรฟ์อ่อน), ringing, ทำงานเชิงเส้น วัด V_GS จริง, เวลา rise/fall; คำนวณ \(P_{sw}\)
ไดโอดร้อน/ไหม้ Reverse recovery สูง (ใช้ไดโอดธรรมดา), กระแสพีกเกิน ใช้ Schottky/ultrafast/SiC
ตัวเหนี่ยวนำร้อน, iL เป็นรูปหางยกขึ้น แกนอิ่มตัว (กระแสเกิน, แกนผิดชนิด, ช่องอากาศหาย) ดู iL: ความชันเพิ่มใกล้พีก → เพิ่มรอบ/แกนใหญ่/gap
Ripple ขาออกสูงเกินคำนวณ ESR ตัวเก็บประจุสูง (เสื่อม/ร้อน), วัดผิดวิธี (สายกราวด์ยาว), เซรามิกเสียค่าจาก DC bias วัดด้วย ground spring; ตรวจ ESR meter
ตัวเก็บประจุบวม/รั่ว Ripple current เกิน, ร้อน, ใกล้แหล่งความร้อน, กลับขั้ว คำนวณ \(I_{C,rms}\) (โดยเฉพาะ \(C_{in}\) ของ buck)
ประสิทธิภาพตก ไดโอด/MOSFET เสื่อม, DCM, fs สูงเกิน, ขดลวด skin effect แยกการสูญเสียด้วยการวัดอุณหภูมิทีละชิ้น
ทำงานดีตอนเย็น เสียตอนร้อน ค่า L ลดลง (แกน powder/ferrite ใกล้ Curie), Rds(on) เพิ่ม, ESR อิเล็กโตรไลต์เปลี่ยน ทดสอบด้วย heat gun/chamber, derating
รบกวนวิทยุ/เซนเซอร์อื่น (EMI) Hot loop ใหญ่, switch node กว้าง, ไม่มีฟิลเตอร์ขาเข้า ลด loop area, snubber, common-mode choke, spread spectrum
MCU รีเซ็ตเมื่อมีโหลด Ground bounce, ไฟเลี้ยง MCU ตกขณะสวิตช์ แยก LDO/decoupling, star ground

ใช้ซิมูเลเตอร์ฝึกวิเคราะห์

ใน ห้องแลปจำลอง สร้าง "ความเสีย" แล้วดูผล:

  • ลด L ลง 5 เท่า (จำลองแกนแตก) → ΔiL เพิ่ม, เข้า DCM
  • เพิ่ม ESR (C) เป็น 0.5 Ω (ตัวเก็บประจุเสื่อม) → ripple ขาออกเป็นรูปเหลี่ยม
  • เพิ่ม Rds(on) → ประสิทธิภาพตก
  • PCMC slope = 0 กับ boost → subharmonic
  • Boost + เปลี่ยนเป็นโหลด 1 kΩ แบบ open loop → แรงดันพุ่ง (เหตุผลที่ต้องมี OVP)
