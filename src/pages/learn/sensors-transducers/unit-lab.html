เครื่องมือแปลงหน่วย: ตรวจมิติทุกครั้งก่อนให้คำตอบ

แปลงหน่วยแบบพิมพ์นิพจน์ได้ (psi, bar, kgf/cm², °C/°F, rpm, W/(m·K) ฯลฯ) สเกลกระแส 4–20 mA และเครื่องมือเดซิเบล ทำงานในเบราว์เซอร์ทั้งหมด

เขียนโดย อาจารย์มดอัปเดต
แปลงหน่วยเครื่องมืออื่น
// เครื่องมือ 1 · แปลงหน่วยทั่วไป

แปลงหน่วย (พิมพ์นิพจน์หน่วยเองได้)

ลองเลย:
วิธีพิมพ์นิพจน์หน่วย
  • คูณด้วย * หรือ · ; หารด้วย / ; ยกกำลังด้วย ^ หรือ ² ³ ; ใช้วงเล็บเมื่อมีหารหลายตัว เช่น W/(m*K)
  • ใส่คำนำหน้าได้: mbar, kPa, µA (พิมพ์ u แทน µ ได้)
  • อุณหภูมิ: °C, °F, K, °R แปลงแบบจุด ส่วนผลต่างใช้ Δ°C, Δ°F, ΔK ; ในนิพจน์ผสมเช่น W/(m*K) หรือ BTU/(h*ft*degF) เครื่องมือถือเป็นผลต่างอยู่แล้ว
  • เครื่องมือจะ ไม่แปลง เมื่อมิติไม่ตรงกัน เช่น psi→m และจะบอกว่ามิติของทั้งสองข้างคืออะไร
  • Hz ถูกนับเป็น 1 รอบ/วินาที จึงเท่ากับ 2π rad/s ส่วน rpm = 1/60 Hz
// เครื่องมือ 2 · สเกลสัญญาณ 4–20 mA

กระแส ↔ เปอร์เซ็นต์ ↔ ค่าวิศวกรรม

สูตร: I = 4 + 16·(x − LRV)/(URV − LRV) ; "ศูนย์มีชีวิต" (live zero) ทำให้สายขาด (0 mA) แยกจากค่าศูนย์จริง (4 mA) ได้ แนวคิด 20 % ออฟเซ็ตสืบทอดจากสัญญาณลม 3–15 psi (3/15 = 20 %)

// เครื่องมือ 3 · เดซิเบล

แปลง dB, dBm, dBV

กำลัง: dB = 10·log₁₀(P₂/P₁) ; แรงดัน/กระแส: dB = 20·log₁₀(V₂/V₁) ; −3 dB ≈ 0.707 เท่าของแรงดัน (ครึ่งกำลัง) · +6 dB ≈ 2 เท่าของแรงดัน · +20 dB = 10 เท่าของแรงดัน

เครื่องมืออื่นที่เกี่ยวข้อง

  • ตรวจมิติของสมการ: เครื่องมือวิเคราะห์มิติ
  • แปลงตรีโกณและมุม: ตารางตรีโกณมิติ
  • ค่าตัวเลขของค่าคงตัวนิยาม SI: ตาราง SI
ข้อจำกัด: ตัวแปลงทำงานในเบราว์เซอร์ด้วยตารางตัวคูณในหน้านี้ ค่าที่เป็นนิยามแน่นอน (เช่น 1 in = 0.0254 m, 1 lb = 0.453 592 37 kg, 1 kgf = 9.80665 N) ตรงตามนิยาม ส่วนหน่วยที่มีหลายนิยาม (เช่น cal, BTU, ตัน, แกลลอน US/UK) ใช้ค่าตามที่ระบุในรายการ ถ้างานต้องการนิยามอื่น ให้ระบุหน่วยให้ตรง เช่น galUK, tonUK, kcal เครื่องมือนี้เพื่อการเรียนรู้และการประมาณการ ไม่ใช่เอกสารสอบเทียบ
