// บทที่ 26.2 · ลำดับและอนุกรม · Infinite Series

อนุกรมอนันต์ (Infinite Series): ผลบวกย่อย อนุกรมเรขาคณิต กล้องส่องทางไกล ฮาร์มอนิก และอนุกรม p

บวกจำนวนไม่สิ้นสุดแล้วได้ค่าจำกัดได้อย่างไร คำตอบคือมองผ่านลำดับผลบวกย่อย ถ้าผลบวกสะสมเข้าใกล้ค่าหนึ่ง ค่านั้นคือผลบวกของอนุกรม หน้านี้รวมอนุกรมที่หาผลบวกได้จริงทั้งหมด (เรขาคณิต กล้องส่องทางไกล เลขคณิต-เรขาคณิต) อนุกรมมาตรฐานที่ใช้เป็นตัวเทียบ (ฮาร์มอนิก อนุกรม p) และการทดสอบพจน์ที่ n ซึ่งเป็นด่านแรกของทุกโจทย์

เขียนโดย อาจารย์มดอัปเดต
แล็บผลบวกย่อย สูตรซิกมา เรขาคณิตอนันต์ กล้องส่องทางไกล ฮาร์มอนิก · อนุกรม p
สรุปใน 30 วินาที
  • \(\sum a_n = \lim S_n\) · ถ้าลิมิตไม่มีหรือเป็นอนันต์ อนุกรมลู่ออก · \(a_n = S_n - S_{n-1}\)
  • เรขาคณิต: \(\sum_{n=0}^{\infty} ar^n = \dfrac{a}{1-r}\) เมื่อ \(|r| < 1\) · กล้องส่องทางไกล: \(\sum (b_n - b_{n+1}) = b_1 - \lim b_n\)
  • อนุกรม p \(\sum 1/n^p\) ลู่เข้า ⇔ \(p > 1\) · ฮาร์มอนิก (\(p = 1\)) ลู่ออก
  • \(a_n \not\to 0 \Rightarrow\) ลู่ออก แต่ \(a_n \to 0\) ยังสรุปไม่ได้
ระดับพื้นฐาน ม.ปลาย · เตรียมสอบเข้ากลาง แคลคูลัส 2ขั้นสูง ทฤษฎี

อนุกรมคือลิมิตของผลบวกย่อย พื้นฐาน

ให้ลำดับ \(a_1, a_2, a_3, \dots\) ผลบวกย่อย (partial sum) ตัวที่ n คือ \(S_n = a_1 + a_2 + \cdots + a_n\) ซึ่งเป็นลำดับใหม่ อนุกรม \(\sum a_n\) ลู่เข้า เมื่อลำดับ \(S_n\) ลู่เข้า และผลบวกของอนุกรมคือลิมิตนั้น ภาพด้านล่างคือหัวใจของทั้งบท: แท่งคือพจน์ เส้นคือผลบวกสะสม

S1 Sum of a series ผลบวกของอนุกรม

\[ \sum_{n=1}^{\infty} a_n = \lim_{N\to\infty} S_N,\qquad S_N = \sum_{n=1}^{N} a_n \]

เศษเหลือ (remainder) \(R_N = S - S_N = \sum_{n=N+1}^{\infty} a_n\) บอกความคลาดเมื่อหยุดบวกที่ N

S2 Terms from partial sums หาพจน์จากผลบวกย่อย

\[ a_1 = S_1,\qquad a_n = S_n - S_{n-1}\ (n \ge 2) \]

โจทย์ให้สูตร \(S_n\) มา ให้หา \(a_n\) ด้วยวิธีนี้ และผลบวกอนันต์คือ \(\lim S_n\)

ตัวอย่าง S-1 · ผลบวกย่อยให้มา

อนุกรมหนึ่งมี \(S_n = \dfrac{n}{2n+1}\) จงหา \(a_n\) และผลบวกของอนุกรม

  1. \(a_n = \dfrac{n}{2n+1} - \dfrac{n-1}{2n-1} = \dfrac{n(2n-1) - (n-1)(2n+1)}{(2n+1)(2n-1)} = \dfrac{1}{4n^2 - 1}\) (ใช้ได้ทั้ง n = 1 ด้วย เพราะ \(S_1 = \tfrac13\))

  2. ผลบวก \(= \lim \dfrac{n}{2n+1} = \dfrac12\)

\(a_n = \dfrac{1}{4n^2-1}\) และ \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{4n^2-1} = \frac12\)

แล็บผลบวกย่อย พื้นฐาน

เลือกอนุกรมแล้วเลื่อนจำนวนพจน์ N เทียบผลบวกย่อยกับผลบวกจริง และดูสูตรเศษเหลือของแต่ละแบบ ลองเลือกฮาร์มอนิกเพื่อดูผลบวกที่โตไม่หยุดแม้จะช้ามาก

อนุกรมจำกัดและสูตรซิกมา พื้นฐาน

ก่อนไปอนุกรมอนันต์ ต้องคล่องผลบวกจำกัด ซึ่งออกข้อสอบเข้ามหาวิทยาลัยทุกปี สูตรสามตัวของ \(\sum k^p\) และสมบัติเชิงเส้นของซิกมาใช้แก้โจทย์ผลบวกของพหุนามได้ทุกข้อ

S3 Power sums สูตรผลบวกกำลัง

\[ \sum_{k=1}^{n} k = \frac{n(n+1)}{2},\qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6},\qquad \sum_{k=1}^{n} k^3 = \left[\frac{n(n+1)}{2}\right]^2 \]

พิสูจน์ได้ด้วยอุปนัยเชิงคณิตศาสตร์ · \(\sum (c\,a_k + b_k) = c\sum a_k + \sum b_k\) · \(\sum_{k=1}^n c = cn\)

S4 Arithmetic series อนุกรมเลขคณิต

\[ S_n = \frac{n}{2}\left(a_1 + a_n\right) = \frac{n}{2}\left[2a_1 + (n-1)d\right] \]

“จำนวนพจน์ × ค่าเฉลี่ยของพจน์แรกกับพจน์สุดท้าย” แบบเกาส์ · อนุกรมเลขคณิตอนันต์ลู่ออกเสมอ (ยกเว้นทุกพจน์เป็น 0)

S5 Finite geometric series อนุกรมเรขาคณิตจำกัด

\[ S_n = a_1 + a_1 r + \cdots + a_1 r^{n-1} = a_1\frac{1 - r^n}{1 - r}\quad (r \ne 1) \]

ได้จาก \(S_n - rS_n = a_1 - a_1 r^n\) · ถ้า \(r = 1\): \(S_n = n a_1\)

ตัวอย่าง S-2 · ซิกมา (แนวข้อสอบเข้า)

(ก) \(\displaystyle\sum_{k=1}^{20}(2k-1)(k+1)\) (ข) \(1\cdot2 + 2\cdot3 + 3\cdot4 + \cdots + 20\cdot21\)

  1. (ก) กระจาย \((2k-1)(k+1) = 2k^2 + k - 1\) แล้วแยกซิกมา: \(2\sum k^2 + \sum k - \sum 1\)

  2. n = 20: \(\sum k^2 = \dfrac{20\cdot21\cdot41}{6} = 2870\), \(\sum k = 210\), \(\sum 1 = 20\) ⇒ \(5740 + 210 - 20 = 5930\)

  3. (ข) \(\sum_{k=1}^{20} k(k+1) = \sum k^2 + \sum k = 2870 + 210 = 3080\) · ตรวจด้วยสูตรลัด \(\dfrac{n(n+1)(n+2)}{3} = \dfrac{20\cdot21\cdot22}{3} = 3080\)

(ก) 5930 · (ข) 3080

อนุกรมเรขาคณิตอนันต์และทศนิยมซ้ำ พื้นฐาน

อนุกรมเรขาคณิตเป็นอนุกรมอนันต์ตัวแรกที่หาผลบวกได้ และเป็นตัวเทียบสำคัญของการทดสอบทุกแบบ จาก S5 ถ้า \(|r| < 1\) แล้ว \(r^n \to 0\) ผลบวกย่อยจึงเข้าใกล้ \(\dfrac{a}{1-r}\)

S6 Infinite geometric series อนุกรมเรขาคณิตอนันต์

\[ \sum_{n=0}^{\infty} ar^n = a + ar + ar^2 + \cdots = \frac{a}{1-r} \iff |r| < 1;\qquad |r| \ge 1 \Rightarrow \text{ลู่ออก} \]

a = พจน์แรกของอนุกรม (อย่าหลงใช้ 1) · เศษเหลือ \(R_N = \dfrac{ar^N}{1-r}\)

S7 Repeating decimals ทศนิยมซ้ำเป็นเศษส่วน

\[ 0.\overline{d_1 d_2\cdots d_k} = \frac{d_1 d_2 \cdots d_k}{\underbrace{99\cdots9}_{k}} \]

มาจาก \(\tfrac{D}{10^k} + \tfrac{D}{10^{2k}} + \cdots\) · \(0.\overline{9} = \tfrac{9}{9} = 1\) พอดี

ตัวอย่าง S-3 · ทศนิยมซ้ำและเรขาคณิต

(ก) เขียน \(0.2\overline{45}\) เป็นเศษส่วน (ข) \(\displaystyle\sum_{n=1}^{\infty}\frac{3^{n+1}}{5^n}\) (ค) ค่า x ใดที่ \(\sum_{n=0}^{\infty}(x-1)^n\) ลู่เข้า และผลบวกเท่าไร

  1. (ก) \(0.2\overline{45} = \dfrac{2}{10} + \dfrac{45}{1000} + \dfrac{45}{100000} + \cdots = \dfrac15 + \dfrac{45/1000}{1 - 1/100} = \dfrac15 + \dfrac{45}{990} = \dfrac15 + \dfrac{1}{22} = \dfrac{27}{110}\)

  2. (ข) พจน์แรก (n = 1) \(= \dfrac{9}{5}\), \(r = \dfrac35\) ⇒ \(S = \dfrac{9/5}{1 - 3/5} = \dfrac{9/5}{2/5} = \dfrac92\)

  3. (ค) \(r = x - 1\) ต้อง \(|x - 1| < 1 \iff 0 < x < 2\) และ \(S = \dfrac{1}{1 - (x-1)} = \dfrac{1}{2-x}\)

(ก) \(\tfrac{27}{110}\) · (ข) \(\tfrac92\) · (ค) \(0 < x < 2,\ S = \tfrac{1}{2-x}\) — ข้อ (ค) คืออนุกรมกำลังตัวแรกของเรา (ดูอนุกรมกำลัง)

ตัวอย่าง S-4 · แนวข้อสอบเข้า + ฟิสิกส์

(ก) อนุกรมเรขาคณิตอนันต์มีผลบวก 8 และผลบวกของกำลังสองของพจน์เท่ากับ 32 จงหา a และ r (ข) ปล่อยลูกบอลจากความสูง 12 m ทุกครั้งที่กระทบพื้นจะเด้งขึ้น 3/4 ของความสูงก่อนหน้า ระยะทางรวมเท่าไร

  1. (ก) \(\dfrac{a}{1-r} = 8\) และกำลังสองของพจน์เป็นเรขาคณิตอัตราส่วน \(r^2\): \(\dfrac{a^2}{1-r^2} = 32\)

  2. หารสมการที่สองด้วยกำลังสองของสมการแรก: \(\dfrac{a^2/(1-r^2)}{a^2/(1-r)^2} = \dfrac{1-r}{1+r} = \dfrac{32}{64} = \dfrac12 \Rightarrow r = \dfrac13,\ a = 8\cdot\dfrac23 = \dfrac{16}{3}\)

  3. (ข) ความสูงที่เด้งขึ้น 9, 6.75, … รวม \(\dfrac{9}{1 - 3/4} = 36\) m ขาขึ้นและขาลงเท่ากัน ⇒ \(2\times36 = 72\) บวกระยะตกแรก 12 m

(ก) \(a = \tfrac{16}{3},\ r = \tfrac13\) · (ข) 84 m

แนวข้อสอบเข้ามหาวิทยาลัยข้อสอบชอบให้ “ผลบวกอนันต์” และ “ผลบวกของกำลังสอง” หรือ “ผลบวกพจน์คี่” มาพร้อมกัน จำว่ากำลังสองของพจน์ยังเป็นเรขาคณิตด้วยอัตราส่วน \(r^2\) และพจน์ตำแหน่งคี่เป็นเรขาคณิตด้วยอัตราส่วน \(r^2\) เช่นกัน แล้วหารสองสมการเพื่อกำจัด a

อนุกรมกล้องส่องทางไกล (Telescoping Series) กลาง

ชื่อมาจากกล้องโทรทรรศน์แบบพับเก็บได้: เมื่อเขียนพจน์เป็นผลต่างของลำดับเดียวกัน พจน์กลางจะหักล้างกันจนเหลือหัวกับท้าย ทักษะที่ต้องมีคือการแยกเศษส่วนย่อย (partial fractions)

S8 Telescoping series อนุกรมกล้องส่องทางไกล

\[ \sum_{n=1}^{N}(b_n - b_{n+1}) = b_1 - b_{N+1}\ \Rightarrow\ \sum_{n=1}^{\infty}(b_n - b_{n+1}) = b_1 - \lim_{n\to\infty} b_n \]

ถ้า \(b_n\) ไม่มีลิมิตจำกัด อนุกรมลู่ออก เช่น \(\sum\ln\frac{n+1}{n} = \lim\ln(N+1) = \infty\)

S9 Partial fractions for telescoping แยกเศษส่วนย่อย

\[ \frac{1}{n(n+k)} = \frac1k\left(\frac1n - \frac{1}{n+k}\right),\qquad \sum_{n=1}^{\infty}\frac{1}{n(n+k)} = \frac1k\left(1 + \frac12 + \cdots + \frac1k\right) \]

ช่องว่าง k ทำให้เหลือ k พจน์แรก (ไม่ใช่พจน์เดียว) — จุดที่ทำผิดบ่อยที่สุด

ตัวอย่าง S-5 · กล้องส่องทางไกล

(ก) \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n(n+2)}\) (ข) \(\displaystyle\sum_{n=2}^{\infty}\frac{1}{n^2-1}\) (ค) \(\displaystyle\sum_{n=1}^{\infty}\ln\left(1 + \frac1n\right)\)

  1. (ก) \(\dfrac{1}{n(n+2)} = \dfrac12\left(\dfrac1n - \dfrac{1}{n+2}\right)\) เหลือสองพจน์แรกของ \(\tfrac1n\): \(\dfrac12\left(1 + \dfrac12\right) = \dfrac34\)

  2. (ข) \(\dfrac{1}{n^2-1} = \dfrac12\left(\dfrac{1}{n-1} - \dfrac{1}{n+1}\right)\) เริ่ม n = 2 เหลือ \(\dfrac12\left(1 + \dfrac12\right) = \dfrac34\)

  3. (ค) \(\ln\left(1 + \tfrac1n\right) = \ln(n+1) - \ln n\) ⇒ \(S_N = \ln(N+1) \to \infty\) ลู่ออก

(ก) \(\tfrac34\) · (ข) \(\tfrac34\) · (ค) ลู่ออก ทั้งที่พจน์ → 0

อนุกรมฮาร์มอนิกและอนุกรม p กลาง

อนุกรมฮาร์มอนิก \(\sum 1/n\) เป็นตัวอย่างคลาสสิกว่า “พจน์เข้าใกล้ศูนย์ ไม่ได้แปลว่าบวกแล้วจำกัด” การพิสูจน์ของนิโคล โอเรสม์ (ศตวรรษที่ 14) จัดกลุ่มพจน์ให้แต่ละกลุ่มมากกว่า ½ ส่วนอนุกรม p เป็นตัวเทียบมาตรฐานที่สุดในการทดสอบแบบเปรียบเทียบ

S10 Harmonic series diverges อนุกรมฮาร์มอนิกลู่ออก

\[ 1 + \tfrac12 + \underbrace{\tfrac13 + \tfrac14}_{>\frac12} + \underbrace{\tfrac15 + \cdots + \tfrac18}_{>\frac12} + \cdots \ \Rightarrow\ S_{2^k} > 1 + \frac{k}{2} \to \infty \]

ลู่ออกช้ามาก: ต้องใช้ 12,367 พจน์จึงเกิน 10

S11 p-series อนุกรม p

\[ \sum_{n=1}^{\infty}\frac{1}{n^p}\ \text{ลู่เข้า} \iff p > 1 \]

พิสูจน์ด้วยการทดสอบด้วยปริพันธ์ · \(p = 2\): \(\pi^2/6\) (ปัญหาบาเซิล) · \(p = 4\): \(\pi^4/90\)

S12 Growth of harmonic numbers การโตของผลบวกฮาร์มอนิก

\[ H_n = \sum_{k=1}^{n}\frac1k = \ln n + \gamma + \frac{1}{2n} - \cdots,\quad \gamma \approx 0.5772 \]

γ คือค่าคงที่ออยเลอร์-มาสเคโรนี · ใช้ประมาณ \(H_{1000} \approx 7.485\)

ตัวอย่าง S-6 · ฮาร์มอนิก

ต้องบวกอนุกรมฮาร์มอนิกอย่างน้อยกี่พจน์ ผลบวกจึงเกิน 10

  1. ใช้ S12: \(\ln n + 0.5772 > 10 \Rightarrow \ln n > 9.4228 \Rightarrow n > e^{9.4228} \approx 12{,}367\) (ค่าประมาณเท่านั้น ต้องยืนยัน)

  2. คำนวณตรงยืนยัน: \(H_{12366} \approx 9.99996\) และ \(H_{12367} \approx 10.00004\)

12,367 พจน์ — ล้านพจน์ได้แค่ราว 14.39 แต่ก็ยังโตไม่หยุด

สมบัติของอนุกรมและการทดสอบพจน์ที่ n พื้นฐาน

S13 Linearity สมบัติเชิงเส้น

\[ \sum(c\,a_n + b_n) = c\sum a_n + \sum b_n\quad(\text{เมื่อทั้งสองลู่เข้า}) \]

ลู่เข้า + ลู่ออก = ลู่ออกเสมอ · ลู่ออก + ลู่ออก อาจลู่เข้าได้ เช่น \(\sum 1 + \sum(-1)\)

S14 n-th term test การทดสอบพจน์ที่ n

\[ \lim_{n\to\infty} a_n \ne 0 \ \ (\text{หรือไม่มี}) \ \Rightarrow\ \sum a_n \text{ ลู่ออก} \]

เพราะถ้า \(\sum a_n = S\) แล้ว \(a_n = S_n - S_{n-1} \to S - S = 0\) · บทกลับไม่จริง (ฮาร์มอนิก)

S15 Tails decide convergence พจน์ช่วงแรกไม่มีผล

\[ \sum_{n=1}^{\infty} a_n \text{ ลู่เข้า} \iff \sum_{n=m}^{\infty} a_n \text{ ลู่เข้า} \]

ตัดหรือเพิ่มพจน์จำนวนจำกัดไม่เปลี่ยนการลู่เข้า (แต่เปลี่ยนค่าผลบวก) · เลื่อนดัชนีได้ตามสะดวก

กับดักที่พบบ่อยเขียนว่า “\(a_n \to 0\) จึงลู่เข้า” ผิดทุกครั้ง nth-term test ใช้สรุปได้เพียงทางเดียวคือลู่ออก ถ้าพจน์เข้าใกล้ 0 ต้องไปใช้การทดสอบอื่นในหน้าถัดไป

อนุกรมเลขคณิต-เรขาคณิต: วิธี S − rS กลาง

พจน์รูป (เลขคณิต) × (เรขาคณิต) เช่น \(n r^n\) พบในข้อสอบเข้ามหาวิทยาลัยและในค่าคาดหมายของความน่าจะเป็น วิธีมาตรฐานคือคูณด้วย r แล้วลบเพื่อให้เหลืออนุกรมเรขาคณิตธรรมดา

S16 Arithmetico-geometric series อนุกรมเลขคณิต-เรขาคณิต

\[ \sum_{n=1}^{\infty} n r^n = \frac{r}{(1-r)^2},\qquad \sum_{n=1}^{\infty} n^2 r^n = \frac{r(1+r)}{(1-r)^3}\qquad (|r| < 1) \]

วิธี: \(S - rS = r + r^2 + r^3 + \cdots = \dfrac{r}{1-r}\) · หรือหาอนุพันธ์ของ \(\sum r^n\) ในอนุกรมกำลัง

ตัวอย่าง S-7 · S − rS

(ก) \(\displaystyle\sum_{n=1}^{\infty}\frac{n}{3^n}\) (ข) \(1 + \dfrac22 + \dfrac34 + \dfrac48 + \dfrac5{16} + \cdots\)

  1. (ก) \(S = \tfrac13 + \tfrac{2}{9} + \tfrac{3}{27} + \cdots\) · \(\tfrac13 S = \tfrac19 + \tfrac{2}{27} + \cdots\) · ลบ: \(\tfrac23 S = \tfrac13 + \tfrac19 + \tfrac1{27} + \cdots = \dfrac{1/3}{1 - 1/3} = \tfrac12 \Rightarrow S = \tfrac34\)

  2. ตรวจด้วย S16: \(\dfrac{1/3}{(2/3)^2} = \dfrac{1/3}{4/9} = \dfrac34\) ✓

  3. (ข) พจน์ทั่วไป \(\dfrac{n}{2^{n-1}} = 2\cdot\dfrac{n}{2^n}\) ⇒ \(2\cdot\dfrac{1/2}{(1/2)^2} = 2\cdot2 = 4\)

(ก) \(\tfrac34\) · (ข) 4

อนุกรมในโลกจริง: ซีโน เกล็ดหิมะค็อค และเงิน กลาง

ปฏิทรรศน์ของซีโน: เดินครึ่งทาง แล้วครึ่งของที่เหลือ ไปเรื่อย ๆ ระยะทางรวม \(\tfrac12 + \tfrac14 + \cdots = 1\) และเวลารวมก็จำกัด อนุกรมอนันต์จึงไม่ได้แปลว่าใช้เวลาอนันต์ · เกล็ดหิมะค็อค: ทุกขั้นเพิ่มสามเหลี่ยมเล็ก \(3\cdot4^{k-1}\) รูป แต่ละรูปพื้นที่ \(A_0/9^k\) พื้นที่รวม \(A_0\left(1 + \sum_{k\ge1}\tfrac{3\cdot4^{k-1}}{9^k}\right) = \tfrac85 A_0\) จำกัด ขณะที่เส้นรอบรูปคูณด้วย \(\tfrac43\) ทุกขั้นจึงยาวอนันต์ · เงินและพลังงาน: มูลค่าปัจจุบันของรายรับเท่ากันทุกปีเป็นอนุกรมเรขาคณิต ดูตัวอย่างโซลาร์รูฟท็อปในอนุกรมในงานวิศวกรรม

ต่อไป: ทดสอบว่าลู่เข้าหรือไม่ เมื่อหาผลบวกไม่ได้

อนุกรมส่วนใหญ่ เช่น \(\sum \dfrac{1}{n^2+1}\) หรือ \(\sum \dfrac{n!}{n^n}\) หาผลบวกเป็นสูตรไม่ได้ แต่เรายังตัดสินได้ว่าลู่เข้าหรือไม่ด้วยการทดสอบการลู่เข้า เช่น ปริพันธ์ เปรียบเทียบ อัตราส่วน และราก ทบทวนลำดับได้ที่ ลำดับและลิมิตของลำดับ หรืออ่านบทความ สูตรอนุกรมเรขาคณิตแบบเข้าใจง่าย
