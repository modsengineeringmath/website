// บทที่ 26.6 · ลำดับและอนุกรม · Taylor & Maclaurin Series

อนุกรมเทย์เลอร์และแมคลอริน (Taylor & Maclaurin Series): สูตร ตารางอนุกรม เศษเหลือ ทวินาม และการประมาณค่า

เครื่องคิดเลขไม่รู้จัก sin หรือ eˣ มันรู้แค่บวก ลบ คูณ หาร อนุกรมเทย์เลอร์คือสะพานที่เปลี่ยนฟังก์ชันใด ๆ ให้เป็นพหุนาม โดยจับคู่ค่าและอนุพันธ์ทุกอันดับที่จุดหนึ่ง หน้านี้สอนการสร้างอนุกรม ตารางที่ต้องจำ วิธีบอกความแม่นยำด้วยเศษเหลือ เทคนิคลัดที่ไม่ต้องหาอนุพันธ์ และการใช้หาลิมิตกับผลบวก ซึ่งออกข้อสอบทุกระดับ

เขียนโดย อาจารย์มดอัปเดต
แล็บพหุนามเทย์เลอร์ ตารางที่ต้องจำ เศษเหลือ · ใช้กี่พจน์ เทคนิคลัด ลิมิตด้วยอนุกรม
สรุปใน 30 วินาที
  • \(f(x) = \sum\dfrac{f^{(n)}(a)}{n!}(x-a)^n\) · a = 0 เรียกแมคลอริน
  • \(e^x,\ \sin x,\ \cos x\) ลู่เข้าทุก x · \(\tfrac{1}{1-x},\ \ln(1+x),\ \arctan x,\ (1+x)^\alpha\) มีรัศมี 1
  • \(|R_n| \le \dfrac{M|x-a|^{n+1}}{(n+1)!}\) · อนุกรมสลับ: คลาดไม่เกินพจน์ถัดไป
  • หาอนุกรมด้วยการแทนค่า คูณ หาร อินทิกรัล แทนการหาอนุพันธ์ทีละอันดับ
ระดับพื้นฐาน ตาราง · ประมาณค่ากลาง แคลคูลัส 2ขั้นสูง ทฤษฎี · หลายตัวแปร

แนวคิด: พหุนามที่มีอนุพันธ์ตรงกับฟังก์ชัน พื้นฐาน

อยากได้พหุนาม \(P(x)\) ที่ใกล้ \(f(x)\) ที่สุดรอบจุด a วิธีที่เป็นธรรมชาติคือบังคับให้ \(P(a) = f(a)\), \(P'(a) = f'(a)\), \(P''(a) = f''(a)\), … ไปเรื่อย ๆ เมื่อหาอนุพันธ์ \(c_n(x-a)^n\) n ครั้งจะได้ \(n!\,c_n\) จึงต้องเลือก \(c_n = f^{(n)}(a)/n!\) ดีกรีหนึ่งคือเส้นสัมผัส ดีกรีสองเพิ่มความโค้ง และยิ่งดีกรีสูงยิ่งเกาะได้กว้าง

Y1 Taylor series อนุกรมเทย์เลอร์

\[ f(x) = \sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^n = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots \]

เท่ากับ f จริงเมื่อเศษเหลือ \(R_n(x) \to 0\) (f วิเคราะห์) · เป็นอนุกรมกำลังตัวเดียวที่แทน f ได้ (P10)

Y2 Maclaurin series อนุกรมแมคลอริน

\[ f(x) = \sum_{n=0}^{\infty}\frac{f^{(n)}(0)}{n!}x^n \]

กรณี a = 0 ตั้งชื่อตามโคลิน แมคลอริน (ศตวรรษที่ 18)

Y3 Taylor polynomial พหุนามเทย์เลอร์ดีกรี n

\[ P_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k,\qquad P_1 = \text{การประมาณเชิงเส้น} \]

\(P_1(x) = f(a) + f'(a)(x - a)\) คือ linearization ในบทอนุพันธ์

ตัวอย่าง Y-1 · จากนิยาม

หาอนุกรมเทย์เลอร์ของ (ก) \(\ln x\) รอบ \(a = 1\) (ข) \(e^x\) รอบ \(a = 2\)

  1. (ก) \(f = \ln x,\ f' = x^{-1},\ f'' = -x^{-2},\ f''' = 2x^{-3},\ f^{(n)} = (-1)^{n+1}(n-1)!\,x^{-n}\) ⇒ ที่ x = 1: \(f^{(n)}(1) = (-1)^{n+1}(n-1)!\)

  2. \(c_n = \dfrac{(-1)^{n+1}(n-1)!}{n!} = \dfrac{(-1)^{n+1}}{n}\) ⇒ \(\ln x = (x-1) - \dfrac{(x-1)^2}{2} + \dfrac{(x-1)^3}{3} - \cdots\), \(0 < x \le 2\)

  3. (ข) อนุพันธ์ทุกอันดับของ \(e^x\) คือ \(e^x\) ⇒ \(f^{(n)}(2) = e^2\) ⇒ \(e^x = e^2\sum\dfrac{(x-2)^n}{n!}\) ลู่เข้าทุก x

(ก) \(\sum_{n\ge1}\dfrac{(-1)^{n+1}(x-1)^n}{n}\) · (ข) \(e^2\sum\dfrac{(x-2)^n}{n!}\) — ข้อ (ข) ตรวจได้จาก \(e^x = e^2\cdot e^{x-2}\)

ตารางอนุกรมแมคลอรินที่ต้องจำ พื้นฐาน

จำเจ็ดตัวนี้ให้ขึ้นใจ แล้วอนุกรมเกือบทั้งหมดในข้อสอบสร้างได้จากเทคนิคในหัวข้อถัดไป สังเกตรูปแบบ: ฟังก์ชันคู่ (cos) มีแต่กำลังคู่ ฟังก์ชันคี่ (sin, arctan) มีแต่กำลังคี่

Y4 Exponential เอกซ์โพเนนเชียล

\[ e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots,\quad R = \infty \]

ที่ x = 1 ได้ \(e = \sum 1/n!\) · \(e^{-x}\) สลับเครื่องหมาย

Y5 Sine ไซน์

\[ \sin x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots,\quad R = \infty \]

x เป็นเรเดียนเสมอ · \(\sin x \approx x\) เมื่อมุมเล็ก

Y6 Cosine โคไซน์

\[ \cos x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots,\quad R = \infty \]

หาอนุพันธ์ของ Y5 ทีละพจน์ได้ Y6 · \(1 - \cos x \approx x^2/2\)

Y7 Geometric เรขาคณิต

\[ \frac{1}{1-x} = \sum_{n=0}^{\infty}x^n = 1 + x + x^2 + \cdots,\quad |x| < 1 \]

แม่ของอนุกรมตรรกยะทั้งหมด · \(\frac{1}{1+x} = \sum(-1)^n x^n\)

Y8 Logarithm ลอการิทึม

\[ \ln(1+x) = \sum_{n=1}^{\infty}\frac{(-1)^{n+1}x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots,\quad -1 < x \le 1 \]

ไม่มีอนุกรมแมคลอรินของ \(\ln x\) (ไม่นิยามที่ 0) ต้องใช้รอบ a = 1

Y9 Arctangent อาร์กแทนเจนต์

\[ \arctan x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots,\quad |x| \le 1 \]

ที่ x = 1 ได้อนุกรมเกรกอรี-ไลบ์นิซ \(\tfrac{\pi}{4}\)

Y10 Binomial series อนุกรมทวินาม (นิวตัน)

\[ (1+x)^{\alpha} = \sum_{n=0}^{\infty}\binom{\alpha}{n}x^n = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \frac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3 + \cdots,\quad |x| < 1 \]

α จำนวนเต็มบวกได้พหุนาม (สิ้นสุด) · \(\sqrt{1+x} = 1 + \tfrac{x}{2} - \tfrac{x^2}{8} + \tfrac{x^3}{16} - \cdots\) · \(\tfrac{1}{\sqrt{1+x}} = 1 - \tfrac{x}{2} + \tfrac{3x^2}{8} - \cdots\)

Y11 Hyperbolic ไฮเพอร์โบลิก

\[ \sinh x = \sum\frac{x^{2n+1}}{(2n+1)!},\qquad \cosh x = \sum\frac{x^{2n}}{(2n)!} \]

เหมือน sin, cos แต่ไม่สลับเครื่องหมาย · \(R = \infty\)

Y12 tan, arcsin, sec พจน์ต้นที่ควรรู้

\[ \tan x = x + \tfrac{x^3}{3} + \tfrac{2x^5}{15} + \cdots,\ \ \arcsin x = x + \tfrac{x^3}{6} + \tfrac{3x^5}{40} + \cdots,\ \ \sec x = 1 + \tfrac{x^2}{2} + \tfrac{5x^4}{24} + \cdots \]

tan, sec: \(R = \tfrac{\pi}{2}\) · arcsin: \(R = 1\)

แล็บพหุนามเทย์เลอร์ พื้นฐาน

พิมพ์ฟังก์ชันและจุดกระจาย เลื่อนดีกรี n และจุด x ที่ต้องการประเมิน ดูความคลาดจริงเทียบขอบเขตลากรองจ์ และสังเกตว่านอกรัศมีการลู่เข้า (เช่น \(\ln(1+x)\) ที่ x > 1) เพิ่มดีกรีเท่าไรก็ไม่ช่วย

ประมาณค่าด้วยพหุนามเทย์เลอร์ พื้นฐาน

ตัวอย่าง Y-2 · ประมาณรากที่สอง

ใช้พหุนามเทย์เลอร์ดีกรีสองของ \(\sqrt x\) รอบ \(a = 4\) ประมาณ \(\sqrt{4.1}\)

  1. \(f(4) = 2,\ f'(x) = \tfrac{1}{2\sqrt x} \Rightarrow f'(4) = \tfrac14,\ f''(x) = -\tfrac{1}{4x^{3/2}} \Rightarrow f''(4) = -\tfrac{1}{32}\)

  2. \(P_2(x) = 2 + \tfrac14(x-4) - \tfrac{1}{64}(x-4)^2\) (เพราะ \(\tfrac{-1/32}{2!} = -\tfrac1{64}\))

  3. \(P_2(4.1) = 2 + 0.025 - 0.00015625 = 2.02484375\) ค่าจริง 2.02484567 คลาด \(1.9\times10^{-6}\)

\(\sqrt{4.1} \approx 2.024844\) ถูกต้อง 5 ตำแหน่ง ด้วยการคำนวณเลขในใจ

ตัวอย่าง Y-3 · ทวินาม

ประมาณ (ก) \(\sqrt{1.1}\) ด้วย 4 พจน์ (ข) \(\sqrt[3]{1.03}\) ด้วย 3 พจน์

  1. (ก) \(\sqrt{1+x} = 1 + \tfrac{x}{2} - \tfrac{x^2}{8} + \tfrac{x^3}{16}\) ที่ x = 0.1: \(1 + 0.05 - 0.00125 + 0.0000625 = 1.0488125\) (จริง 1.0488088, คลาด \(3.7\times10^{-6}\))

  2. (ข) \((1+x)^{1/3} = 1 + \tfrac{x}{3} - \tfrac{x^2}{9} + \cdots\) ที่ x = 0.03: \(1 + 0.01 - 0.0001 = 1.0099\) (จริง 1.0099016)

(ก) 1.04881 · (ข) 1.0099 — ฟิสิกส์ใช้แบบเดียวกันกับ \(\tfrac{1}{\sqrt{1 - v^2/c^2}} \approx 1 + \tfrac{v^2}{2c^2}\) ได้พลังงานจลน์ \(\tfrac12mv^2\) เป็นพจน์แรก

ทฤษฎีบทเทย์เลอร์และเศษเหลือ: ต้องใช้กี่พจน์ กลาง

การประมาณที่ไม่บอกความคลาดใช้ในงานวิศวกรรมไม่ได้ ทฤษฎีบทเทย์เลอร์บอกว่าความต่างระหว่างฟังก์ชันกับพหุนาม (เศษเหลือ) เขียนได้เป็นพจน์ถัดไปที่ประเมินที่จุดใดจุดหนึ่งระหว่าง a กับ x เราไม่รู้จุดนั้น แต่หาขอบเขตได้

Y13 Taylor's theorem (Lagrange remainder) ทฤษฎีบทเทย์เลอร์ เศษเหลือแบบลากรองจ์

\[ f(x) = P_n(x) + R_n(x),\quad R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1},\ \xi \text{ ระหว่าง } a,\ x \ \Rightarrow\ |R_n(x)| \le \frac{M}{(n+1)!}|x-a|^{n+1} \]

\(M = \max|f^{(n+1)}|\) บนช่วงระหว่าง a กับ x · sin, cos: M = 1 · \(e^x\) (x > 0): \(M = e^x\) ใช้ \(e < 3\) ช่วยประมาณ

Y14 Integral remainder เศษเหลือรูปอินทิกรัล

\[ R_n(x) = \frac{1}{n!}\int_a^x f^{(n+1)}(t)\,(x-t)^n\,dt \]

แม่นตรง ไม่มี ξ · ใช้พิสูจน์ว่าอนุกรมทวินามลู่เข้าสู่ \((1+x)^\alpha\)

Y15 Alternating shortcut ทางลัดอนุกรมสลับ

\[ \text{อนุกรมสลับที่ผ่านไลบ์นิซ:}\ |R| \le |\text{พจน์แรกที่ตัดทิ้ง}| \]

sin, cos, arctan, ln(1+x) ที่ \(0 < x \le 1\) ใช้ได้ (A3)

ตัวอย่าง Y-4 · ใช้กี่พจน์ (ลากรองจ์)

ต้องใช้พหุนามแมคลอรินดีกรีเท่าใด ประมาณ \(e^{0.5}\) ให้คลาดไม่เกิน \(10^{-5}\)

  1. \(|R_n(0.5)| \le \dfrac{e^{0.5}}{(n+1)!}(0.5)^{n+1} < \dfrac{2\,(0.5)^{n+1}}{(n+1)!}\) (ใช้ \(e^{0.5} < 2\))

  2. \(n = 5\): \(\dfrac{2(0.5)^6}{720} = 4.3\times10^{-5}\) ยังไม่พอ · \(n = 6\): \(\dfrac{2(0.5)^7}{5040} = 3.1\times10^{-6}\) ✓

  3. \(P_6(0.5) = 1 + 0.5 + 0.125 + 0.0208333 + 0.0026042 + 0.0002604 + 0.0000217 = 1.6487196\) ค่าจริง 1.6487213 คลาด \(1.7\times10^{-6}\)

ดีกรี 6 (7 พจน์) · ขอบเขตรับประกันโดยไม่ต้องรู้ค่าจริง ซึ่งเป็นสิ่งที่โจทย์ต้องการ

ตัวอย่าง Y-5 · ใช้กี่พจน์ (อนุกรมสลับ)

ประมาณ \(\sin(0.2)\) ด้วย \(x - \tfrac{x^3}{6}\) และหาขอบเขตความคลาด

  1. \(0.2 - \dfrac{0.008}{6} = 0.1986667\)

  2. อนุกรมสลับ พจน์แรกที่ตัดทิ้ง \(\dfrac{0.2^5}{5!} = 2.67\times10^{-6}\) ⇒ \(|R| \le 2.67\times10^{-6}\)

  3. ค่าจริง \(\sin 0.2 = 0.1986693\) คลาดจริง \(2.66\times10^{-6}\) (ขอบเขตแทบจะพอดี)

\(\sin 0.2 \approx 0.19867\) คลาดไม่เกิน \(2.7\times10^{-6}\)

เทคนิคลัด: แทนค่า คูณ หาร อินทิกรัล ประกอบ กลาง

การหาอนุพันธ์ทีละอันดับของ \(e^{-x^2}\) หรือ \(e^x\sin x\) ยุ่งเกินจำเป็น เพราะทฤษฎีบทความเป็นหนึ่งเดียวรับประกันว่าได้อนุกรมด้วยวิธีใดก็คืออนุกรมเทย์เลอร์ตัวเดียวกัน เทคนิคเหล่านี้จึงเป็นทักษะหลักในข้อสอบ

Y16 Substitution แทนค่า

\[ e^{-x^2} = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{n!} = 1 - x^2 + \frac{x^4}{2} - \cdots \]

แทน \(u = -x^2\) ใน Y4 · รัศมีเปลี่ยนตามตัวแปร: \(\tfrac{1}{1-2x}\) มี \(R = \tfrac12\)

Y17 Multiply & divide คูณและหาร

\[ e^x\sin x = x + x^2 + \frac{x^3}{3} - \frac{x^5}{30} + \cdots,\qquad \tan x = \frac{\sin x}{\cos x} = x + \frac{x^3}{3} + \cdots \]

คูณเหมือนพหุนาม เก็บถึงดีกรีที่ต้องการ · หารด้วยการหารยาวหรือเทียบสัมประสิทธิ์

Y18 Integrate term by term อินทิกรัลทีละพจน์

\[ \int_0^1 e^{-x^2}dx = \sum_{n=0}^{\infty}\frac{(-1)^n}{n!\,(2n+1)} = 1 - \frac13 + \frac{1}{10} - \frac{1}{42} + \cdots \]

ใช้กับอินทิกรัลที่ไม่มีปฏิยานุพันธ์พื้นฐาน (ฟังก์ชันค่าคลาดเคลื่อน erf ในสถิติและการแพร่ความร้อน)

Y19 Composition ฟังก์ชันประกอบ

\[ e^{\sin x} = 1 + x + \frac{x^2}{2} - \frac{x^4}{8} - \frac{x^5}{15} + \cdots \]

แทนอนุกรมของ \(\sin x\) ลงใน \(e^u\) แล้วเก็บพจน์ถึงดีกรีที่ต้องการ (พจน์ \(x^3\) หักล้างเป็น 0)

ตัวอย่าง Y-6 · อินทิกรัลที่หาปฏิยานุพันธ์ไม่ได้

ประมาณ \(\displaystyle\int_0^1 e^{-x^2}\,dx\) ด้วย 5 พจน์ และบอกความคลาด

  1. จาก Y18: \(1 - \tfrac13 + \tfrac{1}{10} - \tfrac{1}{42} + \tfrac{1}{216} = 0.747487\)

  2. เป็นอนุกรมสลับ ความคลาด ≤ พจน์ถัดไป \(\dfrac{1}{5!\cdot 11} = \dfrac{1}{1320} = 7.6\times10^{-4}\)

  3. ค่าจริง \(\tfrac{\sqrt\pi}{2}\operatorname{erf}(1) = 0.746824\) คลาด \(6.6\times10^{-4}\) อยู่ในขอบเขต

≈ 0.7475 ± 0.0008 — ใช้ 7 พจน์จะได้ถูกต้องทศนิยม 4 ตำแหน่ง

หาลิมิตด้วยอนุกรมเทย์เลอร์ กลาง

รูป 0/0 ที่ต้องใช้โลปิตาลหลายครั้ง แก้ด้วยอนุกรมได้ในบรรทัดเดียว: แทนฟังก์ชันด้วยอนุกรม ตัดพจน์ที่หักล้างกัน แล้วดูพจน์แรกที่เหลือ วิธีนี้ยังบอก “อัตราการเข้าใกล้” ซึ่งโลปิตาลไม่บอก

ตัวอย่าง Y-7 · ลิมิต (แนวข้อสอบ)

(ก) \(\lim_{x\to0}\dfrac{\sin x - x + x^3/6}{x^5}\) (ข) \(\lim_{x\to0}\dfrac{\tan x - x}{x^3}\) (ค) \(\lim_{x\to0}\dfrac{x - \sin x}{x - \tan x}\)

  1. (ก) \(\sin x - x + \tfrac{x^3}{6} = \tfrac{x^5}{120} - \tfrac{x^7}{5040} + \cdots\) ⇒ ลิมิต \(\tfrac{1}{120}\)

  2. (ข) \(\tan x - x = \tfrac{x^3}{3} + \tfrac{2x^5}{15} + \cdots\) ⇒ ลิมิต \(\tfrac13\)

  3. (ค) ตัวเศษ \(\tfrac{x^3}{6} - \cdots\) ตัวส่วน \(-\tfrac{x^3}{3} - \cdots\) ⇒ \(\dfrac{1/6}{-1/3} = -\tfrac12\)

(ก) \(\tfrac{1}{120}\) · (ข) \(\tfrac13\) · (ค) \(-\tfrac12\) — ข้อ (ก) ถ้าใช้โลปิตาลต้องหาอนุพันธ์ 5 ครั้ง

หาผลบวกอนุกรมจากอนุกรมเทย์เลอร์ กลาง

ย้อนทาง: เห็นอนุกรมตัวเลขแล้วจำได้ว่าเป็นอนุกรมเทย์เลอร์ของฟังก์ชันใดที่จุดใด เช่น \(\sum\tfrac{2^n}{n!} = e^2\), \(\sum\tfrac{(-1)^n\pi^{2n}}{(2n)!} = \cos\pi = -1\)

ตัวอย่าง Y-8 · หาผลบวก

(ก) \(\displaystyle\sum_{n=1}^{\infty}\frac{n^2}{n!}\) (ข) \(\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n}{3^n(2n+1)}\)

  1. (ก) \(\dfrac{n^2}{n!} = \dfrac{n}{(n-1)!}\) ให้ \(m = n - 1\): \(\sum_{m\ge0}\dfrac{m+1}{m!} = \sum\dfrac{m}{m!} + \sum\dfrac{1}{m!} = e + e = 2e\)

  2. (ข) เทียบ \(\arctan x = \sum\dfrac{(-1)^n x^{2n+1}}{2n+1}\): ต้องการ \(x^{2n} = 3^{-n}\) ⇒ \(x = \tfrac{1}{\sqrt3}\) ⇒ อนุกรม \(= \sqrt3\arctan\tfrac{1}{\sqrt3} = \sqrt3\cdot\tfrac{\pi}{6}\)

(ก) \(2e \approx 5.4366\) · (ข) \(\tfrac{\pi\sqrt3}{6} \approx 0.9069\) (นี่คืออนุกรมที่ลู่เข้าเร็วสำหรับคำนวณ π)

สูตรออยเลอร์: จากอนุกรมสู่เฟสเซอร์ กลาง

แทน \(x = j\theta\) ในอนุกรมของ \(e^x\) แล้วแยกพจน์คู่-คี่ จะได้อนุกรมของ cos และ sin พอดี นี่คือรากฐานของการวิเคราะห์วงจรไฟฟ้ากระแสสลับด้วยเฟสเซอร์ และของอนุกรมฟูริเยร์

Y20 Euler's formula สูตรออยเลอร์

\[ e^{j\theta} = \sum\frac{(j\theta)^n}{n!} = \underbrace{\left(1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \cdots\right)}_{\cos\theta} + j\underbrace{\left(\theta - \frac{\theta^3}{3!} + \cdots\right)}_{\sin\theta} \]

\(j^2 = -1,\ j^3 = -j,\ j^4 = 1\) ทำให้เครื่องหมายสลับ · \(e^{j\pi} + 1 = 0\)

ฟังก์ชันวิเคราะห์ และฟังก์ชันที่อนุกรมเทย์เลอร์ใช้ไม่ได้ ขั้นสูง

Y21 Analytic function ฟังก์ชันวิเคราะห์

\[ f \text{ วิเคราะห์ที่ } a \iff f(x) = \sum\frac{f^{(n)}(a)}{n!}(x-a)^n \text{ ในบางช่วงรอบ } a \]

พหุนาม eˣ sin cos ln ราก และผลบวก ผลคูณ ผลหาร ประกอบของพวกนี้ วิเคราะห์ในโดเมนของมัน

Y22 Smooth but not analytic เรียบแต่ไม่วิเคราะห์

\[ f(x) = \begin{cases} e^{-1/x^2} & x \ne 0 \\ 0 & x = 0 \end{cases},\quad f^{(n)}(0) = 0\ \forall n \]

อนุกรมเทย์เลอร์รอบ 0 เป็น 0 ทุกพจน์ ลู่เข้าทุก x แต่ไม่เท่ากับ f — ต้องตรวจ \(R_n \to 0\) เสมอ

Y23 Two-variable Taylor expansion เทย์เลอร์สองตัวแปร

\[ f(a+h, b+k) \approx f + f_x h + f_y k + \tfrac12\left(f_{xx}h^2 + 2f_{xy}hk + f_{yy}k^2\right) \]

ทุกอนุพันธ์ประเมินที่ (a, b) · พจน์อันดับสองคือเมทริกซ์เฮสเซียน ใช้จำแนกจุดวิกฤตในค่าสุดขีดหลายตัวแปร

ต่อไป: เมื่อมีจุดเอกฐานอยู่ตรงกลาง

อนุกรมเทย์เลอร์ใช้ไม่ได้รอบจุดที่ฟังก์ชันระเบิด เช่น \(\tfrac{1}{z}\) หรือ \(e^{1/z}\) รอบ 0 ทางแก้คือยอมให้มีกำลังลบ ได้อนุกรมโลรองต์ ซึ่งเป็นเครื่องมือของเรซิดิว การแปลงลาปลาซผกผัน และการแปลง Z · ดูการใช้อนุกรมเทย์เลอร์ในงานจริงที่ อนุกรมในงานวิศวกรรม · บทความ อนุกรมเทย์เลอร์คืออะไร
