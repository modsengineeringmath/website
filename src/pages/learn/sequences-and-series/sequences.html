// บทที่ 26.1 · ลำดับและอนุกรม · Sequences

ลำดับ (Sequences): เลขคณิต เรขาคณิต เวียนเกิด ลิมิตของลำดับ และทฤษฎีบทการลู่เข้า

ลำดับคือจำนวนที่เรียงเป็นแถวตามกฎ เช่น ยอดเงินฝากทุกสิ้นปี แรงดันของตัวเก็บประจุทุกตัวอย่างสัญญาณ หรือค่าประมาณที่ได้จากวิธีของนิวตันทีละรอบ คำถามสำคัญที่สุดคือ “เมื่อ n ใหญ่มาก ๆ ลำดับเข้าใกล้ค่าใดหรือไม่” หน้านี้ปูพื้นตั้งแต่สูตรลำดับระดับมัธยมปลาย จนถึงนิยาม ε–N และทฤษฎีบทที่ใช้พิสูจน์การลู่เข้า ซึ่งเป็นฐานของอนุกรมทุกชนิดในบทนี้

เขียนโดย อาจารย์มดอัปเดต
แล็บลำดับ เลขคณิต · เรขาคณิต เวียนเกิด ลิมิตของลำดับ ทางเดียวมีขอบเขต
สรุปใน 30 วินาที
  • เลขคณิต \(a_n = a_1 + (n-1)d\) · เรขาคณิต \(a_n = a_1 r^{n-1}\) · ฮาร์มอนิก: ส่วนกลับเป็นเลขคณิต
  • \(a_n \to L\) หมายถึง ทุก \(\varepsilon > 0\) มี \(N\) ที่ \(n > N \Rightarrow |a_n - L| < \varepsilon\)
  • ลำดับโตเร็วเรียงจากช้าไปเร็ว: \(\ln n \ll n^p \ll a^n \ll n! \ll n^n\) · \(\left(1 + \tfrac{x}{n}\right)^n \to e^x\)
  • ทางเดียว + มีขอบเขต ⇒ ลู่เข้า · มีลำดับย่อยสองชุดลู่เข้าคนละค่า ⇒ ลู่ออก
ระดับพื้นฐาน ม.ปลาย · เตรียมสอบเข้ากลาง แคลคูลัส 1-2ขั้นสูง พิสูจน์ · คณิตวิเคราะห์

ลำดับคืออะไร: สูตรพจน์ทั่วไปและแบบเวียนเกิด พื้นฐาน

ลำดับ (sequence) คือฟังก์ชันที่มีโดเมนเป็นจำนวนนับ เขียนค่าที่ตำแหน่ง n ว่า \(a_n\) เรียกว่าพจน์ที่ n (n-th term) ลำดับกำหนดได้สองแบบ: เขียนสูตรตรง ๆ ของ \(a_n\) เป็นฟังก์ชันของ n หรือบอกพจน์แรกแล้วบอกวิธีสร้างพจน์ถัดไปจากพจน์ก่อนหน้า (เวียนเกิด) ทั้งสองแบบพบบ่อยในงานวิศวกรรม: สูตรตรงคำนวณพจน์ไกล ๆ ได้ทันที ส่วนแบบเวียนเกิดคือสิ่งที่คอมพิวเตอร์และตัวกรองดิจิทัลทำจริง

Q1 Sequence ลำดับ

\[ a : \mathbb N \to \mathbb R,\quad n \mapsto a_n \qquad (a_n)_{n=1}^{\infty} = a_1,\ a_2,\ a_3,\ \dots \]

ลำดับจำกัด (finite) มีพจน์สุดท้าย ลำดับอนันต์ (infinite) ไม่มี · ดัชนีเริ่มที่ 0 หรือ 1 ก็ได้ ต้องอ่านโจทย์ให้ดี

Q2 Explicit vs recursive สูตรตรงกับเวียนเกิด

\[ a_n = f(n) \qquad\text{หรือ}\qquad a_1 \text{ กำหนด},\ a_{n+1} = g(a_n) \]

ตัวอย่าง: \(a_n = 2^n\) กับ \(a_1 = 2,\ a_{n+1} = 2a_n\) คือลำดับเดียวกัน

Q3 Bounded & monotone มีขอบเขต · ทางเดียว

\[ |a_n| \le M\ \forall n \qquad a_{n+1} \ge a_n\ (\text{เพิ่ม}) \quad a_{n+1} \le a_n\ (\text{ลด}) \]

ตรวจความเป็นทางเดียวด้วย \(a_{n+1} - a_n\), \(a_{n+1}/a_n\) (พจน์บวก) หรือ \(f'(x)\) ของ \(f(n) = a_n\)

ตัวอย่าง Q-1 · หาสูตรพจน์ทั่วไป

เขียนสูตร \(a_n\) ของ (ก) \(\tfrac12, \tfrac23, \tfrac34, \dots\) (ข) \(1, -\tfrac14, \tfrac19, -\tfrac1{16}, \dots\) (ค) \(2, 6, 12, 20, 30, \dots\)

  1. (ก) ตัวเศษเป็น 1, 2, 3, … และตัวส่วนมากกว่าตัวเศษ 1 ⇒ \(a_n = \dfrac{n}{n+1}\)

  2. (ข) ตัวส่วนเป็นกำลังสอง \(n^2\) เครื่องหมายสลับเริ่มบวก ⇒ \(a_n = \dfrac{(-1)^{n+1}}{n^2}\)

  3. (ค) ผลต่าง 4, 6, 8, 10 เพิ่มทีละ 2 (ผลต่างอันดับสองคงที่ ⇒ พหุนามดีกรีสอง) ลองแยก \(2 = 1\cdot2,\ 6 = 2\cdot3,\ 12 = 3\cdot4\) ⇒ \(a_n = n(n+1)\)

(ก) \(\dfrac{n}{n+1}\) · (ข) \(\dfrac{(-1)^{n+1}}{n^2}\) · (ค) \(n(n+1)\) — ตรวจโดยแทน n = 1, 2, 3 ทุกครั้ง

ลำดับเลขคณิต เรขาคณิต และฮาร์มอนิก พื้นฐาน

สองลำดับนี้คือแกนของข้อสอบเข้ามหาวิทยาลัยเรื่องลำดับ ลำดับเลขคณิต (arithmetic) เพิ่มด้วย “การบวกค่าคงที่” เหมือนเงินเดือนที่ขึ้นปีละเท่ากัน ลำดับเรขาคณิต (geometric) เพิ่มด้วย “การคูณค่าคงที่” เหมือนดอกเบี้ยทบต้นหรือแรงดันที่ลดลงในแต่ละช่วงเวลาคงที่ของวงจร RC

Q4 Arithmetic sequence ลำดับเลขคณิต

\[ a_n = a_1 + (n-1)d,\qquad d = a_{n+1} - a_n,\qquad a_n = a_m + (n-m)d \]

\(a, b, c\) เป็นเลขคณิต ⇔ \(2b = a + c\) (b คือค่าเฉลี่ยเลขคณิต)

Q5 Geometric sequence ลำดับเรขาคณิต

\[ a_n = a_1 r^{n-1},\qquad r = \frac{a_{n+1}}{a_n},\qquad a_n = a_m r^{n-m} \]

\(a, b, c\) (บวก) เป็นเรขาคณิต ⇔ \(b^2 = ac\) · \(r^n \to 0\) เมื่อ \(|r| < 1\)

Q6 Harmonic sequence ลำดับฮาร์มอนิก

\[ \frac{1}{a_1}, \frac{1}{a_2}, \frac{1}{a_3}, \dots \text{ เป็นเลขคณิต} \quad\Rightarrow\quad a_n = \frac{1}{\frac{1}{a_1} + (n-1)d} \]

เช่น \(1, \tfrac12, \tfrac13, \dots\) · \(b\) เป็นค่าเฉลี่ยฮาร์มอนิกของ \(a, c\) ⇔ \(b = \dfrac{2ac}{a+c}\)

Q7 AM ≥ GM ≥ HM อสมการค่าเฉลี่ย

\[ \frac{a+b}{2} \ \ge\ \sqrt{ab} \ \ge\ \frac{2ab}{a+b}\qquad (a, b > 0) \]

เท่ากันเมื่อ \(a = b\) · ใช้ในโจทย์ค่าสูงสุด-ต่ำสุดระดับ ม.ปลาย บ่อยมาก

ตัวอย่าง Q-2 · เลขคณิต

ลำดับเลขคณิตมี \(a_4 = 11\) และ \(a_{10} = 29\) จงหา \(a_1,\ d\) และ \(a_{20}\)

  1. ใช้ \(a_{10} = a_4 + 6d\): \(29 = 11 + 6d \Rightarrow d = 3\)

  2. \(a_4 = a_1 + 3d \Rightarrow 11 = a_1 + 9 \Rightarrow a_1 = 2\)

  3. \(a_{20} = a_1 + 19d = 2 + 57 = 59\)

\(a_1 = 2,\ d = 3,\ a_{20} = 59\) (เทคนิค: ไม่ต้องแก้ระบบสมการ ใช้ \(a_n = a_m + (n - m)d\) ตรง ๆ)

ตัวอย่าง Q-3 · เรขาคณิต (แนวข้อสอบเข้า)

สามจำนวนเรียงเป็นลำดับเรขาคณิต ผลบวกเท่ากับ 26 และผลคูณเท่ากับ 216 จงหาสามจำนวนนั้น

  1. เขียนสามจำนวนเป็น \(\dfrac{b}{r},\ b,\ br\) (สมมาตรรอบพจน์กลาง) ผลคูณ \(= b^3 = 216 \Rightarrow b = 6\)

  2. ผลบวก: \(\dfrac6r + 6 + 6r = 26 \Rightarrow 6r^2 - 20r + 6 = 0 \Rightarrow 3r^2 - 10r + 3 = 0\)

  3. \((3r - 1)(r - 3) = 0 \Rightarrow r = 3\) หรือ \(r = \tfrac13\)

สามจำนวนคือ 2, 6, 18 (หรือเรียงกลับ 18, 6, 2) — ตรวจ: 2 + 6 + 18 = 26 และ 2 · 6 · 18 = 216

แนวข้อสอบเข้ามหาวิทยาลัยโจทย์ “สามจำนวนเป็นลำดับเลขคณิต/เรขาคณิต” ให้เขียนเป็น \(a - d,\ a,\ a + d\) หรือ \(\tfrac{b}{r},\ b,\ br\) เสมอ ผลบวกหรือผลคูณจะตัดตัวแปรไปหนึ่งตัวทันที ประหยัดเวลาได้มาก

แล็บลำดับ: พจน์ ลิมิต แถบ ε และใยแมงมุม พื้นฐาน

พิมพ์สูตรพจน์ทั่วไป หรือสลับเป็นความสัมพันธ์เวียนเกิด แล้วเลื่อนค่า ε ดูว่า N ต้องใหญ่แค่ไหนจึงทำให้ทุกพจน์หลังจากนั้นอยู่ในแถบรอบลิมิต มุมมองใยแมงมุมแสดงลำดับเวียนเกิดเป็นบันไดระหว่างกราฟ \(y = g(x)\) กับเส้น \(y = x\)

ความสัมพันธ์เวียนเกิดและสมการลักษณะเฉพาะ กลาง

ความสัมพันธ์เวียนเกิดเชิงเส้น (linear recurrence) เป็น “สมการเชิงอนุพันธ์ของโลกดิจิทัล” วิธีแก้มีโครงเดียวกับสมการเชิงอนุพันธ์: หาคำตอบเฉพาะ (จุดตรึง) แล้วบวกคำตอบเอกพันธ์ที่เป็นเลขยกกำลัง ทักษะนี้ใช้ต่อในตัวกรองดิจิทัล การแปลง Z และระบบควบคุมแบบดิจิทัล

Q8 First-order linear recurrence เวียนเกิดเชิงเส้นอันดับหนึ่ง

\[ a_{n+1} = r a_n + c\ (r \ne 1)\ \Rightarrow\ a_n = L + (a_1 - L)\,r^{n-1},\quad L = \frac{c}{1-r} \]

\(L\) คือจุดตรึง (\(L = rL + c\)) · ลู่เข้าสู่ \(L\) ⇔ \(|r| < 1\) (หรือ \(a_1 = L\))

Q9 Second-order: characteristic equation สมการลักษณะเฉพาะ

\[ a_{n+2} = p\,a_{n+1} + q\,a_n:\quad t^2 = pt + q\ \Rightarrow\ a_n = \begin{cases} A t_1^{\,n} + B t_2^{\,n} & t_1 \ne t_2 \\ (A + Bn)\,t^{\,n} & \text{รากซ้ำ} \end{cases} \]

รากเชิงซ้อน \(\rho e^{\pm j\theta}\) ให้ \(\rho^n(A\cos n\theta + B\sin n\theta)\) — ลำดับแกว่ง ลู่เข้า 0 เมื่อ \(\rho < 1\)

Q10 Fibonacci & Binet's formula ฟีโบนัชชีและสูตรบิเนต์

\[ F_{n+2} = F_{n+1} + F_n,\ F_0 = 0,\ F_1 = 1 \ \Rightarrow\ F_n = \frac{\varphi^n - \psi^n}{\sqrt5},\quad \varphi, \psi = \frac{1 \pm \sqrt5}{2} \]

\(F_{n+1}/F_n \to \varphi \approx 1.618\) ซึ่งเป็นค่าเดียวกับความต้านทานของบันไดตัวต้านทานอนันต์ (หน่วย R)

ตัวอย่าง Q-4 · อันดับหนึ่ง

\(a_1 = 1,\ a_{n+1} = 3a_n + 2\) จงหาสูตรพจน์ทั่วไป และบอกว่าลู่เข้าหรือไม่

  1. จุดตรึง: \(L = 3L + 2 \Rightarrow L = -1\)

  2. ตั้ง \(b_n = a_n - L = a_n + 1\) จะได้ \(b_{n+1} = 3b_n\) เป็นเรขาคณิต \(b_1 = 2\) ⇒ \(b_n = 2\cdot 3^{n-1}\)

  3. \(a_n = -1 + 2\cdot 3^{n-1}\) · ตรวจ: \(a_2 = 5,\ a_3 = 17,\ a_4 = 53\) ตรงกับการคำนวณทีละขั้น

  4. \(|r| = 3 > 1\) ⇒ \(a_n \to \infty\) ลู่ออก (จุดตรึง −1 เป็นจุดตรึงไม่เสถียร)

\(a_n = 2\cdot 3^{n-1} - 1\) ลู่ออก

ตัวอย่าง Q-5 · อันดับสอง

\(a_0 = 2,\ a_1 = 5,\ a_{n+2} = 5a_{n+1} - 6a_n\) จงหา \(a_n\)

  1. สมการลักษณะเฉพาะ \(t^2 = 5t - 6 \Rightarrow t^2 - 5t + 6 = 0 \Rightarrow t = 2, 3\)

  2. \(a_n = A\,2^n + B\,3^n\) · \(n = 0: A + B = 2\) · \(n = 1: 2A + 3B = 5\) ⇒ \(B = 1,\ A = 1\)

  3. ตรวจ \(a_2 = 5\cdot5 - 6\cdot2 = 13 = 4 + 9\) ✓

\(a_n = 2^n + 3^n\)

ในงานไฟฟ้า สมการ \(y[n] = 0.8\,y[n-1] + 0.2\,x[n]\) ของตัวกรองดิจิทัลอันดับหนึ่งคือ Q8 พอดี โดยมี \(r = 0.8\) ค่าตอบสนองต่อขั้นบันไดจึงเข้าสู่ 1 แบบเรขาคณิต ดูการคำนวณเต็มในอนุกรมในงานวิศวกรรม

ลิมิตของลำดับ: ลู่เข้าและลู่ออก กลาง

ลำดับลู่เข้า (converges) สู่ \(L\) ถ้าพจน์เข้าใกล้ \(L\) และ “อยู่ใกล้ตลอดไป” นิยามแบบ ε–N ทำให้คำว่าใกล้ชัดเจน: ไม่ว่าจะขอความแม่นยำ ε เล็กเพียงใด ต้องมีตำแหน่ง N ที่ทุกพจน์หลังจากนั้นห่างจาก \(L\) ไม่ถึง ε ถ้าไม่มี \(L\) แบบนี้ ลำดับลู่ออก (diverges) ซึ่งอาจโตไม่มีขอบเขตหรือแกว่ง

Q11 Limit of a sequence (ε–N) ลิมิตของลำดับ

\[ \lim_{n\to\infty} a_n = L \iff \forall \varepsilon > 0\ \exists N:\ n > N \Rightarrow |a_n - L| < \varepsilon \]

\(a_n \to \infty\) หมายถึง ทุก \(M\) มี \(N\) ที่ \(n > N \Rightarrow a_n > M\) (ลู่ออกสู่อนันต์) · ลิมิตถ้ามีจะมีค่าเดียว

Q12 Limit laws สมบัติของลิมิต

\[ \lim(a_n \pm b_n) = A \pm B,\quad \lim a_n b_n = AB,\quad \lim \frac{a_n}{b_n} = \frac{A}{B}\ (B \ne 0) \]

ใช้ได้เมื่อ \(a_n \to A\) และ \(b_n \to B\) เป็นจำนวนจริงทั้งคู่ · \(\infty - \infty\), \(0\cdot\infty\), \(\infty/\infty\) ต้องจัดรูปก่อน

Q13 Through a function ผ่านฟังก์ชัน f(x)

\[ \lim_{x\to\infty} f(x) = L,\ a_n = f(n)\ \Rightarrow\ \lim_{n\to\infty} a_n = L;\quad g \text{ ต่อเนื่อง} \Rightarrow g(a_n) \to g(L) \]

จึงใช้กฎของโลปิตาลกับ \(f(x)\) ได้ (ห้ามหาอนุพันธ์เทียบ n ตรง ๆ) · บทกลับไม่จริง: \(\sin(\pi n) \to 0\) แต่ \(\sin \pi x\) ไม่มีลิมิต

Q14 Standard limits ลิมิตมาตรฐานที่ต้องจำ

\[ r^n \to 0\ (|r|<1),\quad \sqrt[n]{n} \to 1,\quad \sqrt[n]{a} \to 1\ (a>0),\quad \left(1 + \frac{x}{n}\right)^n \to e^x,\quad \frac{n^k}{a^n} \to 0\ (a>1),\quad \frac{a^n}{n!} \to 0,\quad \frac{n!}{n^n} \to 0 \]

ลำดับความเร็วการโต: \(\ln n \ll n^{p} \ll a^{n} \ll n! \ll n^{n}\) (\(p > 0,\ a > 1\)) ตัวที่โตเร็วกว่าชนะเสมอเมื่อ n ใหญ่พอ

ตัวอย่าง Q-6 · หาลิมิต

(ก) \(\lim \dfrac{2n^2 - 3n}{5n^2 + 1}\) (ข) \(\lim\left(\sqrt{n^2 + n} - n\right)\) (ค) \(\lim\left(1 - \dfrac3n\right)^{2n}\)

  1. (ก) หารด้วยกำลังสูงสุด \(n^2\): \(\dfrac{2 - 3/n}{5 + 1/n^2} \to \dfrac25\)

  2. (ข) รูป \(\infty - \infty\) คูณด้วยคอนจูเกต: \(\dfrac{(n^2 + n) - n^2}{\sqrt{n^2+n} + n} = \dfrac{n}{\sqrt{n^2+n} + n} = \dfrac{1}{\sqrt{1 + 1/n} + 1} \to \dfrac12\)

  3. (ค) \(\left(1 - \dfrac3n\right)^{2n} = \left[\left(1 + \dfrac{-3}{n}\right)^{n}\right]^2 \to (e^{-3})^2 = e^{-6}\) ใช้ Q14 กับ \(x = -3\)

(ก) \(\tfrac25\) · (ข) \(\tfrac12\) · (ค) \(e^{-6} \approx 0.00248\)

ตัวอย่าง Q-7 · พิสูจน์ด้วย ε–N

พิสูจน์ว่า \(\lim \dfrac{3n+1}{n+2} = 3\) และหา N เมื่อ \(\varepsilon = 0.01\)

  1. คำนวณระยะห่าง: \(\left|\dfrac{3n+1}{n+2} - 3\right| = \left|\dfrac{3n + 1 - 3n - 6}{n+2}\right| = \dfrac{5}{n+2}\)

  2. ต้องการ \(\dfrac{5}{n+2} < \varepsilon \iff n > \dfrac5\varepsilon - 2\) จึงเลือก \(N = \left\lceil \dfrac5\varepsilon - 2 \right\rceil\) แล้วทุก \(n > N\) ใช้ได้

  3. \(\varepsilon = 0.01\): \(n > 500 - 2 = 498\) ⇒ \(N = 498\) (พจน์ที่ 499 เป็นต้นไปอยู่ในแถบ)

ทุก ε มี N จึงลู่เข้าสู่ 3 ตามนิยาม · ε = 0.01 ใช้ N = 498

กับดักที่พบบ่อย\(\left(1 + \tfrac1n\right)^n\) ไม่ได้เข้าใกล้ \(1^\infty = 1\) แต่เข้าใกล้ \(e \approx 2.718\) — รูป \(1^\infty\) เป็นรูปไม่กำหนด ต้องใช้ Q14 หรือเขียนเป็น \(e^{n\ln(1 + 1/n)}\) แล้วหาลิมิตของเลขชี้กำลัง

ทฤษฎีบทแซนด์วิชและลำดับสลับเครื่องหมาย กลาง

Q15 Squeeze theorem ทฤษฎีบทแซนด์วิช

\[ b_n \le a_n \le c_n\ (n \ge n_0),\ \ b_n, c_n \to L\ \Rightarrow\ a_n \to L \]

ใช้กับพจน์ที่มี \(\sin, \cos, (-1)^n\) หรือแฟกทอเรียลที่ประมาณยาก

Q16 |aₙ| → 0 ⇒ aₙ → 0 ค่าสัมบูรณ์เข้าใกล้ศูนย์

\[ |a_n| \to 0 \iff a_n \to 0 \qquad (\text{เฉพาะลิมิต } 0) \]

\((-1)^n/n \to 0\) แต่ \((-1)^n\) ลู่ออก · \(|a_n| \to L \ne 0\) ไม่ได้บอกว่า \(a_n\) ลู่เข้า

ตัวอย่าง Q-8 · แซนด์วิช

หา (ก) \(\lim \dfrac{\sin n}{n}\) (ข) \(\lim \dfrac{n!}{n^n}\)

  1. (ก) \(-\dfrac1n \le \dfrac{\sin n}{n} \le \dfrac1n\) และทั้งสองข้าง → 0 ⇒ ลิมิตเป็น 0

  2. (ข) \(\dfrac{n!}{n^n} = \dfrac{1}{n}\cdot\dfrac{2}{n}\cdots\dfrac{n}{n} \le \dfrac1n\) (ทุกตัวประกอบหลังตัวแรก ≤ 1) และ \(\dfrac{n!}{n^n} > 0\) ⇒ ประกบระหว่าง 0 กับ \(\tfrac1n\) ⇒ ลิมิต 0

ทั้งสองลิมิตเท่ากับ 0

ลำดับทางเดียวมีขอบเขต (Monotone Convergence Theorem) กลาง

ทฤษฎีบทนี้ตอบปัญหาของลำดับเวียนเกิด: เรามักหาสูตรตรงไม่ได้ แต่ถ้าพิสูจน์ได้ว่าลำดับ “ขึ้นอย่างเดียวและมีเพดาน” ลำดับต้องลู่เข้า จากนั้นจึงแทน \(L = g(L)\) หาค่าลิมิตได้อย่างถูกต้อง

Q17 Monotone convergence theorem ทางเดียว + มีขอบเขต ⇒ ลู่เข้า

\[ a_n \uparrow,\ a_n \le M \Rightarrow a_n \to \sup a_n \le M;\qquad a_n \downarrow,\ a_n \ge m \Rightarrow a_n \to \inf a_n \]

พิสูจน์ความมีขอบเขตและทางเดียวของลำดับเวียนเกิดมักใช้อุปนัยเชิงคณิตศาสตร์

Q18 Fixed-point iteration การวนหาจุดตรึง

\[ a_{n+1} = g(a_n),\ g(L) = L,\ |g'(L)| < 1 \Rightarrow a_n \to L \text{ (เมื่อเริ่มใกล้ } L) \]

\(|g'(L)| > 1\) จุดตรึงไม่เสถียร · วิธีของนิวตันคือ \(g(x) = x - f(x)/f'(x)\) ซึ่งมี \(g'(L) = 0\) จึงลู่เข้าเร็วมาก

ตัวอย่าง Q-9 · ลำดับเวียนเกิด

\(a_1 = 1,\ a_{n+1} = \sqrt{6 + a_n}\) ลู่เข้าหรือไม่ ถ้าลู่เข้า ลิมิตเท่าไร

  1. มีขอบเขตบน 3 (อุปนัย): \(a_1 = 1 < 3\) · ถ้า \(a_k < 3\) แล้ว \(a_{k+1} = \sqrt{6 + a_k} < \sqrt{9} = 3\)

  2. เพิ่มขึ้น: \(a_{k+1}^2 - a_k^2 = 6 + a_k - a_k^2 = (3 - a_k)(2 + a_k) > 0\) เมื่อ \(0 < a_k < 3\) ⇒ \(a_{k+1} > a_k\)

  3. Q17 ⇒ ลู่เข้าสู่ L บางค่า ผ่านลิมิตในสมการ: \(L = \sqrt{6 + L} \Rightarrow L^2 - L - 6 = 0 \Rightarrow L = 3\) (ตัด −2 เพราะพจน์เป็นบวก)

ลู่เข้าสู่ 3 · ตรวจ \(g'(3) = \tfrac{1}{2\sqrt9} = \tfrac16\) น้อยกว่า 1 สอดคล้องกับ Q18

กับดักที่พบบ่อยห้ามแทน \(L = g(L)\) ก่อนพิสูจน์ว่าลู่เข้า ตัวอย่าง \(a_1 = 1,\ a_{n+1} = 2a_n\): แทนได้ \(L = 0\) แต่ลำดับจริงคือ \(1, 2, 4, 8, \dots \to \infty\)

ลำดับย่อย ลำดับโคชี และโบลซาโน-ไวแยร์สตราส ขั้นสูง

หัวข้อนี้คือเครื่องมือของคณิตวิเคราะห์ (real analysis) ที่ทำให้การพิสูจน์การลู่เข้าทำได้โดยไม่ต้องรู้ค่าลิมิตล่วงหน้า ลำดับโคชีคือรากฐานของการทดสอบอนุกรมหลายแบบในหน้าถัดไป

Q19 Subsequences ลำดับย่อย

\[ a_n \to L \Rightarrow a_{n_k} \to L \text{ ทุกลำดับย่อย};\quad a_{2n} \to L_1 \ne L_2 \leftarrow a_{2n+1} \Rightarrow \text{ลู่ออก} \]

ถ้าลำดับย่อยคู่และคี่ลู่เข้าสู่ค่าเดียวกัน ลำดับเดิมลู่เข้า (ใช้พิสูจน์การทดสอบอนุกรมสลับ)

Q20 Bolzano–Weierstrass ทฤษฎีบทโบลซาโน-ไวแยร์สตราส

\[ (a_n) \text{ มีขอบเขต} \Rightarrow \text{มีลำดับย่อยที่ลู่เข้า} \]

เช่น \(\sin n\) มีขอบเขต จึงมีลำดับย่อยลู่เข้า (จริง ๆ มีลำดับย่อยลู่เข้าสู่ทุกค่าใน [−1, 1])

Q21 Cauchy sequence ลำดับโคชี

\[ \forall\varepsilon>0\ \exists N:\ m, n > N \Rightarrow |a_m - a_n| < \varepsilon \iff (a_n) \text{ ลู่เข้าใน } \mathbb R \]

พจน์เข้าใกล้กันเองโดยไม่ต้องรู้ลิมิต · ใช้พิสูจน์ว่าอนุกรมลู่เข้าแบบสัมบูรณ์แล้วลู่เข้า

Q22 Stolz–Cesàro โลปิตาลฉบับลำดับ

\[ b_n \uparrow \infty,\ \lim \frac{a_{n+1} - a_n}{b_{n+1} - b_n} = L \ \Rightarrow\ \lim \frac{a_n}{b_n} = L \]

เช่น \(\dfrac{1^2 + 2^2 + \cdots + n^2}{n^3} \to \lim \dfrac{(n+1)^2}{(n+1)^3 - n^3} = \dfrac13\)

ตัวอย่าง Q-10 · ลำดับย่อย

แสดงว่า \(a_n = (-1)^n\dfrac{n}{n+1}\) ลู่ออก

  1. ลำดับย่อยคู่: \(a_{2k} = \dfrac{2k}{2k+1} \to 1\)

  2. ลำดับย่อยคี่: \(a_{2k+1} = -\dfrac{2k+1}{2k+2} \to -1\)

  3. ลิมิตของลำดับย่อยไม่เท่ากัน ⇒ ตาม Q19 ลำดับเดิมลู่ออก ทั้งที่ \(|a_n| \to 1\)

ลู่ออก (แกว่งระหว่างใกล้ 1 กับใกล้ −1)

เช็กลิสต์หาลิมิตของลำดับ พื้นฐาน

1. เศษส่วนของพหุนาม/รากหารด้วยกำลังสูงสุดของตัวส่วน · รูป \(\infty - \infty\) ที่มีรากใช้คอนจูเกต
2. รูป \(1^\infty\)ใช้ \(\left(1 + \tfrac{x}{n}\right)^n \to e^x\) หรือ \(e^{\lim n\ln(\cdot)}\)
3. ยกกำลัง แฟกทอเรียล ลอการิทึมเทียบลำดับชั้นการโต Q14 หรือใช้โลปิตาลกับ f(x)
4. มี sin, cos, (−1)ⁿประกบด้วยแซนด์วิช Q15 หรือดูลำดับย่อย Q19
5. ลำดับเวียนเกิดพิสูจน์ทางเดียว + มีขอบเขต (Q17) ก่อน แล้วจึงแก้ \(L = g(L)\)
6. ตรวจด้วยแล็บดูค่าพจน์ที่ n ใหญ่เพื่อยืนยันคำตอบ ไม่ใช่แทนการพิสูจน์

ต่อไป: จากลำดับสู่อนุกรม

เมื่อเข้าใจลิมิตของลำดับแล้ว อนุกรมก็คือลิมิตของลำดับผลบวกย่อย \(S_n = a_1 + \cdots + a_n\) หน้าถัดไป อนุกรมอนันต์ เริ่มจากอนุกรมเรขาคณิต กล้องส่องทางไกล และอนุกรม p ถ้าต้องการทบทวนลิมิตของฟังก์ชันก่อน ดู ลิมิตและความต่อเนื่อง และสรุปทั้งบทแบบหน้าเดียวที่ ลำดับและอนุกรมฉบับสรุป · ฝึกโจทย์ที่ แนวข้อสอบชุด A
