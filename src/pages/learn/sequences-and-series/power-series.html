// บทที่ 26.5 · ลำดับและอนุกรม · Power Series

อนุกรมกำลัง (Power Series): รัศมีและช่วงการลู่เข้า อนุพันธ์-อินทิกรัลทีละพจน์ และการแทนฟังก์ชัน

อนุกรมกำลังคือ “พหุนามที่ยาวไม่สิ้นสุด” \(c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots\) ต่างจากอนุกรมตัวเลขตรงที่การลู่เข้าขึ้นกับ x คำตอบมีรูปแบบสวยงามเสมอ: ลู่เข้าในช่วงที่สมมาตรรอบ a รัศมี R และลู่ออกนอกช่วง ในช่วงนั้นอนุกรมประพฤติเหมือนพหุนาม หาอนุพันธ์และอินทิกรัลทีละพจน์ได้ ทำให้เป็นเครื่องมือหลักในการแทนฟังก์ชัน คำนวณเชิงตัวเลข และแก้สมการเชิงอนุพันธ์

เขียนโดย อาจารย์มดอัปเดต
แล็บรัศมีการลู่เข้า หารัศมี R ตรวจปลายช่วง อนุพันธ์ · อินทิกรัล R จากระนาบเชิงซ้อน
สรุปใน 30 วินาที
  • \(\sum c_n(x-a)^n\) ลู่เข้าเมื่อ \(|x - a| < R\) ลู่ออกเมื่อ \(|x - a| > R\) (R อาจเป็น 0 หรือ ∞)
  • \(R = \lim\left|\dfrac{c_n}{c_{n+1}}\right|\) หรือ \(\dfrac1R = \limsup\sqrt[n]{|c_n|}\) · ปลายช่วงต้องทดสอบเอง
  • หาอนุพันธ์/อินทิกรัลทีละพจน์ได้ใน \(|x - a| < R\) โดย R ไม่เปลี่ยน
  • R = ระยะจาก a ถึงจุดเอกฐานที่ใกล้ที่สุดในระนาบเชิงซ้อน
ระดับพื้นฐาน แนวคิดกลาง แคลคูลัส 2ขั้นสูง คณิตศาสตร์วิศวกรรม

อนุกรมกำลังคืออะไร พื้นฐาน

ตัวอย่างแรกเราเห็นแล้วในหน้าอนุกรมเรขาคณิต: \(1 + x + x^2 + \cdots = \dfrac{1}{1-x}\) เมื่อ \(|x| < 1\) ด้านซ้ายคืออนุกรมกำลัง ด้านขวาคือฟังก์ชันที่มันแทน โดยแทนได้เฉพาะในช่วง \((-1, 1)\) เท่านั้น ทั้งบทนี้คือการศึกษาว่าเกิดอะไรขึ้นกับคู่นี้

P1 Power series centered at a อนุกรมกำลังรอบจุด a

\[ \sum_{n=0}^{\infty} c_n (x - a)^n = c_0 + c_1(x - a) + c_2(x - a)^2 + \cdots \]

\(a\) = จุดศูนย์กลาง (center) · \(c_n\) = สัมประสิทธิ์ · ที่ \(x = a\) ลู่เข้าเสมอ (เท่ากับ \(c_0\))

รัศมีการลู่เข้า: สามกรณีเท่านั้น กลาง

P2 Radius of convergence theorem ทฤษฎีบทรัศมีการลู่เข้า

\[ \exists R \in [0, \infty]:\quad |x - a| < R \Rightarrow \text{ลู่เข้าแบบสัมบูรณ์},\qquad |x - a| > R \Rightarrow \text{ลู่ออก} \]

R = 0: ลู่เข้าแค่ที่ \(x = a\) · R = ∞: ลู่เข้าทุก x · ไม่มีกรณีที่ลู่เข้าเป็นช่วงไม่สมมาตร (ยกเว้นปลายช่วง)

P3 Ratio formula สูตรจากอัตราส่วน

\[ R = \lim_{n\to\infty}\left|\frac{c_n}{c_{n+1}}\right| \quad(\text{ถ้าลิมิตมี}) \]

ระวังลำดับ: \(c_n\) อยู่บน · ในทางปฏิบัติใช้ ratio test กับพจน์เต็ม \(|a_{n+1}/a_n|\) แล้วแก้อสมการ < 1 จะไม่สับสน

P4 Cauchy–Hadamard formula สูตรโคชี-อาดามาร์

\[ \frac1R = \limsup_{n\to\infty}\sqrt[n]{|c_n|} \]

ใช้ได้เสมอ แม้มีช่องว่าง (สัมประสิทธิ์เป็น 0 สลับ) ที่สูตรอัตราส่วนใช้ไม่ได้

P5 Interval of convergence ช่วงการลู่เข้า

\[ (a - R,\ a + R) \ \cup\ \{\text{ปลายที่ลู่เข้า}\}:\quad (\,),\ [\,),\ (\,],\ [\,] \]

ที่ปลายช่วง ratio test ให้ 1 เสมอ ต้องใช้ p-series, ไลบ์นิซ, พจน์ที่ n หรือเปรียบเทียบ

ตัวอย่าง P-1 · ครบสูตร

หาช่วงการลู่เข้าของ \(\displaystyle\sum_{n=1}^{\infty}\frac{(x-3)^n}{n\,2^n}\)

  1. อัตราส่วน: \(\left|\dfrac{(x-3)^{n+1}}{(n+1)2^{n+1}}\cdot\dfrac{n\,2^n}{(x-3)^n}\right| = \dfrac{|x-3|}{2}\cdot\dfrac{n}{n+1} \to \dfrac{|x-3|}{2}\)

  2. ลู่เข้าเมื่อ \(\dfrac{|x-3|}{2} < 1 \iff |x - 3| < 2\) ⇒ \(R = 2\), ช่วงเปิด \((1, 5)\)

  3. ปลายซ้าย \(x = 1\): \(\sum\dfrac{(-2)^n}{n2^n} = \sum\dfrac{(-1)^n}{n}\) ลู่เข้า (ไลบ์นิซ) · ปลายขวา \(x = 5\): \(\sum\dfrac{2^n}{n2^n} = \sum\dfrac1n\) ลู่ออก

\(R = 2\) · ช่วงการลู่เข้า \([1, 5)\) (ในแล็บพิมพ์ cₙ แล้วตั้ง a = 3)

ตัวอย่าง P-2 · R เป็นค่าพิเศษ และช่องว่าง

หาช่วงการลู่เข้าของ (ก) \(\sum\dfrac{n!\,x^n}{n^n}\) (ข) \(\sum\dfrac{x^{2n}}{4^n}\) (ค) \(\sum\dfrac{(2x-1)^n}{n^2}\)

  1. (ก) \(\left|\dfrac{c_{n+1}}{c_n}\right| = \left(\dfrac{n}{n+1}\right)^n \to \dfrac1e\) ⇒ \(R = e\) · ที่ \(x = \pm e\): \(|a_n| = \dfrac{n!\,e^n}{n^n} \sim \sqrt{2\pi n} \to \infty\) ลู่ออกทั้งสองปลาย ⇒ \((-e, e)\)

  2. (ข) มีแต่กำลังคู่ (ช่องว่าง) มองเป็นเรขาคณิตของ \(u = x^2/4\): ลู่เข้า ⇔ \(x^2/4 < 1 \iff |x| < 2\) · ที่ \(x = \pm2\) ได้ \(\sum 1\) ลู่ออก ⇒ \((-2, 2)\)

  3. (ค) อัตราส่วน \(|2x - 1|\cdot\dfrac{n^2}{(n+1)^2} \to |2x-1| < 1 \iff 0 < x < 1\) (\(R = \tfrac12\) รอบ \(a = \tfrac12\)) · ปลาย: \(\sum\dfrac{(\pm1)^n}{n^2}\) ลู่เข้าแบบสัมบูรณ์ทั้งคู่ ⇒ \([0, 1]\)

(ก) \((-e, e)\) · (ข) \((-2, 2)\) · (ค) \([0, 1]\) — ข้อ (ค) ระวัง: \((2x-1)^n = 2^n(x - \tfrac12)^n\) จึงมีจุดศูนย์กลาง ½ ไม่ใช่ 1

แล็บรัศมีการลู่เข้า: เส้นจำนวนจริงและระนาบเชิงซ้อน พื้นฐาน

เลือกอนุกรมแล้วเลื่อนดีกรี N ของผลบวกย่อย: ในแถบเขียวเส้นส้มเกาะฟังก์ชันแน่นขึ้นเรื่อย ๆ นอกแถบเส้นส้มแกว่งหนี วงกลมเขียวทึบ/แดงโปร่งบอกปลายช่วงที่ลู่เข้า/ลู่ออก ภาพระนาบเชิงซ้อนแสดงจุดเอกฐานที่กำหนดรัศมี หรือเลือก “พิมพ์ cₙ เอง”

ตรวจปลายช่วง: ที่ที่ข้อสอบเก็บคะแนน กลาง

นักศึกษาส่วนใหญ่หา R ได้ แต่เสียคะแนนที่ปลายช่วง ตารางนี้สรุปอนุกรมกำลังมาตรฐานที่มีรัศมี 1 แต่ปลายช่วงต่างกันทั้งหมด จำไว้ใช้เป็นตัวเทียบ

อนุกรมฟังก์ชันx = −1x = 1ช่วง
\(\sum x^n\)\(\tfrac{1}{1-x}\)ลู่ออกลู่ออก\((-1, 1)\)
\(\sum \tfrac{x^n}{n}\)\(-\ln(1-x)\)มีเงื่อนไขลู่ออก\([-1, 1)\)
\(\sum \tfrac{(-1)^{n+1}x^n}{n}\)\(\ln(1+x)\)ลู่ออกมีเงื่อนไข\((-1, 1]\)
\(\sum \tfrac{x^n}{n^2}\)\(\operatorname{Li}_2(x)\)สัมบูรณ์สัมบูรณ์\([-1, 1]\)
\(\sum \tfrac{(-1)^n x^{2n+1}}{2n+1}\)\(\arctan x\)มีเงื่อนไขมีเงื่อนไข\([-1, 1]\)
แนวข้อสอบโจทย์ “หาช่วงการลู่เข้า” ให้คะแนนสามส่วน: หา R (ใช้อัตราส่วนหรือราก) · ตรวจปลายซ้าย · ตรวจปลายขวา เขียนการทดสอบที่ใช้ที่ปลายแต่ละข้างให้ชัด ห้ามสรุปจาก ratio test ที่ปลายช่วงเพราะได้ 1 เสมอ

อนุพันธ์และอินทิกรัลทีละพจน์ กลาง

ภายในช่วงลู่เข้า อนุกรมกำลังเป็นฟังก์ชันที่หาอนุพันธ์ได้ทุกอันดับ และทำได้ทีละพจน์เหมือนพหุนาม นี่คือ “เครื่องจักรผลิตอนุกรม”: เริ่มจากอนุกรมเรขาคณิตตัวเดียว หาอนุพันธ์ อินทิกรัล หรือแทนตัวแปร จะได้อนุกรมของฟังก์ชันอื่นอีกมาก

P6 Term-by-term calculus อนุพันธ์และอินทิกรัลทีละพจน์

\[ f(x) = \sum_{n=0}^{\infty} c_n(x-a)^n \ \Rightarrow\ f'(x) = \sum_{n=1}^{\infty} n c_n (x-a)^{n-1},\quad \int f\,dx = C + \sum_{n=0}^{\infty}\frac{c_n(x-a)^{n+1}}{n+1} \]

ทั้งสองมีรัศมี R เท่าเดิม · ปลายช่วงอาจได้หรือเสียการลู่เข้า ต้องตรวจใหม่

P7 Series built from the geometric series อนุกรมที่สร้างจากอนุกรมเรขาคณิต

\[ \frac{1}{1-x} = \sum x^n,\quad \frac{1}{(1-x)^2} = \sum (n+1)x^n,\quad \ln(1+x) = \sum_{n=1}^{\infty}\frac{(-1)^{n+1}x^n}{n},\quad \arctan x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1} \]

ทั้งหมดมี \(R = 1\) · \(\ln(1+x) = \int_0^x \tfrac{dt}{1+t}\) · \(\arctan x = \int_0^x\tfrac{dt}{1+t^2}\)

ตัวอย่าง P-3 · หาผลบวกด้วยอนุพันธ์-อินทิกรัล

หาผลบวก (ก) \(\displaystyle\sum_{n=1}^{\infty}\frac{n}{2^n}\) (ข) \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n\,2^n}\)

  1. (ก) จาก \(\sum x^n = \dfrac{1}{1-x}\) หาอนุพันธ์: \(\sum nx^{n-1} = \dfrac{1}{(1-x)^2}\) คูณ x: \(\sum nx^n = \dfrac{x}{(1-x)^2}\) · ที่ \(x = \tfrac12\): \(\dfrac{1/2}{1/4} = 2\)

  2. (ข) อินทิกรัล \(\sum x^{n-1}\) ตั้งแต่ 0 ถึง x: \(\sum\dfrac{x^n}{n} = -\ln(1-x)\) · ที่ \(x = \tfrac12\): \(-\ln\tfrac12 = \ln 2\)

(ก) 2 · (ข) \(\ln 2 \approx 0.6931\) (ลู่เข้าเร็วกว่า \(1 - \tfrac12 + \tfrac13 - \cdots\) มาก)

แทนฟังก์ชันด้วยอนุกรมกำลัง: เทคนิคเรขาคณิต กลาง

P8 The geometric trick เทคนิคอนุกรมเรขาคณิต

\[ \frac{1}{c - x} = \frac1c\cdot\frac{1}{1 - x/c} = \sum_{n=0}^{\infty}\frac{x^n}{c^{n+1}},\quad |x| < |c|;\qquad \frac{1}{c - x} = \frac{1}{(c - a) - (x - a)} \text{ สำหรับรอบ } a \]

ฟังก์ชันตรรกยะ: แยกเศษส่วนย่อยก่อน แล้วกระจายทีละตัว รัศมี = ระยะถึงโพลที่ใกล้ที่สุด

ตัวอย่าง P-4 · ฟังก์ชันตรรกยะ

เขียน \(f(x) = \dfrac{3}{(1-x)(1+2x)}\) เป็นอนุกรมกำลังรอบ 0 และหารัศมีการลู่เข้า

  1. แยกเศษส่วนย่อย: \(\dfrac{3}{(1-x)(1+2x)} = \dfrac{1}{1-x} + \dfrac{2}{1+2x}\) (ตรวจที่ x = 1 และ x = −½)

  2. \(\dfrac{1}{1-x} = \sum x^n\) (\(|x| < 1\)) · \(\dfrac{2}{1+2x} = 2\sum(-2x)^n\) (\(|x| < \tfrac12\))

  3. รวม: \(f(x) = \sum_{n=0}^{\infty}\left[1 + 2(-2)^n\right]x^n = 3 - 3x + 9x^2 - 15x^3 + 33x^4 - \cdots\)

  4. ต้องลู่เข้าทั้งสองตัว ⇒ \(R = \tfrac12\) ตรงกับระยะจาก 0 ถึงโพล \(x = -\tfrac12\)

\(c_n = 1 + 2(-2)^n,\ R = \tfrac12\)

รัศมีการลู่เข้ามาจากระนาบเชิงซ้อน ขั้นสูง

ทำไมอนุกรมของ \(\dfrac{1}{1+x^2}\) จึงลู่เข้าแค่ \(|x| < 1\) ทั้งที่กราฟบนแกนจริงเรียบทุกจุด คำตอบอยู่นอกแกนจริง: อนุกรมกำลังลู่เข้าเป็น “ดิสก์” ในระนาบเชิงซ้อน และดิสก์ขยายได้จนชนจุดเอกฐานแรก ส่วนที่เห็นบนแกนจริงคือรอยตัดของดิสก์ ความเข้าใจนี้นำไปสู่อนุกรมโลรองต์ และฟังก์ชันวิเคราะห์

P9 Radius = distance to the nearest singularity รัศมีคือระยะถึงจุดเอกฐานที่ใกล้ที่สุด

\[ f \text{ วิเคราะห์ใน } |z - a| < \rho \text{ และมีจุดเอกฐานบน } |z - a| = \rho \ \Rightarrow\ R = \rho \]

\(\dfrac{1}{x^2 - 4x + 13}\): โพล \(2 \pm 3i\) · รอบ 0 ได้ \(R = \sqrt{13} \approx 3.61\) · รอบ 2 ได้ \(R = 3\) — ไม่ต้องคำนวณสัมประสิทธิ์เลย

P10 Uniqueness ความเป็นหนึ่งเดียว

\[ \sum c_n (x-a)^n = \sum d_n (x-a)^n \text{ ใกล้ } a \Rightarrow c_n = d_n = \frac{f^{(n)}(a)}{n!} \]

ได้อนุกรมด้วยวิธีใดก็ตาม (แทนค่า แยกเศษส่วน คูณ) ผลคืออนุกรมเทย์เลอร์ตัวเดียวกันเสมอ

P11 Abel's theorem ทฤษฎีบทของอาเบล

\[ \sum c_n R^n \text{ ลู่เข้า} \Rightarrow \lim_{x\to R^-}\sum c_n x^n = \sum c_n R^n \]

ใช้หาผลบวกที่ปลายช่วง: \(\arctan 1 = \tfrac{\pi}{4} = 1 - \tfrac13 + \tfrac15 - \cdots\) และ \(\ln 2 = 1 - \tfrac12 + \tfrac13 - \cdots\)

P12 Uniform convergence ลู่เข้าอย่างสม่ำเสมอ

\[ |x - a| \le r < R:\quad |c_n(x-a)^n| \le |c_n| r^n =: M_n,\ \sum M_n < \infty \]

Weierstrass M-test ⇒ ลู่เข้าสม่ำเสมอบนช่วงปิดข้างใน จึงสลับลิมิต อนุพันธ์ และอินทิกรัลกับผลบวกได้

แก้สมการเชิงอนุพันธ์ด้วยอนุกรมกำลัง ขั้นสูง

สมการเชิงอนุพันธ์จำนวนมากในฟิสิกส์และวิศวกรรมไม่มีคำตอบเป็นฟังก์ชันพื้นฐาน วิธีอนุกรมกำลังเปลี่ยนสมการเชิงอนุพันธ์เป็นความสัมพันธ์เวียนเกิดของสัมประสิทธิ์ ซึ่งคอมพิวเตอร์คำนวณได้ทันที (เทียบกับการแปลงลาปลาซที่เหมาะกับสัมประสิทธิ์คงที่)

P13 Power series method วิธีอนุกรมกำลัง

\[ y = \sum c_n x^n,\ y' = \sum (n+1)c_{n+1}x^n,\ y'' = \sum (n+2)(n+1)c_{n+2}x^n \ \Rightarrow \text{ เทียบสัมประสิทธิ์ของ } x^n \]

จุดสามัญ (ordinary point) ให้คำตอบอนุกรมกำลังเสมอ · จุดเอกฐานปกติใช้วิธีโฟรเบเนียส \(y = x^r\sum c_n x^n\)

P14 Bessel function J₀ ฟังก์ชันเบสเซล

\[ x^2y'' + xy' + x^2y = 0:\quad J_0(x) = \sum_{k=0}^{\infty}\frac{(-1)^k}{(k!)^2}\left(\frac{x}{2}\right)^{2k},\ R = \infty \]

ใช้กับการสั่นของแผ่นกลม การนำความร้อนในทรงกระบอก และแอมพลิจูดของไซด์แบนด์ในสัญญาณ FM

ตัวอย่าง P-5 · y″ + y = 0

แก้ \(y'' + y = 0\) ด้วยอนุกรมกำลังรอบ 0

  1. แทน \(y = \sum c_n x^n\): \(\sum\left[(n+2)(n+1)c_{n+2} + c_n\right]x^n = 0\) ⇒ \(c_{n+2} = -\dfrac{c_n}{(n+2)(n+1)}\)

  2. เริ่มจาก \(c_0\): \(c_2 = -\tfrac{c_0}{2!},\ c_4 = \tfrac{c_0}{4!}, \dots\) · เริ่มจาก \(c_1\): \(c_3 = -\tfrac{c_1}{3!},\ c_5 = \tfrac{c_1}{5!}, \dots\)

  3. \(y = c_0\left(1 - \tfrac{x^2}{2!} + \tfrac{x^4}{4!} - \cdots\right) + c_1\left(x - \tfrac{x^3}{3!} + \tfrac{x^5}{5!} - \cdots\right) = c_0\cos x + c_1\sin x\)

\(y = c_0\cos x + c_1\sin x\) — นิยามของ sin และ cos ผ่านอนุกรมคือคำตอบของสมการการสั่นอย่างง่าย (วงจร LC, สปริง-มวล)

ตัวอย่าง P-6 · สมการไม่เชิงเส้น

หา 3 พจน์แรกของคำตอบ \(y' = 1 + y^2,\ y(0) = 0\)

  1. \(y(0) = 0\) ⇒ \(c_0 = 0\) · \(y'(0) = 1 + 0 = 1\) ⇒ \(c_1 = 1\)

  2. หาอนุพันธ์ต่อ: \(y'' = 2yy'\) ⇒ \(y''(0) = 0\) · \(y''' = 2(y')^2 + 2yy''\) ⇒ \(y'''(0) = 2\) ⇒ \(c_3 = \tfrac{2}{3!} = \tfrac13\)

  3. ต่อไปจะได้ \(c_5 = \tfrac{2}{15}\) ตรงกับอนุกรมของ \(\tan x\) ซึ่งคือคำตอบแม่นตรง

\(y = x + \tfrac{x^3}{3} + \tfrac{2x^5}{15} + \cdots = \tan x\) · R = π/2 (จุดเอกฐานที่ x = ±π/2 ทำให้คำตอบระเบิด)

ต่อไป: สัมประสิทธิ์มาจากไหน

ทฤษฎีบทความเป็นหนึ่งเดียว (P10) บอกว่าสัมประสิทธิ์ต้องเป็น \(c_n = f^{(n)}(a)/n!\) เสมอ นั่นคืออนุกรมเทย์เลอร์ หน้าถัดไปจะสร้างอนุกรมของทุกฟังก์ชันพื้นฐาน พร้อมเศษเหลือที่บอกความแม่นยำ · อ่านบทความ รัศมีการลู่เข้าหาอย่างไร (English) · ทบทวนอนุกรมสลับสำหรับปลายช่วง
