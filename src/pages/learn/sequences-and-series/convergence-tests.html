// บทที่ 26.3 · ลำดับและอนุกรม · Convergence Tests

การทดสอบการลู่เข้าของอนุกรม (Convergence Tests): พจน์ที่ n ปริพันธ์ เปรียบเทียบ อัตราส่วน ราก และผังเลือกใช้

อนุกรมส่วนใหญ่หาผลบวกเป็นสูตรไม่ได้ แต่วิศวกรยังต้องรู้ว่าบวกแล้ว “จำกัด” หรือไม่ ก่อนนำไปคำนวณ หน้านี้รวบรวมการทดสอบสำหรับอนุกรมพจน์บวกทุกแบบที่ใช้ในแคลคูลัส 2 และคณิตศาสตร์วิศวกรรม พร้อมผังตัดสินใจที่บอกว่าเห็นรูปแบบไหนควรใช้อะไร และเกมฝึกให้มองเป็นภายในไม่กี่วินาที ส่วนอนุกรมที่มีเครื่องหมายสลับอยู่ในหน้าอนุกรมสลับ

การทดสอบพจน์ที่ n (n-th Term Test) พื้นฐาน

T1 n-th term test for divergence การทดสอบพจน์ที่ n

\[ \lim_{n\to\infty} a_n \ne 0 \ \text{(หรือไม่มีลิมิต)} \ \Longrightarrow\ \sum a_n \ \text{ลู่ออก} \]

ใช้เป็นด่านแรกทุกข้อ ใช้เวลา 5 วินาที · ถ้าได้ \(a_n \to 0\) สรุปไม่ได้ ต้องไปข้อถัดไปในผัง

การทดสอบด้วยปริพันธ์ (Integral Test) และขอบเขตเศษเหลือ กลาง

ถ้าพจน์มาจากฟังก์ชันที่ลดลง ผลบวกของพจน์คือพื้นที่สี่เหลี่ยมกว้าง 1 ซึ่งประกบพื้นที่ใต้กราฟจากทั้งบนและล่าง อนุกรมกับปริพันธ์จึงลู่เข้าหรือลู่ออกพร้อมกัน และยิ่งไปกว่านั้น ปริพันธ์บอกได้ว่าผลบวกจริงอยู่ในช่วงใด

T2 Integral test การทดสอบด้วยปริพันธ์

\[ a_n = f(n),\ f \text{ บวก ต่อเนื่อง ลดลงเมื่อ } x \ge N:\qquad \sum_{n=N}^{\infty} a_n \text{ ลู่เข้า} \iff \int_{N}^{\infty} f(x)\,dx \text{ ลู่เข้า} \]

ตรวจ “ลดลง” ด้วย \(f'(x) < 0\) · ค่าปริพันธ์ ≠ ผลบวกของอนุกรม · ใช้พิสูจน์อนุกรม p (\(\int_1^\infty x^{-p}dx\) จำกัด ⇔ \(p > 1\))

T3 Remainder estimate ขอบเขตเศษเหลือจากปริพันธ์

\[ \int_{N+1}^{\infty} f(x)\,dx \ \le\ R_N = \sum_{n=N+1}^{\infty} a_n \ \le\ \int_{N}^{\infty} f(x)\,dx \quad\Rightarrow\quad S_N + \int_{N+1}^{\infty} f \le S \le S_N + \int_N^{\infty} f \]

ค่ากลางของช่วงเป็นค่าประมาณที่ดีมากโดยบวกพจน์ไม่กี่ตัว

ตัวอย่าง T-1 · ประมาณผลบวก

ประมาณ \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^3}\) โดยบวก 10 พจน์ แล้วหาช่วงที่ผลบวกจริงอยู่

  1. \(S_{10} = 1 + \tfrac18 + \tfrac1{27} + \cdots + \tfrac{1}{1000} = 1.1975320\)

  2. \(\displaystyle\int_N^{\infty}\frac{dx}{x^3} = \frac{1}{2N^2}\) ⇒ ขอบล่าง \(S_{10} + \tfrac{1}{2\cdot 11^2} = 1.2016642\) · ขอบบน \(S_{10} + \tfrac{1}{2\cdot10^2} = 1.2025320\)

  3. ค่ากลาง \(1.2020981 \pm 0.0004339\) ผลบวกจริง \(\zeta(3) = 1.2020569\) อยู่ในช่วง

\(1.20166 \le S \le 1.20253\) — แม่นถึงทศนิยม 3 ตำแหน่งด้วยพจน์เพียง 10 ตัว ขณะที่ \(S_{10}\) อย่างเดียวคลาดถึง 0.0045

ตัวอย่าง T-2 · ลู่เข้าหรือลู่ออก

(ก) \(\displaystyle\sum_{n=1}^{\infty} n e^{-n^2}\) (ข) \(\displaystyle\sum_{n=2}^{\infty}\frac{1}{n\sqrt{\ln n}}\)

  1. (ก) \(f(x) = xe^{-x^2}\) บวก ต่อเนื่อง และ \(f'(x) = e^{-x^2}(1 - 2x^2) < 0\) เมื่อ \(x \ge 1\) · \(\int_1^\infty xe^{-x^2}dx = \left[-\tfrac12 e^{-x^2}\right]_1^\infty = \tfrac{1}{2e}\) จำกัด ⇒ ลู่เข้า

  2. (ข) แทน \(u = \ln x\): \(\int_2^\infty \dfrac{dx}{x\sqrt{\ln x}} = \int_{\ln2}^\infty u^{-1/2}du = \left[2\sqrt u\right]_{\ln 2}^{\infty} = \infty\) ⇒ ลู่ออก

(ก) ลู่เข้า · (ข) ลู่ออก — ข้อ (ข) คืออนุกรม \(\sum 1/(n(\ln n)^p)\) ที่ \(p = \tfrac12 \le 1\)

การทดสอบโดยการเปรียบเทียบ (Direct Comparison Test) กลาง

หลักคิดง่ายมาก: ถ้าตัวใหญ่บวกแล้วจำกัด ตัวเล็กก็จำกัด ถ้าตัวเล็กบวกแล้วไม่จำกัด ตัวใหญ่ก็ไม่จำกัด สิ่งที่ต้องระวังคือทิศของอสมการ: เทียบกับตัวใหญ่ที่ลู่ออก หรือตัวเล็กที่ลู่เข้า สรุปอะไรไม่ได้

T4 Direct comparison test การเปรียบเทียบโดยตรง

\[ 0 \le a_n \le b_n \ (n \ge N):\qquad \sum b_n \text{ ลู่เข้า} \Rightarrow \sum a_n \text{ ลู่เข้า};\qquad \sum a_n \text{ ลู่ออก} \Rightarrow \sum b_n \text{ ลู่ออก} \]

ตัวเทียบยอดนิยม: \(\tfrac{1}{n^p}\), \(r^n\) · อสมการช่วย \(|\sin x| \le 1\), \(\ln n < \sqrt n\), \(\ln n < n^{\epsilon}\) (n ใหญ่พอ), \(n! \ge 2^{n-1}\)

ตัวอย่าง T-3 · เปรียบเทียบตรง

(ก) \(\sum \dfrac{1}{2^n + 1}\) (ข) \(\sum \dfrac{2 + \sin n}{n^2}\) (ค) \(\displaystyle\sum_{n=2}^{\infty}\frac{1}{\sqrt n - 1}\)

  1. (ก) \(\dfrac{1}{2^n + 1} < \dfrac{1}{2^n}\) และ \(\sum (1/2)^n\) ลู่เข้า ⇒ ลู่เข้า

  2. (ข) \(0 < \dfrac{2 + \sin n}{n^2} \le \dfrac{3}{n^2}\) และ \(\sum 3/n^2\) ลู่เข้า ⇒ ลู่เข้า

  3. (ค) \(\dfrac{1}{\sqrt n - 1} > \dfrac{1}{\sqrt n}\) และ \(\sum 1/\sqrt n\) ลู่ออก (p = ½) ⇒ ลู่ออก

(ก) ลู่เข้า · (ข) ลู่เข้า · (ค) ลู่ออก

การเปรียบเทียบแบบลิมิต (Limit Comparison Test) กลาง

ในทางปฏิบัติ การทดสอบนี้ใช้บ่อยที่สุด เพราะไม่ต้องหาอสมการที่ถูกทิศ ดูแค่ว่าเมื่อ n ใหญ่ พจน์ “ประพฤติเหมือน” อะไร โดยเก็บเฉพาะตัวเด่น (dominant term) ของเศษและส่วน

T5 Limit comparison test การเปรียบเทียบแบบลิมิต

\[ a_n, b_n > 0,\quad \lim_{n\to\infty}\frac{a_n}{b_n} = c,\ \ 0 < c < \infty\ \Rightarrow\ \sum a_n,\ \sum b_n \text{ ลู่เข้าหรือลู่ออกพร้อมกัน} \]

\(c = 0\) และ \(\sum b_n\) ลู่เข้า ⇒ \(\sum a_n\) ลู่เข้า · \(c = \infty\) และ \(\sum b_n\) ลู่ออก ⇒ \(\sum a_n\) ลู่ออก · เลือก \(b_n\) = ตัวเด่นบน/ตัวเด่นล่าง

T6 Asymptotic equivalents พจน์ที่สมมูลกันเมื่อ n ใหญ่

\[ \sin\tfrac1n \sim \tfrac1n,\quad 1 - \cos\tfrac1n \sim \tfrac{1}{2n^2},\quad \ln\left(1 + \tfrac1n\right) \sim \tfrac1n,\quad e^{1/n} - 1 \sim \tfrac1n \]

มาจากอนุกรมเทย์เลอร์ พจน์แรก · ใช้คู่กับ T5 ได้ทันที

ตัวอย่าง T-4 · เปรียบเทียบแบบลิมิต

(ก) \(\sum \dfrac{n+1}{n^3 - n + 2}\) (ข) \(\sum \dfrac{1}{\sqrt{n^2 + 1}}\) (ค) \(\sum \sin\dfrac{1}{n^2}\)

  1. (ก) ตัวเด่น \(\tfrac{n}{n^3} = \tfrac{1}{n^2}\): \(\lim \dfrac{(n+1)/(n^3-n+2)}{1/n^2} = \lim\dfrac{n^3 + n^2}{n^3 - n + 2} = 1\) ⇒ ลู่เข้าเหมือน \(\sum 1/n^2\)

  2. (ข) \(\sqrt{n^2+1} \sim n\): \(\lim \dfrac{1/\sqrt{n^2+1}}{1/n} = 1\) ⇒ ลู่ออกเหมือนฮาร์มอนิก

  3. (ค) \(\lim \dfrac{\sin(1/n^2)}{1/n^2} = 1\) (เพราะ \(\tfrac{\sin u}{u} \to 1\)) ⇒ ลู่เข้าเหมือน \(\sum 1/n^2\)

(ก) ลู่เข้า · (ข) ลู่ออก · (ค) ลู่เข้า

สูตรลัดสำหรับเศษส่วนของพหุนามถ้า \(a_n = \dfrac{P(n)}{Q(n)}\) โดย P ดีกรี p และ Q ดีกรี q แล้ว \(a_n \sim \dfrac{C}{n^{q-p}}\) อนุกรมลู่เข้า ⇔ \(q - p > 1\) (ดีกรีล่างมากกว่าบนอย่างน้อย 2) · รากนับดีกรีครึ่ง เช่น \(\sqrt{n^3 + 1}\) มีดีกรี 3/2

การทดสอบอัตราส่วน (Ratio Test) กลาง

ถ้าพจน์ถัดไปเล็กกว่าพจน์ก่อนหน้าด้วยอัตราส่วนเกือบคงที่ \(\rho\) อนุกรมก็ประพฤติเหมือนอนุกรมเรขาคณิตอัตราส่วน \(\rho\) การทดสอบนี้จึงเก่งกับพจน์ที่มีการคูณซ้ำ เช่น แฟกทอเรียลและเลขยกกำลัง

T7 Ratio test (d'Alembert) การทดสอบอัตราส่วน

\[ \rho = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|:\qquad \rho < 1 \Rightarrow \text{ลู่เข้าแบบสัมบูรณ์},\quad \rho > 1 \text{ (หรือ } \infty) \Rightarrow \text{ลู่ออก},\quad \rho = 1 \Rightarrow \text{สรุปไม่ได้} \]

อนุกรม p ทุกตัวให้ \(\rho = 1\) จึงใช้ ratio test กับเศษส่วนของพหุนามไม่ได้ · ตัวช่วย \(\dfrac{(n+1)!}{n!} = n+1\), \(\left(\dfrac{n}{n+1}\right)^n \to \dfrac1e\)

ตัวอย่าง T-5 · อัตราส่วน

(ก) \(\sum \dfrac{n^3}{3^n}\) (ข) \(\sum \dfrac{(2n)!}{(n!)^2\,5^n}\) (ค) \(\sum \dfrac{n^n}{n!}\)

  1. (ก) \(\dfrac{a_{n+1}}{a_n} = \dfrac{(n+1)^3}{3^{n+1}}\cdot\dfrac{3^n}{n^3} = \dfrac13\left(1 + \dfrac1n\right)^3 \to \dfrac13 < 1\) ⇒ ลู่เข้า

  2. (ข) \(\dfrac{a_{n+1}}{a_n} = \dfrac{(2n+2)(2n+1)}{(n+1)^2\cdot5} = \dfrac{2(2n+1)}{5(n+1)} \to \dfrac45 < 1\) ⇒ ลู่เข้า

  3. (ค) \(\dfrac{a_{n+1}}{a_n} = \dfrac{(n+1)^{n+1}}{(n+1)!}\cdot\dfrac{n!}{n^n} = \left(\dfrac{n+1}{n}\right)^n \to e > 1\) ⇒ ลู่ออก

(ก) ลู่เข้า · (ข) ลู่เข้า · (ค) ลู่ออก

การทดสอบราก (Root Test) กลาง

T8 Root test (Cauchy) การทดสอบราก

\[ \rho = \lim_{n\to\infty}\sqrt[n]{|a_n|}\ \left(\text{ทั่วไปใช้ } \limsup\right):\quad \rho < 1 \Rightarrow \text{ลู่เข้าแบบสัมบูรณ์},\quad \rho > 1 \Rightarrow \text{ลู่ออก},\quad \rho = 1 \Rightarrow \text{สรุปไม่ได้} \]

เหมาะกับ \((\cdots)^n\) · ตัวช่วย \(\sqrt[n]{n} \to 1\), \(\sqrt[n]{n^k} \to 1\), \(\sqrt[n]{c} \to 1\)

T9 Ratio vs root อัตราส่วนกับราก

\[ \lim\left|\frac{a_{n+1}}{a_n}\right| = L \ \Rightarrow\ \lim\sqrt[n]{|a_n|} = L \]

รากแข็งแรงกว่า: บางอนุกรมอัตราส่วนแกว่ง (ไม่มีลิมิต) แต่รากยังสรุปได้ เช่น \(\sum 2^{-n + (-1)^n}\)

ตัวอย่าง T-6 · ราก

(ก) \(\sum\left(\dfrac{2n}{3n+1}\right)^n\) (ข) \(\sum\left(1 + \dfrac1n\right)^{-n^2}\)

  1. (ก) \(\sqrt[n]{a_n} = \dfrac{2n}{3n+1} \to \dfrac23 < 1\) ⇒ ลู่เข้า

  2. (ข) \(\sqrt[n]{a_n} = \left(1 + \dfrac1n\right)^{-n} \to \dfrac1e < 1\) ⇒ ลู่เข้า (ใช้อัตราส่วนจะยุ่งกว่ามาก)

ลู่เข้าทั้งคู่

เมื่อการทดสอบปกติได้ 1: ควบแน่นของโคชี ราบี และสเตอร์ลิง ขั้นสูง

ข้อสอบไฟนอลและคณิตศาสตร์วิศวกรรมขั้นสูงชอบอนุกรมที่ ratio test ได้ 1 พอดี เครื่องมือสามชิ้นนี้ปิดช่องว่างนั้น

T10 Cauchy condensation test การทดสอบควบแน่นของโคชี

\[ a_n \downarrow 0:\quad \sum_{n=1}^{\infty} a_n \text{ ลู่เข้า} \iff \sum_{k=0}^{\infty} 2^k a_{2^k} \text{ ลู่เข้า} \]

\(\sum \dfrac{1}{n(\ln n)^p} \to \sum \dfrac{2^k}{2^k (k\ln 2)^p} = \dfrac{1}{(\ln2)^p}\sum\dfrac{1}{k^p}\) ลู่เข้า ⇔ \(p > 1\)

T11 Raabe's test การทดสอบราบี

\[ R = \lim_{n\to\infty} n\left(\frac{a_n}{a_{n+1}} - 1\right):\quad R > 1 \Rightarrow \text{ลู่เข้า},\quad R < 1 \Rightarrow \text{ลู่ออก} \]

ใช้เมื่อ ratio test ได้ \(\rho = 1\) · อนุกรม p ให้ \(R = p\) พอดี จึงเป็นการวัด “p ที่แฝงอยู่”

T12 Stirling's approximation สูตรประมาณของสเตอร์ลิง

\[ n! \sim \sqrt{2\pi n}\left(\frac{n}{e}\right)^n,\qquad \binom{2n}{n} \sim \frac{4^n}{\sqrt{\pi n}} \]

เปลี่ยนแฟกทอเรียลเป็นกำลัง แล้วใช้ T5 หรือ T1 · \(10! = 3{,}628{,}800\) สูตรให้ 3,598,696 (คลาด 0.8 %)

ตัวอย่าง T-7 · ราบี

\(\displaystyle\sum_{n=1}^{\infty}\frac{1\cdot3\cdot5\cdots(2n-1)}{2\cdot4\cdot6\cdots(2n)}\) ลู่เข้าหรือไม่

  1. \(\dfrac{a_{n+1}}{a_n} = \dfrac{2n+1}{2n+2} \to 1\) ratio test สรุปไม่ได้

  2. ราบี: \(n\left(\dfrac{a_n}{a_{n+1}} - 1\right) = n\left(\dfrac{2n+2}{2n+1} - 1\right) = \dfrac{n}{2n+1} \to \dfrac12 < 1\) ⇒ ลู่ออก

  3. ยืนยันด้วยสเตอร์ลิง: \(a_n = \dfrac{(2n)!}{4^n (n!)^2} = \dfrac{1}{4^n}\binom{2n}{n} \sim \dfrac{1}{\sqrt{\pi n}}\) เทียบลิมิตกับ \(1/\sqrt n\) ซึ่งลู่ออก

ลู่ออก (พจน์ลดลงช้าเหมือน \(1/\sqrt{n}\))

ตัวทดสอบอนุกรมแบบโต้ตอบ พื้นฐาน

เลือกอนุกรมมาตรฐานเพื่อดูเหตุผลเต็ม หรือพิมพ์ \(a_n\) เองเพื่อดูอัตราส่วน รากที่ n และผลบวกย่อย (หลักฐานเชิงตัวเลข ไม่ใช่บทพิสูจน์)

เกมฝึกเลือกการทดสอบ กลาง

40 อนุกรมจากง่ายไปยาก รวมกับดักที่เจอในข้อสอบจริง เช่น \(\sum 1/n^{1+1/n}\) และ \(\sum (1 + 1/n)^n\) เลือกการทดสอบและผลสรุปแล้วกดตรวจ

แบบฝึกหัดผสม (ซ่อนเฉลย) กลาง

1\(\displaystyle\sum_{n=1}^{\infty}\frac{n^2+2}{n^4+1}\)

เทียบลิมิตกับ \(1/n^2\): \(\lim\dfrac{n^4 + 2n^2}{n^4+1} = 1\) ⇒ ลู่เข้า

2\(\displaystyle\sum_{n=1}^{\infty}\frac{5^n}{n!}\)

อัตราส่วน \(\dfrac{5}{n+1} \to 0\) ⇒ ลู่เข้า (ผลบวก \(e^5 - 1\))

3\(\displaystyle\sum_{n=2}^{\infty}\frac{n}{\ln n}\)

\(\dfrac{n}{\ln n} \to \infty \ne 0\) ⇒ ลู่ออก ด้วยพจน์ที่ n

4\(\displaystyle\sum_{n=1}^{\infty}\left(\frac{n}{n+1}\right)^{n^2}\)

ราก: \(\left(\dfrac{n}{n+1}\right)^{n} \to \dfrac1e < 1\) ⇒ ลู่เข้า

5\(\displaystyle\sum_{n=1}^{\infty}\frac{\arctan n}{n^2}\)

\(0 < \arctan n < \tfrac{\pi}{2}\) ⇒ \(a_n < \dfrac{\pi/2}{n^2}\) ⇒ ลู่เข้า (เปรียบเทียบตรง)

6\(\displaystyle\sum_{n=1}^{\infty}\frac{2^n\,n!}{n^n}\)

อัตราส่วน \(2\left(\dfrac{n}{n+1}\right)^n \to \dfrac2e \approx 0.736 < 1\) ⇒ ลู่เข้า (ถ้าเปลี่ยน 2 เป็น 3 จะได้ 3/e > 1 ลู่ออก)

7\(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^{1.01}}\) เทียบกับ \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n\cdot 1.01}\)

ตัวแรกเป็นอนุกรม p ที่ \(p = 1.01 > 1\) ลู่เข้า · ตัวที่สองคือ \(\tfrac{1}{1.01}\sum\tfrac1n\) ลู่ออก ระวังอ่านโจทย์

8\(\displaystyle\sum_{n=1}^{\infty}\frac{1}{3^n - n}\)

เทียบลิมิตกับ \(1/3^n\): \(\lim\dfrac{3^n}{3^n - n} = 1\) ⇒ ลู่เข้า (เปรียบเทียบตรงใช้ไม่ได้ทันทีเพราะ \(\tfrac{1}{3^n - n} > \tfrac{1}{3^n}\))
