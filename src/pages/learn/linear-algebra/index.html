// บทที่ 7 · คณิตศาสตร์วิศวกรรม · Linear Algebra

พีชคณิตเชิงเส้น (Linear Algebra): เมทริกซ์ ดีเทอร์มิแนนต์ อินเวอร์ส คราเมอร์ และค่าเฉพาะ

พื้นฐานที่วิศวกรไฟฟ้าใช้ทุกวันโดยไม่รู้ตัว ตั้งแต่แก้กระแสในวงจรหลายลูป ไปจนถึงหาขั้วของระบบควบคุมและวิเคราะห์ฟอลต์ในระบบสามเฟส ชุดบทเรียนนี้มี 9 หน้า ไล่จากระดับ ม.ปลาย ถึงระดับบัณฑิตศึกษา รวมหน้าการประยุกต์ในงานไฟฟ้า เครื่องกล โยธา และแล็บเมทริกซ์ ทุกสูตรมีรหัสอ้างอิงถาวร ค้นได้ทั้งหมดจากหน้านี้ และมีเครื่องคิดเลขที่แสดงวิธีทำทีละขั้นให้ตรวจการบ้านของตัวเอง

เขียนโดย อาจารย์มดอัปเดต
ค้นหาสูตรทั้งหมด แล็บเมทริกซ์ งงตรงไหน เริ่มตามระดับ
ทั้งบทในหนึ่งนาที
  • ระบบสมการหลายตัวแปรเขียนสั้น ๆ ได้เป็น \(A\mathbf x = \mathbf b\) เมทริกซ์
  • \(\det A \ne 0\) บอกว่ามีคำตอบเดียว ดีเทอร์มิแนนต์ หาคำตอบด้วย การลดแถว อินเวอร์ส หรือ คราเมอร์
  • \(A\mathbf v = \lambda\mathbf v\) หาทิศพิเศษที่ไม่ถูกหมุน ซึ่งคือขั้วและโหมดของวงจร ค่าเฉพาะ
  • ทุกเครื่องมือมาบรรจบที่การวิเคราะห์วงจรและระบบ ประยุกต์ในงานไฟฟ้า และงานเครื่องกล-โยธา โครงถัก โหมดการสั่น

เริ่มตามระดับของคุณ

ค้นหาสูตรทั้งหมดในที่เดียว

รวมทุกสูตรจากทุกหน้า พิมพ์ได้ทั้งภาษาไทยและอังกฤษ หรือพิมพ์รหัสสูตรตรง ๆ เช่น D4 กดที่ชื่อสูตรเพื่อไปยังคำอธิบายและตัวอย่างวิธีทำของสูตรนั้น

แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ

เครื่องคิดเลขเมทริกซ์ 2×2 ถึง 4×4 ที่แสดงวิธีทำแบบเศษส่วนแม่นตรง ตัวช่วยดูการคูณทีละช่อง และแล็บลากเมทริกซ์ 2×2 ย้ายไปอยู่รวมกันในหน้าแล็บเมทริกซ์ แล้ว พร้อมโจทย์ตัวอย่างจากงานวงจร ระบบไฟฟ้ากำลัง การสั่น และโครงสร้าง กดครั้งเดียวใส่ให้ทันที

เปิดแล็บเมทริกซ์ →ดูงานไฟฟ้า เครื่องกล โยธา

งงตรงไหน คลิกตรงนั้น

อาการที่นักศึกษาเจอบ่อยที่สุด พร้อมทางแก้ กดแล้วไปที่คำอธิบายนั้นทันที

คูณเมทริกซ์ไม่ได้ หรือได้ขนาดแปลก ๆเช็กขนาด ตัวเลขด้านในต้องเท่ากัน → M10 ทำไม AB ≠ BA ทำไมตัดเมทริกซ์ไม่ได้สิ่งที่ใช้กับตัวเลขได้ แต่เมทริกซ์ไม่ได้ → M12 det(2A) ทำไมไม่ใช่ 2 det Aดึงตัวคูณได้ทีละแถว จึงได้ kⁿ → D7 กระจายโคแฟกเตอร์แล้วเครื่องหมายเพี้ยนเครื่องหมายแบบกระดานหมากรุก → D3 ลดแถวแล้วเจอ [0 0 0 | 5]ระบบไม่มีคำตอบ → L6 ลดแถวแล้วได้แถวศูนย์ทั้งแถว ตอบอย่างไรคำตอบไม่จำกัด เขียนแบบพารามิเตอร์ → L12 อินเวอร์สแบบแอดจอยต์ไม่ตรงเฉลยลืมทรานสโพสเมทริกซ์โคแฟกเตอร์ → I3 (AB)⁻¹ ต้องสลับลำดับไหมสลับเสมอ: B⁻¹A⁻¹ → I5 Δ = 0 แล้วคราเมอร์ใช้ไม่ได้ต้องลดแถวตรวจ ห้ามสรุปจาก 0/0 → C5 ลดแถว A − λI แล้วไม่มีแถวศูนย์ค่า λ ผิด กลับไปตรวจสมการลักษณะเฉพาะ → E2 เวกเตอร์เฉพาะไม่ตรงเฉลยคูณค่าคงที่ได้ ตรวจ Av = λv → E1 เขียนเมทริกซ์จากวงจรไม่ถูกกฎการมอง: ทแยง = ผลรวม นอกทแยง = ลบตัวร่วม → A1
