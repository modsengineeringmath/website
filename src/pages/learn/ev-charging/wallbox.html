ชาร์จเร็วที่บ้านด้วยวอลล์บ็อกซ์ (Mode 3): 7.4 / 11 / 22 kW, Control Pilot PWM, Proximity และการเลือกเครื่อง

วอลล์บ็อกซ์คือวิธีชาร์จที่บ้านซึ่งเร็วและปลอดภัยที่สุด เพราะต่อตายตัวกับวงจรเฉพาะ ไม่มีปลั๊กที่หลวมได้ และสื่อสารกับรถตลอดเวลา สิ่งที่น่าทึ่งคือ “ภาษา” ระหว่างเครื่องชาร์จกับรถใช้แค่ไฟสัญญาณเส้นเดียว ตัวต้านทานสองสามตัว และไดโอดหนึ่งตัว — หน้านี้แกะวงจรนั้นทีละขั้น พร้อมแล็บให้ลองเปลี่ยนสถานะเอง

ข้างในวอลล์บ็อกซ์ พื้นฐาน

  • คอนแทกเตอร์ สวิตช์กำลังที่ต่อ L (และ N) เข้าหัวชาร์จเมื่อได้สถานะ C เท่านั้น — ไม่มีไฟที่ขาหัวชาร์จขณะถือหัวไว้ในมือ
  • ตรวจจับไฟรั่ว AC 30 mA และ DC 6 mA (RDC-DD) หรือใช้ RCD Type B ที่ตู้ไฟ — ความปลอดภัย
  • ไมโครคอนโทรลเลอร์ + วงจร CP สร้าง PWM ±12 V และวัดแรงดันตอบกลับ
  • มิเตอร์ในตัว นับ kWh (รุ่นที่ใช้คิดเงินต้องมี MID/มาตรวิทยา)
  • ตรวจหน้าสัมผัสคอนแทกเตอร์ติด (welding detection) และตรวจอุณหภูมิขั้วต่อ
  • การสื่อสาร Wi-Fi/Ethernet/4G โปรโตคอล OCPP สำหรับแอปตั้งเวลาและจัดการโหลด

สัญญาณ Control Pilot: ภาษาของเครื่องชาร์จกับรถ กลาง

W2 Duty cycle → maximum current duty cycle บอกกระแสสูงสุด (IEC 61851-1 / SAE J1772)

\[ I_{max} = 0.6\,D \quad (10\,\% \le D \le 85\,\%) \qquad I_{max} = 2.5\,(D-64) \quad (85\,\% < D \le 96\,\%) \]

W3 Current → duty cycle ต้องการกระแสนี้ ตั้ง duty เท่าไร

\[ D = \frac{I}{0.6}\ \ (6 \le I \le 51\ \text{A}) \qquad D = \frac{I}{2.5}+64\ \ (51 < I \le 80\ \text{A}) \]

duty 5 % มีความหมายพิเศษ: “คุยกันแบบดิจิทัล” ตาม ISO 15118 (สัญญาณสื่อสารซ้อนบนสาย CP) ใช้กับตู้ DC และระบบ Plug & Charge ส่วน duty ต่ำกว่า 8 % (ยกเว้น 5 %) หรือสูงกว่า 97 % หมายถึงห้ามชาร์จ

W4 Pilot voltage seen by the EVSE แรงดันที่เครื่องชาร์จวัดได้ (ครึ่งบวกของ PWM)

\[ V_{CP} = V_D + (12 - V_D)\,\frac{R_{car}}{R_{car} + 1\ \text{k}\Omega} \qquad V_D \approx 0.7\ \text{V} \]
สถานะ\(V_{CP}\) ครึ่งบวกฝั่งรถความหมาย
A+12 V (ไม่มี PWM)ไม่ได้ต่อยังไม่เสียบ
B+9 VR2 2.74 kΩเสียบแล้ว รถยังไม่ขอไฟ (เครื่องชาร์จเริ่ม PWM)
C+6 VR2 ∥ R3 = 882 Ωรถขอชาร์จ → คอนแทกเตอร์ต่อ
D+3 VR2 ∥ 270 Ωชาร์จและต้องการระบายอากาศ
E0 V—ไฟเครื่องชาร์จดับหรือ CP ลัดลงดิน
F−12 V—เครื่องชาร์จขัดข้อง

ครึ่งลบของ PWM ต้องอยู่ที่ −12 V เสมอ ไดโอดในรถทำให้ฝั่งรถไม่ดึงกระแสในครึ่งลบ เครื่องชาร์จจึงใช้ครึ่งลบตรวจว่ามีรถจริง (ไม่ใช่ตัวต้านทานลัดลงดิน)

ตัวอย่าง W-1

ตรวจแรงดัน CP สถานะ B และ C

  1. สถานะ B: W4 \(V = 0.7 + 11.3 \times \dfrac{2740}{3740} = 0.7 + 8.28 = 8.98\ \text{V} \approx 9\ \text{V}\) ✓

  2. สถานะ C: \(R_{car} = \dfrac{2740 \times 1300}{2740 + 1300} = 882\ \Omega\) → \(V = 0.7 + 11.3 \times \dfrac{882}{1882} = 6.0\ \text{V}\) ✓

  3. นี่คือเหตุผลที่ค่าตัวต้านทานในมาตรฐานเป็นเลขแปลก ๆ อย่าง 2.74 kΩ — ออกแบบให้แรงดันออกมาเป็น 9 V และ 6 V พอดีเมื่อรวมไดโอด

ตัวอย่าง W-2

ตั้งวอลล์บ็อกซ์ที่ 32 A 16 A และ 65 A

  1. W3: 32 A → \(D = 32/0.6 = 53.3\,\%\) ความกว้างพัลส์ 533 µs ในคาบ 1 ms

  2. 16 A → \(D = 26.7\,\%\) · 6 A (ต่ำสุด) → \(D = 10\,\%\)

  3. 65 A เกิน 51 A ใช้ช่วงที่สอง: \(D = 65/2.5 + 64 = 90\,\%\) ตรวจกลับด้วย W2: \(2.5(90-64) = 65\ \text{A}\) ✓

Proximity Pilot: สายบอกพิกัดของตัวเอง กลาง

W5 Current actually drawn กระแสที่รถดึงจริง

\[ I_{EV} = \min\!\left(I_{PWM},\ I_{PP},\ I_{OBC}\right) \qquad R_{PP}:\ 1.5\,\text{k}\Omega{=}13\,\text{A},\ 680\,\Omega{=}20\,\text{A},\ 220\,\Omega{=}32\,\text{A},\ 100\,\Omega{=}63\,\text{A} \]

ในหัว Type 2 มีตัวต้านทานระหว่างขา PP กับ PE ค่าของมันบอกพิกัดกระแสของสายเส้นนั้น เครื่องชาร์จแบบมีเต้ารับ (untethered) อ่านค่านี้แล้วจำกัดกระแส ป้องกันการใช้สาย 13 A กับเครื่อง 32 A ลองเปลี่ยนสายในแล็บด้านล่าง

แล็บ Control Pilot: ลองเปลี่ยนสถานะ กระแส และสาย

Dynamic load balancing: ไม่ให้เมนทริปเมื่อเปิดแอร์ กลาง

ระบบจัดการโหลดใช้ CT คล้องสายเมนหลังมิเตอร์ วัดกระแสที่บ้านใช้ทุกวินาที แล้วสั่งวอลล์บ็อกซ์เปลี่ยน duty cycle ทันที รถจะลดกระแสตามภายในไม่กี่วินาที (มาตรฐานกำหนดให้รถตอบสนองภายใน 5 วินาที)

W6 Dynamic load balancing กระแสที่อนุญาตให้รถ

\[ I_{EV}(t) = \min\!\Big(I_{set},\ \max\!\big(0,\ I_{main} - I_{house}(t) - I_{margin}\big)\Big) \qquad I_{EV} < 6\ \text{A} \Rightarrow \text{หยุดชั่วคราว} \]
ตัวอย่าง W-3

เมน 63 A บ้านใช้ 40 A ตอนหัวค่ำ

  1. ตั้งเผื่อ \(I_{margin} = 5\) A → W6: \(I_{EV} = \min(32,\ 63 - 40 - 5) = 18\ \text{A}\)

  2. W3: วอลล์บ็อกซ์ส่ง duty \(18/0.6 = 30\,\%\) → รถชาร์จ \(230 \times 18 = 4.1\) kW

  3. สี่ทุ่ม แอร์ห้องนั่งเล่นปิดและครัวเลิกใช้ บ้านเหลือ 6 A → \(I_{EV} = \min(32, 52) = 32\) A ชาร์จเต็ม 7.4 kW

  4. ผล: ไม่ต้องขยายมิเตอร์จาก 30(100) A หรือเปลี่ยนเป็น 3 เฟส และยังชาร์จเต็มในคืนเดียว

ระบบเดียวกันใช้กับ การชาร์จจากโซลาร์ส่วนเกิน: CT วัดกระแสที่กำลังไหลออกกริด แล้วตั้ง \(I_{EV}\) ให้เท่ากับส่วนเกินนั้น อ่านที่ โซลาร์ + แอร์ + รถ

ไฟ 3 เฟสกับรถ OBC เฟสเดียว: ปัญหาเฟสไม่สมดุล ขั้นสูง

บ้าน 3 เฟสที่ใช้รถ OBC เฟสเดียว 32 A จะดึงกระแส 32 A ที่เฟสเดียว เพิ่มความไม่สมดุลระหว่างเฟสและกระแสในสายนิวทรัล การไฟฟ้าบางแห่งจำกัดกระแสไม่สมดุลต่อจุดต่อไฟ ควรเลือกเฟสที่มีโหลดน้อยให้วอลล์บ็อกซ์ หรือใช้วอลล์บ็อกซ์ที่สลับเฟสอัตโนมัติ (phase switching) ซึ่งมีประโยชน์กับการชาร์จจากโซลาร์ด้วย: เมื่อโซลาร์เกินน้อยใช้ 1 เฟส 6 A (1.4 kW) ต่ำสุด เมื่อเกินมากสลับเป็น 3 เฟส (ต่ำสุด 4.1 kW) — ความเข้าใจเรื่ององค์ประกอบสมมาตรช่วยอธิบายผลของความไม่สมดุลนี้ (องค์ประกอบสมมาตร)
