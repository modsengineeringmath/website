// บทที่ 22.8 · PLC · Analog, PID & VFD

อนาล็อก PID และการสั่งงานอินเวอร์เตอร์ด้วย PLC: สเกล 4–20 mA บล็อก PID ปั๊มแรงดันคงที่ และ Modbus RTU

โลกจริงไม่ได้มีแค่ 0 กับ 1: ความดัน ระดับ อุณหภูมิ และความเร็วมอเตอร์เป็นค่าต่อเนื่อง หน้านี้พาจากตัวเลขดิบในโมดูลแอนะล็อกไปสู่ลูปควบคุมความดันที่สั่งอินเวอร์เตอร์ ซึ่งเป็นงานที่พบมากที่สุดในอาคารและโรงงาน

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • สเกล: \(y = y_{min} + (x - x_{min})(y_{max} - y_{min})/(x_{max} - x_{min})\) คำนวณเป็น REAL
  • ต่ำกว่า 3.6 mA หรือเกิน 21 mA = ความผิดพลาด ไม่ใช่ค่าวัด
  • PID: \(u = K_p\left(e + \frac{1}{T_i}\int e\,dt + T_d\frac{de}{dt}\right)\) · เริ่มจูนด้วย PI
  • สั่ง VFD: DI + AI ง่ายที่สุด · Modbus ได้ข้อมูลกลับ (กระแส ความผิดพลาด) ด้วยสายคู่เดียว

จากค่าดิบสู่หน่วยวิศวกรรม พื้นฐาน

P1 Linear scaling สเกลเชิงเส้น

\[ y = y_{min} + (x - x_{min})\,\frac{y_{max} - y_{min}}{x_{max} - x_{min}} \]

P2 Resolution ความละเอียดต่อหนึ่งหน่วยดิบ

\[ \Delta y = \frac{y_{max} - y_{min}}{x_{max} - x_{min}} \qquad \text{เช่น } \frac{10\ \text{bar}}{27648} = 0.36\ \text{mbar} \]

P3 Signal validity (NAMUR NE 43) ตรวจความถูกต้องของสัญญาณ

\[ 3.8 \le I \le 20.5\ \text{mA ค่าวัดเชื่อได้} \qquad I \le 3.6 \text{ หรือ } I \ge 21\ \text{mA → ความผิดพลาด} \]
ตัวอย่าง P-1

สเกลค่าดิบ 13824 ด้วย INT แล้วเกิดศูนย์

  1. ผิด: Bar := Raw / 27648 * 10; ใช้ INT → 13824/27648 = 0 (ปัดทิ้ง) → 0 bar

  2. ผิดอีกแบบ: Raw * 10 / 27648 ด้วย INT → 27648 × 10 = 276480 ล้น INT

  3. ถูก: Bar := INT_TO_REAL(Raw) * 10.0 / 27648.0; → 5.0 bar

  4. ตรวจ P3: โมดูล Siemens ให้ค่าดิบติดลบเมื่อกระแสต่ำกว่า 4 mA (ลงไปถึง −4864 ≈ 1.185 mA) และเมื่อเปิดการวินิจฉัยสายขาดจะรายงานค่าพิเศษ (32767) — ตรวจทั้งช่วงค่าดิบตาม P3 และบิตสถานะของโมดูล

บล็อก PID ใน PLC กลาง

P4 PID (standard form) PID แบบมาตรฐาน

\[ u(t) = K_p\left(e + \frac{1}{T_i}\int_0^t e\,d\tau + T_d\,\frac{de}{dt}\right) \qquad e = SP - PV \]

P5 Discrete PID PID ดิจิทัล (คาบสุ่ม \(T_s\))

\[ u_k = K_p\left(e_k + \frac{T_s}{T_i}\sum_{j=0}^{k} e_j - \frac{T_d}{T_s}(PV_k - PV_{k-1})\right) \]

เทอมอนุพันธ์ใช้ PV แทน e (derivative on measurement) เพื่อไม่ให้กระชากเมื่อเปลี่ยน SP และต้องมี anti-windup: เมื่อเอาต์พุตชนขีด (เช่น 50 Hz) ให้หยุดสะสมอินทิกรัล งานปั๊ม-พัดลมส่วนใหญ่ใช้แค่ PI (Td = 0) เพราะสัญญาณความดันมีสัญญาณรบกวนมาก

จูนเริ่มต้นสำหรับปั๊มแรงดันคงที่

  1. เริ่ม Kp เล็ก (เช่น 0.5 ของสเกลเต็ม) Ti ยาว (เช่น 5 s) Td = 0
  2. เพิ่ม Kp จนเริ่มแกว่ง แล้วลดลงครึ่งหนึ่ง
  3. ลด Ti ทีละน้อยจนค่ากลับเข้าเป้าเร็วพอโดยไม่แกว่ง (ปกติ 1–5 s สำหรับความดันน้ำ)
  4. ทดสอบด้วยการเปิด-ปิดก๊อกจริง ดูทั้งการตกและการพุ่งเกิน

ทดลองผลของ Kp Ti Td ได้ใน แล็บ PID และลูปความดันกับปั๊ม VFD ใน แล็บวัดคุมเสมือน

ตัวอย่าง P-2

PLC ส่ง 4–20 mA ให้ VFD ช่วง 20–50 Hz ต้องการ 42 Hz

  1. กลับสูตร P1: \(I = 4 + 16\,(42 - 20)/(50 - 20) = 4 + 11.73 = 15.73\) mA

  2. ถ้าเอาต์พุตแอนะล็อก 0–27648 = 4–20 mA: ค่าดิบ \(= 27648 \times 11.73/16 = 20275\)

  3. ตั้งไดรฟ์ให้ตรวจ AI ต่ำกว่า 2 mA ว่าสายขาด และเลือกการตอบสนอง (หยุด/ความเร็วสำรอง)
