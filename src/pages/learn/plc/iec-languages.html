// บทที่ 22.5 · PLC · IEC 61131-3 Languages

ภาษาโปรแกรม PLC ตาม IEC 61131-3: LD FBD ST SFC และ IL — โปรแกรมเดียวกันในหลายภาษา ชนิดข้อมูล และการเลือกใช้

IEC 61131-3 กำหนดห้าภาษาให้ PLC ทุกยี่ห้อ เพื่อให้คนที่เรียนจากยี่ห้อหนึ่งอ่านอีกยี่ห้อได้ หน้านี้เขียนงานเดียวกัน — มอเตอร์ล็อกตัวเองพร้อมแตรเตือน 5 วินาที — ในทุกภาษา ให้เห็นว่าแต่ละภาษาถนัดอะไร

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • LD: ตรรกะบิต อ่านเหมือนวงจรรีเลย์ · FBD: บล็อกต่อสาย เหมาะงานกระบวนการ
  • ST: ภาษาข้อความแบบ Pascal เหมาะคำนวณ ลูป ข้อมูล สเตตแมชชีน
  • SFC: ขั้นและเงื่อนไข เหมาะงานลำดับ · IL: ถูกยกเลิกในฉบับ 2013
  • FUNCTION ไม่มีหน่วยความจำ · FUNCTION_BLOCK มีหน่วยความจำ (ไทเมอร์ PID)

โจทย์เดียว ห้าภาษา พื้นฐาน

อินพุต: STOP (NC) START · เอาต์พุต: แตร (Horn) สายพาน (Conveyor) · กด START แล้วแตรดัง 5 s จากนั้นสายพานเดิน กด STOP หยุดทั้งหมด

Structured Text (ST)

VAR
    Run      : BOOL;
    T1       : TON;
END_VAR

Run := (PB_Start OR Run) AND PB_Stop_NC;      // ล็อกตัวเอง
T1(IN := Run, PT := T#5S);                       // เรียกอินสแตนซ์ไทเมอร์ทุกสแกน
Horn     := Run AND NOT T1.Q;
Conveyor := T1.Q;

Instruction List (IL) — ภาษาที่ถูกยกเลิก

LD   PB_Start
OR   Run
AND  PB_Stop_NC
ST   Run

IL คล้ายภาษาแอสเซมบลี ถูกตัดออกจาก IEC 61131-3 ฉบับที่ 3 (2013) แต่ยังพบในโปรแกรมเก่า (Siemens STL, Mitsubishi List)

ชนิดข้อมูลและค่าคงที่ กลาง

ชนิดขนาดช่วงค่าใช้กับ
BOOL1 บิตFALSE / TRUEI/O ดิจิทัล สถานะ
INT16 บิต−32 768 … 32 767ค่าดิบแอนะล็อก ตัวนับ
DINT32 บิต−2 147 483 648 … 2 147 483 647ตัวนับใหญ่ ตำแหน่งเอนโค้ดเดอร์
REAL32 บิต IEEE 754~7 หลักนัยสำคัญค่าทางวิศวกรรม PID
TIME32 บิต (ms)T#0ms … T#24d20h…ค่าตั้งไทเมอร์
WORD / DWORD16 / 32 บิตบิตแพทเทิร์นสถานะหลายบิต รีจิสเตอร์ Modbus

L1 Signed integer range ช่วงค่าจำนวนเต็มแบบมีเครื่องหมาย

\[ -2^{n-1} \le x \le 2^{n-1} - 1 \qquad n = 16 \Rightarrow -32768 \ldots 32767 \]

L2 Integer pitfalls in scaling กับดักการคำนวณจำนวนเต็ม

\[ \frac{27648 \times 10}{27648} \;\text{(ล้น INT ที่ขั้นคูณ)} \qquad \frac{13824}{27648}\times 10 = 0 \;\text{(หารปัดทิ้งก่อนคูณ)} \]

วิธีหลีกเลี่ยง: แปลงเป็น REAL ก่อนคำนวณ (INT_TO_REAL) หรือใช้ DINT และคูณก่อนหาร — ตัวอย่างการสเกลอยู่ใน อนาล็อก · PID

สร้างฟังก์ชันบล็อกมอเตอร์ใช้ซ้ำ ขั้นสูง

โรงงานที่มีมอเตอร์ 50 ตัว ไม่ควรเขียนวงจรล็อกตัวเอง ตรวจป้อนกลับ และนับชั่วโมงซ้ำ 50 ครั้ง สร้าง FB หนึ่งตัวแล้วเรียก 50 อินสแตนซ์

FUNCTION_BLOCK FB_Motor
VAR_INPUT  Start, Stop_NC, OL_NC, Feedback : BOOL; FbTime : TIME := T#2S; END_VAR
VAR_OUTPUT Run, Fault : BOOL; Hours : REAL; END_VAR
VAR Cmd : BOOL; TFb : TON; THr : TON; END_VAR

Cmd := (Start OR Cmd) AND Stop_NC AND OL_NC AND NOT Fault;
TFb(IN := Cmd XOR Feedback, PT := FbTime);   // สั่งแล้วไม่มีป้อนกลับ หรือไม่สั่งแต่มีป้อนกลับ
IF TFb.Q THEN Fault := TRUE; END_IF          // รีเซ็ต Fault จาก HMI
Run := Cmd;
THr(IN := Feedback AND NOT THr.Q, PT := T#36S);  // พัลส์ทุก 0.01 ชม.
IF THr.Q THEN Hours := Hours + 0.01; END_IF
END_FUNCTION_BLOCK
