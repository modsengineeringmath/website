แลดเดอร์ไดอะแกรมพื้นฐาน: หน้าสัมผัส NO NC คอยล์ AND OR ล็อกตัวเอง SET RESET ขอบสัญญาณ และพีชคณิตบูลีน

แลดเดอร์ถูกออกแบบให้ช่างไฟที่อ่านวงจรรีเลย์เป็นอ่านโปรแกรมได้ทันที รางซ้ายคือ “ไฟบวก” รางขวาคือ “ศูนย์” แต่ละขั้นบันได (rung) คือเส้นทางที่ไฟจะไหลถึงคอยล์ได้ถ้าหน้าสัมผัสปิดครบ สิ่งเดียวที่ต้องเปลี่ยนความคิดคือ หน้าสัมผัสในโปรแกรมตรวจ ค่าบิต ไม่ใช่ตรวจปุ่ม

  • อนุกรม AND · ขนาน OR · NC NOT · ทุกรังคือสมการบูลีนหนึ่งสมการ

  • คอยล์หนึ่งตัวเขียนได้ที่เดียว · ขอบสัญญาณ P/N นำกระแสหนึ่งสแกน

B4 De Morgan ทฤษฎีเดอมอร์แกน

\[ \overline{A\cdot B} = \overline{A} + \overline{B} \qquad \overline{A + B} = \overline{A}\cdot\overline{B} \]

B4 ใช้ทุกครั้งที่ต้องการ “ไม่ใช่ทั้งคู่” ในแลดเดอร์ เพราะแลดเดอร์พื้นฐานไม่มี NOT หน้าวงเล็บ ซิมูเลเตอร์ในหน้านี้ใช้กฎนี้แปลงสมการเป็นหน้าสัมผัส NO/NC ให้อัตโนมัติ

B5 XOR เอกซ์คลูซีฟ-ออร์ (สวิตช์สองทาง)

\[ Y = A\overline{B} + \overline{A}B \]

ปุ่ม STOP ที่ต่อ NC กับหน้าสัมผัสในโปรแกรม พื้นฐาน

B6 Motor latch in a PLC รังล็อกตัวเองใน PLC

\[ Q0.0 = I0.0_{(\text{STOP, NC})}\cdot(I0.1_{(\text{START})} + Q0.0)\cdot I0.2_{(\text{OL 95-96, NC})} \]

ในซิมูเลเตอร์ อินพุตที่มีกรอบประคือปุ่ม NC: ไฟสีเขียวที่ I0.0 ติดอยู่แล้วโดยไม่ต้องกด ลองกด START แล้ว STOP และกดปุ่มโอเวอร์โหลดเพื่อจำลองการทริป

SET RESET และขอบสัญญาณ กลาง

คอยล์ SET (─(S)─) ทำให้บิตเป็น 1 เมื่อรังเป็นจริง และ คงค่าไว้ แม้รังจะเป็นเท็จ คอยล์ RESET (─(R)─) ทำให้เป็น 0 ใช้คู่กันแทนวงจรล็อกตัวเอง หน้าสัมผัสขอบขาขึ้น P (rising edge) นำกระแสเพียงหนึ่งสแกนตอนบิตเปลี่ยน 0→1 ขอบขาลง N นำหนึ่งสแกนตอน 1→0 ใช้นับครั้ง สลับสถานะ หรือสั่งงานครั้งเดียวต่อการกด

B7 Set/Reset with reset priority SET/RESET แบบ RESET มาก่อน (รัง R อยู่ล่าง)

\[ Q_{k+1} = (S + Q_k)\cdot\overline{R} \]

B8 Rising edge (one-shot) ขอบขาขึ้น

\[ P(A)_k = A_k\cdot\overline{A_{k-1}} \qquad N(A)_k = \overline{A_k}\cdot A_{k-1} \]
ตัวอย่าง B-1

ปุ่มเดียวกดติด กดดับ (toggle / flip-flop)

  1. สร้างพัลส์หนึ่งสแกน: \(M0.1 = P(I0.0)\)

  2. ถ้ายังดับอยู่ให้ติด: \(S\ M0.2 = M0.1\cdot\overline{Q0.1}\) · ถ้าติดอยู่ให้ดับ: \(R\ M0.2 = M0.1\cdot Q0.1\)

  3. \(Q0.1 = M0.2\) — สังเกตว่าเงื่อนไขทั้งสองอ่าน Q0.1 ค่าเดิมของสแกนก่อน จึงไม่ติดแล้วดับในสแกนเดียว ลองในซิมูเลเตอร์ตัวอย่าง “SET/RESET และขอบสัญญาณ”

กฎการเขียนที่ป้องกันบั๊ก กลาง

  • คอยล์หนึ่งตัวเขียนที่เดียว — ถ้าเขียนสองรัง รังล่างทับรังบน (double coil)
  • ใช้หน่วยความจำภายใน (M) เป็นตัวกลาง แล้วค่อยเขียนเอาต์พุตจริง (Q) ที่ท้ายโปรแกรม ทำให้ดูแลง่าย
  • ตั้งชื่อสัญลักษณ์ (tag) ทุกบิต เช่น M1_Run PB_Stop_NC ไม่ใช้แอดเดรสเปล่า
  • เขียนคอมเมนต์ทุกรังว่า “ทำไม” ไม่ใช่ “ทำอะไร” (แลดเดอร์บอกอยู่แล้วว่าทำอะไร)
  • เงื่อนไขความปลอดภัย (STOP, OL, E-stop status) วางซ้ายสุดของรัง อ่านเจอก่อน
