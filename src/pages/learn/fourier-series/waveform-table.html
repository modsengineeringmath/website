ตารางอนุกรมฟูเรียร์ของรูปคลื่นในงานไฟฟ้าและอิเล็กทรอนิกส์กำลัง

งานจริงไม่มีเวลาอินทิเกรตใหม่ทุกครั้ง ตารางนี้รวบรวมรูปคลื่นที่วิศวกรไฟฟ้าเจอซ้ำ ๆ พร้อมอนุกรม ค่า RMS THD และ crest factor ทุกสูตรตรวจกับการอินทิเกรตแบบปิดของแล็บในชุดนี้แล้ว เลือกจุด t = 0 ตามที่ระบุในแต่ละการ์ด ถ้าวางต่างไป ใช้สมบัติการเลื่อน (S6) ขนาดเท่าเดิม เปลี่ยนแค่เฟส

เขียนโดย อาจารย์มดอัปเดต
ตารางสรุป พื้นฐาน เรียงกระแส อินเวอร์เตอร์ สวิตชิ่ง
วิธีใช้
  • หาสูตรจากรหัส W ในกล่องค้นหา หรือพิมพ์ชื่อ เช่น six-step, triac, ripple
  • \(A_n\) คือค่ายอดของฮาร์มอนิก ค่า RMS ของฮาร์มอนิก = \(A_n/\sqrt2\)
  • รูปซับซ้อน = ผลรวมของรูปในตาราง (เชิงเส้น C8)
  • ทุกรูปเปิดดูในแล็บได้ทันที เลือกจากรายการรูปคลื่นท้ายหน้า

รูปคลื่นพื้นฐาน: สี่เหลี่ยม พัลส์ สามเหลี่ยม ฟันเลื่อย พื้นฐาน

W1 Square wave ±A สี่เหลี่ยม (ขาขึ้นที่ t = 0)

\[ x(t) = \frac{4A}{\pi}\sum_{n=1,3,5}^{\infty}\frac{\sin n\omega_0 t}{n} \]

RMS = A · \(X_1 = 0.900A\) · THD 48.3 % · ที่มา T-1

W2 Square wave 0 to A (50 %) สี่เหลี่ยมลอจิก

\[ x(t) = \frac{A}{2} + \frac{2A}{\pi}\sum_{n=1,3,5}^{\infty}\frac{\sin n\omega_0 t}{n} \]

= W1 ที่ A/2 บวก DC A/2 (S9) · RMS \(A/\sqrt2\) · นาฬิกา 3.3 V 10 MHz มีฮาร์มอนิกที่ 30, 50 MHz ขนาด 0.70, 0.42 V

W3 Pulse train, duty D พัลส์สูง A กว้าง DT เริ่มที่ t = 0

\[ a_0 = AD,\quad a_n = \frac{A}{n\pi}\sin 2\pi nD,\quad b_n = \frac{A}{n\pi}(1 - \cos 2\pi nD),\quad A_n = \frac{2A}{n\pi}|\sin n\pi D| \]

RMS \(A\sqrt D\) · ไม่มีฮาร์มอนิกที่ \(n = k/D\) · ที่มา T-2 C7

W4 Pulse train, centred at t = 0 พัลส์วางกึ่งกลาง (ฟังก์ชันคู่)

\[ x(t) = AD + \sum_{n=1}^{\infty}\frac{2A}{n\pi}\sin(n\pi D)\cos n\omega_0 t \]

ขนาดเท่า W3 ทุกตัว แต่เป็นโคไซน์ล้วน สะดวกเมื่อคูณกับฟังก์ชันคู่อื่น

W5 Triangle wave ±A สามเหลี่ยม (ขาขึ้นผ่าน 0 ที่ t = 0)

\[ x(t) = \frac{8A}{\pi^2}\sum_{n=1,3,5}^{\infty}\frac{(-1)^{(n-1)/2}}{n^2}\sin n\omega_0 t \]

RMS \(A/\sqrt3\) · THD 12.1 % · CF 1.73 · ที่มา S-1

W6 Sawtooth ±A ฟันเลื่อย (ผ่าน 0 ขาขึ้นที่ t = 0)

\[ x(t) = \frac{2A}{\pi}\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin n\omega_0 t \]

RMS \(A/\sqrt3\) · THD 80.3 % · มีทั้งคู่และคี่ · ที่มา T-3

วงจรเรียงกระแสและโหลดไม่เชิงเส้น กลาง

W7 Half-wave rectified sine ไซน์เรียงกระแสครึ่งคลื่น

\[ v = \frac{V_m}{\pi} + \frac{V_m}{2}\sin\omega_0 t - \frac{2V_m}{\pi}\sum_{n=2,4,6}^{\infty}\frac{\cos n\omega_0 t}{n^2 - 1} \]

RMS \(V_m/2\) · DC \(0.318V_m\) · THD (ไม่นับ DC) 43.5 % · ที่มา T-4

W8 Full-wave rectified sine ไซน์เรียงกระแสเต็มคลื่น (ω₀ = ความถี่แหล่งจ่าย)

\[ v = \frac{2V_m}{\pi} - \frac{4V_m}{\pi}\sum_{n=2,4,6}^{\infty}\frac{\cos n\omega_0 t}{n^2 - 1} \]

DC \(0.637V_m\) · ฮาร์มอนิกที่ 2 (100 Hz) \(0.424V_m\) · RMS ริปเปิล/DC = 48.3 % (ripple factor)

W12 6-pulse rectifier line current (ideal) กระแสไลน์ของบริดจ์ 3 เฟส (I_d เรียบ, วางกึ่งกลางบล็อกที่ t = 0)

\[ i_a = \frac{2\sqrt3 I_d}{\pi}\Big[\cos\omega t - \tfrac15\cos5\omega t + \tfrac17\cos7\omega t - \tfrac1{11}\cos11\omega t + \tfrac1{13}\cos13\omega t - \cdots\Big] \]

\(I_1 = \frac{\sqrt6}{\pi}I_d = 0.780I_d\) (RMS) · \(I_h = I_1/h\) · RMS \(\sqrt{2/3}\,I_d = 0.816I_d\) · THD 31.1 % · รายละเอียดและผลของช่วงทับซ้อนที่ R7

W15 Phase-controlled (TRIAC) current, R load ไตรแอกตัดเฟส \(i = I_m\sin\theta\) เมื่อ \(\alpha \lt \theta \lt \pi\) (และครึ่งลบ)

\[ a_1 = \frac{I_m}{2\pi}(\cos 2\alpha - 1),\quad b_1 = \frac{I_m}{2\pi}\big(2(\pi - \alpha) + \sin 2\alpha\big) \] \[ a_n = \frac{I_m}{\pi}\Big[\frac{\cos(n+1)\alpha - 1}{n+1} - \frac{\cos(n-1)\alpha - 1}{n-1}\Big],\quad b_n = \frac{I_m}{\pi}\Big[\frac{\sin(n+1)\alpha}{n+1} - \frac{\sin(n-1)\alpha}{n-1}\Big]\;\;(n\text{ คี่} \ge 3) \]

\(I_{rms} = I_m\sqrt{\frac{\pi - \alpha}{2\pi} + \frac{\sin 2\alpha}{4\pi}}\) · \(a_1 \ne 0\) → ฮาร์มอนิกหลักล้าหลัง DPF < 1 แม้โหลดเป็นตัวต้านทาน · α = 90°: THD 64 % PF 0.707

W16 Symmetrically clipped sine ไซน์ตัดยอดที่ระดับ \(cA\), \(\theta_c = \sin^{-1}c\)

\[ b_1 = \frac{2A}{\pi}\big(\theta_c + \sin\theta_c\cos\theta_c\big),\quad b_n = \frac{2A}{\pi}\Big[\frac{\sin(n-1)\theta_c}{n-1} - \frac{\sin(n+1)\theta_c}{n+1}\Big] + \frac{4cA}{n\pi}\cos n\theta_c \]

n คี่ (n ≥ 3) · c = 0.7: \(b_1 = 0.812A\), \(b_3 = 0.108A\) THD 13.8 % · ตัดไม่สมมาตรดู S-4

W17 Capacitor-input rectifier current (SMPS without PFC) กระแสของบริดจ์ + ตัวเก็บประจุ

\[ I_3 \approx 0.8\text{–}0.95\,I_1,\quad I_5 \approx 0.6\text{–}0.85\,I_1,\quad I_7 \approx 0.4\text{–}0.7\,I_1,\quad \text{THD} \approx 100\text{–}150\,\% \]

ไม่มีรูปปิด ขึ้นกับ C อิมพีแดนซ์สายและ NTC จำลองในแล็บ (300 W, 220 µF, อิมพีแดนซ์ปลั๊ก 0.35 Ω): 90.8 / 74.3 / 53.7 / 33.0 % ของ \(I_1\) ที่ h = 3, 5, 7, 9 THD 134 % PF 0.59 CF 3.0 R4

อินเวอร์เตอร์ กลาง

W9 Quasi-square (3-level) wave สี่เหลี่ยมสามระดับ มุมศูนย์ α ที่ขอบแต่ละด้าน

\[ x(t) = \frac{4A}{\pi}\sum_{n=1,3,5}^{\infty}\frac{\cos n\alpha}{n}\sin n\omega_0 t \]

RMS \(A\sqrt{1 - 2\alpha/\pi}\) · α = 30° ไม่มี 3, 9, 15 · α = 18° ไม่มี 5 · ที่มา S-2

W10 Six-step inverter, phase voltage แรงดันเฟส (ขั้น \(V_{dc}/3\), \(2V_{dc}/3\))

\[ v_{aN} = \frac{2V_{dc}}{\pi}\Big[\sin\omega t + \tfrac15\sin5\omega t + \tfrac17\sin7\omega t + \tfrac1{11}\sin11\omega t + \cdots\Big] \]

RMS \(\frac{\sqrt2}{3}V_{dc} = 0.471V_{dc}\) · ฮาร์มอนิกหลัก (RMS) \(0.450V_{dc}\) · THD 31.1 %

W11 Six-step inverter, line voltage แรงดันไลน์ = quasi-square α = 30° สูง \(V_{dc}\)

\[ |V_{ab,n}| = \frac{2\sqrt3\,V_{dc}}{n\pi}\;\;(n = 6k\pm1),\qquad V_{ab,1,rms} = \frac{\sqrt6}{\pi}V_{dc} = 0.780V_{dc} \]

RMS \(0.816V_{dc}\) · หน้าตาเดียวกับกระแส 6 พัลส์ (W12) จึงมีสเปกตรัมเดียวกัน

W13 Sinusoidal PWM (bipolar, ±Vdc/2) SPWM แบบไบโพลาร์

\[ V_1 = m_a\frac{V_{dc}}{2}\;(m_a \le 1),\qquad h = j\,m_f \pm k\;\;(j \text{ คี่ → } k \text{ คู่},\; j \text{ คู่ → } k \text{ คี่}) \]

ตารางขนาดไซด์แบนด์และแบบยูนิโพลาร์ที่ V6 · เปิดในแล็บ: “SPWM”

คอนเวอร์เตอร์สวิตชิ่งและ EMI กลาง

W14 Trapezoidal pulse พัลส์คางหมู: ดิวตี้ D (วัดที่ 50 %) เวลาขึ้น = ลง = \(t_r\)

\[ A_n = 2AD\,\big|\mathrm{sinc}(nD)\big|\,\Big|\mathrm{sinc}\Big(\frac{n t_r}{T}\Big)\Big| \]

เอนเวโลปหักมุมที่ \(1/(\pi\tau)\) และ \(1/(\pi t_r)\) · ใช้ประเมิน EMI B9

W18 Asymmetric triangle (inductor ripple) ขึ้นช่วง DT ลงช่วง (1−D)T ยอดถึงยอด ΔI

\[ A_n = \frac{\Delta I\,|\sin n\pi D|}{\pi^2 n^2 D(1 - D)},\qquad I_{ac,rms} = \frac{\Delta I}{\sqrt{12}} \]

D = 0.5 ได้สามเหลี่ยมสมมาตร (W5 ที่ \(A = \Delta I/2\)) · ใช้หาความสูญเสียแกนและทองแดงที่ความถี่สวิตชิ่ง B7

ใช้ตารางแก้โจทย์จริง กลาง

เรกติไฟเออร์ 6 พัลส์กระแส DC 100 A (เรียบ) หากระแสไลน์ RMS ฮาร์มอนิกหลัก ที่ 5, 7, 11, 13 และ THD
