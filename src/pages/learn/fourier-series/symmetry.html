ทางลัดด้วยสมมาตร: ฟังก์ชันคู่ คี่ ครึ่งคลื่น เสี้ยวคลื่น และการเลื่อน

ก่อนอินทิเกรตสักตัว ดูรูปคลื่นสักห้าวินาทีก็บอกได้แล้วว่าพจน์ไหนเป็นศูนย์ และที่สำคัญกว่านั้นในงานไฟฟ้า สมมาตรบอกว่าทำไมระบบไฟปกติมีแต่ฮาร์มอนิกคี่ และเมื่อไรฮาร์มอนิกคู่โผล่มา ซึ่งมักเป็นสัญญาณว่ามีอะไรผิดปกติ

เขียนโดย อาจารย์มดอัปเดต
ตารางตัดสินใจ คู่ · คี่ ครึ่งคลื่น เสี้ยวคลื่น ตัดยอด
สรุปใน 30 วินาที
  • คู่ \(x(-t) = x(t)\) → \(b_n = 0\) · คี่ \(x(-t) = -x(t)\) → \(a_0 = a_n = 0\)
  • ครึ่งคลื่น \(x(t + T/2) = -x(t)\) → ไม่มี DC ไม่มีฮาร์มอนิกคู่ (ระบบไฟปกติ)
  • ครึ่งคลื่น + คี่ (เสี้ยวคลื่น) → \(b_n = \frac{8}{T}\int_0^{T/4} x\sin n\omega_0 t\,dt\) เฉพาะ n คี่
  • เลื่อนเวลาเปลี่ยนแค่เฟส ไม่เปลี่ยน \(A_n\) · ซ้ำทุก T/2 → มีแต่ n คู่
ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

ฟังก์ชันคู่และฟังก์ชันคี่ พื้นฐาน

ฟังก์ชันคู่สะท้อนกระจกรอบแกนตั้ง เหมือน \(\cos t\) ฟังก์ชันคี่หมุนครึ่งรอบรอบจุดกำเนิดแล้วทับตัวเอง เหมือน \(\sin t\) อินทิกรัลของฟังก์ชันคี่บนช่วงสมมาตร \(-T/2\) ถึง \(T/2\) เป็นศูนย์เสมอ เพราะพื้นที่ซ้ายกับขวาหักกันพอดี

S1 Even function ฟังก์ชันคู่ → อนุกรมโคไซน์

\[ x(-t) = x(t) \;\Rightarrow\; b_n = 0,\quad a_0 = \frac{2}{T}\int_0^{T/2} x\,dt,\quad a_n = \frac{4}{T}\int_0^{T/2} x\cos n\omega_0 t\,dt \]

S2 Odd function ฟังก์ชันคี่ → อนุกรมไซน์

\[ x(-t) = -x(t) \;\Rightarrow\; a_0 = a_n = 0,\quad b_n = \frac{4}{T}\int_0^{T/2} x\sin n\omega_0 t\,dt \]

S3 Products and integrals คู่ × คู่ = คู่ · คี่ × คี่ = คู่ · คู่ × คี่ = คี่

\[ \int_{-T/2}^{T/2} (\text{คี่})\,dt = 0, \qquad \int_{-T/2}^{T/2} (\text{คู่})\,dt = 2\int_0^{T/2} (\text{คู่})\,dt \]

ถ้า \(x\) คู่ \(x\sin n\omega_0 t\) เป็นคี่ → \(b_n = 0\) และ \(x\cos n\omega_0 t\) เป็นคู่ → อินทิเกรตครึ่งช่วงคูณสอง (นี่คือที่มาของ 4/T)

ความเป็นคู่หรือคี่ขึ้นกับการเลือก t = 0: คลื่นสี่เหลี่ยมเดียวกัน ถ้าวางขอบขาขึ้นที่ t = 0 เป็นฟังก์ชันคี่ ถ้าวางกึ่งกลางช่วงบวกที่ t = 0 เป็นฟังก์ชันคู่ เลือกจุดเริ่มที่ทำให้ได้สมมาตรมากที่สุดก่อนเริ่มคำนวณ

สมมาตรครึ่งคลื่น: ทำไมระบบไฟมีแต่ฮาร์มอนิกคี่ พื้นฐาน

อุปกรณ์ไฟฟ้าส่วนใหญ่ทำงานเหมือนกันทั้งครึ่งบวกและครึ่งลบ กระแสครึ่งลบจึงเป็นครึ่งบวกกลับหัว นี่คือสมมาตรครึ่งคลื่น และไม่ขึ้นกับว่าเลือก t = 0 ตรงไหน ฮาร์มอนิกคู่เมื่อเลื่อนครึ่งคาบจะได้รูปเดิม (ไม่กลับหัว) จึงอยู่ในสัญญาณแบบนี้ไม่ได้

S4 Half-wave symmetry สมมาตรครึ่งคลื่น → เฉพาะฮาร์มอนิกคี่

\[ x\!\left(t + \tfrac{T}{2}\right) = -x(t) \;\Rightarrow\; a_0 = 0,\;\; a_n = b_n = 0 \;(n \text{ คู่}),\;\; \begin{Bmatrix} a_n \\ b_n \end{Bmatrix} = \frac{4}{T}\int_0^{T/2} x(t)\begin{Bmatrix} \cos \\ \sin \end{Bmatrix} n\omega_0 t\,dt \;(n \text{ คี่}) \]

ตัวอย่าง: สี่เหลี่ยม 50 % สามเหลี่ยม กระแส SMPS กระแสเรกติไฟเออร์ 6 พัลส์ แรงดันอินเวอร์เตอร์ ทุกตัวไม่มีฮาร์มอนิกคู่

S8 Repeats every half period ซ้ำทุก T/2 → เฉพาะฮาร์มอนิกคู่ (และ DC)

\[ x\!\left(t + \tfrac{T}{2}\right) = x(t) \;\Rightarrow\; a_n = b_n = 0 \;\;(n \text{ คี่}) \]

คาบจริงคือ T/2 แต่เรายังวัดเทียบความถี่แหล่งจ่าย เช่นแรงดันเรียงกระแสเต็มคลื่นจากไฟ 50 Hz มีแค่ DC, 100, 200, 300 Hz W8

ถ้าเครื่องวัดเห็นฮาร์มอนิกคู่ หรือ DC ในกระแสสาเหตุที่เป็นไปได้
ฮาร์มอนิกที่ 2 ช่วงสั้น ๆ ตอนจ่ายไฟกระแสพุ่งเข้า (inrush) ของหม้อแปลง แกนอิ่มตัวข้างเดียว
DC และฮาร์มอนิกคู่ต่อเนื่องเรียงกระแสครึ่งคลื่น เครื่องเป่าผม/ฮีตเตอร์ที่ใช้ไดโอดลดกำลัง
ฮาร์มอนิกคู่ในไดรฟ์ 6 พัลส์ไดโอดหรือไทริสเตอร์ตัวหนึ่งเสีย หรือมุมจุดชนวนไม่เท่ากัน
ฮาร์มอนิกคู่ในอินเวอร์เตอร์เวลาตาย (dead time) ไม่เท่ากัน ออฟเซตในวงจรวัดกระแส

สมมาตรเสี้ยวคลื่น: อินทิเกรตแค่หนึ่งในสี่คาบ กลาง

ถ้ารูปมีทั้งสมมาตรครึ่งคลื่นและเป็นฟังก์ชันคี่ (หรือคู่) ในเวลาเดียวกัน หนึ่งในสี่คาบแรกก็บอกทุกอย่างแล้ว รูปคลื่นของอินเวอร์เตอร์เกือบทุกชนิดออกแบบให้มีสมมาตรนี้ การคำนวณจึงสั้นมาก

S5 Quarter-wave symmetry สมมาตรเสี้ยวคลื่น

\[ \text{ครึ่งคลื่น + คี่:}\;\; b_n = \frac{8}{T}\int_0^{T/4} x\sin n\omega_0 t\,dt = \frac{4}{\pi}\int_0^{\pi/2} x(\theta)\sin n\theta\,d\theta \;\;(n \text{ คี่}),\quad a_n = 0 \]

ครึ่งคลื่น + คู่: สลับบทบาท ได้ \(a_n = \frac{8}{T}\int_0^{T/4} x\cos n\omega_0 t\,dt\) เฉพาะ n คี่ และ \(b_n = 0\)

ตัวอย่าง S-1 · สามเหลี่ยมด้วยเสี้ยวคลื่น

คลื่นสามเหลี่ยมสูง \(\pm A\) เริ่มจาก 0 ขาขึ้นที่ t = 0 หาอนุกรมโดยอินทิเกรตเพียง T/4

  1. คี่และครึ่งคลื่น → เสี้ยวคลื่น ใช้ S5 ช่วง \(0 \lt t \lt T/4\) เส้นตรง \(x = 4At/T\)

  2. อินทิกรัลทีละส่วน T10

    \[ b_n = \frac{8}{T}\cdot\frac{4A}{T}\Big[-\frac{t\cos n\omega_0 t}{n\omega_0} + \frac{\sin n\omega_0 t}{(n\omega_0)^2}\Big]_0^{T/4} \]

  3. n คี่: \(\cos(n\pi/2) = 0\) พจน์แรกหาย เหลือ \(\sin(n\pi/2)/(n\omega_0)^2\) และ \((n\omega_0)^2 = 4\pi^2n^2/T^2\)

    \[ b_n = \frac{32A}{T^2}\cdot\frac{T^2\sin(n\pi/2)}{4\pi^2 n^2} = \frac{8A}{\pi^2 n^2}\sin\frac{n\pi}{2} \]

\(x(t) = \dfrac{8A}{\pi^2}\Big[\sin\omega_0 t - \tfrac19\sin 3\omega_0 t + \tfrac1{25}\sin 5\omega_0 t - \cdots\Big]\) · ลดลงตาม \(1/n^2\) เร็วกว่าสี่เหลี่ยมมาก ฮาร์มอนิกที่ 3 เหลือ 11.1 % ของหลัก

ตัวอย่าง S-2 · quasi-square ของอินเวอร์เตอร์

แรงดัน +A ช่วง \(\alpha \lt \theta \lt \pi - \alpha\), −A ช่วง \(\pi + \alpha \lt \theta \lt 2\pi - \alpha\) นอกนั้นเป็น 0 หา \(b_n\) และค่าเมื่อ \(\alpha = 30^\circ\)

  1. เสี้ยวคลื่น (คี่ + ครึ่งคลื่น) ใช้รูปมุมของ S5 ในช่วง \(0\) ถึง \(\pi/2\) มีค่า A เฉพาะ \(\alpha\) ถึง \(\pi/2\)

    \[ b_n = \frac{4}{\pi}\int_{\alpha}^{\pi/2} A\sin n\theta\,d\theta = \frac{4A}{n\pi}\Big[\cos n\alpha - \cos\frac{n\pi}{2}\Big] = \frac{4A}{n\pi}\cos n\alpha \quad (n \text{ คี่}) \]

  2. \(\alpha = 30^\circ\): \(b_1 = \frac{4A}{\pi}(0.866) = 1.1027A\) · \(b_3 = \frac{4A}{3\pi}\cos 90^\circ = 0\) · \(b_5 = \frac{4A}{5\pi}\cos 150^\circ = -0.2205A\) · \(b_7 = -0.1575A\) · \(b_{11} = 0.1002A\)

มุม α = 30° ทำให้ \(\cos 3\alpha = 0\) ฮาร์มอนิกที่ 3, 9, 15 หายหมด ที่เหลือคือ \(1/n\) ของหลักพอดี (THD 31.1 %) นี่คือแรงดันไลน์ของอินเวอร์เตอร์ six-step และหน้าตาเดียวกับกระแสเรกติไฟเออร์ 6 พัลส์ V2

ลองเปลี่ยน α ในแล็บด้านล่าง: α = 18° ฮาร์มอนิกที่ 5 หาย (\(\cos 90^\circ\)) แต่ที่ 3 กลับมา

เลื่อนเวลา เลื่อนระดับ และย่อขยาย กลาง

S6 Time shift เลื่อนเวลาเปลี่ยนแค่เฟส

\[ x(t - t_0):\quad A_n \text{ เท่าเดิม},\quad \varphi_n \to \varphi_n - n\omega_0 t_0 \]

ฮาร์มอนิกที่ n เลื่อนเฟสไป n เท่าของฮาร์มอนิกหลัก นี่คือเหตุที่การเลื่อน 120° ระหว่างเฟสทำให้ฮาร์มอนิกที่ 3 ของทั้งสามเฟสอยู่ในเฟสเดียวกัน H10

S9 Level shift & scaling เลื่อนระดับและย่อขยาย

\[ x + c \Rightarrow a_0 + c, \qquad kx \Rightarrow k\,a_n,\;k\,b_n, \qquad x(\lambda t) \Rightarrow \omega_0 \to \lambda\omega_0 \]

พัลส์ 0 ถึง A ดิวตี้ 50 % = สี่เหลี่ยม \(\pm A/2\) บวก DC \(A/2\) ใช้อนุกรมเดิมได้ทันที

ตัวอย่าง S-3 · ทำให้เป็นฟังก์ชันคู่ด้วยการเลื่อน

จากสี่เหลี่ยมคี่ของ T-1 เลื่อนให้กึ่งกลางช่วงบวกอยู่ที่ t = 0 แล้วเขียนเป็นอนุกรมโคไซน์

  1. ฟังก์ชันใหม่ \(x_e(t) = x(t + T/4)\) แทนในแต่ละพจน์ \(\sin n\omega_0(t + T/4) = \sin n\omega_0 t\cos\tfrac{n\pi}{2} + \cos n\omega_0 t\sin\tfrac{n\pi}{2}\)

  2. n คี่: \(\cos\frac{n\pi}{2} = 0\) และ \(\sin\frac{n\pi}{2} = (-1)^{(n-1)/2}\) T11 → \(a_n = \frac{4A}{n\pi}(-1)^{(n-1)/2}\)

\(x_e(t) = \dfrac{4A}{\pi}\Big[\cos\omega_0 t - \tfrac13\cos 3\omega_0 t + \tfrac15\cos 5\omega_0 t - \cdots\Big]\) ขนาดทุกตัวเท่าเดิม เปลี่ยนแค่เครื่องหมายสลับ ซึ่งคือเฟส

สมมาตรของความไม่เป็นเชิงเส้น: ตัดยอด แกนเหล็ก ไดโอด กลาง

อุปกรณ์ที่ไม่เป็นเชิงเส้นรับไซน์เข้าแล้วให้รูปอื่นออก รูปที่ออกมีสมมาตรแบบไหนขึ้นกับว่าความไม่เป็นเชิงเส้นนั้นสมมาตรหรือไม่ จึงทำนายชนิดของฮาร์มอนิกได้ก่อนคำนวณ

S7 Symmetric vs asymmetric nonlinearity ไม่เป็นเชิงเส้นแบบสมมาตรและไม่สมมาตร

\[ y = f(x),\;\; x = \sin\omega t: \qquad f(-x) = -f(x) \Rightarrow \text{เฉพาะฮาร์มอนิกคี่} \qquad f(-x) \neq -f(x) \Rightarrow \text{มี DC และฮาร์มอนิกคู่} \]

สมมาตร: ตัดยอดทั้งบนล่างเท่ากัน แกนเหล็กอิ่มตัว (B–H สมมาตร) → ฮาร์มอนิกที่ 3 เด่น · ไม่สมมาตร: ไดโอด ทรานซิสเตอร์ไบแอสไม่ตรงกลาง → ฮาร์มอนิกที่ 2 เด่น

ตัวอย่าง S-4 · ตัดยอดสมมาตรกับไม่สมมาตร

ไซน์แอมพลิจูด 1 ถูกตัด (ก) ทั้งบนและล่างที่ ±0.7 (ข) เฉพาะบนที่ 0.6 เปรียบเทียบสเปกตรัม

  1. (ก) \(f(-x) = -f(x)\) → ไม่มี DC ไม่มี n คู่ อินทิเกรตเป็นช่วงไซน์กับช่วงค่าคงตัว ได้ \(b_1 = 0.812\), \(b_3 = 0.108\) (13.3 %), \(b_5 = -0.020\) (2.5 %), \(b_7 = -0.016\) (2.0 %) THD = 13.8 %

  2. (ข) ตัดข้างเดียว สมมาตรครึ่งคลื่นหาย: \(a_0 = -0.078\) (ค่าเฉลี่ยติดลบ เพราะส่วนบนหายไป) \(b_1 = 0.858\), \(a_2 = 0.109\) (12.7 %), \(b_3 = 0.065\) (7.6 %), \(a_4 = -0.025\) (2.9 %) THD = 15.2 %

ตัดสมมาตรได้เฉพาะคี่ ตัดข้างเดียวได้ DC และฮาร์มอนิกที่ 2 เด่น วิศวกรเสียงใช้ข้อนี้บอกได้ว่าเครื่องขยายตัดยอดข้างไหน ทั้งหมดคำนวณแบบปิด (ไม่ประมาณ) ในแล็บ เลือก “ไซน์ถูกตัดยอด”

อนุกรมครึ่งช่วง: ขยายฟังก์ชันที่รู้แค่ครึ่งเดียว ขั้นสูง

ปัญหาค่าขอบเขต เช่นการนำความร้อนในแท่งโลหะ (ปัญหาดั้งเดิมของฟูเรียร์) หรือแรงดันบนสายส่งที่ปลายสองข้างกำหนดไว้ ฟังก์ชันถูกกำหนดแค่ช่วง \(0 \lt x \lt L\) เราจะ “สร้าง” ครึ่งที่เหลือให้เป็นคู่หรือคี่ตามเงื่อนไขขอบ แล้วได้อนุกรมโคไซน์หรือไซน์ล้วน

S10 Half-range expansions on 0 < x < L อนุกรมครึ่งช่วง

\[ \text{ไซน์ (ขยายแบบคี่):}\; b_n = \frac{2}{L}\int_0^L f(x)\sin\frac{n\pi x}{L}dx \qquad \text{โคไซน์ (ขยายแบบคู่):}\; a_0 = \frac{1}{L}\int_0^L f\,dx,\;\; a_n = \frac{2}{L}\int_0^L f(x)\cos\frac{n\pi x}{L}dx \]

ปลายทั้งสองถูกตรึงเป็นศูนย์ (เช่นอุณหภูมิที่ปลายแท่งคงที่) ใช้อนุกรมไซน์ ปลายหุ้มฉนวนไม่มีความร้อนไหล (อนุพันธ์เป็นศูนย์) ใช้อนุกรมโคไซน์

ตัวอย่าง S-5 · อนุกรมไซน์ครึ่งช่วง

เขียน \(f(x) = x\) บน \(0 \lt x \lt \pi\) เป็นอนุกรมไซน์

  1. \(L = \pi\) ใช้ S10 และ T10

    \[ b_n = \frac{2}{\pi}\int_0^{\pi} x\sin nx\,dx = \frac{2}{\pi}\Big[-\frac{x\cos nx}{n} + \frac{\sin nx}{n^2}\Big]_0^{\pi} = \frac{2}{\pi}\cdot\Big(-\frac{\pi(-1)^n}{n}\Big) = \frac{2(-1)^{n+1}}{n} \]

\(x = 2\big(\sin x - \tfrac12\sin 2x + \tfrac13\sin 3x - \cdots\big)\) บน \(0 \lt x \lt \pi\) ซึ่งก็คือฟันเลื่อยของ T-3 นั่นเอง (ขยายแบบคี่ของเส้นตรงคือฟันเลื่อย)

ตัวอย่าง S-6 · ฝึกดูสมมาตร

บอกสมมาตรและฮาร์มอนิกที่มีของ: (ก) กระแส SMPS (ข) พัลส์ 0–5 V ดิวตี้ 25 % (ค) แรงดันเรียงกระแสเต็มคลื่น (ง) กระแสเรกติไฟเออร์ 6 พัลส์ (จ) ฟันเลื่อย

  1. (ก) พัลส์บวกกับลบหน้าตาเหมือนกัน → ครึ่งคลื่น → เฉพาะคี่ (3, 5, 7, …) ไม่มี DC

  2. (ข) ไม่มีสมมาตรครึ่งคลื่น มี DC = 1.25 V · ถ้าวางกึ่งกลางพัลส์ที่ t = 0 เป็นฟังก์ชันคู่ → มีแต่โคไซน์ ทั้ง n คู่และคี่ (ยกเว้น n = 4, 8, …)

  3. (ค) ซ้ำทุกครึ่งคาบของไฟ → เฉพาะ n คู่ และเป็นฟังก์ชันคู่ (วาง t = 0 ที่ยอด) → โคไซน์ล้วน

  4. (ง) ครึ่งคลื่น + คู่ (วางกึ่งกลางบล็อกที่ t = 0) → เสี้ยวคลื่น เฉพาะคี่ และความเป็น 3 เฟสตัด 3, 9, 15 ออกอีก เหลือ 6k ± 1

  5. (จ) คี่แต่ไม่มีครึ่งคลื่น → ไซน์ล้วน มีทุก n

ลองยืนยันทุกข้อในแล็บด้านล่าง แผงด้านล่างกราฟบอกสมมาตรที่ตรวจพบจากสัมประสิทธิ์ให้อัตโนมัติ

แล็บ: ทายสมมาตรก่อนดูสเปกตรัม พื้นฐาน

ติ๊ก “ซ่อนสเปกตรัม (ทายก่อน)” เลือกรูปคลื่น ทายว่ามีฮาร์มอนิกคู่ไหม มี DC ไหม แล้วค่อยกดดู ลองเลื่อน α ของ quasi-square และดิวตี้ของพัลส์แล้วสังเกตว่าศูนย์ของสเปกตรัมย้ายไปที่ไหน
