อนุกรมฟูเรียร์คืออะไร: ทุกคลื่นคาบคือผลรวมของไซน์

คลื่นสี่เหลี่ยมจากเครื่องกำเนิดสัญญาณ แรงดันที่ขาออกของอินเวอร์เตอร์ กระแสที่คอมพิวเตอร์ดึงจากปลั๊ก ทั้งหมดไม่ใช่ไซน์ แต่ทุกรูปที่ซ้ำเดิมเป็นคาบเขียนเป็นผลรวมของไซน์ได้เสมอ นี่คือความคิดของโจเซฟ ฟูเรียร์ และเป็นภาษาที่วิศวกรไฟฟ้าใช้พูดถึงฮาร์มอนิก ตัวกรอง และคุณภาพไฟฟ้า หน้านี้ปูพื้นให้เห็นภาพก่อนลงมือคำนวณในหน้าถัดไป

เขียนโดย อาจารย์มดอัปเดต
ลองรวมไซน์เอง แนวคิด ภาษาฮาร์มอนิก ใช้ทำอะไร เรียนต่ออะไร
สรุปใน 30 วินาที
  • สัญญาณคาบ \(x(t + T) = x(t)\) มีความถี่มูลฐาน \(f_0 = 1/T\)
  • \(x(t) = a_0 + \sum_{n=1}^{\infty}\big[a_n\cos n\omega_0 t + b_n \sin n\omega_0 t\big]\) โดย \(\omega_0 = 2\pi f_0\)
  • ตัวที่ \(n\) เรียกว่าฮาร์มอนิกที่ \(n\) มีความถี่ \(nf_0\) ไฟ 50 Hz จึงมีฮาร์มอนิกที่ 150, 250, 350 Hz …
  • กราฟของ \(A_n = \sqrt{a_n^2 + b_n^2}\) เทียบ \(n\) คือสเปกตรัม สิ่งที่ FFT บนสโคปและเครื่องวิเคราะห์กำลังแสดง

แนวคิด: ไซน์คืออิฐก้อนพื้นฐานของทุกคลื่นคาบ พื้นฐาน

ลองนึกถึงคอร์ดดนตรี เสียงที่ได้ยินคือโน้ตหลายตัวที่ดังพร้อมกัน หูของเราแยกได้ว่ามีโน้ตอะไรบ้าง อนุกรมฟูเรียร์ทำแบบเดียวกันกับสัญญาณไฟฟ้า มันบอกว่าคลื่นรูปไหนก็ตามที่ซ้ำเป็นคาบ ประกอบด้วยไซน์ความถี่อะไร ขนาดเท่าไร และเลื่อนเฟสไปเท่าไร

เงื่อนไขเดียวที่ต้องมีคือความเป็นคาบ รูปคลื่นต้องซ้ำเดิมทุกช่วงเวลา \(T\) เท่ากัน ไซน์ที่ใช้ประกอบจึงมีได้เฉพาะความถี่ที่ซ้ำพอดีกับคาบนั้น คือ \(f_0, 2f_0, 3f_0, \dots\) ไม่มีความถี่อื่นปน

F1 Periodic signal & fundamental frequency สัญญาณคาบและความถี่มูลฐาน

\[ x(t + T) = x(t), \qquad f_0 = \frac{1}{T}, \qquad \omega_0 = 2\pi f_0 = \frac{2\pi}{T} \]

\(T\) คือคาบที่สั้นที่สุดที่รูปซ้ำ ไฟบ้านไทย \(f_0 = 50\) Hz, \(T = 20\) ms, \(\omega_0 = 314.16\) rad/s

F2 Harmonic frequencies ความถี่ของฮาร์มอนิก

\[ f_n = n f_0, \qquad \omega_n = n\omega_0, \qquad n = 1, 2, 3, \dots \]

\(n = 1\) คือฮาร์มอนิกหลัก (fundamental) \(n = 2\) คือฮาร์มอนิกที่ 2 ไปเรื่อย ๆ ความถี่ที่ไม่ใช่จำนวนเต็มเท่าเรียกว่าอินเตอร์ฮาร์มอนิก ไม่อยู่ในอนุกรมฟูเรียร์

F3 Fourier series (trigonometric form) อนุกรมฟูเรียร์รูปตรีโกณมิติ

\[ x(t) = a_0 + \sum_{n=1}^{\infty} \Big[\, a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t) \,\Big] \]

\(a_0\) คือค่าเฉลี่ย (DC) ส่วน \(a_n\) กับ \(b_n\) บอกว่ามีโคไซน์และไซน์ของความถี่ \(nf_0\) อยู่เท่าไร วิธีหาอยู่ที่ T6 · บางตำราเขียน \(a_0/2\) แทน \(a_0\) ชุดนี้ใช้ \(a_0\) = ค่าเฉลี่ยตลอด เพราะอ่านเป็นแรงดัน DC ได้ทันที

F4 Amplitude–phase form รูปแอมพลิจูด–เฟส (ฮาร์มอนิกละหนึ่งไซน์)

\[ x(t) = a_0 + \sum_{n=1}^{\infty} A_n \cos(n\omega_0 t + \varphi_n), \qquad A_n = \sqrt{a_n^2 + b_n^2} \]

รวมโคไซน์กับไซน์ความถี่เดียวกันเป็นไซน์ตัวเดียว (harmonic addition จากตรีโกณมิติ) \(A_n\) คือแอมพลิจูด (ค่ายอด) ของฮาร์มอนิกที่ \(n\) รายละเอียดมุม \(\varphi_n\) ที่ C3

สังเคราะห์: รวมไซน์ให้ได้คลื่นสี่เหลี่ยม พื้นฐาน

คลื่นสี่เหลี่ยมสูง \(\pm A\) เขียนเป็นอนุกรมได้ว่า \(x(t) = \tfrac{4A}{\pi}\big[\sin\omega_0 t + \tfrac13 \sin 3\omega_0 t + \tfrac15 \sin 5\omega_0 t + \cdots\big]\) มีเฉพาะฮาร์มอนิกคี่ และขนาดลดลงตาม \(1/n\) ที่มาของสูตรนี้อยู่ในตัวอย่าง T-1 ตอนนี้ลองเชื่อไปก่อนแล้วดูด้วยตาว่ามันรวมกันเป็นสี่เหลี่ยมจริง กด “▶ เพิ่มทีละตัว” หรือเลื่อน N

ตัวอย่าง F-1 · ผลรวมสามพจน์

ใช้ฮาร์มอนิกที่ 1, 3, 5 ของคลื่นสี่เหลี่ยม \(\pm1\) V หาค่าที่ \(t = T/4\) และ \(t = T/8\) แล้วบอกว่ารวมสามตัวได้กำลังกี่เปอร์เซ็นต์

  1. ที่ \(t = T/4\) มุม \(\omega_0 t = \pi/2\): \(\sin\tfrac{\pi}{2} = 1\), \(\sin\tfrac{3\pi}{2} = -1\), \(\sin\tfrac{5\pi}{2} = 1\)

    \[ x_5\!\left(\tfrac{T}{4}\right) = \frac{4}{\pi}\Big(1 - \tfrac13 + \tfrac15\Big) = 1.2732 \times 0.8667 = 1.1035\ \text{V} \]

  2. ที่ \(t = T/8\) มุม \(\pi/4\): \(\sin 45^\circ = 0.7071\), \(\sin 135^\circ = 0.7071\), \(\sin 225^\circ = -0.7071\)

    \[ x_5\!\left(\tfrac{T}{8}\right) = \frac{4}{\pi}\Big(0.7071 + \tfrac{0.7071}{3} - \tfrac{0.7071}{5}\Big) = 1.0204\ \text{V} \]

  3. กำลัง (ค่า RMS²) ของสี่เหลี่ยมคือ \(A^2 = 1\) ส่วนฮาร์มอนิกที่ \(n\) มีกำลัง \(A_n^2/2\) P5

    \[ \frac{1}{2}\Big(\frac{4}{\pi}\Big)^2\Big(1 + \tfrac19 + \tfrac1{25}\Big) = 0.8106 \times 1.1511 = 0.9331 \]

ค่าที่ T/4 เกินไป 10 % ที่ T/8 เกินไป 2 % แต่สามตัวแรกให้กำลังแล้ว 93.3 % ของทั้งหมด ฮาร์มอนิกหลักตัวเดียวมีกำลัง 81.1 % ส่วนที่เหลือคือสิ่งที่ทำให้มุมคม

ตรวจในแล็บด้านบน: ตั้ง N = 5 อ่าน “กำลังที่รวมแล้ว” ได้ 93.31 % ✓

สังเกต: เพิ่มฮาร์มอนิกเท่าไรมุมก็คมขึ้น แต่ยอดแหลมข้างรอยกระโดดไม่หาย มันสูงราว 9 % ของขนาดรอยกระโดดเสมอ เรียกว่าปรากฏการณ์กิบส์ อธิบายที่ 12.5

ภาษาของฮาร์มอนิก: ชื่อที่ต้องรู้ พื้นฐาน

งานไฟฟ้าใช้คำเหล่านี้ทุกวัน ในรายงานคุณภาพไฟฟ้า สเปกของไดรฟ์ หรือหน้าจอเครื่องวัด

F5 DC component องค์ประกอบ DC = ค่าเฉลี่ย

\[ a_0 = \frac{1}{T}\int_{0}^{T} x(t)\,dt \]

ไซน์บริสุทธิ์มี \(a_0 = 0\) คลื่นที่เรียงกระแสแล้ว หรือพัลส์ 0 ถึง 5 V มี \(a_0 \neq 0\) ฮาร์มอนิกที่ “ลำดับศูนย์” คือ DC

F6 Odd, even and triplen harmonics ฮาร์มอนิกคี่ คู่ และทริปเพลน

\[ \text{odd: } n = 1, 3, 5, \dots \quad \text{even: } n = 2, 4, \dots \quad \text{triplen: } n = 3, 9, 15, \dots \]

ครึ่งบวกกับครึ่งลบหน้าตาเหมือนกัน (กลับหัว) → มีแต่ฮาร์มอนิกคี่ S4 · ทริปเพลน (คี่ที่หารด้วย 3 ลงตัว) บวกกันในสายนิวทรัล H10

F7 Line spectrum สเปกตรัมเส้น: มองสัญญาณในโดเมนความถี่

\[ x(t) \;\longleftrightarrow\; \{\, a_0;\ (A_1, \varphi_1);\ (A_2, \varphi_2);\ \dots \,\} \quad \text{at} \quad 0,\ f_0,\ 2f_0,\ \dots \]

สัญญาณคาบมีพลังงานเฉพาะที่ความถี่ \(nf_0\) กราฟสเปกตรัมจึงเป็นแท่ง ๆ ไม่ต่อเนื่อง ระยะห่างของแท่งคือ \(f_0 = 1/T\) เครื่องวัดมักแสดงเป็นค่า RMS \(A_n/\sqrt2\) หรือเป็น % ของฮาร์มอนิกหลัก

ถ้าสัญญาณเขียนเป็นผลรวมของไซน์อยู่แล้ว อนุกรมฟูเรียร์ก็คือตัวมันเอง แค่จัดรูปให้ตรงกับ F3 และถ้าเป็นกำลังของไซน์ ใช้สูตรลดกำลังจากตรีโกณมิติเปลี่ยนเป็นผลบวกได้ทันที

ตัวอย่าง F-2 · อ่านค่าตรง

\(v(t) = 12 + 5\cos(100\pi t) - 2\sin(300\pi t)\) V หาคาบ \(f_0\), \(a_0\), \(a_n\), \(b_n\) และค่า RMS

  1. ความถี่เชิงมุมที่มีคือ \(100\pi\) และ \(300\pi\) rad/s ตัวที่ต่ำที่สุดที่ทุกตัวเป็นจำนวนเต็มเท่าคือ \(\omega_0 = 100\pi\) → \(f_0 = 50\) Hz, \(T = 20\) ms

  2. เทียบกับ F3: \(a_0 = 12\), \(a_1 = 5\), \(b_3 = -2\) ค่าอื่นเป็นศูนย์ทั้งหมด (ไม่มีฮาร์มอนิกที่ 2)

  3. RMS จากพาร์เซวาล P6: DC ใช้ค่าเต็ม ไซน์ใช้ \(A/\sqrt2\)

    \[ V_{rms} = \sqrt{12^2 + \tfrac{5^2}{2} + \tfrac{2^2}{2}} = \sqrt{144 + 12.5 + 2} = 12.59\ \text{V} \]

\(f_0 = 50\) Hz · \(a_0 = 12\) V · \(a_1 = 5\) V · \(b_3 = -2\) V · \(V_{rms} = 12.59\) V

ตัวอย่าง F-3 · ความไม่เป็นเชิงเส้นสร้างฮาร์มอนิก

ป้อน \(x = \sin\omega t\) เข้าอุปกรณ์ที่ได้ขาออก \(y = x^2\) และ \(y = x^3\) ขาออกมีฮาร์มอนิกอะไรบ้าง

  1. สูตรลดกำลัง (power-reduction) จากตรีโกณมิติ

    \[ \sin^2\omega t = \tfrac12 - \tfrac12\cos 2\omega t \]

  2. \[ \sin^3\omega t = \tfrac34\sin\omega t - \tfrac14\sin 3\omega t \]

  3. อ่านค่า: \(x^2\) มี \(a_0 = \tfrac12\), \(a_2 = -\tfrac12\) · \(x^3\) มี \(b_1 = \tfrac34\), \(b_3 = -\tfrac14\)

กำลังสอง (ไม่สมมาตร) สร้าง DC กับฮาร์มอนิกคู่ กำลังสาม (สมมาตรแบบคี่) สร้างเฉพาะฮาร์มอนิกคี่ นี่คือเหตุผลที่แกนเหล็กหม้อแปลงที่อิ่มตัว (คี่) สร้างฮาร์มอนิกที่ 3 และไดโอด (ไม่สมมาตร) สร้างฮาร์มอนิกคู่ ดู S7

อนุกรมฟูเรียร์ใช้กับอะไรได้ และอะไรไม่ได้ กลาง

  • ใช้ได้: สัญญาณคาบในสถานะคงตัว (steady state) ที่ปฏิบัติตามเงื่อนไขของดีริชเลต์ ซึ่งสัญญาณไฟฟ้าจริงทุกตัวผ่าน แม้จะมีรอยกระโดดหรือมุมแหลม P1
  • ไม่เป็นคาบ เช่นพัลส์เดียว ใช้การแปลงฟูเรียร์ (Fourier transform) ได้สเปกตรัมต่อเนื่อง ดูแล็บสัญญาณ
  • ช่วงชั่วครู่ เช่นสวิตช์เพิ่งเปิด ใช้การแปลงลาปลาซ แล้วค่อยใช้ฟูเรียร์กับส่วนสถานะคงตัว
  • ความถี่ไม่สัมพันธ์กัน เช่น 50 Hz กับ 173 Hz ผลรวมไม่เป็นคาบที่สั้น เรียก 173 Hz ว่าอินเตอร์ฮาร์มอนิก เครื่องวัดตามมาตรฐานจัดกลุ่มแยกไว้ D8

  1. 12.2 หาสัมประสิทธิ์ทีละขั้น ต้องใช้อินทิกรัล (ทีละส่วน) และตรีโกณมิติ
  2. 12.3 สมมาตร ลดงานคำนวณได้ครึ่งหนึ่งหรือมากกว่า
