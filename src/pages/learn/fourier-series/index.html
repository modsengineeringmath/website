อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก

อนุกรมฟูเรียร์ (หรือ ฟูริเยร์) เปลี่ยนรูปคลื่นที่ไม่ใช่ไซน์ให้เป็นผลรวมของไซน์ แล้ววิศวกรไฟฟ้าก็ใช้เครื่องมือวงจร AC เดิมแก้ได้ทีละความถี่ ชุดนี้พาไปทีละขั้นตั้งแต่อินทิกรัลหาสัมประสิทธิ์ จนถึงอ่านค่า THD PF บนเครื่องวิเคราะห์กำลังไฟฟ้า ออกแบบฟิลเตอร์ และเข้าใจสเปกตรัมของเรกติไฟเออร์ อินเวอร์เตอร์ และคอนเวอร์เตอร์ มี 15 หน้า สูตรที่มีรหัสอ้างอิงถาวร ตัวอย่างวิธีทำ และแล็บเสมือนที่วัดและแก้ปัญหาได้ด้วยตัวเอง

เขียนโดย อาจารย์มดอัปเดต
เปิดแล็บวิเคราะห์ฮาร์มอนิก เรียนทีละขั้น ค้นหาสูตร งงตรงไหน ปัญหาหน้างาน
ทั้งชุดในหนึ่งนาที
  • ทุกคลื่นคาบ \(x(t)\) = DC + \(\sum A_n\cos(n\omega_0 t+\varphi_n)\) หาค่าด้วยอินทิกรัล \(a_n = \tfrac{2}{T}\int x\cos n\omega_0 t\,dt\) และใช้สมมาตรตัดพจน์ที่เป็นศูนย์ทิ้งก่อน T6 S
  • กำลังรวม = ผลรวมกำลังของแต่ละฮาร์มอนิก (พาร์เซวาล) จึงได้ \(I_{rms} = I_1\sqrt{1+\mathrm{THD}^2}\) P5 H1
  • วงจรเชิงเส้น: แยก → คูณ \(H(jn\omega_0)\) ทีละฮาร์มอนิก → รวม A1–A3
  • กระแสเพี้ยนทำให้ \(\mathrm{PF} = \mathrm{DPF}/\sqrt{1+\mathrm{THD}_I^2}\) คาปาซิเตอร์แก้ได้แค่ DPF และอาจเรโซแนนซ์ที่ \(h_r=\sqrt{S_{sc}/Q_c}\) H7 M2
  • ตัวแปลง p พัลส์สร้างฮาร์มอนิก \(h = kp\pm1\) ขนาดราว \(1/h\) ส่วน PWM ย้ายฮาร์มอนิกไปรอบ \(m_f\) R6 V6

แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลัง

สามเครื่องมือในหน้าเดียว: ① สังเคราะห์และแยกรูปคลื่น 13 แบบพร้อมวิธีคิดทีละขั้น ② ป้อนคลื่นเข้าวงจร RC RL LC RLC ดูทีละฮาร์มอนิก ③ วัดโหลดจริง 10 แบบ อ่าน P Q S D PF THD TDD K-factor เทียบ IEEE 519 แล้วลองแก้ด้วยรีแอกเตอร์ คาปาซิเตอร์ดีจูน ฟิลเตอร์ พร้อมแปลผลอัตโนมัติ ใบงาน 16 ชุด และกรณีศึกษาหน้างาน 6 เรื่อง

ลองเลย: แล็บขนาดเล็ก

เลือกรูปคลื่น เลื่อนจำนวนฮาร์มอนิก N แล้วดูผลรวมเข้าหารูปจริง สลับไปแท็บวงจรหรือเครื่องวิเคราะห์กำลังได้ หรือกดปุ่มในตาราง เรียนทีละขั้น เพื่อโหลดการทดลองของขั้นนั้น

ค้นหาสูตรทั้งหมดในที่เดียว

รวมทุกสูตรจากทั้ง 14 บท พิมพ์ได้ทั้งภาษาไทยและอังกฤษ หรือพิมพ์รหัสสูตรตรง ๆ เช่น H7 กดที่ชื่อสูตรเพื่อไปยังคำอธิบายและตัวอย่างวิธีทำของสูตรนั้น

งงตรงไหน คลิกตรงนั้น

จุดที่นักศึกษาติดบ่อยที่สุดเวลาทำโจทย์อนุกรมฟูเรียร์ กดแล้วไปที่คำอธิบายนั้นทันที

a₀ ต้องหารสองหรือไม่ขึ้นกับรูปแบบที่ตำราใช้ ชุดนี้ a₀ = ค่าเฉลี่ย → T8 cos nπ กับ sin nπ แทนค่าอย่างไรsin nπ = 0, cos nπ = (−1)ⁿ → T11 อินทิเกรตแล้วได้ n = 1 หารศูนย์ต้องแยกกรณี n = 1 ของไซน์เรียงกระแส → ข้อผิดพลาดที่เจอบ่อย ไม่รู้จะหาพจน์ไหนก่อนดูสมมาตรก่อนอินทิเกรต → ตารางตัดสินใจ เลื่อนรูปคลื่นแล้วสัมประสิทธิ์เปลี่ยนขนาดเท่าเดิม เฟสเลื่อน nω₀t₀ → S6 ค่าที่จุดกระโดดคือเท่าไรค่าเฉลี่ยของสองฝั่ง → T13, P2 cₙ กับ aₙ bₙ เกี่ยวกันอย่างไรcₙ = (aₙ − jbₙ)/2 และ Aₙ = 2|cₙ| → C4 เฟสใช้ atan(b/a) แล้วผิดควอดแรนต์ใช้ atan2(−bₙ, aₙ) สำหรับรูปโคไซน์ → C3 เพิ่ม N แล้วยอดเกินไม่หายหูกิบส์ราว 9 % ของการกระโดด → P3, σ-factor P4 หา RMS จากอนุกรมอย่างไรรากของผลรวมกำลังสองของ RMS แต่ละตัว → P5, P6 ลืมพจน์ DC เวลาแก้วงจรDC ผ่าน L ได้ ไม่ผ่าน C → A5 ใช้ซูเปอร์โพซิชันกับไดโอดได้ไหมไม่ได้โดยตรง วงจรต้องเป็นเชิงเส้น → ข้อจำกัด

ปัญหาหน้างาน: อาการ → สาเหตุ → แก้

อาการที่เจอจริงในอาคารและโรงงาน แต่ละข้อพาไปหาสูตร วิธีวัด และการทดลองในแล็บที่จำลองอาการนั้น รายการเต็มอยู่ที่ เช็กลิสต์แก้ปัญหาหน้างาน
