สเปกตรัมของอินเวอร์เตอร์: สี่เหลี่ยม quasi-square six-step SHE และ SPWM

อินเวอร์เตอร์สร้างไซน์จากสวิตช์ที่เปิดปิดได้แค่สองหรือสามระดับ ทุกเทคนิคตั้งแต่คลื่นสี่เหลี่ยมถึง PWM คือการเลือกจังหวะสวิตช์ให้ฮาร์มอนิกหลักได้ขนาดที่ต้องการ แล้วย้ายฮาร์มอนิกที่เหลือไปอยู่ที่ที่กรองง่ายที่สุด อนุกรมฟูเรียร์บอกได้แม่นยำว่าแต่ละวิธีย้ายไปไว้ที่ไหน

เขียนโดย อาจารย์มดอัปเดต
SPWM สี่เหลี่ยม quasi-square six-step SHE
สรุปใน 30 วินาที
  • สี่เหลี่ยมเต็มบริดจ์: \(V_1 = \frac{4V_{dc}}{\pi}\) ฮาร์มอนิก \(1/n\) · quasi-square: \(\frac{4V_{dc}}{n\pi}\cos n\alpha\) เลือก α ฆ่าฮาร์มอนิกได้
  • six-step 3 เฟส: เหลือ 6k ± 1 · \(V_{LL1} = 0.780V_{dc}\) (RMS)
  • SPWM: \(V_1 = m_a\frac{V_{dc}}{2}\) (ครึ่งบริดจ์) ฮาร์มอนิกย้ายไปรอบ \(m_f\), \(2m_f\) · ยูนิโพลาร์ย้ายไปรอบ \(2m_f\)
  • 3 เฟส: \(V_{LL1,rms} = 0.612\,m_aV_{dc}\) · \(m_f\) คี่ หารด้วย 3 ลงตัว

อินเวอร์เตอร์คลื่นสี่เหลี่ยม พื้นฐาน

V1 Square-wave inverter อินเวอร์เตอร์คลื่นสี่เหลี่ยม

\[ \text{เต็มบริดจ์ } (\pm V_{dc}):\; V_n = \frac{4V_{dc}}{n\pi},\; V_{1,rms} = 0.900V_{dc} \qquad \text{ครึ่งบริดจ์ } (\pm V_{dc}/2):\; V_n = \frac{2V_{dc}}{n\pi} \]

ใช้ W1 ตรง ๆ · ปรับขนาดฮาร์มอนิกหลักไม่ได้นอกจากเปลี่ยน \(V_{dc}\) THD 48 % · โหลดเหนี่ยวนำช่วยกรองกระแส (A-2)

quasi-square: ปรับแรงดันและกำจัดฮาร์มอนิกด้วยมุมเดียว กลาง

เต็มบริดจ์สร้างระดับศูนย์ได้ด้วย (สวิตช์บนทั้งสองหรือล่างทั้งสองนำพร้อมกัน) ใส่ช่วงศูนย์กว้าง α ที่ขอบทั้งสองของแต่ละครึ่งคาบ ได้รูปเสี้ยวคลื่นสมมาตรที่วิเคราะห์ไว้แล้วใน S-2

V2 Quasi-square inverter ปรับด้วยมุม α

\[ V_n = \frac{4V_{dc}}{n\pi}\cos n\alpha,\qquad \alpha = \frac{90^\circ}{n} \;\Rightarrow\; V_n = 0 \;\;(\alpha = 30^\circ:\ n = 3 \quad \alpha = 18^\circ:\ n = 5 \quad \alpha = 12.86^\circ:\ n = 7) \]

มุมเดียวทำได้สองงานไม่พร้อมกัน: ปรับขนาด \(V_1\) หรือกำจัดฮาร์มอนิกหนึ่งตัว ต้องการมากกว่านั้นใช้ SHE หรือ PWM

ตัวอย่าง V-1 · อินเวอร์เตอร์สำรองไฟแบบ modified sine

เต็มบริดจ์ \(V_{dc}\) = 311 V ใช้ quasi-square α = 30° หาแรงดันฮาร์มอนิกหลัก (ยอดและ RMS) ฮาร์มอนิกที่ 5, 7 และค่า RMS รวม

  1. V2: \(V_1 = \frac{4(311)}{\pi}\cos 30^\circ = 342.9\) V ยอด = 242.5 V RMS

  2. \(V_5 = \frac{4(311)}{5\pi}|\cos 150^\circ| = 68.6\) V · \(V_7 = 49.0\) V (ยอด) · \(V_3 = 0\)

  3. RMS รวม W9: \(311\sqrt{1 - 1/3} = 253.9\) V

ได้ราว 242 V RMS ที่ 50 Hz (ใกล้ไฟบ้าน) ไม่มีฮาร์มอนิกที่ 3 THD 31 % · ขาย UPS แบบนี้ในชื่อ “modified sine wave” อุปกรณ์ที่มีตัวเก็บประจุด้านเข้าหรือมอเตอร์บางชนิดทำงานได้แต่ร้อนกว่า

อินเวอร์เตอร์ 3 เฟส six-step กลาง

สามขา (leg) แต่ละขาเป็นสี่เหลี่ยม ±Vdc/2 เลื่อนกัน 120° แรงดันไลน์คือผลต่างของสองขา ได้ quasi-square α = 30° โดยอัตโนมัติ ฮาร์มอนิกที่ 3 ของแต่ละขาอยู่ในเฟสเดียวกัน (ลำดับศูนย์ H10) จึงหักล้างกันในแรงดันไลน์

V3 Six-step inverter อินเวอร์เตอร์ six-step

\[ V_{LL1,rms} = \frac{\sqrt6}{\pi}V_{dc} = 0.780V_{dc},\qquad V_{ph1,rms} = \frac{\sqrt2}{\pi}V_{dc} = 0.450V_{dc},\qquad V_h = \frac{V_1}{h},\; h = 6k \pm 1 \]

รูปคลื่นแรงดันเฟส W10 แรงดันไลน์ W11 · ให้แรงดันสูงสุดที่ \(V_{dc}\) ทำได้ (สูงกว่า SPWM เชิงเส้น 27 %) ไดรฟ์ใช้ในย่านความเร็วสูงสุด

Selective Harmonic Elimination (SHE) ขั้นสูง

ขยายแนวคิดของ quasi-square: ใส่ช่วงศูนย์หลายช่วงในหนึ่งในสี่คาบ ได้มุมสวิตช์ k มุม จึงตั้งสมการได้ k สมการ ใช้หนึ่งสมการกำหนดขนาด \(V_1\) ที่เหลือบังคับให้ฮาร์มอนิกที่ไม่ต้องการเป็นศูนย์

V4 SHE equations (3-level, quarter-wave) สมการ SHE

\[ V_n = \frac{4V_{dc}}{n\pi}\sum_{k=1}^{K}(-1)^{k+1}\cos n\alpha_k,\qquad 0 \lt \alpha_1 \lt \alpha_2 \lt \cdots \lt \alpha_K \lt 90^\circ \]

ไม่เชิงเส้น ต้องแก้เชิงตัวเลข (นิวตัน) แล้วเก็บเป็นตารางมุมในไมโครคอนโทรลเลอร์ ใช้ในอินเวอร์เตอร์กำลังสูงที่ความถี่สวิตช์ต่ำ

ตัวอย่าง V-2 · กำจัด 5 และ 7 พร้อมกัน

ใช้สามมุม ต้องการ \(V_1 = 0.8 \times \frac{4V_{dc}}{\pi}\) และ \(V_5 = V_7 = 0\) หามุมและฮาร์มอนิกที่เหลือ

  1. สมการ: \(\cos\alpha_1 - \cos\alpha_2 + \cos\alpha_3 = 0.8\) · \(\cos 5\alpha_1 - \cos 5\alpha_2 + \cos 5\alpha_3 = 0\) · \(\cos 7\alpha_1 - \cos 7\alpha_2 + \cos 7\alpha_3 = 0\)

  2. แก้ด้วยวิธีนิวตัน: \(\alpha_1 = 23.63^\circ\), \(\alpha_2 = 38.06^\circ\), \(\alpha_3 = 47.84^\circ\)

  3. แทนกลับ (% ของ \(V_1\)): \(V_3\) 2.8 % · \(V_5 = V_7 = 0\) · \(V_9\) 20.3 % · \(V_{11}\) 18.9 % · \(V_{13}\) 11.2 %

สามมุมฆ่า 5 และ 7 ได้จริง ในระบบ 3 เฟสแรงดันไลน์ตัด 3 และ 9 ทิ้งเอง ฮาร์มอนิกแรกที่เหลือคือ 11 และ 13 ซึ่งกรองง่ายกว่ามาก ตรวจด้วยแล็บโหมด “พิมพ์สมการเอง” ได้

Sinusoidal PWM: ย้ายฮาร์มอนิกไปความถี่สวิตชิ่ง กลาง

เทียบสัญญาณอ้างอิงไซน์ (ความถี่ขาออก \(f_1\)) กับคลื่นพาหะสามเหลี่ยม (ความถี่ \(f_s\)) สวิตช์บนเปิดเมื่ออ้างอิงสูงกว่าพาหะ ค่าเฉลี่ยเฉพาะที่ของพัลส์ (local average) ติดตามไซน์ ฮาร์มอนิกหลักจึงแปรตรงกับขนาดของอ้างอิง ส่วนฮาร์มอนิกที่เหลือเป็นไซด์แบนด์รอบความถี่พาหะ (การคูณสัญญาณ C12)

V5 SPWM fundamentals นิยามและฮาร์มอนิกหลัก

\[ m_a = \frac{\hat v_{ref}}{\hat v_{tri}},\qquad m_f = \frac{f_s}{f_1},\qquad \hat V_1 = m_a\frac{V_{dc}}{2}\;(\text{ครึ่งบริดจ์}),\qquad \hat V_1 = m_aV_{dc}\;(\text{เต็มบริดจ์}),\qquad m_a \le 1 \]

V6 Where the PWM harmonics are ตำแหน่งไซด์แบนด์

\[ h = j\,m_f \pm k:\quad \text{ไบโพลาร์: } j \text{ คี่} \to k \text{ คู่ (0, 2, 4)},\; j \text{ คู่} \to k \text{ คี่ (1, 3)} \qquad \text{ยูนิโพลาร์: กลุ่ม } j \text{ คี่หายหมด เหลือ } 2m_f \pm 1, 2m_f \pm 3, \dots \]

ฮาร์มอนิกต่ำกว่า \(m_f - 4\) แทบไม่มีเมื่อ \(m_a \le 1\) ตัวกรองจึงออกแบบที่ \(f_s\) (หรือ \(2f_s\) สำหรับยูนิโพลาร์) ไม่ใช่ที่ 150 Hz

ขนาดฮาร์มอนิกของ SPWM ไบโพลาร์ (ค่ายอดหารด้วย \(V_{dc}/2\)) คำนวณแบบปิดในแล็บที่ \(m_f\) = 51 · ยูนิโพลาร์ใช้คอลัมน์ \(2m_f \pm 1\), \(2m_f \pm 3\) เดียวกันแต่หารด้วย \(V_{dc}\) และไม่มีกลุ่ม \(m_f\), \(3m_f\)

V7 Choosing mf เลือก mf

\[ m_f \in \mathbb Z,\quad m_f \text{ คี่},\quad m_f = 3k \;(\text{3 เฟส}) \]

จำนวนเต็ม: เป็นคาบพอดี ไม่มีอินเตอร์ฮาร์มอนิก · คี่: สมมาตรครึ่งคลื่น ไม่มีคู่ · 3k: กลุ่มที่ \(m_f\) ของสามเฟสเป็นลำดับศูนย์ หายจากแรงดันไลน์ (เหลือ \(m_f \pm 2\)) · เมื่อ \(m_f\) > 21 ข้อเหล่านี้สำคัญน้อยลง

V8 Overmodulation โอเวอร์มอดูเลชัน \(m_a \gt 1\)

\[ m_a\frac{V_{dc}}{2} \lt \hat V_1 \le \frac{4}{\pi}\cdot\frac{V_{dc}}{2} \]

พัลส์บางช่วงหายไป \(V_1\) เพิ่มไม่เป็นเชิงเส้นจนเข้าใกล้คลื่นสี่เหลี่ยม ฮาร์มอนิกต่ำ 3, 5, 7 กลับมา ลองตั้ง \(m_a\) = 1.3 ในแล็บ

V9 Three-phase SPWM แรงดันไลน์

\[ V_{LL1,rms} = \frac{\sqrt3}{2\sqrt2}\,m_aV_{dc} = 0.612\,m_aV_{dc} \]

ฉีดฮาร์มอนิกที่ 3 ในอ้างอิง (หรือใช้ SVPWM) เพิ่มได้อีก 15.5 % เพราะฮาร์มอนิกที่ 3 หายในแรงดันไลน์ (ลำดับศูนย์)

ตัวอย่าง V-3 · อินเวอร์เตอร์ 1 เฟส 220 V พร้อมฟิลเตอร์

เต็มบริดจ์ยูนิโพลาร์ \(V_{dc}\) = 400 V, \(m_a\) = 0.8, \(f_1\) = 50 Hz, \(m_f\) = 21 (สวิตช์ 1.05 kHz) ฟิลเตอร์ L = 3 mH, C = 20 µF โหลด 20 Ω หาแรงดันขาออกและ THD

  1. V5: \(\hat V_1 = 0.8 \times 400 = 320\) V (226 V RMS) · THD ก่อนกรอง 72 %

  2. V6 ยูนิโพลาร์: ไม่มีกลุ่มที่ 21 · กลุ่มใหญ่ที่ 41, 43 (2050, 2150 Hz) ยอด 125.7 V และ 39, 45 ยอด 55.8 V

  3. ฟิลเตอร์ \(f_0 = \frac{1}{2\pi\sqrt{LC}} = 650\) Hz · A2 ที่ 2050 Hz \(|H| = 0.109\) → ฮาร์มอนิกที่ 41 เหลือ 13.7 V

  4. รวมทุกฮาร์มอนิกที่ขาออก: \(V_1\) = 227 V RMS (ฟิลเตอร์ยกขึ้นเล็กน้อย) THD = 6.4 %

ได้ 227 V RMS THD 6.4 % ยังเกิน 5 % ทางเลือก: เพิ่ม \(m_f\) (สวิตช์เร็วขึ้น ฮาร์มอนิกย้ายไกลขึ้น ลดลงตาม \(f^2\)) หรือเพิ่ม LC · เปิดแล็บวงจร “SPWM → ฟิลเตอร์ LC ได้ไซน์” เพื่อลองปรับ

V10 Weighted THD WTHD: ความเพี้ยนของกระแสในโหลดเหนี่ยวนำ

\[ \mathrm{WTHD} = \frac{\sqrt{\sum_{h\ge2}(V_h/h)^2}}{V_1} \]

กระแสในโหลด L ∝ \(V_h/(hX_1)\) WTHD จึงทำนาย THD ของกระแสมอเตอร์ได้ดีกว่า THD ของแรงดัน ใช้เปรียบเทียบวิธี PWM ต่าง ๆ
