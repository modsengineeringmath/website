// บทที่ 3 · คณิตศาสตร์วิศวกรรม

พีชคณิตของเวกเตอร์ ผลคูณจุด และผลคูณไขว้

แรง สนามไฟฟ้า สนามแม่เหล็ก และแรงบิดในมอเตอร์ ล้วนมีทั้งขนาดและทิศทาง เวกเตอร์คือภาษาที่ใช้คำนวณปริมาณเหล่านี้ และผลคูณสองแบบของเวกเตอร์ตอบคำถามที่ต่างกันโดยสิ้นเชิง

เขียนโดย อาจารย์มดอัปเดต
สรุปใน 30 วินาที
  • ขนาดของเวกเตอร์ \(|\vec A| = \sqrt{a_1^2 + a_2^2 + a_3^2}\)
  • ผลคูณจุด ได้สเกลาร์ \(\vec A\cdot\vec B = |\vec A||\vec B|\cos\theta\) ใช้หามุมและการฉาย
  • ผลคูณไขว้ ได้เวกเตอร์ตั้งฉาก ขนาด \(|\vec A||\vec B|\sin\theta\) ทิศตามกฎมือขวา
  • แรงบนตัวนำในสนามแม่เหล็ก \(\vec F = I\,\vec L\times\vec B\) คือหลักการของมอเตอร์

เวกเตอร์คืออะไร

เวกเตอร์ในสามมิติเขียนในรูปองค์ประกอบตามแกน \(x, y, z\) โดยใช้เวกเตอร์หนึ่งหน่วย \(\hat{i}, \hat{j}, \hat{k}\)

การบวกและลบเวกเตอร์ทำทีละองค์ประกอบ ส่วนเวกเตอร์หนึ่งหน่วยในทิศของ \(\vec A\) คือ \(\hat a = \vec A / |\vec A|\) ซึ่งเก็บเฉพาะทิศทาง ทิ้งขนาด

ผลคูณจุด (Dot Product)

ผลคูณจุดคำนวณได้สองทาง ทางหนึ่งจากองค์ประกอบ อีกทางจากขนาดและมุม การที่ทั้งสองทางเท่ากันทำให้เราหามุมระหว่างเวกเตอร์ได้

ความหมายเชิงกายภาพคือ "เอาเฉพาะส่วนที่ไปทางเดียวกัน" เช่น งานที่แรงทำ \(W = \vec F\cdot\vec d\) นับเฉพาะแรงในทิศการเคลื่อนที่ ส่วนการฉายเวกเตอร์ \(\vec A\) ลงบน \(\vec B\) คือ

\[ \operatorname{proj}_{\vec B}\vec A = \frac{\vec A\cdot\vec B}{|\vec B|^2}\,\vec B \]
เชื่อมกับวงจรไฟฟ้ากระแสสลับ: กำลังไฟฟ้าจริง \(P = |V||I|\cos\varphi\) มีโครงสร้างเดียวกับผลคูณจุด คือนับเฉพาะส่วนของกระแสที่ร่วมเฟสกับแรงดัน \(\cos\varphi\) ในที่นี้คือตัวประกอบกำลัง (power factor)

ผลคูณไขว้ (Cross Product)

ผลคูณไขว้ให้ผลเป็นเวกเตอร์ใหม่ที่ตั้งฉากกับทั้ง \(\vec A\) และ \(\vec B\) คำนวณได้สะดวกด้วยดีเทอร์มิแนนต์ (ดูวิธีหาดีเทอร์มิแนนต์ได้ในบท เมทริกซ์และดีเทอร์มิแนนต์)

ทิศของผลคูณไขว้หาด้วยกฎมือขวา ชี้นิ้วไปตาม \(\vec A\) งอนิ้วเข้าหา \(\vec B\) นิ้วโป้งชี้ทิศของ \(\vec A\times\vec B\) ปริมาณทางไฟฟ้าที่ใช้ผลคูณไขว้ เช่น แรงบิด \(\vec\tau = \vec r\times\vec F\) และแรงที่กระทำต่อตัวนำ \(\vec F = I\,\vec L\times\vec B\)

ตัวอย่างการคำนวณ

ตัวอย่างที่ 1

กำหนด \(\vec A = (1, 2, 2)\) และ \(\vec B = (3, 0, 4)\) จงหาขนาด มุมระหว่างเวกเตอร์ และ \(\vec A\times\vec B\)

ดูวิธีทำ

ขนาด

\[ \begin{aligned} |\vec A| &= \sqrt{1+4+4} = 3 \\ |\vec B| &= \sqrt{9+0+16} = 5 \end{aligned} \]

ผลคูณจุดและมุม

\[ \vec A\cdot\vec B = (1)(3) + (2)(0) + (2)(4) = 11 \] \[ \cos\theta = \frac{11}{(3)(5)} = \frac{11}{15} \;\Rightarrow\; \theta \approx 42.8^\circ \]

ผลคูณไขว้

\[ \begin{aligned} \vec A\times\vec B &= \big(2\cdot4 - 2\cdot0\big)\hat{i} + \big(2\cdot3 - 1\cdot4\big)\hat{j} + \big(1\cdot0 - 2\cdot3\big)\hat{k} \\ &= (8,\ 2,\ -6) \end{aligned} \]

ตรวจคำตอบ ผลคูณไขว้ต้องตั้งฉากกับทั้งสองเวกเตอร์

\[ \begin{aligned} (8,2,-6)\cdot(1,2,2) &= 8+4-12 = 0 \\ (8,2,-6)\cdot(3,0,4) &= 24+0-24 = 0 \end{aligned} \]

\(|\vec A| = 3,\ |\vec B| = 5,\ \theta \approx 42.8^\circ,\ \vec A\times\vec B = (8, 2, -6)\) และขนาด \(\sqrt{104} \approx 10.2\) ตรงกับ \(15\sin 42.8^\circ\)

ตัวอย่างที่ 2 · มอเตอร์

แรงที่กระทำต่อลวดตัวนำในสนามแม่เหล็ก

ลวดยาว 0.5 m วางตามแกน \(x\) มีกระแส 2 A ไหลในทิศ \(+x\) อยู่ในสนามแม่เหล็กสม่ำเสมอ 0.4 T ในทิศ \(+z\) จงหาแรงที่กระทำต่อลวด

ดูวิธีทำ

เขียน \(\vec L = 0.5\,\hat{i}\) m และ \(\vec B = 0.4\,\hat{k}\) T แล้วใช้ \(\hat{i}\times\hat{k} = -\hat{j}\)

\[ \begin{aligned} \vec F = I\,\vec L\times\vec B &= 2\,(0.5\,\hat{i}\times 0.4\,\hat{k}) \\ &= 0.4\,(\hat{i}\times\hat{k}) = -0.4\,\hat{j}\ \text{N} \end{aligned} \]

แรงขนาด 0.4 N ในทิศ \(-y\) ตั้งฉากกับทั้งกระแสและสนาม แรงลักษณะนี้คือสิ่งที่ทำให้ขดลวดในมอเตอร์หมุน

ต่อยอดไปบทถัดไป

สูตรผลคูณไขว้ที่ใช้ดีเทอร์มิแนนต์เป็นสะพานไปสู่บทถัดไป เมทริกซ์และดีเทอร์มิแนนต์ ซึ่งจะใช้แก้ระบบสมการของวงจรหลายลูป
