ระบบอันดับสอง: ζ และ ωn

ζ กำหนด รูปร่าง ของผลตอบสนอง ส่วน ωn กำหนด ความเร็ว ปรับค่าทั้งสอง หรือค่า R, L, C ของวงจรจริง หรือลากขั้วบนระนาบ s แล้วดูกราฟเวลา เปลือกเอกซ์โพเนนเชียล Bode plot และระนาบเฟสเปลี่ยนไปพร้อมกัน อ่านทฤษฎีด้านล่าง ↓

ζ กับ ωn ทำหน้าที่ต่างกัน

แทนเวลาด้วยเวลาปรับมาตรฐาน \(t' = \omega_n t\) จะได้ \(\dfrac{d}{dt} = \omega_n\dfrac{d}{dt'}\) แทนลงในสมการแล้วหารด้วย \(\omega_n^2\)

\[ \frac{d^2y}{dt'^2} + 2\zeta\,\frac{dy}{dt'} + y = K\,u \]

ωn หายไปจากสมการทั้งหมด เหลือเพียง ζ แปลว่า รูปร่างของกราฟเมื่อพล็อตเทียบกับ \(\omega_n t\) ขึ้นกับ ζ อย่างเดียว ส่วน ωn ทำหน้าที่เพียงยืดหรือหดแกนเวลา ในแล็บด้านบน ลองเลือกแกน "เวลาปรับมาตรฐาน ωₙt" แล้วกด "กวาด ωn" กราฟจะนิ่งสนิท จากนั้นกด "กวาด ζ" จะเห็นรูปร่างเปลี่ยนตั้งแต่แกว่งมากจนถึงค่อย ๆ ขึ้นช้า ๆ

สี่กรณีของ ζ

ζชื่อขั้วผลตอบสนองขั้นบันได
0ไม่หน่วง\(\pm j\omega_n\) บนแกนจินตภาพแกว่งตลอดไป พุ่งเกิน 100%
0 < ζ < 1หน่วงน้อยคู่สังยุค \(-\zeta\omega_n \pm j\omega_d\)พุ่งเกินแล้วแกว่งลดลงตามเปลือก
1หน่วงวิกฤตขั้วซ้ำที่ \(-\omega_n\)เร็วที่สุดโดยไม่พุ่งเกิน
> 1หน่วงมากขั้วจริงสองตัวไม่พุ่งเกิน ช้า ถูกครอบงำด้วยขั้วที่ใกล้แกนจินตภาพ

ตำแหน่งขั้วบอกทุกอย่าง

  • ระยะจากจุดกำเนิด คือ ωn ขั้วที่อยู่บนวงกลมเดียวกันมีความเร็วโดยรวมเท่ากัน
  • มุม θ วัดจากแกนจริงลบ กำหนด ζ จึงกำหนด %OS เส้นรัศมีที่มุมเดียวกันให้ %OS เท่ากัน
  • ส่วนจริง σ = ζωn กำหนดอัตราการลดลง เปลือก \(e^{-\sigma t}\) มีค่าคงตัวเวลา \(\tau = 1/\sigma\) และเวลาเข้าที่ \(t_s \approx 4\tau\)
  • ส่วนจินตภาพ ωd กำหนดความถี่การแกว่ง คาบ \(T_d = 2\pi/\omega_d\) และเวลาถึงยอด \(t_p = \pi/\omega_d\)

ในแล็บ ลากขั้วบนระนาบ s ไปตามวงกลม (ωn คงที่) แล้วดูรูปร่างเปลี่ยน หรือลากออกไปตามเส้นรัศมี (ζ คงที่) แล้วดูว่ากราฟเร็วขึ้นโดย %OS เท่าเดิม

สเปกในโดเมนเวลา

ตัวอย่างที่ 1

ระบบมี ζ = 0.5 และ ωn = 4 rad/s จงหา %OS, tₚ และ tₛ

ดูวิธีทำ \[ \omega_d = 4\sqrt{1 - 0.25} = 3.46\ \text{rad/s} \qquad \%OS = 100\,e^{-0.5\pi/0.866} = 16.3\% \] \[ t_p = \frac{\pi}{3.46} = 0.907\ \text{s} \qquad t_s \approx \frac{4}{0.5 \times 4} = 2\ \text{s} \]

%OS = 16.3%, tₚ = 0.907 s, tₛ ≈ 2 s ลองตั้ง ζ = 0.5 และ ωn = 4 ในแล็บแล้วเปิด "แถบเข้าที่ ±2%" เพื่อเทียบค่า tₛ จริงกับสูตร

ตัวอย่างที่ 2 · ออกแบบ

ต้องการให้พุ่งเกินไม่เกิน 5% ต้องใช้ ζ อย่างน้อยเท่าใด

ดูวิธีทำ

กลับสูตร %OS โดยให้ \(L = -\ln(0.05)\)

\[ \zeta = \frac{-\ln(\%OS/100)}{\sqrt{\pi^2 + \ln^2(\%OS/100)}} = \frac{2.996}{\sqrt{9.870 + 8.974}} = 0.690 \]

ζ ≥ 0.69 ซึ่งตรงกับมุมขั้ว θ ≤ 46.4° บนระนาบ s

ผลตอบสนองเชิงความถี่

\[ \lvert G(j\omega)\rvert = \frac{\omega_n^2}{\sqrt{(\omega_n^2-\omega^2)^2 + (2\zeta\omega_n\omega)^2}} \qquad \angle G(j\omega) = -\tan^{-1}\frac{2\zeta\omega_n\omega}{\omega_n^2 - \omega^2} \]
  • ที่ \(\omega = \omega_n\) เฟสเท่ากับ −90° เสมอ และขนาดเท่ากับ \(1/(2\zeta)\)
  • ถ้า \(\zeta < 0.707\) มียอดเรโซแนนซ์ \(M_r = \dfrac{1}{2\zeta\sqrt{1-\zeta^2}}\) ที่ \(\omega_r = \omega_n\sqrt{1-2\zeta^2}\)

ตัวอย่างวงจร RLC

ตัวอย่างที่ 3 · วงจร

วงจร RLC อนุกรม R = 20 Ω, L = 100 mH, C = 100 µF ป้อนแรงดันขั้นบันได จงหา ωn, ζ, %OS และ tₛ ของแรงดันตัวเก็บประจุ

ดูวิธีทำ \[ \omega_n = \frac{1}{\sqrt{(0.1)(100\times10^{-6})}} = 316\ \text{rad/s} \qquad \zeta = \frac{20}{2}\sqrt{\frac{100\times10^{-6}}{0.1}} = 0.316 \] \[ \%OS = 100\,e^{-0.316\pi/\sqrt{1-0.1}} = 35.1\% \qquad \tau = \frac{1}{\zeta\omega_n} = 10\ \text{ms} \qquad t_s \approx 4\tau = 40\ \text{ms} \]

ωn = 316 rad/s, ζ = 0.316, พุ่งเกิน 35.1% และเข้าที่ประมาณ 40 ms เลือก "วงจร RLC อนุกรม" ในแล็บ ค่าเริ่มต้นคือวงจรนี้พอดี ลองเพิ่ม R จะเห็น ζ เพิ่มขึ้นและการพุ่งเกินลดลง
