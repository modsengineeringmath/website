// บทที่ 28.6 · สมการเชิงอนุพันธ์ · Exam Practice

โจทย์สมการเชิงอนุพันธ์พร้อมเฉลย (ODE Exam Practice): 32 ข้อ 3 ชุด ตรวจด้วยการแทนกลับทุกข้อ

ทุกข้อซ่อนเฉลยไว้ ลองทำก่อนแล้วค่อยเปิด เฉลยเขียนเฉพาะขั้นที่สำคัญ ป้ายสีน้ำเงินบอกเอกลักษณ์ตรีโกณ ป้ายสีส้มบอกเทคนิคทางแคลคูลัส ถ้าอยากเห็นทุกขั้นแบบละเอียด ใส่ข้อเดียวกันในเครื่องแก้สมการเชิงอนุพันธ์ ได้เลย

เขียนโดย อาจารย์มดอัปเดต
ชุด A อันดับหนึ่ง ชุด B อันดับสอง ชุด C ประยุกต์

ชุด A · อันดับหนึ่ง (10 ข้อ) พื้นฐาน

A1\(y' = 3y,\ y(0) = 2\)

แยกตัวแปร \(\tfrac{dy}{y} = 3\,dt\)

\(y = 2e^{3t}\) · แยกตัวแปร

A2\(y' = t^2y\)

\(\ln|y| = \tfrac{t^3}{3} + C\)

\(y = Ce^{t^3/3}\) · แยกตัวแปร

A3\(y' = \dfrac{t}{y},\ y(0) = 2\)

\(y\,dy = t\,dt \Rightarrow \tfrac{y^2}{2} = \tfrac{t^2}{2} + C\)

\(y(0) = 2\) ได้ \(y^2 = t^2 + 4\) เลือกรากบวก

\(y = \sqrt{t^2 + 4}\) · แยกตัวแปร

A4\(y' = \cos t\,(1 + y^2),\ y(0) = 0\)

\(\dfrac{dy}{1+y^2} = \cos t\,dt\) อินทิเกรตได้ \(\tan^{-1}y = \sin t + C\) ฟังก์ชันตรีโกณผกผัน

\(y = \tan(\sin t)\) พีทาโกรัสแบบ tan · คำตอบเป็น tan

A5\(y' + 3y = 6,\ y(0) = 0\)

\(\mu = e^{3t}\), \((e^{3t}y)' = 6e^{3t}\) ตัวประกอบอินทิเกรต

\(y = 2(1 - e^{-3t})\) · ตัวประกอบอินทิเกรต

A6\(y' - 2y = e^{t}\)

\(\mu = e^{-2t}\), \((e^{-2t}y)' = e^{-t}\)

\(y = -e^t + Ce^{2t}\) · ตัวประกอบอินทิเกรต

A7\(ty' + 2y = t^2,\ t > 0\)

หารด้วย t: \(y' + \tfrac2ty = t\) ได้ \(\mu = t^2\)

\((t^2y)' = t^3\)

\(y = \dfrac{t^2}{4} + \dfrac{C}{t^2}\) · ตัวประกอบอินทิเกรต

A8\(y' + y = \cos t,\ y(0) = 0\)

เดา \(y_p = A\cos t + B\sin t\) ได้ \(A + B = 1\) และ \(B - A = 0\) เลื่อนเฟส 90° (โคฟังก์ชัน)

รวมเป็นคลื่นเดียว รวมเป็นคลื่นเดียว

\(y = \tfrac12(\cos t + \sin t) - \tfrac12e^{-t} = \tfrac{\sqrt2}{2}\cos(t - \tfrac{\pi}{4}) - \tfrac12e^{-t}\) · แรงขับ sin cos

A9วงจร RC: R = 2 kΩ, C = 100 µF ชาร์จจาก 9 V ตอนแรกว่าง หา v(t) และเวลาที่ v = 6 V

\(\tau = RC = 0.2\) s, \(v = 9(1 - e^{-t/0.2})\)

\(6 = 9(1 - e^{-5t}) \Rightarrow t = 0.2\ln3\)

\(v = 9(1 - e^{-5t})\) V และ \(t \approx 0.22\) s · RC

A10\((3x^2 + y)\,dx + (x + 2y)\,dy = 0\)

\(M_y = 1 = N_x\) แม่นตรง

\(F = x^3 + xy + g(y)\), \(F_y = x + g' = x + 2y \Rightarrow g = y^2\)

\(x^3 + xy + y^2 = C\) · แม่นตรง

ชุด B · อันดับสองและไม่เอกพันธ์ (12 ข้อ) กลาง

B1\(y'' + y' - 6y = 0\)

\(r^2 + r - 6 = (r + 3)(r - 2)\)

\(y = C_1e^{2t} + C_2e^{-3t}\) · รากจริง

B2\(y'' - 6y' + 9y = 0,\ y(0) = 1,\ y'(0) = 0\)

รากซ้ำ r = 3: \(y = (C_1 + C_2t)e^{3t}\)

\(C_1 = 1\), \(3C_1 + C_2 = 0\)

\(y = (1 - 3t)e^{3t}\) · รากซ้ำ

B3\(y'' + 16y = 0,\ y(0) = 3,\ y'(0) = 16\)

\(r = \pm4j\) ได้ \(y = C_1\cos4t + C_2\sin4t\) สูตรออยเลอร์

\(C_1 = 3,\ 4C_2 = 16\) แล้วรวมเป็นคลื่นเดียว รวมเป็นคลื่นเดียว

\(y = 3\cos4t + 4\sin4t = 5\cos(4t - 53.13^\circ)\) · R cos(ωt − φ)

B4\(y'' + 4y' + 13y = 0\)

\(r = -2 \pm 3j\) สูตรออยเลอร์

\(y = e^{-2t}(C_1\cos3t + C_2\sin3t)\) · รากเชิงซ้อน

B5\(y'' + 2y' + 2y = 0,\ y(0) = 0,\ y'(0) = 2\)

\(r = -1 \pm j\)

\(C_1 = 0\), \(-C_1 + C_2 = 2\)

\(y = 2e^{-t}\sin t\) · รากเชิงซ้อน

B6\(y'' - 4y = 8\)

\(y_h = C_1e^{2t} + C_2e^{-2t}\), เดา \(y_p = A\): \(-4A = 8\)

\(y = C_1e^{2t} + C_2e^{-2t} - 2\) · ตารางรูปเดา

B7\(y'' + 3y' + 2y = 4t\)

เดา \(y_p = At + B\): \(3A + 2(At + B) = 4t\) ได้ \(A = 2,\ B = -3\)

\(y = C_1e^{-t} + C_2e^{-2t} + 2t - 3\) · พหุนาม

B8\(y'' - y = e^{t}\)

\(e^t\) ซ้ำกับ \(y_h\) ต้องคูณ t: \(y_p = Ate^t\)

\(A\cdot P'(1) = 1\), \(P'(r) = 2r\) ได้ \(A = \tfrac12\)

\(y = C_1e^t + C_2e^{-t} + \tfrac12te^t\) · กฎคูณ t

B9\(y'' + y' + y = \sin t\)

เดา \(A\cos t + B\sin t\) เลื่อนเฟส 90° (โคฟังก์ชัน) แทนแล้วพจน์ \(A\cos t\) จาก \(y\) หักล้างกับ \(-A\cos t\) จาก \(y''\) เหลือ \(B\cos t - A\sin t = \sin t\)

เทียบสัมประสิทธิ์ได้ \(B = 0,\ A = -1\)

\(y_p = -\cos t\) · คำตอบทั่วไป \(e^{-t/2}\big(C_1\cos\tfrac{\sqrt3}{2}t + C_2\sin\tfrac{\sqrt3}{2}t\big) - \cos t\) · แรงขับ sin

B10\(y'' + 9y = 6\sin3t\)

เรโซแนนซ์ (ความถี่ธรรมชาติ 3) เดา \(t(A\cos3t + B\sin3t)\)

แทนได้ \(-6A\sin3t + 6B\cos3t = 6\sin3t\) ได้ \(A = -1,\ B = 0\)

\(y_p = -t\cos3t\) · เรโซแนนซ์

B11\(y'' + 4y = \sin t,\ y(0) = 0,\ y'(0) = 0\)

\(y_p = \tfrac{\sin t}{4 - 1} = \tfrac13\sin t\)

เงื่อนไขเริ่มต้นได้ \(C_1 = 0,\ 2C_2 + \tfrac13 = 0\)

\(y = \tfrac13\sin t - \tfrac16\sin2t\) · ใกล้บีต

B12\(y'' + y = \tan t\) (แปรผันพารามิเตอร์)

\(W = 1\) เอกลักษณ์พีทาโกรัส, \(u_1' = -\sin t\tan t = -\tfrac{\sin^2t}{\cos t} = \cos t - \sec t\) เอกลักษณ์พีทาโกรัส ส่วนกลับ

\(u_1 = \sin t - \ln|\sec t + \tan t|\), \(u_2' = \cos t\tan t = \sin t \Rightarrow u_2 = -\cos t\)

\(y_p = -\cos t\,\ln|\sec t + \tan t|\) · แปรผันพารามิเตอร์

ชุด C · การประยุกต์ ยูเลอร์–โคชี และวิธีเชิงตัวเลข (10 ข้อ) ประยุกต์

C1มวล 2 kg สปริง k = 50 N/m ไม่มีตัวหน่วง ดึงออก 0.1 m แล้วปล่อย หา x(t) และคาบ

\(2x'' + 50x = 0 \Rightarrow \omega_n = 5\) rad/s

\(x(0) = 0.1,\ x'(0) = 0\)

\(x = 0.1\cos5t\) m, \(T = \tfrac{2\pi}{5} \approx 1.257\) s · ωn

C2ระบบเดิมเพิ่มตัวหน่วง c = 12 N·s/m หา ζ และชนิดการหน่วง

\(\zeta = \tfrac{c}{2\sqrt{mk}} = \tfrac{12}{2\cdot10} = 0.6\)

\(\zeta = 0.6\) หน่วงน้อย แกว่งด้วย \(\omega_d = 5\sqrt{1 - 0.36} = 4\) rad/s · ζ

C3วงจร RLC: L = 1 H, C = 0.25 F, R = 4 Ω ไม่มีแหล่งจ่าย q(0) = 1 C, i(0) = 0 หา q(t)

\(q'' + 4q' + 4q = 0\) รากซ้ำ −2 (หน่วงวิกฤต)

\(C_1 = 1\), \(-2 + C_2 = 0\)

\(q = (1 + 2t)e^{-2t}\) C · RLC

C4ระบบ \(x'' + 2\zeta\omega_nx' + \omega_n^2x\) มี ζ = 0.5 หา %OS ของผลตอบสนองขั้นบันได

\(\%OS = 100e^{-\pi\zeta/\sqrt{1-\zeta^2}} = 100e^{-\pi(0.5)/0.866}\)

\(\approx 16.3\%\) · %OS

C5ลูกตุ้มยาว 0.5 m (g = 9.81) มุมเล็ก หาคาบ

\(T = 2\pi\sqrt{L/g}\) อนุกรมของ sin cos

\(T \approx 1.419\) s · ลูกตุ้ม

C6\(x^2y'' - 2xy' + 2y = 0,\ x > 0\)

ลอง \(y = x^m\): \(m(m-1) - 2m + 2 = (m-1)(m-2) = 0\)

\(y = C_1x + C_2x^2\) · ยูเลอร์–โคชี

C7\(x^2y'' + xy' + 9y = 0,\ x > 0\)

\(m^2 + 9 = 0 \Rightarrow m = \pm3j\) แล้ว \(x^{3j} = e^{3j\ln x}\) สูตรออยเลอร์

\(y = C_1\cos(3\ln x) + C_2\sin(3\ln x)\) · ยูเลอร์–โคชี

C8ใช้ออยเลอร์ h = 0.5 สองก้าวประมาณ y(1) ของ \(y' = y,\ y(0) = 1\) เทียบค่าจริง

\(y_1 = 1 + 0.5(1) = 1.5\), \(y_2 = 1.5 + 0.5(1.5) = 2.25\)

\(2.25\) เทียบกับ \(e \approx 2.718\) คลาดเคลื่อนราว 17% · ออยเลอร์

C9ออยเลอร์กับ \(y' = -20y\) ต้องใช้ h เท่าไรจึงไม่ระเบิด

ตัวคูณต่อก้าว \(1 - 20h\) ต้องมีขนาดน้อยกว่า 1

\(h < 0.1\) · เสถียรภาพ

C10ถังผสม 200 L รับน้ำเกลือ 5 g/L ที่ 4 L/min ปล่อยออก 4 L/min เริ่มจากน้ำจืด หามวลเกลือ A(t)

\(A' = 20 - \tfrac{4A}{200} = 20 - \tfrac{A}{50}\)

\(A = 1000(1 - e^{-t/50})\) g · ถังผสม
