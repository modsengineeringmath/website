วิธีเชิงตัวเลขสำหรับสมการเชิงอนุพันธ์ (Numerical Methods for ODEs): Euler, Heun, RK4 และระบบสมการ

สมการส่วนใหญ่ในงานจริงแก้เป็นสูตรไม่ได้ ลูกตุ้มมุมใหญ่ มอเตอร์ที่แกนเหล็กอิ่มตัว ระบบควบคุมที่มีตัวจำกัด ทั้งหมดต้องให้คอมพิวเตอร์เดินหาคำตอบทีละก้าว หน้านี้อธิบายสามวิธีที่ใช้มากที่สุด ทำไมแต่ละวิธีแม่นต่างกัน และเมื่อไรขนาดก้าวใหญ่เกินไปจนคำตอบระเบิด

วิธีของออยเลอร์: เดินตามเส้นสัมผัส

สมการ \(y' = f(t, y)\) บอกความชันที่จุดปัจจุบัน ถ้าเดินไปข้างหน้าสั้น ๆ เป็นระยะ h ตามเส้นสัมผัส จะได้ค่าประมาณของจุดถัดไป นี่คือการประมาณเชิงเส้นที่ใช้ซ้ำ ๆ ประมาณเชิงเส้น

\[ y_{n+1} = y_n + h\,f(t_n, y_n),\qquad t_{n+1} = t_n + h \]

ปัญหาคือความชันเปลี่ยนไปตลอดทางในก้าวนั้น แต่ออยเลอร์ใช้แค่ความชันที่ต้นก้าว ถ้าเส้นคำตอบโค้ง เส้นสัมผัสจะหลุดออกจากเส้นจริงเรื่อย ๆ ความคลาดเคลื่อนต่อก้าวเป็น \(O(h^2)\) และสะสมจากจำนวนก้าว \(1/h\) จึงเหลือความคลาดเคลื่อนรวม \(O(h)\)

วิธีของฮอยน์ (Heun / Improved Euler): เฉลี่ยความชันหัวท้าย

เดินแบบออยเลอร์ไปก่อนเพื่อ “ดู” ความชันที่ปลายก้าว แล้วกลับมาใช้ค่าเฉลี่ยของความชันต้นกับปลาย

\[ k_1 = f(t_n, y_n),\quad k_2 = f(t_n + h,\ y_n + hk_1),\quad y_{n+1} = y_n + \frac h2(k_1 + k_2) \]

นี่คือกฎสี่เหลี่ยมคางหมูของการอินทิเกรต ความคลาดเคลื่อนรวมเป็น \(O(h^2)\) ลด h ลงครึ่งหนึ่ง ความคลาดเคลื่อนลดราว 4 เท่า

รุงเงอ-คุตตาอันดับ 4 (RK4): มาตรฐานของงานวิศวกรรม

\[ \begin{aligned} k_1 &= f(t_n,\ y_n) \\ k_2 &= f\big(t_n + \tfrac h2,\ y_n + \tfrac h2k_1\big) \\ k_3 &= f\big(t_n + \tfrac h2,\ y_n + \tfrac h2k_2\big) \\ k_4 &= f(t_n + h,\ y_n + hk_3) \\ y_{n+1} &= y_n + \tfrac h6\big(k_1 + 2k_2 + 2k_3 + k_4\big) \end{aligned} \]

น้ำหนัก 1, 2, 2, 1 หารด้วย 6 คือกฎของซิมป์สัน: ความชันกลางก้าวได้น้ำหนักมากกว่าเพราะเป็นตัวแทนของทั้งก้าวได้ดีที่สุด ความคลาดเคลื่อนรวมเป็น \(O(h^4)\)

ตัวเลขจริง: \(y' = t - y,\ y(0) = 1\) ที่ \(t = 1\)

คำตอบจริงคือ \(y = t - 1 + 2e^{-t}\) ได้ \(y(1) = 2e^{-1} \approx 0.735759\)

RK4 ใช้การคำนวณ f มากกว่าออยเลอร์ 4 เท่าต่อก้าว แต่แม่นกว่าหลายหมื่นเท่าที่ h เดียวกัน คุ้มเกือบทุกกรณี

แล็บ: สนามความชันกับสามวิธี

พิมพ์ f(t, y) เอง (ใช้ sin, cos, exp, sqrt, ^ ได้) แตะกราฟเพื่อย้ายจุดเริ่ม แล้วเลื่อนขนาดก้าว h ตารางท้ายแล็บเทียบค่าปลายทางกับคำตอบอ้างอิงที่คำนวณด้วย RK4 ก้าวเล็กมาก

ลองตัวอย่าง “sin t − y” ที่ h = 1: ออยเลอร์จะเหวี่ยงออกนอกคลื่นชัดเจน ส่วน RK4 ยังเกาะเส้นอ้างอิงแทบสนิท คำตอบระยะยาวของสมการนี้คือ \(\tfrac{\sqrt2}{2}\sin(t - \tfrac{\pi}{4})\) รวมเป็นคลื่นเดียว (ดูที่มาในตัวอย่าง 6 ของ 28.1)

เสถียรภาพ: ขนาดก้าวที่ใหญ่เกินไปทำให้คำตอบระเบิด

ลองกับ \(y' = -10y,\ y(0) = 1\) ซึ่งคำตอบจริง \(e^{-10t}\) ลดลงอย่างเรียบร้อย ออยเลอร์ให้ \(y_{n+1} = (1 - 10h)\,y_n\) ทุกก้าวคูณด้วย \(1 - 10h\)

  • h = 0.05: ตัวคูณ 0.5 ลดลงถูกทาง
  • h = 0.15: ตัวคูณ −0.5 ลดลงแต่สลับเครื่องหมาย (แกว่งปลอม)
  • h = 0.25: ตัวคูณ −1.5 โตขึ้นทุกก้าว คำตอบระเบิด ทั้งที่ระบบจริงเสถียร

เงื่อนไขของออยเลอร์สำหรับ \(y' = -\lambda y\) คือ \(h < 2/\lambda\) ระบบที่มีค่าคงที่เวลาเร็วมากปนกับช้ามาก (stiff) เช่นวงจรที่มีตัวเก็บประจุเล็กมากร่วมกับตัวใหญ่ ต้องใช้วิธีโดยนัย (implicit) อย่างที่โปรแกรมจำลองวงจรใช้

สมการอันดับสอง → ระบบอันดับหนึ่ง

ทุกสมการอันดับสองเขียนเป็นระบบสองสมการได้โดยตั้ง \(y_1 = y,\ y_2 = y'\) เช่นลูกตุ้มมุมใหญ่ \(\theta'' = -\tfrac gL\sin\theta\)

\[ \begin{bmatrix} y_1 \\ y_2 \end{bmatrix}' = \begin{bmatrix} y_2 \\ -\tfrac gL\sin y_1 \end{bmatrix} \]

แล้วใช้ RK4 กับเวกเตอร์ทั้งก้อน สูตรเหมือนเดิมทุกตัวอักษร แค่ y และ k กลายเป็นเวกเตอร์

import numpy as np
def rk4(f, t0, y0, t1, n):
    h = (t1 - t0) / n; t = t0; y = np.array(y0, float)
    for _ in range(n):
        k1 = f(t, y); k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2); k4 = f(t + h, y + h*k3)
        y = y + h/6*(k1 + 2*k2 + 2*k3 + k4); t += h
    return y

g, L = 9.81, 1.0
pend = lambda t, y: np.array([y[1], -g/L*np.sin(y[0])])
print(rk4(pend, 0, [np.radians(45), 0], 2.0, 2000))   # มุมและความเร็วเชิงมุมที่ t = 2 s
