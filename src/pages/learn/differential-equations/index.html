สมการเชิงอนุพันธ์ (Differential Equations): ภาพรวม การจำแนก และวิธีเลือกวิธีแก้

กฎทางฟิสิกส์ส่วนใหญ่ไม่ได้บอกตรง ๆ ว่าปริมาณหนึ่งมีค่าเท่าไร แต่บอกว่ามันเปลี่ยนแปลงอย่างไร ตัวเก็บประจุบอกว่า \(i = C\,dv/dt\) สปริงบอกว่าแรงเป็นสัดส่วนกับระยะยืด กาแฟร้อนบอกว่ายิ่งร้อนกว่าห้องยิ่งเย็นลงเร็ว พอนำความสัมพันธ์เหล่านี้มาเขียนเป็นสมการ เราได้สมการที่มีอนุพันธ์อยู่ข้างใน งานของบทนี้คือย้อนกลับจาก “อัตราการเปลี่ยน” ไปหา “ตัวปริมาณ” ให้ได้

เขียนโดย อาจารย์มดอัปเดต
คืออะไร การจำแนก เลือกวิธีแก้ แล็บสนามความชัน เครื่องแก้สมการเชิงอนุพันธ์

สมการเชิงอนุพันธ์คืออะไร

สมการเชิงอนุพันธ์ (differential equation) คือสมการที่ตัวไม่รู้เป็นฟังก์ชัน และมีอนุพันธ์ของฟังก์ชันนั้นอยู่ในสมการ ต่างจากสมการที่เรียนมาตั้งแต่ ม.ต้น ที่ตัวไม่รู้เป็นตัวเลข ลองเทียบดู

สมการพีชคณิตสมการเชิงอนุพันธ์
ตัวอย่าง\(x^2 - 5x + 6 = 0\)\(y' = 2y\)
หาอะไรตัวเลข xฟังก์ชัน y(t)
คำตอบ\(x = 2\) หรือ \(3\)\(y = Ce^{2t}\) ทุกค่า C
ตรวจคำตอบแทนค่า xดิฟ y แล้วแทนทั้ง y และ y′

ลองตรวจ \(y = Ce^{2t}\) ดิฟได้ \(y' = 2Ce^{2t} = 2y\) จริงทุกค่า C คำตอบจึงเป็นตระกูลของฟังก์ชัน ไม่ใช่ตัวเดียว ค่า C ที่เหลืออยู่มาจากการอินทิเกรตหนึ่งครั้ง ถ้ารู้เพิ่มว่า \(y(0) = 3\) จะได้ \(C = 3\) คำตอบเดียวคือ \(y = 3e^{2t}\) โจทย์ที่ให้สมการพร้อมค่าเริ่มต้นแบบนี้เรียกว่าปัญหาค่าเริ่มต้น (initial value problem)

การจำแนกสมการเชิงอนุพันธ์

ก่อนแก้ ต้องรู้ว่าสมการตรงหน้าเป็นชนิดไหน เพราะแต่ละชนิดมีวิธีของมัน ถามสี่ข้อนี้ตามลำดับ

1. สามัญหรือย่อย (ODE / PDE)

สมการเชิงอนุพันธ์สามัญ (ordinary differential equation, ODE) มีตัวแปรอิสระตัวเดียว ส่วนสมการเชิงอนุพันธ์ย่อย (partial differential equation, PDE) มีตัวแปรอิสระหลายตัวและมีอนุพันธ์ย่อย เช่นสมการความร้อน \(\dfrac{\partial u}{\partial t} = \alpha\dfrac{\partial^2u}{\partial x^2}\) บทนี้ทั้งบทเป็น ODE

2. อันดับ (order)

ดูอนุพันธ์ตัวที่สูงที่สุด \(y' = 2y\) อันดับหนึ่ง \(y'' + 4y = 0\) อันดับสอง อันดับบอกจำนวนค่าคงที่ในคำตอบทั่วไป และจำนวนเงื่อนไขเริ่มต้นที่ต้องใช้ ระบบไฟฟ้าและเครื่องกลส่วนใหญ่เป็นอันดับหนึ่งหรือสอง เพราะมีตัวเก็บพลังงานหนึ่งหรือสองตัว

3. เชิงเส้นหรือไม่เชิงเส้น

สมการเป็นเชิงเส้นเมื่อ y และอนุพันธ์ทุกตัวปรากฏแบบ “ยกกำลังหนึ่ง ไม่คูณกันเอง และไม่อยู่ในฟังก์ชันอื่น” รูปทั่วไปของอันดับสองคือ

\[ a_2(t)\,y'' + a_1(t)\,y' + a_0(t)\,y = f(t) \]
สมการเชิงเส้น?เหตุผล
\(y'' + 3ty' + y = \sin t\)ใช่สัมประสิทธิ์เป็นฟังก์ชันของ t ได้ ไม่ผิดกติกา
\(y' = y^2\)ไม่มี \(y^2\)
\(yy'' = 1\)ไม่y คูณกับ y″
\(\theta'' + \sin\theta = 0\)ไม่θ อยู่ใน sin อนุกรมของ sin cos แต่ถ้ามุมเล็ก \(\sin\theta \approx \theta\) จะกลายเป็นเชิงเส้น

ความเป็นเชิงเส้นสำคัญมาก เพราะทำให้ใช้หลักการซ้อนทับ (superposition) ได้ ถ้า \(y_1\) กับ \(y_2\) เป็นคำตอบของสมการเชิงเส้นเอกพันธ์ ผลรวม \(C_1y_1 + C_2y_2\) ก็เป็นคำตอบด้วย วิศวกรไฟฟ้าใช้หลักนี้ทุกครั้งที่วิเคราะห์วงจรด้วยการซ้อนทับแหล่งจ่าย

4. เอกพันธ์ (homogeneous) สองความหมายที่ต้องระวัง

คำว่าเอกพันธ์ในตำราภาษาไทยและอังกฤษใช้สองความหมาย ทำให้สับสนบ่อย

  • ความหมายที่ใช้กับสมการเชิงเส้น (ใช้มากที่สุดในวิศวกรรม): ด้านขวาเป็นศูนย์ เช่น \(y'' + 3y' + 2y = 0\) คำตอบคือการตอบสนองของระบบเมื่อไม่มีแรงหรือแหล่งจ่ายภายนอก ถ้าด้านขวาไม่เป็นศูนย์เรียกว่าไม่เอกพันธ์ (nonhomogeneous)
  • ความหมายที่ใช้กับสมการอันดับหนึ่ง: เขียนได้เป็น \(y' = F(y/x)\) เช่น \(y' = \dfrac{x + y}{x}\) แก้โดยแทน \(v = y/x\) ดูอันดับหนึ่ง: สมการเอกพันธ์แบบ y/x

มองสมการเป็นภาพ: สนามความชัน (slope field)

สมการ \(y' = f(t, y)\) บอกความชันของคำตอบที่ทุกจุด ถ้าวาดขีดสั้น ๆ ตามความชันนั้นทั่วระนาบ จะได้ภาพที่เหมือนเศษเหล็กเรียงตัวในสนามแม่เหล็ก คำตอบทุกเส้นต้องวิ่งตามขีดเหล่านี้ ภาพนี้ช่วยให้เห็นพฤติกรรมของคำตอบก่อนแก้สมการด้วยซ้ำ เช่น ทุกเส้นวิ่งเข้าหาเส้นเดียวกันไหม หรือแยกออกจากกัน

ลองกดตัวอย่าง “y” จะเห็นว่าคำตอบโตแบบเลขชี้กำลังและแยกจากกันเรื่อย ๆ ส่วน “t − y” ทุกเส้นวิ่งเข้าหาเส้นตรง \(y = t - 1\) ไม่ว่าจะเริ่มที่ไหน นั่นคือคำตอบเฉพาะที่ชนะในระยะยาว ส่วนที่เหลือ \(Ce^{-t}\) ค่อย ๆ หายไป เส้นสามสีคือวิธีเชิงตัวเลขสามแบบ อธิบายเต็มในวิธีเชิงตัวเลข

ทำไมบทนี้มีตรีโกณมิติเต็มไปหมด

ตั้งแต่อันดับสองเป็นต้นไป คำตอบของระบบที่สั่นได้จะออกมาเป็น sin และ cos เสมอ เหตุผลมีบรรทัดเดียว: \((\sin\omega t)'' = -\omega^2\sin\omega t\) เลื่อนเฟส 90° (โคฟังก์ชัน) ฟังก์ชันที่ดิฟสองครั้งแล้วได้ตัวเองติดลบคือคำตอบของ \(y'' + \omega^2y = 0\) พอดี แล้วเมื่อรากของสมการลักษณะเฉพาะเป็นจำนวนเชิงซ้อน สูตรออยเลอร์ \(e^{j\theta} = \cos\theta + j\sin\theta\) สูตรออยเลอร์ จะพาเลขชี้กำลังเชิงซ้อนกลับมาเป็น cos กับ sin ส่วนการรวม \(A\cos\omega t + B\sin\omega t\) เป็นคลื่นเดียว \(R\cos(\omega t - \varphi)\) รวมเป็นคลื่นเดียว ใช้ตลอดบทเพื่ออ่านแอมพลิจูดกับเฟส ทุกครั้งที่ใช้เอกลักษณ์เหล่านี้จะมีป้ายสีน้ำเงินกำกับไว้

เส้นทางเรียนในบทนี้

  1. อันดับหนึ่ง: แยกตัวแปร ตัวประกอบอินทิเกรต แม่นตรง เบอร์นูลลี วงจร RC RL การเย็นตัว ถังผสม
  2. อันดับสองเอกพันธ์: สมการลักษณะเฉพาะ สามกรณีของราก สูตรออยเลอร์ ยูเลอร์–โคชี
  3. อันดับสองไม่เอกพันธ์: ตารางเดาคำตอบ เรโซแนนซ์ บีต แปรผันพารามิเตอร์
  4. การประยุกต์: มวล-สปริง RLC อัตราส่วนการหน่วง ผลตอบสนองขั้นบันได ไฟ AC ลูกตุ้ม
  5. วิธีเชิงตัวเลข: Euler, Heun, RK4 ความแม่นและเสถียรภาพ ระบบสมการ
  6. โจทย์พร้อมเฉลย: 32 ข้อ ทุกข้อตรวจด้วยการแทนกลับแล้ว
