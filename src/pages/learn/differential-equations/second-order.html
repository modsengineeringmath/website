// บทที่ 28.2 · สมการเชิงอนุพันธ์ · Second-Order Linear ODEs

สมการเชิงอนุพันธ์อันดับสองแบบเอกพันธ์ (Second-Order Linear ODEs): สมการลักษณะเฉพาะและสามกรณีของราก

หน้านี้คือหัวใจของการสั่นทุกชนิด ทั้งสปริง ลูกตุ้ม วงจร LC และวงจร RLC สมการที่จะแก้คือ \(ay'' + by' + cy = 0\) เมื่อ a, b, c เป็นค่าคงที่ ทั้งหมดลดเหลือการแก้สมการกำลังสองหนึ่งตัว แล้วอ่านคำตอบจากชนิดของราก ส่วนที่ยากที่สุดคือรากเชิงซ้อน ซึ่งต้องใช้ตรีโกณมิติเยอะ ผมจึงอธิบายช้า ๆ และติดป้ายบอกเอกลักษณ์ทุกตัวที่ใช้

เขียนโดย อาจารย์มดอัปเดต
สมการลักษณะเฉพาะ รากเชิงซ้อน R cos(ωt − φ) แล็บแก้สมการ ยูเลอร์–โคชี
สรุปทั้งหน้าในตารางเดียว
ราก \(ar^2 + br + c = 0\)เงื่อนไขคำตอบทั่วไปพฤติกรรม
จริงสองค่า \(r_1 \ne r_2\)\(b^2 - 4ac > 0\)\(C_1e^{r_1t} + C_2e^{r_2t}\)ไม่แกว่ง (หน่วงเกิน)
ซ้ำ \(r\)\(b^2 - 4ac = 0\)\((C_1 + C_2t)e^{rt}\)ไม่แกว่ง (หน่วงวิกฤต)
เชิงซ้อน \(\alpha \pm j\beta\)\(b^2 - 4ac < 0\)\(e^{\alpha t}(C_1\cos\beta t + C_2\sin\beta t)\)แกว่ง (หน่วงน้อย)

สมการลักษณะเฉพาะ: เดา \(e^{rt}\) แล้วสมการจะบอกค่า r

ต้องการฟังก์ชันที่เมื่อนำตัวมันเอง อนุพันธ์อันดับหนึ่ง และอันดับสองมาบวกกันด้วยค่าคงที่ แล้วได้ศูนย์ ฟังก์ชันที่ดิฟแล้วหน้าตาเหมือนเดิมมีแค่เลขชี้กำลัง จึงลอง \(y = e^{rt}\) ดิฟ eˣ

\[ a\,r^2e^{rt} + b\,re^{rt} + c\,e^{rt} = e^{rt}\big(ar^2 + br + c\big) = 0 \]

\(e^{rt}\) ไม่เป็นศูนย์ที่ไหนเลย สมการจึงเหลือ \(ar^2 + br + c = 0\) เรียกว่าสมการลักษณะเฉพาะ (characteristic equation) แก้ด้วยสูตรกำลังสอง

\[ r = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

ดิสคริมิแนนต์ \(b^2 - 4ac\) แบ่งเรื่องทั้งหมดเป็นสามกรณี ในงานจริงสามกรณีนี้ตรงกับระบบที่หน่วงมาก หน่วงพอดี และหน่วงน้อยจนแกว่ง

กรณีที่ 1: รากจริงสองค่าไม่ซ้ำ พื้นฐาน

ตัวอย่าง 1

\(y'' - 5y' + 6y = 0\)

  1. \(r^2 - 5r + 6 = (r - 2)(r - 3) = 0\)

\(y = C_1e^{2t} + C_2e^{3t}\)

ทำไมผลรวมก็เป็นคำตอบด้วย เพราะสมการเป็นเชิงเส้น ถ้าแทน \(C_1y_1 + C_2y_2\) ลงไป แต่ละก้อนให้ศูนย์ของมันเอง ผลรวมจึงเป็นศูนย์ (หลักการซ้อนทับ) และเพราะสมการเป็นอันดับสอง จึงต้องการคำตอบที่เป็นอิสระต่อกันสองตัวพอดี ตรวจความเป็นอิสระด้วยวรอนสเกียน (Wronskian)

\[ W = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = \begin{vmatrix} e^{2t} & e^{3t} \\ 2e^{2t} & 3e^{3t}\end{vmatrix} = e^{5t} \neq 0 \]

กรณีที่ 2: รากซ้ำ และที่มาของ \(t\,e^{rt}\) กลาง

ถ้า \(b^2 = 4ac\) จะได้รากเดียว \(r = -\tfrac{b}{2a}\) และคำตอบ \(e^{rt}\) แค่ตัวเดียว ขาดอีกหนึ่งตัว วิธีหาคือลดอันดับ (reduction of order) ลอง \(y = v(t)\,e^{rt}\) แทนลงไป

\[ y' = (v' + rv)e^{rt},\qquad y'' = (v'' + 2rv' + r^2v)e^{rt} \]

แทนแล้วจัดกลุ่ม พจน์ที่มี v หายเพราะ \(ar^2 + br + c = 0\) พจน์ที่มี v′ หายเพราะ \(2ar + b = 0\) (นี่คือเงื่อนไขรากซ้ำ) เหลือเพียง \(a\,v'' = 0\) จึงได้ \(v = C_1 + C_2t\)

ตัวอย่าง 2

\(y'' + 4y' + 4y = 0\)

  1. \(r^2 + 4r + 4 = (r + 2)^2 = 0\) รากซ้ำ \(r = -2\)

\(y = (C_1 + C_2t)e^{-2t}\)

กรณีที่ 3: รากเชิงซ้อน ทำไมได้ cos และ sin หัวใจของบท

ถ้า \(b^2 < 4ac\) รากเป็นคู่สังยุค \(r = \alpha \pm j\beta\) โดย

\[ \alpha = -\frac{b}{2a},\qquad \beta = \frac{\sqrt{4ac - b^2}}{2a} \]

คำตอบเชิงซ้อนตัวหนึ่งคือ \(e^{(\alpha + j\beta)t}\) แต่ระบบจริงต้องการคำตอบจริง ทางแปลงอยู่ในขั้นตอนต่อไปนี้ ค่อย ๆ อ่านทีละบรรทัด

  1. แยกเลขชี้กำลังด้วยกฎ \(e^{u + v} = e^ue^v\)

    \[ e^{(\alpha + j\beta)t} = e^{\alpha t}\cdot e^{j\beta t} \]

  2. ใช้สูตรออยเลอร์กับก้อนจินตภาพ สูตรออยเลอร์

    \[ e^{j\beta t} = \cos\beta t + j\sin\beta t \] สูตรออยเลอร์ วงกลมหนึ่งหน่วย

  3. ได้คำตอบเชิงซ้อนที่มีทั้งส่วนจริงและส่วนจินตภาพ

    \[ e^{(\alpha + j\beta)t} = e^{\alpha t}\cos\beta t + j\,e^{\alpha t}\sin\beta t \]

  4. สมการมีสัมประสิทธิ์จริง ถ้า \(u + jv\) เป็นคำตอบ แทนลงไปแล้วแยกส่วนจริงกับจินตภาพ จะได้ว่า u และ v ต่างก็เป็นคำตอบเอง จึงเก็บสองตัวนี้มาใช้

    \[ y_1 = e^{\alpha t}\cos\beta t,\qquad y_2 = e^{\alpha t}\sin\beta t \]

  5. อีกทางหนึ่งที่ให้ผลเดียวกัน: รวมรากทั้งคู่ \(Ke^{j\beta t} + \bar Ke^{-j\beta t}\) โดยเลือกค่าคงที่เป็นคู่สังยุค ผลรวมเป็นจริงเสมอ เพราะ \(\cos\beta t = \tfrac{e^{j\beta t} + e^{-j\beta t}}{2}\) cos, sin ในรูปเลขชี้กำลัง

\(y = e^{\alpha t}\big(C_1\cos\beta t + C_2\sin\beta t\big)\)

อ่านความหมายของตัวเลขสองตัวนี้ให้ออก: \(\alpha\) (ส่วนจริง) คุมว่าแอมพลิจูดหดเร็วแค่ไหน เป็นลบเมื่อระบบมีการหน่วง ส่วน \(\beta\) (ส่วนจินตภาพ) คือความถี่เชิงมุมของการแกว่ง คาบของการแกว่งคือ \(2\pi/\beta\) คาบ 2π

ตัวอย่าง 3

\(y'' + 2y' + 5y = 0,\ y(0) = 1,\ y'(0) = 0\)

  1. \(r = \dfrac{-2 \pm \sqrt{4 - 20}}{2} = -1 \pm 2j\) ได้ \(\alpha = -1,\ \beta = 2\)

  2. \(y = e^{-t}(C_1\cos2t + C_2\sin2t)\) และ \(y(0) = 1\) ได้ \(C_1 = 1\) มุมพิเศษ

  3. ดิฟด้วยกฎผลคูณ กฎผลคูณ ที่ \(t = 0\): \(y'(0) = -C_1 + 2C_2 = 0\) ได้ \(C_2 = \tfrac12\)

\(y = e^{-t}\big(\cos2t + \tfrac12\sin2t\big)\)

อ่านคำตอบให้เป็นคลื่น: \(C_1\cos\beta t + C_2\sin\beta t = R\cos(\beta t - \varphi)\)

คำตอบรูป cos บวก sin อ่านยาก บอกไม่ได้ทันทีว่าแกว่งแรงแค่ไหน ถ้ารวมเป็นคลื่นเดียวจะเห็นแอมพลิจูดกับเฟสชัดเจน เริ่มจากสูตรผลต่างของมุม สูตรผลบวกมุมของ cos

\[ R\cos(\beta t - \varphi) = R\cos\varphi\cos\beta t + R\sin\varphi\sin\beta t \]

เทียบกับ \(C_1\cos\beta t + C_2\sin\beta t\) จะได้ \(R\cos\varphi = C_1\) และ \(R\sin\varphi = C_2\) ยกกำลังสองแล้วบวกกัน เอกลักษณ์พีทาโกรัส และหารกัน นิยาม tan = sin/cos

\[ R = \sqrt{C_1^2 + C_2^2},\qquad \tan\varphi = \frac{C_2}{C_1} \] รวมเป็นคลื่นเดียว เอกลักษณ์พีทาโกรัส นิยาม tan = sin/cos

ระวังจตุภาคของ φ: \(\tan^{-1}\) ในเครื่องคิดเลขให้มุมระหว่าง −90° ถึง 90° เท่านั้น ถ้า \(C_1 < 0\) ต้องบวก 180° เพิ่ม ใช้ฟังก์ชัน atan2(C₂, C₁) จะได้มุมที่ถูกเสมอ ฟังก์ชันตรีโกณผกผัน

ตัวอย่าง 3 ต่อ

เขียน \(\cos2t + \tfrac12\sin2t\) เป็นคลื่นเดียว

  1. \(R = \sqrt{1 + \tfrac14} = \tfrac{\sqrt5}{2} \approx 1.118\) และ \(\tan\varphi = \tfrac12 \Rightarrow \varphi \approx 26.57^\circ\)

\(y = \tfrac{\sqrt5}{2}\,e^{-t}\cos(2t - 26.57^\circ)\) · เห็นทันทีว่าเป็นคลื่นความถี่ 2 rad/s แอมพลิจูดเริ่ม 1.118 ที่หดลงตามเปลือก \(e^{-t}\)

ตัวอย่าง 4 · ไม่มีการหน่วง

\(y'' + 9y = 0,\ y(0) = 1,\ y'(0) = 6\)

  1. \(r^2 + 9 = 0 \Rightarrow r = \pm3j\) ได้ \(\alpha = 0\)

  2. \(y = C_1\cos3t + C_2\sin3t\) ได้ \(C_1 = 1\) และ \(3C_2 = 6 \Rightarrow C_2 = 2\)

  3. \(R = \sqrt5\) และ \(\varphi = \tan^{-1}2 \approx 63.43^\circ\) รวมเป็นคลื่นเดียว

\(y = \cos3t + 2\sin3t = \sqrt5\cos(3t - 63.43^\circ)\) แกว่งด้วยแอมพลิจูดคงที่ √5 ตลอดไป เพราะไม่มีอะไรดูดพลังงานออก

แล็บ: แก้ \(ay'' + by' + cy = f(t)\) แสดงทุกขั้น

ค่าเริ่มต้นคือตัวอย่าง 3 ลองเพิ่ม b ทีละน้อยจาก 0 ถึง 6 แล้วดูว่ารากเปลี่ยนจากเชิงซ้อน (แกว่ง) เป็นรากซ้ำที่ b = 2√5 ≈ 4.47 แล้วเป็นรากจริงสองค่า (ไม่แกว่ง) อัตราส่วนการหน่วง ζ จะบอกกรณีให้ทุกครั้ง

สมการยูเลอร์–โคชี: เมื่อสัมประสิทธิ์เป็นกำลังของ x ขั้นสูง

รูป \(x^2y'' + bxy' + cy = 0\) (\(x > 0\)) ไม่มีสัมประสิทธิ์คงที่ แต่ลอง \(y = x^m\) จะได้ \(m(m-1) + bm + c = 0\) เป็นสมการกำลังสองอีกครั้ง ถ้าได้รากเชิงซ้อน \(m = \alpha \pm j\beta\) ใช้ \(x^{j\beta} = e^{j\beta\ln x}\) แล้วสูตรออยเลอร์ สูตรออยเลอร์

\[ x^{j\beta} = \cos(\beta\ln x) + j\sin(\beta\ln x) \;\Longrightarrow\; y = x^{\alpha}\big(C_1\cos(\beta\ln x) + C_2\sin(\beta\ln x)\big) \]
ตัวอย่าง 5

\(x^2y'' + xy' + 4y = 0\)

  1. \(m(m-1) + m + 4 = m^2 + 4 = 0 \Rightarrow m = \pm2j\)

\(y = C_1\cos(2\ln x) + C_2\sin(2\ln x)\) · แกว่งแบบที่ระยะห่างระหว่างยอดยืดออกเรื่อย ๆ ตามสเกล log

จุดที่มักพลาด

  • รากเชิงซ้อนแล้วเขียน \(\cos(-1 \pm 2j)t\) ส่วนจริงต้องไปอยู่ที่ \(e^{\alpha t}\) ส่วนจินตภาพเท่านั้นที่เข้าไปอยู่ใน cos sin
  • ใช้ β ติดลบ เลือก β เป็นบวกเสมอ เครื่องหมาย ± ถูกดูดเข้าไปใน C₂ แล้ว ฟังก์ชันคู่-คี่
  • รากซ้ำแล้วตอบ \(C_1e^{rt} + C_2e^{rt}\) สองพจน์นี้เป็นพจน์เดียวกัน ต้องเป็น \(C_2te^{rt}\)
  • หา φ จาก \(\tan^{-1}(C_2/C_1)\) โดยไม่ดูจตุภาค ใช้ atan2 หรือดูเครื่องหมายของ C₁ C₂

ต่อไป: เมื่อด้านขวาไม่เป็นศูนย์ ซึ่งมีเรโซแนนซ์และบีต และการประยุกต์กับ RLC และมวล-สปริง
