// บทที่ 28.3 · สมการเชิงอนุพันธ์ · Nonhomogeneous ODEs

สมการเชิงอนุพันธ์อันดับสองแบบไม่เอกพันธ์ (Nonhomogeneous ODEs): เดาสัมประสิทธิ์ เรโซแนนซ์ บีต และการแปรผันพารามิเตอร์

เมื่อระบบถูกขับจากภายนอก เช่นสปริงที่มีแรงดึงเป็นจังหวะ หรือวงจร RLC ที่ต่อกับแหล่งจ่าย ด้านขวาของสมการจะไม่เป็นศูนย์ คำตอบมีสองส่วนเสมอ ส่วนแรกคือคำตอบเอกพันธ์ที่หาได้จากหน้าก่อน ส่วนที่สองคือคำตอบเฉพาะ \(y_p\) ตัวไหนก็ได้หนึ่งตัวที่ทำให้สมการเป็นจริง หน้านี้คือวิธีหา \(y_p\)

เขียนโดย อาจารย์มดอัปเดต
ตารางรูปเดา แรงขับ sin cos เรโซแนนซ์ บีต แปรผันพารามิเตอร์

โครงของคำตอบ: \(y = y_h + y_p\)

ถ้า \(y_p\) ทำให้ \(ay'' + by' + cy = f\) เป็นจริง และ \(y_h\) ทำให้ด้านซ้ายเป็นศูนย์ ผลรวมก็ยังให้ f เพราะสมการเป็นเชิงเส้น ทุกคำตอบของสมการไม่เอกพันธ์จึงเขียนได้เป็น

\[ y(t) = \underbrace{C_1y_1 + C_2y_2}_{y_h\ \text{(ช่วงชั่วครู่ / ธรรมชาติของระบบ)}} + \underbrace{y_p}_{\text{ตามแรงขับ}} \]

ลำดับการทำงานที่ไม่ควรสลับ: (1) หา \(y_h\) (2) หา \(y_p\) (3) รวมกัน (4) แล้วจึงใช้เงื่อนไขเริ่มต้นหา \(C_1, C_2\) ข้อผิดพลาดที่พบบ่อยคือใช้เงื่อนไขเริ่มต้นกับ \(y_h\) ก่อนบวก \(y_p\)

ตารางรูปเดา (Undetermined coefficients table)

ความคิดหลัก: เดารูปที่หน้าตาเหมือนด้านขวา แต่ใส่สัมประสิทธิ์ที่ยังไม่รู้ แทนลงสมการ แล้วเทียบสัมประสิทธิ์ ใช้ได้เพราะฟังก์ชันในตารางนี้ดิฟกี่ครั้งก็ยังเป็นตระกูลเดิม

ด้านขวา f(t)รูปเดา \(y_p\)หมายเหตุ
ค่าคงที่ \(K\)\(A\)
พหุนามดีกรี n\(A_nt^n + \dots + A_1t + A_0\)ต้องครบทุกดีกรีจนถึง n

กฎคูณ t (modification rule): ถ้ารูปเดาซ้ำกับพจน์ใดใน \(y_h\) ต้องคูณ t ถ้ายังซ้ำอีกให้คูณ \(t^2\) เหตุผลคือพจน์ที่ซ้ำกับ \(y_h\) แทนลงไปแล้วด้านซ้ายเป็นศูนย์ ไม่มีทางได้ f ออกมา

ตัวอย่าง 1 · ค่าคงที่

\(y'' - 3y' + 2y = 4\)

  1. \(y_h\): \(r^2 - 3r + 2 = 0 \Rightarrow r = 1, 2\)

  2. เดา \(y_p = A\) แทนได้ \(2A = 4\)

\(y = C_1e^t + C_2e^{2t} + 2\)

ตัวอย่าง 2 · เลขชี้กำลังที่ซ้ำ

\(y'' - 3y' + 2y = e^{t}\)

  1. \(e^t\) อยู่ใน \(y_h\) แล้ว (r = 1 เป็นราก) เดา \(Ae^t\) จะได้ \(0 = e^t\) ใช้ไม่ได้

  2. คูณ t: \(y_p = Ate^t\) แทนแล้วได้ \(A\cdot P'(1) = 1\) โดย \(P'(r) = 2r - 3\) ได้ \(A = -1\)

\(y = C_1e^t + C_2e^{2t} - te^t\)

แรงขับ sin cos: ตรีโกณมิติทำงานอย่างไรในการเทียบสัมประสิทธิ์

ตัวอย่าง 3

\(y'' + 2y' + 5y = 10\cos t\)

  1. เดา \(y_p = A\cos t + B\sin t\) ทั้งคู่ เพราะ \(y'\) จะสร้าง sin ออกมา เลื่อนเฟส 90° (โคฟังก์ชัน)

    \[ y_p' = -A\sin t + B\cos t,\qquad y_p'' = -A\cos t - B\sin t \]

  2. แทนแล้วจัดกลุ่มตาม cos และ sin

    \[ \underbrace{(-A + 2B + 5A)}_{\cos t}\cos t + \underbrace{(-B - 2A + 5B)}_{\sin t}\sin t = 10\cos t \]

  3. cos กับ sin เป็นอิสระต่อกัน ความตั้งฉาก เทียบสัมประสิทธิ์แยกได้สองสมการ

    \[ 4A + 2B = 10,\qquad -2A + 4B = 0 \;\Rightarrow\; A = 2,\ B = 1 \]

  4. รวมเป็นคลื่นเดียว รวมเป็นคลื่นเดียว

    \[ y_p = 2\cos t + \sin t = \sqrt5\cos(t - 26.57^\circ) \] รวมเป็นคลื่นเดียว สูตรผลบวกมุมของ cos เอกลักษณ์พีทาโกรัส

\(y = e^{-t}(C_1\cos2t + C_2\sin2t) + \sqrt5\cos(t - 26.57^\circ)\) · ส่วนแรกหายไปตามเวลา เหลือแต่คลื่นความถี่เดียวกับแรงขับที่ตามหลัง 26.57°

ทางลัดด้วยเลขเชิงซ้อน แทน \(\cos t\) ด้วย \(e^{jt}\) สูตรออยเลอร์ เดา \(y_p = Ke^{jt}\) แทนได้ \(K(-1 + 2j + 5) = 10\) ดังนั้น \(K = \tfrac{10}{4 + 2j} = 2 - j\) เอาส่วนจริงของ \((2 - j)(\cos t + j\sin t)\) ได้ \(2\cos t + \sin t\) ตรงกัน นี่คือที่มาของวิธีเฟสเซอร์ในวงจรไฟฟ้า ค่า \(4 + 2j\) ทำหน้าที่เหมือนอิมพีแดนซ์

เรโซแนนซ์: เมื่อแรงขับตรงกับความถี่ธรรมชาติ

ตัวอย่าง 4

\(y'' + 4y = \cos2t,\ y(0) = 0,\ y'(0) = 0\)

  1. \(y_h = C_1\cos2t + C_2\sin2t\) ความถี่ธรรมชาติคือ 2 rad/s ตรงกับแรงขับพอดี

  2. รูปเดาปกติซ้ำกับ \(y_h\) ต้องคูณ t: \(y_p = t(A\cos2t + B\sin2t)\)

  3. แทนลงไป พจน์ที่ไม่มี t หักล้างกันหมด เลื่อนเฟส 90° (โคฟังก์ชัน) เหลือ \(-4A\sin2t + 4B\cos2t = \cos2t\) ได้ \(A = 0,\ B = \tfrac14\)

\(y = \tfrac14t\sin2t\) · แอมพลิจูด \(t/4\) โตเป็นเส้นตรงไม่หยุด ในระบบจริงจะมีการหน่วงหรือวัสดุพังก่อน

ลองในแล็บ: ใส่ a = 1, b = 0, c = 4 แรงขับ cos ω = 2 จะเห็นกราฟบานออกแบบเปลือกตรง ถ้าเพิ่ม b เป็น 0.2 แอมพลิจูดจะหยุดโตที่ค่าหนึ่ง ซึ่งคือยอดเรโซแนนซ์ของระบบที่มีการหน่วง

บีต: ความถี่ใกล้กันแต่ไม่เท่ากัน

ตัวอย่าง 5

\(y'' + 9y = \cos2t,\ y(0) = 0,\ y'(0) = 0\)

  1. \(y_p = \dfrac{\cos2t}{9 - 4} = \tfrac15\cos2t\) ไม่ซ้ำกับ \(y_h\) (ความถี่ธรรมชาติ 3)

  2. ใช้เงื่อนไขเริ่มต้นได้ \(y = \tfrac15(\cos2t - \cos3t)\)

  3. แปลงผลต่างเป็นผลคูณ ผลต่าง cos เป็นผลคูณ \(\cos A - \cos B = -2\sin\tfrac{A+B}{2}\sin\tfrac{A-B}{2}\) และ sin เป็นฟังก์ชันคี่ ฟังก์ชันคู่-คี่

    \[ \cos2t - \cos3t = -2\sin\tfrac{5t}{2}\sin\!\Big(-\tfrac t2\Big) = 2\sin\tfrac t2\,\sin\tfrac{5t}{2} \] ผลต่าง cos เป็นผลคูณ ฟังก์ชันคู่-คี่

\(y = \tfrac25\sin\tfrac t2\,\sin\tfrac{5t}{2}\) · คลื่นเร็ว (5/2 rad/s) ที่แอมพลิจูดขึ้นลงช้า ๆ ตาม \(\sin\tfrac t2\) ได้ยินเป็นเสียงดัง-เบาสลับกัน เวลาตั้งสายกีตาร์สองเส้นที่เพี้ยนกันเล็กน้อย

การแปรผันพารามิเตอร์ (Variation of parameters) ขั้นสูง

เมื่อด้านขวาไม่อยู่ในตาราง เช่น \(\sec t\) หรือ \(\tan t\) ให้นำคำตอบเอกพันธ์ \(y_1, y_2\) มาเปลี่ยนค่าคงที่เป็นฟังก์ชัน \(y_p = u_1y_1 + u_2y_2\) (สำหรับสมการที่ทำให้ a = 1 แล้ว และด้านขวาเป็น g)

\[ u_1' = -\frac{y_2\,g}{W},\qquad u_2' = \frac{y_1\,g}{W},\qquad W = y_1y_2' - y_2y_1' \]
ตัวอย่าง 6

\(y'' + y = \sec t,\ \ -\tfrac{\pi}{2} < t < \tfrac{\pi}{2}\)

  1. \(y_1 = \cos t,\ y_2 = \sin t\) วรอนสเกียน \(W = \cos t\cdot\cos t - \sin t\cdot(-\sin t) = 1\) เอกลักษณ์พีทาโกรัส

  2. \(u_1' = -\sin t\sec t = -\tan t\) ส่วนกลับ นิยาม tan = sin/cos อินทิเกรตได้ \(u_1 = \ln|\cos t|\)

  3. \(u_2' = \cos t\sec t = 1\) ได้ \(u_2 = t\)

\(y_p = \cos t\,\ln|\cos t| + t\sin t\) และ \(y = C_1\cos t + C_2\sin t + y_p\) · ตรวจด้วยการแทนกลับแล้วเป็นจริง (หรือให้ sympy ตรวจ) ข้อนี้วิธีเดาใช้ไม่ได้เลย

จุดที่มักพลาด

  • เดาแค่ cos เมื่อแรงขับเป็น cos ต้องมี sin ด้วยทุกครั้งที่สมการมี y′ เลื่อนเฟส 90° (โคฟังก์ชัน)
  • ลืมกฎคูณ t ตรวจรูปเดากับ \(y_h\) ทุกครั้งก่อนแทน
  • ใช้เงื่อนไขเริ่มต้นก่อนบวก \(y_p\) ค่าคงที่จะผิดทั้งชุด
  • หา φ ผิดจตุภาค ใช้ atan2 รวมเป็นคลื่นเดียว

ทั้งหมดนี้ทำในแล็บได้ทันที หรือเปิดเครื่องแก้สมการเชิงอนุพันธ์ แบบเต็มหน้าที่แชร์ลิงก์คำตอบได้
