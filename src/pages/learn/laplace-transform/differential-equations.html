// บทที่ 8.4 · การแปลงลาปลาซ · Solving ODEs

แก้สมการเชิงอนุพันธ์อันดับหนึ่งและอันดับสองด้วยการแปลงลาปลาซ

นี่คือเหตุผลที่วิศวกรเรียนลาปลาซ: สมการเชิงอนุพันธ์ของวงจรและระบบกลไกกลายเป็นพีชคณิต ค่าเริ่มต้นเข้ามาในสมการเอง และอินพุตที่กระโดดหรือหน่วงเวลาไม่ใช่ปัญหาอีกต่อไป หน้านี้มีขั้นตอนมาตรฐาน ตัวอย่างครบทุกกรณีที่เจอในการสอบและงานจริง และตัวแก้สมการโต้ตอบที่แสดงวิธีทำเหมือนเขียนบนกระดาน สูตรใช้รหัส Q

เขียนโดย อาจารย์มดอัปเดต
ตัวแก้สมการโต้ตอบ อันดับหนึ่ง อันดับสอง วงจร RLC ระบบสมการ
สรุปใน 30 วินาที
  • แปลงทั้งสองข้าง → แทนค่าเริ่มต้น → แก้หา \(Y(s)\) → เศษส่วนย่อย → แปลงกลับ
  • รากของ \(as^2 + bs + c\) บอกรูปคำตอบ: จริงต่างกัน หน่วงเกิน · ซ้ำ หน่วงวิกฤต · เชิงซ้อน แกว่ง
  • \(Y(s) = \underbrace{\text{(ค่าเริ่มต้น)}/D(s)}_{\text{zero-input}} + \underbrace{H(s)X(s)}_{\text{zero-state}}\)
  • อินพุตตรงกับความถี่ธรรมชาติ → โพลซ้ำบนแกน jω → แอมพลิจูดโตตามเวลา (เรโซแนนซ์)

Q1 Laplace method for IVPs ขั้นตอนแก้ปัญหาค่าเริ่มต้น

\[ \text{ODE} \xrightarrow{\ \mathcal L\ } \text{สมการพีชคณิตใน } Y(s) \xrightarrow{\text{แก้}} Y(s) = \frac{N(s)}{D(s)} \xrightarrow{\text{เศษส่วนย่อย}} \sum\frac{c_k}{(s-p_k)^m} \xrightarrow{\ \mathcal L^{-1}\ } y(t) \]

(1) แปลงทั้งสองข้างด้วย P6–P7 (2) แทนค่าเริ่มต้น (3) จัด \(Y(s)\) ไว้ข้างเดียว (4) แยกเศษส่วนย่อย หน้า 8.5 (5) แปลงกลับจากตาราง และตรวจด้วยค่าเริ่มต้น

Q2 Derivatives สูตรที่ใช้ทุกข้อ

\[ \mathcal L\{y'\} = sY - y(0),\quad \mathcal L\{y''\} = s^2Y - sy(0) - y'(0) \]

Q3 Zero-input + zero-state แยกคำตอบสองส่วน

\[ Y(s) = \underbrace{\frac{I(s)}{D(s)}}_{\text{จากค่าเริ่มต้น}} + \underbrace{\frac{N(s)}{D(s)}X(s)}_{H(s)X(s)} \]

\(D(s)\) = พหุนามลักษณะเฉพาะ, \(I(s)\) = พหุนามที่มาจากค่าเริ่มต้น

สมการเชิงอนุพันธ์อันดับหนึ่ง พื้นฐาน

Q4 First-order linear ODE สมการอันดับหนึ่ง \(y' + ay = r(t)\)

\[ Y(s) = \frac{y(0)}{s + a} + \frac{R(s)}{s + a}\ \Rightarrow\ y(t) = y(0)e^{-at} + \int_0^t e^{-a(t-\tau)}r(\tau)\,d\tau \]

โพลเดียวที่ \(s = -a\) ค่าคงตัวเวลา \(\tau = 1/a\) · ส่วนที่สองคือคอนโวลูชันของอินพุตกับ \(e^{-at}\) (P12)

ตัวอย่าง Q-1 · ไม่มีอินพุต

\(y' + 2y = 0,\ y(0) = 3\)

  1. \[ sY - 3 + 2Y = 0 \ \Rightarrow\ Y(s) = \frac{3}{s+2} \]
  2. \[ y(t) = 3e^{-2t} \]

\(y(t) = 3e^{-2t}\) · ค่าคงตัวเวลา 0.5 หน่วย

ตัวอย่าง Q-2 · อินพุตขั้นบันได + ค่าเริ่มต้น

\(y' + 2y = 4u(t),\ y(0) = 1\)

  1. \[ sY - 1 + 2Y = \frac{4}{s} \ \Rightarrow\ (s+2)Y = 1 + \frac{4}{s} = \frac{s + 4}{s} \]
  2. \[ Y(s) = \frac{s + 4}{s(s+2)} = \frac{A}{s} + \frac{B}{s+2},\quad A = \frac{4}{2} = 2,\quad B = \frac{-2+4}{-2} = -1 \]
  3. \[ y(t) = 2 - e^{-2t} \]

\(y(t) = 2 - e^{-2t},\ t \ge 0\)

ตรวจ: \(y(0) = 1\) ✓ · \(y' + 2y = 2e^{-2t} + 4 - 2e^{-2t} = 4\) ✓

ตัวอย่าง Q-3 · อินพุตไซน์

\(y' + y = \sin t,\ y(0) = 0\)

  1. \[ (s+1)Y = \frac{1}{s^2+1} \ \Rightarrow\ Y = \frac{1}{(s+1)(s^2+1)} = \frac{1/2}{s+1} + \frac{-\tfrac12 s + \tfrac12}{s^2+1} \]

  2. ค่า \(\tfrac12\) ได้จากปิด \((s+1)\) ที่ \(s = -1\) ส่วนตัวเศษของพจน์ที่สองได้จากเทียบสัมประสิทธิ์ \(1 = \tfrac12(s^2+1) + (Bs + C)(s+1)\)

  3. \[ y(t) = \underbrace{\tfrac12e^{-t}}_{\text{ชั่วครู่}} + \underbrace{\tfrac12(\sin t - \cos t)}_{\text{สถานะคงตัว}} \]

หลังพจน์ชั่วครู่หายไป เหลือ \(\tfrac{1}{\sqrt2}\sin(t - 45^\circ)\) ตรงกับการวิเคราะห์เฟสเซอร์ \(H(j1) = \tfrac{1}{1+j} = \tfrac{1}{\sqrt2}\angle -45^\circ\)

ตัวอย่าง Q-4 · วงจร RL

วงจร RL อนุกรม \(V = 12\) V, \(R = 4\ \Omega\), \(L = 2\) H ปิดสวิตช์ที่ \(t = 0\) โดย \(i(0^-) = 0\) หา \(i(t)\)

  1. KVL: \(L\dfrac{di}{dt} + Ri = 12u(t)\) → \(2(sI) + 4I = \dfrac{12}{s}\)

  2. \[ I(s) = \frac{6}{s(s+2)} = \frac{3}{s} - \frac{3}{s+2} \]
  3. \[ i(t) = 3\left(1 - e^{-2t}\right)\ \text{A} \]

กระแสโตจาก 0 ไปที่ \(V/R = 3\) A ค่าคงตัวเวลา \(L/R = 0.5\) s

สมการเชิงอนุพันธ์อันดับสอง: สี่กรณีของราก กลาง

Q5 Second-order ODE สมการอันดับสอง \(ay'' + by' + cy = r(t)\)

\[ (as^2 + bs + c)Y(s) = a\left[sy(0) + y'(0)\right] + b\,y(0) + R(s) \]

\(D(s) = as^2 + bs + c\) คือพหุนามลักษณะเฉพาะ รากของมันคือโพลของระบบ

Q6 Damping cases กรณีของความหน่วง \(\zeta = \dfrac{b}{2\sqrt{ac}}\)

\[ \begin{array}{lll} b^2 - 4ac > 0\ (\zeta > 1) & s_{1,2} \text{ จริงต่างกัน} & y_h = c_1e^{s_1t} + c_2e^{s_2t} \\ b^2 - 4ac = 0\ (\zeta = 1) & s \text{ ซ้ำ} & y_h = (c_1 + c_2t)e^{st} \\ b^2 - 4ac < 0\ (0 < \zeta < 1) & -\sigma \pm j\omega_d & y_h = e^{-\sigma t}(c_1\cos\omega_dt + c_2\sin\omega_dt) \\ b = 0\ (\zeta = 0) & \pm j\omega_n & y_h = c_1\cos\omega_nt + c_2\sin\omega_nt \end{array} \]
ตัวอย่าง Q-5 · หน่วงเกิน + ขั้นบันได

\(y'' + 3y' + 2y = u(t),\ y(0) = y'(0) = 0\)

  1. \[ (s^2 + 3s + 2)Y = \frac{1}{s} \ \Rightarrow\ Y = \frac{1}{s(s+1)(s+2)} \]

  2. ปิดตัวประกอบสามครั้ง

    \[ A = \frac{1}{(1)(2)} = \frac12,\quad B = \frac{1}{(-1)(1)} = -1,\quad C = \frac{1}{(-2)(-1)} = \frac12 \]
  3. \[ y(t) = \frac12 - e^{-t} + \frac12e^{-2t} \]

\(y(t) = \tfrac12 - e^{-t} + \tfrac12e^{-2t}\) เข้าสู่ \(\tfrac12\) โดยไม่พุ่งเกิน (ราก −1, −2 จริงทั้งคู่)

ตรวจ: \(y(0) = \tfrac12 - 1 + \tfrac12 = 0\) ✓ · ทฤษฎีบทค่าสุดท้าย \(\lim_{s\to0}sY = \tfrac12\) ✓

ตัวอย่าง Q-6 · หน่วงวิกฤต

\(y'' + 2y' + y = 0,\ y(0) = 1,\ y'(0) = 0\)

  1. \[ s^2Y - s + 2(sY - 1) + Y = 0 \ \Rightarrow\ Y = \frac{s + 2}{(s+1)^2} \]

  2. เขียน \(s + 2 = (s + 1) + 1\)

    \[ Y = \frac{1}{s+1} + \frac{1}{(s+1)^2} \]
  3. \[ y(t) = e^{-t} + te^{-t} = (1 + t)e^{-t} \]

\((1+t)e^{-t}\) โพลซ้ำให้พจน์ \(te^{-t}\)

ตัวอย่าง Q-7 · หน่วงน้อย (แกว่ง)

\(y'' + 2y' + 5y = 0,\ y(0) = 1,\ y'(0) = 1\)

  1. \[ s^2Y - s - 1 + 2(sY - 1) + 5Y = 0 \ \Rightarrow\ Y = \frac{s + 3}{s^2 + 2s + 5} \]

  2. เติมกำลังสอง \(s^2 + 2s + 5 = (s+1)^2 + 2^2\) แล้วแยกเศษ \(s + 3 = (s + 1) + 2\)

    \[ Y = \frac{s + 1}{(s+1)^2 + 4} + \frac{2}{(s+1)^2 + 4} \]
  3. \[ y(t) = e^{-t}\left(\cos 2t + \sin 2t\right) = \sqrt2\,e^{-t}\cos(2t - 45^\circ) \]

แกว่งที่ \(\omega_d = 2\) rad/s ด้วยเปลือก \(\sqrt2e^{-t}\) · \(\zeta = 2/(2\sqrt5) \approx 0.447\)

ตัวอย่าง Q-8 · เรโซแนนซ์

\(y'' + 4y = \sin 2t,\ y(0) = y'(0) = 0\)

  1. ความถี่ของอินพุต (2 rad/s) ตรงกับความถี่ธรรมชาติ \(\omega_n = 2\)

    \[ (s^2 + 4)Y = \frac{2}{s^2+4} \ \Rightarrow\ Y = \frac{2}{(s^2+4)^2} \]

  2. ใช้ตารางแถว 20 ที่ \(\omega = 2\): \(\mathcal L^{-1}\{1/(s^2+\omega^2)^2\} = \tfrac{1}{2\omega^3}(\sin\omega t - \omega t\cos\omega t)\)

    \[ y(t) = 2\cdot\frac{1}{16}\left(\sin 2t - 2t\cos 2t\right) = \frac{\sin 2t}{8} - \frac{t\cos 2t}{4} \]

พจน์ \(t\cos 2t\) โตเชิงเส้นไม่หยุด นี่คือเหตุที่สะพานพังเมื่อถูกกระตุ้นตรงความถี่ธรรมชาติ และวงจร LC ไม่มีความต้านทานจะมีแรงดันสูงขึ้นเรื่อย ๆ

วงจร RLC และระบบมวล-สปริง-ตัวหน่วง กลาง

Q7 s-domain element models อุปกรณ์ในโดเมน s พร้อมค่าเริ่มต้น

\[ R:\ V = RI \qquad L:\ V = sLI - Li(0^-) \qquad C:\ V = \frac{I}{sC} + \frac{v(0^-)}{s} \]

Q8 Series RLC (capacitor voltage) RLC อนุกรม

\[ LC\,v_C'' + RC\,v_C' + v_C = v_s(t),\quad \omega_n = \frac{1}{\sqrt{LC}},\ \zeta = \frac{R}{2}\sqrt{\frac{C}{L}} \]

Q9 Mass–spring–damper มวล-สปริง-ตัวหน่วง

\[ m\ddot x + c\dot x + kx = F(t),\quad \omega_n = \sqrt{\frac{k}{m}},\ \zeta = \frac{c}{2\sqrt{km}} \]

เทียบกับวงจร: \(m \leftrightarrow L,\ c \leftrightarrow R,\ k \leftrightarrow 1/C\) สมการรูปเดียวกันทุกประการ

ตัวอย่าง Q-9 · วงจร RLC อนุกรม

\(L = 1\) H, \(R = 4\ \Omega\), \(C = \tfrac13\) F ป้อน 6 V ขั้นบันได ตัวเก็บประจุว่างและไม่มีกระแสเริ่มต้น หา \(v_C(t)\)

  1. Q8: \(\tfrac13 v'' + \tfrac43 v' + v = 6\) คูณ 3: \(v'' + 4v' + 3v = 18u(t)\)

  2. \[ V_C(s) = \frac{18}{s(s+1)(s+3)} = \frac{6}{s} - \frac{9}{s+1} + \frac{3}{s+3} \]
  3. \[ v_C(t) = 6 - 9e^{-t} + 3e^{-3t}\ \text{V} \]

ราก −1, −3 จริงต่างกัน หน่วงเกิน \(\zeta = \tfrac42\sqrt{\tfrac{1/3}{1}} \approx 1.155\) แรงดันขึ้นสู่ 6 V โดยไม่พุ่งเกิน

ตรวจ: \(v(0) = 6 - 9 + 3 = 0\) ✓ · \(v'(0) = 9 - 9 = 0\) ✓ (กระแสเริ่มต้น \(i = Cv' = 0\))

ตัวอย่าง Q-10 · ระบบกลไก

\(m = 1\) kg, \(c = 2\) N·s/m, \(k = 10\) N/m ดึงมวลออก 0.1 m แล้วปล่อยจากหยุดนิ่ง

  1. \[ s^2X - 0.1s + 2(sX - 0.1) + 10X = 0 \ \Rightarrow\ X = \frac{0.1(s + 2)}{(s+1)^2 + 9} \]
  2. \[ X = 0.1\left[\frac{s+1}{(s+1)^2 + 3^2} + \frac{1}{3}\cdot\frac{3}{(s+1)^2 + 3^2}\right] \]
  3. \[ x(t) = 0.1e^{-t}\left(\cos 3t + \tfrac13\sin 3t\right)\ \text{m} \]

แกว่ง 3 rad/s (≈ 0.48 Hz) ลดลงด้วย \(e^{-t}\) · \(\zeta = 2/(2\sqrt{10}) \approx 0.316\)

อินพุตเป็นช่วงและหน่วงเวลา กลาง

นี่คือจุดที่ลาปลาซเหนือกว่าวิธีปกติชัดเจน: อินพุตที่เปิดแล้วปิด ไม่ต้องแบ่งช่วงแก้แล้วต่อค่าที่รอยต่อ แค่เขียนด้วย \(u(t - T)\) แล้วใช้การเลื่อนเวลา

ตัวอย่าง Q-11 · พัลส์ 1 วินาที

\(y' + y = u(t) - u(t - 1),\ y(0) = 0\)

  1. \[ (s+1)Y = \frac{1 - e^{-s}}{s} \ \Rightarrow\ Y = \left(1 - e^{-s}\right)\frac{1}{s(s+1)} \]

  2. \(\mathcal L^{-1}\{1/(s(s+1))\} = 1 - e^{-t}\) แล้วใช้การเลื่อนเวลากับพจน์ที่มี \(e^{-s}\)

    \[ y(t) = \left(1 - e^{-t}\right)u(t) - \left(1 - e^{-(t-1)}\right)u(t-1) \]

ช่วง \(0 \le t < 1\): ชาร์จขึ้น \(1 - e^{-t}\) · ช่วง \(t \ge 1\): \(y = (e - 1)e^{-t}\) ลดลง (รวมสองพจน์แล้วจัดรูป) ต่อเนื่องที่ \(t = 1\) โดยอัตโนมัติ

Q10 Systems / state space ระบบสมการ

\[ \dot{\mathbf x} = A\mathbf x + B\mathbf u \ \Rightarrow\ \mathbf X(s) = (sI - A)^{-1}\left[\mathbf x(0) + B\mathbf U(s)\right] \]

\((sI - A)^{-1}\) เรียกว่า resolvent และ \(\mathcal L^{-1}\{(sI - A)^{-1}\} = e^{At}\) โพลคือค่าเฉพาะของ \(A\) ดูค่าเฉพาะ และปริภูมิสถานะ

ตัวอย่าง Q-12 · สองสมการคู่กัน

\(x' = -2x + y,\ y' = x - 2y,\ x(0) = 1,\ y(0) = 0\)

  1. \[ sX - 1 = -2X + Y,\qquad sY = X - 2Y \]

  2. จากสมการที่สอง \(Y = X/(s+2)\) แทนในสมการแรก

    \[ (s+2)X - \frac{X}{s+2} = 1 \ \Rightarrow\ X = \frac{s+2}{(s+2)^2 - 1} = \frac{s+2}{(s+1)(s+3)} \]
  3. \[ X = \frac{1/2}{s+1} + \frac{1/2}{s+3},\qquad Y = \frac{1}{(s+1)(s+3)} = \frac{1/2}{s+1} - \frac{1/2}{s+3} \]

\(x(t) = \tfrac12(e^{-t} + e^{-3t}),\ y(t) = \tfrac12(e^{-t} - e^{-3t})\) โพล −1, −3 คือค่าเฉพาะของ \(\begin{bmatrix}-2 & 1\\ 1 & -2\end{bmatrix}\)

Q11 Variable coefficients สมการสัมประสิทธิ์เป็นพหุนามใน t

\[ \mathcal L\{ty'\} = -\frac{d}{ds}\left[sY - y(0)\right],\qquad \mathcal L\{ty''\} = -\frac{d}{ds}\left[s^2Y - sy(0) - y'(0)\right] \]

ใช้ P9 แล้วได้สมการเชิงอนุพันธ์อันดับหนึ่งใน \(Y(s)\) ซึ่งมักแก้ง่ายกว่าเดิม

ตัวอย่าง Q-13 · สัมประสิทธิ์ตัวแปร

\(ty'' - ty' + y = 2,\ y(0) = 2,\ y'(0) = -1\)

  1. \[ -\frac{d}{ds}\left[s^2Y - 2s + 1\right] + \frac{d}{ds}\left[sY - 2\right] + Y = \frac{2}{s} \]
  2. \[ -(2sY + s^2Y' - 2) + (Y + sY') + Y = \frac{2}{s} \ \Rightarrow\ s(1 - s)Y' + 2(1 - s)Y = \frac{2(1 - s)}{s} \]

  3. หารด้วย \((1 - s)\): \(sY' + 2Y = \dfrac{2}{s}\) คูณ \(s\) ได้ \(\dfrac{d}{ds}\left(s^2Y\right) = 2\)

    \[ s^2Y = 2s + C \ \Rightarrow\ Y = \frac{2}{s} + \frac{C}{s^2} \ \Rightarrow\ y = 2 + Ct \]

  4. \(y'(0) = C = -1\)

\(y(t) = 2 - t\)

ตรวจ: \(t\cdot 0 - t(-1) + (2 - t) = 2\) ✓

ตัวแก้สมการโต้ตอบ: แสดงวิธีทำทุกขั้น

เลือกอันดับ ใส่สัมประสิทธิ์ \(a, b, c\) ขนาดอินพุต \(K\) และค่าเริ่มต้น แล้วเลือกชนิดอินพุต ตัวแก้จะแสดงการแปลงทั้งสองข้าง การจัดรูป สมการลักษณะเฉพาะพร้อมชนิดของความหน่วง เศษส่วนย่อย และคำตอบ กราฟแยกส่วนที่มาจากค่าเริ่มต้นกับส่วนที่มาจากอินพุตให้เห็นด้วย ปุ่ม “เปิดในตัวแก้สมการ” ในแต่ละตัวอย่างจะใส่ค่าให้อัตโนมัติ
