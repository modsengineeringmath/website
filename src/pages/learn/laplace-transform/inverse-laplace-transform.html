// บทที่ 8.5 · การแปลงลาปลาซ · Inverse Laplace Transform

การแปลงลาปลาซผกผัน (Inverse Laplace Transform) ครบทุกกรณี

การแปลงไปข้างหน้าใช้ตารางและคุณสมบัติก็พอ แต่การแปลงกลับคือที่ที่คะแนนหายในห้องสอบ หน้านี้เรียงเนื้อหาแบบตำรา Ogata: เริ่มจากนิยามและอินทิกรัลบรอมวิช แล้วไล่ทุกกรณีของเศษส่วนย่อย โพลเดี่ยว โพลเชิงซ้อน โพลซ้ำ เศษส่วนไม่แท้ ตัวหน่วงเวลา จากนั้นวิธีทางเลือก (เทียบสัมประสิทธิ์ คอนโวลูชัน เรซิดิว) ทฤษฎีบทการกระจายของเฮวิไซด์ การใช้ MATLAB/Python และโจทย์ฝึก 12 ข้อ ทุกตัวอย่างลองในเครื่องคิดเลขแสดงวิธีทำได้ สูตรใช้รหัส V

เขียนโดย อาจารย์มดอัปเดต
เครื่องคิดเลขแสดงวิธีทำ โพลเดี่ยว โพลเชิงซ้อน โพลซ้ำ เศษส่วนไม่แท้ โจทย์ฝึก
สรุปใน 30 วินาที
  • ทำให้เป็นเศษส่วนแท้ (หารยาว) → แยกตัวประกอบตัวส่วน → เลือกรูปเศษส่วนย่อยตามชนิดโพล → หาสัมประสิทธิ์ → เปิดตาราง
  • โพลเดี่ยว \(-p_k\): \(a_k = [(s+p_k)F(s)]_{s=-p_k}\) → \(a_ke^{-p_kt}\)
  • โพลซ้ำอันดับ r: \(b_{r-k} = \tfrac{1}{k!}\tfrac{d^k}{ds^k}[(s+p)^rF]_{s=-p}\) → \(\tfrac{t^{j-1}}{(j-1)!}e^{-pt}\)
  • โพลเชิงซ้อน: เติมกำลังสอง \((s+a)^2 + \omega^2\) → \(e^{-at}(A\cos\omega t + B\sin\omega t)\)

นิยาม ความเป็นหนึ่งเดียว และภาพรวมวิธีหา พื้นฐาน

V1 Inverse Laplace transform การแปลงผกผัน

\[ f(t) = \mathcal L^{-1}\{F(s)\} = \frac{1}{2\pi j}\int_{c-j\infty}^{c+j\infty}F(s)\,e^{st}\,ds,\quad t > 0,\ c > \operatorname{Re}(\text{ทุกโพล}) \]

ความเป็นหนึ่งเดียว (ทฤษฎีบทของ Lerch): ฟังก์ชันต่อเนื่องสองตัวที่มีการแปลงลาปลาซเท่ากันเป็นฟังก์ชันเดียวกันสำหรับ \(t \ge 0\) เราจึงแปลงกลับด้วยการ “เปิดตาราง” ได้อย่างมั่นใจ

รูปทั่วไปของ F(s) และหลักของเศษส่วนย่อย พื้นฐาน

ในงานวิศวกรรม \(F(s)\) เกือบทั้งหมดเป็นอัตราส่วนของพหุนามสองตัว (Ogata ใช้สัญลักษณ์ \(B(s)/A(s)\))

V2 Rational F(s) รูปทั่วไป

\[ F(s) = \frac{B(s)}{A(s)} = K\,\frac{(s+z_1)(s+z_2)\cdots(s+z_m)}{(s+p_1)(s+p_2)\cdots(s+p_n)},\quad m < n \]

\(-p_k\) คือโพล \(-z_i\) คือซีโร่ (เครื่องหมายแบบ Ogata) · ถ้า \(m \ge n\) ต้องหารยาวก่อน (กรณีที่ 4)

V3 Partial-fraction rules กฎการตั้งรูปเศษส่วนย่อย

\[ \begin{array}{ll} (s + p) & \to\ \dfrac{a}{s+p} \\[6pt] (s + p)^r & \to\ \dfrac{b_1}{s+p} + \dfrac{b_2}{(s+p)^2} + \cdots + \dfrac{b_r}{(s+p)^r} \\[6pt] (s+\alpha)^2 + \omega^2 & \to\ \dfrac{A(s+\alpha) + B\omega}{(s+\alpha)^2 + \omega^2}\ \text{ หรือ }\ \dfrac{K}{s + \alpha - j\omega} + \dfrac{\bar K}{s + \alpha + j\omega} \end{array} \]

จำนวนค่าคงที่ที่ต้องหา = ดีกรีของตัวส่วนเสมอ ใช้นับตรวจว่าตั้งรูปครบ

กรณีที่ 1: โพลเดี่ยวจริงทั้งหมด (Distinct Real Poles) พื้นฐาน

V4 Heaviside cover-up วิธีปิดตัวประกอบ

\[ F(s) = \sum_{k=1}^{n}\frac{a_k}{s + p_k},\qquad a_k = \Big[(s + p_k)F(s)\Big]_{s = -p_k},\qquad f(t) = \sum_{k=1}^{n}a_ke^{-p_kt} \]

ที่มา: คูณทั้งสองข้างด้วย \((s+p_k)\) แล้วแทน \(s = -p_k\) ทุกพจน์อื่นมี \((s + p_k)\) จึงเป็นศูนย์ เหลือ \(a_k\) ตัวเดียว · \(a_k\) คือเรซิดิวของ \(F\) ที่ \(-p_k\)

V5 Using A′(s) สูตรอนุพันธ์ตัวส่วน

\[ a_k = \frac{B(-p_k)}{A'(-p_k)} \]

สะดวกเมื่อตัวส่วนยังไม่แยกตัวประกอบหรือมีดีกรีสูง

V6 Quick checks ตรวจคำตอบเร็ว

\[ f(0^+) = \sum a_k = \lim_{s\to\infty}sF(s) \]

ถ้า \(n - m \ge 2\) ผลรวมของ \(a_k\) ต้องเป็นศูนย์

ตัวอย่าง V-1 · Ogata ตัวอย่างพื้นฐาน

\(F(s) = \dfrac{s+3}{(s+1)(s+2)}\)

  1. \[ F(s) = \frac{a_1}{s+1} + \frac{a_2}{s+2} \]

  2. ปิด \((s+1)\) แล้วแทน \(s = -1\) V4

    \[ a_1 = \left[\frac{s+3}{\hlU{\cancel{(s+1)}}(s+2)}\right]_{s=-1} = \frac{2}{1} = 2 \]

  3. ปิด \((s+2)\) แล้วแทน \(s = -2\)

    \[ a_2 = \left[\frac{s+3}{(s+1)}\right]_{s=-2} = \frac{1}{-1} = -1 \]
  4. \[ f(t) = 2e^{-t} - e^{-2t},\quad t \ge 0 \]

\(f(t) = 2e^{-t} - e^{-2t}\)

ตรวจ V6: \(f(0^+) = 2 - 1 = 1 = \lim_{s\to\infty}\tfrac{s(s+3)}{(s+1)(s+2)}\) ✓

ตัวอย่าง V-2 · สามโพล ด้วยสูตร A′(s)

\(F(s) = \dfrac{5s+3}{s^3 + 6s^2 + 11s + 6}\)

  1. แยกตัวประกอบ: ลอง \(s = -1\): \(-1 + 6 - 11 + 6 = 0\) ✓ หารได้ \(s^2 + 5s + 6 = (s+2)(s+3)\)

    \[ A(s) = (s+1)(s+2)(s+3),\qquad A'(s) = 3s^2 + 12s + 11 \]

  2. ใช้ \(a_k = B(-p_k)/A'(-p_k)\) V5

    \[ a_1 = \frac{-5+3}{3-12+11} = \frac{-2}{2} = -1,\quad a_2 = \frac{-10+3}{12-24+11} = \frac{-7}{-1} = 7,\quad a_3 = \frac{-15+3}{27-36+11} = \frac{-12}{2} = -6 \]
  3. \[ f(t) = -e^{-t} + 7e^{-2t} - 6e^{-3t} \]

\(f(t) = -e^{-t} + 7e^{-2t} - 6e^{-3t}\)

ตรวจ V6: \(n - m = 2\) ผลรวมต้องเป็นศูนย์: \(-1 + 7 - 6 = 0\) ✓

กรณีที่ 2: โพลเชิงซ้อนสังยุค (Complex-Conjugate Poles) กลาง

มีสองวิธีที่ให้คำตอบเดียวกัน วิธีเติมกำลังสองไม่ต้องใช้จำนวนเชิงซ้อนเลย เหมาะกับการคิดมือ ส่วนวิธีเรซิดิวเชิงซ้อนให้รูปแอมพลิจูด-มุมเฟสโดยตรง และเป็นสิ่งที่เครื่องคิดเลขกับ MATLAB ทำ

V7 Completing the square เติมกำลังสองสมบูรณ์

\[ \frac{A(s+\alpha) + B\omega}{(s+\alpha)^2 + \omega^2}\ \longrightarrow\ e^{-\alpha t}\left(A\cos\omega t + B\sin\omega t\right) \]

ขั้นตอน: \(s^2 + bs + c = (s + \tfrac b2)^2 + (c - \tfrac{b^2}{4})\) ได้ \(\alpha = b/2,\ \omega = \sqrt{c - b^2/4}\) แล้วเขียนตัวเศษใหม่ในรูป \(A(s + \alpha) + B\omega\)

V8 Complex residue form รูปแอมพลิจูด-มุมเฟส

\[ \frac{K}{s + \alpha - j\omega} + \frac{\bar K}{s + \alpha + j\omega}\ \longrightarrow\ 2|K|\,e^{-\alpha t}\cos\left(\omega t + \angle K\right),\quad K = \Big[(s + \alpha - j\omega)F(s)\Big]_{s = -\alpha + j\omega} \]

หา K ตัวเดียวพอ อีกตัวเป็นสังยุค · เทียบกับ V7: \(A = 2\operatorname{Re}K,\ B = -2\operatorname{Im}K\)

ตัวอย่าง V-3 · Ogata: เติมกำลังสอง

\(F(s) = \dfrac{2s + 12}{s^2 + 2s + 5}\)

  1. ดิสคริมิแนนต์ \(4 - 20 < 0\) → โพลเชิงซ้อน \(-1 \pm 2j\) เติมกำลังสอง

    \[ s^2 + 2s + 5 = (s+1)^2 + 2^2 \]

  2. จัดตัวเศษเป็น \(A(s+1) + B\cdot 2\) V7

    \[ 2s + 12 = 2(s + 1) + 10 = 2(s+1) + 5\cdot 2 \]
  3. \[ F(s) = 2\,\frac{s+1}{(s+1)^2 + 2^2} + 5\,\frac{2}{(s+1)^2 + 2^2} \]
  4. \[ f(t) = e^{-t}\left(2\cos 2t + 5\sin 2t\right) \]

\(f(t) = 2e^{-t}\cos 2t + 5e^{-t}\sin 2t,\ t \ge 0\)

ตัวอย่าง V-4 · ข้อเดิมด้วยเรซิดิวเชิงซ้อน

\(F(s) = \dfrac{2s + 12}{s^2 + 2s + 5}\) ในรูปแอมพลิจูด-มุมเฟส

  1. ปิด \((s + 1 - 2j)\) แล้วแทน \(s = -1 + 2j\) V8

    \[ K = \left[\frac{2s+12}{s + 1 + 2j}\right]_{s=-1+2j} = \frac{10 + 4j}{4j} = \frac{(10 + 4j)(-j)}{4} = 1 - 2.5j \]
  2. \[ |K| = \sqrt{1 + 6.25} = \frac{\sqrt{29}}{2},\qquad \angle K = \tan^{-1}\frac{-2.5}{1} = -68.20^\circ \]
  3. \[ f(t) = 2|K|e^{-t}\cos(2t + \angle K) = \sqrt{29}\,e^{-t}\cos\left(2t - 68.20^\circ\right) \]

\(\sqrt{29}e^{-t}\cos(2t - 68.2^\circ)\) เท่ากับคำตอบ V-3 ทุกประการ (\(A = 2\operatorname{Re}K = 2,\ B = -2\operatorname{Im}K = 5\))

ตัวอย่าง V-5 · โพลจริง + คู่เชิงซ้อน (ผลตอบสนองขั้นบันไดของระบบอันดับสอง)

\(F(s) = \dfrac{10}{s(s^2 + 4s + 13)}\)

  1. \[ \frac{10}{s(s^2+4s+13)} = \frac{A}{s} + \frac{Bs + C}{s^2 + 4s + 13},\qquad A = \left[\frac{10}{s^2+4s+13}\right]_{s=0} = \frac{10}{13} \]

  2. เทียบสัมประสิทธิ์ \(10 = A(s^2 + 4s + 13) + (Bs + C)s\): ที่ \(s^2\): \(A + B = 0\) → \(B = -\tfrac{10}{13}\) · ที่ \(s\): \(4A + C = 0\) → \(C = -\tfrac{40}{13}\)

  3. เติมกำลังสอง \((s+2)^2 + 3^2\) และ \(Bs + C = -\tfrac{10}{13}(s + 4) = -\tfrac{10}{13}\left[(s+2) + \tfrac23\cdot 3\right]\)

  4. \[ f(t) = \frac{10}{13} - \frac{10}{13}e^{-2t}\cos 3t - \frac{20}{39}e^{-2t}\sin 3t \]

\(f(t) = \tfrac{10}{13}\left[1 - e^{-2t}\left(\cos 3t + \tfrac23\sin 3t\right)\right]\) เข้าสู่ \(\tfrac{10}{13}\) แบบแกว่งหน่วง

ตรวจ: \(f(0) = \tfrac{10}{13}(1 - 1) = 0\) ✓ · ค่าสุดท้าย \(\lim_{s\to0}sF = \tfrac{10}{13}\) ✓

กรณีที่ 3: โพลซ้ำ (Multiple Poles) กลาง

V9 Multiple-pole coefficients สัมประสิทธิ์ของโพลซ้ำอันดับ r

\[ \frac{B(s)}{A(s)} = \frac{b_r}{(s+p)^r} + \frac{b_{r-1}}{(s+p)^{r-1}} + \cdots + \frac{b_1}{s+p} + (\text{พจน์ของโพลอื่น}) \] \[ b_r = \Big[(s+p)^rF(s)\Big]_{s=-p},\qquad b_{r-k} = \frac{1}{k!}\left\{\frac{d^k}{ds^k}\Big[(s+p)^rF(s)\Big]\right\}_{s=-p},\quad k = 1, \dots, r-1 \]

ที่มา: \((s+p)^rF(s) = b_r + b_{r-1}(s+p) + \cdots + b_1(s+p)^{r-1} + \cdots\) คืออนุกรมเทย์เลอร์รอบ \(-p\) สัมประสิทธิ์จึงได้จากอนุพันธ์ (เหมือนสูตรเรซิดิวอันดับ m)

V10 Time terms แปลงกลับพจน์โพลซ้ำ

\[ \frac{1}{(s+p)^j}\ \longrightarrow\ \frac{t^{j-1}}{(j-1)!}e^{-pt} \]

V11 Repeated complex poles โพลเชิงซ้อนซ้ำ

\[ \frac{1}{(s^2+\omega^2)^2}\ \longrightarrow\ \frac{\sin\omega t - \omega t\cos\omega t}{2\omega^3} \]

หรือใช้ V9 กับเรซิดิวเชิงซ้อน หรือคอนโวลูชัน P-11

ตัวอย่าง V-6 · Ogata: โพลอันดับสาม

\(F(s) = \dfrac{s^2 + 2s + 3}{(s+1)^3}\)

  1. \[ F(s) = \frac{b_3}{(s+1)^3} + \frac{b_2}{(s+1)^2} + \frac{b_1}{s+1},\qquad (s+1)^3F(s) = s^2 + 2s + 3 \]

  2. \(k = 0\): แทน \(s = -1\) V9

    \[ b_3 = (-1)^2 + 2(-1) + 3 = 2 \]

  3. \(k = 1\): อนุพันธ์ครั้งเดียว

    \[ b_2 = \left[\frac{d}{ds}(s^2 + 2s + 3)\right]_{s=-1} = \left[2s + 2\right]_{s=-1} = 0 \]

  4. \(k = 2\): อนุพันธ์สองครั้งหาร \(2!\)

    \[ b_1 = \frac{1}{2!}\left[\frac{d^2}{ds^2}(s^2 + 2s + 3)\right]_{s=-1} = \frac{2}{2} = 1 \]

  5. ใช้ V10: \(\tfrac{2}{(s+1)^3} \to t^2e^{-t}\) และ \(\tfrac{1}{s+1} \to e^{-t}\)

    \[ f(t) = t^2e^{-t} + 0 + e^{-t} = \left(t^2 + 1\right)e^{-t} \]

\(f(t) = (1 + t^2)e^{-t},\ t \ge 0\)

ทางลัด: แทน \(u = s + 1\) ได้ \(s^2 + 2s + 3 = u^2 + 2\) ดังนั้น \(F = \tfrac{1}{u} + \tfrac{2}{u^3}\) ตรงกัน ✓

ตัวอย่าง V-7 · โพลเดี่ยว + โพลซ้ำ

\(F(s) = \dfrac{s+3}{(s+1)(s+2)^2}\)

  1. \[ F = \frac{a}{s+1} + \frac{b_1}{s+2} + \frac{b_2}{(s+2)^2} \]

  2. โพลเดี่ยว: \(a = \left[\dfrac{s+3}{(s+2)^2}\right]_{s=-1} = \dfrac{2}{1} = 2\)

  3. โพลซ้ำ: \((s+2)^2F = \dfrac{s+3}{s+1}\)

    \[ b_2 = \left[\frac{s+3}{s+1}\right]_{s=-2} = \frac{1}{-1} = -1,\qquad b_1 = \left[\frac{d}{ds}\frac{s+3}{s+1}\right]_{s=-2} = \left[\frac{-2}{(s+1)^2}\right]_{s=-2} = -2 \]
  4. \[ f(t) = 2e^{-t} - 2e^{-2t} - te^{-2t} \]

\(f(t) = 2e^{-t} - (2 + t)e^{-2t}\)

ตรวจ: \(n - m = 2\) → สัมประสิทธิ์ของพจน์ \(1/(s+p)\) รวมกันเป็นศูนย์: \(2 + (-2) = 0\) ✓ · \(f(0) = 2 - 2 = 0\) ✓

ตัวอย่าง V-8 · โพลซ้ำที่จุดกำเนิด

\(F(s) = \dfrac{1}{s^2(s+1)}\)

  1. \(s^2F = \dfrac{1}{s+1}\): \(b_2 = 1,\ b_1 = \left[\dfrac{-1}{(s+1)^2}\right]_{s=0} = -1\) · โพล −1: \(a = \left[\dfrac{1}{s^2}\right]_{s=-1} = 1\)

  2. \[ F = \frac{1}{s^2} - \frac{1}{s} + \frac{1}{s+1} \ \Rightarrow\ f(t) = t - 1 + e^{-t} \]

\(f(t) = t - 1 + e^{-t}\) คือผลตอบสนองแรมป์ของระบบอันดับหนึ่ง ตามหลังแรมป์อยู่ 1 หน่วยในสถานะคงตัว

กรณีที่ 4: เศษส่วนไม่แท้ (deg B ≥ deg A) กลาง

V12 Improper F(s) หารยาวก่อน

\[ \frac{B(s)}{A(s)} = Q(s) + \frac{R(s)}{A(s)},\quad \mathcal L^{-1}\{c_0 + c_1s + c_2s^2 + \cdots\} = c_0\,\delta(t) + c_1\,\delta'(t) + c_2\,\delta''(t) + \cdots \]

ผลหาร \(Q(s)\) ให้อิมพัลส์และอนุพันธ์ของอิมพัลส์ ส่วนเศษ \(R/A\) เป็นเศษส่วนแท้ แยกตามกรณีที่ 1–3 · ทบทวนการหารยาวพหุนามได้ที่บทอินทิกรัล

ตัวอย่าง V-9 · Ogata: ดีกรีเศษมากกว่าส่วน

\(G(s) = \dfrac{s^3 + 5s^2 + 9s + 7}{(s+1)(s+2)}\)

  1. ตัวส่วน \(s^2 + 3s + 2\) หารยาว: \(s^3 + 5s^2 + 9s + 7 = (s + 2)(s^2 + 3s + 2) + (s + 3)\)

    \[ G(s) = s + 2 + \frac{s + 3}{(s+1)(s+2)} \]

  2. เศษที่เหลือคือ V-1: \(\dfrac{s+3}{(s+1)(s+2)} = \dfrac{2}{s+1} - \dfrac{1}{s+2}\)

  3. ใช้ V12: \(s \to \delta'(t)\), \(2 \to 2\delta(t)\)

    \[ g(t) = \frac{d}{dt}\delta(t) + 2\delta(t) + 2e^{-t} - e^{-2t},\quad t \ge 0^- \]

\(g(t) = \delta'(t) + 2\delta(t) + 2e^{-t} - e^{-2t}\)

กรณีที่ 5: มีตัวหน่วงเวลา e^(−sT) กลาง

V13 Delayed terms พจน์ที่มีตัวหน่วง

\[ \mathcal L^{-1}\{e^{-sT}G(s)\} = g(t - T)\,u(t - T),\qquad g = \mathcal L^{-1}\{G\} \]

อย่ารวม \(e^{-sT}\) เข้าไปในเศษส่วนย่อย ให้แยกพจน์ตามตัวหน่วง แปลงกลับส่วนตรรกยะแต่ละก้อน แล้วเลื่อนทีละก้อน

ตัวอย่าง V-10 · หน่วงหนึ่งก้อน

\(F(s) = \dfrac{e^{-2s}}{s(s+1)}\)

  1. \[ G(s) = \frac{1}{s(s+1)} = \frac{1}{s} - \frac{1}{s+1} \ \Rightarrow\ g(t) = 1 - e^{-t} \]

  2. เลื่อนไป 2 หน่วย V13

    \[ f(t) = \left[1 - e^{-(t-2)}\right]u(t - 2) \]

เป็นศูนย์จนถึง \(t = 2\) แล้วชาร์จขึ้นแบบเอกซ์โพเนนเชียล

ตัวอย่าง V-11 · ผลต่างของสองก้อน

\(F(s) = \dfrac{1 - e^{-s}}{s^2}\)

  1. \[ F = \frac{1}{s^2} - e^{-s}\frac{1}{s^2} \ \Rightarrow\ f(t) = t\,u(t) - (t - 1)\,u(t - 1) \]

แรมป์ที่หยุดโตที่ \(t = 1\): \(f = t\) เมื่อ \(0 \le t < 1\) และ \(f = 1\) เมื่อ \(t \ge 1\)

วิธีทางเลือก: เทียบสัมประสิทธิ์และแทนค่า s พื้นฐาน

V14 Equating coefficients เทียบสัมประสิทธิ์

\[ B(s) = \sum_k a_k\frac{A(s)}{s + p_k} + \cdots \quad\Rightarrow\quad \text{เทียบสัมประสิทธิ์ของ } s^0, s^1, \dots \text{ หรือแทน } s \text{ หลายค่า} \]

ใช้ร่วมกับการปิดตัวประกอบเพื่อหาตัวที่เหลือ โดยเฉพาะตัวเศษ \(Bs + C\) ของตัวประกอบกำลังสอง

ตัวอย่าง V-12 · ไม่แตะจำนวนเชิงซ้อนเลย

\(F(s) = \dfrac{s+1}{s(s^2 + 2s + 2)}\)

  1. \[ \frac{s+1}{s(s^2+2s+2)} = \frac{A}{s} + \frac{Bs + C}{s^2 + 2s + 2},\qquad A = \left[\frac{s+1}{s^2+2s+2}\right]_{s=0} = \frac12 \]

  2. เทียบ: \(s + 1 = \tfrac12(s^2 + 2s + 2) + Bs^2 + Cs\) · \(s^2\): \(\tfrac12 + B = 0\) → \(B = -\tfrac12\) · \(s\): \(1 + C = 1\) → \(C = 0\)

  3. เติมกำลังสอง \((s+1)^2 + 1\) และ \(-\tfrac12 s = -\tfrac12(s+1) + \tfrac12\)

    \[ F = \frac{1/2}{s} - \frac12\cdot\frac{s+1}{(s+1)^2 + 1} + \frac12\cdot\frac{1}{(s+1)^2+1} \]
  4. \[ f(t) = \frac12 - \frac12e^{-t}\cos t + \frac12e^{-t}\sin t \]

\(f(t) = \tfrac12\left[1 - e^{-t}(\cos t - \sin t)\right]\)

วิธีทางเลือก: คอนโวลูชัน กลาง

V15 Inverse of a product แปลงกลับผลคูณ

\[ \mathcal L^{-1}\{F(s)G(s)\} = \int_0^t f(\tau)\,g(t - \tau)\,d\tau \]
ตัวอย่าง V-13

\(\mathcal L^{-1}\left\{\dfrac{1}{s(s+a)}\right\}\)

  1. \(F = 1/s \to 1,\ G = 1/(s+a) \to e^{-at}\)

    \[ \int_0^t 1\cdot e^{-a(t-\tau)}\,d\tau = e^{-at}\left[\frac{e^{a\tau}}{a}\right]_0^t = \frac{1 - e^{-at}}{a} \]

\(\dfrac{1}{a}\left(1 - e^{-at}\right)\) ตรงกับตารางแถว 17

เรซิดิว อินทิกรัลบรอมวิช และทฤษฎีบทการกระจายของเฮวิไซด์ ขั้นสูง

ทุกวิธีข้างต้นเป็นกรณีพิเศษของสูตรเดียว: ปิดเส้นบรอมวิชด้วยครึ่งวงกลมทางซ้าย (บทตั้งของจอร์แดนทำให้ส่วนโค้งหายเมื่อ \(F(s) \to 0\)) อินทิกรัลจึงเท่ากับผลรวมเรซิดิวของ \(F(s)e^{st}\) ดูภาพและที่มาที่หน้า 8.1

V16 Residue inversion แปลงกลับด้วยเรซิดิว

\[ f(t) = \sum_{k}\operatorname{Res}_{s = s_k}\left[F(s)e^{st}\right],\qquad \operatorname{Res}_{s_k} = \frac{1}{(m-1)!}\lim_{s\to s_k}\frac{d^{\,m-1}}{ds^{m-1}}\left[(s - s_k)^mF(s)e^{st}\right] \]

V17 Heaviside expansion theorem ทฤษฎีบทการกระจายของเฮวิไซด์

\[ \mathcal L^{-1}\left\{\frac{B(s)}{A(s)}\right\} = \sum_{k=1}^{n}\frac{B(s_k)}{A'(s_k)}e^{s_kt}\quad(\text{โพลเดี่ยวทั้งหมด } s_k) \]
ตัวอย่าง V-14 · เรซิดิวกับโพลซ้ำ

\(F(s) = \dfrac{1}{s(s+1)^2}\) ด้วย V16

  1. โพลเดี่ยวที่ 0

    \[ \operatorname{Res}_{0} = \left[\frac{e^{st}}{(s+1)^2}\right]_{s=0} = 1 \]

  2. โพลอันดับ 2 ที่ −1: อนุพันธ์หนึ่งครั้งของ \(e^{st}/s\) (กฎผลหาร)

    \[ \operatorname{Res}_{-1} = \left[\frac{d}{ds}\frac{e^{st}}{s}\right]_{s=-1} = \left[\frac{te^{st}}{s} - \frac{e^{st}}{s^2}\right]_{s=-1} = -te^{-t} - e^{-t} \]

\(f(t) = 1 - e^{-t} - te^{-t}\) ไม่ต้องตั้งรูปเศษส่วนย่อยเลย แต่ต้องหาอนุพันธ์ที่มี \(t\) อยู่ข้างใน

ตรวจด้วย MATLAB และ Python กลาง

ตำรา Ogata ใช้คำสั่ง residue ของ MATLAB ตลอดเล่ม ผลลัพธ์คือ r (สัมประสิทธิ์) p (โพล) และ k (ผลหารจากการหารยาว) ตัวอย่างนี้คือ V-4 และ V-6

% MATLAB / Octave
num = [2 12];  den = [1 2 5];
[r, p, k] = residue(num, den)
% r = 1.0000 - 2.5000i ; 1.0000 + 2.5000i   (K ของโพล -1+2i และสังยุค)
% p = -1.0000 + 2.0000i ; -1.0000 - 2.0000i
% k = []

[r, p, k] = residue([1 2 3], conv([1 1], conv([1 1], [1 1])))
% r = 1 ; 0 ; 2   → 1/(s+1) + 0/(s+1)^2 + 2/(s+1)^3   (กำลังเรียงจากต่ำไปสูง)

syms s t
ilaplace((2*s + 12)/(s^2 + 2*s + 5))   % exp(-t)*(2*cos(2*t) + 5*sin(2*t))
# Python
from scipy.signal import residue
r, p, k = residue([2, 12], [1, 2, 5])

import sympy as sp
s, t = sp.symbols('s t', positive=True)
F = (s**2 + 2*s + 3)/(s + 1)**3
sp.apart(F, s)                              # 1/(s + 1) + 2/(s + 1)**3
sp.inverse_laplace_transform(F, s, t)      # (t**2 + 1)*exp(-t)

ข้อควรระวัง: residue คำนวณเชิงตัวเลข โพลซ้ำอาจคลาดเล็กน้อยจนถูกมองเป็นโพลเดี่ยวสองตัวที่ใกล้กันมาก ถ้าเห็นค่า r ใหญ่ผิดปกติและมีเครื่องหมายตรงข้ามกัน ให้สงสัยว่าเป็นโพลซ้ำ

พิมพ์ \(F(s)\) ในรูปใดก็ได้ ทั้งแบบแยกตัวประกอบแล้ว แบบพหุนามกระจาย หรือมีตัวหน่วง \(e^{-Ts}\) เครื่องคิดเลขจะทำตามขั้นตอนเดียวกับในหน้านี้: ตรวจแท้-ไม่แท้ (หารยาว) แยกตัวประกอบหาโพลและอันดับ ตั้งรูปเศษส่วนย่อย หาสัมประสิทธิ์ด้วยสูตรปิดตัวประกอบหรือสูตรอนุพันธ์ แปลงกลับ แล้ววาดกราฟ \(f(t)\) ตัวเลขแสดงเป็นเศษส่วนหรือรากที่สองเมื่อเป็นค่าแม่นตรง
