// บทที่ 8.1 · การแปลงลาปลาซ · Complex Variables

จำนวนเชิงซ้อน ตัวแปรเชิงซ้อน ฟังก์ชันวิเคราะห์ และเรซิดิว สำหรับการแปลงลาปลาซ

ทุกอย่างในลาปลาซเกิดบนระนาบเชิงซ้อน: ตัวแปร \(s = \sigma + j\omega\) โพลที่บอกเสถียรภาพ และสูตรแปลงกลับที่จริง ๆ แล้วคืออินทิกรัลเส้นของฟังก์ชันวิเคราะห์ หน้านี้ปูพื้นตั้งแต่บวกลบจำนวนเชิงซ้อน ไปจนถึงทฤษฎีบทเรซิดิว โดยเลือกเฉพาะส่วนที่ลาปลาซต้องใช้จริง และมีแล็บให้ลากดูทุกแนวคิด สูตรใช้รหัส Z

เขียนโดย อาจารย์มดอัปเดต
จำนวนเชิงซ้อน ระนาบ s โคชี-รีมันน์ เรซิดิว สู่การแปลงกลับ
สรุปใน 30 วินาที
  • \(z = x + jy = re^{j\theta}\) คูณ = ขนาดคูณกัน มุมบวกกัน เป็นเหตุผลที่เฟสเซอร์และฟังก์ชันถ่ายโอนใช้รูปเชิงขั้ว
  • \(e^{st} = e^{\sigma t}(\cos\omega t + j\sin\omega t)\): σ คุมการโต-หด ω คุมการแกว่ง จึงเรียก \(s\) ว่าความถี่เชิงซ้อน
  • ฟังก์ชันวิเคราะห์ ⇔ สมการโคชี-รีมันน์ \(u_x = v_y,\ u_y = -v_x\) ฟังก์ชันตรรกยะในลาปลาซวิเคราะห์ทุกจุดยกเว้นโพล
  • เรซิดิวคือสัมประสิทธิ์ของ \(1/(s-p)\) ในอนุกรมโลรองต์ และ \(f(t) = \sum\operatorname{Res}\,[F(s)e^{st}]\)
ระดับพื้นฐาน ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท

จำนวนเชิงซ้อนและการดำเนินการ พื้นฐาน

จำนวนเชิงซ้อนเกิดจากความต้องการให้ \(x^2 + 1 = 0\) มีคำตอบ เรานิยามหน่วยจินตภาพ \(j\) ที่ \(j^2 = -1\) แล้วจำนวนเชิงซ้อนทุกตัวเขียนเป็นคู่ของจำนวนจริงสองตัว ภาพที่ช่วยมากที่สุดคือมองเป็นจุดหรือเวกเตอร์บนระนาบ

Z1 Rectangular form รูปคาร์ทีเซียน

\[ z = x + jy,\quad x = \operatorname{Re}z,\ y = \operatorname{Im}z,\quad j^2 = -1 \]

Z2 Arithmetic บวก ลบ คูณ

\[ (a+jb)(c+jd) = (ac - bd) + j(ad + bc) \]

บวก ลบ ทีละส่วนเหมือนเวกเตอร์ คูณกระจายแล้วแทน \(j^2 = -1\)

Z3 Conjugate & modulus สังยุคและขนาด

\[ \bar z = x - jy,\qquad |z| = \sqrt{x^2+y^2},\qquad z\bar z = |z|^2 \]

Z4 Division หารด้วยการคูณสังยุค

\[ \frac{a+jb}{c+jd} = \frac{(a+jb)(c-jd)}{c^2+d^2} \]
ตัวอย่าง Z-1 · คูณและหาร

ให้ \(z_1 = 3 + 4j,\ z_2 = 1 - 2j\) หา \(z_1z_2\) และ \(z_1/z_2\)

  1. \[ z_1z_2 = 3 - 6j + 4j - 8j^2 = 3 + 8 - 2j = 11 - 2j \]

  2. หาร: คูณทั้งเศษและส่วนด้วย \(\bar z_2 = 1 + 2j\) Z4

    \[ \frac{3+4j}{1-2j} = \frac{(3+4j)(1+2j)}{1^2 + 2^2} = \frac{3 + 6j + 4j + 8j^2}{5} = \frac{-5 + 10j}{5} = -1 + 2j \]

\(z_1z_2 = 11 - 2j\), \(\ z_1/z_2 = -1 + 2j\)

ตรวจ: \((-1+2j)(1-2j) = -1 + 2j + 2j - 4j^2 = 3 + 4j\) ✓

ลองในแล็บ: ลากจุด z₁ และ z₂ แล้วเปลี่ยนการดำเนินการ สังเกตว่าการคูณ “หมุนและยืด” เสมอ ส่วนรากที่ n กระจายเป็นรูปหลายเหลี่ยมด้านเท่า

รูปเชิงขั้ว สูตรออยเลอร์ และเดอมัวฟวร์ พื้นฐาน

Z5 Polar form รูปเชิงขั้ว

\[ z = r(\cos\theta + j\sin\theta) = r\angle\theta,\quad r = |z|,\ \theta = \arg z \]

หามุมด้วย \(\operatorname{atan2}(y, x)\) เสมอ ห้ามใช้ \(\tan^{-1}(y/x)\) ตรง ๆ เพราะจะผิดจตุภาคเมื่อ \(x < 0\)

Z6 Euler's formula สูตรของออยเลอร์

\[ e^{j\theta} = \cos\theta + j\sin\theta \ \Rightarrow\ z = re^{j\theta} \]

ได้ \(\cos\theta = \tfrac{e^{j\theta} + e^{-j\theta}}{2},\ \sin\theta = \tfrac{e^{j\theta} - e^{-j\theta}}{2j}\) ใช้หาลาปลาซของ sin, cos ในตัวอย่าง L-2

Z7 Products & De Moivre คูณ หาร ยกกำลัง

\[ z_1z_2 = r_1r_2\angle(\theta_1+\theta_2),\quad \frac{z_1}{z_2} = \frac{r_1}{r_2}\angle(\theta_1-\theta_2),\quad z^n = r^n\angle n\theta \]

Z8 n-th roots รากที่ n มี n ค่า

\[ z^{1/n} = r^{1/n}\angle\frac{\theta + 2\pi k}{n},\quad k = 0, 1, \dots, n-1 \]
ตัวอย่าง Z-2 · ยกกำลังด้วยเดอมัวฟวร์

หา \((1 + j)^8\)

  1. \[ 1 + j = \sqrt{2}\angle 45^\circ \]

  2. ยกกำลัง 8: ขนาดยกกำลัง 8 มุมคูณ 8 Z7

    \[ (1+j)^8 = (\sqrt2)^8\angle 360^\circ = 16\angle 0^\circ \]

\((1+j)^8 = 16\) ถ้ากระจายทวินามต้องคำนวณ 9 พจน์ ส่วนรูปเชิงขั้วใช้สองบรรทัด

ตัวอย่าง Z-3 · รากที่สาม = โพลของระบบ

หารากของ \(s^3 + 8 = 0\) แล้วบอกว่า \(H(s) = \dfrac{1}{s^3 + 8}\) เสถียรไหม

  1. \[ s^3 = -8 = 8\angle 180^\circ \]

  2. รากที่สามสามค่า Z8

    \[ s_k = 2\angle\frac{180^\circ + 360^\circ k}{3} = 2\angle 60^\circ,\ 2\angle 180^\circ,\ 2\angle 300^\circ \]
  3. \[ s = 1 + j\sqrt3,\quad -2,\quad 1 - j\sqrt3 \]

มีโพลคู่หนึ่งที่ส่วนจริงเป็นบวก (\(1 \pm j\sqrt3\)) ผลตอบสนองจึงมีพจน์ \(e^{t}\cos\sqrt3 t\) โตไม่หยุด ระบบนี้ไม่เสถียร

ตรวจ: \((1+j\sqrt3)^3 = 2^3\angle 180^\circ = -8\) ✓ · ผลรวมรากต้องเท่ากับ \(-(\text{สัมประสิทธิ์ } s^2) = 0\): \(1 + 1 - 2 = 0\) ✓

ตัวแปรเชิงซ้อน s = σ + jω และระนาบ s พื้นฐาน

ในลาปลาซเราใช้ตัวอักษร \(s\) แทน \(z\) และเรียกระนาบเชิงซ้อนว่าระนาบ s แกนนอนคือ \(\sigma\) แกนตั้งคือ \(j\omega\) ทำไมต้องเป็นสองมิติ คำตอบอยู่ในสัญญาณ \(e^{st}\) ซึ่งเป็น “อิฐ” ที่ลาปลาซใช้สร้างทุกสัญญาณ

Z9 Complex frequency ความถี่เชิงซ้อน

\[ e^{st} = e^{(\sigma + j\omega)t} = \underbrace{e^{\sigma t}}_{\text{โต/หด}}\ \underbrace{(\cos\omega t + j\sin\omega t)}_{\text{หมุน/แกว่ง}},\qquad \operatorname{Re}\{e^{st}\} = e^{\sigma t}\cos\omega t \]

\(\sigma < 0\) ลดลง · \(\sigma = 0\) แกว่งค้าง · \(\sigma > 0\) โตขึ้น · \(\omega = 0\) ไม่แกว่ง ยิ่ง \(|\omega|\) มากยิ่งแกว่งเร็ว

ข้อสังเกตที่สำคัญมาก: สัญญาณจริงอย่าง \(e^{-t}\cos 3t\) ต้องใช้ \(e^{st}\) สองตัว ที่ \(s = -1 \pm 3j\) เพราะ \(\cos 3t = \tfrac12(e^{j3t} + e^{-j3t})\) นี่คือเหตุผลที่โพลเชิงซ้อนของระบบจริงมาเป็นคู่สังยุคเสมอ

ฟังก์ชันเชิงซ้อนและการส่ง (mapping) กลาง

ฟังก์ชันเชิงซ้อน \(w = f(z)\) รับจำนวนเชิงซ้อนแล้วคืนจำนวนเชิงซ้อน เราวาดกราฟแบบปกติไม่ได้เพราะต้องใช้ 4 มิติ จึงดูเป็น “การส่ง” จากระนาบ z ไประนาบ w แทน ฟังก์ชันถ่ายโอน \(H(s)\) ก็คือฟังก์ชันเชิงซ้อนชนิดหนึ่ง

Z10 Complex function แยกส่วนจริง-จินตภาพ

\[ w = f(z) = u(x, y) + jv(x, y) \]

เช่น \(z^2 = (x^2 - y^2) + j(2xy)\) ได้ \(u = x^2 - y^2,\ v = 2xy\)

Z11 Complex limit ลิมิตต้องเท่ากันทุกทิศ

\[ \lim_{z\to z_0}f(z) = L \iff |f(z) - L| \to 0 \text{ ไม่ว่า } z \text{ จะเข้าหา } z_0 \text{ จากทางใด} \]

เข้มกว่าลิมิตจริงมาก เพราะมีทิศเข้าได้ไม่จำกัด (ทบทวนลิมิตของฟังก์ชันจริง)

ตัวอย่าง Z-4 · ลิมิตที่ไม่มีค่า

พิจารณา \(\displaystyle\lim_{z\to 0}\frac{\bar z}{z}\)

  1. เข้าหา 0 ตามแกนจริง \(z = x\): \(\bar z/z = x/x = 1\)

  2. เข้าหา 0 ตามแกนจินตภาพ \(z = jy\): \(\bar z/z = -jy/(jy) = -1\)

สองทิศได้ค่าต่างกัน ลิมิตจึงไม่มีค่า ทั้งที่ทั้งเศษและส่วนต่อเนื่องดี

แล็บการส่ง: เส้นกริดสีส้มคือเส้นแนวตั้ง (x คงที่) สีน้ำเงินคือเส้นแนวนอน (y คงที่) ในระนาบ z ดูว่าแต่ละฟังก์ชันบิดมันเป็นอะไรในระนาบ w สี่เหลี่ยมเล็กสีเขียวคือย่านรอบจุด \(z_0\) ที่ลากได้ ใต้ภาพคำนวณอนุพันธ์ย่อยให้ตรวจสมการโคชี-รีมันน์ในหัวข้อถัดไป

อนุพันธ์เชิงซ้อน สมการโคชี-รีมันน์ และฟังก์ชันวิเคราะห์ กลาง

นิยามอนุพันธ์เหมือนฟังก์ชันจริงทุกตัวอักษร แต่เพราะลิมิตต้องเท่ากันทุกทิศ เงื่อนไขจึงเข้มมาก บังคับให้ \(u\) และ \(v\) ผูกกันด้วยสมการสองข้อ

Z12 Complex derivative อนุพันธ์เชิงซ้อน

\[ f'(z_0) = \lim_{\Delta z\to 0}\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} \]

Z13 Cauchy–Riemann equations สมการโคชี-รีมันน์

\[ \frac{\partial u}{\partial x} = \frac{\partial v}{\partial y},\qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} \]

ถ้าเป็นจริงและอนุพันธ์ย่อยต่อเนื่อง แล้ว \(f'(z) = u_x + jv_x = v_y - ju_y\)

Z14 Cauchy–Riemann (polar) รูปเชิงขั้ว

\[ u_r = \frac{1}{r}v_\theta,\qquad v_r = -\frac{1}{r}u_\theta \]

Z15 Analytic function ฟังก์ชันวิเคราะห์

\[ f \text{ วิเคราะห์ที่ } z_0 \iff f' \text{ มีค่าทุกจุดในย่านรอบ } z_0 \]

วิเคราะห์ทั้งระนาบเรียกว่า entire เช่น พหุนาม \(e^z,\ \sin z\) · ฟังก์ชันตรรกยะ \(N(s)/D(s)\) วิเคราะห์ทุกจุดยกเว้นรากของ \(D\)

Z16 Harmonic parts u และ v เป็นฟังก์ชันฮาร์มอนิก

\[ \nabla^2 u = u_{xx} + u_{yy} = 0,\qquad \nabla^2 v = 0 \]

ตามมาจาก Z13 ทันที ใช้กับสนามไฟฟ้าสถิตและการไหลของความร้อนสองมิติ: \(u\) เป็นศักย์ เส้น \(v\) คงที่เป็นเส้นแรง

ตัวอย่าง Z-5 · ตรวจด้วยโคชี-รีมันน์

\(f(z) = z^2\), \(g(z) = e^z\) และ \(h(z) = \bar z\) ฟังก์ชันใดวิเคราะห์

  1. \(z^2\): \(u = x^2 - y^2,\ v = 2xy\) · \(u_x = 2x = v_y\) ✓ · \(u_y = -2y = -v_x\) ✓ วิเคราะห์ทุกจุด \(f'(z) = u_x + jv_x = 2x + j2y = 2z\)

  2. \(e^z = e^x\cos y + je^x\sin y\): \(u_x = e^x\cos y = v_y\) ✓ · \(u_y = -e^x\sin y = -v_x\) ✓ วิเคราะห์ทุกจุด \(g'(z) = e^z\)

  3. \(\bar z = x - jy\): \(u_x = 1\) แต่ \(v_y = -1\) ✗ ไม่วิเคราะห์ที่ใดเลย

\(z^2\) และ \(e^z\) วิเคราะห์ทั้งระนาบ ส่วน \(\bar z\) ไม่วิเคราะห์ ลองเปลี่ยนฟังก์ชันในแล็บการส่งด้านบนแล้วดูตารางตรวจ ✓/✗ เปลี่ยนตาม

ตัวอย่าง Z-6 · หาฮาร์มอนิกสังยุค

ให้ \(u = x^3 - 3xy^2\) หา \(v\) ที่ทำให้ \(f = u + jv\) วิเคราะห์

  1. ตรวจก่อนว่า \(u\) เป็นฮาร์มอนิก: \(u_{xx} + u_{yy} = 6x - 6x = 0\) ✓ Z16

  2. จาก \(v_y = u_x = 3x^2 - 3y^2\) อินทิเกรตเทียบ \(y\): \(v = 3x^2y - y^3 + g(x)\)

  3. จาก \(v_x = -u_y\): \(6xy + g'(x) = -(-6xy) = 6xy\) ได้ \(g'(x) = 0\) ดังนั้น \(g = C\)

\(v = 3x^2y - y^3 + C\) และ \(f(z) = z^3 + jC\)

ซีโร่ ภาวะเอกฐาน และอันดับของโพล กลาง

จุดที่ฟังก์ชันเลิกเป็นฟังก์ชันวิเคราะห์เรียกว่าภาวะเอกฐาน (singularity) ในลาปลาซเราเจอเกือบทั้งหมดเป็น โพล แต่ควรรู้จักอีกสองชนิดเพื่อไม่สับสน

Z17 Zero of order m ซีโร่อันดับ m

\[ f(z) = (z - z_0)^m g(z),\quad g(z_0) \ne 0 \]

Z18 Pole of order m โพลอันดับ m

\[ f(z) = \frac{g(z)}{(z - z_0)^m},\quad g \text{ วิเคราะห์},\ g(z_0) \ne 0 \]

ทดสอบ: \(\lim_{z\to z_0}(z-z_0)^m f(z)\) มีค่าจำกัดและไม่เป็นศูนย์ · \(m = 1\) เรียกโพลเดี่ยว (simple pole)

Z19 Types of isolated singularities ชนิดของภาวะเอกฐานเฉพาะจุด

\[ \underbrace{\frac{\sin z}{z}}_{\text{ถอดได้ที่ }0},\qquad \underbrace{\frac{1}{z^2(z+1)}}_{\text{โพลอันดับ 2 ที่ }0,\ \text{อันดับ 1 ที่ }-1},\qquad \underbrace{e^{1/z}}_{\text{สาระสำคัญที่ }0} \]

ถอดได้ (removable): ลิมิตมีค่า แค่ไม่นิยาม เช่น \(\frac{1 - e^{-s}}{s}\) ที่ \(s = 0\) ซึ่งเป็นลาปลาซของพัลส์สี่เหลี่ยม ไม่ใช่โพล · โพล: \(|f| \to \infty\) · สาระสำคัญ (essential): ทำตัวแปลกไม่มีลิมิตเลย ไม่เจอในฟังก์ชันตรรกยะ

ตัวอย่าง Z-7 · จำแนกโพลและซีโร่

\(F(s) = \dfrac{(s+3)(s-1)}{s^2(s+2)(s^2+2s+5)}\)

  1. ซีโร่ (รากของเศษ): \(s = -3,\ s = 1\) อันดับ 1 ทั้งคู่ · ซีโร่ที่ \(s = 1\) อยู่ครึ่งขวา (non-minimum phase)

  2. โพล: \(s = 0\) อันดับ 2 · \(s = -2\) อันดับ 1 · \(s^2 + 2s + 5 = 0 \Rightarrow s = -1 \pm 2j\) อันดับ 1

  3. ดีกรีส่วน 5 ดีกรีเศษ 2: เมื่อ \(s \to \infty\) \(F \sim 1/s^3\) จึงมี “ซีโร่ที่อนันต์” อันดับ 3

5 โพล (นับซ้ำ) 2 ซีโร่จำกัด + 3 ซีโร่ที่อนันต์ จำนวนโพลเท่ากับจำนวนซีโร่เมื่อนับที่อนันต์ด้วยเสมอ

อนุกรมเทย์เลอร์และอนุกรมโลรองต์ ขั้นสูง

เรียนละเอียด: หัวข้อนี้มีบทเต็มพร้อมแล็บลากจุด z ข้ามวงแหวน ที่ อนุกรมโลรองต์ (บทที่ 26.7) ทบทวนรัศมีการลู่เข้าที่ อนุกรมกำลัง และตารางอนุกรมที่ต้องจำที่ อนุกรมเทย์เลอร์

Z20 Taylor series อนุกรมเทย์เลอร์

\[ f(z) = \sum_{n=0}^{\infty}\frac{f^{(n)}(z_0)}{n!}(z - z_0)^n,\quad |z - z_0| < R \]

ฟังก์ชันวิเคราะห์เขียนเป็นอนุกรมกำลังได้เสมอ รัศมีลู่เข้า \(R\) = ระยะถึงภาวะเอกฐานที่ใกล้ที่สุด

Z21 Laurent series อนุกรมโลรองต์

\[ f(z) = \sum_{n=-\infty}^{\infty}a_n(z - z_0)^n = \underbrace{\cdots + \frac{a_{-2}}{(z-z_0)^2} + \frac{a_{-1}}{z - z_0}}_{\text{ส่วนหลัก (principal part)}} + a_0 + a_1(z-z_0) + \cdots \]

ใช้ได้ในวงแหวน \(0 < |z - z_0| < R\) · โพลอันดับ m ⇔ ส่วนหลักมี m พจน์ · สาระสำคัญ ⇔ ส่วนหลักไม่สิ้นสุด

ตัวอย่าง Z-8 · โลรองต์รอบโพล

หาอนุกรมโลรองต์ของ \(F(s) = \dfrac{1}{s(s+1)}\) รอบ \(s = 0\) ในวงแหวน \(0 < |s| < 1\)

  1. ใช้อนุกรมเรขาคณิต \(\dfrac{1}{1+s} = 1 - s + s^2 - s^3 + \cdots\) ซึ่งลู่เข้าเมื่อ \(|s| < 1\)

  2. \[ F(s) = \frac{1}{s}\left(1 - s + s^2 - \cdots\right) = \frac{1}{s} - 1 + s - s^2 + \cdots \]

ส่วนหลักคือ \(\tfrac{1}{s}\) พจน์เดียว → โพลอันดับ 1 และ \(a_{-1} = 1\) คือเรซิดิวที่ \(s = 0\) ซึ่งเท่ากับ A ในเศษส่วนย่อย \(\tfrac{1}{s(s+1)} = \tfrac{1}{s} - \tfrac{1}{s+1}\) พอดี

เรซิดิว (Residue) และวิธีคำนวณ กลาง

เรซิดิวคือสัมประสิทธิ์ \(a_{-1}\) ของ \(1/(z - z_0)\) ในอนุกรมโลรองต์ ชื่อมาจากคำว่า “ส่วนที่เหลือ” เพราะเมื่ออินทิเกรตรอบโพล ทุกพจน์หายไปหมดเหลือเพียงพจน์นี้ ไม่ต้องหาอนุกรมทั้งเส้นก็ได้ มีสูตรลัดสามตัว

Z22 Residue นิยาม

\[ \operatorname{Res}_{z=z_0}f(z) = a_{-1} = \frac{1}{2\pi j}\oint_C f(z)\,dz \]

Z23 Simple pole โพลเดี่ยว

\[ \operatorname{Res}_{z=p}f = \lim_{z\to p}(z - p)f(z) \]

คือ “วิธีปิดตัวประกอบ” ของเฮวิไซด์ในเศษส่วนย่อยนั่นเอง

Z24 Simple pole of N/D ใช้อนุพันธ์ตัวส่วน

\[ \operatorname{Res}_{z=p}\frac{N(z)}{D(z)} = \frac{N(p)}{D'(p)},\quad D(p) = 0,\ D'(p) \ne 0 \]

Z25 Pole of order m โพลซ้ำ

\[ \operatorname{Res}_{z=p}f = \frac{1}{(m-1)!}\lim_{z\to p}\frac{d^{\,m-1}}{dz^{m-1}}\left[(z-p)^m f(z)\right] \]
ตัวอย่าง Z-9 · เรซิดิวที่โพลจริงและโพลเชิงซ้อน

หาเรซิดิวทุกตัวของ \(F(s) = \dfrac{s+2}{(s+1)(s^2+4)}\)

  1. โพล: \(s = -1\) และ \(s = \pm 2j\) อันดับ 1 ทั้งหมด

  2. ที่ \(s = -1\) ปิด \((s+1)\) Z23

    \[ \operatorname{Res}_{-1} = \frac{-1+2}{(-1)^2 + 4} = \frac{1}{5} \]

  3. ที่ \(s = 2j\) ใช้ \(s^2 + 4 = (s - 2j)(s + 2j)\) แล้วปิด \((s - 2j)\)

    \[ \operatorname{Res}_{2j} = \frac{2j + 2}{(2j + 1)(4j)} = \frac{2 + 2j}{-8 + 4j} = \frac{(2+2j)(-8-4j)}{80} = -\frac{1}{10} - \frac{3}{10}j \]

  4. ที่ \(s = -2j\) เป็นสังยุคของค่าก่อนหน้า (เพราะสัมประสิทธิ์ของ \(F\) เป็นจำนวนจริง)

    \[ \operatorname{Res}_{-2j} = -\frac{1}{10} + \frac{3}{10}j \]

เรซิดิว: \(\tfrac15,\ -\tfrac{1}{10} \mp \tfrac{3}{10}j\) · ผลรวมทั้งหมด \(= \tfrac15 - \tfrac{2}{10} = 0\)

ผลรวมเป็นศูนย์ไม่ใช่เรื่องบังเอิญ: เมื่อดีกรีส่วนมากกว่าเศษอย่างน้อย 2 ผลรวมเรซิดิวทุกตัวเป็นศูนย์เสมอ (เพราะ \(\oint\) รอบวงกลมใหญ่มาก → 0)

ตัวอย่าง Z-10 · โพลอันดับสอง

หา \(\operatorname{Res}_{s=-1}\dfrac{e^{st}}{(s+1)^2}\)

  1. \(m = 2\) ใช้สูตรอนุพันธ์ Z25: คูณ \((s+1)^2\) ออกแล้วหาอนุพันธ์หนึ่งครั้ง

    \[ \operatorname{Res} = \frac{1}{1!}\frac{d}{ds}\left[e^{st}\right]_{s=-1} = \left[t e^{st}\right]_{s=-1} = te^{-t} \]

\(te^{-t}\) ตรงกับตารางลาปลาซ \(\mathcal L^{-1}\{1/(s+1)^2\} = te^{-t}\) ซึ่งอธิบายว่าทำไมโพลซ้ำจึงให้พจน์ \(t^k e^{pt}\)

ทฤษฎีบทโคชีและทฤษฎีบทเรซิดิว ขั้นสูง

Z26 Cauchy–Goursat theorem ทฤษฎีบทของโคชี

\[ f \text{ วิเคราะห์บนและภายในเส้นปิด } C \ \Rightarrow\ \oint_C f(z)\,dz = 0 \]

Z27 Residue theorem ทฤษฎีบทเรซิดิว

\[ \oint_C f(z)\,dz = 2\pi j\sum_{k}\operatorname{Res}_{z=z_k}f(z) \]

ผลรวมเฉพาะภาวะเอกฐาน \(z_k\) ที่อยู่ภายใน \(C\) และ \(C\) วิ่งทวนเข็มนาฬิกา ห้ามมีภาวะเอกฐานอยู่บนเส้น

ตัวอย่าง Z-11 · อินทิกรัลรอบวงกลมสองขนาด

หา \(\oint_C \dfrac{s+2}{(s+1)(s^2+4)}\,ds\) เมื่อ \(C: |s| = 1.5\) และ \(C: |s| = 3\)

  1. \(|s| = 1.5\): ล้อมเฉพาะโพล \(s = -1\) (ส่วน \(\pm 2j\) อยู่นอกเพราะ \(|2j| = 2 > 1.5\))

    \[ \oint = 2\pi j\cdot\frac{1}{5} = \frac{2\pi j}{5} \approx 1.2566j \]

  2. \(|s| = 3\): ล้อมทั้งสามโพล ผลรวมเรซิดิวเป็นศูนย์จากตัวอย่าง Z-9

    \[ \oint = 2\pi j\cdot 0 = 0 \]

\(2\pi j/5\) และ \(0\) ลองลากวงกลมในแล็บด้านล่างแล้วเทียบค่าอินทิกรัลเชิงตัวเลขกับ \(2\pi j\sum\operatorname{Res}\)

เชื่อมสู่การแปลงลาปลาซผกผัน: อินทิกรัลบรอมวิช ขั้นสูง

สูตรแปลงกลับที่แท้จริงคืออินทิกรัลบนเส้นตรงแนวตั้ง \(\operatorname{Re}s = c\) ซึ่งอยู่ใน ROC (ทางขวาของทุกโพล) เมื่อ \(t > 0\) ปิดเส้นนี้ด้วยครึ่งวงกลมใหญ่ทางซ้าย อินทิกรัลบนครึ่งวงกลมหายไป (บทตั้งของจอร์แดน เมื่อ \(F(s) \to 0\)) จึงเหลือเพียงผลรวมเรซิดิว

Z28 Inversion by residues การแปลงกลับด้วยเรซิดิว

\[ f(t) = \frac{1}{2\pi j}\int_{c-j\infty}^{c+j\infty}F(s)e^{st}\,ds = \sum_{\text{ทุกโพล } p_k}\operatorname{Res}_{s=p_k}\left[F(s)e^{st}\right],\quad t > 0 \]

ใช้ได้เมื่อ \(F(s)\) เป็นฟังก์ชันตรรกยะแท้ (ดีกรีเศษ < ดีกรีส่วน) รายละเอียด เงื่อนไข และตัวอย่างโพลซ้ำอยู่ในหน้า 8.5

ตัวอย่าง Z-12 · แปลงกลับด้วยเรซิดิวล้วน

หา \(\mathcal L^{-1}\left\{\dfrac{1}{(s+1)(s+2)}\right\}\) ด้วยสูตร Z28

  1. \[ \operatorname{Res}_{s=-1}\frac{e^{st}}{(s+1)(s+2)} = \frac{e^{-t}}{-1+2} = e^{-t} \]
  2. \[ \operatorname{Res}_{s=-2}\frac{e^{st}}{(s+1)(s+2)} = \frac{e^{-2t}}{-2+1} = -e^{-2t} \]

\(f(t) = e^{-t} - e^{-2t},\ t \ge 0\) เหมือนกับที่ได้จากเศษส่วนย่อยทุกประการ เพราะเศษส่วนย่อยคือเรซิดิวที่เขียนอีกแบบ

มองฟังก์ชันตรรกยะเป็นภูมิประเทศ

\(|F(s)|\) เป็นพื้นผิวเหนือระนาบ s ที่พุ่งขึ้นเป็นยอดเขาไม่สิ้นสุดที่โพล และจมลงเป็นหลุมที่ซีโร่ เส้นตัดตามแกน jω คือผลตอบสนองเชิงความถี่ \(|F(j\omega)|\) ลองพิมพ์ฟังก์ชันของคุณเองแล้วเลื่อนเส้นตัด
