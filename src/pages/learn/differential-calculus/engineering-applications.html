// บทที่ 4.1 · อนุพันธ์ · Engineering Applications

การประยุกต์อนุพันธ์ทางวิศวกรรมไฟฟ้า เครื่องกล และโยธา

อนุพันธ์ไม่ใช่แค่แบบฝึกหัดในห้อง ทุกสาขาวิศวกรรมใช้มันทุกวัน: วิศวกรไฟฟ้าใช้หากระแสในตัวเก็บประจุและแรงดันกระชากของขดลวด วิศวกรเครื่องกลใช้หาความเร็วและความเร่งของกลไก วิศวกรโยธาใช้อ่านความชันและโมเมนต์ของคาน และทุกสาขาใช้หาจุดที่ดีที่สุด หน้านี้แยกตามสาขา ทุกตัวอย่างมีตัวเลขจริงและแล็บให้ลอง สูตรใช้รหัส A

เขียนโดย อาจารย์มดอัปเดต
ไฟฟ้า เครื่องกล โยธา ออกแบบเหมาะสม
สรุปใน 30 วินาที
  • ไฟฟ้า: \(i = C\frac{dv}{dt}\), \(v = L\frac{di}{dt}\), \(e = -N\frac{d\Phi}{dt}\), กำลังสูงสุดเมื่อ \(R_L = R_s\)
  • เครื่องกล: \(v = \dot x,\ a = \dot v\), \(q = -k\frac{dT}{dx}\), \(P = T\omega\) สูงสุดที่ครึ่งความเร็วไร้โหลด
  • โยธา: \(V = \frac{dM}{dx}\), \(\theta = \frac{dy}{dx}\), \(M = EI\frac{d^2y}{dx^2}\) โมเมนต์สูงสุดที่ V = 0
  • ทุกสาขา: ค่าเหมาะสมอยู่ที่อนุพันธ์ = 0 และความคลาดเคลื่อน \(dy = f'(x)dx\)

วิศวกรรมไฟฟ้า: C, L, ฟาราเดย์ และกำลัง พื้นฐาน

A1 Capacitor ตัวเก็บประจุ

\[ i_C = C\frac{dv_C}{dt} \]

แรงดันคงที่ → ไม่มีกระแส (DC เปิดวงจร) · แรงดันกระโดด → กระแสอนันต์ จึงเป็นไปไม่ได้

A2 Inductor ตัวเหนี่ยวนำ

\[ v_L = L\frac{di_L}{dt} \]

กระแสคงที่ → ไม่มีแรงดัน (DC ลัดวงจร) · ตัดกระแสเร็ว → แรงดันกระชากสูงมาก

A3 Faraday's law กฎของฟาราเดย์

\[ e = -N\frac{d\Phi}{dt} = -\frac{d\lambda}{dt} \]

A4 Maximum power transfer ถ่ายโอนกำลังสูงสุด

\[ P = \frac{V_s^2R_L}{(R_s + R_L)^2},\quad \frac{dP}{dR_L} = 0 \Rightarrow R_L = R_s,\ P_{\max} = \frac{V_s^2}{4R_s} \]

A5 Small-signal resistance ความต้านทานพลวัต

\[ r_d = \frac{dV_D}{dI_D} = \frac{nV_T}{I_D} \]

ความชันของกราฟ I-V ที่จุดทำงาน = การประมาณเชิงเส้น D30

A6 Sensitivity ความไว

\[ S_x^y = \frac{\partial y}{\partial x}\cdot\frac{x}{y} \approx \frac{\Delta y/y}{\Delta x/x} \]
ตัวอย่าง A-1 · กระแสตัวเก็บประจุ

\(v(t) = 10\sin(100\pi t)\) V คร่อม \(C = 10\ \mu\text{F}\) หา \(i(t)\)

  1. \[ i = C\frac{dv}{dt} = 10\times10^{-6}\cdot 10\cdot100\pi\cos(100\pi t) = 0.0314\cos(100\pi t)\ \text{A} \]

ยอด 31.4 mA และกระแสนำหน้าแรงดัน 90° (cos นำ sin) ตรงกับ \(X_C = 1/(\omega C) = 318\ \Omega\): \(10/318 = 31.4\) mA ✓

ตัวอย่าง A-2 · แรงดันกระชากของรีเลย์

ขดลวด \(L = 50\) mH มีกระแส 2 A (ก) เพิ่มกระแสจาก 0 ถึง 2 A ใน 1 ms (ข) ตัดกระแสเหลือ 0 ใน 10 µs

  1. (ก) \(v = 0.05\times\dfrac{2}{10^{-3}} = 100\) V

  2. (ข) \(v = 0.05\times\dfrac{2}{10^{-5}} = 10{,}000\) V

ตัดเร็วขึ้น 100 เท่า แรงดันสูงขึ้น 100 เท่าเป็น 10 kV จึงต้องมีไดโอดฟรีวีลคร่อมขดลวดเสมอ

ตัวอย่าง A-3 · กฎของฟาราเดย์ในหม้อแปลง

ฟลักซ์ \(\Phi = 0.02\sin(100\pi t)\) Wb ผ่านขดลวด 100 รอบ หาแรงเคลื่อนเหนี่ยวนำ

  1. \[ e = -N\frac{d\Phi}{dt} = -100\cdot0.02\cdot100\pi\cos(100\pi t) = -628.3\cos(100\pi t)\ \text{V} \]

ยอด 628 V (RMS ≈ 444 V) ตรงกับสมการหม้อแปลง \(E_{\text{rms}} = 4.44fN\Phi_m = 4.44(50)(100)(0.02) = 444\) V ✓ — 4.44 มาจาก \(2\pi/\sqrt2\) ซึ่งได้จากการหาอนุพันธ์

ตัวอย่าง A-4 · ถ่ายโอนกำลังสูงสุด

แหล่งจ่าย 12 V ความต้านทานภายใน 4 Ω ต่อโหลด \(R_L\) หาค่าที่ได้กำลังสูงสุด

  1. \[ P = \frac{144R_L}{(4 + R_L)^2},\quad \frac{dP}{dR_L} = 144\frac{(4 + R_L) - 2R_L}{(4 + R_L)^3} = \frac{144(4 - R_L)}{(4 + R_L)^3} \]

  2. \(dP/dR_L = 0 \Rightarrow R_L = 4\ \Omega\) (ก่อนหน้าเป็นบวก หลังเป็นลบ → สูงสุด)

    \[ P_{\max} = \frac{144\cdot4}{64} = 9\ \text{W} \]

\(R_L = 4\ \Omega\), \(P_{\max} = 9\) W ประสิทธิภาพตอนนั้นแค่ 50% ระบบไฟฟ้ากำลังจึงไม่ทำงานที่จุดนี้ แต่วงจรสื่อสารและสายอากาศจับคู่ให้ได้กำลังสูงสุด

ตัวอย่าง A-5 · ความต้านทานสัญญาณเล็กและความไว

(ก) ไดโอดทำงานที่ \(I_D = 1\) mA, \(nV_T = 26\) mV หา \(r_d\) (ข) วงจรแบ่งแรงดัน \(R_1 = R_2\) ถ้า \(R_2\) คลาด 1% \(V_o\) คลาดเท่าไร

  1. (ก) \(r_d = 26\text{ mV}/1\text{ mA} = 26\ \Omega\)

  2. (ข) \(V_o = V_i\dfrac{R_2}{R_1 + R_2}\): \(S = \dfrac{\partial V_o}{\partial R_2}\dfrac{R_2}{V_o} = \dfrac{R_1}{R_1 + R_2} = 0.5\)

(ก) 26 Ω · (ข) 0.5% — ความไวบอกว่าควรใช้ตัวต้านทานเกรดไหน

วิศวกรรมเครื่องกล: การเคลื่อนที่ กลไก ความร้อน และกำลัง กลาง

A7 Kinematics จลนศาสตร์

\[ v = \frac{dx}{dt},\quad a = \frac{dv}{dt} = \frac{d^2x}{dt^2},\quad a = v\frac{dv}{dx} \]

A8 Slider–crank ข้อเหวี่ยง-ก้านสูบ

\[ x(\theta) = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta},\quad v = \omega\frac{dx}{d\theta},\quad a \approx -r\omega^2\left(\cos\theta + \frac rl\cos2\theta\right) \]

A9 Newton's second law

\[ F = \frac{dp}{dt} = m\frac{dv}{dt}\ (m \text{ คงที่}) \]

A10 Fourier's law การนำความร้อน

\[ q = -k\frac{dT}{dx}\ \ (\text{W/m}^2) \]

A11 Motor power กำลังของมอเตอร์ DC

\[ T = T_0\left(1 - \frac{\omega}{\omega_0}\right),\ P = T\omega \Rightarrow P_{\max} = \frac{T_0\omega_0}{4}\ \text{ที่ } \omega = \frac{\omega_0}{2} \]
ตัวอย่าง A-6 · ตำแหน่ง ความเร็ว ความเร่ง

\(x(t) = 2t^3 - 9t^2 + 12t\) m หาเวลาที่หยุดนิ่งและเวลาที่ความเร่งเป็นศูนย์

  1. \[ v = 6t^2 - 18t + 12 = 6(t - 1)(t - 2) = 0 \Rightarrow t = 1,\ 2\ \text{s} \]
  2. \[ a = 12t - 18 = 0 \Rightarrow t = 1.5\ \text{s} \]

หยุดที่ t = 1 s (x = 5 m) และ t = 2 s (x = 4 m) ถอยหลังในช่วง 1–2 s · ความเร่งเปลี่ยนเครื่องหมายที่ 1.5 s (จุดเปลี่ยนเว้าของ x(t))

ตัวอย่าง A-7 · ลูกสูบ

\(r = 5\) cm, \(l = 15\) cm หมุน 600 rpm หาความเร็วลูกสูบที่ \(\theta = 90^\circ\) และความเร่งที่ \(\theta = 0^\circ\)

  1. \(\omega = 600\cdot2\pi/60 = 62.83\) rad/s · \(\dfrac{dx}{d\theta} = -r\sin\theta - \dfrac{r^2\sin\theta\cos\theta}{\sqrt{l^2 - r^2\sin^2\theta}}\) ที่ 90°: \(= -5\) cm/rad

    \[ v = -5\times62.83 = -314\ \text{cm/s} = -3.14\ \text{m/s} \]

  2. ที่ 0°: \(a = -r\omega^2(1 + r/l) = -5(3948)(1.333) = -26{,}319\) cm/s²

\(|v| = 3.14\) m/s ที่ 90° · \(|a| \approx 263\) m/s² ≈ 27 g ที่ศูนย์ตายบน ความเร่งนี้คูณมวลลูกสูบคือแรงที่ก้านสูบต้องรับ

ตัวอย่าง A-8 · ความร้อนผ่านผนัง และกำลังมอเตอร์

(ก) ผนัง \(k = 0.8\) W/m·K หนา 0.2 m ด้านใน 30 °C ด้านนอก 20 °C (ข) มอเตอร์ \(T_0 = 2\) N·m, \(\omega_0 = 300\) rad/s

  1. (ก) อุณหภูมิลดลงเชิงเส้น \(dT/dx = -10/0.2 = -50\) K/m → \(q = -0.8(-50) = 40\) W/m²

  2. (ข) \(P = 2\omega - \tfrac{2}{300}\omega^2\), \(dP/d\omega = 2 - \tfrac{4}{300}\omega = 0 \Rightarrow \omega = 150\) rad/s, \(P = 150\) W

(ก) 40 W/m² · (ข) กำลังสูงสุด 150 W ที่ 150 rad/s (≈ 1432 rpm) ครึ่งหนึ่งของความเร็วไร้โหลด

วิศวกรรมโยธา: คาน ถนน รางน้ำ และงานสำรวจ กลาง

A12 Beam relations ความสัมพันธ์ของคาน

\[ \frac{dV}{dx} = -w(x),\qquad \frac{dM}{dx} = V(x),\qquad \theta = \frac{dy}{dx},\qquad EI\frac{d^2y}{dx^2} = M(x) \]

อนุพันธ์ไล่จากการโก่งขึ้นไปหาน้ำหนัก ส่วนการอินทิเกรตไล่ลงมา ดูแล็บคานในหน้าอินทิกรัล

A13 Vertical curve โค้งทางดิ่งแบบพาราโบลา

\[ y = g_1x + \frac{g_2 - g_1}{2L}x^2,\quad y' = 0 \Rightarrow x = \frac{g_1L}{g_1 - g_2} \]

A14 Best rectangular channel หน้าตัดรางน้ำดีที่สุด

\[ P = \frac{A}{y} + 2y,\quad \frac{dP}{dy} = 0 \Rightarrow b = 2y \]
ตัวอย่าง A-9 · โมเมนต์สูงสุดของคาน

คานช่วงเดียว \(L = 6\) m รับน้ำหนักแผ่ \(w = 10\) kN/m หาโมเมนต์ดัดสูงสุด

  1. แรงปฏิกิริยา \(wL/2 = 30\) kN · \(M(x) = 30x - 5x^2\)

  2. \(\dfrac{dM}{dx} = 30 - 10x = V(x) = 0 \Rightarrow x = 3\) m (กลางคาน) A12

    \[ M_{\max} = 30(3) - 5(9) = 45\ \text{kN}\cdot\text{m} = \frac{wL^2}{8} \]

45 kN·m ที่กลางคาน ตรงจุดที่แรงเฉือนเป็นศูนย์

ตัวอย่าง A-10 · ความชันที่ฐานและการโก่งสูงสุด

คานเดิม \(EI = 20{,}000\) kN·m² เส้นโก่ง \(y = -\dfrac{wx}{24EI}\left(L^3 - 2Lx^2 + x^3\right)\)

  1. \(\theta = y' = -\dfrac{w}{24EI}\left(L^3 - 6Lx^2 + 4x^3\right)\) ที่ฐาน \(x = 0\):

    \[ \theta_0 = -\frac{wL^3}{24EI} = -\frac{10(216)}{480{,}000} = -0.0045\ \text{rad} \]

  2. โก่งสูงสุดที่ \(\theta = 0\) คือ \(x = L/2\) (สมมาตร)

    \[ y_{\max} = -\frac{5wL^4}{384EI} = -\frac{5(10)(1296)}{7{,}680{,}000} = -8.44\ \text{mm} \]

θ ที่ฐาน 0.0045 rad (0.26°) · โก่ง 8.44 mm ≈ L/711 ผ่านเกณฑ์ทั่วไป L/360

ตัวอย่าง A-11 · จุดสูงสุดของโค้งทางดิ่ง

ทางขึ้นลาด +3% เปลี่ยนเป็นลง −2% ด้วยโค้งยาว 200 m จุดสูงสุดอยู่ที่ใด

  1. \[ y' = 0.03 + \frac{-0.02 - 0.03}{200}x = 0 \Rightarrow x = \frac{0.03(200)}{0.05} = 120\ \text{m} \]
  2. \[ y(120) = 0.03(120) - \frac{0.05}{400}(120)^2 = 3.6 - 1.8 = 1.8\ \text{m} \]

ที่ 120 m จากจุดเริ่มโค้ง สูงกว่าจุดเริ่ม 1.8 m (ตำแหน่งท่อระบายน้ำและระยะมองเห็น)

ตัวอย่าง A-12 · รางน้ำและงานสำรวจ

(ก) รางสี่เหลี่ยมพื้นที่หน้าตัด 8 m² ขนาดใดใช้วัสดุบุน้อยสุด (ข) วัดรัศมีลานวงกลม 50 m คลาด ±0.05 m พื้นที่คลาดเท่าไร

  1. (ก) \(\dfrac{dP}{dy} = -\dfrac{8}{y^2} + 2 = 0 \Rightarrow y = 2\) m, \(b = 4\) m, \(P = 8\) m A14

  2. (ข) \(dA = 2\pi r\,dr = 2\pi(50)(0.05) = 15.7\) m² (สัมพัทธ์ \(2\,dr/r = 0.2\%\))

(ก) กว้าง 4 m ลึก 2 m · (ข) ±15.7 m² จากพื้นที่ 7,854 m²

แล็บออกแบบให้เหมาะสมที่สุด (ทุกสาขา)

ห้าโจทย์คลาสสิกจากสามสาขา ลากจุดบนกราฟบนเพื่อเปลี่ยนค่า x กราฟล่างคืออนุพันธ์ จุดที่ดีที่สุดอยู่ตรงที่อนุพันธ์ข้ามแกนศูนย์ทุกโจทย์ วิธีคิดเหมือนกันหมด: เขียนปริมาณที่ต้องการให้เป็นฟังก์ชันของตัวแปรเดียว หาอนุพันธ์ ตั้งเท่ากับศูนย์ แล้วตรวจว่าเป็นสูงสุดหรือต่ำสุด

ตัวอย่าง A-13 · กระป๋องใช้วัสดุน้อยสุด

กระป๋องทรงกระบอกปิดหัวท้าย ปริมาตร 1 ลิตร (1000 cm³) ใช้แผ่นโลหะน้อยที่สุดเมื่อมีขนาดเท่าใด

  1. \(\pi r^2h = 1000 \Rightarrow h = \dfrac{1000}{\pi r^2}\) · พื้นที่ผิว \(A = 2\pi r^2 + 2\pi rh = 2\pi r^2 + \dfrac{2000}{r}\)

  2. \[ A'(r) = 4\pi r - \frac{2000}{r^2} = 0 \Rightarrow r^3 = \frac{500}{\pi} \Rightarrow r = 5.42\ \text{cm} \]

  3. \(A''(r) = 4\pi + 4000/r^3 > 0\) → ต่ำสุด · \(h = 1000/(\pi\cdot5.42^2) = 10.84\) cm

\(r = 5.42\) cm, \(h = 10.84\) cm คือ \(h = 2r\): สูงเท่าเส้นผ่านศูนย์กลาง
