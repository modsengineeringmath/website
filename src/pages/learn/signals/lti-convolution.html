ระบบ LTI และคอนโวลูชัน (LTI Systems and Convolution): จากผลตอบสนองอิมพัลส์ถึงผลตอบสนองเชิงความถี่

ถ้าวิชาสัญญาณและระบบมีประโยคเดียวที่ต้องจำ ผมเลือกประโยคนี้: ระบบ LTI ถูกบรรยายครบด้วยผลตอบสนองอิมพัลส์ h(t) และเอาต์พุตคือคอนโวลูชันของอินพุตกับ h หน้านี้อธิบายว่าประโยคนี้มาจากไหน คิดคอนโวลูชันด้วยมืออย่างไรทั้งแบบต่อเนื่องและไม่ต่อเนื่อง แล้วปิดท้ายด้วยเรื่องที่ใช้ตรีโกณหนักที่สุดของบท คือทำไมไซน์เข้าแล้วไซน์ออก ซึ่งเป็นประตูไปสู่ฟูริเยร์

เขียนโดย อาจารย์มดอัปเดต
คุณสมบัติของระบบ อินทิกรัลคอนโวลูชัน คอนโวลูชันไม่ต่อเนื่อง ไซน์เข้า ไซน์ออก
สรุปทั้งหน้า

เอาต์พุตของระบบ LTI\(y(t) = \displaystyle\int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau\)\(y[n] = \displaystyle\sum_{k} x[k]\,h[n-k]\)
คอซัล\(h(t) = 0\) เมื่อ \(t < 0\)\(h[n] = 0\) เมื่อ \(n < 0\)
เสถียร (BIBO)\(\int |h(t)|\,dt < \infty\)\(\sum |h[n]| < \infty\)
ผลตอบสนองขั้นบันได\(s(t) = \int_{-\infty}^{t} h(\tau)\,d\tau\)\(s[n] = \sum_{k \le n} h[k]\)
อินพุตไซน์\(\cos\omega t \to |H(j\omega)|\cos(\omega t + \angle H)\)\(\cos\Omega n \to |H(e^{j\Omega})|\cos(\Omega n + \angle H)\)

คุณสมบัติของระบบ: ทดสอบทีละข้อ พื้นฐาน

ระบบคือกฎที่รับสัญญาณ x แล้วให้สัญญาณ y เขียนสั้น ๆ ว่า \(y = T\{x\}\) ก่อนจะคิดคอนโวลูชันได้ ระบบต้องมีสองคุณสมบัติแรกในตารางนี้ ส่วนคุณสมบัติที่เหลือใช้บอกว่าระบบสร้างได้จริงและใช้งานได้หรือไม่

คุณสมบัตินิยามวิธีทดสอบเร็ว
เชิงเส้น (linear)\(T\{a x_1 + b x_2\} = aT\{x_1\} + bT\{x_2\}\)ใส่ x = 0 ต้องได้ y = 0 และไม่มี x², |x|, ค่าคงที่บวกเพิ่ม
ไม่แปรตามเวลา (time-invariant)ถ้า \(x(t) \to y(t)\) แล้ว \(x(t - t_0) \to y(t - t_0)\)t ต้องไม่ปรากฏนอก x(·) และไม่มีการสเกลเวลา x(2t)
คอซัล (causal)y ณ เวลา t ใช้ x แค่ถึงเวลา tไม่มี x(t + 1) หรือ x(−t)
มีหน่วยความจำ (memory)y(t) ขึ้นกับ x ที่เวลาอื่นด้วยมีการเลื่อน อินทิกรัล หรืออนุพันธ์
เสถียร (BIBO stable)อินพุตจำกัดต้องให้เอาต์พุตจำกัดสำหรับ LTI ดูว่า \(\int|h|\) จำกัดหรือไม่
ตัวอย่าง 1

จำแนกระบบห้าตัว

  1. \(y(t) = x(t - 2)\): เชิงเส้น ไม่แปรตามเวลา คอซัล (ใช้อดีต) มีหน่วยความจำ เสถียร นี่คือตัวหน่วงเวลา \(h(t) = \delta(t-2)\)

  2. \(y(t) = t\,x(t)\): เชิงเส้น แต่แปรตามเวลา เพราะเลื่อนอินพุตแล้วได้ \(t\,x(t - t_0)\) ไม่ใช่ \((t - t_0)\,x(t - t_0)\)

  3. \(y(t) = x^2(t)\): ไม่เชิงเส้น ใส่ 2x ได้ 4y

  4. \(y(t) = x(t) + 1\): ไม่เชิงเส้น ใส่ x = 0 แล้วได้ y = 1 (เรียกว่า affine)

  5. \(y(t) = x(2t)\): เชิงเส้น แต่แปรตามเวลา และไม่คอซัล เพราะ y(1) ต้องใช้ x(2) ซึ่งอยู่ในอนาคต

มีแค่ข้อแรกที่เป็น LTI จึงมีข้อแรกข้อเดียวที่ใช้คอนโวลูชันได้

ทำไมผลตอบสนองอิมพัลส์บอกทุกอย่าง

อิมพัลส์ \(\delta(t)\) มีคุณสมบัติร่อน (sifting) คือ \(\int x(\tau)\,\delta(t-\tau)\,d\tau = x(t)\) อ่านอีกแบบได้ว่า สัญญาณใดก็คือกองอิมพัลส์จำนวนมาก อิมพัลส์ที่ตำแหน่ง τ มีน้ำหนัก \(x(\tau)\,d\tau\)

\[ x(t) = \int_{-\infty}^{\infty} x(\tau)\,\delta(t - \tau)\,d\tau \]

ส่งกองอิมพัลส์นี้เข้าระบบ แล้วใช้สองคุณสมบัติทีละข้อ

  1. ไม่แปรตามเวลา: ถ้า \(\delta(t) \to h(t)\) แล้ว \(\delta(t - \tau) \to h(t - \tau)\)
  2. เชิงเส้น: น้ำหนัก \(x(\tau)\,d\tau\) ติดไปด้วย และผลรวม (อินทิกรัล) ของอินพุตให้ผลรวมของเอาต์พุต
\[ y(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t - \tau)\,d\tau \;\equiv\; (x * h)(t) \]

ฉะนั้นถ้าวัด h(t) ได้ครั้งเดียว เราก็ทำนายเอาต์พุตของอินพุตแบบใดก็ได้ ในงานจริงเราวัด h ได้หลายแบบ เช่น ตบมือในห้องแล้วอัดเสียงก้อง (ได้ h ของห้อง) หรือป้อนขั้นบันไดแล้วดิฟผลตอบสนอง เพราะ \(h(t) = \tfrac{d}{dt}s(t)\) อนุพันธ์อันดับสูง

คุณสมบัติที่ควรรู้ของ * : สลับที่ได้ \(x * h = h * x\) จัดกลุ่มได้ (ต่ออนุกรมสองระบบ = คอนโวลูชันของ h ทั้งสอง) แจกแจงได้ (ต่อขนาน = บวก h) และ \(x * \delta(t - t_0) = x(t - t_0)\)

คิดอินทิกรัลคอนโวลูชันด้วยมือ: กลับ เลื่อน คูณ อินทิเกรต กลาง

อ่านสูตรจากมุมของตัวแปร τ: ที่ t คงที่หนึ่งค่า \(h(t - \tau)\) คือ h ที่ถูกกลับซ้ายขวา (เพราะมี −τ) แล้วเลื่อนไปให้จุดเริ่มอยู่ที่ τ = t ต่อจากนั้นคูณกับ x(τ) แล้วหาพื้นที่ ขั้นที่คนพลาดมากที่สุดคือขอบเขตของอินทิกรัล วิธีกันพลาดคือวาดรูปทุกช่วงของ t

ตัวอย่าง 2

\(u(t) * e^{-t}u(t)\) ผลตอบสนองขั้นบันไดของวงจร RC

  1. ถ้า t < 0 ตัวกลับ-เลื่อน \(e^{-(t-\tau)}u(t-\tau)\) อยู่ทางซ้ายของ 0 ทั้งหมด ไม่ซ้อนกับ u(τ) ได้ y = 0

  2. ถ้า t ≥ 0 ซ้อนกันช่วง \(0 \le \tau \le t\)

  3. \(y(t) = \displaystyle\int_0^t e^{-(t-\tau)}\,d\tau = e^{-t}\big[e^{\tau}\big]_0^t = e^{-t}(e^t - 1)\)

\(y(t) = (1 - e^{-t})\,u(t)\) ตรงกับการชาร์จตัวเก็บประจุที่ τ = RC = 1 s ในสมการอันดับหนึ่ง

ตัวอย่าง 3

\(e^{-t}u(t) * e^{-2t}u(t)\)

  1. t ≥ 0: \(y = \displaystyle\int_0^t e^{-\tau}e^{-2(t-\tau)}\,d\tau = e^{-2t}\int_0^t e^{\tau}\,d\tau = e^{-2t}(e^t - 1)\)

\(y(t) = (e^{-t} - e^{-2t})\,u(t)\) · ระบบอันดับหนึ่งสองตัวต่ออนุกรมได้ระบบอันดับสองแบบหน่วงเกิน

ตัวอย่าง 4

พัลส์ \(0 \le t < 1\) คอนโวลูชันกับตัวเอง

  1. 0 ≤ t < 1: ซ้อนกันช่วง \([0, t]\) ยาว t

  2. 1 ≤ t < 2: ซ้อนกันช่วง \([t - 1, 1]\) ยาว \(2 - t\)

  3. นอกนั้นไม่ซ้อนกัน

ได้สามเหลี่ยมฐาน 0 ถึง 2 ยอดสูง 1 ที่ t = 1 · ความกว้างของผลลัพธ์ = ผลรวมความกว้าง (1 + 1)

ลองดูด้วยตาในแล็บข้างล่าง เลือก x และ h แล้วลากแถบ t หรือกดเล่น เส้นประคือ h ที่ถูกกลับแล้วเลื่อน พื้นที่สีเขียวคือค่า y(t) ณ ตำแหน่งนั้น กราฟล่างคือ y ทั้งเส้นที่ได้จากการลากไปจนสุด

คอนโวลูชันไม่ต่อเนื่อง: ตารางคูณแล้วบวกตามแนวทแยง

ในเวลาไม่ต่อเนื่อง อิมพัลส์คือ \(\delta[n]\) (มีค่า 1 ที่ n = 0 เท่านั้น) และอินทิกรัลกลายเป็นผลรวม

\[ y[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n - k] \]

วิธีกลับ-เลื่อนใช้ได้เหมือนเดิม แต่ถ้าสัญญาณสั้น ตารางคูณเร็วกว่ามาก เอา x เป็นหัวคอลัมน์ h เป็นหัวแถว คูณทุกช่อง แล้วบวกช่องที่อยู่บนเส้นทแยงเดียวกัน (ช่องที่ i + j เท่ากันคือเวลาเดียวกัน) วิธีนี้เหมือนการคูณพหุนามทุกขั้น เพราะพจน์ \(z^{-i}\) คูณ \(z^{-j}\) ได้ \(z^{-(i+j)}\) ซึ่งเป็นเหตุผลที่การแปลง Z เปลี่ยนคอนโวลูชันเป็นการคูณ

ตัวอย่าง 5

\(\{1, 2, 1\} * \{1, -1\}\) เริ่มที่ n = 0 ทั้งคู่

  1. แถว h[0] = 1: \(1, 2, 1\) · แถว h[1] = −1: \(-1, -2, -1\) (เลื่อนไปหนึ่งช่อง)

  2. บวกตามเวลา: \(y[0] = 1,\ y[1] = 2 - 1,\ y[2] = 1 - 2,\ y[3] = -1\)

\(y[n] = \{1, 1, -1, -1\}\) ยาว 3 + 2 − 1 = 4 · ระบบ \(h = \{1, -1\}\) คือผลต่างย้อนหลัง หรือ "อนุพันธ์ไม่ต่อเนื่อง"

ตัวอย่าง 6

ค่าเฉลี่ยเคลื่อนที่ 3 จุดของ \(\{1, 2, 3, 4\}\)

  1. \(h = \{\tfrac13, \tfrac13, \tfrac13\}\)

  2. \(y[0] = \tfrac13,\ y[1] = \tfrac{1+2}{3},\ y[2] = \tfrac{1+2+3}{3},\ y[3] = \tfrac{2+3+4}{3},\ y[4] = \tfrac{3+4}{3},\ y[5] = \tfrac43\)

\(y = \{\tfrac13, 1, 2, 3, \tfrac73, \tfrac43\}\) ช่วงกลางเรียบตามข้อมูล ส่วนหัวและท้ายเป็นช่วงที่หน้าต่างยังไม่เต็ม

แล็บนี้คิดเป็นเศษส่วนแท้ แสดงตารางคูณ ผลลัพธ์ และรูปพหุนามใน \(z^{-1}\) แล้วตรวจซ้ำด้วยเลขทศนิยมให้ทุกครั้ง ถ้าอยากใช้เป็นเครื่องคิดเลขเต็มหน้า ไปที่เครื่องคำนวณคอนโวลูชัน

คอซัลและเสถียรภาพ อ่านจาก h ได้ทันที

ดูสูตร \(y(t) = \int x(t - \tau)h(\tau)\,d\tau\) (สลับที่แล้ว) ถ้า h(τ) ไม่เป็นศูนย์ที่ τ < 0 ก็แปลว่า y ใช้ \(x\) ในอนาคต ระบบคอซัลจึงต้องมี \(h(t) = 0\) เมื่อ t < 0

ส่วนเสถียรภาพ ถ้า \(|x| \le M\) แล้ว \(|y(t)| \le M\int|h(\tau)|\,d\tau\) ดังนั้นถ้า \(\int|h|\) จำกัด เอาต์พุตก็จำกัด กลับกัน ถ้าอินทิกรัลนี้เป็นอนันต์ เราสร้างอินพุตขนาดไม่เกิน 1 ที่ทำให้ y ระเบิดได้เสมอ (เลือก x ให้มีเครื่องหมายตรงกับ h ที่กลับแล้ว)

h\(\int|h|\) หรือ \(\sum|h|\)เสถียร?

\(u(t)\) (ตัวอินทิเกรต)∞ไม่เสถียร ป้อน DC แล้วเอาต์พุตโตเป็นเส้นตรง

แถวที่สามน่าสนใจ \(|\sin t|\) ไม่ลดลงเลย อินทิกรัลจึงโตไม่จำกัด ทั้งที่ h เองไม่ระเบิด นี่คือเรื่องเดียวกับเรโซแนนซ์ในสมการเชิงอนุพันธ์

ทำไมไซน์เข้าแล้วไซน์ออก: พิสูจน์ด้วยตรีโกณทีละบรรทัด ขั้นสูง

นี่คือเหตุผลที่วิศวกรไฟฟ้าใช้เฟสเซอร์ได้ และเป็นเหตุผลที่ฟูริเยร์ใช้ได้กับระบบ LTI ผมจะพิสูจน์สองแบบ แบบแรกใช้แค่ตรีโกณ แบบที่สองใช้สูตรออยเลอร์

แบบที่ 1: สูตรผลบวกมุมอย่างเดียว

ให้อินพุต \(x(t) = \cos\omega t\) แทนลงในคอนโวลูชัน (เขียนแบบ h อยู่ข้างหน้า)

\[ y(t) = \int_{-\infty}^{\infty} h(\tau)\cos\big(\omega t - \omega\tau\big)\,d\tau \]

กระจาย cos ของผลต่างมุม สูตรผลบวกมุมของ cos \(\cos(A - B) = \cos A\cos B + \sin A\sin B\) โดย A = ωt และ B = ωτ

\[ y(t) = \cos\omega t\underbrace{\int h(\tau)\cos\omega\tau\,d\tau}_{a} \;+\; \sin\omega t\underbrace{\int h(\tau)\sin\omega\tau\,d\tau}_{b} \]

a และ b เป็นแค่ตัวเลข (ไม่มี t) ดังนั้น y เป็นผลรวมของ cos ωt กับ sin ωt ความถี่เดียวกัน รวมเป็นคลื่นเดียวได้เสมอ รวมเป็นคลื่นเดียว

\[ y(t) = a\cos\omega t + b\sin\omega t = R\cos(\omega t - \varphi),\qquad R = \sqrt{a^2 + b^2},\ \tan\varphi = \frac{b}{a} \]

จบการพิสูจน์ ความถี่ไม่เปลี่ยน สิ่งที่ระบบทำได้มีแค่สองอย่าง คูณขนาดด้วย R และหน่วงเฟสไป φ ระบบไม่เชิงเส้นทำแบบนี้ไม่ได้ เช่น \(y = x^2\) ป้อน cos ωt ได้ \(\tfrac12 + \tfrac12\cos2\omega t\) ลดกำลัง cos² เกิดความถี่ใหม่ 2ω ซึ่งคือที่มาของฮาร์มอนิกในระบบไฟฟ้ากำลัง

ตัวอย่าง 7

วงจร RC โลว์พาส \(RC = 1\) ms ป้อน \(\cos(1000t)\)

  1. \(h(t) = a\,e^{-at}u(t)\) โดย \(a = \tfrac{1}{RC} = 1000\ \text{s}^{-1}\)

  2. \(\displaystyle a_{\cos} = \int_0^\infty a e^{-a\tau}\cos\omega\tau\,d\tau = \frac{a^2}{a^2 + \omega^2} = \frac12,\qquad b_{\sin} = \int_0^\infty a e^{-a\tau}\sin\omega\tau\,d\tau = \frac{a\omega}{a^2 + \omega^2} = \frac12\) (อินทิเกรตทีละส่วนสองรอบ หรือใช้ลาปลาซ)

  3. \(y = \tfrac12\cos1000t + \tfrac12\sin1000t\) รวมคลื่นได้ \(R = \tfrac{\sqrt2}{2}\), \(\tan\varphi = 1 \Rightarrow \varphi = 45^\circ\) รวมเป็นคลื่นเดียว มุมพิเศษ

\(y(t) = 0.7071\cos(1000t - 45^\circ)\) · ความถี่นี้คือความถี่ตัด (cutoff) พอดี ขนาดลดเหลือ \(1/\sqrt2\) หรือ −3 dB

แบบที่ 2: เลขชี้กำลังเชิงซ้อน (สั้นกว่าและเป็นที่มาของ H(jω))

ป้อน \(x(t) = e^{j\omega t}\) แทน แล้วดึง \(e^{j\omega t}\) ออกจากอินทิกรัลได้ทันที

\[ y(t) = \int h(\tau)e^{j\omega(t - \tau)}\,d\tau = e^{j\omega t}\underbrace{\int h(\tau)e^{-j\omega\tau}\,d\tau}_{H(j\omega)} \]

ฟังก์ชันที่เข้าแล้วออกมาเป็นตัวเดิมคูณค่าคงที่เรียกว่าฟังก์ชันลักษณะเฉพาะ (eigenfunction) ของระบบ และ H(jω) คือค่าลักษณะเฉพาะ ซึ่งก็คือการแปลงฟูริเยร์ของ h นั่นเอง กลับมาที่ cos: cos, sin ในรูปเลขชี้กำลัง \(\cos\omega t = \tfrac12\big(e^{j\omega t} + e^{-j\omega t}\big)\) ป้อนสองก้อนแยกกันแล้วบวก (เชิงเส้น)

\[ y = \tfrac12\big(H(j\omega)e^{j\omega t} + H(-j\omega)e^{-j\omega t}\big) \]

ถ้า h เป็นจริง \(H(-j\omega) = \overline{H(j\omega)}\) สองก้อนจึงเป็นสังยุคกัน ผลบวกเท่ากับสองเท่าของส่วนจริง เขียน \(H = |H|e^{j\theta}\) แล้วใช้สูตรออยเลอร์อีกครั้ง สูตรออยเลอร์

\[ y = \operatorname{Re}\big\{|H|e^{j(\omega t + \theta)}\big\} = |H(j\omega)|\cos\big(\omega t + \angle H(j\omega)\big) \]

ตรวจกับตัวอย่าง 7: \(H(j\omega) = \dfrac{a}{a + j\omega} = \dfrac{1}{1 + j}\) ได้ \(|H| = \tfrac{1}{\sqrt2}\) และ \(\angle H = -45^\circ\) ตรงกัน ทั้งสองวิธีคือเรื่องเดียวกัน แบบแรกเห็นตรีโกณชัด แบบที่สองสั้นและขยายไปสู่ฟูริเยร์ได้

จุดที่มักพลาด

  • ลืมกลับ h คอนโวลูชันใช้ \(h(t - \tau)\) ไม่ใช่ \(h(\tau - t)\) ถ้าไม่กลับจะได้สหสัมพันธ์ (correlation) ซึ่งเป็นอีกเรื่อง
  • ขอบเขตอินทิกรัลผิด หาช่วงที่ทั้งสองตัวไม่เป็นศูนย์พร้อมกัน แยกเป็นกรณีตาม t และอย่าลืมกรณี y = 0
  • ลืม u(t) ในคำตอบ \(1 - e^{-t}\) ที่ t < 0 ไม่ใช่ศูนย์ ต้องเขียน \((1 - e^{-t})u(t)\)
  • ความยาวคอนโวลูชันไม่ต่อเนื่อง ยาว N + M − 1 และเริ่มที่ผลรวมของจุดเริ่ม
  • ตอบเฟสเป็นบวก ระบบคอซัลแบบโลว์พาสหน่วงเฟส คำตอบควรเป็น \(\cos(\omega t - 45^\circ)\) ไม่ใช่ +45°

ต่อไป: การแปลงฟูริเยร์ ซึ่งเปลี่ยนคอนโวลูชันเป็นการคูณ และทำให้เห็นระบบผ่านสายตาของความถี่
