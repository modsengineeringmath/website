// บทที่ 11.3 · สัญญาณและระบบ · Sampling & Aliasing

การสุ่มสัญญาณและอเลียสซิง (Sampling and Aliasing): ทฤษฎีบทการสุ่มของไนควิสต์–แชนนอน

ทุกครั้งที่ไมโครคอนโทรลเลอร์อ่านเซนเซอร์ มือถืออัดเสียง หรือออสซิลโลสโคปดิจิทัลวัดสัญญาณ สิ่งที่เกิดขึ้นคือการสุ่ม เก็บค่าเป็นจุด ๆ ทุก Tₛ วินาที คำถามคือ จุดพวกนั้นพอจะบอกสัญญาณเดิมได้ครบหรือเปล่า คำตอบอยู่ในเอกลักษณ์ตรีโกณสองตัว ได้แก่ cos มีคาบ 2π และ cos เป็นฟังก์ชันคู่ หน้านี้เดินจากสองบรรทัดนั้นไปจนถึงทฤษฎีบทการสุ่ม

เขียนโดย อาจารย์มดอัปเดต
ทำไมเกิดอเลียส ทฤษฎีบทการสุ่ม สูตรความถี่ปลอม แล็บอเลียสซิง
สรุปทั้งหน้า
คาบสุ่ม / อัตราสุ่ม\(T_s = 1/f_s\)
เงื่อนไขไม่เกิดอเลียส\(f_s > 2B\) (B = ความถี่สูงสุดของสัญญาณ)
อัตรา Nyquist · ความถี่ Nyquist\(2B\) · \(f_s/2\)
ความถี่ปลอม\(f_a = |f - k f_s|\) เลือก k ให้ \(0 \le f_a \le f_s/2\)
ความถี่ดิจิทัล\(\Omega = 2\pi f/f_s\) rad/sample · Ω กับ Ω + 2π คือตัวเดียวกัน
สเปกตรัมหลังสุ่ม\(X_s(f) = f_s\sum_k X(f - kf_s)\) ซ้ำทุก fₛ

การสุ่มคืออะไร และความถี่ดิจิทัล พื้นฐาน

สุ่มสัญญาณ x(t) ทุก \(T_s\) วินาที ได้ลำดับ \(x[n] = x(nT_s)\) ถ้าสัญญาณเป็น \(\cos(2\pi ft)\) จะได้

\[ x[n] = \cos(2\pi f nT_s) = \cos\!\Big(\underbrace{2\pi\frac{f}{f_s}}_{\Omega}\,n\Big) \]

Ω มีหน่วยเรเดียนต่อจุดสุ่ม (rad/sample) เรียกว่าความถี่ดิจิทัล บอกว่าระหว่างจุดสุ่มสองจุดติดกัน ไซน์หมุนไปกี่เรเดียน มุมเป็นเรเดียน เช่น f = 1 kHz สุ่มด้วย 8 kHz ได้ \(\Omega = 2\pi/8 = \pi/4\) คือหนึ่งคาบมีแปดจุด

สิ่งสำคัญคือ Ω ไม่ได้มีค่าเดียว เพราะ n เป็นจำนวนเต็ม \(\cos\big((\Omega + 2\pi)n\big) = \cos(\Omega n + 2\pi n) = \cos\Omega n\) คาบ 2π ความถี่ดิจิทัลจึงวนซ้ำทุก 2π นี่คือรากของอเลียสซิงทั้งหมด

ทำไมเกิดอเลียสซิง: สองเอกลักษณ์ตรีโกณ กลาง

เทียบไซน์ความถี่ f กับไซน์ความถี่ \(f_s - f\) ที่จุดสุ่มเดียวกัน

\[ \cos\big(2\pi(f_s - f)nT_s\big) = \cos\big(2\pi n - 2\pi fnT_s\big) \]

เพราะ \(f_sT_s = 1\) ตัวแรกจึงเหลือ \(2\pi n\) ต่อจากนี้ใช้เอกลักษณ์สองตัวต่อกัน

  1. คาบ 2π: ตัด \(2\pi n\) ทิ้งได้เพราะ n เป็นจำนวนเต็ม คาบ 2π เหลือ \(\cos(-2\pi fnT_s)\)
  2. cos เป็นฟังก์ชันคู่: \(\cos(-\theta) = \cos\theta\) ฟังก์ชันคู่-คี่ เหลือ \(\cos(2\pi fnT_s)\)
\[ \cos\big(2\pi(f_s - f)nT_s\big) = \cos\big(2\pi fnT_s\big)\quad\text{ทุกค่า } n \]

ไซน์สองความถี่ให้จุดสุ่มเหมือนกันทุกจุด ดูจากจุดอย่างเดียวแยกไม่ออกเลยว่ามาจากตัวไหน ใช้เหตุผลเดียวกันกับ \(f + kf_s\) และ \(kf_s - f\) สำหรับจำนวนเต็ม k ใดก็ได้ ความถี่ทั้งตระกูลนี้เป็น "ชื่อปลอม" (alias) ของกันและกัน

ตัวอย่าง 1

ไซน์ 7 Hz สุ่มด้วย 10 Hz

  1. \(f_s - f = 10 - 7 = 3\) Hz

  2. ตรวจ: \(\cos(2\pi\cdot7\cdot\tfrac{n}{10}) = \cos(1.4\pi n)\) และ \(\cos(2\pi\cdot3\cdot\tfrac{n}{10}) = \cos(0.6\pi n)\) ผลรวมของมุมคือ \(2\pi n\) จึงเป็น cos ของมุมตรงข้ามบวกคาบเต็ม ค่าเท่ากัน

จุดสุ่มดูเหมือนไซน์ 3 Hz · ความถี่ Nyquist คือ 5 Hz และ 7 Hz อยู่เกินไป 2 Hz จึงพับกลับมาที่ 5 − 2 = 3 Hz

sin ต่างจาก cos ตรงไหน: ทิศหมุนกลับ

sin เป็นฟังก์ชันคี่ ฟังก์ชันคู่-คี่ ดังนั้น \(\sin\big(2\pi(f_s - f)nT_s\big) = \sin(-2\pi fnT_s) = -\sin(2\pi fnT_s)\) จุดสุ่มเหมือนกันแต่กลับเครื่องหมาย ถ้ามองไซน์เป็นเฟสเซอร์หมุน \(e^{j2\pi ft}\) สูตรออยเลอร์ ความถี่ปลอมคือ \(f - f_s\) ซึ่งติดลบ แปลว่าเฟสเซอร์ดูเหมือนหมุนกลับทิศ

ตัวอย่าง 2

ล้อหมุน 23 รอบ/วินาที ถ่ายวิดีโอ 24 ภาพ/วินาที

  1. \(f - f_s = 23 - 24 = -1\) รอบ/วินาที

ในวิดีโอเห็นล้อถอยหลังช้า ๆ 1 รอบต่อวินาที ถ้าหมุน 24 รอบ/วินาทีพอดี ล้อจะดูหยุดนิ่ง ไฟสโตรโบสโคปที่ใช้วัดความเร็วรอบมอเตอร์ทำงานด้วยหลักนี้

ทฤษฎีบทการสุ่ม: มองจากสเปกตรัม

การสุ่มเทียบได้กับการคูณ x(t) ด้วยขบวนอิมพัลส์ทุก Tₛ ขบวนอิมพัลส์มีคาบ จึงเขียนเป็นอนุกรมฟูริเยร์ได้ และทุกสัมประสิทธิ์มีค่า \(1/T_s\) เท่ากัน

\[ \sum_n \delta(t - nT_s) = \frac{1}{T_s}\sum_k e^{j2\pi kf_st} \]

คูณด้วย \(e^{j2\pi kf_st}\) คือเลื่อนสเปกตรัมไป \(kf_s\) (คุณสมบัติเลื่อนความถี่ในหน้าฟูริเยร์) ผลคือสำเนาของ X(f) วางซ้ำทุก fₛ

\[ X_s(f) = f_s\sum_{k=-\infty}^{\infty} X(f - kf_s) \]

ถ้า X(f) กว้างจาก −B ถึง B สำเนาข้างเคียงเริ่มที่ \(f_s - B\) จะไม่ทับกับก้อนกลางก็ต่อเมื่อ \(f_s - B > B\) หรือ

\[ \boxed{f_s > 2B} \]

นี่คือทฤษฎีบทการสุ่มของไนควิสต์–แชนนอน ถ้าเงื่อนไขนี้จริง กรองเอาก้อนกลางด้วยโลว์พาสที่ตัดที่ \(f_s/2\) ก็ได้ x(t) กลับมาครบ ถ้าไม่จริง สำเนาทับกัน ส่วนที่ทับคืออเลียสซิง และไม่มีตัวกรองไหนแยกออกได้อีก

ตัวอย่าง 3

ทำไมแผ่นซีดีใช้ 44.1 kHz และโทรศัพท์ใช้ 8 kHz

  1. หูได้ยินถึงราว 20 kHz อัตรา Nyquist คือ 40 kHz ซีดีเลือก 44.1 kHz เผื่อช่วง 20 ถึง 22.05 kHz ไว้ให้ตัวกรองกันอเลียสค่อย ๆ ลดลง

  2. เสียงพูดในโทรศัพท์จำกัดไว้ที่ 3.4 kHz อัตรา Nyquist 6.8 kHz ใช้ 8 kHz เผื่อขอบ 0.6 kHz

ในทางปฏิบัติ fₛ ถูกเลือกราว 2.2 ถึง 2.5 เท่าของ B ไม่ใช่ 2 เท่าพอดี

ทำไม fₛ = 2B พอดีไม่พอ

สุ่ม \(\sin(2\pi Bt)\) ด้วย \(f_s = 2B\) ได้ \(\sin(2\pi B\cdot\tfrac{n}{2B}) = \sin(\pi n) = 0\) ทุกจุด มุมพิเศษ สัญญาณหายไปทั้งเส้น ถ้าเฟสต่างไป จุดสุ่มจะมีค่าแต่ขนาดผิด เพราะ \(\cos(\pi n + \varphi) = (-1)^n\cos\varphi\) สูตรผลบวกมุมของ cos ขนาดที่ได้คือ \(\cos\varphi\) ไม่ใช่ 1 ข้อมูลเฟสและขนาดปนกันจนแยกไม่ได้ จึงต้องใช้เครื่องหมายมากกว่า

สูตรหาความถี่ปลอมและตัวอย่างงานจริง

ความถี่ที่ระบบดิจิทัล "เห็น" อยู่ในช่วง 0 ถึง \(f_s/2\) เสมอ ถ้า f เกินช่วงนั้น ให้ลบ (หรือบวก) \(f_s\) ทีละก้อนจนเข้าช่วง แล้วถอดเครื่องหมาย

\[ f_a = \big|\,f - k f_s\,\big|,\qquad k = \operatorname{round}\!\Big(\frac{f}{f_s}\Big) \]

ภาพที่ช่วยจำคือ "การพับกระดาษ" แกนความถี่ถูกพับไปมาที่ 0, \(f_s/2\), \(f_s\), \(3f_s/2\), … ทุกความถี่ตกลงมาซ้อนกันในช่วงแรก

บทเรียนจากแถวที่สองและสาม: ในงานวัดไฟฟ้ากำลัง อย่าตั้งอัตราสุ่มใกล้ 50 Hz หรือพหุคูณของมัน โดยไม่มีตัวกรองกันอเลียส ไม่อย่างนั้นสัญญาณรบกวนจากสายไฟจะกลายเป็นคลื่นความถี่ต่ำที่ดูเหมือนข้อมูลจริง ถ้าเคยใช้ออสซิลโลสโคปดิจิทัลแล้วตั้งฐานเวลาช้าเกิน ภาพที่ได้คือเรื่องเดียวกัน ดูแล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป

แล็บ: เห็นอเลียสซิงกับตา

เส้นเทาบางคือสัญญาณจริง จุดคือค่าที่สุ่มได้ เส้นประคือไซน์ความถี่ปลอมที่ลากผ่านจุดชุดเดียวกัน กราฟล่างคือสเปกตรัมหลังสุ่ม เส้นสีเข้มคือความถี่จริง เส้นเทาคือสำเนาทุก fₛ แถบเขียวคือช่วงที่ระบบมองเห็น (\(-f_s/2\) ถึง \(f_s/2\)) ลองลาก f จาก 0 ถึง 20 Hz ที่ fₛ = 10 Hz จะเห็นความถี่ปลอมเดินขึ้นถึง 5 แล้วเดินกลับลงมา

ตัวกรองกันอเลียสและการสร้างกลับ ขั้นสูง

ระบบสุ่มจริงมีสามท่อน ตัวกรองโลว์พาสแอนะล็อกก่อนสุ่ม (anti-aliasing filter) ตัวแปลง ADC และฝั่งออกมีตัวแปลง DAC ตามด้วยตัวกรองสร้างกลับ (reconstruction filter) ตัวกรองแรกสำคัญที่สุด เพราะเมื่อสุ่มไปแล้ว อเลียสแยกไม่ออกอีกเลย

ในอุดมคติ ตัวกรองสร้างกลับคือโลว์พาสคมที่ \(f_s/2\) ซึ่ง h(t) เป็น sinc (ดูอัลของพัลส์) ผลคือสูตรสร้างกลับ

\[ x(t) = \sum_{n} x[n]\,\mathrm{sinc}\!\Big(\frac{t - nT_s}{T_s}\Big) \]

แต่ละจุดสุ่มปล่อย sinc หนึ่งตัวที่มียอดอยู่ที่ตัวมันและเป็นศูนย์ที่จุดสุ่มอื่นทุกจุด เพราะ \(\sin(\pi m) = 0\) เมื่อ m เป็นจำนวนเต็มที่ไม่ใช่ศูนย์ มุมพิเศษ ผลรวมจึงผ่านทุกจุดพอดี และระหว่างจุดเติมเส้นที่มีความถี่ไม่เกิน \(f_s/2\) ให้เอง DAC จริงใช้การค้างค่า (zero-order hold) แทน ทำให้ได้ขั้นบันไดที่ต้องกรองเพิ่ม และขนาดสเปกตรัมถูกคูณด้วย sinc เล็กน้อย

ความละเอียดของ ADC

การสุ่มแบ่งเวลา การควอนไทซ์แบ่งขนาด ADC N บิตมีระดับ \(2^N\) ขั้น อัตราส่วนสัญญาณต่อสัญญาณรบกวนสูงสุดสำหรับไซน์เต็มสเกลคือ

\[ \mathrm{SNR} \approx 6.02N + 1.76\ \text{dB} \]

16 บิตได้ราว 98.1 dB ค่า 1.76 dB มาจากค่า RMS ของไซน์ \(A/\sqrt2\) ลดกำลัง sin² เทียบกับค่า RMS ของสัญญาณรบกวนควอนไทซ์ที่กระจายสม่ำเสมอ \(\Delta/\sqrt{12}\)

เทคนิคที่ควรรู้อีกอย่างคือการสุ่มแบบแถบผ่าน (bandpass sampling) สัญญาณวิทยุที่อยู่แค่ช่วงแคบ ๆ รอบความถี่สูง สุ่มด้วยอัตราต่ำกว่า 2 เท่าของความถี่สูงสุดได้ โดยตั้งใจให้อเลียสพับก้อนสัญญาณลงมาที่ความถี่ต่ำแบบไม่ทับกัน วิทยุดิจิทัล (SDR) หลายรุ่นทำแบบนี้

จุดที่มักพลาด

  • สับสนอัตรา Nyquist กับความถี่ Nyquist อัตรา Nyquist = 2B เป็นคุณสมบัติของสัญญาณ ความถี่ Nyquist = fₛ/2 เป็นคุณสมบัติของระบบสุ่ม
  • ใช้ความถี่ของไซน์หลักแต่ลืมฮาร์มอนิก คลื่นสี่เหลี่ยม 1 kHz มีฮาร์มอนิกคี่ 3, 5, 7 kHz ไปเรื่อย ๆ B จึงไม่ใช่ 1 kHz
  • คิดว่าตัวกรองดิจิทัลแก้อเลียสได้ ต้องกรองก่อนสุ่ม หลังสุ่มแล้วความถี่ปลอมกับความถี่จริงอยู่ที่เดียวกัน
  • หาความถี่ปลอมแล้วได้เกิน fₛ/2 ยังพับไม่ครบ ลองค่า k อื่น
