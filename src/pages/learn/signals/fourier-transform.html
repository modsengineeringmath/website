การแปลงฟูริเยร์ (Fourier Transform): จากอนุกรมฟูริเยร์สู่สเปกตรัมต่อเนื่อง

การแปลงฟูริเยร์ (หลายตำราสะกดว่า ฟูเรียร์) ตอบคำถามเดียว: สัญญาณนี้ประกอบด้วยไซน์ความถี่ไหนบ้าง และแต่ละความถี่หนักเท่าไร ทุกอย่างในหน้านี้ ตั้งแต่ตารางคู่การแปลง ไปจนถึงวิทยุ AM สร้างขึ้นจากสูตรออยเลอร์ตัวเดียว ผมจึงติดป้ายตรีโกณไว้ทุกครั้งที่มันถูกใช้ ชี้เมาส์ที่ป้ายจะเห็นสูตร คลิกจะไปที่คำอธิบายเต็มในบทตรีโกณมิติ

เขียนโดย อาจารย์มดอัปเดต
ตารางคู่การแปลง คุณสมบัติ การมอดูเลต AM แล็บสเปกตรัม
สูตรหลัก (ใช้ f เป็นเฮิรตซ์) \[ X(f) = \int_{-\infty}^{\infty} x(t)\,e^{-j2\pi ft}\,dt \qquad\qquad x(t) = \int_{-\infty}^{\infty} X(f)\,e^{j2\pi ft}\,df \]

ถ้าใช้ \(\omega = 2\pi f\): \(X(\omega) = \int x(t)e^{-j\omega t}dt\) และ \(x(t) = \tfrac{1}{2\pi}\int X(\omega)e^{j\omega t}d\omega\)

จากอนุกรมฟูริเยร์สู่การแปลงฟูริเยร์

ในอนุกรมฟูริเยร์ สัญญาณคาบ T เขียนเป็นผลรวมของ \(e^{j2\pi nt/T}\) ความถี่ \(n/T\) ห่างกันทีละ \(1/T\) เฮิรตซ์

\[ x_T(t) = \sum_{n} c_n e^{j2\pi (n/T) t},\qquad c_n = \frac1T\int_{-T/2}^{T/2} x_T(t)\,e^{-j2\pi(n/T)t}\,dt \]

ทีนี้ลองให้คาบยาวขึ้นเรื่อย ๆ จนสัญญาณไม่ซ้ำเลย (T → ∞) สามอย่างจะเกิดพร้อมกัน ระยะห่างของเส้น 1/T หดเป็น df ความถี่ n/T กลายเป็นตัวแปรต่อเนื่อง f และ \(c_n\) เล็กลงจนเป็นศูนย์ แต่ \(T c_n\) ไม่เป็นศูนย์ เราตั้งชื่อ \(T c_n\) ใหม่ว่า X(f) ผลรวมจึงกลายเป็นอินทิกรัลในสูตรด้านบน

อ่านความหมาย: \(|X(f)|\,df\) คือ "ปริมาณ" ของไซน์ความถี่ f ที่อยู่ในสัญญาณ ส่วน \(\angle X(f)\) บอกเฟสของไซน์ตัวนั้น

\(e^{-j2\pi ft}\) คือ cos กับ sin ที่หมุนอยู่ พื้นฐาน

ทุกครั้งที่เห็นเคอร์เนล \(e^{-j2\pi ft}\) ให้แตกด้วยสูตรออยเลอร์ สูตรออยเลอร์ และฟังก์ชันคู่-คี่ ฟังก์ชันคู่-คี่

\[ e^{-j2\pi ft} = \cos(2\pi ft) - j\sin(2\pi ft) \quad\Longrightarrow\quad X(f) = \underbrace{\int x(t)\cos 2\pi ft\,dt}_{\text{ส่วนจริง}} \;-\; j\underbrace{\int x(t)\sin 2\pi ft\,dt}_{\text{ส่วนจินตภาพ}} \]

การแปลงจึงคือการวัดว่า x "คล้าย" cos และ sin ความถี่ f แค่ไหน (อินทิกรัลของผลคูณคือการวัดความคล้าย เหมือนผลคูณจุดของเวกเตอร์) ผลที่ตามมาทันทีมีสามข้อ

  1. x จริงและคู่ (เช่น พัลส์สี่เหลี่ยมที่อยู่ตรงกลาง): ผลคูณกับ sin ซึ่งเป็นฟังก์ชันคี่ ได้ฟังก์ชันคี่ อินทิเกรตสมมาตรได้ศูนย์ X จึงเป็นจำนวนจริงล้วน
  2. x จริงและคี่: ส่วน cos หายแทน X เป็นจินตภาพล้วน
  3. x จริงใด ๆ: \(X(-f) = \overline{X(f)}\) เพราะ \(\cos(-\theta) = \cos\theta\) แต่ \(\sin(-\theta) = -\sin\theta\) ขนาด |X| จึงสมมาตร และเฟสเป็นฟังก์ชันคี่ นี่คือเหตุผลที่ดูสเปกตรัมแค่ฝั่ง f ≥ 0 ก็พอ

หาคู่การแปลงด้วยมือ กลาง

ตัวอย่าง 1

พัลส์สี่เหลี่ยมกว้าง T: \(x(t) = 1\) เมื่อ \(|t| < T/2\)

  1. \(X(f) = \displaystyle\int_{-T/2}^{T/2} e^{-j2\pi ft}\,dt = \frac{e^{-j2\pi ft}}{-j2\pi f}\Big|_{-T/2}^{T/2} = \frac{e^{j\pi fT} - e^{-j\pi fT}}{j2\pi f}\)

  2. ตัวเศษคือ \(2j\sin(\pi fT)\) cos, sin ในรูปเลขชี้กำลัง

  3. \(X(f) = \dfrac{2j\sin\pi fT}{j2\pi f} = \dfrac{\sin\pi fT}{\pi f} = T\,\dfrac{\sin\pi fT}{\pi fT}\)

\(X(f) = T\,\mathrm{sinc}(fT)\) โดย \(\mathrm{sinc}(u) = \dfrac{\sin\pi u}{\pi u}\) · ที่ f = 0 ใช้ลิมิต ลิมิต sin h / h ได้ X(0) = T คือพื้นที่ของพัลส์

ศูนย์ของ sinc อยู่ที่ \(\sin\pi fT = 0\) คือ \(f = \pm\tfrac1T, \pm\tfrac2T, \dots\) พัลส์กว้าง 1 ms จึงมีศูนย์แรกที่ 1 kHz ถ้าแคบลงเหลือ 1 µs ศูนย์แรกขยับไปที่ 1 MHz นี่คือหลักความไม่แน่นอนของสัญญาณ ความกว้างในเวลาคูณแถบความถี่มีค่าคงที่ เหตุผลที่สายสัญญาณความเร็วสูงต้องมีแบนด์วิดท์กว้าง ก็เพราะขอบพัลส์ที่คมต้องใช้ความถี่สูง

ตัวอย่าง 2

\(x(t) = e^{-at}u(t),\ a > 0\)

  1. \(X(f) = \displaystyle\int_0^\infty e^{-(a + j2\pi f)t}\,dt = \frac{1}{a + j2\pi f}\) (ส่วนจริงของเลขชี้กำลังเป็นลบ จึงลู่เข้า)

  2. ขนาด \(|X| = \dfrac{1}{\sqrt{a^2 + 4\pi^2f^2}}\) · เฟส \(\angle X = -\tan^{-1}\dfrac{2\pi f}{a}\) ฟังก์ชันตรีโกณผกผัน

ที่ \(f = \tfrac{a}{2\pi}\) ขนาดลดเหลือ \(\tfrac{1}{a\sqrt2}\) (−3 dB) และเฟส −45° มุมพิเศษ · เฟสวิ่งจาก +90° (f → −∞) ถึง −90° (f → +∞)

ตัวอย่าง 3

\(x(t) = e^{-a|t|}\)

  1. เป็น \(e^{-at}u(t)\) บวกภาพสะท้อน \(e^{at}u(-t)\) ซึ่งแปลงได้ \(\tfrac{1}{a - j2\pi f}\)

  2. \(\dfrac{1}{a + j2\pi f} + \dfrac{1}{a - j2\pi f} = \dfrac{2a}{a^2 + 4\pi^2f^2}\)

\(X(f) = \dfrac{2a}{a^2 + 4\pi^2f^2}\) เป็นจริงล้วนตามข้อ 1 ของหัวข้อก่อน (x จริงและคู่)

การเลื่อนเวลาคือการหมุนเฟส

\(e^{-j2\pi ft_0}\) มีขนาด 1 เสมอ เอกลักษณ์พีทาโกรัส (\(\cos^2 + \sin^2 = 1\)) จึงไม่เปลี่ยนขนาดสเปกตรัม แค่หมุนเฟสไป \(-2\pi ft_0\) เรเดียน ความถี่สูงถูกหมุนมากกว่าความถี่ต่ำ เพราะการหน่วงเวลา \(t_0\) เท่ากันคิดเป็นจำนวนรอบได้มากกว่า ตัวกรองที่มี "เฟสเชิงเส้น" จึงหน่วงทุกความถี่เท่ากันและไม่ทำให้รูปคลื่นเพี้ยน

ตัวอย่าง 4

พัลส์กว้าง 2 อยู่ช่วง \(0 < t < 2\)

  1. คือพัลส์กว้าง 2 ที่อยู่ตรงกลาง แล้วเลื่อนไป 1 → \(2\,\mathrm{sinc}(2f)\,e^{-j2\pi f}\)

\(X(f) = 2\,\mathrm{sinc}(2f)\,e^{-j2\pi f}\) ขนาดเหมือนเดิม ส่วนเฟสลดลงเป็นเส้นตรง

อนุพันธ์คูณด้วย j2πf: ตรีโกณยืนยันได้

\(\tfrac{d}{dt}\cos 2\pi ft = -2\pi f\sin 2\pi ft = 2\pi f\cos(2\pi ft + 90^\circ)\) เลื่อนเฟส 90° (โคฟังก์ชัน) กฎลูกโซ่ ขนาดคูณ 2πf และเฟสเลื่อน 90° ซึ่งก็คือการคูณด้วย \(j2\pi f\) เพราะ \(j = e^{j\pi/2}\) ตัวเหนี่ยวนำที่มี \(v = L\,di/dt\) จึงมีอิมพีแดนซ์ \(j\omega L\) ด้วยเหตุผลเดียวกัน

การมอดูเลต AM: สูตรผลคูณเป็นผลบวกในโลกจริง ประยุกต์

สัญญาณเสียงมีความถี่ไม่กี่กิโลเฮิรตซ์ ส่งออกเสาอากาศโดยตรงไม่ได้ (เสาต้องยาวเป็นกิโลเมตร) วิธีแก้คือคูณกับพาหะ \(\cos 2\pi f_0t\) แตก cos ด้วยสูตรออยเลอร์ cos, sin ในรูปเลขชี้กำลัง แล้วใช้การเลื่อนความถี่ทีละก้อน

\[ x(t)\cos 2\pi f_0t = \tfrac12x(t)e^{j2\pi f_0t} + \tfrac12x(t)e^{-j2\pi f_0t} \;\longleftrightarrow\; \tfrac12X(f - f_0) + \tfrac12X(f + f_0) \]

ถ้า x เองเป็นไซน์ \(\cos 2\pi f_mt\) ก็เห็นผลเดียวกันด้วยสูตรผลคูณเป็นผลบวก ผลคูณ cos·cos

\[ \cos 2\pi f_mt\,\cos 2\pi f_0t = \tfrac12\cos 2\pi(f_0 - f_m)t + \tfrac12\cos 2\pi(f_0 + f_m)t \]

เกิดสองความถี่ใหม่คือ \(f_0 \pm f_m\) เรียกว่าแถบข้างล่างและแถบข้างบน (lower/upper sideband)

ตัวอย่าง 5

เสียงแบนด์วิดท์ 5 kHz บนพาหะ 1 MHz

  1. สเปกตรัมถูกยกไปวางรอบ ±1 MHz กินช่วง 995 ถึง 1005 kHz

แบนด์วิดท์ที่ส่ง 10 kHz คือสองเท่าของเสียง นี่คือเหตุผลที่สถานี AM ต้องอยู่ห่างกันอย่างน้อยราว 10 kHz

ฝั่งรับ: คูณซ้ำแล้วกรอง

คูณสัญญาณที่รับได้ด้วย \(\cos 2\pi f_0t\) อีกครั้ง แล้วลดกำลังสองด้วยสูตร ลดกำลัง cos² \(\cos^2\theta = \tfrac12(1 + \cos 2\theta)\)

\[ x(t)\cos^2 2\pi f_0t = \tfrac12x(t) + \tfrac12x(t)\cos 4\pi f_0t \]

ก้อนแรกคือเสียงเดิม ก้อนที่สองอยู่รอบ \(2f_0\) ซึ่งตัวกรองโลว์พาสตัดทิ้งได้ง่าย ถ้าออสซิลเลเตอร์ฝั่งรับเพี้ยนเฟสไป φ จะได้ \(\tfrac12x(t)\cos\varphi\) แทน ผลคูณ cos·cos ถ้า φ = 90° เสียงหายหมด นี่คือเหตุผลที่เครื่องรับแบบซิงโครนัสต้องล็อกเฟส

ตัวกรองและคอนโวลูชัน: ในความถี่เป็นแค่การคูณ

คุณสมบัติคอนโวลูชันบอกว่า \(Y(f) = H(f)X(f)\) ตัวกรองโลว์พาสอุดมคติ \(H(f) = 1\) เมื่อ \(|f| < B\) คือพัลส์ในโดเมนความถี่ ตามดูอัล h(t) จึงเป็น \(2B\,\mathrm{sinc}(2Bt)\) ซึ่งเริ่มก่อน t = 0 คือไม่คอซัล สร้างจริงไม่ได้ ตัวกรองจริงอย่าง RC จึงประนีประนอม

\[ H(f) = \frac{1}{1 + j2\pi fRC},\qquad |H| = \frac{1}{\sqrt{1 + (2\pi fRC)^2}},\qquad f_c = \frac{1}{2\pi RC} \]

R = 1 kΩ, C = 0.1 µF ได้ \(f_c = 1591.5\) Hz ถ้าอยากเห็นผลกับไซน์ทีละความถี่ ดูไซน์เข้า ไซน์ออก หรือแล็บ Bode ในระบบอันดับหนึ่ง

พาร์เซวาล: ตรวจพลังงานสองทาง

\(x = e^{-t}u(t)\): ในเวลา \(\int_0^\infty e^{-2t}dt = \tfrac12\) ในความถี่ \(\int_{-\infty}^{\infty}\dfrac{df}{1 + 4\pi^2f^2}\) แทน \(u = 2\pi f\) ได้ \(\tfrac{1}{2\pi}\int\dfrac{du}{1 + u^2} = \tfrac{1}{2\pi}\cdot\pi = \tfrac12\) ฟังก์ชันตรีโกณผกผัน ตรงกัน

แล็บ: คู่การแปลงฟูริเยร์

เลือกสัญญาณแล้วปรับความกว้าง T หรือค่า a ดูว่าสเปกตรัมกว้างขึ้นเมื่อสัญญาณแคบลง ลองโหมดพัลส์มอดูเลต แล้วเพิ่ม f₀ จะเห็นก้อน sinc แยกไปอยู่ที่ ±f₀ ป้ายสีเขียวท้ายกราฟยืนยันว่าสูตรในตารางตรงกับการอินทิเกรตเชิงตัวเลขจริง

จุดที่มักพลาด

  • ปน f กับ ω ตารางที่ใช้ ω มี 2π อยู่หน้าเดลตา ตารางที่ใช้ f ไม่มี เลือกแบบเดียวทั้งข้อ
  • sinc สองนิยาม หน้านี้ใช้ \(\mathrm{sinc}(u) = \sin(\pi u)/(\pi u)\) บางตำราใช้ \(\sin u/u\) ตรวจก่อนเปิดตาราง
  • สเกลเวลาลืม 1/|a| บีบสัญญาณให้สั้นลงครึ่งหนึ่ง สเปกตรัมกว้างขึ้นสองเท่าแต่สูงลดลงครึ่งหนึ่ง
