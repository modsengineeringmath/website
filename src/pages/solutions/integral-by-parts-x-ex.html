มองโจทย์ก่อน: อะไรทำให้ข้อนี้ยาก

ตัวในอินทิกรัลเป็นผลคูณของฟังก์ชันสองชนิด คือพหุนาม \(x\) กับเลขชี้กำลัง \(e^x\) การอินทิเกรตไม่มีกฎผลคูณแบบการดิฟ จะอินทิเกรตแยกแล้วคูณกันไม่ได้ \(\int xe^x\,dx \ne \int x\,dx\cdot\int e^x\,dx\)

ลองเปลี่ยนตัวแปรก่อน ถ้าให้ \(u = x\) หรือ \(u = e^x\) ก็ไม่มีอนุพันธ์ของ u อยู่ในโจทย์ให้จับคู่ การเปลี่ยนตัวแปรจึงใช้ไม่ได้ เครื่องมือที่ออกแบบมาสำหรับผลคูณแบบนี้คือการอินทิเกรตทีละส่วน (integration by parts)

\[ \int u\,dv = uv - \int v\,du \]

ที่มาของการเลือก u = x และ dv = eˣ dx

สูตรทีละส่วนมาจากกฎผลคูณของการดิฟ \((uv)' = u'v + uv'\) อินทิเกรตทั้งสองข้างแล้วย้ายข้างจะได้สูตรข้างบน ความหมายคือ แลกอินทิกรัล \(\int u\,dv\) กับอินทิกรัลใหม่ \(\int v\,du\) การแลกจะคุ้มก็ต่อเมื่ออินทิกรัลใหม่ง่ายกว่าเดิม

ลองทั้งสองทางแล้วเทียบกัน

ทางเลือกdu และ vอินทิกรัลใหม่ \(\int v\,du\)ผล
\(u = x,\ dv = e^x dx\)\(du = dx,\ v = e^x\)\(\int e^x\,dx\)ง่ายลง ✓
\(u = e^x,\ dv = x\,dx\)\(du = e^x dx,\ v = \tfrac{x^2}{2}\)\(\int \tfrac{x^2}{2}e^x\,dx\)กำลังของ x เพิ่ม ยากขึ้น ✗

เหตุผลสั้น ๆ: ดิฟ \(x\) แล้วกำลังลดลงจนหายไป แต่ดิฟหรืออินทิเกรต \(e^x\) ก็ยังเป็น \(e^x\) จึงควรให้ตัวที่ “ดิฟแล้วง่ายลง” เป็น u และให้ตัวที่ “อินทิเกรตแล้วไม่ยากขึ้น” อยู่ใน dv หลักนี้สรุปเป็นลำดับ T4 LIATE คือ Log, Inverse trig, Algebraic, Trig, Exponential ตัวที่มาก่อนเป็น u พหุนาม (A) มาก่อนเลขชี้กำลัง (E) จึงเลือก \(u = x\)

วิธีทำอย่างละเอียด

อ่านวิธีทำ ตัวแปรใหม่ u สูตรที่ใช้ คุณสมบัติที่ใช้ ค่าคงที่ C เส้นแดง = ตัดกัน
วิธีทำ · Integration by parts

หา \(\displaystyle \int x e^{x}\,dx\)

  1. เลือก u ตาม LIATE (พีชคณิตก่อนเลขชี้กำลัง) แล้วหา du กับ v T4 LIATE

    \[ \hlU{u = x} \;\Rightarrow\; \hlU{du = dx}, \qquad dv = e^{x}\,dx \;\Rightarrow\; v = \hlF{e^{x}} \]

  2. แทนลงสูตรทีละส่วน T3 Integration by parts

    \[ \int \hlU{x}\,e^{x}\,dx = \hlU{x}\,e^{x} - \int e^{x}\,\hlU{dx} \]

  3. อินทิกรัลที่เหลือเป็นสูตรพื้นฐาน F4 Exponential rule

    \[ \int e^{x}\,dx = \hlF{e^{x}} + C \]

  4. รวมผลและดึงตัวร่วม \(e^x\) ออก

    \[ \begin{aligned} \int x e^{x}\,dx &= x e^{x} - e^{x} + \hlC{C} \\ &= (x-1)\,e^{x} + \hlC{C} \end{aligned} \]

\(\displaystyle \int x e^{x}\,dx = (x-1)\,e^{x} + \hlC{C}\)

ตรวจคำตอบ: ดิฟด้วยกฎผลคูณ \(\tfrac{d}{dx}\big[(x-1)e^x\big] = e^x + (x-1)e^x = xe^x\) ✓

ทางลัด: วิธีตาราง (Tabular integration)

เมื่อ u เป็นพหุนามที่ดิฟซ้ำแล้วกลายเป็นศูนย์ ทำทีละส่วนได้เร็วด้วยตาราง คอลัมน์ซ้ายดิฟ u ไปเรื่อย ๆ จนได้ 0 คอลัมน์ขวาอินทิเกรต dv ไปเรื่อย ๆ แล้วคูณทแยงลงโดยใส่เครื่องหมายสลับ \(+,-,+,\dots\)

เครื่องหมายดิฟ uอินทิเกรต dv

\[ \int xe^x\,dx = +\,x\cdot e^x \;-\; 1\cdot e^x + C = (x-1)e^x + C \]

วิธีตารางคุ้มมากเมื่อกำลังของ x สูง เช่น \(\int x^3e^x\,dx\) ทำสี่แถวก็ได้ \((x^3-3x^2+6x-6)e^x + C\) แทนการทำทีละส่วนสามรอบ

ตัวอย่างตัวเลข: อินทิกรัลจำกัดเขต

ตัวอย่าง

หา \(\displaystyle\int_0^1 xe^{x}\,dx\)

  1. ใช้ปฏิยานุพันธ์ที่ได้ แล้วแทนขอบเขต Q1 FTC

    \[ \Big[(x-1)e^x\Big]_0^1 = (1-1)e^{1} - (0-1)e^{0} = 0 - (-1) \]

\(\displaystyle\int_0^1 xe^{x}\,dx = 1\)

ตรวจขนาดคร่าว ๆ: บนช่วง [0, 1] ฟังก์ชันเพิ่มจาก 0 ถึง \(e \approx 2.72\) พื้นที่ราว 1 สมเหตุสมผล

อินทิกรัลนี้โผล่ที่ไหนในงานวิศวกรรมไฟฟ้า

รูป \(t\,e^{-at}\) คือคำตอบของวงจรอันดับสองแบบหน่วงวิกฤต (critically damped) และเป็นรูปของพัลส์กระแสที่ขึ้นแล้วค่อย ๆ ลดลง ถ้ากระแส \(i(t) = 10\,t\,e^{-2t}\) แอมแปร์ไหลเข้าตัวเก็บประจุ ประจุรวมคือ

\[ q = \int_0^{\infty} 10\,t\,e^{-2t}\,dt = 10\left[\frac{e^{-2t}}{4}(-2t-1)\right]_0^{\infty} = 10\left(0 + \frac14\right) = 2.5\ \text{C} \]

ขั้นนี้ใช้สูตรทั่วไป \(\int te^{at}\,dt = \tfrac{e^{at}}{a^2}(at-1)\) ที่ \(a=-2\) ซึ่งได้ด้วยวิธีทีละส่วนแบบเดียวกับข้อนี้ ตัวอย่างอื่นอยู่ในการประยุกต์อินทิกรัลทางไฟฟ้า

จุดที่มักพลาด

  • เลือก u = eˣ อินทิกรัลใหม่มี \(x^2\) ยากกว่าเดิม ถ้าทำไปแล้วรู้สึกว่าโจทย์ยากขึ้น แปลว่าเลือก u ผิด ให้สลับ
  • ลืมเครื่องหมายลบหน้า \(\int v\,du\) ได้ \(xe^x + e^x\) ซึ่งดิฟแล้วไม่ได้โจทย์คืน
  • ใส่ +C ตอนหา v ไม่จำเป็น ค่าคงที่จะหักล้างกันเอง ใส่ +C ครั้งเดียวท้ายสุดพอ
  • คิดว่ามีกฎผลคูณสำหรับอินทิกรัล \(\int xe^x dx \ne \tfrac{x^2}{2}e^x\) ดู P6
