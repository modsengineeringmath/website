// เฉลยโจทย์ · ข้อ

เฉลยโจทย์คณิตศาสตร์วิศวกรรมแบบละเอียดทีละขั้น

โจทย์ที่โพสต์บนเพจ Mod's Engineering Mathematics เฉลยไว้ที่นี่ข้อละหน้า ทุกขั้นบอกว่าใช้สูตรหรือเหตุผลอะไร และทำไมถึงเลือกวิธีนั้น ไม่ใช่แค่คำตอบ เปิด โหมดฝึกทำ เพื่อซ่อนวิธีทำ ลองคิดเองก่อน แล้วกด ดูทีละขั้น เมื่อติด

// วิธีใช้

อ่านเฉลยให้ได้มากกว่าคำตอบ

  1. อ่านโจทย์แล้วลองทำเองก่อน อย่างน้อยให้ได้ขั้นแรก คำตอบสุดท้ายซ่อนอยู่ใต้กล่องโจทย์ ใช้ตรวจหลังทำเสร็จ
  2. ติดตรงไหน ค่อยเปิดทีละขั้น ปุ่ม “ดูทีละขั้น” เปิดเฉลยครั้งละหนึ่งขั้น สีในสมการบอกว่าขั้นนั้นใช้สูตร ตัวแปรใหม่ หรือตัดทอนอะไร
  3. อ่านส่วน “ที่มา” เสมอ โจทย์ส่วนใหญ่ยากที่การเลือกวิธี ไม่ใช่การคำนวณ ส่วนนี้อธิบายว่าทำไมต้องแทนค่าแบบนั้น จะได้ใช้กับข้ออื่นได้เอง
  4. แชร์ให้เพื่อน ทุกข้อมีปุ่มแชร์ LINE, Facebook และ X พร้อมภาพโจทย์ ส่งเข้ากลุ่มเรียนแล้วให้เพื่อนลองทำก่อนเปิดเฉลย
