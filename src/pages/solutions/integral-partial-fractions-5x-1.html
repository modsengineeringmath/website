มองโจทย์ก่อน: อะไรทำให้ข้อนี้ยาก

ตัวในอินทิกรัลเป็นเศษส่วนพหุนาม ลองเปลี่ยนตัวแปร \(u = x^2-x-2\) ก่อน จะได้ \(du = (2x-1)\,dx\) แต่ตัวเศษเป็น \(5x-1\) ไม่ใช่ผลคูณค่าคงที่ของ \(2x-1\) วิธีนี้จึงไม่ลงตัว

แต่ตัวส่วนแยกตัวประกอบได้ \(x^2-x-2 = (x-2)(x+1)\) แปลว่าเศษส่วนก้อนนี้เกิดจากการรวมเศษส่วนง่าย ๆ สองก้อนที่มีตัวส่วน \(x-2\) และ \(x+1\) ถ้าแยกคืนได้ แต่ละก้อนอินทิเกรตได้ทันทีด้วย \(\int\tfrac{dx}{ax+b} = \tfrac1a\ln|ax+b|\)

ตรวจก่อนว่าไม่ต้องหารยาว: ดีกรีบน (1) น้อยกว่าดีกรีล่าง (2) ✓

ที่มาของรูป A/(x − 2) + B/(x + 1) และวิธีปิดตัวประกอบ

ลองบวกเศษส่วนสองก้อนดู \(\tfrac{A}{x-2} + \tfrac{B}{x+1} = \tfrac{A(x+1) + B(x-2)}{(x-2)(x+1)}\) ตัวเศษเป็นพหุนามดีกรี 1 พอดี มีค่าคงที่สองตัวให้ปรับ จึงสร้างตัวเศษ \(5x-1\) ได้เสมอ นี่คือเหตุผลที่ตั้งรูปแบบนี้

เทียบตัวเศษ

\[ 5x-1 = A(x+1) + B(x-2) \]

สมการนี้ต้องจริงทุกค่า x จึงเลือกค่า x ที่ทำให้พจน์หนึ่งหายไป

  • แทน \(x = 2\): พจน์ B หาย \(\;9 = 3A \Rightarrow A = 3\)
  • แทน \(x = -1\): พจน์ A หาย \(\;-6 = -3B \Rightarrow B = 2\)

ขั้นนี้ย่อได้อีกเป็นวิธีปิดตัวประกอบ (Heaviside cover-up): จะหา A ให้เอามือปิด \((x-2)\) ในเศษส่วนเดิม แล้วแทน \(x = 2\) ในส่วนที่เหลือ

\[ A = \left.\frac{5x-1}{\boxed{\phantom{x}}\,(x+1)}\right|_{x=2} = \frac{9}{3} = 3, \qquad B = \left.\frac{5x-1}{(x-2)\,\boxed{\phantom{x}}}\right|_{x=-1} = \frac{-6}{-3} = 2 \]

วิธีปิดตัวประกอบใช้ได้ตรง ๆ เฉพาะตัวประกอบเชิงเส้นที่ไม่ซ้ำ ถ้าตัวประกอบซ้ำ เช่น \((x+1)^2\) ต้องตั้งให้ครบทุกกำลัง ดูข้อ B10 ในแนวข้อสอบ

วิธีทำอย่างละเอียด

อ่านวิธีทำ ตัวแปรใหม่ u สูตรที่ใช้ คุณสมบัติที่ใช้ ค่าคงที่ C เส้นแดง = ตัดกัน
วิธีทำ · Partial fractions

หา \(\displaystyle \int \frac{5x-1}{x^2-x-2}\,dx\)

  1. แยกตัวประกอบตัวส่วน (หาจำนวนสองตัวที่คูณกันได้ −2 บวกกันได้ −1 คือ −2 กับ 1)

    \[ x^2 - x - 2 = (x-2)(x+1) \]

  2. ตั้งเศษส่วนย่อยและหาค่าคงที่ด้วยวิธีปิดตัวประกอบ

    \[ \frac{5x-1}{(x-2)(x+1)} = \frac{\hlP{3}}{x-2} + \frac{\hlP{2}}{x+1} \]

  3. อินทิเกรตทีละก้อนด้วยความเป็นเชิงเส้น P3 Linearity G2

    \[ \int \frac{5x-1}{x^2-x-2}\,dx = 3\int\frac{dx}{x-2} + 2\int\frac{dx}{x+1} \]

  4. ใช้ \(\int\tfrac{dx}{x-r} = \ln|x-r|\)

    \[ = \hlF{3\ln|x-2|} + \hlF{2\ln|x+1|} + \hlC{C} \]

\(\displaystyle \int \frac{5x-1}{x^2-x-2}\,dx = 3\ln|x-2| + 2\ln|x+1| + \hlC{C}\)

ตรวจคำตอบ: \(\tfrac{3}{x-2} + \tfrac{2}{x+1} = \tfrac{3(x+1) + 2(x-2)}{(x-2)(x+1)} = \tfrac{5x-1}{x^2-x-2}\) ✓

ตัวอย่างตัวเลข: อินทิกรัลจำกัดเขต

ตัวอย่าง

หา \(\displaystyle\int_3^4 \frac{5x-1}{x^2-x-2}\,dx\)

  1. ช่วง [3, 4] ไม่มีจุดที่ตัวส่วนเป็นศูนย์ (x = 2 และ x = −1 อยู่นอกช่วง) จึงแทนค่าได้

    \[ \Big[3\ln|x-2| + 2\ln|x+1|\Big]_3^4 = (3\ln2 + 2\ln5) - (3\ln1 + 2\ln4) \]

  2. ใช้ \(\ln4 = 2\ln2\) และ \(\ln 1 = 0\)

    \[ = 3\ln2 + 2\ln5 - 4\ln2 = 2\ln5 - \ln2 = \ln\frac{25}{2} \]

\(\displaystyle\int_3^4 \frac{5x-1}{x^2-x-2}\,dx = \ln 12.5 \approx 2.526\)

ถ้าช่วงอินทิเกรตคร่อม x = 2 หรือ x = −1 อินทิกรัลจะเป็นแบบไม่ตรงแบบ (improper) และลู่ออก แทนค่าตรง ๆ ไม่ได้

เศษส่วนย่อยชุดเดียวกันในการแปลงลาปลาซผกผัน

วิศวกรไฟฟ้าใช้เศษส่วนย่อยบ่อยที่สุดตอนหาคำตอบของวงจรหรือระบบควบคุมจาก \(F(s)\) ถ้า \(F(s) = \tfrac{5s-1}{s^2-s-2}\) การแยกเหมือนข้อนี้ทุกขั้น ต่างกันแค่ชื่อตัวแปร

\[ F(s) = \frac{3}{s-2} + \frac{2}{s+1} \quad\Longrightarrow\quad f(t) = 3e^{2t} + 2e^{-t},\ t \ge 0 \]

ค่า A และ B ที่ได้จากวิธีปิดตัวประกอบคือเรซิดิวของโพลแต่ละตัว และโพล \(s = 2\) ที่อยู่ซีกขวาบอกว่าระบบนี้ไม่เสถียร (คำตอบโตแบบ \(e^{2t}\)) อ่านต่อที่ลาปลาซผกผันด้วยเศษส่วนย่อย และบทเรียนการแปลงลาปลาซผกผัน

จุดที่มักพลาด

  • แยกตัวประกอบผิดเครื่องหมาย เป็น \((x+2)(x-1)\) ตรวจโดยคูณกลับเสมอ
  • ลืมค่าสัมบูรณ์ใน ln \(x-2\) ติดลบได้เมื่อ \(x<2\) คำตอบที่ใช้ได้ทุกช่วงต้องเป็น \(\ln|x-2|\)
  • ใช้วิธีปิดตัวประกอบกับตัวประกอบซ้ำหรือกำลังสองที่แยกไม่ได้ ได้ค่าผิด ต้องตั้งรูปให้ครบแล้วเทียบสัมประสิทธิ์
  • ไม่หารยาวก่อนเมื่อดีกรีบน ≥ ล่าง การแยกจะไม่ลงตัว ดูหารยาวก่อนอินทิเกรต
