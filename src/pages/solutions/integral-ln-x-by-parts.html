มองโจทย์ก่อน: อะไรทำให้ข้อนี้ยาก

ในตารางสูตรพื้นฐานมี \(\int \tfrac1x\,dx = \ln|x|\) แต่ไม่มีสูตรของ \(\int \ln x\,dx\) ตรง ๆ คนส่วนใหญ่ติดเพราะคิดว่า ทีละส่วนใช้กับผลคูณเท่านั้น และโจทย์นี้มีฟังก์ชันตัวเดียว

สิ่งที่เรารู้เกี่ยวกับ \(\ln x\) คืออนุพันธ์ของมันง่ายมาก \(\tfrac{d}{dx}\ln x = \tfrac1x\) เป็นฟังก์ชันพีชคณิตธรรมดา ถ้าหาทางทำให้ \(\ln x\) ถูกดิฟแทนที่จะถูกอินทิเกรต โจทย์จะง่ายทันที การอินทิเกรตทีละส่วนทำแบบนั้นได้พอดี

ที่มาของการให้ dv = dx

มองว่ามีตัวคูณ 1 ซ่อนอยู่ \(\ln x = \ln x \cdot 1\) แล้วเลือก

\[ \hlU{u = \ln x}, \qquad dv = 1\cdot dx \]

การเลือกนี้สอดคล้องกับ LIATE เพราะลอการิทึม (L) มาก่อนทุกตัว ผลที่ได้คือ \(u\) ถูกดิฟเป็น \(\tfrac1x\) ส่วน \(dv = dx\) อินทิเกรตได้ \(v = x\) แล้วในอินทิกรัลใหม่ \(x\) กับ \(\tfrac1x\) ตัดกันพอดี เหลือ \(\int dx\)

เทคนิค “ให้ dv = dx” ใช้ได้กับทุกฟังก์ชันที่อินทิเกรตตรงไม่ได้แต่ดิฟแล้วง่าย เช่น \(\int \tan^{-1}x\,dx\), \(\int \sin^{-1}x\,dx\), \(\int (\ln x)^2\,dx\) (ดูตารางสูตรกลุ่มผลคูณ)

วิธีทำอย่างละเอียด

อ่านวิธีทำ ตัวแปรใหม่ u สูตรที่ใช้ คุณสมบัติที่ใช้ ค่าคงที่ C เส้นแดง = ตัดกัน
วิธีทำ · Integration by parts

หา \(\displaystyle \int \ln x\,dx\) เมื่อ \(x > 0\)

  1. มองเป็น \(\ln x\cdot1\) แล้วเลือก u ตาม LIATE T4 LIATE

    \[ \hlU{u = \ln x} \;\Rightarrow\; \hlU{du = \frac{1}{x}\,dx}, \qquad dv = dx \;\Rightarrow\; v = x \]

  2. แทนลงสูตรทีละส่วน T3 Integration by parts

    \[ \int \hlU{\ln x}\,dx = x\,\hlU{\ln x} - \int x\cdot\hlU{\frac{1}{x}\,dx} \]

  3. \(x\) กับ \(\tfrac1x\) ตัดกัน เหลืออินทิกรัลของค่าคงที่ F1 Constant rule

    \[ \int \rc{x}\cdot\frac{1}{\rc{x}}\,dx = \int 1\,dx = \hlF{x} \]

  4. รวมผล

    \[ \int \ln x\,dx = x\ln x - x + \hlC{C} = x(\ln x - 1) + \hlC{C} \]

\(\displaystyle \int \ln x\,dx = x\ln x - x + \hlC{C}\)

ตรวจคำตอบ: \(\tfrac{d}{dx}(x\ln x - x) = \ln x + x\cdot\tfrac1x - 1 = \ln x\) ✓

ตัวอย่างตัวเลข: ∫ ln x จาก 1 ถึง e

ตัวอย่าง

หา \(\displaystyle\int_1^{e}\ln x\,dx\)

  1. แทนขอบเขตในปฏิยานุพันธ์ ใช้ \(\ln e = 1\) และ \(\ln 1 = 0\)

    \[ \Big[x\ln x - x\Big]_1^{e} = (e\cdot1 - e) - (1\cdot0 - 1) = 0 + 1 \]

\(\displaystyle\int_1^{e}\ln x\,dx = 1\)

ตรวจขนาด: \(\ln x\) ขึ้นจาก 0 ถึง 1 บนช่วงยาว \(e-1\approx1.72\) ถ้าเป็นเส้นตรงพื้นที่จะราว 0.86 แต่กราฟ ln โค้งอยู่เหนือเส้นตรงที่เชื่อมปลายทั้งสอง จึงได้มากกว่าเล็กน้อย ได้ 1 สมเหตุสมผล

ใช้จริง: ประมาณ ln n! ด้วยอินทิกรัล (สเตอร์ลิง)

\(\ln n! = \ln1 + \ln2 + \dots + \ln n\) คือผลบวกของ \(\ln k\) ซึ่งประมาณได้ด้วยพื้นที่ใต้กราฟ \(\ln x\)

\[ \ln n! \approx \int_1^{n}\ln x\,dx = \Big[x\ln x - x\Big]_1^n = n\ln n - n + 1 \]

ที่ \(n = 10\): ค่าจริง \(\ln 10! = \ln 3{,}628{,}800 \approx 15.10\) ส่วนสูตรได้ \(10\ln10 - 9 \approx 14.03\) ใกล้กันมากและยิ่ง n ใหญ่ยิ่งแม่น ใช้ในความน่าจะเป็น สถิติ และการคำนวณเอนโทรปีในงานสื่อสาร ผลบวกกับอินทิกรัลเชื่อมกันอย่างไรอ่านต่อที่อนุกรมอนันต์และการทดสอบด้วยปริพันธ์

จุดที่มักพลาด

  • ตอบ \(\tfrac{1}{x} + C\) นั่นคืออนุพันธ์ของ \(\ln x\) ไม่ใช่อินทิกรัล สลับทิศกัน
  • ตอบ \(\tfrac{(\ln x)^2}{2}\) ใช้ได้กับ \(\int\tfrac{\ln x}{x}\,dx\) เท่านั้น (มี \(\tfrac1x\) ให้เปลี่ยนตัวแปร) โจทย์นี้ไม่มี
  • เลือก u = 1 และ dv = ln x dx ต้องรู้ \(\int\ln x\,dx\) ก่อน วนกลับมาที่เดิม
  • ลืมเงื่อนไข x > 0 \(\ln x\) นิยามเฉพาะ \(x>0\) ถ้าโจทย์เป็น \(\int\ln|x|\,dx\) คำตอบคือ \(x\ln|x| - x + C\)
