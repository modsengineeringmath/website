เครื่องคำนวณคอนโวลูชัน (Discrete Convolution Calculator): ตารางคูณ เศษส่วนแท้ และกราฟ

กรอกลำดับ x[n] และ h[n] เครื่องมือจะคำนวณ y[n] = x[n] * h[n] เป็นเศษส่วนแท้ แสดงตารางคูณที่บวกตามแนวทแยง บอกจุดเริ่มและความยาวของผลลัพธ์ เขียนเป็นการคูณพหุนามใน \(z^{-1}\) และวาดกราฟแบบก้านทั้งสามสัญญาณ เหมาะกับการตรวจการบ้านวิชาสัญญาณและระบบ ตัวกรอง FIR และการคูณพหุนาม

เขียนโดย อาจารย์มดอัปเดต

เครื่องมือ

วิธีใช้งาน

  1. พิมพ์ค่าของ x[n] คั่นด้วยจุลภาค และใส่ดัชนีของค่าแรกในช่อง เริ่มที่ n =
  2. ทำแบบเดียวกันกับ h[n] ใช้เศษส่วนอย่าง 1/3 หรือทศนิยมอย่าง -0.25 ได้
  3. กดคำนวณ หรือกดปุ่มตัวอย่าง (ค่าเฉลี่ยเคลื่อนที่ ผลต่าง คูณพหุนาม เลื่อนเวลา) ลิงก์ของหน้าจะเก็บค่าที่กรอกไว้ให้แชร์ได้

สูตรและกฎที่ใช้

\[ y[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n - k] \]
  • ถ้า x มี N ค่าเริ่มที่ \(n_x\) และ h มี M ค่าเริ่มที่ \(n_h\) ผลลัพธ์มี N + M − 1 ค่า เริ่มที่ \(n_x + n_h\)
  • สลับที่ได้ \(x * h = h * x\) และ \(x * \delta[n - k] = x[n - k]\) (เลื่อนเวลา)
  • ผลรวมของ y = ผลรวมของ x × ผลรวมของ h ใช้ตรวจคำตอบได้เร็ว

ตัวอย่าง

\(\{1, 2, 3\} * \{1, 1\}\) (เริ่มที่ n = 0 ทั้งคู่) แถวแรกได้ 1, 2, 3 แถวที่สองได้ 1, 2, 3 แต่เลื่อนไปหนึ่งช่อง บวกตามแนวทแยงได้

\(y = \{1, 3, 5, 3\}\) · ผลรวม 12 = 6 × 2 · เหมือน \((1 + 2x + 3x^2)(1 + x) = 1 + 3x + 5x^2 + 3x^3\)

ระบบ \(h = \{1, 1\}\) คือการบวกค่าปัจจุบันกับค่าก่อนหน้า ผลตอบสนองเชิงความถี่ของมันคือ \(1 + e^{-j\Omega} = 2e^{-j\Omega/2}\cos\tfrac\Omega2\) cos, sin ในรูปเลขชี้กำลัง ขนาด \(2|\cos\tfrac\Omega2|\) จึงเป็นโลว์พาส ดูเพิ่มในหน้าการแปลง Z

เรียนทฤษฎีต่อ

  • ระบบ LTI และคอนโวลูชัน (มีแล็บคอนโวลูชันต่อเนื่องแบบกลับ-เลื่อน)
  • การแปลง Z: ทำไมคอนโวลูชันกลายเป็นการคูณ
  • การแปลงฟูริเยร์
  • โจทย์สัญญาณและระบบพร้อมเฉลย
