# วิดีโอสอนคณิตศาสตร์วิศวกรรมและวิศวกรรมไฟฟ้า

// วิดีโอ · 4 คลิป


คลิปที่มีคนดูมากที่สุดจากช่อง Mod's Engineering Mathematics แยกไว้คลิปละหน้า แต่ละหน้าเปิดดูคลิปได้ทันที พร้อมสรุปสูตร ตัวอย่างที่ตรวจตัวเลขแล้ว และลิงก์ไปบทเรียนที่ลงรายละเอียดต่อ

x = Δx / Δ
เมทริกซ์ · ดีเทอร์มิแนนต์กฎของคราเมอร์ (Cramer's Rule): แก้ระบบสมการเชิงเส้นด้วยดีเทอร์มิแนนต์หา Δ แล้วแทนคอลัมน์ทีละตัว x = Δx/Δ ใช้ได้เมื่อ Δ ≠ 0เผยแพร่ 9 ส.ค. 2563 · YouTube

A⁻¹ = adj A / det A
เมทริกซ์ · อินเวอร์สอินเวอร์สของเมทริกซ์ (Inverse of a Matrix): หาด้วยแอดจอยต์หารดีเทอร์มิแนนต์หาดีเทอร์มิแนนต์ หาโคแฟกเตอร์ ทรานสโพสเป็นแอดจอยต์ แล้วหารเผยแพร่ 2 ม.ค. 2565 · YouTube

Cᵢⱼ = (−1)ⁱ⁺ʲ Mᵢⱼ
เมทริกซ์ · ดีเทอร์มิแนนต์ไมเนอร์และโคแฟกเตอร์ (Minor & Cofactor) ของเมทริกซ์ตัดแถวและหลัก หาดีเทอร์มิแนนต์ที่เหลือ แล้วคูณเครื่องหมาย (−1)^(i+j)เผยแพร่ 22 ก.ย. 2565 · YouTube

Vo = D · Vin
อิเล็กทรอนิกส์กำลังบั๊กคอนเวอร์เตอร์ (Buck Converter) ตอนที่ 1: ที่มาและการคำนวณดิวตี้ไซเคิลวงจรลดแรงดันไฟตรง ที่มาของดิวตี้ไซเคิล และการคำนวณ D = Vo/Vinเผยแพร่ 30 ส.ค. 2566 · YouTube
