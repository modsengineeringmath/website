# Laplace transforms constant function การแปลงลาปลาซของฟังก์ชันค่าคงที c

ติดตามดูบน YouTube ↗

เผยแพร่ 24 พ.ย. 2569 · ภาษาไทย #controlsystem #ระบบควบคุม #feedbackcontrol #การควบคุมป้อนกลับ

การแปลงลาปลาซของฟังก์ชันค่าคงที่ด้วยนิยามการแปลงลาปลาซ นี่เป็นบทเรียนแรกของการเรียนระบบกควบคุม ซึ่งจะต้องมีพื้นฐานการแปลงลาปลาซที่ครบถ้วนก่อน เพราะจะต้องนำไปใช้ต่อในการหาผลตอบสนองเชิงเวลา เหล่านี้เป็นสิ่งสำคัญอย่างยิ่ง ขบวนการไม่มีความซับซ้อน สามารถหาคำตอบได้ไม่ยากโดยมีเทคนิคการอินทิเกรตเล็กน้อยในการเปลี่ยนตัวแปร u

## สรุปสูตรอ่านประกอบคลิป

$$\mathcal{L}\{c\} = \int_{0}^{\infty} c\,e^{-st}\,dt = \frac{c}{s}, \qquad \operatorname{Re}(s) > 0$$

ขั้นตอนจากนิยาม ด้วยการเปลี่ยนตัวแปร $u = -st$

- นิยาม: $\mathcal{L}\{f(t)\} = F(s) = \int_0^\infty f(t)\,e^{-st}\,dt$ แทน $f(t) = c$ แล้วดึงค่าคงที่ออกนอกอินทิกรัล ได้ $c\int_0^\infty e^{-st}\,dt$

- ให้ $u = -st$ จะได้ $du = -s\,dt$ หรือ $dt = -\dfrac{du}{s}$

- เปลี่ยนขอบเขต: $t = 0 \Rightarrow u = 0$ และ $t \to \infty \Rightarrow u \to -\infty$ (เมื่อ $s > 0$)

- แทนค่า: $c\displaystyle\int_0^{-\infty} e^{u}\left(-\frac{du}{s}\right) = \frac{c}{s}\int_{-\infty}^{0} e^{u}\,du = \frac{c}{s}\Big[e^{u}\Big]_{-\infty}^{0} = \frac{c}{s}\,(1 - 0) = \frac{c}{s}$

เงื่อนไข $\operatorname{Re}(s) > 0$ สำคัญ เพราะถ้า $s \le 0$ พจน์ $e^{-st}$ จะไม่ลดลงเป็นศูนย์ และอินทิกรัลลู่ออก ช่วงค่า $s$ ที่อินทิกรัลลู่เข้านี้เรียกว่า region of convergence (ROC)

### ตัวอย่างฝึกเพิ่ม

- $\mathcal{L}\{5\} = \dfrac{5}{s}$ และ $\mathcal{L}\{1\} = \dfrac{1}{s}$ ซึ่งเท่ากับลาปลาซของฟังก์ชันขั้นบันไดหนึ่งหน่วย $u(t)$

- แปลงกลับ: $\mathcal{L}^{-1}\left\{\dfrac{12}{s}\right\} = 12$ สำหรับ $t \ge 0$

- ต่อแหล่งจ่ายไฟตรง 24 V เข้าวงจรที่เวลา $t = 0$ อินพุตในโดเมน $s$ คือ $V_{in}(s) = \dfrac{24}{s}$ ถ้าวงจรมีฟังก์ชันถ่ายโอน $G(s) = \dfrac{1}{RCs+1}$ เอาต์พุตคือ $V_C(s) = \dfrac{24}{s\,(RCs+1)}$ ซึ่งเป็นจุดเริ่มของการหาผลตอบสนองเชิงเวลาในวิชาระบบควบคุม

## คำถามที่พบบ่อย

การแปลงลาปลาซของค่าคงที่ c ได้เท่าไร?
L{c} = c/s โดยใช้ได้เมื่อส่วนจริงของ s มากกว่าศูนย์ (Re(s) > 0) เพราะต้องให้ e^(−st) ลดลงเป็นศูนย์เมื่อ t เข้าใกล้อนันต์ ถ้า c = 1 จะได้ L{1} = 1/s ซึ่งเท่ากับลาปลาซของฟังก์ชันขั้นบันไดหนึ่งหน่วย u(t)

ทำไมต้องเปลี่ยนตัวแปร u = −st?
เพื่อให้อินทิกรัล ∫ e^(−st) dt กลายเป็น ∫ e^u du ซึ่งอินทิเกรตได้ทันที โดยต้องเปลี่ยน dt = −du/s และเปลี่ยนขอบเขตด้วย t = 0 ได้ u = 0 และ t → ∞ ได้ u → −∞ เมื่อ s > 0

ลาปลาซของค่าคงที่ใช้ในระบบควบคุมตรงไหน?
ใช้กับอินพุตที่เป็นค่าคงที่ตั้งแต่ t = 0 เช่น ต่อแหล่งจ่ายไฟตรง V โวลต์เข้าวงจร หรือสั่งค่าอ้างอิงแบบขั้นบันได อินพุตเหล่านี้แปลงเป็น V/s แล้วนำไปคูณฟังก์ชันถ่ายโอนเพื่อหาผลตอบสนองเชิงเวลา (step response)
