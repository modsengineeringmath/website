    คำถามที่พบบ่อย

    การแปลงลาปลาซของค่าคงที่ c ได้เท่าไร?

    L{c} = c/s โดยใช้ได้เมื่อส่วนจริงของ s มากกว่าศูนย์ (Re(s) > 0) เพราะต้องให้ e^(−st) ลดลงเป็นศูนย์เมื่อ t เข้าใกล้อนันต์ ถ้า c = 1 จะได้ L{1} = 1/s ซึ่งเท่ากับลาปลาซของฟังก์ชันขั้นบันไดหนึ่งหน่วย u(t)

    ทำไมต้องเปลี่ยนตัวแปร u = −st?

    เพื่อให้อินทิกรัล ∫ e^(−st) dt กลายเป็น ∫ e^u du ซึ่งอินทิเกรตได้ทันที โดยต้องเปลี่ยน dt = −du/s และเปลี่ยนขอบเขตด้วย t = 0 ได้ u = 0 และ t → ∞ ได้ u → −∞ เมื่อ s > 0

    ลาปลาซของค่าคงที่ใช้ในระบบควบคุมตรงไหน?

    ใช้กับอินพุตที่เป็นค่าคงที่ตั้งแต่ t = 0 เช่น ต่อแหล่งจ่ายไฟตรง V โวลต์เข้าวงจร หรือสั่งค่าอ้างอิงแบบขั้นบันได อินพุตเหล่านี้แปลงเป็น V/s แล้วนำไปคูณฟังก์ชันถ่ายโอนเพื่อหาผลตอบสนองเชิงเวลา (step response)
