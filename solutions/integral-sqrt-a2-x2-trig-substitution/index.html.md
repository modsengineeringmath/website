# เฉลยอินทิเกรต ∫√(a² − x²) dx ด้วยการแทนค่าตรีโกณ (Trigonometric substitution)

// เฉลยโจทย์อินทิเกรต #006 · Trigonometric substitution


โจทย์ · อินทิเกรต #006
จงหาอินทิกรัลไม่จำกัดเขต $\int \sqrt{a^2-x^2}\,dx$ เมื่อ $a > 0$ และ $|x| \le a$ โดยใช้การแทนค่า $x = a\sin\theta$

$$\int \sqrt{a^2-x^2}\,dx$$

แตะเพื่อดูคำตอบสุดท้าย (ลองคิดเองก่อนนะ)

$$\int \sqrt{a^2-x^2}\,dx = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\sin^{-1}\frac{x}{a} + C$$

## มองโจทย์ก่อน: อะไรทำให้ข้อนี้ยาก

ตัวที่ขวางคือรากที่สอง ลองเปลี่ยนตัวแปร $u = a^2 - x^2$ ได้ $du = -2x\,dx$ แต่ในโจทย์ไม่มี $x$ มาจับคู่ (ถ้าโจทย์เป็น $\int x\sqrt{a^2-x^2}\,dx$ จะใช้ได้ทันที) การอินทิเกรตทีละส่วนก็ยังวนกลับมามีรากเหมือนเดิม

เป้าหมายจึงเป็นหาตัวแปรใหม่ที่ทำให้ $a^2 - x^2$ เป็นกำลังสองสมบูรณ์ เมื่อถอดรากได้ อินทิกรัลจะเหลือฟังก์ชันตรีโกณธรรมดา

อีกมุมหนึ่ง $y = \sqrt{a^2-x^2}$ คือครึ่งบนของวงกลมรัศมี a อินทิกรัลนี้จึงเป็นพื้นที่ใต้ส่วนโค้งของวงกลม และมุมเป็นตัวแปรที่เหมาะกับวงกลมที่สุด

## ที่มาของการแทนค่า x = a sin θ

เอกลักษณ์ $1 - \sin^2\theta = \cos^2\theta$ มีหน้าตาแบบเดียวกับ $a^2 - x^2$ ถ้าให้ $x = a\sin\theta$

$$a^2 - x^2 = a^2 - a^2\sin^2\theta = a^2\cos^2\theta \quad\Longrightarrow\quad \sqrt{a^2-x^2} = a\cos\theta$$

เลือกช่วง $-\tfrac{\pi}{2} \le \theta \le \tfrac{\pi}{2}$ ซึ่ง (1) ครอบคลุมทุก $x\in[-a,a]$ พอดี (2) ทำให้ $\cos\theta \ge 0$ จึงถอดรากได้ $a\cos\theta$ โดยไม่ต้องใส่ค่าสัมบูรณ์ และ (3) กลับไปหา $\theta = \sin^{-1}(x/a)$ ได้ไม่กำกวม

ในเชิงเรขาคณิต จุด $(x, y)$ บนวงกลมเขียนได้เป็น $(a\sin\theta, a\cos\theta)$ โดย $\theta$ วัดจากแกน y การแทนค่านี้จึงเป็นการเปลี่ยนจาก “เดินตามแกน x” เป็น “เดินตามมุม” นั่นเอง

| รูปในราก | แทนค่า | เอกลักษณ์ที่ใช้ | รากกลายเป็น |

| $a^2 - x^2$ | $x = a\sin\theta$ | $1-\sin^2\theta = \cos^2\theta$ | $a\cos\theta$ |

| $a^2 + x^2$ | $x = a\tan\theta$ | $1+\tan^2\theta = \sec^2\theta$ | $a\sec\theta$ |

| $x^2 - a^2$ | $x = a\sec\theta$ | $\sec^2\theta - 1 = \tan^2\theta$ | $a\tan\theta$ |

## วิธีทำอย่างละเอียด

วิธีทำ · Trigonometric substitution

### หา $\displaystyle \int \sqrt{a^2-x^2}\,dx$ เมื่อ $|x| \le a$

- แทนค่า โดย $-\tfrac{\pi}{2} \le \theta \le \tfrac{\pi}{2}$

$${x = a\sin\theta} \;\Rightarrow\; {dx = a\cos\theta\,d\theta}, \qquad \sqrt{a^2-x^2} = a\cos\theta$$

- เขียนอินทิกรัลใหม่ทั้งหมดด้วย $\theta$

$$\int \sqrt{a^2-x^2}\,dx = \int a\cos\theta\cdot{a\cos\theta\,d\theta} = a^2\int\cos^2\theta\,d\theta$$

- ลดกำลังด้วยสูตรมุมสองเท่า แล้วอินทิเกรต S12

$$a^2\int\frac{1+\cos2\theta}{2}\,d\theta = \frac{a^2}{2}\left(\theta + \frac{\sin2\theta}{2}\right) = \frac{a^2}{2}\left(\theta + {\sin\theta\cos\theta}\right)$$

- กลับเป็น x: จาก $\sin\theta = \tfrac{x}{a}$ วาดสามเหลี่ยมมุมฉากด้านตรงข้าม x ด้านตรงข้ามมุมฉาก a ได้ด้านประชิด $\sqrt{a^2-x^2}$

$$\theta = \sin^{-1}\frac{x}{a}, \qquad \sin\theta = \frac{x}{a}, \qquad \cos\theta = \frac{\sqrt{a^2-x^2}}{a}$$

- แทนกลับและจัดรูป

$$\frac{a^2}{2}\left(\sin^{-1}\frac{x}{a} + \frac{x}{a}\cdot\frac{\sqrt{a^2-x^2}}{a}\right) = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\sin^{-1}\frac{x}{a} + {C}$$

$\displaystyle \int \sqrt{a^2-x^2}\,dx = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\sin^{-1}\frac{x}{a} + {C}$

ตรวจคำตอบ: ดิฟพจน์แรกได้ $\tfrac12\sqrt{a^2-x^2} - \tfrac{x^2}{2\sqrt{a^2-x^2}}$ พจน์ที่สองได้ $\tfrac{a^2}{2\sqrt{a^2-x^2}}$ รวมกันได้ $\tfrac{(a^2-x^2) - x^2 + a^2}{2\sqrt{a^2-x^2}} = \sqrt{a^2-x^2}$ ✓

## ความหมายของคำตอบ: สามเหลี่ยม + เสี้ยววงกลม

อินทิกรัลจำกัดเขต $\int_0^{x}\sqrt{a^2-t^2}\,dt$ คือพื้นที่ใต้วงกลมจาก 0 ถึง x ซึ่งแบ่งได้เป็นสองชิ้นพอดีกับสองพจน์ของคำตอบ

- $\tfrac{x}{2}\sqrt{a^2-x^2} = \tfrac12\cdot x\cdot y$ คือพื้นที่สามเหลี่ยมที่มีจุดยอดที่จุดศูนย์กลาง จุด $(x, 0)$ และจุด $(x, y)$ บนวงกลม

- $\tfrac{a^2}{2}\sin^{-1}\tfrac{x}{a} = \tfrac12a^2\theta$ คือพื้นที่เสี้ยววงกลม (sector) มุม $\theta$ ระหว่างแกน y กับรัศมีไปยัง $(x, y)$

ตัวอย่าง

### หา $\displaystyle\int_0^{1}\sqrt{4-x^2}\,dx$ (a = 2)

- แทนขอบเขต $\sin^{-1}\tfrac12 = \tfrac{\pi}{6}$

$$\left[\frac{x}{2}\sqrt{4-x^2} + 2\sin^{-1}\frac{x}{2}\right]_0^1 = \frac{\sqrt3}{2} + 2\cdot\frac{\pi}{6} = \frac{\sqrt3}{2} + \frac{\pi}{3}$$

$\approx 0.866 + 1.047 = 1.913$ ตารางหน่วย (สามเหลี่ยม 0.866 + เสี้ยววงกลม 30° ที่มีพื้นที่ 1.047)

ถ้าอินทิเกรตเต็มช่วง $-a$ ถึง $a$ พจน์สามเหลี่ยมเป็นศูนย์ที่ปลายทั้งสอง เหลือ $\tfrac{a^2}{2}\left(\tfrac{\pi}{2} + \tfrac{\pi}{2}\right) = \tfrac{\pi a^2}{2}$ คือครึ่งวงกลม ได้สูตรพื้นที่วงกลม $\pi a^2$ จากอินทิกรัล

## ใช้จริง: ปริมาตรน้ำในถังทรงกระบอกนอน

ถังน้ำมันหรือถังน้ำวางนอน รัศมี R ยาว L ถ้าวัดความลึกของเหลวได้ h ปริมาตรคือพื้นที่หน้าตัดส่วนที่จมคูณ L พื้นที่หน้าตัดหาได้จากอินทิกรัลข้อนี้ (ความกว้างที่ระดับ y คือ $2\sqrt{R^2-y^2}$)

$$A(h) = \int_{-R}^{-R+h} 2\sqrt{R^2-y^2}\,dy = R^2\cos^{-1}\frac{R-h}{R} - (R-h)\sqrt{2Rh - h^2}$$

ถัง R = 1 m ยาว 3 m มีน้ำลึก 0.5 m: $A = \cos^{-1}0.5 - 0.5\sqrt{0.75} = 1.047 - 0.433 = 0.614\ \text{m}^2$ ปริมาตร $0.614\times3 \approx 1.84\ \text{m}^3$ หรือราว 1,840 ลิตร ทั้งที่ความลึกเป็นแค่ 1/4 ของเส้นผ่านศูนย์กลาง ปริมาตรกลับเป็นแค่ราว 20% ของถัง (ถังเต็มจุ $3\pi \approx 9.42\ \text{m}^3$) ไม้วัดระดับจึงต้องมีตารางเทียบ ไม่ใช่แบ่งขีดเท่ากัน

## จุดที่มักพลาด

- ลืมแทน dx เขียน $\int a\cos\theta\,d\theta$ โดยไม่คูณ $a\cos\theta$ จาก dx ได้คำตอบผิดทั้งข้อ

- ทิ้งคำตอบไว้เป็น θ อินทิกรัลไม่จำกัดเขตต้องกลับเป็น x เสมอ ใช้สามเหลี่ยมช่วยหา $\cos\theta$

- เขียน $\sin2\theta$ เป็น $2\tfrac{x}{a}$ ผิด ต้องใช้ $\sin2\theta = 2\sin\theta\cos\theta$ ก่อนแทนกลับ

- สับสนกับ $\int\tfrac{dx}{\sqrt{a^2-x^2}}$ ข้อนั้นได้ $\sin^{-1}\tfrac{x}{a}$ อย่างเดียว ข้อนี้รากอยู่บนเศษจึงมีพจน์สามเหลี่ยมเพิ่ม

ทบทวนได้ที่ตารางสูตรอินทิเกรตกลุ่มรากที่สอง (R34) และฝึกต่อด้วยข้อ B12 ∫dx/(x²√(4 − x²))

## คำถามที่พบบ่อย

∫√(a² − x²) dx เท่ากับเท่าไร?
เท่ากับ $\tfrac{x}{2}\sqrt{a^2-x^2} + \tfrac{a^2}{2}\sin^{-1}\tfrac{x}{a} + C$ สำหรับ $|x| \le a$

ทำไมต้องแทน x = a sin θ ไม่ใช่ a tan θ?
เพราะ $a^2 - a^2\sin^2\theta = a^2\cos^2\theta$ เป็นกำลังสองสมบูรณ์ รากจึงหายไป รูป $a^2 - x^2$ ใช้ sin รูป $a^2 + x^2$ ใช้ tan และรูป $x^2 - a^2$ ใช้ sec ตามเอกลักษณ์ $1-\sin^2 = \cos^2$, $1+\tan^2 = \sec^2$, $\sec^2 - 1 = \tan^2$

พื้นที่วงกลมหาด้วยอินทิกรัลได้อย่างไร?
ครึ่งบนของวงกลมรัศมี a คือ $y = \sqrt{a^2-x^2}$ อินทิเกรตจาก $-a$ ถึง $a$ ได้ $\tfrac{\pi a^2}{2}$ คูณ 2 ได้ $\pi a^2$
