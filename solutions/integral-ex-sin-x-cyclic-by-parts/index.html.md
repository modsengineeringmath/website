# เฉลยอินทิเกรต ∫eˣ sin x dx ด้วยการอินทิเกรตทีละส่วนแบบวนกลับ

// เฉลยโจทย์อินทิเกรต #007 · Cyclic integration by parts


โจทย์ · อินทิเกรต #007

$$\int e^{x}\sin x\,dx$$

## มองโจทย์ก่อน: อะไรทำให้ข้อนี้ยาก

เป็นผลคูณของฟังก์ชันต่างชนิด จึงนึกถึงการอินทิเกรตทีละส่วน แต่ต่างจาก $\int xe^x\,dx$ ตรงที่ไม่มีตัวไหนดิฟแล้วหายไป ดิฟ $e^x$ ก็ยังเป็น $e^x$ ดิฟ $\sin x$ ได้ $\cos x$ ดิฟอีกครั้งได้ $-\sin x$ วนกลับมาเหมือนเดิม

ทำทีละส่วนกี่รอบก็ไม่จบ แต่การ “วนกลับมาเหมือนเดิม” นี่เองคือทางออก ถ้าหลังสองรอบอินทิกรัลเดิมโผล่กลับมาพร้อมเครื่องหมายลบ เราจะได้สมการที่มีอินทิกรัลที่ต้องการเป็นตัวไม่ทราบค่า แล้วแก้หาเหมือนพีชคณิตธรรมดา

## ที่มาของวิธีวนกลับ และกับดัก 0 = 0

ตั้งชื่อ $I = \int e^x\sin x\,dx$ แล้วทำทีละส่วนสองรอบ โดยมีกติกาเดียวที่ต้องรักษา: ให้ u เป็นฟังก์ชันชนิดเดียวกันทั้งสองรอบ ในหน้านี้ให้ u เป็นตรีโกณทั้งคู่ (เลือก eˣ ทั้งคู่ก็ได้ผลเหมือนกัน)

ถ้ารอบแรกให้ $u = \sin x$ แต่รอบสองเปลี่ยนไปให้ $u = e^x$ รอบสองจะย้อนสิ่งที่รอบแรกทำทุกขั้น สุดท้ายได้

$$I = e^x\sin x - \big(e^x\sin x - I\big) \quad\Longrightarrow\quad I = I$$

ซึ่งจริงแต่ไม่บอกอะไร นี่คือกับดักที่นักศึกษาเจอบ่อยที่สุดในข้อนี้

## วิธีทำอย่างละเอียด

วิธีทำ · Cyclic integration by parts

### หา $\displaystyle I = \int e^{x}\sin x\,dx$

- รอบที่ 1: ให้ u เป็นตรีโกณ T3 Integration by parts

$${u = \sin x},\ {du = \cos x\,dx},\quad dv = e^x dx,\ v = e^x$$

$$I = e^x\sin x - \int e^x\cos x\,dx$$

- รอบที่ 2: กับอินทิกรัลใหม่ ให้ u เป็นตรีโกณอีก (ชนิดเดิม)

$${u = \cos x},\ {du = -\sin x\,dx},\quad dv = e^x dx,\ v = e^x$$

$$\int e^x\cos x\,dx = e^x\cos x - \int e^x(-\sin x)\,dx = e^x\cos x + {I}$$

- แทนกลับในรอบที่ 1 อินทิกรัลเดิม $I$ โผล่มาพร้อมเครื่องหมายลบ

$$I = e^x\sin x - \big(e^x\cos x + {I}\big) = e^x\sin x - e^x\cos x - {I}$$

- ย้ายข้างแก้สมการหา $I$ แล้วเติมค่าคงที่

$$2I = e^x(\sin x - \cos x) \quad\Longrightarrow\quad I = \frac{e^x}{2}(\sin x - \cos x) + {C}$$

$\displaystyle \int e^{x}\sin x\,dx = \frac{e^{x}}{2}(\sin x - \cos x) + {C}$

ตรวจคำตอบ: $\tfrac{d}{dx}\Big[\tfrac{e^x}{2}(\sin x-\cos x)\Big] = \tfrac{e^x}{2}(\sin x-\cos x) + \tfrac{e^x}{2}(\cos x+\sin x) = e^x\sin x$ ✓

ค่าคงที่ C เติมหลังย้ายข้าง เพราะสมการในขั้น 3 เป็นความสัมพันธ์ระหว่างปฏิยานุพันธ์ที่ยังไม่ได้กำหนดค่าคงที่

## วิธีที่สั้นกว่า: ใช้เลขเชิงซ้อน

จากสูตรออยเลอร์ $e^{ix} = \cos x + i\sin x$ จะได้ $e^x\sin x = \operatorname{Im}\big(e^{(1+i)x}\big)$ และอินทิเกรตเลขชี้กำลังได้ทันที

$$\int e^{(1+i)x}\,dx = \frac{e^{(1+i)x}}{1+i} = \frac{(1-i)}{2}\,e^x(\cos x + i\sin x)$$

กระจายแล้วเก็บเฉพาะส่วนจินตภาพ: $\tfrac{e^x}{2}(\sin x - \cos x)$ ตรงกับวิธีทีละส่วน ส่วนจริงเป็นของแถม $\int e^x\cos x\,dx = \tfrac{e^x}{2}(\sin x + \cos x)$ ซึ่งเป็นข้อ B7 ในแนวข้อสอบ วิศวกรไฟฟ้าใช้ความคิดนี้ทุกวันในรูปของเฟสเซอร์

## ตัวอย่างตัวเลข: อินทิกรัลจำกัดเขต

$$\int_0^{\pi}e^x\sin x\,dx = \left[\frac{e^x}{2}(\sin x - \cos x)\right]_0^{\pi} = \frac{e^{\pi}(0+1)}{2} - \frac{1\cdot(0-1)}{2} = \frac{e^{\pi}+1}{2} \approx 12.07$$

ตรวจขนาด: $\sin x \ge 0$ ตลอดช่วงจึงต้องได้ค่าบวก และ $e^x$ โตถึง $e^\pi \approx 23$ ที่ปลายช่วง พื้นที่ราว 12 สมเหตุสมผล

## ที่มาของการแปลงลาปลาซของ sin ωt

ถ้าเปลี่ยน $e^x$ เป็น $e^{-st}$ และ $\sin x$ เป็น $\sin\omega t$ วิธีวนกลับเดียวกันให้สูตรทั่วไป $\int e^{at}\sin bt\,dt = \tfrac{e^{at}}{a^2+b^2}(a\sin bt - b\cos bt)$ เมื่อแทนขอบเขต 0 ถึง ∞ (โดย $s > 0$) จะได้

$$\mathcal{L}\{\sin\omega t\} = \int_0^{\infty}e^{-st}\sin\omega t\,dt = \frac{\omega}{s^2+\omega^2}$$

ซึ่งเป็นหนึ่งในบรรทัดที่ใช้บ่อยที่สุดของตารางการแปลงลาปลาซ และรูป $e^{-at}\sin\omega t$ ก็คือแรงดันหรือกระแสของวงจร RLC แบบหน่วงน้อย (underdamped) ซึ่งต้องอินทิเกรตเพื่อหาประจุหรือพลังงานที่ส่งผ่าน

## จุดที่มักพลาด

- สลับชนิดของ u ในรอบที่สอง ได้ $I = I$ ไม่ได้คำตอบ ต้องเลือกชนิดเดิม

- เครื่องหมายของ $\tfrac{d}{dx}\cos x = -\sin x$ ถ้าพลาดตรงนี้จะได้ $I = \ldots + I$ ซึ่งย้ายข้างไม่ได้ ให้ตรวจเครื่องหมายใหม่

- ลืมหารด้วย 2 หลังย้ายข้าง

- ทำต่อเป็นรอบที่ 3, 4 ไม่จำเป็น เห็น $I$ โผล่กลับมาเมื่อไรให้หยุดแล้วย้ายข้าง

ทบทวนได้ที่การอินทิเกรตทีละส่วน และตารางสูตรอินทิเกรต R45–R46

## คำถามที่พบบ่อย

∫eˣ sin x dx เท่ากับเท่าไร?
เท่ากับ $\tfrac{e^{x}}{2}(\sin x - \cos x) + C$

ทำไมทำทีละส่วนสองรอบแล้วได้ 0 = 0?
เพราะรอบที่สองเลือก u สลับชนิดกับรอบแรก (รอบแรกให้ u เป็นตรีโกณ รอบสองให้ u เป็น eˣ) การทำแบบนั้นเท่ากับย้อนขั้นแรกกลับ ต้องให้ u เป็นชนิดเดียวกันทั้งสองรอบ

∫e^(ax) sin bx dx ทั่วไปเท่ากับเท่าไร?
เท่ากับ $\tfrac{e^{ax}}{a^2+b^2}(a\sin bx - b\cos bx) + C$ กรณี $a = b = 1$ คือข้อนี้
