# เฉลยโจทย์คณิตศาสตร์วิศวกรรมแบบละเอียดทีละขั้น

// เฉลยโจทย์ · 7 ข้อ


โจทย์ที่โพสต์บนเพจ Mod's Engineering Mathematics เฉลยไว้ที่นี่ข้อละหน้า ทุกขั้นบอกว่าใช้สูตรหรือเหตุผลอะไร และทำไมถึงเลือกวิธีนั้น ไม่ใช่แค่คำตอบ เปิด โหมดฝึกทำ เพื่อซ่อนวิธีทำ ลองคิดเองก่อน แล้วกด ดูทีละขั้น เมื่อติด

∫อินทิเกรต 7

## ∫เฉลยโจทย์อินทิเกรต Integration
7 ข้อ · ทบทวนบทเรียน →

อินทิเกรต #001●●○ ปานกลาง

$$\int \frac{dx}{\sqrt{x^2+a^2}}$$

∫dx/√(x²+a²) ด้วยการแทนค่าแบบออยเลอร์
Euler's substitution
24 ต.ค. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #002●○○ พื้นฐาน

$$\int x e^{x}\,dx$$

∫x eˣ dx ด้วยการอินทิเกรตทีละส่วน
Integration by parts
14 พ.ย. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #003●○○ พื้นฐาน

$$\int \ln x\,dx$$

∫ln x dx ด้วยทีละส่วนแบบ dv = dx
Integration by parts
14 พ.ย. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #004●●○ ปานกลาง

$$\int \frac{5x-1}{x^2-x-2}\,dx$$

∫(5x − 1)/(x² − x − 2) dx ด้วยเศษส่วนย่อย
Partial fraction decomposition
14 พ.ย. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #005●●○ ปานกลาง

$$\int \sec x\,dx$$

∫sec x dx สองวิธี
Multiply by a clever one / u-substitution
14 พ.ย. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #006●●○ ปานกลาง

$$\int \sqrt{a^2-x^2}\,dx$$

∫√(a² − x²) dx ด้วยการแทนค่าตรีโกณ
Trigonometric substitution
14 พ.ย. 2569ดูเฉลยทีละขั้น →

อินทิเกรต #007●●○ ปานกลาง

$$\int e^{x}\sin x\,dx$$

∫eˣ sin x dx ด้วยทีละส่วนแบบวนกลับ
Cyclic integration by parts

## อ่านเฉลยให้ได้มากกว่าคำตอบ

- อ่านโจทย์แล้วลองทำเองก่อน อย่างน้อยให้ได้ขั้นแรก คำตอบสุดท้ายซ่อนอยู่ใต้กล่องโจทย์ ใช้ตรวจหลังทำเสร็จ

- ติดตรงไหน ค่อยเปิดทีละขั้น ปุ่ม “ดูทีละขั้น” เปิดเฉลยครั้งละหนึ่งขั้น สีในสมการบอกว่าขั้นนั้นใช้สูตร ตัวแปรใหม่ หรือตัดทอนอะไร

- อ่านส่วน “ที่มา” เสมอ โจทย์ส่วนใหญ่ยากที่การเลือกวิธี ไม่ใช่การคำนวณ ส่วนนี้อธิบายว่าทำไมต้องแทนค่าแบบนั้น จะได้ใช้กับข้ออื่นได้เอง
