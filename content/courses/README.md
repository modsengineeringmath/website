# คู่มือโพสต์บทเรียนในห้องเรียนออนไลน์ด้วยตัวเอง

โฟลเดอร์นี้คือเนื้อหาของ **https://modsengineeringmath.com/courses/** ทุกไฟล์เป็นข้อความธรรมดา (Markdown)
แก้ได้จากเว็บ github.com บนมือถือหรือคอมพิวเตอร์ **ไม่ต้องติดตั้งโปรแกรม ไม่ต้องใช้ Claude**
เมื่อกด Commit ระบบจะสร้างหน้าเว็บให้เองและขึ้นเว็บจริงภายในประมาณ 3–5 นาที

```
content/courses/control-engineering/
  course.md                  ข้อมูลรายวิชา + แผนการเรียน 17 หน่วย + ข้อความบนหน้ารายวิชา
  01-introduction.md         หน่วยที่ 1  →  /courses/control-engineering/introduction/
  02-transfer-function.md    หน่วยที่ 2  →  /courses/control-engineering/transfer-function/
  _template.md               แม่แบบ (ไฟล์ที่ขึ้นต้นด้วย _ ไม่ขึ้นเว็บ)
  en/                        ฉบับภาษาอังกฤษ ชื่อไฟล์เหมือนฉบับไทยทุกไฟล์  →  /en/courses/control-engineering/…
files/courses/control-engineering/     ไฟล์แจก: PDF สไลด์ ตำรา
images/courses/control-engineering/    รูปประกอบ
```

## 1. เพิ่มหน่วยใหม่ (ทำบน github.com)

1. เปิด https://github.com/modsengineeringmath/website แล้วเข้าโฟลเดอร์ `content/courses/control-engineering`
2. เปิดไฟล์ `_template.md` กดปุ่ม **Raw** แล้วคัดลอกข้อความทั้งหมด
3. กลับมาที่โฟลเดอร์ กด **Add file → Create new file**
4. ตั้งชื่อไฟล์ `เลขหน่วย-ชื่ออังกฤษ.md` เช่น `03-modelling.md`
   - ใช้ได้เฉพาะ a–z ตัวเลข และขีดกลาง `-` ห้ามเว้นวรรค ห้ามภาษาไทย
   - เลขข้างหน้าคือเลขหน่วย และกำหนดลำดับ ส่วนชื่อหลังเลขจะเป็นลิงก์ของหน้า **ตั้งแล้วไม่ควรเปลี่ยน** (ลิงก์ที่แชร์ไปแล้วจะเสีย)
5. วางข้อความจากแม่แบบ แก้ส่วนหัวและเนื้อหา (ดูข้อ 3 และ 4)
6. ลบบรรทัด `draft: true` เมื่อพร้อมเผยแพร่ (ถ้ายังไม่ลบ หน้าจะถูกสร้างแต่ไม่อยู่ในแผนการเรียน ไม่ถูกค้นเจอ ใช้ดูตัวอย่างได้)
7. กด **Commit changes…** → **Commit changes**
8. รอ 3–5 นาที แล้วเปิด `https://modsengineeringmath.com/courses/control-engineering/modelling/`

หน่วยใหม่จะขึ้นในแผนการเรียน แทนป้าย "เร็วๆ นี้" ของเลขหน่วยนั้น มีปุ่มหน่วยก่อนหน้า/ถัดไป และเข้าระบบค้นหาของเว็บ
sitemap ของ Google และ llms.txt ให้เองทั้งหมด

**แก้ไขหน่วยเดิม:** เปิดไฟล์ กดรูปดินสอ ✏️ แก้ แล้ว Commit ถ้าแก้เนื้อหามากให้เปลี่ยนวันที่ `updated:` เป็นวันนี้

**โพสต์เสริมหรือประกาศ** (ไม่นับเป็นหน่วย): ตั้งชื่อไฟล์โดยไม่มีเลขนำหน้า เช่น `midterm-review.md`
จะไปอยู่ในหัวข้อ "เนื้อหาเสริมและประกาศ" ของหน้ารายวิชา

## 2. ตรวจว่าขึ้นเว็บสำเร็จหรือไม่

เปิดแท็บ **Actions** ของ repository ดูรายการบนสุดชื่อ **Build site**

- ✅ สีเขียว = สร้างหน้าเสร็จ อีกประมาณ 1 นาทีขึ้นเว็บจริง
- ❌ สีแดง = มีจุดผิด **เว็บจริงยังเป็นของเดิม ไม่เสียหาย** กดเข้าไปดูขั้น "Build" จะมีข้อความภาษาไทยบอกชื่อไฟล์และสาเหตุ
  แก้ไฟล์แล้ว Commit ใหม่ ระบบจะสร้างให้อีกรอบ

ข้อผิดพลาดที่พบบ่อย

| ข้อความ | วิธีแก้ |
|---|---|
| `ต้องขึ้นต้นไฟล์ด้วยส่วนหัวระหว่างบรรทัด ---` | บรรทัดแรกของไฟล์ต้องเป็น `---` และปิดส่วนหัวด้วย `---` อีกบรรทัด |
| `ส่วนหัวบรรทัดที่ … อ่านไม่ได้` | บรรทัดนั้นลืมเครื่องหมาย `:` หลังชื่อ เช่น `title: …` |
| `KaTeX error … in: …` | สมการพิมพ์ผิด ข้อความจะบอกสมการที่ผิด มักเป็นวงเล็บปีกกา `{ }` ไม่ครบคู่ |
| `ไม่พบไฟล์ /files/…` | ยังไม่ได้อัปโหลดไฟล์ หรือชื่อไม่ตรง (ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกัน) |
| `เปิดกล่อง ":::" ไว้ … ยังไม่ได้ปิด` | เพิ่มบรรทัด `:::` ปิดท้ายกล่อง |

## 5. อัปโหลดไฟล์แจกและรูป

1. เข้าโฟลเดอร์ `files/courses/control-engineering` (รูปใช้ `images/courses/control-engineering`)
2. กด **Add file → Upload files** ลากไฟล์มาวาง แล้ว Commit
   - ตั้งชื่อไฟล์เป็นอังกฤษ ไม่เว้นวรรค เช่น `unit03-slides.pdf` · ขนาดไม่เกิน 25 MB ต่อไฟล์
   - ไฟล์ใหญ่กว่านั้นหรือวิดีโอ ให้ฝากที่ Google Drive / YouTube แล้วใส่ลิงก์เต็ม `https://…` แทน
3. อ้างถึงในส่วนหัวของหน่วย
   ```
   files:
     - เอกสารประกอบการสอน หน่วยที่ 3 | /files/courses/control-engineering/unit03-handout.pdf
     - สไลด์ | /files/courses/control-engineering/unit03-slides.pdf
   ```
   **อัปโหลดไฟล์ก่อน แล้วจึงแก้ไฟล์บทเรียน** ถ้าอ้างถึงไฟล์ที่ยังไม่มี ระบบจะหยุดและแจ้งเตือน

ตำราทั้งเล่มหรือเอกสารของทั้งรายวิชา ใส่ที่ `files:` ในส่วนหัวของ `course.md` รูปแบบ `- ชื่อ | ลิงก์ | หมายเหตุ`
จะแสดงที่หัวข้อ "ตำราและเอกสารประกอบการสอน" ของหน้ารายวิชา

## 6. แก้แผนการเรียนหรือเปิดรายวิชาใหม่

- **แผนการเรียน:** แก้ `plan:` ใน `course.md` รูปแบบ `- เลขหน่วย | ชื่อไทย | ชื่ออังกฤษ` หน่วยที่ยังไม่มีไฟล์จะแสดงป้าย "เร็วๆ นี้"
  การแบ่งภาคแก้ที่ `parts:` รูปแบบ `- 1-4 | ชื่อภาค`
- **เพลย์ลิสต์ YouTube ของรายวิชา:** `playlist:` ใน `course.md` (รหัสหลัง `list=`)
- **รายวิชาใหม่:** สร้างโฟลเดอร์ใหม่ใน `content/courses/` เช่น `signals-and-systems/` คัดลอก `course.md` ไปแก้
  แล้วเพิ่มไฟล์หน่วยแบบเดียวกัน หน้า `/courses/signals-and-systems/` และการ์ดในหน้า `/courses/` จะถูกสร้างให้เอง
- **ลบหน่วย:** ลบไฟล์ `.md` และลบโฟลเดอร์ผลลัพธ์ `courses/control-engineering/<ชื่อ>/` ด้วย (ระบบไม่ลบหน้าที่เคยสร้างให้เอง)

## ฉบับภาษาอังกฤษ (โฟลเดอร์ en/)

- ฉบับภาษาไทยเป็นต้นฉบับ ฉบับภาษาอังกฤษอยู่ในโฟลเดอร์ `en/` ของรายวิชา ใช้**ชื่อไฟล์เดียวกัน** เช่น `13-pid-control.md` กับ `en/13-pid-control.md`
  ระบบจับคู่สองหน้าให้เอง: มีปุ่มสลับภาษา และแจ้ง Google ว่าเป็นหน้าเดียวกันคนละภาษา (hreflang)
- **เมื่อแก้เนื้อหาภาษาไทยเอง ฉบับภาษาอังกฤษจะยังไม่เปลี่ยน** ให้แจ้ง Claude ว่า "แปลหน่วยที่ … ที่แก้ล่าสุดเป็นภาษาอังกฤษ" Claude จะปรับไฟล์ใน `en/` ให้ตรงกัน
- ถ้าเพิ่มหน่วยใหม่เฉพาะภาษาไทย หน้าภาษาไทยขึ้นเว็บได้ตามปกติ แผนการเรียนฉบับอังกฤษจะแสดงหน่วยนั้นเมื่อมีไฟล์ใน `en/` แล้วเท่านั้น
- ในไฟล์ภาษาอังกฤษห้ามมีข้อความภาษาไทยเหลืออยู่ (ระบบตรวจให้ ถ้ามีจะขึ้น ✗ ในแท็บ Actions)
