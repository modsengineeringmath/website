## ภาพในใจก่อนเริ่ม: ต้องมีค่าผิดพลาดจึงจะมีแรงขับ {#idea}

ตัวควบคุมแบบสัดส่วนสั่งงานตามขนาดของค่าผิดพลาด ถ้าค่าผิดพลาดเป็นศูนย์ สัญญาณสั่งก็เป็นศูนย์ แต่มอเตอร์ที่หมุนอยู่ต้องการแรงดันค่าหนึ่งจึงจะหมุนต่อไปได้ ระบบจึงต้องยอมให้มีค่าผิดพลาดเหลืออยู่เล็กน้อยเพื่อสร้างแรงดันนั้น ค่าที่เหลือนี้คือ**ค่าผิดพลาดในสถานะอยู่ตัว (steady-state error)**

ทางออกคือให้ตัวควบคุม**จำ**ได้ อินทิเกรเตอร์สะสมค่าผิดพลาดไว้ เมื่อค่าผิดพลาดกลายเป็นศูนย์แล้ว เอาต์พุตของอินทิเกรเตอร์ยังค้างอยู่ที่ค่าที่ต้องใช้พอดี หน่วยนี้ทำให้ความคิดนี้เป็นตัวเลข

## ทฤษฎีบทค่าสุดท้าย {#fvt}

สำหรับระบบป้อนกลับหนึ่งหน่วยที่มีฟังก์ชันถ่ายโอนของลูป $L(s) = C(s)G(s)$ ค่าผิดพลาดคือ

$$E(s) = R(s) - Y(s) = \frac{R(s)}{1 + L(s)}$$

**ทฤษฎีบทค่าสุดท้าย (final value theorem)** ให้ค่าเมื่อเวลาผ่านไปนานโดยไม่ต้องแปลงกลับ

$$e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} sE(s) = \lim_{s \to 0} \frac{sR(s)}{1 + L(s)}$$

:::warn ใช้ได้เมื่อระบบวงปิดเสถียรเท่านั้น
ถ้าระบบไม่เสถียร ค่าผิดพลาดโตไม่มีขอบเขต แต่สูตรอาจยังให้ตัวเลขออกมาซึ่งไม่มีความหมาย ต้องตรวจเสถียรภาพก่อนเสมอ วิธีตรวจอยู่ในหน่วยที่ 8
:::

## ชนิดของระบบ {#type}

เขียน $L(s)$ ในรูป

$$L(s) = \frac{K(s + z_1)(s + z_2)\cdots}{s^N(s + p_1)(s + p_2)\cdots}$$

จำนวน $N$ ของตัวประกอบ $s$ ในตัวส่วน หรือจำนวน**อินทิเกรเตอร์ในลูป** เรียกว่า**ชนิดของระบบ (system type)**

| ชนิด | ตัวอย่างในงานไฟฟ้า |
|---|---|
| 0 | ลูปความเร็วมอเตอร์หรือลูปแรงดัน AVR ที่ใช้ตัวควบคุม P |
| 1 | เซอร์โวตำแหน่ง (ตำแหน่งคือปริพันธ์ของความเร็ว) หรือลูปใดก็ตามที่ใช้ตัวควบคุม PI |
| 2 | เซอร์โวตำแหน่งที่ใช้ตัวควบคุม PI, เฟสล็อกลูป (PLL) ของอินเวอร์เตอร์เชื่อมต่อกริด |

## ค่าคงตัวความผิดพลาด {#constants}

| อินพุต | $R(s)$ | ค่าคงตัว | $e_{ss}$ |
|---|---|---|---|
| ขั้นบันได $A$ | $\dfrac{A}{s}$ | $K_p = \lim\limits_{s \to 0} L(s)$ | $\dfrac{A}{1 + K_p}$ |
| แรมป์ $At$ | $\dfrac{A}{s^2}$ | $K_v = \lim\limits_{s \to 0} sL(s)$ | $\dfrac{A}{K_v}$ |
| พาราโบลา $\tfrac12At^2$ | $\dfrac{A}{s^3}$ | $K_a = \lim\limits_{s \to 0} s^2L(s)$ | $\dfrac{A}{K_a}$ |

เมื่อรวมกับชนิดของระบบจะได้ตารางที่ใช้ตลอดวิชา

| ชนิดของระบบ | ขั้นบันได | แรมป์ | พาราโบลา |
|---|---|---|---|
| 0 | $\dfrac{A}{1 + K_p}$ | $\infty$ | $\infty$ |
| 1 | 0 | $\dfrac{A}{K_v}$ | $\infty$ |
| 2 | 0 | 0 | $\dfrac{A}{K_a}$ |

:::key อ่านตารางนี้ด้วยประโยคเดียว
อินทิเกรเตอร์แต่ละตัวในลูปทำให้ตามอินพุตที่ "ยากขึ้นอีกหนึ่งขั้น" ได้โดยไม่มีค่าผิดพลาด แต่อินทิเกรเตอร์แต่ละตัวก็เพิ่มเฟสล้าหลัง 90° ทำให้ระบบเสถียรยากขึ้น จึงใส่เท่าที่จำเป็น
:::

:::example ตัวอย่างที่ 7.1 เกนของ AVR
ลูปควบคุมแรงดันของเครื่องกำเนิดไฟฟ้ามีตัวขยาย $K_A$ เอกไซเตอร์ $\dfrac{1}{0.4s + 1}$ และเครื่องกำเนิด $\dfrac{1}{s + 1}$ ป้อนกลับหนึ่งหน่วย ต้องการให้แรงดันผิดจากค่าที่ตั้งไม่เกิน 1 % ต้องใช้ $K_A$ อย่างน้อยเท่าใด

$L(s) = \dfrac{K_A}{(0.4s + 1)(s + 1)}$ ไม่มีอินทิเกรเตอร์ เป็นระบบชนิด 0 จึงได้ $K_p = L(0) = K_A$

$$e_{ss} = \frac{1}{1 + K_A} \le 0.01 \quad\Longrightarrow\quad K_A \ge 99$$

เกนสูงขนาดนี้ทำให้ผลตอบสนองแกว่งมาก และเมื่อคิดค่าคงตัวเวลาอื่นในลูปด้วยระบบจะไม่เสถียร (ดูตัวอย่างที่ 8.2) AVR จริงจึงใช้ส่วนอินทิกรัลหรือตัวชดเชยแทนการเพิ่มเกนอย่างเดียว
:::

:::example ตัวอย่างที่ 7.2 เซอร์โวตำแหน่งตามสัญญาณแรมป์
เซอร์โวมี $L(s) = \dfrac{8.4}{s(s + 4)}$ (จากตัวอย่างที่ 6.3) จงหาค่าผิดพลาดเมื่อสั่งตำแหน่งคงที่ และเมื่อสั่งให้เคลื่อนที่ด้วยความเร็วคงที่ 2 rad/s

ระบบมีอินทิเกรเตอร์หนึ่งตัว เป็นชนิด 1

- สั่งตำแหน่งคงที่ (ขั้นบันได): $e_{ss} = 0$
- สั่งความเร็วคงที่ (แรมป์ $A = 2$): $K_v = \lim\limits_{s \to 0} s\,\dfrac{8.4}{s(s + 4)} = 2.1$ s⁻¹ ดังนั้น $e_{ss} = \dfrac{2}{2.1} = 0.95$ rad

แกนของเครื่องจักรจะตามหลังตำแหน่งที่สั่งอยู่ 0.95 rad ตลอดการเคลื่อนที่ ค่านี้เรียกว่า following error ในคู่มือเซอร์โวไดรฟ์
:::

## ค่าผิดพลาดจากการรบกวน {#disturbance}

เมื่อการรบกวนคงที่ขนาด $D_0$ เข้าระหว่างตัวควบคุม $C(s)$ กับพลานต์ $G(s)$ ค่าผิดพลาดที่เกิดคือ

$$e_{ss} = -\lim_{s \to 0}\frac{G(s)}{1 + C(s)G(s)}\,D_0$$

ถ้า $C(s)$ มีอินทิเกรเตอร์ ตัวส่วนจะโตไม่มีขอบเขตเมื่อ $s \to 0$ และ $e_{ss} = 0$ สิ่งสำคัญคือ**อินทิเกรเตอร์ต้องอยู่ก่อนจุดที่การรบกวนเข้า** อินทิเกรเตอร์ที่อยู่ในพลานต์หลังจุดนั้นไม่ช่วยหักล้างการรบกวน

:::example ตัวอย่างที่ 7.3 ดรูปของกัฟเวอร์เนอร์และการควบคุมความถี่
ในระบบไฟฟ้ากำลัง เมื่อโหลดเพิ่ม $\Delta P_L$ ความถี่จะลดลง กัฟเวอร์เนอร์ที่มีค่าเรกูเลชัน (droop) $R$ และโหลดที่มีค่าการหน่วง $D$ ให้ความถี่เบี่ยงเบนในสถานะอยู่ตัว

$$\Delta f_{ss} = -\frac{\Delta P_L}{D + 1/R}$$

ให้ $R = 0.05$ pu (ดรูป 5 %), $D = 1$ pu และโหลดเพิ่ม 0.1 pu ในระบบ 50 Hz

$$\Delta f_{ss} = -\frac{0.1}{1 + 20} = -0.00476\ \text{pu} = -0.238\ \text{Hz}$$

ความถี่ค้างอยู่ที่ 49.76 Hz กัฟเวอร์เนอร์แบบดรูปคือตัวควบคุมแบบสัดส่วน จึงเหลือค่าผิดพลาด ซึ่งเป็นความตั้งใจ เพราะทำให้เครื่องกำเนิดหลายเครื่องแบ่งโหลดกันได้ตามสัดส่วน จากนั้นการควบคุมขั้นที่สอง (AGC) ซึ่งเป็นตัวควบคุมแบบอินทิกรัลจะค่อย ๆ ปรับกำลังผลิตจนความถี่กลับสู่ 50 Hz
:::

## แบบฝึกหัด {#exercises}

:::exercise แบบฝึกหัด 7.1
ลูปความเร็วมอเตอร์มี $L(s) = \dfrac{K}{0.074s + 1}$ ต้องการค่าผิดพลาดต่ออินพุตขั้นบันไดไม่เกิน 2 % ต้องใช้ $K$ เท่าใด และถ้าเปลี่ยนเป็นตัวควบคุม PI จะได้ค่าผิดพลาดเท่าใด

:::answer ดูเฉลย
ระบบชนิด 0: $\dfrac{1}{1 + K} \le 0.02$ ได้ $K \ge 49$

ตัวควบคุม PI เพิ่มอินทิเกรเตอร์หนึ่งตัว ระบบกลายเป็นชนิด 1 ค่าผิดพลาดต่ออินพุตขั้นบันไดเป็นศูนย์ที่เกนใดก็ได้ (ตราบที่ระบบเสถียร)
:::
:::

:::exercise แบบฝึกหัด 7.2
ระบบป้อนกลับหนึ่งหน่วยมี $L(s) = \dfrac{50(s + 2)}{s(s + 5)(s + 10)}$ จงหา $K_p$, $K_v$, $K_a$ และค่าผิดพลาดต่อแรมป์ $r(t) = 3t$

:::answer ดูเฉลย
ระบบชนิด 1: $K_p = \infty$, $K_v = \dfrac{50 \times 2}{5 \times 10} = 2$ s⁻¹, $K_a = 0$

$e_{ss} = \dfrac{3}{2} = 1.5$
:::
:::

:::exercise แบบฝึกหัด 7.3
จากตัวอย่างที่ 7.3 ถ้าต้องการให้ความถี่เบี่ยงเบนไม่เกิน 0.1 Hz ต่อโหลดที่เพิ่ม 0.1 pu ต้องตั้งดรูป $R$ เท่าใด (ให้ $D = 1$)

:::answer ดูเฉลย
$0.1\ \text{Hz} = 0.002$ pu ต้องการ $\dfrac{0.1}{1 + 1/R} \le 0.002$ จึงได้ $1 + 1/R \ge 50$ และ $R \le \dfrac{1}{49} = 0.0204$ pu หรือดรูปประมาณ 2 %
:::
:::

## สรุปหน่วยที่ 7 {#summary}

- $e_{ss} = \lim\limits_{s \to 0}\dfrac{sR(s)}{1 + L(s)}$ ใช้ได้เมื่อระบบวงปิดเสถียร
- ชนิดของระบบคือจำนวนอินทิเกรเตอร์ในลูป ชนิด 0 เหลือค่าผิดพลาดต่อขั้นบันได ชนิด 1 ไม่เหลือ
- ค่าคงตัว $K_p$, $K_v$, $K_a$ ยิ่งมาก ค่าผิดพลาดยิ่งน้อย
- อินทิเกรเตอร์ในตัวควบคุมกำจัดผลของการรบกวนคงที่ได้ ดรูปของกัฟเวอร์เนอร์คือตัวอย่างของตัวควบคุม P ที่จงใจเหลือค่าผิดพลาดไว้

หน่วยถัดไปตอบคำถามที่ค้างอยู่: เพิ่มเกนได้มากแค่ไหนก่อนที่ระบบจะไม่เสถียร
