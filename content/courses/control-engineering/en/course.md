## How this classroom differs from the reference library {#about}

The [control systems library](/learn/control-systems/) is a reference for looking up formulas and using single-topic labs. This **classroom** is a continuous path, one unit at a time, with theory, step-by-step examples, an interactive lab, exercises and answers. Units that are not open yet show a "coming soon" tag and open one by one in order.

## Using it with the standard textbooks {#textbooks}

The order of topics and the notation follow the standard control textbooks, such as K. Ogata's *Modern Control Engineering* and *System Dynamics*, so you can read them side by side. The explanations, examples, problems and figures here are all written from scratch and are not copied or translated from any book. The exercises are of the same kinds you meet at the end of textbook chapters, but they use our own systems and numbers.

## How to use each unit {#how-to-use}

1. **Read the outcomes** at the top to know what you will be able to do.
2. **Work the examples** step by step with pencil and paper.
3. **Play with the lab**: change a value and watch what follows.
4. **Try the exercises before opening the answers**, which are folded away.
5. Press **Mark as learned**. Progress is kept only in your own browser.

## Prerequisites {#prerequisites}

- Calculus and ordinary differential equations
- Basic linear algebra (for Part 7)
- Basic circuit analysis ([see the DC circuits lessons](/learn/dc-circuits/))

Later units build the complex variables you need from the start, so no prior course in complex analysis is required.
