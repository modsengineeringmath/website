## If it feels hard, read this first {#start-here}

Many students give up on control in the first week because they meet Laplace transforms and differential equations before they know why. This classroom turns that order around: **real systems first, mathematics after**. Every equation comes with a picture or a graph that shows what it means.

- **You do not need to be good at it already.** Basic calculus is enough to start; where something is missing there is a link back to exactly that topic.
- **You do not need to do it all at once.** 20–30 minutes a day is enough. Mark a unit as learned and come back to where you left off.
- **Mistakes are private.** Answers are folded away, so try first and then check.

By the end of this path you will read response graphs, tell whether a system is stable, and set up a PID controller for a motor or an oven for a reason, not by guessing.

## How to study well {#how-to-use}

1. **Read the outcomes first** so you know what you should be able to do at the end.
2. **Work the examples with pen and paper.** Skimming does not make it stick.
3. **Play with the interactive labs.** Change a value, but guess first how the graph will move.
4. **Try the exercises before opening the answers.** Finding out where you went wrong is when you learn most.
5. **Mark the unit as learned.** Progress is kept in your browser only.

## What you should know first {#prerequisites}

- Basic calculus and [differential equations](/learn/differential-equations/) (Thai)
- Basic [DC circuits](/learn/dc-circuits/) (Thai)

If these are not solid yet, that is fine. Start anyway, and follow the links back whenever something is unclear.

## Read it alongside a textbook {#textbooks}

The order of topics and the notation follow the standard control textbooks, such as K. Ogata's *Modern Control Engineering* and *System Dynamics*, so you can read them side by side. All explanations, examples, problems and figures here are written from scratch, not copied or translated from any book.
