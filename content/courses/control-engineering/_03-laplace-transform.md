## ทำไมต้องแปลง {#why}

สมการเชิงอนุพันธ์ของพลานต์แก้ตรงๆ ได้ แต่ทุกครั้งต้องเดาคำตอบ จัดค่าคงที่ และจัดการเงื่อนไขเริ่มต้น

การแปลงลาปลาซทำให้ **การหาอนุพันธ์เป็นการคูณด้วย $s$** สมการเชิงอนุพันธ์จึงกลายเป็นสมการพีชคณิต และเงื่อนไขเริ่มต้นเข้าไปอยู่ในสมการตั้งแต่ต้น

ที่สำคัญกว่านั้น มันให้**ฟังก์ชันถ่ายโอน** ซึ่งเป็นภาษากลางของวิชานี้ และเชื่อมเวลากับระนาบ $s$ ที่เราสร้างในหน่วยที่ 2

## นิยาม {#definition}

การแปลงลาปลาซ (ด้านเดียว) ของ $f(t)$ ที่ $t \ge 0$ คือ

$$F(s) = \mathcal{L}\{f(t)\} = \int_{0^-}^{\infty} f(t)\,e^{-st}\,dt, \qquad s = \sigma + j\omega$$

เราใช้ขอบล่าง $0^-$ เพื่อให้ครอบคลุมอิมพัลส์ที่ $t = 0$ และเงื่อนไขเริ่มต้นก่อนเริ่มสวิตช์

เพราะ $e^{-st} = e^{-\sigma t}e^{-j\omega t}$ ตัวคูณ $e^{-\sigma t}$ ช่วยกดฟังก์ชันที่โตแบบเอกซ์โพเนนเชียลให้อินทิกรัลลู่เข้าได้ ถ้า $\sigma$ มากพอ

### การมีอยู่และบริเวณลู่เข้า (ROC)

ถ้ามีค่าคงที่ $M$ และ $\alpha$ ที่ทำให้ $\lvert f(t)\rvert \le M e^{\alpha t}$ สำหรับ $t \ge 0$ (เรียกว่า **อันดับเอกซ์โพเนนเชียล**) แล้วอินทิกรัลลู่เข้าสำหรับ

$$\operatorname{Re}\,s > \alpha$$

นี่คือ **บริเวณลู่เข้า (region of convergence, ROC)** ซึ่งเป็นครึ่งระนาบทางขวาของเส้นดิ่ง

ฟังก์ชัน $e^{t^2}$ โตเร็วกว่าเอกซ์โพเนนเชียลทุกตัว จึงไม่มีการแปลงลาปลาซ

:::note ROC กับขั้ว
สำหรับสัญญาณที่เริ่มที่ $t=0$ ROC คือทางขวาของขั้วขวาสุดของ $F(s)$ เสมอ ในงานควบคุมเรามักใช้ $F(s)$ โดยไม่ระบุ ROC เพราะเรารู้ว่าเป็นด้านขวา
:::

## คู่การแปลงพื้นฐานจากนิยาม {#pairs}

**ขั้นบันได $f = 1$**

$$F(s) = \int_0^\infty e^{-st}dt = \left[-\frac{e^{-st}}{s}\right]_0^\infty = \frac{1}{s}, \qquad \operatorname{Re}\,s > 0$$

**เอกซ์โพเนนเชียล $f = e^{-at}$**

$$F(s) = \int_0^\infty e^{-(s+a)t}dt = \frac{1}{s + a}, \qquad \operatorname{Re}\,s > -a$$

**อิมพัลส์ $\delta(t)$** สมบัติการคัดค่าของอิมพัลส์ให้ $\mathcal{L}\{\delta\} = 1$

**แรมป์ $f = t$** อินทิกรัลโดยส่วนให้ $\dfrac{1}{s^2}$ (ตรวจในภายหลังด้วยสมบัติ)

**ไซน์และไคโคไซน์** เขียน $\sin\omega t = \dfrac{e^{j\omega t} - e^{-j\omega t}}{2j}$ แล้วใช้เอกซ์โพเนนเชียลกับ $a = \mp j\omega$

$$\mathcal{L}\{\sin\omega t\} = \frac{1}{2j}\left(\frac{1}{s - j\omega} - \frac{1}{s + j\omega}\right) = \frac{\omega}{s^2 + \omega^2}$$

$$\mathcal{L}\{\cos\omega t\} = \frac{1}{2}\left(\frac{1}{s - j\omega} + \frac{1}{s + j\omega}\right) = \frac{s}{s^2 + \omega^2}$$

| $f(t)$ | $F(s)$ |
|---|---|
| $\delta(t)$ | $1$ |
| $1$ | $\dfrac{1}{s}$ |
| $t$ | $\dfrac{1}{s^2}$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ |
| $e^{-at}$ | $\dfrac{1}{s + a}$ |
| $\sin\omega t$ | $\dfrac{\omega}{s^2 + \omega^2}$ |
| $\cos\omega t$ | $\dfrac{s}{s^2 + \omega^2}$ |

สังเกตว่าขั้วของ $F(s)$ ในตารางคือรูปแบบของ $f(t)$ ที่เรียนในหน่วยที่ 2 ขั้วที่ $-a$ ให้ $e^{-at}$ และขั้วที่ $\pm j\omega$ ให้การแกว่งคงที่

## สมบัติที่ใช้ตลอดวิชา {#properties}

ให้ $\mathcal{L}\{f\} = F(s)$ และ $\mathcal{L}\{g\} = G(s)$

| สมบัติ | สูตร |
|---|---|
| เชิงเส้น | $\mathcal{L}\{af + bg\} = aF + bG$ |
| อนุพันธ์ | $\mathcal{L}\{f'\} = sF(s) - f(0^-)$ |
| อนุพันธ์อันดับสอง | $\mathcal{L}\{f''\} = s^2F(s) - sf(0^-) - f'(0^-)$ |
| อินทิกรัล | $\mathcal{L}\left\{\int_0^t f\,d\tau\right\} = \dfrac{F(s)}{s}$ |
| เลื่อนใน $s$ | $\mathcal{L}\{e^{-at}f(t)\} = F(s + a)$ |
| เลื่อนใน $t$ | $\mathcal{L}\{f(t - T)\,1(t - T)\} = e^{-sT}F(s)$ |
| คูณด้วย $t$ | $\mathcal{L}\{t f(t)\} = -\dfrac{dF}{ds}$ |
| คอนโวลูชัน | $\mathcal{L}\{f * g\} = F(s)\,G(s)$ |

**ที่มาของสมบัติอนุพันธ์** อินทิกรัลโดยส่วน

$$\int_0^\infty f'(t)e^{-st}dt = \left[f e^{-st}\right]_0^\infty + s\int_0^\infty f e^{-st}dt = -f(0) + sF(s)$$

ภายในบริเวณลู่เข้า พจน์ที่ $t \to \infty$ เป็นศูนย์

:::example ตัวอย่างที่ 3.1: ใช้การเลื่อนใน s
หา $\mathcal{L}\{e^{-2t}\cos 3t\}$

เริ่มจาก $\mathcal{L}\{\cos 3t\} = \dfrac{s}{s^2 + 9}$ แล้วแทน $s \to s + 2$

$$\mathcal{L}\{e^{-2t}\cos 3t\} = \frac{s + 2}{(s + 2)^2 + 9}$$

ขั้วอยู่ที่ $s = -2 \pm j3$ ตรงกับการแกว่งที่ลดลงด้วยอัตรา 2
:::

:::example ตัวอย่างที่ 3.2: ใช้การเลื่อนใน t
หา $\mathcal{L}$ ของแรมป์ที่เริ่มที่ $t = 2$ คือ $f(t) = (t - 2)\,1(t - 2)$

ตามสมบัติ ได้ $e^{-2s}\cdot\mathcal{L}\{t\} = \dfrac{e^{-2s}}{s^2}$

ดีเลย์ $T$ วินาทีในเวลาคือตัวคูณ $e^{-sT}$ ในโดเมน $s$ ซึ่งไม่ใช่ฟังก์ชันตรรกยะ เรื่องนี้เป็นที่มาของ $e^{-sT}$ ในระบบที่มีเวลาหน่วง
:::

## ทฤษฎีบทค่าเริ่มต้นและค่าสุดท้าย {#ivt-fvt}

ทฤษฎีบทสองข้อนี้ให้ค่าของ $f(t)$ ที่ปลายทั้งสองโดยไม่ต้องแปลงกลับ

$$\textbf{ค่าเริ่มต้น:}\quad f(0^+) = \lim_{s\to\infty} sF(s)$$

$$\textbf{ค่าสุดท้าย:}\quad \lim_{t\to\infty} f(t) = \lim_{s\to 0} sF(s)$$

ที่มา ใช้สมบัติอนุพันธ์ $sF(s) - f(0) = \int_0^\infty f'(t)e^{-st}dt$ แล้วให้ $s \to \infty$ (ด้านขวาเป็นศูนย์) หรือ $s \to 0$ (ด้านขวาเป็น $f(\infty) - f(0)$)

:::warn ทฤษฎีบทค่าสุดท้ายมีเงื่อนไข
ใช้ได้ต่อเมื่อ **$sF(s)$ มีขั้วทั้งหมดอยู่ทางซ้ายของแกน $j\omega$ อย่างเข้มงวด** (หรือที่ $s = 0$ ที่ถูกตัดไปแล้ว) ถ้ามีขั้วบนแกน $j\omega$ หรือด้านขวา สูตรอาจให้ค่าที่ไม่มีความหมาย

ตัวอย่าง $f = \sin t$ ให้ $F = \dfrac{1}{s^2 + 1}$ และ $\lim_{s\to 0} sF = 0$ แต่ $\sin t$ ไม่ลู่เข้าสู่ค่าใดเลย
:::

## การแก้สมการเชิงอนุพันธ์ด้วยลาปลาซ {#ode}

ขั้นตอนมีสามขั้น แปลงสมการ แก้พีชคณิตหา $Y(s)$ แล้วแปลงกลับ

:::example ตัวอย่างที่ 3.3
แก้ $\ddot y + 3\dot y + 2y = u(t)$ เมื่อ $u$ เป็นขั้นบันไดหนึ่งหน่วย $y(0) = 1,\ \dot y(0) = 0$

**แปลงทั้งสองข้าง**

$$\left(s^2 Y - s\cdot 1 - 0\right) + 3\left(sY - 1\right) + 2Y = \frac{1}{s}$$

**แก้หา $Y$**

$$Y(s)\,(s^2 + 3s + 2) = s + 3 + \frac{1}{s} = \frac{s^2 + 3s + 1}{s}$$

$$Y(s) = \frac{s^2 + 3s + 1}{s(s+1)(s+2)}$$

**เศษส่วนย่อย** ได้ $Y = \dfrac{1/2}{s} + \dfrac{1}{s + 1} - \dfrac{1/2}{s + 2}$

**แปลงกลับ**

$$y(t) = \tfrac12 + e^{-t} - \tfrac12 e^{-2t}$$

ตรวจ $y(0) = 0.5 + 1 - 0.5 = 1$ ✓ และ $\dot y(0) = -1 + 1 = 0$ ✓

**ตรวจด้วยทฤษฎีบท** $\lim_{s\to\infty} sY = 1 = y(0)$ ✓ และ $\lim_{s\to 0}sY = \tfrac12 = y(\infty)$ ✓ ซึ่งขั้ว $0,-1,-2$ เข้าเงื่อนไข
:::

สังเกตเทอมที่มาจากสองแหล่ง ส่วนที่ขึ้นกับเงื่อนไขเริ่มต้น $(s+3)/(s^2+3s+2)$ คือ **ผลตอบสนองอินพุตศูนย์** และส่วนที่ขึ้นกับอินพุต $\dfrac{1}{s(s^2+3s+2)}$ คือ **ผลตอบสนองสถานะศูนย์** ระบบเชิงเส้นรวมกันได้ตรงๆ

## จากลาปลาซสู่ฟังก์ชันถ่ายโอน {#tf}

ถ้าเงื่อนไขเริ่มต้นเป็นศูนย์ทั้งหมด ในตัวอย่าง 3.3 จะได้

$$\frac{Y(s)}{U(s)} = \frac{1}{s^2 + 3s + 2}$$

นี่คือ **ฟังก์ชันถ่ายโอน (transfer function)** อัตราส่วนของการแปลงลาปลาซของเอาต์พุตต่ออินพุตเมื่อเงื่อนไขเริ่มต้นเป็นศูนย์

มันขึ้นกับระบบอย่างเดียว ไม่ขึ้นกับอินพุต รากของตัวส่วนคือขั้ว และเป็นตัวกำหนดรูปแบบของผลตอบสนองทั้งหมด หน่วยที่ 5 ต่อเรื่องนี้

:::example ตัวอย่างที่ 3.4: วงจร RC
วงจร RC อนุกรม อินพุตคือแรงดัน $v_i$ เอาต์พุตคือแรงดันตกคร่อมตัวเก็บประจุ $v_o$ กฎของเคอร์ชอฟฟ์ได้ $RC\,\dot v_o + v_o = v_i$

แปลงลาปลาซโดย $v_o(0) = 0$

$$RC\,s V_o + V_o = V_i \;\Longrightarrow\; \frac{V_o}{V_i} = \frac{1}{RCs + 1}$$

เป็นระบบอันดับหนึ่ง ขั้วที่ $s = -1/(RC)$ ค่าคงตัวเวลา $\tau = RC$
:::

## แบบฝึกหัด {#exercises}

:::exercise แบบฝึกหัด 3.1 ใช้สมบัติ
หา (ก) $\mathcal{L}\{t e^{-3t}\}$ (ข) $\mathcal{L}\{5 - 2e^{-4t} + \sin 2t\}$ (ค) $\mathcal{L}\{e^{-t}\sin 2t\}$

:::answer ดูเฉลย
(ก) $\mathcal{L}\{t\} = 1/s^2$ แล้วเลื่อน $s \to s+3$ ได้ $\dfrac{1}{(s+3)^2}$

(ข) เชิงเส้น: $\dfrac{5}{s} - \dfrac{2}{s + 4} + \dfrac{2}{s^2 + 4}$

(ค) $\dfrac{2}{(s+1)^2 + 4}$
:::
:::

:::exercise แบบฝึกหัด 3.2 แก้สมการอันดับหนึ่ง
แก้ $\dot y + 4y = 8$ (ขั้นบันไดขนาด 8) เมื่อ $y(0) = 1$

:::answer ดูเฉลย
$sY - 1 + 4Y = 8/s$ ได้ $Y = \dfrac{s + 8}{s(s+4)} = \dfrac{2}{s} - \dfrac{1}{s + 4}$

$$y(t) = 2 - e^{-4t}$$

ตรวจ $y(0) = 1$ ✓ ค่าสุดท้าย 2 และค่าคงตัวเวลา $1/4$ s
:::
:::

:::exercise แบบฝึกหัด 3.3 ค่าเริ่มต้นและค่าสุดท้าย
$F(s) = \dfrac{10}{s(s+2)}$ หา $f(0^+)$ และ $f(\infty)$ โดยไม่แปลงกลับ แล้วตรวจเงื่อนไข

:::answer ดูเฉลย
$f(0^+) = \lim_{s\to\infty} \dfrac{10}{s+2} = 0$

$f(\infty) = \lim_{s\to 0}\dfrac{10}{s+2} = 5$

$sF(s) = \dfrac{10}{s+2}$ มีขั้วเดียวที่ $-2$ อยู่ซ้ายอย่างเข้มงวด ใช้ทฤษฎีบทได้ ตรวจ: $f(t) = 5(1 - e^{-2t})$ ✓
:::
:::

:::exercise แบบฝึกหัด 3.4 พัลส์สี่เหลี่ยม
สัญญาณเป็นพัลส์สูง 1 เริ่มที่ $t=1$ จบที่ $t=3$ เขียนเป็นผลต่างของขั้นบันไดสองตัวแล้วหา $F(s)$

:::answer ดูเฉลย
$f(t) = 1(t-1) - 1(t-3)$

$$F(s) = \frac{e^{-s} - e^{-3s}}{s}$$
:::
:::

:::exercise แบบฝึกหัด 3.5 คูณด้วย t (ระดับสูง)
แสดงว่า $\mathcal{L}\{t\sin\omega t\} = \dfrac{2\omega s}{(s^2 + \omega^2)^2}$

:::answer ดูเฉลย
ใช้ $\mathcal{L}\{tf\} = -F'(s)$ กับ $F = \dfrac{\omega}{s^2 + \omega^2}$

$$-\frac{d}{ds}\frac{\omega}{s^2 + \omega^2} = \frac{\omega\cdot 2s}{(s^2 + \omega^2)^2}$$
:::
:::

:::exercise แบบฝึกหัด 3.6 คอนโวลูชัน (ระดับสูง)
หา $e^{-t} * e^{-2t}$ จากนิยามคอนโวลูชัน แล้วตรวจด้วยการแปลงลาปลาซ

:::answer ดูเฉลย
$$\int_0^t e^{-\tau}e^{-2(t-\tau)}d\tau = e^{-2t}\int_0^t e^{\tau}d\tau = e^{-2t}(e^{t} - 1) = e^{-t} - e^{-2t}$$

ลาปลาซ: $\dfrac{1}{s+1} - \dfrac{1}{s+2} = \dfrac{1}{(s+1)(s+2)}$ ซึ่งเท่ากับผลคูณ $\dfrac{1}{s+1}\cdot\dfrac{1}{s+2}$ ✓
:::

:::exercise แบบฝึกหัด 3.7 การมีอยู่ (ระดับสูง)
$e^{t^2}$ มีการแปลงลาปลาซหรือไม่ และ $e^{5t}$ มี ROC เป็นอย่างไร

:::answer ดูเฉลย
$e^{t^2}$ ไม่มี เพราะ $e^{t^2}e^{-\sigma t}$ ไม่ลู่เข้าไม่ว่า $\sigma$ จะมากเท่าใด (โตเร็วกว่าเอกซ์โพเนนเชียลทุกตัว)

$e^{5t}$ ได้ $\dfrac{1}{s - 5}$ ที่ $\operatorname{Re}\,s > 5$ ขั้วอยู่ทางขวา ระบบที่มีขั้วนี้ไม่เสถียร
:::
:::

## สรุป {#summary}

- ลาปลาซเปลี่ยนอนุพันธ์เป็นการคูณด้วย $s$ และสมการเชิงอนุพันธ์เป็นพีชคณิต
- ROC ของสัญญาณที่เริ่มที่ $t = 0$ คือทางขวาของขั้วขวาสุด
- สมบัติหลักคือ เชิงเส้น อนุพันธ์ เลื่อน $s$ เลื่อน $t$ และคอนโวลูชัน
- ทฤษฎีบทค่าสุดท้ายใช้ได้เมื่อขั้วของ $sF(s)$ อยู่ซ้ายอย่างเข้มงวดเท่านั้น
- ฟังก์ชันถ่ายโอนคืออัตราส่วน $Y/U$ เมื่อเงื่อนไขเริ่มต้นเป็นศูนย์

**หน่วยถัดไป** การแปลงลาปลาซผกผัน ด้วยเศษส่วนย่อยและเรซิดิว
