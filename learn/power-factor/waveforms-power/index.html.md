> มองเพาเวอร์แฟกเตอร์ผ่านรูปคลื่นจริง: แรงดัน v(t) กระแส i(t) ที่ตามหลังมุม φ คูณกันทีละจุดได้กำลังขณะหนึ่ง p(t) ที่แกว่งด้วยความถี่สองเท่า ค่าเฉลี่ยคือ P = VI cos φ ช่วงที่ p ติดลบคือโหลดคืนพลังงาน แยก p(t) เป็นส่วนกำลังจริงและส่วนรีแอกทีฟ Q คือแอมพลิจูดของการไหลไปกลับ พลังงานที่เก็บในตัวเหนี่ยวนำ เวลาที่กระแสตามหลัง และเฟสเซอร์หมุน พร้อมซิมูเลเตอร์ภาพเคลื่อนไหว

# เพาเวอร์แฟกเตอร์ในรูปคลื่น: กำลังขณะหนึ่ง p(t) กำลังไหลกลับ เฟสเซอร์ และความหมายของกำลังรีแอกทีฟ

// บทที่ 19.2 · เพาเวอร์แฟกเตอร์ · Power Factor in Waveforms & Phasors


สามเหลี่ยมกำลังบอก “ผล” แต่รูปคลื่นบอก “สิ่งที่เกิดขึ้นจริง” ในทุกเสี้ยววินาที เมื่อคูณแรงดันกับกระแสทีละจุด เราจะเห็นว่ากำลังไม่ได้ไหลทางเดียวเสมอ บางช่วงโหลดส่งพลังงานกลับ — และนั่นคือที่มาของคำว่า “กำลังรีแอกทีฟ”

สรุปใน 30 วินาที

- $p(t) = VI\cos\varphi - VI\cos(2\omega t - \varphi)$: ค่าคงที่ + แกว่ง 100 Hz

- ค่าเฉลี่ยของ p(t) คือ $P = VI\cos\varphi$ — นี่คือที่มาของ cos φ

- p(t) < 0 เป็นสัดส่วน φ/180° ของเวลา: พลังงานไหลกลับ

- Q = แอมพลิจูดของส่วนที่ไหลไปกลับ = 2ω × พลังงานเฉลี่ยที่เก็บในสนาม

## กำลังขณะหนึ่ง p(t) กลาง

W1 Voltage and lagging current แรงดันและกระแสที่ตามหลัง

$$v(t) = \sqrt2\,V\sin\omega t \qquad i(t) = \sqrt2\,I\sin(\omega t - \varphi)$$

W2 Instantaneous power กำลังขณะหนึ่ง

$$p(t) = v(t)\,i(t) = 2VI\sin\omega t\,\sin(\omega t-\varphi) = VI\cos\varphi - VI\cos(2\omega t - \varphi)$$

ใช้เอกลักษณ์ $2\sin A\sin B = \cos(A-B) - \cos(A+B)$ (สูตรตรีโกณ) ผลคือเทอมคงที่ $VI\cos\varphi$ บวกกับคลื่นโคไซน์ความถี่ $2\omega$ ที่มีแอมพลิจูด $VI$ (= S)

W3 Average (real) power กำลังเฉลี่ย

$$P = \frac1T\int_0^T p(t)\,dt = VI\cos\varphi$$

เพราะค่าเฉลี่ยของ $\cos(2\omega t-\varphi)$ ตลอดคาบเป็นศูนย์ (อินทิกรัล) นี่คือเหตุผลที่ cos φ ปรากฏในสูตรกำลัง — ไม่ได้มาจากการท่องจำ แต่มาจากการเฉลี่ยผลคูณของสองไซน์

W7 Fraction of time with p < 0 สัดส่วนเวลาที่กำลังไหลกลับ

$$\frac{t_{p<0}}{T} = \frac{\varphi}{180^\circ} \qquad p_{min} = VI(\cos\varphi - 1),\ \ p_{max} = VI(\cos\varphi + 1)$$

ตัวอย่าง W-1

### มอเตอร์ 230 V 15.05 A φ = 34.6°

- W3: $P = 230(15.05)\cos 34.6^\circ = 3461(0.823) = 2.85$ kW

- W7: $p_{max} = 3461(1.823) = 6.31$ kW · $p_{min} = 3461(0.823 - 1) = -0.61$ kW

- สัดส่วนเวลาที่ไหลกลับ $34.6/180 = 19\,\%$ — ช่วงสีแดงในกราฟซิมูเลเตอร์

- W6: กระแสถึงยอดช้ากว่าแรงดัน $\Delta t = 34.6/360 \times 20\ \text{ms} = 1.92$ ms

W6 Time shift เวลาที่กระแสตามหลัง

$$\Delta t = \frac{\varphi}{360^\circ}\,T = \frac{\varphi}{360^\circ\,f}$$

## แยก p(t) เป็นส่วนที่ทำงานกับส่วนที่ไหลไปกลับ ขั้นสูง

W4 Active and reactive parts of p(t) แยกส่วนจริงและส่วนรีแอกทีฟ

$$p(t) = \underbrace{P\,(1 - \cos 2\omega t)}_{\ge 0\ \text{เสมอ: ไหลทางเดียว}} \;-\; \underbrace{Q\,\sin 2\omega t}_{\text{ค่าเฉลี่ย } 0:\ \text{ไหลไปกลับ}}$$

ส่วนแรกเป็นบวกเสมอ — พลังงานไหลไปที่โหลดแล้วไม่กลับมา (กลายเป็นงานหรือความร้อน) ส่วนที่สองแกว่งรอบศูนย์ มีแอมพลิจูดเท่ากับ Q พอดี นี่คือนิยามทางกายภาพของกำลังรีแอกทีฟ: อัตราสูงสุดที่พลังงานวิ่งไปกลับระหว่างแหล่งจ่ายกับโหลด

W5 Q and stored energy Q กับพลังงานที่เก็บในสนาม

$$w_L(t) = \tfrac12 L\,i^2(t) \qquad \bar W_L = \tfrac12 L I^2 \qquad Q_L = \omega L I^2 = 2\omega\,\bar W_L$$

ตัวอย่าง W-2

### Q = 1.96 kvar ที่ 50 Hz เก็บพลังงานในสนามแม่เหล็กเท่าไร

- W5: $\bar W = Q/(2\omega) = 1960/(2 \times 314.16) = 3.12$ J

- พลังงานแค่ 3 จูล แต่ถูกเติมและถอนออก 100 ครั้งต่อวินาที อัตราการไหลสูงสุดจึงเป็นหลักกิโลวาร์

- คาปาซิเตอร์ที่อยู่ข้างมอเตอร์เก็บพลังงานในสนามไฟฟ้า $\tfrac12Cv^2$ ในจังหวะตรงข้ามกัน (เมื่อขดลวดคายพลังงาน คาปาซิเตอร์รับ) พลังงานจึงวิ่งไปกลับระหว่างสองตัวนี้ในพื้นที่ แทนที่จะวิ่งผ่านสายยาวไปถึงโรงไฟฟ้า

## เฟสเซอร์หมุน: มองคลื่นเป็นเงา กลาง

เฟสเซอร์คือลูกศรที่หมุนทวนเข็มนาฬิกาด้วยความเร็ว ω ค่าขณะหนึ่งของไซน์คือ “เงา” ของปลายลูกศรบนแกนตั้ง แรงดันและกระแสหมุนด้วยความเร็วเท่ากัน มุมระหว่างสองลูกศรจึงคงที่เป็น φ เราจึงวาดหยุดนิ่งได้ (V บนแกนจริง) แล้วแยกกระแสเป็นสองส่วน:

W8 Active and reactive current กระแสส่วนทำงานและส่วนรีแอกทีฟ

$$I_P = I\cos\varphi \ \ (\text{ตรงเฟสกับ } V) \qquad I_Q = I\sin\varphi \ \ (\text{ตั้งฉากกับ } V) \qquad I = \sqrt{I_P^2 + I_Q^2}$$

คาปาซิเตอร์แก้ได้เฉพาะ $I_Q$ (ใส่กระแสนำหน้าที่หักล้างกัน) ส่วน $I_P$ คืองานที่โหลดต้องการจริง ไม่มีใครลดได้ถ้าไม่ลดงาน — ในซิมูเลเตอร์ด้านล่าง ลูกศรสีเหลืองคือ $I_P$ สังเกตว่ามันยาวเท่าเดิมเมื่อเปิดคาปาซิเตอร์

## ซิมูเลเตอร์ภาพเคลื่อนไหว

กด ▶ เล่น: เส้นประแนวตั้งวิ่งตามเวลา ค่า v i p ใต้กราฟเปลี่ยนตามจริง และเฟสเซอร์หมุนพร้อมกัน ลองเปลี่ยนเป็น “ฮีตเตอร์ล้วน” (p ไม่เคยติดลบ) และ “ชดเชยเกิน” (กระแสนำหน้า p ติดลบอีกครั้ง)

## คำถามที่พบบ่อย

ทำไมกำลังขณะหนึ่ง p(t) มีความถี่ 100 Hz?
เพราะ p(t) คือผลคูณของแรงดันและกระแสที่เป็นไซน์ 50 Hz ทั้งคู่ ผลคูณของไซน์สองตัวตามเอกลักษณ์ตรีโกณมิติให้ค่าคงที่บวกกับไซน์ความถี่สองเท่า กำลังจึงเต้นขึ้นลง 100 ครั้งต่อวินาที ค่าคงที่คือกำลังเฉลี่ย P

กำลังรีแอกทีฟ Q มีอยู่จริงไหม?
มีในความหมายว่าพลังงานไหลไปกลับจริงระหว่างแหล่งจ่ายกับสนามแม่เหล็กหรือสนามไฟฟ้าของโหลด Q คือแอมพลิจูดของส่วนที่ไหลไปกลับนั้น ค่าเฉลี่ยของมันเป็นศูนย์ จึงไม่ทำงานสุทธิ แต่กระแสที่ทำให้เกิดการไหลนี้ทำให้สายร้อนจริง
