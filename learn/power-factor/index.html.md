# เพาเวอร์แฟกเตอร์ (Power Factor) เข้าใจได้ทุกระดับ

// บทที่ 17 · Power Factor Explained · ทุกระดับ: ทั่วไป → ช่าง → วิศวกร


เพาเวอร์แฟกเตอร์ (PF) เป็นเรื่องที่เกือบทุกคนในวงการไฟฟ้าเคยได้ยิน แต่น้อยคนอธิบายได้ว่า “กำลังที่ไม่ทำงาน” ไปอยู่ที่ไหน ทำไมคาปาซิเตอร์แก้ได้ และทำไมบางครั้งแก้ไม่ได้ ชุดนี้อธิบายสามระดับคู่กันเสมอ — ภาพเปรียบเทียบ ตัวเลขที่ใช้งาน และคณิตศาสตร์เบื้องหลัง — พร้อมซิมูเลเตอร์ที่เห็นกระแสไหลไปกลับจริง ๆ มี 47 สูตรที่มีรหัสอ้างอิง และ 15 ตัวอย่างคำนวณ

สรุปใน 30 วินาที

- P (kW) ทำงานจริง · Q (kvar) วิ่งไปกลับเติมสนามแม่เหล็ก/ไฟฟ้า · S (kVA) ที่สายต้องแบก · $S^2 = P^2 + Q^2$

- $PF = P/S = \cos\varphi$ เมื่อกระแสเป็นไซน์ · มอเตอร์ทำให้กระแส “ตามหลัง” แรงดัน

- PF ต่ำ → กระแสสูง สายร้อน (∝ 1/PF²) แรงดันตก หม้อแปลงเต็มเร็ว และค่าปรับ kvar

- คาปาซิเตอร์จ่าย Q ให้มอเตอร์ในพื้นที่: $Q_c = P(\tan\varphi_1 - \tan\varphi_2)$

- โหลดอิเล็กทรอนิกส์มี PF ต่ำจากฮาร์มอนิก — คาปาซิเตอร์แก้ส่วนนี้ไม่ได้

## อ่านตามระดับที่คุณต้องการ

ระดับ 1 · ไม่ต้องใช้สูตร

### เข้าใจด้วยภาพ
แก้วเบียร์ ม้าลากเรือ ชิงช้า แล้วดูซิมูเลเตอร์ว่ากระแสไหลไปกลับจริง
PF คืออะไร → ซิมูเลเตอร์

ระดับ 2 · ช่าง · เจ้าของกิจการ

### ใช้ตัวเลขให้เป็น
kW kvar kVA บนบิลและมิเตอร์ ขนาดคาปาซิเตอร์ ตู้อัตโนมัติ ค่าปรับ ระยะคืนทุน
คำนวณคาปาซิเตอร์ → ตู้คาปาซิเตอร์ → ค่าปรับ kvar

ระดับ 3 · นักศึกษา · วิศวกร

### คณิตศาสตร์และฟิสิกส์
p(t) = v·i, เฟสเซอร์ S = VI*, DPF × distortion factor, เรโซแนนซ์ $h = \sqrt{S_{sc}/Q_c}$
รูปคลื่น → ฮาร์มอนิก → การวัด

## ลองเลย: มอเตอร์ปั๊มน้ำกับคาปาซิเตอร์

กด ▶ เล่น แล้วดูเส้นสีม่วง p(t) — ช่วงสีแดงคือเวลาที่มอเตอร์ “คืน” พลังงานกลับไปที่แหล่งจ่าย จากนั้นกดคาปาซิเตอร์ C1 C2 C3 ทีละขั้น สังเกตว่ากระแสลดลง พื้นที่สีแดงหายไป แต่ P (kW) เท่าเดิม ลองโหลดอื่นในแล็บเต็มที่ ซิมูเลเตอร์ PF

## ความเชื่อผิด ๆ ที่พบบ่อย

| ความเชื่อ | ความจริง |

| “กล่องประหยัดไฟเสียบปลั๊กแก้ PF แล้วค่าไฟบ้านลด 30 %” | บ้านคิดเงินตาม kWh (P) ไม่ใช่ kVA การแก้ PF ลดกระแสในสายบ้านเล็กน้อยเท่านั้น ผลต่อค่าไฟน้อยมาก |

| “Q คือพลังงานที่เสียไปเปล่า ๆ” | Q ไม่ได้ถูกใช้หมดไป มันวิ่งไปกลับ สิ่งที่เสียจริงคือความร้อน I²R จากกระแสส่วนเกินที่ Q ทำให้เกิด |

| “ใส่คาปาซิเตอร์ยิ่งมากยิ่งดี” | เกินจะกลายเป็น PF นำหน้า กระแสกลับมาสูงขึ้น แรงดันเพิ่ม และเสี่ยงเรโซแนนซ์ |

| “cos φ = PF เสมอ” | จริงเฉพาะกระแสเป็นไซน์ โหลดอิเล็กทรอนิกส์มี cos φ ≈ 1 แต่ PF จริงอาจแค่ 0.6 |

| “PF ต่ำทำให้มิเตอร์บ้านหมุนเร็วขึ้น” | มิเตอร์ kWh วัดเฉพาะ P มิเตอร์จะหมุนเพิ่มเฉพาะการสูญเสียในสายที่อยู่หลังมิเตอร์ ซึ่งน้อย |

## คำถามที่พบบ่อย

เพาเวอร์แฟกเตอร์คืออะไรแบบเข้าใจง่ายที่สุด?
คือสัดส่วนของไฟฟ้าที่ทำงานจริง (kW) เทียบกับไฟฟ้าทั้งหมดที่สายไฟต้องส่ง (kVA) เหมือนเบียร์หนึ่งแก้ว ส่วนที่ดื่มได้คือเนื้อเบียร์ (kW) ส่วนฟองคือกำลังรีแอกทีฟ (kvar) แก้วทั้งใบคือ kVA แก้วที่มีฟองมาก ต้องใช้แก้วใหญ่ขึ้นเพื่อได้เบียร์เท่าเดิม PF = 1 คือไม่มีฟองเลย

PF ต่ำเสียหายอย่างไร?
กระแสในสายสูงขึ้นทั้งที่งานเท่าเดิม ทำให้สายร้อนและสูญเสียพลังงานตาม 1/PF² แรงดันตกมากขึ้น หม้อแปลงและสายต้องใหญ่ขึ้น และผู้ใช้ไฟประเภทกิจการขนาดกลางขึ้นไปจะเสียค่าเพาเวอร์แฟกเตอร์เมื่อ kvar เกิน 61.97 % ของ kW ความต้องการสูงสุด (ต่ำกว่า PF 0.85)
