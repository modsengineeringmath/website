# PF จริงกับฮาร์มอนิก: Displacement PF, Distortion PF, THD, เรโซแนนซ์ของคาปาซิเตอร์ และตู้ Detuned

// บทที่ 19.6 · เพาเวอร์แฟกเตอร์ · True Power Factor & Harmonics


ทุกอย่างก่อนหน้านี้สมมติว่ากระแสเป็นไซน์ แต่โหลดสมัยใหม่ส่วนใหญ่ผ่านวงจรเรียงกระแสกับตัวเก็บประจุ กระแสจึงไหลเป็นยอดแหลมเฉพาะช่วงยอดของแรงดัน ตรงนี้เองที่ “cos φ” กับ “PF” แยกทางกัน และคาปาซิเตอร์ที่เคยเป็นพระเอกอาจกลายเป็นตัวปัญหา

สรุปใน 30 วินาที

- $PF = DPF \times DF = \cos\varphi_1/\sqrt{1 + THD_I^2}$

- THD 100 % → PF สูงสุดแค่ 0.707 แม้ cos φ = 1

- คาปาซิเตอร์แก้ได้เฉพาะ DPF · ส่วน DF ต้องแก้ด้วย PFC ตัวเหนี่ยวนำ หรือแอกทีฟฟิลเตอร์

- เรโซแนนซ์ $h_r = \sqrt{S_{sc}/Q_c}$ → ใช้ตู้ detuned 7 % (189 Hz)

## ทำไมกระแสเป็นยอดแหลม พื้นฐาน

อุปกรณ์อิเล็กทรอนิกส์เกือบทุกชนิดเริ่มด้วยไดโอดบริดจ์และตัวเก็บประจุ (วงจรเรียงกระแส) ตัวเก็บประจุจะเติมประจุเฉพาะตอนแรงดันไฟบ้านสูงกว่าแรงดันของมันเอง คือช่วงสั้น ๆ รอบยอดคลื่น กระแสจึงเป็นพัลส์แคบสูง ตรงกลางพัลส์ตรงกับยอดแรงดันพอดี (cos φ₁ ≈ 1) แต่รูปร่างไม่ใช่ไซน์ — แยกด้วย อนุกรมฟูเรียร์ ได้ฮาร์มอนิกคี่ 3 5 7 9 …

H1 RMS current and THD กระแส rms และ THD

$$I_{rms} = \sqrt{\sum_{h=1}^{\infty} I_h^2} = I_1\sqrt{1 + THD_I^2} \qquad THD_I = \frac{\sqrt{\sum_{h\ge2} I_h^2}}{I_1}$$

## PF จริง = DPF × Distortion factor กลาง

H2 True power factor เพาเวอร์แฟกเตอร์จริง (แรงดันเป็นไซน์)

$$PF = \frac{P}{V I_{rms}} = \underbrace{\cos\varphi_1}_{DPF}\times\underbrace{\frac{I_1}{I_{rms}}}_{DF} = \frac{\cos\varphi_1}{\sqrt{1 + THD_I^2}}$$

H3 Power components with distortion กำลังเมื่อมีฮาร์มอนิก

$$S^2 = P^2 + Q_1^2 + D^2 \qquad D = V\sqrt{\sum_{h\ge2} I_h^2} = V I_1\,THD_I$$

H4 Best PF reachable with capacitors only PF สูงสุดที่คาปาซิเตอร์ทำได้

$$PF_{max} = DF = \frac{1}{\sqrt{1 + THD_I^2}} \qquad THD\ 100\,\% \Rightarrow 0.707$$

ตัวอย่าง H-1

### คอมพิวเตอร์ 10 เครื่อง 1.5 kW cos φ₁ = 0.986 THD = 103 %

- H2: $DF = 1/\sqrt{1 + 1.03^2} = 0.697$ → $PF = 0.986 \times 0.697 = 0.687$ (ซิมูเลเตอร์: 0.689)

- H1: $I_1 = 1500/(230 \times 0.986) = 6.61$ A → $I_{rms} = 6.61\sqrt{1 + 1.03^2} = 9.49$ A

- H3: $D = 230 \times 6.61 \times 1.03 = 1.57$ kVA — มากกว่า Q (0.25 kvar) หลายเท่า

- ใส่คาปาซิเตอร์ 0.5 kvar: Q กลายเป็น −0.75 (นำหน้า) PF แย่ลงเป็น 0.655 — ลองปุ่ม “คาปาซิเตอร์ช่วยฮาร์มอนิกไม่ได้” ในซิมูเลเตอร์

## ซิมูเลเตอร์: กระแสยอดแหลมกับเฟสเซอร์ที่ “ดูดี”

สังเกต: เฟสเซอร์ I₁ เกือบตรงกับ V (cos φ ดี) แต่รูปคลื่นกระแสเป็นยอดแหลม และมิเตอร์แสดง THD-I สูง PF จริงต่ำ เพิ่ม “แอร์อินเวอร์เตอร์ (มี PFC)” ลงไปเพื่อดูว่าโหลดที่มีวงจร PFC ต่างกันอย่างไร

## ฮาร์มอนิกที่ 3 กับสายนิวทรัล กลาง

H8 Neutral current from triplen harmonics กระแสนิวทรัลจากฮาร์มอนิกลำดับ 3 6 9

$$I_N \approx 3\sqrt{I_3^2 + I_9^2 + \cdots}\ \ (\text{โหลดเฟสเดียวสมดุลสามเฟส})$$

ฮาร์มอนิกที่ 3 ของสามเฟสมีมุมตรงกัน (เป็นลำดับศูนย์ — องค์ประกอบสมมาตร) จึงบวกกันในสายนิวทรัลแทนที่จะหักล้าง อาคารสำนักงานที่มีคอมพิวเตอร์มากอาจมีกระแสนิวทรัลสูงกว่ากระแสเฟส — ดูการจำลองที่ แล็บฮาร์มอนิก พรีเซ็ต neutral

## เรโซแนนซ์ขนาน: เมื่อคาปาซิเตอร์ขยายฮาร์มอนิก ขั้นสูง

H5 Parallel resonance order อันดับเรโซแนนซ์ขนาน

$$h_r = \sqrt{\frac{S_{sc}}{Q_c}} \approx \sqrt{\frac{S_T}{Q_c\,(\%Z_T/100)}} \qquad f_r = h_r\,f_1$$

มองจากแหล่งกระแสฮาร์มอนิก (ไดรฟ์) อิมพีแดนซ์ของหม้อแปลง (ตัวเหนี่ยวนำ) ขนานกับคาปาซิเตอร์ ที่ $h_r$ อิมพีแดนซ์ขนานสูงมาก กระแสฮาร์มอนิกเล็ก ๆ สร้างแรงดันฮาร์มอนิกใหญ่ และกระแสวนระหว่างหม้อแปลงกับคาปาซิเตอร์ถูกขยายหลายเท่า เมื่อตู้อัตโนมัติสับขั้นเพิ่ม $Q_c$ เพิ่ม $h_r$ ก็เลื่อนลง — ทุกตู้จึงผ่านช่วงอันตรายบางขณะ

ตัวอย่าง H-2

### หม้อแปลง 1,000 kVA 6 % กับตู้ที่สับ 150 / 300 / 450 kvar

- $S_{sc} = 1000/0.06 = 16{,}667$ kVA

- H5: 150 kvar → $h_r = 10.5$ · 300 kvar → $h_r = 7.45$ (ใกล้ 7!) · 450 kvar → $h_r = 6.1$

- โรงงานที่มี VFD ผลิตฮาร์มอนิกที่ 5 และ 7 สูง ตู้ธรรมดา 300 kvar จะขยายฮาร์มอนิกที่ 7 อย่างรุนแรง

## ตู้ Detuned 7 % และ 14 % ขั้นสูง

H6 Detuned tuning frequency ความถี่จูนของตู้ detuned

$$p = \frac{X_L}{X_C} \qquad f_{tune} = \frac{f_1}{\sqrt{p}} \qquad p = 7\,\% \Rightarrow 189\ \text{Hz}\ (h = 3.78),\ \ p = 14\,\% \Rightarrow 134\ \text{Hz}\ (h = 2.67)$$

H7 Capacitor voltage in a detuned branch แรงดันคร่อมคาปาซิเตอร์

$$U_C = \frac{U_N}{1 - p} \qquad Q_{branch} = \frac{Q_{C,rated}}{1-p}\left(\frac{U_N}{U_{C,rated}}\right)^2$$

รีแอกเตอร์อนุกรมทำให้กิ่งคาปาซิเตอร์เป็น “ตัวเหนี่ยวนำ” สำหรับทุกฮาร์มอนิกที่สูงกว่า 189 Hz (h = 5, 7, 11, …) จึงไม่มีเรโซแนนซ์ขนานในช่วงนั้น และยังจำกัดกระแสพุ่งเข้า ข้อแลกเปลี่ยน: แรงดันคร่อมคาปาซิเตอร์สูงขึ้น 7.5 % ต้องใช้คาปาซิเตอร์พิกัด 480–525 V และตู้แพงกว่า ใช้ 14 % เมื่อมีฮาร์มอนิกที่ 3 มาก (อาคารที่มีโหลดเฟสเดียวมาก)

## เลือกวิธีแก้ให้ตรงปัญหา กลาง

| สถานการณ์ | วิธี |

| มอเตอร์ บัลลาสต์ THD ต่ำ (< 10 %) | ตู้คาปาซิเตอร์ธรรมดา |

| มี VFD/อินเวอร์เตอร์ปนอยู่ (THD-I 10–30 %) หรือ THD-U > 3 % | ตู้ detuned 7 % |

| อาคารสำนักงาน โหลดเฟสเดียวมาก | detuned 14 % · สายนิวทรัลใหญ่ขึ้น |

| ฮาร์มอนิกสูงมาก PF แย่จากการบิดเบือน | แอกทีฟฟิลเตอร์ (ชดเชยทั้ง Q และฮาร์มอนิก) · AC/DC choke ที่ไดรฟ์ · ไดรฟ์ 12 พัลส์ หรือ Active Front End |

| ออกแบบอุปกรณ์ใหม่ | ใส่วงจร PFC แบบบูสต์ (บูสต์คอนเวอร์เตอร์) ให้ผ่าน IEC 61000-3-2 |

วัดก่อนแก้เสมอ: ใช้เพาเวอร์อนาไลเซอร์บันทึก THD-I THD-U และสเปกตรัมอย่างน้อยหนึ่งสัปดาห์ (การวัด PF) และทดลองผลของตู้ใน แล็บฮาร์มอนิก พรีเซ็ต detuned

## คำถามที่พบบ่อย

Displacement PF กับ True PF ต่างกันอย่างไร?
Displacement PF (DPF หรือ cos φ₁) คิดเฉพาะมุมระหว่างแรงดันกับกระแสความถี่พื้นฐาน 50 Hz ส่วน True PF คือ P หารด้วย S ที่รวมกระแสฮาร์มอนิกทุกลำดับ ถ้ากระแสเป็นไซน์ ทั้งสองเท่ากัน ถ้ามีฮาร์มอนิก True PF = DPF / √(1 + THD²) ซึ่งต่ำกว่าเสมอ

ทำไมตู้คาปาซิเตอร์ระเบิดหรือฟิวส์ขาดบ่อยในโรงงานที่มีอินเวอร์เตอร์มาก?
คาปาซิเตอร์กับอิมพีแดนซ์ของหม้อแปลงเกิดเรโซแนนซ์ขนานที่อันดับฮาร์มอนิก h = √(S_sc/Q_c) ถ้าตรงหรือใกล้ฮาร์มอนิกที่ 5 หรือ 7 ที่ไดรฟ์ผลิต กระแสฮาร์มอนิกจะถูกขยายหลายเท่า คาปาซิเตอร์ร้อน ฟิวส์ขาด แรงดันเพี้ยน วิธีแก้คือใช้ตู้ detuned ที่มีรีแอกเตอร์อนุกรมให้ความถี่เรโซแนนซ์ต่ำกว่าฮาร์มอนิกที่ 5
