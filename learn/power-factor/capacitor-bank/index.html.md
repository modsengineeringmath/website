# ตู้คาปาซิเตอร์อัตโนมัติ: PF Controller ขั้นสวิตช์ C/k คอนแทกเตอร์ ตัวต้านทานคายประจุ และการบำรุงรักษา

// บทที่ 17.4 · เพาเวอร์แฟกเตอร์ · Automatic Capacitor Banks


โหลดของโรงงานเปลี่ยนตลอดวัน คาปาซิเตอร์ขนาดคงที่จะชดเชยขาดตอนโหลดหนักและเกินตอนโหลดเบา ตู้คาปาซิเตอร์อัตโนมัติแก้ปัญหานี้ด้วยการวัด PF ตลอดเวลาแล้วสับหรือปลดคาปาซิเตอร์ทีละขั้น หน้านี้มีตู้จำลองเสมือนให้ลองตั้งค่าเหมือนกดคอนโทรลเลอร์จริง

สรุปใน 30 วินาที

- ตู้ = CT + PF controller + ฟิวส์/MCCB + คอนแทกเตอร์ AC-6b + คาปาซิเตอร์ + ตัวต้านทานคายประจุ + พัดลม (+ รีแอกเตอร์ถ้า detuned)

- C/k = Q ขั้นเล็กสุด ÷ (√3 V × อัตราส่วน CT) — เกณฑ์ตัดสินใจสับ/ปลด

- แบ่งขั้น 1:1:2:2 หรือ 1:2:4 ได้ระดับละเอียดด้วยคอนแทกเตอร์น้อยตัว

- หน่วงเวลาต่อซ้ำ ≥ เวลาคายประจุ (มักตั้ง 30–60 s)

## ส่วนประกอบของตู้ พื้นฐาน

| อุปกรณ์ | หน้าที่ | ข้อกำหนดที่สำคัญ |

| CT (ที่สายเมน) | ให้คอนโทรลเลอร์วัดกระแสรวมของโรงงาน | ติดต้นทางของตู้คาปาซิเตอร์ (เห็นทั้งโหลดและคาปาซิเตอร์) · เฟสที่ CT ต้องตรงกับที่ตั้งค่าในคอนโทรลเลอร์ |

| PF controller | คำนวณ P Q PF ตัดสินใจสับ/ปลดขั้น แสดงผล แจ้งเตือน | ตั้ง PF เป้า C/k หน่วงเวลา จำนวนขั้น การหมุนเวียน |

| ฟิวส์ NH / MCCB ต่อขั้น | ป้องกันลัดวงจรในขั้น | พิกัด ≈ 1.5–1.8 เท่ากระแสคาปาซิเตอร์ |

| คอนแทกเตอร์ AC-6b | สับ/ปลดขั้น | มีตัวต้านทานจำกัดกระแสพุ่งเข้า |

| คาปาซิเตอร์ (self-healing, IEC 60831) | จ่าย kvar | แรงดันพิกัด 440–480 V สำหรับระบบ 400 V มีอุปกรณ์ตัดเมื่อแรงดันภายในสูง |

| ตัวต้านทานคายประจุ | คายประจุให้ปลอดภัยและพร้อมสับซ้ำ | ≤ 75 V ภายใน 3 นาที (IEC 60831) |

| พัดลมและเทอร์โมสตัท | ระบายความร้อน | คาปาซิเตอร์อายุสั้นลงครึ่งหนึ่งทุก 7–10 °C ที่ร้อนขึ้น |

| รีแอกเตอร์ detuned (ถ้ามี) | กันเรโซแนนซ์ฮาร์มอนิก | p = 7 % (189 Hz) หรือ 14 % (134 Hz) — อ่าน |

## คอนโทรลเลอร์ตัดสินใจอย่างไร กลาง

K1 Reactive power still needed รีแอกทีฟที่ยังขาด

$$\Delta Q = Q_{measured} - P\tan\varphi_{target} \qquad \Delta Q > k_r Q_{step,min} \Rightarrow \text{สับ} \qquad \Delta Q < -k_r Q_{step,min} \Rightarrow \text{ปลด}$$

K2 C/k setting ค่า C/k (แอมป์ด้านทุติยภูมิ)

$$C/k = \frac{Q_{step,min}}{\sqrt3\,V_L\,k_{CT}} \qquad k_{CT} = \frac{I_{p}}{I_{s}}$$

$k_r$ (มักประมาณ 0.6–0.7) กำหนดความกว้างของ “แถบนิ่ง” รอบเป้าหมาย ถ้าแคบเกินไป ขั้นเล็กจะสับไปมา (hunting) คอนโทรลเลอร์ยังหน่วงเวลาก่อนตัดสินใจ (ไม่ตอบสนองโหลดกระชากชั่วครู่) และห้ามสับขั้นเดิมซ้ำจนกว่าคายประจุเสร็จ

ตัวอย่าง K-1

### ตู้ 6 × 25 kvar ระบบ 400 V CT 1000/5

- K2: $C/k = 25{,}000/(\sqrt3 \times 400 \times 200) = 0.18$ A

- ถ้าใช้ CT 2000/5 (k = 400): C/k = 0.09 A — ค่ายิ่งเล็ก คอนโทรลเลอร์ยิ่งต้องวัดละเอียด เลือก CT ให้เหมาะกับกระแสโหลดจริง

- คอนโทรลเลอร์รุ่นใหม่หลายรุ่นวัด C/k อัตโนมัติตอนเริ่มใช้งาน (สับแต่ละขั้นแล้ววัดกระแสที่เปลี่ยน)

## การแบ่งขั้น กลาง

K3 Number of levels จำนวนระดับที่ได้

$$\text{ขั้นเท่ากัน } n\ \text{ขั้น: } n\ \text{ระดับ} \qquad 1{:}2{:}4{:}\dots\ (n\ \text{ขั้น}): 2^n - 1\ \text{ระดับ} \qquad \Delta Q_{res} = Q_{step,min}$$

| รูปแบบ (150 kvar) | ระดับ | ข้อดี | ข้อเสีย |

| 6 × 25 | 6 ระดับ ทีละ 25 | สึกเท่ากัน หมุนเวียนได้ | คอนแทกเตอร์มาก |

| 1:1:2:2 (25 25 50 50) | 6 ระดับ ทีละ 25 | คอนแทกเตอร์ 4 ตัว | สับหลายขั้นพร้อมกันบางครั้ง |

| 1:2:4 (25 50 100) | 7 ระดับ (ถึง 175) | คอนแทกเตอร์น้อยที่สุด | ขั้นใหญ่สับบ่อย กระแสพุ่งเข้าสูง |

## กระแสพุ่งเข้าและการคายประจุ ขั้นสูง

K4 Inrush peak, single bank ค่ายอดกระแสพุ่งเข้า (สับขั้นแรก)

$$\frac{\hat i_{inrush}}{\sqrt2\,I_{C}} \approx \sqrt{\frac{2\,S_{sc}}{Q_c}}$$

เมื่อสับขั้นใหม่ขนานกับขั้นที่มีประจุอยู่แล้ว (back-to-back) อิมพีแดนซ์ระหว่างกันเหลือแค่สายสั้น ๆ ในตู้ กระแสพุ่งเข้าสูงกว่ากรณีแรกมาก นี่คือเหตุผลของคอนแทกเตอร์ AC-6b ที่มีตัวต้านทานต่อก่อน หรือรีแอกเตอร์ (ซึ่งตู้ detuned มีอยู่แล้ว)

K5 Discharge resistor ตัวต้านทานคายประจุ (≤ 75 V ใน t วินาที)

$$R \le \frac{t}{C\,\ln\!\left(\dfrac{\sqrt2\,U_N}{U_R}\right)} \qquad U_R = 75\ \text{V},\ t = 180\ \text{s}$$

ตัวอย่าง K-2

### ขั้น 25 kvar 440 V (137 µF ต่อเฟส Δ) และหม้อแปลง 1,000 kVA 6 %

- K4: $S_{sc} = 1000/0.06 = 16{,}700$ kVA → $\sqrt{2(16{,}700)/25} = 36.5$ เท่าของค่ายอดพิกัด

- K5: $R \le 180/(137\text{e-}6 \times \ln(\sqrt2 \cdot 440/75)) = 180/(137\text{e-}6 \times 2.12) = 620\ \text{k}\Omega$

- ผู้ผลิตมักใส่ตัวต้านทานที่คายเร็วกว่ามาก (เช่น ถึง 50 V ใน 60 s) เพื่อให้คอนโทรลเลอร์สับขั้นเดิมซ้ำได้เร็ว — ค่าหน่วงเวลาต่อซ้ำในคอนโทรลเลอร์ต้องไม่สั้นกว่าเวลาคายประจุ

## ตู้คาปาซิเตอร์จำลองเสมือน: หนึ่งวันของโรงงาน

หน้าจอคอนโทรลเลอร์ด้านบนแสดง cos φ และไฟสถานะของแต่ละขั้น เลื่อนแถบเวลาเพื่อดูว่าขั้นไหนสับอยู่ กราฟด้านล่างเทียบ PF เมื่อไม่มีตู้ (เส้นเทา) กับเมื่อมีตู้ (เส้นน้ำเงิน) พร้อม kvar ที่โหลดต้องการกับที่ตู้จ่าย ลองเปลี่ยนการแบ่งขั้น และลดค่า C/k เหลือ 0.3 แล้วดูจำนวนครั้งที่คอนแทกเตอร์ทำงาน

## บำรุงรักษาและอาการเสีย พื้นฐาน

| รายการ | ความถี่ | วิธี |

| ดูหน้าจอคอนโทรลเลอร์ PF และการแจ้งเตือน | รายสัปดาห์ | บันทึก PF ช่วงพีก |

| วัดกระแสแต่ละขั้นเทียบพิกัด | ทุก 6 เดือน | ลดลงเกิน 10–15 % = คาปาซิเตอร์เสื่อม (ความจุลด) |

| ภาพถ่ายความร้อน ขั้วต่อ ฟิวส์ คอนแทกเตอร์ | ทุก 6–12 เดือน | หาจุดร้อน ขั้วหลวม |

| ทำความสะอาดแผ่นกรองพัดลม | ทุก 3–6 เดือน | อุณหภูมิในตู้สูงทำให้อายุสั้น |

| ตรวจคาปาซิเตอร์บวม รั่ว กลิ่น | ทุกครั้งที่เปิดตู้ | เปลี่ยนทันที |

| อาการ | สาเหตุที่พบบ่อย |

| PF ไม่ขึ้นแม้สับครบทุกขั้น | คาปาซิเตอร์เสื่อม ฟิวส์ขาด ตู้เล็กเกินไปเมื่อโหลดเพิ่ม หรือ CT ติดผิดตำแหน่ง (หลังตู้) |

| คอนโทรลเลอร์แสดง PF แปลก ๆ หรือนำหน้าตลอด | CT ผิดเฟส กลับขั้ว k-l หรือตั้งค่าเฟสอ้างอิงผิด |

| คอนแทกเตอร์สับไปมาถี่ | C/k เล็กเกินไป หน่วงเวลาสั้น โหลดเปลี่ยนเร็ว (เครื่องเชื่อม ลิฟต์) |

| ฟิวส์ขาดบ่อย คาปาซิเตอร์ร้อน | ฮาร์มอนิกและเรโซแนนซ์ — ต้องวัด THD พิจารณาตู้ detuned |

| แรงดันสูงตอนกลางคืน | ขั้นค้าง (คอนแทกเตอร์ติด) หรือมีคาปาซิเตอร์คงที่มากเกิน |

## คำถามที่พบบ่อย

ค่า C/k ของ PF controller คืออะไร?
C/k คือกระแสรีแอกทีฟด้านทุติยภูมิของ CT ที่เทียบเท่ากับคาปาซิเตอร์ขั้นเล็กที่สุด คำนวณจาก Qขั้นเล็กสุด ÷ (√3 × V × อัตราส่วน CT) คอนโทรลเลอร์ใช้ค่านี้ตัดสินว่ารีแอกทีฟที่ขาดหรือเกินมากพอที่จะสับหรือปลดหนึ่งขั้นหรือยัง ถ้าตั้งเล็กเกินไปคอนแทกเตอร์จะสับไปมาบ่อย ถ้าตั้งใหญ่เกินไป PF จะไม่ถึงเป้า

ทำไมต้องใช้คอนแทกเตอร์สำหรับคาปาซิเตอร์โดยเฉพาะ?
ขณะสับคาปาซิเตอร์ที่ยังไม่มีประจุ โดยเฉพาะเมื่อมีขั้นอื่นต่ออยู่แล้ว (back-to-back) กระแสพุ่งเข้ามีค่ายอดหลายสิบถึงหลายร้อยเท่าของพิกัดในเวลาไม่กี่มิลลิวินาที หน้าสัมผัสคอนแทกเตอร์ธรรมดาจะเชื่อมติดหรือสึกเร็ว คอนแทกเตอร์ AC-6b มีหน้าสัมผัสช่วยพร้อมตัวต้านทานหน่วงที่ต่อก่อนหน้าสัมผัสหลักเพื่อจำกัดกระแสช่วงแรก
