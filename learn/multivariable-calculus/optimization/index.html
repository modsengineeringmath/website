    เครื่องกลรูปทรงถัง/ท่อที่ใช้วัสดุน้อยที่สุดLagrange (ตัวอย่าง O-7)
    เครื่องกลกล่อง/ครีบระบายความร้อนที่รับกำลังได้สูงสุดในพื้นที่จำกัดจุดวิกฤต + บริเวณปิด
    โยธาหน้าตัดคานที่แข็งแรงสุดจากวัสดุกลมLagrange (ตัวอย่าง O-8)
    โยธาจุดตั้งสถานีที่ทำให้ระยะทางรวมถึงจุดต่าง ๆ สั้นที่สุดกำลังสองน้อยสุดและจุดวิกฤต

    ข้อผิดพลาดที่พบบ่อย พื้นฐาน

    1. สรุปว่าจุดวิกฤตทุกจุดคือสูงสุดหรือต่ำสุด ต้องแยกจุดอานม้าด้วย DDD (เช่น (0,0)(0,0)(0,0) ของ x2−y2x^2 - y^2x2−y2)
    2. ใช้ DDD ที่จุดที่ไม่ใช่จุดวิกฤต · ต้องแก้ ∇f=0\nabla f = \mathbf 0∇f=0 ก่อนเสมอ
    3. ลืมตรวจขอบ ในโจทย์บริเวณปิด ค่าสูงสุดสัมบูรณ์มักอยู่บนขอบหรือที่มุม (ตัวอย่าง O-3 ค่าสูงสุดอยู่ที่มุม)
    4. ลืมเทียบค่า fff หลังหาจุดจาก Lagrange · วิธีนี้ให้ “ผู้ต้องสงสัย” ไม่ได้บอกว่าจุดไหนสูงสุดหรือต่ำสุด
    5. สับสนตัวแปรของกำลังสองน้อยสุด · ตัวแปรเมื่อหาค่าต่ำสุดคือ a,ba, ba,b (พารามิเตอร์) ส่วน xi,yix_i, y_ixi​,yi​ คือข้อมูลคงที่

    คำถามที่พบบ่อย

    จุดวิกฤต (critical point) ของฟังก์ชันสองตัวแปรหาอย่างไร?

    ตั้ง fx=0f_x = 0fx​=0 และ fy=0f_y = 0fy​=0 พร้อมกันแล้วแก้ระบบสมการ ได้จุดที่ผิวมีระนาบสัมผัสแนวนอน (หรือจุดที่ fxf_xfx​ หรือ fyf_yfy​ ไม่มีค่า) ตัวอย่าง f=x4+y4−4xyf = x^4 + y^4 - 4xyf=x4+y4−4xy: 4x3−4y=04x^3 - 4y = 04x3−4y=0 และ 4y3−4x=04y^3 - 4x = 04y3−4x=0 ได้ (0,0),(1,1),(−1,−1)(0,0), (1,1), (-1,-1)(0,0),(1,1),(−1,−1) จากนั้นจำแนกชนิดด้วยการทดสอบอนุพันธ์อันดับสอง

    การทดสอบอนุพันธ์อันดับสอง (second derivative test) ทำอย่างไร?

    คำนวณ D=fxxfyy−fxy2D = f_{xx}f_{yy} - f_{xy}^2D=fxx​fyy​−fxy2​ ที่จุดวิกฤต ถ้า D>0D > 0D>0 และ fxx>0f_{xx} > 0fxx​>0 เป็นค่าต่ำสุดสัมพัทธ์ ถ้า D>0D > 0D>0 และ fxx<0f_{xx} < 0fxx​<0 เป็นค่าสูงสุดสัมพัทธ์ ถ้า D<0D < 0D<0 เป็นจุดอานม้า (saddle point) ถ้า D=0D = 0D=0 ทดสอบนี้ไม่สรุป ต้องดูแบบอื่น เช่นตัวอย่าง x3−3xy2x^3 - 3xy^2x3−3xy2 ที่ D=0D = 0D=0 แต่เป็นจุดอานม้า

    ตัวคูณลากรองจ์ (Lagrange multiplier) ใช้เมื่อไร และ λ แปลว่าอะไร?

    ใช้หาค่าสูงสุด-ต่ำสุดของ fff ภายใต้เงื่อนไข g(x,y)=cg(x,y) = cg(x,y)=c โดยแก้ ∇f=λ∇g\nabla f = \lambda\nabla g∇f=λ∇g ร่วมกับ g=cg = cg=c ความหมายเชิงเรขาคณิตคือที่จุดเหมาะสม เส้นชั้นของ fff สัมผัสเส้นเงื่อนไข จึง gradient ขนานกัน ส่วน λ\lambdaλ เท่ากับ df∗/dcdf^*/dcdf∗/dc คืออัตราที่ค่าเหมาะสมที่สุดเปลี่ยนเมื่อผ่อนเงื่อนไข (shadow price) เช่นขยายงบประมาณ 1 หน่วยจะได้ผลดีขึ้นประมาณ λ\lambdaλ หน่วย

    กำลังสองน้อยสุด (least squares) เกี่ยวกับอนุพันธ์ย่อยอย่างไร?

    เส้นตรง y=ax+by = ax + by=ax+b ที่พอดีกับข้อมูลที่สุดคือเส้นที่ทำให้ผลรวมกำลังสองความคลาดเคลื่อน S(a,b)=∑(yi−axi−b)2S(a,b) = \sum (y_i - ax_i - b)^2S(a,b)=∑(yi​−axi​−b)2 น้อยที่สุด ซึ่งเป็นปัญหาหาค่าต่ำสุดของฟังก์ชันสองตัวแปร a,ba, ba,b ตั้ง ∂S/∂a=0\partial S/\partial a = 0∂S/∂a=0 และ ∂S/∂b=0\partial S/\partial b = 0∂S/∂b=0 ได้ระบบสมการปกติ (normal equations) เชิงเส้นสองสมการ แก้หา a,ba, ba,b ตรง ๆ ได้ นี่คือที่มาของ linear regression

    หาค่าสูงสุด-ต่ำสุดสัมบูรณ์บนบริเวณปิดทำอย่างไร?

    เมื่อบริเวณปิดและมีขอบเขต (closed and bounded) ค่าสุดขีดสัมบูรณ์มีแน่นอน ให้ (1) หาจุดวิกฤตภายในและคำนวณ fff (2) หาค่าสุดขีดบนขอบโดยลดเป็นปัญหาตัวแปรเดียวทีละด้าน ตรวจมุมด้วย (3) เปรียบเทียบค่าทั้งหมด ค่ามากสุดคือค่าสูงสุดสัมบูรณ์ ค่าน้อยสุดคือค่าต่ำสุดสัมบูรณ์ ไม่ต้องทดสอบด้วยอนุพันธ์อันดับสอง

    เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม · อุปนัย อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
