# ฟังก์ชันหลายตัวแปร (Functions of Several Variables) คืออะไร: โดเมน กราฟผิว เส้นชั้นความสูง และลิมิต

// บทที่ 24.1 · แคลคูลัสหลายตัวแปร · Functions of Several Variables


โลกจริงแทบไม่เคยขึ้นกับตัวแปรเดียว อุณหภูมิในห้องขึ้นกับตำแหน่ง $(x, y, z)$ กำลังไฟฟ้า $P = V^2/R$ ขึ้นกับทั้งแรงดันและความต้านทาน ความดันแก๊ส $P = nRT/V$ ขึ้นกับอุณหภูมิและปริมาตร หน้านี้เริ่มจากคำถามพื้นฐานที่สุดของแคลคูลัสหลายตัวแปร (multivariable calculus): ฟังก์ชันที่รับตัวเลขหลายตัวหน้าตาเป็นอย่างไร วาดได้อย่างไร และเมื่อ $(x, y)$ เข้าใกล้จุดหนึ่งแล้ว $f$ เข้าใกล้อะไร พร้อมแล็บที่ลากหมุนพื้นผิว 3 มิติและดูเส้นชั้นความสูงพร้อมกัน

สรุปใน 30 วินาที

- $f(x, y)$ รับคู่ตัวเลขแล้วให้ค่าเดียว · กราฟ $z = f(x, y)$ คือผิวในสามมิติ · โดเมนคือบริเวณในระนาบ ไม่ใช่ช่วงบนเส้นตรง

- เส้นชั้นความสูง (contour) $f(x, y) = c$ คือรอยตัดของผิวด้วยระนาบแนวนอน · เส้นชิด = ชัน เส้นห่าง = ลาด

- ถ้า $f$ มีสามตัวแปรขึ้นไปใช้ ผิวระดับ (level surface) $f(x, y, z) = c$ แทนกราฟ

- ลิมิต ที่จุดหนึ่งมีก็ต่อเมื่อทุกเส้นทางให้ค่าเดียวกัน · สองเส้นทางให้ค่าต่างกัน = ไม่มีลิมิต · ทุกเส้นทางที่ลองตรงกัน ≠ พิสูจน์แล้ว

## ฟังก์ชันหลายตัวแปรคืออะไร พื้นฐาน

ฟังก์ชันหลายตัวแปร (multivariable function) คือกฎที่จับคู่ “กลุ่มตัวเลข” หนึ่งชุดกับจำนวนจริงหนึ่งตัว ถ้ารับสองตัวเขียน $z = f(x, y)$ ถ้าสามตัวเขียน $w = f(x, y, z)$ ส่วนฟังก์ชันที่ให้ค่าเป็นเวกเตอร์ (เช่นสนามไฟฟ้า) จะเรียนในบทสนามเวกเตอร์ หน้านี้พูดถึงเฉพาะฟังก์ชันค่าสเกลาร์ (scalar function) ที่ให้ตัวเลขตัวเดียว

| ปริมาณทางวิศวกรรม | ฟังก์ชัน | ตัวแปรอิสระ |

| กำลังไฟฟ้าในตัวต้านทาน | $P(V, R) = V^2/R$ | แรงดัน $V$, ความต้านทาน $R$ |

| ความต้านทานขนาน | $R(R_1, R_2) = \dfrac{R_1 R_2}{R_1 + R_2}$ | $R_1, R_2$ |

| ความดันแก๊สอุดมคติ (n = 1 mol) | $P(T, V) = 8.314\,T/V$ | อุณหภูมิ $T$, ปริมาตร $V$ |

| อุณหภูมิในห้อง | $T(x, y, z)$ | ตำแหน่ง 3 พิกัด |

| ความสูงของภูมิประเทศ | $h(x, y)$ | พิกัดทางราบ |

| ศักย์ไฟฟ้ารอบประจุจุด | $V(x, y, z) = \dfrac{kq}{\sqrt{x^2+y^2+z^2}}$ | ตำแหน่ง |

| ปริมาตรกระป๋องทรงกระบอก | $V(r, h) = \pi r^2 h$ | รัศมี $r$, สูง $h$ |

F1 Function of two variables ฟังก์ชันสองตัวแปร

$$f: D \subseteq \mathbb{R}^2 \to \mathbb{R},\qquad (x, y) \longmapsto z = f(x, y)$$

$D$ = โดเมน (domain) เซตของคู่ $(x, y)$ ที่นิยามได้ · เรนจ์ (range) = เซตของค่า $f$ ทั้งหมด · สำหรับสามตัวแปร $D \subseteq \mathbb{R}^3$

F2 Function of n variables ฟังก์ชัน n ตัวแปร

$$f:\mathbb{R}^n \to \mathbb{R},\quad w = f(\mathbf x) = f(x_1, \dots, x_n)$$

เขียนสั้นด้วยเวกเตอร์ตำแหน่ง $\mathbf x$ · ใช้ในการหาค่าเหมาะสมของระบบหลายพารามิเตอร์

## โดเมนและเรนจ์ของฟังก์ชันสองตัวแปร พื้นฐาน

หลักเดิมของตัวแปรเดียวใช้ได้ทั้งหมด: ตัวส่วนไม่เป็นศูนย์ ค่าใต้รากที่สองไม่ติดลบ ค่าใน $\ln$ ต้องมากกว่าศูนย์ ต่างกันตรงที่ผลลัพธ์เป็นบริเวณในระนาบ ให้วาดบริเวณก่อนเสมอ แล้วจึงเขียนเป็นเซต และจดไว้ว่าขอบรวมหรือไม่รวม (เส้นทึบ = รวม เส้นประ = ไม่รวม)

ตัวอย่าง F-1 · โดเมนที่เป็นแผ่นวงกลม

### หาโดเมนและเรนจ์ของ $f(x, y) = \sqrt{9 - x^2 - y^2}$

- ค่าใต้รากต้องไม่ติดลบ: $9 - x^2 - y^2 \ge 0 \Rightarrow x^2 + y^2 \le 9$

- นี่คือแผ่นวงกลมรัศมี 3 กึ่งกลางที่จุดกำเนิด รวมขอบ: $D = \{(x, y) : x^2 + y^2 \le 9\}$

- เรนจ์: ที่จุดกำเนิด $f = 3$ (มากที่สุด) ที่ขอบ $f = 0$ (น้อยที่สุด) และ $f$ ต่อเนื่อง จึงได้ทุกค่าในช่วง $[0, 3]$

- กราฟ $z = \sqrt{9 - x^2 - y^2}$ คือซีกบนของทรงกลมรัศมี 3 เพราะยกกำลังสองได้ $x^2 + y^2 + z^2 = 9,\ z \ge 0$

โดเมน $= \{x^2 + y^2 \le 9\}$ · เรนจ์ $= [0, 3]$

### กำลังไฟฟ้า $P(V, R) = V^2/R$ ของตัวต้านทานในวงจร มีโดเมนอย่างไร?

## กราฟของ z = f(x, y) เป็นผิว: แล็บพื้นผิว 3 มิติ พื้นฐาน

ตัวแปรเดียววาดกราฟเป็นเส้นโค้ง สองตัวแปรวาดเป็นผิว (surface) เหนือบริเวณโดเมน ความสูงของผิวที่จุด $(x, y)$ คือ $f(x, y)$ ในแล็บนี้ลากภาพซ้ายเพื่อหมุน ลาก/คลิกแผนที่ขวาเพื่อย้ายจุด เส้นสีส้มและสีฟ้าคือรอยตัดของผิวด้วยระนาบ $y = y_0$ และ $x = x_0$ (จะกลับมาใช้เป็นอนุพันธ์ย่อยในบทถัดไป) ลองพิมพ์ฟังก์ชันของคุณเอง เช่น x*y หรือ sin(x)*cos(y)

ผิวอานม้า $z = x^2 - y^2$ กับเส้นชั้นความสูงของมัน: ตัดผิวด้วยระนาบ $z = c$ แล้วฉายลงระนาบ $xy$ ได้ไฮเพอร์โบลา (สีฟ้า $c < 0$, สีส้ม $c > 0$, เส้นทแยง $c = 0$)

F3 Plane as a graph ระนาบเป็นกราฟของฟังก์ชันเชิงเส้น

$$z = f(x, y) = c + a x + b y$$

ความชันตามแกน $x$ คือ $a$ ตามแกน $y$ คือ $b$ ทุกที่เท่ากัน — แบบจำลองของ “ผิวที่ไม่โค้ง” และของระนาบสัมผัสในบทหน้า

F4 Graph of f กราฟของ f

$$\operatorname{graph}(f) = \{(x, y, z) : z = f(x, y),\ (x, y) \in D\}$$

ผิวเหนือโดเมน $D$ · เส้นตั้งฉากกับระนาบ $xy$ ใด ๆ ตัดผิวไม่เกินหนึ่งจุด (vertical line test แบบ 3 มิติ)

## เส้นชั้นความสูง (Level Curves) และผิวระดับ (Level Surfaces) พื้นฐาน

วาดผิว 3 มิติด้วยมือเป็นเรื่องยาก วิศวกรจึงใช้อีกวิธีที่เก่าแก่ที่สุด คือแผนที่เส้นชั้นความสูง (contour map) ตัดผิวด้วยระนาบแนวนอน $z = c$ หลายระดับ แล้วฉายรอยตัดลงบนระนาบ $xy$ ถ้าเลือก $c$ ห่างกันเท่า ๆ กัน (เช่นทุก 1 เมตร) ระยะห่างของเส้นบอกความชันได้ทันที เส้นชิดกันคือชัน เส้นห่างกันคือลาด

F5 Level curve เส้นชั้นความสูง

$$L_c = \{(x, y) \in D : f(x, y) = c\}$$

ชื่อเรียกตามปริมาณ: ความสูง → contour · อุณหภูมิ → isotherm · ความดัน → isobar · ศักย์ไฟฟ้า → equipotential · เส้นชั้นของคนละระดับ $c$ ไม่ตัดกัน (ฟังก์ชันให้ค่าเดียว)

F6 Level surface ผิวระดับ

$$S_c = \{(x, y, z) : f(x, y, z) = c\}$$

ฟังก์ชันสามตัวแปรวาดกราฟไม่ได้ (ต้อง 4 มิติ) จึงดูผ่านผิวระดับ เช่น $x^2 + y^2 + z^2 = c$ เป็นทรงกลมซ้อนกัน

ตัวอย่าง F-4 · เส้นชั้นเป็นวงรี

### วาดเส้นชั้นความสูงของ $f(x, y) = x^2 + 4y^2$ ที่ $c = 1, 4, 9$

- ตั้ง $x^2 + 4y^2 = c$ หารด้วย $c$: $\dfrac{x^2}{c} + \dfrac{y^2}{c/4} = 1$ เป็นวงรีกึ่งแกนยาว $\sqrt{c}$ (แนว $x$) และกึ่งแกนสั้น $\sqrt{c}/2$ (แนว $y$)

- $c = 1$: $a = 1,\ b = 0.5$ · $c = 4$: $a = 2,\ b = 1$ · $c = 9$: $a = 3,\ b = 1.5$

- ที่ $c = 0$ เหลือจุดเดียว $(0,0)$ ซึ่งเป็นจุดต่ำสุด และ $c < 0$ ไม่มีเส้น เพราะ $f \ge 0$ เสมอ

- สังเกต: ในแนวแกน $y$ ผิวชันกว่าแนว $x$ สองเท่าตัว วงรีจึงแบนตามแกน $y$ และเส้นที่ห่างกันเท่า ๆ ใน $c$ จะชิดกันมากกว่าตามแกน $y$

วงรีโฟกัสร่วมจุดกำเนิด กึ่งแกน $(\sqrt{c},\ \sqrt{c}/2)$

ตัวอย่างจากงานจริง: ศักย์ไฟฟ้ารอบประจุจุด $V = kq/r$ มีเส้นชั้นเป็นวงกลมศูนย์กลางเดียวกัน ผนังเตาที่ร้อนด้านเดียวมี isotherm เป็นเส้นตรงขนานผนัง และแผนที่อากาศมี isobar ปิดรอบศูนย์กลางพายุ ในบทเกรเดียนต์จะเห็นว่าทิศที่ปริมาณเปลี่ยนเร็วสุดตั้งฉากกับเส้นชั้นเหล่านี้เสมอ

## ผิวกำลังสอง (Quadric Surfaces) กลาง

สมการดีกรีสองในสามตัวแปรให้ผิวมาตรฐานเพียงไม่กี่แบบ ซึ่งเจอซ้ำ ๆ ในงานวิศวกรรม: จานรับสัญญาณดาวเทียมคือพาราโบลอยด์ หอคอยระบายความร้อนของโรงไฟฟ้าคือไฮเพอร์โบลอยด์ 1 ตอน ถังแก๊สคือทรงรี วิธีจำแนกคือตัดด้วยระนาบ (trace) แล้วดูรูปรอยตัด

ผิวกำลังสองหกแบบ: ทรงรี พาราโบลอยด์ทรงรี อานม้า กรวย ไฮเพอร์โบลอยด์ 1 ตอน และทรงกระบอกพาราโบลา

| ผิว (English) | สมการมาตรฐาน | รอยตัด $z = k$ | รอยตัดตั้ง | พบใน |

| ทรงรี (ellipsoid) | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ | วงรี | วงรี | ถังแก๊ส เปลือกตัวถัง |

| พาราโบลอยด์ทรงรี (elliptic paraboloid) | $z = \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2}$ | วงรี | พาราโบลา | จานสะท้อน เสาอากาศ กระจกโค้ง |

| อานม้า (hyperbolic paraboloid) | $z = \dfrac{x^2}{a^2} - \dfrac{y^2}{b^2}$ | ไฮเพอร์โบลา | พาราโบลา | หลังคาเปลือกบาง จุดอานม้าของ $f$ |

| กรวย (cone) | $z^2 = \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2}$ | วงรี | เส้นตรงตัดกัน/ไฮเพอร์โบลา | ปล่องกรวย ปากลำโพง |

| ไฮเพอร์โบลอยด์ 1 ตอน (hyperboloid of one sheet) | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$ | วงรี | ไฮเพอร์โบลา | หอระบายความร้อน (cooling tower) |

| ไฮเพอร์โบลอยด์ 2 ตอน (hyperboloid of two sheets) | $\dfrac{z^2}{c^2} - \dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ | วงรี (เมื่อ $\lvert k \rvert > c$) | ไฮเพอร์โบลา | กระจกสะท้อนแบบ Cassegrain |

| ทรงกระบอก (cylinder) | $x^2 + y^2 = r^2$ (ไม่มี $z$) | วงกลม | เส้นตรงขนาน | ท่อ ถังเก็บ เสา |

F7 Ellipsoid · sphere ทรงรี · ทรงกลม

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1,\qquad x^2 + y^2 + z^2 = R^2$$

$a = b = c = R$ คือทรงกลม · ซีกบนคือกราฟ $z = \sqrt{R^2 - x^2 - y^2}$

F8 Paraboloids พาราโบลอยด์

$$z = \frac{x^2}{a^2} + \frac{y^2}{b^2}\ \ (\text{ชาม}),\qquad z = \frac{x^2}{a^2} - \frac{y^2}{b^2}\ \ (\text{อานม้า})$$

เครื่องหมายระหว่างสองพจน์ตัดสินว่าเป็นชามหรืออานม้า · จุดวิกฤตของทั้งคู่อยู่ที่จุดกำเนิด (ดูบทค่าสุดขีด)

ตัวอย่าง F-5 · จำแนกผิวจากสมการ

### จำแนกผิว $4x^2 + y^2 - z^2 = 4$ และบอกรอยตัดที่ $z = 0$ และ $z = 2$

- หารด้วย 4: $x^2 + \dfrac{y^2}{4} - \dfrac{z^2}{4} = 1$ เทียบ $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$ ได้ $a = 1,\ b = 2,\ c = 2$ — เครื่องหมายลบเพียงหนึ่งตัวและเท่ากับ 1: ไฮเพอร์โบลอยด์ 1 ตอน

- $z = 0$: $x^2 + y^2/4 = 1$ วงรีกึ่งแกน 1 (แนว $x$) และ 2 (แนว $y$) — นี่คือ “เอว” ที่แคบที่สุด

- $z = 2$: $x^2 + y^2/4 = 1 + 1 = 2$ วงรีกึ่งแกน $\sqrt{2}$ และ $2\sqrt{2}$ — ใหญ่ขึ้นเมื่อห่างจากเอว

- รอยตัดที่ $y = 0$: $4x^2 - z^2 = 4$ ไฮเพอร์โบลา จึงยืนยันว่าไม่ใช่ทรงรี

ไฮเพอร์โบลอยด์ 1 ตอน แกนตามแนว $z$ · เอว ($z = 0$) เป็นวงรี $x^2 + y^2/4 = 1$

## ลิมิตของฟังก์ชันสองตัวแปร: ทำไมต้องตรวจทุกเส้นทาง กลาง

ลิมิตของตัวแปรเดียวมีแค่สองทิศ (ซ้ายกับขวา) แต่เมื่อ $(x, y) \to (a, b)$ บนระนาบ จุดเข้าหาได้จากทุกทิศและตามเส้นโค้งทุกรูปแบบ นิยามจึงเข้มงวดขึ้น: ลิมิตมี ต่อเมื่อ ทุกเส้นทางให้ค่าเดียวกัน

F9 Limit (ε–δ) นิยามลิมิตสองตัวแปร

$$\lim_{(x,y)\to(a,b)} f(x, y) = L \iff \forall \varepsilon > 0\ \exists \delta > 0:\ 0 เงื่อนไขเป็น “วงกลมรัศมี $\delta$” รอบ $(a, b)$ (ไม่ใช่ช่วง) ที่ไม่รวมจุดศูนย์กลาง · ทุกจุดในวงกลมต้องทำให้ $f$ ห่างจาก $L$ น้อยกว่า $\varepsilon$

F10 Two-path test การทดสอบสองเส้นทาง

$$f \to L_1 \text{ ตาม } C_1,\ f \to L_2 \text{ ตาม } C_2,\ L_1 \neq L_2 \Rightarrow \text{ลิมิตไม่มี (DNE)}$$

ใช้ได้ทางเดียว: พิสูจน์ว่า “ไม่มี” ได้ แต่ทุกเส้นทางที่ลองตรงกันก็ยังไม่พิสูจน์ว่า “มี”

ประเมินขอบบนด้วยอสมการ เช่น $x^2 \le x^2 + y^2$ หรือ $|y| \le \sqrt{x^2 + y^2}$ แล้วแสดงว่าขอบบนเข้าหาศูนย์

F12 Polar substitution แทนด้วยพิกัดขั้ว (ที่จุดกำเนิด)

$$x = r\cos\theta,\ y = r\sin\theta;\qquad (x, y) \to (0, 0) \iff r \to 0^{+} \ \text{(ทุก } \theta)$$

ถ้า $|f(r\cos\theta,\, r\sin\theta) - L| \le g(r)$ โดยที่ $g$ ไม่ขึ้นกับ $\theta$ และ $g(r) \to 0$ ลิมิตคือ $L$ · ถ้านิพจน์ยังขึ้นกับ $\theta$ หลัง $r \to 0$ ลิมิตไม่มี

### แล็บทดสอบลิมิตตามเส้นทาง

เลือกตัวอย่างแล้วสลับชนิดของเส้นทาง สังเกตกรณี $xy^2/(x^2 + y^4)$: เส้นตรงทุกเส้นให้ 0 แต่พาราโบลา $x = m y^2$ ให้ค่าไม่เท่ากัน

หลายเส้นทางเข้าหาจุดกำเนิดในระนาบ $xy$: ถ้า $f$ ให้ค่าต่างกันตามเส้นทาง (เช่น $xy/(x^2+y^2) = m/(1+m^2)$ ตามเส้น $y = mx$) ลิมิตไม่มี

ตัวอย่าง F-6 · ลิมิตไม่มี

### $\displaystyle\lim_{(x,y)\to(0,0)} \dfrac{xy}{x^2+y^2}$

- เส้นทางที่ 1: ตามแกน $x$ ($y = 0$): $f = \dfrac{0}{x^2} = 0$ จึงได้ $0$

- เส้นทางที่ 2: ตามเส้น $y = x$: $f = \dfrac{x^2}{2x^2} = \dfrac{1}{2}$ จึงได้ $\tfrac12$

- สองเส้นทางให้ค่าต่างกัน ($0 \ne \tfrac12$) · ทั่วไป ตาม $y = mx$ ได้ $\dfrac{m}{1+m^2}$ ซึ่งเปลี่ยนตาม $m$ (ในพิกัดขั้ว $f = \sin\theta\cos\theta$ ขึ้นกับ $\theta$)

ลิมิตไม่มี (DNE) — ฟังก์ชันนี้ไม่ต่อเนื่องที่จุดกำเนิดแม้จะนิยามค่าที่นั่นอย่างไรก็ตาม

ตัวอย่าง F-7 · พิสูจน์ว่าลิมิตมีด้วย squeeze และพิกัดขั้ว

### $\displaystyle\lim_{(x,y)\to(0,0)} \dfrac{x^2 y}{x^2+y^2}$

- ลองเส้นทางก่อน: $y = mx$ ได้ $\dfrac{m x^3}{x^2(1+m^2)} = \dfrac{m x}{1+m^2} \to 0$ ทุก $m$ และตามแกนก็ $0$ จึงคาดว่าลิมิตคือ 0 (ยังไม่ใช่การพิสูจน์)

- วิธี squeeze: $x^2 \le x^2 + y^2$ จึง $\dfrac{x^2}{x^2+y^2} \le 1$ ดังนั้น $\left|\dfrac{x^2 y}{x^2+y^2}\right| \le |y|$

- เมื่อ $(x, y) \to (0, 0)$ ได้ $|y| \to 0$ โดย squeeze ลิมิตเท่ากับ 0

- วิธีพิกัดขั้ว: $\dfrac{r^2\cos^2\theta \cdot r\sin\theta}{r^2} = r\cos^2\theta\sin\theta$ และ $|r\cos^2\theta\sin\theta| \le r \to 0$ โดยขอบบน $r$ ไม่ขึ้นกับ $\theta$ ยืนยันคำตอบเดียวกัน

$\displaystyle\lim = 0$

ตัวอย่าง F-8 · เส้นตรงทุกเส้นหลอกได้

### $\displaystyle\lim_{(x,y)\to(0,0)} \dfrac{x y^2}{x^2+y^4}$

- ตามเส้น $y = mx$: $\dfrac{x \cdot m^2 x^2}{x^2 + m^4 x^4} = \dfrac{m^2 x}{1 + m^4 x^2} \to 0$ และตามแกน $y$ ($x = 0$) ก็ $0$ — เส้นตรงทุกเส้นให้ 0

- แต่ตามพาราโบลา $x = y^2$: $\dfrac{y^2 \cdot y^2}{y^4 + y^4} = \dfrac{y^4}{2y^4} = \dfrac{1}{2}$ สำหรับทุก $y \ne 0$

- ได้ $0$ กับ $\tfrac12$ → ต่างกัน ลิมิตไม่มี

ลิมิตไม่มี (DNE) — ตัวอย่างนี้แสดงว่าการทดสอบด้วยเส้นตรงอย่างเดียวไม่พอ ต้องลองเส้นโค้งที่ “เข้ากับ” รูปของนิพจน์ด้วย

ตัวอย่าง F-9 · ลิมิตมาตรฐานด้วยพิกัดขั้ว

### $\displaystyle\lim_{(x,y)\to(0,0)} \dfrac{\sin(x^2+y^2)}{x^2+y^2}$

- แทน $x^2 + y^2 = r^2$: นิพจน์เป็น $\dfrac{\sin r^2}{r^2}$ ไม่ขึ้นกับ $\theta$ เลย

- เมื่อ $(x, y) \to (0, 0)$ ได้ $r \to 0^{+}$ และ $u = r^2 \to 0^{+}$ จึง $\dfrac{\sin u}{u} \to 1$ (ลิมิตตัวแปรเดียวมาตรฐาน)

$\displaystyle\lim = 1$ — เทคนิคนี้ใช้ได้เสมอเมื่อ $f$ เป็นฟังก์ชันของ $x^2 + y^2$ เท่านั้น

### ความต่อเนื่อง (Continuity)

F13 Continuity at a point ความต่อเนื่อง ณ จุดหนึ่ง

$$f \text{ ต่อเนื่องที่ } (a, b) \iff \lim_{(x,y)\to(a,b)} f(x, y) = f(a, b)$$

ต้องครบสามข้อ: $f(a, b)$ นิยามได้ · ลิมิตมี · ทั้งสองเท่ากัน · พหุนาม ฟังก์ชันตรรกยะ (ที่ตัวส่วน $\ne 0$) และ $\sin, \cos, e^{(\cdot)}, \ln$ ของฟังก์ชันต่อเนื่อง ต่างต่อเนื่องบนโดเมนของมัน

ผลที่ตามมา: ถ้าฟังก์ชันสร้างจากพหุนามและฟังก์ชันพื้นฐานด้วยการบวก ลบ คูณ หาร และประกอบ เราหาลิมิตได้ด้วยการ “แทนค่า” ตราบใดที่จุดนั้นอยู่ในโดเมน ปัญหาเกิดเฉพาะจุดที่ได้ $0/0$ เช่นจุดกำเนิดของตัวอย่าง F-6 ถึง F-9 ซึ่งต้องใช้เทคนิคข้างต้น ความต่อเนื่องคือเงื่อนไขที่ทำให้อนุพันธ์ย่อยและอินทิกรัลหลายชั้นในบทถัดไปมีความหมายและคำนวณได้

## ข้อผิดพลาดที่พบบ่อย พื้นฐาน

- สรุปว่ามีลิมิตเพราะ “ลองสามเส้นทางแล้วเท่ากัน” — ต้องพิสูจน์ด้วย squeeze หรือพิกัดขั้ว (ตัวอย่าง F-8 เป็นตัวอย่างค้านคลาสสิก)

- ใช้พิกัดขั้วแล้วลืมว่าต้อง “ทุก $\theta$” — ขอบบนของ $|f - L|$ ต้องไม่ขึ้นกับ $\theta$ · ถ้ายังมี $\theta$ เหลือหลังให้ $r \to 0$ ลิมิตไม่มี (เช่น F-6 ได้ $\sin\theta\cos\theta$)

- ตอบโดเมนเป็นช่วง — โดเมนของ $f(x, y)$ เป็นบริเวณในระนาบ ต้องอธิบายด้วยอสมการของ $x$ และ $y$ ร่วมกัน

- เข้าใจว่าเส้นชั้นความสูงคือเส้นที่ผิวสูง $c$ บนกราฟ — เส้นชั้นอยู่บนระนาบ $xy$ คือรอยตัดที่ถูก “ฉายลงมา” ไม่ใช่เส้นบนผิว (แต่เส้นบนผิวที่ $z = c$ เป็นเส้นชั้นยกขึ้น)

- เชื่อกราฟคอมพิวเตอร์ใกล้จุดที่ $0/0$ — ผิวอาจดูเรียบแต่ลิมิตไม่มี ใช้การทดสอบเส้นทางควบคู่

## คำถามที่พบบ่อย

ฟังก์ชันหลายตัวแปร (multivariable function) คืออะไร ต่างจากฟังก์ชันตัวแปรเดียวอย่างไร?
ฟังก์ชันตัวแปรเดียว $y = f(x)$ รับตัวเลขหนึ่งตัวแล้วให้ค่าออกหนึ่งค่า กราฟเป็นเส้นโค้งบนระนาบ ส่วนฟังก์ชันหลายตัวแปรรับตัวเลขหลายตัวพร้อมกัน เช่น $z = f(x, y)$ หรือ $T = f(x, y, z)$ แต่ยังให้ค่าออกเป็นจำนวนจริงหนึ่งค่า กราฟของ $f(x,y)$ เป็นผิวในปริภูมิสามมิติ ส่วน $f(x,y,z)$ วาดกราฟไม่ได้จึงดูผ่านผิวระดับ (level surface) แทน ตัวอย่างในงานวิศวกรรมคืออุณหภูมิในห้อง ศักย์ไฟฟ้ารอบประจุ และความดันแก๊ส $P = nRT/V$

หาโดเมนของฟังก์ชันสองตัวแปรอย่างไร?
หาเงื่อนไขของคู่ $(x, y)$ ที่ทำให้นิพจน์นิยามได้ เหมือนฟังก์ชันตัวแปรเดียวแต่เงื่อนไขกลายเป็นบริเวณในระนาบ: ตัวส่วนต้องไม่เป็นศูนย์ ค่าใต้รากที่สองต้องไม่ติดลบ ค่าใน $\ln$ ต้องมากกว่าศูนย์ ตัวอย่าง $f = \sqrt{9 - x^2 - y^2}$ ต้องมี $x^2 + y^2 \le 9$ โดเมนคือแผ่นวงกลมรัศมี 3 รวมขอบ ส่วน $f = \ln(x - y)$ ต้องมี $x > y$ โดเมนคือครึ่งระนาบเหนือเส้น $y = x$ ไม่รวมเส้น วาดบริเวณก่อนแล้วจึงเขียนเป็นเซต

เส้นชั้นความสูง (level curve / contour) คืออะไร ใช้ทำอะไร?
เส้นชั้นความสูงของ $f(x,y)$ คือเซตของจุดที่ $f(x, y) = c$ เมื่อ $c$ เป็นค่าคงที่ ถ้า $f$ คือความสูงของภูเขา เส้นเหล่านี้คือเส้นชั้นความสูงบนแผนที่ ถ้า $f$ คืออุณหภูมิจะเรียก isotherm ถ้าคือศักย์ไฟฟ้าจะเรียกเส้นศักย์เท่ากัน (equipotential) ที่ใดเส้นชิดกันแสดงว่า $f$ เปลี่ยนเร็ว (ชัน) ที่ใดห่างกันแสดงว่าเปลี่ยนช้า วิศวกรใช้อ่านและออกแบบสนามต่าง ๆ โดยไม่ต้องวาดกราฟ 3 มิติ

ทำไมลิมิตสองตัวแปรต้องตรวจหลายเส้นทาง?
ในตัวแปรเดียวเข้าหาจุดได้แค่ซ้ายกับขวา แต่ในระนาบเข้าหาจุด $(a, b)$ ได้ไม่จำกัดเส้นทาง ลิมิตมีก็ต่อเมื่อทุกเส้นทางให้ค่าเดียวกัน ดังนั้นถ้าพบสองเส้นทางที่ให้ค่าต่างกันก็สรุปได้ทันทีว่าลิมิตไม่มี (DNE) เช่น $xy/(x^2+y^2)$ ที่จุดกำเนิดได้ $m/(1+m^2)$ ตามเส้น $y = mx$ แต่ถ้าทุกเส้นทางที่ลองให้ค่าเท่ากันยังไม่พอสรุปว่าลิมิตมี ต้องพิสูจน์ด้วย squeeze theorem หรือพิกัดขั้ว และระวังเส้นโค้งอย่าง $x = y^2$ ที่อาจให้ค่าต่างจากเส้นตรงทั้งหมด

ผิวกำลังสอง (quadric surface) มีกี่แบบ ดูอย่างไรว่าเป็นแบบไหน?
มีหลักคือทรงรี (ellipsoid) ไฮเพอร์โบลอยด์ 1 และ 2 ตอน (hyperboloid) กรวย (cone) พาราโบลอยด์ทรงรี (elliptic paraboloid) พาราโบลอยด์ไฮเพอร์โบลิก หรืออานม้า (hyperbolic paraboloid) และทรงกระบอกชนิดต่าง ๆ วิธีดูที่ง่ายที่สุดคือตัดด้วยระนาบ $z = k$ และระนาบอีกสองแกน (trace) แล้วดูว่าได้วงรี พาราโบลา หรือไฮเพอร์โบลา เช่น $z = x^2 + y^2$ ตัดที่ $z = k$ ได้วงกลม ตัดที่ $y = 0$ ได้พาราโบลา จึงเป็นพาราโบลอยด์ทรงรี

## คำถามที่พบบ่อย (FAQ)

**ฟังก์ชันหลายตัวแปร (multivariable function) คืออะไร ต่างจากฟังก์ชันตัวแปรเดียวอย่างไร?**
ฟังก์ชันตัวแปรเดียว $y = f(x)$ รับตัวเลขหนึ่งตัวแล้วให้ค่าออกหนึ่งค่า กราฟเป็นเส้นโค้งบนระนาบ ส่วนฟังก์ชันหลายตัวแปรรับตัวเลขหลายตัวพร้อมกัน เช่น $z = f(x, y)$ หรือ $T = f(x, y, z)$ แต่ยังให้ค่าออกเป็นจำนวนจริงหนึ่งค่า กราฟของ $f(x,y)$ เป็นผิวในปริภูมิสามมิติ ส่วน $f(x,y,z)$ วาดกราฟไม่ได้จึงดูผ่านผิวระดับ (level surface) แทน ตัวอย่างในงานวิศวกรรมคืออุณหภูมิในห้อง ศักย์ไฟฟ้ารอบประจุ และความดันแก๊ส $P = nRT/V$

**หาโดเมนของฟังก์ชันสองตัวแปรอย่างไร?**
หาเงื่อนไขของคู่ $(x, y)$ ที่ทำให้นิพจน์นิยามได้ เหมือนฟังก์ชันตัวแปรเดียวแต่เงื่อนไขกลายเป็นบริเวณในระนาบ: ตัวส่วนต้องไม่เป็นศูนย์ ค่าใต้รากที่สองต้องไม่ติดลบ ค่าใน $\ln$ ต้องมากกว่าศูนย์ ตัวอย่าง $f = \sqrt{9 - x^2 - y^2}$ ต้องมี $x^2 + y^2 \le 9$ โดเมนคือแผ่นวงกลมรัศมี 3 รวมขอบ ส่วน $f = \ln(x - y)$ ต้องมี $x > y$ โดเมนคือครึ่งระนาบเหนือเส้น $y = x$ ไม่รวมเส้น วาดบริเวณก่อนแล้วจึงเขียนเป็นเซต

**เส้นชั้นความสูง (level curve / contour) คืออะไร ใช้ทำอะไร?**
เส้นชั้นความสูงของ $f(x,y)$ คือเซตของจุดที่ $f(x, y) = c$ เมื่อ $c$ เป็นค่าคงที่ ถ้า $f$ คือความสูงของภูเขา เส้นเหล่านี้คือเส้นชั้นความสูงบนแผนที่ ถ้า $f$ คืออุณหภูมิจะเรียก isotherm ถ้าคือศักย์ไฟฟ้าจะเรียกเส้นศักย์เท่ากัน (equipotential) ที่ใดเส้นชิดกันแสดงว่า $f$ เปลี่ยนเร็ว (ชัน) ที่ใดห่างกันแสดงว่าเปลี่ยนช้า วิศวกรใช้อ่านและออกแบบสนามต่าง ๆ โดยไม่ต้องวาดกราฟ 3 มิติ

**ทำไมลิมิตสองตัวแปรต้องตรวจหลายเส้นทาง?**
ในตัวแปรเดียวเข้าหาจุดได้แค่ซ้ายกับขวา แต่ในระนาบเข้าหาจุด $(a, b)$ ได้ไม่จำกัดเส้นทาง ลิมิตมีก็ต่อเมื่อทุกเส้นทางให้ค่าเดียวกัน ดังนั้นถ้าพบสองเส้นทางที่ให้ค่าต่างกันก็สรุปได้ทันทีว่าลิมิตไม่มี (DNE) เช่น $xy/(x^2+y^2)$ ที่จุดกำเนิดได้ $m/(1+m^2)$ ตามเส้น $y = mx$ แต่ถ้าทุกเส้นทางที่ลองให้ค่าเท่ากันยังไม่พอสรุปว่าลิมิตมี ต้องพิสูจน์ด้วย squeeze theorem หรือพิกัดขั้ว และระวังเส้นโค้งอย่าง $x = y^2$ ที่อาจให้ค่าต่างจากเส้นตรงทั้งหมด

**ผิวกำลังสอง (quadric surface) มีกี่แบบ ดูอย่างไรว่าเป็นแบบไหน?**
มีหลักคือทรงรี (ellipsoid) ไฮเพอร์โบลอยด์ 1 และ 2 ตอน (hyperboloid) กรวย (cone) พาราโบลอยด์ทรงรี (elliptic paraboloid) พาราโบลอยด์ไฮเพอร์โบลิก หรืออานม้า (hyperbolic paraboloid) และทรงกระบอกชนิดต่าง ๆ วิธีดูที่ง่ายที่สุดคือตัดด้วยระนาบ $z = k$ และระนาบอีกสองแกน (trace) แล้วดูว่าได้วงรี พาราโบลา หรือไฮเพอร์โบลา เช่น $z = x^2 + y^2$ ตัดที่ $z = k$ ได้วงกลม ตัดที่ $y = 0$ ได้พาราโบลา จึงเป็นพาราโบลอยด์ทรงรี
