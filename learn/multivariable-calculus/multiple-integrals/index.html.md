# อินทิกรัลสองชั้นและสามชั้น (Double & Triple Integrals): พิกัดขั้ว ทรงกระบอก ทรงกลม และ Jacobian

// บทที่ 24.5 · แคลคูลัสหลายตัวแปร · Double & Triple Integrals


อินทิกรัลตัวแปรเดียวรวม “พื้นที่ใต้เส้นโค้ง” ส่วนอินทิกรัลสองชั้น (double integral) รวม “ปริมาตรใต้ผิว” และอินทิกรัลสามชั้น (triple integral) รวมปริมาณใด ๆ ทั่วเนื้อของวัตถุ ไม่ว่าจะเป็นมวล ประจุ พลังงาน หรือโมเมนต์ความเฉื่อยของชิ้นส่วนเครื่องจักร หน้านี้สอนทั้งวิธีคำนวณทีละชั้น การเลือกบริเวณ การสลับลำดับ การเปลี่ยนไปใช้พิกัดขั้ว ทรงกระบอก ทรงกลมพร้อมตัวคูณ Jacobian และการประยุกต์หามวลกับจุดศูนย์กลางมวล พร้อมแล็บที่เห็นทั้งผลรวมรีมันน์และค่าที่แท้จริง

สรุปใน 30 วินาที

- $\iint_R f\,dA =$ ปริมาตรใต้ผิว (เมื่อ $f \ge 0$) · คำนวณทีละชั้น (Fubini): ในสุดก่อน ถือตัวนอกเป็นค่าคงที่

- บริเวณ type I $a \le x \le b,\ g_1(x) \le y \le g_2(x)$ · type II $c \le y \le d,\ h_1(y) \le x \le h_2(y)$ · อินทิเกรตไม่ออกให้สลับลำดับ

- พิกัดขั้ว: $dA = r\,dr\,d\theta$ · ทรงกระบอก: $dV = r\,dz\,dr\,d\theta$ · ทรงกลม: $dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$ · ตัวคูณคือ $|J|$

- ประยุกต์: มวล $M = \iint\rho\,dA$ · $\bar x = \tfrac1M\iint x\rho\,dA$ · $I_x = \iint y^2\rho\,dA$

ระดับพื้นฐาน ปี 1 · แคลคูลัส 1กลาง แคลคูลัส 3 · คณิตศาสตร์วิศวกรรมขั้นสูง พิสูจน์ · ทฤษฎี

## อินทิกรัลสองชั้นคืออะไร: ผลรวมรีมันน์ในสองมิติ พื้นฐาน

ตัวแปรเดียว: แบ่งช่วงเป็นชิ้นแคบ $\Delta x$ คูณความสูง $f$ แล้วบวก สองตัวแปร: แบ่งบริเวณ $R$ เป็นช่องเล็กพื้นที่ $\Delta A$ แต่ละช่องมี “แท่ง” สูง $f(x_i^*, y_j^*)$ ปริมาตรรวมของแท่งทั้งหมดคือผลรวมรีมันน์ (Riemann sum) เมื่อช่องเล็กลงจนไม่สิ้นสุด ผลรวมเข้าใกล้อินทิกรัลสองชั้น ในแล็บด้านล่างเลื่อน $n$ จาก 1 ถึง 40 แล้วดูแท่งปริมาตรกับค่า “ที่แท้จริง” วิ่งเข้าหากัน

M1 Double integral (Riemann sum) อินทิกรัลสองชั้น (ผลรวมรีมันน์)

$$\iint_R f(x, y)\,dA = \lim_{m,n\to\infty}\sum_{i=1}^{m}\sum_{j=1}^{n} f(x_i^{*}, y_j^{*})\,\Delta A,\qquad \Delta A = \Delta x\,\Delta y$$

$f \ge 0$: ปริมาตรใต้ผิว $z = f(x, y)$ เหนือ $R$ · จุด $(x_i^*, y_j^*)$ เลือกกึ่งกลางช่อง = midpoint rule · $f = 1$ ให้พื้นที่ $A(R)$

M2 Fubini's theorem (rectangle) ทฤษฎีบทฟูบินี (สี่เหลี่ยมผืนผ้า)

$$\iint_{[a,b]\times[c,d]} f\,dA = \int_a^b\!\left(\int_c^d f(x, y)\,dy\right)dx = \int_c^d\!\left(\int_a^b f(x, y)\,dx\right)dy$$

เมื่อ $f$ ต่อเนื่อง สองลำดับให้ค่าเท่ากัน · ชั้นในอินทิเกรตก่อน โดยถือตัวแปรนอกเป็นค่าคงที่ · ถ้า $f = g(x)h(y)$ แยกเป็นผลคูณ $\int g\,dx\cdot\int h\,dy$

M3 Average value ค่าเฉลี่ยของฟังก์ชัน

$$f_{\text{avg}} = \frac{1}{A(R)}\iint_R f\,dA,\qquad A(R) = \iint_R dA$$

เชิงเส้นและบวกกันได้ตามบริเวณ · ค่าเฉลี่ยทางวิศวกรรม เช่น อุณหภูมิเฉลี่ยของแผ่น ความสูงเฉลี่ยของพื้นที่ (ใช้หาระดับสมดุลในบทโยธา)

ตัวอย่าง M-1 · Riemann sum กับค่าที่แท้จริง

### หา $\displaystyle\iint_R (x^2 + y^2)\,dA$ เมื่อ $R = [0, 1]\times[0, 2]$ และเทียบกับผลรวมรีมันน์แบบ 2×2 ช่อง (กึ่งกลาง)

- ชั้นใน (ตาม $y$, ถือ $x$ คงที่): $\displaystyle\int_0^2 (x^2 + y^2)\,dy = \left[x^2 y + \dfrac{y^3}{3}\right]_0^2 = 2x^2 + \dfrac83$

- ชั้นนอก: $\displaystyle\int_0^1\left(2x^2 + \dfrac83\right)dx = \dfrac{2}{3} + \dfrac83 = \dfrac{10}{3} \approx 3.3333$

- Riemann sum 2×2: $\Delta x = 0.5,\ \Delta y = 1,\ \Delta A = 0.5$ · จุดกึ่งกลาง $x \in \{0.25, 0.75\}$, $y \in \{0.5, 1.5\}$

- ค่า $f$: $0.3125,\ 0.8125,\ 2.3125,\ 2.8125$ · ผลรวม $= 6.25$ · $\times\,0.5 = 3.125$ (ต่ำกว่าจริง 6.25%) · เพิ่ม $n$ เป็น 6 ได้ $3.3102$ (ต่ำกว่า 0.7%)

$\iint_R (x^2 + y^2)\,dA = \dfrac{10}{3}$ · midpoint 2×2 ได้ 3.125

## บริเวณที่ไม่ใช่สี่เหลี่ยม: type I, type II และการสลับลำดับ พื้นฐาน

บริเวณในงานจริงแทบไม่เป็นสี่เหลี่ยมผืนผ้า ให้วาดบริเวณก่อน แล้วเลือกว่าจะ “กวาด” ด้วยแถบแนวตั้งหรือแนวนอน: type I ขอบบนและล่างเป็นฟังก์ชันของ $x$ (แถบตั้ง) · type II ขอบซ้ายและขวาเป็นฟังก์ชันของ $y$ (แถบนอน) ขอบเขตของชั้นในได้เป็นฟังก์ชันของตัวแปรนอกได้ แต่ขอบเขตของชั้นนอกต้องเป็นค่าคงที่เสมอ

บริเวณ type I (แถบแนวตั้ง: $y$ ระหว่าง $g_1(x)$ กับ $g_2(x)$) และ type II (แถบแนวนอน: $x$ ระหว่าง $h_1(y)$ กับ $h_2(y)$) ของบริเวณเดียวกัน — การสลับลำดับการอินทิเกรตคือการเปลี่ยนวิธีแบ่ง

M4 Type I region บริเวณ type I

$$R = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}:\qquad \iint_R f\,dA = \int_a^b\!\int_{g_1(x)}^{g_2(x)} f(x, y)\,dy\,dx$$

แถบตั้ง: ลากเส้นตั้งผ่านบริเวณ เส้นเข้าที่ $g_1$ ออกที่ $g_2$ · ขอบชั้นนอก $a, b$ เป็นค่าคงที่

M5 Type II region บริเวณ type II

$$R = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}:\qquad \iint_R f\,dA = \int_c^d\!\int_{h_1(y)}^{h_2(y)} f(x, y)\,dx\,dy$$

แถบนอน: ลากเส้นนอนผ่านบริเวณ เส้นเข้าที่ $h_1$ ออกที่ $h_2$ · เปลี่ยนลำดับ = เปลี่ยนจาก type I เป็น type II (วาดรูปแล้วอ่านขอบใหม่)

ตัวอย่าง M-2 · บริเวณสามเหลี่ยม

### หา $\iint_R xy\,dA$ เมื่อ $R$ เป็นสามเหลี่ยมที่มีจุดยอด $(0,0),\ (2,0),\ (0,2)$

- วาดบริเวณ: เส้นตรงจาก $(2,0)$ ถึง $(0,2)$ คือ $y = 2 - x$ · type I: $0 \le x \le 2,\ 0 \le y \le 2 - x$

- ชั้นใน: $\displaystyle\int_0^{2-x} xy\,dy = x\cdot\dfrac{(2-x)^2}{2}$

- ชั้นนอก: $\displaystyle\dfrac12\int_0^2 x(4 - 4x + x^2)\,dx = \dfrac12\left[2x^2 - \dfrac{4x^3}{3} + \dfrac{x^4}{4}\right]_0^2 = \dfrac12\left(8 - \dfrac{32}{3} + 4\right) = \dfrac12\cdot\dfrac43 = \dfrac23$

- ตรวจด้วยอีกลำดับ (type II: $0 \le y \le 2,\ 0 \le x \le 2 - y$): โดยสมมาตรของ $xy$ ได้ $\tfrac23$ เท่ากัน ✓

$\iint_R xy\,dA = \dfrac23$

ตัวอย่าง M-3 · สลับลำดับเมื่อชั้นในอินทิเกรตไม่ได้

### คำนวณ $\displaystyle\int_0^1\!\int_x^1 e^{y^2}\,dy\,dx$

- $\int e^{y^2}\,dy$ ไม่มีรูปปิดจากฟังก์ชันพื้นฐาน จึงอินทิเกรตตาม $y$ ก่อนไม่ได้

- อ่านบริเวณ: $0 \le x \le 1$ และ $x \le y \le 1$ คือสามเหลี่ยมใต้เส้น $y = 1$ เหนือเส้น $y = x$ (จุดยอด $(0,0),(0,1),(1,1)$)

- เปลี่ยนเป็น type II: $0 \le y \le 1$ และ $0 \le x \le y$ · $\displaystyle\int_0^1\!\int_0^y e^{y^2}\,dx\,dy$

- ชั้นใน (ตาม $x$, $e^{y^2}$ คงที่): $y\,e^{y^2}$ · ชั้นนอก: $\displaystyle\int_0^1 y\,e^{y^2}\,dy = \left[\tfrac12 e^{y^2}\right]_0^1 = \dfrac{e - 1}{2} \approx 0.8591$

$\dfrac{e - 1}{2} \approx 0.8591$

ตัวอย่าง M-4 · พื้นที่ระหว่างเส้นโค้ง

### หาพื้นที่ที่ล้อมด้วย $y = x^2$ และ $y = x$

- จุดตัด: $x^2 = x$ → $x = 0, 1$ · บน $0 < x < 1$ เส้นตรง $y = x$ อยู่เหนือพาราโบลา

- $A = \displaystyle\int_0^1\!\int_{x^2}^{x} dy\,dx = \int_0^1 (x - x^2)\,dx = \dfrac12 - \dfrac13 = \dfrac16$

$A = \dfrac16$ (นี่คืออินทิกรัลสองชั้นของ $f = 1$ · ตรงกับอินทิกรัลตัวแปรเดียว $\int (\text{บน} - \text{ล่าง})\,dx$)

## พิกัดขั้ว (Polar Coordinates) ในอินทิกรัลสองชั้น กลาง

บริเวณวงกลม ครึ่งวงกลม เซกเตอร์ และวงแหวนเขียนในพิกัดฉากยากมาก แต่ในพิกัดขั้วเรียบง่าย: $0 \le r \le R,\ 0 \le \theta \le 2\pi$ กฎคือแทน $x = r\cos\theta,\ y = r\sin\theta$ แล้วเปลี่ยน $dA = r\,dr\,d\theta$ ตัวคูณ $r$ มาจากการที่ “ช่องขั้ว” กว้าง $\Delta r$ และยาวเป็นส่วนโค้ง $r\,\Delta\theta$ ยิ่งไกลจุดกำเนิด ช่องเดียวกันใน $(r,\theta)$ ยิ่งใหญ่

ช่องในพิกัดขั้ว (polar rectangle): กว้าง $\Delta r$ ยาว $r\,\Delta\theta$ จึงมีพื้นที่ $\Delta A \approx r\,\Delta r\,\Delta\theta$ ซึ่งเป็นที่มาของตัวคูณ $r$

M6 Double integral in polar coordinates อินทิกรัลสองชั้นในพิกัดขั้ว

$$\iint_R f(x, y)\,dA = \int_{\alpha}^{\beta}\!\int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta,\ r\sin\theta)\;\underbrace{r}_{\text{Jacobian}}\;dr\,d\theta$$

ใช้เมื่อบริเวณหรือ $f$ มี $x^2 + y^2$ · $r^2 = x^2 + y^2$ · พื้นที่ $A = \tfrac12\int (r_2^2 - r_1^2)\,d\theta$ · ระวังขอบเขต $\theta$ ของบริเวณ (ครึ่งบน $0 \le \theta \le \pi$, ควอดแรนต์แรก $0 \le \theta \le \pi/2$)

ลองในแล็บ: โหมดขั้วใช้ $r$ ระหว่าง $r_1(\theta)$ ถึง $r_2(\theta)$ และ $\theta$ ระหว่างสองค่า เลือกพรีเซ็ต “พื้นที่วงกลม” “ปริมาตรพาราโบลอยด์” หรือ “ใบกลีบ $r = 2\sin 2\theta$” แล้วดูแผนผังช่องที่เป็นรูปพัด

ตัวอย่าง M-5 · ปริมาตรพาราโบลอยด์

### หาปริมาตรใต้ผิว $z = 4 - x^2 - y^2$ เหนือระนาบ $xy$

- ผิวตัดระนาบ $z = 0$ ที่ $x^2 + y^2 = 4$ · บริเวณคือแผ่นวงกลมรัศมี 2: $0 \le r \le 2,\ 0 \le \theta \le 2\pi$

- แทน $x^2 + y^2 = r^2$: $V = \displaystyle\int_0^{2\pi}\!\int_0^2 (4 - r^2)\,r\,dr\,d\theta$

- ชั้นใน: $\displaystyle\int_0^2 (4r - r^3)\,dr = \left[2r^2 - \dfrac{r^4}{4}\right]_0^2 = 8 - 4 = 4$

- ชั้นนอก: $\displaystyle\int_0^{2\pi} 4\,d\theta = 8\pi \approx 25.13$

$V = 8\pi \approx 25.13$ หน่วยปริมาตร (ตรงกับค่าที่แล็บคำนวณ)

ตัวอย่าง M-6 · อินทิกรัลเกาส์เซียน (ไฟฟ้า)

### แสดงว่า $\displaystyle\int_{-\infty}^{\infty} e^{-x^2}dx = \sqrt{\pi}$ ด้วยอินทิกรัลสองชั้น

- ให้ $I = \int_{-\infty}^{\infty} e^{-x^2}dx$ · $I^2 = \int e^{-x^2}dx\int e^{-y^2}dy = \iint_{\mathbb R^2} e^{-(x^2+y^2)}\,dA$

- พิกัดขั้ว: ทั่วระนาบคือ $0 \le r < \infty,\ 0 \le \theta \le 2\pi$ · $I^2 = \displaystyle\int_0^{2\pi}\!\int_0^{\infty} e^{-r^2}\,r\,dr\,d\theta$

- $\displaystyle\int_0^\infty r e^{-r^2}dr = \left[-\tfrac12 e^{-r^2}\right]_0^\infty = \tfrac12$ · $I^2 = 2\pi\cdot\tfrac12 = \pi$ → $I = \sqrt{\pi}$

- ผลนี้คือตัวทำให้เป็นปกติ (normalizing constant) ของการแจกแจงเกาส์เซียน $\dfrac{1}{\sigma\sqrt{2\pi}}e^{-x^2/2\sigma^2}$ ที่ใช้อธิบายสัญญาณรบกวนในระบบสื่อสารและการวัด

$\int_{-\infty}^{\infty} e^{-x^2}dx = \sqrt{\pi}$ (ใช้ตัวคูณ $r$ จึงอินทิเกรตได้ — ในพิกัดฉากไม่มีรูปปิด)

ตัวอย่าง M-7 · พื้นที่กลีบกุหลาบ

### หาพื้นที่หนึ่งกลีบของ $r = 2\sin 2\theta$ ($0 \le \theta \le \pi/2$)

- $A = \displaystyle\int_0^{\pi/2}\!\int_0^{2\sin 2\theta} r\,dr\,d\theta = \int_0^{\pi/2}\dfrac{(2\sin2\theta)^2}{2}\,d\theta = 2\int_0^{\pi/2}\sin^2 2\theta\,d\theta$

- $\sin^2 2\theta = \tfrac12(1 - \cos 4\theta)$ → $2\cdot\tfrac12\left[\theta - \tfrac{\sin4\theta}{4}\right]_0^{\pi/2} = \dfrac{\pi}{2}$

$A = \dfrac{\pi}{2} \approx 1.571$

## อินทิกรัลสามชั้น: พิกัดฉาก ทรงกระบอก และทรงกลม กลาง

เมื่อเพิ่มมิติ $z$ ได้ $\iiint_E f\,dV$ ที่รวม $f$ ทั่วบริเวณตัน $E$ ถ้า $f = 1$ ได้ปริมาตร ถ้า $f = \rho$ (ความหนาแน่น) ได้มวล เลือกพิกัดตามรูปทรง: ฉาก (กล่อง ปริซึม เตตระฮีดรอน) · ทรงกระบอก (ท่อ ถัง กรวย พาราโบลอยด์) · ทรงกลม (ลูกบอล เปลือก ซีกทรงกลม)

พิกัดทรงกระบอก (cylindrical coordinates) $(r, \theta, z)$ และพิกัดทรงกลม (spherical coordinates) $(\rho, \varphi, \theta)$ พร้อมความสัมพันธ์กับ $(x, y, z)$

M7 Triple integral (rectangular) อินทิกรัลสามชั้น (พิกัดฉาก)

$$\iiint_E f\,dV = \int_a^b\!\int_{g_1(x)}^{g_2(x)}\!\int_{u_1(x,y)}^{u_2(x,y)} f(x, y, z)\,dz\,dy\,dx,\qquad V = \iiint_E dV,\quad M = \iiint_E \rho\,dV$$

ขอบชั้นในเป็นฟังก์ชันของตัวแปรนอกได้ · วาดเงาของ $E$ บนระนาบ $xy$ เพื่อหาขอบ $x$ และ $y$ แล้วระบุผิวบน-ล่างของ $z$

M8 Cylindrical coordinates พิกัดทรงกระบอก

$$x = r\cos\theta,\ \ y = r\sin\theta,\ \ z = z;\qquad r^2 = x^2 + y^2;\qquad dV = r\,dz\,dr\,d\theta$$

เหมาะกับรูปที่สมมาตรรอบแกน $z$ · $\iiint f\,dV = \iiint f(r\cos\theta, r\sin\theta, z)\,r\,dz\,dr\,d\theta$

M9 Spherical coordinates พิกัดทรงกลม

$$x = \rho\sin\varphi\cos\theta,\ \ y = \rho\sin\varphi\sin\theta,\ \ z = \rho\cos\varphi;\quad \rho^2 = x^2 + y^2 + z^2;\quad dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$$

$\rho \ge 0$ ระยะจากจุดกำเนิด · $0 \le \varphi \le \pi$ มุมจากแกน $+z$ · $0 \le \theta \le 2\pi$ มุมราบ · ระวังตำราบางเล่นสลับ $\theta$ กับ $\varphi$ (ฟิสิกส์ใช้แบบนี้ ตำราคณิตศาสตร์บางเล่มสลับ)

แล็บสามชั้นรับ $f(x, y, z)$ เสมอในพิกัดฉาก โปรแกรมแทนพิกัดใหม่และคูณจาโคเบียนให้ จุดสีในภาพแสดงตัวอย่างจุดภายในรูปทรง เลือกพรีเซ็ต แล้วลองแก้ขอบเขตเอง

ตัวอย่าง M-8 · เตตระฮีดรอน (พิกัดฉาก)

### หาปริมาตรของรูปตันที่ล้อมด้วยระนาบพิกัดสามระนาบกับ $x + y + z = 1$

- เงาบนระนาบ $xy$: สามเหลี่ยม $0 \le x \le 1,\ 0 \le y \le 1 - x$ · $z$ จาก 0 ถึง $1 - x - y$

- $V = \displaystyle\int_0^1\!\int_0^{1-x}\!\int_0^{1-x-y} dz\,dy\,dx = \int_0^1\!\int_0^{1-x}(1 - x - y)\,dy\,dx = \int_0^1 \dfrac{(1-x)^2}{2}\,dx = \dfrac16$

$V = \dfrac16$ (ตรงกับสูตรปริมาตรพีระมิด $\tfrac13 \cdot \text{ฐาน}\tfrac12 \cdot \text{สูง}1$)

ตัวอย่าง M-9 · กรวย (พิกัดทรงกระบอก)

### หาปริมาตรรูปตันที่อยู่เหนือกรวย $z = r$ และใต้ระนาบ $z = 2$

- กรวยตัดระนาบ $z = 2$ ที่ $r = 2$ · ขอบเขต: $0 \le \theta \le 2\pi,\ 0 \le r \le 2,\ r \le z \le 2$

- $V = \displaystyle\int_0^{2\pi}\!\int_0^2\!\int_r^2 r\,dz\,dr\,d\theta = \int_0^{2\pi}\!\int_0^2 r(2 - r)\,dr\,d\theta$

- ชั้นใน: $\left[r^2 - \dfrac{r^3}{3}\right]_0^2 = 4 - \dfrac83 = \dfrac43$ · ชั้นนอก: $2\pi\cdot\dfrac43 = \dfrac{8\pi}{3}$

- ตรวจด้วยสูตร: ทรงกระบอกรัศมี 2 สูง 2 มีปริมาตร $8\pi$ และกรวยมี $\tfrac13$ ของ $8\pi$ = $\tfrac{8\pi}{3}$ → รูปตันที่ถามคือ “กรวยกลับหัว” ปริมาตร $\tfrac{8\pi}{3}$ ✓

$V = \dfrac{8\pi}{3} \approx 8.378$

ตัวอย่าง M-10 · ทรงกลมและซีกทรงกลม (พิกัดทรงกลม)

### (ก) ปริมาตรทรงกลมรัศมี $R$ (ข) จุดศูนย์กลางมวลของซีกทรงกลมตันรัศมี 1 ความหนาแน่นสม่ำเสมอ

- (ก) $V = \displaystyle\int_0^{2\pi}\!\int_0^{\pi}\!\int_0^{R}\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\cdot 2\cdot\dfrac{R^3}{3} = \dfrac{4\pi R^3}{3}$ (R = 2 ได้ $\tfrac{32\pi}{3} = 33.51$)

- (ข) ซีกบน: $0 \le \varphi \le \pi/2$ · ปริมาตร $= \tfrac{2\pi}{3}$

-
$$\iiint z\,dV = \int_0^{2\pi}\!\int_0^{\pi/2}\!\int_0^1 (\rho\cos\varphi)\,\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\cdot\dfrac14\cdot\dfrac12 = \dfrac{\pi}{4}$$

- $\bar z = \dfrac{\pi/4}{2\pi/3} = \dfrac38$ และโดยสมมาตร $\bar x = \bar y = 0$

(ก) $V = \tfrac43\pi R^3$ · (ข) $(\bar x, \bar y, \bar z) = (0, 0, \tfrac38 R)$ สำหรับซีกทรงกลมรัศมี $R$ (ตรงกับตารางในหนังสือกลศาสตร์วิศวกรรม)

## การเปลี่ยนตัวแปรและ Jacobian ขั้นสูง

พิกัดขั้วเป็นกรณีเฉพาะของการเปลี่ยนตัวแปรทั่วไป $x = x(u, v),\ y = y(u, v)$ ซึ่งแปลงช่องสี่เหลี่ยมเล็กบนระนาบ $uv$ ให้เป็นสี่เหลี่ยมด้านขนานโค้งบนระนาบ $xy$ ขนาดพื้นที่ใหม่เท่ากับ $|J|$ คูณพื้นที่เดิม โดย $J$ คือดีเทอร์มิแนนต์ของเมทริกซ์จาโคเบียน (จากบทอนุพันธ์ย่อย) ใช้แล็บด้านล่างลากแถบ $(u_0, v_0)$ และขนาดช่อง แล้วเทียบ “พื้นที่ภาพจริง” กับ $|\det J|\Delta u\Delta v$

M10 Change of variables (2D) เปลี่ยนตัวแปร (สองมิติ)

$$\iint_R f(x, y)\,dx\,dy = \iint_S f\big(x(u,v),\,y(u,v)\big)\left|\frac{\partial(x, y)}{\partial(u, v)}\right|du\,dv,\qquad \frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix} x_u & x_v\\ y_u & y_v\end{vmatrix}$$

การแปลงต้องหนึ่งต่อหนึ่ง (อาจยกเว้นขอบ) · พิกัดขั้ว $J = r$ · $|J|$ ใช้ค่าสัมบูรณ์เสมอ (พื้นที่ไม่ติดลบ) · เลือกตัวแปรใหม่ให้บริเวณ $S$ กลายเป็นสี่เหลี่ยมผืนผ้า

M11 Jacobians of standard coordinates จาโคเบียนของพิกัดมาตรฐาน

$$\text{ขั้ว: } \left|\tfrac{\partial(x,y)}{\partial(r,\theta)}\right| = r\qquad \text{ทรงกระบอก: } r\qquad \text{ทรงกลม: } \left|\tfrac{\partial(x,y,z)}{\partial(\rho,\varphi,\theta)}\right| = \rho^2\sin\varphi$$

ตัวคูณทั้งสามคือที่มาของ $r\,dr\,d\theta,\ r\,dz\,dr\,d\theta,\ \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$ · สามตัวแปร $J$ เป็นดีเทอร์มิแนนต์ 3×3

จาโคเบียน (Jacobian): ช่องเล็ก $\Delta u\times\Delta v$ ถูกแปลงเป็นสี่เหลี่ยมด้านขนานที่ขึงด้วย $(x_u, y_u)\Delta u$ และ $(x_v, y_v)\Delta v$ พื้นที่ใหม่คือ $|\det J|\,\Delta u\,\Delta v$

ตัวอย่าง M-11 · พื้นที่วงรี

### หาพื้นที่ภายในวงรี $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} \le 1$

- เปลี่ยนตัวแปร $x = au,\ y = bv$ · วงรีกลายเป็นแผ่นวงกลมหนึ่งหน่วย $u^2 + v^2 \le 1$

- $J = \begin{vmatrix} a & 0\\ 0 & b\end{vmatrix} = ab$

- $A = \iint dx\,dy = \iint_{u^2+v^2\le1} ab\,du\,dv = ab\cdot\pi\cdot1^2 = \pi ab$

- ตัวอย่างเชิงตัวเลข: $a = 2,\ b = 1$ ได้ $A = 2\pi = 6.283$ (แล็บ Jacobian โหมด “วงรี” ให้ $\det J = 2u$ เมื่อรวม $x = 2u\cos v$ ในพิกัดขั้ววงรี)

$A = \pi ab$

## มวล จุดศูนย์กลางมวล และโมเมนต์ความเฉื่อย กลาง

แผ่นบางที่ความหนาแน่นผิว $\rho(x, y)$ (มวลต่อพื้นที่) มีมวล $M = \iint\rho\,dA$ จุดศูนย์กลางมวลคือค่าเฉลี่ยถ่วงน้ำหนักของพิกัด และโมเมนต์ความเฉื่อยวัดความ “ต้านการหมุน” ซึ่งใช้ในสมการ $\tau = I\alpha$ ของเครื่องกล และ $I$ ของหน้าตัดคาน (ใส่ $\rho = 1$) ในงานโยธา เปิดสวิตช์ “ถือว่า $f$ = ความหนาแน่น” ในแล็บเพื่อให้โปรแกรมคำนวณทั้งหมดพร้อมกัน

M12 Mass and center of mass มวลและจุดศูนย์กลางมวล

$$M = \iint_R \rho\,dA,\qquad \bar x = \frac{1}{M}\iint_R x\,\rho\,dA,\qquad \bar y = \frac{1}{M}\iint_R y\,\rho\,dA$$

$\rho = 1$: จุดศูนย์ถ่วงทางเรขาคณิต (centroid) · สามมิติ $\bar z = \tfrac1M\iiint z\rho\,dV$ · บริเวณสมมาตรให้ $\bar x$ หรือ $\bar y$ อยู่ที่แกนสมมาตร

M13 Moments of inertia โมเมนต์ความเฉื่อย

$$I_x = \iint y^2\rho\,dA,\qquad I_y = \iint x^2\rho\,dA,\qquad I_0 = I_x + I_y = \iint (x^2 + y^2)\rho\,dA,\qquad I_z = \iiint (x^2 + y^2)\rho\,dV$$

$I_x$ ถ่วงด้วยระยะจากแกน $x$ (จึงเป็น $y^2$) · $I_0$ = โมเมนต์เชิงขั้ว · ทฤษฎีบทแกนขนาน $I = I_c + Md^2$ · รัศมีไจเรชัน $k = \sqrt{I/M}$

ตัวอย่าง M-12 · แผ่นครึ่งวงกลม

### แผ่นครึ่งวงกลมรัศมี 1 ($y \ge 0$) ความหนาแน่นสม่ำเสมอ $\rho = 1$ หา $M,\ \bar y,\ I_x,\ I_y$

- ขอบเขตขั้ว: $0 \le r \le 1,\ 0 \le \theta \le \pi$ · $M = \displaystyle\int_0^\pi\!\int_0^1 r\,dr\,d\theta = \dfrac{\pi}{2}$

- $\iint y\,dA = \displaystyle\int_0^\pi\sin\theta\,d\theta\int_0^1 r^2\,dr = 2\cdot\dfrac13 = \dfrac23$ → $\bar y = \dfrac{2/3}{\pi/2} = \dfrac{4}{3\pi} \approx 0.4244$ · $\bar x = 0$ (สมมาตร)

- $I_x = \iint y^2\,dA = \displaystyle\int_0^\pi\sin^2\theta\,d\theta\int_0^1 r^3\,dr = \dfrac{\pi}{2}\cdot\dfrac14 = \dfrac{\pi}{8}$ · $I_y = \iint x^2\,dA = \dfrac{\pi}{8}$

- $I_0 = \dfrac{\pi}{4}$ และเมื่อ $\rho$ เป็นมวลต่อพื้นที่ $M = \dfrac{\pi}{2}$ ได้ $I_0 = \tfrac12 M R^2$ เหมือนจานกลมเต็มดวง (ซีกก็มี $I_0$ อัตราส่วนเดียวกัน)

$M = \dfrac{\pi}{2}$ · $\bar y = \dfrac{4}{3\pi}$ · $I_x = I_y = \dfrac{\pi}{8}$ · $I_0 = \dfrac{\pi}{4}$

ตัวอย่าง M-13 · โมเมนต์ความเฉื่อยของกระบอกและทรงกลม (เครื่องกล)

### แสดงว่าทรงกระบอกตันรัศมี $R$ สูง $h$ มี $I_z = \tfrac12 MR^2$ และทรงกลมตันมี $I = \tfrac25 MR^2$ (ความหนาแน่น $\rho_0$ สม่ำเสมอ)

- ทรงกระบอก (พิกัดทรงกระบอก): $I_z = \displaystyle\int_0^{2\pi}\!\int_0^R\!\int_0^h \rho_0\,r^2\cdot r\,dz\,dr\,d\theta = \rho_0\cdot2\pi\cdot\dfrac{R^4}{4}\cdot h = \dfrac{\pi\rho_0 hR^4}{2}$

- มวล $M = \rho_0\pi R^2h$ ดังนั้น $I_z = \dfrac{1}{2}MR^2$ ✓

- ทรงกลม (พิกัดทรงกลม): $(x^2 + y^2) = \rho^2\sin^2\varphi$ · $I = \rho_0\displaystyle\int_0^{2\pi}\!\int_0^\pi\!\int_0^R \rho^2\sin^2\varphi\cdot\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = \rho_0\cdot\dfrac{R^5}{5}\cdot\dfrac43\cdot2\pi = \dfrac{8\pi\rho_0R^5}{15}$

- มวล $M = \dfrac{4\pi\rho_0R^3}{3}$ → $I = \dfrac{8\pi/15}{4\pi/3}MR^2 = \dfrac25MR^2$ ✓

กระบอกตัน $I_z = \tfrac12MR^2$ · ทรงกลมตัน $I = \tfrac25MR^2$ (ใช้ $\int_0^\pi\sin^3\varphi\,d\varphi = \tfrac43$)

ตัวอย่าง M-14 · ประจุรวมบนแผ่นกลม (ไฟฟ้า)

### แผ่นตัวนำกลมรัศมี $a = 5$ cm มีความหนาแน่นประจุผิว $\sigma(r) = \sigma_0 e^{-r/b}$ เมื่อ $\sigma_0 = 20$ nC/m² และ $b = 2$ cm จงหาประจุรวม

- $Q = \displaystyle\iint\sigma\,dA = \int_0^{2\pi}\!\int_0^{a}\sigma_0 e^{-r/b}\,r\,dr\,d\theta = 2\pi\sigma_0\int_0^a r e^{-r/b}dr$

- อินทิเกรตทีละส่วน: $\displaystyle\int_0^a r e^{-r/b}dr = b^2\left[1 - \left(1 + \dfrac{a}{b}\right)e^{-a/b}\right]$

- แทน $a/b = 2.5$: $e^{-2.5} = 0.08208$ · วงเล็บ $= 1 - 3.5(0.08208) = 0.7127$

- $Q = 2\pi(20\times10^{-9})(0.02)^2(0.7127) = 3.58\times10^{-11}$ C

$Q \approx 35.8$ pC (ถ้าประจุสม่ำเสมอที่ $\sigma_0$ ทั้งแผ่นจะได้ 157 pC ซึ่งมากกว่า 4.4 เท่า เพราะประจุจริงกระจุกใกล้ศูนย์กลาง)

## ข้อผิดพลาดที่พบบ่อย พื้นฐาน

- ไม่วาดบริเวณ ก่อนเขียนขอบเขต · ส่วนใหญ่ที่ผิดเพราะอ่านขอบจากสมการโดยไม่เห็นรูป

- ขอบชั้นนอกเป็นตัวแปร · ขอบชั้นนอกต้องเป็นค่าคงที่ (ผลลัพธ์สุดท้ายต้องเป็นตัวเลข)

- ลืมตัวคูณ $r$ ในพิกัดขั้วและทรงกระบอก และ $\rho^2\sin\varphi$ ในพิกัดทรงกลม

- สลับลำดับโดยไม่เปลี่ยนขอบ · เปลี่ยนลำดับ $dy\,dx$ เป็น $dx\,dy$ ต้องอ่านขอบจากรูปใหม่ทุกตัว

- ใช้ $\varphi$ กับ $\theta$ สลับกัน ระหว่างตำราต่างเล่ม · ตรวจนิยามก่อน (ในเว็บนี้ $\varphi$ = มุมจากแกน $z$, $\theta$ = มุมราบ)

- ได้ปริมาตรติดลบ · ตรวจว่า “บน − ล่าง” ถูกด้าน; พื้นที่และปริมาตรไม่เป็นลบ

ไปต่อที่ฟังก์ชันเวกเตอร์ ซึ่งอธิบายการเคลื่อนที่ของวัตถุในอวกาศด้วย $\mathbf r(t)$ และเตรียมไปสู่อินทิกรัลตามเส้นและบนผิว

## คำถามที่พบบ่อย

อินทิกรัลสองชั้น (double integral) คืออะไร คำนวณอย่างไร?
คือผลรวมของค่า $f(x,y)$ คูณพื้นที่ช่องเล็ก $\Delta A$ ทั่วบริเวณ $R$ เมื่อ $f \ge 0$ จะเป็นปริมาตรใต้ผิว $z = f(x, y)$ เหนือ $R$ คำนวณด้วยทฤษฎีบทฟูบินี (Fubini) โดยทำทีละชั้น: อินทิเกรตตัวแปรในสุดก่อนโดยถือตัวแปรนอกเป็นค่าคงที่ แล้วอินทิเกรตผลลัพธ์ตามตัวแปรนอก เช่น $\int_0^1\!\int_0^2 (x^2+y^2)\,dy\,dx = \int_0^1 (2x^2 + \tfrac83)\,dx = \tfrac{10}{3}$

เมื่อไรควรเปลี่ยนเป็นพิกัดขั้ว (polar) ในอินทิกรัลสองชั้น?
เมื่อบริเวณเป็นวงกลม ครึ่งวงกลม วงแหวน หรือเซกเตอร์ หรือเมื่อ integrand มีกลุ่ม $x^2 + y^2$ แทน $x = r\cos\theta,\ y = r\sin\theta$ และเปลี่ยน $dA$ เป็น $r\,dr\,d\theta$ อย่าลืมตัวคูณ $r$ เด็ดขาด เพราะช่องเล็กในพิกัดขั้วกว้าง $dr$ และยาว $r\,d\theta$ ตัวอย่าง $\iint e^{-(x^2+y^2)}\,dA$ ทั่วระนาบ = $\pi$ คำนวณได้ง่ายในพิกัดขั้ว แต่แทบทำไม่ได้ในพิกัดฉาก

พิกัดทรงกระบอกกับพิกัดทรงกลมเลือกใช้อย่างไร?
พิกัดทรงกระบอก $(r, \theta, z)$ เหมาะกับรูปที่มีแกนสมมาตร เช่นทรงกระบอก กรวย พาราโบลอยด์ และมี $dV = r\,dz\,dr\,d\theta$ ส่วนพิกัดทรงกลม $(\rho, \varphi, \theta)$ เหมาะกับรูปที่สมมาตรรอบจุด เช่นทรงกลม ซีกทรงกลม เปลือกทรงกลม และมี $dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$ ข้อสังเกต: ถ้าสมการขอบเขตมี $x^2 + y^2 + z^2$ ให้นึกถึงทรงกลมก่อน ถ้ามี $x^2 + y^2$ อย่างเดียวให้นึกถึงทรงกระบอก

สลับลำดับการอินทิเกรต (change order of integration) ทำอย่างไร?
วาดบริเวณก่อน แล้วอธิบายบริเวณเดิมด้วยลำดับใหม่ เช่น $\int_0^1\!\int_x^1 e^{y^2}\,dy\,dx$ อินทิเกรต $e^{y^2}$ ตาม $y$ ไม่ได้ แต่บริเวณคือสามเหลี่ยม $0 \le x \le y \le 1$ สลับเป็น $\int_0^1\!\int_0^y e^{y^2}\,dx\,dy = \int_0^1 y e^{y^2}\,dy = \tfrac{e-1}{2}$ ใช้สลับเมื่อลำดับเดิมอินทิเกรตไม่ได้หรือขอบเขตซับซ้อน

จาโคเบียน (Jacobian) คืออะไร ทำไมต้องคูณเวลาเปลี่ยนตัวแปร?
จาโคเบียนคือดีเทอร์มิแนนต์ของเมทริกซ์อนุพันธ์ย่อยของการแปลง $\partial(x,y)/\partial(u,v)$ มันบอกว่าช่องเล็กบนระนาบ $uv$ ถูกขยายหรือหดเป็นกี่เท่าเมื่อแปลงไปเป็นระนาบ $xy$ จึงต้องคูณ $|J|$ เพื่อรักษาพื้นที่ที่ถูกต้อง ในพิกัดขั้ว $J = r$ ในพิกัดทรงกระบอก $J = r$ ในพิกัดทรงกลม $J = \rho^2\sin\varphi$ สำหรับวงรี $x = au,\ y = bv$ ได้ $J = ab$ จึงได้พื้นที่ $\pi ab$

## คำถามที่พบบ่อย (FAQ)

**อินทิกรัลสองชั้น (double integral) คืออะไร คำนวณอย่างไร?**
คือผลรวมของค่า $f(x,y)$ คูณพื้นที่ช่องเล็ก $\Delta A$ ทั่วบริเวณ $R$ เมื่อ $f \ge 0$ จะเป็นปริมาตรใต้ผิว $z = f(x, y)$ เหนือ $R$ คำนวณด้วยทฤษฎีบทฟูบินี (Fubini) โดยทำทีละชั้น: อินทิเกรตตัวแปรในสุดก่อนโดยถือตัวแปรนอกเป็นค่าคงที่ แล้วอินทิเกรตผลลัพธ์ตามตัวแปรนอก เช่น $\int_0^1\!\int_0^2 (x^2+y^2)\,dy\,dx = \int_0^1 (2x^2 + \tfrac83)\,dx = \tfrac{10}{3}$
