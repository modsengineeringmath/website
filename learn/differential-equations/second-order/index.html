    คำถามที่พบบ่อย

    สมการลักษณะเฉพาะ (characteristic equation) มาจากไหน?

    ลองแทน y = e^{rt} ลงใน ay″ + by′ + cy = 0 จะได้ e^{rt}(ar² + br + c) = 0 เนื่องจาก e^{rt} ไม่เคยเป็นศูนย์ จึงต้องมี ar² + br + c = 0 สมการพีชคณิตนี้คือสมการลักษณะเฉพาะ รากของมันบอกรูปของคำตอบทั้งหมด

    ทำไมรากเชิงซ้อนให้คำตอบเป็น cos และ sin?

    รากเชิงซ้อน α ± jβ ให้ e^{(α+jβ)t} = e^{αt}(cos βt + j sin βt) ตามสูตรออยเลอร์ เนื่องจากสมการมีสัมประสิทธิ์จริง ส่วนจริงและส่วนจินตภาพแยกกันเป็นคำตอบได้ จึงได้คำตอบจริง e^{αt}(C₁ cos βt + C₂ sin βt)

    ทำไมรากซ้ำต้องคูณ t?

    รากซ้ำ r ให้ e^{rt} มาเพียงตัวเดียว แต่สมการอันดับสองต้องมีคำตอบอิสระสองตัว การลดอันดับ (reduction of order) โดยลอง y = v(t)e^{rt} จะได้ v″ = 0 ดังนั้น v = C₁ + C₂t คำตอบตัวที่สองจึงเป็น te^{rt}

    จะเขียน C₁ cos ωt + C₂ sin ωt เป็นคลื่นเดียวอย่างไร?

    เขียนเป็น R cos(ωt − φ) โดย R = √(C₁² + C₂²) และ tan φ = C₂/C₁ (เลือก φ ให้อยู่ในจตุภาคเดียวกับจุด (C₁, C₂)) มาจากสูตรผลบวกมุม cos(A − B) = cos A cos B + sin A sin B
