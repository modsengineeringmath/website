    คำถามที่พบบ่อย

    ตัวประกอบอินทิเกรต (integrating factor) คืออะไร?

    สำหรับสมการ y′ + p(t)y = q(t) ตัวประกอบอินทิเกรตคือ μ(t) = e^{∫p dt} เมื่อคูณทั้งสมการด้วย μ ด้านซ้ายจะกลายเป็นอนุพันธ์ของผลคูณ (μy)′ พอดี จึงอินทิเกรตได้ทันทีเป็น μy = ∫μq dt + C

    จะรู้ได้อย่างไรว่าสมการแยกตัวแปรได้?

    ถ้าจัดให้อยู่ในรูป dy/dx = g(x)h(y) ได้ คือด้านขวาเป็นผลคูณของฟังก์ชัน x ล้วนกับฟังก์ชัน y ล้วน ก็แยกได้ เช่น y′ = xy แยกได้ แต่ y′ = x + y แยกไม่ได้ ต้องใช้ตัวประกอบอินทิเกรต

    ค่าคงที่เวลา τ ของวงจร RC คืออะไร?

    τ = RC เป็นเวลาที่แรงดันตัวเก็บประจุชาร์จได้ 63.2% ของค่าสุดท้าย มาจากคำตอบ v = Vs(1 − e^{−t/RC}) ที่ t = τ ได้ 1 − e^{−1} ≈ 0.632 หลัง 5τ ถือว่าชาร์จเต็มในทางปฏิบัติ (99.3%)

    สมการแม่นตรงตรวจอย่างไร?

    เขียนเป็น M(x, y)dx + N(x, y)dy = 0 แล้วเทียบ ∂M/∂y กับ ∂N/∂x ถ้าเท่ากันเป็นสมการแม่นตรง คำตอบคือ F(x, y) = C โดย ∂F/∂x = M และ ∂F/∂y = N

(Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ
