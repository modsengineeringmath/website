# สมการเชิงอนุพันธ์อันดับหนึ่ง (First-Order ODEs): แยกตัวแปร ตัวประกอบอินทิเกรต แม่นตรง เบอร์นูลลี และงานจริง

// บทที่ 28.1 · สมการเชิงอนุพันธ์ · First-Order ODEs


สมการอันดับหนึ่งมีหน้าตาทั่วไปเป็น $y' = f(t, y)$ ไม่มีวิธีเดียวที่แก้ได้ทุกตัว แต่มีห้ารูปแบบที่พบบ่อยจนครอบคลุมเกือบทุกโจทย์ในห้องเรียนและงานวงจร หน้านี้เรียงจากวิธีที่ใช้บ่อยที่สุด ท้ายแต่ละวิธีมีตัวอย่างจริงทางไฟฟ้าหรือฟิสิกส์ และมีแล็บที่แก้สมการแสดงวิธีทำให้ดูทุกขั้น

## 1. แยกตัวแปร (Separable equations) พื้นฐาน

ถ้าด้านขวาเขียนเป็นผลคูณ $g(t)\,h(y)$ ได้ ให้ย้าย y ทั้งหมดไปอยู่กับ dy และ t ทั้งหมดไปอยู่กับ dt แล้วอินทิเกรตแยกกัน

$$\frac{dy}{dt} = g(t)\,h(y) \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(t)\,dt + C$$

การ “ย้าย dt ข้ามฝั่ง” ดูเหมือนเล่นกลกับสัญลักษณ์ แต่ที่จริงคือกฎลูกโซ่ย้อนกลับ กฎลูกโซ่ ถ้า $H(y) = \int dy/h(y)$ แล้ว $\tfrac{d}{dt}H(y(t)) = \tfrac{1}{h(y)}\,y'$ ซึ่งเท่ากับ $g(t)$ พอดี

ตัวอย่าง 1

### $y' = ty,\ y(0) = 1$

- แยก: $\dfrac{dy}{y} = t\,dt$

- อินทิเกรต: $\ln|y| = \dfrac{t^2}{2} + C$

- ถอด ln: $y = Ae^{t^2/2}$ และ $y(0) = 1$ ได้ $A = 1$

$y = e^{t^2/2}$
ตรวจ: $y' = t\,e^{t^2/2} = ty$ ✓

ตัวอย่าง 2 · คำตอบเป็น tan

### $y' = 1 + y^2,\ y(0) = 0$

- แยก: $\dfrac{dy}{1 + y^2} = dt$

- อินทิเกรตฝั่งซ้ายได้ arctan ฟังก์ชันตรีโกณผกผัน

$$\tan^{-1}y = t + C,\quad y(0) = 0 \Rightarrow C = 0$$

- กลับด้วย tan: $y = \tan t$ พีทาโกรัสแบบ tan

$y = \tan t$ · ตรวจ: $(\tan t)' = \sec^2t = 1 + \tan^2t = 1 + y^2$ ✓ คำตอบพุ่งไปอนันต์ที่ $t = \pi/2$ ทั้งที่สมการดูเรียบร้อยดี นี่คือตัวอย่างว่าสมการไม่เชิงเส้นมีคำตอบที่ “ระเบิด” ในเวลาจำกัดได้

### การเย็นตัวของนิวตัน

อุณหภูมิวัตถุ T เปลี่ยนด้วยอัตราที่แปรผันตามผลต่างกับอุณหภูมิห้อง $T_a$: $\;T' = -k(T - T_a)$ แยกตัวแปรได้ $T = T_a + (T_0 - T_a)e^{-kt}$

ตัวอย่าง 3

### กาแฟ 90°C ในห้อง 30°C ผ่านไป 10 นาทีเหลือ 70°C อีกนานเท่าไรจึงเหลือ 40°C

- $70 = 30 + 60e^{-10k} \Rightarrow e^{-10k} = \tfrac23 \Rightarrow k = \tfrac{\ln 1.5}{10} \approx 0.04055\ \text{min}^{-1}$

- $40 = 30 + 60e^{-kt} \Rightarrow t = \tfrac{\ln 6}{k} \approx 44.2$ นาที

ประมาณ 44 นาทีนับจากเริ่ม (อีกราว 34 นาทีหลังจากวัดได้ 70°C)

## 2. สมการเชิงเส้นและตัวประกอบอินทิเกรต (Integrating factor) พื้นฐาน

รูปมาตรฐานคือ

$$y' + p(t)\,y = q(t)$$

ด้านซ้ายเกือบจะเป็นอนุพันธ์ของผลคูณอยู่แล้ว ขาดแค่ตัวคูณที่เหมาะ ถ้าคูณทั้งสมการด้วย $\mu(t)$ แล้วอยากให้ด้านซ้ายเป็น $(\mu y)' = \mu y' + \mu'y$ กฎผลคูณ ต้องมี $\mu' = p\,\mu$ ซึ่งเป็นสมการแยกตัวแปรได้ทันที

$$\mu(t) = e^{\int p(t)\,dt} \quad\Longrightarrow\quad (\mu y)' = \mu q \quad\Longrightarrow\quad y = \frac{1}{\mu}\left(\int\mu q\,dt + C\right)$$

ขั้นตอนจำง่าย: (1) จัดให้สัมประสิทธิ์ของ y′ เป็น 1 (2) หา μ (3) เขียน $(\mu y)' = \mu q$ (4) อินทิเกรต (5) หารด้วย μ

ตัวอย่าง 4

### $y' + 2y = 4,\ y(0) = 0$

- $p = 2$ ได้ $\mu = e^{2t}$

- $(e^{2t}y)' = 4e^{2t} \Rightarrow e^{2t}y = 2e^{2t} + C$

- $y = 2 + Ce^{-2t}$ และ $y(0) = 0$ ได้ $C = -2$

$y = 2\big(1 - e^{-2t}\big)$ ขึ้นจาก 0 ไปหา 2 แบบเดียวกับตัวเก็บประจุที่กำลังชาร์จ

ตัวอย่าง 5 · สัมประสิทธิ์ไม่คงที่

### $y' + \dfrac{y}{x} = x^2,\ x > 0$

- $\mu = e^{\int dx/x} = e^{\ln x} = x$

- $(xy)' = x^3 \Rightarrow xy = \dfrac{x^4}{4} + C$

$y = \dfrac{x^3}{4} + \dfrac{C}{x}$

ตัวอย่าง 6 · แรงขับเป็น sin

### $y' + y = \sin t,\ y(0) = 0$

- $\mu = e^t$ ได้ $(e^ty)' = e^t\sin t$ อินทิกรัลนี้ทำด้วยทีละส่วนแบบวนกลับ (ดูเฉลยอินทิเกรต #007)

$$e^ty = \tfrac{e^t}{2}(\sin t - \cos t) + C$$

- $y = \tfrac12(\sin t - \cos t) + Ce^{-t}$ และ $y(0) = 0$ ได้ $C = \tfrac12$

- รวมสองพจน์ตรีโกณเป็นคลื่นเดียว $R = \sqrt{(\tfrac12)^2 + (\tfrac12)^2} = \tfrac{\sqrt2}{2}$ รวมเป็นคลื่นเดียว

$$\tfrac12(\sin t - \cos t) = \tfrac{\sqrt2}{2}\sin\!\Big(t - \frac{\pi}{4}\Big)$$

รวมเป็นคลื่นเดียว สูตรผลบวกมุมของ sin มุมพิเศษ

$y = \tfrac{\sqrt2}{2}\sin\!\big(t - \tfrac{\pi}{4}\big) + \tfrac12e^{-t}$ · ส่วน $e^{-t}$ คือช่วงชั่วครู่ (transient) ที่หายไป ส่วน sin คือสภาวะอยู่ตัว (steady state) ที่ตามหลังแรงขับ 45° และเล็กลงเหลือ 0.707 เท่า

## แล็บ: แก้ $ay' + by = f(t)$ พร้อมวิธีทำ

ค่าเริ่มต้นคือวงจร RC ที่ $RC = 0.5$ วินาที ชาร์จจากแหล่งจ่าย 12 V ($a = 0.5,\ b = 1$) ลองเปลี่ยนแรงขับเป็น cos หรือ sin แล้วดูว่าขั้นตอนเปลี่ยนไปอย่างไร คำตอบจะแสดงหลังจากตรวจเทียบกับวิธีเชิงตัวเลขแล้วเท่านั้น

## วงจร RC และ RL: สมการอันดับหนึ่งที่วิศวกรไฟฟ้าเจอทุกวัน

### RC ชาร์จ

KVL รอบวง: $V_s = Ri + v$ และ $i = C\,v'$ จึงได้

$$RC\,v' + v = V_s \quad\Longrightarrow\quad v(t) = V_s\big(1 - e^{-t/\tau}\big),\quad \tau = RC$$

| เวลา | τ | 2τ | 3τ | 4τ | 5τ |

| % ของค่าสุดท้าย | 63.2 | 86.5 | 95.0 | 98.2 | 99.3 |

ตัวอย่างตัวเลข: R = 10 kΩ, C = 10 µF ได้ τ = 0.1 s ชาร์จเต็มในทางปฏิบัติที่ 0.5 s ที่ t = 0.1 s แรงดันเป็น 63.2% ของแหล่งจ่าย

### RL ป้อนไฟ AC: เฟสตามหลังมาจากไหน

$L\,i' + Ri = V_m\sin\omega t$ แก้ด้วยตัวประกอบอินทิเกรตหรือเดาสัมประสิทธิ์ จะได้ส่วนสภาวะอยู่ตัว

$$i_{ss}(t) = \frac{V_m}{\sqrt{R^2 + (\omega L)^2}}\sin(\omega t - \varphi),\qquad \tan\varphi = \frac{\omega L}{R}$$

รวมเป็นคลื่นเดียว สูตรผลบวกมุมของ sin
ตัวหาร $\sqrt{R^2 + (\omega L)^2}$ คือขนาดอิมพีแดนซ์ และมุม φ คือมุมที่กระแสตามหลังแรงดัน ทั้งสองค่าโผล่ออกมาจากการรวม $A\sin\omega t + B\cos\omega t$ เป็นคลื่นเดียว ตัวอย่าง R = 10 Ω, L = 0.1 H, 50 Hz, $V_m = 325$ V ได้ $\omega L = 31.42\ \Omega$, $|Z| = 32.97\ \Omega$, $I_m \approx 9.87$ A และ $\varphi \approx 72.3^\circ$ เทียบกับวิธีเฟสเซอร์ในวิเคราะห์วงจร AC ได้ผลเดียวกัน

### ถังผสม

ถังน้ำ 100 L รับน้ำเกลือเข้มข้น 10 g/L ด้วยอัตรา 5 L/min ปล่อยออกด้วยอัตราเดียวกัน ถ้าตอนแรกเป็นน้ำจืด ให้ A(t) เป็นมวลเกลือ (g)

$$A' = \underbrace{10\times5}_{\text{เข้า}} - \underbrace{\frac{A}{100}\times5}_{\text{ออก}} = 50 - \frac{A}{20} \;\Longrightarrow\; A(t) = 1000\big(1 - e^{-t/20}\big)$$

หน้าตาเหมือนวงจร RC ทุกประการ τ = 20 นาที และค่าสุดท้ายคือ 1000 g ซึ่งก็คือความเข้มข้นขาเข้าคูณปริมาตร

## 3. สมการแม่นตรง (Exact equations) กลาง

เขียนสมการเป็น $M(x,y)\,dx + N(x,y)\,dy = 0$ ถ้ามีฟังก์ชัน $F(x, y)$ ที่ $F_x = M$ และ $F_y = N$ ด้านซ้ายคือ $dF$ สมการจึงบอกว่า $F = C$ ตรวจได้ง่ายเพราะอนุพันธ์ย่อยผสมต้องเท่ากัน

$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

ตัวอย่าง 7

### $(2xy + 3)\,dx + (x^2 - 1)\,dy = 0$

- $M_y = 2x,\ N_x = 2x$ เท่ากัน เป็นสมการแม่นตรง

- อินทิเกรต M เทียบ x: $F = x^2y + 3x + g(y)$

- ดิฟเทียบ y ต้องได้ N: $x^2 + g'(y) = x^2 - 1 \Rightarrow g = -y$

$x^2y + 3x - y = C$ หรือ $y = \dfrac{C - 3x}{x^2 - 1}$

## 4. สมการเอกพันธ์แบบ y/x กลาง

ถ้า $y' = F\!\left(\tfrac{y}{x}\right)$ ให้ $v = \tfrac yx$ หรือ $y = vx$ จะได้ $y' = v + xv'$ สมการกลายเป็น $xv' = F(v) - v$ ซึ่งแยกตัวแปรได้

ตัวอย่าง 8

### $y' = \dfrac{x + y}{x},\ x > 0$

- $F(v) = 1 + v$ ได้ $v + xv' = 1 + v \Rightarrow v' = \tfrac1x$

- $v = \ln x + C$

$y = x\ln x + Cx$ · ตรวจ: $y' = \ln x + 1 + C = \tfrac{x + y}{x}$ ✓

## 5. สมการเบอร์นูลลี (Bernoulli) ขั้นสูง

รูป $y' + p\,y = q\,y^n$ ไม่เชิงเส้นเพราะมี $y^n$ แต่ถ้าแทน $v = y^{1-n}$ จะกลายเป็นสมการเชิงเส้นในตัวแปร v

ตัวอย่าง 9

### $y' + y = y^2$

- $n = 2$ แทน $v = y^{-1}$ ได้ $v' = -y^{-2}y'$

- หารสมการด้วย $-y^2$: $v' - v = -1$ เป็นเชิงเส้น ตัวประกอบอินทิเกรต

- $\mu = e^{-x}$ ได้ $v = 1 + Ce^{x}$

$y = \dfrac{1}{1 + Ce^{x}}$ · รูปแบบเดียวกับสมการโลจิสติกของประชากร

## จุดที่มักพลาด

- ลืมทำสัมประสิทธิ์ของ y′ ให้เป็น 1 ก่อนหา μ เช่น $2y' + 4y = 8$ ต้องหารสองก่อน p จึงเป็น 2 ไม่ใช่ 4

- เติม +C ผิดที่ ต้องเติมตอนอินทิเกรต $\int\mu q\,dt$ ไม่ใช่หลังหารด้วย μ เพราะ C ต้องถูกหารด้วย μ ด้วย

- ทิ้งคำตอบคงที่ตอนแยกตัวแปร การหารด้วย h(y) ทำให้คำตอบ $h(y) = 0$ หายไป เช่น $y' = y^2$ มี $y = 0$ เป็นคำตอบด้วย

- ใช้องศาใน sin, cos ของแรงขับ ω ต้องเป็นเรเดียนต่อวินาที มุมเป็นเรเดียน

ต่อไป: สมการอันดับสอง ที่คำตอบแกว่งเป็นคลื่นได้ และฝึกโจทย์ที่ชุด A

## คำถามที่พบบ่อย

ตัวประกอบอินทิเกรต (integrating factor) คืออะไร?
สำหรับสมการ y′ + p(t)y = q(t) ตัวประกอบอินทิเกรตคือ μ(t) = e^{∫p dt} เมื่อคูณทั้งสมการด้วย μ ด้านซ้ายจะกลายเป็นอนุพันธ์ของผลคูณ (μy)′ พอดี จึงอินทิเกรตได้ทันทีเป็น μy = ∫μq dt + C

จะรู้ได้อย่างไรว่าสมการแยกตัวแปรได้?
ถ้าจัดให้อยู่ในรูป dy/dx = g(x)h(y) ได้ คือด้านขวาเป็นผลคูณของฟังก์ชัน x ล้วนกับฟังก์ชัน y ล้วน ก็แยกได้ เช่น y′ = xy แยกได้ แต่ y′ = x + y แยกไม่ได้ ต้องใช้ตัวประกอบอินทิเกรต

ค่าคงที่เวลา τ ของวงจร RC คืออะไร?
τ = RC เป็นเวลาที่แรงดันตัวเก็บประจุชาร์จได้ 63.2% ของค่าสุดท้าย มาจากคำตอบ v = Vs(1 − e^{−t/RC}) ที่ t = τ ได้ 1 − e^{−1} ≈ 0.632 หลัง 5τ ถือว่าชาร์จเต็มในทางปฏิบัติ (99.3%)

สมการแม่นตรงตรวจอย่างไร?
เขียนเป็น M(x, y)dx + N(x, y)dy = 0 แล้วเทียบ ∂M/∂y กับ ∂N/∂x ถ้าเท่ากันเป็นสมการแม่นตรง คำตอบคือ F(x, y) = C โดย ∂F/∂x = M และ ∂F/∂y = N
