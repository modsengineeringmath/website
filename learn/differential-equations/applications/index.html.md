# การประยุกต์สมการเชิงอนุพันธ์ (ODE Applications): มวล-สปริง วงจร RLC การหน่วง ไฟ AC และลูกตุ้ม

// บทที่ 28.4 · สมการเชิงอนุพันธ์ · Applications


สองหน้าที่ผ่านมาเป็นเครื่องมือ หน้านี้คืองานจริง ผมเลือกระบบที่วิศวกรไฟฟ้าและเครื่องกลเจอบ่อยที่สุด ใส่ตัวเลขจริง และให้ดูว่าตัวเลขที่ออกมาจากสมการ (ราก, ζ, ωn) บอกอะไรเกี่ยวกับพฤติกรรมของระบบ

## มวล-สปริง-ตัวหน่วง กับวงจร RLC อนุกรม: สมการเดียวกัน

$$m\,x'' + c\,x' + k\,x = F(t) \qquad\longleftrightarrow\qquad L\,q'' + R\,q' + \frac1C\,q = v(t)$$

| เครื่องกล | ไฟฟ้า | บทบาท |

| ตำแหน่ง x | ประจุ q | ตัวแปรสถานะ |

| ความเร็ว x′ | กระแส i = q′ | อัตราการเปลี่ยน |

| มวล m | ความเหนี่ยวนำ L | เก็บพลังงานจลน์ ½mv² ↔ ½Li² |

| ค่าคงที่สปริง k | 1/C | เก็บพลังงานศักย์ ½kx² ↔ q²/2C |

| ตัวหน่วง c | ความต้านทาน R | เปลี่ยนพลังงานเป็นความร้อน |

| แรง F | แรงดันแหล่งจ่าย v | แรงขับจากภายนอก |

เพราะฉะนั้นทุกผลที่ได้จากฝั่งหนึ่งใช้กับอีกฝั่งได้ทันที วิศวกรเครื่องกลที่เข้าใจการสั่นของแท่นเครื่องจะเข้าใจวงจรกรองความถี่ และกลับกัน

## ความถี่ธรรมชาติ ωn และอัตราส่วนการหน่วง ζ

หารสมการด้วยตัวหน้าแล้วเขียนในรูปมาตรฐาน

$$x'' + 2\zeta\omega_n\,x' + \omega_n^2\,x = \frac{F(t)}{m},\qquad \omega_n = \sqrt{\frac km},\qquad \zeta = \frac{c}{2\sqrt{mk}}$$

ฝั่งไฟฟ้าคือ $\omega_n = \dfrac{1}{\sqrt{LC}}$ และ $\zeta = \dfrac R2\sqrt{\dfrac CL}$ สมการลักษณะเฉพาะกลายเป็น $r^2 + 2\zeta\omega_nr + \omega_n^2 = 0$ รากคือ

$$r = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1}$$

เมื่อ $\zeta < 1$ รากเป็น $-\zeta\omega_n \pm j\omega_d$ โดย $\omega_d = \omega_n\sqrt{1 - \zeta^2}$ คือความถี่ที่ระบบแกว่งจริง ซึ่งต่ำกว่า ωn เล็กน้อย คำตอบเป็น $e^{-\zeta\omega_nt}\cos(\omega_dt - \varphi)$ สูตรออยเลอร์ รวมเป็นคลื่นเดียว

| ζ | ราก | ชื่อ | พฤติกรรม |

| 0 | $\pm j\omega_n$ | ไม่หน่วง | แกว่งค้างตลอดไป |

| 0 < ζ < 1 | เชิงซ้อนคู่สังยุค | หน่วงน้อย (underdamped) | แกว่งแล้วหยุด |

| 1 | จริงซ้ำ | หน่วงวิกฤต (critically damped) | เข้าเร็วที่สุดโดยไม่เกิน |

| > 1 | จริงสองค่า | หน่วงเกิน (overdamped) | ค่อย ๆ เข้า ไม่แกว่ง |

### วงจร RLC: L = 0.5 H, C = 0.02 F ต้องใช้ R เท่าไรจึงหน่วงวิกฤต

- $\omega_n = 1/\sqrt{0.5\times0.02} = 10$ rad/s

- $\zeta = \tfrac R2\sqrt{C/L} = \tfrac R2\times0.2 = 0.1R$ ตั้ง ζ = 1 ได้ R = 10 Ω

R = 2 Ω → ζ = 0.2 (แกว่ง) · R = 10 Ω → ζ = 1 (วิกฤต) · R = 20 Ω → ζ = 2 (หน่วงเกิน)

## ผลตอบสนองขั้นบันได: เปิดสวิตช์แล้วเกิดอะไรขึ้น

วงจรเดิมที่ R = 2 Ω ป้อนแรงดัน 12 V ที่ t = 0 แรงดันตัวเก็บประจุ v เป็นไปตาม $LC\,v'' + RC\,v' + v = 12$ หรือ $0.01v'' + 0.04v' + v = 12$ แล็บข้างล่างตั้งค่านี้ไว้แล้ว

สูตรเปอร์เซ็นต์โอเวอร์ชูต (percent overshoot) ของระบบอันดับสองขึ้นกับ ζ ตัวเดียว

$$\%OS = 100\,e^{-\pi\zeta/\sqrt{1-\zeta^2}}$$

ที่ ζ = 0.2 ได้ $e^{-0.6413} \approx 0.527$ แรงดันพุ่งไปถึง $12\times1.527 \approx 18.3$ V ก่อนกลับมาที่ 12 V ตัวเก็บประจุที่ทนได้ 16 V จึงเสียหายได้ทั้งที่แหล่งจ่ายมีแค่ 12 V ลองเปลี่ยน b เป็น 0.2 (R = 10 Ω) ในแล็บ จะไม่มีโอเวอร์ชูตเลย ความหมายของ ζ ในระบบควบคุมอ่านต่อที่แล็บระบบอันดับสอง

## สภาวะอยู่ตัวกับไฟ AC: ทำไมเฟสเซอร์ใช้ได้

ป้อน $v(t) = V_m\cos\omega t$ ให้วงจร RLC อนุกรม สนใจกระแสหลังผ่านช่วงชั่วครู่ไปแล้ว ใช้ทางลัดเลขเชิงซ้อนจากหน้าก่อน แทน $\cos\omega t$ ด้วย $e^{j\omega t}$ สูตรออยเลอร์ แล้วเดา $i = Ie^{j\omega t}$ ทุกการดิฟกลายเป็นการคูณ $j\omega$ ทุกการอินทิเกรตกลายเป็นการหาร $j\omega$

$$\Big(R + j\omega L + \frac{1}{j\omega C}\Big)I = V_m \;\Longrightarrow\; I = \frac{V_m}{Z},\quad Z = R + j\Big(\omega L - \frac{1}{\omega C}\Big)$$

Z คืออิมพีแดนซ์ นี่คือเหตุผลทางคณิตศาสตร์ที่วิธีเฟสเซอร์ใช้ได้: มันคือวิธีเดาสัมประสิทธิ์ของสมการเชิงอนุพันธ์ที่เขียนให้สั้นลง เมื่อ $\omega L = 1/(\omega C)$ ส่วนจินตภาพหาย Z เหลือ R น้อยที่สุด กระแสสูงสุด เรียกว่าเรโซแนนซ์อนุกรมที่ $\omega = 1/\sqrt{LC} = \omega_n$ อ่านต่อในวิเคราะห์วงจร AC ด้วยเฟสเซอร์

## ลูกตุ้ม: สมการไม่เชิงเส้นที่กลายเป็นเชิงเส้นเมื่อมุมเล็ก

โมเมนต์รอบจุดหมุนให้ $\theta'' + \dfrac gL\sin\theta = 0$ สมการนี้ไม่เชิงเส้นเพราะ θ อยู่ใน sin แต่ถ้ามุมเล็ก ใช้ $\sin\theta\approx\theta$ ซึ่งมาจากความชันของ sin ที่ศูนย์เท่ากับ 1 ประมาณเชิงเส้น อนุกรมของ sin cos

$$\theta'' + \frac gL\,\theta = 0 \;\Longrightarrow\; \theta = \theta_0\cos\!\Big(\sqrt{\tfrac gL}\,t\Big),\qquad T = 2\pi\sqrt{\frac Lg}$$

ลูกตุ้มยาว 1 m มีคาบ $2\pi\sqrt{1/9.81} \approx 2.006$ วินาที ไม่ขึ้นกับมวลและไม่ขึ้นกับมุมแกว่ง (เมื่อมุมเล็ก) ที่มุม 10° ค่า sin ต่างจากมุมไม่ถึง 0.5% แต่ที่มุม 45° ต่างกันราว 10% คาบจริงจะยาวกว่าสูตรราว 4% ต้องใช้วิธีเชิงตัวเลขหรืออินทิกรัลวงรี ลองใส่ $y' = \ldots$ ไม่ได้เพราะเป็นอันดับสอง แต่ดูการแปลงเป็นระบบอันดับหนึ่ง

## การเติบโตและการสลาย

- สลายตัวแบบเลขชี้กำลัง $N' = -\lambda N$ ได้ $N = N_0e^{-\lambda t}$ ครึ่งชีวิต $t_{1/2} = \tfrac{\ln2}{\lambda}$ ใช้กับสารกัมมันตรังสี ยาในกระแสเลือด และการคายประจุของตัวเก็บประจุผ่านตัวต้านทาน

- ลอจิสติก $P' = rP(1 - P/K)$ โตแบบเลขชี้กำลังตอนแรก แล้วช้าลงเมื่อเข้าใกล้ K ได้ $P = \dfrac{K}{1 + Ae^{-rt}}$ ซึ่งเป็นสมการเบอร์นูลลี (ดู28.1) ลองในแล็บสนามความชันด้วยตัวอย่าง “โลจิสติก y(1 − y)”

## คำถามที่พบบ่อย

อัตราส่วนการหน่วง ζ คืออะไร?
เป็นตัวเลขไร้หน่วยที่บอกว่าระบบอันดับสองหน่วงมากแค่ไหน จากสมการ ay″ + by′ + cy = 0 ได้ ζ = b/(2√(ac)) ถ้า ζ 1 หน่วงเกิน เข้าช้าโดยไม่แกว่ง

ทำไมวงจร RLC กับระบบมวล-สปริงจึงเหมือนกัน?
เพราะสมการมีรูปเดียวกัน Lq″ + Rq′ + q/C = v(t) กับ mx″ + cx′ + kx = F(t) ตัวเหนี่ยวนำเก็บพลังงานแบบเดียวกับมวล (พลังงานจลน์) ตัวเก็บประจุเหมือนสปริง (พลังงานศักย์) และตัวต้านทานเหมือนตัวหน่วงที่เปลี่ยนพลังงานเป็นความร้อน

เปอร์เซ็นต์โอเวอร์ชูตคำนวณอย่างไร?
สำหรับระบบอันดับสองที่หน่วงน้อยและรับอินพุตขั้นบันได %OS = 100·e^{−πζ/√(1−ζ²)} ขึ้นกับ ζ อย่างเดียว เช่น ζ = 0.2 ได้ประมาณ 52.7% ζ = 0.7 ได้ราว 4.6%
