# ฟังก์ชัน (Functions): โดเมน เรนจ์ กราฟ และการแปลง

// บทที่ 1 · คณิตศาสตร์วิศวกรรม · Functions


แคลคูลัสทั้งหมดคือการถามคำถามเกี่ยวกับฟังก์ชัน: เข้าใกล้ค่าอะไร (ลิมิต) เปลี่ยนเร็วแค่ไหน (อนุพันธ์) สะสมได้เท่าไร (อินทิกรัล) ถ้าอ่านฟังก์ชันและกราฟได้คล่อง ทุกบทหลังจากนี้จะง่ายขึ้นมาก หน้านี้ปูพื้นตั้งแต่นิยาม โดเมน เรนจ์ กราฟพื้นฐาน การแปลงกราฟ ฟังก์ชันประกอบ ฟังก์ชันผกผัน ไปจนถึงฟังก์ชันที่วิศวกรไฟฟ้าใช้จริง พร้อมแล็บให้ลากเลื่อนกราฟเอง

สรุปใน 30 วินาที

- ฟังก์ชัน = กฎที่ให้ y หนึ่งค่าต่อ x หนึ่งค่า (ทดสอบเส้นแนวตั้ง)

- โดเมน: ตัดค่าที่ทำให้ตัวส่วนเป็นศูนย์ รากที่สองติดลบ ลอการิทึมไม่เป็นบวก

- $af(b(x - h)) + k$: h เลื่อนขวา k เลื่อนขึ้น a ยืดแนวตั้ง b บีบแนวนอน เครื่องหมายลบ = สะท้อน

- $f^{-1}$ มีได้เมื่อ f เป็นหนึ่งต่อหนึ่ง (ทดสอบเส้นแนวนอน) กราฟคือภาพสะท้อนข้าม y = x

ระดับพื้นฐาน ม.ปลาย · ปี 1กลาง ป.ตรี วิศวกรรม

## ฟังก์ชันคืออะไร พื้นฐาน

ฟังก์ชันคือ “เครื่องจักร” ที่รับค่าเข้า $x$ แล้วให้ค่าออก $y = f(x)$ เพียงค่าเดียวเสมอ ในวงจรไฟฟ้า แรงดันขาออกของวงจรแบ่งแรงดันเป็นฟังก์ชันของแรงดันขาเข้า กระแสในตัวเก็บประจุเป็นฟังก์ชันของเวลา และอัตราขยายของแอมป์เป็นฟังก์ชันของความถี่

F1 Function ฟังก์ชัน

$$f: A \to B,\qquad x \mapsto y = f(x) \text{ ค่าเดียว}$$

$A$ = โดเมน (ค่าที่ใส่ได้) · เซตของ $f(x)$ ทั้งหมด = เรนจ์ (ค่าที่ออกมาได้)

F2 Vertical line test ทดสอบเส้นแนวตั้ง

$$\text{ทุกเส้น } x = c \text{ ตัดกราฟไม่เกิน 1 จุด} \iff \text{กราฟเป็นฟังก์ชัน}$$

ตัวอย่าง F-1 · แทนค่าฟังก์ชัน

### ให้ $f(x) = x^2 - 3x$ หา $f(2)$, $f(-1)$ และ $f(a + h)$

-
$$f(2) = 4 - 6 = -2,\qquad f(-1) = 1 + 3 = 4$$

- แทน $x$ ด้วย $(a + h)$ ทั้งก้อน

$$f(a + h) = (a+h)^2 - 3(a+h) = a^2 + 2ah + h^2 - 3a - 3h$$

$f(a+h) - f(a) = 2ah + h^2 - 3h$ และ $\dfrac{f(a+h) - f(a)}{h} = 2a + h - 3$ ซึ่งคือ “ผลหารผลต่าง” ที่จะกลายเป็นอนุพันธ์ $2a - 3$ เมื่อ $h \to 0$ ในบทอนุพันธ์

## โดเมนและเรนจ์ พื้นฐาน

F3 Natural domain สามกฎหาโดเมน

$$\frac{p(x)}{q(x)}:\ q(x) \ne 0 \qquad \sqrt{g(x)}:\ g(x) \ge 0 \qquad \ln g(x):\ g(x) > 0$$

โดเมนตามธรรมชาติคือจำนวนจริงทุกตัวที่ไม่ละเมิดสามข้อนี้ · ในงานวิศวกรรมยังมีโดเมนทางกายภาพ เช่น $t \ge 0$, $R > 0$

ตัวอย่าง F-2 · หาโดเมนและเรนจ์

### (ก) $f(x) = \sqrt{4 - x^2}$ (ข) $g(x) = \dfrac{1}{x^2 - 1}$ (ค) $h(x) = \ln(x - 2)$

- (ก) $4 - x^2 \ge 0 \Rightarrow -2 \le x \le 2$ · ค่าในรากอยู่ระหว่าง 0 ถึง 4 จึงได้เรนจ์ $[0, 2]$ (กราฟคือครึ่งวงกลมบน)

- (ข) $x^2 - 1 \ne 0 \Rightarrow x \ne \pm 1$ · เรนจ์ $(-\infty, -1] \cup (0, \infty)$ (ค่าสูงสุดของช่วงกลางคือ $-1$ ที่ $x = 0$)

- (ค) $x - 2 > 0 \Rightarrow x > 2$ · ลอการิทึมให้ค่าได้ทุกจำนวนจริง เรนจ์ $\mathbb{R}$

(ก) $D = [-2, 2],\ R = [0, 2]$ · (ข) $D = \mathbb R \setminus \{\pm1\}$ · (ค) $D = (2, \infty),\ R = \mathbb R$

## กราฟของฟังก์ชันพื้นฐานที่ต้องจำหน้าตาได้ พื้นฐาน

ฟังก์ชันที่ซับซ้อนเกือบทุกตัวสร้างจาก 12 แบบนี้ด้วยการบวก คูณ ประกอบ และแปลงกราฟ จำรูปร่าง จุดตัดแกน โดเมน และพฤติกรรมเมื่อ x ใหญ่มากของแต่ละตัวให้ได้

ฟังก์ชันพื้นฐาน: เชิงเส้น กำลังสอง กำลังสาม รากที่สอง ค่าสัมบูรณ์ ส่วนกลับ เอกซ์โพเนนเชียล ลอการิทึม ไซน์ โคไซน์ แทนเจนต์ และขั้นบันได

F4 Even & odd ฟังก์ชันคู่ คี่

$$\text{คู่: } f(-x) = f(x),\qquad \text{คี่: } f(-x) = -f(x)$$

คู่สมมาตรกับแกน y ($x^2,\ \cos x,\ |x|$) · คี่สมมาตรกับจุดกำเนิด ($x^3,\ \sin x,\ 1/x$) · ใช้ลดงานในอนุกรมฟูเรียร์ สมมาตรของคลื่น

F5 Periodic ฟังก์ชันคาบ

$$f(x + T) = f(x)\ \ \forall x,\qquad \sin(\omega x)\ \text{มีคาบ } T = \frac{2\pi}{\omega}$$

## การแปลงกราฟ: เลื่อน ยืด หด สะท้อน พื้นฐาน

F6 General transformation การแปลงทั่วไป

$$g(x) = a\,f\big(b(x - h)\big) + k$$

นอกวงเล็บ (แนวตั้ง ทำตามที่เห็น): $k$ เลื่อนขึ้น · $|a| > 1$ ยืด · $a < 0$ สะท้อนแกน x ในวงเล็บ (แนวนอน ทำกลับกัน): $h$ เลื่อนขวา · $|b| > 1$ บีบ · $b < 0$ สะท้อนแกน y

ตัวอย่าง F-3 · อ่านการแปลง

### อธิบายกราฟ $g(x) = -2(x - 3)^2 + 5$ เทียบกับ $f(x) = x^2$

- ในวงเล็บ: $x - 3$ → เลื่อนขวา 3

- นอกวงเล็บ: คูณ −2 → ยืดแนวตั้ง 2 เท่าและคว่ำลง · บวก 5 → เลื่อนขึ้น 5

พาราโบลาคว่ำ จุดยอดที่ $(3, 5)$ แคบกว่าเดิม 2 เท่า ค่าสูงสุดคือ 5

ตัวอย่าง F-4 · ไฟฟ้า

### แรงดันไซน์ $v(t) = 10\sin(100\pi t - \pi/3) + 2$ เป็นการแปลงของ $\sin t$ อย่างไร

- เขียนเป็น $10\sin\big(100\pi(t - \tfrac{1}{300})\big) + 2$

- $b = 100\pi$: บีบให้คาบเป็น $2\pi/100\pi = 0.02$ s (50 Hz) · $h = 1/300$ s: เลื่อนขวา = ตามหลัง 60° · $a = 10$: แอมพลิจูด 10 V · $k = 2$: มีไฟตรง (offset) 2 V

ไซน์ 50 Hz แอมพลิจูด 10 V ตามหลัง 60° และยกขึ้น 2 V DC ดูต่อในsin · cos ในไฟฟ้ากระแสสลับ

## แล็บกราฟ: เลื่อน ยืด สะท้อน ประกอบ และผกผัน

เลือกฟังก์ชันพื้นฐานหรือพิมพ์เอง (เช่น x^3 - x, exp(-x), sin(x)/x) เส้นประคือกราฟเดิม เส้นส้มคือกราฟที่แปลงแล้ว ด้านบนบอกลำดับการแปลงเป็นภาษาไทย สลับแท็บเพื่อดูฟังก์ชันประกอบและฟังก์ชันผกผัน

## ฟังก์ชันประกอบ (Composition) พื้นฐาน

F7 Composite function ฟังก์ชันประกอบ

$$(f \circ g)(x) = f\big(g(x)\big),\qquad D_{f\circ g} = \{x \in D_g : g(x) \in D_f\}$$

ทำ g ก่อน แล้วส่งผลให้ f · โดยทั่วไป $f\circ g \ne g\circ f$ · เป็นโครงสร้างที่กฎลูกโซ่ของอนุพันธ์จัดการ

ตัวอย่าง F-5

### ให้ $f(x) = \sqrt{x}$, $g(x) = x - 4$ หา $f\circ g$, $g \circ f$ และโดเมน

-
$$(f\circ g)(x) = \sqrt{x - 4},\quad x \ge 4$$

-
$$(g\circ f)(x) = \sqrt{x} - 4,\quad x \ge 0$$

ได้ฟังก์ชันต่างกันและโดเมนต่างกัน ลำดับของการประกอบสำคัญ

## ฟังก์ชันผกผัน (Inverse Function) กลาง

F8 One-to-one หนึ่งต่อหนึ่ง

$$f(x_1) = f(x_2) \Rightarrow x_1 = x_2$$

ตรวจด้วยเส้นแนวนอน: ทุกเส้นตัดกราฟไม่เกินหนึ่งจุด ฟังก์ชันที่เพิ่มขึ้นหรือลดลงตลอดผ่านเสมอ

F9 Inverse ฟังก์ชันผกผัน

$$f^{-1}(f(x)) = x,\quad f(f^{-1}(y)) = y,\quad D_{f^{-1}} = R_f$$

หาโดยสลับ x กับ y แล้วแก้หา y · กราฟคือภาพสะท้อนข้ามเส้น $y = x$ · $f^{-1}(x) \ne 1/f(x)$

ตัวอย่าง F-6 · หาฟังก์ชันผกผัน

### $f(x) = \dfrac{2x + 1}{x - 3}$

- เขียน $y = \dfrac{2x+1}{x-3}$ แล้วสลับ: $x = \dfrac{2y+1}{y-3}$

-
$$x(y - 3) = 2y + 1 \Rightarrow xy - 2y = 3x + 1 \Rightarrow y(x - 2) = 3x + 1$$

-
$$f^{-1}(x) = \frac{3x + 1}{x - 2}$$

$f^{-1}(x) = \dfrac{3x+1}{x-2}$ โดเมน $x \ne 2$ (= เรนจ์ของ f เพราะ f มีเส้นกำกับแนวนอน y = 2)

ตรวจ: $f(0) = -\tfrac13$ และ $f^{-1}(-\tfrac13) = \dfrac{-1 + 1}{-\tfrac13 - 2} = 0$ ✓

ตัวอย่างคู่ผกผันที่ใช้ตลอดวิชา: $e^x \leftrightarrow \ln x$ · $x^2\ (x \ge 0) \leftrightarrow \sqrt x$ · $\sin x\ (-\tfrac\pi2 \le x \le \tfrac\pi2) \leftrightarrow \sin^{-1}x$ ดูฟังก์ชันตรีโกณผกผันในหน้าตรีโกณมิติ

## ฟังก์ชันเป็นช่วง ขั้นบันได และแรมป์ กลาง

วิศวกรไฟฟ้าเขียนสัญญาณที่ “เปิด-ปิด” ด้วยฟังก์ชันขั้นบันไดหนึ่งหน่วย ทำให้ฟังก์ชันเป็นช่วงที่ยาวหลายบรรทัดกลายเป็นสูตรเดียว ซึ่งพร้อมใช้กับการเลื่อนเวลาของลาปลาซ

F10 Unit step ขั้นบันไดหนึ่งหน่วย

$$u(t) = \begin{cases} 0, & t < 0 \\ 1, & t \ge 0 \end{cases}$$

F11 Ramp แรมป์

$$r(t) = t\,u(t),\qquad \frac{dr}{dt} = u(t)$$

F12 Window / pulse พัลส์สี่เหลี่ยม

$$u(t - a) - u(t - b) = \begin{cases} 1, & a \le t < b \\ 0, & \text{อื่น ๆ} \end{cases}$$

คูณฟังก์ชันใดก็ได้ด้วยหน้าต่างนี้ = “เปิดใช้” เฉพาะช่วง $[a, b)$

ตัวอย่าง F-7 · เขียนฟังก์ชันเป็นช่วงด้วย u(t)

### $f(t) = 0$ เมื่อ $t < 0$, $= 2t$ เมื่อ $0 \le t < 1$, $= 2$ เมื่อ $t \ge 1$

- เปิดแรมป์ $2t$ ที่ t = 0 แล้ว “หักล้าง” ด้วยแรมป์ลบที่ t = 1

$$f(t) = 2t\,u(t) - 2(t - 1)\,u(t - 1) = 2r(t) - 2r(t - 1)$$

$f(t) = 2r(t) - 2r(t-1)$ ตรวจ: เมื่อ $t \ge 1$ ได้ $2t - 2t + 2 = 2$ ✓ (เป็นรูปคลื่นแรงดันชาร์จแบบ soft-start)

## ฟังก์ชันเอกซ์โพเนนเชียลและลอการิทึม พื้นฐาน

F13 Exponential laws กฎเลขชี้กำลัง

$$e^ae^b = e^{a+b},\quad \frac{e^a}{e^b} = e^{a-b},\quad (e^a)^b = e^{ab},\quad e^0 = 1$$

F14 Logarithm laws กฎลอการิทึม

$$\ln(ab) = \ln a + \ln b,\quad \ln\frac ab = \ln a - \ln b,\quad \ln a^n = n\ln a,\quad \log_b x = \frac{\ln x}{\ln b}$$

F15 Time constant & decibels ค่าคงตัวเวลาและเดซิเบล

$$e^{-t/\tau}:\ \text{ที่ } t = \tau \text{ เหลือ } 36.8\%,\ t = 5\tau \text{ เหลือ } 0.7\% \qquad G_{\text{dB}} = 20\log_{10}\left|\frac{V_o}{V_i}\right|$$

ลอการิทึมเปลี่ยนการคูณเป็นการบวก จึงใช้ในแผนภาพโบดที่คูณฟังก์ชันถ่ายโอนกันหลายตัว โบดไดอะแกรม

ตัวอย่าง F-8 · แก้สมการด้วยลอการิทึม

### ตัวเก็บประจุชาร์จตาม $v(t) = 12(1 - e^{-t/0.5})$ V ต้องใช้เวลาเท่าไรถึง 10 V

-
$$10 = 12(1 - e^{-2t}) \Rightarrow e^{-2t} = \frac{1}{6}$$

- ใส่ ln ทั้งสองข้าง

$$-2t = \ln\frac16 = -\ln 6 \Rightarrow t = \frac{\ln 6}{2} \approx 0.896\ \text{s}$$

ประมาณ 0.896 s หรือราว 1.79τ

## ฟังก์ชันในงานวิศวกรรมไฟฟ้า กลาง

| ฟังก์ชัน | ความหมาย | ใช้ที่ไหน |

| $v(t) = V\left(1 - e^{-t/RC}\right)u(t)$ | ชาร์จตัวเก็บประจุ | ระบบอันดับหนึ่ง |

| $v(t) = V_m\sin(\omega t + \phi)$ | ไฟฟ้ากระแสสลับ | ไซน์และเฟสเซอร์ |

| $I_D = I_S\left(e^{V_D/(nV_T)} - 1\right)$ | สมการไดโอดของช็อคลีย์ | วงจรเรียงกระแส · แหล่งจ่าย |

| $R(T) = R_0e^{B(1/T - 1/T_0)}$ | เทอร์มิสเตอร์ NTC | วัดอุณหภูมิ · ต้องหาฟังก์ชันผกผัน $T(R)$ |

| $V_o = \begin{cases} A V_i, & |AV_i| < V_{\text{sat}} \\ \pm V_{\text{sat}}, & \text{อื่น ๆ} \end{cases}$ | แอมป์อิ่มตัว (ฟังก์ชันเป็นช่วง) | แล็บออปแอมป์ |

| $|H(j\omega)| = \dfrac{1}{\sqrt{1 + (\omega RC)^2}}$ | ผลตอบสนองเชิงความถี่ของ RC | ผลตอบสนองเชิงความถี่ |

ตัวอย่าง F-9 · ฟังก์ชันผกผันของเซนเซอร์

### เทอร์มิสเตอร์ $R(T) = 10{,}000\,e^{3950(1/T - 1/298.15)}$ Ω วัดได้ 5 kΩ อุณหภูมิเท่าไร

- หาฟังก์ชันผกผัน: $\ln\dfrac{R}{10000} = 3950\left(\dfrac1T - \dfrac{1}{298.15}\right)$

$$T(R) = \left(\frac{1}{298.15} + \frac{1}{3950}\ln\frac{R}{10000}\right)^{-1}$$

-
$$T(5000) = \left(0.0033540 + \frac{-0.69315}{3950}\right)^{-1} = (0.0031785)^{-1} \approx 314.6\ \text{K}$$

$T \approx 314.6\ \text{K} \approx 41.5^\circ\text{C}$ ไมโครคอนโทรลเลอร์ทำแบบนี้ทุกครั้งที่อ่านค่าเทอร์มิสเตอร์

## คำถามที่พบบ่อย

ฟังก์ชันต่างจากความสัมพันธ์อย่างไร?
ความสัมพันธ์ใด ๆ จับคู่ x กับ y ได้หลายค่า แต่ฟังก์ชันต้องให้ y เพียงค่าเดียวต่อ x หนึ่งค่า ตรวจจากกราฟด้วยการทดสอบเส้นแนวตั้ง ถ้าเส้นแนวตั้งใดตัดกราฟเกินหนึ่งจุด กราฟนั้นไม่ใช่ฟังก์ชัน เช่น วงกลม $x^2 + y^2 = 1$

หาโดเมนของฟังก์ชันอย่างไร?
เริ่มจากจำนวนจริงทั้งหมด แล้วตัดค่าที่ทำให้ (1) ตัวส่วนเป็นศูนย์ (2) ในรากที่สองติดลบ (3) ในลอการิทึมไม่เป็นบวก และ (4) เงื่อนไขทางกายภาพ เช่น เวลาหรือความยาวต้องไม่ติดลบ

f(x − h) ทำไมเลื่อนไปทางขวา ทั้งที่มีเครื่องหมายลบ?
เพราะกราฟใหม่ต้องใช้ x ที่มากกว่าเดิม h หน่วยเพื่อให้ได้ค่าเดิม เช่น จุดยอดของ $x^2$ อยู่ที่ x = 0 แต่ของ $(x-3)^2$ อยู่ที่ x = 3 การเปลี่ยนแปลงในวงเล็บจะทำตรงข้ามกับสิ่งที่ตาเห็นเสมอ

ฟังก์ชันขั้นบันได u(t) ใช้ทำอะไรในงานไฟฟ้า?
แทนการเปิดสวิตช์ที่เวลาหนึ่ง เช่น แหล่งจ่าย 12 V ที่ต่อเข้าวงจรเมื่อ t = 0 เขียนเป็น $12u(t)$ และสัญญาณที่เปิดแล้วปิด เขียนเป็นผลต่างของขั้นบันได $u(t) - u(t - T)$ ซึ่งใช้ต่อในการแปลงลาปลาซ
