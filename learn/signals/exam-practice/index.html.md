# โจทย์สัญญาณและระบบพร้อมเฉลย (Signals and Systems Exam Practice): 27 ข้อ 4 ชุด

// บทที่ 11.5 · สัญญาณและระบบ · Exam Practice


โจทย์ชุดนี้ไล่ตามบทเรียนสี่หน้าก่อนหน้า เฉลยซ่อนไว้ทุกข้อ ลองทำก่อนแล้วค่อยกดเปิด ผมเขียนเฉลยเฉพาะขั้นที่ตัดสินคำตอบ ป้ายสีน้ำเงินบอกเอกลักษณ์ตรีโกณที่ใช้ ชี้เมาส์เพื่อดูสูตร ท้ายเฉลยมีลิงก์กลับไปหัวข้อที่อธิบายวิธีนั้นเต็ม ๆ ทุกคำตอบผ่านการตรวจด้วยคอมพิวเตอร์แล้ว (อินทิเกรตสัญลักษณ์ บวกอนุกรม หรืออินทิเกรตเชิงตัวเลข)

## ชุด A · คุณสมบัติระบบและคอนโวลูชัน (7 ข้อ) พื้นฐาน

A1ระบบ $y(t) = x(t) + x(t - 1)$ เป็น LTI หรือไม่ หา h(t)
เชิงเส้นเพราะเป็นผลบวกของ x ที่ไม่ถูกยกกำลัง ไม่แปรตามเวลาเพราะ t ปรากฏเฉพาะใน x(·)
ใส่ $x = \delta(t)$
เป็น LTI, $h(t) = \delta(t) + \delta(t - 1)$ คอซัลและเสถียร · คุณสมบัติของระบบ

A2ระบบ $y(t) = \cos(t)\,x(t)$ เป็นเชิงเส้นไหม ไม่แปรตามเวลาไหม
เชิงเส้น: $\cos t\,(ax_1 + bx_2) = a\cos t\,x_1 + b\cos t\,x_2$
เลื่อนอินพุตได้ $\cos t\,x(t - t_0)$ แต่ y ที่เลื่อนคือ $\cos(t - t_0)\,x(t - t_0)$ คาบ 2π
เชิงเส้น แต่แปรตามเวลา (คือมิกเซอร์ในวิทยุ ไม่ใช่ LTI) · คุณสมบัติของระบบ

A3หา $u(t) * e^{-2t}u(t)$
t ≥ 0: $\int_0^t e^{-2(t-\tau)}d\tau = e^{-2t}\cdot\tfrac{e^{2t} - 1}{2}$
$\tfrac12(1 - e^{-2t})u(t)$ · อินทิกรัลคอนโวลูชัน

A4หา $e^{-t}u(t) * e^{-t}u(t)$
$\int_0^t e^{-\tau}e^{-(t-\tau)}d\tau = e^{-t}\int_0^t d\tau$
$t\,e^{-t}u(t)$ · โพลซ้ำ เหมือนรากซ้ำในสมการอันดับสอง · อินทิกรัลคอนโวลูชัน

A5$x[n] = \{2, 1, -1\}$ เริ่ม n = 0 และ $h[n] = \{1, 3\}$ เริ่ม n = −1 หา y[n]
ตารางคูณ: แถว 1 ได้ 2, 1, −1 · แถว 3 ได้ 6, 3, −3 (เลื่อนหนึ่งช่อง)
บวกตามแนวทแยง: 2, 1 + 6, −1 + 3, −3 และ y เริ่มที่ n = 0 + (−1) = −1
$y[n] = \{2, 7, 2, -3\}$ ที่ n = −1, 0, 1, 2 · ตารางคูณ

A6ระบบที่มี $h[n] = (-0.8)^nu[n]$ เสถียรไหม และ $h(t) = e^{t}u(-t)$ คอซัลไหม
$\sum|h| = \sum 0.8^n = \tfrac{1}{1 - 0.8} = 5$
$e^tu(-t)$ ไม่เป็นศูนย์ที่ t < 0
ตัวแรกเสถียร (ผลรวม 5) · ตัวที่สองไม่คอซัล แต่เสถียร ($\int_{-\infty}^0 e^t dt = 1$) · คอซัลและเสถียรภาพ

A7ระบบ $h(t) = e^{-t}u(t)$ ป้อน $x(t) = \cos 3t$ หาเอาต์พุตในสภาวะอยู่ตัว
$H(j\omega) = \dfrac{1}{1 + j\omega}$ ที่ ω = 3: $|H| = \dfrac{1}{\sqrt{10}}$, $\angle H = -\tan^{-1}3$ ฟังก์ชันตรีโกณผกผัน
หรือคิดด้วยสูตรผลบวกมุม: $a = \int e^{-\tau}\cos3\tau\,d\tau = \tfrac{1}{10}$, $b = \tfrac{3}{10}$ สูตรผลบวกมุมของ cos แล้วรวมคลื่น รวมเป็นคลื่นเดียว
$y = \tfrac{1}{10}\cos3t + \tfrac{3}{10}\sin3t = 0.3162\cos(3t - 71.57^\circ)$ · ไซน์เข้า ไซน์ออก

อยากตรวจคอนโวลูชันไม่ต่อเนื่องของตัวเอง ใช้เครื่องคำนวณคอนโวลูชันได้ทันที

## ชุด B · การแปลงฟูริเยร์ (7 ข้อ) กลาง

B1หาการแปลงฟูริเยร์ของพัลส์สูง 1 ช่วง $0 < t < 2$
พัลส์กว้าง 2 อยู่ตรงกลางให้ $2\,\mathrm{sinc}(2f)$
เลื่อนไป 1 คูณ $e^{-j2\pi f}$
$X(f) = 2\,\mathrm{sinc}(2f)\,e^{-j2\pi f}$ · เลื่อนเวลา

B2หา X(f) ของ $e^{-3t}u(t)$ และความถี่ที่ขนาดลดเหลือ $1/\sqrt2$ ของค่าที่ DC
$X = \dfrac{1}{3 + j2\pi f}$
$|X|$ ลด $\sqrt2$ เท่าเมื่อ $2\pi f = 3$ มุมพิเศษ
$f = \tfrac{3}{2\pi} \approx 0.477$ Hz เฟสที่จุดนั้น −45° · คู่การแปลง

B3หา X(f) ของ $x(t) = e^{-2|t|}$
$\dfrac{1}{2 + j2\pi f} + \dfrac{1}{2 - j2\pi f}$
$X(f) = \dfrac{4}{4 + 4\pi^2f^2} = \dfrac{1}{1 + \pi^2f^2}$ เป็นจริงล้วนเพราะ x จริงและคู่ ฟังก์ชันคู่-คี่ · จริงและคู่

B4สัญญาณ $x(t) = 4\cos(200\pi t)$ มีสเปกตรัมอย่างไร
$\cos\theta = \tfrac12(e^{j\theta} + e^{-j\theta})$ cos, sin ในรูปเลขชี้กำลัง และ $200\pi t = 2\pi(100)t$
$X(f) = 2\delta(f - 100) + 2\delta(f + 100)$ เส้นสองเส้นที่ ±100 Hz สูงเส้นละ 2 · ตาราง

B5สัญญาณเสียงแบนด์วิดท์ 4 kHz มอดูเลตด้วย $\cos(2\pi\cdot 600\text{k}\,t)$ สเปกตรัมอยู่ช่วงไหน แบนด์วิดท์เท่าไร
การคูณด้วย cos เลื่อนสเปกตรัมไป ±f₀ ก้อนละครึ่ง ผลคูณ cos·cos
596 ถึง 604 kHz (และฝั่งลบ) แบนด์วิดท์ 8 kHz · มอดูเลต AM

B6ฝั่งรับคูณ $x(t)\cos 2\pi f_0t$ ด้วย $\cos(2\pi f_0t + \varphi)$ แล้วกรองโลว์พาส ได้อะไร
$\cos A\cos B = \tfrac12[\cos(A - B) + \cos(A + B)]$ ผลคูณ cos·cos ก้อน $A + B$ อยู่ที่ $2f_0$ ถูกกรองทิ้ง
ก้อน $A - B = -\varphi$ ได้ $\cos(-\varphi) = \cos\varphi$ ฟังก์ชันคู่-คี่
$\tfrac12x(t)\cos\varphi$ · ถ้า φ = 90° สัญญาณหายหมด · ฝั่งรับ

B7ใช้พาร์เซวาลหาพลังงานของ $x(t) = e^{-2t}u(t)$ แล้วตรวจในโดเมนความถี่
เวลา: $\int_0^\infty e^{-4t}dt = \tfrac14$
ความถี่: $\int\dfrac{df}{4 + 4\pi^2f^2}$ แทน $u = \pi f$ ได้ $\tfrac{1}{4\pi}\cdot\pi$ ฟังก์ชันตรีโกณผกผัน
$E = \tfrac14$ ทั้งสองทาง · พาร์เซวาล

## ชุด C · การสุ่มสัญญาณ (6 ข้อ) กลาง

C1สัญญาณมีความถี่สูงสุด 3 kHz อัตรา Nyquist และความถี่ Nyquist ถ้าสุ่มที่ 8 kHz คือเท่าไร
อัตรา Nyquist = 2B · ความถี่ Nyquist = fₛ/2
อัตรา Nyquist 6 kHz · ความถี่ Nyquist 4 kHz ไม่เกิดอเลียส · ทฤษฎีบทการสุ่ม

C2ไซน์ 12 kHz สุ่มด้วย 20 kHz จะเห็นเป็นความถี่เท่าไร
$k = \mathrm{round}(12/20) = 1$, $f_a = |12 - 20|$ คาบ 2π ฟังก์ชันคู่-คี่
8 kHz · สูตรความถี่ปลอม

C3ไซน์ 130 Hz สุ่มด้วย 100 Hz จะเห็นเป็นความถี่เท่าไร
$k = \mathrm{round}(1.3) = 1$, $f_a = |130 - 100|$
30 Hz · สูตรความถี่ปลอม

C4$x(t) = \cos(2\pi\cdot 50t) + \cos(2\pi\cdot 120t)$ ต้องสุ่มอย่างน้อยเท่าไร และถ้าสุ่ม 200 Hz จะเห็นอะไร
ความถี่สูงสุด 120 Hz อัตรา Nyquist 240 Hz
ที่ 200 Hz: 50 Hz ผ่าน ส่วน 120 Hz พับเป็น |120 − 200| = 80 Hz
ต้องมากกว่า 240 Hz · ที่ 200 Hz จะเห็น 50 Hz กับ 80 Hz (ผิด) · อัตรา Nyquist

C5สุ่ม $\cos(2\pi\cdot 1\text{k}\,t)$ ที่ 8 kHz ความถี่ดิจิทัล Ω และจำนวนจุดต่อคาบคือเท่าไร
$\Omega = 2\pi f/f_s = 2\pi/8$ มุมเป็นเรเดียน
$\Omega = \pi/4$ rad/sample · 8 จุดต่อคาบ · ความถี่ดิจิทัล

C6ADC 12 บิต ช่วง 0 ถึง 3.3 V มีขนาดขั้นและ SNR สูงสุดเท่าไร
$\Delta = 3.3/2^{12}$
SNR ≈ 6.02N + 1.76 dB ลดกำลัง sin²
$\Delta \approx 0.806$ mV · SNR ≈ 74.0 dB · ADC

## ชุด D · การแปลง Z (7 ข้อ) ขั้นสูง

D1หาการแปลง Z ของ $x[n] = \big[3(\tfrac12)^n - 2(-\tfrac13)^n\big]u[n]$ พร้อม ROC
แต่ละพจน์ $a^nu[n] \leftrightarrow \dfrac{z}{z - a}$
$X(z) = \dfrac{3z}{z - \frac12} - \dfrac{2z}{z + \frac13}$, ROC $|z| > \tfrac12$ · ตาราง

D2หาการแปลง Z ผกผันของ $X(z) = \dfrac{z^2}{(z - 1)(z - \tfrac12)}$ (คอซัล)
$\dfrac{X}{z} = \dfrac{2}{z - 1} - \dfrac{1}{z - \frac12}$
$x[n] = \big[2 - (\tfrac12)^n\big]u[n]$ · เศษส่วนย่อย

D3หาการแปลง Z ผกผันของ $X(z) = \dfrac{z}{z^2 - 0.5z + 0.06}$
$z^2 - 0.5z + 0.06 = (z - 0.3)(z - 0.2)$
$\dfrac{X}{z} = \dfrac{10}{z - 0.3} - \dfrac{10}{z - 0.2}$
$x[n] = 10\big(0.3^n - 0.2^n\big)u[n]$ · เศษส่วนย่อย

D4หา $\mathcal{Z}\{\cos(\tfrac{\pi}{3}n)u[n]\}$
ใช้คู่ cos ที่ $\cos\tfrac\pi3 = \tfrac12$ มุมพิเศษ cos, sin ในรูปเลขชี้กำลัง
$X(z) = \dfrac{z(z - \frac12)}{z^2 - z + 1}$ โพลที่ $e^{\pm j\pi/3}$ บนวงกลมพอดี · คู่ cos

D5$y[n] = 0.6\,y[n-1] + x[n]$, $x = u[n]$, เริ่มจากศูนย์ หา y[n] และค่าสุดท้าย
$Y = \dfrac{z}{z - 0.6}\cdot\dfrac{z}{z - 1}$ · $\dfrac{Y}{z} = \dfrac{2.5}{z - 1} - \dfrac{1.5}{z - 0.6}$
$y[n] = 2.5 - 1.5(0.6)^n$ ค่าสุดท้าย 2.5 = $H(1) = \tfrac{1}{1 - 0.6}$ · สมการผลต่าง

D6$H(z) = \dfrac{z + 1}{z^2 - 1.2z + 0.72}$ เสถียรไหม
โพล $z = 0.6 \pm 0.6j$ ขนาด $\sqrt{0.72} \approx 0.849$ เอกลักษณ์พีทาโกรัส
เสถียร (โพลอยู่ในวงกลม) · มุมโพล π/4 จึงมีการแกว่งคาบ 8 จุด · เสถียรภาพ

D7ตัวกรอง $y[n] = \tfrac12(x[n] - x[n-1])$ มีขนาดตอบสนองที่ Ω = π/2 และ Ω = π เท่าไร
$H = \tfrac12(1 - e^{-j\Omega}) = je^{-j\Omega/2}\sin\tfrac\Omega2$ cos, sin ในรูปเลขชี้กำลัง
$|H| = |\sin\tfrac\Omega2|$: ที่ π/2 ได้ 0.707 ที่ π ได้ 1 (ไฮพาส) · ผลตอบสนองเชิงความถี่

## คำถามที่พบบ่อย

ข้อสอบสัญญาณและระบบออกเรื่องอะไรบ่อย?
เกือบทุกที่ออกการจำแนกคุณสมบัติระบบ คอนโวลูชันต่อเนื่องหนึ่งข้อและไม่ต่อเนื่องหนึ่งข้อ การแปลงฟูริเยร์ของพัลส์หรือเอกซ์โพเนนเชียลพร้อมคุณสมบัติเลื่อนเวลา การหาความถี่ปลอม และการแปลง Z ผกผันด้วยเศษส่วนย่อยเพื่อแก้สมการผลต่าง

ตรวจคำตอบคอนโวลูชันอย่างไรให้เร็ว?
ดูสามอย่าง ความกว้างของผลลัพธ์ต้องเท่ากับผลรวมความกว้าง (ไม่ต่อเนื่องยาว N + M − 1) พื้นที่ของผลลัพธ์ต้องเท่ากับผลคูณพื้นที่ของสองตัว (ผลรวมของ y เท่ากับผลรวมของ x คูณผลรวมของ h) และค่าที่ขอบต้องต่อเนื่องกันถ้าสัญญาณไม่มีอิมพัลส์

การแปลง Z ผกผันทำไมต้องหารด้วย z ก่อน?
เพราะตารางมีรูป z/(z − a) ซึ่งมี z อยู่ข้างบน ถ้าแยกเศษส่วนย่อยของ X(z)/z แล้วคูณ z กลับ ทุกพจน์จะอยู่ในรูปนี้ทันที ไม่ต้องใช้คุณสมบัติเลื่อนเวลาเพิ่ม

**ข้อสอบสัญญาณและระบบออกเรื่องอะไรบ่อย?**

**ตรวจคำตอบคอนโวลูชันอย่างไรให้เร็ว?**

**การแปลง Z ผกผันทำไมต้องหารด้วย z ก่อน?**
