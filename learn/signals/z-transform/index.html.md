# การแปลง Z (Z-Transform): เครื่องมือหลักของสัญญาณและระบบเวลาไม่ต่อเนื่อง

// บทที่ 11.4 · สัญญาณและระบบ · Z-Transform


โปรแกรมกรองสัญญาณในไมโครคอนโทรลเลอร์ ตัวควบคุม PID แบบดิจิทัล หรือเครื่องปรับเสียงในมือถือ ทั้งหมดคือสมการผลต่าง (difference equation) การแปลง Z เปลี่ยนสมการพวกนี้เป็นพีชคณิต แบบเดียวกับที่ลาปลาซทำกับสมการเชิงอนุพันธ์ ผมจะเล่าเป็นลำดับ นิยาม ตาราง คุณสมบัติ ผกผัน แล้วจบที่โพล-ซีโรกับตัวกรอง ส่วนที่ใช้ตรีโกณ (คู่ cos sin และผลตอบสนองเชิงความถี่) ผมแสดงทุกบรรทัด

สามบรรทัดที่ต้องจำ

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n},\qquad x[n-k] \leftrightarrow z^{-k}X(z),\qquad x * h \leftrightarrow X(z)H(z)$$

ระบบคอซัลเสถียร ⇔ โพลทุกตัวอยู่ใน $|z| < 1$ · ผลตอบสนองเชิงความถี่ = $H(z)$ ที่ $z = e^{j\Omega}$

## นิยามและ ROC พื้นฐาน

การแปลง Z ของลำดับ x[n] คืออนุกรมกำลังของ $z^{-1}$ ที่มี x[n] เป็นสัมประสิทธิ์ ลองตัวที่สำคัญที่สุดก่อน $x[n] = a^nu[n]$

$$X(z) = \sum_{n=0}^{\infty} a^n z^{-n} = \sum_{n=0}^{\infty}\big(az^{-1}\big)^n = \frac{1}{1 - az^{-1}} = \frac{z}{z - a},\qquad |z| > |a|$$

ขั้นนี้คืออนุกรมเรขาคณิตตรง ๆ ลู่เข้าก็ต่อเมื่ออัตราส่วน $|az^{-1}| < 1$ เงื่อนไขนี้คือ ROC (region of convergence) ซึ่งเป็นบริเวณนอกวงกลมรัศมี |a|

ทำไม ROC สำคัญ ลองลำดับที่อยู่ฝั่งลบ $x[n] = -a^nu[-n-1]$ คิดแบบเดียวกันจะได้ $\dfrac{z}{z - a}$ เหมือนกันทุกตัวอักษร แต่ ROC เป็น $|z| < |a|$ คือสูตรเดียวกันมาจากสองสัญญาณ ROC เท่านั้นที่บอกว่าเป็นตัวไหน ในวิชานี้ถ้าไม่บอก ให้ถือว่าสัญญาณเป็นคอซัล ROC อยู่นอกโพลตัวที่ไกลที่สุด

### z คืออะไรในทางกายภาพ

เขียน $z = re^{j\Omega}$ แล้ว $z^n = r^ne^{j\Omega n} = r^n(\cos\Omega n + j\sin\Omega n)$ สูตรออยเลอร์ ฟังก์ชันพื้นฐานของการแปลง Z จึงเป็นไซน์ที่ขนาดโตหรือหดตาม rⁿ r บอกการโตหรือหด Ω บอกความเร็วการหมุน เทียบกับลาปลาซที่ $e^{st} = e^{\sigma t}(\cos\omega t + j\sin\omega t)$ จะเห็นว่าเป็นเรื่องเดียวกัน เชื่อมกันด้วย $z = e^{sT_s}$ ได้ $r = e^{\sigma T_s}$ และ $\Omega = \omega T_s$ ดังนั้น σ < 0 (ซีกซ้ายของระนาบ s) ไปอยู่ที่ r < 1 (ในวงกลมหนึ่งหน่วย)

## ตารางคู่การแปลง Z (สัญญาณคอซัล)

| $x[n]$ | $X(z)$ | ROC |

| $\delta[n]$ | $1$ | ทุก z |

| $\delta[n - k]$ | $z^{-k}$ | $z \ne 0$ |

| $u[n]$ | $\dfrac{z}{z - 1}$ | $|z| > 1$ |

| $a^nu[n]$ | $\dfrac{z}{z - a}$ | $|z| > |a|$ |

| $n\,u[n]$ | $\dfrac{z}{(z - 1)^2}$ | $|z| > 1$ |

| $n\,a^nu[n]$ | $\dfrac{az}{(z - a)^2}$ | $|z| > |a|$ |

| $\cos(\Omega_0n)\,u[n]$ | $\dfrac{z(z - \cos\Omega_0)}{z^2 - 2z\cos\Omega_0 + 1}$ | $|z| > 1$ |

| $\sin(\Omega_0n)\,u[n]$ | $\dfrac{z\sin\Omega_0}{z^2 - 2z\cos\Omega_0 + 1}$ | $|z| > 1$ |

| $r^n\cos(\Omega_0n)\,u[n]$ | $\dfrac{z(z - r\cos\Omega_0)}{z^2 - 2rz\cos\Omega_0 + r^2}$ | $|z| > r$ |

| $r^n\sin(\Omega_0n)\,u[n]$ | $\dfrac{zr\sin\Omega_0}{z^2 - 2rz\cos\Omega_0 + r^2}$ | $|z| > r$ |

ทุกแถวในตารางนี้ผมตรวจด้วยการบวกอนุกรมเชิงตัวเลข 400 พจน์ที่ z เชิงซ้อนค่าหนึ่ง ได้ผลต่างระดับ 10⁻¹⁶

### ที่มาของคู่ cos: สูตรออยเลอร์สามครั้ง กลาง

คู่ cos กับ sin ดูยาก แต่จริง ๆ มาจากแถว $a^nu[n]$ แถวเดียว แค่ใช้ a เป็นจำนวนเชิงซ้อน

- แตก cos เป็นเลขชี้กำลัง cos, sin ในรูปเลขชี้กำลัง $\cos\Omega_0n = \tfrac12\big(e^{j\Omega_0n} + e^{-j\Omega_0n}\big)$ แต่ละก้อนคือ $a^n$ ที่ $a = e^{\pm j\Omega_0}$

- เปิดตาราง: $X(z) = \tfrac12\Big(\dfrac{z}{z - e^{j\Omega_0}} + \dfrac{z}{z - e^{-j\Omega_0}}\Big)$

- ตัวส่วนร่วม: $(z - e^{j\Omega_0})(z - e^{-j\Omega_0}) = z^2 - z\big(e^{j\Omega_0} + e^{-j\Omega_0}\big) + e^{0} = z^2 - 2z\cos\Omega_0 + 1$ cos, sin ในรูปเลขชี้กำลัง

- ตัวเศษ: $\tfrac12 z\big[(z - e^{-j\Omega_0}) + (z - e^{j\Omega_0})\big] = \tfrac12 z\big[2z - 2\cos\Omega_0\big] = z(z - \cos\Omega_0)$

ทำแบบเดียวกันกับ sin cos, sin ในรูปเลขชี้กำลัง ตัวเศษจะเป็น $\tfrac{1}{2j}z\big(e^{j\Omega_0} - e^{-j\Omega_0}\big) = z\sin\Omega_0$ ส่วนแถว $r^n\cos$ ได้จากการแทน z ด้วย z/r (คุณสมบัติการคูณด้วย $r^n$) สังเกตว่าตัวส่วนคือ $|z - re^{j\Omega_0}|$ คูณกับสังยุค โพลคู่จึงอยู่ที่ $re^{\pm j\Omega_0}$ รัศมี r มุม ±Ω₀

## คุณสมบัติที่ใช้บ่อย

| คุณสมบัติ | เวลา | Z |

| เชิงเส้น | $ax_1 + bx_2$ | $aX_1 + bX_2$ |

| หน่วงเวลา (เงื่อนไขเริ่มต้นเป็นศูนย์) | $x[n - k]$ | $z^{-k}X(z)$ |

| หน่วงหนึ่งก้าว (มีค่าเริ่มต้น) | $x[n - 1]u[n]$ | $z^{-1}X(z) + x[-1]$ |

| คอนโวลูชัน | $x * h$ | $X(z)H(z)$ |

| คูณด้วย $a^n$ | $a^nx[n]$ | $X(z/a)$ |

| คูณด้วย n | $n\,x[n]$ | $-z\,\dfrac{dX}{dz}$ |

| ค่าเริ่มต้น | $x[0]$ | $\lim_{z\to\infty}X(z)$ |

| ค่าสุดท้าย (ถ้ามี) | $\lim_{n\to\infty}x[n]$ | $\lim_{z\to1}(z - 1)X(z)$ |

$z^{-1}$ คือ "หน่วงหนึ่งจุด" ในแผนภาพบล็อกตัวกรองดิจิทัลจึงเห็นกล่อง $z^{-1}$ อยู่ทุกที่ ในโปรแกรมมันคือตัวแปรที่จำค่ารอบที่แล้ว และเพราะคอนโวลูชันกลายเป็นการคูณ ตารางคูณคอนโวลูชันจึงเหมือนการคูณพหุนามใน $z^{-1}$ ทุกประการ

## การแปลง Z ผกผัน: เศษส่วนย่อยของ X(z)/z กลาง

ตารางมีแต่รูป $\dfrac{z}{z - a}$ ซึ่งมี z อยู่ข้างบน เคล็ดลับคือหารด้วย z ก่อน แยกเศษส่วนย่อยของ X(z)/z ด้วยวิธีปิดตัวประกอบ (cover-up) แล้วคูณ z กลับ ทุกพจน์จะอยู่ในรูปที่เปิดตารางได้ทันที ขั้นตอนเหมือนลาปลาซผกผันทุกอย่าง

ตัวอย่าง 1

### $X(z) = \dfrac{z}{(z - 0.5)(z - 1)}$, คอซัล

- $\dfrac{X(z)}{z} = \dfrac{1}{(z - 0.5)(z - 1)} = \dfrac{A}{z - 0.5} + \dfrac{B}{z - 1}$

- ปิดตัวประกอบ: $A = \dfrac{1}{0.5 - 1} = -2$, $B = \dfrac{1}{1 - 0.5} = 2$

- $X(z) = -2\dfrac{z}{z - 0.5} + 2\dfrac{z}{z - 1}$

$x[n] = 2\big(1 - 0.5^n\big)u[n]$ · ตรวจ: x[0] = 0 ตรงกับ $\lim_{z\to\infty}X = 0$ และค่าสุดท้าย $\lim_{z\to1}(z - 1)X = \tfrac{1}{0.5} = 2$ ตรงกัน

ตัวอย่าง 2

### $X(z) = \dfrac{z}{(z - \tfrac12)(z + \tfrac14)}$

- $A = \dfrac{1}{\tfrac12 + \tfrac14} = \tfrac43$, $B = \dfrac{1}{-\tfrac14 - \tfrac12} = -\tfrac43$

$x[n] = \tfrac43\Big[\big(\tfrac12\big)^n - \big(-\tfrac14\big)^n\Big]u[n]$ · โพลลบให้พจน์ที่สลับเครื่องหมายทุกก้าว (แกว่งที่ความถี่ Nyquist Ω = π)

ตัวอย่าง 3

### โพลเชิงซ้อน: $H(z) = \dfrac{z^2}{z^2 - z + \tfrac12}$

- โพล $z = \tfrac12 \pm \tfrac12j = \tfrac{1}{\sqrt2}e^{\pm j\pi/4}$ ได้ $r = \tfrac{1}{\sqrt2}$, $\Omega_0 = \tfrac\pi4$ มุมพิเศษ

- เทียบกับตาราง: $2r\cos\Omega_0 = 1$ และ $r^2 = \tfrac12$ ตรง แยกตัวเศษ $z^2 = z\big(z - \tfrac12\big) + \tfrac12z$ โดย $r\cos\Omega_0 = r\sin\Omega_0 = \tfrac12$

- ได้ $h[n] = r^n\cos\tfrac{\pi n}{4} + r^n\sin\tfrac{\pi n}{4}$

- รวมคลื่น รวมเป็นคลื่นเดียว $\cos\theta + \sin\theta = \sqrt2\cos(\theta - \tfrac\pi4)$

$h[n] = \big(\tfrac{1}{\sqrt2}\big)^{n}\sqrt2\cos\!\big(\tfrac{\pi n}{4} - \tfrac{\pi}{4}\big)u[n]$ = $\{1, 1, \tfrac12, 0, -\tfrac14, -\tfrac14, -\tfrac18, 0, \dots\}$ แกว่งด้วยคาบ 8 จุดและหดลงตาม rⁿ

## แก้สมการผลต่างและหาฟังก์ชันถ่ายโอน

สมการผลต่างเชิงเส้นสัมประสิทธิ์คงที่แปลง Z ได้ทีละพจน์ด้วยคุณสมบัติหน่วงเวลา แล้วแยก Y(z) ออกมา

ตัวอย่าง 4

### $y[n] = 0.9\,y[n-1] + x[n]$ ป้อน $x = u[n]$

- $Y = 0.9z^{-1}Y + X \Rightarrow H(z) = \dfrac{Y}{X} = \dfrac{1}{1 - 0.9z^{-1}} = \dfrac{z}{z - 0.9}$

- $Y(z) = \dfrac{z}{z - 0.9}\cdot\dfrac{z}{z - 1}$ · $\dfrac{Y}{z} = \dfrac{-9}{z - 0.9} + \dfrac{10}{z - 1}$

$y[n] = \big(10 - 9(0.9)^n\big)u[n] = 10\big(1 - 0.9^{n+1}\big)u[n]$ · ตรวจ y[0] = 1, y[1] = 1.9 ตรงกับการแทนค่าวนซ้ำ ค่าสุดท้าย 10 = อัตราขยาย DC $H(1)$

ระบบในตัวอย่าง 4 คือตัวกรองโลว์พาสอันดับหนึ่งที่ใช้กันมากที่สุดในเฟิร์มแวร์ (exponential smoothing) ถ้าอยากได้อัตราขยาย DC เท่ากับ 1 ให้เขียน $y[n] = 0.9y[n-1] + 0.1x[n]$ ระบบนี้เป็นคู่แฝดดิจิทัลของวงจร RC ในสมการอันดับหนึ่ง เทียบได้ด้วย $0.9 = e^{-T_s/RC}$

เทียบกับสมการเชิงอนุพันธ์อันดับสอง: สมการลักษณะเฉพาะของสมการผลต่างได้จากการลอง $y = z^n$ (เหมือนลอง $e^{rt}$) โพลเชิงซ้อนให้คำตอบ $r^n\cos$ และ $r^n\sin$ เหมือนรากเชิงซ้อนที่ให้ $e^{\alpha t}\cos$ และ $e^{\alpha t}\sin$ ทุกประการ

## โพล-ซีโร เสถียรภาพ และผลตอบสนองเชิงความถี่ ขั้นสูง

เสถียรภาพ: โพลที่ $z = p$ ให้พจน์ $p^n$ ใน h[n] ถ้า $|p| < 1$ พจน์นี้หดเป็นศูนย์ ถ้า $|p| = 1$ ไม่หด (แกว่งค้างหรือคงที่) ถ้า $|p| > 1$ ระเบิด ระบบคอซัลจึงเสถียรก็ต่อเมื่อโพลทุกตัวอยู่ในวงกลมหนึ่งหน่วย ส่วนซีโรอยู่ที่ไหนก็ได้

ผลตอบสนองเชิงความถี่: ป้อน $x[n] = e^{j\Omega n}$ เหมือนที่ทำในหน้า LTI จะได้ $y[n] = H(e^{j\Omega})e^{j\Omega n}$ จุด $e^{j\Omega}$ อยู่บนวงกลมหนึ่งหน่วยเสมอ เพราะ $|e^{j\Omega}|^2 = \cos^2\Omega + \sin^2\Omega = 1$ เอกลักษณ์พีทาโกรัส เดินจาก Ω = 0 (z = 1, DC) ทวนเข็มถึง Ω = π (z = −1, ความถี่ Nyquist) คือกวาดความถี่ทั้งหมดที่ระบบดิจิทัลมองเห็น

อ่านด้วยตาจากรูป: $|H(e^{j\Omega})|$ เท่ากับผลคูณระยะจากจุดบนวงกลมไปยังซีโรทุกตัว หารด้วยผลคูณระยะไปยังโพลทุกตัว เดินเข้าใกล้โพลแล้วขนาดพุ่ง (ยอด) เดินผ่านซีโรแล้วขนาดตก (ร่อง)

ตัวอย่าง 5

### ค่าเฉลี่ยสองจุด $y[n] = \tfrac12\big(x[n] + x[n-1]\big)$

- $H(e^{j\Omega}) = \tfrac12\big(1 + e^{-j\Omega}\big)$

- ดึงครึ่งมุมออก: $= e^{-j\Omega/2}\cdot\tfrac12\big(e^{j\Omega/2} + e^{-j\Omega/2}\big) = e^{-j\Omega/2}\cos\tfrac\Omega2$ cos, sin ในรูปเลขชี้กำลัง

$|H| = \big|\cos\tfrac\Omega2\big|$ และเฟส $-\tfrac\Omega2$ (เฟสเชิงเส้น หน่วงครึ่งจุด) · DC ผ่านเต็ม ที่ Ω = π/2 เหลือ $\cos\tfrac\pi4 = 0.707$ มุมพิเศษ ที่ Nyquist เป็นศูนย์ เพราะซีโรอยู่ที่ z = −1

เทคนิคดึงครึ่งมุมในตัวอย่าง 5 ใช้ได้กับตัวกรอง FIR สมมาตรทุกตัว และเป็นเหตุผลที่ FIR สมมาตรมีเฟสเชิงเส้นเสมอ

## แล็บ: ลากโพล ดูตัวกรองเปลี่ยน

เลือกตัวกรองแบบหนึ่ง แล้วปรับรัศมีโพล r และมุม θ ดูว่ายอดของ |H| เลื่อนตาม θ และคมขึ้นเมื่อ r เข้าใกล้ 1 ลองดัน r เกิน 1 ป้ายจะเปลี่ยนเป็นไม่เสถียรและ h[n] จะไม่หดลง โหมดนอตช์วางซีโรบนวงกลมพอดี จึงตัดความถี่ θ ได้หมด ใช้ตัดสัญญาณรบกวน 50 Hz จากสายไฟได้

ตัวอย่าง 6

### ตั้งนอตช์ตัด 50 Hz ที่ fₛ = 1 kHz

- $\theta = 2\pi\cdot\tfrac{50}{1000} = 0.1\pi = 0.3142$ rad

- ซีโรที่ $e^{\pm j0.1\pi}$: ตัวเศษ $1 - 2\cos(0.1\pi)z^{-1} + z^{-2} = 1 - 1.902z^{-1} + z^{-2}$ cos, sin ในรูปเลขชี้กำลัง

- โพลที่ $0.95e^{\pm j0.1\pi}$ ทำให้ร่องแคบ ตัวส่วน $1 - 1.807z^{-1} + 0.9025z^{-2}$

ร่องตกตรง 50 Hz ส่วนความถี่ที่ห่างออกไปผ่านเกือบเต็ม ยิ่ง r ใกล้ 1 ร่องยิ่งแคบ แต่ใช้เวลาตั้งตัวนานขึ้น

## จุดที่มักพลาด

- แยกเศษส่วนย่อยของ X(z) ตรง ๆ ได้พจน์ $\tfrac{A}{z - a}$ ซึ่งคือ $a^{n-1}u[n-1]$ ไม่ใช่ $a^nu[n]$ หารด้วย z ก่อนจะง่ายกว่า

- ลืม ROC ถ้าโจทย์ไม่ได้บอกว่าคอซัล ต้องดู ROC ก่อนเปิดตาราง

- ใช้ทฤษฎีบทค่าสุดท้ายกับระบบไม่เสถียร ใช้ได้เมื่อโพลของ $(z - 1)X(z)$ อยู่ในวงกลมหนึ่งหน่วยเท่านั้น

- สับสน z⁻¹ กับ z ตัวกรองมักเขียนด้วย $z^{-1}$ ก่อนหาโพลให้คูณตัวเศษตัวส่วนด้วยกำลังของ z ให้เป็นพหุนามใน z

ต่อไป: โจทย์สัญญาณและระบบพร้อมเฉลย ครบทั้งสี่เรื่องในบทนี้

## คำถามที่พบบ่อย

การแปลง Z คืออะไร ต่างจากลาปลาซอย่างไร?
การแปลง Z คือ X(z) = Σ x[n] z^{−n} ใช้กับสัญญาณไม่ต่อเนื่อง เทียบได้กับการแปลงลาปลาซที่ใช้กับสัญญาณต่อเนื่อง ทั้งสองเปลี่ยนสมการ (ผลต่างหรืออนุพันธ์) เป็นพีชคณิต และเชื่อมกันด้วย z = e^{sT} ซีกซ้ายของระนาบ s ถูกส่งไปอยู่ในวงกลมหนึ่งหน่วยของระนาบ z

ROC (region of convergence) สำคัญอย่างไร?
X(z) สูตรเดียวกันมาจากสัญญาณต่างกันได้ เช่น z/(z − a) มาจาก aⁿu[n] ถ้า ROC คือ |z| > |a| แต่มาจาก −aⁿu[−n−1] ถ้า ROC คือ |z|
ระบบดิจิทัลเสถียรเมื่อไร?
ระบบคอซัลเสถียรก็ต่อเมื่อโพลทุกตัวของ H(z) อยู่ในวงกลมหนึ่งหน่วย |z|
หาการแปลง Z ผกผันอย่างไร?
วิธีที่ใช้บ่อยที่สุดคือแยกเศษส่วนย่อยของ X(z)/z (หารด้วย z ก่อน) แล้วคูณ z กลับ จะได้พจน์ Az/(z − p) ซึ่งเปิดตารางได้ A pⁿ u[n] ทันที วิธีอื่นคือหารยาวเพื่อได้ทีละค่า หรือใช้อินทิกรัลเชิงซ้อนกับเรซิดิว

ทำไมผลตอบสนองเชิงความถี่ของระบบดิจิทัลอยู่บนวงกลมหนึ่งหน่วย?
เพราะอินพุตไซน์ความถี่ดิจิทัล Ω เขียนเป็น e^{jΩn} ซึ่งก็คือ zⁿ ที่ z = e^{jΩ} จุดนี้มีขนาด 1 เสมอ (cos²Ω + sin²Ω = 1) จึงอยู่บนวงกลมหนึ่งหน่วย เดินรอบวงกลมจาก Ω = 0 ถึง π คือกวาดจาก DC ถึงความถี่ Nyquist
