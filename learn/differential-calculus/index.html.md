# อนุพันธ์ (Differential Calculus): นิยาม สูตร และวิธีทำทีละขั้น

// บทที่ 4 · คณิตศาสตร์วิศวกรรม · Differential Calculus


อนุพันธ์วัดว่าสิ่งหนึ่งเปลี่ยนเร็วแค่ไหนเทียบกับอีกสิ่ง เป็นภาษาของความเร็ว กระแส กำลัง ความชันของคาน และการหาจุดที่ดีที่สุด หน้านี้รวมทุกอย่างที่ต้องใช้ตั้งแต่นิยามที่ลากดูได้ สูตรครบทุกกลุ่มพร้อมรหัส D ไปจนถึงการหาค่าสุดขีดและนิวตัน-ราฟสัน ส่วนตัวอย่างงานจริงในวิศวกรรมไฟฟ้า เครื่องกล และโยธา แยกไว้ในหน้าการประยุกต์

สรุปใน 30 วินาที

- $f'(x) = \lim_{h\to0}\frac{f(x+h) - f(x)}{h}$ = ความชันของเส้นสัมผัส = อัตราการเปลี่ยนแปลงขณะหนึ่ง

- $(x^n)' = nx^{n-1}$ · $(uv)' = u'v + uv'$ · $(u/v)' = (u'v - uv')/v^2$ · $f(g(x))' = f'(g)g'$

- จุดวิกฤต f′ = 0 → f″ < 0 สูงสุด · f″ > 0 ต่ำสุด

- ใกล้จุด a: $f(x) \approx f(a) + f'(a)(x - a)$ และหารากด้วย $x_{n+1} = x_n - f/f'$

ระดับพื้นฐาน ม.ปลาย · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง เชิงตัวเลข

## นิยาม: จากเส้นตัดสู่เส้นสัมผัส พื้นฐาน

ความชันของเส้นตัดผ่านสองจุดบนกราฟคืออัตราการเปลี่ยนแปลงเฉลี่ย เมื่อเลื่อนจุดที่สองเข้าหาจุดแรก (h → 0) เส้นตัดจะหมุนเข้าหาเส้นสัมผัส ความชันที่ได้คืออนุพันธ์

D1 Derivative นิยามอนุพันธ์

$$f'(x) = \frac{dy}{dx} = \lim_{h\to 0}\frac{f(x+h) - f(x)}{h}$$

สัญลักษณ์: $f'(x)$ (ลากรองจ์) · $\frac{dy}{dx}$ (ไลบ์นิซ) · $\dot x$ (นิวตัน ใช้กับเวลา) · $Df$

D2 Tangent line สมการเส้นสัมผัส

$$y = f(a) + f'(a)(x - a)$$

D3 Differentiability หาอนุพันธ์ได้ ⇒ ต่อเนื่อง

$$f'(a) \text{ มีค่า} \Rightarrow f \text{ ต่อเนื่องที่ } a\quad(\text{กลับกันไม่จริง: } |x| \text{ ที่ } 0)$$

ตัวอย่าง D-1 · จากนิยาม

### หาอนุพันธ์ของ $f(x) = x^2$ และ $g(x) = \sqrt x$ จากนิยาม

-
$$\frac{(x+h)^2 - x^2}{h} = \frac{2xh + h^2}{h} = 2x + h \xrightarrow{h\to0} 2x$$

- คูณคอนจูเกต (เหมือนตัวอย่าง L-5)

$$\frac{\sqrt{x+h} - \sqrt x}{h}\cdot\frac{\sqrt{x+h} + \sqrt x}{\sqrt{x+h} + \sqrt x} = \frac{1}{\sqrt{x+h} + \sqrt x} \xrightarrow{h\to0} \frac{1}{2\sqrt x}$$

$(x^2)' = 2x$, $(\sqrt x)' = \dfrac{1}{2\sqrt x}$ ตรงกับกฎยกกำลัง $nx^{n-1}$ ที่ $n = 2$ และ $n = \tfrac12$

## แล็บเส้นตัด → เส้นสัมผัส และกราฟของอนุพันธ์

ลากจุดสีส้มไปตามกราฟ และเลื่อน h ลงไปที่ศูนย์ กราฟล่างคือ $f'(x)$ (เขียว) และ $f''(x)$ (ม่วง เส้นประ) จุดเขียวบนแกน x คือจุดวิกฤตที่ f′ = 0 สังเกตว่าตรงที่ f′ เป็นบวก กราฟบนกำลังขึ้นเสมอ พิมพ์ฟังก์ชันของคุณเองได้

## สูตรอนุพันธ์ครบทุกกลุ่ม พื้นฐาน

### กฎพื้นฐาน

D4 Constant rule ค่าคงที่

$$\frac{d}{dx}c = 0$$

D5 Power rule กฎยกกำลัง

$$\frac{d}{dx}x^n = nx^{n-1},\quad n \in \mathbb{R}$$
กรณี n เป็นจำนวนนับ พิสูจน์ด้วยอุปนัยเชิงคณิตศาสตร์

D6 Linearity ผลบวกและตัวคูณ

$$(af + bg)' = af' + bg'$$

D7 Product rule ผลคูณ

$$(uv)' = u'v + uv'$$

D8 Quotient rule ผลหาร

$$\left(\frac uv\right)' = \frac{u'v - uv'}{v^2}$$

D9 Chain rule กฎลูกโซ่

$$\frac{d}{dx}f\big(g(x)\big) = f'\big(g(x)\big)\,g'(x),\qquad \frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx}$$

### เอกซ์โพเนนเชียลและลอการิทึม

D10 Natural exponential

$$\frac{d}{dx}e^x = e^x,\qquad \frac{d}{dx}e^{ax} = ae^{ax}$$

D11 General exponential

$$\frac{d}{dx}a^x = a^x\ln a$$

D12 Natural logarithm

$$\frac{d}{dx}\ln|x| = \frac1x$$

D13 Logarithm base a

$$\frac{d}{dx}\log_ax = \frac{1}{x\ln a}$$

### ตรีโกณมิติ

D14 sin, cos

$$(\sin x)' = \cos x,\qquad (\cos x)' = -\sin x$$

D15 tan, cot

$$(\tan x)' = \sec^2x,\qquad (\cot x)' = -\csc^2x$$

D16 sec, csc

$$(\sec x)' = \sec x\tan x,\qquad (\csc x)' = -\csc x\cot x$$

### ตรีโกณผกผันและไฮเพอร์โบลิก

D17 arcsin, arccos

$$(\sin^{-1}x)' = \frac{1}{\sqrt{1-x^2}},\qquad (\cos^{-1}x)' = -\frac{1}{\sqrt{1-x^2}}$$

D18 arctan, arccot

$$(\tan^{-1}x)' = \frac{1}{1+x^2},\qquad (\cot^{-1}x)' = -\frac{1}{1+x^2}$$

D19 Hyperbolic

$$(\sinh x)' = \cosh x,\qquad (\cosh x)' = \sinh x$$

ตัวอย่าง D-2 · ผลคูณและผลหาร

### (ก) $\dfrac{d}{dx}\left(x^2\sin x\right)$ (ข) $\dfrac{d}{dx}\dfrac{x^2+1}{x-1}$

- (ก) $u = x^2,\ v = \sin x$ D7

$$2x\sin x + x^2\cos x$$

- (ข) $u = x^2 + 1,\ v = x - 1$ D8

$$\frac{2x(x-1) - (x^2+1)(1)}{(x-1)^2} = \frac{x^2 - 2x - 1}{(x-1)^2}$$

(ก) $2x\sin x + x^2\cos x$ · (ข) $\dfrac{x^2 - 2x - 1}{(x-1)^2}$

## กฎลูกโซ่ อนุพันธ์โดยปริยาย และลอการิทึม กลาง

ตัวอย่าง D-3 · กฎลูกโซ่

### (ก) $\dfrac{d}{dx}(3x^2+1)^5$ (ข) $\dfrac{d}{dt}V_m\sin(\omega t + \phi)$ (ค) $\dfrac{d}{dt}e^{-t/\tau}$

- (ก) ชั้นนอก $(\ )^5$ ชั้นใน $3x^2 + 1$ D9

$$5(3x^2+1)^4\cdot 6x = 30x(3x^2+1)^4$$

- (ข) $V_m\cos(\omega t + \phi)\cdot\omega = \omega V_m\cos(\omega t + \phi)$ — ความถี่ยิ่งสูง อนุพันธ์ยิ่งใหญ่

- (ค) $e^{-t/\tau}\cdot\left(-\dfrac1\tau\right) = -\dfrac{1}{\tau}e^{-t/\tau}$ — ความชันเริ่มต้นเป็น $-1/\tau$

กฎลูกโซ่คือเหตุที่ $i = C\,dv/dt$ ของแรงดันไซน์ได้ $\omega CV_m$ และเป็นที่มาของ $X_C = 1/(\omega C)$

D20 Implicit differentiation อนุพันธ์โดยปริยาย

$$F(x, y) = 0 \Rightarrow \text{หาอนุพันธ์ทั้งสองข้างเทียบ } x \text{ โดยถือ } y = y(x)$$

D21 Logarithmic differentiation ใส่ ln ก่อนหาอนุพันธ์

$$y = f(x)^{g(x)} \Rightarrow \frac{y'}{y} = \frac{d}{dx}\big[g\ln f\big]$$

ตัวอย่าง D-4 · โดยปริยายและลอการิทึม

### (ก) ความชันของวงกลม $x^2 + y^2 = 25$ ที่ $(3, 4)$ (ข) $\dfrac{d}{dx}x^x$

- (ก) $2x + 2y\,y' = 0 \Rightarrow y' = -x/y$ ที่ $(3, 4)$: $y' = -\tfrac34$

- (ข) $\ln y = x\ln x \Rightarrow \dfrac{y'}{y} = \ln x + 1 \Rightarrow y' = x^x(\ln x + 1)$

(ก) $-\tfrac34$ (ตั้งฉากกับรัศมีที่มีความชัน $\tfrac43$) · (ข) $x^x(1 + \ln x)$

## อนุพันธ์อันดับสูง และฟังก์ชันอิงพารามิเตอร์ กลาง

D22 Higher derivatives อนุพันธ์อันดับสูง

$$f''(x) = \frac{d^2y}{dx^2},\quad f^{(n)}(x) = \frac{d^ny}{dx^n}$$

ตำแหน่ง → ความเร็ว → ความเร่ง → jerk · $f''$ บอกความเว้า

D23 Parametric curves อิงพารามิเตอร์

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt},\qquad \frac{d^2y}{dx^2} = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{dx/dt}$$

ตัวอย่าง D-5 · การสั่นแบบฮาร์มอนิก

### แสดงว่า $y = A\cos\omega t + B\sin\omega t$ สอดคล้อง $y'' + \omega^2 y = 0$

-
$$y' = -A\omega\sin\omega t + B\omega\cos\omega t,\qquad y'' = -A\omega^2\cos\omega t - B\omega^2\sin\omega t = -\omega^2y$$

$y'' + \omega^2y = 0$ ✓ คือสมการของวงจร LC ไม่มีความต้านทานและมวล-สปริงไม่มีแรงหน่วง ความถี่ $\omega = 1/\sqrt{LC}$ หรือ $\sqrt{k/m}$

## อัตราสัมพัทธ์ (Related Rates) กลาง

เมื่อหลายปริมาณเปลี่ยนตามเวลาและผูกกันด้วยสมการ ให้หาอนุพันธ์ทั้งสมการเทียบ t (ใช้กฎลูกโซ่ทุกตัวแปร) แล้วแทนค่า ณ ขณะที่ถาม

ตัวอย่าง D-6 · บันไดลื่น

### บันไดยาว 5 m พิงผนัง ปลายล่างเลื่อนออกด้วยอัตรา 0.5 m/s ขณะปลายล่างห่างผนัง 3 m ปลายบนเลื่อนลงเร็วเท่าใด

- $x^2 + y^2 = 25$ หาอนุพันธ์เทียบ t: $2x\dot x + 2y\dot y = 0$

- ขณะ $x = 3$: $y = 4$

$$\dot y = -\frac{x\dot x}{y} = -\frac{3(0.5)}{4} = -0.375\ \text{m/s}$$

ปลายบนเลื่อนลง 0.375 m/s (เครื่องหมายลบ = ลดลง)

## ค่าสูงสุด ต่ำสุด ความเว้า และการวาดกราฟ พื้นฐาน

D24 Critical points จุดวิกฤต

$$f'(c) = 0 \text{ หรือ } f'(c) \text{ ไม่นิยาม}$$

D25 First derivative test

$$f': +\to- \Rightarrow \text{สูงสุด},\qquad -\to+ \Rightarrow \text{ต่ำสุด}$$

D26 Second derivative test

$$f'(c) = 0:\ f''(c) < 0 \Rightarrow \text{สูงสุด},\ f''(c) > 0 \Rightarrow \text{ต่ำสุด}$$

D27 Concavity & inflection ความเว้า

$$f'' > 0 \text{ เว้าขึ้น},\ f'' < 0 \text{ เว้าลง},\ f'' \text{ เปลี่ยนเครื่องหมาย} \Rightarrow \text{จุดเปลี่ยนเว้า}$$

D28 Closed-interval method ค่าสุดขีดสัมบูรณ์บน [a, b]

$$\max_{[a,b]}f = \max\{f(a),\ f(b),\ f(c_1),\ \dots\},\quad c_i = \text{จุดวิกฤตใน } (a, b)$$

ตัวอย่าง D-7 · ค่าสุดขีดบนช่วงปิด

### หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^3 - 3x$ บน $[-2, 3]$

- $f'(x) = 3x^2 - 3 = 0 \Rightarrow x = \pm1$ (อยู่ในช่วงทั้งคู่)

- เทียบค่า: $f(-2) = -2$, $f(-1) = 2$, $f(1) = -2$, $f(3) = 18$

สูงสุดสัมบูรณ์ 18 ที่ $x = 3$ (ปลายช่วง ไม่ใช่จุดวิกฤต) · ต่ำสุดสัมบูรณ์ −2 ที่ $x = -2$ และ $x = 1$ · ค่า 2 ที่ $x = -1$ เป็นเพียงสูงสุดสัมพัทธ์

ปัญหาหาค่าเหมาะสมในงานจริง (กล่อง กระป๋อง ถ่ายโอนกำลังสูงสุด คานจากซุง) พร้อมแล็บ อยู่ในหน้าการประยุกต์

## ทฤษฎีบทค่าเฉลี่ยและการประมาณเชิงเส้น กลาง

D29 Mean value theorem ทฤษฎีบทค่าเฉลี่ย

$$\exists c \in (a, b):\ f'(c) = \frac{f(b) - f(a)}{b - a}$$

f ต่อเนื่องบน [a, b] หาอนุพันธ์ได้บน (a, b) · กรณี $f(a) = f(b)$ คือทฤษฎีบทของโรล · ตัวอย่าง: ขับรถเฉลี่ย 90 km/h แปลว่ามีขณะหนึ่งที่มาตรวัดชี้ 90 พอดี

D30 Linearization การประมาณเชิงเส้น

$$f(x) \approx f(a) + f'(a)(x - a)$$

พื้นฐานของแบบจำลองสัญญาณเล็ก (small-signal) ของทรานซิสเตอร์และการทำให้ระบบไม่เชิงเส้นเป็นเชิงเส้นในวิชาควบคุม

D31 Differentials & error propagation การแพร่ของความคลาดเคลื่อน

$$dy = f'(x)\,dx,\qquad y = kx^n \Rightarrow \frac{dy}{y} = n\frac{dx}{x}$$

ตัวอย่าง D-8 · ประมาณและความคลาดเคลื่อน

### (ก) ประมาณ $\sqrt{4.1}$ (ข) วัด $V = 230$ V คลาด ±1% กำลังในตัวต้านทาน $P = V^2/R$ คลาดกี่ %

- (ก) $f = \sqrt x,\ a = 4$: $f(4) = 2,\ f'(4) = \tfrac{1}{4}$

$$\sqrt{4.1} \approx 2 + \tfrac14(0.1) = 2.025$$

- (ข) $P \propto V^2$ ใช้ D31 ด้วย $n = 2$: $\dfrac{dP}{P} = 2\dfrac{dV}{V} = 2(\pm1\%)$

(ก) 2.025 (ค่าจริง 2.02485 คลาด 0.007%) · (ข) ±2% ความคลาดเคลื่อนสัมพัทธ์คูณด้วยเลขชี้กำลังเสมอ

## วิธีนิวตัน-ราฟสัน (Newton–Raphson) ขั้นสูง

หารากของ $f(x) = 0$ โดยลากเส้นสัมผัสที่จุดปัจจุบันลงไปตัดแกน x แล้วใช้จุดตัดเป็นค่าประมาณถัดไป ใกล้รากจำนวนหลักทศนิยมที่ถูกเพิ่มเป็นสองเท่าทุกรอบ (ลู่เข้าแบบกำลังสอง) โปรแกรมจำลองวงจรอย่าง SPICE ใช้วิธีนี้หาจุดทำงานของไดโอดและทรานซิสเตอร์

D32 Newton–Raphson iteration

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

ล้มเหลวได้ถ้า $f'(x_n) \approx 0$ หรือเริ่มไกลรากเกินไป · $\sqrt{a}$: $x_{n+1} = \tfrac12\left(x_n + \tfrac{a}{x_n}\right)$ (วิธีของชาวบาบิโลน)

ตัวอย่าง D-9 · ตัวอย่างดั้งเดิมของนิวตัน

### หารากของ $x^3 - 2x - 5 = 0$ เริ่มที่ $x_0 = 2$

- $f'(x) = 3x^2 - 2$ · $x_1 = 2 - \dfrac{8 - 4 - 5}{12 - 2} = 2 + 0.1 = 2.1$

- $x_2 = 2.1 - \dfrac{9.261 - 4.2 - 5}{13.23 - 2} = 2.1 - \dfrac{0.061}{11.23} = 2.0945681$

- $x_3 = 2.0945515$ · $x_4 = 2.0945514815$

ราก $\approx 2.0945514815$ ใช้เพียง 4 รอบได้ 10 หลัก

## คำถามที่พบบ่อย

อนุพันธ์คืออะไรในภาษาง่าย ๆ?
อัตราการเปลี่ยนแปลง ณ ขณะหนึ่ง หรือความชันของเส้นสัมผัสกราฟ เช่น ความเร็วคืออนุพันธ์ของตำแหน่ง กระแสคืออนุพันธ์ของประจุ และกระแสในตัวเก็บประจุเป็นสัดส่วนกับอนุพันธ์ของแรงดัน $i = C\,dv/dt$

กฎลูกโซ่ใช้เมื่อไร?
เมื่อมีฟังก์ชันซ้อนฟังก์ชัน เช่น $\sin(\omega t)$, $e^{-t/\tau}$, $(3x^2+1)^5$ ให้หาอนุพันธ์ของฟังก์ชันชั้นนอกโดยคงข้างในไว้ แล้วคูณด้วยอนุพันธ์ของข้างใน $\frac{d}{dx}f(g(x)) = f'(g(x))g'(x)$

หาค่าสูงสุด-ต่ำสุดอย่างไร?
หาจุดวิกฤตที่ f′ = 0 หรือไม่นิยาม แล้วทดสอบด้วยอนุพันธ์อันดับสอง (f″ 0 ต่ำสุด) หรือดูการเปลี่ยนเครื่องหมายของ f′ ถ้าเป็นช่วงปิดต้องเทียบกับค่าที่ปลายช่วงด้วย

ฟังก์ชันต่อเนื่องหาอนุพันธ์ได้เสมอไหม?
ไม่ หาอนุพันธ์ได้ทำให้ต่อเนื่อง แต่กลับกันไม่จริง เช่น $|x|$ ต่อเนื่องที่ x = 0 แต่มีมุมแหลม ความชันซ้ายเป็น −1 ขวาเป็น 1 จึงไม่มีอนุพันธ์ที่จุดนั้น
