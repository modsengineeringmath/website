# สูตรดิฟทั้งหมด (Table of Derivatives): ดิฟอะไรได้อะไร พร้อมที่มาและเอกลักษณ์ตรีโกณที่ใช้

// บทที่ 4.2 · อนุพันธ์ · Table of Derivatives


ตารางนี้ทำไว้สำหรับวันที่ต้องการคำตอบเร็ว ว่าดิฟตัวนี้แล้วได้อะไร แต่ละแถวมีหมายเหตุสั้น ๆ ว่าสูตรมาจากไหน ส่วนแถวที่เป็นตรีโกณจะมีป้ายเล็กสีน้ำเงินบอกชื่อเอกลักษณ์ที่ใช้ ชี้ค้างหรือแตะที่ป้ายเพื่อดูสูตรและไปยังหัวข้อนั้นในบทตรีโกณมิติ ทุกแถวผมให้โปรแกรมดิฟซ้ำและเทียบค่าเชิงตัวเลขแล้ว ถ้าอยากรู้ว่าทำไมดิฟ sin ได้ cos ให้อ่านต่อที่อนุพันธ์ของฟังก์ชันตรีโกณมิติ

## ดิฟอะไรได้อะไร: คำตอบสั้นที่ถูกถามบ่อยที่สุด

| ดิฟ… | ได้… | ถ้าข้างในเป็น u(x) |

| $\sin x$ | $\cos x$ | $\cos u \cdot u'$ |

| $\cos x$ | $-\sin x$ | $-\sin u \cdot u'$ |

| $\tan x$ | $\sec^2 x$ | $\sec^2 u \cdot u'$ |

| $\sec x$ | $\sec x \tan x$ | $\sec u\tan u \cdot u'$ |

| $e^x$ | $e^x$ | $e^{u} \cdot u'$ |

| $\ln x$ | $\dfrac1x$ | $\dfrac{u'}{u}$ |

| $x^n$ | $nx^{n-1}$ | $n u^{n-1} \cdot u'$ |

| $\sqrt{x}$ | $\dfrac{1}{2\sqrt x}$ | $\dfrac{u'}{2\sqrt u}$ |

| $\dfrac1x$ | $-\dfrac{1}{x^2}$ | $-\dfrac{u'}{u^2}$ |

| $\sin^{-1}x$ | $\dfrac{1}{\sqrt{1-x^2}}$ | $\dfrac{u'}{\sqrt{1-u^2}}$ |

| $\tan^{-1}x$ | $\dfrac{1}{1+x^2}$ | $\dfrac{u'}{1+u^2}$ |

คอลัมน์ขวาสุดคือที่มาของคะแนนที่หายไปในห้องสอบมากที่สุด นักศึกษาจำสูตรซ้ายได้ แต่ลืมคูณ $u'$ เวลาข้างในไม่ใช่ x เฉย ๆ เช่น ดิฟ $\sin 3x$ ต้องได้ $3\cos 3x$ ไม่ใช่ $\cos 3x$ กฎลูกโซ่

## สามกฎที่ใช้ร่วมกับตาราง: ผลคูณ ผลหาร ลูกโซ่

| กฎ | สูตร | จำแบบไหนไม่พลาด |

| ผลคูณ
product rule | $(uv)' = u'v + uv'$ | ดิฟทีละตัว อีกตัวอยู่เฉย ๆ แล้วบวกกัน สลับลำดับได้ |

| ผลหาร
quotient rule | $\left(\dfrac uv\right)' = \dfrac{u'v - uv'}{v^2}$ | “ดิฟบนคูณล่าง ลบบนคูณดิฟล่าง ส่วนล่างยกกำลังสอง” ลำดับสลับไม่ได้ เพราะมีลบ |

| ลูกโซ่
chain rule | $\dfrac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$ | ดิฟจากชั้นนอกเข้าชั้นใน ข้างในยังเหมือนเดิม แล้วคูณดิฟของข้างใน ทีละชั้นจนหมด |

กฎผลหารเป็นกฎที่คนลืมเครื่องหมายบ่อยที่สุด วิธีเช็กเร็ว ๆ คือลองกับ $\dfrac{1}{x}$ ถ้าใส่ $u = 1,\ v = x$ จะได้ $\dfrac{0\cdot x - 1\cdot 1}{x^2} = -\dfrac1{x^2}$ ตรงกับกฎยกกำลัง ถ้าสลับลำดับจะได้เครื่องหมายบวก ซึ่งผิด

ตัวอย่างที่ใช้ทั้งสามกฎพร้อมกัน เช่น $\dfrac{d}{dx}\dfrac{x^2\sin 3x}{e^x}$ มีอยู่ในโจทย์ดิฟพร้อมเฉลย ชุด B

## สูตรดิฟตรีโกณ (sin cos tan sec csc cot) กลาง

ทุกบรรทัดในกลุ่มนี้ต่อยอดมาจากสองบรรทัดแรก คือ (sin x)′ = cos x และ (cos x)′ = −sin x ที่เหลือได้จากนิยาม tan = sin/cos, sec = 1/cos กับกฎผลหารหรือลูกโซ่ แล้วจัดรูปด้วยเอกลักษณ์ ป้ายเล็กสีน้ำเงินบอกว่าใช้เอกลักษณ์ตัวไหน ชี้ค้างไว้เพื่อดูสูตร มุมต้องเป็นเรเดียนเสมอ

## จำสูตรดิฟตรีโกณให้ได้ภายในห้านาที

ไม่ต้องท่องทั้งหกบรรทัด จำแค่สามข้อสังเกตนี้

- คู่หลักมีสองคู่ คือ sin กับ cos และ tan กับ sec ส่วน cot กับ csc เป็นคู่ “โค” ที่หน้าตาเหมือนคู่หลักทุกอย่าง แค่สลับเป็นตัวโค เลื่อนเฟส 90° (โคฟังก์ชัน)

- ตัวที่ขึ้นต้นด้วย c ดิฟแล้วได้เครื่องหมายลบ ได้แก่ cos, cot, csc ไม่มีข้อยกเว้น

- tan กับ sec จับคู่กัน (tan)′ = sec² และ (sec)′ = sec tan ส่วน cot กับ csc ก็จับคู่กันแบบเดียวกัน (cot)′ = −csc² และ (csc)′ = −csc cot

ทำไมตัวโคต้องติดลบ เหตุผลอยู่ที่ $\cos x = \sin\!\left(\tfrac{\pi}{2} - x\right)$ ดิฟด้วยกฎลูกโซ่ ข้างในคือ $\tfrac{\pi}{2} - x$ ซึ่งดิฟได้ $-1$ เครื่องหมายลบจึงติดมาเสมอ เลื่อนเฟส 90° (โคฟังก์ชัน) กฎลูกโซ่

## ใช้ตารางนี้ต่ออย่างไร

- อนุพันธ์ของฟังก์ชันตรีโกณมิติ: พิสูจน์ทุกบรรทัดในกลุ่มตรีโกณ พร้อมแล็บดูความชันของกราฟ sin ที่กลายเป็น cos

- โจทย์ดิฟพร้อมเฉลย 36 ข้อ: ฝึกใช้ตารางกับกฎลูกโซ่ ผลคูณ ผลหาร และดิฟโดยปริยาย

- เครื่องคำนวณอนุพันธ์: พิมพ์ฟังก์ชันแล้วได้คำตอบพร้อมกฎที่ใช้ทีละพจน์

- ตารางสูตรอินทิเกรต: อ่านกลับทิศ ดิฟสูตรไหนได้อะไร อินทิเกรตก็ได้กลับคืน

## คำถามที่พบบ่อย

ดิฟ sin ได้อะไร?
ดิฟ sin x ได้ cos x และดิฟ sin(ax) ได้ a cos(ax) ตามกฎลูกโซ่ ใช้ได้เมื่อ x เป็นเรเดียนเท่านั้น ถ้าวัดมุมเป็นองศาต้องคูณ π/180 เพิ่ม

ดิฟ cos ได้อะไร?
ดิฟ cos x ได้ −sin x เครื่องหมายลบมาจากการที่ cos ลดลงในช่วง 0 ถึง π ซึ่งเป็นช่วงที่ sin เป็นบวก

ดิฟ tan ได้อะไร?
ดิฟ tan x ได้ sec²x ซึ่งเท่ากับ 1 + tan²x ได้จากกฎผลหารของ sin x / cos x แล้วใช้ sin²x + cos²x = 1

ดิฟ ln x ได้อะไร?
ดิฟ ln x ได้ 1/x และดิฟ ln(u) ได้ u′/u ส่วน ln|x| ดิฟได้ 1/x เช่นกันแต่ใช้ได้ทั้ง x บวกและลบ

ดิฟ e^x ได้อะไร?
ดิฟ e^x ได้ e^x เหมือนเดิม ดิฟ e^{ax} ได้ a e^{ax} และดิฟ e^{u} ได้ e^{u} · u′

สูตรดิฟผลคูณและผลหารคืออะไร?
ผลคูณ (uv)′ = u′v + uv′ ส่วนผลหาร (u/v)′ = (u′v − uv′)/v² จำว่าผลหารขึ้นต้นด้วยดิฟตัวบนและมีเครื่องหมายลบ

ดิฟ e^x ได้ e^x เหมือนเดิม ดิฟ e^{ax} ได้ a e^{ax} และดิฟ e^{u} ได้ e^{u} · u′

**สูตรดิฟผลคูณและผลหารคืออะไร?**
ผลคูณ (uv)′ = u′v + uv′ ส่วนผลหาร (u/v)′ = (u′v − uv′)/v² จำว่าผลหารขึ้นต้นด้วยดิฟตัวบนและมีเครื่องหมายลบ
