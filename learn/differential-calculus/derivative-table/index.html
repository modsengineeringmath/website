    1. คู่หลักมีสองคู่ คือ sin กับ cos และ tan กับ sec ส่วน cot กับ csc เป็นคู่ “โค” ที่หน้าตาเหมือนคู่หลักทุกอย่าง แค่สลับเป็นตัวโค เลื่อนเฟส 90° (โคฟังก์ชัน)

    3. tan กับ sec จับคู่กัน (tan)′ = sec² และ (sec)′ = sec tan ส่วน cot กับ csc ก็จับคู่กันแบบเดียวกัน (cot)′ = −csc² และ (csc)′ = −csc cot

    • อนุพันธ์ของฟังก์ชันตรีโกณมิติ: พิสูจน์ทุกบรรทัดในกลุ่มตรีโกณ พร้อมแล็บดูความชันของกราฟ sin ที่กลายเป็น cos
    • โจทย์ดิฟพร้อมเฉลย 36 ข้อ: ฝึกใช้ตารางกับกฎลูกโซ่ ผลคูณ ผลหาร และดิฟโดยปริยาย
    • เครื่องคำนวณอนุพันธ์: พิมพ์ฟังก์ชันแล้วได้คำตอบพร้อมกฎที่ใช้ทีละพจน์
    • ตารางสูตรอินทิเกรต: อ่านกลับทิศ ดิฟสูตรไหนได้อะไร อินทิเกรตก็ได้กลับคืน

    คำถามที่พบบ่อย

    ดิฟ sin ได้อะไร?

    ดิฟ sin x ได้ cos x และดิฟ sin(ax) ได้ a cos(ax) ตามกฎลูกโซ่ ใช้ได้เมื่อ x เป็นเรเดียนเท่านั้น ถ้าวัดมุมเป็นองศาต้องคูณ π/180 เพิ่ม

    ดิฟ cos ได้อะไร?

    ดิฟ cos x ได้ −sin x เครื่องหมายลบมาจากการที่ cos ลดลงในช่วง 0 ถึง π ซึ่งเป็นช่วงที่ sin เป็นบวก

    ดิฟ tan ได้อะไร?

    ดิฟ tan x ได้ sec²x ซึ่งเท่ากับ 1 + tan²x ได้จากกฎผลหารของ sin x / cos x แล้วใช้ sin²x + cos²x = 1

    ดิฟ ln x ได้อะไร?

    ดิฟ ln x ได้ 1/x และดิฟ ln(u) ได้ u′/u ส่วน ln|x| ดิฟได้ 1/x เช่นกันแต่ใช้ได้ทั้ง x บวกและลบ

    ดิฟ e^x ได้อะไร?

    ดิฟ e^x ได้ e^x เหมือนเดิม ดิฟ e^{ax} ได้ a e^{ax} และดิฟ e^{u} ได้ e^{u} · u′

    สูตรดิฟผลคูณและผลหารคืออะไร?

    ผลคูณ (uv)′ = u′v + uv′ ส่วนผลหาร (u/v)′ = (u′v − uv′)/v² จำว่าผลหารขึ้นต้นด้วยดิฟตัวบนและมีเครื่องหมายลบ

ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม เครื่องคิดเลขลำดับและอนุกรม พร้อมวิธีทำ อุปนัยเชิงคณิตศาสตร์ อุปนัยแบบเข้ม (Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ แรงก์ (ค่าลำดับขั้น) ของเมทริกซ์ ผลเฉลยเชิงตัวเลข: LU จาโคบี เกาส์-ไซเดล แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ คราเมอร์ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์
