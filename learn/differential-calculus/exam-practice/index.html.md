# โจทย์ดิฟพร้อมเฉลย (Derivative Exam Practice): 36 ข้อ 3 ระดับ เฉลยทีละขั้นพร้อมป้ายบอกสูตร

// บทที่ 4.4 · อนุพันธ์ · Exam Practice


36 ข้อเรียงจากง่ายไปยาก ทุกข้อซ่อนเฉลยไว้ เปิดดูเมื่อลองทำเองแล้ว ในเฉลยมีป้ายเล็กสองสี สีส้มบอกกฎของแคลคูลัสที่ใช้ สีน้ำเงินบอกเอกลักษณ์ตรีโกณ ชี้ค้างเพื่อดูสูตร หรือกดเพื่อไปอ่านที่มา คำตอบทุกข้อผมให้โปรแกรมดิฟซ้ำแล้ว

## อ่านโจทย์แบบแยกชั้น

ก่อนดิฟ ให้ถามตัวเองว่า “ตัวนอกสุดคืออะไร” แค่คำถามเดียวนี้ก็ตัดสินได้ว่าจะใช้กฎไหนก่อน

| ตัวนอกสุดเป็น… | ใช้ | ตัวอย่าง |

| ผลบวก ผลต่าง ค่าคงที่คูณ | ดิฟทีละพจน์ ความเป็นเชิงเส้น | A1–A4 |

| ผลคูณของสองก้อน | กฎผลคูณ กฎผลคูณ | B1, B2, B11 |

| เศษส่วน | กฎผลหาร กฎผลหาร | B3, B4 |

| ฟังก์ชันที่มีก้อนอื่นอยู่ข้างใน | กฎลูกโซ่ กฎลูกโซ่ | A5–A8, B5–B9 |

| สมการที่แยก y ไม่ออก | ดิฟโดยปริยาย ดิฟโดยปริยาย | C1, C2 |

| ฐานกับเลขชี้กำลังมี x ทั้งคู่ | ดิฟลอการิทึม ดิฟลอการิทึม | C3 |

## ชุด A · พื้นฐาน ม.6 (12 ข้อ) พื้นฐาน

A1$\dfrac{d}{dx}\big(4x^3 - 5x^2 + 7x - 2\big)$
กฎยกกำลังทีละพจน์ ค่าคงที่ดิฟได้ศูนย์ กฎยกกำลัง ความเป็นเชิงเส้น
$12x^2 - 10x + 7$ · S3

A2$\dfrac{d}{dx}\Big(\sqrt{x} + \dfrac{3}{x^2}\Big)$
เขียนเป็นเลขยกกำลัง $x^{1/2} + 3x^{-2}$ แล้วใช้กฎยกกำลัง
$\dfrac{1}{2\sqrt x} - \dfrac{6}{x^3}$ · ราก · ส่วนกลับ

A3$\dfrac{d}{dx}\big(3e^x - 2\ln x\big)$
$(e^x)' = e^x$ และ $(\ln x)' = \tfrac1x$ ดิฟ eˣ ดิฟ ln
$3e^x - \dfrac{2}{x}$ · eˣ · ln

A4$\dfrac{d}{dx}\big(2\sin x - 5\cos x\big)$
$(\sin x)' = \cos x$, $(\cos x)' = -\sin x$ ลบคูณลบเป็นบวก วงกลมหนึ่งหน่วย
$2\cos x + 5\sin x$ · พิสูจน์

A5$\dfrac{d}{dx}(2x+1)^5$
ลูกโซ่: ชั้นนอกยกกำลังห้า ชั้นในดิฟได้ 2 กฎลูกโซ่
$10(2x+1)^4$ · กฎลูกโซ่

A6$\dfrac{d}{dx}e^{3x^2}$
$(e^u)' = e^u u'$ โดย $u = 3x^2$ กฎลูกโซ่
$6x\,e^{3x^2}$ · S10

A7$\dfrac{d}{dx}\sin 5x$
ข้างในคือ 5x ดิฟได้ 5 กฎลูกโซ่
$5\cos 5x$ · S23

A8$\dfrac{d}{dx}\ln(x^2+1)$
$(\ln u)' = u'/u$ ดิฟ ln
$\dfrac{2x}{x^2+1}$ · S12

A9ความชันของ $y = x^3 - 3x$ ที่ $x = 2$
$y' = 3x^2 - 3$ แทน $x = 2$
$9$ · นิยาม

A10สมการเส้นสัมผัส $y = \sqrt{x}$ ที่จุด $(4, 2)$
$y' = \tfrac{1}{2\sqrt x}$ ที่ $x = 4$ ได้ $\tfrac14$ แล้วใช้ $y - 2 = \tfrac14(x - 4)$
$y = \tfrac14x + 1$ · D2

A11$\dfrac{d}{dx}\tan x$ ที่ $x = \tfrac{\pi}{4}$
$(\tan x)' = \sec^2x = 1 + \tan^2x$ พีทาโกรัสแบบ tan ที่ π/4 มี tan = 1 มุมพิเศษ
$2$ · tan

A12$f(x) = x^4$ จงหา $f''(x)$ และ $f'''(x)$
ดิฟซ้ำ $4x^3 \to 12x^2 \to 24x$ อนุพันธ์อันดับสูง
$f'' = 12x^2,\ f''' = 24x$ · อันดับสูง

## ชุด B · ผลคูณ ผลหาร ลูกโซ่ และตรีโกณ (12 ข้อ) กลาง

B1$\dfrac{d}{dx}\big(x^2\sin x\big)$
ผลคูณ กฎผลคูณ
$2x\sin x + x^2\cos x$ · ผลคูณ

B2$\dfrac{d}{dx}\big(e^x\cos x\big)$
ผลคูณ กฎผลคูณ แล้วดึง $e^x$ ร่วม
$e^x(\cos x - \sin x) = \sqrt2\,e^x\cos\!\big(x + \tfrac{\pi}{4}\big)$ รวมเป็นคลื่นเดียว · ผลคูณ

B3$\dfrac{d}{dx}\dfrac{x^2+1}{x-1}$
ผลหาร $\dfrac{2x(x-1) - (x^2+1)}{(x-1)^2}$ กฎผลหาร
$\dfrac{x^2 - 2x - 1}{(x-1)^2}$ · ผลหาร

B4$\dfrac{d}{dx}\dfrac{\sin x}{1+\cos x}$
ผลหาร กฎผลหาร ตัวเศษ $\cos x(1+\cos x) + \sin^2x = \cos x + 1$ เอกลักษณ์พีทาโกรัส
$\dfrac{1}{1+\cos x}$ (เท่ากับ $\tfrac12\sec^2\tfrac x2$) มุมสองเท่า cos · sin² + cos²

B5$\dfrac{d}{dx}\sin^3 x$
ลูกโซ่ $3\sin^2x\cdot\cos x$ กฎลูกโซ่
$3\sin^2x\cos x$ · ตัวอย่าง

B6$\dfrac{d}{dx}\cos(x^2 + 1)$
ลูกโซ่ ข้างในดิฟได้ $2x$ กฎลูกโซ่
$-2x\sin(x^2+1)$ · S18

B7$\dfrac{d}{dx}\sqrt{1 + \sin^2 x}$
ลูกโซ่สองชั้น $\dfrac{1}{2\sqrt{1+\sin^2x}}\cdot2\sin x\cos x$ กฎลูกโซ่ แล้วย่อ มุมสองเท่า sin
$\dfrac{\sin x\cos x}{\sqrt{1+\sin^2x}} = \dfrac{\sin 2x}{2\sqrt{1+\sin^2x}}$ · S25

B8$\dfrac{d}{dx}\tan^2(3x)$
สามชั้น: ยกกำลังสอง → tan → 3x กฎลูกโซ่
$6\tan 3x\sec^2 3x$ · S28

B9$\dfrac{d}{dx}\sec(2x)$
$(\sec u)' = \sec u\tan u\cdot u'$ ส่วนกลับ กฎลูกโซ่
$2\sec 2x\tan 2x$ · S21

B10$\dfrac{d}{dx}\ln(\sin x)$
$\dfrac{\cos x}{\sin x}$ ดิฟ ln นิยาม tan = sin/cos
$\cot x$ · S20

B11$\dfrac{d}{dx}\dfrac{x^2\sin 3x}{e^x}$
เขียนเป็น $x^2\sin3x\cdot e^{-x}$ ผลคูณสามตัว: ดิฟทีละตัว ตัวอื่นอยู่เฉย ๆ แล้วบวก กฎผลคูณ กฎลูกโซ่
$e^{-x}\big(2x\sin3x + 3x^2\cos3x - x^2\sin3x\big)$ · สามกฎ

B12$\dfrac{d}{dx}\big(\sin^2x + \cos^2x\big)$ ทำสองวิธี
ดิฟตรง ๆ: $2\sin x\cos x - 2\cos x\sin x = 0$
หรือเห็นก่อนว่าผลบวกคือ 1 เอกลักษณ์พีทาโกรัส ดิฟค่าคงที่ได้ 0
$0$ · ข้อนี้ใช้ตรวจว่าจำเครื่องหมายของ (cos x)′ ถูก · พิสูจน์

## ชุด C · โดยปริยาย ลอการิทึม ผกผัน และงานจริง (12 ข้อ) ขั้นสูง

C1หา $\dfrac{dy}{dx}$ จาก $x^2 + y^2 = 25$ และความชันที่ $(3, 4)$
ดิฟโดยปริยาย $2x + 2y\,y' = 0$ ดิฟโดยปริยาย
$y' = -\dfrac xy$ ที่ (3, 4) ได้ $-\tfrac34$
$y' = -\dfrac{x}{y},\ \ -\dfrac34$ · เส้นสัมผัสวงกลมตั้งฉากกับรัศมี (ความชันรัศมี 4/3) · โดยปริยาย

C2หา $\dfrac{dy}{dx}$ จาก $\sin y = x\cos y$
ดิฟทั้งสองข้าง $\cos y\,y' = \cos y - x\sin y\,y'$ ดิฟโดยปริยาย
ย้าย $y'$ ไปข้างเดียว
$y' = \dfrac{\cos y}{\cos y + x\sin y}$ (หรือ $\dfrac{1}{1+x^2}$ เพราะ $\tan y = x$) พีทาโกรัสแบบ tan · arctan

C3$\dfrac{d}{dx}x^{\sin x}$ เมื่อ $x > 0$
ใส่ ln: $\ln y = \sin x\ln x$ ดิฟลอการิทึม
ดิฟ: $\dfrac{y'}{y} = \cos x\ln x + \dfrac{\sin x}{x}$
$x^{\sin x}\Big(\cos x\ln x + \dfrac{\sin x}{x}\Big)$ · S16

C4$\dfrac{d}{dx}\sin^{-1}\!\big(\sqrt{x}\big)$
$\dfrac{1}{\sqrt{1-x}}\cdot\dfrac{1}{2\sqrt x}$ ฟังก์ชันตรีโกณผกผัน กฎลูกโซ่
$\dfrac{1}{2\sqrt{x(1-x)}}$ · S31

C5$\dfrac{d}{dx}\tan^{-1}\!\Big(\dfrac{1+x}{1-x}\Big)$
ลูกโซ่ได้ $\dfrac{1}{1+u^2}\cdot\dfrac{2}{(1-x)^2}$ แล้วย่อ ตัวส่วน $(1-x)^2 + (1+x)^2 = 2(1+x^2)$
$\dfrac{1}{1+x^2}$ · เหตุผล: $\tan^{-1}\tfrac{1+x}{1-x} = \tfrac{\pi}{4} + \tan^{-1}x$ จากสูตรผลบวกมุมของ tan · S33

C6$\dfrac{d^{50}}{dx^{50}}\cos 2x$
ดิฟหนึ่งครั้งคูณ 2 และเลื่อนเฟส 90° เลื่อนเฟส 90° (โคฟังก์ชัน)
$\dfrac{d^n}{dx^n}\cos2x = 2^n\cos\!\big(2x + \tfrac{n\pi}{2}\big)$ ที่ n = 50 ได้เลื่อน 25π คาบ 2π
$-2^{50}\cos 2x$ · วงจรสี่จังหวะ

C7เส้นโค้งอิงพารามิเตอร์ $x = 3\cos\theta,\ y = 2\sin\theta$ หา $\dfrac{dy}{dx}$ ที่ $\theta = \tfrac{\pi}{4}$
$\dfrac{dy}{dx} = \dfrac{dy/d\theta}{dx/d\theta} = \dfrac{2\cos\theta}{-3\sin\theta}$
ที่ π/4 sin = cos มุมพิเศษ
$-\dfrac{2}{3}$ · นี่คือวงรี $\tfrac{x^2}{9}+\tfrac{y^2}{4} = 1$ เอกลักษณ์พีทาโกรัส · อิงพารามิเตอร์

C8$y = e^{-t}\sin t$ หาจุดที่ $y$ สูงสุดครั้งแรกเมื่อ $t > 0$
$y' = e^{-t}(\cos t - \sin t) = 0$ กฎผลคูณ
$\tan t = 1$ นิยาม tan = sin/cos ได้ $t = \tfrac{\pi}{4}$
$t = \tfrac{\pi}{4},\ y = \tfrac{\sqrt2}{2}e^{-\pi/4} \approx 0.322$ · ค่าสุดขีด

C9ตัวเก็บประจุ $C = 47\ \mu\text{F}$ แรงดัน $v = 10\sin(1000t)$ V จงหากระแส $i(t)$
$i = C\dfrac{dv}{dt} = 47\times10^{-6}\times10\times1000\cos1000t$ กฎลูกโซ่
เขียนเป็น sin เพื่อดูเฟส เลื่อนเฟส 90° (โคฟังก์ชัน)
$i = 0.47\cos(1000t) = 0.47\sin(1000t + 90^\circ)$ A กระแสนำหน้าแรงดัน 90° · ตัวเก็บประจุ

C10บันไดยาว 5 m พิงผนัง ปลายล่างไถลออกด้วยอัตรา 0.6 m/s ขณะปลายล่างห่างผนัง 3 m มุมระหว่างบันไดกับพื้นเปลี่ยนเร็วเท่าใด
$x = 5\cos\theta$ ดิฟเทียบเวลา $\dot x = -5\sin\theta\,\dot\theta$ กฎลูกโซ่
ที่ x = 3 ได้ $\cos\theta = \tfrac35,\ \sin\theta = \tfrac45$ เอกลักษณ์พีทาโกรัส สามเหลี่ยมอ้างอิง
$\dot\theta = -\dfrac{0.6}{5\cdot0.8} = -0.15$ rad/s (มุมลดลง) · อัตราสัมพัทธ์

C11ใช้ค่าประมาณเชิงเส้นหา $\sin 31^\circ$
ใช้ $a = 30^\circ = \tfrac{\pi}{6}$ และ $h = 1^\circ = \tfrac{\pi}{180}$ ต้องเป็นเรเดียน มุมเป็นเรเดียน
$\sin(a+h) \approx \sin a + \cos a\cdot h = \tfrac12 + \tfrac{\sqrt3}{2}\cdot\tfrac{\pi}{180}$ ประมาณเชิงเส้น มุมพิเศษ
$\approx 0.51511$ (ค่าจริง 0.51504) · ประมาณเชิงเส้น

C12แสดงว่า $y = A\cos\omega t + B\sin\omega t$ สอดคล้องกับ $y'' + \omega^2y = 0$
$y' = -A\omega\sin\omega t + B\omega\cos\omega t$
$y'' = -\omega^2(A\cos\omega t + B\sin\omega t) = -\omega^2y$ อนุพันธ์อันดับสูง
$y'' + \omega^2y = 0$ จริง ทุก A, B · นี่คือคำตอบทั่วไปของการสั่นแบบไม่หน่วง ต่อที่สมการอันดับสอง · ดิฟสองครั้ง

## ฝึกต่อ

- อนุพันธ์ตรีโกณ ถ้าชุด B ข้อตรีโกณยังไม่คล่อง

- การประยุกต์อนุพันธ์ โจทย์แบบ C9–C10 ในงานไฟฟ้า เครื่องกล โยธา

- เครื่องคำนวณอนุพันธ์ ตรวจคำตอบโจทย์ที่แต่งเอง

## คำถามที่พบบ่อย

ควรเริ่มฝึกโจทย์ดิฟจากตรงไหน?
เริ่มชุด A ให้ทำได้คล่องโดยไม่เปิดตารางก่อน จากนั้นชุด B ซึ่งเป็นแกนของข้อสอบแคลคูลัส 1 เกือบทุกที่ คือผลคูณ ผลหาร และลูกโซ่ที่ซ้อนกันหลายชั้น ชุด C เหมาะกับคนที่เตรียมสอบไฟนอลหรือเรียนวิศวกรรม

ดิฟโจทย์ซับซ้อนให้ไม่พลาดทำอย่างไร?
แยกโจทย์เป็นชั้นก่อนลงมือ ถามว่าตัวนอกสุดคืออะไร ผลคูณ ผลหาร หรือฟังก์ชันประกอบ แล้วจัดการทีละชั้น อย่าทำหลายกฎในบรรทัดเดียว และเมื่อเจอตรีโกณยกกำลัง ให้เขียนวงเล็บให้ชัด เช่น (sin x)³

ตรวจคำตอบดิฟเองได้อย่างไร?
แทนค่า x สักค่า เช่น 0.5 ลงในคำตอบ แล้วเทียบกับความชันประมาณ [f(0.501) − f(0.499)]/0.002 ถ้าใกล้กันมากก็ถูก หรือใช้เครื่องคำนวณอนุพันธ์บนเว็บนี้ ซึ่งตรวจเชิงตัวเลขให้ทุกครั้ง

## คำถามที่พบบ่อย (FAQ)

**ควรเริ่มฝึกโจทย์ดิฟจากตรงไหน?**
เริ่มชุด A ให้ทำได้คล่องโดยไม่เปิดตารางก่อน จากนั้นชุด B ซึ่งเป็นแกนของข้อสอบแคลคูลัส 1 เกือบทุกที่ คือผลคูณ ผลหาร และลูกโซ่ที่ซ้อนกันหลายชั้น ชุด C เหมาะกับคนที่เตรียมสอบไฟนอลหรือเรียนวิศวกรรม

**ดิฟโจทย์ซับซ้อนให้ไม่พลาดทำอย่างไร?**
แยกโจทย์เป็นชั้นก่อนลงมือ ถามว่าตัวนอกสุดคืออะไร ผลคูณ ผลหาร หรือฟังก์ชันประกอบ แล้วจัดการทีละชั้น อย่าทำหลายกฎในบรรทัดเดียว และเมื่อเจอตรีโกณยกกำลัง ให้เขียนวงเล็บให้ชัด เช่น (sin x)³

**ตรวจคำตอบดิฟเองได้อย่างไร?**
แทนค่า x สักค่า เช่น 0.5 ลงในคำตอบ แล้วเทียบกับความชันประมาณ [f(0.501) − f(0.499)]/0.002 ถ้าใกล้กันมากก็ถูก หรือใช้เครื่องคำนวณอนุพันธ์บนเว็บนี้ ซึ่งตรวจเชิงตัวเลขให้ทุกครั้ง
