เป้าหมายการออกแบบ 5 ข้อ พื้นฐาน

  1. เสถียรภาพ (stability): ต้องมาก่อนทุกอย่าง → เสถียรภาพ, เราท์
  2. สมรรถนะชั่วครู่ (transient): เร็ว ไม่พุ่งเกิน ไม่แกว่งนาน → ผลตอบสนองเวลา
  3. ความแม่นยำสถานะอยู่ตัว (steady-state accuracy) → ความผิดพลาดอยู่ตัว
  4. ต้านการรบกวนและสัญญาณรบกวน (disturbance/noise rejection) → SSS และ TTT
  5. ความทนทาน (robustness): ยังดีเมื่อพลานต์จริงไม่ตรงแบบจำลอง → มาร์จิน, ทนทาน

บวกข้อจำกัดในโลกจริง: ตัวขับมีขีดจำกัด (PWM เต็ม 100% ไม่ได้มากกว่านั้น) เซนเซอร์มีสัญญาณรบกวนและหน่วงเวลา และตัวควบคุมดิจิทัลทำงานเป็นคาบ

  • อิเล็กทรอนิกส์: ออปแอมป์ป้อนกลับ ไอซีเรกูเลเตอร์ LDO วงจร PLL สังเคราะห์ความถี่ AGC ในวิทยุ

ระบบวงเปิดกับวงปิดต่างกันอย่างไร?

วงเปิดสั่งตัวขับตามค่าที่ตั้งไว้โดยไม่วัดผลลัพธ์ เช่น เครื่องปิ้งขนมปังตั้งเวลา ถ้ามีอะไรเปลี่ยนก็ไม่รู้ตัว วงปิดวัดเอาต์พุตแล้วนำมาเทียบกับค่าอ้างอิงตลอดเวลา เช่น เครื่องปรับอากาศที่วัดอุณหภูมิห้อง จึงแก้ไขผลของการรบกวนและการเปลี่ยนแปลงของระบบได้เอง

ทำไมเรียกว่าป้อนกลับเชิงลบ (negative feedback)?

เพราะสัญญาณที่วัดได้ถูกนำไปลบออกจากค่าอ้างอิง ถ้าเอาต์พุตสูงเกิน ความผิดพลาดเป็นลบ ตัวควบคุมจะลดสัญญาณควบคุม ระบบจึงถูกดึงกลับเข้าหาเป้าหมาย ถ้าเป็นป้อนกลับเชิงบวก เอาต์พุตที่สูงจะยิ่งถูกผลักให้สูงขึ้น ใช้ในวงจรออสซิลเลเตอร์และวงจรชมิตต์ทริกเกอร์

การป้อนกลับมีข้อเสียไหม?

มี การป้อนกลับอาจทำให้ระบบที่เสถียรกลายเป็นไม่เสถียรได้ถ้าเกนสูงเกินหรือมีหน่วงเวลามาก ต้องใช้เซนเซอร์ซึ่งเพิ่มต้นทุนและนำสัญญาณรบกวนเข้ามาในลูป และลดเกนรวมของระบบ วิชาระบบควบคุมจึงเน้นการออกแบบให้ได้ประโยชน์ของการป้อนกลับโดยยังเสถียรและทนทาน

ระบบควบคุมเกี่ยวกับวิศวกรรมไฟฟ้าอย่างไร?

เกือบทุกวงจรที่ทำงานได้แม่นยำใช้การป้อนกลับ ออปแอมป์ที่ต่อเป็นแอมป์เกนคงที่ ไอซีเรกูเลเตอร์ สวิตชิงพาวเวอร์ซัพพลาย PLL ในวิทยุ ไดรฟ์มอเตอร์ อินเวอร์เตอร์โซลาร์ และการควบคุมความถี่ของระบบไฟฟ้ากำลัง ล้วนเป็นระบบควบคุมป้อนกลับ

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ สูตรและตารางตรีโกณมิติ สูตรอินทิเกรตและวิธีทำ พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ เครื่องคิดเลขเมทริกซ์แสดงวิธีทำ แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
