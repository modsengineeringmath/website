    เป้าหมายการออกแบบ 5 ข้อ พื้นฐาน

    1. เสถียรภาพ (stability): ต้องมาก่อนทุกอย่าง → เสถียรภาพ, เราท์
    2. สมรรถนะชั่วครู่ (transient): เร็ว ไม่พุ่งเกิน ไม่แกว่งนาน → ผลตอบสนองเวลา
    3. ความแม่นยำสถานะอยู่ตัว (steady-state accuracy) → ความผิดพลาดอยู่ตัว
    4. ต้านการรบกวนและสัญญาณรบกวน (disturbance/noise rejection) → SSS และ TTT
    5. ความทนทาน (robustness): ยังดีเมื่อพลานต์จริงไม่ตรงแบบจำลอง → มาร์จิน, ทนทาน

    บวกข้อจำกัดในโลกจริง: ตัวขับมีขีดจำกัด (PWM เต็ม 100% ไม่ได้มากกว่านั้น) เซนเซอร์มีสัญญาณรบกวนและหน่วงเวลา และตัวควบคุมดิจิทัลทำงานเป็นคาบ

    ประวัติย่อ: จากเครื่องจักรไอน้ำถึงจรวด

    ระบบควบคุมอยู่ทุกที่ (โดยเฉพาะในวงจรไฟฟ้า)

    • อิเล็กทรอนิกส์: ออปแอมป์ป้อนกลับ ไอซีเรกูเลเตอร์ LDO วงจร PLL สังเคราะห์ความถี่ AGC ในวิทยุ
    • อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ คอนเวอร์เตอร์ ที่ชาร์จแบตเตอรี่ CC–CV อินเวอร์เตอร์โซลาร์ PFC → สะพานสู่อิเล็กทรอนิกส์กำลัง
    • เมคาทรอนิกส์: เซอร์โว CNC เครื่องพิมพ์ 3 มิติ กิมบอลกล้อง ระบบเบรก ABS → เมคาทรอนิกส์

    • ระบบไฟฟ้ากำลัง: AVR ของเครื่องกำเนิด governor ควบคุมความถี่ 50 Hz ของทั้งประเทศ

    คำถามที่พบบ่อย

    ระบบวงเปิดกับวงปิดต่างกันอย่างไร?

    วงเปิดสั่งตัวขับตามค่าที่ตั้งไว้โดยไม่วัดผลลัพธ์ เช่น เครื่องปิ้งขนมปังตั้งเวลา ถ้ามีอะไรเปลี่ยนก็ไม่รู้ตัว วงปิดวัดเอาต์พุตแล้วนำมาเทียบกับค่าอ้างอิงตลอดเวลา เช่น เครื่องปรับอากาศที่วัดอุณหภูมิห้อง จึงแก้ไขผลของการรบกวนและการเปลี่ยนแปลงของระบบได้เอง

    ทำไมเรียกว่าป้อนกลับเชิงลบ (negative feedback)?

    เพราะสัญญาณที่วัดได้ถูกนำไปลบออกจากค่าอ้างอิง ถ้าเอาต์พุตสูงเกิน ความผิดพลาดเป็นลบ ตัวควบคุมจะลดสัญญาณควบคุม ระบบจึงถูกดึงกลับเข้าหาเป้าหมาย ถ้าเป็นป้อนกลับเชิงบวก เอาต์พุตที่สูงจะยิ่งถูกผลักให้สูงขึ้น ใช้ในวงจรออสซิลเลเตอร์และวงจรชมิตต์ทริกเกอร์

    การป้อนกลับมีข้อเสียไหม?

    มี การป้อนกลับอาจทำให้ระบบที่เสถียรกลายเป็นไม่เสถียรได้ถ้าเกนสูงเกินหรือมีหน่วงเวลามาก ต้องใช้เซนเซอร์ซึ่งเพิ่มต้นทุนและนำสัญญาณรบกวนเข้ามาในลูป และลดเกนรวมของระบบ วิชาระบบควบคุมจึงเน้นการออกแบบให้ได้ประโยชน์ของการป้อนกลับโดยยังเสถียรและทนทาน

    ระบบควบคุมเกี่ยวกับวิศวกรรมไฟฟ้าอย่างไร?

    เกือบทุกวงจรที่ทำงานได้แม่นยำใช้การป้อนกลับ ออปแอมป์ที่ต่อเป็นแอมป์เกนคงที่ ไอซีเรกูเลเตอร์ สวิตชิงพาวเวอร์ซัพพลาย PLL ในวิทยุ ไดรฟ์มอเตอร์ อินเวอร์เตอร์โซลาร์ และการควบคุมความถี่ของระบบไฟฟ้ากำลัง ล้วนเป็นระบบควบคุมป้อนกลับ

    เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม · อุปนัย อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
