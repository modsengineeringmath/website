# ระบบควบคุมคืออะไร: วงเปิด วงปิด และการป้อนกลับ

// บทที่ 13.1 · ระบบควบคุม · Introduction to Feedback Control


ลองเดินในห้องมืดไปหยิบแก้วน้ำ คุณมองตำแหน่งมือ เทียบกับตำแหน่งแก้ว แล้วขยับแก้ไขจนถึง นั่นคือระบบควบคุมป้อนกลับในร่างกายเรา วิศวกรรมระบบควบคุมคือการทำสิ่งเดียวกันนี้ด้วยเซนเซอร์ วงจร และซอฟต์แวร์ ให้เครื่องจักรทำงานได้ตามเป้าหมายโดยอัตโนมัติ แม่นยำ และไม่สนว่าโลกภายนอกจะรบกวนแค่ไหน หน้านี้วางภาษาและแนวคิดพื้นฐานของทั้งชุด สูตรใช้รหัส F

สรุปใน 30 วินาที

- วงเปิด: สั่งแล้วหวังว่าจะได้ · วงปิด: วัด เทียบ แก้ ซ้ำไปเรื่อย ๆ

- $T(s) = \dfrac{CG}{1 + CGH}$ · ตัวหารเดียวกัน $1 + L(s)$ อยู่ในทุกฟังก์ชันของลูป

- ลูปเกนสูง → การรบกวนและการเปลี่ยนแปลงของพลานต์ถูกลดลง $|1 + L|$ เท่า

- ราคาที่ต้องจ่าย: อาจไม่เสถียร ต้องมีเซนเซอร์ที่แม่น และสัญญาณรบกวนจากเซนเซอร์เข้าลูปได้

## วงเปิดกับวงปิด พื้นฐาน

| | วงเปิด (open loop) | วงปิด (closed loop, feedback) |

| หลักการ | คำนวณสัญญาณสั่งจากค่าที่ต้องการล่วงหน้า | วัดเอาต์พุตจริง เทียบกับค่าอ้างอิง แก้ตามความผิดพลาด |

| ตัวอย่าง | ไมโครเวฟตั้งเวลา สเต็ปเปอร์มอเตอร์ไม่มีเอนโค้ดเดอร์ ไฟจราจรตั้งเวลา | แอร์อินเวอร์เตอร์ ครูสคอนโทรล เซอร์โวมอเตอร์ เรกูเลเตอร์แรงดัน |

| เมื่อมีการรบกวน | ไม่รู้ตัว ผลลัพธ์คลาด | รู้และแก้เอง |

| เมื่อพลานต์เปลี่ยน (ร้อน เสื่อม โหลดเปลี่ยน) | ผลลัพธ์เปลี่ยนตาม | แทบไม่เปลี่ยน |

| เสถียรภาพ | เสถียรถ้าพลานต์เสถียร | อาจไม่เสถียรถ้าออกแบบไม่ดี |

| ต้นทุน | ต่ำ ไม่ต้องมีเซนเซอร์ | สูงกว่า ต้องมีเซนเซอร์และการออกแบบ |

ระบบจริงมักใช้ทั้งสองอย่างร่วมกัน: feedforward (วงเปิด) สั่งส่วนใหญ่ที่คำนวณได้ล่วงหน้าให้เร็ว และ feedback (วงปิด) เก็บงานส่วนที่เหลือให้แม่น เช่น เครื่องพิมพ์ 3 มิติและแขนกลอุตสาหกรรม

## กายวิภาคของลูปป้อนกลับ พื้นฐาน

บล็อกไดอะแกรมมาตรฐานที่ใช้ตลอดชุดบทเรียนนี้

| สัญลักษณ์ | ชื่อ | ตัวอย่าง (ไดรฟ์มอเตอร์ควบคุมความเร็ว) |

| $r$ | ค่าอ้างอิง (reference, setpoint) | ความเร็วที่ต้องการ 1500 rpm |

| $e = r - y_m$ | ความผิดพลาด (error) | ต่างจากที่วัดได้กี่ rpm |

| $C(s)$ | ตัวควบคุม (controller, compensator) | PI ในไมโครคอนโทรลเลอร์ |

| $u$ | สัญญาณควบคุม (control signal) | duty cycle ของ PWM |

| $G(s)$ | พลานต์ (plant, process) รวมตัวขับ | H-bridge + มอเตอร์ + โหลด |

| $d$ | การรบกวน (disturbance) | แรงบิดโหลดที่เปลี่ยน แรงดันแบตเตอรี่ตก |

| $H(s)$ | เซนเซอร์ (sensor, transducer) | เอนโค้ดเดอร์ + การนับพัลส์ |

| $y$ | เอาต์พุต (controlled variable) | ความเร็วจริงของเพลา |

## สมการของลูป: ทุกอย่างหารด้วย 1 + L พื้นฐาน

จากบล็อกไดอะแกรม (ให้ $H = 1$ เพื่อความง่าย) $Y = G(CE + D)$ และ $E = R - Y$ แก้สมการได้ (ทบทวนเทคนิคในบล็อกไดอะแกรม)

F1 Closed-loop transfer function ฟังก์ชันถ่ายโอนวงปิด

$$\frac{Y(s)}{R(s)} = \frac{C(s)G(s)}{1 + C(s)G(s)H(s)} = \frac{\text{เส้นทางไปข้างหน้า}}{1 + \text{ลูปเกน } L(s)}, \qquad L(s) = C(s)G(s)H(s)$$

ขั้ววงปิดคือรากของ $1 + L(s) = 0$ ซึ่งเป็นจุดตั้งต้นของเราท์ รูทโลคัส และไนควิสต์ · ป้อนกลับบวก: เปลี่ยน + เป็น −

F2 Sensitivity functions ฟังก์ชันความไวและความไวเติมเต็ม ($H = 1$)

$$S = \frac{1}{1 + L}, \qquad T = \frac{L}{1 + L}, \qquad S + T = 1, \qquad Y = TR + SGD - TN, \qquad E = SR - SGD + TN$$

$N$ = สัญญาณรบกวนของเซนเซอร์ · ต้องการ $S$ เล็ก (ติดตามดี ต้านการรบกวนดี) แต่ $T$ เล็กจึงจะไม่ส่งสัญญาณรบกวนเซนเซอร์ออก ซึ่งขัดกันเพราะ $S + T = 1$ ทางออก: $|L|$ ใหญ่ที่ความถี่ต่ำ $|L|$ เล็กที่ความถี่สูง (ภาษาของโบด)

F3 Sensitivity to plant variation ความไวต่อการเปลี่ยนแปลงของพลานต์

$$S_G^T = \frac{\partial T/T}{\partial G/G} = \frac{1}{1 + L} = S$$

พลานต์เปลี่ยน 10% วงปิดเปลี่ยนแค่ $10\%/|1 + L|$ · นี่คือเหตุที่ Harold Black (1927) คิดแอมป์ป้อนกลับเชิงลบ: ใช้หลอดสุญญากาศที่เกนไม่คงที่ สร้างแอมป์ที่เกนคงที่ด้วยตัวต้านทาน

ตัวอย่าง F-1 · แอมป์ป้อนกลับของ Black

### แอมป์มีเกนวงเปิด $A = 10^5$ แต่เปลี่ยนได้ ±20% ตามอุณหภูมิ ป้อนกลับด้วยตัวแบ่งแรงดัน $\beta = 0.01$ เกนวงปิดเป็นเท่าไรและเปลี่ยนกี่เปอร์เซ็นต์

- F1: $A_{CL} = \dfrac{A}{1 + A\beta} = \dfrac{10^5}{1 + 1000} = 99.90 \approx \dfrac{1}{\beta}$

- F3: ความไว $= \dfrac{1}{1 + A\beta} = \dfrac{1}{1001}$ ได้การเปลี่ยน $20\% / 1001 = 0.02\%$

- ตรวจ: $A = 0.8 \times 10^5$ ได้ $A_{CL} = 99.875$ เปลี่ยน 0.025% ✓

เกนวงปิด ≈ 100 (= $1/\beta$ กำหนดด้วยตัวต้านทานล้วน) และเปลี่ยนเพียงราว 0.02% แลกกับเกนที่ลดลงพันเท่า หลักการเดียวกับที่ออปแอมป์ทุกตัวใช้ (ดูแล็บออปแอมป์)

ตัวอย่าง F-2 · ต้านการรบกวนของมอเตอร์

### มอเตอร์ $G(s) = \dfrac{2}{0.5s + 1}$ (rad/s ต่อ V) เมื่อมีโหลดเพิ่ม ความเร็วตก 20 rad/s ในแบบวงเปิด ถ้าใช้ตัวควบคุม P $K = 10$ จะตกเท่าไร และตอบสนองเร็วขึ้นเท่าไร

- ลูปเกนที่ DC: $L(0) = KG(0) = 10 \times 2 = 20$

- ผลของการรบกวนถูกคูณด้วย $S(0) = \dfrac{1}{1 + 20} = \dfrac{1}{21}$ F2 ได้ $20/21 = 0.95$ rad/s

- วงปิด: $T(s) = \dfrac{20}{0.5s + 21} = \dfrac{20/21}{(0.5/21)s + 1}$ ค่าคงเวลาจาก 0.5 s เหลือ $0.024$ s

ความเร็วตกแค่ 0.95 rad/s (ลดลง 21 เท่า) และตอบสนองเร็วขึ้น 21 เท่า แต่เอาต์พุตไปได้แค่ $20/21$ ของค่าอ้างอิง (ผิดพลาด 4.8%) ซึ่งแก้ได้ด้วยเทอม I ในPI

## เป้าหมายการออกแบบ 5 ข้อ พื้นฐาน

- เสถียรภาพ (stability): ต้องมาก่อนทุกอย่าง → เสถียรภาพ, เราท์

- สมรรถนะชั่วครู่ (transient): เร็ว ไม่พุ่งเกิน ไม่แกว่งนาน → ผลตอบสนองเวลา

- ความแม่นยำสถานะอยู่ตัว (steady-state accuracy) → ความผิดพลาดอยู่ตัว

- ต้านการรบกวนและสัญญาณรบกวน (disturbance/noise rejection) → $S$ และ $T$

- ความทนทาน (robustness): ยังดีเมื่อพลานต์จริงไม่ตรงแบบจำลอง → มาร์จิน, ทนทาน

บวกข้อจำกัดในโลกจริง: ตัวขับมีขีดจำกัด (PWM เต็ม 100% ไม่ได้มากกว่านั้น) เซนเซอร์มีสัญญาณรบกวนและหน่วงเวลา และตัวควบคุมดิจิทัลทำงานเป็นคาบ

## ระบบควบคุมอยู่ทุกที่ (โดยเฉพาะในวงจรไฟฟ้า)

- อิเล็กทรอนิกส์: ออปแอมป์ป้อนกลับ ไอซีเรกูเลเตอร์ LDO วงจร PLL สังเคราะห์ความถี่ AGC ในวิทยุ

- อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ คอนเวอร์เตอร์ ที่ชาร์จแบตเตอรี่ CC–CV อินเวอร์เตอร์โซลาร์ PFC → สะพานสู่อิเล็กทรอนิกส์กำลัง

- เมคาทรอนิกส์: เซอร์โว CNC เครื่องพิมพ์ 3 มิติ กิมบอลกล้อง ระบบเบรก ABS → เมคาทรอนิกส์

- หุ่นยนต์: แขนกล หุ่นยนต์ทรงตัว โดรน AGV → โรโบติกส์

- ระบบไฟฟ้ากำลัง: AVR ของเครื่องกำเนิด governor ควบคุมความถี่ 50 Hz ของทั้งประเทศ

รายการเต็มกว่า 60 ระบบพร้อมเซนเซอร์และตัวขับอยู่ในคลังไอเดีย

## ต่อยอดไปหน้าถัดไป

ก่อนควบคุมอะไรได้ ต้องเขียนพลานต์เป็นสมการก่อน ไปต่อที่แบบจำลองทางคณิตศาสตร์ ซึ่งเริ่มจากวงจร RLC ที่คุ้นเคยแล้วขยายไปมอเตอร์และกลไก

## คำถามที่พบบ่อย

ระบบวงเปิดกับวงปิดต่างกันอย่างไร?
วงเปิดสั่งตัวขับตามค่าที่ตั้งไว้โดยไม่วัดผลลัพธ์ เช่น เครื่องปิ้งขนมปังตั้งเวลา ถ้ามีอะไรเปลี่ยนก็ไม่รู้ตัว วงปิดวัดเอาต์พุตแล้วนำมาเทียบกับค่าอ้างอิงตลอดเวลา เช่น เครื่องปรับอากาศที่วัดอุณหภูมิห้อง จึงแก้ไขผลของการรบกวนและการเปลี่ยนแปลงของระบบได้เอง

ทำไมเรียกว่าป้อนกลับเชิงลบ (negative feedback)?
เพราะสัญญาณที่วัดได้ถูกนำไปลบออกจากค่าอ้างอิง ถ้าเอาต์พุตสูงเกิน ความผิดพลาดเป็นลบ ตัวควบคุมจะลดสัญญาณควบคุม ระบบจึงถูกดึงกลับเข้าหาเป้าหมาย ถ้าเป็นป้อนกลับเชิงบวก เอาต์พุตที่สูงจะยิ่งถูกผลักให้สูงขึ้น ใช้ในวงจรออสซิลเลเตอร์และวงจรชมิตต์ทริกเกอร์

การป้อนกลับมีข้อเสียไหม?
มี การป้อนกลับอาจทำให้ระบบที่เสถียรกลายเป็นไม่เสถียรได้ถ้าเกนสูงเกินหรือมีหน่วงเวลามาก ต้องใช้เซนเซอร์ซึ่งเพิ่มต้นทุนและนำสัญญาณรบกวนเข้ามาในลูป และลดเกนรวมของระบบ วิชาระบบควบคุมจึงเน้นการออกแบบให้ได้ประโยชน์ของการป้อนกลับโดยยังเสถียรและทนทาน

ระบบควบคุมเกี่ยวกับวิศวกรรมไฟฟ้าอย่างไร?
เกือบทุกวงจรที่ทำงานได้แม่นยำใช้การป้อนกลับ ออปแอมป์ที่ต่อเป็นแอมป์เกนคงที่ ไอซีเรกูเลเตอร์ สวิตชิงพาวเวอร์ซัพพลาย PLL ในวิทยุ ไดรฟ์มอเตอร์ อินเวอร์เตอร์โซลาร์ และการควบคุมความถี่ของระบบไฟฟ้ากำลัง ล้วนเป็นระบบควบคุมป้อนกลับ

## คำถามที่พบบ่อย (FAQ)

**ระบบวงเปิดกับวงปิดต่างกันอย่างไร?**
วงเปิดสั่งตัวขับตามค่าที่ตั้งไว้โดยไม่วัดผลลัพธ์ เช่น เครื่องปิ้งขนมปังตั้งเวลา ถ้ามีอะไรเปลี่ยนก็ไม่รู้ตัว วงปิดวัดเอาต์พุตแล้วนำมาเทียบกับค่าอ้างอิงตลอดเวลา เช่น เครื่องปรับอากาศที่วัดอุณหภูมิห้อง จึงแก้ไขผลของการรบกวนและการเปลี่ยนแปลงของระบบได้เอง

**ทำไมเรียกว่าป้อนกลับเชิงลบ (negative feedback)?**
เพราะสัญญาณที่วัดได้ถูกนำไปลบออกจากค่าอ้างอิง ถ้าเอาต์พุตสูงเกิน ความผิดพลาดเป็นลบ ตัวควบคุมจะลดสัญญาณควบคุม ระบบจึงถูกดึงกลับเข้าหาเป้าหมาย ถ้าเป็นป้อนกลับเชิงบวก เอาต์พุตที่สูงจะยิ่งถูกผลักให้สูงขึ้น ใช้ในวงจรออสซิลเลเตอร์และวงจรชมิตต์ทริกเกอร์

**การป้อนกลับมีข้อเสียไหม?**
มี การป้อนกลับอาจทำให้ระบบที่เสถียรกลายเป็นไม่เสถียรได้ถ้าเกนสูงเกินหรือมีหน่วงเวลามาก ต้องใช้เซนเซอร์ซึ่งเพิ่มต้นทุนและนำสัญญาณรบกวนเข้ามาในลูป และลดเกนรวมของระบบ วิชาระบบควบคุมจึงเน้นการออกแบบให้ได้ประโยชน์ของการป้อนกลับโดยยังเสถียรและทนทาน

**ระบบควบคุมเกี่ยวกับวิศวกรรมไฟฟ้าอย่างไร?**
เกือบทุกวงจรที่ทำงานได้แม่นยำใช้การป้อนกลับ ออปแอมป์ที่ต่อเป็นแอมป์เกนคงที่ ไอซีเรกูเลเตอร์ สวิตชิงพาวเวอร์ซัพพลาย PLL ในวิทยุ ไดรฟ์มอเตอร์ อินเวอร์เตอร์โซลาร์ และการควบคุมความถี่ของระบบไฟฟ้ากำลัง ล้วนเป็นระบบควบคุมป้อนกลับ
