# คลังไอเดียระบบควบคุม 70 ระบบ: ตั้งแต่ชักโครกถึงจรวด

// บทที่ 13.26 · ระบบควบคุม · Control Systems Examples Gallery


เมื่อเข้าใจลูปป้อนกลับหนึ่งลูป คุณจะเริ่มเห็นมันทุกที่ ตารางนี้รวบรวมระบบควบคุมจริง 70 ระบบ ตั้งแต่วงจรในห้องแล็บไฟฟ้า พาวเวอร์ซัพพลาย มอเตอร์ หุ่นยนต์ ไปจนถึงรถยนต์ เครื่องบิน และร่างกายมนุษย์ ทุกแถวตอบสี่คำถามเดียวกัน: ควบคุมอะไร วัดด้วยอะไร ขับด้วยอะไร และใช้ตัวควบคุมแบบไหน พร้อมลิงก์ไปบทเรียนที่เกี่ยวข้อง ใช้เป็นไอเดียโปรเจกต์ ตัวอย่างสอน หรือโจทย์ฝึกวาดบล็อกไดอะแกรมก็ได้

## วิธีใช้ตารางนี้

- ฝึกวาดบล็อกไดอะแกรม: เลือกหนึ่งแถว วาดลูปแบบลูปมาตรฐาน ระบุ r, e, C, u, G, d, H, y ให้ครบ

- ฝึกสร้างแบบจำลอง: เขียนฟังก์ชันถ่ายโอนของพลานต์อย่างง่าย (แบบจำลอง) แล้วลองปิดวงในแล็บ

- เลือกโปรเจกต์: ระบบที่มีคำว่า PI/PID เหมาะเริ่มต้น · lead, LQR, ไม่เสถียรวงเปิด เหมาะโปรเจกต์ปีสุดท้ายหรือบัณฑิตศึกษา

- สอน: ใช้ระบบใกล้ตัว (แอร์ ครูสคอนโทรล หัวแร้ง) เปิดชั่วโมงแรกของวิชา

| หัวแร้งบัดกรีควบคุมอุณหภูมิ | อุณหภูมิปลาย | เทอร์โมคัปเปิล | ฮีตเตอร์ PWM | PID + anti-windup | จูน PID |

## คำถามที่พบบ่อย

จะเลือกโปรเจกต์ระบบควบคุมสำหรับนักศึกษาอย่างไร?
เริ่มจากระบบที่มีพลานต์อันดับหนึ่งและวัดง่าย เช่น ความเร็วมอเตอร์ อุณหภูมิ หรือระดับน้ำ ฝึก PI และการจูนให้คล่อง จากนั้นขยับไปยังระบบอันดับสองหรือไม่เสถียรวงเปิด เช่น ball-and-beam ลอยแม่เหล็ก หรือหุ่นยนต์ทรงตัว ซึ่งต้องใช้ lead หรือป้อนกลับสถานะ

ทำไมเกือบทุกระบบใช้ PI หรือ PID?
เพราะ PID ต้องการแบบจำลองน้อย จูนได้จากการทดลอง เข้าใจง่ายสำหรับช่างเทคนิค และพอสำหรับพลานต์อันดับต่ำส่วนใหญ่ ระบบที่ต้องการมากกว่านั้น เช่น หลายตัวแปรผูกกัน ไม่เสถียรวงเปิด หรือมีข้อจำกัดเข้มงวด จึงใช้ป้อนกลับสถานะ LQR หรือ MPC
