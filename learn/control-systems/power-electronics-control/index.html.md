# ควบคุมตัวแปลงกำลัง: จากบั๊กคอนเวอร์เตอร์ถึงตัวชดเชย Type II/III

// บทที่ 13.25 · ระบบควบคุม · Control of Power Converters


สวิตชิงพาวเวอร์ซัพพลายทุกตัวคือระบบควบคุมป้อนกลับที่ทำงานเร็วระดับหมื่นเฮิรตซ์: บั๊กคอนเวอร์เตอร์คือพลานต์ (มี LC ฟิลเตอร์เป็นระบบอันดับสอง) โมดูเลเตอร์ PWM คือแอคชูเอเตอร์ ตัวแบ่งแรงดันคือเซนเซอร์ และวงจรออปแอมป์ Type III คือตัวชดเชย lead + อินทิเกรเตอร์ หน้านี้ใช้ทุกอย่างในชุดบทเรียน ทั้งแบบจำลอง โบด มาร์จิน และวงจรออปแอมป์ ออกแบบลูปของบั๊ก 12 V → 5 V จนได้ค่าอุปกรณ์จริง เป็นสะพานสู่หมวดอิเล็กทรอนิกส์กำลังที่จะตามมา สูตรใช้รหัส H

สรุปใน 30 วินาที

- บั๊ก: $G_{vd}(s) \approx V_{in}\dfrac{1 + s/\omega_{esr}}{1 + \frac{s}{Q\omega_0} + \frac{s^2}{\omega_0^2}}$, $\omega_0 = 1/\sqrt{LC}$

- ลูปเกน $T = G_c \cdot \frac{1}{V_{pp}} \cdot G_{vd}$ · ครอสโอเวอร์ $f_c \le f_{sw}/10$ · PM 45°–70°

- Type III: อินทิเกรเตอร์ + ศูนย์คู่ที่ $f_0$ + ขั้วที่ $f_{esr}$ และ $f_{sw}/2$

- บูสต์มี RHP zero $f_{RHPZ} = \frac{R(1-D)^2}{2\pi L}$: ครอสโอเวอร์ต้องต่ำกว่าราว 1/3 ของมัน

## พลานต์: แบบจำลองสัญญาณเล็กของบั๊กคอนเวอร์เตอร์ กลาง

สวิตช์เปิดปิดหลายแสนครั้งต่อวินาทีเป็นระบบไม่เชิงเส้น แต่ถ้าดูค่าเฉลี่ยในหนึ่งคาบสวิตช์ (state-space averaging) แล้วทำให้เป็นเชิงเส้นรอบจุดทำงาน $D$ จะได้ฟังก์ชันถ่ายโอนจาก duty cycle $d$ ไปแรงดันเอาต์พุต ใช้ได้ดีที่ความถี่ต่ำกว่าประมาณครึ่งหนึ่งของ $f_{sw}$

H1 Buck control-to-output ฟังก์ชันถ่ายโอนจาก duty ไปเอาต์พุต

$$G_{vd}(s) = \frac{\hat v_o}{\hat d} = V_{in}\,\frac{1 + sr_CC}{LC\left(1 + \frac{r_C}{R}\right)s^2 + \left(\frac LR + r_CC\right)s + 1} \approx V_{in}\,\frac{1 + s/\omega_{esr}}{1 + \frac{s}{Q\omega_0} + \frac{s^2}{\omega_0^2}}$$

$\omega_0 = \frac{1}{\sqrt{LC}}$ · $Q \approx R\sqrt{C/L}$ (โหลดเบา $Q$ สูง ยอดสูง) · $\omega_{esr} = \frac{1}{r_CC}$ · คือวงจร RLC ที่คูณด้วย $V_{in}$

H2 PWM modulator gain เกนของ PWM

$$\frac{\hat d}{\hat v_c} = \frac{1}{V_{pp}}$$

$V_{pp}$ = แอมพลิจูดของสัญญาณฟันเลื่อยในไอซี (ดู datasheet) · PWM ดิจิทัล: $1/\text{ค่าเต็มสเกลของ counter}$

H3 Voltage-mode loop gain ลูปเกนโหมดแรงดัน

$$T(s) = G_c(s)\cdot\frac{1}{V_{pp}}\cdot G_{vd}(s)\cdot H$$

$H = \frac{V_{ref}}{V_o}$ (ตัวแบ่งแรงดัน) · ถ้าใช้ออปแอมป์ที่ตัวต้านทานด้านบนของตัวแบ่งเป็น $R_1$ ของตัวชดเชย $H$ จะรวมอยู่ใน $G_c$ แล้ว (ตัวล่างกำหนดแค่ DC)

## ตัวชดเชย Type I, II, III กลาง

H4 Type I and Type II ตัวชดเชย Type I และ Type II

$$\text{Type I: } \frac{\omega_I}{s}, \qquad \text{Type II: } G_c(s) = \frac{\omega_I}{s}\cdot\frac{1 + s/\omega_z}{1 + s/\omega_p}$$

Type II = อินทิเกรเตอร์ + lead หนึ่งชุด เติมเฟสได้ไม่เกิน 90° · ใช้กับโหมดกระแส (พลานต์เหลืออันดับหนึ่ง) หรือเมื่อ ESR zero ต่ำกว่าครอสโอเวอร์

H5 Type III (op-amp) ตัวชดเชย Type III ด้วยออปแอมป์

$$G_c(s) = \frac{(1 + sR_2C_1)\big(1 + s(R_1 + R_3)C_3\big)}{sR_1(C_1 + C_2)\left(1 + sR_2\frac{C_1C_2}{C_1 + C_2}\right)(1 + sR_3C_3)}$$

อินทิเกรเตอร์ $\omega_I = \frac{1}{R_1(C_1 + C_2)}$ · ศูนย์ที่ $\frac{1}{R_2C_1}$ และ $\frac{1}{(R_1 + R_3)C_3}$ · ขั้วที่ $\frac{C_1 + C_2}{R_2C_1C_2}$ และ $\frac{1}{R_3C_3}$ · $R_2, C_1, C_2$ คร่อมป้อนกลับ $R_3$ อนุกรม $C_3$ ขนานกับ $R_1$

H6 Type III placement กฎการวางขั้วและศูนย์

$$f_{z1} = f_{z2} \approx f_0, \qquad f_{p1} \approx f_{esr}, \qquad f_{p2} \approx \frac{f_{sw}}{2}, \qquad |T(j2\pi f_c)| = 1 \ \text{ที่ } f_c \le \frac{f_{sw}}{10}$$

ศูนย์คู่หักล้างขั้วคู่ของ LC (เติมเฟส 180°) · ขั้วแรกหักล้าง ESR zero · ขั้วที่สองกรองริปเปิลสวิตชิ่ง · แล้วเลือก $\omega_I$ ให้ได้ครอสโอเวอร์ตามต้องการ

ตัวอย่าง H-1 · ออกแบบลูปบั๊ก 12 V → 5 V

### $V_{in} = 12$ V, $V_o = 5$ V, $I_o = 2$ A ($R = 2.5\ \Omega$), $L = 22\ \mu$H, $C = 100\ \mu$F, ESR $= 20$ mΩ, $f_{sw} = 200$ kHz, $V_{pp} = 1$ V ออกแบบ Type III ให้ครอสโอเวอร์ 20 kHz

- พลานต์ H1: $f_0 = \dfrac{1}{2\pi\sqrt{22\mu \cdot 100\mu}} = 3.39$ kHz · $Q = 2.5\sqrt{100/22} = 5.33$ (ยอด 14.5 dB) · $f_{esr} = \dfrac{1}{2\pi(0.02)(100\mu)} = 79.6$ kHz · เกน DC $V_{in}/V_{pp} = 12$ (21.6 dB)

- ที่ 20 kHz พลานต์ (รวม PWM) มีขนาด −8.8 dB เฟส −164° · ถ้าไม่ชดเชย PM เหลือแค่ 16°

- วาง H6: ศูนย์คู่ที่ 3.39 kHz ขั้วที่ 79.6 kHz และ 100 kHz แล้วหา $\omega_I$ ให้ $|T| = 1$ ที่ 20 kHz: $\omega_I = 1.02 \times 10^4\ \text{s}^{-1}$

$$G_c(s) = 10173\,\frac{(1 + s/\omega_0)^2}{s(1 + s/\omega_{esr})(1 + s/\omega_{p2})}$$

- ค่าอุปกรณ์ H5 เลือก $R_1 = 10$ kΩ (ตัวบนของตัวแบ่งแรงดัน): $C_1 + C_2 = \frac{1}{R_1\omega_I} = 9.83$ nF · จาก $R_2C_1 = 1/\omega_0 = 46.9\ \mu$s และขั้ว $f_{esr}$: $C_1 = 9.41$ nF, $C_2 = 419$ pF, $R_2 = 4.98$ kΩ · จาก $(R_1 + R_3)C_3 = 46.9\ \mu$s และ $R_3C_3 = 1.59\ \mu$s: $C_3 = 4.53$ nF, $R_3 = 351\ \Omega$

PM = 61.7° ที่ $f_c$ = 20 kHz, GM = ∞ · ค่ามาตรฐานใกล้เคียง: $R_2 = 4.99$ kΩ, $C_1 = 10$ nF, $C_2 = 390$ pF, $C_3 = 4.7$ nF, $R_3 = 348\ \Omega$ (ตรวจ PM อีกครั้งหลังปัดค่า)

จำลองด้วย python-control ใช้ $G_{vd}$ แบบเต็ม (รวม ESR) ✓ · ลองในแล็บด้านล่าง: PM และ GM ตรงกัน · เมื่อโหลดเบาลง $Q$ สูงขึ้น ต้องตรวจซ้ำที่โหลดต่ำสุดด้วย

## โหมดกระแส และ RHP zero ของบูสต์ ขั้นสูง

H7 Current-mode control ควบคุมโหมดกระแส

$$\frac{\hat v_o}{\hat v_c} \approx \frac{R}{R_i}\cdot\frac{1 + s/\omega_{esr}}{1 + sRC/2}\ (\text{บั๊ก โดยประมาณ})$$

ลูปกระแสในเร็วมาก (ทุกคาบ) ทำให้ตัวเหนี่ยวนำเหมือนแหล่งกระแส ขั้วคู่ของ LC แยกเหลือขั้วเดียวจาก $RC$ · ใช้ Type II ได้ · ป้องกันกระแสเกินในตัว · $D \gt 0.5$ ต้องมี slope compensation (ไม่อย่างนั้นแกว่งที่ $f_{sw}/2$) · หลักการเดียวกับลูปคาสเคดของมอเตอร์

H8 Boost RHP zero ศูนย์ฝั่งขวาของบูสต์

$$G_{vd}^{boost}(s) \propto \frac{1 - s/\omega_{RHP}}{1 + \frac{s}{Q\omega_0} + \frac{s^2}{\omega_0^2}}, \qquad f_{RHPZ} = \frac{R(1 - D)^2}{2\pi L}, \qquad f_c \lt \frac{f_{RHPZ}}{3}$$

เพิ่ม duty ทันที เอาต์พุตลดลงก่อน (ไดโอดนำนานน้อยลงชั่วขณะ) แล้วค่อยเพิ่ม = ศูนย์ฝั่งขวา · เติมเฟสแก้ไม่ได้ จำกัดแบนด์วิดท์ลูปโดยธรรมชาติ

ตัวอย่าง H-2 · บูสต์ 5 V → 12 V

### บูสต์ $L = 10\ \mu$H จ่าย 12 V 1 A จาก 5 V ครอสโอเวอร์ได้สูงสุดเท่าไร

- $D = 1 - \frac{V_{in}}{V_o} = 0.583$ · $R = 12\ \Omega$

- H8: $f_{RHPZ} = \dfrac{12(0.417)^2}{2\pi(10^{-5})} = 33.2$ kHz → $f_c \lt 11$ kHz

ครอสโอเวอร์ไม่ควรเกินประมาณ 10 kHz แม้ $f_{sw}$ จะเป็น 500 kHz ก็ตาม · โหลดหนักขึ้น (R ลด) หรือแรงดันเข้าต่ำลง (D เพิ่ม) RHP zero ยิ่งต่ำ ต้องออกแบบที่กรณีแย่ที่สุด

## วัดลูปเกนจริงบนโต๊ะแล็บ กลาง

H9 Loop-gain measurement วัดลูปเกนด้วยการฉีดสัญญาณ

$$T(j\omega) = -\frac{\hat v_y}{\hat v_x}\ \ (\text{วัดสองฝั่งของตัวต้านทานฉีดสัญญาณ } R_{inj})$$

ใส่ $R_{inj}$ 10–50 Ω ระหว่างเอาต์พุตกับตัวแบ่งแรงดัน (จุดอิมพีแดนซ์ต่ำ→สูง) ฉีดไซน์ขนาดเล็กผ่านหม้อแปลงฉีดสัญญาณ วัดด้วยสโคปสองช่องที่ฟังก์ชันเจเนอเรเตอร์กวาดความถี่ หรือ network analyzer ได้โบดของ $T$ โดยตรง

## แล็บ: ลูปเกนบั๊กคอนเวอร์เตอร์

ความถี่ในแล็บสเกลเป็น krad/s เพื่อให้อ่านง่าย (หาร ω ด้วย 1000): พลานต์ $G_{vd}/V_{pp}$ มีขั้วคู่ที่ 21.3 krad/s และ ESR zero ที่ 500 krad/s ค่าเริ่มต้นคือ Type III จาก H-1: PM 61.7° ที่ครอสโอเวอร์ 125.7 krad/s (20 kHz) สังเกตกราฟเฟสที่ถูกยกขึ้นเป็นเนิน เทียบกับ “ก่อน” ที่ใช้อินทิเกรเตอร์อย่างเดียว ซึ่งต้องลดเกนจนครอสโอเวอร์เหลือแค่ 0.6 krad/s (96 Hz) เพื่อให้ยอดเรโซแนนซ์ 14.5 dB ของ LC อยู่ใต้ 0 dB (ช้ากว่า 200 เท่า)

หน่วยในแล็บ: ω เป็น krad/s และเวลาเป็นมิลลิวินาที (เกน $\omega_I$ จึงเป็น 10.17 ms⁻¹) ผล PM ไม่ขึ้นกับการสเกลนี้

## ทางต่อไป: หมวดอิเล็กทรอนิกส์กำลังและสวิตชิงพาวเวอร์ซัพพลาย

หน้านี้เป็นสะพาน หมวดอิเล็กทรอนิกส์กำลังที่กำลังจะตามมาจะลงลึกในตัวแปลงแต่ละแบบ (บั๊ก บูสต์ บั๊ก-บูสต์ ฟลายแบค ฟอร์เวิร์ด) การเลือก L และ C จากริปเปิล โหมดนำกระแสต่อเนื่องและไม่ต่อเนื่อง การออกแบบแม่เหล็ก การสูญเสียและความร้อน และการควบคุมแบบดิจิทัล โดยใช้เครื่องมือจากชุดระบบควบคุมนี้ทั้งหมด

| ในพาวเวอร์ซัพพลาย | เรียนมาแล้วที่ |

| LC ฟิลเตอร์ ขั้วคู่ Q | RLC · โบดอันดับสอง |

| แบบจำลองสัญญาณเล็ก | ทำให้เป็นเชิงเส้น · ปริภูมิสถานะ |

| Type II / III | lead lag · PID ออปแอมป์ |

| PM, GM, ครอสโอเวอร์ | มาร์จิน |

| โหมดกระแส | ลูปซ้อน |

| RHP zero ของบูสต์ | ศูนย์ฝั่งขวา |

| ควบคุมด้วย DSP | ควบคุมดิจิทัล |

| ริปเปิล ฟิลเตอร์ LC และ EMI ของโหนดสวิตช์ | ฟูเรียร์ในคอนเวอร์เตอร์ DC-DC |

| ฮาร์มอนิกของเรกติไฟเออร์ อินเวอร์เตอร์ PWM และ PFC | เรกติไฟเออร์ · อินเวอร์เตอร์ PWM · Active PFC |

เรียนต่อในชุดอิเล็กทรอนิกส์กำลัง บั๊ก บูสต์ บั๊ก-บูสต์ ชุค แบบละเอียด แบบจำลองเฉลี่ยและสเตตสเปซของบั๊ก ฟังก์ชันถ่ายโอนบั๊กทุกคู่อินพุต–เอาต์พุต แบบจำลองสัญญาณเล็ก ออกแบบตัวชดเชยด้วย k-factor และ peak current mode ควบคุมดิจิทัล และ แล็บจำลองคอนเวอร์เตอร์

## คำถามที่พบบ่อย

ทำไมบั๊กคอนเวอร์เตอร์โหมดแรงดันต้องใช้ Type III?
เพราะ LC ฟิลเตอร์ให้ขั้วคู่ที่เฟสลดลงเกือบ 180° ใกล้ความถี่เรโซแนนซ์ ถ้าครอสโอเวอร์อยู่สูงกว่าเรโซแนนซ์ (ซึ่งต้องการเพื่อความเร็ว) เฟสของพลานต์เกือบ −180° แล้ว ตัวชดเชยต้องเติมเฟสบวกได้มากกว่า 90° Type III มีศูนย์สองตัวจึงเติมเฟสได้ถึงเกือบ 180° ส่วน Type II เติมได้ไม่ถึง 90° เหมาะกับโหมดกระแสหรือเมื่อ ESR zero อยู่ต่ำ

เลือกความถี่ครอสโอเวอร์ของพาวเวอร์ซัพพลายอย่างไร?
ไม่เกินประมาณหนึ่งในสิบถึงหนึ่งในห้าของความถี่สวิตชิ่ง เพราะแบบจำลองเฉลี่ยใช้ได้แค่ความถี่ต่ำกว่าการสวิตช์มาก และต้องไม่ให้ริปเปิลสวิตชิ่งผ่านลูป สำหรับบูสต์และบั๊ก-บูสต์ต้องต่ำกว่าความถี่ของ RHP zero อีกประมาณ 3 เท่า

ใส่ตัวต้านทานเล็ก ๆ (10–50 Ω) อนุกรมในเส้นป้อนกลับ ฉีดสัญญาณไซน์ขนาดเล็กคร่อมตัวต้านทานนั้นด้วยหม้อแปลงฉีดสัญญาณ แล้ววัดอัตราส่วนแรงดันสองฝั่งด้วย network analyzer หรือฟังก์ชันเจเนอเรเตอร์กับสโคปสองช่อง กวาดความถี่ได้โบดของลูปเกนจริง อ่าน PM และ GM ได้ทันที

## คำถามที่พบบ่อย (FAQ)

**ทำไมบั๊กคอนเวอร์เตอร์โหมดแรงดันต้องใช้ Type III?**
เพราะ LC ฟิลเตอร์ให้ขั้วคู่ที่เฟสลดลงเกือบ 180° ใกล้ความถี่เรโซแนนซ์ ถ้าครอสโอเวอร์อยู่สูงกว่าเรโซแนนซ์ (ซึ่งต้องการเพื่อความเร็ว) เฟสของพลานต์เกือบ −180° แล้ว ตัวชดเชยต้องเติมเฟสบวกได้มากกว่า 90° Type III มีศูนย์สองตัวจึงเติมเฟสได้ถึงเกือบ 180° ส่วน Type II เติมได้ไม่ถึง 90° เหมาะกับโหมดกระแสหรือเมื่อ ESR zero อยู่ต่ำ
