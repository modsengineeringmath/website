# รูทโลคัส (Root Locus): นิยามและกฎการวาดทุกข้อ

// บทที่ 13.8 · ระบบควบคุม · Root Locus


ปี 1948 วอลเตอร์ อีแวนส์ (Walter R. Evans) แสดงว่าเราวาดทางเดินของขั้ววงปิดได้ครบทุกค่าเกน โดยไม่ต้องแก้สมการเลยสักครั้ง ใช้แค่ขั้วและศูนย์ของวงเปิด ไม้บรรทัด และไม้โปรแทรกเตอร์ หน้านี้ไม่ได้ให้ท่องกฎ แต่จะพิสูจน์ทุกกฎจากเงื่อนไขมุมข้อเดียว แล้วใช้ครบทุกข้อกับตัวอย่างคลาสสิก จากนั้นหน้าถัดไปคือการฝึกวาดจนคล่องแทน MATLAB สูตรใช้รหัส L

สรุปใน 30 วินาที

- จุด $s$ อยู่บนโลคัส $\iff$ $\angle G(s)H(s) = \pm180^\circ(2q+1)$ (มุมจากศูนย์ลบมุมจากขั้ว)

- เริ่มที่ขั้ว ($K = 0$) จบที่ศูนย์ ($K \to \infty$) กิ่งส่วนเกิน $n - m$ กิ่งไปตามเส้นกำกับ

- บนแกนจริง: เป็นโลคัสถ้าจำนวนขั้วและศูนย์ทางขวาเป็นเลขคี่

- คำนวณ: $\sigma_a,\ \theta_a$, จุดแยก $dK/ds = 0$, ตัด $j\omega$ (Routh), มุมออกจากขั้วเชิงซ้อน · $K$ ที่จุดใด ๆ = ผลคูณระยะถึงขั้ว ÷ ผลคูณระยะถึงศูนย์

ระดับพื้นฐาน เริ่มเรียนควบคุมกลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท

## แนวคิด: ขั้วเดินอย่างไรเมื่อหมุนปุ่มเกน พื้นฐาน

ระบบป้อนกลับที่มีเกนปรับได้ $K$ อยู่ในลูป (เช่น เกนของแอมป์ขับมอเตอร์ หรือ $K_P$ ของตัวควบคุม) มีขั้ววงปิดเป็นรากของสมการลักษณะเฉพาะ เมื่อหมุน $K$ จาก 0 ขึ้นไป รากแต่ละตัวจะเคลื่อนที่เป็นเส้นต่อเนื่องบนระนาบ $s$ เส้นเหล่านี้คือรูทโลคัส อ่านแล้วรู้ทันทีว่าเกนเท่าไรเร็ว เท่าไรแกว่ง และเท่าไรเริ่มไม่เสถียร ซึ่งต่อยอดจากเราท์–เฮอร์วิตซ์ (บอกแค่ขอบเสถียร) และผลตอบสนองเวลา (ขั้วอยู่ไหน ผลตอบสนองเป็นแบบนั้น)

รูทโลคัสของ $K/[s(s+1)(s+2)]$ · เส้นประคือเส้นกำกับ · ■ จุดแยก · ◆ จุดตัดแกน $j\omega$ · ลูกศรคือทิศที่ $K$ เพิ่ม

L1 Root-locus form รูปแบบมาตรฐานของสมการลักษณะเฉพาะ

$$1 + KG(s)H(s) = 0, \qquad G(s)H(s) = \frac{(s - z_1)(s - z_2)\cdots(s - z_m)}{(s - p_1)(s - p_2)\cdots(s - p_n)}$$

ต้องจัดให้ $K$ อยู่หน้าและ $GH$ เป็นmonic (สัมประสิทธิ์กำลังสูงสุดเป็น 1) ก่อนใช้กฎ · $n$ = จำนวนขั้ว $m$ = จำนวนศูนย์ ($n \ge m$) · ถ้าตัวแปรที่ปรับไม่ใช่เกน (เช่น ตำแหน่งขั้ว) ให้จัดรูปให้เป็นแบบนี้ก่อน

## เงื่อนไขมุมและเงื่อนไขขนาด: หัวใจของทุกกฎ พื้นฐาน

จาก L1 จะได้ $KG(s)H(s) = -1$ จำนวนเชิงซ้อน $-1$ มีขนาด 1 และมุม $180^\circ$ จึงแยกได้เป็นสองเงื่อนไข มองเป็นเวกเตอร์: $(s - p_i)$ คือลูกศรที่ลากจากขั้ว $p_i$ ไปหาจุดทดสอบ $s$ (ทบทวนมุมของเวกเตอร์เชิงซ้อนได้ที่ตรีโกณมิติ)

L2 Angle condition เงื่อนไขมุม (บอกว่าจุดไหนอยู่บนโลคัส)

$$\sum_{i=1}^{m}\angle(s - z_i) - \sum_{j=1}^{n}\angle(s - p_j) = \pm180^\circ(2q + 1), \quad q = 0, 1, 2, \dots$$

“มุมจากศูนย์ทั้งหมด ลบ มุมจากขั้วทั้งหมด ต้องเป็นเลขคี่คูณ 180°” · ไม่เกี่ยวกับ $K$ เลย รูปร่างของโลคัสจึงกำหนดโดยตำแหน่งขั้วและศูนย์ล้วน ๆ

L3 Magnitude condition เงื่อนไขขนาด (บอกว่าจุดนั้นใช้ $K$ เท่าไร)

$$K = \frac{1}{|G(s)H(s)|} = \frac{\prod_{j=1}^{n}|s - p_j|}{\prod_{i=1}^{m}|s - z_i|} = \frac{\text{ผลคูณระยะจากขั้วทุกตัว}}{\text{ผลคูณระยะจากศูนย์ทุกตัว}}$$

ไม่มีศูนย์ ตัวส่วนเป็น 1 · ใช้หลังจากรู้แล้วว่าจุดนั้นอยู่บนโลคัส (ผ่าน L2) · ได้ $K$ ของขั้ววงปิดตัวนั้น และขั้วตัวอื่นที่ $K$ เดียวกันหาได้ต่อด้วยกฎ L10

ตัวอย่าง L-0 · ทดสอบจุด

### สำหรับ $G(s) = \dfrac{K}{s(s+1)(s+2)}$ จุด $s = -1 + j$ อยู่บนรูทโลคัสไหม และ $s = -\tfrac13 + j\tfrac{1}{\sqrt3}$ ล่ะ

- จุด $-1 + j$: มุมจากขั้ว 0 คือ $135^\circ$ จากขั้ว $-1$ คือ $90^\circ$ จากขั้ว $-2$ คือ $45^\circ$ L2

$$0 - (135^\circ + 90^\circ + 45^\circ) = -270^\circ \ne \pm180^\circ(2q+1) \ \Rightarrow\ \text{ไม่อยู่บนโลคัส}$$

- จุด $s = -\tfrac13 + j0.5774$: มุมจาก 0 คือ $180^\circ - \tan^{-1}\frac{0.5774}{0.3333} = 120^\circ$ · จาก $-1$: $\tan^{-1}\frac{0.5774}{0.6667} = 40.9^\circ$ · จาก $-2$: $\tan^{-1}\frac{0.5774}{1.6667} = 19.1^\circ$

$$-(120^\circ + 40.9^\circ + 19.1^\circ) = -180^\circ \ \checkmark$$

- หา $K$ ด้วยระยะ L3: $|s| = 0.667$, $|s + 1| = 0.882$, $|s + 2| = 1.764$

$$K = 0.667 \times 0.882 \times 1.764 = {1.037} \ (= 28/27)$$

$-1 + j$ ไม่อยู่บนโลคัส · $-\tfrac13 \pm j\tfrac{1}{\sqrt3}$ อยู่บนโลคัสที่ $K = 28/27 \approx 1.037$ จุดนี้อยู่บนเส้น $\zeta = 0.5$ พอดี (มุม $60^\circ$ จากแกนจริงลบ)

ตรวจ: $s^3 + 3s^2 + 2s + \tfrac{28}{27} = (s + \tfrac73)(s^2 + \tfrac23s + \tfrac49)$ รากคือ $-\tfrac73$ และ $-\tfrac13 \pm j0.5774$ ✓

## กฎการวาดรูทโลคัส (สำหรับ K ≥ 0) กลาง

ทุกกฎข้างล่างพิสูจน์ได้จาก L2 และ L3 เท่านั้น ใต้แต่ละกฎมีเหตุผลสั้น ๆ ให้เข้าใจแทนการท่อง ลำดับที่แนะนำเวลาวาดคือตามเลขกฎ

L4 Rule 1 · Branches, start and end จำนวนกิ่ง จุดเริ่ม จุดจบ

$$\#\text{กิ่ง} = n, \qquad K = 0:\ s = p_j \ (\text{ขั้ว}), \qquad K \to \infty:\ s \to z_i \ \text{หรือ} \ \infty \ (n - m \text{ กิ่ง})$$

เหตุผล: L3 ให้ $K \to 0$ เมื่อ $s \to p_j$ และ $K \to \infty$ เมื่อ $s \to z_i$ · โลคัสสมมาตรรอบแกนจริงเสมอ เพราะรากเชิงซ้อนของพหุนามสัมประสิทธิ์จริงมาเป็นคู่สังยุค วาดครึ่งบนแล้วสะท้อน

L5 Rule 2 · Real-axis segments ส่วนบนแกนจริง

$$\text{จุดบนแกนจริงอยู่บนโลคัส} \iff \#(\text{ขั้ว} + \text{ศูนย์ที่อยู่บนแกนจริง ทาง}\textbf{ขวา}\text{ของจุดนั้น}) \text{ เป็นเลขคี่}$$

เหตุผล: คู่เชิงซ้อนให้มุมหักล้างกัน ($+\theta$ กับ $-\theta$) ขั้วหรือศูนย์ทางซ้ายให้มุม $0^\circ$ ทางขวาให้ $180^\circ$ จึงต้องมีจำนวนคี่ตัวทางขวาเพื่อให้รวมเป็น $180^\circ$ คี่เท่า

L6 Rule 3 · Asymptotes เส้นกำกับ: มุมและจุดตัดแกนจริง

$$\theta_a = \frac{(2q + 1)180^\circ}{n - m},\ \ q = 0, 1, \dots, n - m - 1, \qquad \sigma_a = \frac{\sum p_j - \sum z_i}{n - m}$$

$n - m = 1$: 180° · 2: ±90° · 3: ±60°, 180° · 4: ±45°, ±135° · เหตุผล: ไกลมาก ๆ ขั้วและศูนย์ทุกตัวดูเหมือนรวมเป็นจุดเดียวที่ $\sigma_a$ มุมจาก $n - m$ ตัวที่เหลือต้องรวมเป็น 180° · ใน $\sum p_j$ คู่เชิงซ้อนรวมกันเหลือแค่ส่วนจริงสองเท่า

L7 Rule 4 · Breakaway and break-in points จุดแยกและจุดเข้า

$$K(s) = -\frac{1}{G(s)H(s)}, \qquad \frac{dK}{ds} = 0 \quad \Longleftrightarrow \quad \sum_{j=1}^{n}\frac{1}{\sigma - p_j} = \sum_{i=1}^{m}\frac{1}{\sigma - z_i}$$

ระหว่างขั้วสองตัวที่ติดกันบนโลคัสแกนจริง ต้องมีจุดแยกออก (K บนแกนจริงสูงสุดตรงนั้น) ระหว่างศูนย์สองตัวมีจุดเข้า · เก็บเฉพาะรากที่อยู่บนโลคัสและให้ $K \gt 0$ · $r$ กิ่งมาพบกันจะแยกออกห่างกันมุม $180^\circ/r$ (สองกิ่ง: ตั้งฉากกับแกนจริง)

L8 Rule 5 · jω-axis crossings จุดตัดแกน $j\omega$

$$\text{แทน } s = j\omega \text{ ใน } 1 + KGH = 0:\ \ \operatorname{Re}\{\cdot\} = 0,\ \ \operatorname{Im}\{\cdot\} = 0 \quad \text{หรือใช้ตารางเราท์หา } K_{cr}$$

ได้ $\omega_{cr}$ และ $K_{cr}$ ซึ่งคือขอบเสถียรภาพ R10 · ถ้าไม่มีคำตอบที่ $K \gt 0$ แสดงว่าโลคัสไม่ตัดแกน $j\omega$

L9 Rule 6 · Angles of departure and arrival มุมออกจากขั้วเชิงซ้อนและมุมเข้าศูนย์เชิงซ้อน

$$\theta_{d} = 180^\circ - \sum_{j \ne k}\angle(p_k - p_j) + \sum_{i}\angle(p_k - z_i), \qquad \theta_{a} = 180^\circ - \sum_{i \ne k}\angle(z_k - z_i) + \sum_{j}\angle(z_k - p_j)$$

เหตุผล: ใช้ L2 กับจุดทดสอบที่อยู่ชิดขั้ว $p_k$ มาก ๆ มุมจาก $p_k$ เองคือมุมออกที่ต้องการ มุมจากตัวอื่นแทบไม่เปลี่ยน · ขั้วซ้ำ $r$ ตัว: หาร $r$ และเพิ่มทีละ $360^\circ/r$

L10 Rule 7 · Sum of closed-loop poles ผลรวมขั้ววงปิดคงที่

$$n - m \ge 2:\ \ \sum_{j} r_j(K) = \sum_j p_j = -a_1 \ \ \text{ทุกค่า } K$$

$K$ ไม่ไปแตะสัมประสิทธิ์ $s^{n-1}$ · กิ่งหนึ่งไปขวา อีกกิ่งต้องไปซ้าย · ใช้หาขั้วที่สามเมื่อรู้คู่เด่น

L11 Product of closed-loop poles ผลคูณขั้ววงปิด (ไม่มีศูนย์)

$$\prod_j(-r_j) = a_n + K$$

พจน์คงที่ของสมการลักษณะเฉพาะ · ใช้ตรวจคำตอบหรือหาขั้วที่เหลือ

## ตัวอย่างครบทุกกฎ: K/(s(s+1)(s+2)) กลาง

ระบบนี้คือมอเตอร์ไฟฟ้ากระแสตรงควบคุมตำแหน่ง (อินทิเกรเตอร์ $1/s$ จากตำแหน่ง = อินทิกรัลของความเร็ว) ที่มีค่าคงเวลาทางกลและทางไฟฟ้า เป็นโจทย์รูทโลคัสที่ออกสอบบ่อยที่สุดในโลก ทำทีละกฎ

ตัวอย่าง L-1 · ครบ 7 กฎ

### วาดรูทโลคัสของ $KG(s) = \dfrac{K}{s(s+1)(s+2)}$ ระบุทุกจุดสำคัญ และหา $K$ ที่ให้ $\zeta = 0.5$

- กฎ 1 L4: ขั้ว $0, -1, -2$ ($n = 3$) ไม่มีศูนย์ ($m = 0$) มี 3 กิ่ง ทั้ง 3 กิ่งไปอนันต์

- กฎ 2 L5: ช่วง $[-1, 0]$ มีขั้วทางขวา 1 ตัว (คี่) ✓ · ช่วง $(-2, -1)$ มี 2 ตัว (คู่) ✗ · ช่วง $(-\infty, -2]$ มี 3 ตัว (คี่) ✓

- กฎ 3 L6: $n - m = 3$ ได้ $\theta_a = 60^\circ, 180^\circ, 300^\circ$ และ

$$\sigma_a = \frac{0 + (-1) + (-2) - 0}{3} = {-1}$$

- กฎ 4 L7: ช่วง $[-1, 0]$ มีขั้วสองข้าง ต้องมีจุดแยก $K = -(s^3 + 3s^2 + 2s)$

$$\frac{dK}{ds} = -(3s^2 + 6s + 2) = 0 \ \Rightarrow\ s = \frac{-6 \pm \sqrt{36 - 24}}{6} = -1 \pm 0.577$$

$s = -0.423$ อยู่ในช่วง $[-1, 0]$ ✓ ใช้ได้ ($K = 0.385$) · $s = -1.577$ อยู่ในช่วงที่ไม่ใช่โลคัส ✗ ทิ้ง (ให้ $K = -0.385$)

- กฎ 5 L8: แทน $s = j\omega$ ใน $s^3 + 3s^2 + 2s + K = 0$

$$-j\omega^3 - 3\omega^2 + 2j\omega + K = 0 \ \Rightarrow\ \begin{cases} \operatorname{Im}:\ \omega(2 - \omega^2) = 0 \Rightarrow \omega = \sqrt2 \\ \operatorname{Re}:\ K = 3\omega^2 = 6 \end{cases}$$

ตรงกับตัวอย่าง R-5 ✓ ได้จุดตัด $\pm j1.414$ ที่ $K = 6$

- กฎ 6 L9: ไม่มีขั้วหรือศูนย์เชิงซ้อน ไม่ต้องหามุมออก

- หา $K$ ที่ $\zeta = 0.5$: เส้น $\zeta = 0.5$ ทำมุม $\cos^{-1}0.5 = 60^\circ$ กับแกนจริงลบ จากตัวอย่าง L-0 จุดตัดคือ $s = -0.333 \pm j0.577$ ที่ $K = 1.037$ ขั้วที่สามจาก L10: $r_3 = -3 - 2(-0.333) = -2.333$

โลคัสเริ่มที่ 0, −1, −2 · สองกิ่งชนกันที่ −0.423 แล้วแยกขึ้นลง โค้งไปตามเส้นกำกับ ±60° จาก σ = −1 ตัดแกน $j\omega$ ที่ ±j1.414 เมื่อ K = 6 · อีกกิ่งวิ่งไปทางซ้ายจาก −2 · $\zeta = 0.5$ ที่ $K = 1.037$ (ขั้วที่สามอยู่ไกลกว่า 7 เท่า คู่เด่นจึงทำนายผลตอบสนองได้ดี)

รูปด้านบนและแล็บท้ายหน้าคำนวณจากเครื่อง ตรงกับทุกค่า · ระบบอยู่ในช่วงเสถียร $0 \lt K \lt 6$ ตามเราท์ ✓

ตัวอย่าง L-2 · มุมออกจากขั้วเชิงซ้อน

### หามุมออกจากขั้ว $-1 + j$ ของ $KG(s) = \dfrac{K}{s(s^2 + 2s + 2)}$

- ขั้ว: $0,\ -1 \pm j$ · มุมจากขั้วอื่นไปหา $p_k = -1 + j$: จาก $0$ คือ $\angle(-1 + j) = 135^\circ$ · จาก $-1 - j$ คือ $\angle(2j) = 90^\circ$

- ไม่มีศูนย์ แทน L9

$$\theta_d = 180^\circ - (135^\circ + 90^\circ) = {-45^\circ}$$

## อ่านรูทโลคัสให้เป็น: จากรูปสู่สเปก กลาง

เมื่อวาดแล้ว คำถามออกแบบตอบได้จากรูปทันที เพราะตำแหน่งขั้วบอกสเปกเวลาโดยตรง

| ต้องการ | มองหาอะไรบนระนาบ s | สูตร |

| overshoot ไม่เกินค่าที่กำหนด | ขั้วเด่นอยู่ในกรวยระหว่างเส้น $\pm\cos^{-1}\zeta$ | $M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}}$ |

| เวลาเข้าที่ (2%) ไม่เกิน $t_s$ | ขั้วเด่นอยู่ซ้ายเส้นดิ่ง $\sigma = -4/t_s$ | $t_s \approx 4/(\zeta\omega_n)$ |

| เวลายอดไม่เกิน $t_p$ | ขั้วเด่นอยู่เหนือเส้น $\omega_d = \pi/t_p$ | $t_p = \pi/\omega_d$ |

| ตอบสนองเร็ว ($\omega_n$ สูง) | ขั้วอยู่ไกลจากจุดกำเนิด | $\omega_n = |s|$ |

## แล็บรูทโลคัส: ลากขั้วและศูนย์ ดูกฎทำงาน

แผงด้านล่างคำนวณผลของกฎทุกข้อจาก L(s) ที่พิมพ์ ใช้ตรวจการบ้านได้ ลองลากขั้วที่ −2 ไปทางซ้ายช้า ๆ ดูเส้นกำกับเลื่อนตาม $\sigma_a$ หรือกด “+ ศูนย์จริง” ดูโลคัสถูกดึงไปทางซ้าย คลิกบนเส้นโลคัสเพื่อเลือก $K$ ที่จุดนั้น

## ข้อผิดพลาดที่พบบ่อย

- ไม่จัดรูป monic ก่อน → $\dfrac{K}{2s(s+1)}$ ต้องคิดเป็น $K' = K/2$ ไม่อย่างนั้นค่า $K$ จากเงื่อนไขขนาดจะผิด L1

- นับขั้วและศูนย์ทางซ้าย → กฎแกนจริงนับทางขวาเท่านั้น L5

- ลืมคู่สังยุคในผลรวม σa → $-1 \pm j$ รวมกันได้ $-2$

- ใช้รากของ dK/ds ทุกตัวเป็นจุดแยก → ต้องอยู่บนโลคัสจริงและ $K \gt 0$ L7

- มุมออกเครื่องหมายผิด → มุมจากศูนย์บวก มุมจากขั้วลบ วัดทวนเข็มจากแกนจริงบวกเสมอ

- คิดว่ากิ่งเดินตามเส้นกำกับเป๊ะ → เส้นกำกับคือทิศเมื่อ $K$ โตมาก ใกล้ ๆ ขั้วกิ่งอาจโค้งต่างไปมาก ต้องใช้จุดตัด $j\omega$ และมุมออกช่วย
