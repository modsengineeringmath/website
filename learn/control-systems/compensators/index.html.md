# ตัวชดเชย Lead, Lag และ Lag-Lead

// บทที่ 13.15 · ระบบควบคุม · Lead, Lag & Lag-Lead Compensators


เมื่อปรับเกนอย่างเดียวแล้วได้แค่ “เร็วแต่แกว่ง” หรือ “นิ่งแต่ช้าและไม่แม่น” ทางออกคือเพิ่มขั้วและศูนย์อย่างมีชั้นเชิงเพื่อดัดรูปทรงของรูทโลคัสและโบด Lead แก้ปัญหาช่วงความถี่กลาง (ความเร็ว เสถียรภาพ) Lag แก้ปัญหาความถี่ต่ำ (ความแม่นยำ) หน้านี้ออกแบบทั้งสองแบบทีละขั้นด้วยทั้งโบดและรูทโลคัส ตรวจทุกคำตอบด้วยการจำลอง และจบที่วงจรออปแอมป์ที่สร้างได้จริง สูตรใช้รหัส C

สรุปใน 30 วินาที

- Lead: $\dfrac{Ts + 1}{\alpha Ts + 1},\ \alpha \lt 1$ เฟสสูงสุด $\sin\phi_m = \frac{1 - \alpha}{1 + \alpha}$ ที่ $\omega_m = \frac{1}{T\sqrt\alpha}$ วางให้ $\omega_m$ = ครอสโอเวอร์ใหม่

- Lag: $\dfrac{Ts + 1}{\beta Ts + 1},\ \beta \gt 1$ วางศูนย์ต่ำกว่าครอสโอเวอร์ 1 เดคาด เพิ่มเกนความถี่ต่ำ $\beta$ เท่า

- รูทโลคัส: lead ชดเชย “มุมที่ขาด” ให้โลคัสผ่านจุดที่ต้องการ · lag คู่ขั้ว-ศูนย์ใกล้ 0 เพิ่ม $K_v$ โดยไม่ย้ายโลคัส

- Lead ≈ PD + ฟิลเตอร์ · Lag ≈ PI · Lag-lead ≈ PID

ระดับพื้นฐาน แนวคิดกลาง ออกแบบขั้นสูง งานจริง

## ตัวชดเชยเฟสนำ (Lead) พื้นฐาน

ศูนย์อยู่ใกล้จุดกำเนิดกว่าขั้ว ช่วงระหว่างศูนย์กับขั้ว เฟสเป็นบวก (“นำ”) และเกนค่อย ๆ เพิ่มขึ้น $1/\alpha$ เท่า ใช้เฟสบวกนี้เติมเฟสมาร์จินตรงครอสโอเวอร์

C1 Lead compensator ตัวชดเชยเฟสนำ

$$G_c(s) = K_c\frac{Ts + 1}{\alpha Ts + 1} = K_c\alpha\,\frac{s + 1/T}{s + 1/(\alpha T)}, \qquad 0 \lt \alpha \lt 1$$

ศูนย์ที่ $-1/T$ ขั้วที่ $-1/(\alpha T)$ (ไกลกว่า $1/\alpha$ เท่า) · รูปแบบนี้ไม่เปลี่ยนเกน DC ($G_c(0) = K_c$) ทำให้ใช้ $K_c$ ตั้งความผิดพลาดอยู่ตัวแยกจากเรื่องเฟสได้

C2 Maximum phase lead เฟสนำสูงสุดและตำแหน่ง

$$\sin\phi_m = \frac{1 - \alpha}{1 + \alpha} \iff \alpha = \frac{1 - \sin\phi_m}{1 + \sin\phi_m}, \qquad \omega_m = \frac{1}{T\sqrt\alpha}, \qquad \left|\frac{j\omega_mT + 1}{j\omega_m\alpha T + 1}\right| = \frac{1}{\sqrt\alpha}$$

$\omega_m$ คือค่าเฉลี่ยเรขาคณิตของศูนย์และขั้ว (กึ่งกลางบนแกน log) · เกนที่ $\omega_m$ เพิ่ม $10\log(1/\alpha)$ dB · ตาราง: $\phi_m$ = 30° → α = 0.333 · 40° → 0.217 · 50° → 0.132 · 60° → 0.072

## ออกแบบ Lead ด้วยโบด ทีละขั้น กลาง

C3 Lead design procedure (Bode) ขั้นตอนออกแบบ lead ด้วยโบด

- เลือก $K_c$ ให้ได้ $K_v$ (หรือ $K_p, K_a$) ตามสเปก วาดโบดของ $K_cG$ หา PM เดิม

- เฟสที่ต้องเติม $\phi_m = \text{PM}_{\text{ต้องการ}} - \text{PM}_{\text{เดิม}} + (5^\circ\text{ ถึง }12^\circ)$ หา α จาก C2

- ครอสโอเวอร์ใหม่ $\omega_m$ คือความถี่ที่ $|K_cG(j\omega)| = -10\log(1/\alpha)$ dB (lead จะยกขึ้นมาเป็น 0 dB พอดี)

- $T = \dfrac{1}{\omega_m\sqrt\alpha}$ · ศูนย์ $1/T$ ขั้ว $1/(\alpha T)$

- ตรวจ PM, GM และผลตอบสนองจริง ถ้าไม่ถึงให้เพิ่มค่าเผื่อแล้วทำซ้ำ

ตัวอย่าง C-1 · Lead ด้วยโบด

### พลานต์ $G(s) = \dfrac{4}{s(s+2)}$ ต้องการ $K_v = 20\ \text{s}^{-1}$ และ PM ≥ 50°

- $K_v = \lim_{s\to0} sK_cG(s) = \dfrac{4K_c}{2} = 20 \Rightarrow K_c = 10$ ได้ $K_cG = \dfrac{40}{s(s+2)}$

- PM เดิม: $\omega_{gc} = 6.17$, PM = 18.0° น้อยเกินไป (step แกว่ง overshoot 60%)

- เฟสที่ต้องเติม: $50^\circ - 18^\circ + 6^\circ = 38^\circ$ C2

$$\alpha = \frac{1 - \sin38^\circ}{1 + \sin38^\circ} = \frac{0.384}{1.616} = 0.2375 \quad (\text{lead เพิ่มเกน } 10\log\tfrac{1}{0.2375} = 6.24 \text{ dB})$$

- หาความถี่ที่ $|K_cG| = -6.24$ dB: $\dfrac{40}{\omega\sqrt{\omega^2 + 4}} = 0.488 \Rightarrow \omega_m = 8.95$ rad/s

- $T = \dfrac{1}{8.95\sqrt{0.2375}} = 0.229$ · ศูนย์ $-4.36$ ขั้ว $-18.4$

$$G_c(s) = 10\,\frac{0.229s + 1}{0.0545s + 1} = {42.1\,\frac{s + 4.36}{s + 18.4}}$$

PM = 50.6° ที่ $\omega_{gc} = 8.95$ rad/s, GM = ∞ · overshoot ลดจาก 60% เหลือ 21.5% และ $t_s$ จาก 3.69 s เหลือ 0.62 s (เร็วขึ้น 6 เท่า) โดย $K_v = 20$ ตามสเปก

## ตัวชดเชยเฟสล้าหลัง (Lag) พื้นฐาน

ขั้วอยู่ใกล้จุดกำเนิดกว่าศูนย์ ไม่ได้ใช้เฟส (ซึ่งเป็นลบ) แต่ใช้เกนที่ลดลง $\beta$ เท่าที่ความถี่สูง หรือมองกลับกัน: เพิ่มเกน DC $\beta$ เท่าโดยไม่ไปแตะช่วงครอสโอเวอร์ ความผิดพลาดอยู่ตัวจึงลดลง $\beta$ เท่า

C4 Lag compensator ตัวชดเชยเฟสล้าหลัง

$$G_c(s) = K_c\frac{Ts + 1}{\beta Ts + 1} = \frac{K_c}{\beta}\cdot\frac{s + 1/T}{s + 1/(\beta T)}, \qquad \beta \gt 1$$

ที่ความถี่สูง เกนลดลง $\beta$ เท่า ($-20\log\beta$ dB) · วางศูนย์ $1/T \approx \omega_{gc}/10$ เพื่อให้เฟสล้าหลังที่ครอสโอเวอร์เหลือแค่ประมาณ 5°

C5 Lag design procedure (Bode) ขั้นตอนออกแบบ lag ด้วยโบด

- เลือก $K_c$ ให้ได้ค่าคงตัวความผิดพลาดตามสเปก

- หาความถี่ $\omega_{gc}'$ ที่เฟสของ $K_cG$ เท่ากับ $-180^\circ + \text{PM}_{\text{ต้องการ}} + (5^\circ\text{ ถึง }12^\circ)$

- $\beta = |K_cG(j\omega_{gc}')|$ (ลดให้เหลือ 0 dB ที่ความถี่นั้น)

- ศูนย์ $1/T = \omega_{gc}'/10$ · ขั้ว $1/(\beta T)$

## ออกแบบ Lag ด้วยโบด กลาง

ตัวอย่าง C-2 · Lag ด้วยโบด

### พลานต์ $G(s) = \dfrac{1}{s(s+1)(0.5s+1)}$ ต้องการ $K_v = 5\ \text{s}^{-1}$, PM ≥ 40°, GM ≥ 10 dB

- $K_v = K_c = 5$ · ปิดวงด้วยเกนนี้: GM = −4.4 dB, PM = −13° ไม่เสถียร (lead ไม่ช่วย เพราะเฟสลงเร็วมาก ต้องใช้ lag)

- ต้องการเฟส $-180^\circ + 40^\circ + 12^\circ = -128^\circ$: $-90^\circ - \tan^{-1}\omega - \tan^{-1}0.5\omega = -128^\circ \Rightarrow \omega_{gc}' = 0.465$ rad/s

- $|K_cG(j0.465)| = 9.5$ (19.6 dB) ได้ $\beta \approx 10$ C5

- ศูนย์ $\approx 0.465/10 \approx 0.05$ · ขั้ว $0.05/10 = 0.005$

$$G_c(s) = 5\,\frac{20s + 1}{200s + 1} = {0.5\,\frac{s + 0.05}{s + 0.005}}$$

## ออกแบบ Lead ด้วยรูทโลคัส: ชดเชยมุมที่ขาด กลาง

ถ้าสเปกให้มาเป็น $\zeta$ และ $\omega_n$ (หรือ $M_p$ และ $t_s$) จะได้จุดที่ต้องการ $s_d$ บนระนาบ $s$ ทันที ถ้ารูทโลคัสเดิมไม่ผ่าน $s_d$ แปลว่าเงื่อนไขมุมไม่ครบ 180° lead ต้องเติมมุมส่วนที่ขาด

C6 Angle deficiency มุมที่ตัวชดเชยต้องเติม

$$\phi_c = -180^\circ - \angle G(s_d), \qquad \angle(s_d + z_c) - \angle(s_d + p_c) = \phi_c, \qquad K = \frac{1}{|G_c(s_d)G(s_d)|}$$

มีศูนย์-ขั้วหลายคู่ที่ให้ $\phi_c$ เท่ากัน วิธีที่นิยม: (1) วางศูนย์ใต้ $s_d$ หรือหักล้างขั้วพลานต์ที่สองแล้วหาขั้ว (2) วิธีเส้นแบ่งครึ่งมุม (bisector) ของ Ogata ซึ่งให้ $\alpha$ ใหญ่ที่สุด

ตัวอย่าง C-3 · Lead ด้วยรูทโลคัส

### พลานต์ $G(s) = \dfrac{1}{s(s+2)}$ ต้องการขั้ววงปิดที่ $\zeta = 0.5,\ \omega_n = 4$ rad/s

- $s_d = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2} = -2 \pm j3.464$ · โลคัสเดิมเป็นเส้นดิ่ง $\sigma = -1$ ไม่ผ่าน

- มุมของพลานต์ที่ $s_d$: จาก 0 คือ $120^\circ$ จาก −2 คือ $90^\circ$ ได้ $\angle G = -210^\circ$ มุมที่ขาด $\phi_c = -180^\circ + 210^\circ = 30^\circ$ C6

- วางศูนย์หักล้างขั้ว −2 ของพลานต์ แล้วหาขั้ว $p_c$ ให้มุมรวมถูก: ต้องการ $-120^\circ - \theta_p = -180^\circ \Rightarrow \theta_p = 60^\circ$

$$p_c = -2 - \frac{3.464}{\tan60^\circ} = -4$$

- เกนจากเงื่อนไขขนาด: $L = \dfrac{K}{s(s+4)}$ ที่ $s_d$: $K = |s_d||s_d + 4| = 4 \times 4 = 16$

$G_c(s) = {16\,\dfrac{s + 2}{s + 4}}$ วงปิด $s^2 + 4s + 16$ ได้ $\zeta = 0.5,\ \omega_n = 4$ พอดี · overshoot 16.3%, $t_s = 2.0$ s · $K_v = 16/4 = 4$

python-control: ขั้ววงปิด $-2 \pm j3.464$ ✓ · การหักล้างขั้วใช้ได้เพราะขั้ว −2 เสถียร และแม้ค่าจริงจะคลาดเล็กน้อย คู่ขั้ว-ศูนย์ที่เหลือจะอยู่ใกล้กันจนแทบไม่มีผล

ตัวอย่าง C-4 · เติม Lag ให้แม่นขึ้น 5 เท่า

### จากผลของ C-3 ($K_v = 4$) ต้องการ $K_v = 20$ โดยขั้วเด่นแทบไม่เปลี่ยน

- ต้องเพิ่ม $K_v$ 5 เท่า: $\beta = 5$ C4

- วางคู่ศูนย์-ขั้วใกล้จุดกำเนิดมาก ๆ เทียบกับ $|s_d| = 4$: ศูนย์ −0.1 ขั้ว −0.02 (มุมที่เสียที่ $s_d$ ไม่ถึง 1.2°)

$$L(s) = \frac{16}{s(s+4)}\cdot\frac{s + 0.1}{s + 0.02}, \qquad K_v = \frac{16}{4}\cdot\frac{0.1}{0.02} = 20$$

ขั้ววงปิด $-1.96 \pm j3.44$ (แทบไม่ขยับ) และขั้วช้า $-0.102$ ที่เกือบหักล้างกับศูนย์ $-0.1$ · ความผิดพลาดต่อแรมป์ลดจาก 0.25 เหลือ 0.05

จำลอง: overshoot 18.9% (จาก 16.3%) และ $t_s$ (2%) 2.86 s เพราะหางช้าจากขั้ว −0.102 คือราคาของ lag ที่ต้องรู้

## Lag-Lead และความสัมพันธ์กับ PID กลาง

C7 Lag-lead and PID lag-lead กับ PID

$$G_c(s) = K_c\underbrace{\frac{T_1s + 1}{\beta T_1s + 1}}_{\text{lag}}\ \underbrace{\frac{T_2s + 1}{\alpha T_2s + 1}}_{\text{lead}}, \qquad \beta \to \infty,\ \alpha \to 0:\ \ \text{PID แบบอนุกรม}$$

ออกแบบทีละส่วน: lead ก่อนเพื่อเฟสมาร์จินและความเร็ว แล้ว lag เพื่อความแม่นยำ · lag ที่ขั้วอยู่ที่ 0 พอดีคือ PI · lead ที่ขั้วอยู่อนันต์คือ PD · ใช้ใน Type III compensator ของพาวเวอร์ซัพพลาย

| | Lead | Lag | Lag-lead / PID |

| แก้ปัญหา | overshoot มาก ช้า PM น้อย | ความผิดพลาดอยู่ตัว | ทั้งสองอย่าง |

| บนโบด | เติมเฟสที่ครอสโอเวอร์ ครอสโอเวอร์สูงขึ้น | ลดเกนความถี่สูง ครอสโอเวอร์ต่ำลง | รวมกัน |

| บนรูทโลคัส | ดึงโลคัสไปทางซ้าย | โลคัสเดิมแทบไม่เปลี่ยน | ดึงไปซ้าย + แม่นขึ้น |

| แบนด์วิดท์ | กว้างขึ้น (ไวต่อสัญญาณรบกวน) | แคบลง | ปรับได้ |

| เทียบเท่า | PD + ฟิลเตอร์ | PI (โดยประมาณ) | PID + ฟิลเตอร์ |

## สร้างจริง: วงจร RC และออปแอมป์ กลาง

C8 Op-amp lead/lag วงจรออปแอมป์ตัวเดียว ($Z_i = R_1 \parallel C_1$, $Z_f = R_2 \parallel C_2$)

$$\frac{V_o}{V_i} = -\frac{R_2}{R_1}\cdot\frac{R_1C_1s + 1}{R_2C_2s + 1} \qquad \begin{cases} R_1C_1 \gt R_2C_2 & \text{lead} \\ R_1C_1 \lt R_2C_2 & \text{lag} \end{cases}$$

$T = R_1C_1$, $\alpha T$ (หรือ $\beta T$) $= R_2C_2$ · เกน DC $= R_2/R_1$ · ต่อออปแอมป์อินเวอร์เตอร์อีกตัวเพื่อกลับเครื่องหมายและปรับเกน · ทดลองในแล็บออปแอมป์

C9 Passive RC lead network วงจร RC แบบพาสซีฟ

$$\frac{V_o}{V_i} = \alpha\,\frac{R_1Cs + 1}{\alpha R_1Cs + 1}, \qquad \alpha = \frac{R_2}{R_1 + R_2}$$

$R_1 \parallel C$ อนุกรม แล้ว $R_2$ ลงกราวด์ · ลดทอน $\alpha$ เท่า ต้องชดเชยด้วยแอมป์ · ต้องการโหลดอิมพีแดนซ์สูงตามหลัง

ตัวอย่าง C-5 · ทำ C-3 ด้วยออปแอมป์

### สร้าง $G_c(s) = 16\dfrac{s + 2}{s + 4} = 8\dfrac{0.5s + 1}{0.25s + 1}$ โดยใช้ $C_1 = C_2 = 10\ \mu\text{F}$

- $R_1C_1 = 0.5 \Rightarrow R_1 = 50\ \text{k}\Omega$ · $R_2C_2 = 0.25 \Rightarrow R_2 = 25\ \text{k}\Omega$ C8

- เกน DC ของวงจร $R_2/R_1 = 0.5$ ต้องการ 8 ใช้อินเวอร์เตอร์เกน $-16$ (เช่น $R_f = 160\ \text{k}\Omega,\ R_i = 10\ \text{k}\Omega$)

ออปแอมป์ตัวแรก $R_1 = 50$ k, $C_1 = 10$ µF, $R_2 = 25$ k, $C_2 = 10$ µF ตามด้วยอินเวอร์เตอร์เกน 16 ได้ $+16\dfrac{s+2}{s+4}$

## แล็บ: ก่อนและหลังชดเชย

เลือกรายการ “ก่อน” และ “หลัง” ของแต่ละตัวอย่างเทียบกัน ดู PM GM และผลตอบสนองขั้นบันไดเปลี่ยน ในมุมมองรูทโลคัสจะเห็น lead ดึงโลคัสไปทางซ้าย ส่วน lag แทบไม่เปลี่ยนรูป

## ข้อผิดพลาดที่พบบ่อย

- วาง $\omega_m$ ไว้ที่ครอสโอเวอร์เดิม → lead ยกเกนทำให้ครอสโอเวอร์ย้าย ต้องวางที่ครอสโอเวอร์ใหม่ (ขั้น 3 ของ C3)

- ลืมเฟสเผื่อ → ได้ PM ต่ำกว่าสเปกเล็กน้อยเสมอ

- ใช้ lead กับระบบที่เฟสลงเร็วมาก → เติมเฟสไม่ทัน (ตัวอย่าง C-2) ใช้ lag หรือ lag-lead

- วาง lag ใกล้ครอสโอเวอร์เกินไป → กินเฟสมาร์จิน วางศูนย์ต่ำกว่าอย่างน้อย 1 เดคาด

- สับสนเกนสองรูปแบบ → $K_c\frac{Ts+1}{\alpha Ts+1} = K_c\alpha\,\frac{s + 1/T}{s + 1/(\alpha T)}$ เกนหน้าวงเล็บต่างกัน $\alpha$ เท่า ตรวจด้วยเกน DC ทุกครั้ง

## ต่อยอดไปหน้าถัดไป

ตัวชดเชยที่นิยมที่สุดในอุตสาหกรรมคือPID ซึ่งก็คือ lag-lead ในอีกรูปหนึ่ง และเมื่อเข้าใจหน้านี้ ตัวชดเชย Type II และ Type III ของพาวเวอร์ซัพพลายก็คือ lead/lag ที่ใส่อินทิเกรเตอร์เพิ่ม ออกแบบด้วยขั้นตอนเดียวกันทุกประการ

## คำถามที่พบบ่อย

Lead กับ Lag ต่างกันอย่างไรสั้น ๆ?
Lead (ศูนย์อยู่ก่อนขั้ว) เพิ่มเฟสบวกใกล้ความถี่ครอสโอเวอร์ ทำให้เฟสมาร์จินดีขึ้นและตอบสนองเร็วขึ้น เหมาะกับการแก้ overshoot และความเร็ว Lag (ขั้วอยู่ก่อนศูนย์ ใกล้จุดกำเนิด) เพิ่มเกนความถี่ต่ำ ทำให้ความผิดพลาดอยู่ตัวลดลงโดยแทบไม่แตะช่วงครอสโอเวอร์ เหมาะกับการแก้ความแม่นยำ

ทำไมออกแบบ lead ต้องบวกเฟสเผื่อ 5–12°?
เพราะ lead เพิ่มเกนที่ความถี่สูงด้วย ทำให้ความถี่ครอสโอเวอร์ขยับไปทางขวา ซึ่งเฟสของพลานต์ที่ตำแหน่งใหม่ต่ำกว่าเดิม จึงต้องเผื่อเฟสไว้ชดเชยส่วนที่หายไปนี้ ถ้าคำนวณแล้ว PM ยังไม่ถึง ให้เพิ่มค่าเผื่อแล้วทำซ้ำ

Lead เพิ่มเฟสได้มากสุดเท่าไร?
ในทางทฤษฎีเกือบ 90° เมื่อ α เข้าใกล้ 0 แต่ในทางปฏิบัตินิยมไม่เกิน 60–65° ต่อหนึ่งตัว (α ≥ 0.07) เพราะ α เล็กมากทำให้เกนความถี่สูงเพิ่ม 1/α เท่า ขยายสัญญาณรบกวน ถ้าต้องการเฟสมากกว่านั้นใช้ lead สองตัวต่ออนุกรม

Lag ทำให้ระบบช้าลงไหม?
ช่วงต้นแทบไม่ แต่คู่ขั้ว-ศูนย์ใกล้จุดกำเนิดสร้างขั้ววงปิดช้าที่เกือบถูกหักล้างด้วยศูนย์ ทำให้ผลตอบสนองมีหางยาวค่อย ๆ เข้าที่ (slow tail) ยิ่งวางคู่นี้ใกล้จุดกำเนิดมาก หางยิ่งยาวแต่เล็กลง เป็นการแลกเปลี่ยนที่ต้องพิจารณา
