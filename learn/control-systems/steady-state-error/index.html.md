# ความผิดพลาดสถานะอยู่ตัว ชนิดของระบบ และการรบกวน

// บทที่ 13.5 · ระบบควบคุม · Steady-State Error


เมื่อผลตอบสนองชั่วครู่หายไปแล้ว เอาต์พุตตรงกับค่าอ้างอิงหรือไม่ เครื่อง CNC ต้องตามเส้นทางได้แม่นถึงไมครอน พาวเวอร์ซัพพลายต้องได้ 5.000 V ไม่ใช่ 4.95 V หน้านี้บอกว่าความแม่นยำขึ้นกับจำนวนอินทิเกรเตอร์ในลูปและเกนที่ความถี่ต่ำ และคำนวณได้ในบรรทัดเดียวด้วยทฤษฎีบทค่าสุดท้าย สูตรใช้รหัส E

สรุปใน 30 วินาที

- $e_{ss} = \lim_{s\to0}sE(s)$ ใช้ได้เมื่อวงปิดเสถียร

- ชนิด = จำนวนขั้วที่ $s = 0$ ของ $G(s)$ (ป้อนกลับหนึ่งหน่วย)

- ขั้นบันได: $\frac{1}{1 + K_p}$ · แรมป์: $\frac{1}{K_v}$ · พาราโบลา: $\frac{1}{K_a}$

- ชนิด N ติดตามอินพุต $t^{N-1}$ ได้ไม่มีผิด และ $t^N$ ผิดคงที่

## ทฤษฎีบทค่าสุดท้ายและชนิดของระบบ พื้นฐาน

E1 Steady-state error (unity feedback) ความผิดพลาดอยู่ตัว

$$E(s) = \frac{R(s)}{1 + G(s)}, \qquad e_{ss} = \lim_{t\to\infty}e(t) = \lim_{s\to0}\frac{sR(s)}{1 + G(s)}$$

ตรวจเสถียรภาพวงปิดก่อนทุกครั้ง · $G$ คือ $C \cdot$ พลานต์ ทั้งหมดในเส้นทางไปข้างหน้า

E2 System type ชนิดของระบบ

$$G(s) = \frac{K\prod(s + z_i)}{s^N\prod(s + p_j)} \quad\Rightarrow\quad \text{ชนิด } N$$

มอเตอร์ควบคุมตำแหน่งเป็นชนิด 1 อยู่แล้ว (ตำแหน่ง = อินทิกรัลของความเร็ว) · PI เพิ่มชนิดหนึ่งระดับ

E3 Static error constants ค่าคงตัวความผิดพลาดและตาราง

$$K_p = \lim_{s\to0}G(s), \quad K_v = \lim_{s\to0}sG(s), \quad K_a = \lim_{s\to0}s^2G(s)$$

$$\begin{array}{c|ccc} \text{อินพุต} & \text{ชนิด 0} & \text{ชนิด 1} & \text{ชนิด 2} \\ \hline u(t) & \frac{1}{1 + K_p} & 0 & 0 \\ t\,u(t) & \infty & \frac{1}{K_v} & 0 \\ \tfrac12t^2u(t) & \infty & \infty & \frac{1}{K_a} \end{array}$$

อินพุตขนาด $A$ คูณ $A$ เข้าไป · $K_v$ มีหน่วย s⁻¹ เช่น $K_v = 20$ แปลว่าตามแรมป์ 1 หน่วย/วินาที ช้ากว่า 0.05 หน่วย

ตัวอย่าง E-1 · ครบทุกอินพุต

### $G(s) = \dfrac{100(s+2)}{s(s+5)(s+10)}$ ป้อนกลับหนึ่งหน่วย หาความผิดพลาดต่อขั้นบันได แรมป์ และพาราโบลา

- ตรวจเสถียรภาพ: $s^3 + 15s^2 + 150s + 200$ สูตรลัด $15 \times 150 \gt 200$ ✓ เสถียร

- ชนิด 1 E2 · $K_v = \lim sG = \dfrac{100 \times 2}{5 \times 10} = 4$ E3

ขั้นบันได: 0 · แรมป์: $1/4 = 0.25$ · พาราโบลา: ∞

ตัวอย่าง E-2 · แม่นกับเสถียร ขัดกัน

### $G(s) = \dfrac{K}{s(s+2)(s+4)}$ ต้องการความผิดพลาดต่อแรมป์ ≤ 0.05 ทำได้ด้วยการปรับ $K$ หรือไม่

- $K_v = K/8 \ge 1/0.05 = 20 \Rightarrow K \ge 160$

- เสถียรภาพ: $s^3 + 6s^2 + 8s + K$ ต้อง $48 \gt K$ (R6)

ต้องการ $K \ge 160$ แต่เสถียรเมื่อ $K \lt 48$ เท่านั้น เป็นไปไม่ได้ด้วยเกนอย่างเดียว ต้องใช้ตัวชดเชย lag (เพิ่ม $K_v$ ที่ความถี่ต่ำ $\beta \ge 160/K$ เท่า) หรือ PI

## ความผิดพลาดจากการรบกวนและป้อนกลับไม่เป็นหนึ่งหน่วย กลาง

E4 Disturbance at the plant input การรบกวนที่อินพุตพลานต์

$$E_D(s) = -\frac{G_p(s)}{1 + C(s)G_p(s)}D(s), \qquad e_{ss,D} = -\lim_{s\to0}\frac{sG_pD}{1 + CG_p}$$

กำจัดการรบกวนขั้นบันไดได้เมื่อตัวควบคุมมีอินทิเกรเตอร์ (อินทิเกรเตอร์ในพลานต์ช่วยค่าอ้างอิง แต่ไม่ช่วยการรบกวนที่เข้าก่อนมัน)

E5 Non-unity feedback ป้อนกลับไม่เป็นหนึ่งหน่วย

$$e = r - y, \quad G_e = \frac{G}{1 + GH - G}$$

แปลงเป็นป้อนกลับหนึ่งหน่วยก่อน (B5) แล้วใช้ตาราง E3 กับ $G_e$

ตัวอย่าง E-3 · แรงบิดโหลดกับมอเตอร์

### พลานต์ความเร็ว $G_p = \dfrac{1}{s + 1}$ มีแรงบิดโหลดขั้นบันไดขนาด 1 ที่อินพุตพลานต์ เทียบ P ($K = 9$) กับ PI ($9 + 9/s$)

- P: $e_{ss,D} = -\dfrac{G_p(0)}{1 + 9G_p(0)} = -\dfrac{1}{10} = -0.1$ E4

- PI: $C(s) \to \infty$ ที่ $s \to 0$ ได้ $e_{ss,D} = 0$

P ปล่อยให้ความเร็วตก 10% ของผลกระทบ · PI กำจัดได้หมด นี่คือเหตุที่ไดรฟ์มอเตอร์ทุกตัวใช้ PI ในลูปความเร็ว (ลองในแล็บPID ที่มีการรบกวนครึ่งทาง)

## ข้อผิดพลาดที่พบบ่อย

- ใช้ทฤษฎีบทค่าสุดท้ายกับระบบไม่เสถียร → ได้ตัวเลขที่ไม่มีความหมาย

- นับชนิดจากอันดับ → ชนิดคือจำนวนขั้วที่ศูนย์เท่านั้น

- ใช้ตาราง E3 กับ H ≠ 1 → ต้องแปลงก่อน E5

- คิดว่าพลานต์ชนิด 1 ต้านการรบกวนได้ → ต้องมีอินทิเกรเตอร์ก่อนจุดที่การรบกวนเข้า E4

## ต่อยอดไปหน้าถัดไป

ทุกอย่างในหน้านี้ใช้ได้เมื่อระบบเสถียร คำถามแรกของวิศวกรควบคุมจึงอยู่ที่เสถียรภาพ และเครื่องมือที่เร็วที่สุดคือเราท์–เฮอร์วิตซ์

## คำถามที่พบบ่อย

ใช้ทฤษฎีบทค่าสุดท้ายได้ทุกครั้งไหม?
ไม่ได้ ใช้ได้เฉพาะเมื่อ sE(s) มีขั้วอยู่ฝั่งซ้ายทั้งหมด คือระบบวงปิดต้องเสถียรก่อน ถ้าวงปิดไม่เสถียร ความผิดพลาดไม่มีค่าสุดท้าย แต่สูตรจะยังให้ตัวเลขออกมาซึ่งไม่มีความหมาย จึงต้องตรวจเสถียรภาพด้วยเราท์ก่อนเสมอ

ชนิดของระบบ (type) นับอย่างไร?
นับจำนวนขั้วที่ s = 0 (อินทิเกรเตอร์บริสุทธิ์) ของฟังก์ชันวงเปิด G(s)H(s) ในระบบป้อนกลับหนึ่งหน่วย ไม่ใช่อันดับของระบบ เช่น K/(s(s+1)(s+2)) เป็นอันดับสาม แต่ชนิด 1

ทำไมเพิ่มเกนเพื่อลดความผิดพลาดแล้วระบบแกว่ง?
เพราะเกนที่สูงขึ้นทั้งลดความผิดพลาดอยู่ตัวและผลักขั้ววงปิดเข้าหาแกน jω (ดูรูทโลคัส) ถึงจุดหนึ่งก็ไม่เสถียร ทางออกคือตัวชดเชย lag หรือ PI ที่เพิ่มเกนเฉพาะความถี่ต่ำ โดยไม่แตะช่วงความถี่ที่กำหนดเสถียรภาพ
