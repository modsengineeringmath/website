วาดโบดได้แล้ว คำถามสำคัญคือ “ปิดวงแล้วจะเสถียรไหม และเหลือที่ว่างเท่าไร” ซึ่งอ่านได้ทันทีจากโบดของวงเปิด ไปต่อที่เกนมาร์จินและเฟสมาร์จิน

คำถามที่พบบ่อย

ทำไมโบดไดอะแกรมใช้สเกลลอการิทึม?

เพราะลอการิทึมเปลี่ยนการคูณเป็นการบวก ฟังก์ชันถ่ายโอนที่เป็นผลคูณของหลายปัจจัย จึงวาดได้โดยวาดแต่ละปัจจัยแล้วบวกกราฟ และปัจจัยแต่ละตัวกลายเป็นเส้นตรงบนแกน log ω ทำให้วาดด้วยไม้บรรทัดได้ อีกทั้งยังดูช่วงความถี่กว้างหลายเดคาดได้ในรูปเดียว

เส้นกำกับคลาดจากกราฟจริงมากที่สุดเท่าไร?

ขั้วหรือศูนย์จริงอันดับหนึ่งคลาดมากที่สุด 3 dB ที่จุดมุม (และ 1 dB ที่ครึ่งเท่าและสองเท่าของจุดมุม) ส่วนเฟสคลาดไม่เกินประมาณ 6° สำหรับอันดับสองความคลาดเคลื่อนขึ้นกับ ζ ที่จุดมุมเท่ากับ −20 log(2ζ) dB ซึ่ง ζ น้อยจะมียอดสูงมาก ต้องแก้ด้วยมือ

จะรู้ได้อย่างไรว่าเส้นเริ่มที่ระดับไหน?

เขียนฟังก์ชันในรูปมาตรฐาน Kb (1 + s/z)… / [s^q (1 + s/p)…] เส้นความถี่ต่ำคือ 20 log Kb − 20q log ω ซึ่งผ่านจุด (ω = 1, 20 log Kb) เสมอ ความชัน −20q dB/เดคาด และเฟสเริ่มที่ −90q องศา

Bode ต่างจาก Nyquist อย่างไร?

เป็นข้อมูลเดียวกัน G(jω) แต่แสดงคนละแบบ Bode แยกขนาดและเฟสเป็นสองกราฟเทียบกับความถี่ วาดและออกแบบง่าย Nyquist วาดเป็นเส้นโค้งเดียวบนระนาบเชิงซ้อน ใช้ตัดสินเสถียรภาพได้ทุกกรณีรวมถึงพลานต์ไม่เสถียรวงเปิด
