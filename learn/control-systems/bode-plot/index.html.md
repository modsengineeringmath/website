# โบดไดอะแกรม (Bode Plot): วาดด้วยมือทีละขั้น

// บทที่ 13.12 · ระบบควบคุม · Bode Plot


เฮนดริก โบด (Hendrik W. Bode) แห่ง Bell Labs คิดวิธีนี้ในทศวรรษ 1930 เพื่อออกแบบแอมป์ป้อนกลับของระบบโทรศัพท์ทางไกล ความฉลาดคือใช้สเกลลอการิทึม ทำให้ฟังก์ชันถ่ายโอนที่ซับซ้อนกลายเป็นผลบวกของเส้นตรงไม่กี่เส้น วาดได้ด้วยไม้บรรทัด จนทุกวันนี้ datasheet ของออปแอมป์ ไอซีพาวเวอร์ซัพพลาย และไดรฟ์มอเตอร์ยังพูดภาษานี้ หน้านี้สอนวาดให้คล่องจนอ่านกราฟเป็นฟังก์ชันได้ทั้งไปและกลับ สูตรใช้รหัส D

สรุปใน 30 วินาที

- ขนาดเป็น dB: $20\log_{10}|G(j\omega)|$ · แกนนอนเป็น $\log\omega$ · ผลคูณกลายเป็นผลบวก

- เขียนรูปมาตรฐาน $K_b\dfrac{\prod(1 + s/z_i)}{s^q\prod(1 + s/p_j)}$ เริ่มที่ความชัน $-20q$ dB/เดคาด ผ่าน $(1,\ 20\log K_b)$

- ผ่านจุดมุมของขั้ว ความชันลด 20 · ศูนย์ ความชันเพิ่ม 20 · อันดับสอง ±40 พร้อมยอดเรโซแนนซ์

- เฟสของปัจจัยอันดับหนึ่งเปลี่ยน ±90° ใน 2 เดคาด (45° ที่จุดมุม) · หน่วงเวลา $-\omega T$ rad ไม่มีขีดจำกัด

ระดับพื้นฐาน เริ่มเรียนกลาง ป.ตรี วิศวกรรมขั้นสูง งานออกแบบ

## เดซิเบลและเดคาด: ภาษาของโบด พื้นฐาน

โบดไดอะแกรมคือกราฟสองรูปของผลตอบสนองความถี่ $G(j\omega)$: ขนาด (dB) และเฟส (องศา) เทียบกับความถี่บนสเกล log วิศวกรไฟฟ้าคุ้นอยู่แล้วจากการวัดฟิลเตอร์ด้วยฟังก์ชันเจเนอเรเตอร์และสโคป

D1 Decibel, decade, octave เดซิเบล เดคาด และออกเทฟ

$$|G|_{\text{dB}} = 20\log_{10}|G(j\omega)|, \qquad \text{เดคาด: } \omega \to 10\omega, \qquad \text{ออกเทฟ: } \omega \to 2\omega$$

ค่าที่ควรจำ: ×10 = 20 dB · ×2 = 6 dB · ×√2 = 3 dB · ×1 = 0 dB · ×0.707 = −3 dB · ×0.1 = −20 dB · −20 dB/เดคาด = −6 dB/ออกเทฟ

D2 Bode (time-constant) form รูปมาตรฐานสำหรับวาดโบด

$$G(s) = K_b\,\frac{(1 + s/z_1)(1 + s/z_2)\cdots}{s^q(1 + s/p_1)(1 + s/p_2)\cdots\left(1 + 2\zeta\frac{s}{\omega_n} + \frac{s^2}{\omega_n^2}\right)\cdots}$$

ดึงค่าคงที่ออกให้ทุกวงเล็บเริ่มด้วย 1 · $K_b$ คือเกน “Bode gain” · $q$ = จำนวนอินทิเกรเตอร์ ($q \lt 0$ คือตัวอนุพันธ์) · จุดมุม (corner, break frequency) คือ $z_i, p_j, \omega_n$

## ปัจจัยพื้นฐาน 5 แบบ พื้นฐาน

ทุกฟังก์ชันถ่ายโอนประกอบจากปัจจัยไม่กี่แบบนี้ วาดแต่ละตัวเป็นเส้นตรงแล้วบวกกัน

D3 Constant K ค่าคงที่

$$20\log|K| \text{ (เส้นราบ)}, \quad \angle K = 0^\circ \ (K \gt 0) \ \text{หรือ} \ \pm180^\circ \ (K \lt 0)$$

เปลี่ยน $K$ = เลื่อนกราฟขนาดขึ้นลงทั้งเส้น เฟสไม่เปลี่ยน

D4 Poles/zeros at the origin $s^{\mp q}$

$$\frac{1}{s^q}:\ -20q\log\omega \ \text{dB}, \ \ -90q^\circ$$

เส้นตรงผ่าน 0 dB ที่ $\omega = 1$ ความชัน $-20q$ dB/เดคาดตลอดย่าน · ตัวอนุพันธ์ $s$ เป็นภาพกลับ: +20 dB/เดคาด, +90°

D5 First-order pole $1/(1 + s/p)$ ขั้วจริงอันดับหนึ่ง (ศูนย์: กลับเครื่องหมายทุกอย่าง)

$$|\cdot|_{\text{dB}} \approx \begin{cases} 0 & \omega \ll p \\ -20\log(\omega/p) & \omega \gg p \end{cases}, \qquad \angle = -\tan^{-1}\frac{\omega}{p} \approx \begin{cases} 0^\circ & \omega \le p/10 \\ -45^\circ & \omega = p \\ -90^\circ & \omega \ge 10p \end{cases}$$

ค่าแก้ของขนาด: −3 dB ที่ $\omega = p$ · −1 dB ที่ $p/2$ และ $2p$ · เฟสเส้นตรงลาดลง 45°/เดคาด จาก $p/10$ ถึง $10p$ (คลาดไม่เกิน 5.7°) · ศูนย์ฝั่งขวา $(1 - s/z)$: ขนาดเหมือนศูนย์ปกติ แต่เฟสลงเหมือนขั้ว

D6 Second-order poles ขั้วเชิงซ้อนคู่ $\dfrac{1}{1 + 2\zeta s/\omega_n + s^2/\omega_n^2}$

$$\text{ชัน } -40 \text{ dB/เดคาด หลัง } \omega_n, \quad \text{ที่ } \omega_n:\ -20\log(2\zeta) \ \text{dB},\ -90^\circ, \quad M_r = \frac{1}{2\zeta\sqrt{1 - \zeta^2}} \text{ ที่ } \omega_r = \omega_n\sqrt{1 - 2\zeta^2}$$

มียอดเรโซแนนซ์เมื่อ $\zeta \lt 0.707$ · เฟสเปลี่ยน 180° ชันขึ้นเมื่อ $\zeta$ เล็ก (ช่วงประมาณ $\omega_n/10^{\zeta}$ ถึง $\omega_n \cdot 10^{\zeta}$) · ดูภาพ ζ ต่าง ๆ ในหน้าระบบอันดับสอง

D7 Time delay $e^{-sT}$ หน่วงเวลา

$$|e^{-j\omega T}| = 1 \ (0 \text{ dB}), \qquad \angle e^{-j\omega T} = -\omega T \ \text{rad} = -57.3\,\omega T \ \text{องศา}$$

ไม่เปลี่ยนขนาดเลย แต่เฟสลดลงไม่มีขีดจำกัด (บนแกน log ดูเหมือนดิ่งลงเร็วขึ้นเรื่อย ๆ) · เป็นศัตรูตัวฉกาจของเฟสมาร์จิน: พบในระบบความร้อน สายพาน การสื่อสาร และการหน่วงจากการคำนวณของไมโครคอนโทรลเลอร์ (ครึ่งคาบสุ่มของ ZOH)

## ขั้นตอนการวาดโบดด้วยมือ พื้นฐาน

D8 Sketching procedure ขั้นตอนการวาด

- เขียนรูปมาตรฐาน D2 หา $K_b$, $q$ และเรียงจุดมุมจากน้อยไปมาก

- เส้นความถี่ต่ำ: $20\log K_b - 20q\log\omega$ (ผ่านจุด $\omega = 1$ ที่ระดับ $20\log K_b$) ลากจากซ้ายสุดถึงจุดมุมแรก

- ผ่านจุดมุมแต่ละจุด เปลี่ยนความชัน: ขั้ว −20, ศูนย์ +20, คู่เชิงซ้อน ±40 dB/เดคาด

- แก้ค่าที่จุดมุม (−3 dB ต่อขั้วจริง, ยอดเรโซแนนซ์ของคู่เชิงซ้อน) แล้วลากโค้งนุ่ม

- เฟส: เริ่ม $-90q^\circ$ (บวก −180° ถ้า $K_b \lt 0$) แต่ละปัจจัยค่อย ๆ เพิ่ม/ลด 90° (180° สำหรับคู่เชิงซ้อน) ตลอด 2 เดคาดรอบจุดมุม รวมกันทีละช่วง

- ตรวจ: ปลายความถี่สูงต้องชัน $-20(n - m)$ dB/เดคาด เฟสต้องจบที่ $-90(n - m)^\circ$ (ระบบ minimum phase ไม่มีหน่วงเวลา)

ตัวอย่าง D-1 · ขั้วจริงสองตัว

### วาดโบดของ $G(s) = \dfrac{100}{(s+1)(s+10)}$

- รูปมาตรฐาน: $G(s) = \dfrac{100}{10}\cdot\dfrac{1}{(1 + s)(1 + s/10)} \Rightarrow K_b = 10$ ($20$ dB), $q = 0$, จุดมุม 1 และ 10 D2

- ขนาด: ราบที่ 20 dB จนถึง $\omega = 1$ · ชัน −20 dB/เดคาด จาก 1 ถึง 10 (ที่ $\omega = 10$ ลงไปเหลือ 0 dB) · ชัน −40 dB/เดคาดหลัง 10

- ค่าจริงที่จุดมุม: $\omega = 1$: $20 - 3 - 0.04 = 16.96$ dB · $\omega = 10$: $0 - 3 - 0.04 = -3.05$ dB D5

- เฟส: $-\tan^{-1}\omega - \tan^{-1}(\omega/10)$ เริ่ม 0° จบ −180° ที่ $\omega = 1$: $-45^\circ - 5.7^\circ = -50.7^\circ$ · ที่ $\omega = 10$: $-84.3^\circ - 45^\circ = -129.3^\circ$

เส้นทึบคือกราฟจริง เส้นประคือเส้นกำกับที่วาดด้วยมือ

python-control: $|G(j1)| = 16.95$ dB, $\angle G(j1) = -50.7^\circ$ · $|G(j10)| = -3.05$ dB, $\angle = -129.3^\circ$ ✓

ตัวอย่าง D-2 · อินทิเกรเตอร์ + ศูนย์ + ขั้ว

### วาดโบดของ $G(s) = \dfrac{10(s+1)}{s(s+10)}$

- $G = \dfrac{10 \cdot 1}{10}\cdot\dfrac{(1 + s)}{s(1 + s/10)} \Rightarrow K_b = 1$ (0 dB), $q = 1$

- เส้นความถี่ต่ำ: $-20\log\omega$ ผ่าน 0 dB ที่ $\omega = 1$ ชัน −20 D4

- $\omega = 1$ ศูนย์: ความชันเพิ่ม 20 กลายเป็น 0 (ราบที่ 0 dB) · $\omega = 10$ ขั้ว: กลับเป็น −20

- เฟส: เริ่ม −90° ศูนย์ดันขึ้น ขั้วดึงลง สูงสุดที่ค่าเฉลี่ยเรขาคณิต $\sqrt{1 \cdot 10} = 3.16$: $-90^\circ + 72.5^\circ - 17.5^\circ = -35.1^\circ$ แล้วกลับไป −90°

รูปนี้คือตัวชดเชย lead + อินทิเกรเตอร์: ศูนย์มาก่อนขั้ว ยกเฟสขึ้น “เป็นเนิน” ที่ $\omega = 3.16$ นี่คือวิธีที่ตัวชดเชย Type II ของพาวเวอร์ซัพพลายเพิ่มเฟสมาร์จิน

$|G(j3.16)| = 0.00$ dB และ $\angle = -35.1^\circ$ ✓

## ขั้วเชิงซ้อน: ยอดเรโซแนนซ์ที่เส้นกำกับมองไม่เห็น กลาง

ตัวอย่าง D-3 · ζ = 0.2

### วาดโบดของ $G(s) = \dfrac{1}{s^2 + 0.4s + 1}$ (เช่น วงจร LC ที่หน่วงน้อย หรือแขนกลที่ข้อต่อยืดหยุ่น)

- $\omega_n = 1$, $2\zeta\omega_n = 0.4 \Rightarrow \zeta = 0.2$, $K_b = 1$

- เส้นกำกับ: 0 dB ถึง $\omega = 1$ แล้วชัน −40 dB/เดคาด D6

- ที่ $\omega_n$: $-20\log(2 \times 0.2) = +7.96$ dB เหนือเส้นกำกับ · ยอดจริง $M_r = \dfrac{1}{2(0.2)\sqrt{0.96}} = 2.55$ (8.14 dB) ที่ $\omega_r = \sqrt{1 - 0.08} = 0.959$

- เฟส: 0° → −180° ผ่าน −90° ที่ $\omega = 1$ เปลี่ยนเร็วมากในช่วงแคบ ($\zeta$ เล็ก)

เส้นกำกับคลาดไปถึง 8 dB ตรงจุดมุม ห้ามลืมแก้ เพราะยอดนี้คือสิ่งที่ทำให้ระบบหุ่นยนต์และ LC ฟิลเตอร์ของพาวเวอร์ซัพพลาย “ร้อง” และเป็นจุดที่ GM หายได้

## กลับทาง: หาฟังก์ชันถ่ายโอนจากกราฟโบด กลาง

งานจริงมักวัดผลตอบสนองความถี่ของพลานต์ได้ (ด้วยสโคปหรือ network analyzer) แต่ไม่รู้สมการ อ่านเส้นกำกับย้อนกลับก็ได้แบบจำลอง เทคนิคเรียกว่า system identification แบบกราฟ

D9 Reading G(s) from asymptotes อ่านฟังก์ชันจากเส้นกำกับ

$$\text{ชันเริ่มต้น} = -20q \Rightarrow q, \qquad K_b = 10^{\,|G(j1)|_{\text{dB, asym}}/20}, \qquad \Delta\text{ชัน} = \mp20k \text{ ที่ } \omega_c \Rightarrow (1 + s/\omega_c)^{\pm k}$$

ถ้าเส้นความถี่ต่ำไม่ได้ลากถึง $\omega = 1$ ให้ต่อเส้นออกไปจนถึง · เฟสใช้ยืนยันว่าเป็นขั้ว/ศูนย์ฝั่งซ้ายหรือขวา และตรวจหน่วงเวลา (เฟสลดมากกว่าที่ขนาดบอก)

ตัวอย่าง D-4 · อ่านกราฟย้อนกลับ

### เส้นกำกับขนาดชัน −20 dB/เดคาดผ่าน 20 dB ที่ $\omega = 1$ เปลี่ยนเป็น −40 ที่ $\omega = 5$ และ −60 ที่ $\omega = 50$ จงหา $G(s)$

- ชันเริ่ม −20: $q = 1$ · ที่ $\omega = 1$ ระดับ 20 dB: $K_b = 10$ D9

- ที่ 5 และ 50 ความชันลดทีละ 20: เป็นขั้วอันดับหนึ่ง

$$G(s) = \frac{10}{s(1 + s/5)(1 + s/50)} = \frac{10 \cdot 5 \cdot 50}{s(s + 5)(s + 50)} = {\frac{2500}{s(s + 5)(s + 50)}}$$

$|G(j1)| = 19.83$ dB (เส้นจริงต่ำกว่าเส้นกำกับเล็กน้อยเพราะขั้วที่ 5) ✓ · ปิดวงหนึ่งหน่วยได้ GM = 14.8 dB, PM = 31.7° (ดูหน้ามาร์จิน)

## หน่วงเวลาและศูนย์ฝั่งขวา: เฟสที่ขนาดไม่บอก ขั้นสูง

ระบบ minimum phase (ขั้วและศูนย์อยู่ฝั่งซ้ายทั้งหมด ไม่มีหน่วงเวลา) มีความสัมพันธ์แบบหนึ่งต่อหนึ่งระหว่างขนาดกับเฟส (ทฤษฎีบทขนาด-เฟสของโบด: ชัน −20k dB/เดคาดยาว ๆ คู่กับเฟสประมาณ −90k°) แต่หน่วงเวลาและศูนย์ฝั่งขวาเพิ่มเฟสล่าช้าโดยไม่เปลี่ยนขนาดเลย ทำให้ออกแบบยากกว่ามาก

ตัวอย่าง D-5 · หน่วงเวลา

### ฮีตเตอร์ $G(s) = \dfrac{e^{-0.1s}}{s + 1}$ มีเฟสเท่าไรที่ $\omega = 1$ และ $\omega = 10$ rad/s

- ขนาดเหมือน $\frac{1}{s + 1}$ ทุกประการ D7

- $\omega = 1$: $-45^\circ - 57.3(0.1)(1) = -45^\circ - 5.7^\circ = -50.7^\circ$

- $\omega = 10$: $-84.3^\circ - 57.3^\circ = -141.6^\circ$

ที่ความถี่สูงขึ้น หน่วงเวลากินเฟสมากขึ้นแบบเชิงเส้น ถ้าจะปิดวงให้ครอสโอเวอร์ที่ 10 rad/s จะเหลือเฟสมาร์จินแค่ 38° แม้พลานต์จะเป็นแค่อันดับหนึ่ง กฎหัวแม่มือ: เลือก $\omega_{gc} \lt 1/T$

## แล็บโบด: เทียบเส้นกำกับกับกราฟจริง

เส้นประคือเส้นกำกับที่ควรวาดได้ด้วยมือ เส้นทึบคือกราฟจริง ชี้เมาส์บนกราฟเพื่ออ่านค่าที่ความถี่ใด ๆ เลื่อน $K$ ดูขนาดเลื่อนขึ้นลงทั้งเส้นโดยเฟสไม่เปลี่ยน ลองพิมพ์ $e^{-0.1s}/(s+1)$ หรือ $(1-s)/(1+s)$ เพื่อดูเฟสที่ขนาดไม่บอก

## ข้อผิดพลาดที่พบบ่อย

- ไม่แปลงเป็นรูปมาตรฐาน → $\frac{100}{(s+1)(s+10)}$ เริ่มที่ 20 dB ไม่ใช่ 40 dB D2

- ใช้ 10 log แทน 20 log → 10 log ใช้กับกำลัง ฟังก์ชันถ่ายโอนแรงดัน/กระแส/ตำแหน่งใช้ 20 log

- เฟสเปลี่ยนทันทีที่จุดมุม → เฟสค่อย ๆ เปลี่ยนตลอด 2 เดคาด ($\omega_c/10$ ถึง $10\omega_c$)

- ลืมยอดเรโซแนนซ์ → อันดับสองที่ $\zeta$ เล็ก ต้องแก้ $-20\log 2\zeta$ D6

- ใช้ Hz ปนกับ rad/s → จุดมุมของ $1 + s/p$ อยู่ที่ $p$ rad/s = $p/2\pi$ Hz datasheet ส่วนใหญ่ใช้ Hz

## ต่อยอดไปหน้าถัดไป

วาดโบดได้แล้ว คำถามสำคัญคือ “ปิดวงแล้วจะเสถียรไหม และเหลือที่ว่างเท่าไร” ซึ่งอ่านได้ทันทีจากโบดของวงเปิด ไปต่อที่เกนมาร์จินและเฟสมาร์จิน

## คำถามที่พบบ่อย

ทำไมโบดไดอะแกรมใช้สเกลลอการิทึม?
เพราะลอการิทึมเปลี่ยนการคูณเป็นการบวก ฟังก์ชันถ่ายโอนที่เป็นผลคูณของหลายปัจจัย จึงวาดได้โดยวาดแต่ละปัจจัยแล้วบวกกราฟ และปัจจัยแต่ละตัวกลายเป็นเส้นตรงบนแกน log ω ทำให้วาดด้วยไม้บรรทัดได้ อีกทั้งยังดูช่วงความถี่กว้างหลายเดคาดได้ในรูปเดียว

เส้นกำกับคลาดจากกราฟจริงมากที่สุดเท่าไร?
ขั้วหรือศูนย์จริงอันดับหนึ่งคลาดมากที่สุด 3 dB ที่จุดมุม (และ 1 dB ที่ครึ่งเท่าและสองเท่าของจุดมุม) ส่วนเฟสคลาดไม่เกินประมาณ 6° สำหรับอันดับสองความคลาดเคลื่อนขึ้นกับ ζ ที่จุดมุมเท่ากับ −20 log(2ζ) dB ซึ่ง ζ น้อยจะมียอดสูงมาก ต้องแก้ด้วยมือ

จะรู้ได้อย่างไรว่าเส้นเริ่มที่ระดับไหน?
เขียนฟังก์ชันในรูปมาตรฐาน Kb (1 + s/z)… / [s^q (1 + s/p)…] เส้นความถี่ต่ำคือ 20 log Kb − 20q log ω ซึ่งผ่านจุด (ω = 1, 20 log Kb) เสมอ ความชัน −20q dB/เดคาด และเฟสเริ่มที่ −90q องศา

Bode ต่างจาก Nyquist อย่างไร?
เป็นข้อมูลเดียวกัน G(jω) แต่แสดงคนละแบบ Bode แยกขนาดและเฟสเป็นสองกราฟเทียบกับความถี่ วาดและออกแบบง่าย Nyquist วาดเป็นเส้นโค้งเดียวบนระนาบเชิงซ้อน ใช้ตัดสินเสถียรภาพได้ทุกกรณีรวมถึงพลานต์ไม่เสถียรวงเปิด
