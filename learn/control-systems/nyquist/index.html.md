# เกณฑ์เสถียรภาพของไนควิสต์ (Nyquist Criterion)

// บทที่ 13.14 · ระบบควบคุม · Nyquist Stability Criterion


แฮร์รี ไนควิสต์ (Harry Nyquist, Bell Labs, 1932) ตอบคำถามที่โบดตอบได้ไม่ครบ: ถ้าวงเปิดไม่เสถียร หรือกราฟตัด 0 dB หลายครั้ง จะรู้ได้อย่างไรว่าวงปิดเสถียร คำตอบคือนับจำนวนรอบที่กราฟ $L(j\omega)$ อ้อมจุด −1 สูตรเดียว $Z = N + P$ ใช้ได้กับระบบเชิงเส้นทุกแบบ รวมหน่วงเวลา สูตรใช้รหัส N

สรุปใน 30 วินาที

- วาด $L(j\omega)$ บนระนาบเชิงซ้อน ω จาก −∞ ถึง ∞ (ครึ่งล่างคือภาพสะท้อน)

- $N$ = จำนวนรอบตามเข็มที่อ้อม −1 · $P$ = ขั้วฝั่งขวาของวงเปิด

- $Z = N + P$ = ขั้ววงปิดฝั่งขวา · เสถียร $\iff Z = 0$

- วงเปิดเสถียร: ห้ามอ้อม −1 · GM จากจุดตัดแกนจริงลบ · PM จากจุดตัดวงกลมหนึ่งหน่วย

## แนวคิด: ทฤษฎีบทอาร์กิวเมนต์ กลาง

ลากจุด $s$ วนรอบเส้นทางปิดตามเข็มนาฬิกา แล้วดูเวกเตอร์ $s - p$ จากขั้วหรือศูนย์ $p$ ถ้า $p$ อยู่ในเส้นทาง เวกเตอร์หมุนครบ 360° หนึ่งรอบ ถ้าอยู่นอกจะส่ายไปมาแล้วกลับที่เดิม (หมุนสุทธิ 0) ฟังก์ชัน $F(s) = 1 + L(s)$ จึงหมุนรอบจุดกำเนิดเท่ากับ (ศูนย์ภายใน − ขั้วภายใน) รอบ

N1 Argument principle ทฤษฎีบทอาร์กิวเมนต์ (โคชี)

$$\#\text{รอบตามเข็มของ } F(s) \text{ รอบ } 0 = Z_F - P_F \quad (\text{ศูนย์และขั้วของ } F \text{ ภายในเส้นทาง})$$

เลือก $F = 1 + L$: ศูนย์ของ $F$ = ขั้ววงปิด, ขั้วของ $F$ = ขั้ววงเปิด · $F$ รอบ 0 ↔ $L$ รอบ −1

N2 Nyquist contour เส้นทางไนควิสต์

$$s:\ j0 \to j\infty \ \to\ \text{ครึ่งวงกลมรัศมี } \infty \text{ (ฝั่งขวา)} \ \to\ -j\infty \to j0$$

ครอบคลุมฝั่งขวาทั้งหมด · ระบบ proper: ครึ่งวงกลมใหญ่ส่งไปจุดเดียว (0 หรือค่าคงที่) · ขั้วบนแกน $j\omega$ อ้อมด้วยครึ่งวงกลมเล็กรัศมี $\varepsilon$ ทางขวา N4

N3 Nyquist stability criterion เกณฑ์ไนควิสต์

$$Z = N + P, \qquad \text{วงปิดเสถียร} \iff Z = 0 \iff N = -P$$

$N$ = รอบตามเข็มที่ $L(j\omega)$ อ้อม −1 (ทวนเข็มนับลบ) · $P$ = ขั้วฝั่งขวาของ $L$ · วงเปิดไม่เสถียร $P$ ตัว ต้องอ้อม −1 ทวนเข็ม $P$ รอบพอดี · ถ้า $L$ ผ่านจุด −1 พอดี: ขั้ววงปิดอยู่บนแกน $j\omega$

## วาดกราฟไนควิสต์ทีละขั้น กลาง

N4 Sketching procedure ขั้นตอนวาด

- $\omega \to 0^+$: จากโบด ขนาดและเฟสเริ่มต้น (ระบบชนิด $q$: ขนาด → ∞ ที่มุม $-90q^\circ$)

- $\omega \to \infty$: ขนาด → 0 เข้าหาจุดกำเนิดที่มุม $-90(n - m)^\circ$

- จุดตัดแกนจริง: ตั้ง $\operatorname{Im}L(j\omega) = 0$ (หรือเฟส = −180°) จุดตัดวงกลมหนึ่งหน่วย: $|L| = 1$

- สะท้อนครึ่งบน/ล่างรอบแกนจริงเพื่อได้ส่วน ω ลบ

- ขั้ว $q$ ตัวที่จุดกำเนิด: ปิดกราฟด้วยส่วนโค้งรัศมีอนันต์ หมุนตามเข็ม $q \times 180^\circ$ จากปลาย $\omega = 0^-$ ไป $\omega = 0^+$

- นับ $N$ แล้วใช้ $Z = N + P$

ตัวอย่าง N-1 · ระบบเดิมของเรา

### ใช้ไนควิสต์ตรวจ $L(s) = \dfrac{K}{s(s+1)(s+2)}$ ที่ $K = 2$ และ $K = 10$

- $P = 0$ · $\omega \to 0^+$: ขนาด ∞ มุม −90° (ลงมาจากด้านล่างซ้าย ส่วนจริงเข้าหา $-3K/4$) · $\omega \to \infty$: เข้าจุดกำเนิดที่ −270°

- ตัดแกนจริงที่ $\omega = \sqrt2$: $L(j\sqrt2) = -K/6$ N4

- $K = 2$: ตัดที่ $-1/3$ อยู่ขวาของ −1 → ไม่อ้อม $N = 0$ → $Z = 0$ เสถียร · GM $= 1/(1/3) = 3$

- $K = 10$: ตัดที่ $-5/3$ อยู่ซ้ายของ −1 → อ้อมตามเข็ม 2 รอบ $N = 2$ → $Z = 2$ N3

$K = 2$: ไม่อ้อม −1 (เส้นประคือส่วน ω ลบ) · วงกลมม่วงคือ $|L| = 1$

$K = 10$: อ้อม −1 สองรอบ วงปิดมีขั้วฝั่งขวา 2 ตัว

สอดคล้องกับเราท์ ($K \lt 6$) และรูทโลคัส ✓ · python-control นับ $N = 0$ และ $N = 2$ ✓

## วงเปิดไม่เสถียร: ต้องอ้อมทวนเข็ม กลาง

ตัวอย่าง N-2 · พลานต์ไม่เสถียร

### $L(s) = \dfrac{K}{s - 1}$ เสถียรเมื่อ $K$ เท่าไร (ตรวจด้วยไนควิสต์)

- $P = 1$ (ขั้วที่ +1) · $L(j\omega) = \dfrac{K}{j\omega - 1} = \dfrac{-K(1 + j\omega)}{1 + \omega^2}$

- $\omega = 0$: $-K$ · $\omega \to \infty$: 0 จากด้านล่าง (มุม −90°) · เป็นวงกลมศูนย์กลาง $-K/2$ รัศมี $K/2$

- $K \gt 1$: วงกลมครอบ −1 อ้อมทวนเข็ม 1 รอบ $N = -1$ → $Z = -1 + 1 = 0$ เสถียร · $K \lt 1$: ไม่ครอบ $N = 0$ → $Z = 1$ ไม่เสถียร

เสถียรเมื่อ $K \gt 1$ ตรงกับตัวอย่าง S-2 · กรณีนี้ถ้าอ่าน GM จากโบดแบบปกติจะได้คำตอบผิด เพราะเกณฑ์โบดใช้เฉพาะวงเปิดเสถียร

## มาร์จินบนกราฟไนควิสต์ กลาง

N5 Margins on the Nyquist plot มาร์จินบนไนควิสต์

$$\text{GM} = \frac{1}{|a|}\ (\text{จุดตัดแกนจริงลบที่ } -a), \qquad \text{PM} = \angle\text{ระหว่างจุดตัดวงกลม } |L| = 1 \text{ กับแกนจริงลบ}, \qquad s_m = \min_\omega|1 + L(j\omega)| = \frac{1}{M_s}$$

$s_m$ (modulus margin) คือระยะใกล้สุดถึง −1 ในทุกทิศ ครอบคลุมทั้ง GM และ PM · $M_s \lt 2$ รับประกัน GM $\ge 6$ dB และ PM $\ge 29^\circ$

## ระบบที่ลดเกนแล้วไม่เสถียร ขั้นสูง

ตัวอย่าง N-3 · เกนต่ำเกินก็ไม่ได้

### $L(s) = \dfrac{K(s+1)^2}{s^3}$ (ระบบชนิด 3 เช่น เซอร์โวติดตามความเร่ง) เสถียรเมื่อใด

- $P = 0$ · เฟสเริ่ม −270° แล้วศูนย์คู่ดึงขึ้นไปจบที่ −90° ข้ามเส้น −180° หนึ่งครั้ง

- เราท์ของ $s^3 + Ks^2 + 2Ks + K$: $K \cdot 2K \gt K \Rightarrow K \gt 0.5$

- ไนควิสต์: $K = 2$ นับได้ $N = 0$ · $K = 0.3$ นับได้ $N = 2$

เสถียรเมื่อ $K \gt 0.5$ เท่านั้น: ลดเกนกลับทำให้ไม่เสถียร (ต่างจากระบบปกติ) การอิ่มตัวของตัวขับลดเกนประสิทธิผลได้ ระบบแบบนี้จึงอาจแกว่งเมื่ออิ่มตัว (ดูฟังก์ชันพรรณนา) · ลองในแล็บ preset “เกนต่ำไม่เสถียร”

## แล็บไนควิสต์

เลื่อน $K$ ดูกราฟขยายจนอ้อม −1 (กากบาทแดง) ตัวเลข P, N, Z คำนวณให้มุมขวาบน ใช้ปุ่ม + − ซูม ลองเทียบกับรูทโลคัสในจอเดียวกัน

## ข้อผิดพลาดที่พบบ่อย

- ลืมส่วน ω ลบ และส่วนโค้งที่อนันต์ → นับรอบผิด ต้องปิดเส้นทางให้ครบ

- สลับทิศตามเข็ม/ทวนเข็ม → ตำราบางเล่มนิยาม $N$ เป็นทวนเข็ม และเขียน $Z = P - N$ ผลเหมือนกัน ต้องรู้ว่าใช้แบบไหน

- ลืมนับ P → พลานต์ไม่เสถียรต้องอ้อม −1 ทวนเข็มพอดี P รอบ

- ใช้ GM/PM กับระบบวงเปิดไม่เสถียร → ตัดสินด้วยไนควิสต์เท่านั้น

## ต่อยอดไปหน้าถัดไป

รู้วิธีตัดสินเสถียรภาพครบทุกเครื่องมือแล้ว ถึงเวลาออกแบบ: ตัวชดเชย lead lag ดัดกราฟโบดและไนควิสต์ให้ห่างจาก −1 ตามสเปก

## คำถามที่พบบ่อย

นับรอบอ้อม −1 อย่างไรให้ไม่พลาด?
ลากเส้นตรงจากจุด −1 ออกไปทิศใดก็ได้ (นิยมไปทาง −∞ บนแกนจริง) นับจำนวนครั้งที่กราฟตัดเส้นนั้น ตัดแบบตามเข็มนับ +1 ทวนเข็มนับ −1 ผลรวมคือ N ต้องรวมทั้งส่วน ω บวก ส่วน ω ลบ (ภาพสะท้อน) และส่วนที่ปิดวงที่อนันต์ด้วย

P ในสูตร Z = N + P คืออะไร?
P คือจำนวนขั้วของฟังก์ชันวงเปิด L(s) ที่อยู่ฝั่งขวาของระนาบ s (ไม่รวมขั้วบนแกน jω ซึ่งเลี่ยงด้วยครึ่งวงกลมเล็ก) ถ้าวงเปิดเสถียร P = 0 จึงต้องการ N = 0 คือไม่อ้อม −1 เลย

ไนควิสต์ดีกว่าโบดตรงไหน?
ใช้ได้กับทุกกรณี รวมถึงวงเปิดไม่เสถียร ครอสโอเวอร์หลายครั้ง และหน่วงเวลา และให้ภาพระยะห่างจากจุด −1 ในทุกทิศ ซึ่งบอกความทนทานได้ดีกว่าการดูแค่ GM และ PM ส่วนโบดวาดและออกแบบง่ายกว่าในกรณีทั่วไป
