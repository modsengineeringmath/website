# ระบบควบคุม (Control Systems Engineering): ป้อนกลับ เสถียรภาพ รูทโลคัส โบด และ PID

// บทที่ 13 · วิศวกรรมไฟฟ้า · Control Systems Engineering


เครื่องปรับอากาศที่รักษาอุณหภูมิ มอเตอร์ที่หมุนได้ความเร็วตามสั่ง แขนหุ่นยนต์ที่หยุดตรงตำแหน่ง โดรนที่ลอยนิ่งกลางลม และพาวเวอร์ซัพพลายที่จ่าย 5.00 V ไม่ว่าโหลดจะเปลี่ยนแค่ไหน ทั้งหมดใช้หลักการเดียวกัน คือวัดผลลัพธ์ เทียบกับเป้าหมาย แล้วแก้ไข ชุดบทเรียนนี้เริ่มจากวงจรไฟฟ้าที่เราคุ้นเคย ไล่ไปถึงการวาดรูทโลคัสด้วยมือ วิเคราะห์โบด ออกแบบตัวชดเชยและ PID จนถึงหุ่นยนต์และตัวแปลงกำลัง

ทั้งวิชาในหนึ่งนาที

- เขียนพลานต์เป็นฟังก์ชันถ่ายโอน $G(s)$ ต่อตัวควบคุม $C(s)$ แล้วปิดวงได้ $T(s) = \dfrac{CG}{1 + CG}$ บล็อกไดอะแกรม

- ระบบเสถียรเมื่อรากของ $1 + KG(s) = 0$ อยู่ซ้ายของแกน $j\omega$ ทุกตัว ตรวจได้โดยไม่ต้องหาราก เราท์–เฮอร์วิตซ์

- รากเหล่านั้นเดินอย่างไรเมื่อปรับ $K$ รูทโลคัส · ห่างจากความไม่เสถียรแค่ไหน เกนและเฟสมาร์จิน

- ไม่ได้ตามสเปก เพิ่มขั้วและศูนย์อย่างมีชั้นเชิง lead · lag และ PID

## Control Engineering หรือ Control Systems เรียกอะไรดี

ทั่วโลกใช้สองคำนี้แทนกันได้ แต่มีน้ำหนักต่างกันเล็กน้อย Control Systems คือชื่อวิชาที่มหาวิทยาลัยส่วนใหญ่ใช้ (Control Systems Engineering ของ Nise, Modern Control Systems ของ Dorf) เน้นตัวระบบและเครื่องมือวิเคราะห์ ส่วน Control Engineering คือชื่อสาขาวิชาชีพ เน้นงานออกแบบ หน้านี้จึงใช้ชื่อเต็ม Control Systems Engineering ครอบทั้งสองคำ ภาษาไทยใช้ ระบบควบคุม และ วิศวกรรมระบบควบคุม

| คำ | ความหมายที่ใช้ในชุดนี้ | เชื่อมไปหน้า |

| Control system | ระบบที่จัดการให้ตัวแปรหนึ่งเป็นไปตามที่ต้องการ | ภาพรวม |

| Feedback control system | ระบบวงปิดที่วัดเอาต์พุตย้อนกลับมาเทียบกับค่าอ้างอิง | ภาพรวม · บล็อก |

| Automatic control | การควบคุมที่ทำงานเองโดยไม่ต้องมีคนคอยปรับ | PID |

| Classical control | วิเคราะห์ในโดเมน $s$ และความถี่: Routh รูทโลคัส โบด ไนควิสต์ | ส่วนที่ 2 ถึง 6 |

| Modern control | วิเคราะห์ในปริภูมิสถานะด้วยเมทริกซ์ | ส่วนที่ 7 |

| Mechatronics | กลไก + ไฟฟ้า + อิเล็กทรอนิกส์ + ซอฟต์แวร์ ที่มีระบบควบคุมเป็นแกนกลาง | เมคาทรอนิกส์ |

| Robotics | เมคาทรอนิกส์ที่มีหลายข้อต่อ รับรู้ และตัดสินใจเอง | โรโบติกส์ |

## แผนที่การเรียน: classical ก่อน แล้วค่อย modern

ลำดับในชุดนี้ตั้งใจเรียงแบบที่อาจารย์สอนในห้อง เริ่ม classical ก่อน เพราะฟังก์ชันถ่ายโอนให้ภาพทางกายภาพชัด (ขั้วคือความเร็วตอบสนอง เฟสคือความล่าช้า) งานออกแบบในอุตสาหกรรมส่วนใหญ่จบได้ที่ PID และตัวชดเชย และเป็นภาษาที่ datasheet ของไอซีควบคุมใช้ เมื่อแน่นแล้วจึงขึ้น modern control ที่ต่อยอดจากค่าเฉพาะ สำหรับระบบหลายตัวแปร หุ่นยนต์ และการควบคุมที่เหมาะสมที่สุด

## เริ่มจากไฟฟ้า ปูทางไปอิเล็กทรอนิกส์กำลัง

นักศึกษาไฟฟ้ามีข้อได้เปรียบ เพราะวงจร RC คือระบบอันดับหนึ่ง วงจร RLC คือระบบอันดับสอง และออปแอมป์คือตัวควบคุมที่สร้างได้จริงบนโต๊ะ ชุดนี้จึงใช้วงจรเป็นตัวอย่างหลักตลอดทาง แล้วค่อยขยายไปมอเตอร์ กลไก และหุ่นยนต์ ปลายทางคือตัวแปลงกำลังแบบสวิตชิ่ง ซึ่งรวมทุกเรื่องในชุดนี้ไว้ในวงจรเดียว

| สิ่งที่รู้จากไฟฟ้า | ในภาษาระบบควบคุม | ใช้ต่อที่ |

| วงจร RC, $\tau = RC$ | ระบบอันดับหนึ่ง ขั้ว $s = -1/\tau$ | แล็บระบบอันดับ 1 |

| วงจร RLC อนุกรม | ระบบอันดับสอง $\zeta,\ \omega_n$ | แล็บระบบอันดับ 2 |

| อิมพีแดนซ์ $Z(s)$ | ฟังก์ชันถ่ายโอน $G(s)$ | แบบจำลอง |

| ออปแอมป์อินเวอร์ติง $-Z_f/Z_i$ | ตัวควบคุม PI, PD, lead, lag | แล็บออปแอมป์ · ตัวชดเชย |

| ฟิลเตอร์ low-pass, $-3$ dB | แบนด์วิดท์ โบดไดอะแกรม | โบด |

| ฟังก์ชันเจเนอเรเตอร์ + สโคป วัดเกนและเฟส | วัดผลตอบสนองความถี่จริง | แล็บ FG + สโคป |

| มอเตอร์ DC: $V = Ri + L\,di/dt + K_e\omega$ | พลานต์ของเซอร์โว | เมคาทรอนิกส์ |

| บั๊กคอนเวอร์เตอร์, LC ฟิลเตอร์, PWM | $G_{vd}(s)$ และตัวชดเชย Type III | สะพานสู่อิเล็กทรอนิกส์กำลัง |

## แล็บระบบควบคุม: รูทโลคัส โบด ไนควิสต์ ในจอเดียว

พิมพ์ฟังก์ชันถ่ายโอนวงเปิด $L(s)$ เช่น 1/(s(s+1)(s+2)) หรือ (s+3)/(s^2(s+10)) แล้วเลื่อนเกน $K$ ดูขั้ววงปิด (จุดส้ม) เดินตามรูทโลคัส พร้อมกับโบดที่เลื่อนขึ้นลงและกราฟไนควิสต์ที่ขยายจนอ้อม $-1$ ลากขั้ว × หรือศูนย์ ○ เพื่อดูว่ารูปร่างเปลี่ยนอย่างไร คลิกบนเส้นโลคัสเพื่อเลือก $K$ ที่จุดนั้น

ลองตั้งโจทย์ให้ตัวเอง: ระบบ $\dfrac{K}{s(s+1)(s+2)}$ เสถียรถึง $K$ เท่าไร (เฉลย $K = 6$ ที่ $\omega = \sqrt2$ ซึ่งตรงกับตารางเราท์ในหน้าเราท์–เฮอร์วิตซ์ และเกนมาร์จินที่ $K = 1$ คือ $20\log 6 = 15.6$ dB ในหน้ามาร์จิน) สามวิธีให้คำตอบเดียวกัน นี่คือความงามของวิชานี้

| $j$ | หน่วยจินตภาพ $j^2 = -1$ | imaginary unit |
