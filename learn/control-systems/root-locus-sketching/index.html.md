# ฝึกวาดรูทโลคัสด้วยมือ: ทีละขั้นจนคล่อง

// บทที่ 13.9 · ระบบควบคุม · Root Locus Sketching


วิศวกรควบคุมที่เก่งจริงมองขั้วและศูนย์แล้วเห็นรูปรูทโลคัสในหัวก่อนเปิดโปรแกรม เพราะรูปบอกว่าควรเพิ่มศูนย์ตรงไหน ใช้ lead หรือ lag และเกนสูงสุดเท่าไร ซึ่งโปรแกรมไม่ได้บอก หน้านี้คือสนามฝึก มีสูตรวาด 8 ขั้นที่ใช้ได้กับทุกโจทย์ ตัวอย่างทีละขั้น 7 แบบเรียงจากง่ายไปยาก และแล็บที่ซ่อนเฉลยให้วาดก่อนแล้วค่อยตรวจ ก่อนอ่านควรผ่านกฎการวาดมาแล้ว สูตรใช้รหัส W

สรุปใน 30 วินาที

- วางขั้ว × ศูนย์ ○ → ระบายส่วนแกนจริง → เส้นกำกับ → จุดแยก → ตัด $j\omega$ → มุมออก → ลากโค้งเชื่อม → ตรวจ

- ขั้วจริงสองตัวติดกันบนโลคัส = มีจุดแยกระหว่างกลาง · ศูนย์สองตัวติดกัน = มีจุดเข้า

- ขั้วจริง 2 + ศูนย์จริง 1 = วงกลมรอบศูนย์ · เพิ่มศูนย์ดึงโลคัสไปซ้าย (เสถียรขึ้น) · เพิ่มขั้วผลักไปขวา

- ทุกรูปในหน้านี้คำนวณจากเครื่อง ใช้ตรวจที่วาดเองได้

ระดับพื้นฐาน เริ่มวาดกลาง ป.ตรี วิศวกรรมขั้นสูง โจทย์ยาก

## สูตรวาด 8 ขั้น ใช้ได้ทุกโจทย์ พื้นฐาน

W1 Sketching recipe ขั้นตอนการวาดรูทโลคัส

- จัดรูป $1 + KGH = 0$ ให้ $GH$ monic หาขั้ว (×) และศูนย์ (○) วางบนระนาบ $s$ สเกลแกนเท่ากัน

- ระบายส่วนบนแกนจริง (นับขั้ว+ศูนย์ทางขวาเป็นเลขคี่) L5

- ถ้า $n - m \ge 2$: วาดเส้นกำกับจาก $\sigma_a$ ที่มุม $\theta_a$ (เส้นประ) L6

- หาจุดแยก/จุดเข้าในช่วงที่มีขั้วสองฝั่ง (หรือศูนย์สองฝั่ง) L7

- หาจุดตัดแกน $j\omega$ และ $K_{cr}$ ด้วย Routh L8

- มีขั้ว/ศูนย์เชิงซ้อน: หามุมออก/เข้า L9

- ลากโค้งนุ่มนวลเชื่อมทุกจุด ใส่ลูกศรทิศ $K$ เพิ่ม สะท้อนครึ่งล่าง

- ตรวจ: จำนวนกิ่ง = $n$ · กิ่งจบที่ศูนย์หรือตามเส้นกำกับ · ผลรวมขั้วคงที่ ($n - m \ge 2$) L10

## ขั้วจริงสองตัว: รูปพื้นฐานที่สุด พื้นฐาน

ตัวอย่าง W-1 · ระบบอันดับสองแบบ P

### วาดรูทโลคัสของ $\dfrac{K}{(s+1)(s+3)}$

- ขั้ว $-1, -3$ ไม่มีศูนย์ · ส่วนแกนจริง: $[-3, -1]$ (ทางขวามี 1 ตัว)

- $n - m = 2$: $\theta_a = \pm90^\circ$, $\sigma_a = \dfrac{-1 - 3}{2} = -2$

- จุดแยก: $\dfrac{1}{\sigma + 1} + \dfrac{1}{\sigma + 3} = 0 \Rightarrow \sigma = -2$ ($K = 1 \cdot 1 = 1$)

- ไม่ตัดแกน $j\omega$ ($s^2 + 4s + 3 + K$ สัมประสิทธิ์บวกเสมอ)

สองกิ่งวิ่งเข้าหากันบนแกนจริง ชนที่ $-2$ เมื่อ $K = 1$ แล้วแยกขึ้นลงเป็นเส้นดิ่ง ขั้ววงปิดคือ $-2 \pm j\sqrt{K - 1}$

ข้อสังเกตสำคัญ: ส่วนจริงคงที่ $-2$ ทุก $K \gt 1$ แปลว่าเวลาเข้าที่ $t_s \approx 4/2 = 2$ sไม่ดีขึ้นเลยเมื่อเพิ่มเกน มีแต่แกว่งเร็วขึ้นและ overshoot มากขึ้น ตัวควบคุม P จึงมีขีดจำกัด

## เพิ่มศูนย์: โลคัสเป็นวงกลม พื้นฐาน

W2 Circle rule ขั้วจริง 2 ตัว + ศูนย์จริง 1 ตัว

$$\text{วงกลมศูนย์กลาง } z, \quad r = \sqrt{|z - p_1|\,|z - p_2|}$$

ใช้ได้เมื่อศูนย์อยู่นอกช่วงระหว่างขั้วทั้งสอง · จุดแยกและจุดเข้าคือ $z \pm r$

ตัวอย่าง W-2 · PI/PD กับพลานต์อันดับหนึ่งที่มีอินทิเกรเตอร์

### วาดรูทโลคัสของ $\dfrac{K(s+3)}{s(s+1)}$

- ขั้ว $0, -1$ ศูนย์ $-3$ · ส่วนแกนจริง: $[-1, 0]$ และ $(-\infty, -3]$ · $n - m = 1$ กิ่งเดียวไปอนันต์ที่ $180^\circ$

- วงกลม W2: $r = \sqrt{3 \times 2} = \sqrt6 = 2.449$ รอบ $-3$

- จุดแยก $-3 + \sqrt6 = -0.551$ ($K = 0.101$) · จุดเข้า $-3 - \sqrt6 = -5.449$ ($K = 9.899$)

สองกิ่งแยกที่ −0.551 วนตามวงกลมรอบศูนย์ แล้วกลับเข้าแกนจริงที่ −5.449 กิ่งหนึ่งไปหาศูนย์ −3 อีกกิ่งไป −∞ เสถียรทุก $K \gt 0$

เทียบกับ W-1: ศูนย์ดึงโลคัสไปทางซ้ายและโค้งกลับเข้าแกนจริง เกนสูงจึงไม่แกว่งอีกต่อไป นี่คือพลังของศูนย์ (PD, lead) · $\zeta$ ต่ำสุดอยู่ที่จุดสัมผัสวงกลมกับเส้นจากจุดกำเนิด: $\sin\theta = \sqrt6/3 \Rightarrow \zeta_{min} = \sqrt{1 - 6/9} = 0.577$

## ขั้วเชิงซ้อน: มุมออกคือกุญแจ กลาง

ตัวอย่าง W-3 · อินทิเกรเตอร์ + ขั้วเชิงซ้อน

### วาดรูทโลคัสของ $\dfrac{K}{s(s^2 + 2s + 2)}$

- ขั้ว $0,\ -1 \pm j$ · แกนจริง: $(-\infty, 0]$ ทั้งเส้น (ทางขวามีขั้วจริงตัวเดียว คู่เชิงซ้อนไม่นับ)

- $n - m = 3$: $\theta_a = \pm60^\circ, 180^\circ$ · $\sigma_a = \dfrac{0 + (-1) + (-1)}{3} = -\tfrac23$

- จุดแยก: $\dfrac{dK}{ds} = -(3s^2 + 4s + 2) = 0 \Rightarrow s = \dfrac{-2 \pm j\sqrt2}{3}$ เชิงซ้อนและไม่ผ่านเงื่อนไขมุม จึงไม่มีจุดแยก

- ตัด $j\omega$: $s^3 + 2s^2 + 2s + K$ สูตรลัด $2 \cdot 2 \gt K \Rightarrow K_{cr} = 4$ · $2s^2 + 4 = 0 \Rightarrow \omega = \sqrt2$

- มุมออกจาก $-1 + j$: $180^\circ - (135^\circ + 90^\circ) = -45^\circ$ (จากตัวอย่าง L-2)

กิ่งจากขั้วเชิงซ้อนออกที่ $-45^\circ$ โค้งเข้าหาเส้นกำกับ $\pm60^\circ$ ตัดแกน $j\omega$ ที่ $\pm j\sqrt2$ เมื่อ $K = 4$ · กิ่งจาก 0 วิ่งไปทางซ้ายตลอดแกนจริง

ถ้าคำนวณมุมออกผิดเป็น $+45^\circ$ กิ่งจะวิ่งขึ้นซ้ายผิดทิศ ทั้งที่จุดตัดแกนถูก มุมออกจึงจำเป็นสำหรับรูปที่ถูก

## ขั้วเชิงซ้อนกับศูนย์จริง: วงกลมอีกแบบ กลาง

ตัวอย่าง W-4 · มุมออกและจุดเข้า

### วาดรูทโลคัสของ $\dfrac{K(s+2)}{s^2 + 2s + 3}$

- ขั้ว $-1 \pm j\sqrt2$ ($\pm j1.414$) ศูนย์ $-2$ · แกนจริง: $(-\infty, -2]$ · $n - m = 1$

- มุมออกจาก $p = -1 + j\sqrt2$: มุมจากศูนย์ $\angle(1 + j\sqrt2) = 54.7^\circ$ มุมจากขั้วคู่ $90^\circ$

$$\theta_d = 180^\circ - 90^\circ + 54.7^\circ = {144.7^\circ}$$

- จุดเข้า: $K = -\dfrac{s^2 + 2s + 3}{s + 2}$, $\dfrac{dK}{ds} = 0 \Rightarrow s^2 + 4s + 1 = 0 \Rightarrow s = -2 \pm \sqrt3$ ใช้ $-3.732$ (อยู่บนโลคัส $K = 5.46$) ทิ้ง $-0.268$

กิ่งออกจากขั้วเชิงซ้อนที่ $144.7^\circ$ โค้งเป็นวงกลมรัศมี $\sqrt3$ รอบศูนย์ $-2$ เข้าแกนจริงที่ $-3.732$ แล้วกิ่งหนึ่งไปหา $-2$ อีกกิ่งไป $-\infty$

รัศมี = ระยะจากศูนย์ถึงขั้ว $|-1 + j\sqrt2 + 2| = \sqrt{1 + 2} = \sqrt3$ ✓ และ $-2 - \sqrt3 = -3.732$ ✓

## จุดแยกเชิงซ้อน: โจทย์ระดับสอบเข้า ขั้นสูง

ตัวอย่าง W-5 · สี่ขั้ว มีจุดแยกสามจุด

### วาดรูทโลคัสของ $\dfrac{K}{s(s+4)(s^2 + 4s + 20)}$

- ขั้ว $0, -4, -2 \pm j4$ · แกนจริง: $[-4, 0]$ · $n - m = 4$: $\theta_a = \pm45^\circ, \pm135^\circ$ · $\sigma_a = \dfrac{0 - 4 - 2 - 2}{4} = -2$

- $K = -(s^4 + 8s^3 + 36s^2 + 80s)$ · $\dfrac{dK}{ds} = -4(s^3 + 6s^2 + 18s + 20) = 0$

$$(s + 2)(s^2 + 4s + 10) = 0 \ \Rightarrow\ s = -2,\ \ -2 \pm j\sqrt6$$

$s = -2$: $K = 64$ ✓ · $s = -2 \pm j2.449$: แทนแล้วได้ $K = 100$ เป็นจำนวนจริงบวก ✓ อยู่บนโลคัสทั้งสามจุด

- มุมออกจาก $-2 + j4$: จาก 0 คือ $116.6^\circ$ จาก −4 คือ $63.4^\circ$ จาก $-2 - j4$ คือ $90^\circ$

$$\theta_d = 180^\circ - (116.6^\circ + 63.4^\circ + 90^\circ) = -90^\circ$$

- Routh ของ $s^4 + 8s^3 + 36s^2 + 80s + K$: แถว $s^2$: $26,\ K$ · แถว $s^1$: $\dfrac{2080 - 8K}{26}$ ได้ $K_{cr} = 260$ · $26\omega^2 = 260 \Rightarrow \omega = \sqrt{10} = 3.162$

กิ่งจากขั้วเชิงซ้อนพุ่งลงตรง ($-90^\circ$) มาชนกันที่ $-2 \pm j2.45$ เมื่อ $K = 100$ ส่วนกิ่งจาก 0 และ −4 ชนกันที่ −2 เมื่อ $K = 64$ แล้วแยกขึ้นลงตามเส้น $\sigma = -2$ ไปพบกิ่งเชิงซ้อน จากนั้นทั้งสี่กิ่งแยกไปตามเส้นกำกับ ตัดแกน $j\omega$ ที่ $\pm j3.162$ เมื่อ $K = 260$

โจทย์นี้ (จากตำรา Ogata) หลอกคนที่ใช้เฉพาะรากจริงของ $dK/ds$ · ขั้วทั้งสี่สมมาตรรอบ $\sigma = -2$ โลคัสจึงสมมาตรรอบเส้นนั้นด้วย

## ขั้วซ้ำที่จุดกำเนิดและสามกิ่งพบกัน ขั้นสูง

W3 Repeated poles and multiple meeting ขั้วซ้ำและหลายกิ่งพบกัน

$$\theta_{d} = \frac{180^\circ(2q+1) + \sum\angle(\text{ศูนย์}) - \sum\angle(\text{ขั้วอื่น})}{r}, \qquad \text{กิ่งเข้า-ออกสลับกันทุก } \frac{180^\circ}{r}$$

$r$ = จำนวนขั้วที่ซ้ำ หรือจำนวนกิ่งที่มาพบที่จุดเดียว

ตัวอย่าง W-6 · ระบบ type 2 กับศูนย์

### วาดรูทโลคัสของ $\dfrac{K(s+1)}{s^2(s+9)}$

- ขั้ว $0, 0, -9$ ศูนย์ $-1$ · แกนจริง: $[-9, -1]$ (ช่วง $(-1, 0)$ มีขั้วทางขวา 2 ตัว ไม่ใช่)

- ขั้วคู่ที่ 0: มุมจากศูนย์และขั้ว −9 เป็น $0^\circ$ ได้ $2\theta_d = 180^\circ \Rightarrow \theta_d = \pm90^\circ$ W3

- $n - m = 2$: $\pm90^\circ$ · $\sigma_a = \dfrac{-9 - (-1)}{2} = -4$

- $\dfrac{dK}{ds} = 0 \Rightarrow 2s(s + 3)^2 = 0$ ได้ $s = -3$ รากซ้ำ ($K = 27$) สามกิ่งพบกันพร้อมกัน

สองกิ่งออกจากจุดกำเนิดขึ้นลง โค้งวนมาพบกับกิ่งจาก −9 ที่ −3 พร้อมกันเมื่อ $K = 27$ (ขั้ววงปิดซ้ำสามตัว) แล้วแยกเป็นหนึ่งกิ่งไปหาศูนย์ −1 และสองกิ่งไปตามเส้นกำกับ $\sigma = -4$

ตรวจ: $s^3 + 9s^2 + 27s + 27 = (s + 3)^3$ ✓ ที่ $K = 27$ · ระบบ type 2 แบบนี้พบในเซอร์โวที่ต้องติดตามความเร็วคงที่ได้ไม่มีความผิดพลาด

## สี่ขั้วจริงและผลของการเพิ่มศูนย์ กลาง

ตัวอย่าง W-7 · สี่ขั้วจริง

### วาดรูทโลคัสของ $\dfrac{K}{(s+1)(s+2)(s+3)(s+4)}$

- แกนจริง: $[-2, -1]$ และ $[-4, -3]$ · $\theta_a = \pm45^\circ, \pm135^\circ$ · $\sigma_a = -10/4 = -2.5$

- $\dfrac{dK}{ds} = 0$: $4s^3 + 30s^2 + 70s + 50 = 0 \Rightarrow s = -2.5,\ -2.5 \pm \tfrac{\sqrt5}{2}$ ใช้ $-1.382$ และ $-3.618$ (ทั้งคู่ $K = 1$) ทิ้ง $-2.5$ (ไม่อยู่บนโลคัส)

- Routh ของ $s^4 + 10s^3 + 35s^2 + 50s + (24 + K)$: $K_{cr} = 126$, $\omega = \sqrt5 = 2.236$

สองคู่ชนกันที่ −1.382 และ −3.618 พร้อมกันที่ $K = 1$ แยกออกไปตามเส้นกำกับ คู่ขวาตัดแกน $j\omega$ ที่ $\pm j2.236$ เมื่อ $K = 126$

เทียบผลของการเพิ่มศูนย์กับตัวอย่าง L-1: เพิ่มศูนย์ที่ $-3$ ให้ $\dfrac{K}{s(s+1)(s+2)}$ (คือการใส่ PD) เส้นกำกับเปลี่ยนจาก 3 เส้น (±60°) เหลือ 2 เส้น (±90°) ที่ $\sigma_a = \frac{-3 - (-3)}{2} = 0$ โลคัสจึงไม่ข้ามไปฝั่งขวาอีกต่อไป ระบบเสถียรทุก $K$

$K(s+3)/[s(s+1)(s+2)]$: ศูนย์ที่ −3 ดึงเส้นกำกับมาที่ ±90° โลคัสไม่ตัดแกน $j\omega$ · จุดแยกขยับเป็น −0.468

## แกลเลอรีรูปแบบมาตรฐานที่ควรจำได้ทันที กลาง

รูปเหล่านี้ปรากฏซ้ำในโจทย์และงานจริง ถ้าจำได้จะวาดเร็วขึ้นมาก ลองพิมพ์แต่ละอันลงในแล็บด้านล่างเพื่อดูรูปจริง

| L(s) | ลักษณะรูป | ความหมายในงานจริง |

| $\dfrac{K}{s + a}$ | กิ่งเดียววิ่งจาก $-a$ ไป $-\infty$ | P กับวงจร RC: เร็วขึ้นตาม $K$ ไม่มีวันไม่เสถียร |

| $\dfrac{K}{(s + a)(s + b)}$ | ชนกันกลางแล้วขึ้นลงเป็นเส้นดิ่ง (W-1) | P กับระบบอันดับสอง: $t_s$ ไม่ดีขึ้นเมื่อเพิ่ม $K$ |

| $\dfrac{K}{s(s + a)}$ | เหมือนกันที่ $-a/2$ | เซอร์โวตำแหน่งแบบ P |

| $\dfrac{K(s + c)}{s(s + a)},\ c \gt a$ | วงกลมรอบ $-c$ (W-2) | PD หรือ lead กับเซอร์โว |

| $\dfrac{K}{s(s + a)(s + b)}$ | 3 เส้นกำกับ ±60° ข้ามไปขวาที่ $K_{cr}$ (L-1) | เซอร์โวที่มีค่าคงเวลาไฟฟ้า: มีเกนสูงสุด |

| $\dfrac{K}{s^2}$ | อยู่บนแกน $j\omega$ ตลอด | มวลอิสระ (ดาวเทียม ไจโร): P อย่างเดียวแกว่งค้าง ต้องมี D |

| $\dfrac{K(s + c)}{s^2}$ | วงกลมรอบ $-c$ จากจุดกำเนิด | PD กับมวลอิสระ: เสถียรทุก $K$ |

| $\dfrac{K}{(s - a)(s + b)}$ | ต้อง $K$ เกินค่าหนึ่งจึงข้ามมาซ้าย | ลูกตุ้มกลับหัว ลอยแม่เหล็ก: พลานต์ไม่เสถียร |

| $\dfrac{K(s + z)}{s(s + p)},\ z \ll p$ (z ใกล้ 0) | ขั้ว-ศูนย์คู่ใกล้จุดกำเนิดแทบไม่เปลี่ยนรูป | PI หรือ lag: แม่นขึ้นโดยไม่เสียความเร็ว |

## โหมดฝึกวาด: วาดก่อน แล้วค่อยเปิดเฉลย

กด “ซ่อนเฉลย (โหมดฝึกวาด)” เส้นกำกับ จุดแยก จุดตัด และผลของกฎจะถูกซ่อน เหลือแต่ขั้วและศูนย์ ให้วาดลงกระดาษตามสูตร 8 ขั้น แล้วกด “แสดงเฉลย” เทียบ เลือกโจทย์ได้จากรายการ หรือพิมพ์โจทย์จากตำราเองก็ได้

เฉลยสั้นโจทย์ฝึก 1: $\sigma_a = -3$, ±60°, จุดแยก −1.268 ($K = 10.39$), ตัด $j\omega$ ที่ $\pm j4.243$ เมื่อ $K = 162$ · ฝึก 2: วงกลมรัศมี $\sqrt8$ รอบ −4 จุดแยก −1.172 จุดเข้า −6.828

## ข้อผิดพลาดตอนวาดที่พบบ่อย

- สเกลแกนไม่เท่ากัน → มุมเพี้ยน วงกลมกลายเป็นวงรี เส้น $\zeta$ ผิด ใช้กระดาษกราฟและสเกลเท่ากันเสมอ

- ลืมว่ากิ่งไม่ตัดกันเอง → ยกเว้นที่จุดแยก/จุดเข้า กิ่งสองกิ่งไม่ข้ามกัน (ที่ $K$ เดียวกันมีรากชุดเดียว)

- วาดกิ่งย้อนกลับบนแกนจริง → บนแต่ละช่วงของแกนจริง $K$ เพิ่มทางเดียว จากขั้วไปหาจุดแยก หรือจากจุดเข้าไปหาศูนย์

- ลืมสมมาตร → ครึ่งล่างเป็นภาพสะท้อนของครึ่งบนเสมอ

- ไม่ตรวจผลรวมขั้ว → ถ้า $n - m \ge 2$ กิ่งหนึ่งไปขวา ต้องมีกิ่งไปซ้ายชดเชย ใช้ตรวจว่ารูปสมเหตุสมผล

## ต่อยอดไปหน้าถัดไป

วาดได้แล้วต้องใช้ให้เป็น หน้าออกแบบด้วยรูทโลคัสจะใช้รูปเหล่านี้เลือกเกนจากสเปก วางศูนย์ของ PD และ lead ให้โลคัสผ่านจุดที่ต้องการ และวางคู่ขั้ว-ศูนย์ของ PI หรือ lag เพื่อแก้ความผิดพลาดอยู่ตัว

## คำถามที่พบบ่อย

วาดรูทโลคัสด้วยมือต้องแม่นแค่ไหน?
ไม่ต้องแม่นทุกจุด แต่จุดสำคัญต้องถูก: ส่วนบนแกนจริง เส้นกำกับ (มุมและ σa) จุดแยกและจุดเข้า จุดตัดแกน jω พร้อมค่า K และมุมออกจากขั้วเชิงซ้อน จากนั้นลากเส้นโค้งผ่านจุดเหล่านี้อย่างนุ่มนวลและสมมาตร ก็ใช้ออกแบบได้แล้ว

ทำไมบางระบบไม่มีจุดแยกบนแกนจริง?
เพราะไม่มีช่วงบนแกนจริงที่มีขั้วอยู่สองฝั่ง เช่น K/(s(s²+2s+2)) มีขั้วจริงตัวเดียว ส่วนแกนจริงทั้งหมดคือกิ่งที่วิ่งจาก 0 ไปทาง −∞ สองกิ่งที่เหลือเริ่มจากขั้วเชิงซ้อน dK/ds = 0 จึงได้รากเชิงซ้อนที่ไม่อยู่บนโลคัส

จุดแยกเป็นจำนวนเชิงซ้อนได้ไหม?
ได้ เมื่อขั้วเชิงซ้อนและขั้วจริงจัดตัวกันพอเหมาะ เช่น K/(s(s+4)(s²+4s+20)) มีจุดแยกที่ −2 ± j2.45 ต้องตรวจด้วยเงื่อนไขมุมว่ารากของ dK/ds = 0 อยู่บนโลคัสจริงและให้ K เป็นจำนวนจริงบวก

ฝึกวาดอย่างไรให้เร็ว?
จำรูปแบบมาตรฐานในแกลเลอรีให้ได้ก่อน แล้วฝึกตามสูตร 8 ขั้นทุกครั้งจนเป็นนิสัย ใช้แล็บในหน้านี้กดซ่อนเฉลย วาดลงกระดาษ แล้วค่อยเปิดเทียบ ทำวันละ 2–3 โจทย์สักสัปดาห์จะเห็นรูปในหัวก่อนคำนวณ
