# ระบบอันดับหนึ่งและค่าคงตัวเวลา τ

// ทฤษฎีประกอบแล็บ

## ระบบอันดับหนึ่งทำงานอย่างไร

สรุปใน 30 วินาที

- ระบบอันดับหนึ่ง: $\tau\,\dfrac{dy}{dt} + y = K\,u(t)$ หรือ $G(s) = \dfrac{K}{\tau s + 1}$

- ทุก ๆ τ ส่วนที่ยังไม่เปลี่ยนจะเหลือ $1/e \approx 36.8\%$ จึงได้ 63.2%, 86.5%, 95.0%, 98.2%, 99.3%

- เส้นสัมผัสจากจุดใดก็ตาม ไปถึงค่าสุดท้ายหลังจากนั้น τ เสมอ

- วงจร RC: $\tau = RC$ · วงจร RL: $\tau = L/R$ · ความถี่มุม $\omega_c = 1/\tau$

## สมการและฟังก์ชันถ่ายโอน

ระบบที่มีตัวเก็บพลังงานเพียงตัวเดียว เช่น ตัวเก็บประจุหนึ่งตัวในวงจร RC หรือตัวเหนี่ยวนำหนึ่งตัวในวงจร RL อธิบายได้ด้วยสมการเชิงอนุพันธ์อันดับหนึ่ง

$$\tau\,\frac{dy}{dt} + y = K\,u(t) \quad\xrightarrow{\ \mathcal{L}\ }\quad G(s) = \frac{Y(s)}{U(s)} = \frac{K}{\tau s + 1}$$

$K$ คืออัตราขยายสถานะคงตัว และ $\tau$ คือค่าคงตัวเวลา มีหน่วยเป็นวินาที

เมื่อป้อนอินพุตขั้นบันไดขนาด $A$ และ $y(0) = 0$ จะได้ $Y(s) = \dfrac{KA}{s(\tau s + 1)}$ แยกเศษส่วนย่อยแล้วแปลงกลับ (ดูวิธีใน บทการแปลงลาปลาซ)

$$y(t) = KA\left(1 - e^{-t/\tau}\right) \qquad\text{และในกรณีทั่วไป}\qquad y(t) = y_\infty + \big(y(0) - y_\infty\big)\,e^{-t/\tau}$$

ทุกผลตอบสนองของระบบอันดับหนึ่ง = ส่วนคงตัว + ส่วนชั่วครู่ที่ลดลงแบบ $e^{-t/\tau}$

## ความหมายของค่าคงตัวเวลา τ

แทน $t = k\tau$ ลงในส่วนชั่วครู่ $e^{-t/\tau}$ จะได้ $e^{-k}$ ซึ่งไม่ขึ้นกับ K, A หรือหน่วยใด ๆ ตัวเลขชุดนี้จึงใช้ได้กับระบบอันดับหนึ่งทุกระบบ

| เวลา | ส่วนที่เหลือ $e^{-k}$ | เปลี่ยนไปแล้ว | ความหมายในทางปฏิบัติ |

| 1τ | 36.8% | 63.2% | นิยามของ τ |

| 2τ | 13.5% | 86.5% | |

| 3τ | 5.0% | 95.0% | เข้าที่ตามเกณฑ์ 5% |

| 4τ | 1.8% | 98.2% | เข้าที่ตามเกณฑ์ 2% |

| 5τ | 0.7% | 99.3% | ถือว่าเข้าที่สมบูรณ์ |

ในแล็บด้านบน การ์ด 1τ ถึง 5τ ใต้กราฟแสดงค่าชุดนี้พร้อมเวลาจริงตามค่า τ ที่ตั้ง ลองกด "เล่น" แล้วดูการ์ดสว่างขึ้นทีละใบ

## เส้นช่วยวิเคราะห์โครงสร้างเอกซ์โพเนนเชียล

### 1. เส้นสัมผัส: ถึงค่าสุดท้ายหลังจากนั้น τ เสมอ

จัดสมการใหม่ให้อยู่ในรูปอัตราการเปลี่ยนแปลง (กรณีอินพุตคงที่ ค่าสุดท้ายคือ $y_\infty = KA$)

$$\frac{dy}{dt} = \frac{y_\infty - y}{\tau}$$

ถ้าลากเส้นสัมผัสจากจุด $(t_0, y(t_0))$ ด้วยความชันนี้ เส้นจะไปถึงระดับ $y_\infty$ เมื่อ $\Delta t \cdot \dfrac{y_\infty - y}{\tau} = y_\infty - y$ นั่นคือ $\Delta t = \tau$ พอดี ไม่ว่าเริ่มจากจุดไหนของกราฟ เปิดตัวเลือก "เส้นสัมผัสที่ตำแหน่งชี้" แล้วเลื่อนเมาส์ไปตามกราฟเพื่อดูสมบัตินี้

### 2. สเกลลอการิทึม: เอกซ์โพเนนเชียลกลายเป็นเส้นตรง

$$\ln\lvert y_\infty - y(t)\rvert = \ln\lvert y_\infty - y(0)\rvert - \frac{t}{\tau}$$

พล็อตส่วนที่เหลือบนแกนลอการิทึมจะได้เส้นตรงที่มีความชัน $-1/\tau$ ถ้าข้อมูลจากการวัดจริงไม่เป็นเส้นตรงบนกราฟนี้ แปลว่าระบบไม่ใช่อันดับหนึ่งล้วน เช่น มีตัวเก็บพลังงานมากกว่าหนึ่งตัว

### 3. เวลาที่ใช้บ่อย

- ครึ่งทาง 50%: $t_{50} = \tau\ln 2 \approx 0.693\tau$

- เวลาขึ้น 10% → 90%: $t_r = \tau\ln 9 \approx 2.20\tau$

- เวลาเข้าที่ 2%: $t_s = \tau\ln 50 \approx 3.91\tau$ (นิยมปัดเป็น 4τ) และ 5%: $\tau\ln 20 \approx 3.00\tau$

## หาค่า τ จากข้อมูลที่วัดได้

ตัวอย่างที่ 1 · วัดจากออสซิลโลสโคป

### ป้อนแรงดันขั้นบันได 5 V ให้วงจร RC ที่ไม่มีประจุ วัดได้ว่าที่ $t = 10$ ms แรงดันตัวเก็บประจุเท่ากับ 2 V จงหา τ

ดูวิธีทำ

ส่วนที่เหลือคือ $\dfrac{5 - 2}{5} = 0.6$ และต้องเท่ากับ $e^{-t/\tau}$

$$e^{-10\,\text{ms}/\tau} = 0.6 \quad\Rightarrow\quad \tau = \frac{10\ \text{ms}}{\ln(1/0.6)} = \frac{10\ \text{ms}}{0.511} \approx 19.6\ \text{ms}$$

$\tau \approx 19.6$ ms วิธีนี้ใช้จุดวัดเพียงจุดเดียว ถ้ามีหลายจุด ให้ใช้ความชันบนกราฟลอการิทึมจะลดผลของสัญญาณรบกวน

## วงจร RC และ RL

| วงจร | ค่าคงตัวเวลา | ตัวแปรที่ต่อเนื่อง |

| RC อนุกรม | $\tau = RC$ | แรงดันตัวเก็บประจุ $v_C(t)$ |

| RL อนุกรม | $\tau = L/R$ | กระแสตัวเหนี่ยวนำ $i_L(t)$ |

ตัวอย่างที่ 2 · วงจร RL

### ตัวเหนี่ยวนำ 50 mH ต่ออนุกรมกับตัวต้านทาน 10 Ω ป้อนแรงดัน 12 V จงหา τ และกระแสที่ $t = \tau$

ดูวิธีทำ

$$\tau = \frac{L}{R} = \frac{50\times10^{-3}}{10} = 5\ \text{ms} \qquad I_\infty = \frac{V}{R} = \frac{12}{10} = 1.2\ \text{A}$$

$$i(\tau) = 1.2\left(1 - e^{-1}\right) \approx 0.759\ \text{A}$$

$\tau = 5$ ms กระแสถึง 0.759 A (63.2% ของ 1.2 A) ใน 5 ms และเข้าที่ 2% ภายในประมาณ 20 ms ลองตั้งค่า "วงจร RL" ในแล็บด้วย R = 10 Ω และ L = 50 mH

## มุมมองเชิงความถี่

แทน $s = j\omega$ ลงในฟังก์ชันถ่ายโอน จะได้ขนาดและเฟส

$$\lvert G(j\omega)\rvert = \frac{K}{\sqrt{1 + \omega^2\tau^2}} \qquad \angle G(j\omega) = -\tan^{-1}(\omega\tau)$$

ที่ความถี่มุม $\omega_c = 1/\tau$ ขนาดเหลือ $K/\sqrt2$ (ลดลง 3 dB) และเฟสล้าหลัง 45° เหนือความถี่นี้ขนาดลดลง 20 dB ต่อทศวรรษ ระบบอันดับหนึ่งจึงเป็นวงจรกรองความถี่ต่ำผ่าน (low-pass filter) โดยธรรมชาติ

เวลาและความถี่ผูกกันด้วย τ ตัวเดียว: เวลาขึ้น $t_r = 2.2\tau$ และแบนด์วิดท์ $f_c = \dfrac{1}{2\pi\tau}$ คูณกันได้ $t_r f_c \approx 0.35$ เสมอ ระบบที่ตอบสนองเร็วจึงต้องมีแบนด์วิดท์กว้าง ลองเลือกอินพุตแบบไซน์ในแล็บ แล้วดูจุด "ω อินพุต" บน Bode plot เทียบกับแอมพลิจูดที่ได้ในกราฟเวลา

ระบบที่มีตัวเก็บพลังงานสองตัว เช่น วงจร RLC จะแกว่งได้และมีพารามิเตอร์สองตัวคือ ζ และ ωn ศึกษาต่อได้ใน แล็บระบบอันดับสอง

## ต่อยอด: ระบบอันดับหนึ่งในลูปป้อนกลับ

เมื่อนำระบบอันดับหนึ่งไปปิดวงด้วยตัวควบคุม ค่าคงตัวเวลาจะเปลี่ยนตามเกน ดูตัวอย่างมอเตอร์ในหน้าภาพรวมระบบควบคุม การกำจัดความผิดพลาดค้างด้วย PI และการจูน PID ให้ระบบอันดับหนึ่งที่มีหน่วงเวลา (เช่น เตาอบ)
