อัตราการเปลี่ยนแปลง dy/dt

สมการและฟังก์ชันถ่ายโอน

ระบบที่มีตัวเก็บพลังงานเพียงตัวเดียว เช่น ตัวเก็บประจุหนึ่งตัวในวงจร RC หรือตัวเหนี่ยวนำหนึ่งตัวในวงจร RL อธิบายได้ด้วยสมการเชิงอนุพันธ์อันดับหนึ่ง

เมื่อป้อนอินพุตขั้นบันไดขนาด AAA และ y(0)=0y(0) = 0y(0)=0 จะได้ Y(s)=KAs(τs+1)Y(s) = \dfrac{KA}{s(\tau s + 1)}Y(s)=s(τs+1)KA​ แยกเศษส่วนย่อยแล้วแปลงกลับ (ดูวิธีใน บทการแปลงลาปลาซ)

เส้นช่วยวิเคราะห์โครงสร้างเอกซ์โพเนนเชียล

1. เส้นสัมผัส: ถึงค่าสุดท้ายหลังจากนั้น τ เสมอ

จัดสมการใหม่ให้อยู่ในรูปอัตราการเปลี่ยนแปลง (กรณีอินพุตคงที่ ค่าสุดท้ายคือ y∞=KAy_\infty = KAy∞​=KA)

dydt=y∞−yτ\frac{dy}{dt} = \frac{y_\infty - y}{\tau}dtdy​=τy∞​−y​

ถ้าลากเส้นสัมผัสจากจุด (t0,y(t0))(t_0, y(t_0))(t0​,y(t0​)) ด้วยความชันนี้ เส้นจะไปถึงระดับ y∞y_\inftyy∞​ เมื่อ Δt⋅y∞−yτ=y∞−y\Delta t \cdot \dfrac{y_\infty - y}{\tau} = y_\infty - yΔt⋅τy∞​−y​=y∞​−y นั่นคือ Δt=τ\Delta t = \tauΔt=τ พอดี ไม่ว่าเริ่มจากจุดไหนของกราฟ เปิดตัวเลือก "เส้นสัมผัสที่ตำแหน่งชี้" แล้วเลื่อนเมาส์ไปตามกราฟเพื่อดูสมบัตินี้

2. สเกลลอการิทึม: เอกซ์โพเนนเชียลกลายเป็นเส้นตรง

ln⁡∣y∞−y(t)∣=ln⁡∣y∞−y(0)∣−tτ\ln\lvert y_\infty - y(t)\rvert = \ln\lvert y_\infty - y(0)\rvert - \frac{t}{\tau}ln∣y∞​−y(t)∣=ln∣y∞​−y(0)∣−τt​

พล็อตส่วนที่เหลือบนแกนลอการิทึมจะได้เส้นตรงที่มีความชัน −1/τ-1/\tau−1/τ ถ้าข้อมูลจากการวัดจริงไม่เป็นเส้นตรงบนกราฟนี้ แปลว่าระบบไม่ใช่อันดับหนึ่งล้วน เช่น มีตัวเก็บพลังงานมากกว่าหนึ่งตัว

3. เวลาที่ใช้บ่อย

  • เวลาขึ้น 10% → 90%: tr=τln⁡9≈2.20τt_r = \tau\ln 9 \approx 2.20\tautr​=τln9≈2.20τ

คำถามที่พบบ่อย

ค่าคงตัวเวลา τ คืออะไร?

เป็นเวลาที่ระบบอันดับหนึ่งใช้ในการเปลี่ยนแปลงไปได้ 63.2% ของการเปลี่ยนแปลงทั้งหมด หรือเวลาที่ส่วนชั่วครู่ลดลงเหลือ 1/e1/e1/e ของค่าเริ่มต้น สำหรับวงจร RC มีค่าเท่ากับ RCRCRC และวงจร RL มีค่าเท่ากับ L/RL/RL/R

ทำไมต้องเป็น 63.2%?

เพราะผลตอบสนองเป็นเอกซ์โพเนนเชียล ที่ t=τt = \taut=τ ส่วนที่เหลือคือ e−1≈0.368e^{-1} \approx 0.368e−1≈0.368 ส่วนที่เปลี่ยนไปแล้วจึงเป็น 1−0.368=0.6321 - 0.368 = 0.6321−0.368=0.632 หรือ 63.2% ตัวเลขนี้ไม่ขึ้นกับค่า K หรือขนาดของอินพุต

ระบบอันดับหนึ่งเข้าที่ภายในกี่ τ?

นิยมใช้ 4τ สำหรับเกณฑ์ 2% (ค่าแม่นยำคือ τln⁡50≈3.91τ\tau\ln 50 \approx 3.91\tauτln50≈3.91τ) และ 3τ สำหรับเกณฑ์ 5% หลังจาก 5τ ระบบเปลี่ยนไปแล้ว 99.3% ในทางปฏิบัติถือว่าเข้าที่สมบูรณ์

หาค่า τ จากกราฟที่วัดได้จริงอย่างไร?

วิธีที่ง่ายที่สุดคืออ่านเวลาที่สัญญาณไปถึง 63.2% ของการเปลี่ยนแปลงทั้งหมด หรือลากเส้นสัมผัสที่จุดเริ่มต้นไปตัดเส้นค่าสุดท้าย เวลาที่ตัดคือ τ วิธีที่แม่นที่สุดคือพล็อตลอการิทึมของส่วนที่เหลือเทียบกับเวลา จะได้เส้นตรงที่มีความชัน −1/τ-1/\tau−1/τ
