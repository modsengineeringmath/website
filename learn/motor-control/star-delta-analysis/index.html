    สตาร์ (Star), วาย (Wye, Y) และ เดลต้า (Delta, Δ) คือการต่อขดลวดสามชุดของมอเตอร์เหนี่ยวนำสามเฟส สตาร์กับวายเป็นการต่อแบบเดียวกัน (ยุโรปและเอเชียเรียก star อเมริกาเรียก wye) ชุดสตาร์ทจึงเรียกได้ทั้ง star–delta starter และ wye–delta starter หน้านี้ตั้งคำถามวิจัยหกข้อ แล้วตอบด้วยการทดลองเชิงตัวเลข 14 ชุด (E1–E14)

    1. ควรตั้งไทเมอร์สตาร์กี่วินาที และหาค่านี้จากข้อมูลแคตตาล็อกได้อย่างไร
    2. อะไรกำหนดยอดกระแสและแรงบิดกระชากตอนเปลี่ยนจากสตาร์เป็นเดลต้า ช่วงตายและลำดับเฟสมีผลเท่าไร
    3. สตาร์-เดลต้าลดอะไรได้จริง: กระแส พลังงาน ความร้อน หรือแรงดันตก
    4. โหลดแบบใดใช้สตาร์-เดลต้าได้ และแรงดันไฟตกส่งผลอย่างไร
    5. เดินมอเตอร์แบบสตาร์ถาวรที่โหลดเบาประหยัดไฟได้จริงหรือไม่ คุ้มที่โหลดเท่าไร
    6. ปัญหาในอดีตแก้อย่างไรในปัจจุบัน และอนาคตของการสตาร์ทมอเตอร์จะเป็นอย่างไร

    2. ปั๊ม: กวาดช่วงตาย 5–300 ms ทั้งสองลำดับเฟส อธิบายรูปคลื่นของกราฟด้วยสูตร E14–E15 และระบุช่วงตายที่ยอดกระแสต่ำกว่า DOL
    3. เพิ่ม J ของปั๊มเป็น 3 เท่า แล้วซ้ำข้อ 2 อธิบายว่าทำไมมุม δ ลดลง (พจน์ TLtd2/2JT_L t_d^2/2JTL​td2​/2J ใน E14)

    1. ไทเมอร์ = c·τm c ≈ 2.1–3.4 สำหรับปั๊ม/พัดลม (รวมเผื่อไฟตก 10 %) และ ≈ 3.7 สำหรับแรงบิดคงที่ 50 % (E13)
    2. สำหรับปั๊มและพัดลม ยอดกระแส 1–3 ไซเคิลตอนเปลี่ยน ไม่ลดลงตามไทเมอร์ (7.6–10.5·In ทุกค่า) ไทเมอร์ลดเพียงเวลาที่กระแสสูงค้าง ส่วนโหลดที่สลิปสตาร์ต่ำ (สายพาน 50 %) เปลี่ยนที่ความเร็วสมดุลได้ยอดเพียง 5.6·In (E2)
    3. ยอดถูกกำหนดโดย |VΔ − e| และทำนายได้ด้วย E14–E16 (คลาดราว 1–5 % ในตัวอย่าง E-4)
    4. ช่วงตายมีผลแบบ “ลอตเตอรีเฟส” สั้นกว่าดีกว่าในช่วงที่ทำได้จริง การยืดช่วงตายไม่ใช่วิธีลดกระชาก (E3)
    5. KM3 แบบตามหลังลดยอด 10–40 % ในช่วงตาย 0–60 ms และลดแรงบิดติดลบจาก −4.4 เหลือ −0.55·Tn ในกรณีปั๊ม (E3)
    6. แบบปิดวงจรที่ Rt ≈ 0.1–0.2·Zb ลดยอดเหลือ 2.9–6.2·In และไม่มีแรงบิดติดลบ (E4)
    7. วิธีที่รู้สถานะมอเตอร์ (กระแส/ความเร็ว) ลดเวลากระแสสูงได้ 3–4 เท่าเมื่อไฟตกหรือโหลดเปลี่ยน (E5)
    8. สตาร์-เดลต้าลด I²t ของสายจ่ายเหลือ 51 % (พัดลม) และ 75 % (ปั๊ม) แต่ความร้อนโรเตอร์ 130 % และ 155 % ของ DOL (E10)
    9. บนเครื่องกำเนิดไฟฟ้า ยอดตอนเปลี่ยนทำแรงดันตกได้มากกว่า DOL (41 % เทียบ 32 %) (E12)
    10. เดินสตาร์ถาวรประหยัด 188 W ต่อ 7.5 kW ที่โหลด 25 % จุดคุ้มทุน ≈ 53 % ขอบเผื่อแรงบิดจำกัดที่ ≈ 40 % (E9)
    11. สูตรคลอสส์ประเมินเวลาเร่งของมอเตอร์กรงคู่สูงเกินราว 74 % วิธีแรงบิดเฉลี่ยคลาดเพียง 2 % (E8)

    ข้อจำกัดของแบบจำลอง

    • แม่เหล็กเชิงเส้น ไม่รวมความอิ่มตัวและการสูญเสียแกนเหล็กในพลวัต (มีในสถานะคงตัวของ E9)
    • คอนแทกเตอร์เปิดสามเฟสพร้อมกันในอุดมคติ ของจริงตัดที่จุดกระแสผ่านศูนย์ของแต่ละเฟส ห่างกันได้หลายมิลลิวินาที และมีการเด้งของหน้าสัมผัสตอนต่อ
    • แหล่งจ่ายอุดมคติ (ไม่มีอิมพีแดนซ์) ในการจำลองพลวัต แรงดันตกคิดแยกด้วย E21 แบบมุมเดียวกัน
    • ขยายผลไปมอเตอร์ขนาดอื่นแบบต่อหน่วย (per-unit) ผ่าน τm และ In ∝ kW มอเตอร์จริงต่างขนาดและต่างผู้ผลิตมีกราฟแรงบิดและค่าคงตัวเวลาต่างกัน
    • งบความร้อนโอเวอร์โหลด (E14) เป็นการประมาณแบบอะเดียแบติก ไม่ใช่กราฟของรีเลย์รุ่นใดรุ่นหนึ่ง

    คำถามที่พบบ่อย

    ตั้งไทเมอร์สตาร์-เดลต้ากี่วินาทีจึงเหมาะสม?

    ตั้งให้มอเตอร์เปลี่ยนเป็นเดลต้าหลังจากถึงราว 98 % ของความเร็วสมดุลในสตาร์แล้ว คำนวณได้จากค่าคงตัวเวลาทางกล τm = J·ωs/Tn คูณสัมประสิทธิ์ c ≈ 2–4 (ปั๊มหอยโข่ง 80 % ≈ 2.6 พัดลม ≈ 2.9 รวมเผื่อไฟตก 10 %) เช่น ปั๊ม 37 kW ที่ J รวม 0.87 kg·m² ใช้ราว 1.5–3 s ส่วนพัดลม 7.5 kW ที่ J รวม 2.245 kg·m² ใช้ราว 21 s แล้วยืนยันหน้างานด้วยแคลมป์มิเตอร์ว่ากระแสช่วงสตาร์นิ่งก่อนเปลี่ยน

    ทำไมตอนเปลี่ยนจากสตาร์เป็นเดลต้ากระแสกระชากสูงเกือบเท่าหรือมากกว่าสตาร์ทตรง?

    ในช่วงตายที่มอเตอร์หลุดจากไฟ ฟลักซ์ที่ค้างในโรเตอร์สร้างแรงดันค้างที่ขั้วซึ่งหมุนช้ากว่าไฟและเลื่อนเฟสไปเรื่อยๆ เมื่อ KM3 ต่อ ทรานเซียนต์ถูกขับด้วยผลต่างเวกเตอร์ |V_Δ − e| ซึ่งอาจถึง 1.0–1.3 เท่าของแรงดันที่ขับตอนสตาร์ทตรง ผลจำลองมอเตอร์ 7.5 kW ที่ขับปั๊มและพัดลมจึงได้ยอด 1–3 ไซเคิลราว 0.85–1.2 เท่าของยอด DOL แต่สั้นมาก ลดได้ด้วยช่วงตายสั้นที่สุดที่คอนแทกเตอร์ยอมได้ ต่อ KM3 แบบตามหลัง หรือใช้สตาร์-เดลต้าแบบปิดวงจร

    ช่วงตาย (dead time) ระหว่าง KM2 หลุดกับ KM3 ต่อควรเป็นเท่าไร?

    ต้องนานกว่าเวลาเปิดหน้าสัมผัสบวกเวลาดับอาร์กของ KM2 เพื่อไม่ให้เกิดลัดวงจรระหว่างเฟส ไทเมอร์สตาร์-เดลต้าสำเร็จรูปมักใช้ราว 30–80 ms การยืดช่วงตายให้นานขึ้นไม่ได้ลดยอดกระแสเสมอไป เพราะมุมของแรงดันค้างหมุนไปเรื่อยๆ ผลจำลองชี้ว่าช่วงตายสั้นที่สุดที่ปลอดภัยให้ผลดีกว่า โดยเฉพาะปั๊มที่ความเฉื่อยต่ำและชะลอเร็ว

    ต่อคอนแทกเตอร์เดลต้า KM3 แบบ L1→W2 หรือ L1→V2 ดีกว่า?

    ทั้งสองแบบหมุนทางเดียวกันและถูกต้อง แบบมาตรฐาน L1→W2 L2→U2 L3→V2 ทำให้แรงดันขดลวดหลังเปลี่ยนนำหน้า 30° ส่วนแบบตามหลัง L1→V2 L2→W2 L3→U2 ทำให้ล้าหลัง 30° ซึ่งใกล้มุมของแรงดันค้างที่ล้าหลังอยู่แล้ว ผลจำลองปั๊มได้ยอด 9.7·In เทียบ 11.5·In และแรงบิดติดลบ −0.5·Tn เทียบ −4.4·Tn จึงแนะนำแบบตามหลัง

    เดินมอเตอร์แบบสตาร์ตลอดเวลาเพื่อประหยัดไฟได้ไหม?

    ได้เฉพาะเมื่อโหลดเบามาก ในสตาร์แรงดันขดลวดเหลือ 1/√3 แกนเหล็กและกระแสแม่เหล็กลดลง แต่แรงบิดสูงสุดเหลือ 1/3 และสลิปเพิ่มราว 3 เท่า แบบจำลองมอเตอร์ 7.5 kW ประหยัด 188 W ที่โหลด 25 % (cos φ 0.46 → 0.79) จุดคุ้มทุนราว 50 % แต่ควรใช้จริงไม่เกิน 35–40 % ของพิกัดเพื่อเผื่อแรงบิด ≥ 2.5 เท่า และต้องมีรีเลย์วัดกำลังสลับกลับเป็นเดลต้าอัตโนมัติ

    สตาร์ (Star) กับวาย (Wye) ต่างกันไหม?

    ไม่ต่างกัน เป็นการต่อแบบเดียวกัน คือนำปลายขดทั้งสามมาต่อรวมเป็นจุดนิวทรัล ยุโรปและเอเชียเรียก star (Y) อเมริกาเรียก wye ชุดสตาร์ทจึงเรียกได้ทั้ง star-delta starter และ wye-delta starter ส่วนเดลต้า (Δ) บางตำราเรียก mesh

    สตาร์-เดลต้าประหยัดพลังงานกว่าสตาร์ทตรงไหม?

    ไม่ประหยัดพลังงาน พลังงานที่ใช้สตาร์ทหนึ่งครั้งน้อยมาก (หลักสิบ kJ คือหลักหนึ่งในร้อยหน่วย) สิ่งที่สตาร์-เดลต้าลดได้คือกระแสและแรงดันตกช่วงเร่ง และ I²t ของสายจ่ายราวครึ่งหนึ่งสำหรับโหลดความเฉื่อยสูง แต่โรเตอร์จะร้อนมากกว่า DOL ราว 30–55 % เพราะเร่งด้วยสลิปสูงนานกว่า
