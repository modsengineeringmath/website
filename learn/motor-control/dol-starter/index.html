// บทที่ 21.6 · ควบคุมมอเตอร์ AC · Direct-On-Line Starter

วงจรสตาร์ทมอเตอร์โดยตรง (DOL): วงจรกำลัง วงจรควบคุมแบบล็อกตัวเอง ควบคุมสองจุด จ็อก และการเลือกอุปกรณ์ทีละขั้น

DOL คือวงจรมอเตอร์ที่ง่ายและพบมากที่สุด และเป็นแม่แบบของวงจรอื่นทั้งหมด: กลับทางหมุนคือ DOL สองชุดที่อินเตอร์ล็อกกัน สตาร์ท-เดลต้าคือ DOL ที่เพิ่มคอนแทกเตอร์และไทเมอร์ ถ้าเข้าใจหน้านี้ลึก หน้าต่อไปจะง่ายมาก

เขียนโดย อาจารย์มดอัปเดต 14 ต.ค. 2569
สรุปใน 30 วินาที
  • วงจรกำลัง: Q1 (ลัดวงจร) → K1 (ตัด-ต่อ) → F2 (โหลดเกิน) → มอเตอร์
  • วงจรควบคุม: F2 95-96 → STOP (NC) → [START (NO) ∥ K1 13-14] → คอยล์ K1
  • STOP ทุกจุดต่ออนุกรม START ทุกจุดต่อขนาน
  • ล็อกตัวเองให้ความปลอดภัยแบบ no-volt release: ไฟดับแล้วไม่สตาร์ทเอง
  • มอเตอร์ 7.5 kW: MPCB 13–18 A · คอนแทกเตอร์ 18 A AC-3 · สาย 2.5 mm² (≤ 60 m)

ลำดับการทำงาน

  1. สภาวะปกติ: F2 95-96 ปิด · S0 ปิด · S1 เปิด · K1 13-14 เปิด → คอยล์ไม่มีไฟ
  2. กด S1: ไฟผ่าน S1 ถึงคอยล์ K1 → K1 ดูด → หน้าสัมผัสหลักต่อมอเตอร์ · 13-14 ปิด · 43-44 ไฟเดินติด
  3. ปล่อย S1: ไฟยังไปถึงคอยล์ผ่าน 13-14 ซึ่งขนานกับ S1 → ล็อกตัวเอง
  4. กด S0: ตัดเส้นทางทั้งหมด → K1 ปล่อย → 13-14 เปิด → ปล่อย S0 แล้วก็ไม่กลับมา
  5. โหลดเกิน: F2 95-96 เปิดเหมือนกด STOP · 97-98 ปิด ไฟทริปติด · ต้องแก้สาเหตุแล้วรีเซ็ต
  6. ไฟดับ: คอยล์หมดไฟ K1 ปล่อย ล็อกหาย → ไฟกลับมามอเตอร์ไม่เดินเอง

K1ใหม่=F2‾⋅S0‾⋅(S1+K1เดิม)K1_{\text{ใหม่}} = \overline{F2}\cdot\overline{S0}\cdot(S1 + K1_{\text{เดิม}})K1ใหม่​=F2⋅S0⋅(S1+K1เดิม​)

ทำไม STOP ต้องเป็น NC: ถ้าใช้ปุ่ม NO แล้วออกแบบให้ “กดเพื่อตัด” สายหลุดหรือหน้าสัมผัสสกปรกจะทำให้กด STOP แล้วไม่มีผล ปุ่ม NC ที่ต่ออนุกรม ถ้าสายขาดเครื่องจะหยุดเอง — ล้มเหลวแบบปลอดภัย (fail-safe) เหตุผลเดียวกันใช้กับโอเวอร์โหลด 95-96 และหยุดฉุกเฉิน

ควบคุมหลายจุดและจ็อก กลาง

เครื่องจักรมักต้องสั่งได้ทั้งที่ตู้และที่หน้างาน กฎคือ STOP ทุกตัวต่ออนุกรม (กดตัวไหนก็หยุด) และ START ทุกตัวต่อขนาน (กดตัวไหนก็เดิน) ปุ่มจ็อก (inching) ให้มอเตอร์เดินเฉพาะขณะกด ใช้ตั้งตำแหน่งสายพานหรือเครื่องมือ ทำได้ด้วยปุ่มคู่ NO+NC: ส่วน NC ตัดเส้นทางล็อกตัวเอง ส่วน NO จ่ายคอยล์โดยตรง

งานจ็อกบ่อย ๆ คือ AC-4 หน้าสัมผัสคอนแทกเตอร์ตัดกระแสสตาร์ททุกครั้ง ต้องลดพิกัดคอนแทกเตอร์หรือเลือกขนาดใหญ่ขึ้น และระวังมอเตอร์ร้อนจากการสตาร์ทถี่

เดินสายในตู้: แนวปฏิบัติ

  • สีสายวงจรกำลังตามมาตรฐานที่ใช้ (ไทยตาม วสท.: L1 น้ำตาล L2 ดำ L3 เทา N ฟ้า PE เขียวคาดเหลือง) วงจรควบคุมใช้สีแยก เช่น แดง (AC) น้ำเงินเข้ม (DC)
  • สวมปลอกเลขสายทั้งสองปลายตามแบบ ย้ำหางปลา/ปลอกย้ำสาย (ferrule) ทุกเส้นที่เป็นสายฝอย
  • ปุ่มกดหน้าตู้ต่อผ่านรางเทอร์มินัล -X1 ไม่ต่อตรงจากอุปกรณ์ในตู้ เพื่อถอดประตูซ่อมได้
  • ทดสอบวงจรควบคุมก่อนต่อมอเตอร์: ปลดวงจรกำลัง กด START/STOP ดูคอนแทกเตอร์และไฟแสดงทำงานถูกลำดับ
  • ทดสอบโอเวอร์โหลดด้วยปุ่ม TEST ระหว่างเดิน ต้องหยุดและไฟทริปติด

คำถามที่พบบ่อย

ทำไมต้องใช้หน้าสัมผัสช่วยล็อกตัวเอง ไม่ใช้สวิตช์ค้าง?

เพื่อความปลอดภัย: เมื่อไฟดับแล้วกลับมา วงจรล็อกตัวเองจะไม่สตาร์ทมอเตอร์เอง (no-volt release) เพราะคอนแทกเตอร์ปล่อยตอนไฟดับและต้องมีคนกด START ใหม่ ถ้าใช้สวิตช์ค้าง มอเตอร์จะเดินทันทีที่ไฟกลับ ซึ่งอันตรายกับคนที่กำลังซ่อมเครื่อง (IEC 60204-1 กำหนดเรื่องการป้องกันการสตาร์ทเองโดยไม่ตั้งใจ)

มอเตอร์ขนาดเท่าไรสตาร์ทตรงได้?

ไม่มีตัวเลขเดียว ขึ้นกับความแข็งแรงของแหล่งจ่าย (ขนาดหม้อแปลง ความยาวสาย) และข้อกำหนดของการไฟฟ้า หลักทั่วไปคือแรงดันตกขณะสตาร์ทที่ตู้เมนไม่ควรเกิน 10–15 % และไม่กระทบอุปกรณ์อื่น ใช้เครื่องคำนวณแรงดันตกในหน้านี้ตรวจ และตรวจข้อกำหนดการขอใช้ไฟในพื้นที่

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
