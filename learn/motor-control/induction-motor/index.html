ส่วนประกอบ พื้นฐาน

มอเตอร์เหนี่ยวนำกรงกระรอก (squirrel-cage) ที่ใช้มากที่สุดในโรงงานมีสองส่วน: สเตเตอร์ แกนเหล็กแผ่นบางที่มีขดลวดสามชุดวางห่างกัน 120° ทางไฟฟ้า และ โรเตอร์ ที่เป็นแท่งอะลูมิเนียมหรือทองแดงหล่อเข้ากับแหวนลัดวงจรทั้งสองปลาย ไม่มีแปรงถ่าน ไม่มีคอมมิวเตเตอร์ จึงทนทานและบำรุงรักษาน้อย แบบที่พบบ่อยคือ TEFC (Totally Enclosed Fan Cooled, รหัส IC411) มีพัดลมบนเพลาเป่าลมผ่านครีบ

สนามแม่เหล็กหมุนและความเร็วซิงโครนัส พื้นฐาน

เมื่อป้อนกระแสสามเฟสที่ห่างกัน 120° ทางเวลา เข้าขดลวดที่วางห่างกัน 120° ทางพื้นที่ ผลรวมเวกเตอร์ของสนามทั้งสามมีขนาดคงที่เท่ากับ 1.5 เท่าของสนามสูงสุดของเฟสเดียว และ หมุน ไปรอบสเตเตอร์ด้วยความเร็วคงที่ นี่คือหัวใจของมอเตอร์ AC สามเฟส: สร้างการหมุนได้โดยไม่มีชิ้นส่วนเคลื่อนที่

กราฟแรงบิด-ความเร็ว และกระแสสตาร์ท กลาง

กราฟในรูป 4 คำนวณจากวงจรสมมูลของมอเตอร์ตัวอย่าง (โรเตอร์กรงคู่ ปรับค่าให้ตรงข้อมูลแคตตาล็อกทั่วไป) จุดที่ต้องรู้จัก:

  • แรงบิดเริ่ม (locked-rotor torque) Ts ≈ 2.2 Tn ที่ n = 0 — ต้องมากกว่าแรงบิดเริ่มของโหลดพอสมควร
  • แรงบิดสูงสุด (breakdown) Tk ≈ 3 Tn ใกล้ 85–90 % ความเร็ว — ถ้าโหลดเกินจุดนี้มอเตอร์จะหยุด (stall)
  • ย่านทำงาน ด้านขวาของจุดแรงบิดสูงสุด กราฟเกือบเป็นเส้นตรง แรงบิดแปรตามสลิป
  • กระแสสตาร์ท ≈ 6.5 In แทบไม่ลดลงจนความเร็วถึง 80 % — ช่วงเร่งทั้งหมดจึงเป็นช่วงกระแสสูง

คำถามที่พบบ่อย

ทำไมมอเตอร์เหนี่ยวนำหมุนช้ากว่าความเร็วซิงโครนัส?

แรงบิดเกิดจากกระแสที่ถูกเหนี่ยวนำในโรเตอร์ ซึ่งต้องมีการตัดกันระหว่างสนามหมุนกับตัวนำโรเตอร์ ถ้าโรเตอร์หมุนเท่าสนามพอดี จะไม่มีการตัดเส้นแรง ไม่มีกระแส ไม่มีแรงบิด จึงต้องช้ากว่าเสมอ ส่วนต่างนี้คือสลิป ประมาณ 1–5 % ที่โหลดพิกัด

กระแสสตาร์ทสูงทำไมแต่มอเตอร์ไม่ไหม้?

กระแสสูงอยู่เพียงช่วงเร่งความเร็วไม่กี่วินาที ความร้อนสะสมตาม I²t ยังน้อยกว่าที่ฉนวนรับได้ แต่ถ้าโรเตอร์ถูกล็อกหรือเร่งช้าเกิน (โหลดเฉื่อยมาก แรงดันตก) ความร้อนจะสูงจนต้องอาศัยโอเวอร์โหลดคลาสที่เหมาะสมตัดก่อน

กำลังบนแผ่นป้ายเป็นกำลังไฟฟ้าหรือกำลังกล?

เป็นกำลังกลที่เพลา (output) ตาม IEC 60034-1 กำลังไฟฟ้าที่ดึงจากระบบมากกว่านี้เท่ากับ P/η เช่น 7.5 kW ประสิทธิภาพ 90.4 % ดึงไฟ 8.3 kW

เว็บไซต์ หน้าแรก คลังความรู้ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
