อินเวอร์เตอร์แต่ละยี่ห้อตั้งชื่อพารามิเตอร์ต่างกัน แต่สิ่งที่ต้องตั้งเหมือนกันทุกยี่ห้อ หน้านี้ให้ลำดับการตั้งค่าที่ใช้ได้ทั่วไป ตัวอย่างงานที่พบบ่อยที่สุด และวิธีพิสูจน์ด้วยตัวเลขว่าอินเวอร์เตอร์คุ้มค่าหรือไม่

สรุปใน 30 วินาที

- ใส่ข้อมูลแผ่นป้ายให้ครบ แล้ว auto-tune ก่อนทำอย่างอื่น

- เวลาเร่ง-ลดสั้นเกิน → ทริป OC/OV · ยาวเกิน → ตอบสนองช้า

- แอนะล็อก: $f = f_{min} + (f_{max} - f_{min})\cdot\frac{x - x_0}{x_1 - x_0}$

- ปั๊ม-พัดลม: $P \propto n^3$ ลด 20 % ความเร็ว กำลังเหลือ ~51 % (ถ้าไม่มีหัวสถิต)

- ภูมิอากาศร้อนชื้น: ตรวจอุณหภูมิในตู้ ลดพิกัดตามคู่มือ

## ขั้นตอนตั้งค่า 12 ข้อ พื้นฐาน

- รีเซ็ตเป็นค่าโรงงาน (เมื่อรับเครื่องเก่ามาใช้ใหม่)

- ข้อมูลมอเตอร์: แรงดัน กระแส กำลัง ความถี่ ความเร็ว cos φ จากแผ่นป้าย (ตามการต่อ Y/Δ ที่ใช้จริง)

- Auto-tune: แบบหยุดนิ่ง (static) ถ้าแยกโหลดไม่ได้ แบบหมุน (rotating) ถ้าปลดโหลดได้

- โหมดควบคุม: V/f สำหรับปั๊ม-พัดลม หรือหลายมอเตอร์ · vector สำหรับแรงบิดสูงที่รอบต่ำ

- ความถี่ต่ำสุด-สูงสุด: เช่น 20–50 Hz สำหรับปั๊ม (ต่ำกว่านั้นน้ำไม่ขึ้น)

- เวลาเร่ง-ลด: เริ่ม 5–10 s แล้วปรับ (ดู P1)

- วิธีหยุด: ramp (ลดตามเวลา) หรือ coast (ปล่อยหมุนอิสระ) — พัดลมใหญ่มัก coast

- แหล่งคำสั่ง: keypad / ขั้วต่อ (DI) / สื่อสาร (Modbus) · แหล่งความเร็ว: keypad / AI / preset / bus

- อินพุตดิจิทัล: RUN FWD, RUN REV, reset, preset speed, external fault

- อินพุตแอนะล็อก: ชนิด (0–10 V หรือ 4–20 mA) และการสเกล (ดู P2)

- เอาต์พุต: รีเลย์ fault/run ไปไฟแสดงหรือ PLC · AO แสดงความถี่หรือกระแส

- ทดสอบ: เดินตัวเปล่า ตรวจทิศหมุน (กลับทางด้วยพารามิเตอร์ได้) ใส่โหลด วัดกระแส บันทึกค่าทั้งหมด

ชื่อพารามิเตอร์ที่หน้าที่ตรงกัน (ตัวอย่างคำที่ผู้ผลิตใช้)

| หน้าที่ | คำที่พบในคู่มือ |

| กระแสพิกัดมอเตอร์ | Motor rated current · Rated motor current · Nominal current |

| เวลาเร่ง / ลด | Acceleration time · Ramp-up time · Accel 1 / Decel 1 |

| แหล่งคำสั่งเดิน | Run command source · Control place · Operation mode |

| แหล่งความถี่ | Frequency reference · Speed setpoint source |

| ความถี่สวิตช์ | Carrier frequency · PWM frequency · Switching frequency |

P1 Minimum ramp time เวลาเร่งต่ำสุดที่ไม่ทริป

$$t_{acc,min} \approx \frac{J\,\omega_n}{T_{lim} - \overline{T_L}} \qquad T_{lim} \approx 1.5\,T_n\ \ (\text{ตามขีดกระแสไดรฟ์})$$

P2 Analog reference scaling สเกลอินพุตแอนะล็อก

$$f = f_{min} + (f_{max} - f_{min})\,\frac{x - x_0}{x_1 - x_0} \qquad x: 0\text{–}10\ \text{V หรือ } 4\text{–}20\ \text{mA}$$

## ปั๊มน้ำแรงดันคงที่ด้วย PID ในไดรฟ์ กลาง

ระบบประปาอาคารแบบบูสเตอร์ใช้ทรานสมิตเตอร์ความดัน 4–20 mA ต่อเข้า AI ของไดรฟ์ ตั้งค่าเป้าหมาย (เช่น 3.5 bar) ไดรฟ์คำนวณ PID ปรับความถี่ให้ความดันคงที่แม้การใช้น้ำเปลี่ยน ฟังก์ชันที่ควรตั้ง:

- Sleep / wake-up: เมื่อไม่มีการใช้น้ำ ความถี่ลดถึงค่าต่ำนานเกินเวลาหนึ่ง ไดรฟ์หยุดปั๊ม และกลับมาเดินเมื่อความดันตกต่ำกว่าเป้าหมายระดับหนึ่ง

- Dry-run protection: กระแสหรือกำลังต่ำผิดปกติที่ความถี่สูง = ปั๊มเดินแห้ง ให้หยุดและแจ้งเตือน

- Pipe fill: เติมท่อช้า ๆ ตอนเริ่มเพื่อกันค้อนน้ำ

- Multi-pump: ไดรฟ์หลายรุ่นสั่งปั๊มตัวที่สอง (DOL หรือไดรฟ์อีกตัว) เมื่อความต้องการเกิน

ทฤษฎีของ PID และการปรับจูนอยู่ใน ระบบควบคุม: PID และตัวอย่าง PLC สั่ง VFD อยู่ใน PLC อนาล็อก PID

## กฎแอฟฟินิตีและการประหยัดพลังงาน กลาง

รูป 1 · ซ้าย: กฎแอฟฟินิตี · ขวา: ที่อัตราไหล 80 % การหรี่วาล์วยังใช้กำลังราว 90 % ขณะที่ VFD ใช้ราว 55 %

P3 Affinity law — flow อัตราไหล

$$\frac{Q_2}{Q_1} = \frac{n_2}{n_1}$$

P4 Affinity law — head หัวหรือความดัน

$$\frac{H_2}{H_1} = \left(\frac{n_2}{n_1}\right)^2$$

P5 Affinity law — power กำลัง

$$\frac{P_2}{P_1} = \left(\frac{n_2}{n_1}\right)^3$$

P6 System with static head ระบบที่มีหัวสถิต

$$H_{sys} = H_{st} + kQ^2 \qquad \frac{n}{n_1} \approx \sqrt{h_0 + (1 - h_0)q^2} \quad (h_0 = H_{st}/H_1,\ q = Q/Q_1)$$

P7 Energy saved พลังงานที่ประหยัดต่อปี

$$\Delta E = (P_{throttle} - P_{VFD})\,h \qquad \text{เงิน} = \Delta E \times \text{ค่าไฟต่อ kWh}$$

P8 Simple payback ระยะคืนทุนอย่างง่าย

$$t_{payback} = \frac{\text{ราคา VFD ติดตั้ง}}{\text{เงินที่ประหยัดต่อปี}}$$

ตัวอย่าง P-2

### พัดลมระบายอากาศ 30 kW เดิน 6,000 ชม./ปี ใช้อัตราไหลเฉลี่ย 75 % ค่าไฟ 4.5 บาท/kWh

- หรี่แดมเปอร์: $P \approx 30(0.55 + 0.45 \times 0.75) = 26.6$ kW

- VFD (P5, ไม่มีหัวสถิต): $30 \times 0.75^3 / 0.97 + 0.6 = 13.6$ kW (รวมสูญเสียไดรฟ์)

- P7: $\Delta E = (26.6 - 13.6)(6000) = 78{,}000$ kWh/ปี ≈ 351,000 บาท/ปี

- P8: ไดรฟ์ติดตั้ง 180,000 บาท → คืนทุน ~0.5 ปี

## ติดตั้งในภูมิอากาศร้อนชื้น กลาง

- พิกัดอินเวอร์เตอร์ส่วนใหญ่กำหนดที่อุณหภูมิแวดล้อม 40 °C (บางรุ่น 50 °C) เกินกว่านั้นลดพิกัดประมาณ 1–2.5 %/°C ตามคู่มือ — ตู้กลางแดดในเขตร้อนภายในอาจเกิน 50 °C

- สูงเหนือน้ำทะเลเกิน 1000 m ลดพิกัด ~1 % ต่อ 100 m

- ความชื้นสูงและการกลั่นตัว: ใช้ฮีตเตอร์กันชื้นในตู้ที่หยุดเดินนาน และเลือกแผงวงจรเคลือบ (conformal coating, 3C2/3C3)

- ระบายความร้อน: กำลังสูญเสียของไดรฟ์ ~2–3 % ของกำลัง ต้องรวมในการคำนวณพัดลมตู้ (ดู K7)

## บายพาสและมอเตอร์หลายตัว ขั้นสูง

งานสำคัญ (ปั๊มดับเพลิงห้ามใช้ VFD เป็นทางเดียว ปั๊มน้ำเสียหลัก) อาจต้องมีบายพาส: คอนแทกเตอร์ KM-VFD (ด้านออกไดรฟ์) และ KM-BYP (จากเมนตรงเข้ามอเตอร์) อินเตอร์ล็อกทั้งไฟฟ้าและกลไก สลับได้เมื่อไดรฟ์หยุดและมอเตอร์ไม่มีไฟเท่านั้น และต้องมีโอเวอร์โหลดสำหรับเส้นทางบายพาส ไดรฟ์ตัวเดียวขับมอเตอร์หลายตัวพร้อมกันได้ในโหมด V/f โดยเลือกไดรฟ์ ≥ ผลรวมกระแส × 1.1 และมีโอเวอร์โหลดแยกแต่ละตัว

## รหัสความผิดพลาดที่พบบ่อย

| รหัส (ทั่วไป) | ความหมาย | สาเหตุ/วิธีแก้ |

| OC / Overcurrent | กระแสเกินทันที | เร่งเร็วเกิน สายมอเตอร์ลัด ไม่ได้ auto-tune บูสต์สูงเกิน |

| OV / DC overvoltage | บัส DC สูงเกิน | ลดความเร็วเร็วเกิน โหลดดันกลับ ไฟเข้าสูง → เพิ่ม decel หรือใส่ตัวต้านทานเบรก |

| UV / Undervoltage | บัส DC ต่ำ | ไฟตก เฟสเข้าขาด ฟิวส์ด้านเข้าขาด |

| OH / Overtemperature | ฮีตซิงก์ร้อน | พัดลมไดรฟ์เสีย ตู้ร้อน ฝุ่นอุดตัน ความถี่สวิตช์สูง |

| OL / Motor overload | แบบจำลองความร้อนมอเตอร์เต็ม | โหลดเกิน เดินรอบต่ำแรงบิดสูงนาน ตั้งค่ากระแสมอเตอร์ผิด |

| GF / Earth fault | กระแสรั่วลงดินด้านออก | ฉนวนสายหรือมอเตอร์เสื่อม ความชื้นในกล่องขั้ว |

| PHL / Input phase loss | เฟสเข้าขาดหรือไม่สมดุล | ตรวจฟิวส์ ขั้วต่อ แรงดันสามเฟส |
