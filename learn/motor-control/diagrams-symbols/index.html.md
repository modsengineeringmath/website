# อ่านแบบวงจรควบคุมมอเตอร์: สัญลักษณ์ IEC 60617 เทียบ NEMA รหัสอุปกรณ์ IEC 81346 เลขขั้ว เลขสาย และการอ้างอิงข้าม

// บทที่ 21.5 · ควบคุมมอเตอร์ AC · Symbols & Reading Diagrams


แบบวงจรคือภาษากลางระหว่างผู้ออกแบบ ช่างประกอบตู้ และช่างซ่อม ถ้าอ่านคล่อง จะเดินสายถูกตั้งแต่ครั้งแรก และหาจุดเสียได้จากแบบโดยไม่ต้องรื้อตู้ หน้านี้สอนอ่านแบบตามธรรมเนียม IEC ที่ใช้ในชุดนี้ และเทียบกับแบบอเมริกาที่พบในเครื่องจักรนำเข้า

สรุปใน 30 วินาที

- แบบมีสองส่วน: วงจรกำลัง (400 V ไปมอเตอร์) และ วงจรควบคุม (230 VAC/24 VDC ไปคอยล์)

- หน้าสัมผัสวาดในสถานะปกติเสมอ (ไม่มีไฟเลี้ยง ไม่ถูกกด)

- อนุกรม = AND · ขนาน = OR · NC = NOT — อ่านวงจรควบคุมเป็นตรรกะได้ทันที

- รหัสอุปกรณ์ + เลขขั้ว เช่น “-K1:13” ระบุจุดต่อได้ไม่ซ้ำในทั้งตู้

## วงจรกำลังและวงจรควบคุม พื้นฐาน

วงจรกำลัง (main circuit) วาดสามเส้น L1 L2 L3 ลงจากด้านบนผ่านเบรกเกอร์ คอนแทกเตอร์ โอเวอร์โหลด ไปมอเตอร์ อ่านจากบนลงล่างตามทางไหลของพลังงาน วงจรควบคุม (control circuit) วาดระหว่างรางบน (L หรือ +24 V) กับรางล่าง (N หรือ 0 V) แต่ละเส้นทางแนวตั้งเรียกว่า “path” หรือ “current path” มีหมายเลขคอลัมน์กำกับด้านบน สัญลักษณ์ของอุปกรณ์ชิ้นเดียวกัน (เช่น คอยล์ -K1 และหน้าสัมผัส -K1 13-14) อาจอยู่คนละคอลัมน์หรือคนละหน้า เชื่อมกันด้วยรหัสอุปกรณ์

วงจรกำลัง: อ่านบน → ล่าง

วงจรควบคุม: ราง L → อุปกรณ์ → คอยล์ → ราง N

## สัญลักษณ์ IEC 60617 พื้นฐาน

รูป 1 · เส้นประจากหน้าสัมผัสคือการเชื่อมทางกล เช่น ปุ่มกด (รูปวงเล็บเหลี่ยม) ลูกลอย สวิตช์ความดัน หรืออุปกรณ์ทางความร้อนของโอเวอร์โหลด

### กฎการวาดที่ต้องรู้

- หน้าสัมผัสวาดในสถานะ “ไม่มีไฟ ไม่ถูกกระทำ” — ลิมิตสวิตช์ที่ปกติถูกกดค้างจะมีหมายเหตุกำกับ

- หน้าสัมผัส NO วาดใบมีดเอียงไปทางซ้าย NC มีขีดขวางที่จุดสัมผัส

- สัญลักษณ์ครึ่งวงกลมบนหน้าสัมผัสไทเมอร์บอกทิศของการหน่วงเวลา (เหมือนร่มชูชีพ)

- จุดทึบ (●) คือจุดต่อสาย เส้นที่ตัดกันโดยไม่มีจุด ไม่ได้ต่อกัน

## รหัสอุปกรณ์และเลขขั้ว กลาง

| รหัสแบบเดิม (ใช้ในชุดนี้) | IEC 81346-2 ฉบับใหม่ (ตัวอย่าง) | อุปกรณ์ |

| -Q | -QA | เบรกเกอร์ MPCB สวิตช์ตัดตอน (และคอนแทกเตอร์กำลังในฉบับใหม่) |

| -K | -QA (คอนแทกเตอร์) · -KF (รีเลย์ ไทเมอร์ PLC) | คอนแทกเตอร์ รีเลย์ ไทเมอร์ |

| -F | -FC | ฟิวส์ โอเวอร์โหลด อุปกรณ์ป้องกัน |

| -S | -SF | ปุ่มกด สวิตช์เลือก (คนสั่ง) |

| -B | -BG -BP -BL | เซนเซอร์ ลิมิตสวิตช์ สวิตช์ความดัน ลูกลอย |

| -P / -H | -PF -PG | หลอดไฟแสดงสถานะ มิเตอร์ |

| -M | -MA | มอเตอร์ |

| -X | -XD | รางเทอร์มินัล |

| -T | -TA | หม้อแปลง พาวเวอร์ซัพพลาย (ฉบับใหม่ใช้ T กับการแปลงพลังงาน) |

เลขขั้วอ่านคู่กับรหัสเสมอ เช่น “-K1:A1” คือขั้วคอยล์ของคอนแทกเตอร์ K1 “-X1:5” คือขั้วที่ 5 ของรางเทอร์มินัล X1 เลขสายในแบบมักตั้งตามหมายเลขหน้าและคอลัมน์ (เช่น สาย 2.4 คือสายในหน้า 2 คอลัมน์ 4) ทำให้ตามสายในตู้ได้จริง

### ตารางอ้างอิงข้าม (cross reference)

ใต้คอยล์แต่ละตัวในแบบ IEC มักมีตารางเล็ก ๆ บอกว่าหน้าสัมผัสของมันอยู่ที่ไหน เช่น

-K1
1-2 │ 3.2 ← หน้าสัมผัสหลัก อยู่หน้า 3 คอลัมน์ 2
13-14 │ 4.3 ← NO ใช้ล็อกตัวเอง หน้า 4 คอลัมน์ 3
21-22 │ 4.6 ← NC ใช้อินเตอร์ล็อก หน้า 4 คอลัมน์ 6
43-44 │ 4.8 ← NO ไฟเดิน

## อ่านวงจรควบคุมเป็นตรรกะ กลาง

ทางเดินไฟไปถึงคอยล์เมื่อมีอย่างน้อยหนึ่งเส้นทางที่หน้าสัมผัสปิดทั้งหมด จึงเขียนเป็นพีชคณิตบูลีนได้ ซึ่งเป็นพื้นฐานของการเขียนแลดเดอร์ใน PLC

G1 Series = AND หน้าสัมผัสอนุกรม

$$K = A \cdot B$$

G2 Parallel = OR หน้าสัมผัสขนาน

$$K = A + B$$

G3 NC contact = NOT หน้าสัมผัสปกติปิด

$$K = \overline{A}$$

G4 Self-holding (seal-in) สมการล็อกตัวเอง

$$K1 = \overline{S0}\cdot\overline{F2}\cdot(S1 + K1)$$

ตัวอย่าง G-1

### อ่านวงจร DOL เป็นสมการ

- เส้นทางเดียวจากราง L: F2 (95-96, NC) → S0 (NC) → [S1 (NO) ขนาน K1 13-14] → คอยล์ K1

- แทน NC ด้วย NOT ของ “ถูกกระทำ”: $K1 = \overline{F2}\cdot\overline{S0}\cdot(S1 + K1)$ — ตรงกับ G4

- ตรวจ: กด S1 → K1 = 1 · ปล่อย S1 → เทอม K1 ค้างไว้ · กด S0 หรือ F2 ทริป → K1 = 0 และไม่กลับมาเองเมื่อปล่อย

## แบบอเมริกา (NEMA/ANSI) และญี่ปุ่น กลาง

| เรื่อง | IEC (ยุโรป · ไทย · อาเซียน) | NEMA / JIC (อเมริกาเหนือ) |

| ทิศการวาด | รางบน-ล่าง วงจรแนวตั้ง | รางซ้าย-ขวา วงจรแนวนอนเป็นขั้นบันได (ladder) |

| หน้าสัมผัส NO | ใบมีดเอียง | เส้นขนานสองเส้น ─┤ ├─ |

| หน้าสัมผัส NC | ใบมีดเอียงพาดขีด | เส้นขนานมีเส้นทแยง ─┤/├─ |

| คอยล์ | สี่เหลี่ยม | วงกลม มีตัวอักษร M, CR, TR |

| รหัสอุปกรณ์ | -K1 -S1 -F2 | M (มอเตอร์สตาร์ทเตอร์) CR (รีเลย์) OL PB LS |

| แรงดันควบคุม | 230 VAC / 24 VDC | 120 VAC จากหม้อแปลงควบคุม / 24 VDC |

แบบญี่ปุ่นปัจจุบันใช้ JIS C 0617 ซึ่งตรงกับ IEC 60617 แต่เครื่องจักรรุ่นเก่ายังพบสัญลักษณ์แบบเดิม แลดเดอร์ใน PLC ทุกยี่ห้อวาดแบบแนวนอนคล้าย NEMA

## ขั้นตอนอ่านแบบเพื่อหาจุดเสีย

- เริ่มที่มอเตอร์/โหลดที่มีปัญหา ดูรหัสอุปกรณ์ในวงจรกำลัง (เช่น -K3)

- หาคอยล์ -K3 ในวงจรควบคุม แล้วไล่จากราง L ลงมาทีละอุปกรณ์

- วัดแรงดันเทียบราง N ทีละจุด จุดแรกที่ “ไม่มีไฟ” อยู่หลังอุปกรณ์ที่เปิดวงจร

- ดูตารางอ้างอิงข้ามว่าหน้าสัมผัสที่เปิดอยู่ (เช่น -K2 21-22) ขึ้นกับอุปกรณ์ตัวใด แล้วตามต่อ

## คำถามที่พบบ่อย

แบบวงจรแสดงหน้าสัมผัสในสถานะใด?
สถานะปกติ คือไม่มีไฟเลี้ยงคอยล์ ไม่มีใครกดปุ่ม และไม่มีแรงกระทำกับเซนเซอร์ (de-energised, unactuated) NO จึงวาดเป็นเปิด NC วาดเป็นปิด แม้ในการใช้งานจริงคอนแทกเตอร์จะดูดอยู่เกือบตลอดก็ตาม

ทำไมบางแบบใช้ K สำหรับคอนแทกเตอร์ บางแบบใช้ Q?
ธรรมเนียมเดิมของ IEC/DIN ใช้ K กับคอนแทกเตอร์และรีเลย์ ส่วน IEC 81346-2 ฉบับใหม่จัดคอนแทกเตอร์กำลังไว้กลุ่ม Q (สวิตช์ตัด-ต่อพลังงาน) เช่น -QA1 และรีเลย์ควบคุมไว้กลุ่ม K เช่น -KF1 ทั้งสองแบบพบได้ในแบบจริง ให้ดูหน้าคำอธิบายรหัสของแบบชุดนั้น
