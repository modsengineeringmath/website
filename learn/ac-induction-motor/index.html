// บทที่ 23 · มอเตอร์ไฟฟ้ากระแสสลับ · AC Induction Motors — Complete Guide

มอเตอร์ไฟฟ้ากระแสสลับ (AC Induction Motor) คืออะไร: จากระบบไฟฟ้าไทยถึงกราฟแรงบิด-ความเร็ว การต่อสตาร์-เดลต้า และสูตรออกแบบสาย-เบรกเกอร์

หน้านี้เล่ามอเตอร์เหนี่ยวนำตั้งแต่ไฟฟ้าออกจากโรงไฟฟ้า ผ่านสายส่ง หม้อแปลง ตู้ไฟ จนถึงขดลวดและเพลา แล้วให้ความสำคัญกับเครื่องมือที่วิศวกรต้องดูตลอดเวลา คือ กราฟแรงบิด-ความเร็ว (speed–torque curve) ซ้อนกับเส้นแรงบิดของโหลด เพราะสตาร์ทได้หรือไม่ เร็วแค่ไหน ร้อนแค่ไหน และวิธีสตาร์ทแบบใดใช้ได้ ล้วนอ่านได้จากสองเส้นนี้ กราฟทุกรูปคำนวณจากแบบจำลองมอเตอร์ 7.5 kW 4 ขั้ว 400 V 50 Hz ตัวเดียวกับชุดบทเรียนควบคุมมอเตอร์ ไม่ใช่ภาพวาดประกอบ

รูป 34 อธิบายคำถามยอดฮิต “ทำไมมอเตอร์ 7.5 kW ใช้เบรกเกอร์ลูกย่อย 20 A แบบ C แล้วทริปตอนสตาร์ท” — ส่วนปลดทันทีของแบบ C อยู่ที่ 5–10 เท่า (100–200 A) ทับกระแสสตาร์ท 95 A รวมยอดไซเคิลแรกที่สูงกว่านั้นอีก ทางแก้คือใช้ MPCB หรือเบรกเกอร์แบบ D/MCCB ที่ออกแบบสำหรับมอเตอร์ ไม่ใช่เพิ่มขนาดเบรกเกอร์จนป้องกันสายไม่ได้

ตัวอย่าง D-2

สายป้อนตู้ MCC ที่มีมอเตอร์ 55 A (สตาร์-เดลต้า) 28 A และ 14.6 A

  1. D3: สายป้อน ≥ 1.25 × 55 + 28 + 14.6 = 111.4 A

  2. เบรกเกอร์วงจรย่อยตัวใหญ่สุด ≤ 2.5 × 55 = 137.5 A → 125 A

  3. เบรกเกอร์สายป้อน ≤ 125 + 28 + 14.6 = 167.6 A → 160 A และสายป้อนต้องรับได้ตามที่เบรกเกอร์ป้องกัน

ขั้นตอนออกแบบ 10 ข้อ ตู้ควบคุม การทดสอบ Megger และตารางแก้ปัญหาอยู่ในบทออกแบบ · ติดตั้ง · แก้ปัญหา ส่วนคลาสทริปของโอเวอร์โหลดและการประสานการป้องกัน Type 1/Type 2 อยู่ในคอนแทกเตอร์ · โอเวอร์โหลด

การควบคุมมอเตอร์ 3 เฟส: เลือกวงจรจากโหลด พื้นฐาน

วงจรควบคุมมอเตอร์ทุกแบบประกอบจากอุปกรณ์ชุดเดียวกัน คือ อุปกรณ์ตัดตอนและป้องกันลัดวงจร (เบรกเกอร์ MPCB ฟิวส์) แมกเนติกคอนแทกเตอร์สำหรับสั่งต่อ-ตัด โอเวอร์โหลดรีเลย์สำหรับป้องกันโหลดเกิน และวงจรควบคุมที่มีปุ่ม START/STOP หน้าสัมผัสช่วยล็อกตัวเอง (self-holding) และอินเตอร์ล็อก เลือกวงจรตามสิ่งที่โหลดต้องการ:

โหลด/ความต้องการวงจรที่ใช้บทเรียน
เดินทางเดียว ระบบไฟรับกระแสสตาร์ทได้สตาร์ทตรง DOL + ล็อกตัวเอง ควบคุมสองจุด จ็อกสตาร์ทตรง DOL
ต้องกลับทาง (ประตูม้วน รอก สายพาน)สลับสองเฟส อินเตอร์ล็อกไฟฟ้า + กล + ปุ่มกด ลิมิตสวิตช์กลับทางหมุน
ปั๊ม พัดลม ต้องลดกระแสสตาร์ทสตาร์-เดลต้า / ซอฟต์สตาร์ทสตาร์-เดลต้า · ซอฟต์สตาร์ท
ต้องปรับรอบ ประหยัดพลังงาน หรือสตาร์ทโหลดหนักด้วยกระแสต่ำอินเวอร์เตอร์ VFDVFD · ตั้งค่า VFD
หลายมอเตอร์ทำงานตามลำดับ ปั๊มสลับ ลูกลอยวงจรประยุกต์ หรือ PLCวงจรประยุกต์ · PLC คุมมอเตอร์

ลองกดปุ่มและเห็นกระแส แรงบิด ความเร็วของแต่ละวงจรในซิมูเลเตอร์วงจรสตาร์ท ซึ่งใช้แบบจำลองมอเตอร์ตัวเดียวกับหน้านี้

สรุปสำหรับหน้างาน

  1. อ่านแผ่นป้าย แรงดัน (230/400 หรือ 400/690) การต่อ กระแส In Is/In แรงบิด Ts/Tn คลาส IE ความเร็ว
  2. รู้จักโหลด ชนิดเส้นแรงบิด แรงบิดเริ่ม (breakaway) และความเฉื่อยอ้างถึงเพลามอเตอร์
  3. วาดสองเส้น มอเตอร์ (ที่แรงดันขณะสตาร์ทจริง) กับโหลด ตรวจว่าเส้นมอเตอร์อยู่เหนือตลอด แล้วประมาณเวลาเร่ง (L2)
  4. เลือกวิธีสตาร์ท ถูกที่สุดที่ผ่านเงื่อนไขแรงบิดและแรงดันตก · สตาร์-เดลต้าตรวจ Y4 และตั้งไทเมอร์จากเวลาเร่งในสตาร์ ต่อ KM3 ลำดับ U1–V2
  5. ออกแบบสายและการป้องกัน สาย ≥ 125 % In แรงดันตก ≤ 3 % / ≤ 10–15 % ขณะสตาร์ท เบรกเกอร์ ≤ 250 % ตั้งโอเวอร์โหลดเท่า In คลาสตามเวลาเร่ง ตรวจ Icu และกระแสลัดวงจรปลายสาย
  6. ทดสอบ ความต้านทานฉนวน ทิศทางหมุน กระแสขณะสตาร์ทและขณะเดินด้วยแคลมป์มิเตอร์เทียบกับค่าที่คำนวณ

  • IEC 60947-4-1 (คอนแทกเตอร์ สตาร์ทเตอร์ คลาสทริปโอเวอร์โหลด) · IEC 60898-1 (เบรกเกอร์ลูกย่อยแบบ B C D) · IEC 60364-5-52 (พิกัดกระแสสาย)

กราฟและตัวเลขในหน้านี้สร้างด้วยสคริปต์ที่เปิดเผยในคลังซอร์สของเว็บไซต์ (แบบจำลองวงจรสมมูลกรงคู่ แบบจำลองพลวัต αβ และแบบจำลองมอเตอร์ 1 เฟสสองขดลวด) ค่าพารามิเตอร์เลือกให้พฤติกรรมใกล้เคียงแคตตาล็อกทั่วไปเพื่อการสอน ไม่ใช่ข้อมูลของผลิตภัณฑ์ใดผลิตภัณฑ์หนึ่ง

คำถามที่พบบ่อย

มอเตอร์ 3 เฟสต่อสตาร์หรือเดลต้า ดูจากอะไร?

ดูแรงดันบนแผ่นป้ายเทียบกับแรงดันสายของระบบ ระบบไทยคือ 400 V: ป้าย 230/400 V (Δ/Y) ต้องต่อสตาร์ ส่วนป้าย 400/690 V (Δ/Y) ต่อเดลต้า และเฉพาะแบบหลังเท่านั้นที่สตาร์ทแบบสตาร์-เดลต้าได้ เพราะขดลวดทนแรงดันสาย 400 V ตอนวิ่งเดลต้า

ทำไมมอเตอร์ 1 เฟสต้องมีคาปาซิเตอร์ และคาปาซิเตอร์เสียมีอาการอย่างไร?

ขดลวดเฟสเดียวสร้างสนามพัลส์ที่ไม่หมุน แรงบิดตอนหยุดนิ่งเป็นศูนย์ คาปาซิเตอร์ทำให้กระแสขดช่วยต่างเฟสจากขดหลักจนเกิดสนามหมุน ถ้าคาปาซิเตอร์สตาร์ทเสีย มอเตอร์จะครางแต่ไม่หมุน กระแสสูง แต่ถ้าใช้มือหมุนช่วยจะหมุนต่อได้ ถ้าคาปาซิเตอร์รันของแบบ PSC เสื่อม มอเตอร์จะหมุนช้า ร้อน และสตาร์ทยาก

สตาร์-เดลต้าลดกระแสสตาร์ทได้เท่าไร ทำไมบางครั้งเบรกเกอร์ยังทริปตอนเปลี่ยนเป็นเดลต้า?

ช่วงสตาร์ กระแสสายและแรงบิดเหลือ 1/3 ของสตาร์ทตรง แต่ตอนเปลี่ยนเป็นเดลต้ากระแสจะกระโดดตามความเร็วขณะนั้น ถ้าเปลี่ยนเร็วเกินขณะมอเตอร์ยังช้า หรือโหลดหนักจนสตาร์หมุนได้ไม่ถึง ~90 % ความเร็ว กระแสจะเกือบเท่าสตาร์ทตรง และในช่วงตาย 50 ms แรงดันค้างในมอเตอร์เลื่อนเฟส ถ้าต่อเดลต้าผิดลำดับจะเกิดกระแสกระชากสูงกว่าสตาร์ทตรงได้

เลือกขนาดสายไฟและเบรกเกอร์ของมอเตอร์อย่างไร?

ใช้กระแสพิกัดจากแผ่นป้าย สายวงจรย่อยต้องรับกระแสได้ไม่น้อยกว่า 125 % ของกระแสพิกัด แล้วตรวจแรงดันตกขณะเดิน (ไม่เกินราว 3 %) และขณะสตาร์ท (ไม่เกินราว 10–15 %) เบรกเกอร์ป้องกันลัดวงจรแบบเวลาผกผันตั้งได้ไม่เกิน 250 % ของกระแสพิกัด ส่วนการป้องกันโหลดเกินใช้โอเวอร์โหลดรีเลย์หรือ MPCB ตั้งเท่ากระแสแผ่นป้าย

กราฟแรงบิด-ความเร็ว (speed-torque curve) ใช้ดูอะไร และจุดทำงานของมอเตอร์อยู่ตรงไหน?

กราฟบอกแรงบิดที่มอเตอร์ให้ได้ทุกความเร็ว ตั้งแต่แรงบิดเริ่ม แรงบิดสูงสุด จนถึงความเร็วซิงโครนัส เมื่อวาดเส้นแรงบิดของโหลดซ้อน จุดตัดด้านขวาของแรงบิดสูงสุดคือจุดทำงาน ส่วนต่างระหว่างสองเส้นคือแรงบิดเร่งที่บอกว่าสตาร์ทได้หรือไม่และใช้เวลานานเท่าไร

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม · อุปนัย อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
