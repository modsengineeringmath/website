# การควบคุมอัตโนมัติด้วย PLC

THภาษาไทยENEnglish

// บทที่ 22 · PLC Automation · ช่างไฟฟ้า → นักศึกษา → วิศวกร


PLC (Programmable Logic Controller) แทนที่ตู้รีเลย์นับร้อยตัวด้วยโปรแกรมที่แก้ไขได้ ชุดนี้สอนตั้งแต่ PLC สแกนอย่างไร ต่อเซนเซอร์ PNP/NPN ให้ถูก เขียนแลดเดอร์ ไทเมอร์ เคาน์เตอร์ ไปจนถึงควบคุมมอเตอร์ สตาร์-เดลต้า ระบบลำดับขั้น อนาล็อก PID และการสั่งอินเวอร์เตอร์ ทุกตัวอย่างลองได้ทันทีในซิมูเลเตอร์ในหน้าเว็บ มี 43 สูตรที่มีรหัสอ้างอิง และ 10 ตัวอย่าง

สรุปใน 30 วินาที

- PLC วนทำสามอย่างซ้ำทุกไม่กี่มิลลิวินาที: อ่านอินพุต → รันโปรแกรม → เขียนเอาต์พุต

- แลดเดอร์: อนุกรม = AND · ขนาน = OR · NC = NOT · วงจรล็อกตัวเองเหมือนคอนแทกเตอร์

- เซนเซอร์ PNP คู่กับอินพุตแบบซิงก์ (COM ลง 0 V) · NPN คู่กับซอร์ส

- ปุ่ม STOP และหยุดฉุกเฉินต่อแบบ NC และอินเตอร์ล็อกสำคัญต้องคงไว้ในฮาร์ดแวร์

- ไทเมอร์ TON TOF TP และเคาน์เตอร์ CTU CTD ตาม IEC 61131-3 ใช้ได้ทุกยี่ห้อ

## เส้นทางเรียนตามระดับ

ระดับ 1 · ช่าง · ปวช.–ปวส.

### ต่อสายและเขียนแลดเดอร์
PLC คืออะไร ต่อ I/O แลดเดอร์ ล็อกตัวเอง ไทเมอร์ เคาน์เตอร์
พื้นฐาน → ต่อสาย I/O → แลดเดอร์ → ไทเมอร์

ระดับ 2 · ช่างเทคนิค · โปรแกรมเมอร์

### งานจริงในโรงงาน
ควบคุมมอเตอร์ ลำดับขั้น อนาล็อก สั่ง VFD ทดสอบระบบ
ควบคุมมอเตอร์ → ลำดับขั้น → อนาล็อก · PID

ระดับ 3 · นักศึกษาวิศวกรรม · วิศวกร

### ออกแบบเชิงระบบ
พีชคณิตบูลีน สเตตแมชชีน SFC ST เวลาตอบสนอง PID เชิงตัวเลข ความปลอดภัยเชิงฟังก์ชัน
IEC 61131-3 → SFC → ความปลอดภัย

## ลองเลย: PLC สตาร์-เดลต้าในเบราว์เซอร์

กด START (I0.1) แล้วดูเส้นสีเขียวไหลในแลดเดอร์ ไทเมอร์ T1 นับ 6 วินาที K2 (สตาร์) ปล่อย รอช่วงตาย 80 ms แล้ว K3 (เดลต้า) ดูด เลือกตัวอย่างอื่นจากเมนู หรือเปิด “แก้ไขโปรแกรม” เพื่อเขียนเอง ซิมูเลเตอร์เต็มพร้อมใบงานอยู่ที่ ซิมูเลเตอร์แลดเดอร์

ต้องเปิด JavaScript เพื่อใช้ซิมูเลเตอร์

## สมการหลักที่ใช้ทั้งชุด

H1 Worst-case response เวลาตอบสนองแย่ที่สุด

$$t_{resp,max} \approx t_{in} + 2\,t_{scan} + t_{out}$$

H2 Latch rung แลดเดอร์ล็อกตัวเอง

$$Q = \overline{\text{STOP}}\cdot(\text{START} + Q) \;\;\equiv\;\; \text{STOP ต่อ NC → ในโปรแกรมใช้หน้าสัมผัส NO}$$

H3 On-delay timer ไทเมอร์หน่วงเวลาเปิด

$$Q_{TON} = IN \wedge (ET \ge PT) \qquad ET \le PT$$

H4 Analog scaling สเกลค่าแอนะล็อก

$$y = y_{min} + (x - x_{min})\,\frac{y_{max} - y_{min}}{x_{max} - x_{min}}$$

## ค้นหาสูตรทั้งหมดในที่เดียว

## ต่อยอดบนเว็บนี้

- การควบคุมมอเตอร์ไฟฟ้ากระแสสลับ — วงจรคอนแทกเตอร์ทุกแบบที่นำมาเขียนเป็นแลดเดอร์ในชุดนี้

- สัญญาณ 4–20 mA และ HART · Modbus RTU/TCP · แล็บวัดคุมเสมือนที่มี PLC

- ระบบควบคุม: PID — ทฤษฎีเบื้องหลังบล็อก PID ใน PLC

## คำถามที่พบบ่อย

เรียน PLC ต้องรู้อะไรก่อน?
ควรเข้าใจวงจรควบคุมด้วยคอนแทกเตอร์ (ล็อกตัวเอง อินเตอร์ล็อก ไทเมอร์) เพราะแลดเดอร์ถูกออกแบบให้อ่านเหมือนวงจรรีเลย์ และรู้ไฟฟ้าพื้นฐาน 24 VDC กับ 230 VAC เพื่อต่อสาย I/O ได้ถูก ทั้งหมดนี้อยู่ในชุดควบคุมมอเตอร์บนเว็บนี้

ควรเริ่มกับ PLC ยี่ห้อไหน?
หลักการเหมือนกันทุกยี่ห้อเพราะอิงมาตรฐาน IEC 61131 เลือกยี่ห้อที่ใช้ในโรงงานหรือสถานศึกษาใกล้ตัว และที่มีซอฟต์แวร์ฟรีพร้อมซิมูเลเตอร์ ในภูมิภาคนี้พบ Mitsubishi, Omron, Siemens, Delta, Schneider, Rockwell และ Keyence บ่อย

PLC ต่างจาก Arduino หรือไมโครคอนโทรลเลอร์อย่างไร?
PLC ออกแบบมาสำหรับสภาพแวดล้อมโรงงาน: I/O 24 VDC ที่ทนสัญญาณรบกวนและมีการแยกโดดเดี่ยว ทำงานแบบสแกนที่คาดเดาได้ มีการวินิจฉัยตัวเอง ภาษาตามมาตรฐาน ซ่อมและเปลี่ยนโมดูลได้ระหว่างใช้งาน และผ่านการรับรองตามมาตรฐานอุตสาหกรรม ส่วนไมโครคอนโทรลเลอร์ยืดหยุ่นและถูกกว่า แต่ผู้ใช้ต้องสร้างความทนทานเหล่านี้เอง

## คำถามที่พบบ่อย (FAQ)

**เรียน PLC ต้องรู้อะไรก่อน?**
ควรเข้าใจวงจรควบคุมด้วยคอนแทกเตอร์ (ล็อกตัวเอง อินเตอร์ล็อก ไทเมอร์) เพราะแลดเดอร์ถูกออกแบบให้อ่านเหมือนวงจรรีเลย์ และรู้ไฟฟ้าพื้นฐาน 24 VDC กับ 230 VAC เพื่อต่อสาย I/O ได้ถูก ทั้งหมดนี้อยู่ในชุดควบคุมมอเตอร์บนเว็บนี้

**ควรเริ่มกับ PLC ยี่ห้อไหน?**
หลักการเหมือนกันทุกยี่ห้อเพราะอิงมาตรฐาน IEC 61131 เลือกยี่ห้อที่ใช้ในโรงงานหรือสถานศึกษาใกล้ตัว และที่มีซอฟต์แวร์ฟรีพร้อมซิมูเลเตอร์ ในภูมิภาคนี้พบ Mitsubishi, Omron, Siemens, Delta, Schneider, Rockwell และ Keyence บ่อย

**PLC ต่างจาก Arduino หรือไมโครคอนโทรลเลอร์อย่างไร?**
PLC ออกแบบมาสำหรับสภาพแวดล้อมโรงงาน: I/O 24 VDC ที่ทนสัญญาณรบกวนและมีการแยกโดดเดี่ยว ทำงานแบบสแกนที่คาดเดาได้ มีการวินิจฉัยตัวเอง ภาษาตามมาตรฐาน ซ่อมและเปลี่ยนโมดูลได้ระหว่างใช้งาน และผ่านการรับรองตามมาตรฐานอุตสาหกรรม ส่วนไมโครคอนโทรลเลอร์ยืดหยุ่นและถูกกว่า แต่ผู้ใช้ต้องสร้างความทนทานเหล่านี้เอง
