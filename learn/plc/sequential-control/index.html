    ตัวอย่างไฟจราจรในซิมูเลเตอร์ใช้ไทเมอร์ต่อเป็นโซ่ (T1→T6) เป็นสเตตแมชชีนแบบง่าย: ขั้นปัจจุบันระบุได้จากไทเมอร์ตัวไหนครบแล้ว เหมาะกับลำดับที่ขึ้นกับเวลาล้วน ๆ งานที่มีเงื่อนไขจากเซนเซอร์ใช้วิธี SFC ด้านล่าง

    SFC / GRAFCET: ถังผสมแบบแบตช์ กลาง

    แปลงเป็นแลดเดอร์ด้วย SET/RESET

    // ขั้นเริ่มต้นเมื่อเปิดเครื่อง (first scan)
S  X0 = FirstScan
// แต่ละรัง: ขั้นปัจจุบัน AND เงื่อนไข → SET ขั้นถัดไป, RESET ขั้นปัจจุบัน
S  X1 = X0 & START & !LL         R  X0 = X0 & START & !LL
S  X2 = X1 & LM                  R  X1 = X1 & LM
S  X3 = X2 & LH                  R  X2 = X2 & LH
S  X4 = X3 & T3.Q                R  X3 = X3 & T3.Q
S  X0 = X4 & !LL                 R  X4 = X4 & !LL
T3 = TON(X3, 60s)
// ส่วนเอาต์พุต (S3)
V1 = X1 · V2 = X2 · M1 = X3 · V3 = X4

    แปลงเป็น Structured Text ด้วย CASE

    CASE Step OF
  0: IF Start AND NOT LL THEN Step := 10; END_IF
 10: IF LM THEN Step := 20; END_IF          // เติม A
 20: IF LH THEN Step := 30; END_IF          // เติม B
 30: IF TMix.Q THEN Step := 40; END_IF      // กวน
 40: IF NOT LL THEN Step := 0; END_IF       // ปล่อย
END_CASE
TMix(IN := Step = 30, PT := T#60S);
V1 := Step = 10;  V2 := Step = 20;  M1 := Step = 30;  V3 := Step = 40;

    เลขขั้นเว้นทีละ 10 เพื่อแทรกขั้นใหม่ภายหลังได้โดยไม่ต้องเลื่อนเลขทั้งโปรแกรม และแสดง Step บน HMI ช่างจะรู้ทันทีว่าเครื่องรออะไรอยู่

    ตัวอย่างเติมถังอัตโนมัติ (มีโรงงานจำลอง)

    กด START ระบบเติมน้ำจนถึง LH หยุด และเติมใหม่เมื่อระดับต่ำกว่า LL เปิดก๊อก (I0.4) ให้มีการใช้น้ำ ดูการ SET/RESET ของปั๊ม Q0.0 ตามสวิตช์ระดับ — นี่คือวงจรสองระดับแบบเดียวกับ ปั๊มลูกลอย แต่เขียนในโปรแกรม

    โหมดอัตโนมัติ-มือ หยุด และกลับจุดเริ่ม ขั้นสูง

    • Auto / Manual: โหมดมือให้สั่งเอาต์พุตทีละตัวจาก HMI แต่ยังผ่านอินเตอร์ล็อก (เช่น ห้ามเปิดวาล์วปล่อยขณะเติม) ลำดับขั้นหยุดนับขณะอยู่โหมดมือ
    • Cycle stop: กดหยุดแล้วให้ทำรอบปัจจุบันจนจบก่อนหยุดที่ขั้น 0 — เหมาะกับงานที่หยุดกลางรอบแล้วเสียวัตถุดิบ
    • Immediate stop / E-stop: ตัดเอาต์พุตทั้งหมดทันที เก็บขั้นที่หยุดไว้ และต้องผ่านขั้นตอนกลับจุดเริ่ม (homing) หรือกู้คืนด้วยมือก่อนเริ่มใหม่
    • Timeout ต่อขั้น: ทุกขั้นที่รอเซนเซอร์ควรมีไทเมอร์เฝ้า เช่น เติมนานเกิน 5 นาทีแปลว่าวาล์วค้างหรือเซนเซอร์เสีย → แจ้งเตือนพร้อมบอกขั้น

    คำถามที่พบบ่อย

    ทำไมโปรแกรมลำดับขั้นที่เขียนด้วยวงจรล็อกตัวเองหลายชั้นมักมีบั๊ก?

    เพราะสถานะของเครื่องกระจายอยู่ในบิตหลายตัวที่ไม่มีกฎบังคับว่าต้องเป็นหนึ่งเดียว ทำให้เกิดสองขั้นทำงานพร้อมกันหรือไม่มีขั้นไหนทำงานได้ วิธีสเตตแมชชีนเก็บสถานะในตัวแปรเดียว (หรือบิตขั้นที่ SET/RESET คู่กันอย่างมีวินัย) ทำให้มีขั้นเดียวที่ทำงานเสมอ และรู้ทันทีว่าเครื่องค้างที่ไหน

    เอาต์พุตควรเขียนในแต่ละขั้นหรือท้ายโปรแกรม?

    แนะนำให้ส่วนลำดับคำนวณแค่ “ขั้นปัจจุบัน” แล้วมีส่วนเอาต์พุตแยกที่ท้ายโปรแกรม เขียนเอาต์พุตแต่ละตัวครั้งเดียวเป็น OR ของขั้นที่ต้องการให้ทำงาน เช่น ปั๊ม = ขั้น1 OR ขั้น4 วิธีนี้ป้องกันคอยล์ซ้ำและเพิ่มเงื่อนไขโหมดมือหรือหยุดฉุกเฉินได้จุดเดียว

    คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

    เว็บไซต์ หน้าแรก คลังความรู้ อัปเดตล่าสุด · บันทึกการปรับปรุง บทความ: ลำดับและอนุกรม Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม อุปนัยเชิงคณิตศาสตร์ อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
