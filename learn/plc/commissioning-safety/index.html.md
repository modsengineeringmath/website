# ทดสอบระบบ PLC ความปลอดภัยเครื่องจักร และการแก้ปัญหา: ลูปเช็ก การ Force หยุดฉุกเฉิน IEC 60204-1 ISO 13849 และเอกสาร

// บทที่ 22.9 · PLC · Commissioning & Safety


โปรแกรมที่ผ่านซิมูเลเตอร์ยังไม่ใช่เครื่องที่พร้อมใช้ ช่วงเดินระบบคือช่วงที่เกิดอุบัติเหตุบ่อยที่สุด เพราะสายยังไม่ครบ คนยังไม่คุ้นเครื่อง และมีการแก้โปรแกรมสด หน้านี้ให้ขั้นตอนที่เป็นระบบ หลักความปลอดภัยที่บังคับในมาตรฐาน และวิธีหาจุดเสียอย่างมีหลักการ

สรุปใน 30 วินาที

- ทดสอบเป็นชั้น: สาย → ไฟเลี้ยง → I/O ทีละจุด → ลอจิกโดยไม่มีกำลัง → เดินจริง

- หยุดฉุกเฉิน = หมวดหยุด 0 หรือ 1 ผ่านอุปกรณ์เซฟตี้ ไม่ใช่ผ่านโปรแกรม PLC ทั่วไป

- ระดับที่ต้องการ (PLr) มาจากการประเมินความเสี่ยง · ระยะม่านแสง $S = K\,T + C$

- Force ทุกครั้งต้องมีขั้นตอน และต้องไม่เหลือค้างเมื่อส่งมอบ

## ขั้นตอนทดสอบและเดินระบบ พื้นฐาน

- ก่อนจ่ายไฟ: ตรวจสายตามแบบ ความต่อเนื่องของ PE ความเป็นฉนวนสายกำลัง (ปลดอิเล็กทรอนิกส์ออก) ขั้วขันแน่น

- จ่ายไฟทีละส่วน: ไฟควบคุม 24 VDC ก่อน วัดแรงดันที่ทุกกลุ่ม I/O · ไฟกำลังยังปลด

- ทดสอบอินพุตทีละจุด: กดปุ่ม/กระตุ้นเซนเซอร์จริงที่หน้างาน ดูบิตเปลี่ยนในซอฟต์แวร์ บันทึกในใบ I/O check

- ทดสอบเอาต์พุตทีละจุด: ขณะไฟกำลังยังปลด สั่งเอาต์พุต (ใช้โหมดทดสอบหรือ Force ตามขั้นตอน) ดูคอนแทกเตอร์ วาล์ว ไฟ ทำงานถูกตัว

- ลูปเช็กแอนะล็อก: ป้อนกระแส 4 · 12 · 20 mA ด้วยเครื่องสอบเทียบ อ่านค่าหน่วยวิศวกรรมใน PLC และบน HMI

- ทดสอบความปลอดภัย: หยุดฉุกเฉินทุกจุด ประตูนิรภัย ม่านแสง ตรวจว่าตัดพลังงานจริงและรีเซ็ตต้องทำด้วยมือ

- ทดสอบลอจิกแห้ง: เดินลำดับทั้งหมดโดยไฟกำลังปลด จำลองเซนเซอร์

- เดินจริง: ทีละมอเตอร์ ตรวจทิศ กระแส แล้วทั้งลำดับ ทั้งปกติและกรณีผิดปกติ (ดึงเซนเซอร์ ทริปโอเวอร์โหลด)

- ส่งมอบ: ไม่มี Force ค้าง สำรองโปรแกรมพร้อมคอมเมนต์ เอกสาร I/O list แบบวงจร as-built ค่าพารามิเตอร์ไดรฟ์

การ Force: ก่อน Force เอาต์พุตที่ทำให้เครื่องเคลื่อนที่ ต้องแจ้งทุกคนในพื้นที่ มีคนเฝ้าปุ่มหยุดฉุกเฉิน และบันทึก ซอฟต์แวร์ส่วนใหญ่แสดงสัญลักษณ์เตือนเมื่อมี Force — ตรวจทุกครั้งก่อนออกจากหน้างาน

## หมวดการหยุดและหยุดฉุกเฉิน (IEC 60204-1) กลาง

K1 Stop categories หมวดการหยุด

$$\text{Cat 0: ตัดพลังงานทันที} \qquad \text{Cat 1: หยุดแบบควบคุมแล้วตัดพลังงาน} \qquad \text{Cat 2: หยุดแบบควบคุม คงพลังงานไว้}$$

หยุดฉุกเฉินต้องเป็นหมวด 0 หรือ 1 เท่านั้น หมวด 1 ใช้เมื่อการตัดทันทีอันตรายกว่า เช่น เครื่องเหวี่ยงขนาดใหญ่ที่ต้องเบรกด้วยไดรฟ์ก่อนตัดไฟ (ใช้รีเลย์เซฟตี้แบบหน่วงเวลา) ปุ่มหยุดฉุกเฉินเป็นหัวเห็ดสีแดงบนพื้นเหลือง ล็อกค้างเมื่อกด หน้าสัมผัสเปิดด้วยกลไกบังคับ และการปลดล็อกปุ่มต้องไม่ทำให้เครื่องเดินเอง

รูป 1 · รีเลย์เซฟตี้ตรวจสองช่องและการลัดข้ามช่อง หน้าสัมผัสเซฟตี้ต่ออนุกรมกับเอาต์พุต PLC จึงตัดคอยล์ได้เสมอ PLC เพียงอ่านสถานะ

## ระดับความปลอดภัย PL และ SIL ขั้นสูง

ISO 13849-1 ประเมินความเสี่ยงจากสามปัจจัย: ความรุนแรงของการบาดเจ็บ (S1 เล็กน้อย / S2 รุนแรง) ความถี่ที่สัมผัสอันตราย (F1 นาน ๆ ครั้ง / F2 บ่อย) และโอกาสหลบเลี่ยง (P1 เป็นไปได้ / P2 แทบเป็นไปไม่ได้) ได้ระดับที่ต้องการ PLr ตั้งแต่ a ถึง e จากนั้นออกแบบฟังก์ชันความปลอดภัย (โครงสร้างหมวด B 1 2 3 4 อายุอุปกรณ์ MTTFd การตรวจจับความผิดพลาด DC) ให้ได้ PL ≥ PLr

K2 PL / SIL by dangerous failure rate ระดับตามอัตราความล้มเหลวอันตรายต่อชั่วโมง

$$\text{PL d} \approx \text{SIL 2}: 10^{-7} \le PFH_D

| หยุดฉุกเฉินเครื่องจักรทั่วไป | c–d | ปุ่มสองช่อง + รีเลย์เซฟตี้ + คอนแทกเตอร์สองตัวอนุกรมพร้อมป้อนกลับ |

| ประตูนิรภัยเครื่องตัด/เครื่องอัด | d–e | สวิตช์ประตูสองตัวหรือสวิตช์เข้ารหัส + safety PLC |

| ม่านแสงหน้าเครื่องปั๊ม | d–e | ม่านแสง Type 4 + ระยะติดตั้งตาม K3 |

K3 Minimum safety distance (ISO 13855) ระยะติดตั้งขั้นต่ำของม่านแสง

$$S = K\,T + C \qquad K = 2000\ \text{mm/s (ถ้า } S \le 500\ \text{mm)},\ 1600\ \text{mm/s (ถ้ามากกว่า)} \qquad C = 8(d - 14)\ \text{mm},\ d \le 40\ \text{mm}$$

### ม่านแสงความละเอียด 14 mm เวลาหยุดรวม 120 ms

- เวลารวม T = เวลาตอบสนองม่านแสง + รีเลย์เซฟตี้ + เวลาหยุดของเครื่อง (วัดจริง) = 0.12 s

- $C = 8(14 - 14) = 0$ · $S = 2000(0.12) + 0 = 240$ mm ≤ 500 ✓ ใช้ K = 2000

- ติดตั้งม่านแสงห่างจุดอันตรายอย่างน้อย 240 mm (ขั้นต่ำตามมาตรฐานคือ 100 mm) และกันการเอื้อมข้ามด้านบน-ด้านข้าง

## แก้ปัญหาเมื่อเครื่องไม่ทำงาน กลาง

- ดูสถานะ PLC: RUN/STOP ไฟ ERR ไฟแบตเตอรี่ บันทึกเหตุการณ์ (diagnostic buffer)

- ดู HMI: ข้อความแจ้งเตือน ขั้นที่ค้าง (ถ้าเขียนแบบสเตตแมชชีน)

- ไล่จากเอาต์พุตย้อนกลับ: เอาต์พุตที่ควรติดแต่ไม่ติด → เปิดรังนั้นออนไลน์ → หาหน้าสัมผัสที่ “ไม่เขียว” → เป็นอินพุตหรือบิตภายใน?

- ถ้าเป็นอินพุต: ดูไฟ LED ที่โมดูล → ถ้าไม่ติด วัดแรงดันที่ขั้ว → ตรวจเซนเซอร์/สาย/ไฟเลี้ยงเซนเซอร์

- ถ้าบิตเอาต์พุตเป็น 1 แต่อุปกรณ์ไม่ทำงาน: ไฟ LED เอาต์พุต → ฟิวส์เอาต์พุต → รีเลย์ต่อกลาง → คอยล์ → อินเตอร์ล็อกฮาร์ดไวร์ (NC ช่วย, 95-96, รีเลย์เซฟตี้)

กฎทอง: “เปลี่ยนสิ่งเดียวในเวลาเดียว และบันทึกทุกการเปลี่ยน” โดยเฉพาะการแก้โปรแกรมออนไลน์ เก็บสำเนาก่อนแก้ทุกครั้ง และตั้งชื่อไฟล์ด้วยวันที่และสาเหตุ

## เอกสารที่ต้องส่งมอบ

- แบบวงจรไฟฟ้าฉบับ as-built พร้อมรายการอุปกรณ์

- รายการ I/O (แอดเดรส ชื่อ tag คำอธิบาย ชนิดสัญญาณ ช่วงสเกล)

- โปรแกรม PLC และ HMI ที่มีคอมเมนต์ ไฟล์ต้นฉบับ (ไม่ใช่แค่ไฟล์ที่ดึงจาก PLC) พร้อมรหัสผ่านที่ส่งมอบให้เจ้าของ

- ค่าพารามิเตอร์อินเวอร์เตอร์และอุปกรณ์อัจฉริยะทุกตัว

- ใบ I/O check ลูปเช็ก และผลทดสอบฟังก์ชันความปลอดภัยที่ลงนาม

- คู่มือการใช้งานและการกู้คืนเมื่อเครื่องหยุดฉุกเฉิน

## คำถามที่พบบ่อย

การ Force บิตใน PLC อันตรายอย่างไร?
Force บังคับค่าบิตโดยไม่สนเงื่อนไขในโปรแกรมหรือสถานะจริงของอินพุต เครื่องอาจเคลื่อนที่ในจังหวะที่ไม่มีใครคาด อินเตอร์ล็อกในซอฟต์แวร์ถูกข้าม และถ้าลืมยกเลิก ค่า Force จะค้างไปจนเกิดเหตุ ควรมีขั้นตอนขออนุญาต แจ้งคนในพื้นที่ บันทึก และตรวจว่าไม่มี Force ค้างก่อนส่งมอบเครื่อง

ปุ่มหยุดฉุกเฉินต่อเข้า PLC แล้วให้โปรแกรมตัดเอาต์พุตได้ไหม?
ไม่เพียงพอสำหรับ PLC มาตรฐาน หยุดฉุกเฉินต้องมีระดับความน่าเชื่อถือที่ประเมินตาม ISO 13849-1 หรือ IEC 62061 ซึ่ง PLC ทั่วไปไม่ได้รับรอง ให้ใช้รีเลย์เซฟตี้หรือ safety PLC ที่ตัดพลังงานจากอุปกรณ์ขับเคลื่อนโดยตรง แล้วนำสถานะเข้า PLC เพื่อแสดงผลและจัดลำดับการกลับมาทำงาน
