// บทที่ 22.6 · PLC · Motor Control with a PLC

ควบคุมมอเตอร์ด้วย PLC: DOL กลับทางหมุน สตาร์-เดลต้า รายการ I/O การต่อสาย อินเตอร์ล็อกฮาร์ดไวร์ และการตรวจสอบป้อนกลับคอนแทกเตอร์

เมื่อย้ายลอจิกจากตู้รีเลย์มาไว้ใน PLC สิ่งที่ได้คือความยืดหยุ่น การแสดงสถานะ และการตรวจจับความผิดปกติ แต่สิ่งที่ต้องไม่เสียไปคือความปลอดภัยของวงจรเดิม หน้านี้แบ่งชัดเจนว่าอะไรอยู่ในซอฟต์แวร์ อะไรต้องอยู่ในฮาร์ดแวร์ และให้โปรแกรมที่ใช้ได้จริงสำหรับวงจรมอเตอร์ทั้งสามแบบ

เพิ่ม FB‾\overline{FB}FB ของอีกทิศ (ป้อนกลับจากคอนแทกเตอร์จริง) ทำให้โปรแกรมไม่สั่งทิศใหม่จนกว่าคอนแทกเตอร์เดิมปล่อยจริง และนิยมเพิ่มไทเมอร์หน่วงกลับทาง 0.5–2 s ให้มอเตอร์ชะลอ

สตาร์-เดลต้าด้วย PLC กลาง

M4 Star–delta sequence ลำดับสตาร์-เดลต้าในโปรแกรม

KY=Run TY‾ KΔ‾K1=Run (KY+K1)KΔ=Run TON(TY, tdead) KY‾ FBY‾K_Y = \text{Run}\,\overline{T_Y}\,\overline{K_\Delta} \quad K_1 = \text{Run}\,(K_Y + K_1) \quad K_\Delta = \text{Run}\,\text{TON}(T_Y,\ t_{dead})\,\overline{K_Y}\,\overline{FB_Y}KY​=RunTY​​KΔ​​K1​=Run(KY​+K1​)KΔ​=RunTON(TY​, tdead​)KY​​FBY​​
(* Structured Text: star–delta with feedback check *)
Run := (PB_Start OR Run) AND PB_Stop_NC AND OL_NC AND NOT Fault;
TY(IN := Run, PT := T#6S);                         // เวลาช่วงสตาร์
KY    := Run AND NOT TY.Q AND NOT KD;              // K2 สตาร์
K1    := Run AND (FB_Y OR K1);                     // K1 หลัง เมื่อสตาร์ดูดจริง
TDead(IN := TY.Q AND NOT FB_Y, PT := T#80MS);    // รอ K2 ปล่อยจริงแล้วนับช่วงตาย
KD    := Run AND TDead.Q;                            // K3 เดลต้า
TChk(IN := (K1 XOR FB_1) OR (KY XOR FB_Y) OR (KD XOR FB_D), PT := T#1S);
IF TChk.Q OR (FB_Y AND FB_D) THEN Fault := TRUE; END_IF

สังเกต: ช่วงตายเริ่มนับเมื่อ ป้อนกลับ ของ K2 ยืนยันว่าปล่อยแล้ว ไม่ใช่เมื่อสั่งปล่อย — ป้องกันกรณีหน้าสัมผัส K2 ค้าง นี่คือสิ่งที่วงจรรีเลย์ธรรมดาทำไม่ได้ ซิมูเลเตอร์ด้านล่างเป็นรุ่นย่อที่ไม่มีป้อนกลับ

ตัวอย่าง M-1

ทดสอบลำดับในซิมูเลเตอร์และตอบคำถาม

  1. กด START: บันทึกลำดับที่ Q0.1 (Y) และ Q0.0 (K1) ติด — ทำไม Q0.1 ต้องติดก่อน? (เพื่อให้จุดสตาร์ต่อเสร็จก่อนจ่ายไฟเข้าขดลวด)

  2. ดูแถบ ET ของ T1 และ T2: ช่วงที่ Q0.1 ดับแต่ Q0.2 ยังไม่ติดยาวเท่าไร? (80 ms = PT ของ T2)

  3. แก้รัง Q0.1 ลบเงื่อนไข !Q0.2 แล้วโหลดใหม่ ระบบยังทำงานไหม และทำไมอินเตอร์ล็อกนี้ยังควรอยู่?

คำถามที่พบบ่อย

ใช้ PLC แล้วยังต้องมีหน้าสัมผัสช่วยอินเตอร์ล็อกในวงจรคอยล์อีกไหม?

ต้องมี อินเตอร์ล็อกที่ป้องกันลัดวงจร (K1/K2 กลับทาง K2/K3 สตาร์-เดลต้า) ต้องทำงานได้แม้ PLC เสีย เอาต์พุตทรานซิสเตอร์ลัดค้าง หรือมีคนสั่ง force บิต การใส่หน้าสัมผัส NC ของคอนแทกเตอร์ตรงข้ามอนุกรมกับคอยล์และอินเตอร์ล็อกทางกลจึงยังจำเป็น โปรแกรมเป็นชั้นเพิ่มเติม ไม่ใช่ชั้นเดียว

ต่อโอเวอร์โหลดเข้า PLC อย่างเดียวได้ไหม?

ทำได้ในทางเทคนิค แต่แนวปฏิบัติที่ดีคือให้ 95-96 อนุกรมกับคอยล์คอนแทกเตอร์โดยตรง (ตัดได้แม้ PLC ค้าง) และนำ 97-98 หรือหน้าสัมผัสช่วยเข้า PLC เพื่อแสดงสถานะและบันทึกเหตุการณ์

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
