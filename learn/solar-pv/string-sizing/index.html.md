# ออกแบบสตริงและจับคู่อินเวอร์เตอร์: Voc ตอนหนาว ช่วง MPPT กระแส และ DC/AC ratio

// บทที่ 14.5 · ออกแบบระบบโซลาร์เซลล์ · String Sizing & Inverter Matching


อินเวอร์เตอร์รับแรงดันได้ในหน้าต่างหนึ่ง และรับกระแสได้ไม่เกินค่าหนึ่ง ส่วนแรงดันของสตริงเปลี่ยนตามอุณหภูมิทุกวัน การออกแบบสตริงคือการเลือก “แผงกี่แผงต่ออนุกรม และกี่สตริงต่อขนาน” ให้สตริงอยู่ในหน้าต่างนั้น ทั้งในเช้าที่หนาวที่สุดและเที่ยงที่ร้อนที่สุดของปี — พลาดด้านบนอินเวอร์เตอร์พัง พลาดด้านล่างเสียพลังงานทุกบ่าย

สรุปใน 30 วินาที

- ขีดบน: $N_s V_{oc}(T_{min}) \le V_{dc,max}$ — ห้ามเกินเด็ดขาด

- ขีดล่าง: $N_s V_{mp}(T_{c,max}) \ge V_{MPPT,min}$ — ต่ำกว่านี้เสียพลังงานช่วงร้อน

- กระแส: $N_p I_{mp} \le I_{MPPT,max}$ และ $1.25 N_p I_{sc} \le I_{sc,max}$

- DC/AC 1.1–1.3 · สตริงต่างทิศแยก MPPT · สตริงขนานต้องจำนวนแผงเท่ากัน

## ค่าในดาต้าชีตอินเวอร์เตอร์ที่ต้องใช้ พื้นฐาน

| ค่า | ตัวอย่าง 5 kW 1 เฟส | ความหมาย |

| Max. DC input voltage $V_{dc,max}$ | 600 V | เกินแล้วเสียหายถาวร (ไม่ครอบคลุมประกัน) |

| MPPT voltage range | 120–550 V | ช่วงที่ MPPT ทำงาน |

| Full-load MPPT range | ~ 160–550 V | ช่วงที่จ่ายได้เต็มพิกัด (บางยี่ห้อระบุ) |

| Start-up voltage | ~ 100–150 V | แรงดันที่เริ่มทำงานตอนเช้า |

| Rated DC voltage | 360 V | แรงดันที่ประสิทธิภาพดีที่สุด |

| จำนวน MPPT / สตริงต่อ MPPT | 2 / 1 | แยกทิศหรือแยกขนาดสตริง |

| Max. input current per MPPT | 16 A | เกินแล้วอินเวอร์เตอร์ตัดยอด (ไม่พัง) |

| Max. short-circuit current per MPPT | 22 A | ความปลอดภัยของวงจรภายใน ต้องไม่เกิน |

| Max. DC input power / DC/AC ที่อนุญาต | 7.5 kW (150 %) | ขนาดแผงสูงสุดที่ผู้ผลิตยอม |

| Rated AC power | 5 kW | ฐานของ DC/AC ratio และการขออนุญาต |

## ขีดจำกัดแรงดัน: หนาวสุดและร้อนสุด พื้นฐาน

แรงดันของแผงขึ้นกับอุณหภูมิเซลล์เป็นหลัก (P6) แรงดันสูงสุดเกิดในเช้าที่อากาศหนาวที่สุด เมื่อแสงพอให้แรงดันขึ้นเต็มแต่แผงยังไม่ร้อน จึงใช้ อุณหภูมิอากาศต่ำสุดเป็นอุณหภูมิเซลล์ ส่วนแรงดันต่ำสุดขณะทำงานเกิดตอนเที่ยงที่แผงร้อนที่สุด

D1 Maximum module voltage (coldest morning) แรงดันสูงสุดของแผงตอนหนาวสุด

$$V_{oc,max} = V_{oc,STC}\left[1 + \beta_{V_{oc}}\,(T_{min} - 25)\right]$$

D2 Maximum modules per string จำนวนแผงต่อสตริงสูงสุด

$$N_{s,max} = \left\lfloor \frac{V_{dc,max}}{V_{oc,max}} \right\rfloor \quad \text{(และต้องไม่เกิน } V_{sys,max}\text{ ของแผงด้วย)}$$

D3 Minimum MPP voltage (hottest noon) แรงดัน MPP ต่ำสุดตอนร้อนสุด

$$V_{mp,min} = V_{mp,STC}\left[1 + \beta_{V_{mp}}(T_{c,max} - 25)\right] \qquad \beta_{V_{mp}} \approx \gamma - \alpha$$

D4 Minimum modules per string จำนวนแผงต่อสตริงต่ำสุด

$$N_{s,min} = \left\lceil \frac{V_{MPPT,min}}{V_{mp,min}} \right\rceil$$

D5 MPPT upper limit ขอบบนของช่วง MPPT

$$N_{s} \le \left\lfloor \frac{V_{MPPT,max}}{V_{mp}(T_{min})} \right\rfloor$$

### เลือก $T_{min}$ และ $T_{c,max}$ อย่างไร

- $T_{min}$: อุณหภูมิต่ำสุดที่เคยบันทึกของพื้นที่ (จากกรมอุตุนิยมวิทยา) กรุงเทพฯ และภาคใต้ใช้ 10–15 °C ภาคกลางและอีสาน 5–10 °C ภาคเหนือและพื้นที่สูง 0–5 °C ถ้าไม่แน่ใจใช้ค่าต่ำไว้ก่อน (ปลอดภัยกว่า)

- $T_{c,max}$: อุณหภูมิเซลล์สูงสุด ≈ อากาศสูงสุด + 30–35 °C (P7) ในไทยใช้ 70–75 °C สำหรับแผงยกลอย และ 75–80 °C สำหรับแผงติดชิดหลังคา

- ผลของ $T_{min}$ ไม่น้อย: ถ้าเปลี่ยนจาก 10 °C เป็น 0 °C แผงตัวอย่างมี $V_{oc,max}$ 55.5 V และอินเวอร์เตอร์ 600 V ยังรับได้ 10 แผง (จาก 11) — ในภาคเหนือต้องคิดค่านี้จริงจัง

อย่าเผื่อด้านบนน้อยเกินไป แรงดันเกิน $V_{dc,max}$ แม้เพียงไม่กี่นาทีตอนเช้าก็ทำให้ตัวเก็บประจุหรือสวิตช์ด้านเข้าเสียหายได้ และผู้ผลิตจะไม่รับประกัน บางรายแนะนำให้เผื่ออีก 2–3 % สำหรับ tolerance และแสงที่สูงกว่า 1,000 W/m² จากเมฆสะท้อน (cloud enhancement)

## ขีดจำกัดกระแส: สตริงขนานต่อ MPPT พื้นฐาน

D6 Parallel strings per MPPT จำนวนสตริงขนานต่อ MPPT

$$N_p \le \left\lfloor \frac{I_{MPPT,max}}{I_{mp}} \right\rfloor \qquad 1.25\,N_p\,I_{sc} \le I_{sc,max}$$

ตัวคูณ 1.25 เผื่อแสงที่สูงกว่า STC (cloud enhancement, albedo) และกระแสด้านหลังของแผงสองหน้า ข้อกำหนดของ IEC 62548 ใช้ตัวคูณนี้กับการเลือกสายและฟิวส์ด้วย ถ้า $N_p I_{mp}$ เกิน $I_{MPPT,max}$ เล็กน้อย อินเวอร์เตอร์จะจำกัดกระแสเอง (เสียพลังงานแต่ไม่พัง) แต่ถ้า $I_{sc}$ เกิน $I_{sc,max}$ อาจเสียหายเมื่อเกิดความผิดพร่องภายใน

แผงกระแสสูงกับอินเวอร์เตอร์รุ่นเก่า: แผง 182/210 mm มี $I_{mp}$ 13–18 A อินเวอร์เตอร์รุ่นเก่ารับได้ 11–13 A ต่อ MPPT จึงต้องตรวจทุกครั้ง อินเวอร์เตอร์รุ่นปัจจุบันจำนวนมากรองรับ 16–20 A ต่อสตริงแล้ว

## DC/AC ratio และ clipping กลาง

D7 DC/AC ratio อัตราส่วนกำลังแผงต่อพิกัดอินเวอร์เตอร์

$$r_{DC/AC} = \frac{N_s N_p P_{STC}}{P_{AC,rated}}$$

แผงในไทยแทบไม่เคยจ่ายกำลังถึง STC เพราะอุณหภูมิ ฝุ่น และการสูญเสียในสาย กำลังสูงสุดจริงช่วงเที่ยงจึงอยู่ราว 75–85 % ของ $P_{STC}$ การใช้แผงมากกว่าพิกัดอินเวอร์เตอร์ (oversizing) ทำให้อินเวอร์เตอร์ทำงานใกล้พิกัดนานขึ้น ได้พลังงานเช้าเย็นมากขึ้น และต้นทุนต่อหน่วยลดลง เมื่อกำลัง DC เกินพิกัด อินเวอร์เตอร์จะเลื่อนจุดทำงานออกจาก MPP เพื่อจำกัดกำลัง (clipping)

| DC/AC | clipping ต่อปีในไทย (ประมาณ) | ใช้เมื่อ |

| 1.0–1.1 | ~0 % | สัญญาจำกัดกำลังส่งออกตามพิกัด kW แผง |

| 1.1–1.3 | 0.2–2 % | บ้านและอาคารทั่วไป (แนะนำ) |

| 1.3–1.5 | 2–6 % | หลังคาตะวันออก-ตะวันตก ระบบที่ขนาดอินเวอร์เตอร์ถูกจำกัดด้วยสัญญาหรือหม้อแปลง |

D8 Minimum voltage for full power แรงดันต่ำสุดที่ยังจ่ายเต็มพิกัด

$$V_{full,min} \approx \frac{P_{AC,rated}}{\eta_{inv}\,\sum I_{MPPT,max}}$$

ถ้าแรงดันสตริงตอนร้อนต่ำกว่า $V_{full,min}$ อินเวอร์เตอร์ถูกจำกัดด้วยกระแส ไม่สามารถจ่ายเต็มพิกัด แม้แสงมาก — เกิดบ่อยในระบบที่สตริงสั้นเกินไป

## เครื่องคำนวณสตริง

ใส่ค่าจากดาต้าชีตแผงและอินเวอร์เตอร์ เครื่องจะคำนวณช่วงจำนวนแผงที่ใช้ได้ แล้วตรวจแบบที่คุณเลือกทีละเงื่อนไข (✓/✗) ค่าเริ่มต้นคือตัวอย่าง D-1

## ตัวอย่างออกแบบ 3 ขนาด กลาง

ทุกตัวอย่างใช้แผง 580 Wp ($V_{oc}$ 52.2 V, $V_{mp}$ 43.4 V, $I_{sc}$ 14.10 A, $I_{mp}$ 13.37 A, β = −0.25, γ = −0.29, α = +0.045 %/°C) $T_{min}$ = 10 °C $T_{c,max}$ = 70 °C จึงได้ $V_{oc,max}$ = 54.16 V $V_{mp,min}$ = 36.86 V $V_{mp}(T_{min})$ = 45.58 V (ใช้ $\beta_{V_{mp}} = -0.335$ %/°C)

ตัวอย่าง D-1

### บ้าน: อินเวอร์เตอร์ไฮบริด 5 kW 1 เฟส

$V_{dc,max}$ 600 V · MPPT 120–550 V · 2 MPPT · 16 A/MPPT · $I_{sc,max}$ 22 A/MPPT

- D2: $N_{s,max} = \lfloor 600/54.16 \rfloor = 11$

- D4: $N_{s,min} = \lceil 120/36.86\rceil = 4$ · D5: $\lfloor 550/45.58 \rfloor = 12$ → ใช้ได้ 4–11 แผงต่อสตริง

- D6: $\lfloor 16/13.37 \rfloor = 1$ สตริงต่อ MPPT · $1.25 \times 14.1 = 17.6 \le 22$ ✓

- เลือก 5 แผง × 2 สตริง (สตริงละ MPPT) = 10 แผง = 5.80 kWp → DC/AC = 1.16 ✓

- ตรวจ: $V_{oc}$ สตริงตอนหนาว 270.8 V ≤ 600 ✓ · $V_{mp}$ ตอนร้อน 184.3 V ≥ 120 ✓ · D8: $5000/(0.97 \times 32) = 161$ V ≤ 184 ✓

- ข้อสังเกต: ถ้าหลังคามีสองทิศ ใช้สตริงละทิศ แต่ละ MPPT ทำงานอิสระ ถ้าทิศเดียว อาจเลือก 10 แผงสตริงเดียว (Voc 541.6 V) ได้แรงดันใกล้ rated DC voltage มากกว่า แต่เหลือ MPPT ว่างหนึ่งตัว และเงาบังส่งผลทั้งสตริง

ตัวอย่าง D-2

### บ้านใหญ่/ร้านค้า: อินเวอร์เตอร์ 10 kW 3 เฟส

$V_{dc,max}$ 1,100 V · MPPT 160–1,000 V · 2 MPPT · 16 A/MPPT

- $N_{s,max} = \lfloor 1100/54.16 \rfloor = 20$ · $N_{s,min} = \lceil 160/36.86 \rceil = 5$ · ขอบบน MPPT $\lfloor 1000/45.58\rfloor = 21$

- เลือก 11 แผง × 2 สตริง = 22 แผง = 12.76 kWp → DC/AC = 1.28

- ตรวจ: $V_{oc}$ ตอนหนาว 595.7 V ✓ · $V_{mp}$ ตอนร้อน 405.4 V ✓ · $V_{mp}$ ตอนหนาว 501.4 V ✓ (ใกล้ rated DC voltage ของอินเวอร์เตอร์ 3 เฟสส่วนใหญ่ ≈ 600 V)

ตัวอย่าง D-3

### โรงงาน: อินเวอร์เตอร์ 100 kW

$V_{dc,max}$ 1,100 V · MPPT 200–1,000 V · 10 MPPT · 2 สตริงต่อ MPPT · 32 A/MPPT · $I_{sc,max}$ 40 A/MPPT · เป้า DC/AC ≈ 1.25

- เลือก 18 แผงต่อสตริง: $V_{oc}$ ตอนหนาว $18 \times 54.16 = 974.8$ V ≤ 1,100 ✓ (เผื่อ 11 %) · $V_{mp}$ ตอนร้อน 663.4 V ✓ · ตอนหนาว 820.5 V ✓

- แผงที่ต้องการ: $1.25 \times 100/0.58 \approx 216$ แผง = 12 สตริง × 18 = 216 แผง = 125.3 kWp → DC/AC = 1.25

- กระแสต่อ MPPT ที่มี 2 สตริง: $2 \times 13.37 = 26.7$ A ≤ 32 ✓ · $1.25 \times 2 \times 14.1 = 35.3$ A ≤ 40 ✓

- 12 สตริงบน 10 MPPT: 2 MPPT รับ 2 สตริง อีก 8 MPPT รับ 1 สตริง — ทุกสตริงใน MPPT เดียวกันต้องทิศเดียวกันและยาวเท่ากัน

- สตริงยาวทำให้กระแส DC ต่ำ สายเล็กลง แรงดันตกน้อย (ดู สายไฟ) แต่ต้องใช้อุปกรณ์ DC พิกัด 1,000–1,100 V ทั้งหมด

## กฎการจัดสตริงที่ใช้จริง

- แผงในสตริงเดียวกัน: รุ่นเดียวกัน ทิศเดียวกัน มุมเอียงเดียวกัน เงาใกล้เคียงกัน

- สตริงที่ขนานใน MPPT เดียวกัน: จำนวนแผงเท่ากันและทิศเดียวกัน

- สตริงต่างทิศหรือต่างความยาว: แยก MPPT

- เงาบังบางแผงเป็นประจำ: รวมแผงที่มีเงาไว้ในสตริงเดียว อย่ากระจายไปทุกสตริง หรือใช้ optimizer เฉพาะแผงนั้น

- เดินสาย + และ − ของสตริงคู่กันไป (leap-frog / ไม่ให้เกิดวงรอบ) ลดพื้นที่วงลูปเพื่อลดแรงดันเหนี่ยวนำจากฟ้าผ่า

- ระบบใหญ่: ออกแบบให้สตริงยาวเท่ากันทั้งโครงการ ใช้ combiner box หรือ string inverter กระจายตามโซน

## ประเด็นระดับปริญญาโท ขั้นสูง

- Clipping loss แบบรายชั่วโมง คำนวณจากข้อมูล POA รายชั่วโมงหรือราย 1–5 นาที (ข้อมูลรายชั่วโมงประเมิน clipping ต่ำเกินจริงเมื่อเมฆผ่านเร็ว)

- Optimal DC/AC ratio แก้ปัญหาเชิงเศรษฐศาสตร์: ต้นทุนแผงส่วนเพิ่มเทียบพลังงานส่วนเพิ่ม โดยมีข้อจำกัดของสัญญาและ grid code

- สายยาวกับแรงดันสูง 1,500 V ในโซลาร์ฟาร์ม ลดจำนวน combiner และต้นทุนสาย แต่ต้องออกแบบฉนวนและ PID

- ผลของ $I_{sc}$ ที่เพิ่มจากด้านหลังของแผงสองหน้า และ cloud enhancement ที่วัดได้ถึง 1,400–1,600 W/m² ในเขตร้อนช่วงสั้น ๆ ต่อการเลือกฟิวส์และอินเวอร์เตอร์

หาร Vdc สูงสุดของอินเวอร์เตอร์ด้วย Voc ของแผงที่อุณหภูมิต่ำสุดของพื้นที่ แล้วปัดลง เช่น อินเวอร์เตอร์ 600 V แผง Voc 52.2 V β −0.25 %/°C ที่ 10 °C Voc เพิ่มเป็น 54.2 V ต่อได้สูงสุด 11 แผง ต้องใช้ Voc ตอนหนาวเพราะแรงดันสูงที่สุดเกิดตอนเช้าที่อากาศเย็นและแผงยังไม่ร้อน

DC/AC ratio ควรเป็นเท่าไร?
สำหรับประเทศไทยนิยม 1.1–1.3 คือแผงใหญ่กว่าพิกัดอินเวอร์เตอร์ 10–30 % เพราะแผงแทบไม่เคยจ่ายถึงพิกัด STC จากอุณหภูมิและการสูญเสีย การสูญเสียจากการตัดยอด (clipping) ที่ 1.2–1.3 มักไม่เกิน 1–2 % แต่ได้พลังงานช่วงเช้าเย็นเพิ่ม ต้องไม่เกินค่าที่ผู้ผลิตอินเวอร์เตอร์อนุญาตและเงื่อนไขของการไฟฟ้า

แผงสองทิศต่อเข้า MPPT เดียวกันได้ไหม?
ไม่ควร สตริงที่ขนานกันต้องมีแรงดัน MPP ใกล้กัน ถ้าทิศต่างกัน แสงและอุณหภูมิต่างกัน จุด MPP ไม่ตรงกันทำให้เสียพลังงาน ให้แยกแต่ละทิศไปคนละ MPPT หรือใช้ optimizer ถ้าจำเป็นต้องรวม ต้องเป็นสตริงจำนวนแผงเท่ากันและยอมรับการสูญเสีย
