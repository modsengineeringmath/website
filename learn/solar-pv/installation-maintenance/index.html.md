# ติดตั้ง ทดสอบ ส่งมอบ และบำรุงรักษาระบบโซลาร์: IEC 62446 I-V tracer ภาพความร้อน และวิเคราะห์อาการเสีย

// บทที่ 16.18 · ออกแบบระบบโซลาร์เซลล์ · Installation, Commissioning & O&M


การออกแบบที่ดีพังได้ด้วยการติดตั้งที่ไม่ดี: ขั้วต่อย้ำไม่แน่น สายถูกบาดใต้แผง น็อตยึดหลังคารั่ว หรือไม่เคยวัดค่าจริงเทียบกับที่ออกแบบ หน้านี้รวมงานภาคสนามตั้งแต่วันติดตั้งจนถึงปีที่ 25: ขั้นตอนที่ปลอดภัย การทดสอบก่อนจ่ายไฟพร้อมวิธีตีความตัวเลข ตารางบำรุงรักษา และตารางวิเคราะห์อาการเสีย

สรุปใน 30 วินาที

- ทุกสตริง: วัดขั้ว $V_{oc}$ $I_{sc}$ และฉนวน แล้วเทียบกับค่าที่ปรับตามแสงและอุณหภูมิขณะวัด

- $V_{oc}$ ต่ำไป 1/3 แผง = ไดโอดลัด · ต่ำไปหนึ่งแผง = ต่อข้าม/แผงหาย · ฉนวนต่ำ = สายถลอกหรือความชื้น

- ภาพความร้อนและ I-V curve หาปัญหาที่ตาเปล่ามองไม่เห็น

- ล้างแผงเมื่อมูลค่าไฟที่เสียไปเท่ากับค่าล้าง ไม่ใช่ตามปฏิทินอย่างเดียว

## ความปลอดภัยต้องมาก่อน พื้นฐาน

- ทำงานบนที่สูง: เข็มขัดนิรภัยแบบเต็มตัวพร้อมจุดยึด บันไดยึดแน่น ห้ามเดินบนแผ่นหลังคาโปร่งแสงหรือกระเบื้องที่ไม่ได้รับน้ำหนัก หยุดงานเมื่อลมแรงหรือฝนฟ้าคะนอง

- ไฟ DC มีตลอดเวลาที่มีแสง: ใช้เครื่องมือหุ้มฉนวน ถุงมือ แว่นตา ห้ามถอดขั้ว MC4 ขณะมีกระแส (ตัด DC isolator หรือหยุดอินเวอร์เตอร์ก่อน) ปิดแผงด้วยผ้าทึบเมื่อต้องทำงานกับขั้วที่เปิดอยู่

- ล็อกและติดป้าย (LOTO) ทั้งฝั่ง AC และ DC ก่อนทำงานกับอินเวอร์เตอร์และแบตเตอรี่

- ผู้ปฏิบัติงาน มีความรู้และใบอนุญาตตามข้อกำหนด งานต่อเข้าระบบไฟฟ้าทำโดยช่าง/วิศวกรไฟฟ้าที่มีคุณสมบัติ

## ขั้นตอนติดตั้ง พื้นฐาน

- สำรวจโครงสร้าง: แป จันทัน ระยะห่าง สภาพสนิม แผ่นหลังคาเดิม ให้วิศวกรโยธาประเมินน้ำหนักเพิ่ม (ระบบหลังคาทั่วไป 12–20 kg/m²) และแรงลมยก ตามมาตรฐานการคำนวณแรงลมของกรมโยธาธิการและผังเมือง (มยผ. 1311)

- เลือกอุปกรณ์ยึดให้ตรงชนิดหลังคา: เมทัลชีต (แคลมป์ยึดลอนหรือ L-foot พร้อมยางกันซึม) กระเบื้องลอน/CPAC (ตะขอใต้กระเบื้อง) ดาดฟ้าคอนกรีต (ฐานถ่วงน้ำหนักหรือพุกเคมีพร้อมกันซึม) — วัสดุอะลูมิเนียมและสแตนเลส น็อตกันคลาย

- วางราง จัดแนว เว้นระยะขอบหลังคา (ลมแรงที่ขอบและมุม) และช่องลมใต้แผง ≥ 10 cm

- ยกและวางแผง ตามจุดจับยึดในคู่มือแผง ขันด้วยแรงบิดที่กำหนด (torque wrench) ห้ามเหยียบ ห้ามวางของทับ

- เดินสาย DC ตาม หน้าสายไฟ ย้ำขั้วด้วยเครื่องมือที่ถูกต้อง ทดสอบดึง ยึดสายด้วยคลิปสแตนเลส/เคเบิลไทร์ทน UV ติดฉลากสตริงที่ปลายสายทั้งสองด้าน

- ติดตั้งอินเวอร์เตอร์ ในที่ร่ม อากาศถ่ายเท เว้นระยะรอบตัวเครื่องตามคู่มือ ต่อสายดิน SPD สวิตช์ตัดตอน เบรกเกอร์

- ทดสอบตามหัวข้อถัดไปก่อนเชื่อมกริด แล้วตั้งค่าประเทศ/มาตรฐาน (country code) ให้ตรงกับข้อกำหนดของการไฟฟ้า

## การทดสอบก่อนจ่ายไฟ (IEC 62446-1) กลาง

| การทดสอบ | เครื่องมือ | เกณฑ์/สิ่งที่ดู |

| ตรวจด้วยตา | เช็กลิสต์ | สายยึดแน่น ไม่ห้อย ขั้วต่อยี่ห้อเดียวกัน ป้ายครบ ไม่มีแผงแตก |

| ความต่อเนื่องของสายดิน/ประสานศักย์ | มิเตอร์ความต้านทานต่ำ | ทุกโครงและกรอบแผงต่อถึงขั้วดินหลัก |

| ขั้ว (polarity) | มัลติมิเตอร์ DC | ถูกขั้วทุกสตริงก่อนเสียบเข้าอินเวอร์เตอร์ (กลับขั้วอาจทำให้อินเวอร์เตอร์เสียหาย) |

| $V_{oc}$ ทุกสตริง | มัลติมิเตอร์ DC CAT III 1000 V ขึ้นไป | เทียบค่าคาดหมาย (I1) และเทียบสตริงกันเอง ต่างกันไม่เกิน ~2–3 % |

| $I_{sc}$ หรือกระแสใช้งาน | แคลมป์มิเตอร์ DC / I-V tracer | เทียบค่าคาดหมายที่แสงขณะวัด (≥ 400–600 W/m²) |

| ความต้านทานฉนวน | เครื่องทดสอบฉนวน 500/1,000 V DC | ≥ 1 MΩ ตามเกณฑ์ของมาตรฐาน (ทดสอบ + และ − ลงดิน โดยใช้วิธีที่ปลอดภัยตามคู่มือเครื่องมือ) |

| การทำงาน | — | สวิตช์ตัดตอน การตัดเมื่อไฟดับ (anti-islanding) การสื่อสาร monitoring |

| (ระดับ 2) I-V curve ทุกสตริง | I-V curve tracer + เซนเซอร์แสง/อุณหภูมิ | รูปร่างเส้นโค้ง FF กำลังที่ปรับเป็น STC |

| (ระดับ 2) ภาพถ่ายความร้อน | กล้องอินฟราเรด/โดรน (IEC 62446-3) | แสงบนแผง ≥ 600 W/m² หา hot spot ไดโอด ขั้วต่อร้อน |

I1 Expected string values at test conditions ค่าคาดหมายของสตริงขณะทดสอบ

$$V_{oc,exp} = N_s V_{oc,STC}\left[1+\beta(T_c-25)\right] \qquad I_{sc,exp} = I_{sc,STC}\,\frac{G}{1000}\left[1+\alpha(T_c-25)\right]$$

ตัวอย่าง I-1

### ตีความผลวัดสตริง 10 แผง

ขณะวัด: แสง 850 W/m² อุณหภูมิแผง 45 °C (วัดด้านหลังแผง)

- $V_{oc,exp} = 10(52.2)\left[1 - 0.0025(20)\right] = 495.9$ V · $I_{sc,exp} = 14.1(0.85)\left[1 + 0.00045(20)\right] = 12.09$ A

- สตริง A วัดได้ 489 V 12.0 A → ต่าง −1.4 % และ −0.7 % ปกติ

- สตริง B วัดได้ 479 V → ต่ำไป ≈ 17 V ≈ 1/3 ของแผงหนึ่งแผง → บายพาสไดโอดลัดหนึ่งตัว ไล่วัดรายแผง

- สตริง C วัดได้ 446 V → ต่ำไป ≈ 50 V ≈ หนึ่งแผง → ต่อข้ามแผงหรือนับแผงผิด ตรวจการเดินสาย

- สตริง D วัดได้ 495 V แต่กระแส 8.9 A → กระแสต่ำ 26 % → เงา สกปรกเฉพาะส่วน แผงต่างรุ่น หรือเซลล์ร้าว — ตรวจด้วยกล้องความร้อน/I-V curve

### อ่านรูปร่างเส้น I-V จาก curve tracer

| รูปร่างที่ผิดปกติ | สาเหตุที่น่าจะเป็น |

| ขั้นบันได (notch) | เงาบางส่วน สกปรกเฉพาะจุด เซลล์ร้าว บายพาสไดโอดนำ |

| ความชันใกล้ $V_{oc}$ ลดลง (โค้งลาด) | $R_s$ สูง: ขั้วต่อหลวม/ไหม้ ริบบอนขาด สายเล็ก |

| ความชันใกล้ $I_{sc}$ เอียงลง | $R_{sh}$ ต่ำ: PID เซลล์รั่ว |

| กระแสต่ำทั้งเส้น | ฝุ่นทั่วแผง การเสื่อม เซนเซอร์แสงไม่ตรงระนาบ |

| แรงดันต่ำเป็นขั้น 1/3 แผง | บายพาสไดโอดลัด |

### เอกสารส่งมอบ

SLD ฉบับติดตั้งจริง ผังแผงและสตริง ดาต้าชีตและใบรับรอง ผลทดสอบทุกสตริง (พร้อมแสงและอุณหภูมิขณะวัด) ภาพถ่ายระหว่างติดตั้ง (ขั้วต่อ จุดยึด กันซึม) ใบรับประกัน คู่มือการใช้งานและบำรุงรักษา ข้อมูลการเข้าระบบ monitoring และขั้นตอนตัดระบบฉุกเฉิน — ผลทดสอบวันส่งมอบคือ “ค่าตั้งต้น” ที่ใช้เทียบไปอีก 25 ปีและใช้ในการเคลมประกัน

| รายวัน/รายสัปดาห์ | ดูพลังงานในแอป เทียบวันที่แดดคล้ายกัน | ระบบแจ้งเตือนอัตโนมัติ PI รายสตริง (A6) |

| ทุก 3–6 เดือน | ล้างแผงตามความสกปรก ตรวจด้วยตาจากพื้น | ตัดหญ้า ตรวจรั้ว ระบายน้ำ |

## ล้างแผงเมื่อไรจึงคุ้ม กลาง

I2 Soiling ratio อัตราส่วนความสกปรก

$$SR = \frac{P_{dirty}}{P_{clean}}\ \text{(ที่แสงและอุณหภูมิเดียวกัน)} \qquad L_{soil} = 1 - SR$$

I3 Optimal cleaning interval (linear soiling) รอบล้างที่คุ้มที่สุด

$$\text{มูลค่าที่เสียใน } n \text{ วัน} \approx \frac{s\,n^2}{2}\,E_{day}\,c \qquad n^* = \sqrt{\frac{2\,C_{clean}}{s\,E_{day}\,c}}$$

$s$ = อัตราสะสมฝุ่น (สัดส่วนต่อวัน เช่น 0.001 = 0.1 %/วัน ในหน้าแล้ง) $E_{day}$ = พลังงานต่อวัน $c$ = มูลค่าต่อหน่วย $C_{clean}$ = ค่าล้างต่อครั้ง ล้างเมื่อครบ $n^*$ วัน หรือก่อนหน้านั้นถ้าฝนไม่ตก

ตัวอย่าง I-2

### บ้าน 5.8 kWp ค่าล้างครั้งละ 800 บาท

- $E_{day}$ = 22.8 kWh, $c$ = 4.2 บาท, $s$ = 0.1 %/วัน (หน้าแล้ง ไม่มีฝน)

- $n^* = \sqrt{\dfrac{2(800)}{0.001(22.8)(4.2)}} = \sqrt{16{,}700} \approx 129$ วัน

- ที่ 129 วัน แผงสกปรกสะสม ≈ 6.5 % (เฉลี่ยช่วงนั้น ≈ 3 %) → ล้างราว 2–3 ครั้งต่อปีเฉพาะช่วงแล้ง ฝนช่วยล้างหน้าฝน

- ถ้าใกล้ไร่อ้อยช่วงเผาหรือฟาร์มไก่ $s$ อาจเป็น 0.3–0.5 %/วัน → $n^*$ ≈ 60–75 วัน

## ตารางวิเคราะห์อาการเสีย 20 แบบ กลาง

| # | อาการ | สาเหตุที่น่าจะเป็น | วิธีตรวจ/แก้ |

| 1 | อินเวอร์เตอร์ไม่ทำงานเลยตอนเช้า | แรงดันสตริงต่ำกว่า start-up, DC isolator ปิด, ฟิวส์ขาด | วัด $V_{oc}$ ที่ขั้วอินเวอร์เตอร์ |

| 2 | Error “Isolation fault / Riso low” ตอนเช้าหลังฝนตก | สายถลอกที่ขอบราง ขั้วต่อเปียก กล่องแยกสายมีน้ำ | ทดสอบฉนวนทีละสตริง ตรวจขั้วต่อ |

| 3 | ตัดช่วงเที่ยง “Grid overvoltage” | แรงดันสายจำหน่ายสูง สาย AC เล็ก/ยาว | วัดแรงดันที่มิเตอร์และขั้วอินเวอร์เตอร์ แก้สาย AC แจ้งการไฟฟ้า เปิด Volt-VAR ตามที่อนุญาต |

| 4 | กำลังแบนเรียบช่วงเที่ยง | clipping ตาม DC/AC, export limit, derating ความร้อน | ดูอุณหภูมิอินเวอร์เตอร์ การตั้งค่า |

| 5 | สตริงหนึ่งกระแสต่ำกว่าเพื่อน | เงาใหม่ ฝุ่นเฉพาะจุด แผงเสีย ขั้วต่อหลวม | เทียบ δ (A7) ภาพความร้อน |

| 6 | แรงดันสตริงต่ำ 1/3 แผง | บายพาสไดโอดลัด | วัด $V_{oc}$ รายแผง เปลี่ยนกล่องต่อสาย/แผง |

| 7 | จุดร้อนบนแผง (hot spot) | เซลล์ร้าว เงาถาวร สิ่งสกปรกเกาะ (มูลนก) | ภาพความร้อน ทำความสะอาด เคลมแผง |

| 8 | ขั้วต่อ MC4 ร้อน ไหม้ | ต่างยี่ห้อ ย้ำไม่ดี น้ำเข้า | ตัดออกเปลี่ยนคู่ใหม่ยี่ห้อเดียวกัน |

| 9 | พลังงานลดลงทีละน้อยทุกปีมากกว่าการเสื่อม | PID ฝุ่นสะสม เงาต้นไม้ที่โตขึ้น | I-V curve ดูความชัน PID recovery ตัดแต่งต้นไม้ |

| 10 | อินเวอร์เตอร์หยุดเป็นพัก ๆ ช่วงบ่ายร้อน | ระบายความร้อนไม่พอ พัดลมเสีย ติดตั้งกลางแดด | ย้ายที่/ทำร่มเงา ทำความสะอาดพัดลม |

| 11 | RCD ทริปบ่อย | กระแสรั่วผ่านความจุแผงในอากาศชื้น RCD ไม่ตรงชนิด/พิกัด | ใช้ชนิดและพิกัดที่ผู้ผลิตกำหนด ตรวจฉนวน |

| 12 | Hybrid ไม่ชาร์จแบต/แบตหยุดกะทันหัน | การสื่อสาร BMS ขาด โปรโตคอลไม่ตรง แบตร้อน | ตรวจสาย CAN/RS485 ตั้งค่ายี่ห้อแบต |

| 13 | ไฟสำรองไม่ทำงานตอนไฟดับ | โหลดสำรองเกิน ไม่ได้เดินสายตู้สำรอง ตั้งค่า EPS ปิด | ทดสอบตัดไฟเมนเป็นระยะ |

| 14 | มิเตอร์การไฟฟ้าหมุนแปลก/บิลไม่ลด | CT ของ zero export กลับทิศ มิเตอร์ยังไม่ได้เปลี่ยน | ตรวจทิศ CT และสถานะการขนานไฟ |

| 15 | monitoring ขาดหาย | Wi-Fi อ่อน รหัสผ่านเปลี่ยน ดองเกิลเสีย | ใช้ LAN/4G หรือเราเตอร์ใกล้เครื่อง |

| 16 | หลังคารั่วหลังติดตั้ง | จุดเจาะกันซึมไม่ดี สกรูเอียง | ซ่อมกันซึม ใช้อุปกรณ์ยึดที่ไม่เจาะลอน |

| 17 | แผงแตก/กระจกร้าว | ลูกเห็บ กิ่งไม้ แรงบิดยึดมาก แผงบิดตัว | เปลี่ยนแผง (ตัดสตริงก่อน) ตรวจแรงบิดจุดยึด |

| 18 | หนู/สัตว์กัดสาย | สายไม่อยู่ในท่อ ช่องใต้แผงเป็นที่หลบ | ตะแกรงกันสัตว์ ท่อหุ้ม |

| 19 | พลังงานต่ำทั้งระบบแต่ไม่มี error | ฝุ่นทั่วทั้งระบบ ปีฝนชุก (เทียบด้วยแสงจริง) | คำนวณ PI จากแสงจริง ล้างแผง |

| 20 | อินเวอร์เตอร์เสียงหึ่ง/ร้อนผิดปกติ | ตัวเก็บประจุเสื่อม ฮาร์มอนิก ภาระเกิน | ติดต่อผู้ผลิต ตรวจคุณภาพไฟฟ้า (แล็บฮาร์มอนิก) |

วิธีคิดแบบเป็นระบบเหมือนงานซ่อมคอนเวอร์เตอร์ (วิเคราะห์อาการเสียของคอนเวอร์เตอร์): เริ่มจากข้อมูล → แยกส่วน (สตริง/อินเวอร์เตอร์/กริด) → วัดค่าที่เทียบได้ → เปลี่ยนทีละอย่าง → บันทึก

## ประเด็นระดับปริญญาโท ขั้นสูง

- EL (electroluminescence) และ UVF (UV fluorescence) ภาคสนามเพื่อหารอยร้าวเซลล์ในฟาร์มขนาดใหญ่ (ทำกลางคืนหรือด้วยกล้องที่กรองแสง)

- การวิเคราะห์ภาพความร้อนจากโดรนด้วย AI จำแนกชนิดความผิดปกติอัตโนมัติ และหาตำแหน่งบนผังด้วย GPS

- Reliability-centered maintenance และการวางแผนอะไหล่จากอัตราความเสียหาย (FIT) ของอินเวอร์เตอร์ ขั้วต่อ และแผง

- การรีไซเคิลแผงหมดอายุ และการซ่อมแผง (repowering) เมื่อแผงรุ่นเดิมหาไม่ได้
