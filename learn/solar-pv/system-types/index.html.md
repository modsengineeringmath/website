# ระบบโซลาร์ On-grid Off-grid Hybrid และการขนานไฟกับ กฟภ. กฟน.

// บทที่ 14.4 · ออกแบบระบบโซลาร์เซลล์ · System Types & Grid Connection


การนำไฟจากแผงมาใช้มีได้หลายสถาปัตยกรรม และแต่ละแบบเหมาะกับรูปแบบการใช้ไฟต่างกัน การเลือกผิดตั้งแต่ขั้นนี้ทำให้ทั้งโครงการไม่คุ้ม เช่น ใส่แบตเตอรี่ให้บ้านที่ใช้ไฟแค่กลางวัน หรือติด on-grid ให้บ้านที่ต้องการไฟสำรองตอนไฟดับ

สรุปใน 30 วินาที

- On-grid: ถูกที่สุด คืนทุนเร็ว แต่ไฟดับแล้วดับด้วย

- Hybrid: on-grid + แบต + ไฟสำรอง แพงขึ้น คุ้มเมื่อใช้ไฟกลางคืนมากหรือไฟดับบ่อย

- Off-grid: ไม่มีการไฟฟ้า แบตต้องพอทั้งกลางคืนและวันฝนตก ออกแบบเผื่อมาก

- ต่อขนานกับการไฟฟ้าทุกกรณีต้องใช้อินเวอร์เตอร์ในรายชื่อที่การไฟฟ้ายอมรับ และแจ้ง/ขออนุญาตตามระเบียบ

## เปรียบเทียบระบบหลัก พื้นฐาน

| แบตเตอรี่ | ไม่มี | มี | มี (ขนาดใหญ่) | ไม่มี หรือใช้ถังน้ำแทน |

| ไฟดับ | ระบบหยุด | จ่ายโหลดสำรองต่อ | ไม่เกี่ยว | ไม่เกี่ยว |

| อุปกรณ์หลัก | อินเวอร์เตอร์ on-grid | อินเวอร์เตอร์ไฮบริด + แบต + BMS | อินเวอร์เตอร์ off-grid / ชาร์จคอนโทรลเลอร์ + แบต (+ เครื่องปั่นไฟ) | คอนโทรลเลอร์ปั๊ม / ตัวแปลง DC |

| เหมาะกับ | บ้าน ร้าน โรงงาน ที่ใช้ไฟกลางวัน | บ้านใช้ไฟกลางคืน ไฟดับบ่อย ต้องการความมั่นคง | เกาะ ดอย สวน ไร่ สถานีสื่อสาร | ปั๊มน้ำเกษตร พัดลม DC ไฟส่องสว่าง |

### รูปแบบย่อยที่พบบ่อย

- String inverter แผงหลายแผงต่ออนุกรมเป็นสตริงเข้าอินเวอร์เตอร์ตัวเดียว ราคาต่อวัตต์ต่ำ บำรุงรักษาง่าย

- Micro-inverter อินเวอร์เตอร์เล็กต่อแผง 1–4 แผง แรงดัน DC ต่ำ (< 60–80 V) ปลอดภัยเรื่องไฟไหม้ DC ทนเงาบังดี แต่ราคาสูงและอุปกรณ์อยู่บนหลังคาร้อน

- Power optimizer DC-DC ต่อแผง ทำ MPPT ระดับแผง ส่งไปอินเวอร์เตอร์สตริง มีฟังก์ชัน rapid shutdown

- Zero export / Export limit ระบบ on-grid หรือ hybrid ที่มีมิเตอร์หรือ CT ที่จุดต่อ ลดกำลังเมื่อจะมีไฟย้อนออก ใช้เมื่อไม่ได้ขายไฟหรือหม้อแปลงรับไฟย้อนไม่ได้

- Off-grid + เครื่องกำเนิดไฟฟ้า (PV-diesel hybrid) ใช้เมื่อพลังงานแสงไม่พอในบางฤดู แบตเล็กลงได้มาก

## สมดุลพลังงาน: ใช้เอง ส่งออก ซื้อเข้า กลาง

ทุกช่วงเวลา กำลังจากแผง โหลด และการไฟฟ้า ต้องสมดุลกันที่ตู้ไฟ ถ้ารวมทั้งปี:

S1 Energy balance at the meter สมดุลพลังงานที่จุดต่อ

$$E_{PV} = E_{self} + E_{export} \qquad E_{load} = E_{self} + E_{import}$$

S2 Self-consumption and self-sufficiency อัตราการใช้เองและการพึ่งพาตนเอง

$$SCR = \frac{E_{self}}{E_{PV}} \qquad SSR = \frac{E_{self}}{E_{load}}$$

S3 Bill saving under net billing ผลประหยัดค่าไฟแบบ net billing

$$\text{Saving} = E_{self}\,c_{buy} + E_{export}\,c_{sell} \qquad c_{sell} ภายใต้ net billing ไฟที่ใช้เองมีค่าเท่าค่าไฟที่ไม่ต้องซื้อ (≈ 4–4.5 บาท/หน่วยรวม Ft และ VAT) แต่ไฟส่วนเกินที่ส่งออกได้ราคารับซื้อต่ำกว่า (โครงการโซลาร์ภาคประชาชนช่วงปี 2567–2568 ใช้ 2.20 บาท/หน่วย สัญญา 10 ปี) ผลคือ ทุกหน่วยที่ใช้เองมีค่าเกือบสองเท่าของหน่วยที่ขาย การออกแบบที่ดีจึงพยายามให้ SCR สูง (ดู เลือกขนาดจากบิล)

ตัวอย่าง S-1

### บ้านใช้ไฟ 600 หน่วย/เดือน ติด 5 kWp

ระบบผลิต 600 kWh/เดือน บ้านใช้ไฟช่วงมีแดด 270 kWh/เดือน ค่าไฟ 4.2 บาท/หน่วย ราคารับซื้อ 2.2 บาท/หน่วย

- $E_{self} = 270$ kWh (ใช้ได้ไม่เกินโหลดกลางวัน) · $E_{export} = 600 - 270 = 330$ kWh

- Saving = $270(4.2) + 330(2.2) = 1{,}134 + 726 = 1{,}860$ บาท/เดือน

- SCR = 270/600 = 45 % · SSR = 270/600 = 45 %

- ถ้าติดแค่ 2.9 kWp (ผลิต ≈ 326 kWh ใช้เองได้ ≈ 270) ประหยัด ≈ 1,134 + 123 = 1,257 บาท ด้วยเงินลงทุนแค่ 58 % — ผลตอบแทนต่อบาทดีกว่า แม้ประหยัดรวมน้อยกว่า

## Hybrid แบบ DC-coupled กับ AC-coupled กลาง

S4 Efficiency of a conversion chain ประสิทธิภาพของห่วงโซ่การแปลง

$$\eta_{chain} = \prod_k \eta_k$$

| | DC-coupled | AC-coupled |

| เส้นทาง PV → แบต → โหลด AC | MPPT DC-DC (0.98) → แบต (0.95) → อินเวอร์เตอร์ (0.96) | PV inverter (0.97) → battery inverter ชาร์จ (0.96) → แบต (0.95) → ดิสชาร์จ (0.96) |

| ประสิทธิภาพรวม | $0.98 \times 0.95 \times 0.96 \approx 0.89$ | $0.97\times0.96\times0.95\times0.96 \approx 0.85$ |

| เหมาะกับ | ระบบใหม่ทั้งชุด | เพิ่มแบตให้ระบบ on-grid ที่มีอยู่ ระบบใหญ่หลายอินเวอร์เตอร์ |

| ข้อจำกัด | ขนาดแผงและแบตผูกกับอินเวอร์เตอร์ตัวเดียว | อุปกรณ์มากขึ้น ต้องประสานการควบคุม (frequency shifting ในโหมด off-grid) |

ประสิทธิภาพต่างกันราว 4 % เฉพาะพลังงานที่ผ่านแบตเตอรี่ ส่วนพลังงานที่ใช้ตรงช่วงกลางวันผ่านการแปลงขั้นเดียวในทั้งสองแบบ

## ทำไมระบบ on-grid ต้องดับเมื่อไฟดับ พื้นฐาน

ถ้าอินเวอร์เตอร์ยังจ่ายไฟเข้าสายที่การไฟฟ้าตัดออกเพื่อซ่อม ช่างที่คิดว่าสายไม่มีไฟจะถูกไฟดูด ปรากฏการณ์นี้เรียกว่า islanding มาตรฐานจึงกำหนดให้อินเวอร์เตอร์ตรวจจับและตัดตัวเองภายใน 2 วินาที (IEC 62116, IEEE 1547) ด้วยการเฝ้าดูแรงดันและความถี่ (passive) ร่วมกับการรบกวนเล็กน้อยเพื่อดูการตอบสนอง (active) รายละเอียดอยู่ที่ อินเวอร์เตอร์โซลาร์

ระบบ hybrid จ่ายโหลดสำรองได้เพราะมี สวิตช์ถ่ายโอน (transfer relay) ในตัวที่แยกวงจรโหลดสำรองออกจากการไฟฟ้าก่อน แล้วจึงสร้างไฟ AC เองจากแบตเตอรี่ — วงจรสำรองต้องเดินสายแยกเป็นตู้โหลดสำรอง (backup/EPS panel) ไม่ใช่ทั้งบ้าน

## ขั้นตอนขออนุญาตขนานไฟในประเทศไทย พื้นฐาน

ขั้นตอนโดยทั่วไปของระบบบนหลังคาขนาดเล็ก (สรุปเพื่อให้เห็นภาพรวม รายละเอียด เอกสาร และค่าธรรมเนียมเปลี่ยนตามประกาศ ตรวจเว็บไซต์ของการไฟฟ้าและ กกพ. ฉบับล่าสุดก่อนยื่นทุกครั้ง):

- ตรวจโครงสร้างหลังคา ให้วิศวกรโยธาประเมินและรับรองความแข็งแรง ระบบบนหลังคาที่พื้นที่และน้ำหนักไม่เกินเกณฑ์ที่กฎกระทรวงกำหนดสามารถใช้วิธีแจ้งต่อเจ้าพนักงานท้องถิ่นแทนการขออนุญาตดัดแปลงอาคาร

- ยื่นคำขอขนานไฟ กับการไฟฟ้าส่วนภูมิภาค (กฟภ.) หรือการไฟฟ้านครหลวง (กฟน.) ตามพื้นที่ ผ่านระบบออนไลน์ แนบแบบ single-line diagram รายการอุปกรณ์ ใบรับรองวิศวกรไฟฟ้า และใบรับรองโครงสร้าง

- แจ้ง กกพ. (สำนักงานคณะกรรมการกำกับกิจการพลังงาน) เรื่องการยกเว้นใบอนุญาตผลิตไฟฟ้าสำหรับระบบขนาดเล็ก

- ติดตั้ง ด้วยอินเวอร์เตอร์ที่อยู่ในรายชื่อที่ผ่านการทดสอบของการไฟฟ้า อุปกรณ์ตามมาตรฐาน และช่างหรือวิศวกรที่มีใบอนุญาต

- การไฟฟ้าตรวจและทดสอบ (เช่น ทดสอบการตัดเมื่อไฟดับ) เปลี่ยนมิเตอร์เป็นแบบวัดสองทาง (ถ้าขายไฟ) แล้วจึงเริ่มขนานไฟและนับวันซื้อขาย

ห้ามขนานไฟก่อนได้รับอนุญาต การต่อระบบ on-grid โดยไม่แจ้งการไฟฟ้า อาจผิดระเบียบ ถูกตัดไฟ หรือมีปัญหากับประกันภัยเมื่อเกิดเหตุ ระบบ zero export ก็ยังเป็นการต่อขนานและต้องปฏิบัติตามระเบียบ

### โครงการขนาดใหญ่

- ระบบหลังคาโรงงานและอาคารพาณิชย์ขนาดหลายร้อย kW ถึง MW: ศึกษาการเชื่อมต่อ (grid impact study) ข้อกำหนดการเชื่อมต่อระบบโครงข่ายไฟฟ้า (grid code) ระบบป้องกันที่จุดต่อ และอาจต้องขอรับใบอนุญาตผลิตไฟฟ้า

- โรงไฟฟ้า (โซลาร์ฟาร์ม) ขายไฟเข้าระบบ: เข้าร่วมตามประกาศรับซื้อไฟฟ้าของรัฐ (PPA) ใบอนุญาตผลิตไฟฟ้า การใช้ที่ดิน รายงานสิ่งแวดล้อม (CoP/EIA ตามขนาด) และสัญญาซื้อขายไฟฟ้า (ดู โซลาร์ฟาร์ม)

- รูปแบบธุรกิจที่พบบ่อย: ลงทุนเอง (CAPEX), เช่าระบบ, Private PPA (ผู้ลงทุนติดตั้งให้แล้วขายไฟในราคาต่ำกว่าการไฟฟ้า), ESCO

## เลือกระบบให้ตรงกับการใช้ไฟ

| ถ้า… | เลือก | เหตุผล |

| ใช้ไฟกลางวันมาก (แอร์ ร้าน สำนักงาน โรงงานกะกลางวัน) | On-grid ขนาดพอดีโหลดกลางวัน | ใช้เองเกือบ 100 % คืนทุน 4–6 ปี |

| ใช้ไฟกลางคืนเป็นหลัก ไม่ค่อยมีคนอยู่กลางวัน | On-grid ขนาดเล็ก หรือ Hybrid | แบตเตอรี่ช่วยย้ายพลังงาน แต่คืนทุนนานขึ้น |

| ไฟดับบ่อย มีอุปกรณ์สำคัญ (ตู้แช่ ปั๊มออกซิเจนบ่อปลา เครื่องมือแพทย์) | Hybrid + ตู้โหลดสำรอง | มูลค่าความมั่นคงสูงกว่าค่าไฟ |

| ไม่มีสายการไฟฟ้า หรือค่าเดินสายแพงมาก | Off-grid (+ เครื่องปั่นไฟสำรอง) | ถูกกว่าการพาดสายหลายกิโลเมตร |

| ใช้ไฟเพื่อสูบน้ำช่วงกลางวัน | ปั๊มโซลาร์ DC / VFD ต่อตรง | ถังน้ำเก็บพลังงานแทนแบต (ดู เกษตร) |

| หม้อแปลงหรือสัญญาไม่ให้ไฟย้อน | On-grid / Hybrid + zero export | ใช้เองล้วน ไม่ส่งออก |

| หลังคาหลายทิศ มีเงามาก | Micro-inverter หรือ optimizer | MPPT ระดับแผง |

## ประเด็นระดับปริญญาโท ขั้นสูง

- Hosting capacity ของสายจำหน่ายแรงต่ำ: แรงดันเกินช่วงเที่ยง (voltage rise) เมื่อ PV หนาแน่น วิเคราะห์ด้วย load flow แก้ด้วย Volt-VAR, Volt-Watt, OLTC หรือแบตเตอรี่ชุมชน

- Virtual power plant (VPP) และ demand response รวมระบบ hybrid หลายพันหลังเป็นโรงไฟฟ้าเสมือน

- Microgrid ที่สลับโหมด grid-connected/islanded อย่างราบรื่น grid-forming inverter และการแบ่งโหลดด้วย droop control

- Peer-to-peer energy trading ระหว่างบ้าน ทดลองในไทยหลายพื้นที่ ประเด็นด้านกฎหมายและการคิดค่าผ่านสาย (wheeling charge)

ไม่ได้ อินเวอร์เตอร์ on-grid ต้องหยุดจ่ายไฟภายในเวลาที่มาตรฐานกำหนดเมื่อไฟการไฟฟ้าดับ (anti-islanding) เพื่อความปลอดภัยของช่างที่ซ่อมสายส่ง ถ้าต้องการไฟสำรองต้องใช้ระบบ hybrid ที่มีแบตเตอรี่และช่องจ่ายโหลดสำรอง (backup/EPS)

Zero export คืออะไร ต้องขออนุญาตการไฟฟ้าไหม?
Zero export คือการควบคุมไม่ให้ไฟจากโซลาร์ไหลย้อนออกสู่ระบบการไฟฟ้า โดยใช้มิเตอร์หรือ CT วัดกำลังที่จุดต่อแล้วลดกำลังอินเวอร์เตอร์ แม้ไม่ขายไฟ ระบบที่ต่อขนานกับการไฟฟ้ายังต้องแจ้งหรือขออนุญาตตามระเบียบของ กฟภ. หรือ กฟน. และใช้อินเวอร์เตอร์ที่อยู่ในรายชื่อที่การไฟฟ้ายอมรับ

Hybrid แบบ DC-coupled กับ AC-coupled ต่างกันอย่างไร?
DC-coupled ต่อแผงและแบตเตอรี่เข้าอินเวอร์เตอร์ไฮบริดตัวเดียว ชาร์จแบตจากแผงโดยตรง ประสิทธิภาพสูงกว่าและถูกกว่าสำหรับระบบใหม่ AC-coupled เพิ่มแบตเตอรี่พร้อมอินเวอร์เตอร์แบตเข้าทางฝั่ง AC เหมาะกับการเพิ่มแบตให้ระบบ on-grid เดิม แต่พลังงานผ่านการแปลงหลายขั้นกว่า
