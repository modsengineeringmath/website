# อินเวอร์เตอร์โซลาร์: โครงสร้าง Boost + H-bridge, PLL, ควบคุมกระแสกริด, Anti-islanding และมาตรฐาน

// บทที่ 14.13 · ออกแบบระบบโซลาร์เซลล์ · PV Inverters & Grid-Tie Control


อินเวอร์เตอร์คือ “สมอง” ของระบบโซลาร์: ทำ MPPT แปลง DC เป็น AC ที่สะอาดและซิงโครไนซ์กับกริด ป้องกันตัวเองและผู้คน และสื่อสารกับผู้ใช้ หน้านี้เปิดฝาอินเวอร์เตอร์ออกดูทีละบล็อก พร้อมสมการออกแบบที่ใช้ได้จริงกับอินเวอร์เตอร์ 5 kW และเชื่อมกับเนื้อหา อิเล็กทรอนิกส์กำลัง ระบบควบคุม และ สเปกตรัม PWM

สรุปใน 30 วินาที

- Boost (MPPT) → DC-link (C ใหญ่ รับกำลังกระเพื่อม 100 Hz) → H-bridge SPWM → ฟิลเตอร์ L/LCL → กริด

- ลูปซ้อน: ลูปกระแส (เร็ว) ← ลูปแรงดัน DC-link (ช้า) ← MPPT (ช้าสุด) และ PLL ให้มุมเฟส

- อินเวอร์เตอร์เป็นแหล่งกระแส (grid-following) ต้องตัดเมื่อเกิด islanding

- มาตรฐาน: IEC 62109 62116 61727 IEEE 1547 และข้อกำหนดของ กฟภ./กฟน.

## ชนิดของอินเวอร์เตอร์ตามขนาด พื้นฐาน

| ชนิด | กำลัง | จุดเด่น | ข้อจำกัด |

| Micro-inverter | 0.3–2 kW | MPPT รายแผง แรงดัน DC ต่ำ ขยายง่าย | ราคาต่อวัตต์สูง ตัวเครื่องอยู่บนหลังคาร้อน |

| String inverter 1 เฟส | 1–10 kW | มาตรฐานบ้าน ราคาคุ้ม หลาย MPPT | เงาบังกระทบทั้งสตริง |

| String inverter 3 เฟส | 5–350 kW | อาคาร โรงงาน และฟาร์มแบบกระจาย ซ่อมโดยเปลี่ยนเครื่อง | จำนวนเครื่องมาก |

| Central inverter | 1–5 MVA | ต้นทุนต่อ MW ต่ำสุดสำหรับฟาร์มใหญ่ | จุดเสียจุดเดียวกระทบมาก ต้องมีอะไหล่และช่างเฉพาะ |

| Hybrid inverter | 3–30 kW | PV + แบต + ไฟสำรอง ในเครื่องเดียว | ต้องเลือกแบตที่เข้ากันได้ |

## โครงสร้างภายในอินเวอร์เตอร์ 1 เฟส กลาง

สตริง PV→EMI filter DC · ตรวจ Riso→Boost (MPPT) ต่อ MPPT→DC-link 380–420 V→H-bridge (H5/HERIC) SPWM→ฟิลเตอร์ LCL→รีเลย์ตัดต่อ ×2 · RCMU→EMI filter AC · กริด

- ขั้น boost หนึ่งตัวต่อ MPPT ทำ MPPT ของแต่ละสตริงอิสระ (ดู MPPT) และยกแรงดันขึ้นเมื่อสตริงสั้น ถ้าแรงดันสตริงสูงกว่า DC-link อยู่แล้ว ขั้น boost จะถูกบายพาสเพื่อลดการสูญเสีย

- DC-link แยกพลวัตของสองขั้นออกจากกัน และรับกำลังกระเพื่อม 100 Hz ของระบบ 1 เฟส

- H-bridge สวิตช์ 16–50 kHz ด้วย MOSFET (Si/SiC) หรือ IGBT · วงจรไร้หม้อแปลงแบบ H5 หรือ HERIC เพิ่มสวิตช์เพื่อแยกแผงออกจากกริดช่วง freewheeling ทำให้แรงดันโหมดร่วม (common-mode) ของแผงเทียบดินคงที่ ลดกระแสรั่วผ่านความจุแผง-ดิน (ซึ่ง RCMU ต้องตรวจ ≤ 300 mA และตรวจกระแสกระโดด 30 mA)

- รีเลย์สองชุดอนุกรม ตามมาตรฐานความปลอดภัย ตัดได้แม้รีเลย์ตัวหนึ่งติด ทดสอบตัวเองก่อนเชื่อมกริดทุกครั้ง

- ระบบ 3 เฟส ใช้วงจรสามขาสองระดับ หรือสามระดับ (NPC/T-type) เพื่อลด ripple และความเค้นแรงดันที่ DC-link 600–1,100 V

## แรงดันและตัวเก็บประจุ DC-link กลาง

V1 Minimum DC-link voltage แรงดัน DC-link ต่ำสุด

$$\text{1 เฟส: } V_{dc} > \sqrt2\,V_{g,max} \qquad \text{3 เฟส SPWM: } V_{dc} > \frac{2\sqrt2}{\sqrt3}V_{LL} \qquad \text{3 เฟส SVPWM: } V_{dc} > \sqrt2\,V_{LL}$$

ระบบ 230 V ที่แรงดันกริดสูงสุด +10 % ต้องการ $V_{dc} > 358$ V บวกแรงดันตกบนฟิลเตอร์และ margin ของการควบคุม → ใช้ 380–420 V · ระบบ 3 เฟส 400 V ต้องการ ≈ 653 V (SPWM) หรือ ≈ 566 V (SVPWM/third-harmonic injection)

V2 DC-link capacitor for 2ω power ripple (1-phase) ตัวเก็บประจุสำหรับกำลังกระเพื่อม 100 Hz

$$p(t) = P\left[1 - \cos(2\omega t)\right] \quad\Rightarrow\quad C_{dc} = \frac{P}{\omega\,V_{dc}\,\Delta V_{pp}}$$

ตัวอย่าง V-1

### DC-link ของอินเวอร์เตอร์ 5 kW 1 เฟส

- $V_{dc}$ = 400 V ยอมให้ ripple 5 % → $\Delta V_{pp}$ = 20 V

- $C_{dc} = \dfrac{5000}{(2\pi \cdot 50)(400)(20)} = 1{,}989\ \mu\text{F}$ → เช่น 4 × 560 µF/450 V อิเล็กโตรไลต์ ขนาน (ต้องตรวจพิกัดกระแส ripple 100 Hz และอุณหภูมิ เพราะอายุตัวเก็บประจุกำหนดอายุอินเวอร์เตอร์)

- ทางเลือกใหม่: ฟิล์มคาปาซิเตอร์ขนาดเล็กลงร่วมกับ power decoupling แบบแอกทีฟ เพื่อยืดอายุ (สำคัญกับ micro-inverter ที่ร้อน)

## SPWM และฟิลเตอร์ L/LCL กลาง

SPWM แบบ unipolar ทำให้แรงดันขาออกสวิตช์ระหว่าง 0 กับ ±$V_{dc}$ ที่ความถี่ประสิทธิผล $2f_{sw}$ ฮาร์มอนิกจึงย้ายไปรอบ $2f_{sw}$ และ ripple ลดลง 4 เท่าเทียบ bipolar (สเปกตรัมละเอียดอยู่ที่ อนุกรมฟูเรียร์ของอินเวอร์เตอร์)

V3 Grid-side inductor ripple (full-bridge) ริปเปิลกระแสของตัวเหนี่ยวนำ

$$\text{unipolar: } \Delta I_{pp} = \frac{V_{dc}\,d(1-d)}{2 L f_{sw}} \le \frac{V_{dc}}{8 L f_{sw}} \qquad \text{bipolar: } \Delta I_{pp,max} = \frac{V_{dc}}{2 L f_{sw}}$$

V4 LCL resonance ความถี่เรโซแนนซ์ของฟิลเตอร์ LCL

$$f_{res} = \frac{1}{2\pi}\sqrt{\frac{L_1 + L_2}{L_1 L_2 C_f}} \qquad 10 f_g ตัวอย่าง V-2

### ฟิลเตอร์ของอินเวอร์เตอร์ 5 kW 230 V, $f_{sw}$ = 20 kHz

- กระแสพิกัด $5000/230 = 21.7$ A rms → ยอด 30.7 A · ยอมให้ ripple 20 % ของยอด = 6.1 A

- V3 (unipolar): $L \ge \dfrac{400}{8(20\text{k})(6.1)} = 410\ \mu\text{H}$ — ถ้าใช้ฟิลเตอร์ L อย่างเดียว ฮาร์มอนิกความถี่สูงยังผ่านไปกริดมาก

- ใช้ LCL: $L_1$ = 0.5 mH (ฝั่งอินเวอร์เตอร์) $L_2$ = 0.15 mH (ฝั่งกริด) $C_f$ = 5 µF

- V4: $f_{res} = \dfrac{1}{2\pi}\sqrt{\dfrac{0.65\text{m}}{(0.5\text{m})(0.15\text{m})(5\,\mu)}} = 6.6$ kHz อยู่ระหว่าง 500 Hz กับ 10 kHz ✓

- เรโซแนนซ์ต้องหน่วง: passive damping (R อนุกรม $C_f$) หรือ active damping ในลูปควบคุม (ป้อนกลับกระแส $C_f$) — ไม่หน่วงแล้วลูปกระแสจะแกว่งที่ $f_{res}$

## PLL และการควบคุมกระแสกริด ขั้นสูง

อินเวอร์เตอร์เชื่อมกริดเป็น แหล่งกระแสที่ควบคุมได้ โครงสร้างลูปซ้อน (ดู ควบคุมตัวแปลงกำลัง):

- PLL หามุมเฟส $\theta$ และความถี่ของแรงดันกริด · แบบ 3 เฟสใช้ SRF-PLL: แปลง $v_{abc}$ เป็น $v_d, v_q$ แล้วใช้ PI บังคับ $v_q \to 0$ · แบบ 1 เฟสสร้างสัญญาณตั้งฉากด้วย SOGI (second-order generalized integrator) ก่อน · แบนด์วิดท์ 10–30 Hz (เร็วไปติดฮาร์มอนิก ช้าไปตามความถี่ไม่ทัน)

- ลูปแรงดัน DC-link (แบนด์วิดท์ ~10 Hz ช้ากว่า 100 Hz ripple) บอกว่าต้องส่งกำลังเท่าไร → กำหนดแอมพลิจูดกระแสอ้างอิง

- ลูปกระแส (แบนด์วิดท์ 1–2 kHz) ทำให้กระแสตามไซน์อ้างอิงที่มีเฟส $\theta$ จาก PLL · ระบบ 1 เฟสนิยมตัวควบคุม PR · 3 เฟสใช้ PI ในกรอบ dq + decoupling

V5 Proportional-resonant (PR) controller ตัวควบคุมแบบเรโซแนนซ์

$$G_{PR}(s) = K_p + \frac{2K_r\,\omega_c\,s}{s^2 + 2\omega_c s + \omega_0^2} \qquad \omega_0 = 2\pi\cdot 50$$

PI ธรรมดาตามไซน์ไม่ได้โดยไม่มีความผิดพลาดของเฟสและขนาด PR ให้อัตราขยายสูงมากที่ $\omega_0$ (เทียบเท่า PI ในกรอบหมุน) เพิ่มตัวชดเชยฮาร์มอนิก (HC) ที่ 3, 5, 7 เพื่อลดฮาร์มอนิกของกระแสเมื่อแรงดันกริดบิดเบี้ยว

V6 Power in the dq frame (amplitude-invariant) กำลังในกรอบ dq

$$P = \tfrac32\,(v_d i_d + v_q i_q) \qquad Q = \tfrac32\,(v_q i_d - v_d i_q) \qquad (v_q = 0:\ P = \tfrac32 v_d i_d,\ Q = -\tfrac32 v_d i_q)$$

เมื่อ PLL ล็อกแล้ว $i_d$ คุมกำลังจริง $i_q$ คุมกำลังรีแอกทีฟอย่างอิสระ จึงทำฟังก์ชันช่วยกริดได้

V7 Reactive power for a power factor กำลังรีแอกทีฟที่เพาเวอร์แฟกเตอร์ที่กำหนด

$$Q = P\tan(\cos^{-1}PF) \qquad S = \frac{P}{PF}$$

ตัวอย่าง V-3

### จ่ายกำลังรีแอกทีฟช่วยคุมแรงดัน

- อินเวอร์เตอร์ 5 kW ตั้งให้ทำงานที่ PF 0.9 (ดูดกำลังรีแอกทีฟ) เมื่อแรงดันสูง: $Q = 5\tan(25.8^\circ) = 2.42$ kvar

- ต้องการพิกัด $S = 5/0.9 = 5.56$ kVA — ถ้าอินเวอร์เตอร์พิกัด 5 kVA จะต้องลดกำลังจริงลงเหลือ 4.5 kW ขณะใช้ PF 0.9 (นี่คือเหตุผลที่บางโครงการเลือกพิกัด kVA สูงกว่า kW)

## Anti-islanding และการป้องกันที่จุดต่อ กลาง

- Passive: แรงดันต่ำ/เกิน ความถี่ต่ำ/เกิน อัตราเปลี่ยนความถี่ (ROCOF) การกระโดดของเฟส — ไม่พอเมื่อกำลังโหลดในเกาะพอดีกับกำลังอินเวอร์เตอร์ (non-detection zone)

- Active: Sandia frequency shift, slip-mode frequency shift, การฉีดกระแสรบกวนเล็กน้อยเพื่อวัดอิมพีแดนซ์ — เมื่อกริดหายไป สิ่งรบกวนจะผลักความถี่ออกนอกช่วงจนตัด

- มาตรฐานทดสอบ: IEC 62116 (ทดสอบด้วยโหลด RLC เรโซแนนซ์ที่ Q = 1 ต้องตัดภายใน 2 วินาที) · IEEE 1547.1 · อินเวอร์เตอร์สำหรับขนานไฟในไทยต้องผ่านการทดสอบตามระเบียบของ กฟภ./กฟน. และอยู่ในรายชื่อที่ประกาศ

- Ride-through vs trip: ระบบเล็กเดิมเน้นตัดเร็ว แต่เมื่อโซลาร์มีสัดส่วนสูง ถ้าทุกเครื่องตัดพร้อมกันเมื่อแรงดันตกชั่วขณะ ระบบไฟจะยิ่งแย่ grid code สมัยใหม่ (IEEE 1547-2018, ข้อกำหนดของผู้ควบคุมระบบสำหรับโรงไฟฟ้า) จึงกำหนดให้ ทนแรงดันตก (LVRT/HVRT) และจ่ายกระแสรีแอกทีฟช่วย ในช่วงเวลาที่กำหนด และตัดเมื่อเกินขอบเขตนั้น

- ฟังก์ชันช่วยกริด: Volt-VAR (ดูดกำลังรีแอกทีฟเมื่อแรงดันสูง) Volt-Watt (ลดกำลังเมื่อแรงดันเกิน) Freq-Watt (ลดกำลังเมื่อความถี่สูง) และการจำกัดกำลังส่งออก

## ประเด็นระดับปริญญาโท ขั้นสูง

- Grid-forming control (droop, virtual synchronous machine, dispatchable virtual oscillator) ความเฉื่อยเสมือน การจำกัดกระแสเมื่อเกิดลัดวงจร และเสถียรภาพเมื่อกริดอ่อน (SCR ต่ำ)

- เสถียรภาพแบบอิมพีแดนซ์ ระหว่างอินเวอร์เตอร์หลายเครื่องกับสายจำหน่าย (harmonic resonance, PLL-induced instability) วิเคราะห์ด้วยเกณฑ์ Nyquist ของอัตราส่วนอิมพีแดนซ์ (ดู Nyquist)

- Model predictive control และ deadbeat current control สำหรับอินเวอร์เตอร์ความถี่สวิตช์ต่ำกำลังสูง

- SiC/GaN ทำให้ $f_{sw}$ สูงขึ้น ฟิลเตอร์เล็กลง แต่ต้องจัดการ dv/dt กระแสรั่ว และ EMI

- ความเชื่อถือได้ ของตัวเก็บประจุ DC-link และโมดูลสวิตช์ภายใต้วัฏจักรความร้อนรายวันในอากาศร้อน (mission-profile based lifetime)

อินเวอร์เตอร์ส่วนใหญ่มีสองขั้น ขั้นแรกเป็นบูสต์คอนเวอร์เตอร์ที่ทำ MPPT และยกแรงดันแผงขึ้นเป็นแรงดัน DC-link ประมาณ 380–420 V ขั้นที่สองเป็นวงจรเต็มบริดจ์ที่สวิตช์ด้วย PWM แบบไซน์ที่ความถี่สิบกว่าถึงหลายสิบกิโลเฮิรตซ์ แล้วกรองด้วยตัวเหนี่ยวนำหรือฟิลเตอร์ LCL ให้เป็นกระแสไซน์ที่มีเฟสตรงกับแรงดันกริด โดยใช้ PLL ล็อกเฟสและลูปควบคุมกระแส

Anti-islanding คืออะไร?
คือฟังก์ชันที่ทำให้อินเวอร์เตอร์หยุดจ่ายไฟเมื่อการไฟฟ้าดับ เพื่อไม่ให้สายที่ควรไม่มีไฟกลับมีไฟจากโซลาร์จนเป็นอันตรายต่อช่าง อินเวอร์เตอร์ตรวจแรงดันและความถี่ที่ผิดปกติ และใช้วิธีเชิงรุกเช่นการเลื่อนความถี่เล็กน้อยเพื่อดูการตอบสนองของระบบ ต้องตัดภายในเวลาที่มาตรฐานกำหนด เช่น 2 วินาทีตาม IEC 62116

Grid-forming กับ grid-following inverter ต่างกันอย่างไร?
Grid-following ซึ่งเป็นอินเวอร์เตอร์โซลาร์ส่วนใหญ่ ทำตัวเป็นแหล่งกระแสที่ตามแรงดันและความถี่ของกริดผ่าน PLL ต้องมีกริดอยู่ก่อน Grid-forming ทำตัวเป็นแหล่งแรงดันที่สร้างแรงดันและความถี่เอง ใช้ในโหมดสำรองไฟของอินเวอร์เตอร์ไฮบริด microgrid และระบบที่มีพลังงานหมุนเวียนสัดส่วนสูง ซึ่งต้องการความเฉื่อยเสมือนเพื่อพยุงความถี่
