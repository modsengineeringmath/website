# ออกแบบโซลาร์ฟาร์ม: ผังแผง ระยะห่างแถว GCR Tracker อินเวอร์เตอร์ หม้อแปลง และการเชื่อมต่อระบบ

// บทที่ 16.16 · ออกแบบระบบโซลาร์เซลล์ · Utility-Scale Solar Farm Design


โซลาร์ฟาร์มใช้หลักเดียวกับระบบบนหลังคา แต่ทุกการตัดสินใจถูกคูณด้วยหลายพันแผงและ 25 ปี: เปลี่ยนระยะห่างแถว 10 cm คือที่ดินหลายไร่ เลือกอินเวอร์เตอร์ผิดคือรายได้ที่หายเป็นล้าน หน้านี้ไล่ตั้งแต่การพัฒนาโครงการ การวางผัง ไปจนถึงระบบแรงดันปานกลางและการเชื่อมต่อกับการไฟฟ้า

สรุปใน 30 วินาที

- ที่ดิน ≈ 5 ไร่/MWp (fixed) · พลังงาน ≈ 1,450–1,550 MWh/MWp/ปี ในพื้นที่แดดดี

- จุดเชื่อมต่อ (ความสามารถของสายและสถานีไฟฟ้า) มักกำหนดขนาดโครงการมากกว่าที่ดิน

- DC 1,500 V + string inverter 200–350 kW หรือ central 3–5 MVA → หม้อแปลง 0.8/22–33 kV

- Tracker + bifacial ได้พลังงานเพิ่ม 10–20 % ต้องเทียบด้วย LCOE

## ขั้นตอนพัฒนาโครงการ พื้นฐาน

- สัญญาและนโยบาย: รูปแบบการขายไฟ (สัญญาซื้อขายไฟกับการไฟฟ้าตามประกาศรับซื้อ, private PPA กับนิคม/โรงงาน, ใช้เอง) กำหนดขนาด ราคา และข้อกำหนดทางเทคนิค

- จุดเชื่อมต่อ: ตรวจความสามารถของสายจำหน่าย 22/33 kV หรือสถานีไฟฟ้าที่ใกล้ที่สุด (grid capacity) ระยะทางสายเชื่อมต่อ และผลการศึกษาการเชื่อมต่อ

- ที่ดิน: สถานะทางกฎหมายของที่ดิน (ที่ดินบางประเภท เช่น ส.ป.ก. มีข้อจำกัดการใช้) ผังเมือง ความลาดเอียง (< 5 % ดีที่สุด) ระดับน้ำท่วมย้อนหลัง ถนนเข้าออก

- ข้อมูลแสงและพื้นที่: ข้อมูลดาวเทียมระยะยาว + สถานีวัดแสงหน้างาน (ช่วยลดความไม่แน่นอน P90 ดู E7) สำรวจดิน (geotechnical) ทดสอบแรงดึงเสาเข็ม ความต้านทานดินสำหรับระบบกราวด์

- ใบอนุญาต: ใบอนุญาตผลิตไฟฟ้าและใบอนุญาตที่เกี่ยวข้อง การประเมินผลกระทบสิ่งแวดล้อมตามขนาด การรับฟังความคิดเห็นชุมชน

- ออกแบบเบื้องต้นและการเงิน: ผัง พลังงาน P50/P90 ต้นทุน LCOE IRR (ดู ความคุ้มค่า)

- EPC: ออกแบบละเอียด จัดซื้อ ก่อสร้าง ทดสอบ (FAT/SAT) ทดสอบเดินเครื่อง (COD) ทดสอบสมรรถนะ (PR test)

- O&M 20–25 ปี: monitoring ล้างแผง ตัดหญ้า ซ่อม อะไหล่ รายงานสมรรถนะ

## ผังแผงและพื้นที่ที่ต้องใช้ กลาง

G1 Land area พื้นที่ที่ดินที่ต้องใช้

$$A_{land} \approx \frac{P_{STC}}{\eta\cdot 1000\ \text{W/m}^2\cdot GCR}\times k_{aux} \qquad 1\ \text{ไร่} = 1{,}600\ \text{m}^2,\ k_{aux}\approx 1.2\text{–}1.3$$

G2 Energy per unit land พลังงานต่อไร่

$$\frac{E}{A_{land}} = \frac{P_{STC}\,Y_f}{A_{land}}$$

ตัวอย่าง G-1

### ที่ดินและพลังงานของ 1 MWp

- แผง 580 W ประสิทธิภาพ 22.5 % → 1,724 แผง พื้นที่แผง 4,450 m²

- GCR 0.7 (ตัวอย่าง R-3) และพื้นที่ส่วนประกอบ $k_{aux}$ = 1.25: $A_{land} = 4{,}450/0.7 \times 1.25 = 7{,}950\ \text{m}^2$ ≈ 5.0 ไร่

- G2: $Y_f$ ≈ 1,430 kWh/kWp → 1,430 MWh/ปี ÷ 5 ไร่ ≈ 290 MWh/ไร่/ปี ที่ราคาไฟ 2–3 บาท/kWh คือรายได้หลายแสนบาทต่อไร่ต่อปี — เทียบได้ว่าทำไมที่ดินใกล้สถานีไฟฟ้ามีมูลค่าสูง

### หลักการจัดผัง

- โต๊ะแผง (table) 2 แผงแนวตั้ง (2P) × 14–28 แผง หรือ 1P บนตัวติดตาม ขนาดโต๊ะตรงกับความยาวสตริง (เช่น 28 แผง/สตริงที่ 1,500 V) เพื่อลดสาย

- ทางเดินและถนน สำหรับรถล้างแผงและรถบำรุงรักษา ทางระบายน้ำตามแนวลาดธรรมชาติ

- ตำแหน่งอินเวอร์เตอร์/สถานีแปลงแรงดัน อยู่กลางกลุ่มแผงเพื่อลดความยาวสาย DC ที่แพงและสูญเสียสูง

- ระยะจากรั้วและต้นไม้ ตามการวิเคราะห์เงา (R7) ระดับแผงเหนือระดับน้ำท่วมสูงสุดที่บันทึกได้ + ระยะเผื่อ

- พืชคลุมดิน ลดฝุ่นและการกัดเซาะ (ดินเปลือยในหน้าแล้งทำให้แผงสกปรกเร็ว) และเปิดทางให้ทำเกษตรร่วม (ดู agrivoltaics)

## Fixed tilt, Single-axis tracker และ Bifacial กลาง

| | Fixed tilt 10–15° ทิศใต้ | Horizontal single-axis tracker (HSAT) แนวเหนือ-ใต้ |

| พลังงานต่อ kWp (ไทย) | ฐาน | +10–15 % (+ bifacial อีก 5–8 %) |

| รูปร่างการผลิต | ระฆังแหลม | ไหล่กว้าง ช่วงเช้า-บ่ายสูงขึ้น เหมาะ PPA ที่ราคาสูงช่วงเย็น |

| GCR / ที่ดิน | 0.6–0.8 | 0.3–0.45 ใช้ที่ดินมากกว่า |

| ความซับซ้อน | ต่ำ | มอเตอร์ ตัวควบคุม backtracking stow ลมแรง |

| ข้อจำกัด | — | ดินอ่อน น้ำท่วม ความลาดเอียงต่างระดับ |

Backtracking: ช่วงเช้าเย็นตัวติดตามเอียงกลับเพื่อไม่ให้แถวบังกันเอง แลกกับมุมตกกระทบที่ไม่ดีที่สุด ยังได้พลังงานมากกว่าปล่อยให้บัง ตัวควบคุมรุ่นใหม่ใช้ข้อมูลภูมิประเทศและแสงกระจายเพื่อเลือกมุม (diffuse-optimized tracking) ซึ่งช่วยมากในวันครึ้มของไทย

## ระบบไฟฟ้าของฟาร์ม กลาง

สตริง 1,500 V→combiner box / string inverter→สถานีแปลงแรงดัน (inverter + หม้อแปลง 0.6–0.8/22–33 kV + RMU)→สายป้อน MV วงแหวน→สวิตช์เกียร์ MV + มิเตอร์ + รีเลย์ป้องกันที่จุดต่อ→สายของการไฟฟ้า

| | String inverter (200–350 kW) | Central inverter (3–5 MVA) |

| MPPT | หลายตัวต่อเครื่อง ทนเงาและ mismatch ดี | น้อย ต่อหลายสิบสตริง |

| การซ่อม | เปลี่ยนทั้งเครื่องในไม่กี่ชั่วโมง เสียทีละน้อย | ต้องมีช่างเฉพาะ เสียครั้งละมาก |

| ต้นทุน | สูงกว่าเล็กน้อยต่อ W ลดสาย DC/combiner | ต่ำสุดต่อ W ในโครงการใหญ่มาก |

| นิยมในไทย | ฟาร์มหลาย MW ถึงหลายสิบ MW และหลังคาโรงงาน | ฟาร์มขนาดใหญ่มาก |

G3 MV current and transformer rating กระแสแรงดันปานกลางและพิกัดหม้อแปลง

$$I_{MV} = \frac{S}{\sqrt3\,V_{LL}} \qquad S_{tr} \ge \frac{P_{AC,max}}{PF_{min}}$$

G4 Three-phase cable loss การสูญเสียในสายสามเฟส

$$P_{loss} = 3\,I^2\,R'\,L$$

G5 Availability ความพร้อมใช้งาน

$$A = \frac{T_{period} - T_{down}}{T_{period}} \qquad \text{หรือแบบถ่วงพลังงาน } A_E = \frac{E_{actual}}{E_{actual}+E_{lost}}$$

ตัวอย่าง G-2

### ฟาร์ม 5 MWp ที่ลพบุรี เชื่อม 22 kV

- DC/AC 1.25 → อินเวอร์เตอร์รวม 4 MW AC (เช่น string inverter 250 kW × 16) · ที่ดิน ≈ 25 ไร่

- พลังงาน: GHI 5.1 × 1.04 × 365 × PR 0.78 × 5,000 kWp ≈ 7,550 MWh/ปี (≈ 1,510 kWh/kWp)

- G3: $I_{22kV} = 4\text{M}/(\sqrt3 \cdot 22\text{k}) = 105$ A · หม้อแปลง PF 0.95 → ≥ 4.2 MVA (เช่น 2 × 2.5 MVA เพื่อความยืดหยุ่นเมื่อซ่อม)

- G4: สาย MV อะลูมิเนียม 2 km $R'$ ≈ 0.32 Ω/km → $3(105)^2(0.32)(2) = 21$ kW ≈ 0.5 % ที่กำลังเต็ม

- ระบบป้องกันที่จุดต่อ: รีเลย์แรงดัน/ความถี่ ป้องกันกระแสเกิน ทิศทางกำลัง (ถ้าห้ามย้อนเกินพิกัด) และอินเตอร์ล็อกกับการไฟฟ้าตามข้อกำหนด

### SCADA และการวัด

- สถานีตรวจวัดอากาศ: ไพราโนมิเตอร์บนระนาบแผงและแนวราบ (Class A ตาม IEC 61724-1) อุณหภูมิแผง ลม ฝน ตัววัดความสกปรก (soiling station)

- SCADA/PPC (power plant controller) คุมกำลังจริง กำลังรีแอกทีฟ ramp rate ตามคำสั่งศูนย์ควบคุม และส่งพยากรณ์ (ดู พยากรณ์)

- เครือข่ายไฟเบอร์ออปติก ระบบกล้อง รั้ว และไฟส่องสว่างเพื่อความปลอดภัย (การขโมยสายทองแดงพบบ่อย)

## โซลาร์ลอยน้ำ (Floating PV) กลาง

- ติดบนทุ่นลอยในอ่างเก็บน้ำ บ่อดินเก่า บ่อบำบัดน้ำ — ไม่ใช้ที่ดิน น้ำช่วยลดอุณหภูมิแผง (PR สูงขึ้นเล็กน้อย) และลดการระเหยของน้ำ

- ในไทย กฟผ. พัฒนาโซลาร์ลอยน้ำร่วมกับเขื่อนพลังน้ำ (hydro-floating solar hybrid) เช่นที่เขื่อนสิรินธรและเขื่อนอุบลรัตน์ ใช้สายส่งเดิมของเขื่อนและใช้น้ำในเขื่อนเป็น “แบตเตอรี่” ชดเชยช่วงเมฆ

- ประเด็นออกแบบ: ระบบสมอยึดตามระดับน้ำขึ้นลงหลายเมตร แรงลมและคลื่น สาย DC ลอยน้ำต้องทนน้ำ (AD7/AD8) ความชื้นสูงทำให้ PID และการกัดกร่อนมากขึ้น การเข้าถึงเพื่อบำรุงรักษา และผลต่อระบบนิเวศ

## การดำเนินงานและบำรุงรักษาฟาร์ม

| งาน | ความถี่ (ทั่วไป) | หมายเหตุ |

| ล้างแผง | 2–6 ครั้ง/ปี ตามฝุ่น | ตัดสินจาก soiling ratio เทียบค่าน้ำและค่าแรง ใช้น้ำ RO/น้ำอ่อน หุ่นยนต์ล้างแบบแห้งในฟาร์มใหญ่ |

| ตัดหญ้า/จัดการพืช | ทุก 1–3 เดือนช่วงฝน | หญ้าสูงบังแผงแถวล่าง ใช้แกะ/ปศุสัตว์บางพื้นที่ |

| ภาพถ่ายความร้อนด้วยโดรน | 1–2 ครั้ง/ปี | หา hot spot ไดโอดเสีย แผงแตก ตาม IEC 62446-3 |

| ตรวจขั้วต่อ/ขันแน่น (torque) | ปีละครั้ง | กล้องความร้อนที่ combiner และหม้อแปลง |

| บำรุงรักษาหม้อแปลง/สวิตช์เกียร์ | ตามผู้ผลิต | ตรวจน้ำมัน DGA ทดสอบรีเลย์ |

| อินเวอร์เตอร์ | ทุก 6–12 เดือน | ทำความสะอาดไส้กรอง พัดลม อัปเดตเฟิร์มแวร์ |

## ประเด็นระดับปริญญาโท ขั้นสูง

- Layout optimization หา GCR ความยาวโต๊ะ และตำแหน่งอินเวอร์เตอร์ที่ทำให้ LCOE ต่ำสุดบนที่ดินรูปร่างจริงและภูมิประเทศ (terrain-following tracker)

- PV + BESS ในฟาร์ม: firming, ramp-rate control, time-shifting และ DC-coupled storage ที่ใช้พลังงาน clipping

- Grid code และการศึกษาเชิงพลวัต ของโรงไฟฟ้าอินเวอร์เตอร์: fault ride-through, short-circuit contribution, ฮาร์มอนิกและเรโซแนนซ์กับสายเคเบิลยาว (ดู ฮาร์มอนิกและฟิลเตอร์)

- Performance guarantee test ตาม IEC 61724-2/-3 และการจัดการข้อพิพาทเรื่องสมรรถนะระหว่างเจ้าของกับ EPC

## คำถามที่พบบ่อย

โซลาร์ฟาร์ม 1 MW ใช้ที่ดินกี่ไร่?
ด้วยแผงประสิทธิภาพประมาณ 22–23 % แบบยึดอยู่กับที่ ใช้ที่ดินประมาณ 4.5–6 ไร่ต่อ MWp รวมทางเดิน ถนน รั้ว และพื้นที่อุปกรณ์ ถ้าใช้ตัวติดตามแกนเดียวต้องเว้นระยะแถวมากขึ้น ใช้ประมาณ 6–8 ไร่ต่อ MWp ฟาร์มเก่าที่ใช้แผงประสิทธิภาพต่ำเคยใช้ถึง 10–15 ไร่ต่อ MW

โซลาร์ฟาร์ม 1 MW ผลิตไฟได้ปีละเท่าไร?
ในพื้นที่แดดดีของไทยประมาณ 1,450–1,550 MWh ต่อปีต่อ MWp สำหรับแบบยึดอยู่กับที่ และเพิ่มขึ้นประมาณ 10–15 % ถ้าใช้ตัวติดตามแกนเดียวกับแผงสองหน้า ขึ้นกับแสงของพื้นที่ การสูญเสีย และความพร้อมใช้งานของระบบ

ขึ้นกับพื้นที่และราคา ไทยมีแสงกระจายสูงเพราะความชื้นและเมฆ ตัวติดตามจึงได้พลังงานเพิ่มน้อยกว่าในทะเลทราย (ประมาณ 10–15 % เทียบ 20–25 %) แต่ราคาตัวติดตามลดลงมาก และช่วยให้รูปร่างการผลิตกว้างขึ้นช่วงเช้าเย็น ต้องเทียบ LCOE ของสองแบบด้วยราคาจริง ดินที่ทรุดตัวหรือน้ำท่วมขังเป็นข้อจำกัดสำคัญ
