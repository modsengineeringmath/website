คลังความรู้ของอาจารย์มด

บทเรียนคณิตศาสตร์วิศวกรรมภาษาไทย แยกหัวข้อละหนึ่งหน้า แต่ละบทสรุปแนวคิด สูตร และตัวอย่างที่ต่อไปถึงวงจรไฟฟ้า อ่านตามลำดับจะได้พื้นฐานครบสำหรับวิชาระบบควบคุมและอิเล็กทรอนิกส์กำลัง

อ่านตามลำดับ

เลขกำกับคือลำดับที่แนะนำ บทหลังใช้เครื่องมือจากบทก่อนหน้า

∫01 แคลคูลัสเบื้องต้น Basic Calculus ลิมิต อนุพันธ์ และปริพันธ์ พร้อมตัวอย่างกระแสในตัวเก็บประจุและค่า RMS อ่านบทเรียน → →02 พีชคณิตของเวกเตอร์ Vector Algebra ผลคูณจุด ผลคูณไขว้ และแรงที่กระทำต่อตัวนำในสนามแม่เหล็ก อ่านบทเรียน → ⊞03 เมทริกซ์และดีเทอร์มิแนนต์ Matrix & Determinant แก้ระบบสมการเชิงเส้นด้วยกฎของคราเมอร์ พร้อมตัวอย่างวงจรสองเมช อ่านบทเรียน →▶ มีวิดีโอ ℒ04 การแปลงลาปลาซ Laplace Transform นิยาม ตาราง เศษส่วนย่อย และการแก้วงจร RC ใน s-domain อ่านบทเรียน →▶ มีวิดีโอ τ05 ระบบอันดับหนึ่ง First-Order System · Lab แล็บโต้ตอบ: ปรับค่าคงตัวเวลา τ หรือ R, C, L แล้วดูผลตอบสนอง สเกลลอการิทึม ระนาบ s และ Bode พร้อมเส้นช่วยวิเคราะห์ อ่านบทเรียน → ζ06 ระบบอันดับสอง Second-Order System · Lab แล็บโต้ตอบ: ζ กำหนดรูปร่าง ωn กำหนดความเร็ว ลากขั้วบนระนาบ s แล้วดูผลตอบสนองเวลา เปลือก %OS และ Bode เปลี่ยนพร้อมกัน อ่านบทเรียน →
