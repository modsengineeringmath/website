θ01 สูตรตรีโกณมิติและตารางค่า Trigonometric Identities & Table วงกลมหนึ่งหน่วยแบบโต้ตอบ สูตรครบทุกหมวดพร้อมชื่ออังกฤษ และตาราง sin cos tan ทุก 0.05° ตั้งแต่ 0° ถึง 90° ทั้งองศาและเรเดียน อ่านบทเรียน → f′02 แคลคูลัสเบื้องต้น Basic Calculus ลิมิต อนุพันธ์ และปริพันธ์ พร้อมตัวอย่างกระแสในตัวเก็บประจุและค่า RMS อ่านบทเรียน → ∫03 อินทิกรัล: สูตรและวิธีทำ Integral Calculus สูตรอินทิเกรตพร้อมชื่อสากล คุณสมบัติ สูตรสำเร็จ และวิธีทำทีละขั้น: เปลี่ยนตัวแปร u หารยาว เศษส่วนย่อย ทีละส่วน และอินทิกรัลจำกัดเขต อ่านบทเรียน → →04 พีชคณิตของเวกเตอร์ Vector Algebra ผลคูณจุด ผลคูณไขว้ และแรงที่กระทำต่อตัวนำในสนามแม่เหล็ก อ่านบทเรียน → ⊞05 พีชคณิตเชิงเส้น Linear Algebra เมทริกซ์ ดีเทอร์มิแนนต์ ระบบสมการ อินเวอร์ส กฎของคราเมอร์ ค่าเฉพาะและเวกเตอร์เฉพาะ พร้อมโจทย์วงจรไฟฟ้า ตั้งแต่ ม.ปลาย ถึง ป.โท 7 หน้าย่อย →▶ มีวิดีโอ ℒ06 การแปลงลาปลาซ Laplace Transform นิยาม ตาราง เศษส่วนย่อย และการแก้วงจร RC ใน s-domain อ่านบทเรียน →▶ มีวิดีโอ τ07 ระบบอันดับหนึ่ง First-Order System · Lab แล็บโต้ตอบ: ปรับค่าคงตัวเวลา τ หรือ R, C, L แล้วดูผลตอบสนอง สเกลลอการิทึม ระนาบ s และ Bode พร้อมเส้นช่วยวิเคราะห์ อ่านบทเรียน → ζ08 ระบบอันดับสอง Second-Order System · Lab แล็บโต้ตอบ: ζ กำหนดรูปร่าง ωn กำหนดความเร็ว ลากขั้วบนระนาบ s แล้วดูผลตอบสนองเวลา เปลือก %OS และ Bode เปลี่ยนพร้อมกัน อ่านบทเรียน → ∿09 สัญญาณเบื้องต้น Signals · Lab แล็บโต้ตอบ: พิมพ์สมการสัญญาณเอง ทั้ง x(t) และ x[n] ดูอนุพันธ์ ส่วนคู่คี่ พลังงาน สเปกตรัม การแปลงเวลา และคอนโวลูชัน อ่านบทเรียน → Hz10 แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป Function Generator & Oscilloscope Lab แล็บจำลองเสมือนจริง: เครื่องกำเนิดสัญญาณคู่กับออสซิลโลสโคป 2 ช่อง ปรับได้ทุกปุ่ม พร้อมทฤษฎี Vpp Vrms ทริกเกอร์ โพรบ การวัดเฟส Bode วงจร RC RLC ไดโอด ออปแอมป์ และการสร้างเครื่องเอง ตั้งแต่ ม.ปลาย ถึง ป.โท 9 หน้าย่อย → G(s)11 ระบบควบคุม (Control Systems Engineering) Control Systems Engineering วิศวกรรมระบบควบคุมจากพื้นฐานถึงขั้นสูง: ป้อนกลับ แบบจำลอง เสถียรภาพ Routh–Hurwitz รูทโลคัสแบบวาดด้วยมือ ตอบสนองความถี่ Bode Nyquist ตัวชดเชย P PI PD PID ปริภูมิสถานะ ดิจิทัล ไปจนถึงเมคาทรอนิกส์ โรโบติกส์ และตัวแปลงกำลัง 26 หน้าย่อย →▶ มีวิดีโอ Σ12 อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก Fourier Series & Harmonic Analysis อนุกรมฟูเรียร์ทีละขั้นจนใช้งานจริง: หาสัมประสิทธิ์ สมมาตร สเปกตรัม พาร์เซวาล วิเคราะห์วงจรทีละฮาร์มอนิก THD PF และกำลังไฟฟ้า เรกติไฟเออร์ อินเวอร์เตอร์ PWM บั๊กคอนเวอร์เตอร์ การแก้ฮาร์มอนิก และ FFT พร้อมแล็บออสซิลโลสโคปและเครื่องวิเคราะห์กำลังไฟฟ้าเสมือน 14 หน้าย่อย → ⚡13 อิเล็กทรอนิกส์กำลัง Power Electronics วงจรแปลงผัน DC-DC บั๊ก บูสต์ บั๊ก-บูสต์ ชุค ตั้งแต่ volt-second balance ถึงแบบจำลองสัญญาณเล็ก ออกแบบตัวชดเชย Type II/III peak current mode ควบคุมด้วยออปแอมป์และไมโครคอนโทรลเลอร์ ตัวสังเกต AI ออกแบบตัวเหนี่ยวนำ แหล่งจ่ายทดสอบ SMPS เทคนิคหน้างาน วิเคราะห์อาการเสีย พร้อมแล็บจำลองคอนเวอร์เตอร์ 17 หน้าย่อย → ☀14 ออกแบบระบบโซลาร์เซลล์ Solar PV System Design ออกแบบและใช้งานโซลาร์เซลล์ครบวงจร ตั้งแต่เส้นโค้ง I-V เลือกแผง แสงอาทิตย์ในไทย ระบบ on-grid off-grid hybrid ออกแบบสตริง สายไฟและการป้องกัน แบตเตอรี่ คาดการณ์พลังงานและความคุ้มค่า พยากรณ์ล่วงหน้า MPPT อินเวอร์เตอร์ เลือกตัวควบคุม โซลาร์จ่ายแอร์ โซลาร์ฟาร์ม ปั๊มน้ำเพื่อการเกษตร งานติดตั้งและบำรุงรักษา เว็บไซต์ หน้าแรก คลังความรู้ สูตรและตารางตรีโกณมิติ สูตรอินทิเกรตและวิธีทำ พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ เครื่องคิดเลขเมทริกซ์แสดงวิธีทำ แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
