# แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ ดูการคูณทีละช่อง และการแปลง 2×2

// บทที่ 7.9 · พีชคณิตเชิงเส้น · Matrix Lab


รวมเครื่องมือเมทริกซ์ทั้งหมดของชุดพีชคณิตเชิงเส้นไว้ในหน้าเดียว ใส่โจทย์ของคุณเองแล้วดูวิธีทำทุกขั้นด้วยเศษส่วนแม่นตรง เหมือนเขียนบนกระดาน ใช้ตรวจการบ้าน เตรียมสอบ หรือเช็กตัวเลขในงานวงจรและโครงสร้าง ปุ่ม “ลองในเครื่องคิดเลข” จากทุกหน้าในชุดจะพาโจทย์มาที่นี่

## เครื่องคิดเลขเมทริกซ์แสดงวิธีทำ

เลือกโหมด (แก้ระบบสมการ · ดีเทอร์มิแนนต์ · อินเวอร์ส · ค่าเฉพาะ) และขนาด 2×2 ถึง 4×4 รับจำนวนเต็ม ทศนิยม และเศษส่วน เช่น -3/4 ทุกขั้นคำนวณแบบเศษส่วน ไม่มีการปัดเศษ

## โจทย์ตัวอย่างพร้อมใส่ในเครื่องคิดเลข

กดแล้วเครื่องคิดเลขด้านบนจะรับโจทย์ให้อัตโนมัติ ที่มาของแต่ละโจทย์อยู่ในงานวงจรไฟฟ้า และงานไฟฟ้า เครื่องกล โยธา

## ดูการคูณเมทริกซ์ทีละช่อง

ชี้หรือแตะที่ช่องของผลคูณ แล้วดูว่าแถวไหนของ A คูณกับหลักไหนของ B สิ่งที่ต้องจำ: ขนาดด้านในต้องเท่ากัน (m×n คูณ n×p ได้ m×p) อ่านทฤษฎีในหน้าเมทริกซ์

## แล็บการแปลง 2×2: ดีเทอร์มิแนนต์คือพื้นที่ ค่าเฉพาะคือทิศที่ไม่ถูกหมุน

ลากหลักทั้งสองของเมทริกซ์ ตารางกริดและวงกลมหนึ่งหน่วยจะถูกแปลงตาม ในโหมดดีเทอร์มิแนนต์ พื้นที่สี่เหลี่ยมด้านขนานคือ $|\det A|$ (กลับด้านเมื่อ det < 0) ในโหมดค่าเฉพาะ เส้นเขียวคือทิศที่ $A\mathbf v$ ขนานกับ $\mathbf v$

## คำถามที่พบบ่อย

เครื่องคิดเลขนี้คำนวณแบบปัดเศษไหม?
ไม่ปัด ดีเทอร์มิแนนต์ อินเวอร์ส การแก้ระบบ และพหุนามลักษณะเฉพาะคำนวณด้วยเศษส่วนแม่นตรงทุกขั้น ค่าเฉพาะที่เป็นจำนวนตรรกยะได้แบบแม่นตรง ค่าที่เป็นรากที่สองแสดงในรูปราก ส่วนกรณีอื่นแสดงทศนิยม 6 ตำแหน่ง รวมค่าเชิงซ้อน

ใส่เศษส่วนหรือทศนิยมได้ไหม?
ได้ทั้งจำนวนเต็ม ทศนิยม และเศษส่วน เช่น -3/4 หรือ 0.25 รองรับเมทริกซ์ 2×2 ถึง 4×4

ส่งโจทย์ให้เพื่อนเปิดดูได้อย่างไร?
ปุ่ม “ลองในเครื่องคิดเลข” ในทุกหน้าของชุดพีชคณิตเชิงเส้นจะเปิดหน้านี้พร้อมโจทย์ ลิงก์มีรูปแบบ /learn/linear-algebra/matrix-lab/#calc=mode=inv&A=1,2;3,4 คัดลอกส่งต่อได้เลย
