# พีชคณิตเชิงเส้น (Linear Algebra): เมทริกซ์ ดีเทอร์มิแนนต์ แรงก์ อินเวอร์ส คราเมอร์ วิธีเชิงตัวเลข และค่าเฉพาะ

// บทที่ 7 · คณิตศาสตร์วิศวกรรม · Linear Algebra


พื้นฐานที่วิศวกรไฟฟ้าใช้ทุกวันโดยไม่รู้ตัว ตั้งแต่แก้กระแสในวงจรหลายลูป ไปจนถึงหาขั้วของระบบควบคุมและวิเคราะห์ฟอลต์ในระบบสามเฟส ชุดบทเรียนนี้มี 12 หน้า ไล่จากระดับ ม.ปลาย ถึงระดับบัณฑิตศึกษา รวมหน้าแรงก์ ผลเฉลยเชิงตัวเลข แนวข้อสอบ 45 ข้อ การประยุกต์ในงานไฟฟ้า เครื่องกล โยธา และแล็บเมทริกซ์ ทุกสูตรมีรหัสอ้างอิงถาวร ค้นได้ทั้งหมดจากหน้านี้ และมีเครื่องคิดเลขที่แสดงวิธีทำทีละขั้นให้ตรวจการบ้านของตัวเอง

ทั้งบทในหนึ่งนาที

- ระบบสมการหลายตัวแปรเขียนสั้น ๆ ได้เป็น $A\mathbf x = \mathbf b$ เมทริกซ์

- $\det A \ne 0$ บอกว่ามีคำตอบเดียว ดีเทอร์มิแนนต์ หาคำตอบด้วย การลดแถว อินเวอร์ส หรือ คราเมอร์

- แรงก์บอกว่าระบบมีคำตอบเดียว ไม่จำกัด หรือไม่มี แรงก์ · ระบบใหญ่แก้ด้วย LU จาโคบี เกาส์-ไซเดล · ฝึกที่ แนวข้อสอบ 45 ข้อ

- $A\mathbf v = \lambda\mathbf v$ หาทิศพิเศษที่ไม่ถูกหมุน ซึ่งคือขั้วและโหมดของวงจร ค่าเฉพาะ

- ทุกเครื่องมือมาบรรจบที่การวิเคราะห์วงจรและระบบ ประยุกต์ในงานไฟฟ้า และงานเครื่องกล-โยธา โครงถัก โหมดการสั่น

## ค้นหาสูตรทั้งหมดในที่เดียว

รวมทุกสูตรจากทุกหน้า พิมพ์ได้ทั้งภาษาไทยและอังกฤษ หรือพิมพ์รหัสสูตรตรง ๆ เช่น D4 กดที่ชื่อสูตรเพื่อไปยังคำอธิบายและตัวอย่างวิธีทำของสูตรนั้น

## แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ

เครื่องคิดเลขเมทริกซ์ 2×2 ถึง 4×4 ที่แสดงวิธีทำแบบเศษส่วนแม่นตรง ตัวช่วยดูการคูณทีละช่อง และแล็บลากเมทริกซ์ 2×2 ย้ายไปอยู่รวมกันในหน้าแล็บเมทริกซ์ แล้ว พร้อมโจทย์ตัวอย่างจากงานวงจร ระบบไฟฟ้ากำลัง การสั่น และโครงสร้าง กดครั้งเดียวใส่ให้ทันที

## งงตรงไหน คลิกตรงนั้น

คูณเมทริกซ์ไม่ได้ หรือได้ขนาดแปลก ๆเช็กขนาด ตัวเลขด้านในต้องเท่ากัน → M10
ทำไม AB ≠ BA ทำไมตัดเมทริกซ์ไม่ได้สิ่งที่ใช้กับตัวเลขได้ แต่เมทริกซ์ไม่ได้ → M12
det(2A) ทำไมไม่ใช่ 2 det Aดึงตัวคูณได้ทีละแถว จึงได้ kⁿ → D7
กระจายโคแฟกเตอร์แล้วเครื่องหมายเพี้ยนเครื่องหมายแบบกระดานหมากรุก → D3
ลดแถวแล้วเจอ [0 0 0 | 5]ระบบไม่มีคำตอบ → L6
ลดแถวแล้วได้แถวศูนย์ทั้งแถว ตอบอย่างไรคำตอบไม่จำกัด เขียนแบบพารามิเตอร์ → L12
อินเวอร์สแบบแอดจอยต์ไม่ตรงเฉลยลืมทรานสโพสเมทริกซ์โคแฟกเตอร์ → I3
(AB)⁻¹ ต้องสลับลำดับไหมสลับเสมอ: B⁻¹A⁻¹ → I5
โจทย์ “หาแรงก์สำหรับทุกค่า k”หา det แยกตัวประกอบ แล้วลดแถวที่ค่าวิกฤต → R6
จาโคบีกับเกาส์-ไซเดลต่างกันตรงไหนใช้ค่าเก่าทั้งหมด หรือใช้ค่าใหม่ทันที → N13 N14
det(adj A) เท่ากับเท่าไร(det A)ⁿ⁻¹ ขึ้นกับขนาด n → D22
Δ = 0 แล้วคราเมอร์ใช้ไม่ได้ต้องลดแถวตรวจ ห้ามสรุปจาก 0/0 → C5
ลดแถว A − λI แล้วไม่มีแถวศูนย์ค่า λ ผิด กลับไปตรวจสมการลักษณะเฉพาะ → E2
เวกเตอร์เฉพาะไม่ตรงเฉลยคูณค่าคงที่ได้ ตรวจ Av = λv → E1
เขียนเมทริกซ์จากวงจรไม่ถูกกฎการมอง: ทแยง = ผลรวม นอกทแยง = ลบตัวร่วม → A1

## สัญลักษณ์ที่ใช้ในชุดนี้

| สัญลักษณ์ | อ่านว่า / ความหมาย | English |

| $A,\ a_{ij}$ | เมทริกซ์ และสมาชิกแถว $i$ หลัก $j$ | matrix, entry |

| $\mathbf x,\ \mathbf b$ | เวกเตอร์หลัก (ตัวหนา) | column vector |

| $I_n,\ O$ | เมทริกซ์เอกลักษณ์ เมทริกซ์ศูนย์ | identity, zero matrix |

| $A^T,\ A^H$ | ทรานสโพส ทรานสโพสสังยุค | transpose, conjugate transpose |

| $\det A = |A|$ | ดีเทอร์มิแนนต์ (ไม่ใช่ค่าสัมบูรณ์) | determinant |

| $M_{ij},\ C_{ij}$ | ไมเนอร์ โคแฟกเตอร์ | minor, cofactor |

| $\operatorname{adj}A$ | เมทริกซ์ผูกพัน | adjugate (classical adjoint) |

| $A^{-1}$ | อินเวอร์ส เมทริกซ์ผกผัน | inverse |

| $\operatorname{tr}A,\ \operatorname{rank}A$ | เทรซ แรงก์ | trace, rank |

| $[A\mid\mathbf b]$ | เมทริกซ์แต่งเติม | augmented matrix |

| $N(A),\ C(A)$ | ปริภูมิศูนย์ ปริภูมิหลัก · $\operatorname{nullity}A = \dim N(A)$ | null space, column space |

| $L,\ U,\ P$ | สามเหลี่ยมล่าง สามเหลี่ยมบน เมทริกซ์สลับแถว ใน $PA = LU$ | LU factorisation |

| $\mathbf x^{(k)},\ \omega$ | ค่าประมาณรอบที่ $k$ · ตัวประกอบผ่อนปรนของ SOR | iterate, relaxation factor |

| $\rho(T),\ \kappa(A)$ | รัศมีสเปกตรัม · เลขเงื่อนไข | spectral radius, condition number |

| $R_i \leftrightarrow R_j,\ R_i \leftarrow R_i + kR_j$ | สลับแถว · แทนแถว $i$ ด้วยแถว $i$ บวก $k$ เท่าของแถว $j$ | row operations |

| $\Delta,\ \Delta_i$ | ดีเทอร์มิแนนต์ของระบบ และของเมทริกซ์ที่แทนหลัก $i$ ด้วย $\mathbf b$ | Cramer determinants |

| $\lambda,\ \mathbf v$ | ค่าเฉพาะ เวกเตอร์เฉพาะ | eigenvalue, eigenvector |

| $j$ | หน่วยจินตภาพ $j^2 = -1$ (วิศวกรรมไฟฟ้าใช้ $j$ แทน $i$) | imaginary unit |

## คำถามที่พบบ่อย

พีชคณิตเชิงเส้นเรียนอะไรบ้าง?
แกนหลักคือเมทริกซ์และเวกเตอร์ การดำเนินการของเมทริกซ์ ดีเทอร์มิแนนต์ การแก้ระบบสมการเชิงเส้น (ลดแถว อินเวอร์ส คราเมอร์) แรงก์ ค่าเฉพาะและเวกเตอร์เฉพาะ และการทำให้เป็นเมทริกซ์ทแยงมุม ในวิศวกรรมไฟฟ้าใช้กับการวิเคราะห์วงจร ระบบควบคุม สัญญาณ และระบบไฟฟ้ากำลัง

ควรเริ่มเรียนจากหน้าไหน?
ถ้าเพิ่งเริ่ม ให้อ่านตามเส้นทาง 7.1 → 7.2 → 7.3 → 7.10 (แรงก์) → 7.4 → 7.5 → 7.11 (วิธีเชิงตัวเลข) แล้วฝึกด้วยแนวข้อสอบ 7.12 ดูงานจริงใน 7.7–7.8 และใช้แล็บเมทริกซ์ 7.9 ตรวจการบ้าน ถ้ากำลังติดโจทย์อยู่ ใช้ช่องค้นหาสูตรหรือหัวข้อ “งงตรงไหน” ในหน้านี้ แล้วกระโดดไปที่สูตรนั้นได้เลย แต่ละหัวข้อมีป้ายบอกระดับ พื้นฐาน กลาง หรือขั้นสูง

เครื่องคิดเลขเมทริกซ์ในหน้านี้แม่นยำแค่ไหน?
ดีเทอร์มิแนนต์ อินเวอร์ส การแก้ระบบ และพหุนามลักษณะเฉพาะคำนวณด้วยเศษส่วนแม่นตรงทุกขั้น ไม่มีการปัดเศษ ค่าเฉพาะที่เป็นจำนวนตรรกยะได้แบบแม่นตรง ค่าที่เป็นรากที่สองแสดงในรูปราก ส่วนกรณีอื่นแสดงเป็นทศนิยม 6 ตำแหน่ง รวมค่าเชิงซ้อน

อ้างอิงสูตรจากเว็บนี้ในรายงานได้อย่างไร?
ทุกสูตรมีรหัสถาวร เช่น D4 คือการกระจายโคแฟกเตอร์ E2 คือสมการลักษณะเฉพาะ อ้างอิงได้ในรูป Mod's Engineering Mathematics (อาจารย์มด), สูตร D4, พร้อมลิงก์ เช่น modsengineeringmath.com/learn/linear-algebra/determinants/#D4
