    คำถามที่พบบ่อย

    แรงก์ของเมทริกซ์คืออะไร?

    แรงก์ (ค่าลำดับขั้น) คือจำนวนแถวที่เป็นอิสระเชิงเส้นของเมทริกซ์ ซึ่งเท่ากับจำนวนหลักที่อิสระเสมอ หาได้ง่ายที่สุดโดยลดแถวให้เป็นรูปขั้นบันไดแล้วนับแถวที่ไม่เป็นศูนย์ (จำนวนตัวหลัก) ในภาษาระบบสมการคือจำนวนสมการที่ไม่ซ้ำซ้อนกัน

    หาแรงก์ด้วยดีเทอร์มิแนนต์ได้ไหม?

    ได้ แรงก์คืออันดับของไมเนอร์ (ดีเทอร์มิแนนต์ของเมทริกซ์ย่อยจัตุรัส) ที่ใหญ่ที่สุดที่ไม่เป็นศูนย์ สำหรับเมทริกซ์ n×n ถ้า det ≠ 0 แรงก์คือ n แต่ถ้า det = 0 ต้องหาไมเนอร์ขนาดเล็กลงหรือลดแถวต่อ เพราะ det = 0 บอกแค่ว่าแรงก์ไม่เต็ม ไม่ได้บอกว่าเหลือเท่าไร

    แรงก์บอกอะไรเกี่ยวกับระบบสมการ Ax = b?

    ตามทฤษฎีบทรูเช-กาเปลลี ถ้า rank A < rank [A|b] ระบบไม่มีคำตอบ ถ้า rank A = rank [A|b] = n (จำนวนตัวแปร) มีคำตอบเดียว และถ้า rank A = rank [A|b] = r < n มีคำตอบไม่จำกัดโดยมีตัวแปรอิสระ n − r ตัว

    โจทย์หาแรงก์ที่มีพารามิเตอร์ k ทำอย่างไร?

    ถ้าเป็นเมทริกซ์จัตุรัส ให้หา det ในรูปของ k ก่อน ค่า k ที่ไม่ทำให้ det เป็นศูนย์ได้แรงก์เต็ม ส่วนค่า k ที่ทำให้ det = 0 ต้องแทนค่าทีละตัวแล้วลดแถวเพื่อนับแรงก์จริง เช่น [[1,1,k],[1,k,1],[k,1,1]] มี det = −(k−1)²(k+2) ได้แรงก์ 1 เมื่อ k = 1 แรงก์ 2 เมื่อ k = −2 และแรงก์ 3 เมื่อ k อื่น

    ทฤษฎีบทแรงก์-ภาวะศูนย์ (rank–nullity) ใช้ทำอะไร?

    สำหรับเมทริกซ์ m×n จะได้ rank A + nullity A = n ใช้นับจำนวนตัวแปรอิสระของระบบเอกพันธ์ Ax = 0 (เท่ากับ nullity) และจำนวนเวกเตอร์ในฐานของปริภูมิศูนย์ ในวงจรไฟฟ้าใช้นับจำนวนสมการ KCL และ KVL ที่เป็นอิสระ
