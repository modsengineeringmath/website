# วิเคราะห์วงจรไฟฟ้ากระแสสลับด้วยเฟสเซอร์

// เวกเตอร์ · ส่วนที่ 4 · AC circuit analysis with phasors


บทนี้คือจุดที่ทุกอย่างมาบรรจบ: เวกเตอร์ (การบวกหัวต่อหาง) ตรีโกณมิติ (กฎโคไซน์) และจำนวนเชิงซ้อน (การคูณหาร) รวมเป็นวิธีวิเคราะห์วงจรไฟฟ้ากระแสสลับที่วิศวกรใช้ทุกวัน ตั้งแต่มอเตอร์ในบ้าน วงจร RLC เรโซแนนซ์ การแก้เพาเวอร์แฟกเตอร์ในโรงงาน ไปจนถึงวงจรกรองสัญญาณ ทุกตัวอย่างตรวจด้วยตัวเลขและเปิดในแล็บได้ทันที

สรุปใน 30 วินาที

- $Z_R=R,\ Z_L=j\omega L,\ Z_C=\dfrac{1}{j\omega C}=-\dfrac{j}{\omega C}$; $\mathbf V=Z\mathbf I$

- KVL/KCL เป็นการบวกเวกเตอร์ — ผลรวมขนาดไม่เท่ากับขนาดผลรวม

- $\mathbf S=\mathbf V\mathbf I^*=P+jQ$, PF = $\cos(\varphi_v-\varphi_i)$

- เรโซแนนซ์ $f_0=1/(2\pi\sqrt{LC})$, $Q=\omega_0L/R$, แรงดันคร่อม L และ C = Q เท่าของแหล่งจ่าย

## 1. ขั้นตอนวิเคราะห์ห้าขั้น พื้นฐาน

① เขียนแหล่งจ่ายเป็นเฟสเซอร์→② แปลง R L C เป็น Z→③ แก้วงจรเหมือน DC แต่ใช้จำนวนเชิงซ้อน→④ วาดแผนภาพเฟสเซอร์ตรวจ→⑤ แปลงกลับเป็น v(t), i(t) / หากำลัง

กฎของโอห์ม การต่ออนุกรม-ขนาน ตัวแบ่งแรงดัน KVL KCL nodal และ mesh analysis ที่เรียนในวงจร DC ใช้ได้ทั้งหมด เพียงแต่ตัวเลขทุกตัวเป็นจำนวนเชิงซ้อน (เวกเตอร์สองมิติที่คูณหารได้) ทักษะที่ต้องฝึกคือ การคำนวณเฟสเซอร์ และการวาดแผนภาพเพื่อตรวจคำตอบ

## 2. อิมพีแดนซ์และแอดมิตแตนซ์ พื้นฐาน

Z1 Element impedances อิมพีแดนซ์ของ R L C

$$Z_R=R,\qquad Z_L=j\omega L=jX_L,\qquad Z_C=\frac{1}{j\omega C}=-jX_C,\qquad X_L=2\pi fL,\quad X_C=\frac{1}{2\pi fC}$$

R: แรงดันร่วมเฟสกับกระแส · L: แรงดันนำหน้า 90° · C: แรงดันตามหลัง 90° (ELI the ICE man) X_L เพิ่มตามความถี่ X_C ลดตามความถี่

Z2 Combining impedances อนุกรม ขนาน และแอดมิตแตนซ์

$$Z_{\text{series}}=\sum Z_k,\qquad \frac{1}{Z_{\text{par}}}=\sum\frac{1}{Z_k},\qquad Z=R+jX=|Z|\angle\theta_Z,\qquad Y=\frac1Z=G+jB$$

θ_Z > 0 = วงจรแบบเหนี่ยวนำ (กระแสตามหลัง) θ_Z < 0 = แบบตัวเก็บประจุ ขนานหลายสาขาใช้ Y บวกกันง่ายกว่า

## 3. วงจร RL อนุกรม: มอเตอร์ในบ้าน พื้นฐาน

ตัวอย่าง Z-1 · มอเตอร์ 220 V 50 Hz

### มอเตอร์จำลองเป็น R = 30 Ω อนุกรม L = 127 mH ต่อกับ 220∠0° V (RMS) 50 Hz จงหากระแส มุมเฟส กำลัง และ PF

- $X_L=2\pi(50)(0.127)=39.90\ \Omega$ → $Z=30+j39.90=49.92\angle53.06^\circ\ \Omega$

- $\mathbf I=\dfrac{220\angle0^\circ}{49.92\angle53.06^\circ}=4.407\angle-53.06^\circ$ A กระแสตามหลัง 53°

- $\mathbf S=\mathbf V\mathbf I^*=220(4.407\angle53.06^\circ)=969.6\angle53.06^\circ=582.7+j775.0$ VA

- PF = cos 53.06° = 0.601 ตามหลัง — P = 582.7 W (ตรวจ: $I^2R=4.407^2\times30$ ✓)

I = 4.41 A ตามหลัง 53.1° · P = 583 W · Q = 775 var · PF = 0.60

## 4. วงจร RLC อนุกรมและ KVL เชิงเวกเตอร์ กลาง

Z3 Series RLC วงจร RLC อนุกรม

$$Z=R+j(X_L-X_C),\qquad \mathbf I=\frac{\mathbf V_s}{Z},\qquad \mathbf V_s=\mathbf V_R+\mathbf V_L+\mathbf V_C\ \ (\text{บวกเวกเตอร์}),\qquad \mathbf V_k=\mathbf V_s\frac{Z_k}{Z}$$

ตัวอย่าง Z-2 · แรงดันคร่อม C มากกว่าแหล่งจ่าย

### R = 30 Ω, L = 127 mH, C = 53 μF ต่ออนุกรมกับ 220∠0° V 50 Hz จงหากระแสและแรงดันคร่อมแต่ละตัว

- $X_L=39.90\ \Omega$, $X_C=1/(2\pi\cdot50\cdot53\times10^{-6})=60.06\ \Omega$

- $Z=30+j(39.90-60.06)=30-j20.16=36.14\angle-33.90^\circ\ \Omega$ (แบบตัวเก็บประจุ)

- $\mathbf I=220/36.14\angle-33.90^\circ=6.087\angle33.90^\circ$ A กระแสนำหน้า

- $\mathbf V_R=182.6\angle33.90^\circ$, $\mathbf V_L=6.087\angle33.90^\circ\times39.90\angle90^\circ=242.8\angle123.90^\circ$, $\mathbf V_C=365.6\angle-56.10^\circ$ V

- KVL ตรวจแบบเวกเตอร์: $(151.6+j101.8)+(-135.5+j201.6)+(203.9-j303.4)=220.0+j0$ ✓ แต่ผลรวมขนาด 182.6 + 242.8 + 365.6 = 791 V

I = 6.09∠33.9° A · V_C = 366 V มากกว่าแหล่งจ่าย 220 V — ต้องเลือกพิกัดแรงดันตัวเก็บประจุจากค่านี้ ไม่ใช่ 220 V

KVL ของวงจร AC คือรูปหลายเหลี่ยมเวกเตอร์ปิด เหมือนรูปหลายเหลี่ยมแรงบนโต๊ะแรง (สเกลประมาณ)

## 5. วงจรขนานและ KCL เชิงเวกเตอร์ กลาง

Z4 Parallel branches วงจรขนาน

$$\mathbf I=\mathbf I_R+\mathbf I_L+\mathbf I_C=\mathbf V\Big(\frac1R+\frac{1}{j\omega L}+j\omega C\Big)=\mathbf V\,Y$$

ตัวอย่าง Z-3 · ฮีตเตอร์ + บัลลาสต์ + ตัวเก็บประจุ

### 220∠0° V 50 Hz ต่อขนาน R = 44 Ω (ฮีตเตอร์ 1.1 kW), L = 0.14 H และ C = 30 μF จงหากระแสสายรวม

- $\mathbf I_R=5\angle0^\circ$, $\mathbf I_L=220/(j43.98)=-j5.002$, $\mathbf I_C=j(314.16)(30\times10^{-6})(220)=j2.073$ A

- KCL: $\mathbf I=5-j2.929=5.795\angle-30.36^\circ$ A

- $Z=220/\mathbf I=37.97\angle30.36^\circ\ \Omega$, PF = cos 30.36° = 0.863 ตามหลัง

I = 5.80 A — น้อยกว่าผลรวมขนาด 5 + 5 + 2.07 = 12.07 A มาก เพราะ I_L กับ I_C หักล้างกัน

## 6. กำลังเชิงซ้อนและสามเหลี่ยมกำลัง กลาง

Z5 Complex power กำลังเชิงซ้อน (เฟสเซอร์ RMS)

$$\mathbf S=\mathbf V\mathbf I^*=P+jQ,\qquad P=VI\cos\theta,\quad Q=VI\sin\theta,\quad |\mathbf S|=VI,\quad \text{PF}=\frac{P}{|\mathbf S|}=\cos\theta,\ \ \theta=\varphi_v-\varphi_i$$

ใช้ conjugate ของกระแสเพื่อให้มุมของ S เท่ากับความต่างเฟส ไม่ใช่ผลบวกเฟส P (W) ทำงานจริง Q (var) ไหลไปกลับ |S| (VA) คือขนาดที่สายและหม้อแปลงต้องรองรับ — สามเหลี่ยมกำลัง

Z6 Power-factor correction แก้ PF ด้วยตัวเก็บประจุขนาน

$$Q_C=P(\tan\varphi_1-\tan\varphi_2),\qquad C=\frac{Q_C}{\omega V^2}$$

ตัวอย่าง Z-4 · แก้ PF ของมอเตอร์ Z-1 เป็น 0.95

### มอเตอร์ P = 582.7 W, PF 0.601 ตามหลัง ที่ 220 V 50 Hz ต้องใช้ตัวเก็บประจุขนานเท่าใด กระแสสายเหลือเท่าใด

- $\tan\varphi_1=\tan(\arccos0.601)=1.330$, $\tan\varphi_2=\tan(\arccos0.95)=0.3287$

- $Q_C=582.7(1.330-0.3287)=583.4$ var

- $C=583.4/(314.16\times220^2)=38.4\ \mu$F → เลือกค่ามาตรฐาน 40 μF

- เวกเตอร์กระแส: $\mathbf I=\mathbf I_{\text{motor}}+\mathbf I_C$ ส่วนจินตภาพตามหลังถูก I_C หักล้าง กระแสสายลดจาก 4.41 A เหลือ 2.79 A

C ≈ 38 μF (ใช้ 40 μF ได้ PF 0.961) — กระแสลด 37% กำลังจริงเท่าเดิม ลองตัวอย่าง “แก้ PF ด้วย C” ในแล็บ

## 7. เรโซแนนซ์ Q และแบนด์วิดท์ ขั้นสูง

Z7 Series resonance เรโซแนนซ์อนุกรม

$$\omega_0=\frac{1}{\sqrt{LC}},\quad f_0=\frac{1}{2\pi\sqrt{LC}},\quad Q=\frac{\omega_0L}{R}=\frac{1}{R}\sqrt{\frac LC},\quad \text{BW}=\frac{f_0}{Q}=\frac{R}{2\pi L},\quad |\mathbf V_L|=|\mathbf V_C|=Q|\mathbf V_s|$$

ที่ f₀ เฟสเซอร์ V_L กับ V_C ยาวเท่ากันและชี้สวนกัน หักล้างกันพอดี Z = R ต่ำสุด กระแสสูงสุดร่วมเฟส วงจรขนานกลับกัน: อิมพีแดนซ์สูงสุด

ตัวอย่าง Z-5 · เรโซแนนซ์ที่ 159 Hz

### R = 10 Ω, L = 100 mH, C = 10 μF ต่ออนุกรมกับแหล่งจ่าย 10 V จงหา f₀, Q, BW และแรงดันคร่อม L ที่เรโซแนนซ์

- $f_0=1/(2\pi\sqrt{0.1\times10^{-5}})=159.2$ Hz

- $Q=\omega_0L/R=(1000)(0.1)/10=10$, $\text{BW}=159.2/10=15.9$ Hz

- $I=10/10=1$ A, $|\mathbf V_L|=|\mathbf V_C|=QV=100$ V

แหล่งจ่าย 10 V แต่ L และ C แต่ละตัวมี 100 V — อันตรายจริงในตัวกรองฮาร์มอนิกและวงจรเรโซแนนซ์ ดู ฮาร์มอนิกกับตู้คาปาซิเตอร์

## 8. ตัวแบ่งแรงดันเชิงซ้อน: วงจรกรองความถี่ต่ำ RC กลาง

Z8 RC low-pass filter ตัวแบ่งแรงดันเชิงซ้อน

$$H(j\omega)=\frac{\mathbf V_o}{\mathbf V_i}=\frac{Z_C}{R+Z_C}=\frac{1}{1+j\omega RC},\qquad f_c=\frac{1}{2\pi RC},\qquad |H(f_c)|=\frac{1}{\sqrt2},\ \angle H(f_c)=-45^\circ$$

ตัวอย่าง Z-6 · กรองสัญญาณเซนเซอร์

### R = 1 kΩ, C = 0.1 μF จงหา f_c และอัตราขยายที่ 1 kHz

- $f_c=1/(2\pi\cdot1000\cdot10^{-7})=1591.5$ Hz

- ที่ 1 kHz: $\omega RC=0.6283$ → $H=1/(1+j0.6283)=0.8467\angle-32.14^\circ$

ผ่าน 84.7% ของแอมพลิจูด ล่าช้า 32° — ต่อยอดที่ กราฟโบด

## 9. เฟสเซอร์สามเฟส: เวกเตอร์สามตัวที่รวมเป็นศูนย์ กลาง

Z9 Balanced three-phase set เฟสเซอร์สามเฟสสมดุล

$$\mathbf V_a=V\angle0^\circ,\ \mathbf V_b=V\angle-120^\circ,\ \mathbf V_c=V\angle120^\circ,\qquad \mathbf V_a+\mathbf V_b+\mathbf V_c=\mathbf 0,\qquad \mathbf V_{ab}=\sqrt3\,V\angle30^\circ$$

สามเวกเตอร์ที่ห่างกัน 120° ต่อหัวต่อหางเป็นสามเหลี่ยมด้านเท่าปิดพอดี กระแสสายนิวทรัลของโหลดสมดุลจึงเป็นศูนย์ แรงดันระหว่างสาย 230 × √3 = 400 V — ต่อใน เฟสเซอร์และระบบสามเฟส

## 10. แล็บวงจร RLC ด้วยเฟสเซอร์ พื้นฐาน

เลือกวงจรและปรับ R L C f แล้วดูแผนภาพเฟสเซอร์ (KVL/KCL ต่อหัวต่อหาง) รูปคลื่น v(t), i(t) สามเหลี่ยมกำลัง และกราฟผลตอบสนองเชิงความถี่ ปุ่มด้านบนโหลดตัวอย่าง Z-1, Z-5 และ Z-4 ให้ทันที ลากความถี่ผ่าน f₀ แล้วดูว่า V_L กับ V_C สลับกันยาวกว่า

## 11. ข้อผิดพลาดที่พบบ่อย

| ข้อผิดพลาด | วิธีป้องกัน |

| ใช้ f แทน ω ใน X_L = ωL | X_L = 2πfL ลืม 2π ผิดไป 6.28 เท่า |

| Z_C = jωC | Z_C = 1/(jωC) = −j/(ωC) ตัวเก็บประจุให้รีแอกแตนซ์ติดลบ |

| บวกขนาดแรงดันหรือกระแส | KVL/KCL ต้องบวกเฟสเซอร์ (Z-2, Z-3) |

| S = VI (ไม่ conjugate) | มุมของ S ต้องเป็น $\varphi_v-\varphi_i$ ใช้ $\mathbf I^*$ |

| เลือกพิกัด C จากแรงดันแหล่งจ่าย | วงจรอนุกรมใกล้เรโซแนนซ์ V_C = Q V_s |

| ใช้เฟสเซอร์กับโหลดที่มีฮาร์มอนิก | แยกวิเคราะห์ทีละความถี่ หรือใช้ อนุกรมฟูเรียร์ |

## 12. แบบฝึกหัดพร้อมเฉลย

- R = 40 Ω อนุกรม C = 50 μF ที่ 230 V 50 Hz จงหา Z, I และ PF

- วงจร Z-2 ต้องการให้เรโซแนนซ์ที่ 50 Hz ต้องเปลี่ยน C เป็นเท่าใด กระแสจะเป็นเท่าใด?

- โหลด 5 kW PF 0.7 ตามหลังที่ 400 V 50 Hz ต้องการ PF 0.95 ใช้ Q_C เท่าไร?

- $\mathbf V=100\angle20^\circ$ V, $\mathbf I=5\angle-25^\circ$ A จงหา P Q และ PF

เปิดเฉลย

- X_C = 63.66 Ω, Z = 40 − j63.66 = 75.18∠−57.86° Ω, I = 3.059∠57.86° A, PF = 0.532 นำหน้า

- C = 1/(ω²L) = 1/(314.16² × 0.127) = 79.8 μF, I = 220/30 = 7.33 A ร่วมเฟส

- tan φ₁ = 1.0202, tan φ₂ = 0.3287 → Q_C = 5000 × 0.6915 = 3.46 kvar

- S = 100∠20° × 5∠25° = 500∠45° → P = 353.6 W, Q = 353.6 var, PF = 0.707 ตามหลัง

## คำถามที่พบบ่อย

อิมพีแดนซ์ของ R L C คืออะไร?
ตัวต้านทาน Z_R = R ตัวเหนี่ยวนำ Z_L = jωL = jX_L ตัวเก็บประจุ Z_C = 1/(jωC) = −jX_C โดย X_L = 2πfL และ X_C = 1/(2πfC) อิมพีแดนซ์ใช้แทนความต้านทานในกฎของโอห์ม V = ZI และต่ออนุกรม-ขนานได้เหมือนตัวต้านทาน แต่เป็นจำนวนเชิงซ้อน

ทำไมแรงดันคร่อมตัวเก็บประจุในวงจร RLC อนุกรมมากกว่าแรงดันแหล่งจ่ายได้?
เพราะ KVL ในวงจร AC เป็นการบวกเวกเตอร์ แรงดันคร่อม L นำหน้ากระแส 90° แรงดันคร่อม C ตามหลัง 90° สองตัวนี้หักล้างกันบางส่วน แต่ละตัวจึงอาจใหญ่กว่าแรงดันรวมได้มาก โดยเฉพาะใกล้เรโซแนนซ์ที่แรงดันคร่อม L และ C เท่ากับ Q เท่าของแหล่งจ่าย

แก้เพาเวอร์แฟกเตอร์ด้วยตัวเก็บประจุคำนวณอย่างไร?
หากำลังจริง P และมุม φ₁ ปัจจุบัน เลือก PF เป้าหมาย φ₂ แล้ว Q_C = P(tan φ₁ − tan φ₂) ค่าความจุ C = Q_C/(ωV²) ต่อขนานกับโหลด ตัวเก็บประจุให้กระแสนำหน้าที่ไปหักล้างกระแสตามหลังของโหลดแบบเหนี่ยวนำ กระแสในสายจึงลดลงแต่กำลังจริงเท่าเดิม

ความถี่เรโซแนนซ์คืออะไร?
ความถี่ที่ X_L = X_C คือ f₀ = 1/(2π√(LC)) วงจรอนุกรมจะมีอิมพีแดนซ์ต่ำสุดเท่ากับ R กระแสสูงสุดและร่วมเฟสกับแรงดัน ส่วนวงจรขนานจะมีอิมพีแดนซ์สูงสุด ใช้ในวงจรกรองความถี่ วิทยุ และตัวกรองฮาร์มอนิก
