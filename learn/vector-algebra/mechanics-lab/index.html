การทดลองที่ 2 · สามเหลี่ยมแรง: กฎของไซน์และกฎของโคไซน์ กลาง

วัตถุประสงค์ ใช้กฎของโคไซน์หาขนาด กฎของไซน์หาทิศ และพบกรณีมุมป้านที่ arcsin หลอกเรา จากนั้นแตกแรงตามสองแนวที่ไม่ตั้งฉาก

  1. ตั้ง F₁ = 600 N ที่ 0°, F₂ = 400 N ที่ 50° บันทึก R, α, ทิศของ R (ตัวอย่าง R-1)
  2. เปลี่ยน F₂ ไปที่ 90° แล้ว 180° ตรวจว่า R ลดลงจาก F₁ + F₂ ไปถึง |F₁ − F₂|
  3. ตั้ง F₁ = 200 N, F₂ = 500 N ที่ 150° อ่านคำเตือนเรื่องมุมป้าน เทียบกับ R4
  4. เลือกโจทย์ “แตกแรง” ตั้ง F = 500 N ที่ 60°, แนว u = 0°, v = 105° บันทึก F_u, F_v และเทียบกับการฉาย F·û
  5. หมุนแนว v เข้าใกล้ 60° (แนวเดียวกับ F) แล้วดูว่า F_u เป็นศูนย์ เพราะอะไร?

การทดลองที่ 6 · แขนกลสองข้อต่อ ขั้นสูง

วัตถุประสงค์ เห็นตำแหน่งปลายแขนเป็นผลบวกเวกเตอร์ ใช้ inverse kinematics และหาแรงบิดข้อต่อจาก τ = JᵀF (A1–A6)

  1. โหมด Forward: θ₁ = 30°, θ₂ = 60° บันทึก p, det J, τ₁, τ₂ (Fy = 19.6 N)
  2. ตั้ง θ₂ = 0° (เหยียดแขน) แล้วเปลี่ยน θ₁ จาก 90° ลงไป 0° สังเกต τ₁ ว่าสูงสุดที่มุมใด
  3. โหมด Inverse: คลิกบนภาพที่ (0.6, 0.3) สลับ elbow-up/down เทียบมุมกับตัวอย่าง A-2
  4. ติ๊ก “ลากเส้นทาง” แล้ววาดเส้นตรงแนวนอน สังเกตว่ามุมข้อต่อต้องเปลี่ยนไม่เป็นเชิงเส้น

แนวการเขียนรายงานแล็บ

  1. บทนำและวัตถุประสงค์ — ทำไมต้องรู้แรงลัพธ์และสมดุล
  2. ทฤษฎี — สูตรพร้อมรหัสอ้างอิง เช่น R1, R8, S10
  3. ผลการทดลอง — ตาราง กราฟ (เช่น T กับ θ ในการทดลองที่ 3)
  4. การวิเคราะห์ — เทียบสามวิธี (กราฟ ตรีโกณ องค์ประกอบ) และ %error
  5. แหล่งความคลาดเคลื่อน — แรงเสียดทานรอก มวลห่วง การอ่านมุม การปัดเศษ
  6. สรุป — ตอบวัตถุประสงค์เป็นข้อ ๆ

เครื่องมือเสริมระดับโลก: PhET Vector Addition สำหรับฝึกบวกเวกเตอร์ด้วยกราฟ และ สตูดิโอเวกเตอร์ 3 มิติ สำหรับแรงสามมิติ

คำถามที่พบบ่อย

แล็บเสมือนนี้ใช้แทนการทดลองจริงได้ไหม?

ใช้เตรียมตัวก่อนเข้าแล็บ ทบทวน และตรวจคำตอบได้ดี เพราะเห็นเวกเตอร์และวิธีคำนวณพร้อมกัน แต่การทดลองจริงมีแรงเสียดทานของรอก น้ำหนักของห่วง และความคลาดเคลื่อนในการอ่านมุมที่ต้องฝึกจัดการเอง ควรใช้ทั้งสองแบบประกอบกัน

คำนวณเปอร์เซ็นต์ความคลาดเคลื่อนอย่างไร?

%error = |ค่าที่วัดได้ − ค่าทางทฤษฎี| / ค่าทางทฤษฎี × 100 สำหรับโต๊ะแรง ค่าทางทฤษฎีคือแรงสมดุลที่คำนวณจากกฎโคไซน์หรือองค์ประกอบ ส่วนค่าที่วัดคือมวลและมุมของเชือกเส้นที่ทำให้ห่วงอยู่กลางหมุด

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
