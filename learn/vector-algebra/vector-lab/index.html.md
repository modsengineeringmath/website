# แล็บเวกเตอร์ 2D / 3D: เปลี่ยนตัวเลขแล้วเห็นความหมาย

// บทที่ 4.7 · Interactive Vector Lab


พิมพ์องค์ประกอบของ A และ B เลือกการดำเนินการ แล้วเปรียบเทียบลูกศรกับวิธีคำนวณ ใช้คำถามว่า “ถ้าเปลี่ยนทิศอย่างเดียว ผลจะเปลี่ยนอย่างไร?” เป็นจุดเริ่มต้น ก่อนตรวจคำตอบด้วยสมการ

## เครื่องคิดเลขและภาพเวกเตอร์

โหมด 2D ใช้เฉพาะองค์ประกอบ x,y ส่วน Cross product ของเวกเตอร์บนระนาบคิดโดยเติม z=0 แล้วแสดงองค์ประกอบตั้งฉากกับระนาบ โหมด 3D ใช้ x,y,z ทั้งหมด ภาพ 3D เป็นภาพฉาย ไม่ใช่มุมจริง ใช้ค่าตัวเลขตรวจมุมและขนาด

## ใบงานทดลอง: ทำนายก่อนกดคำนวณ

การทดลอง 1 · Projection

### ส่วนขนานที่ยาวกว่าองค์ประกอบ x ของ A

ตั้ง A=(3,4), B=(2,1) เลือก projection คำถาม: เหตุใดองค์ประกอบ x ของส่วนฉายเป็น 4 มากกว่า x ของ A ที่เป็น 3?

- คำนวณ $A\cdot B=3(2)+4(1)=10$ และ $B\cdot B=5$
- ส่วนขนาน $A_\parallel=(10/5)(2,1)=(4,2)$
- ส่วนตั้งฉาก $A_\perp=(3,4)-(4,2)=(-1,2)$ ตรวจ $(-1,2)\cdot(2,1)=0$

การฉายบนเส้นเอียงไม่ใช่การเก็บ x อย่างเดียว ส่วนตั้งฉากมี x ติดลบ จึงรวมกลับเป็น 3 ได้ แม้ x ของส่วนขนานเท่ากับ 4

เปลี่ยน B เป็น (−2,−1): scalar projection จาก $2\sqrt5$ กลายเป็น $-2\sqrt5$ แต่เวกเตอร์ฉายยังเป็น (4,2) เพราะเส้นที่ฉายเป็นเส้นเดิม

การทดลอง 2 · Dot product

### ตั้งฉาก ทิศเดียว และทิศตรงข้าม

- A=(3,4), B=(−4,3) ให้ dot = −12+12=0 และมุม 90°
- เปลี่ยน B=(6,8) ให้ dot=50 และมุม 0° ขนาด B เป็นสองเท่า A
- เปลี่ยน B=(−6,−8) ให้ dot=−50 และมุม 180°

เครื่องหมาย dot บอกมุมแหลม ศูนย์ หรือมุมป้านได้เมื่อเวกเตอร์ทั้งคู่ไม่เป็นศูนย์ ลอง A=(0,0): dot ยังคำนวณเป็น 0 แต่มุมไม่กำหนด

การทดลอง 3 · Cross product

### สลับลำดับแล้วทิศกลับ

- เลือก 3D ให้ A=(1,2,2), B=(3,0,4)
- คำนวณ $A\times B=(8,2,-6)$; ขนาด $\sqrt{104}\approx10.1980$
- ตรวจ $(8,2,-6)\cdot A=8+4-12=0$, $(8,2,-6)\cdot B=24-24=0$
- สลับ A และ B จะได้ (−8,−2,6) ขนาดเท่าเดิมแต่ทิศตรงข้าม

Cross ให้ทิศตั้งฉากและพื้นที่ ห้ามแทน cross ด้วยการคูณองค์ประกอบทีละตัว

## ทดลองจากโจทย์วิศวกรรม

- แรงลัพธ์: โหมดบวก A=(30,40) N และ B=(−10,20) N ให้ (20,60) N ขนาด $20\sqrt{10}\approx63.246$ N
- งาน: โหมด dot ให้ A=(30,40) N และ B=(2,0) m ได้ 60 J ไม่ใช่ 100 J เพราะแรงแนวตั้งไม่ทำงานในการเคลื่อนที่แนวนอนนี้
- แรงบิด: โหมด cross 3D ให้ A=(0.2,0,0) m และ B=(0,50,0) N ได้ (0,0,10) N·m ตาม +z

แล็บรับเฉพาะตัวเลขและไม่ทราบหน่วยโดยอัตโนมัติ ผู้ใช้ต้องกำหนดหน่วยให้สอดคล้องกันก่อนแทนค่า อ่านข้อสมมติของระบบจริงใน หน้าการประยุกต์ทางวิศวกรรม

## ขอบเขตและการตรวจคำตอบ

ภาพและผลลัพธ์ใช้ฐานคาร์ทีเซียนตั้งฉากหนึ่งหน่วย ไม่รองรับฐานเฉียงหรือพิกัดโค้งโดยตรง การคำนวณใช้ floating point; ค่าที่เล็กมากอาจคลาดเคลื่อนจากการปัด อย่าใช้ภาพฉายสามมิติพิสูจน์ความตั้งฉาก ให้ตรวจ dot เป็นศูนย์แทน

กลับไปค้น สรุปสูตร หรืออ่านที่มาใน Component / Projection, Dot product และ Cross product

## คำถามที่พบบ่อย

ภาพสามมิติแสดงมุมจริงหรือไม่?
ภาพเป็นการฉายสามมิติลงบนจอสองมิติ มุมและความยาวที่เห็นบนจออาจไม่เท่าค่าจริง ให้ใช้มุมและขนาดที่คำนวณจากองค์ประกอบในช่องผลลัพธ์

ทำไมฉายลงบนเวกเตอร์ศูนย์ไม่ได้?
เวกเตอร์ศูนย์ไม่มีทิศ และสูตรต้องหารด้วยขนาดหรือขนาดกำลังสองของเวกเตอร์เป้าหมาย แล็บจึงแจ้งว่าไม่กำหนดแทนการแสดงค่าที่ดูเหมือนคำนวณได้

เครื่องคิดเลขนี้มีความแม่นยำเท่าใด?
คำนวณด้วยเลขทศนิยม floating point ของ JavaScript แล้วปัดเพื่อแสดงผล เหมาะสำหรับเรียนและตรวจตัวอย่าง ไม่ใช่เครื่องมือรับรองการออกแบบทางวิศวกรรม ควรตรวจเงื่อนไข หน่วย และค่าจริงก่อนใช้
