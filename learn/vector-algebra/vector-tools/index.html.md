## PhET Interactive Simulations (University of Colorado Boulder)

PhET คือซิมูเลชันการศึกษาที่ใช้มากที่สุดในโลก ผ่านงานวิจัยด้านการเรียนรู้มาอย่างยาวนาน ใช้คู่กับบทเรียนในเว็บนี้ดังนี้

### Vector Addition — บวกเวกเตอร์ด้วยกราฟและองค์ประกอบ

ลากลูกศรบนตาราง ดูองค์ประกอบ x y มุม และผลรวมแบบหัวต่อหาง ใช้ประกอบ การบวกเวกเตอร์ และ แรงลัพธ์ ภารกิจ: สร้างแรง 600 N ที่ 0° กับ 400 N ที่ 50° แล้วตรวจว่าได้ R ≈ 910 N ที่ 19.7°

### Charges and Fields — สนามไฟฟ้า ศักย์ และเส้นศักย์เท่า

## GeoGebra 3D Calculator และ Desmos 3D

สำหรับเรขาคณิตสามมิติที่ซับซ้อน — ระนาบ เส้นตรงในอวกาศ ระยะทาง และการหมุน — GeoGebra 3D คือมาตรฐานโลกในห้องเรียนคณิตศาสตร์ ขั้นตอนใช้ร่วมกับเว็บนี้:

- วาดเวกเตอร์ใน สตูดิโอเวกเตอร์ แล้วเปิดแท็บ “ส่งออก” กดคัดลอกคำสั่ง GeoGebra
- เปิด GeoGebra 3D Calculator ↗ วางในช่อง Input ทีละบรรทัด
- คำนวณต่อด้วยคำสั่งด้านล่าง แล้วเทียบกับคำตอบของสตูดิโอ

| ต้องการ | คำสั่ง GeoGebra | เทียบสูตรในเว็บ |

### ตรวจตัวอย่าง K-4 (แรงสายยึดเสา) ด้วย MATLAB/Octave

P = [0 0 12]; A = [4 -3 0]; B = [-3 4 0];
uA = (A-P)/norm(A-P); uB = (B-P)/norm(B-P);
F = 650*uA + 390*uB % ได้ [110 -30 -960]
R = norm(F) % 966.75 N
alpha_beta_gamma = acosd(F/R) % มุมทิศทาง (องศา)

### วงจร RLC อนุกรม (ตัวอย่าง Z-2) ด้วย Python

import numpy as np
w = 2*np.pi*50
Z = 30 + 1j*w*0.127 + 1/(1j*w*53e-6)
I = 220/Z
for name, z in [("VR", 30), ("VL", 1j*w*0.127), ("VC", 1/(1j*w*53e-6))]:
V = I*z
print(name, round(abs(V), 1), "V at", round(np.degrees(np.angle(V)), 2), "deg")
S = 220*np.conj(I); print("P =", S.real, "Q =", S.imag, "PF =", S.real/abs(S))

### แขนกล (ตัวอย่าง A-4) ด้วย Python และ Robotics Toolbox

J = np.array([[-L1*np.sin(t1)-L2*np.sin(t1+t2), -L2*np.sin(t1+t2)],
[ L1*np.cos(t1)+L2*np.cos(t1+t2), L2*np.cos(t1+t2)]])
tau = J.T @ np.array([0, 2*9.81]) # [8.50, 0.00] N·m

## คำถามที่พบบ่อย

PhET คืออะไร ใช้ฟรีไหม?
PhET Interactive Simulations เป็นโครงการของมหาวิทยาลัยโคโลราโดโบลเดอร์ สร้างซิมูเลชันฟิสิกส์และคณิตศาสตร์ที่ใช้กันทั่วโลก ใช้ฟรีผ่านเบราว์เซอร์ หน้านี้เปิดซิมูเลชันจากเว็บไซต์ของ PhET โดยตรงเมื่อกดปุ่ม และให้เครดิตเจ้าของผลงาน
