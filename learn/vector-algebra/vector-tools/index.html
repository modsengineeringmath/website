ตรวจตัวอย่าง K-4 (แรงสายยึดเสา) ด้วย MATLAB/Octave

P = [0 0 12];  A = [4 -3 0];  B = [-3 4 0];
uA = (A-P)/norm(A-P);  uB = (B-P)/norm(B-P);
F = 650*uA + 390*uB          % ได้ [110 -30 -960]
R = norm(F)                  % 966.75 N
alpha_beta_gamma = acosd(F/R) % มุมทิศทาง (องศา)

วงจร RLC อนุกรม (ตัวอย่าง Z-2) ด้วย Python

import numpy as np
w = 2*np.pi*50
Z = 30 + 1j*w*0.127 + 1/(1j*w*53e-6)
I = 220/Z
for name, z in [("VR", 30), ("VL", 1j*w*0.127), ("VC", 1/(1j*w*53e-6))]:
    V = I*z
    print(name, round(abs(V), 1), "V at", round(np.degrees(np.angle(V)), 2), "deg")
S = 220*np.conj(I);  print("P =", S.real, "Q =", S.imag, "PF =", S.real/abs(S))

แขนกล (ตัวอย่าง A-4) ด้วย Python และ Robotics Toolbox

import numpy as np
L1, L2, t1, t2 = 0.5, 0.4, np.radians(30), np.radians(60)
J = np.array([[-L1*np.sin(t1)-L2*np.sin(t1+t2), -L2*np.sin(t1+t2)],
              [ L1*np.cos(t1)+L2*np.cos(t1+t2),  L2*np.cos(t1+t2)]])
tau = J.T @ np.array([0, 2*9.81])   # [8.50, 0.00] N·m

คำถามที่พบบ่อย

PhET คืออะไร ใช้ฟรีไหม?

PhET Interactive Simulations เป็นโครงการของมหาวิทยาลัยโคโลราโดโบลเดอร์ สร้างซิมูเลชันฟิสิกส์และคณิตศาสตร์ที่ใช้กันทั่วโลก ใช้ฟรีผ่านเบราว์เซอร์ หน้านี้เปิดซิมูเลชันจากเว็บไซต์ของ PhET โดยตรงเมื่อกดปุ่ม และให้เครดิตเจ้าของผลงาน

ส่งเวกเตอร์จากเว็บนี้ไป GeoGebra อย่างไร?

เปิดสตูดิโอเวกเตอร์ เลือกแท็บส่งออก กดคัดลอกคำสั่ง GeoGebra แล้ววางในช่อง Input ของ GeoGebra 3D Calculator ทีละบรรทัด เวกเตอร์ทั้งหมดจะปรากฏในกราฟสามมิติ ใช้คำสั่งเช่น Length, UnitVector, Dot, Cross, Angle ต่อได้

ควรใช้เครื่องมือไหนเรียนวงจร AC?

เริ่มจากแล็บวงจร AC ของเว็บนี้เพื่อดูเฟสเซอร์และวิธีคำนวณ แล้วใช้ PhET Circuit Construction Kit: AC เพื่อต่อวงจรด้วยสายไฟและวัดด้วยมิเตอร์เสมือน จากนั้นใช้ Falstad Circuit Simulator เมื่อต้องการดูรูปคลื่นและวงจรที่ซับซ้อนขึ้น

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซ็นเซอร์และทรานสดิวเซอร์ (หน่วย มาตรฐาน) เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
