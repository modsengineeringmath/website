# เวกเตอร์และพีชคณิตเวกเตอร์: จาก 2 มิติถึงงานวิศวกรรม 3 มิติ

// บทที่ 4 · Vector Algebra


ลูกศรบอกมากกว่าตัวเลข: แรง 100 N ที่ดึงไปข้างหน้าให้ผลต่างจากแรง 100 N ที่ดึงขึ้นบน ชุดบทเรียนนี้พาจากการอ่านลูกศรไปจนถึงการคำนวณแรงลัพธ์ งาน แรงบิด และแรงแม่เหล็ก พร้อมภาพ วิธีทำทีละขั้น และการทดลองที่ปรับตัวเลขได้จริง

ภาพเดียวเชื่อมทั้งชุด: เวกเตอร์เดิม = ส่วนขนานกับทิศที่เลือก + ส่วนตั้งฉาก สองส่วนบวกกลับได้เวกเตอร์เดิมเสมอ

สรุปใน 30 วินาที

- บวก ลบ และคูณสเกลาร์ทำทีละองค์ประกอบในฐานเดียวกัน

- Dot product วัดความสอดคล้องของทิศ ใช้หามุมและฉายเวกเตอร์

- Cross product วัดพื้นที่และทิศตั้งฉาก ใช้คำนวณแรงบิดและแรงแม่เหล็ก

- มี 7 หน้าย่อย 65 สูตรอ้างอิง และ 50 ตัวอย่างทำทีละขั้น

## เลือกเครื่องมือให้ตรงกับคำถาม

| คำถาม | เครื่องมือ | ชนิดคำตอบ |

| แรงหลายแรงรวมกันเป็นเท่าใด? | บวกเวกเตอร์ | เวกเตอร์แรงลัพธ์ (N) |

| แรงส่วนที่ดึงตามรางมีเท่าใด? | Scalar / vector projection | ตัวเลขมีเครื่องหมาย / เวกเตอร์ |

| สองทิศทำมุมกันเท่าใด? แรงทำงานเท่าใด? | Dot product | มุม / สเกลาร์งาน (J) |

| แรงทำให้หมุนรอบแกนอย่างไร? | Cross product และ projection บนแกน | เวกเตอร์แรงบิด (N·m) / โมเมนต์รอบแกน |

## ทดลองการฉายด้วยตัวเอง

เริ่มจาก $\mathbf A=(3,4)$, $\mathbf B=(2,1)$ จะได้ $\mathbf A\cdot\mathbf B=10$, $\operatorname{proj}_{\mathbf B}\mathbf A=(4,2)$ และส่วนตั้งฉาก $(-1,2)$ ลองเปลี่ยน B เป็น $(-2,-1)$: scalar projection กลับเครื่องหมาย แต่ vector projection บนเส้นเดิมไม่เปลี่ยน

## ดัชนีสรุปสูตรที่ค้นหาและอ้างอิงได้

รหัส F = พื้นฐาน, V = การดำเนินการ, P = องค์ประกอบ/การฉาย, D = Dot, C = Cross, E = วิศวกรรม คลิกสูตรเพื่ออ่านเงื่อนไขและตัวอย่างเต็ม อย่าใช้สูตรมุมหรือฉายลงบนเวกเตอร์ศูนย์

## วิธีตรวจคำตอบที่ใช้ได้ทุกบท

- ระบุแกนและฐานก่อนคำนวณ รวมถึงหน่วยของแต่ละเวกเตอร์
- วาดทิศคร่าว ๆ แล้วตรวจเครื่องหมายขององค์ประกอบ
- ตรวจขนาดและหน่วย: projection มีหน่วยเดียวกับเวกเตอร์เดิม งานมีหน่วย J แรงบิดมีหน่วย N·m
- ตรวจเงื่อนไขทางเรขาคณิต: ส่วนตั้งฉาก dot กับทิศฉายเป็นศูนย์; cross ตั้งฉากกับทั้งสองเวกเตอร์
- แทนกลับและใช้แล็บตรวจตัวเลข โดยแยกค่าจริงกับค่าทศนิยมที่ปัดเพื่อแสดงผล

## ต่อยอดสู่พีชคณิตเชิงเส้นและระบบจริง

การเขียนองค์ประกอบเวกเตอร์เป็นคอลัมน์นำไปสู่ เมทริกซ์และการแปลงพิกัด สมการสมดุลแรงหลายตัวแก้ด้วย ระบบสมการเชิงเส้น ส่วนการเคลื่อนที่และแรงในหุ่นยนต์ต่อยอดได้ใน ระบบควบคุมหุ่นยนต์

## คำถามที่พบบ่อย

ควรเริ่มเรียนเวกเตอร์จากตรงไหน?
เริ่มจากขนาด ทิศทาง และพิกัดในหน้าพื้นฐาน แล้วเรียนบวก ลบ คูณสเกลาร์ ก่อนแตกองค์ประกอบ Dot product และการฉาย จากนั้นเรียน Cross product และโจทย์วิศวกรรม ใช้แล็บตรวจภาพและการคำนวณประกอบทุกขั้น

Component กับ projection ต่างกันอย่างไร?
Component คือสัมประสิทธิ์ตามเวกเตอร์ฐานที่เลือก ในฐานตั้งฉากหนึ่งหน่วยสัมประสิทธิ์นี้เท่ากับ scalar projection ส่วน vector projection เป็นเวกเตอร์ทั้งขนาดและทิศทางตามเส้นที่ฉาย ไม่ใช่ตัวเลขเดียว

Dot product กับ Cross product เลือกใช้อย่างไร?
Dot product ให้สเกลาร์ ใช้หามุม งาน และการฉาย ส่วน Cross product ในสามมิติให้เวกเตอร์ตั้งฉาก ใช้หาพื้นที่พร้อมทิศ แรงบิด และแรงแม่เหล็ก ต้องระวังลำดับเวกเตอร์

อ้างอิงสูตรจากบทเรียนอย่างไร?
แต่ละสูตรมีรหัสและลิงก์ถาวร เช่น P4 ในหน้าองค์ประกอบและการฉาย อ้างชื่อบทเรียน รหัสสูตร URL และวันที่เข้าถึงได้ โดยตรวจเงื่อนไขการใช้สูตรและหน่วยด้วย
