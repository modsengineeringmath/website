D10 Goertzel recursion อัลกอริทึม Goertzel

s[n]=x[n]+2cos⁡ωk s[n−1]−s[n−2],X[k]=s[N−1]−e−jωks[N−2],ωk=2πkNs[n] = x[n] + 2\cos\omega_k\,s[n-1] - s[n-2],\qquad X[k] = s[N-1] - e^{-j\omega_k}s[N-2],\qquad \omega_k = \frac{2\pi k}{N}s[n]=x[n]+2cosωk​s[n−1]−s[n−2],X[k]=s[N−1]−e−jωk​s[N−2],ωk​=N2πk​

เท่ากับ DFT ช่องที่ k ทุกประการ (ต่างกันแค่มุมเฟสคงที่) คูณจริงหนึ่งครั้งต่อตัวอย่าง · หน้าต่างต้องครบคาบ ใช้การวัดความถี่ไฟแล้วปรับอัตราสุ่ม หรือปรับ N ให้ครบ 10 คาบ

// Goertzel: แอมพลิจูด (ค่ายอด) ของช่อง k จาก N ตัวอย่าง — ตรงกับ D2 และ D10
#include <math.h>
float goertzel_amp(const float *x, int N, int k) {
  float w = 2.0f * (float)M_PI * k / N, c = 2.0f * cosf(w);
  float s1 = 0.0f, s2 = 0.0f;
  for (int n = 0; n < N; n++) {
    float s0 = x[n] + c * s1 - s2;
    s2 = s1; s1 = s0;
  }
  float re = s1 - s2 * cosf(w), im = s2 * sinf(w);
  return 2.0f * sqrtf(re * re + im * im) / N;
}

// สุ่ม 128 จุดต่อคาบของ 50 Hz (fs = 6.4 kHz) นาน 10 คาบ → N = 1280, ฮาร์มอนิก h อยู่ช่อง k = 10h
float thd_percent(const float *x) {
  const int N = 1280, M = 10;
  float a1 = goertzel_amp(x, N, M * 1), sum = 0.0f;
  for (int h = 2; h <= 15; h++) { float a = goertzel_amp(x, N, M * h); sum += a * a; }
  return 100.0f * sqrtf(sum) / a1;   // THD จนถึงฮาร์มอนิกที่ 15 (Nyquist = ฮาร์มอนิกที่ 64)
}

ลบค่าเฉลี่ย (DC offset ของ ADC) ออกจาก x ก่อน และกรองกันอเลียสซิงด้วย RC ก่อนเข้า ADC ชิปวัดพลังงานบางรุ่นมีวงจร DFT ในตัว ให้ค่าฮาร์มอนิกโดยตรง

แล็บในชุดนี้คำนวณสเปกตรัมแบบปิด (อินทิเกรตแต่ละช่วงตรง ๆ) จึงไม่มีอเลียสซิงหรือ leakage ใช้เป็น “คำตอบอ้างอิง” เทียบกับ FFT บนสโคปจริงของคุณ ส่วนแล็บเครื่องกำเนิดสัญญาณมี FFT แบบสโคปจริงที่เกิดอเลียสซิงได้ ลองอเลียสซิง

คำถามที่พบบ่อย

DFT กับอนุกรมฟูเรียร์เกี่ยวกันอย่างไร?

ถ้าสุ่มสัญญาณคาบจำนวน N จุดเท่ากันพอดีในหนึ่งคาบ (หรือจำนวนเต็มคาบ) DFT ของข้อมูลนั้นหารด้วย N คือสัมประสิทธิ์ฟูเรียร์ ckc_kck​ ตรงตัว ตราบที่สัญญาณไม่มีฮาร์มอนิกเกินครึ่งหนึ่งของความถี่สุ่ม FFT เป็นแค่วิธีคำนวณ DFT ที่เร็ว

ทำไมเครื่องวิเคราะห์กำลังใช้หน้าต่าง 10 คาบ?

IEC 61000-4-7 กำหนดหน้าต่าง 10 คาบที่ 50 Hz (12 คาบที่ 60 Hz) ประมาณ 200 ms ได้ความละเอียด 5 Hz ฮาร์มอนิกที่ h อยู่ช่องที่ 10h และช่องระหว่างนั้นใช้วัดอินเตอร์ฮาร์มอนิก การสุ่มต้องซิงก์กับความถี่ไฟจริงเพื่อไม่ให้เกิด leakage

spectral leakage คืออะไร?

ถ้าหน้าต่างไม่ครอบจำนวนเต็มคาบพอดี DFT มองว่าสัญญาณมีรอยต่อที่ขอบหน้าต่าง พลังงานของฮาร์มอนิกจึงรั่วไปช่องข้างเคียง ค่าแอมพลิจูดผิดและเกิดเส้นปลอม แก้ด้วยการซิงก์อัตราสุ่มกับความถี่ (PLL) ใช้หน้าต่าง Hann หรือ flat-top และการรวมกลุ่มช่อง

Goertzel ดีกว่า FFT เมื่อไร?

เมื่อต้องการแค่ไม่กี่ความถี่ เช่นฮาร์มอนิก 1 ถึง 15 ของไฟ 50 Hz บนไมโครคอนโทรลเลอร์ Goertzel คำนวณแต่ละช่องด้วยลูปเดียว ใช้หน่วยความจำน้อย ทำได้ทีละตัวอย่างระหว่างสุ่ม ส่วน FFT คุ้มกว่าเมื่อต้องการทุกช่อง

คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

เว็บไซต์ หน้าแรก คลังความรู้ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
