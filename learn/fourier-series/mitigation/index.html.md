# แก้ปัญหาฮาร์มอนิก: รีแอกเตอร์ เรโซแนนซ์ คาปาซิเตอร์ดีจูน ฟิลเตอร์จูน ฟิลเตอร์แอกทีฟ และ PFC

// บทที่ 12.12 · อนุกรมฟูเรียร์ · Harmonic Mitigation


ทุกวิธีแก้ฮาร์มอนิกคือการจัดการกับอิมพีแดนซ์ที่แต่ละความถี่ เพิ่มอิมพีแดนซ์ในทางที่ฮาร์มอนิกจะไหลไปหาการไฟฟ้า หรือสร้างทางอิมพีแดนซ์ต่ำให้มันไหลวนอยู่ใกล้โหลด หรือหักล้างมันด้วยกระแสตรงข้าม หน้านี้เริ่มจากความผิดพลาดที่พบบ่อยที่สุดในโรงงานไทย คือการใส่คาปาซิเตอร์แก้ PF ในระบบที่มีไดรฟ์ แล้วไล่ไปทุกวิธีพร้อมตัวเลขจากแล็บ

สรุปใน 30 วินาที

- รีแอกเตอร์ 3–5 % ลด THD ของไดรฟ์จาก ~80 % เหลือ ~35 % ราคาถูกที่สุด ทำก่อน

- คาปาซิเตอร์เปล่า + หม้อแปลง → เรโซแนนซ์ที่ $h_r = \sqrt{S_{sc}/Q_c}$ อันตรายถ้าใกล้ 5, 7, 11

- ดีจูน: $p = X_L/X_C$, จูนที่ $h_t = 1/\sqrt p$ (7 % → 3.78) ฟิลเตอร์จูน: $X_L = X_C/h_t^2$ จูนที่ 4.7

- ต้องการ THD < 5–8 %: 12/18 พัลส์ ฟิลเตอร์แอกทีฟ หรือ Active Front End / PFC

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## ภาพรวม: ลดที่ต้นเหตุ ปิดทาง หรือดักไว้ พื้นฐาน

| วิธี | หลักการ (มุมมองฟูเรียร์) | THD กระแสที่ได้ (โดยประมาณ) | ข้อควรระวัง |

| รีแอกเตอร์ไลน์ / โช้ก DC | เพิ่ม $jhX$ ทำให้พัลส์กว้างขึ้น ฮาร์มอนิกลด | 30–40 % | แรงดันตก 3–5 % |

| 12 / 18 พัลส์ | หักล้างด้วยการเลื่อนเฟส 30° / 20° | 8–15 % | ต้องโหลดสมดุล หม้อแปลงพิเศษ |

| ฟิลเตอร์จูน (passive) | ทางอิมพีแดนซ์ต่ำที่ $h_t$ ใกล้โหลด | 10–20 % | ให้ kvar ด้วย อาจ PF นำหน้าตอนโหลดเบา |

| คาปาซิเตอร์ดีจูน | ย้ายเรโซแนนซ์ไปต่ำกว่า 5th | ไม่ลดมาก แต่ไม่ขยาย | ใช้แทนคาปาซิเตอร์เปล่าเสมอเมื่อมีไดรฟ์ |

| ฟิลเตอร์แอกทีฟ | ฉีดกระแส $-i_h$ หักล้างทุกฮาร์มอนิก | < 5–8 % | ราคาสูง ต้องเลือกพิกัดกระแสพอ |

| Active PFC / Active Front End | บังคับให้กระแสเป็นไซน์ตามแรงดัน | < 5 % | ต้องเปลี่ยนตัวอุปกรณ์ |

## รีแอกเตอร์ไลน์และโช้ก DC กลาง

ไดรฟ์ที่มีตัวเก็บประจุ DC ชาร์จเป็นพัลส์แคบเพราะมีแค่อิมพีแดนซ์สายกั้น เพิ่มความเหนี่ยวนำทำให้กระแสเพิ่มช้าลง พัลส์กว้างและเตี้ยลง ตามหลักความเรียบ (P8) ฮาร์มอนิกจึงลดลงมาก

M1 Line reactor sizing ขนาดรีแอกเตอร์จาก %Z

$$X_r = \frac{\%Z}{100}\cdot\frac{V_{ph}}{I_{rated}},\qquad L_r = \frac{X_r}{2\pi f}$$

%Z คือแรงดันตกคร่อมรีแอกเตอร์ที่กระแสพิกัดเทียบแรงดันเฟส · โช้ก DC ให้ผลใกล้เคียงรีแอกเตอร์ 3–5 % ไม่มีแรงดันตกด้าน AC และตัวเล็กกว่า

ตัวอย่าง M-1 · ไดรฟ์ 11 kW 400 V

### ไดรฟ์ 11 kW กระแสฮาร์มอนิกหลักพิกัด 15.9 A ต้องการรีแอกเตอร์ 3 % หาค่า L และผลต่อ THD (Isc/IL = 100)

- M1: $X_r = 0.03 \times \frac{230}{15.9} = 0.433\ \Omega$ → $L_r = \frac{0.433}{314.2} = 1.38$ mH ต่อเฟส

- จำลองในแล็บ (VFD, C = 1000 µF): ไม่มีรีแอกเตอร์ THD 83.5 % PF 0.75 · รีแอกเตอร์ 3 % THD 34.5 % PF 0.94 · 5 % THD 32.0 % · โช้ก DC 2 mH THD 37.2 %

1.38 mH ลด THD จาก 84 % เหลือ 35 % และ PF จาก 0.75 เป็น 0.94 จาก 3 % ไป 5 % ได้เพิ่มน้อย (กฎผลตอบแทนลดลง) ยังไม่ผ่าน IEEE 519 ถ้าไดรฟ์เป็นโหลดหลักของหม้อแปลง

## เรโซแนนซ์ขนาน: เมื่อคาปาซิเตอร์แก้ PF กลายเป็นตัวขยายฮาร์มอนิก กลาง

มองจากโหลดที่ปล่อยกระแสฮาร์มอนิก มีสองทางให้ไหล: ไปทางหม้อแปลง ($jhX_s$ โตตาม h) หรือเข้าคาปาซิเตอร์ ($-jX_C/h$ เล็กลงตาม h) สองทางนี้ขนานกัน ที่ความถี่ที่รีแอกแตนซ์เท่ากันพอดี อิมพีแดนซ์ขนานพุ่งสูงมาก กระแสฮาร์มอนิกเพียงเล็กน้อยสร้างแรงดันฮาร์มอนิกมหาศาล และกระแสไหลวนระหว่างคาปาซิเตอร์กับหม้อแปลงมากกว่ากระแสที่โหลดปล่อยออกมาหลายเท่า

M2 Parallel resonance order ลำดับฮาร์มอนิกที่เกิดเรโซแนนซ์

$$h_r = \sqrt{\frac{X_C}{X_s}} = \sqrt{\frac{S_{sc}}{Q_c}} \approx \sqrt{\frac{S_{tr}}{Q_c\,z_{tr}}}$$

$S_{sc}$ กำลังลัดวงจรที่จุดต่อ $Q_c$ ขนาดคาปาซิเตอร์ $z_{tr}$ อิมพีแดนซ์หม้อแปลง (ต่อหน่วย) · คาปาซิเตอร์แบบสเต็ป (APFC) ทำให้ $h_r$ เปลี่ยนตามจำนวนสเต็ปที่เปิด ต้องตรวจทุกสเต็ป

M3 Amplification near resonance ตัวคูณการขยาย

$$\frac{I_{src,h}}{I_{load,h}} = \Big|\frac{Z_C}{Z_s + Z_C}\Big| \approx \frac{1}{|1 - (h/h_r)^2|}$$

ไม่คิดการหน่วง ที่ $h = h_r$ เป็นอนันต์ จริง ๆ ถูกจำกัดด้วยความต้านทานและโหลดเชิงเส้นอื่น มักได้ 3–10 เท่า

อิมพีแดนซ์ที่กระแสฮาร์มอนิกของโหลดเห็น เทียบลำดับ h: หม้อแปลงอย่างเดียว (เส้นประ) เพิ่มคาปาซิเตอร์เปล่า (สีแดง: ยอดเรโซแนนซ์ใกล้ 5) และคาปาซิเตอร์ดีจูน 7 % (สีฟ้า: ยอดถูกย้ายไปต่ำกว่า 3.78 ที่ไม่มีฮาร์มอนิก)

ตัวอย่าง M-2 · หม้อแปลง 1000 kVA กับคาปาซิเตอร์ 400 และ 600 kvar

### หม้อแปลง 1000 kVA อิมพีแดนซ์ 6 % (ไม่คิดต้นทาง) ต่อคาปาซิเตอร์ (ก) 400 kvar (ข) 600 kvar เรโซแนนซ์ที่ฮาร์มอนิกไหน

- $S_{sc} = 1000/0.06 = 16.7$ MVA

- M2: (ก) $\sqrt{16.7/0.4} = 6.45$ → ระหว่าง 5 กับ 7 · (ข) $\sqrt{16.7/0.6} = 5.27$ → ชิดฮาร์มอนิกที่ 5

- M3 ที่ h = 5 กรณี (ข): $1/|1 - (5/5.27)^2| = 10$ เท่า (ก่อนการหน่วง)

ยิ่งเพิ่มสเต็ปคาปาซิเตอร์ (kvar มากขึ้น) เรโซแนนซ์ยิ่งเลื่อนลงมาหา 5 ซึ่งเป็นฮาร์มอนิกที่ไดรฟ์ปล่อยมากที่สุด อาการหน้างาน: คาปาซิเตอร์ร้อน บวม ฟิวส์ขาดเป็นประจำ แรงดันเพี้ยนเมื่อสเต็ปเพิ่ม แก้โดยเปลี่ยนเป็นดีจูน

ตัวอย่าง M-3 · ทดลองในแล็บ

### ไดรฟ์ไทริสเตอร์ 100 kW α = 45° (Isc/IL = 25) ใส่คาปาซิเตอร์ 100 kvar แบบเปล่า เทียบกับดีจูน 7 % และฟิลเตอร์จูน 4.7

- ไม่มีคาปาซิเตอร์: PF 0.67, THD กระแส 29 %, THD แรงดัน 13.2 %

- คาปาซิเตอร์เปล่า: เรโซแนนซ์ที่ h = 5.99 · กระแสที่ 5 และ 7 ที่ฝั่งการไฟฟ้าขยาย 2.9 และ 2.4 เท่า · THD กระแส 94 % THD แรงดัน 15.4 % · PF ขึ้นแค่ 0.70

- ดีจูน 7 %: THD กระแส 26 % THD แรงดัน 9.5 % PF 0.96

- ฟิลเตอร์จูน 4.7: กระแสที่ 5 เหลือ 17 % ของที่โหลดปล่อย THD กระแส 18 % THD แรงดัน 8.0 % PF 0.98

kvar เท่ากัน แต่ผลต่างกันสุดขั้ว คาปาซิเตอร์เปล่าแทบไม่ช่วย PF (เพราะความเพี้ยนเพิ่ม D) และทำให้ทุกอย่างแย่ลง ดีจูนและฟิลเตอร์จูนให้ทั้ง kvar และลดฮาร์มอนิก กดปุ่มด้านล่างเพื่อลองเอง

## คาปาซิเตอร์ดีจูน 7 % และ 14 % กลาง

M4 Detuned capacitor bank ชุดคาปาซิเตอร์ดีจูน

$$p = \frac{X_L}{X_C},\qquad h_t = \frac{1}{\sqrt p},\qquad Q_{net} = \frac{V^2}{X_C - X_L} = \frac{V^2}{X_C(1 - p)},\qquad V_C = \frac{V}{1 - p}$$

p = 7 % → $h_t$ = 3.78 (189 Hz) · p = 14 % → 2.67 (134 Hz, ใช้เมื่อมีฮาร์มอนิกที่ 3 เยอะ) · แรงดันคร่อมคาปาซิเตอร์สูงกว่าไฟ 7.5 % (p = 7 %) จึงต้องใช้คาปาซิเตอร์พิกัด 440–480 V ในระบบ 400 V และ kvar บนป้ายจะไม่ใช่ kvar ที่ได้จริง

ตัวอย่าง M-4 · ออกแบบสเต็ปดีจูน 50 kvar

### ระบบ 400 V ต้องการ 50 kvar สุทธิต่อสเต็ป ใช้ดีจูน 7 % หา $X_C$, $X_L$, L, C (ต่อเฟสแบบ Y) แรงดันคร่อม C และ kvar บนป้ายถ้าใช้คาปาซิเตอร์พิกัด 480 V

- M4: $X_C - X_L = \frac{400^2}{50\,000} = 3.20\ \Omega$ → $X_C = \frac{3.20}{0.93} = 3.441\ \Omega$, $X_L = 0.241\ \Omega$

- $L = \frac{0.241}{314.2} = 0.767$ mH · $C = \frac{1}{314.2 \times 3.441} = 925\ \mu$F (Y เทียบเท่า)

- $V_C = 400/0.93 = 430$ V · kvar บนป้ายที่ 480 V: $\frac{480^2}{3.441} = 67.0$ kvar

- จูนที่ $50/\sqrt{0.07} = 189$ Hz ต่ำกว่า 250 Hz ของฮาร์มอนิกที่ 5

L = 0.77 mH, C = 925 µF/เฟส (Y), สั่งคาปาซิเตอร์ 67 kvar 480 V + รีแอกเตอร์ 7 % ได้ 50 kvar จริงที่ 400 V · ผู้ผลิตขายเป็นชุดสำเร็จ แต่ต้องรู้ที่มาเพื่อตรวจสเปกได้

## ฟิลเตอร์จูนเดี่ยว (single-tuned): ออกแบบทีละขั้น กลาง

M5 Single-tuned filter ฟิลเตอร์จูนเดี่ยว

$$X_C = \frac{V^2}{Q_c}\Big(1 - \frac{1}{h_t^2}\Big)^{-1},\qquad X_L = \frac{X_C}{h_t^2},\qquad R = \frac{h_tX_L}{Q_f},\qquad Z_f(h) = R + j\Big(hX_L - \frac{X_C}{h}\Big)$$

เลือก $Q_c$ จาก kvar ที่ต้องการแก้ PF ก่อน แล้วจูนที่ $h_t$ ≈ 0.94–0.96 ของฮาร์มอนิกเป้าหมาย (4.7 สำหรับ 5th) · $Q_f$ 30–100

M6 How much the filter absorbs สัดส่วนกระแสที่ฟิลเตอร์ดักได้

$$I_{f,h} = I_h\frac{Z_s(h)}{Z_s(h) + Z_f(h)},\qquad I_{src,h} = I_h\frac{Z_f(h)}{Z_s(h) + Z_f(h)}$$

ฟิลเตอร์ต้องทนกระแสหลัก $Q_c/(\sqrt3V)$ บวกฮาร์มอนิกที่ดักไว้ (รวมแบบ RMS) และฮาร์มอนิกที่ “ไหลมาจากโหลดอื่น” ในระบบด้วย

ตัวอย่าง M-5 · ฟิลเตอร์ 5th 100 kvar

### ไดรฟ์ไทริสเตอร์ 100 kW (Q₁ ≈ 100 kvar) ระบบ 400 V ออกแบบฟิลเตอร์จูนที่ 4.7 ขนาด 100 kvar $Q_f$ = 40

- $1/h_t^2 = 0.04527$ · M5: $X_C = \frac{400^2}{100\,000}\cdot\frac{1}{0.9547} = 1.676\ \Omega$ · $X_L = 1.676/22.09 = 0.0759\ \Omega$

- $L = 0.2415$ mH · $C = 1899\ \mu$F (Y เทียบเท่า) · $R = 4.7(0.0759)/40 = 8.9$ mΩ

- แรงดันคร่อม C: $400/0.9547 = 419$ V → ใช้คาปาซิเตอร์พิกัด 440 V ขึ้นไป · กระแสหลัก $100\,000/(\sqrt3 \cdot 400) = 144$ A

- แล็บ (Isc/IL = 25): ฟิลเตอร์ดักกระแสที่ 5 ได้ 35 A กระแสที่ 5 ที่เหลือไปหาการไฟฟ้า 17 % THD กระแส 18 % PF 0.98

L = 0.24 mH, C = 1.9 mF/เฟส, R ≈ 9 mΩ, กระแสพิกัด ≈ √(144² + 35²) ≈ 148 A · ฮาร์มอนิกที่ 7 ยังเหลือ ถ้าต้องการต่ำกว่านี้เพิ่มฟิลเตอร์ 7th หรือ high-pass

## ฟิลเตอร์แอกทีฟ Active PFC และ Active Front End กลาง

M7 Shunt active filter ฟิลเตอร์แอกทีฟขนาน

$$i_{AF}(t) = -\sum_{h=2}^{h_{max}} i_h(t),\qquad I_{AF,rated} \gtrsim I_1\cdot\mathrm{THD}_i$$

อินเวอร์เตอร์ที่วัดกระแสโหลด แยกฟูเรียร์ (หรือวิธีเทียบเท่าในเวลาจริง) แล้วจ่ายกระแสตรงข้าม เหลือแค่ฮาร์มอนิกหลักไหลไปหาการไฟฟ้า แล็บ: VFD 11 kW THD 84 % → 8 % ที่ประสิทธิผล 90 %

M8 Active PFC / Active Front End บังคับให้กระแสเป็นไซน์

$$i_{in}(t) = \frac{P}{V_{rms}^2}\,v(t) \;\Rightarrow\; \mathrm{THD}_i \to 0,\;\; \mathrm{PF} \to 1$$

บูสต์คอนเวอร์เตอร์ด้านเข้าควบคุมกระแสตามรูปแรงดัน จำเป็นสำหรับเครื่องใช้ไฟฟ้ากำลังสูงที่ต้องผ่าน IEC 61000-3-2 · แล็บ: SMPS มี PFC THD 3.6 % PF 0.999

M9 Living with harmonics รองรับฮาร์มอนิกแทนการลด

$$K_{tr} \ge K_{load}\;(\text{H9}),\qquad A_{neutral} \ge 2A_{phase}\;(\text{นิวทรัล 200 \%}),\qquad \text{zig-zag: } Z_0 \text{ ต่ำ ดักลำดับศูนย์}$$

อาคารสำนักงานที่โหลดเป็นอิเล็กทรอนิกส์ทั้งหมด มักเลือกหม้อแปลง K-13 และเดินนิวทรัลขนาดสองเท่า หม้อแปลงซิกแซกดักฮาร์มอนิกที่ 3, 9 ไม่ให้ไหลกลับไปที่หม้อแปลงหลัก H9 H10

## เช็กลิสต์แก้ปัญหาหน้างาน: อาการ → วัดอะไร → สาเหตุ → แก้ พื้นฐาน

ใช้เครื่องวิเคราะห์กำลังไฟฟ้า (หรือแล็บด้านล่างเพื่อฝึก) วัดทีละจุด อ่านสเปกตรัม แล้วไล่ตามตารางนี้

| อาการ | วัดอะไร | ถ้าเห็นแบบนี้ → สาเหตุ | แก้ | ลองในแล็บ |

| สายนิวทรัลร้อน | $I_N$, $I_3$ ทุกเฟส | $I_N$ > กระแสเฟส, h = 3 เด่น → โหลดอิเล็กทรอนิกส์ 1 เฟส | นิวทรัล 200 %, ซิกแซก, PFC | |

| หม้อแปลงร้อน แต่ kW ไม่เต็ม | THDI, K-factor, S | K > 4, S ≫ P → กระแสวนจากฮาร์มอนิก | K-rated, ลดพิกัด, ลด THD | |

| คาปาซิเตอร์บวม ฟิวส์ขาด | THDV เมื่อเปิดแต่ละสเต็ป, $I_C$ | THDV เพิ่มเมื่อเพิ่มสเต็ป → เรโซแนนซ์ M2 | ดีจูน 7 %/14 % | |

| PF ต่ำ ทั้งที่ติดคาปาซิเตอร์แล้ว | PF เทียบ DPF | DPF ≈ 1 แต่ PF ต่ำ → ความเพี้ยน (D) | ลดฮาร์มอนิก ไม่ใช่เพิ่ม kvar | |

| ไม่ผ่าน IEEE 519 ที่ PCC | TDD, $I_h$ % ของ $I_L$ | 5, 7 เด่น → ไดรฟ์ 6 พัลส์ | รีแอกเตอร์ → ฟิลเตอร์ → AF/AFE | |

| มิเตอร์สองเครื่องอ่านไม่ตรงกัน | crest factor | CF > 2 → เครื่องหนึ่งไม่ใช่ True RMS | ใช้ True RMS | |

| มอเตอร์ร้อน สั่น ทั้งที่โหลดปกติ | THDV, $V_5$ | $V_5$ ลำดับลบ → แรงบิดต้าน | ลดแหล่งฮาร์มอนิก ฟิลเตอร์ | |

| มีฮาร์มอนิกคู่หรือ DC | $I_2$, $I_0$ | ไม่สมมาตรครึ่งคลื่น → ไดโอดเสีย/เรียงกระแสครึ่งคลื่น | ตรวจอุปกรณ์ S4 | — |

## แล็บ: ลองแก้เองทีละวิธี พื้นฐาน

เริ่มจาก “⚠ คาปาซิเตอร์แก้ PF เรโซแนนซ์” อ่านแผงแปลผลอัตโนมัติ แล้วเปิดเมนู “แก้ปัญหาฮาร์มอนิก” เปลี่ยนเป็นดีจูน 7 % หรือฟิลเตอร์จูน ดูสเปกตรัมและ THD เปลี่ยน ลองไดรฟ์ VFD แล้วเพิ่มรีแอกเตอร์ โช้ก DC และฟิลเตอร์แอกทีฟ เปรียบเทียบกับขีดจำกัด IEEE 519 บนกราฟ

## คำถามที่พบบ่อย

ทำไมคาปาซิเตอร์แก้ PF ระเบิดหรือฟิวส์ขาดบ่อยในโรงงานที่มีไดรฟ์?
คาปาซิเตอร์กับรีแอกแตนซ์ของหม้อแปลงเกิดเรโซแนนซ์ขนานที่ $h_r = \sqrt{S_{sc}/Q_c}$ ถ้า h_r ใกล้ฮาร์มอนิกที่ 5 หรือ 7 ที่ไดรฟ์ปล่อยออกมา กระแสฮาร์มอนิกจะถูกขยายหลายเท่าไหลวนระหว่างคาปาซิเตอร์กับหม้อแปลง คาปาซิเตอร์ร้อนเกินและแรงดันเพี้ยนสูง แก้ด้วยคาปาซิเตอร์ดีจูน

คาปาซิเตอร์ดีจูน 7 % คืออะไร?
คือคาปาซิเตอร์ที่ต่อรีแอกเตอร์อนุกรมให้ $X_L = 7\%$ ของ $X_C$ ทำให้ชุดนี้เรโซแนนซ์อนุกรมที่ $1/\sqrt{0.07} = 3.78$ เท่าของความถี่หลัก (189 Hz ที่ 50 Hz) ต่ำกว่าฮาร์มอนิกที่ 5 ชุดคาปาซิเตอร์จึงเป็นอินดักทีฟที่ 250 Hz ขึ้นไป ไม่เกิดเรโซแนนซ์กับฮาร์มอนิกของไดรฟ์ ใช้ 14 % เมื่อมีฮาร์มอนิกที่ 3 มาก

รีแอกเตอร์ไลน์ 3 % ลด THD ของไดรฟ์ได้เท่าไร?
ไดรฟ์ 6 พัลส์ที่มีตัวเก็บประจุ DC และไม่มีรีแอกเตอร์มี THD กระแสราว 80–100 % ขึ้นกับความแข็งของระบบ รีแอกเตอร์ 3 % ลดเหลือราว 35–40 % และ 5 % ราว 30–35 % ในแล็บของชุดนี้ไดรฟ์ 11 kW ที่ Isc/IL = 100 ได้ 83.5 %, 34.5 % และ 32.0 %

ฟิลเตอร์จูนทำไมจูนที่ 4.7 ไม่ใช่ 5 พอดี?
เผื่อความคลาดเคลื่อนของค่า C ที่ลดลงตามอายุ (ทำให้ความถี่จูนเลื่อนขึ้น) และเพื่อไม่ให้เรโซแนนซ์ขนานที่อยู่ต่ำกว่าความถี่จูนเลื่อนมาชนฮาร์มอนิกที่ 5 พอดี จูนต่ำกว่าเล็กน้อยยังดักกระแสที่ 5 ได้ดีและปลอดภัยกว่า
