    หม้อแปลงร้อน แต่ kW ไม่เต็มTHDI, K-factor, SK > 4, S ≫ P → กระแสวนจากฮาร์มอนิกK-rated, ลดพิกัด, ลด THD
    คาปาซิเตอร์บวม ฟิวส์ขาดTHDV เมื่อเปิดแต่ละสเต็ป, ICI_CIC​THDV เพิ่มเมื่อเพิ่มสเต็ป → เรโซแนนซ์ M2ดีจูน 7 %/14 %
    PF ต่ำ ทั้งที่ติดคาปาซิเตอร์แล้วPF เทียบ DPFDPF ≈ 1 แต่ PF ต่ำ → ความเพี้ยน (D)ลดฮาร์มอนิก ไม่ใช่เพิ่ม kvar
    ไม่ผ่าน IEEE 519 ที่ PCCTDD, IhI_hIh​ % ของ ILI_LIL​5, 7 เด่น → ไดรฟ์ 6 พัลส์รีแอกเตอร์ → ฟิลเตอร์ → AF/AFE
    มิเตอร์สองเครื่องอ่านไม่ตรงกันcrest factorCF > 2 → เครื่องหนึ่งไม่ใช่ True RMSใช้ True RMS
    มอเตอร์ร้อน สั่น ทั้งที่โหลดปกติTHDV, V5V_5V5​V5V_5V5​ ลำดับลบ → แรงบิดต้านลดแหล่งฮาร์มอนิก ฟิลเตอร์
    มีฮาร์มอนิกคู่หรือ DCI2I_2I2​, I0I_0I0​ไม่สมมาตรครึ่งคลื่น → ไดโอดเสีย/เรียงกระแสครึ่งคลื่นตรวจอุปกรณ์ S4—

    แล็บ: ลองแก้เองทีละวิธี พื้นฐาน

    เริ่มจาก “⚠ คาปาซิเตอร์แก้ PF เรโซแนนซ์” อ่านแผงแปลผลอัตโนมัติ แล้วเปิดเมนู “แก้ปัญหาฮาร์มอนิก” เปลี่ยนเป็นดีจูน 7 % หรือฟิลเตอร์จูน ดูสเปกตรัมและ THD เปลี่ยน ลองไดรฟ์ VFD แล้วเพิ่มรีแอกเตอร์ โช้ก DC และฟิลเตอร์แอกทีฟ เปรียบเทียบกับขีดจำกัด IEEE 519 บนกราฟ

    คำถามที่พบบ่อย

    ทำไมคาปาซิเตอร์แก้ PF ระเบิดหรือฟิวส์ขาดบ่อยในโรงงานที่มีไดรฟ์?

    คาปาซิเตอร์กับรีแอกแตนซ์ของหม้อแปลงเกิดเรโซแนนซ์ขนานที่ hr=Ssc/Qch_r = \sqrt{S_{sc}/Q_c}hr​=Ssc​/Qc​​ ถ้า h_r ใกล้ฮาร์มอนิกที่ 5 หรือ 7 ที่ไดรฟ์ปล่อยออกมา กระแสฮาร์มอนิกจะถูกขยายหลายเท่าไหลวนระหว่างคาปาซิเตอร์กับหม้อแปลง คาปาซิเตอร์ร้อนเกินและแรงดันเพี้ยนสูง แก้ด้วยคาปาซิเตอร์ดีจูน

    คาปาซิเตอร์ดีจูน 7 % คืออะไร?

    คือคาปาซิเตอร์ที่ต่อรีแอกเตอร์อนุกรมให้ XL=7%X_L = 7\%XL​=7% ของ XCX_CXC​ ทำให้ชุดนี้เรโซแนนซ์อนุกรมที่ 1/0.07=3.781/\sqrt{0.07} = 3.781/0.07​=3.78 เท่าของความถี่หลัก (189 Hz ที่ 50 Hz) ต่ำกว่าฮาร์มอนิกที่ 5 ชุดคาปาซิเตอร์จึงเป็นอินดักทีฟที่ 250 Hz ขึ้นไป ไม่เกิดเรโซแนนซ์กับฮาร์มอนิกของไดรฟ์ ใช้ 14 % เมื่อมีฮาร์มอนิกที่ 3 มาก

    รีแอกเตอร์ไลน์ 3 % ลด THD ของไดรฟ์ได้เท่าไร?

    ไดรฟ์ 6 พัลส์ที่มีตัวเก็บประจุ DC และไม่มีรีแอกเตอร์มี THD กระแสราว 80–100 % ขึ้นกับความแข็งของระบบ รีแอกเตอร์ 3 % ลดเหลือราว 35–40 % และ 5 % ราว 30–35 % ในแล็บของชุดนี้ไดรฟ์ 11 kW ที่ Isc/IL = 100 ได้ 83.5 %, 34.5 % และ 32.0 %

    ฟิลเตอร์จูนทำไมจูนที่ 4.7 ไม่ใช่ 5 พอดี?

    เผื่อความคลาดเคลื่อนของค่า C ที่ลดลงตามอายุ (ทำให้ความถี่จูนเลื่อนขึ้น) และเพื่อไม่ให้เรโซแนนซ์ขนานที่อยู่ต่ำกว่าความถี่จูนเลื่อนมาชนฮาร์มอนิกที่ 5 พอดี จูนต่ำกว่าเล็กน้อยยังดักกระแสที่ 5 ได้ดีและปลอดภัยกว่า

    คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

    เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม · อุปนัย อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
