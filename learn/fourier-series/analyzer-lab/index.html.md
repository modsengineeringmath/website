# แล็บวิเคราะห์ฮาร์มอนิก: ออสซิลโลสโคปเสมือน + เครื่องวิเคราะห์กำลังไฟฟ้า

// คู่มือ ใบงาน และกรณีศึกษา

## ใช้แล็บให้เข้าใจปัญหาและแก้ได้เอง

เริ่มใน 30 วินาที

- ① ฟูเรียร์: เลือกรูปคลื่น เลื่อน N ดูผลรวมเข้าหารูปจริง เปิด “วิธีคิดทีละขั้น” ดูสมมาตรและตารางสัมประสิทธิ์

- ② วงจร: เลือกวงจรและค่า R L C (พิมพ์ 10k, 4.7u ได้) ตารางคือขั้น แยก → คูณ H(jnω₀) → รวม

- ③ สโคป + เครื่องวิเคราะห์: เลือกโหลด อ่านตัวเลข ดูแท่งฮาร์มอนิกเทียบเส้นขีดจำกัด อ่าน “แปลผลอัตโนมัติ”

- เปิดเมนู “ระบบไฟต้นทาง · แก้ปัญหาฮาร์มอนิก · เกณฑ์มาตรฐาน” เพื่อเปลี่ยนความแข็งของระบบและลองวิธีแก้

## ใบงาน 16 การทดลอง

กด “โหลดการตั้งค่า” แล้วแล็บด้านบนตั้งค่าให้และเลื่อนขึ้นไปให้ ทำตามขั้น ตอบคำถามก่อนเปิดเฉลย ใบงาน 1–9 ใช้แท็บ ① ② ใบงาน 10–16 ใช้แท็บ ③

### สร้างคลื่นสี่เหลี่ยมจากไซน์ พื้นฐาน

เป้าหมาย: เห็นว่าคลื่นสี่เหลี่ยมคือผลรวมของไซน์ความถี่คี่

- กด ▶ เพิ่มทีละตัว ดูว่าตัวเลข n ที่เพิ่มเข้ามามีค่าอะไรบ้าง
- อ่าน A₃/A₁ และ A₅/A₁ จากตาราง
- ตั้ง N = 5 อ่าน “กำลังที่รวมแล้ว” และ THD

สูตร W1 T-1 P7

เฉลย
มีแต่ n คี่ (1, 3, 5, …) เพราะสมมาตรครึ่งคลื่น · A₃/A₁ = 1/3 = 33.3 % · A₅/A₁ = 20 % · N = 5 ได้กำลัง 93.31 % · THD 48.3 %

### ปรากฏการณ์กิบส์และตัวคูณซิกมา กลาง

เป้าหมาย: พิสูจน์ว่าหูกิบส์ไม่หายแม้เพิ่ม N

- N = 99 อ่าน “หูกิบส์” และสังเกตยอดใกล้รอยกระโดด
- ลด N เป็น 19 และ 9 อ่านอีกครั้ง
- ติ๊ก “ลดหูกิบส์ (σ)” ที่ N = 99

สูตร P3 P4

เฉลย
หูกิบส์ 8.95 % (N = 99), 8.99 % (N = 19), 9.12 % (N = 9) ของยอดถึงยอด เกือบคงที่ แค่แคบลง · เปิด σ เหลือ 1.2 % แต่ขอบมนลง

### ดิวตี้กับเอนเวโลป sinc กลาง

เป้าหมาย: หาว่าฮาร์มอนิกตัวไหนหายเมื่อเปลี่ยนดิวตี้

- พัลส์ D = 25 % ดูสเปกตรัมแบบ dB หาลำดับที่หายไป
- โหลด “พัลส์แคบ 10 %” หาลำดับที่หายไป และอ่าน A₁
- เลื่อนดิวตี้เอง ทายลำดับที่หายก่อนดู

สูตร C7 W3

เฉลย
D = 25 %: ไม่มี 4, 8, 12 · D = 10 %: ไม่มี 10, 20, 30 และ A₁ = 2(0.1)sinc(0.1) = 0.197 สเปกตรัมแบนกว้างขึ้นเมื่อพัลส์แคบลง

### สมมาตรกับฮาร์มอนิกคู่ พื้นฐาน

เป้าหมาย: ทำนายฮาร์มอนิกคู่จากรูปร่าง

- ติ๊ก “ซ่อนสเปกตรัม” แล้วโหลด “ตัดยอดสมมาตร” ทายว่ามีฮาร์มอนิกคู่ไหม
- โหลด “ตัดยอดไม่สมมาตร” ทายอีกครั้ง
- โหลด “เรียงกระแสเต็มคลื่น” ทายว่ามี n คี่ไหม

สูตร S4 S7 S8

เฉลย
ตัดสมมาตร: เฉพาะคี่ (ที่ 3 = 13.3 %) · ตัดบนอย่างเดียว: มี DC −0.078 และที่ 2 = 12.7 % · เต็มคลื่น: เฉพาะคู่ (DC 0.637, ที่ 2 = 0.424, ที่ 4 = 0.085)

### กำจัดฮาร์มอนิกด้วยมุม α กลาง

เป้าหมาย: ใช้ $\cos n\alpha = 0$ เลือกมุม

- quasi-square α = 30° อ่าน b₃
- คำนวณมุมที่กำจัดที่ 5 แล้วตั้ง ตรวจด้วย b₅
- ที่มุมนั้น b₃ กลับมาเท่าไร

สูตร V2 W9

เฉลย
α = 30° → b₃ = 0 · กำจัดที่ 5 ใช้ α = 90°/5 = 18° → b₅ = 0 แต่ b₃ = 0.250 (เทียบสี่เหลี่ยม 0.424) และ b₁ = 1.211

### SPWM ไบโพลาร์และยูนิโพลาร์ กลาง

เป้าหมาย: หาตำแหน่งไซด์แบนด์ของ PWM

- SPWM ไบโพลาร์ mₐ = 0.8, m_f = 15 (V_dc = 1) อ่านแอมพลิจูดที่ n = 1, 13, 15, 17, 29, 31
- ติ๊กยูนิโพลาร์ อ่านซ้ำ
- ตั้ง mₐ = 1.3 ดูฮาร์มอนิกต่ำ

สูตร V5 V6 V8

เฉลย
ไบโพลาร์: 0.400, 0.110, 0.409, 0.110, 0.157, 0.157 (= ตาราง × V_dc/2) · ยูนิโพลาร์: หลัก 0.800 กลุ่มที่ 13–17 หายหมด 29, 31 = 0.314 · mₐ = 1.3 มีที่ 3, 5, 7 โผล่

### คลื่นสี่เหลี่ยมผ่าน RC พื้นฐาน

เป้าหมาย: แยก คูณ รวม และตรวจกับคำตอบจริง

- อ่าน |H| ของ n = 1, 3, 5 ในตาราง
- ตั้ง N = 7 อ่าน “ต่างจากคำตอบจริง” แล้วเพิ่มเป็น 49
- คำนวณยอดถึงยอดด้วย $10\tanh(T/4\tau)$ แล้วเทียบ

สูตร A2 A6

เฉลย
|H| = 0.847, 0.469, 0.303 · ความคลาดเคลื่อนลดลงเมื่อเพิ่ม N · ยอดถึงยอดจริง 10 tanh 2.5 = 9.87 V

### ริปเปิลของบั๊กคอนเวอร์เตอร์ กลาง

เป้าหมาย: ประมาณริปเปิลด้วยฮาร์มอนิกแรก

- อ่านฮาร์มอนิกหลักขาออก (mV) และยอดถึงยอดจริง
- เปลี่ยน C เป็น 220u ทำนายก่อนว่าริปเปิลเหลือเท่าไร
- คืน C = 100u แล้วเปลี่ยน f₀ เป็น 100k

สูตร B3 B4

เฉลย
7.48 mV ยอด, ยอดถึงยอด 14.6 mV · C = 220 µF: ราว 6.6 mV (∝ 1/C) · 100 kHz: ราว 3.6 mV (∝ 1/f_s²)

### RLC คัดฮาร์มอนิกที่ 3 กลาง

เป้าหมาย: ใช้เรโซแนนซ์เลือกฮาร์มอนิก

- อ่าน f₀ และ Q
- อ่านแอมพลิจูดขาออกที่ n = 1 และ 3
- เปลี่ยน C เป็น 101.3n แล้วดูว่าฮาร์มอนิกไหนเด่น

สูตร A8

เฉลย
f₀ = 3.00 kHz, Q = 18.9 · n = 3: 2.12 V, n = 1: 0.127 V · C = 101.3 nF จูนที่ 5 kHz ได้ฮาร์มอนิกที่ 5 (1.27 V)

### SMPS ไม่มี PFC กับมี PFC พื้นฐาน

เป้าหมาย: แยก PF ออกเป็น DPF กับ distortion factor

- อ่าน PF, DPF, THD I, crest factor
- คำนวณ DPF × $1/\sqrt{1 + \mathrm{THD}^2}$ เทียบ PF
- โหลด “SMPS มี Active PFC” อ่านซ้ำ

สูตร H7 M8

เฉลย
ไม่มี PFC: THD ≈ 134 %, DPF ≈ 0.99, PF ≈ 0.59 = 0.99/√(1 + 1.34²) · CF ≈ 3 · มี PFC: THD ≈ 3.6 %, PF ≈ 1.00

### นิวทรัลร้อนในอาคาร กลาง

เป้าหมาย: คำนวณกระแสนิวทรัลจากฮาร์มอนิกลำดับศูนย์

- อ่าน I rms และ “I นิวทรัล (3 ชุด สมดุล)”
- เปิดตารางฮาร์มอนิก หา I₃, I₉ แล้วคำนวณ $3\sqrt{I_3^2 + I_9^2 + \cdots}$
- ดูสีแท่ง h = 3, 9, 15

สูตร H10

เฉลย
นิวทรัลราว 1.7 เท่าของกระแสเฟส แท่งลำดับศูนย์เป็นสีม่วง ทางแก้: นิวทรัล 200 % หม้อแปลงซิกแซก หรือ PFC

### ไดรฟ์ VFD กับ IEEE 519 กลาง

เป้าหมาย: ไล่วิธีแก้จนผ่าน TDD

- VFD 11 kW (Isc/IL = 100) อ่าน THD I, TDD, ขีดจำกัด TDD จากแผงแปลผล
- ใส่รีแอกเตอร์ 3 % แล้ว 5 % · ลองโช้ก DC
- เปิดฟิลเตอร์แอกทีฟ

สูตร H13 M1 M7

เฉลย
ขีดจำกัด TDD 15 % (Isc/IL 100–1000) · ไม่มี: THD 83.5 % · 3 %: 34.5 % · 5 %: 32.0 % · โช้ก 2 mH: 37.2 % (ยังไม่ผ่าน) · ฟิลเตอร์แอกทีฟ 90 %: 8.3 % ผ่าน

### คาปาซิเตอร์เรโซแนนซ์และดีจูน ขั้นสูง

เป้าหมาย: หาลำดับเรโซแนนซ์และเปรียบเทียบสามวิธี

- คาปาซิเตอร์เปล่า 100 kvar: อ่าน h_r ในแผงวิธีคำนวณ และอัตราขยายที่ h = 5 (ตาราง: I ต้นทาง/I โหลด)
- เปลี่ยนเป็นดีจูน 7 %
- เปลี่ยนเป็นฟิลเตอร์จูน 4.7 และดู CH2 = “กระแสในคาปาซิเตอร์/ฟิลเตอร์”

สูตร M2 M3 M4 M5

เฉลย
เปล่า: h_r ≈ 6.0 กระแสที่ 5 ขยาย ~2.9 เท่า THD I ~94 % · ดีจูน: เรโซแนนซ์ย้ายไป ~3.2 THD I ~26 % PF ~0.96 · ฟิลเตอร์จูน: กระแสที่ 5 ไปหาการไฟฟ้าเหลือ ~17 % THD I ~18 % PF ~0.98

### ไตรแอกกับ DPF ต่ำทั้งที่โหลดเป็นตัวต้านทาน กลาง

เป้าหมาย: เห็นว่าการตัดเฟสทำให้ฮาร์มอนิกหลักล้าหลัง

- α = 90° อ่าน DPF PF THD และ I₃
- เปิดฮาร์มอนิกหลักของ CH2 ดูว่ามันล้าหลังแรงดัน
- เลื่อน α เป็น 30° และ 150°

สูตร W15 H7

เฉลย
α = 90°: DPF 0.844, PF 0.708, THD 64 %, I₃ ≈ 54 % ของหลัก · โหลดเป็นตัวต้านทานแต่ $a_1 \ne 0$ ทำให้ฮาร์มอนิกหลักล้าหลัง

### 6 พัลส์เทียบ 12 พัลส์ กลาง

เป้าหมาย: ยืนยันกฎ h = kp ± 1

- 6 พัลส์: ลำดับใดมี ลำดับใดไม่มี
- 12 พัลส์: ดู 5, 7 และ 11, 13
- เพิ่ม α ของ 6 พัลส์เป็น 45° ดู DPF

สูตร R6 R10 R11

เฉลย
6 พัลส์: 5, 7, 11, 13 (ไม่มี 3 และคู่) THD ~27 % · 12 พัลส์: 5, 7 หายไป เหลือ 11, 13 THD ~12 % · α = 45°: DPF ~0.71 ≈ cos 45°

### แรงดันยอดแบนกับโหลดเชิงเส้น พื้นฐาน

เป้าหมาย: แยกว่าฮาร์มอนิกมาจากโหลดหรือจากแหล่งจ่าย

- ฮีตเตอร์บนแรงดันที่มีฮาร์มอนิกที่ 5 = 4 % อ่าน THD U และ THD I
- ตั้งฮาร์มอนิกที่ 5 เป็น 0
- เปลี่ยนเป็นมอเตอร์ RL แล้วเทียบ THD I

สูตร A4 H11

เฉลย
ตัวต้านทาน: THD I = THD U ≈ 4 % (กระแสตามแรงดัน) · ไม่มีฮาร์มอนิกในแรงดัน กระแสเป็นไซน์ · มอเตอร์ RL: THD I ต่ำกว่า THD U เพราะ $Z = R + jhX$ โตตาม h

## กรณีศึกษาหน้างาน: คิดเหมือนวิศวกร

แต่ละกรณีมีอาการ คำถามที่ควรถาม การทดลองในแล็บที่จำลองสถานการณ์ และแนวคิดในการแก้ ลองตอบเองก่อนเปิดแนวคิด

### อาคารสำนักงาน: เบรกเกอร์นิวทรัลร้อน

อาคาร 6 ชั้น คอมพิวเตอร์ 400 เครื่อง แคลมป์มิเตอร์อ่านกระแสเฟสละ 120 A แต่นิวทรัลอ่านได้ 180 A ช่างคิดว่าโหลดไม่สมดุล

แนวคิด
โหลดไม่สมดุลทำให้นิวทรัลไม่เกินกระแสเฟส แต่ที่นี่เกิน → ฮาร์มอนิกลำดับศูนย์ (H10) วัดสเปกตรัมนิวทรัลจะเห็น 150 Hz เด่น แก้: นิวทรัลขนาดสองเท่า หม้อแปลงซิกแซกหรือ K-rated ระยะยาวเลือกอุปกรณ์ที่มี PFC

### โรงงาน: คาปาซิเตอร์ APFC ฟิวส์ขาดทุกสัปดาห์

ติดตั้งไดรฟ์ใหม่หลายตัว หลังจากนั้นตู้คาปาซิเตอร์อัตโนมัติฟิวส์ขาด คาปาซิเตอร์บวม และไฟหน้าจอเครื่องจักรกะพริบเมื่อสเต็ปคาปาซิเตอร์เพิ่ม

แนวคิด
คำนวณ $h_r = \sqrt{S_{sc}/Q_c}$ ของแต่ละสเต็ป (M2) ถ้าเข้าใกล้ 5 หรือ 7 คือเรโซแนนซ์ วัด THD แรงดันขณะเปิดสเต็ปจะเห็นเพิ่มขึ้น แก้: เปลี่ยนเป็นคาปาซิเตอร์ดีจูน 7 % พิกัดแรงดัน 440–480 V (M4)

### บิลค่าไฟมีค่าปรับ PF ทั้งที่ cos φ บนมิเตอร์ = 0.98

ร้านอินเทอร์เน็ตคาเฟ่ติดคาปาซิเตอร์แล้ว cos φ ขึ้นเป็น 0.98 แต่การไฟฟ้ายังวัด PF ได้ต่ำ

แนวคิด
cos φ คือ DPF ส่วน PF จริงรวมความเพี้ยน (H7) โหลด SMPS มี THD > 100 % PF จึง ≈ 0.6 แม้ DPF ≈ 1 คาปาซิเตอร์ช่วยไม่ได้ ต้องลดฮาร์มอนิก (PFC, ฟิลเตอร์แอกทีฟ) · หมายเหตุ: การคิดค่า PF ขึ้นกับระเบียบของการไฟฟ้า ตรวจกับการไฟฟ้าที่รับไฟ

### หม้อแปลงร้อนผิดปกติที่โหลด 70 %

หม้อแปลง 500 kVA จ่ายศูนย์ข้อมูลขนาดเล็ก วัด kVA ได้ 70 % ของพิกัด แต่อุณหภูมิขดลวดเกินเกณฑ์

แนวคิด
ดู K-factor (H9) โหลดอิเล็กทรอนิกส์ให้ K ได้ 10–20 ความสูญเสียกระแสวนเพิ่มหลายเท่า ต้องลดพิกัดหรือใช้ K-rated และลดฮาร์มอนิกที่ต้นทาง

### ไดรฟ์ใหม่ไม่ผ่านการตรวจรับของการไฟฟ้า

โรงงานขอเพิ่มไดรฟ์ปั๊ม 6 พัลส์รวม 300 kW บนหม้อแปลง 1000 kVA การไฟฟ้าขอผลการศึกษาฮาร์มอนิก

แนวคิด
หา Isc/IL ที่ PCC → เลือกแถวขีดจำกัด (H13) ประเมิน TDD และ THD แรงดัน (H11, ตัวอย่าง H-4) เริ่มจากรีแอกเตอร์ 3–5 % ถ้ายังไม่พอใช้ฟิลเตอร์แอกทีฟหรือไดรฟ์ 18 พัลส์/AFE ตรวจข้อกำหนดของ กฟภ./กฟน. ประกอบ

### เครื่องกำเนิดไฟฟ้าสำรองแกว่ง เมื่อจ่าย UPS

ขณะไฟดับ เครื่องกำเนิดไฟฟ้าจ่าย UPS ขนาดใหญ่ แรงดันเพี้ยนมาก UPS สลับไปใช้แบตเตอรี่ซ้ำ ๆ

แนวคิด
เครื่องกำเนิดมีอิมพีแดนซ์สูง (ระบบอ่อน Isc/IL ต่ำ) แรงดันเพี้ยนตาม H11 มาก ลดค่า Isc/IL ในแล็บจะเห็น THD U พุ่ง แก้: เครื่องกำเนิดใหญ่ขึ้น (หรือ subtransient reactance ต่ำ) UPS แบบ 12 พัลส์/IGBT rectifier หรือฟิลเตอร์

## สมมติฐานของแบบจำลอง (อ่านก่อนนำตัวเลขไปใช้)

- รูปคลื่นในแท็บ ①: สัมประสิทธิ์อินทิเกรตแบบปิดทีละช่วง (ค่าคงตัว เส้นตรง ไซน์) จึงตรงกับสูตรทุกหลัก รูปที่พิมพ์เองใช้อินทิกรัลเชิงตัวเลข 8,192 จุดต่อคาบ

- วงจรในแท็บ ②: เชิงเส้นอุดมคติ (LC มีความต้านทานอนุกรม 0.02 Ω) คำตอบอ้างอิงคือสถานะคงตัวแบบคาบจาก RK4 ที่ตัดขั้นตอนตรงจุดกระโดดของสัญญาณ

- แหล่งจ่าย: ไซน์ 230 V (เฟส) อิมพีแดนซ์จาก Isc/IL และ X/R ความต้านทานเพิ่มตาม $\sqrt h$ (skin effect) โหลดเชิงเส้นอื่นบนหม้อแปลงเป็นตัวหน่วงขนานที่ PCC

- โหลดไม่เชิงเส้น: แทนด้วยแหล่งจ่ายกระแสฮาร์มอนิก (Norton) · 6/12 พัลส์ใช้บล็อก 120° กับช่วงทับซ้อนรูปไซน์ตามจริง 12 พัลส์หักล้างสมบูรณ์ · SMPS และ VFD จำลองในโดเมนเวลา (VFD ถือว่าการสลับเฟสเกิดทันที) · PFC ใช้สเปกตรัมตัวอย่างคงที่

- ตัวเลขที่ได้ อยู่ในช่วงที่พบจริง แต่ไม่ใช่ข้อมูลของอุปกรณ์ยี่ห้อใด งานออกแบบจริงต้องวัดและทำการศึกษาฮาร์มอนิกตามมาตรฐาน

## คำถามที่พบบ่อย

แล็บนี้ใช้ฟรีไหม ต้องติดตั้งอะไรไหม?
ใช้ฟรีทั้งหมด เปิดในเบราว์เซอร์ทั้งคอมพิวเตอร์และมือถือ ไม่ต้องสมัครหรือติดตั้งโปรแกรม การตั้งค่าทุกอย่างเก็บในลิงก์ กดคัดลอกลิงก์แล้วส่งให้เพื่อนหรืออาจารย์เปิดได้ภาพเดียวกัน

ตัวเลขในแล็บแม่นแค่ไหน?
สัมประสิทธิ์ฟูเรียร์ของรูปคลื่นในรายการคำนวณด้วยการอินทิเกรตแบบปิดทีละช่วง ไม่ใช่ FFT จึงตรงกับสูตรทุกหลัก วงจรเชิงเส้นเทียบกับคำตอบจากสมการอนุพันธ์ โหลดไม่เชิงเส้นเป็นแบบจำลองเพื่อการเรียน (ดูหัวข้อสมมติฐานของแบบจำลอง) ค่า THD และ PF อยู่ในช่วงที่วัดได้จริงแต่ขึ้นกับอุปกรณ์แต่ละรุ่น

ใช้แล็บนี้ฝึกแก้ปัญหาฮาร์มอนิกในโรงงานได้ไหม?
ได้ในระดับความเข้าใจ เลือกโหลด ปรับความแข็งของระบบ (Isc/IL) ใส่รีแอกเตอร์ คาปาซิเตอร์ดีจูน ฟิลเตอร์จูน หรือฟิลเตอร์แอกทีฟ แล้วดู THD TDD PF และการเทียบ IEEE 519 พร้อมแผงแปลผลอัตโนมัติ งานจริงต้องวัดด้วยเครื่องวิเคราะห์คุณภาพไฟฟ้าตามมาตรฐานและทำการศึกษาฮาร์มอนิกโดยวิศวกร

ส่งงานหรือแชร์ผลการทดลองอย่างไร?
กดปุ่ม คัดลอกลิงก์ ลิงก์ที่ได้มีค่าทุกปุ่ม ส่งทาง LINE หรืออีเมลแล้วเปิดได้ผลเดิม หรือแคปหน้าจอแผงวิธีคำนวณทีละขั้นแนบในรายงาน
