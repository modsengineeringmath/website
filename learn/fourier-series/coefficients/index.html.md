# หาสัมประสิทธิ์ฟูเรียร์ทีละขั้น: ความตั้งฉากและสูตรออยเลอร์

// บทที่ 12.2 · อนุกรมฟูเรียร์ · Finding the Coefficients


ทุกโจทย์อนุกรมฟูเรียร์จบที่อินทิกรัลสามตัว แต่ถ้าเข้าใจว่าทำไมอินทิกรัลนั้นดึงสัมประสิทธิ์ออกมาได้ จะไม่ต้องจำสูตรและไม่สับสน 1/T กับ 2/T อีก หน้านี้เริ่มจากความตั้งฉากของไซน์ ซึ่งเป็นแนวคิดเดียวกับผลคูณจุดของเวกเตอร์ แล้วทำตัวอย่างที่เจอในงานไฟฟ้าทีละขั้น

สรุปใน 30 วินาที

- $a_0 = \frac{1}{T}\int_T x\,dt$ · $a_n = \frac{2}{T}\int_T x\cos n\omega_0 t\,dt$ · $b_n = \frac{2}{T}\int_T x\sin n\omega_0 t\,dt$

- มาจากความตั้งฉาก: $\int_T \cos m\omega_0 t\cos n\omega_0 t\,dt = 0$ เมื่อ $m \ne n$ คูณแล้วอินทิเกรตจึงเหลือพจน์เดียว

- ค่าที่ใช้ตลอด: $\sin n\pi = 0$, $\cos n\pi = (-1)^n$, $\int t\sin at\,dt = -\tfrac{t\cos at}{a} + \tfrac{\sin at}{a^2}$

- ดูสมมาตรก่อนอินทิเกรตทุกครั้ง ลดงานได้ครึ่งหนึ่ง 12.3

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## ความตั้งฉากของไซน์และโคไซน์ พื้นฐาน

เวกเตอร์สองตัวตั้งฉากกันเมื่อผลคูณจุดเป็นศูนย์ ผลคูณจุด คือผลคูณของส่วนประกอบแต่ละตัวแล้วรวมกัน สำหรับฟังก์ชัน “ส่วนประกอบ” มีต่อเนื่องทุกค่าของ $t$ การรวมจึงกลายเป็นอินทิกรัล ฟังก์ชัน $\cos n\omega_0 t$ และ $\sin n\omega_0 t$ ทุกตัวตั้งฉากกันหมดเมื่ออินทิเกรตตลอดหนึ่งคาบ

T1 Orthogonality of sines ไซน์ตั้งฉากกัน

$$\int_{0}^{T} \sin m\omega_0 t\,\sin n\omega_0 t\,dt = \begin{cases} 0 & m \ne n \\ T/2 & m = n \ne 0 \end{cases}$$

T2 Orthogonality of cosines โคไซน์ตั้งฉากกัน

$$\int_{0}^{T} \cos m\omega_0 t\,\cos n\omega_0 t\,dt = \begin{cases} 0 & m \ne n \\ T/2 & m = n \ne 0 \\ T & m = n = 0 \end{cases}$$

T3 Sine ⟂ cosine ไซน์ตั้งฉากกับโคไซน์ทุกคู่

$$\int_{0}^{T} \sin m\omega_0 t\,\cos n\omega_0 t\,dt = 0 \quad \text{ทุก } m, n$$

T4 A whole number of cycles averages to zero ไซน์ครบรอบเฉลี่ยเป็นศูนย์

$$\int_{0}^{T} \cos n\omega_0 t\,dt = \int_{0}^{T} \sin n\omega_0 t\,dt = 0,\quad n \ge 1$$

T1–T3 พิสูจน์ได้ด้วยสูตรผลคูณเป็นผลบวก (product-to-sum) แล้วใช้ T4 กับแต่ละพจน์ · ดูตารางเต็มที่ตรีโกณมิติ

ซ้าย: $\sin t \cdot \sin 3t$ พื้นที่บวกกับลบหักกันพอดี อินทิกรัลเป็นศูนย์ · ขวา: $\sin t \cdot \sin t = \sin^2 t$ ไม่เคยติดลบ พื้นที่ตลอดคาบเท่ากับครึ่งหนึ่งของคาบ (T/2)

## สูตรออยเลอร์–ฟูเรียร์: หา a₀ aₙ bₙ พื้นฐาน

สมมติว่า $x(t) = a_0 + \sum_n [a_n \cos n\omega_0 t + b_n \sin n\omega_0 t]$ จริง ถ้าอยากได้ $a_m$ ตัวเดียว ให้คูณทั้งสองข้างด้วย $\cos m\omega_0 t$ แล้วอินทิเกรตตลอดคาบ ทุกพจน์ทางขวาหายหมดตาม T1–T4 ยกเว้นพจน์ $a_m\cos^2 m\omega_0 t$ ซึ่งให้ $a_m T/2$ นี่คือที่มาของ 2/T

T5 Multiply and integrate (projection) คูณด้วยฟังก์ชันฐานแล้วอินทิเกรต

$$\int_{0}^{T} x(t)\cos m\omega_0 t\,dt = a_m \int_0^T \cos^2 m\omega_0 t\,dt = a_m\,\frac{T}{2}$$

เหมือนหาส่วนประกอบของเวกเตอร์: $a_m = \dfrac{\langle x, \cos\rangle}{\langle \cos, \cos\rangle}$ ตัวส่วนคือ “ความยาวกำลังสอง” ของฟังก์ชันฐาน

T6 Euler–Fourier formulas สูตรหาสัมประสิทธิ์

$$a_0 = \frac{1}{T}\int_{t_0}^{t_0+T} x(t)\,dt, \qquad a_n = \frac{2}{T}\int_{t_0}^{t_0+T} x(t)\cos n\omega_0 t\,dt, \qquad b_n = \frac{2}{T}\int_{t_0}^{t_0+T} x(t)\sin n\omega_0 t\,dt$$

เลือก $t_0$ อะไรก็ได้ ขอให้ครบหนึ่งคาบ เลือกช่วงที่ทำให้ฟังก์ชันเขียนง่ายที่สุด เช่น $-T/2$ ถึง $T/2$ เมื่อมีสมมาตรรอบ $t = 0$

T7 In terms of angle θ = ω₀t เขียนด้วยมุม (นิยมในอิเล็กทรอนิกส์กำลัง)

$$a_0 = \frac{1}{2\pi}\int_{0}^{2\pi} x(\theta)\,d\theta, \qquad a_n = \frac{1}{\pi}\int_{0}^{2\pi} x(\theta)\cos n\theta\,d\theta, \qquad b_n = \frac{1}{\pi}\int_{0}^{2\pi} x(\theta)\sin n\theta\,d\theta$$

แทน $\theta = \omega_0 t$, $d\theta = \omega_0\,dt$ ได้ $2/T \cdot dt = d\theta/\pi$ · มุมจุดชนวน α และช่วงนำกระแสของไดโอดอ่านเป็นองศาได้ตรง ๆ

T8 The a₀/2 convention ตำราที่เขียน a₀/2

$$x(t) = \frac{a_0'}{2} + \sum_{n}\big[\cdots\big], \qquad a_0' = \frac{2}{T}\int_T x\,dt = 2a_0$$

ทั้งสองแบบให้อนุกรมเดียวกัน ต่างกันแค่ชื่อ ก่อนใช้สูตรจากตำราใด ตรวจก่อนว่าพจน์ DC เขียนแบบไหน ชุดนี้ใช้ $a_0$ = ค่าเฉลี่ย

## อินทิกรัลและค่าที่ใช้บ่อย พื้นฐาน

รูปคลื่นในงานไฟฟ้าส่วนใหญ่ประกอบด้วยช่วงที่เป็นค่าคงตัว เส้นตรง หรือไซน์ อินทิกรัลจึงวนอยู่แค่ไม่กี่แบบ อินทิกรัลทีละส่วน (by parts) ทบทวนได้ที่หน้าอินทิกรัล

T9 ∫ t cos at dt อินทิกรัลทีละส่วน

$$\int t\cos at\,dt = \frac{t\sin at}{a} + \frac{\cos at}{a^2} + C$$

T10 ∫ t sin at dt อินทิกรัลทีละส่วน

$$\int t\sin at\,dt = -\frac{t\cos at}{a} + \frac{\sin at}{a^2} + C$$

T11 Values at multiples of π (n integer) ค่าที่ใช้แทนตอนท้ายทุกโจทย์

$$\sin n\pi = 0,\qquad \cos n\pi = (-1)^n,\qquad \sin\tfrac{n\pi}{2} = \begin{cases} 0 & n \text{ คู่} \\ (-1)^{(n-1)/2} & n \text{ คี่}\end{cases},\qquad \cos\tfrac{n\pi}{2} = \begin{cases} (-1)^{n/2} & n \text{ คู่} \\ 0 & n \text{ คี่}\end{cases}$$

$1 - \cos n\pi = 1 - (-1)^n$ = 2 เมื่อ n คี่ และ 0 เมื่อ n คู่ ตัวนี้คือที่มาของ “มีแต่ฮาร์มอนิกคี่” ในหลายโจทย์

T12 Product-to-sum for sinusoidal segments ใช้กับช่วงที่เป็นไซน์ (เรียงกระแส ไตรแอก)

$$\sin\theta\cos n\theta = \tfrac12\big[\sin(1+n)\theta + \sin(1-n)\theta\big],\qquad \sin\theta\sin n\theta = \tfrac12\big[\cos(1-n)\theta - \cos(1+n)\theta\big]$$

เมื่อ $n = 1$ พจน์ $(1 - n)\theta$ กลายเป็นค่าคงตัว อินทิเกรตแล้วไม่หารด้วย $1 - n$ ต้องคิดกรณี n = 1 แยกเสมอ

## ขั้นตอน 6 ขั้นที่ใช้ได้ทุกโจทย์ พื้นฐาน

- หาคาบและ $\omega_0$ จากรูป อ่านช่วงที่ซ้ำ ไม่ใช่ช่วงที่เป็นบวก

- เขียน $x(t)$ เป็นช่วง ๆ ในหนึ่งคาบ เลือกช่วงอินทิเกรตที่สะดวก

- ดูสมมาตร (คู่ คี่ ครึ่งคลื่น) แล้วตัดพจน์ที่เป็นศูนย์ทิ้งก่อน ตารางตัดสินใจ

- หา $a_0$ จากพื้นที่ใต้กราฟหารคาบ (มักไม่ต้องอินทิเกรตจริง)

- หา $a_n$, $b_n$ ด้วย T6 หรือ T7 แล้วแทน T11 ให้เหลือรูปที่ขึ้นกับ n ชัดเจน ระวังกรณี n พิเศษ

- ตรวจ: แทนค่า t หนึ่งจุด ใช้พาร์เซวาล และเปิดแล็บสังเคราะห์ ดูวิธีตรวจ

## ตัวอย่างวิธีทำ กลาง

ห้าตัวอย่างนี้ครอบคลุมรูปแบบที่เจอในข้อสอบและงานจริงเกือบทั้งหมด กด “▶ ดูทีละขั้น” เพื่อเปิดทีละบรรทัด หรือเปิดโหมดฝึกทำเพื่อลองทำเองก่อน

ตัวอย่าง T-1 · คลื่นสี่เหลี่ยม

### $x(t) = A$ เมื่อ $0 \lt t \lt T/2$ และ $-A$ เมื่อ $T/2 \lt t \lt T$ หาอนุกรมฟูเรียร์

- $a_0$: พื้นที่บวก $AT/2$ หักพื้นที่ลบ $AT/2$ เป็นศูนย์ → $a_0 = 0$

- $a_n$ T6

$$a_n = \frac{2}{T}\Big[\int_0^{T/2} A\cos n\omega_0 t\,dt - \int_{T/2}^{T} A\cos n\omega_0 t\,dt\Big] = \frac{2A}{T}\Big[\frac{\sin n\omega_0 t}{n\omega_0}\Big|_0^{T/2} - \frac{\sin n\omega_0 t}{n\omega_0}\Big|_{T/2}^{T}\Big] = 0$$
เพราะ $\sin(n\omega_0 T/2) = \sin n\pi = 0$ และ $\sin(n\omega_0 T) = \sin 2n\pi = 0$

- $b_n$: $-\cos$ ที่ปลายแต่ละช่วง แทน $\omega_0 T/2 = \pi$

$$b_n = \frac{2A}{T}\cdot\frac{1}{n\omega_0}\Big[(1 - \cos n\pi) + (\cos 2n\pi - \cos n\pi)\Big] = \frac{2A}{n\pi}\big(1 - \cos n\pi\big)$$

- ใช้ T11: $1 - \cos n\pi = 2$ เมื่อ n คี่ และ 0 เมื่อ n คู่

$$b_n = \begin{cases} \dfrac{4A}{n\pi} & n = 1, 3, 5, \dots \\ 0 & n \text{ คู่} \end{cases}$$

$$x(t) = \frac{4A}{\pi}\Big[\sin\omega_0 t + \tfrac13\sin 3\omega_0 t + \tfrac15\sin 5\omega_0 t + \cdots\Big]$$
ฮาร์มอนิกหลักสูงกว่าตัวคลื่นเอง ($4/\pi = 1.273$ เท่า) ที่เหลือลดลงตาม $1/n$

ตัวอย่าง T-2 · พัลส์ลอจิก 0–5 V ดิวตี้ 25 %

### พัลส์สูง $A = 5$ V ช่วง $0 \lt t \lt DT$ (D = 0.25) และ 0 ในส่วนที่เหลือ หา $a_0$, $a_n$, $b_n$ และแอมพลิจูด $A_1$ ถึง $A_4$

- $a_0 = \dfrac{1}{T}\cdot A \cdot DT = AD = 1.25$ V (ค่าเฉลี่ยที่มัลติมิเตอร์ย่าน DC อ่านได้)

- อินทิเกรตเฉพาะช่วงที่ไม่เป็นศูนย์ ใช้ $\omega_0 DT = 2\pi nD/n$

$$a_n = \frac{2A}{T}\int_0^{DT}\!\cos n\omega_0 t\,dt = \frac{A}{n\pi}\sin 2\pi nD, \qquad b_n = \frac{2A}{T}\int_0^{DT}\!\sin n\omega_0 t\,dt = \frac{A}{n\pi}\big(1 - \cos 2\pi nD\big)$$

- แทน D = 0.25: $2\pi nD = n\pi/2$

| n | $a_n$ | $b_n$ | $A_n = \sqrt{a_n^2 + b_n^2}$ |

| 1 | 1.5915 | 1.5915 | 2.2508 |

| 2 | 0 | 1.5915 | 1.5915 |

| 3 | −0.5305 | 0.5305 | 0.7503 |

| 4 | 0 | 0 | 0 |

- รูปลัดจากรูปเชิงซ้อน C7: $A_n = 2AD\,|\mathrm{sinc}(nD)|$ ตรวจ n = 1: $2.5 \times \dfrac{\sin(\pi/4)}{\pi/4} = 2.5 \times 0.9003 = 2.2508$ ✓

$a_0 = 1.25$ V, $A_1 = 2.25$ V, $A_2 = 1.59$ V, $A_3 = 0.75$ V, $A_4 = 0$ · ฮาร์มอนิกที่ 4, 8, 12 หายไปเพราะ $nD$ เป็นจำนวนเต็ม (ศูนย์ของ sinc)

ลองในแล็บท้ายหน้า: ตั้งพัลส์ D = 25 % แอมพลิจูด 5 อ่านตารางในแผงวิธีคิด ✓

ตัวอย่าง T-3 · ฟันเลื่อย (by parts)

### $x(t) = \dfrac{2A}{T}\,t$ เมื่อ $-T/2 \lt t \lt T/2$ ซ้ำทุกคาบ หาอนุกรมฟูเรียร์

- อินทิเกรตช่วงสมมาตร $-T/2$ ถึง $T/2$: $x$ เป็นฟังก์ชันคี่ → $a_0 = a_n = 0$ (ผลคูณกับโคไซน์เป็นฟังก์ชันคี่ พื้นที่หักกันหมด) S2

- $t\sin n\omega_0 t$ เป็นฟังก์ชันคู่ จึงอินทิเกรตครึ่งช่วงแล้วคูณสอง ใช้ T10 กับ $a = n\omega_0$

$$\int_{-T/2}^{T/2} t\sin n\omega_0 t\,dt = 2\Big[-\frac{t\cos n\omega_0 t}{n\omega_0} + \frac{\sin n\omega_0 t}{(n\omega_0)^2}\Big]_0^{T/2} = -\frac{T\cos n\pi}{n\omega_0} = -\frac{T^2(-1)^n}{2\pi n}$$

- คูณด้วย $\dfrac{2}{T}\cdot\dfrac{2A}{T}$

$$b_n = \frac{4A}{T^2}\cdot\Big(-\frac{T^2(-1)^n}{2\pi n}\Big) = \frac{2A}{n\pi}(-1)^{n+1}$$

$$x(t) = \frac{2A}{\pi}\Big[\sin\omega_0 t - \tfrac12\sin 2\omega_0 t + \tfrac13\sin 3\omega_0 t - \cdots\Big]$$
มีครบทั้งฮาร์มอนิกคู่และคี่ เพราะฟันเลื่อยไม่มีสมมาตรครึ่งคลื่น

ตัวอย่าง T-4 · เรียงกระแสครึ่งคลื่นจากไฟ 230 V

### ไดโอดตัวเดียวต่อกับโหลดตัวต้านทาน แรงดันโหลด $v(\theta) = V_m\sin\theta$ เมื่อ $0 \lt \theta \lt \pi$ และ 0 ในครึ่งหลัง $V_m = 230\sqrt2 = 325.3$ V หา DC ฮาร์มอนิกหลัก และฮาร์มอนิกที่ 2, 4, 6

- ใช้รูปมุม T7 $a_0 = \dfrac{1}{2\pi}\int_0^{\pi} V_m\sin\theta\,d\theta = \dfrac{V_m}{2\pi}\big[-\cos\theta\big]_0^{\pi} = \dfrac{V_m}{\pi} = 103.5$ V

- $a_n$ ใช้ T12 (n ≠ 1)

$$a_n = \frac{V_m}{2\pi}\int_0^{\pi}\big[\sin(1+n)\theta + \sin(1-n)\theta\big]d\theta = \frac{V_m}{2\pi}\Big[\frac{1 - \cos(1+n)\pi}{1+n} + \frac{1 - \cos(1-n)\pi}{1-n}\Big]$$

- n คู่: $\cos(1\pm n)\pi = -1$ → $a_n = \dfrac{V_m}{2\pi}\Big[\dfrac{2}{1+n} + \dfrac{2}{1-n}\Big] = -\dfrac{2V_m}{\pi(n^2 - 1)}$ · n คี่ (n ≥ 3): $\cos(1\pm n)\pi = 1$ → $a_n = 0$

- $b_n$ (n ≠ 1) มีแต่ $\sin(1\pm n)\pi = 0$ จึงเป็นศูนย์หมด

- กรณี n = 1 คิดแยก: $a_1 = \dfrac{V_m}{\pi}\int_0^{\pi}\sin\theta\cos\theta\,d\theta = 0$ และ $b_1 = \dfrac{V_m}{\pi}\int_0^{\pi}\sin^2\theta\,d\theta = \dfrac{V_m}{\pi}\cdot\dfrac{\pi}{2} = \dfrac{V_m}{2} = 162.6$ V

- แทนค่า: $a_2 = -\dfrac{2(325.3)}{3\pi} = -69.0$ V · $a_4 = -\dfrac{2(325.3)}{15\pi} = -13.8$ V · $a_6 = -\dfrac{2(325.3)}{35\pi} = -5.92$ V

$v = 103.5 + 162.6\sin\theta - 69.0\cos 2\theta - 13.8\cos 4\theta - 5.92\cos 6\theta - \cdots$ V · มี DC ฮาร์มอนิกหลัก และฮาร์มอนิกคู่ ไม่มีคี่ตั้งแต่ 3 ขึ้นไป · ถ้าเป็นกระแสในสายไฟ ส่วน DC จะไหลเข้าหม้อแปลงและทำให้แกนอิ่มตัว

ตรวจด้วยพาร์เซวาล: $103.5^2 + \tfrac12(162.6^2 + 69.0^2 + 13.8^2 + 5.92^2) = 26{,}440$ เทียบ $V_{rms}^2 = (V_m/2)^2 = 26{,}450$ ต่างกันเพียง 0.04 % ซึ่งอยู่ในฮาร์มอนิกที่ 8 ขึ้นไป ✓

### แรมป์ 0 ถึง $A = 10$ V: $x(t) = At/T$ เมื่อ $0 \lt t \lt T$ แล้วกลับเป็น 0 (เช่นแรงดันกวาดของสโคปแอนะล็อก) หาอนุกรม

- $a_0 = \dfrac{1}{T}\cdot\dfrac{AT}{2} = \dfrac{A}{2} = 5$ V (พื้นที่สามเหลี่ยม)

- $a_n$ ใช้ T9

$$a_n = \frac{2A}{T^2}\Big[\frac{t\sin n\omega_0 t}{n\omega_0} + \frac{\cos n\omega_0 t}{(n\omega_0)^2}\Big]_0^{T} = \frac{2A}{T^2}\Big[0 + \frac{1 - 1}{(n\omega_0)^2}\Big] = 0$$

- $b_n$ ใช้ T10

$$b_n = \frac{2A}{T^2}\Big[-\frac{t\cos n\omega_0 t}{n\omega_0} + \frac{\sin n\omega_0 t}{(n\omega_0)^2}\Big]_0^{T} = \frac{2A}{T^2}\cdot\Big(-\frac{T}{n\omega_0}\Big) = -\frac{A}{n\pi}$$

$x(t) = 5 - \dfrac{10}{\pi}\displaystyle\sum_{n=1}^{\infty}\frac{\sin n\omega_0 t}{n}$ V · $b_1 = -3.18$ V · ถ้าย้ายแกนลง 5 V จะเหลือฟันเลื่อยคี่ของ T-3 ที่เลื่อนครึ่งคาบ อนุกรมจึงต่างแค่เครื่องหมาย

## ตรวจคำตอบด้วยตัวเอง กลาง

T13 Value at a jump ที่รอยกระโดด อนุกรมให้ค่ากึ่งกลาง

$$\lim_{N\to\infty} x_N(t_0) = \frac{x(t_0^-) + x(t_0^+)}{2}$$

T-5 ที่ $t = 0$: ทุก $\sin$ เป็นศูนย์ เหลือ $a_0 = A/2$ ซึ่งคือกึ่งกลางของ 0 กับ A พอดี ✓

T14 Check by evaluating a point แทนค่าจุดที่รู้คำตอบ

$$x\!\left(\tfrac{T}{4}\right) = A = \frac{4A}{\pi}\Big(1 - \tfrac13 + \tfrac15 - \cdots\Big) \;\Rightarrow\; \frac{\pi}{4} = 1 - \frac13 + \frac15 - \cdots$$

ได้อนุกรมไลบ์นิซของ π เป็นผลพลอยได้ ใช้ยืนยันว่า $4A/\pi$ ถูกต้อง

- DC ด้วยตา: $a_0$ ต้องเท่ากับเส้นที่แบ่งพื้นที่บนล่างเท่ากัน

- เครื่องหมาย: ถ้ารูปคลื่นเริ่มขึ้นจากศูนย์ ตัวไซน์ของฮาร์มอนิกหลักควรเป็นบวก

- พาร์เซวาล: $a_0^2 + \tfrac12\sum A_n^2$ ต้องเข้าใกล้ RMS² P5

- แล็บ: ใส่สูตรของคุณเองในโหมด “พิมพ์สมการเอง” แล้วเทียบตาราง

## คำถามที่พบบ่อย

สูตรหา a0 an bn ของอนุกรมฟูเรียร์คืออะไร?
$a_0 = \frac1T\int_0^T x\,dt$ (ค่าเฉลี่ย), $a_n = \frac2T\int_0^T x\cos(n\omega_0 t)\,dt$ และ $b_n = \frac2T\int_0^T x\sin(n\omega_0 t)\,dt$ อินทิเกรตตลอดหนึ่งคาบใดก็ได้ เช่น $-T/2$ ถึง $T/2$

ทำไม a0 ใช้ 1/T แต่ an ใช้ 2/T?
เพราะ $\int_0^T 1\,dt = T$ แต่ $\int_0^T \cos^2(n\omega_0 t)\,dt = T/2$ เมื่อหารด้วยกำลังของฟังก์ชันฐานแต่ละตัวจึงได้ 1/T กับ 2/T ถ้าตำราเขียนอนุกรมเป็น $a_0/2 + \sum$ ก็จะใช้ 2/T กับ $a_0$ ได้ แต่ $a_0$ นั้นจะเป็นสองเท่าของค่าเฉลี่ย

ทำไมไซน์เรียงกระแสครึ่งคลื่นต้องคิด n = 1 แยก?
สูตรทั่วไปของ $a_n$ มีตัวหาร $1 - n^2$ ซึ่งเป็นศูนย์เมื่อ n = 1 เพราะการใช้สูตรผลคูณเป็นผลบวกให้พจน์ $\sin((1-n)\theta)$ ที่กลายเป็น $\sin 0$ ต้องอินทิเกรตกรณี n = 1 ใหม่ ได้ $a_1 = 0$ และ $b_1 = V_m/2$

ตรวจคำตอบอนุกรมฟูเรียร์อย่างไร?
ตรวจ 4 อย่าง: a0 ตรงกับค่าเฉลี่ยที่ดูด้วยตา ค่าของอนุกรมที่จุดใดจุดหนึ่ง (ที่รอยกระโดดได้ค่ากึ่งกลาง) ทฤษฎีบทพาร์เซวาลว่าผลรวมกำลังเท่ากับ RMS² และเปิดแล็บสังเคราะห์ดูว่ารูปออกมาตรง
