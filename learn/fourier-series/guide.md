## 1. สรุปในหนึ่งนาที

- คลื่นคาบใด ๆ \(x(t)\) ที่คาบ \(T\) เขียนได้เป็น DC + ผลรวมไซน์ที่ความถี่ \(nf_0\) โดย \(f_0 = 1/T\): \(x(t) = a_0 + \sum_{n\ge1}\big[a_n\cos n\omega_0t + b_n\sin n\omega_0t\big] = a_0 + \sum A_n\cos(n\omega_0t + \varphi_n)\)
- สัมประสิทธิ์หาจากอินทิกรัล (สูตรออยเลอร์–ฟูเรียร์ T6) และใช้สมมาตรตัดพจน์ที่เป็นศูนย์ก่อนอินทิเกรต (คู่ → ไม่มี \(b_n\), คี่ → ไม่มี \(a_n\), ครึ่งคลื่น → มีแต่ \(n\) คี่)
- พาร์เซวาล: กำลังรวม = ผลรวมกำลังของแต่ละฮาร์มอนิก → \(X_{rms} = \sqrt{X_0^2 + X_1^2 + X_2^2 + \cdots}\) และ \(I_{rms} = I_1\sqrt{1 + \mathrm{THD}^2}\)
- วงจรเชิงเส้นที่ป้อนด้วยคลื่นไม่ใช่ไซน์: แยกเป็นฮาร์มอนิก → คูณ \(H(jn\omega_0)\) ทีละตัว → รวม
- กระแสเพี้ยนทำให้ \(\mathrm{PF} = \mathrm{DPF}/\sqrt{1 + \mathrm{THD}_i^2}\) คาปาซิเตอร์แก้ได้แค่ DPF และอาจเรโซแนนซ์ขนานกับระบบที่ \(h_r = \sqrt{S_{sc}/Q_c}\)
- ตัวแปลงกำลัง p พัลส์สร้างฮาร์มอนิกลักษณะเฉพาะ \(h = kp \pm 1\) ขนาดราว \(1/h\) ของหลัก ส่วน PWM ย้ายฮาร์มอนิกไปรอบความถี่สวิตชิ่ง \(m_f\)
- เครื่องวัดจริงคำนวณฮาร์มอนิกด้วย DFT/FFT: ต้องสุ่มให้เร็วพอ (อเลียสซิง) และครอบคาบเต็มจำนวน (การรั่วของสเปกตรัม) ตาม IEC 61000-4-7 ใช้หน้าต่าง 10 คาบ (50 Hz) = 200 ms → ความละเอียด 5 Hz

## 4. ข้อตกลงและสัญลักษณ์ที่ใช้ทั้งชุด

- \(\omega_0 = 2\pi f_0 = 2\pi/T\), มุม \(\theta = \omega_0 t\)
- \(a_0\) คือ **ค่าเฉลี่ย** (บางตำราเขียน \(a_0/2\) — ดูสูตร T8 ก่อนเทียบคำตอบ)
- รูปแอมพลิจูด–เฟสใช้ **โคไซน์**: \(A_n = \sqrt{a_n^2 + b_n^2}\), \(\varphi_n = \operatorname{atan2}(-b_n, a_n)\) (สูตร C3) และเฟสเซอร์ค่ายอด \(\mathbf X_n = a_n - jb_n\)
- ค่าที่เครื่องวัดแสดงเป็น RMS ของแต่ละฮาร์มอนิก \(X_n = A_n/\sqrt2\) หรือเป็น % ของฮาร์มอนิกหลัก
- THD ในชุดนี้หมายถึง \(\mathrm{THD}_F\) (เทียบฮาร์มอนิกหลัก) นับถึง h = 50 เว้นแต่ระบุเป็นอนุกรมอนันต์ TDD เทียบกระแสความต้องการสูงสุด \(I_L\)
- ระบบไฟฟ้าตัวอย่าง: 230 V / 400 V 50 Hz (ประเทศไทย) และมีตัวอย่าง 60 Hz ประกอบ

## 5. สูตรหลัก (มีรหัสอ้างอิงถาวร ลิงก์ตรงได้ด้วย `#รหัส`)

### คณิตศาสตร์

- **F3** อนุกรมรูปตรีโกณ: \(x(t) = a_0 + \sum_{n=1}^{\infty}\big[a_n\cos n\omega_0 t + b_n\sin n\omega_0 t\big]\)
- **T6** สูตรออยเลอร์–ฟูเรียร์: \(a_0 = \frac{1}{T}\int_T x\,dt,\; a_n = \frac{2}{T}\int_T x\cos n\omega_0 t\,dt,\; b_n = \frac{2}{T}\int_T x\sin n\omega_0 t\,dt\)
- **S1/S2/S4/S5** สมมาตร: คู่ → \(b_n = 0\); คี่ → \(a_0 = a_n = 0\); ครึ่งคลื่น \(x(t + T/2) = -x(t)\) → เหลือแต่ \(n\) คี่; เสี้ยวคลื่น (ครึ่งคลื่น + คี่) → \(b_n = \frac{4}{\pi}\int_0^{\pi/2} x(\theta)\sin n\theta\,d\theta\)
- **C2/C4** เชิงซ้อน: \(x(t) = \sum c_n e^{jn\omega_0 t}\), \(c_n = \frac{1}{T}\int_T x e^{-jn\omega_0 t}dt\), \(c_n = (a_n - jb_n)/2\), \(|c_n| = A_n/2\)
- **C7** พัลส์ดิวตี้ D: \(A_n = 2AD\,|\mathrm{sinc}(nD)|\) — ฮาร์มอนิกที่ \(n = k/D\) หายไป
- **C9 / S6** เลื่อนเวลา: ขนาดเท่าเดิม เฟสเลื่อน \(-n\omega_0 t_0\)
- **P2** ที่จุดกระโดด อนุกรมลู่เข้าค่าเฉลี่ยของสองฝั่ง
- **P3** กิบส์: ยอดเกิน → \(0.0895\Delta\) (ราว 9 % ของขนาดการกระโดด) ไม่หายแม้ \(N \to \infty\)
- **P5/P6** พาร์เซวาล: \(\frac1T\int_T x^2dt = a_0^2 + \sum A_n^2/2\), \(X_{rms} = \sqrt{X_0^2 + X_1^2 + \cdots}\)
- **P7** \(\mathrm{THD} = \sqrt{X_{rms}^2 - X_0^2 - X_1^2}/X_1\)
- **P8** มีรอยกระโดด → \(1/n\) (−20 dB/dec); มุมหัก → \(1/n^2\) (−40); อนุพันธ์แรกต่อเนื่อง → \(1/n^3\) (−60)
- **P10** แบนด์วิดท์จากเวลาขาขึ้น \(f_{BW} \approx 0.35/t_r\)

### วงจรและกำลังไฟฟ้า

- **A2** \(\mathbf Y_n = H(jn\omega_0)\mathbf X_n\), DC: \(Y_0 = H(0)a_0\); **A4** \(Z_L(n) = jnX_{L1}\), \(Z_C(n) = X_{C1}/(jn)\)
- **A9 / H4** \(P = V_0I_0 + \sum V_nI_n\cos(\theta_{v,n} - \theta_{i,n})\) — แรงดันกับกระแสต่างความถี่ไม่ทำกำลังเฉลี่ย
- **H1** \(I_{rms} = I_1\sqrt{1 + \mathrm{THD}_i^2}\)
- **H2** \(\mathrm{THD}_F = \sqrt{\sum_{h=2}^{50}I_h^2}/I_1\), \(\mathrm{THD}_R = \mathrm{THD}_F/\sqrt{1 + \mathrm{THD}_F^2}\), \(\mathrm{TDD} = \sqrt{\sum I_h^2}/I_L\)
- **H3** crest factor \(I_{peak}/I_{rms}\); มิเตอร์แบบเฉลี่ยอ่าน \(1.111\times\overline{|i|}\) → ผิดเมื่อไม่ใช่ไซน์ ต้องใช้ True RMS
- **H6** \(Q_1 = V_1I_1\sin\varphi_1\), \(D = \sqrt{S^2 - P^2 - Q_1^2}\), \(S^2 = P^2 + Q_1^2 + D^2\)
- **H7** \(\mathrm{PF} = \cos\varphi_1 \times I_1/I_{rms} = \mathrm{DPF}/\sqrt{1 + \mathrm{THD}_i^2}\) (แรงดันเป็นไซน์)
- **H9** K-factor \(= \sum (I_h/I_{rms})^2h^2\)
- **H10** ลำดับเฟส: \(h = 3k+1\) บวก, \(3k+2\) ลบ, \(3k\) ศูนย์ → \(I_N = 3\sqrt{I_3^2 + I_9^2 + \cdots}\) (โหลดสมดุล)
- **H11** แรงดันฮาร์มอนิกที่ PCC \(V_h \approx I_h\,hX_s\), \(\frac{V_h}{V_1} \approx \frac{I_h}{I_L}\cdot\frac{h}{I_{sc}/I_L}\)

### อิเล็กทรอนิกส์กำลัง

- **R1/R2** บริดจ์ 1 เฟส: \(V_{d0} = 0.900V\); กระแส AC (โหลด L ใหญ่) \(I_1 = 0.900I_d\), \(I_h = I_1/h\)
- **R4/R5** บริดจ์ + C: \(\Delta V \approx I_{dc}/(2fC)\), มุมนำกระแสแคบ → กระแสยอดสูง
- **R6** ตัวแปลง p พัลส์: ด้าน AC \(h = kp \pm 1\), ด้าน DC \(h = kp\)
- **R7/R8** 6 พัลส์: \(I_1 = 0.780I_d\), \(I_{rms} = 0.816I_d\), \(V_{d0} = 1.35V_{LL}\)
- **R9/R10** ช่วงทับซ้อน \(\cos\alpha - \cos(\alpha + \mu) = \frac{2X_sI_d}{\sqrt2V_{LL}}\); \(V_d = 1.35V_{LL}\cos\alpha - \frac3\pi X_sI_d\); DPF ≈ \(\cos(\alpha + \mu/2)\)
- **R11/R12** 12 พัลส์หักล้าง 5, 7, 17, 19 …; THD อุดมคติ 6/12/18/24 พัลส์ = 31.1 / 15.2 / 10.1 / 7.6 %
- **V1** อินเวอร์เตอร์สี่เหลี่ยมเต็มบริดจ์ \(V_n = 4V_{dc}/(n\pi)\), \(V_{1,rms} = 0.900V_{dc}\)
- **V2** quasi-square \(V_n = \frac{4V_{dc}}{n\pi}\cos n\alpha\) — α = 90°/n กำจัดฮาร์มอนิกที่ n
- **V3** six-step \(V_{LL1,rms} = 0.780V_{dc}\), \(h = 6k \pm 1\)
- **V5/V6** SPWM: \(m_a = \hat v_{ref}/\hat v_{tri}\), \(m_f = f_s/f_1\), \(\hat V_1 = m_aV_{dc}/2\) (ครึ่งบริดจ์); ฮาร์มอนิกอยู่ที่ \(h = jm_f \pm k\) — ยูนิโพลาร์เหลือเฉพาะกลุ่ม \(2m_f \pm 1, \pm3\)
- **V10** WTHD \(= \sqrt{\sum (V_h/h)^2}/V_1\) (ใช้ประเมินกระแสฮาร์มอนิกในโหลดเหนี่ยวนำ)
- **B1** โหนดสวิตช์บั๊ก \(v_{sw} = DV_{in} + \sum \frac{2V_{in}}{n\pi}\sin(n\pi D)\cos(n\omega_st - n\pi D)\)
- **B3/B4** ริปเปิล: ประมาณจากฮาร์มอนิกแรก \(\Delta V_{pp} \approx 2\cdot\frac{2V_{in}}{\pi}\sin(\pi D)(f_0/f_s)^2\) เทียบสูตรจริง \(\Delta V_{pp} = \frac{(1-D)V_o}{8LCf_s^2}\) (ตัวอย่าง 12 V → 5 V, 50 kHz, 100 µH, 100 µF: 14.96 mV เทียบ 14.6 mV)
- **B9** เอนเวโลป EMI ของคางหมู: แบนถึง \(1/(\pi\tau)\), −20 dB/dec ถึง \(1/(\pi t_r)\), แล้ว −40 dB/dec
- **M1** รีแอกเตอร์ \(X_r = \frac{\%Z}{100}\cdot\frac{V_{ph}}{I_{rated}}\)
- **M2/M3** เรโซแนนซ์ขนาน \(h_r = \sqrt{S_{sc}/Q_c}\); ตัวคูณการขยาย ≈ \(1/|1 - (h/h_r)^2|\)
- **M4** ดีจูน \(p = X_L/X_C\), \(h_t = 1/\sqrt p\) (7 % → 3.78 = 189 Hz, 14 % → 2.67), \(V_C = V/(1-p)\)
- **M5/M6** ฟิลเตอร์จูนเดี่ยว \(X_L = X_C/h_t^2\), \(R = h_tX_L/Q_f\); กระแสแบ่งระหว่างฟิลเตอร์กับระบบตามอิมพีแดนซ์
- **M7** ฟิลเตอร์แอกทีฟ \(i_{AF} = -\sum_{h\ge2} i_h\), พิกัด \(\gtrsim I_1\cdot\mathrm{THD}_i\)

### การวัด

- **D1/D2** DFT \(X[k] = \sum x[n]e^{-j2\pi kn/N}\); ฮาร์มอนิกที่ h อยู่ช่อง \(k = mh\) เมื่อหน้าต่างครอบ m คาบ, \(A_h = 2|X[mh]|/N\)
- **D3** \(\Delta f = f_s/N = 1/T_w\); **D7** เครื่องวิเคราะห์ทั่วไป: \(f_s = 10.24\) kHz, N = 2048 → 200 ms = 10 คาบ, Δf = 5 Hz
- **D5** อเลียสซิง: ฮาร์มอนิกเกิน \(N/2\) พับลงมาทับช่องอื่น; **D6** หน้าต่างไม่ครอบคาบเต็ม → รั่ว ใช้ Hann ลดการรั่ว
- **D10** Goertzel: \(s[n] = x[n] + 2\cos\omega_k s[n-1] - s[n-2]\) — คำนวณฮาร์มอนิกเฉพาะตัวบน MCU ได้ถูกกว่า FFT

| ไดรฟ์ไม่ผ่านเกณฑ์การไฟฟ้า | TDD เกินตาม Isc/IL | H13, M1 · `#preset=vfd-reactor` |
| แรงดันเพี้ยนเมื่อจ่ายจากเครื่องกำเนิด/UPS | อิมพีแดนซ์ต้นทางสูง | H11 |
| มิเตอร์อ่านกระแสต่ำกว่าจริง | มิเตอร์แบบเฉลี่ย ไม่ใช่ True RMS | H3 |
| FFT บนสโคปไม่ตรงเครื่องวัด | คาบไม่เต็ม หน้าต่าง สเกล dB | D6, D9 |
| มอเตอร์ที่ใช้ไดรฟ์ร้อน มีเสียงหวีด | ไซด์แบนด์รอบความถี่สวิตชิ่ง | V6, V10 |
| บอร์ดสวิตชิ่งไม่ผ่าน EMI | ขอบชันเกิน | B9 · `#preset=trapezoid` |
| ริปเปิลบั๊กสูงกว่าที่คำนวณ | ESR ของตัวเก็บประจุ | B4, B5 · `#preset=lc-buck` |

## 9. คำค้นและชื่อเรียกที่หมายถึงเรื่องเดียวกัน

อนุกรมฟูเรียร์ = อนุกรมฟูริเยร์ = ฟูรีเย = Fourier series · ฮาร์มอนิก = harmonics = หาร์มอนิก · ฮาร์มอนิกหลัก = fundamental · ความเพี้ยนฮาร์มอนิกรวม = total harmonic distortion (THD) · ความเพี้ยนต่อความต้องการรวม = total demand distortion (TDD) · ตัวประกอบกำลัง = เพาเวอร์แฟกเตอร์ = power factor (PF) · ตัวประกอบกำลังเชิงการกระจัด = displacement power factor (DPF) = cos φ₁ · กำลังความเพี้ยน = distortion power (D) · จุดต่อร่วม = point of common coupling (PCC) · วงจรเรียงกระแส = เรกติไฟเออร์ = rectifier · อินเวอร์เตอร์ = inverter · มอดูเลชันความกว้างพัลส์แบบไซน์ = SPWM · การกำจัดฮาร์มอนิกแบบเลือก = selective harmonic elimination (SHE) · คาปาซิเตอร์ดีจูน = detuned capacitor bank · ฟิลเตอร์จูน = single-tuned / passive harmonic filter · ฟิลเตอร์แอกทีฟ = active harmonic filter (AHF) · การแปลงฟูเรียร์แบบไม่ต่อเนื่อง = DFT · การแปลงฟูเรียร์แบบเร็ว = FFT · ปรากฏการณ์กิบส์ = Gibbs phenomenon · ทฤษฎีบทพาร์เซวาล = Parseval's theorem

## 10. คำถามที่พบบ่อย

**อนุกรมฟูเรียร์คืออะไรในหนึ่งประโยค?** การเขียนสัญญาณที่ซ้ำรูปเดิมทุกคาบ T เป็นผลรวมของค่าคงตัว (DC) กับไซน์และโคไซน์ที่ความถี่เป็นจำนวนเต็มเท่าของ \(f_0 = 1/T\) แต่ละตัวเรียกว่าฮาร์มอนิก

**ฮาร์มอนิกที่ 3 ของไฟ 50 Hz คือความถี่อะไร?** 150 Hz (ที่ 5 = 250 Hz, ที่ 7 = 350 Hz) ระบบ 60 Hz ฮาร์มอนิกที่ 3 อยู่ที่ 180 Hz

**อนุกรมฟูเรียร์ต่างจากการแปลงฟูเรียร์และลาปลาซอย่างไร?** อนุกรมใช้กับสัญญาณคาบ ได้สเปกตรัมเส้นที่ \(nf_0\); การแปลงฟูเรียร์ใช้กับสัญญาณไม่เป็นคาบ ได้สเปกตรัมต่อเนื่อง; ลาปลาซใช้ \(s = \sigma + j\omega\) เหมาะกับผลตอบสนองชั่วครู่ งานฮาร์มอนิกในสถานะคงตัวจึงใช้อนุกรมฟูเรียร์

**ทำไมคาปาซิเตอร์แก้ PF ไม่ได้เมื่อโหลดเป็น SMPS หรือไดรฟ์?** เพราะ PF ต่ำมาจากความเพี้ยน (D) ไม่ใช่การเลื่อนเฟส คาปาซิเตอร์ชดเชยได้แค่ Q₁ และยังอาจเรโซแนนซ์กับระบบจนขยายฮาร์มอนิก ต้องลดฮาร์มอนิกด้วยรีแอกเตอร์ ฟิลเตอร์ หรือ PFC

**ทำไมกระแสนิวทรัลของอาคารที่มีคอมพิวเตอร์มากจึงสูง?** ฮาร์มอนิกที่ 3, 9, 15 ของสามเฟสเป็นลำดับศูนย์ อยู่ในเฟสเดียวกันจึงบวกกันในนิวทรัล ได้สูงถึงราว 1.7 เท่าของกระแสเฟสเมื่อโหลดเป็น SMPS ล้วน

**ต้องรวมกี่ฮาร์มอนิกในงานจริง?** มาตรฐานคุณภาพไฟฟ้านับถึง h = 50 (2.5 kHz ที่ 50 Hz); งานคอนเวอร์เตอร์ดูถึงหลายเท่าของความถี่สวิตชิ่ง; งาน EMI ใช้เอนเวโลปแทนการรวมทีละตัว

**ไม่มีเครื่องวิเคราะห์คุณภาพไฟฟ้าจะฝึกได้อย่างไร?** ใช้แล็บ 12.14 ซึ่งมีสโคปและเครื่องวิเคราะห์กำลังเสมือน วัดโหลด 10 แบบ ลองวิธีแก้ และอ่านการแปลผลอัตโนมัติ พร้อมใบงาน 16 ชุด
