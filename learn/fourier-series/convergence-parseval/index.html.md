# การลู่เข้า ปรากฏการณ์กิบส์ ทฤษฎีบทพาร์เซวาล และอัตราลดของฮาร์มอนิก

// บทที่ 14.5 · อนุกรมฟูเรียร์ · Convergence, Gibbs & Parseval


อนุกรมฟูเรียร์เป็นผลรวมไม่รู้จบ แต่งานจริงรวมได้แค่จำนวนจำกัด หน้านี้ตอบว่ารวมแค่ N ตัวแล้วผิดไปเท่าไร ตรงไหนผิดมากที่สุด และพลังงานกระจายอยู่ในฮาร์มอนิกอย่างไร คำตอบสุดท้ายคือทฤษฎีบทพาร์เซวาล ซึ่งเป็นฐานของนิยาม RMS และ THD ที่เครื่องวัดทุกเครื่องใช้

สรุปใน 30 วินาที

- ที่รอยกระโดด อนุกรมให้ค่ากึ่งกลาง ใกล้ ๆ รอยกระโดดพุ่งเกิน 8.95 % ของขนาดกระโดดเสมอ (กิบส์)

- พาร์เซวาล: $X_{rms}^2 = a_0^2 + \sum A_n^2/2$ → $X_{rms} = \sqrt{X_0^2 + X_1^2 + X_2^2 + \cdots}$ (ใช้ RMS ของแต่ละตัว)

- THD = $\sqrt{X_{rms}^2 - X_0^2 - X_1^2}\,/\,X_1$ · สี่เหลี่ยม 48.3 % สามเหลี่ยม 12.1 %

- มีรอยกระโดด → ลดตาม 1/n · มุมหัก → 1/n² · อนุพันธ์ต่อเนื่อง → 1/n³

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## อนุกรมลู่เข้าเมื่อไร: เงื่อนไขของดีริชเลต์ กลาง

P1 Dirichlet conditions เงื่อนไขของดีริชเลต์

$$\int_T |x(t)|\,dt \lt \infty,\quad \text{ในหนึ่งคาบมีจุดสูงสุด/ต่ำสุดจำกัด และรอยกระโดดจำกัด (แต่ละรอยมีขนาดจำกัด)}$$

สัญญาณไฟฟ้าจริงทุกตัวผ่านเงื่อนไขนี้ เป็นเงื่อนไขพอเพียง (ไม่จำเป็น) ฟังก์ชันประหลาดทางคณิตศาสตร์บางตัวเท่านั้นที่ไม่ผ่าน

P2 What the series converges to ผลรวมลู่เข้าสู่อะไร

$$\lim_{N\to\infty}\Big[a_0 + \sum_{n=1}^{N}(a_n\cos n\omega_0 t + b_n\sin n\omega_0 t)\Big] = \begin{cases} x(t) & \text{จุดที่ต่อเนื่อง} \\[2pt] \tfrac12\big[x(t^-) + x(t^+)\big] & \text{จุดกระโดด} \end{cases}$$

ถ้า x ต่อเนื่องทุกจุดและเป็นคาบ อนุกรมลู่เข้าแบบเอกรูป (ผิดไม่เกินค่าหนึ่งทุกจุดพร้อมกัน) ถ้ามีรอยกระโดด ลู่เข้ารายจุดเท่านั้น ใกล้รอยกระโดดยังผิดมากเสมอ (ดูกิบส์)

## ปรากฏการณ์กิบส์: ยอดเกิน 9 % ที่ไม่ยอมหาย กลาง

ลองรวมอนุกรมของสี่เหลี่ยมให้มากขึ้นเรื่อย ๆ ส่วนกลางเรียบขึ้น มุมคมขึ้น แต่ข้างรอยกระโดดมี “หู” แหลมขึ้นไปเกินค่าจริงเสมอ หูนี้แคบลงและเข้าใกล้รอยกระโดดตามจำนวนพจน์ แต่ความสูงไม่ลดลงเลย ค้นพบโดย Wilbraham (1848) และอธิบายโดย Gibbs (1899)

P3 Gibbs overshoot ขนาดและตำแหน่งของหูกิบส์

$$\text{overshoot} \to \Big(\frac{1}{\pi}\mathrm{Si}(\pi) - \frac12\Big)\Delta = 0.0895\,\Delta, \qquad t_{peak} \approx \frac{T}{2(N+1)} \text{ จากรอยกระโดด}$$

$\Delta$ คือขนาดรอยกระโดด $\mathrm{Si}(\pi) = \int_0^\pi \frac{\sin u}{u}du = 1.8519$ · สี่เหลี่ยม ±1 (Δ = 2) จึงพุ่งถึง 1.179 ไม่ว่า N จะมากเท่าไร

P4 Lanczos σ-factors ลดหูกิบส์ด้วยการถ่วงน้ำหนัก

$$x_N^{\sigma}(t) = a_0 + \sum_{n=1}^{N} \mathrm{sinc}\!\Big(\frac{n}{N+1}\Big)\big[a_n\cos n\omega_0 t + b_n\sin n\omega_0 t\big]$$

ค่อย ๆ ลดน้ำหนักฮาร์มอนิกสูงแทนการตัดทิ้งทันที หูเหลือราว 1 % แลกกับขอบที่มนลง หลักการเดียวกับ “หน้าต่าง” ใน FFT และการออกแบบตัวกรอง FIR ลองติ๊ก “ลดหูกิบส์ (σ)” ในแล็บ

ผลรวมอนุกรมของสี่เหลี่ยม ±1 ถึงฮาร์มอนิกที่ 9 (สีฟ้า) และ 49 (สีส้ม) หูยังสูงราว 1.18 เท่ากัน แค่แคบลง เส้นประบน 1.179 คือขีดจำกัดของกิบส์

ตัวอย่าง P-1 · หูกิบส์ของสี่เหลี่ยม

### สี่เหลี่ยม ±1 V รวมถึงฮาร์มอนิกที่ 9 และที่ 99 ค่าสูงสุดของผลรวมเท่าไร และอยู่ห่างจากรอยกระโดดเท่าไร

- P3 ทำนาย: $1 + 0.0895 \times 2 = 1.179$ V ตำแหน่ง $T/(2 \times 10) = 0.05T$ และ $T/200 = 0.005T$

- คำนวณจริงด้วยตัวเลข: N = 9 ได้ยอด 1.1823 V ที่ $0.050T$ · N = 99 ได้ 1.1790 V ที่ $0.005T$

ยอดเกินเกือบ 18 % ของแอมพลิจูด (9 % ของ Δ) ทั้งสองกรณี ต่างกันแค่ความกว้าง นี่คือเหตุผลที่ตัวกรองผ่านต่ำแบบ “brick-wall” ทำให้ขอบสี่เหลี่ยมมีการแกว่งราว 9 % เสมอ

## ทฤษฎีบทพาร์เซวาล: กำลังรวม = ผลรวมกำลังของแต่ละฮาร์มอนิก พื้นฐาน

ยกกำลังสองอนุกรมแล้วเฉลี่ยตลอดคาบ ผลคูณไขว้ของฮาร์มอนิกต่างความถี่หายหมดตามความตั้งฉาก (T1–T3) เหลือแค่กำลังสองของแต่ละตัว นี่แปลว่าฮาร์มอนิกแต่ละตัวส่งกำลังเข้าตัวต้านทานแยกกันโดยไม่รบกวนกัน

P5 Parseval's theorem ทฤษฎีบทพาร์เซวาล

$$\frac{1}{T}\int_T x^2(t)\,dt = a_0^2 + \frac12\sum_{n=1}^{\infty}\big(a_n^2 + b_n^2\big) = a_0^2 + \sum_{n=1}^{\infty}\frac{A_n^2}{2} = \sum_{n=-\infty}^{\infty}|c_n|^2$$

P6 RMS from harmonic RMS values RMS จากค่า RMS ของแต่ละตัว

$$X_{rms} = \sqrt{X_0^2 + X_1^2 + X_2^2 + X_3^2 + \cdots}, \qquad X_n = \frac{A_n}{\sqrt2}$$

DC ใช้ค่าเต็ม ฮาร์มอนิกใช้ค่า RMS ของตัวเอง ไม่ใช่ผลรวมตรง ๆ แบบเลขคณิต

P7 THD and power in the fundamental THD จากพาร์เซวาล

$$\mathrm{THD} = \frac{\sqrt{X_{rms}^2 - X_0^2 - X_1^2}}{X_1}, \qquad \frac{X_1^2}{X_{rms}^2} = \frac{1}{1 + \mathrm{THD}^2} \;(X_0 = 0)$$

ใช้ RMS ทั้งก้อนแทนการบวกฮาร์มอนิกทีละตัว จึงหา THD แบบแม่นยำของรูปคลื่นในตารางได้ด้วยอินทิกรัลตัวเดียว

ตัวอย่าง P-2 · THD ของสี่เหลี่ยมแบบแม่นยำ

### สี่เหลี่ยม ±A มีกำลังในฮาร์มอนิกหลักกี่ % และ THD เท่าไร ถ้ารวมถึงฮาร์มอนิกที่ 5, 9, 49 ได้กำลังกี่ %

- $X_{rms} = A$ (สี่เหลี่ยมยกกำลังสองได้ $A^2$ ตลอด) · $X_1 = \frac{4A}{\pi\sqrt2} = 0.9003A$

- สัดส่วนกำลัง $X_1^2/X_{rms}^2 = 8/\pi^2 = 81.06$ %

- P7: $\mathrm{THD} = \sqrt{1/0.8106 - 1} = \sqrt{\pi^2/8 - 1} = 48.34$ %

- สะสม $\frac{8}{\pi^2}\sum_{n\,\text{คี่} \le N}\frac{1}{n^2}$: ถึง 5 → 93.31 % · ถึง 9 → 95.96 % · ถึง 49 → 99.19 %

ฮาร์มอนิกหลัก 81.1 % ของกำลัง THD 48.3 % · ต้องรวมถึงฮาร์มอนิกที่ 49 จึงได้ 99 % นี่คือเหตุผลที่เครื่องวิเคราะห์อ่าน THD ได้ราว 47–48 % จากสี่เหลี่ยม (นับถึงลำดับ 40 หรือ 50) ไม่ถึง 48.3 % พอดี

ตัวอย่าง P-3 · แรงดันไฟเพี้ยนเล็กน้อย

### แรงดันในอาคาร: ฮาร์มอนิกหลัก 230 V, ที่ 5 = 11.5 V, ที่ 7 = 6.9 V, ที่ 11 = 4.6 V (RMS) หา $V_{rms}$ และ THD

- P6: $V_{rms} = \sqrt{230^2 + 11.5^2 + 6.9^2 + 4.6^2} = 230.44$ V

- THD $= \sqrt{11.5^2 + 6.9^2 + 4.6^2}/230 = \sqrt{5^2 + 3^2 + 2^2}\,\% = 6.16$ %

THD 6.2 % (เกินเกณฑ์ กฟภ. 5 % ที่ 0.4 kV) แต่ RMS เพิ่มขึ้นแค่ 0.19 % มิเตอร์จึงแทบไม่เห็นความเปลี่ยนแปลง ต้องดูที่สเปกตรัม ดูขีดจำกัด

ตัวอย่าง P-4 · ผลพลอยได้ทางคณิตศาสตร์

### ใช้พาร์เซวาลกับฟันเลื่อย $x = t$ บน $-\pi \lt t \lt \pi$ หาค่า $\sum_{n=1}^{\infty} 1/n^2$

- จาก S-5: $b_n = 2(-1)^{n+1}/n$

- ซ้าย: $\frac{1}{2\pi}\int_{-\pi}^{\pi}t^2dt = \frac{\pi^2}{3}$ · ขวา: $\frac12\sum\frac{4}{n^2} = 2\sum\frac{1}{n^2}$

$\sum 1/n^2 = \pi^2/6$ (ปัญหาบาเซิล) ทำแบบเดียวกันกับสามเหลี่ยมได้ $\sum_{n\,\text{คี่}} 1/n^4 = \pi^4/96$

## ความเรียบกำหนดอัตราลดของฮาร์มอนิก กลาง

ดูรูปคลื่นแล้วบอกความชันของสเปกตรัมบนกราฟ log–log ได้ทันที ยิ่งรูปเรียบ ฮาร์มอนิกสูงยิ่งน้อย ข้อนี้ใช้ออกแบบ EMI (ทำขอบให้ช้าลง) และอธิบายว่าทำไมแรงดันอินเวอร์เตอร์ที่มีขอบคมต้องใช้ฟิลเตอร์

P8 Smoothness ↔ decay ความเรียบกับอัตราลด

$$\text{มีรอยกระโดด: } A_n \sim \frac{1}{n}\;(-20\ \text{dB/dec}) \quad \text{มุมหัก: } \frac{1}{n^2}\;(-40) \quad \text{อนุพันธ์แรกต่อเนื่อง: } \frac{1}{n^3}\;(-60)$$

เหตุผล: ดิฟหนึ่งครั้งคูณสัมประสิทธิ์ด้วย n (C10) รูปที่ต้องดิฟ k ครั้งจึงจะเกิดรอยกระโดด มีสัมประสิทธิ์ลดตาม $1/n^{k+1}$

แอมพลิจูดเป็น dB เทียบลำดับ n แบบลอการิทึม: สี่เหลี่ยม (1/n) สามเหลี่ยม (1/n²) และพาราโบลาต่อกัน $t(\pi - t)$ ขยายแบบคี่ (1/n³) ความชัน −20, −40, −60 dB ต่อดีเคด

| รูปคลื่น | ลักษณะที่ “ไม่เรียบ” | อัตราลด | ผลในงานจริง |

| สี่เหลี่ยม พัลส์ PWM ฟันเลื่อย | รอยกระโดด | 1/n | EMI สูง ต้องฟิลเตอร์ |

| สามเหลี่ยม ไซน์เรียงกระแส กระแสตัวเหนี่ยวนำ | มุมหัก | 1/n² | ฮาร์มอนิกสูงน้อย ริปเปิลเกือบเป็นไซน์ |

| พัลส์คางหมู (มีเวลาขาขึ้น) | รอยกระโดดถูกทำให้เป็นมุม | 1/n แล้ว 1/n² | หักมุมที่ $f = 1/(\pi t_r)$ B9 |

| ไซน์บริสุทธิ์ | เรียบทุกอันดับ | ไม่มีฮาร์มอนิก | อุดมคติ |

## อินทิเกรตและดิฟอนุกรมทีละพจน์ ขั้นสูง

P9 Term-by-term operations เมื่อไรทำได้

$$\int x\,dt:\ \text{ทำได้เสมอ (ถ้า } a_0 = 0\text{) ลู่เข้าดีขึ้น} \qquad \frac{dx}{dt}:\ \text{ทำได้เมื่อ } x \text{ ต่อเนื่องและ } x' \text{ ผ่านดีริชเลต์}$$

ดิฟอนุกรมของสี่เหลี่ยมทีละพจน์ได้ $\frac{4A\omega_0}{\pi}\sum\cos n\omega_0 t$ ซึ่งไม่ลู่เข้าแบบปกติ เพราะอนุพันธ์จริงคือขบวนอิมพัลส์ (C-3)

## ในงานจริงต้องรวมกี่ฮาร์มอนิก กลาง

P10 Bandwidth from rise time แบนด์วิดท์ที่ต้องใช้

$$f_{BW} \approx \frac{0.35}{t_r}$$

สัญญาณที่มีเวลาขาขึ้น $t_r$ มีพลังงานสำคัญถึงราว $0.35/t_r$ ใช้เลือกแบนด์วิดท์สโคป (O8) และจำนวนฮาร์มอนิกที่ต้องจำลอง

| งาน | ดูถึง | ที่มา |

| คุณภาพไฟฟ้า (THD, IEEE 519) | ลำดับที่ 50 (2.5 kHz ที่ 50 Hz) | IEEE 519-2022, IEC 61000-4-7 · เครื่อง Class S ใช้ถึง 40 |

| เครื่องใช้ไฟฟ้า ≤ 16 A | ลำดับที่ 40 | IEC 61000-3-2 |

| อินเวอร์เตอร์ PWM | อย่างน้อย 2–3 เท่าของ $m_f$ | ไซด์แบนด์อยู่รอบ $m_f$, $2m_f$, $3m_f$ V6 |

| เสียง (THD+N) | 20 kHz | ขอบการได้ยิน |

| EMI นำทาง (conducted) | 150 kHz – 30 MHz | มาตรฐานตระกูล CISPR |

## แล็บ: กิบส์และพาร์เซวาล พื้นฐาน

เปิดค่าเริ่มต้น N = 99 แล้วดูหูกิบส์ อ่าน “หูกิบส์” ในแผงข้างล่าง (≈ 9 % ของ p-p) ติ๊ก “ลดหูกิบส์ (σ)” เพื่อดูผล P4 และเลื่อน N ลงแล้วดู “กำลังที่รวมแล้ว” เทียบกับตัวอย่าง P-2

เมื่อรวมอนุกรมฟูเรียร์ถึงจำนวนพจน์จำกัด ใกล้รอยกระโดดจะมียอดพุ่งเกินประมาณ 8.95 % ของขนาดรอยกระโดด เพิ่มพจน์เท่าไรยอดก็ไม่เตี้ยลง แค่แคบลงและเข้าใกล้รอยกระโดดมากขึ้น เป็นเหตุให้ตัวกรองที่ตัดความถี่คมเกิดการแกว่ง (ringing)

ทฤษฎีบทพาร์เซวาลใช้ทำอะไรในงานไฟฟ้า?
ใช้หาค่า RMS จากค่า RMS ของแต่ละฮาร์มอนิก $V_{rms} = \sqrt{V_0^2 + V_1^2 + V_2^2 + \cdots}$ ซึ่งเป็นวิธีที่เครื่องวิเคราะห์กำลังใช้ และใช้นิยาม THD ว่าเป็นสัดส่วน RMS ของฮาร์มอนิกทั้งหมดเทียบกับฮาร์มอนิกหลัก

ทำไมสามเหลี่ยมลู่เข้าเร็วกว่าสี่เหลี่ยม?
ความเรียบกำหนดอัตราลด รูปที่มีรอยกระโดด (สี่เหลี่ยม) ลดตาม 1/n หรือ −20 dB/decade รูปที่ต่อเนื่องแต่มุมหัก (สามเหลี่ยม) ลดตาม 1/n² หรือ −40 dB/decade รูปที่อนุพันธ์แรกต่อเนื่องลดตาม 1/n³

วัดฮาร์มอนิกถึงลำดับที่เท่าไรจึงพอ?
งานคุณภาพไฟฟ้าตามมาตรฐาน IEEE 519 และ IEC 61000-4-7 ใช้ถึงลำดับที่ 50 (2.5 kHz ที่ 50 Hz) งานอินเวอร์เตอร์ PWM ต้องดูถึงอย่างน้อยสองถึงสามเท่าของความถี่สวิตชิ่ง งาน EMI ดูถึงหลายสิบ MHz ตามเวลาขาขึ้นของสัญญาณ
