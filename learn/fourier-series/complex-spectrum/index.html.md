# รูปเชิงซ้อน สเปกตรัมขนาด–เฟส และสมบัติของอนุกรมฟูเรียร์

// บทที่ 12.4 · อนุกรมฟูเรียร์ · Complex Form & Spectrum


สามสูตรของ $a_0$, $a_n$, $b_n$ รวมเป็นสูตรเดียวได้ด้วยเลขชี้กำลังเชิงซ้อน รูปนี้คือภาษาของ FFT การแปลงฟูเรียร์ และการวิเคราะห์วงจรด้วยเฟเซอร์ เมื่อเข้าใจแล้วจะอ่านสเปกตรัมบนจอเครื่องวัดได้ถูก และใช้สมบัติไม่กี่ข้อหาอนุกรมของรูปใหม่ได้โดยไม่ต้องอินทิเกรต

สรุปใน 30 วินาที

- $x(t) = \sum_{n=-\infty}^{\infty} c_n e^{jn\omega_0 t}$, $c_n = \frac{1}{T}\int_T x(t)e^{-jn\omega_0 t}dt$

- $c_n = \tfrac12(a_n - jb_n)$, $c_{-n} = c_n^*$, $A_n = 2|c_n|$, $\varphi_n = \angle c_n$

- พัลส์ดิวตี้ D: $|c_n| = AD|\mathrm{sinc}(nD)|$ ศูนย์ที่ $n = k/D$

- เลื่อน $t_0$: คูณ $e^{-jn\omega_0t_0}$ · อนุพันธ์: คูณ $jn\omega_0$ · ปริพันธ์: หาร $jn\omega_0$

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## จากสูตรออยเลอร์สู่อนุกรมเชิงซ้อน กลาง

โคไซน์หนึ่งตัวคือเฟเซอร์สองตัวหมุนสวนกัน ตัวหนึ่งที่ความถี่ $+\omega$ อีกตัวที่ $-\omega$ ส่วนจินตภาพหักกันพอดีเหลือค่าจริง เมื่อเขียนทุกฮาร์มอนิกแบบนี้ อนุกรมทั้งก้อนกลายเป็นผลรวมของเลขชี้กำลังเพียงชนิดเดียว ทบทวนสูตรออยเลอร์ที่หน้าตรีโกณมิติ

C1 Euler's formula สูตรออยเลอร์

$$e^{j\theta} = \cos\theta + j\sin\theta, \quad \cos\theta = \frac{e^{j\theta} + e^{-j\theta}}{2}, \quad \sin\theta = \frac{e^{j\theta} - e^{-j\theta}}{2j}$$

C2 Complex (exponential) Fourier series อนุกรมฟูเรียร์รูปเชิงซ้อน

$$x(t) = \sum_{n=-\infty}^{\infty} c_n\, e^{jn\omega_0 t}, \qquad c_n = \frac{1}{T}\int_{T} x(t)\, e^{-jn\omega_0 t}\, dt$$

สูตรเดียวใช้ได้ทุก n รวมทั้ง n = 0 ($c_0$ คือค่าเฉลี่ย) และ n ติดลบ ไม่ต้องแยก 1/T กับ 2/T

## ความสัมพันธ์ระหว่าง cₙ, aₙ, bₙ, Aₙ และ φₙ กลาง

C3 Amplitude–phase (cosine) form รูปแอมพลิจูด–เฟส

$$a_n\cos n\omega_0 t + b_n\sin n\omega_0 t = A_n\cos(n\omega_0 t + \varphi_n), \qquad A_n = \sqrt{a_n^2 + b_n^2}, \quad \varphi_n = \operatorname{atan2}(-b_n,\, a_n)$$

ใช้ atan2 (ดูเครื่องหมายทั้งสองตัว) ไม่ใช่ $\tan^{-1}(b/a)$ ธรรมดา ซึ่งผิดในจตุภาคที่ 2 และ 3 · ตัวอย่าง $b_n$ บวก $a_n = 0$ → $\varphi_n = -90^\circ$ คือ $\cos(\cdot - 90^\circ) = \sin(\cdot)$

C4 cₙ from aₙ, bₙ แปลงไปมา

$$c_0 = a_0,\quad c_n = \frac{a_n - jb_n}{2},\quad c_{-n} = c_n^*,\quad |c_n| = \frac{A_n}{2},\quad \angle c_n = \varphi_n$$

ย้อนกลับ: $a_n = 2\,\mathrm{Re}\,c_n$, $b_n = -2\,\mathrm{Im}\,c_n$

C5 Sine-referenced form รูปอ้างอิงไซน์ (นิยมในไฟฟ้ากำลัง)

$$A_n\sin(n\omega_0 t + \psi_n), \qquad \psi_n = \operatorname{atan2}(a_n,\, b_n) = \varphi_n + 90^\circ$$

เมื่อแรงดันเขียนเป็น $V_m\sin\omega t$ มุม $\psi_1$ ของกระแสคือมุมเฟสที่ใช้คำนวณ DPF โดยตรง

## สเปกตรัมขนาดและเฟส: ด้านเดียวกับสองด้าน กลาง

ตำราคณิตศาสตร์และการแปลงฟูเรียร์วาด $|c_n|$ ทั้งความถี่บวกและลบ (สมมาตรกัน) เครื่องวัดจริงแสดงด้านเดียว และส่วนใหญ่แสดงเป็นค่า RMS หรือ dB ต้องรู้ว่าจอแสดงแบบไหนก่อนอ่านตัวเลข

C6 Reading a spectrum อ่านสเปกตรัมให้ถูกชนิด

$$\text{สองด้าน: } |c_n| \qquad \text{ด้านเดียว (ค่ายอด): } A_n = 2|c_n| \qquad \text{ด้านเดียว (RMS): } \frac{A_n}{\sqrt2} = \sqrt2\,|c_n| \qquad L_n = 20\log_{10}\frac{A_n/\sqrt2}{1\ \text{V}}\ \text{dBV}$$

FFT บนออสซิลโลสโคปแสดงด้านเดียว หน่วย dBV (RMS) เครื่องวิเคราะห์กำลังแสดงด้านเดียวเป็น A หรือ V RMS หรือ % ของฮาร์มอนิกหลัก วิธีอ่าน FFT บนสโคป

คลื่นสี่เหลี่ยม ±1: สเปกตรัมสองด้าน $|c_n|$ (บน) แบ่งพลังงานครึ่งหนึ่งไปไว้ที่ความถี่ลบ สเปกตรัมด้านเดียว $A_n$ (ล่าง) คือสิ่งที่เครื่องวัดแสดง สูงเป็นสองเท่า

## พัลส์และเอนเวโลป sinc: ดิวตี้กำหนดรูปสเปกตรัม กลาง

พัลส์สี่เหลี่ยมเป็นรูปคลื่นที่สำคัญที่สุดในอิเล็กทรอนิกส์กำลังและดิจิทัล ทั้ง PWM นาฬิกาลอจิก และแรงดันโหนดสวิตช์ของบั๊กคอนเวอร์เตอร์ รูปเชิงซ้อนให้คำตอบในบรรทัดเดียว

C7 Pulse train: sinc envelope พัลส์สูง A ดิวตี้ D เริ่มที่ t = 0

$$c_n = \frac{1}{T}\int_0^{DT} A e^{-jn\omega_0 t}dt = AD\,\mathrm{sinc}(nD)\,e^{-j\pi nD}, \qquad \mathrm{sinc}(u) = \frac{\sin \pi u}{\pi u}, \qquad A_n = 2AD\,|\mathrm{sinc}(nD)|$$

เส้นสเปกตรัมห่างกัน $f_0 = 1/T$ แต่รูปเอนเวโลปขึ้นกับความกว้างพัลส์ $\tau = DT$ เท่านั้น ศูนย์แรกที่ $f = 1/\tau$ พัลส์ยิ่งแคบ สเปกตรัมยิ่งกว้างและแบน

แอมพลิจูดของพัลส์ D = 0.25 (บน) และ D = 0.1 (ล่าง) เส้นประคือเอนเวโลป $2AD|\mathrm{sinc}(f\tau)|$ แท่งที่ n = 4, 8 (บน) และ n = 10, 20 (ล่าง) หายไปเพราะตกที่ศูนย์ของ sinc

ตัวอย่าง C-1 · สเปกตรัมของ PWM

### สัญญาณ PWM 0–5 V ความถี่ 20 kHz ดิวตี้ 20 % หา DC แอมพลิจูดและมุมเฟสของฮาร์มอนิก 1–4 และบอกว่าความถี่ใดไม่มีพลังงาน

- $c_0 = AD = 1.00$ V (ถ้าต่อ RC กรองจะได้ DC 1 V)

- C7: $A_n = 2(5)(0.2)\,|\mathrm{sinc}(0.2n)|$, มุม $\varphi_n = -\pi nD = -36^\circ n$ (ตราบที่ sinc ยังเป็นบวก)

- ศูนย์ของ sinc ที่ $nD = 1, 2, \dots$ → n = 5, 10, 15 คือ 100, 200, 300 kHz

## สมบัติที่ใช้แก้โจทย์โดยไม่ต้องอินทิเกรต ขั้นสูง

ถ้า $x(t)$ มีสัมประสิทธิ์ $c_n$ แล้ว รูปที่ได้จากการบวก เลื่อน ดิฟ หรืออินทิเกรต $x(t)$ ก็มีสัมประสิทธิ์ที่หาได้ทันที

C8 Linearity ความเป็นเชิงเส้น

$$\alpha x(t) + \beta y(t) \;\leftrightarrow\; \alpha c_n + \beta d_n$$

รูปซับซ้อน = ผลรวมของรูปในตาราง สัมประสิทธิ์ก็บวกกันได้ตรง ๆ

C9 Time shift เลื่อนเวลา

$$x(t - t_0) \;\leftrightarrow\; c_n\,e^{-jn\omega_0 t_0}$$

ขนาดคงเดิม เฟสลดลง $n\omega_0 t_0$ (ใน S6 คือข้อนี้)

C10 Differentiation อนุพันธ์

$$\frac{dx}{dt} \;\leftrightarrow\; jn\omega_0\, c_n$$

ฮาร์มอนิกสูงถูกขยาย n เท่า ดิฟเฟอเรนชิเอเตอร์จึงขยายนอยส์ และขอบคมของสัญญาณให้สเปกตรัมกว้าง

C11 Integration (zero-mean x) ปริพันธ์

$$\int x\,dt \;\leftrightarrow\; \frac{c_n}{jn\omega_0},\quad n \ne 0$$

ต้องให้ $c_0 = 0$ ก่อน ไม่อย่างนั้นอินทิกรัลโตไม่จำกัด (ไม่เป็นคาบ) ค่าเฉลี่ยของผลลัพธ์กำหนดจากเงื่อนไขเริ่มต้นแยกต่างหาก

C12 Multiplication & modulation การคูณสัญญาณ

$$x(t)\,e^{jm\omega_0 t} \;\leftrightarrow\; c_{n-m}, \qquad x(t)\,y(t) \;\leftrightarrow\; \sum_{k} c_k\, d_{n-k}$$

คูณกับไซน์ = เลื่อนสเปกตรัมไปทั้งสองข้าง (เกิดไซด์แบนด์) อธิบายฮาร์มอนิกรอบความถี่สวิตชิ่งของ PWM และวงจรชอปเปอร์ V6

ตัวอย่าง C-2 · ออปแอมป์อินทิเกรเตอร์ทำสี่เหลี่ยมให้เป็นสามเหลี่ยม

### ป้อนสี่เหลี่ยม ±5 V 1 kHz เข้าอินทิเกรเตอร์ $v_o = -\frac{1}{RC}\int v_{in}dt$ ที่ $RC = 1$ ms หาแอมพลิจูดฮาร์มอนิกหลักของขาออก และเทียบกับค่ายอดของสามเหลี่ยม

- สี่เหลี่ยม: $A_1 = \frac{4(5)}{\pi} = 6.366$ V W1

- C11: แต่ละฮาร์มอนิกหารด้วย $n\omega_0 RC$ และเลื่อนเฟส (เครื่องหมายลบกับ $1/j$)

$$A_{1,out} = \frac{6.366}{(2\pi \cdot 1000)(0.001)} = \frac{6.366}{6.283} = 1.013\ \text{V}$$

- ในโดเมนเวลา: ครึ่งคาบ 0.5 ms ขาออกเปลี่ยน $\frac{1}{RC}(5)(0.5\text{ ms}) = 2.5$ V ยอดถึงยอด → สามเหลี่ยมยอด 1.25 V ซึ่งมีฮาร์มอนิกหลัก $\frac{8(1.25)}{\pi^2} = 1.013$ V ✓

ฮาร์มอนิกที่ n ของขาออกลดลงตาม $1/n^2$ (สี่เหลี่ยม 1/n หารด้วย n อีกครั้ง) ได้สามเหลี่ยมยอด 1.25 V ทดลองจริงได้ที่ แล็บออปแอมป์อินทิเกรเตอร์

ตัวอย่าง C-3 · ขบวนอิมพัลส์

### หาอนุกรมฟูเรียร์ของ $\delta_T(t) = \sum_k \delta(t - kT)$

- C2 อินทิเกรตช่วง $-T/2$ ถึง $T/2$ มีอิมพัลส์ตัวเดียวที่ t = 0: $c_n = \frac1T\int \delta(t)e^{-jn\omega_0 t}dt = \frac1T$

$\delta_T(t) = \frac{1}{T}\sum_n e^{jn\omega_0 t}$ ทุกฮาร์มอนิกเท่ากันหมด สเปกตรัมแบนราบ ข้อนี้คือหัวใจของการสุ่มสัญญาณ (sampling) และที่มาของอเลียสซิง 12.13

## เฟเซอร์ของแต่ละฮาร์มอนิก: สะพานสู่การวิเคราะห์วงจร กลาง

วงจร AC ที่เรียนมาใช้เฟเซอร์ที่ความถี่เดียว อนุกรมฟูเรียร์ทำให้สัญญาณที่ไม่ใช่ไซน์กลายเป็นปัญหาเฟเซอร์หลายปัญหา ความถี่ละหนึ่งปัญหา แต่ละปัญหาแก้ด้วยอิมพีแดนซ์ที่ความถี่นั้นแล้วนำมารวมกัน

C13 Harmonic phasor เฟเซอร์ของฮาร์มอนิกที่ n

$$x_n(t) = \mathrm{Re}\{\mathbf{X}_n e^{jn\omega_0 t}\},\qquad \mathbf{X}_n = a_n - jb_n = 2c_n = A_n\angle\varphi_n \;(\text{ยอด}),\qquad \mathbf{X}_{n,rms} = \mathbf{X}_n/\sqrt2$$

แล็บในชุดนี้ใช้นิยามนี้ทุกที่ ตัวอย่างการใช้ A2: $\mathbf{Y}_n = H(jn\omega_0)\mathbf{X}_n$

## แล็บ: ดูสเปกตรัมขนาดและเฟส พื้นฐาน

สลับปุ่มเหนือกราฟสเปกตรัมระหว่าง “แอมพลิจูด” “dB” และ “เฟส” เลื่อนดิวตี้ของพัลส์แล้วดูศูนย์ของ sinc ขยับ ลองพัลส์ 10 % ในโหมด dB จะเห็นเอนเวโลปชัดเจน

## คำถามที่พบบ่อย

cn กับ an bn สัมพันธ์กันอย่างไร?
$c_0 = a_0$, $c_n = (a_n - jb_n)/2$ และ $c_{-n} = c_n^*$ สำหรับสัญญาณจริง ขนาด $|c_n| = A_n/2$ แอมพลิจูดของไซน์ที่ความถี่ $nf_0$ จึงเท่ากับ $2|c_n|$ เพราะมาจากสองเส้นคือ $+nf_0$ และ $-nf_0$

สเปกตรัมสองด้านมีความถี่ติดลบได้อย่างไร?
ความถี่ติดลบเป็นเรื่องทางคณิตศาสตร์ ไซน์จริงหนึ่งตัวเขียนเป็นผลรวมของเฟเซอร์หมุนทวนเข็ม $e^{j\omega t}$ กับตามเข็ม $e^{-j\omega t}$ อย่างละครึ่ง เครื่องวัดและสโคปแสดงสเปกตรัมด้านเดียว (เฉพาะความถี่บวก) ซึ่งเท่ากับสองเท่าของสองด้าน

ทำไมพัลส์ดิวตี้ 20 % ไม่มีฮาร์มอนิกที่ 5?
สเปกตรัมของพัลส์มีเอนเวโลป $\mathrm{sinc}(nD)$ ซึ่งเป็นศูนย์เมื่อ $nD$ เป็นจำนวนเต็ม D = 0.2 จึงไม่มีฮาร์มอนิกที่ 5, 10, 15 ทั่วไปฮาร์มอนิกที่ $k/D$ หายไป

สมบัติอนุพันธ์ของอนุกรมฟูเรียร์ใช้ทำอะไร?
อนุพันธ์คูณสัมประสิทธิ์ด้วย $jn\omega_0$ ปริพันธ์หารด้วย $jn\omega_0$ จึงหาอนุกรมของสามเหลี่ยมจากสี่เหลี่ยมได้ทันที และอธิบายว่าทำไมอินทิเกรเตอร์ทำให้ฮาร์มอนิกสูงลดลง (ขอบมน) ส่วนดิฟเฟอเรนชิเอเตอร์ขยายฮาร์มอนิกสูง (ขยายนอยส์)

## คำถามที่พบบ่อย (FAQ)

**cn กับ an bn สัมพันธ์กันอย่างไร?**
$c_0 = a_0$, $c_n = (a_n - jb_n)/2$ และ $c_{-n} = c_n^*$ สำหรับสัญญาณจริง ขนาด $|c_n| = A_n/2$ แอมพลิจูดของไซน์ที่ความถี่ $nf_0$ จึงเท่ากับ $2|c_n|$ เพราะมาจากสองเส้นคือ $+nf_0$ และ $-nf_0$

**สเปกตรัมสองด้านมีความถี่ติดลบได้อย่างไร?**
ความถี่ติดลบเป็นเรื่องทางคณิตศาสตร์ ไซน์จริงหนึ่งตัวเขียนเป็นผลรวมของเฟเซอร์หมุนทวนเข็ม $e^{j\omega t}$ กับตามเข็ม $e^{-j\omega t}$ อย่างละครึ่ง เครื่องวัดและสโคปแสดงสเปกตรัมด้านเดียว (เฉพาะความถี่บวก) ซึ่งเท่ากับสองเท่าของสองด้าน

**ทำไมพัลส์ดิวตี้ 20 % ไม่มีฮาร์มอนิกที่ 5?**
สเปกตรัมของพัลส์มีเอนเวโลป $\mathrm{sinc}(nD)$ ซึ่งเป็นศูนย์เมื่อ $nD$ เป็นจำนวนเต็ม D = 0.2 จึงไม่มีฮาร์มอนิกที่ 5, 10, 15 ทั่วไปฮาร์มอนิกที่ $k/D$ หายไป

**สมบัติอนุพันธ์ของอนุกรมฟูเรียร์ใช้ทำอะไร?**
อนุพันธ์คูณสัมประสิทธิ์ด้วย $jn\omega_0$ ปริพันธ์หารด้วย $jn\omega_0$ จึงหาอนุกรมของสามเหลี่ยมจากสี่เหลี่ยมได้ทันที และอธิบายว่าทำไมอินทิเกรเตอร์ทำให้ฮาร์มอนิกสูงลดลง (ขอบมน) ส่วนดิฟเฟอเรนชิเอเตอร์ขยายฮาร์มอนิกสูง (ขยายนอยส์)
