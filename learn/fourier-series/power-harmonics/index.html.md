# กำลังไฟฟ้าเมื่อมีฮาร์มอนิก: RMS THD PF DPF P Q S D และมาตรฐาน IEEE 519

// บทที่ 14.8 · อนุกรมฟูเรียร์ · Power, THD & Power Factor


นิยาม P, Q, S และ PF ที่เรียนในวิชาวงจรใช้ได้เฉพาะไซน์ เมื่อกระแสเป็นพัลส์ของคอมพิวเตอร์หรือไดรฟ์ ต้องนิยามใหม่ด้วยอนุกรมฟูเรียร์ หน้านี้ตอบคำถามที่เจอทุกวันในอาคารและโรงงาน: ทำไม PF ต่ำทั้งที่ cos φ ดี ทำไมนิวทรัลร้อน ทำไมหม้อแปลงร้อนก่อนเต็มพิกัด และโรงงานต้องลดฮาร์มอนิกเท่าไรจึงผ่านมาตรฐาน

สรุปใน 30 วินาที

- $I_{rms} = \sqrt{I_1^2 + I_2^2 + \cdots}$ · THD $= \sqrt{\sum_{h\ge2}I_h^2}/I_1$ · TDD ใช้ $I_L$ แทน $I_1$

- $P = \sum V_hI_h\cos\theta_h$ · แรงดันเป็นไซน์ → $P = V_1I_1\cos\varphi_1$ ฮาร์มอนิกไม่ให้กำลังแต่เพิ่ม S

- $S^2 = P^2 + Q_1^2 + D^2$ · $\mathrm{PF} = \cos\varphi_1 \cdot \dfrac{1}{\sqrt{1 + \mathrm{THD}_i^2}}$

- h = 3k ลำดับศูนย์ → $I_N = 3\sqrt{I_3^2 + I_9^2 + \cdots}$ · IEEE 519: THD แรงดัน ≤ 8 % ที่ ≤ 1 kV

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## ค่า RMS ที่แท้จริง (True RMS) พื้นฐาน

H1 RMS with harmonics RMS เมื่อมีฮาร์มอนิก

$$I_{rms} = \sqrt{I_0^2 + I_1^2 + I_2^2 + I_3^2 + \cdots} = I_1\sqrt{1 + \mathrm{THD}_i^2}\;\;(I_0 = 0)$$

ค่า RMS ของแต่ละฮาร์มอนิก (P6) ใช้เลือกขนาดสาย ฟิวส์ และหม้อแปลง เพราะความร้อนขึ้นกับ RMS ทั้งก้อน

H3 Crest factor & average-responding meters crest factor และมิเตอร์ที่ไม่ใช่ True RMS

$$\mathrm{CF} = \frac{I_{peak}}{I_{rms}}, \qquad \text{มิเตอร์เฉลี่ย: } I_{read} = 1.111\times\overline{|i|}$$

1.111 คือ form factor ของไซน์ ($\pi/(2\sqrt2)$) ถูกเฉพาะไซน์ กระแส SMPS (CF ≈ 3) ทำให้มิเตอร์เฉลี่ยอ่านได้เพียงราวครึ่งหนึ่งของค่าจริง (จำลองในแล็บได้ 47–54 %) ใช้มิเตอร์ True RMS เสมอ

## THD, THDR และ TDD พื้นฐาน

H2 THD (F and R) and TDD สามนิยามที่เครื่องวัดใช้

$$\mathrm{THD}_F = \frac{\sqrt{\sum_{h=2}^{50}I_h^2}}{I_1}, \qquad \mathrm{THD}_R = \frac{\sqrt{\sum_{h=2}^{50}I_h^2}}{I_{rms}} = \frac{\mathrm{THD}_F}{\sqrt{1 + \mathrm{THD}_F^2}}, \qquad \mathrm{TDD} = \frac{\sqrt{\sum_{h=2}^{50}I_h^2}}{I_L}$$

THDF (เทียบหลัก) ใช้ทั่วไปและเกิน 100 % ได้ · THDR (เทียบ RMS) ไม่เกิน 100 % เครื่องบางยี่ห้อตั้งเป็นค่าเริ่มต้น ต้องตรวจเมนู · TDD (IEEE 519) เทียบกับกระแสความต้องการสูงสุด $I_L$ ทำให้โหลดเบาที่มี THD สูงไม่ถูกตัดสินว่าเกิน

## กำลัง P, S, Q₁ และกำลังความเพี้ยน D กลาง

เพราะความตั้งฉาก (T1–T3) แรงดันฮาร์มอนิกที่ h กับกระแสฮาร์มอนิกที่ k ≠ h ให้กำลังเฉลี่ยเป็นศูนย์ แรงดันจากการไฟฟ้าเกือบเป็นไซน์ กำลังจริงจึงมาจากฮาร์มอนิกหลักเกือบทั้งหมด แต่ RMS ของกระแสฮาร์มอนิกยังเพิ่ม S

H4 Active power กำลังจริง

$$P = \frac1T\int_T v\,i\,dt = \sum_{h} V_hI_h\cos\theta_h \;\approx\; V_1I_1\cos\varphi_1 \;\;(\text{แรงดันเป็นไซน์})$$

H5 Apparent power กำลังปรากฏ

$$S = V_{rms}\,I_{rms}$$

หม้อแปลง สายไฟ และเครื่องกำเนิดถูกจำกัดด้วย S (ความร้อนจาก RMS) ไม่ใช่ P

H6 Q₁ and distortion power D กำลังรีแอกทีฟของหลัก และกำลังความเพี้ยน

$$Q_1 = V_1I_1\sin\varphi_1,\qquad D = \sqrt{S^2 - P^2 - Q_1^2} \;\overset{v\ \text{ไซน์}}{=}\; V_1\sqrt{\textstyle\sum_{h\ge2}I_h^2},\qquad S^2 = P^2 + Q_1^2 + D^2$$

ภาพเรขาคณิตเป็นทรงสี่หน้า (power tetrahedron) แทนสามเหลี่ยมกำลัง · นิยามของ Budeanu ใช้ $Q_B = \sum V_hI_h\sin\theta_h$ แทน Q₁ มาตรฐาน IEEE 1459 แนะนำให้ใช้ Q₁ เพราะมีความหมายทางกายภาพชัดเจน (สิ่งที่คาปาซิเตอร์ชดเชยได้)

กำลังเมื่อมีฮาร์มอนิก: P กับ Q₁ เป็นสามเหลี่ยมกำลังของฮาร์มอนิกหลัก (DPF = cos φ₁) กำลังความเพี้ยน D ตั้งฉากกับระนาบนั้น S คือเส้นทแยงของกล่อง PF = P/S

## เพาเวอร์แฟกเตอร์ไม่เท่ากับ cos φ พื้นฐาน

H7 True PF = displacement × distortion PF จริง

$$\mathrm{PF} = \frac{P}{S} = \underbrace{\cos\varphi_1}_{\text{DPF}} \times \underbrace{\frac{I_1}{I_{rms}}}_{\text{distortion factor}} = \frac{\cos\varphi_1}{\sqrt{1 + \mathrm{THD}_i^2}} \quad (\text{แรงดันเป็นไซน์})$$

DPF แก้ได้ด้วยคาปาซิเตอร์ distortion factor แก้ได้ด้วยการลดฮาร์มอนิกเท่านั้น มิเตอร์ที่แสดง “cos φ” อาจหมายถึง DPF ต้องตรวจคู่มือ

ตัวอย่าง H-1 · คอมพิวเตอร์ไม่มี PFC

### วัดที่ 230 V (ไซน์): $I_1 = 1.30$, $I_3 = 1.15$, $I_5 = 0.95$, $I_7 = 0.70$, $I_9 = 0.45$, $I_{11} = 0.25$, $I_{13} = 0.15$ A (RMS), cos φ₁ = 0.99 หา $I_{rms}$, THD, P, S, Q₁, D, PF และ K-factor

- H1:

$$I_{rms} = \sqrt{1.30^2 + 1.15^2 + 0.95^2 + 0.70^2 + 0.45^2 + 0.25^2 + 0.15^2} = 2.166\ \text{A}$$

- H2: $\sqrt{\sum_{h\ge2}I_h^2} = 1.733$ A → THDF = 1.733/1.30 = 133 % · THDR = 1.733/2.166 = 80.0 %

- H4: $P = 230(1.30)(0.99) = 296.0$ W · H5: $S = 230(2.166) = 498.2$ VA

- H6: $Q_1 = 230(1.30)\sin(\cos^{-1}0.99) = 42.2$ var · $D = 230 \times 1.733 = 398.5$ VA

- H7: PF = 296.0/498.2 = 0.594 = 0.99 × (1.30/2.166) = 0.99 × 0.600 ✓

- H9: K = $\sum (I_h/I_{rms})^2h^2$ = 18.7

$I_{rms}$ = 2.17 A, THD 133 %, P = 296 W, S = 498 VA, Q₁ = 42 var, D = 399 VA, PF = 0.59 แม้ cos φ = 0.99 · กำลังความเพี้ยนใหญ่กว่ากำลังรีแอกทีฟเกือบ 10 เท่า

ลองในแล็บ: “SMPS 300 W ไม่มี PFC” ได้ตัวเลขใกล้เคียง (THD ~130 %, PF ~0.6) และกด “เครื่องคำนวณอย่างไร” ดูทุกขั้น ✓

ตัวอย่าง H-2 · ใส่คาปาซิเตอร์แก้ PF ได้ไหม

### จาก H-1 ถ้าชดเชย Q₁ = 42 var ด้วยคาปาซิเตอร์จนหมด PF จะเป็นเท่าไร

- Q₁ → 0 แต่ D ไม่เปลี่ยน: $S' = \sqrt{296^2 + 0^2 + 398.5^2} = 496.4$ VA

- PF' = 296/496.4 = 0.596 (จาก 0.594)

แทบไม่เปลี่ยน PF ต่ำเพราะความเพี้ยน ไม่ใช่เพราะเฟส คาปาซิเตอร์ยังอาจเรโซแนนซ์กับระบบที่ฮาร์มอนิกต่ำ ๆ ทางแก้คือ Active PFC (M8) ซึ่งทำให้ PF > 0.98

## การแยกกำลังตาม IEEE 1459 ขั้นสูง

H8 IEEE 1459 decomposition แยกกำลังปรากฏ

$$S^2 = \underbrace{(V_1I_1)^2}_{S_1^2} + \underbrace{(V_1I_H)^2}_{D_I^2} + \underbrace{(V_HI_1)^2}_{D_V^2} + \underbrace{(V_HI_H)^2}_{S_H^2},\qquad V_H = \sqrt{\textstyle\sum_{h\ne1}V_h^2},\;\; I_H = \sqrt{\textstyle\sum_{h\ne1}I_h^2}$$

$S_N = \sqrt{S^2 - S_1^2}$ คือกำลังปรากฏส่วนที่ไม่ใช่ฮาร์มอนิกหลัก $D_I$ มาจากกระแสเพี้ยน (ปกติใหญ่สุด) $D_V$ มาจากแรงดันเพี้ยน ใช้แยกว่าใครทำให้ไฟเพี้ยน เครื่องวัดคุณภาพไฟฟ้าชั้นสูงแสดงค่าเหล่านี้

## K-factor และหม้อแปลงที่ร้อนเกินพิกัด กลาง

ความสูญเสียกระแสวนในขดลวดหม้อแปลงเพิ่มตามกำลังสองของความถี่ ฮาร์มอนิกที่ 13 ขนาดเล็ก ๆ จึงสร้างความร้อนเท่ากับกระแสหลักก้อนใหญ่ได้

H9 K-factor ตัวคูณความสูญเสียกระแสวน

$$K = \frac{\sum_h I_h^2\,h^2}{\sum_h I_h^2} = \sum_h \Big(\frac{I_h}{I_{rms}}\Big)^2h^2$$

ไซน์ K = 1 · โหลดสำนักงานทั่วไป K ≈ 4–13 · เลือกหม้อแปลง K-rated (K-4, K-13, K-20) ที่สูงกว่าค่าที่วัด หรือลดพิกัดหม้อแปลงธรรมดาตามวิธีของ IEEE C57.110

## ลำดับเฟสของฮาร์มอนิกและกระแสนิวทรัล กลาง

เฟส b ล่าช้ากว่าเฟส a 120° ฮาร์มอนิกที่ h ของเฟส b จึงล่าช้า $h \times 120^\circ$ (S6) สำหรับ h = 3 คือ 360° เท่ากับไม่ล่าช้าเลย ฮาร์มอนิกที่ 3 ของสามเฟสจึงอยู่ในเฟสเดียวกันทุกประการ

H10 Harmonic sequence & neutral current ลำดับเฟสและกระแสนิวทรัล

$$h = 3k+1:\ \text{บวก (1, 4, 7, 13)} \quad h = 3k+2:\ \text{ลบ (2, 5, 11, 14)} \quad h = 3k:\ \text{ศูนย์ (3, 9, 15)} \qquad I_N = 3\sqrt{I_3^2 + I_9^2 + I_{15}^2 + \cdots}$$

ลำดับบวกกับลบของสามเฟสหักกันในนิวทรัล ลำดับศูนย์บวกกันสามเท่า (สำหรับโหลดสมดุล) · ฮาร์มอนิกลำดับลบ (5, 11) สร้างสนามหมุนกลับทางในมอเตอร์ เกิดแรงบิดเบรกและความร้อน

กระแสฮาร์มอนิกหลักของสามเฟส (บน) รวมกันเป็นศูนย์ในนิวทรัล ฮาร์มอนิกที่ 3 ของทั้งสามเฟส (ล่าง) ซ้อนกันพอดีและบวกเป็นสามเท่า

ตัวอย่าง H-3 · ชั้นสำนักงานในระบบ 3 เฟส 4 สาย

### แต่ละเฟสมีกระแส $I_1 = 20$, $I_3 = 16$, $I_5 = 12$, $I_7 = 7$, $I_9 = 4$ A (สมดุลทุกเฟส) หากระแสเฟสและกระแสนิวทรัล

- กระแสเฟส H1: $\sqrt{20^2 + 16^2 + 12^2 + 7^2 + 4^2} = 29.4$ A

- นิวทรัล H10: ฮาร์มอนิกหลักและที่ 5, 7 หักกันหมด เหลือ 3 และ 9 $I_N = 3\sqrt{16^2 + 4^2} = 49.5$ A

นิวทรัล 49.5 A = 168 % ของกระแสเฟส ถ้าเดินสายนิวทรัลขนาดเท่าเฟส (หรือเล็กกว่า) จะร้อนเกิน แก้โดยเพิ่มขนาดนิวทรัลเป็น 200 % หม้อแปลงซิกแซก หรือลดฮาร์มอนิกที่ 3 ที่ต้นทาง ลองในแล็บ: “SMPS 3 kW ต่อเฟส: นิวทรัลร้อน”

## กระแสเพี้ยนทำให้แรงดันเพี้ยน: แรงดันที่จุดต่อร่วม (PCC) กลาง

ระบบไฟมีอิมพีแดนซ์ (ส่วนใหญ่คือรีแอกแตนซ์ของหม้อแปลง) กระแสฮาร์มอนิกที่ไหลผ่านสร้างแรงดันตกที่ความถี่ฮาร์มอนิก โหลดอื่นที่ต่ออยู่จุดเดียวกันจึงได้แรงดันเพี้ยนไปด้วย เป็นเหตุผลที่มาตรฐานกำหนดขีดจำกัดของกระแสที่แต่ละผู้ใช้ไฟปล่อยออกมา

H11 Harmonic voltage at the PCC แรงดันฮาร์มอนิกที่จุดต่อร่วม

$$V_h \approx I_h\,|R_s + jhX_s| \approx I_h\,hX_s, \qquad X_s \approx \frac{V_{ph}}{I_{sc}}, \qquad \frac{V_h}{V_1} \approx \frac{I_h}{I_L}\cdot\frac{h}{I_{sc}/I_L}$$

ระบบแข็ง (Isc/IL สูง) แรงดันเพี้ยนน้อย ระบบอ่อน (หม้อแปลงเล็ก สายยาว เครื่องกำเนิดไฟฟ้าสำรอง) เพี้ยนมาก ฮาร์มอนิกลำดับสูงแม้กระแสน้อยก็สร้างแรงดันได้มากเพราะคูณ h

ตัวอย่าง H-4 · ไดรฟ์ 500 kW บนหม้อแปลง 1000 kVA

### หม้อแปลง 1000 kVA 400 V อิมพีแดนซ์ 6 % จ่ายไดรฟ์ 6 พัลส์ 500 kW (PF 0.95) กระแสฮาร์มอนิกเป็น % ของหลัก: 5 → 30, 7 → 20, 11 → 8, 13 → 6, 17 → 4, 19 → 3 หา THD แรงดันด้าน 400 V (ไม่คิดอิมพีแดนซ์ต้นทาง)

- $Z_{base} = 400^2/10^6 = 0.16\ \Omega$ · $X_s = 0.06 \times 0.16 = 0.0096\ \Omega$ (Isc ≈ 24.1 kA) · $I_1 = \frac{500\,000}{\sqrt3(400)(0.95)} = 760$ A

- H11: $V_5 = 0.30(760)(5)(0.0096) = 10.9$ V (4.7 % ของ 231 V) · $V_7$ = 10.2 V (4.4 %) · $V_{11}$ = 6.4 V (2.8 %) · $V_{13}$ = 5.7 V (2.5 %) · $V_{17}$ = 5.0 V (2.1 %) · $V_{19}$ = 4.2 V (1.8 %)

- THDV:

$$\mathrm{THD}_V = \sqrt{4.74^2 + 4.42^2 + 2.78^2 + 2.46^2 + 2.15^2 + 1.80^2}\ \% = 8.0\ \%$$

THD แรงดันประมาณ 8 % ชนขีดจำกัด IEEE 519 (8 %) และเกินเกณฑ์ กฟภ./กฟน. ที่ 0.4 kV (5 %) ไดรฟ์ขนาดนี้ต้องมีรีแอกเตอร์ โช้ก DC หรือ 12 พัลส์ ดูวิธีแก้

## ขีดจำกัดตามมาตรฐาน: IEEE 519-2022, กฟภ./กฟน. และ IEC 61000-3-2 กลาง

IEEE 519 ใช้ประเมินที่จุดต่อร่วมระหว่างผู้ใช้ไฟกับการไฟฟ้า (PCC) ไม่ใช่ที่เครื่องแต่ละตัว ฉบับ 2022 เปลี่ยนชื่อเป็น “Standard” และผ่อนขีดจำกัดของฮาร์มอนิกคู่ (เดิมทุกตัว 25 % ของค่าในตาราง)

## คำถามที่พบบ่อย

THD คืออะไร คำนวณอย่างไร?
THD (total harmonic distortion) คือสัดส่วนค่า RMS ของฮาร์มอนิกทั้งหมดตั้งแต่ลำดับที่ 2 เทียบกับฮาร์มอนิกหลัก $\mathrm{THD} = \sqrt{I_2^2 + I_3^2 + \cdots}/I_1$ มาตรฐานไฟฟ้ากำลังนับถึงลำดับที่ 50 กระแสของคอมพิวเตอร์ที่ไม่มี PFC มี THD ได้ถึง 100–150 %

PF กับ cos φ ต่างกันอย่างไร?
cos φ (DPF) คือ cos ของมุมระหว่างแรงดันกับกระแสเฉพาะฮาร์มอนิกหลัก PF จริงคือ P/S ซึ่งรวมผลของฮาร์มอนิกด้วย เมื่อแรงดันเป็นไซน์ $\mathrm{PF} = \cos\varphi_1 \times 1/\sqrt{1 + \mathrm{THD}_i^2}$ โหลดที่ cos φ = 0.99 แต่ THD 133 % มี PF เพียง 0.59

ทำไมคาปาซิเตอร์แก้ PF ไม่ช่วยโหลดอิเล็กทรอนิกส์?
คาปาซิเตอร์ชดเชยได้เฉพาะ Q₁ ของฮาร์มอนิกหลัก ถ้า PF ต่ำเพราะความเพี้ยน (D สูง) แต่ cos φ₁ ใกล้ 1 อยู่แล้ว คาปาซิเตอร์จะทำให้กระแสนำหน้าและอาจเกิดเรโซแนนซ์ขยายฮาร์มอนิก ต้องลดฮาร์มอนิกด้วยรีแอกเตอร์ ฟิลเตอร์ หรือ PFC แทน

ทำไมสายนิวทรัลร้อนกว่าสายเฟส?
ฮาร์มอนิกที่ 3, 9, 15 เป็นลำดับศูนย์ ในระบบสามเฟสสี่สายที่มีโหลดแบบ SMPS ทุกเฟส ฮาร์มอนิกพวกนี้ของสามเฟสอยู่ในเฟสเดียวกันจึงบวกกันในนิวทรัล $I_N = 3\sqrt{I_3^2 + I_9^2 + \cdots}$ ได้ถึง 1.5–1.7 เท่าของกระแสเฟส

IEEE 519-2022 กำหนด THD แรงดันเท่าไร?
ที่จุดต่อร่วม (PCC) แรงดันไม่เกิน 1 kV: ฮาร์มอนิกแต่ละตัวไม่เกิน 5 % และ THD ไม่เกิน 8 % · 1–69 kV: 3 % และ 5 % · 69–161 kV: 1.5 % และ 2.5 % · เกิน 161 kV: 1 % และ 1.5 % ส่วนกระแสกำหนดเป็น TDD ตามอัตราส่วน Isc/IL ตั้งแต่ 5 % ถึง 20 %
