# วงจร RC RL RLC กับคลื่นสี่เหลี่ยมและไซน์

// บทที่ 12.6 · แล็บ FG + สโคป · RC, RL & RLC


นี่คือการทดลองแรกที่ทุกคนได้ทำกับเครื่องกำเนิดสัญญาณและสโคปจริงจัง และเป็นสะพานจากวงจรไฟฟ้าไปสู่สัญญาณและระบบ ป้อนคลื่นสี่เหลี่ยมเพื่อดูผลตอบสนองในโดเมนเวลา (τ, การแกว่ง) ป้อนไซน์เพื่อดูผลตอบสนองความถี่ (f_c, Q, แบนด์วิดท์) ทั้งสองแบบบอกเรื่องเดียวกันจากคนละมุม สูตรใช้รหัส R

สรุปใน 30 วินาที

- $\tau = RC$ หรือ $L/R$ โดย R รวม 50 Ω ของเครื่อง · ถึง 63.2 % ที่ $t = \tau$ · เวลาขาขึ้น $2.2\tau$

- $f_c = 1/(2\pi\tau)$ ที่นั่น $|H| = 0.707$ (−3 dB) และเฟส −45°

- ความถี่สูงกว่า $f_c$ มาก: RC ต่ำผ่านเป็นอินทิเกรเตอร์ · ต่ำกว่ามาก: RC สูงผ่านเป็นดิฟเฟอเรนชิเอเตอร์

- RLC: $f_0 = 1/(2\pi\sqrt{LC})$, $Q = \sqrt{L/C}/R$, แบนด์วิดท์ $= f_0/Q$ · ยิ่ง Q สูงยิ่งแกว่งนาน

ระดับพื้นฐาน ม.ปลาย · ปวส. · ปี 1กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท · งานวิจัย

## ต่อวงจรและโพรบ พื้นฐาน

CH1 วัดที่ขาเข้าวงจร (ขั้วเครื่องกำเนิดสัญญาณ) CH2 วัดที่ขาออก กราวด์ของทุกเครื่องอยู่จุดเดียวกัน ชิ้นที่ต้องการวัดแรงดันต้องอยู่ฝั่งที่ติดกราวด์ ถ้าอยากดูแรงดันคร่อม R ในวงจรต่ำผ่าน ให้สลับตำแหน่ง R กับ C (ได้วงจรสูงผ่าน) แทนการหนีบกราวด์โพรบกลางวงจร

RC ต่ำผ่านและสูงผ่านต่างกันแค่ว่าวัดคร่อมชิ้นไหน กระแสเดียวกันไหลผ่านทั้ง R และ C

อย่าลืม 50 Ω: เครื่องกำเนิดสัญญาณคือแหล่งแรงดันอนุกรมกับ 50 Ω V1 ถ้าคิดผลตอบสนองเทียบกับ emf ของเครื่อง ความต้านทานรวมคือ $R + 50\ \Omega$ แต่ถ้าคิดเทียบกับแรงดันที่ขั้วซึ่ง CH1 วัดได้ ใช้ $R$ อย่างเดียว ผลต่างสำคัญเมื่อ $R$ ไม่ถึงราว 5 kΩ

## ค่าคงตัวเวลา τ และผลตอบสนองขั้น พื้นฐาน

ขอบขาขึ้นของคลื่นสี่เหลี่ยมคือ “ขั้นแรงดัน” ตัวเก็บประจุชาร์จผ่าน R แบบเอกซ์โพเนนเชียล ถ้าครึ่งคาบยาวพอ (≥ 5τ) แรงดันจะขึ้นจนเกือบเต็มก่อนขอบถัดไป เราจึงอ่าน τ จากภาพได้โดยตรง

ที่เวลา τ แรงดันขึ้นได้ 63.2 % ของขั้น เส้นสัมผัสที่จุดเริ่มต้นตัดค่าสุดท้ายที่ τ เช่นกัน

R1 Time constant ค่าคงตัวเวลา

$$\tau_{RC} = R_T\,C,\qquad \tau_{RL} = \frac{L}{R_T},\qquad R_T = R + R_s$$

$R_s = 50\ \Omega$ เมื่อคิดเทียบกับ emf ของเครื่อง ตัวเหนี่ยวนำจริงให้บวกความต้านทานขดลวด $r_L$ เข้าไปใน $R_T$ ด้วย

R2 First-order response ผลตอบสนองอันดับหนึ่งทุกกรณี

$$v(t) = v(\infty) + \big[v(0^+) - v(\infty)\big]\,e^{-t/\tau}$$

ใช้ได้กับทุกแรงดันและกระแสในวงจร RC หรือ RL ที่มีตัวเก็บพลังงานตัวเดียว รู้แค่ค่าเริ่ม ค่าสุดท้าย และ τ

R3 Reading τ from the graph อ่าน τ จากกราฟ

$$v(\tau) = 63.2\,\%,\quad v(5\tau) = 99.3\,\%,\quad t_r = \tau\ln 9 = 2.2\,\tau$$

$$t = \tau\,\ln\frac{v(0^+) - v(\infty)}{v(t) - v(\infty)}$$

ตัวอย่าง R-1 · หา τ และค่า C จากภาพ

### R = 10 kΩ, C ไม่ทราบค่า ป้อนสี่เหลี่ยม 0–4 V 500 Hz ที่ 50 µs/div แรงดันคร่อม C ขึ้นถึง 2.53 V (63.2 %) ที่ 2.01 ช่องหลังขอบขาขึ้น หา τ และ C

- อ่าน τ R3

$$\tau = 2.01 \times 50\ \mu\text{s} = 100.5\ \mu\text{s}$$

- ความต้านทานรวม (ขั้นแรงดันมาจาก emf ของเครื่อง) R1

$$C = \frac{\tau}{R + 50} = \frac{100.5\times10^{-6}}{10\,050} = 10.0\ \text{nF}$$

- ตรวจด้วยเวลาขาขึ้น

$$t_r = 2.2\tau = 221\ \mu\text{s}\ (4.4\ \text{ช่อง})$$

τ = 100.5 µs, C = 10 nF ถ้าลืม 50 Ω จะได้ C = 10.05 nF ต่างกันแค่ 0.5 % เพราะ R ใหญ่ แต่ถ้า R = 100 Ω จะต่างกันถึง 50 %

ลองเอง: ครึ่งคาบ 1 ms ≫ τ ปรับ R และ C แล้วเทียบเวลาขาขึ้นในตารางวัดกับ 2.2τ (กล่องทฤษฎีคำนวณ τ ให้) สังเกตว่าที่ 50 µs/div จอเห็นช่วงชาร์จแค่ราว 4.5τ สโคปหาระดับ “ยอด” จากฮิสโทแกรมของจุดบนจอจึงได้ต่ำไปเล็กน้อย และรายงานเวลาขาขึ้นราว 199 µs หมุน Time/div เป็น 100 µs/div ให้เห็นยอดแบนนานขึ้น จะอ่านได้ราว 223 µs ≈ 2.2τ สโคปจริงก็เป็นแบบนี้ ให้ขอบที่วัดเห็นทั้งฐานและยอดที่นิ่งแล้วเสมอ

## เมื่อชาร์จไม่ทัน: คลื่นสี่เหลี่ยมความถี่สูงขึ้น กลาง

เพิ่มความถี่จนครึ่งคาบสั้นกว่าราว 5τ ตัวเก็บประจุจะชาร์จไม่เต็มก่อนสัญญาณกลับทิศ หลังผ่านไปไม่กี่คาบ วงจรจะเข้าสู่สภาวะคงตัวแบบคาบ (periodic steady state) ที่แรงดันแกว่งสมมาตรรอบค่าเฉลี่ย ยิ่งความถี่สูง ภาพยิ่งเหมือนสามเหลี่ยมและยิ่งเล็ก

สีเหลืองคือขาเข้า สีฟ้าคือแรงดันคร่อม C ที่สามความถี่ ภาพขวาสุดคือวงจรอินทิเกรตแบบพาสซีฟ

R4 Periodic steady state (square wave) ยอดของ $v_C$ เมื่อป้อนสี่เหลี่ยม ±V

$$V_{C,peak} = V\,\tanh\!\left(\frac{T}{4\tau}\right)$$

$T/2 \gg \tau$: $\tanh \to 1$ ชาร์จเต็ม · $T/2 \ll \tau$: $\approx V T/(4\tau)$ เป็นสามเหลี่ยม R7 · ถ้ามีออฟเซต ให้บวกค่าเฉลี่ยเข้าไป

ตัวอย่าง R-2 · RC ที่ 10 kHz

### วงจรเดิม (τ = 100.5 µs) ป้อนสี่เหลี่ยม ±1 V ความถี่ 10 kHz แรงดันคร่อม C สูงยอดถึงยอดเท่าไร

- สูตรเต็ม R4

$$\frac{T}{4\tau} = \frac{100\ \mu\text{s}}{402\ \mu\text{s}} = 0.2488,\quad V_{pp} = 2\tanh(0.2488) = 0.487\ \text{V}$$

- เทียบสูตรอินทิเกรเตอร์ R7

$$V_{pp} \approx \frac{V_p T}{2\tau} = \frac{1 \times 100\ \mu\text{s}}{201\ \mu\text{s}} = 0.498\ \text{V}$$

ราว 0.49 Vpp รูปเกือบเป็นสามเหลี่ยม สูตรประมาณคลาดเพียง 2 % เพราะ T/2 = 0.5τ ยังไม่ ≪ τ มากนัก

ลองเอง: เลื่อนความถี่จาก 100 Hz ถึง 50 kHz แล้วดูรูปคลื่นเปลี่ยนจากชาร์จเต็มเป็นสามเหลี่ยม

## RC กับไซน์: ความถี่ตัด −3 dB และเฟส −45° พื้นฐาน กลาง

ป้อนไซน์ ขาออกจะเป็นไซน์ความถี่เดิมเสมอ (วงจรเชิงเส้น) เปลี่ยนแค่แอมพลิจูดและเฟส สองค่านี้คือผลตอบสนองความถี่ $H(j\omega)$ ที่หาได้จากอิมพีแดนซ์ $Z_C = 1/(j\omega C)$ และตัวแบ่งแรงดัน

R5 Cutoff frequency and low-pass gain ความถี่ตัดและขนาดของวงจรต่ำผ่าน

$$f_c = \frac{1}{2\pi\tau},\qquad |H_{LP}| = \frac{1}{\sqrt{1 + (f/f_c)^2}}$$

ที่ $f = f_c$: $|H| = 0.707$ (−3 dB) · ที่ $10f_c$: 0.0995 (−20 dB)

R6 Phase, and the high-pass version เฟสของต่ำผ่านและวงจรสูงผ่าน

$$\varphi_{LP} = -\arctan\frac{f}{f_c},\qquad |H_{HP}| = \frac{f/f_c}{\sqrt{1 + (f/f_c)^2}},\quad \varphi_{HP} = 90^\circ - \arctan\frac{f}{f_c}$$

สูงผ่านนำเฟส +45° ที่ $f_c$ · ทั้งสองวงจรมีความถี่ตัดเดียวกัน และ $|H_{LP}|^2 + |H_{HP}|^2 = 1$

ตัวอย่าง R-3 · ตรวจความถี่ตัดสองวิธี

### R = 10 kΩ, C = 10 nF วัดเทียบแรงดันที่ขั้ว (CH1) ที่ความถี่ไหนได้ −3 dB และ −45° ที่ 5 kHz ได้เท่าไร

- เทียบ CH1 ที่ขั้วจึงไม่รวม 50 Ω R5

$$f_c = \frac{1}{2\pi(10^4)(10^{-8})} = 1591.5\ \text{Hz}$$

- ที่ 5 kHz R6

$$\frac{f}{f_c} = 3.142,\quad |H| = \frac{1}{\sqrt{1 + 9.87}} = 0.303\ (-10.4\ \text{dB}),\quad \varphi = -72.3^\circ$$

ที่ 1.59 kHz ได้ทั้ง 0.707 และ −45° พร้อมกัน ใช้เป็นการตรวจไขว้ ถ้าสองวิธีให้ความถี่ไม่ตรงกัน แปลว่ามีอะไรผิด เช่น โพรบไม่ได้ชดเชย หรือ C ไม่ใช่ค่าที่คิด ดูวิธีเก็บกราฟโบดเต็มที่ เทคนิคการวัด

ลองเอง: เลื่อนความถี่ให้เฟสเป็น −45° แล้วดูอัตราส่วน dB สลับขาออกคร่อม C (ต่ำผ่าน) กับคร่อม R (สูงผ่าน)

## อินทิเกรเตอร์และดิฟเฟอเรนชิเอเตอร์แบบพาสซีฟ กลาง

วงจร RC ทำแคลคูลัสได้ด้วยตัวเองเมื่อความถี่เหมาะสม ถ้าครึ่งคาบสั้นกว่า τ มาก แรงดันคร่อม C แทบไม่เปลี่ยน กระแสจึงถูกกำหนดโดย $v_{in}/R$ และ C สะสมประจุเป็นปริพันธ์ของกระแส ถ้าครึ่งคาบยาวกว่า τ มาก C ตามขาเข้าทัน แรงดันคร่อม R จึงเหลือเฉพาะช่วงที่ขาเข้าเปลี่ยน ซึ่งเป็นสัดส่วนกับอนุพันธ์

RC สูงผ่านกับคลื่นสี่เหลี่ยม: ซ้ายคือดิฟเฟอเรนชิเอเตอร์ (สไปก์สูงถึง 2 เท่าของแอมพลิจูดที่ขอบ) ขวาคือคัปปลิงที่ผ่านคลื่นเกือบครบ

R7 Passive integrator อินทิเกรเตอร์แบบพาสซีฟ $(f \gg f_c)$

$$v_C(t) \approx \frac{1}{\tau}\int v_{in}\,dt,\qquad V_{pp,\triangle} \approx \frac{V_p\,T}{2\tau}$$

ได้สามเหลี่ยมจากสี่เหลี่ยม ±$V_p$ แต่เล็กลงมาก ออปแอมป์อินทิเกรเตอร์ทำได้โดยไม่ลดทอน U7

R8 Passive differentiator ดิฟเฟอเรนชิเอเตอร์แบบพาสซีฟ $(f \ll f_c)$

$$v_R(t) \approx \tau\,\frac{dv_{in}}{dt},\qquad v_R(0^+) = \Delta v_{in}$$

ขอบสี่เหลี่ยมสูง $\Delta v = 2V_p$ จึงได้สไปก์สูง $2V_p$ แล้วลดลงด้วย τ · ใช้ทำวงจรตรวจขอบ (edge detector)

ลองเอง: RC สูงผ่าน (ขาออกคร่อม R) ลดความถี่ลงเพื่อดูสไปก์ เพิ่มความถี่เพื่อดูว่าคลื่นผ่านไปเกือบครบ

## ผลตอบสนองอิมพัลส์: สะพานไปสู่สัญญาณและระบบ กลาง ขั้นสูง

ในวิชาสัญญาณและระบบ ระบบเชิงเส้นไม่แปรตามเวลา (LTI) ถูกบรรยายครบด้วยผลตอบสนองอิมพัลส์ $h(t)$ เพราะขาออกต่อสัญญาณใด ๆ คือคอนโวลูชัน $y = x * h$ ในแล็บเราสร้างอิมพัลส์ไม่ได้จริง แต่พัลส์ที่แคบกว่า τ มากทำตัวเหมือนอิมพัลส์ที่มีพื้นที่เท่ากับ ความสูง × ความกว้าง

R17 Impulse response of RC low-pass ผลตอบสนองอิมพัลส์ของ RC ต่ำผ่าน

$$h(t) = \frac{1}{\tau}e^{-t/\tau}u(t),\qquad y(t) \approx (V_H\,W)\,h(t)\ \ (W \ll \tau)$$

ยอดของขาออก $\approx V_H W/\tau$ แล้วลดลงด้วย τ · พิสูจน์ได้จาก ลาปลาซ: $H(s) = 1/(1 + s\tau)$

ตัวอย่าง R-4 · ประมาณอิมพัลส์ด้วยพัลส์แคบ

### พัลส์ 0–5 V กว้าง 50 µs ซ้ำทุก 10 ms ป้อน RC ที่ R = 10 kΩ, C = 100 nF ขาออกสูงสุดเท่าไร

- τ รวม 50 Ω R1

$$\tau = 10\,050 \times 100\ \text{nF} = 1.005\ \text{ms} \gg 50\ \mu\text{s}$$

- พื้นที่พัลส์และยอด R17

$$V_H W = 5 \times 50\ \mu\text{s} = 250\ \mu\text{V}\cdot\text{s},\quad y_{max} \approx \frac{250\times10^{-6}}{1.005\times10^{-3}} = 0.249\ \text{V}$$

ยอดราว 0.25 V แล้วลดลงครึ่งหนึ่งทุก $0.693\tau = 0.70$ ms รูปทรงของขาออกคือ $h(t)$ ของวงจร ลองเพิ่มความกว้างพัลส์ (ดิวตี้) ในแล็บเต็ม จะเห็นยอดเพิ่มตามพื้นที่จนพัลส์กว้างเทียบกับ τ แล้วรูปเริ่มเพี้ยนจาก $h(t)$

ต่อยอดเรื่อง $h(t)$ คอนโวลูชัน และการแปลงฟูริเยร์ได้ที่ แล็บสัญญาณ และ แล็บระบบอันดับหนึ่ง ซึ่งใช้วงจรเดียวกันนี้ในรูปฟังก์ชันถ่ายโอน

## วงจร RL พื้นฐาน กลาง

RL ทำงานกลับกับ RC: ตัวเหนี่ยวนำต้านการเปลี่ยนกระแส ขาออกคร่อม R เป็นวงจรต่ำผ่าน คร่อม L เป็นสูงผ่าน τ = L/R สั้นมากเมื่อ L เป็น mH และ R เป็น kΩ จึงต้องใช้ความถี่สูงกว่า RC ทั่วไป ตัวเหนี่ยวนำจริงมีความต้านทานขดลวด $r_L$ อยู่ในตัว ทำให้แรงดันคร่อม L ไม่ลดลงถึงศูนย์ แต่ค้างที่ $V\,r_L/(R_T)$

ตัวอย่าง R-5 · หาค่า L จาก τ

### R = 1 kΩ ต่อกับขดลวดไม่ทราบค่า ป้อนสี่เหลี่ยม 10 kHz วัด τ ของแรงดันคร่อม R ได้ 9.5 µs หา L

- จัดรูป R1

$$L = \tau\,(R + 50 + r_L) \approx 9.5\ \mu\text{s} \times 1050\ \Omega = 9.98\ \text{mH}$$

ราว 10 mH ถ้าวัด $r_L$ ด้วยมัลติมิเตอร์ได้ เช่น 20 Ω ให้บวกเข้าไป จะได้ 10.2 mH

## RLC อนุกรม: เรโซแนนซ์ Q และแบนด์วิดท์ กลาง

ที่ความถี่หนึ่ง รีแอกแตนซ์ของ L กับ C หักล้างกันพอดี เหลือแค่ความต้านทาน กระแสสูงสุดและเฟสเป็นศูนย์ นี่คือเรโซแนนซ์ ความคมของยอดบอกด้วย Q ซึ่งเป็นตัวเลขเดียวที่บอกทั้งพฤติกรรมในโดเมนความถี่ (แบนด์วิดท์) และโดเมนเวลา (แกว่งกี่รอบ)

RLC อนุกรม: 50 Ω ภายในเครื่องอนุกรมอยู่ในวงจรเสมอ จึงต้องรวมใน R ของสูตร

R9 Resonant frequency ความถี่เรโซแนนซ์

$$f_0 = \frac{1}{2\pi\sqrt{LC}},\qquad \omega_0 L = \frac{1}{\omega_0 C}$$

R10 Quality factor (series RLC) ตัวประกอบคุณภาพ

$$Q = \frac{1}{R_T}\sqrt{\frac{L}{C}} = \frac{\omega_0 L}{R_T},\qquad \zeta = \frac{1}{2Q}$$

$R_T = R + 50\ \Omega + r_L$ · $Q > 0.5$ แกว่ง ($\zeta < 1$) · $Q = 0.707$ ตอบสนองแบนราบที่สุด (Butterworth)

R11 Bandwidth and half-power frequencies แบนด์วิดท์และความถี่ครึ่งกำลัง

$$B = f_2 - f_1 = \frac{f_0}{Q} = \frac{R_T}{2\pi L},\qquad f_{1,2} = f_0\left(\sqrt{1 + \tfrac{1}{4Q^2}} \mp \tfrac{1}{2Q}\right)$$

$f_0 = \sqrt{f_1 f_2}$ (ค่าเฉลี่ยเรขาคณิต ไม่ใช่เลขคณิต)

R15 Voltage magnification at resonance แรงดันคร่อม L และ C ที่เรโซแนนซ์

$$|V_L| = |V_C| = Q\,|V_{emf}|$$

Q = 10 กับไฟ 2 Vpp ได้ 20 Vpp คร่อม C ระวังพิกัดแรงดันของตัวเก็บประจุ

R16 Parallel RLC (tank) RLC ขนาน

$$Q_p = R_p\sqrt{\frac{C}{L}},\qquad f_0 = \frac{1}{2\pi\sqrt{LC}}$$

ขนาน: R ยิ่งมาก Q ยิ่งสูง (กลับกับอนุกรม) ใช้ในวงจรจูนวิทยุและออสซิลเลเตอร์

ขาออกคร่อม R ของ RLC เดียวกัน L = 10 mH, C = 100 nF ที่ R รวมสองค่า Q สูงยอดแคบ แบนด์วิดท์แคบ

ตัวอย่าง R-6 · RLC ครบทุกค่า

### L = 10 mH, C = 100 nF, R = 100 Ω ต่อกับเครื่องกำเนิดสัญญาณ 2 Vpp (emf) หา $f_0$, Q, แบนด์วิดท์, $f_1$, $f_2$ และแรงดันคร่อม C ที่เรโซแนนซ์

- ความถี่เรโซแนนซ์ R9

$$f_0 = \frac{1}{2\pi\sqrt{(10^{-2})(10^{-7})}} = 5033\ \text{Hz}$$

- Q รวม 50 Ω R10

$$Q = \frac{1}{150}\sqrt{\frac{10^{-2}}{10^{-7}}} = \frac{316.2}{150} = 2.11$$

- แบนด์วิดท์และขอบ R11

$$B = \frac{5033}{2.11} = 2387\ \text{Hz},\quad f_1 = 3979\ \text{Hz},\quad f_2 = 6366\ \text{Hz}$$

- แรงดันคร่อม C R15

$$V_C = 2.11 \times 2 = 4.22\ \text{Vpp}$$

$f_0$ = 5.03 kHz, Q = 2.11, B = 2.39 kHz (3.98–6.37 kHz) และ $V_C$ = 4.2 Vpp มากกว่าแหล่งจ่าย ถ้าลืม 50 Ω จะคำนวณ Q = 3.16 ผิดไป 50 %

ลองเอง: ขาออกคร่อม R ปรับความถี่หายอด (เฟสเป็น 0°) แล้วหาความถี่ที่อัตราส่วนลดเหลือ 0.707 ทั้งสองข้าง ลองสลับขาออกเป็นคร่อม C แล้วดูแรงดันที่ $f_0$

## RLC กับคลื่นสี่เหลี่ยม: การแกว่งและลอการิทึมดีครีเมนต์ กลาง ขั้นสูง

ป้อนคลื่นสี่เหลี่ยมความถี่ต่ำ (ครึ่งคาบยาวกว่าเวลาที่การแกว่งยุบหมด) แต่ละขอบคือขั้นแรงดันที่ทำให้วงจรแกว่งที่ความถี่ธรรมชาติ แล้วค่อย ๆ ยุบตามเปลือกเอกซ์โพเนนเชียล ภาพเดียวนี้ให้ทั้ง $f_d$, ζ, Q และ R รวมของวงจร เป็นวิธีที่ใช้หาความหน่วงของระบบจริง ตั้งแต่วงจรกรองไปจนถึงโครงสร้างเครื่องกล

แรงดันคร่อม C หลังขอบขาขึ้น: วัดความสูงของยอดเหนือค่าสุดท้ายสองยอดถัดกันที่ห่างกันหนึ่งคาบ

R12 Damped ringing การแกว่งแบบหน่วง

$$f_d = f_0\sqrt{1 - \zeta^2},\qquad \text{เปลือก} \propto e^{-\alpha t},\ \ \alpha = \frac{R_T}{2L} = \zeta\omega_0$$

R13 Logarithmic decrement ลอการิทึมดีครีเมนต์

$$\delta = \ln\frac{V_n}{V_{n+1}} = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}},\qquad \zeta = \frac{\delta}{\sqrt{4\pi^2 + \delta^2}},\qquad Q \approx \frac{\pi}{\delta}$$

$V_n$ วัดจากค่าสุดท้ายถึงยอด ยอดที่ห่างกันหนึ่งคาบ · จำง่าย: Q ≈ จำนวนรอบที่แกว่งจนเหลือราว 4 % ($e^{-\pi}$)

R14 Percent overshoot เปอร์เซ็นต์โอเวอร์ชูต (คร่อม C)

$$\%OS = 100\,e^{-\zeta\pi/\sqrt{1-\zeta^2}}$$

เหมือนระบบอันดับสองในวิชาควบคุมทุกประการ ดู แล็บระบบอันดับสอง

ตัวอย่าง R-7 · หา Q และ R จากการแกว่ง

### RLC (L = 10 mH, C = 100 nF) ป้อนสี่เหลี่ยม ±1 V 300 Hz คร่อม C ยอดแรกเกินค่าสุดท้าย 1.48 V ยอดถัดไป (หนึ่งคาบต่อมา) เกิน 0.814 V หา δ, ζ, Q และ R รวม

- ลอการิทึมดีครีเมนต์ R13

$$\delta = \ln\frac{1.48}{0.814} = 0.598$$

- ζ และ Q

$$\zeta = \frac{0.598}{\sqrt{39.48 + 0.358}} = 0.0947,\quad Q = \frac{1}{2\zeta} = 5.28$$

- R รวม จาก R10

$$R_T = \frac{1}{Q}\sqrt{\frac{L}{C}} = \frac{316.2}{5.28} = 59.9\ \Omega$$

- ตรวจโอเวอร์ชูตของขั้น 2 V R14

$$\%OS = 100\,e^{-0.0947\pi/0.9955} = 74.1\ \%\ \Rightarrow\ 0.741\times 2 = 1.48\ \text{V}$$

Q ≈ 5.3, R รวม ≈ 60 Ω = R ที่ใส่ 10 Ω + 50 Ω ของเครื่อง วิธีนี้วัดความต้านทานที่ “ซ่อนอยู่” ได้ ถ้าได้มากกว่าที่คิด ส่วนเกินมักเป็นความต้านทานของขดลวด

ลองเอง: ลด R ให้แกว่งนานขึ้น (Q สูง) เพิ่ม R จนไม่แกว่ง ($R_T \ge 2\sqrt{L/C} = 632\ \Omega$ คือหน่วงวิกฤต)

## สรุป: เวลา ↔ ความถี่ ของวงจรเดียวกัน กลาง

| สิ่งที่เห็นในโดเมนเวลา (สี่เหลี่ยม) | สิ่งที่เห็นในโดเมนความถี่ (ไซน์) | ความสัมพันธ์ |

| τ ของ RC | $f_c$ | $f_c = 1/(2\pi\tau)$ |

| เวลาขาขึ้น $t_r$ | แบนด์วิดท์ | $t_r \approx 0.35/f_c$ O8 |

| ยอดเอียง (tilt) ของสูงผ่าน | ความถี่ตัดต่ำ | $\text{tilt} \approx \pi f_c/f$ O6 |

| ความถี่แกว่ง $f_d$ | ความถี่ยอดเรโซแนนซ์ | $f_d = f_0\sqrt{1-\zeta^2}$ |

| จำนวนรอบที่แกว่ง | ความคมของยอด Q | $Q \approx \pi/\delta$ |

| โอเวอร์ชูต | ยอดเกินใน $|H|$ ของต่ำผ่านอันดับสอง | ทั้งคู่ขึ้นกับ ζ |

ข้อสรุปนี้คือหัวใจของวิชาสัญญาณและระบบ: ระบบเชิงเส้นเดียวกันมองได้สองแบบ ผลตอบสนองอิมพัลส์ $h(t)$ กับผลตอบสนองความถี่ $H(j\omega)$ เป็นคู่การแปลงฟูริเยร์กัน ถ้าอินพุตเป็นคลื่นคาบที่ไม่ใช่ไซน์ ใช้ $H(jn\omega_0)$ ทีละฮาร์มอนิกตาม วิเคราะห์วงจรด้วยอนุกรมฟูเรียร์ ไปต่อที่ ออปแอมป์ เพื่อทำวงจรเหล่านี้ให้มีเกนและไม่ถูกโหลด

## ต่อยอด: วัดผลตอบสนองความถี่เพื่อออกแบบระบบควบคุม

การกวาดความถี่วัดเกนและเฟสของ RC และ RLC คือการวัดผลตอบสนองความถี่ นำไปวาดโบด หาฟังก์ชันถ่ายโอนจากกราฟ และวัดลูปเกนของพาวเวอร์ซัพพลาย

## คำถามที่พบบ่อย

หาค่าคงตัวเวลา τ จากออสซิลโลสโคปอย่างไร?
ป้อนคลื่นสี่เหลี่ยมที่ครึ่งคาบยาวอย่างน้อย 5τ แล้วดูแรงดันคร่อม C วัดเวลาตั้งแต่ขอบขาขึ้นจนแรงดันขึ้นถึง 63.2 % ของความสูงขั้น เวลานั้นคือ τ หรือวัดเวลาขาขึ้น 10–90 % แล้วหารด้วย 2.2 อย่าลืมว่าความต้านทาน 50 Ω ของเครื่องกำเนิดสัญญาณรวมอยู่ใน τ ด้วย ถ้าวัดเทียบกับ emf ของเครื่อง

ทำไมค่า τ หรือ Q ที่วัดได้ไม่ตรงกับที่คำนวณจากค่าบนตัวอุปกรณ์?
สาเหตุหลักคือความต้านทานขาออก 50 Ω ของเครื่องกำเนิดสัญญาณที่อนุกรมอยู่ในวงจร ความต้านทานของขดลวดตัวเหนี่ยวนำ ความคลาดเคลื่อนของตัวเก็บประจุ (±5–20 %) และความจุของโพรบ วงจร RLC ที่ใช้ R ค่าน้อยจะได้รับผลมากที่สุด เพราะ 50 Ω อาจมากกว่า R ที่ใส่เสียอีก

ความถี่ตัด −3 dB หมายถึงอะไร?
คือความถี่ที่แรงดันขาออกเหลือ 1/√2 = 0.707 ของขาเข้า หรือกำลังเหลือครึ่งหนึ่ง สำหรับวงจร RC อันดับหนึ่ง f_c = 1/(2πRC) และที่ความถี่นี้เฟสเลื่อนไป 45° พอดี จึงหาได้สองทาง คือหาความถี่ที่อัตราส่วนเป็น 0.707 หรือหาความถี่ที่เฟสเป็น −45°

วงจร RC เป็นอินทิเกรเตอร์ได้เมื่อไร?
เมื่อความถี่ของสัญญาณสูงกว่าความถี่ตัดมาก (ครึ่งคาบสั้นกว่า τ มาก) แรงดันคร่อม C จะเปลี่ยนน้อยมากเมื่อเทียบกับขาเข้า กระแสจึงเกือบเท่ากับ v_in/R และ v_C ≈ (1/RC)∫v_in dt คลื่นสี่เหลี่ยมจึงกลายเป็นสามเหลี่ยม แต่แอมพลิจูดเล็กลง ถ้าต้องการอินทิเกรตโดยไม่ลดทอน ให้ใช้ออปแอมป์อินทิเกรเตอร์
