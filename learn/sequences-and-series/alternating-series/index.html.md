เมื่อพจน์มีทั้งบวกและลบ การหักล้างกันทำให้อนุกรมบางตัวลู่เข้าได้ทั้งที่ค่าสัมบูรณ์บวกแล้วเป็นอนันต์ หน้านี้อธิบายการทดสอบไลบ์นิซ ขอบเขตความคลาดที่ใช้งานง่ายที่สุดในคณิตศาสตร์เชิงตัวเลข ความต่างของการลู่เข้าแบบสัมบูรณ์กับแบบมีเงื่อนไข และปรากฏการณ์ที่น่าทึ่งที่สุดของบทนี้: สลับลำดับการบวกแล้วผลบวกเปลี่ยน

สรุปใน 30 วินาที

- $\sum(-1)^{n+1}b_n$ ลู่เข้าถ้า $b_n$ ลดลงและ $b_n \to 0$

- ความคลาด $|S - S_N| \le b_{N+1}$ และ S อยู่ระหว่าง $S_N$ กับ $S_{N+1}$

- $\sum|a_n|$ ลู่เข้า ⇒ $\sum a_n$ ลู่เข้า (สัมบูรณ์) · $\sum a_n$ ลู่เข้าแต่ $\sum|a_n|$ ลู่ออก = มีเงื่อนไข

- อนุกรมมีเงื่อนไขจัดเรียงใหม่ให้ได้ผลบวกเท่าใดก็ได้ (รีมันน์)

## การทดสอบอนุกรมสลับ (Leibniz Test) พื้นฐาน

อนุกรมสลับ (alternating series) มีเครื่องหมายบวก-ลบสลับกันทุกพจน์ ภาพผลบวกย่อยเป็นการกระโดดไปซ้ายทีขวาที โดยแต่ละก้าวสั้นลงเรื่อย ๆ จึงต้องหยุดที่จุดหนึ่ง ช่วงที่ผลบวกจริงอยู่ได้แคบลงทุกครั้ง (ช่วงซ้อน) นี่คือแนวคิดของการพิสูจน์

ผลบวกย่อยของ $1 - \tfrac12 + \tfrac13 - \cdots$ กระโดดข้ามผลบวกจริง ln 2 ไปมา ลำดับย่อยคี่ลดลง ลำดับย่อยคู่เพิ่มขึ้น และบีบเข้าหากัน

A1 Alternating series อนุกรมสลับ

$$\sum_{n=1}^{\infty}(-1)^{n+1}b_n = b_1 - b_2 + b_3 - b_4 + \cdots,\qquad b_n > 0$$

$\cos(n\pi) = (-1)^n$ ก็เป็นตัวสลับเครื่องหมาย · $\sin n$ ไม่ใช่ (เครื่องหมายไม่สลับทุกพจน์)

A2 Alternating series test (Leibniz) การทดสอบไลบ์นิซ

$$\text{(i) } b_{n+1} \le b_n \ \text{(เมื่อ } n \ge N)\quad \text{และ}\quad \text{(ii) } \lim_{n\to\infty} b_n = 0 \ \ \Longrightarrow\ \ \sum(-1)^{n+1}b_n \text{ ลู่เข้า}$$

พิสูจน์: $S_{2n}$ เพิ่มขึ้นและมีขอบเขตบน $b_1$, $S_{2n+1} = S_{2n} + b_{2n+1}$ จึงลู่เข้าค่าเดียวกัน (Q17 + Q19)

ตัวอย่าง A-1 · ไลบ์นิซ

### $\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n+1}\,n}{n^2+1}$ ลู่เข้าหรือไม่ และลู่เข้าแบบใด

- $b_n = \dfrac{n}{n^2+1} \to 0$ ✓

- ลดลง: $f(x) = \dfrac{x}{x^2+1}$, $f'(x) = \dfrac{1 - x^2}{(x^2+1)^2} \le 0$ เมื่อ $x \ge 1$ ✓ ⇒ อนุกรมลู่เข้า

- ค่าสัมบูรณ์ $\sum \dfrac{n}{n^2+1}$ เทียบลิมิตกับ $\sum\tfrac1n$ (ลิมิต = 1) ลู่ออก

ลู่เข้าแบบมีเงื่อนไข (conditionally convergent)

กับดักที่พบบ่อย$\sum(-1)^n\dfrac{n}{n+1}$ ไม่ผ่านไลบ์นิซเพราะ $b_n \to 1$ — และไม่ได้ “สรุปไม่ได้” แต่ลู่ออกแน่นอนด้วยการทดสอบพจน์ที่ n เสมอเช็กพจน์ที่ n ก่อน

## ขอบเขตความคลาดเคลื่อนของอนุกรมสลับ กลาง

ข้อดีที่สุดของอนุกรมสลับคือรู้ความคลาดเคลื่อนได้ทันทีโดยไม่ต้องรู้ผลบวกจริง: ความคลาดไม่เกินพจน์แรกที่ตัดทิ้ง นี่คือเหตุผลที่โปรแกรมคำนวณ $\sin x$, $\cos x$ หรือ $\ln(1+x)$ จากอนุกรมรู้ว่าต้องหยุดเมื่อใด

A3 Alternating series estimation theorem ขอบเขตความคลาดเคลื่อน

$$|S - S_N| \le b_{N+1},\qquad \operatorname{sgn}(S - S_N) = \operatorname{sgn}(\text{พจน์ที่ } N+1)$$

ผลบวกจริงอยู่ระหว่าง $S_N$ กับ $S_{N+1}$ เสมอ จึงใช้ค่าเฉลี่ย $\tfrac{S_N + S_{N+1}}{2}$ เป็นค่าประมาณที่ดีกว่าได้

ตัวอย่าง A-2 · ใช้กี่พจน์

### ประมาณ $\dfrac1e = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n}{n!}$ ให้คลาดไม่เกิน $10^{-4}$

- บวกถึงพจน์ $n = N$ ความคลาด $\le b_{N+1} = \dfrac{1}{(N+1)!}$ ต้องการ $(N+1)! > 10^4$

- $7! = 5040$ ไม่พอ $8! = 40320$ พอ ⇒ $N + 1 = 8$ คือบวกพจน์ $n = 0, 1, \dots, 7$ (8 พจน์)

- $S_7 = 1 - 1 + \tfrac12 - \tfrac16 + \tfrac1{24} - \tfrac1{120} + \tfrac1{720} - \tfrac1{5040} = 0.3678571$ ค่าจริง 0.3678794 คลาด $2.2\times10^{-5} \le \tfrac{1}{40320} = 2.5\times10^{-5}$ ✓

ใช้ 8 พจน์ ได้ $1/e \approx 0.36786$

ตัวอย่าง A-3 · อนุกรมไลบ์นิซของ π

### ถ้าใช้ $\pi = 4\left(1 - \tfrac13 + \tfrac15 - \cdots\right)$ ต้องใช้กี่พจน์จึงได้ π ถูกต้องทศนิยม 4 ตำแหน่ง (คลาดน้อยกว่า $5\times10^{-5}$)

- บวกถึง $n = N$ ความคลาดของ π คือ $4b_{N+1} = \dfrac{4}{2N+3}$

- $\dfrac{4}{2N+3} < 5\times10^{-5} \iff 2N + 3 > 80{,}000 \iff N \ge 39{,}999$

ต้องใช้ 40,000 พจน์ — ช้ามาก นี่คือเหตุผลที่การคำนวณ π จริงใช้สูตรของมาชิน $\tfrac{\pi}{4} = 4\arctan\tfrac15 - \arctan\tfrac{1}{239}$ ซึ่งพจน์ลดลงแบบเรขาคณิต

## ลู่เข้าแบบสัมบูรณ์ vs แบบมีเงื่อนไข กลาง

สำหรับอนุกรมที่มีพจน์บวกปนลบ (ไม่จำเป็นต้องสลับเป็นระเบียบ) ให้ทดสอบค่าสัมบูรณ์ก่อนเสมอ เพราะการทดสอบทั้งหมดในหน้าก่อนใช้กับ $\sum|a_n|$ ได้ทันที ถ้าลู่เข้าก็จบ ถ้าลู่ออกจึงค่อยตรวจด้วยไลบ์นิซหรือดีริชเลต์

A4 Absolute convergence ลู่เข้าแบบสัมบูรณ์

$$\sum|a_n| \text{ ลู่เข้า} \ \Longrightarrow\ \sum a_n \text{ ลู่เข้า และ } \left|\sum a_n\right| \le \sum|a_n|$$

พิสูจน์: $0 \le a_n + |a_n| \le 2|a_n|$ แล้วใช้การเปรียบเทียบ · ratio/root test ที่ได้ $\rho < 1$ ให้การลู่เข้าแบบสัมบูรณ์เสมอ

A5 Conditional convergence ลู่เข้าแบบมีเงื่อนไข

$$\sum a_n \text{ ลู่เข้า แต่ } \sum|a_n| \text{ ลู่ออก}$$

ตัวอย่างมาตรฐาน $\sum\dfrac{(-1)^{n+1}}{n^p}$ ที่ $0 < p \le 1$ · ถ้า $p > 1$ เป็นแบบสัมบูรณ์

A6 Classification procedure ขั้นตอนจำแนกอนุกรม

$$a_n \not\to 0 \Rightarrow \text{ลู่ออก};\quad \sum|a_n| \text{ ลู่เข้า} \Rightarrow \text{สัมบูรณ์};\quad \text{ไม่เช่นนั้น ใช้ไลบ์นิซ/ดีริชเลต์} \Rightarrow \text{มีเงื่อนไข หรือ ลู่ออก}$$

ข้อสอบมักถามคำตอบสามแบบ: ลู่เข้าแบบสัมบูรณ์ · ลู่เข้าแบบมีเงื่อนไข · ลู่ออก

ตัวอย่าง A-4 · จำแนก

### (ก) $\sum\dfrac{(-1)^n}{n^2}$ (ข) $\sum\dfrac{(-1)^n}{\sqrt n}$ (ค) $\sum\dfrac{(-1)^n\,n}{2^n}$ (ง) $\sum\dfrac{\cos(n\pi/3)}{n^2}$

- (ก) $\sum 1/n^2$ ลู่เข้า ⇒ สัมบูรณ์

- (ข) $\sum 1/\sqrt n$ ลู่ออก แต่ $1/\sqrt n$ ลดลง → 0 ⇒ มีเงื่อนไข

- (ค) อัตราส่วนของค่าสัมบูรณ์ $\dfrac{n+1}{2n} \to \tfrac12$ ⇒ สัมบูรณ์

- (ง) $\left|\dfrac{\cos(n\pi/3)}{n^2}\right| \le \dfrac{1}{n^2}$ ⇒ สัมบูรณ์ (ไม่ต้องสนใจรูปแบบเครื่องหมาย)

(ก) สัมบูรณ์ · (ข) มีเงื่อนไข · (ค) สัมบูรณ์ · (ง) สัมบูรณ์

## แล็บ: ความคลาดเคลื่อนและการจัดเรียงใหม่ พื้นฐาน

โหมด “ขอบเขตความคลาดเคลื่อน” แสดงแถบ $S_N \pm b_{N+1}$ ที่ต้องครอบผลบวกจริง และคำนวณจำนวนพจน์ที่ต้องใช้ โหมด “จัดเรียงใหม่” ใช้พจน์ $1, \tfrac13, \tfrac15, \dots$ และ $-\tfrac12, -\tfrac14, \dots$ ครบทุกตัว แต่เปลี่ยนลำดับให้ได้ผลบวกตามเป้า

## ทฤษฎีบทการจัดเรียงใหม่ของรีมันน์ ขั้นสูง

ในอนุกรมฮาร์มอนิกสลับ พจน์บวก $1 + \tfrac13 + \tfrac15 + \cdots$ รวมกันเป็นอนันต์ และพจน์ลบก็รวมกันเป็นลบอนันต์ เมื่อมี “งบไม่จำกัด” ทั้งสองฝั่ง เราจึงเลือกบวกตัวบวกจนเกินเป้า แล้วบวกตัวลบจนต่ำกว่าเป้า สลับไปเรื่อย ๆ เนื่องจากพจน์เล็กลงสู่ 0 การแกว่งรอบเป้าจึงแคบลงจนลู่เข้าสู่เป้า

พจน์ชุดเดียวกัน ลำดับต่างกัน: ลำดับปกติลู่เข้า ln 2 ≈ 0.693 แต่แบบ “บวก 2 ลบ 1” ลู่เข้า (3/2) ln 2 ≈ 1.040

A7 Riemann rearrangement theorem การจัดเรียงใหม่ของรีมันน์

$$\sum a_n \text{ ลู่เข้าแบบมีเงื่อนไข} \Rightarrow \forall\, T \in [-\infty, \infty]\ \exists \text{ การจัดเรียง } \sigma:\ \sum a_{\sigma(n)} = T$$

ลู่เข้าแบบสัมบูรณ์ ⇒ ทุกการจัดเรียงให้ผลบวกเท่าเดิม (ทฤษฎีบทของดีริชเลต์)

A8 p positive : q negative บวก p ตัว ลบ q ตัว

$$\underbrace{1 + \tfrac13 + \cdots}_{p\ \text{ตัว}} \underbrace{- \tfrac12 - \cdots}_{q\ \text{ตัว}} + \cdots = \ln 2 + \frac12\ln\frac{p}{q}$$

(1:2) ให้ $\tfrac12\ln 2$ · (1:4) ให้ $0$ พอดี · (4:1) ให้ $2\ln 2$

ตัวอย่าง A-5 · บวก 1 ลบ 2

### แสดงว่า $1 - \tfrac12 - \tfrac14 + \tfrac13 - \tfrac16 - \tfrac18 + \tfrac15 - \tfrac1{10} - \tfrac1{12} + \cdots = \tfrac12\ln 2$

- จัดกลุ่มทีละสามพจน์: $\left(\dfrac{1}{2k-1} - \dfrac{1}{4k-2}\right) - \dfrac{1}{4k}$ และ $\dfrac{1}{2k-1} - \dfrac{1}{2(2k-1)} = \dfrac{1}{2(2k-1)}$

- แต่ละกลุ่มจึงเป็น $\dfrac{1}{2(2k-1)} - \dfrac{1}{4k} = \dfrac12\left(\dfrac{1}{2k-1} - \dfrac{1}{2k}\right)$

- รวมทุกกลุ่ม $= \dfrac12\left(1 - \tfrac12 + \tfrac13 - \tfrac14 + \cdots\right) = \dfrac12\ln 2$ (การจัดกลุ่มนี้ใช้ได้เพราะพจน์ → 0)

$\tfrac12\ln 2 \approx 0.3466$ — ครึ่งหนึ่งของลำดับเดิม ทั้งที่ใช้พจน์ชุดเดียวกัน

ทำไมวิศวกรต้องสนใจเวลาคอมพิวเตอร์บวกเลขทศนิยมลอยตัวจำนวนมาก ลำดับการบวกมีผลต่อผลลัพธ์อยู่แล้ว (round-off) สำหรับอนุกรมที่ลู่เข้าแบบมีเงื่อนไข ลำดับยังเปลี่ยนค่าทางคณิตศาสตร์ด้วย การประมวลผลแบบขนานที่แบ่งพจน์ไปบวกคนละเครื่องจึงต้องใช้อนุกรมที่ลู่เข้าแบบสัมบูรณ์เท่านั้น

## การทดสอบดีริชเลต์และอาเบล ขั้นสูง

ไลบ์นิซเป็นกรณีพิเศษของการทดสอบที่ทั่วไปกว่า: ถ้าผลบวกย่อยของส่วนที่ “แกว่ง” มีขอบเขต และอีกส่วนลดลงสู่ศูนย์ อนุกรมลู่เข้า ใช้กับอนุกรมของไซน์-โคไซน์ซึ่งเป็นพื้นฐานของอนุกรมฟูริเยร์

A9 Dirichlet's test การทดสอบของดีริชเลต์

$$\left|\sum_{k=1}^{N} a_k\right| \le M\ \forall N,\quad b_n \downarrow 0\ \Rightarrow\ \sum a_n b_n \text{ ลู่เข้า}$$

$\left|\sum_{k=1}^{N}\sin k\right| \le \dfrac{1}{\sin(1/2)} \approx 2.09$ ⇒ $\sum\dfrac{\sin n}{n} = \dfrac{\pi - 1}{2}$ ลู่เข้า · ไลบ์นิซคือ $a_n = (-1)^{n+1}$

A10 Abel's test การทดสอบของอาเบล

$$\sum a_n \text{ ลู่เข้า},\ (b_n) \text{ ทางเดียวและมีขอบเขต} \Rightarrow \sum a_n b_n \text{ ลู่เข้า}$$

เช่น $\sum\dfrac{(-1)^n}{n}\left(1 + \dfrac1n\right)^n$ ลู่เข้า เพราะ $(1 + 1/n)^n$ เพิ่มขึ้นและไม่เกิน e

## ผลคูณโคชีของอนุกรม ขั้นสูง

คูณอนุกรมสองชุดเหมือนคูณพหุนาม โดยรวมพจน์ที่ดัชนีบวกกันได้ n ผลคูณนี้คือคอนโวลูชันแบบไม่ต่อเนื่อง (discrete convolution) ตัวเดียวกับในระบบดิจิทัลและการแปลง Z

A11 Cauchy product & Mertens' theorem ผลคูณโคชีและทฤษฎีบทของเมอร์เทนส์

$$\left(\sum_{n=0}^{\infty} a_n\right)\left(\sum_{n=0}^{\infty} b_n\right) = \sum_{n=0}^{\infty} c_n,\quad c_n = \sum_{k=0}^{n} a_k b_{n-k}$$

ใช้ได้เมื่ออย่างน้อยหนึ่งอนุกรมลู่เข้าแบบสัมบูรณ์ (เมอร์เทนส์) · ตัวอย่างโต้แย้ง: ยกกำลังสอง $\sum\dfrac{(-1)^n}{\sqrt{n+1}}$ ได้ $|c_n| \ge \dfrac{2(n+1)}{n+2} \not\to 0$ ลู่ออก

ตัวอย่าง A-6 · ผลคูณโคชี

### ใช้ผลคูณโคชีแสดงว่า $e^x e^y = e^{x+y}$ จากอนุกรม $e^x = \sum\dfrac{x^n}{n!}$

- $c_n = \sum_{k=0}^{n}\dfrac{x^k}{k!}\cdot\dfrac{y^{n-k}}{(n-k)!} = \dfrac{1}{n!}\sum_{k=0}^{n}\binom{n}{k}x^k y^{n-k} = \dfrac{(x+y)^n}{n!}$ (ทฤษฎีบททวินาม)

- อนุกรมของ $e^x$ ลู่เข้าแบบสัมบูรณ์ทุก x ⇒ เมอร์เทนส์ใช้ได้ ⇒ $e^xe^y = \sum\dfrac{(x+y)^n}{n!} = e^{x+y}$

กฎเลขยกกำลังพิสูจน์ได้จากอนุกรมโดยตรง

## ต่อไป: อนุกรมที่มีตัวแปร x

เมื่อพจน์ขึ้นกับ x เช่น $\sum \dfrac{x^n}{n}$ อนุกรมลู่เข้าหรือไม่ขึ้นกับค่า x และที่ปลายช่วงมักเจออนุกรมสลับแบบในหน้านี้ ไปต่อที่ อนุกรมกำลังและรัศมีการลู่เข้า · ทบทวน การทดสอบการลู่เข้า · ทดลองทุกเครื่องมือใน แล็บรวม

## คำถามที่พบบ่อย

การทดสอบอนุกรมสลับ (Leibniz test) มีเงื่อนไขอะไร?
อนุกรม $\sum (-1)^{n+1} b_n$ โดย $b_n > 0$ จะลู่เข้าถ้า (1) $b_n$ ลดลง (อย่างน้อยเมื่อ n มากพอ) และ (2) $b_n \to 0$ ถ้าเงื่อนไข (2) ไม่จริง อนุกรมลู่ออกด้วยการทดสอบพจน์ที่ n ถ้าเงื่อนไข (1) ไม่จริง การทดสอบนี้สรุปไม่ได้

ลู่เข้าแบบสัมบูรณ์กับแบบมีเงื่อนไขต่างกันอย่างไร?
ลู่เข้าแบบสัมบูรณ์ (absolutely) คือ $\sum |a_n|$ ลู่เข้า ซึ่งทำให้ $\sum a_n$ ลู่เข้าแน่นอน ลู่เข้าแบบมีเงื่อนไข (conditionally) คือ $\sum a_n$ ลู่เข้าแต่ $\sum |a_n|$ ลู่ออก เช่น $1 - \tfrac12 + \tfrac13 - \cdots$ อนุกรมแบบหลังเปราะบาง: สลับลำดับพจน์แล้วผลบวกเปลี่ยนได้

ความคลาดเคลื่อนของอนุกรมสลับประมาณอย่างไร?
ถ้าอนุกรมผ่านการทดสอบไลบ์นิซ ผลบวกจริงอยู่ระหว่างผลบวกย่อยสองตัวติดกันเสมอ จึงได้ $|S - S_N| \le b_{N+1}$ คือความคลาดไม่เกินพจน์แรกที่ตัดทิ้ง และเครื่องหมายของความคลาดเหมือนเครื่องหมายของพจน์นั้น

ทฤษฎีบทการจัดเรียงใหม่ของรีมันน์บอกอะไร?
อนุกรมที่ลู่เข้าแบบมีเงื่อนไขสามารถจัดลำดับพจน์ใหม่ให้ผลบวกเป็นจำนวนจริงใดก็ได้ หรือให้ลู่ออกก็ได้ เพราะผลบวกของพจน์บวกและพจน์ลบต่างก็เป็นอนันต์ ส่วนอนุกรมที่ลู่เข้าแบบสัมบูรณ์จัดเรียงอย่างไรก็ได้ผลบวกเท่าเดิม

Σ sin(n)/n ลู่เข้าไหม ในเมื่อเครื่องหมายไม่สลับเป็นระเบียบ?
ลู่เข้า ด้วยการทดสอบของดีริชเลต์: ผลบวกย่อยของ $\sin n$ มีขอบเขต (ไม่เกินประมาณ 2.09) และ $1/n$ ลดลงเข้าหา 0 ผลบวกจริงคือ $(\pi - 1)/2$ แต่ $\sum |\sin n|/n$ ลู่ออก จึงลู่เข้าแบบมีเงื่อนไข
