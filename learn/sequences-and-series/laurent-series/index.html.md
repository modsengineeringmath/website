# อนุกรมโลรองต์ (Laurent Series): บริเวณวงแหวน ภาวะเอกฐาน เรซิดิว และการแปลง Z

// บทที่ 26.7 · ลำดับและอนุกรม · Laurent Series


อนุกรมเทย์เลอร์ใช้ไม่ได้รอบจุดที่ฟังก์ชันระเบิด เช่น $\tfrac{1}{z}$ ที่ 0 ปีแยร์ อัลฟองส์ โลรองต์ (1843) แก้ด้วยการยอมให้มีกำลังลบ อนุกรมที่ได้ลู่เข้าบน “วงแหวน” ระหว่างจุดเอกฐาน และสัมประสิทธิ์ตัวเดียว $a_{-1}$ ก็พอสำหรับคำนวณอินทิกรัลรอบเส้นปิดทั้งหมด หน้านี้ใช้แค่อนุกรมเรขาคณิตเป็นเครื่องมือหลัก แล้วต่อยอดไปถึงเรซิดิว การแปลงลาปลาซผกผัน และการแปลง Z ที่วิศวกรไฟฟ้าใช้ทุกวัน

สรุปใน 30 วินาที

- $f(z) = \sum_{n=-\infty}^{\infty} a_n (z-c)^n$ บนวงแหวน $r_1 < |z-c| < r_2$ · กำลังลบ = ส่วนหลัก

- เครื่องมือหลัก: $\dfrac{1}{z-p}$ กระจายเป็นกำลังบวกเมื่อ $|z| < |p|$ และกำลังลบเมื่อ $|z| > |p|$

- ส่วนหลัก: ไม่มี = ถอดได้ · จำกัด = โพล · อนันต์ = เอกฐานแท้

- $\operatorname{Res}_{z=c}f = a_{-1}$ และ $\oint_C f\,dz = 2\pi i\sum\operatorname{Res}$ · การแปลง Z คืออนุกรมโลรองต์รอบ 0

ระดับพื้นฐาน แนวคิด · อนุกรมเรขาคณิตกลาง คณิตศาสตร์วิศวกรรมขั้นสูง ตัวแปรเชิงซ้อน

## ทำไมต้องมีอนุกรมโลรองต์ พื้นฐาน

จากอนุกรมกำลัง เราเห็นว่าอนุกรมเทย์เลอร์ลู่เข้าในดิสก์ที่ขยายได้จนชนจุดเอกฐานแรก ถ้าจุดศูนย์กลางเป็นจุดเอกฐานเสียเอง ดิสก์มีรัศมีศูนย์ ใช้ไม่ได้เลย แต่ฟังก์ชันอย่าง $\tfrac{e^z}{z^2}$ ก็ยังประพฤติดีในบริเวณ “รอบ ๆ” 0 แค่ไม่ใช่ที่ 0 เอง ถ้าเราตัดจุด 0 ทิ้งเหลือเป็นวงแหวนเจาะ ก็เขียนได้ว่า

$$\frac{e^z}{z^2} = \frac{1}{z^2}\left(1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \cdots\right) = \underbrace{\frac{1}{z^2} + \frac{1}{z}}_{\text{ส่วนหลัก}} + \underbrace{\frac12 + \frac{z}{6} + \cdots}_{\text{ส่วนวิเคราะห์}},\quad 0 < |z| < \infty$$

นี่คืออนุกรมโลรองต์: มีกำลังลบได้ ส่วนกำลังลบเรียกว่าส่วนหลัก (principal part) เพราะเป็นตัวกำหนดพฤติกรรมใกล้จุดเอกฐาน ต้องรู้พื้นฐานจำนวนเชิงซ้อนก่อน ทบทวนได้ที่ จำนวนเชิงซ้อนและฟังก์ชันวิเคราะห์

L1 Laurent series อนุกรมโลรองต์

$$f(z) = \sum_{n=-\infty}^{\infty} a_n (z - c)^n = \underbrace{\sum_{n=1}^{\infty}\frac{a_{-n}}{(z-c)^n}}_{\text{ส่วนหลัก (principal part)}} + \underbrace{\sum_{n=0}^{\infty} a_n (z-c)^n}_{\text{ส่วนวิเคราะห์ (analytic part)}}$$

ลู่เข้าเมื่อทั้งสองส่วนลู่เข้า: ส่วนวิเคราะห์ลู่เข้าเมื่อ $|z - c| < r_2$ ส่วนหลักลู่เข้าเมื่อ $|z - c| > r_1$ จึงได้วงแหวน

L2 Laurent's theorem ทฤษฎีบทโลรองต์

$$f \text{ วิเคราะห์ใน } r_1 < |z - c| < r_2 \ \Rightarrow\ f(z) = \sum_{n=-\infty}^{\infty} a_n (z-c)^n \text{ แบบเดียว},\quad a_n = \frac{1}{2\pi i}\oint_{|z-c|=\rho}\frac{f(z)}{(z-c)^{n+1}}\,dz$$

“แบบเดียว” สำคัญที่สุด: หาด้วยวิธีใดก็ได้ (อนุกรมเรขาคณิต แทนอนุกรมที่รู้) ไม่ต้องคำนวณอินทิกรัล · $r_1$ อาจเป็น 0, $r_2$ อาจเป็น ∞

## เครื่องมือหลัก: อนุกรมเรขาคณิตสองทิศ พื้นฐาน

ฟังก์ชันตรรกยะเกือบทั้งหมดกระจายได้ด้วยเทคนิคเดียว: แยกเศษส่วนย่อย แล้วกระจาย $\tfrac{1}{z - p}$ แต่ละตัว ถ้าบริเวณที่สนใจอยู่ในวงกลม $|z| = |p|$ ให้ดึง p ออก ถ้าอยู่นอก ให้ดึง z ออก เพื่อให้ได้อัตราส่วนที่ขนาดน้อยกว่า 1 เสมอ

L3 1/(z − p) inside and outside กระจาย 1/(z − p) สองแบบ

$$|z| < |p|:\ \frac{1}{z-p} = -\frac1p\cdot\frac{1}{1 - z/p} = -\sum_{n=0}^{\infty}\frac{z^n}{p^{n+1}};\qquad |z| > |p|:\ \frac{1}{z-p} = \frac1z\cdot\frac{1}{1 - p/z} = \sum_{n=0}^{\infty}\frac{p^n}{z^{n+1}}$$

รอบจุดศูนย์กลาง c แทน z ด้วย $z - c$ และ p ด้วย $p - c$ · โพลซ้ำ $\tfrac{1}{(z-p)^m}$ ใช้อนุกรมทวินาม $(1-u)^{-m} = \sum\binom{m+j-1}{j}u^j$

## ตัวอย่างคลาสสิก: 1/((z−1)(z−2)) ทั้งสามบริเวณ กลาง

โพลที่ $z = 1$ และ $z = 2$ แบ่งระนาบรอบ 0 ออกเป็นสามบริเวณ แต่ละบริเวณมีอนุกรมของตัวเอง โจทย์นี้ออกข้อสอบคณิตศาสตร์วิศวกรรมแทบทุกมหาวิทยาลัย

สามบริเวณรอบ 0 ของ $f(z) = \frac{1}{(z-1)(z-2)}$: ดิสก์ |z| < 1 (เทย์เลอร์), วงแหวน 1 < |z| < 2 และภายนอก |z| > 2 วงกลมแบ่งเขตผ่านโพลพอดี

ตัวอย่าง L-1 · สามบริเวณ

### หาอนุกรมโลรองต์ของ $f(z) = \dfrac{1}{(z-1)(z-2)}$ ใน (ก) $|z| < 1$ (ข) $1 < |z| < 2$ (ค) $|z| > 2$

- แยกเศษส่วนย่อย: $f(z) = \dfrac{1}{z-2} - \dfrac{1}{z-1}$

- (ก) $|z| < 1$ อยู่ในทั้งสองวงกลม ใช้ L3 แบบ “ใน” ทั้งคู่: $\dfrac{1}{z-2} = -\sum\dfrac{z^n}{2^{n+1}}$, $-\dfrac{1}{z-1} = \sum z^n$ ⇒ $f = \sum_{n=0}^{\infty}\left(1 - \dfrac{1}{2^{n+1}}\right)z^n = \dfrac12 + \dfrac34 z + \dfrac78 z^2 + \cdots$ (เป็นเทย์เลอร์)

- (ข) $1 < |z| < 2$: นอกวงกลมของ 1 ใน 2 · $-\dfrac{1}{z-1} = -\sum_{n=0}^{\infty}\dfrac{1}{z^{n+1}}$ (แบบ “นอก”) ⇒ $f = -\sum_{n=1}^{\infty}\dfrac{1}{z^n} - \sum_{n=0}^{\infty}\dfrac{z^n}{2^{n+1}} = \cdots - \dfrac{1}{z^2} - \dfrac1z - \dfrac12 - \dfrac{z}{4} - \dfrac{z^2}{8} - \cdots$

- (ค) $|z| > 2$: “นอก” ทั้งคู่: $\dfrac{1}{z-2} = \sum\dfrac{2^n}{z^{n+1}}$ ⇒ $f = \sum_{n=0}^{\infty}\dfrac{2^n - 1}{z^{n+1}} = \dfrac{1}{z^2} + \dfrac{3}{z^3} + \dfrac{7}{z^4} + \cdots$

(ก) $\sum(1 - 2^{-n-1})z^n$ · (ข) $-\sum_{n\ge1}z^{-n} - \sum_{n\ge0}2^{-n-1}z^n$ · (ค) $\sum_{n\ge2}(2^{n-1} - 1)z^{-n}$ — สามอนุกรม ฟังก์ชันเดียว

ตัวอย่าง L-2 · รอบโพล

### ฟังก์ชันเดิม กระจายรอบ $z = 1$ ในวงแหวนเจาะ $0 < |z - 1| < 1$ แล้วหาเรซิดิวที่ z = 1

- ให้ $w = z - 1$: $f = \dfrac{1}{w(w - 1)} = -\dfrac1w\cdot\dfrac{1}{1 - w}$

- $|w| < 1$: $\dfrac{1}{1-w} = 1 + w + w^2 + \cdots$ ⇒ $f = -\dfrac1w - 1 - w - w^2 - \cdots$

$f = -\dfrac{1}{z-1} - 1 - (z-1) - (z-1)^2 - \cdots$ · โพลอย่างง่าย · $\operatorname{Res}_{z=1} f = -1$

## แล็บวงแหวนโลรองต์ พื้นฐาน

เลือกฟังก์ชัน จุดศูนย์กลาง และบริเวณ แล็บแสดงอนุกรม สัมประสิทธิ์ (แท่งส้ม = ส่วนหลัก) และชนิดของจุดศูนย์กลาง ลากจุดเขียว z ในระนาบ: ในวงแหวนผลบวกย่อยลู่เข้าหา f(z) ออกนอกวงแหวนแล้วความคลาดพุ่งขึ้น แม้ f(z) เองจะมีค่าปกติ

## กระจายจากอนุกรมที่รู้แล้ว กลาง

ฟังก์ชันที่ไม่ใช่ตรรกยะ ใช้ตารางอนุกรมแมคลอรินแล้วหารหรือแทนค่า ความเป็นหนึ่งเดียว (L2) รับประกันว่าคำตอบถูก

ตัวอย่าง L-3 · ใช้ตารางแมคลอริน

### หาอนุกรมโลรองต์รอบ 0 และเรซิดิวของ (ก) $e^{1/z}$ (ข) $\dfrac{\sin z}{z^4}$ (ค) $\dfrac{e^z - 1}{z}$ (ง) $z^2 e^{1/z}$

- (ก) แทน $u = 1/z$ ใน $e^u$: $e^{1/z} = 1 + \dfrac1z + \dfrac{1}{2!\,z^2} + \dfrac{1}{3!\,z^3} + \cdots$ ($|z| > 0$) ส่วนหลักอนันต์พจน์ · $\operatorname{Res} = 1$

- (ข) $\dfrac{1}{z^4}\left(z - \dfrac{z^3}{6} + \dfrac{z^5}{120} - \cdots\right) = \dfrac{1}{z^3} - \dfrac{1}{6z} + \dfrac{z}{120} - \cdots$ · โพลอันดับ 3 · $\operatorname{Res} = -\tfrac16$

- (ค) $\dfrac1z\left(z + \dfrac{z^2}{2} + \cdots\right) = 1 + \dfrac{z}{2} + \dfrac{z^2}{6} + \cdots$ ไม่มีกำลังลบ · ถอดได้ (นิยาม f(0) = 1) · $\operatorname{Res} = 0$

- (ง) $z^2\sum\dfrac{1}{n!\,z^n} = z^2 + z + \dfrac12 + \dfrac{1}{6z} + \dfrac{1}{24z^2} + \cdots$ · $a_{-1}$ มาจาก n = 3 · $\operatorname{Res} = \tfrac16$

Res: (ก) 1 · (ข) −1/6 · (ค) 0 · (ง) 1/6 — ข้อ (ง) สูตรลิมิตใช้ไม่ได้เพราะเป็นเอกฐานแท้ ต้องใช้อนุกรมเท่านั้น

## ชนิดของจุดเอกฐานโดดเดี่ยว กลาง

จุด c เป็นจุดเอกฐานโดดเดี่ยว (isolated singularity) ถ้า f วิเคราะห์ในวงแหวนเจาะ $0 < |z - c| < r$ แต่ไม่วิเคราะห์ที่ c อนุกรมโลรองต์ในวงแหวนนี้บอกชนิดได้ทันทีจากจำนวนพจน์ในส่วนหลัก

ขนาด |f(z)| ใกล้จุดเอกฐานสามชนิด: ถอดได้ (มีขอบเขต) · โพล (โตเป็นอนันต์ทุกทิศ) · เอกฐานแท้ (พฤติกรรมขึ้นกับทิศที่เข้าใกล้)

L4 Removable singularity จุดเอกฐานที่ถอดได้

$$a_{-n} = 0\ \forall n \ge 1 \iff \lim_{z\to c} f(z) \text{ มีค่าจำกัด}$$

เช่น $\tfrac{\sin z}{z}$, $\tfrac{e^z - 1}{z}$ ที่ 0 · “แก้” ได้ด้วยการนิยามค่าที่ c

L5 Pole of order m โพลอันดับ m

$$a_{-m} \ne 0,\ a_{-n} = 0\ (n > m) \iff (z-c)^m f(z) \text{ วิเคราะห์และไม่เป็นศูนย์ที่ } c$$

$|f| \to \infty$ เมื่อ $z \to c$ · m = 1 เรียกโพลอย่างง่าย (simple pole) · ศูนย์อันดับ m ของตัวส่วน ⇒ โพลอันดับ m (ถ้าตัวเศษไม่เป็นศูนย์)

L6 Essential singularity จุดเอกฐานแท้

$$a_{-n} \ne 0 \text{ สำหรับ } n \text{ จำนวนอนันต์}$$

คาโซราตี-ไวแยร์สตราส: ใกล้ c ค่าของ f เข้าใกล้ทุกจำนวนเชิงซ้อน · $e^{1/z}$ → ∞ ตามแกนจริงบวก → 0 ตามแกนจริงลบ

วิธีบอกอันดับโพลโดยไม่กระจายอนุกรมถ้า $f = g/h$, $g(c) \ne 0$ และ h มีศูนย์อันดับ m ที่ c แล้ว f มีโพลอันดับ m เช่น $\dfrac{1}{\sin^2 z}$ มีโพลอันดับ 2 ที่ทุก $z = k\pi$ · ถ้า g ก็เป็นศูนย์ที่ c ด้วย ให้หักลบอันดับ เช่น $\dfrac{\sin z}{z^4}$: ศูนย์อันดับ 1 บน ศูนย์อันดับ 4 ล่าง ⇒ โพลอันดับ 3

## เรซิดิวและทฤษฎีบทเรซิดิว กลาง

อินทิกรัลรอบวงกลมของ $(z - c)^n$ เป็นศูนย์ทุก n ยกเว้น n = −1 ซึ่งได้ $2\pi i$ เมื่ออินทิกรัลอนุกรมโลรองต์ทีละพจน์ ทุกพจน์หายไปเหลือแค่ $2\pi i\,a_{-1}$ สัมประสิทธิ์ตัวนี้จึงได้ชื่อว่า “เรซิดิว” (residue = ส่วนที่เหลือ)

L7 Residue เรซิดิว

$$\operatorname{Res}_{z=c} f = a_{-1} = \frac{1}{2\pi i}\oint_{|z-c|=\rho} f(z)\,dz$$

มาจาก $\oint (z-c)^n dz = 2\pi i$ ถ้า $n = -1$ และ 0 ถ้า $n \ne -1$

L8 Residue formulas สูตรหาเรซิดิว

$$\text{โพลอย่างง่าย: } \lim_{z\to c}(z-c)f(z) = \frac{g(c)}{h'(c)}\ \left(f = \tfrac{g}{h}\right);\qquad \text{อันดับ } m:\ \frac{1}{(m-1)!}\lim_{z\to c}\frac{d^{m-1}}{dz^{m-1}}\Big[(z-c)^m f(z)\Big]$$

เอกฐานแท้: ต้องกระจายอนุกรม · สูตร g/h′ คือสิ่งที่ใช้ในInverse Laplace แบบ Heaviside

L9 Residue theorem ทฤษฎีบทเรซิดิว

$$\oint_C f(z)\,dz = 2\pi i\sum_{k}\operatorname{Res}_{z=z_k} f \qquad (z_k \text{ อยู่ภายใน } C,\ C \text{ วนทวนเข็มนาฬิกา})$$

เปลี่ยนอินทิกรัลเป็นการหาสัมประสิทธิ์ · ใช้หาอินทิกรัลจริงที่ยาก อินเวอร์สลาปลาซ (Bromwich) และอินเวอร์ส Z

ตัวอย่าง L-4 · อินทิกรัลเส้นปิด

### คำนวณ $\displaystyle\oint_{|z|=3}\frac{e^z}{z(z-2)}\,dz$

- โพลอย่างง่ายที่ 0 และ 2 อยู่ใน $|z| = 3$ ทั้งคู่

- $\operatorname{Res}_{0} = \lim_{z\to0} z f = \dfrac{e^0}{0 - 2} = -\dfrac12$ · $\operatorname{Res}_{2} = \lim_{z\to2}(z-2)f = \dfrac{e^2}{2}$

- $\oint = 2\pi i\left(\dfrac{e^2}{2} - \dfrac12\right) = \pi i\,(e^2 - 1)$

$\pi i(e^2 - 1) \approx 20.07\,i$ · ถ้าใช้วงกลม $|z| = 1$ จะได้เฉพาะเรซิดิวที่ 0: $-\pi i$

ตัวอย่าง L-5 · อินทิกรัลจริงด้วยเรซิดิว

### (ก) $\displaystyle\int_{-\infty}^{\infty}\frac{dx}{(x^2+1)^2}$ (ข) $\displaystyle\int_0^{2\pi}\frac{d\theta}{2 + \cos\theta}$

- (ก) ปิดเส้นทางด้วยครึ่งวงกลมบน (อินทิกรัลบนครึ่งวงกลม → 0) โพลในครึ่งบนคือ $z = i$ อันดับ 2: $\operatorname{Res} = \dfrac{d}{dz}\left[\dfrac{1}{(z+i)^2}\right]_{z=i} = \dfrac{-2}{(2i)^3} = \dfrac{1}{4i}$

## การแปลง Z คืออนุกรมโลรองต์ ขั้นสูง

สำหรับวิศวกรไฟฟ้า นี่คือเหตุผลที่สำคัญที่สุดในการเรียนอนุกรมโลรองต์ การแปลง Z ของสัญญาณไม่ต่อเนื่อง $x[n]$ นิยามเป็นอนุกรมโลรองต์รอบ 0 โดยตรง เรื่องที่ตำราระบบสัญญาณเรียกว่า “บริเวณการลู่เข้า (ROC)” คือวงแหวนของหน้านี้ และการหาการแปลงผกผันคือการเลือกวงแหวนให้ถูกแล้วกระจายด้วยอนุกรมเรขาคณิต (เทียบกับ ROC ของลาปลาซในโพล-ซีโร่และ ROC)

L10 Z-transform = Laurent series การแปลง Z คืออนุกรมโลรองต์

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n},\qquad \text{ROC} = \{ r_1 < |z| < r_2 \},\qquad x[n] = \frac{1}{2\pi i}\oint X(z)\,z^{n-1}\,dz$$

$$a^n u[n] \longleftrightarrow \frac{z}{z-a},\ |z| > |a|;\qquad -a^n u[-n-1] \longleftrightarrow \frac{z}{z-a},\ |z| < |a|$$

## เชื่อมกับการแปลงลาปลาซผกผัน ขั้นสูง

สูตรผกผันของลาปลาซ (Bromwich) เป็นอินทิกรัลเส้นในระนาบ s ซึ่งปิดเส้นทางแล้วใช้ทฤษฎีบทเรซิดิวได้: $f(t) = \sum \operatorname{Res}\left[F(s)e^{st}\right]$ ที่โพลทั้งหมดของ F(s) วิธีแยกเศษส่วนย่อยแบบ Heaviside cover-up คือสูตร L8 นั่นเอง ดูวิธีทำครบทุกกรณีที่ Inverse Laplace Transform

L13 Inverse Laplace by residues อินเวอร์สลาปลาซด้วยเรซิดิว

$$f(t) = \frac{1}{2\pi i}\int_{\gamma - i\infty}^{\gamma + i\infty}F(s)e^{st}\,ds = \sum_{\text{โพล } s_k}\operatorname{Res}_{s=s_k}\left[F(s)\,e^{st}\right],\quad t > 0$$

ตัวอย่าง $F(s) = \tfrac{1}{s(s+2)}$: Res ที่ 0 = ½ · Res ที่ −2 = $-\tfrac12e^{-2t}$ ⇒ $f(t) = \tfrac12(1 - e^{-2t})$
