# แนวข้อสอบลำดับและอนุกรม (Exam Practice): เตรียมสอบเข้ามหาวิทยาลัย มิดเทอม และไฟนอล พร้อมเฉลยละเอียดและโจทย์สุ่ม

// บทที่ 26.9 · ลำดับและอนุกรม · Exam Practice


60 ข้อเรียงจากระดับมัธยมปลายถึงคณิตศาสตร์วิศวกรรม ทุกข้อซ่อนเฉลยไว้ให้ลองทำเองก่อน แต่ละเฉลยบอกเครื่องมือที่ใช้และลิงก์กลับไปยังหัวข้อในบทเรียน ปิดท้ายด้วยเครื่องสุ่มโจทย์ไม่จำกัดที่ตรวจคำตอบให้ทันที และเกมฝึกเลือกการทดสอบ

วิธีใช้หน้านี้

- อ่านโจทย์ ลองทำในกระดาษ 3–5 นาที แล้วค่อยแตะ “เฉลย” เพื่อเทียบ

- ผิดข้อไหน ให้กดลิงก์ในเฉลยกลับไปอ่านหัวข้อนั้น แล้วฝึกหมวดเดียวกันในเครื่องสุ่มโจทย์

- ชุด A ≈ A-Level / TCAS · ชุด B ≈ มิดเทอม-ไฟนอลแคลคูลัส 2 · ชุด C ≈ คณิตศาสตร์วิศวกรรม / ตัวแปรเชิงซ้อน

## ชุด A · เตรียมสอบเข้ามหาวิทยาลัย (20 ข้อ) พื้นฐาน

A1ลำดับเลขคณิตมี $a_3 = 7$ และ $a_8 = 22$ จงหา $S_{20}$
$a_8 - a_3 = 5d = 15 \Rightarrow d = 3,\ a_1 = 1$ · $S_{20} = \tfrac{20}{2}\left(2\cdot1 + 19\cdot3\right) = 10\times59$

A2จำนวนเต็มระหว่าง 100 ถึง 500 ที่หารด้วย 7 ลงตัวมีกี่จำนวน และผลบวกเท่าใด
ตัวแรก 105 ตัวสุดท้าย 497 · $n = \tfrac{497 - 105}{7} + 1 = 57$ · $S = \tfrac{57}{2}(105 + 497) = 57\times301$
57 จำนวน ผลบวก 17,157

A3ลำดับเรขาคณิตมี $a_2 = 12$ และ $a_5 = 96$ จงหา $S_6$

A10$\lim\dfrac{3^{n+1} + 2^n}{3^n - 2^{n+1}}$

A12สามจำนวนเป็นลำดับเลขคณิต ผลบวก 18 ผลคูณ 120 จงหาสามจำนวนนั้น

A13อนุกรมเรขาคณิตอนันต์มีผลบวก 12 และผลบวกของพจน์ตำแหน่งคี่ (พจน์ที่ 1, 3, 5, …) เท่ากับ 9 จงหา a และ r

## ชุด B · แคลคูลัส 2 มิดเทอม-ไฟนอล (20 ข้อ) กลาง

B1$\displaystyle\sum_{n=1}^{\infty}\frac{n^2 + 1}{n^3 + 2n}$ ลู่เข้าหรือลู่ออก
เทียบลิมิตกับ $\tfrac1n$: $\lim\dfrac{n^3 + n}{n^3 + 2n} = 1$ ฮาร์มอนิกลู่ออก
ลู่ออก · T5

B2$\displaystyle\sum_{n=1}^{\infty}\frac{n^2}{2^n}$ ลู่เข้าหรือไม่ ถ้าลู่เข้าหาผลบวก
อัตราส่วน $\tfrac{(n+1)^2}{2n^2} \to \tfrac12$ ลู่เข้า · สูตร $\sum n^2r^n = \dfrac{r(1+r)}{(1-r)^3} = \dfrac{(1/2)(3/2)}{1/8}$
ลู่เข้า ผลบวก 6

B3$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^n}{\sqrt n + 1}$ ลู่เข้าแบบใด
$b_n = \tfrac{1}{\sqrt n + 1}$ ลดลง → 0 ลู่เข้า (ไลบ์นิซ) · ค่าสัมบูรณ์เทียบลิมิตกับ $1/\sqrt n$ ลู่ออก
ลู่เข้าแบบมีเงื่อนไข · A5

B4$\displaystyle\sum_{n=1}^{\infty}\ln\left(1 + \frac{1}{n^2}\right)$
$\ln(1 + u) \sim u$ ⇒ เทียบลิมิตกับ $1/n^2$ ได้ 1
ลู่เข้า · T6

B5$\displaystyle\sum_{n=1}^{\infty}\frac{2^n + n}{3^n - n}$
ตัวเด่น $(2/3)^n$: $\lim\dfrac{(2^n + n)/(3^n - n)}{(2/3)^n} = 1$ อนุกรมเรขาคณิต r = 2/3 ลู่เข้า
ลู่เข้า

B6หาผลบวก $\displaystyle\sum_{n=1}^{\infty} n e^{-n}$
$\sum nr^n = \dfrac{r}{(1-r)^2}$ กับ $r = e^{-1}$: $\dfrac{e^{-1}}{(1 - e^{-1})^2} = \dfrac{e}{(e-1)^2}$
$\dfrac{e}{(e-1)^2} \approx 0.9207$

B7หาช่วงการลู่เข้าของ $\displaystyle\sum_{n=1}^{\infty}\frac{(x+1)^n}{n\,3^n}$
อัตราส่วน $\tfrac{|x+1|}{3}$ ⇒ $R = 3$ รอบ −1 · x = −4: $\sum\tfrac{(-1)^n}{n}$ ลู่เข้า · x = 2: $\sum\tfrac1n$ ลู่ออก
$[-4, 2)$ · P5

B8หาช่วงการลู่เข้าของ $\displaystyle\sum_{n=1}^{\infty}\frac{n\,x^n}{2^n(n+1)}$
อัตราส่วน $\tfrac{|x|}{2}$ ⇒ $R = 2$ · ที่ $x = \pm2$: $|a_n| = \tfrac{n}{n+1} \to 1 \ne 0$ ลู่ออกทั้งสองปลาย
$(-2, 2)$

B9หาช่วงการลู่เข้าของ $\displaystyle\sum_{n=1}^{\infty}\frac{(x-1)^{2n}}{9^n\,n^2}$
อนุกรมใน $u = (x-1)^2/9$: ลู่เข้าเมื่อ $|x - 1| < 3$ · ปลาย: $\sum\tfrac{1}{n^2}$ ลู่เข้าทั้งคู่
$[-2, 4]$

B10หารัศมีการลู่เข้าของ $\displaystyle\sum_{n=0}^{\infty}\frac{n!\,x^n}{(2n)!}$
$\left|\tfrac{c_{n+1}}{c_n}\right| = \dfrac{n+1}{(2n+2)(2n+1)} = \dfrac{1}{2(2n+1)} \to 0$
$R = \infty$

B11อนุกรมแมคลอรินของ $x^2e^{-x}$ ถึงพจน์ $x^5$
$x^2\left(1 - x + \tfrac{x^2}{2} - \tfrac{x^3}{6} + \cdots\right)$
$x^2 - x^3 + \tfrac{x^4}{2} - \tfrac{x^5}{6}$ · Y16

B12อนุกรมเทย์เลอร์ของ $\tfrac1x$ รอบ $a = 2$ และช่วงการลู่เข้า
$\dfrac{1}{2 + (x-2)} = \dfrac12\cdot\dfrac{1}{1 + \frac{x-2}{2}} = \sum_{n=0}^{\infty}\dfrac{(-1)^n(x-2)^n}{2^{n+1}}$ · ลู่เข้าเมื่อ $|x - 2| < 2$
$\sum\tfrac{(-1)^n(x-2)^n}{2^{n+1}}$, ช่วง $(0, 4)$

B13$\lim_{x\to0}\dfrac{e^{x^2} - 1 - x^2}{x^4}$
$e^{x^2} = 1 + x^2 + \tfrac{x^4}{2} + \cdots$
$\tfrac12$ · ลิมิตด้วยอนุกรม

B14$\lim_{x\to0}\dfrac{\ln(1+x) - x + x^2/2}{x^3}$
$\ln(1+x) = x - \tfrac{x^2}{2} + \tfrac{x^3}{3} - \cdots$
$\tfrac13$

B15$\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n\pi^{2n+1}}{4^{2n+1}(2n+1)!}$
เป็นอนุกรมของ $\sin x$ ที่ $x = \tfrac{\pi}{4}$

B16$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n\,2^n}$
$\ln(1+x) = \sum\tfrac{(-1)^{n+1}x^n}{n}$ ที่ $x = \tfrac12$

B17ประมาณ $\displaystyle\int_0^{0.5}\frac{dx}{1 + x^4}$ ให้คลาดไม่เกิน $10^{-4}$
$\dfrac{1}{1+x^4} = 1 - x^4 + x^8 - \cdots$ อินทิกรัล: $0.5 - \tfrac{0.5^5}{5} + \tfrac{0.5^9}{9} - \tfrac{0.5^{13}}{13} + \cdots$ · พจน์ที่สี่ $9.4\times10^{-6} < 10^{-4}$ จึงพอที่สามพจน์: $0.5 - 0.00625 + 0.000217$
≈ 0.49397 (ค่าจริง 0.493958)

B18ต้องบวก $\sum 1/n^4$ กี่พจน์ ความคลาดจึงน้อยกว่า $10^{-4}$ (ใช้ขอบเขตปริพันธ์)
$R_N \le \int_N^\infty x^{-4}dx = \dfrac{1}{3N^3} < 10^{-4} \iff N^3 > 3333.3$ · $14^3 = 2744,\ 15^3 = 3375$
15 พจน์ · T3

B19ประมาณ $\cos 0.3$ ด้วย $P_4$ และหาขอบเขตความคลาด
$1 - \tfrac{0.09}{2} + \tfrac{0.0081}{24} = 0.9553375$ · อนุกรมสลับ: $|R| \le \tfrac{0.3^6}{720} = 1.01\times10^{-6}$
0.9553375 ± 1.0×10⁻⁶ (จริง 0.9553365)

B20$\displaystyle\sum_{n=3}^{\infty}\frac{1}{n\ln n\,\ln(\ln n)}$

ลู่ออก · T2

## ชุด C · คณิตศาสตร์วิศวกรรมขั้นสูง (20 ข้อ) ขั้นสูง

C1อนุกรมโลรองต์ของ $\dfrac{1}{z(z-2)}$ ใน (ก) $0 < |z| < 2$ (ข) $|z| > 2$
$\dfrac{1}{z(z-2)} = \dfrac12\left(\dfrac{1}{z-2} - \dfrac1z\right)$ · (ก) $\dfrac{1}{z-2} = -\sum\dfrac{z^n}{2^{n+1}}$ · (ข) $\dfrac{1}{z-2} = \sum\dfrac{2^n}{z^{n+1}}$ แล้วพจน์ $\tfrac{1}{2z}$ หักล้าง
(ก) $-\tfrac{1}{2z} - \tfrac14 - \tfrac{z}{8} - \tfrac{z^2}{16} - \cdots$ · (ข) $\tfrac{1}{z^2} + \tfrac{2}{z^3} + \tfrac{4}{z^4} + \cdots$ · L-1

C2เรซิดิวของ $\dfrac{z}{(z-1)(z+2)^2}$ ที่ทุกโพล
z = 1 (อย่างง่าย): $\dfrac{1}{9}$ · z = −2 (อันดับ 2): $\dfrac{d}{dz}\left[\dfrac{z}{z-1}\right]_{-2} = \dfrac{-1}{(z-1)^2}\Big|_{-2} = -\dfrac19$
$\tfrac19$ และ $-\tfrac19$ (ผลรวมเป็น 0 เพราะดีกรีล่างมากกว่าบน 2)

C3$\displaystyle\oint_{|z|=2}\frac{z^2 + 1}{z(z-1)}\,dz$
Res ที่ 0: $\tfrac{1}{-1} = -1$ · Res ที่ 1: $\tfrac{2}{1} = 2$ · รวม 1
$2\pi i$ · L9

C4$\displaystyle\int_{-\infty}^{\infty}\frac{dx}{x^2 + 4x + 5}$
โพล $-2 \pm i$ ครึ่งบน $-2 + i$: Res $= \tfrac{1}{2i}$ ⇒ $2\pi i\cdot\tfrac{1}{2i}$

C5$\displaystyle\int_{-\infty}^{\infty}\frac{\cos x}{x^2 + 1}\,dx$
ใช้ $\dfrac{e^{iz}}{z^2+1}$ (บนครึ่งบน $|e^{iz}| \le 1$) Res ที่ i: $\dfrac{e^{-1}}{2i}$ ⇒ ส่วนจริงของ $2\pi i\cdot\dfrac{e^{-1}}{2i}$
$\dfrac{\pi}{e} \approx 1.1557$

C6จำแนกจุด z = 0 ของ $\dfrac{1 - \cos z}{z^5}$ และหาเรซิดิว
$\dfrac{1}{z^5}\left(\tfrac{z^2}{2} - \tfrac{z^4}{24} + \cdots\right) = \dfrac{1}{2z^3} - \dfrac{1}{24z} + \cdots$
โพลอันดับ 3 · Res $= -\tfrac{1}{24}$

C7จำแนกจุด z = 0 ของ $z\sin\dfrac1z$
$z\left(\tfrac1z - \tfrac{1}{6z^3} + \tfrac{1}{120z^5} - \cdots\right) = 1 - \tfrac{1}{6z^2} + \cdots$ ส่วนหลักอนันต์พจน์
เอกฐานแท้ · Res = 0 (ไม่มีพจน์ $z^{-1}$)

C8หา x[n] จาก $X(z) = \dfrac{2z}{z - 0.8},\ |z| > 0.8$
คู่พื้นฐาน $a^nu[n] \leftrightarrow \tfrac{z}{z-a}$ ROC ข้างนอก
$x[n] = 2(0.8)^n u[n]$ · L11

C9หา x[n] จาก $X(z) = \dfrac{1}{1 - 3z^{-1}},\ |z| < 3$
$\dfrac{z}{z - 3}$ ROC ข้างใน ⇒ กระจายกำลังบวกของ z: $-\sum_{m\ge1}3^{-m}z^m$ ⇒ ข้างซ้าย

## 10 ความผิดพลาดที่เสียคะแนนบ่อยที่สุด

- สรุปว่า “$a_n \to 0$ จึงลู่เข้า” — การทดสอบพจน์ที่ n สรุปได้แค่ลู่ออก

- ใช้ $\tfrac{a}{1-r}$ ทั้งที่ $|r| \ge 1$ หรือใช้ a = 1 ทั้งที่พจน์แรกไม่ใช่ 1

- กล้องส่องทางไกลที่มีช่องว่าง k เหลือพจน์แค่ตัวเดียว (ต้องเหลือ k ตัว)

- ใช้ ratio test กับเศษส่วนของพหุนาม แล้วงงที่ได้ 1

- เปรียบเทียบตรงแต่ทิศของอสมการผิด (เทียบกับตัวใหญ่ที่ลู่ออก)

- ลืมตรวจปลายช่วงของอนุกรมกำลัง หรือใช้ ratio test ที่ปลายช่วง

- $(2x-1)^n$ ระบุจุดศูนย์กลางเป็น 1 แทนที่จะเป็น ½

- หาลิมิตลำดับเวียนเกิดโดยแทน L = g(L) โดยไม่พิสูจน์ว่าลู่เข้า

- อนุกรมโลรองต์ใช้บริเวณผิด (ไม่ได้ดูว่าโพลอยู่ในหรือนอกวงแหวน)

- สูตรเรซิดิวแบบลิมิตกับจุดเอกฐานแท้ (ต้องกระจายอนุกรม)

ข้อสอบลำดับและอนุกรมเข้ามหาวิทยาลัยออกเรื่องอะไรบ้าง?
