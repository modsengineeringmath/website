# หลักการเบื้องต้น: ห่วงโซ่การวัด ความคลาดเคลื่อน และการตอบสนอง

// บทที่ 20.1 · Sensors & Transducers · Fundamentals


เซนเซอร์ (sensor) ทำอะไร ต่างจากทรานส์ดิวเซอร์ (transducer) อย่างไร สเปกที่เห็นในดาต้าชีตหมายความว่าอะไร พร้อมแล็บ 3 ชุดให้ลองปรับเอง

## 1 · ห่วงโซ่การวัด (measuring chain)

ปริมาณทางกายภาพไม่เดินทางเข้าคอมพิวเตอร์โดยตรง ต้องผ่านลำดับขั้น: เซนเซอร์ (sensor) รับรู้ปริมาณ → ภาคปรับสภาพสัญญาณ ทำให้สัญญาณมีขนาดและรูปแบบที่เหมาะสม → ตัวแปลง A/D → ซอฟต์แวร์ แปลงกลับเป็นหน่วยวิศวกรรม VIM เรียกลำดับนี้ว่า measuring chain (3.10) ความคลาดเคลื่อนของทุกขั้นสะสมเข้าด้วยกัน

## 2 · เซนเซอร์เปลี่ยนปริมาณเป็นสัญญาณได้อย่างไร

เซนเซอร์ส่วนใหญ่อาศัยปรากฏการณ์ทางฟิสิกส์เพียงไม่กี่แบบ แบ่งได้เป็นสองตระกูล: แบบ passive (ต้องมีแหล่งกระตุ้น เช่น กระแสหรือแรงดันกระตุ้น) และ แบบ active/self-generating (สร้างแรงดันหรือประจุเอง)

| ปรากฏการณ์ | ชนิด | ตัวอย่างเซนเซอร์ | ปริมาณที่เปลี่ยน |

| ความต้านทานเปลี่ยนตามอุณหภูมิ | passive | RTD (Pt100), เทอร์มิสเตอร์ | R |

| ความต้านทานเปลี่ยนตามความเครียด | passive | สเตรนเกจ โหลดเซลล์ ความดันแบบพีโซรีซิสทีฟ | ΔR/R = GF·ε |

| เทอร์โมอิเล็กทริก (Seebeck) | active | เทอร์โมคัปเปิล | แรงเคลื่อนไฟฟ้า (µV–mV) |

| พีโซอิเล็กทริก | active | เซนเซอร์สั่นสะเทือน/แรงกระแทก | ประจุ Q |

| ความจุไฟฟ้า | passive | ระยะ ระดับ ความชื้น ความดันแบบคาปาซิทีฟ | C |

| ความเหนี่ยวนำ/การเหนี่ยวนำร่วม | passive | LVDT, เซนเซอร์ใกล้เคียงแบบเหนี่ยวนำ, CT | L, M |

| ฮอลล์ (Hall) | passive | เซนเซอร์สนามแม่เหล็ก/กระแสไม่สัมผัส | VH ∝ B |

| โฟโตอิเล็กทริก | active/passive | โฟโตไดโอด เซลล์แสงอาทิตย์ เซนเซอร์แสง | กระแส/แรงดัน |

| เคมีไฟฟ้า | active/passive | pH, เซนเซอร์ออกซิเจน/แก๊ส | แรงดัน/กระแส |

RTD: R เพิ่มเกือบเป็นเส้นตรงตามอุณหภูมิ ค่า Pt100 ที่ 200 °C ≈ 175.86 Ω

เทอร์โมคัปเปิล: วัดผลต่างระหว่างจุดวัดกับจุดอ้างอิง จึงต้องชดเชย cold junction ชนิด K ให้ ≈ 41 µV/°C

สเตรนเกจ: ตัวนำเส้นบางเรียงขนาน ยืดแล้ว R เพิ่ม ค่า GF ทั่วไปประมาณ 2 สำหรับฟอยล์โลหะ

ตัวอย่างคำนวณ: สเตรนเกจ GF = 2 รับความเครียด ε = 1000 µε → ΔR/R = 2 × 1000×10⁻⁶ = 2×10⁻³ บริดจ์ 1/4 ให้ Vo/Vex ≈ GF·ε/4 = 0.5 mV/V เมื่อกระตุ้นด้วย 10 V ได้ราว 5 mV จึงต้องขยายสัญญาณก่อนเข้า ADC

R(T) = R0(1 + A·T + B·T²) · A = 3.9083×10⁻³ °C⁻¹, B = −5.775×10⁻⁷ °C⁻² (0–850 °C, Pt100 ตาม IEC 60751)

## 3 · คุณลักษณะสถิต (static characteristics)

บอกว่าเซนเซอร์ทำงานเที่ยงตรงเพียงใดเมื่ออินพุตเปลี่ยนช้ามาก ศัพท์ด้านล่างอิงความหมายตาม VIM และแนวปฏิบัติทางเครื่องมือวัด

| คุณลักษณะ | ความหมาย | ข้อควรระวัง |

| ช่วงวัด (range) / สแปน (span) | ช่วงของปริมาณที่เซนเซอร์วัดได้ตามสเปก / ผลต่างปลายบน–ปลายล่าง | "FS" คือ full scale = span ของช่วงวัด |

| ความไว (sensitivity) S | S = Δy/Δx ความชันของเส้นโค้งอินพุต–เอาต์พุต | หน่วยมีมิติ เช่น mV/V, mV/bar, µV/°C |

| ออฟเซ็ต/ศูนย์ (offset, zero error) | เอาต์พุตเมื่ออินพุตเป็นศูนย์ ที่ควรเป็นศูนย์ | ปรับได้โดย "zeroing/tare" |

| ความไม่เป็นเส้นตรง (nonlinearity) | ส่วนเบี่ยงเบนสูงสุดจากเส้นตรงอ้างอิง | ต้องบอกว่าเทียบเส้นตรงแบบใด (best-fit, end-point) |

| ฮิสเทอรีซิส (hysteresis) | ผลต่างของเอาต์พุตที่อินพุตเดียวกัน เมื่อวัดขาขึ้นเทียบขาลง | สูงสุดมักอยู่กลางสเกล |

| ความซ้ำได้ (repeatability) | ผลวัดใกล้เคียงกันเมื่อวัดซ้ำภายใต้เงื่อนไขเดิม | ไม่เท่ากับความถูกต้อง |

| ความละเอียด (resolution) | การเปลี่ยนแปลงที่เล็กที่สุดที่แสดง/ตรวจพบได้ | ADC 16 บิตให้ 1 ส่วนใน 65 536 ของสเกล แต่ความถูกต้องอาจแย่กว่านั้นมาก |

| ความถูกต้อง (accuracy) | ความใกล้เคียงของค่าที่วัดกับค่าจริงของปริมาณ | เป็นแนวคิดเชิงคุณภาพ ตัวเลขที่แท้คือ "ความไม่แน่นอน" (ดูบทมาตรวิทยา) |

| ดริฟต์ (drift) | การเปลี่ยนค่าเมื่อเวลาผ่านไปหรืออุณหภูมิเปลี่ยน | ระบุเป็น %FS/ปี, ppm/°C |

อ่านสเปกให้เป็น: "±0.5 %FS" หมายถึงความคลาดคงที่เท่ากันทุกจุดของสเกล ส่วน "±0.5 %RDG" (ของค่าที่อ่าน) ลดลงตามค่าที่อ่านได้ ตัวอย่างโหลดเซลล์ 100 kg ± 0.1 %FS = ± 0.1 kg ทุกที่ ถ้าวัดของหนัก 5 kg ความคลาด 0.1 kg คิดเป็น 2 %RDG แล้ว เลือกช่วงวัดให้ค่าปกติอยู่ราว 50–80 % ของสเกล

## 4 · คุณลักษณะพลวัต (dynamic characteristics)

เซนเซอร์จริงไม่ตอบสนองทันที เซนเซอร์อุณหภูมิต้องรอให้ความร้อนไหลเข้าปลายวัด ระบบส่วนใหญ่จำลองได้ด้วยระบบอันดับหนึ่งที่มีค่าคงตัวเวลา τ:

τ·dy/dt + y = S·x(t) ⇒ y(t) = S·x∞(1 − e−t/τ) · |H(jω)| = 1/√(1 + (ωτ)²) · fc = 1/(2πτ)

แนวคิดเดียวกับแล็บ ระบบอันดับหนึ่ง ในบทที่ 9 ที่นี่นำมาใช้กับเซนเซอร์ที่วัดได้จริง เช่น เทอร์โมคัปเปิลเปลือยในอากาศ τ ≈ วินาที ส่วนในปลอกโลหะในของเหลวอาจเป็นสิบวินาที

// แล็บ 3 · การตอบสนองเวลา

### เซนเซอร์ที่ช้าอ่านค่าผิดไปเท่าไร

ค่าคงตัวเวลา τ (วินาที)
ความถี่อินพุตไซน์ (Hz)

กฎจำง่าย: รอ ≈ 5τ จึงเข้าใกล้ค่าจริง 99.3 % และถ้าต้องการวัดสัญญาณที่เปลี่ยนเร็วขึ้นต้องเลือกเซนเซอร์ที่ τ น้อยลง ไม่ใช่เพียงขยายสัญญาณ

## 5 · เช็กลิสต์เลือกเซนเซอร์

- ปริมาณและช่วงวัด: ค่าปกติ ค่าสูงสุดชั่วขณะ (overload) ค่าต่ำสุดที่ต้องแยกได้

- ความไม่แน่นอนที่ยอมรับได้: ต้องดีกว่าข้อกำหนดของงานอย่างน้อย 3–4 เท่า (แนวปฏิบัติของห้องสอบเทียบเรียกว่า TUR 4:1)

- เวลาตอบสนอง: τ และความถี่ที่ต้องการวัด

- เอาต์พุต: mV, 0–10 V, 4–20 mA, ดิจิทัล และต้องมีภาคปรับสภาพหรือไม่

- สภาพแวดล้อม: อุณหภูมิ ความชื้น การสั่นสะเทือน EMC และระดับ IP

- มาตรฐานและใบรับรอง: ที่ต้องการสอบกลับได้ ใบ Ex, SIL (ดูบท มาตรฐานไฟฟ้า)

- ต้นทุนทั้งวงจรชีวิต: สอบเทียบ บำรุงรักษา อะไหล่
