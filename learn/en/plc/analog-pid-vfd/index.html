    From raw counts to engineering units Basic

    P1 Linear scaling

    y=ymin+(x−xmin) ymax−yminxmax−xminy = y_{min} + (x - x_{min})\,\frac{y_{max} - y_{min}}{x_{max} - x_{min}}y=ymin​+(x−xmin​)xmax​−xmin​ymax​−ymin​​

    P2 Resolution per raw count

    Δy=ymax−yminxmax−xmine.g. 10 bar27648=0.36 mbar\Delta y = \frac{y_{max} - y_{min}}{x_{max} - x_{min}} \qquad \text{e.g. } \frac{10\ \text{bar}}{27648} = 0.36\ \text{mbar}Δy=xmax​−xmin​ymax​−ymin​​e.g. 2764810 bar​=0.36 mbar

    Example P-1

    Scaling a raw value of 13824 with INT gives zero

    1. Wrong: Bar := Raw / 27648 * 10; in INT → 13824/27648 = 0 (truncated) → 0 bar

    2. Also wrong: Raw * 10 / 27648 in INT → 27648 × 10 = 276480 overflows INT

    3. Right: Bar := INT_TO_REAL(Raw) * 10.0 / 27648.0; → 5.0 bar

    4. Check P3: Siemens modules return negative raw values when the current is below 4 mA (down to −4864 ≈ 1.185 mA), and with wire-break diagnostics enabled they report a special value (32767) — check both the raw range per P3 and the module's status bits.

    The PID block in a PLC Intermediate

    P4 PID (standard form)

    u(t)=Kp(e+1Ti∫0te dτ+Td dedt)e=SP−PVu(t) = K_p\left(e + \frac{1}{T_i}\int_0^t e\,d\tau + T_d\,\frac{de}{dt}\right) \qquad e = SP - PVu(t)=Kp​(e+Ti​1​∫0t​edτ+Td​dtde​)e=SP−PV

    P5 Discrete PID (sample time TsT_sTs​)

    uk=Kp(ek+TsTi∑j=0kej−TdTs(PVk−PVk−1))u_k = K_p\left(e_k + \frac{T_s}{T_i}\sum_{j=0}^{k} e_j - \frac{T_d}{T_s}(PV_k - PV_{k-1})\right)uk​=Kp​(ek​+Ti​Ts​​j=0∑k​ej​−Ts​Td​​(PVk​−PVk−1​))

    The derivative term uses PV instead of e (derivative on measurement) so the output does not kick when SP changes, and anti-windup is needed: when the output hits its limit (e.g. 50 Hz), stop accumulating the integral. Most pump and fan loops use PI only (Td = 0) because pressure signals are noisy.

    Initial tuning for a constant-pressure pump

    1. Start with a small Kp (e.g. 0.5 of full scale), a long Ti (e.g. 5 s) and Td = 0
    2. Increase Kp until it starts to oscillate, then halve it
    3. Reduce Ti gradually until the value returns to setpoint quickly enough without oscillating (typically 1–5 s for water pressure)
    4. Test by actually opening and closing taps, watching both the dip and the overshoot

    Try the effect of Kp, Ti and Td in the PID lab (Thai), and a pressure loop with a VFD pump in the virtual instrumentation lab (Thai).

    Example P-2

    The PLC sends 4–20 mA to a VFD ranged 20–50 Hz; 42 Hz is wanted

    Frequently asked questions

    Is it better to run PID in the PLC or in the VFD?

    For a single loop where the transmitter can be wired straight into the VFD, the drive's own PID is simple, responds quickly and keeps working even if the PLC fails. If several pumps must be coordinated, there are many conditions, or the loop must be logged and adjusted from SCADA, PID in the PLC is more flexible.

    What value do I send over Modbus to command 35.5 Hz?

    It depends on the register units in the drive manual. Many drives use 0.01 Hz units, so you send 3550. Some use a fraction of maximum frequency, e.g. 0–16384 or 0–10000 = 0–100 %. Always read the manual and test with a low value first.
