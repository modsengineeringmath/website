    Frequently asked questions

    How detailed is this table?

    It gives every degree from 0° to 360° for all six functions, rounded to six decimal places, and every value was recomputed by program. A dash (—) marks an undefined value such as tan 90°. For angles with decimals or minutes and seconds, use the lookup at the top of the page, which works for any angle.

    How do I find an angle from a sine value?

    Switch the lookup to “value → angle”, choose sin and type the value, for example 0.6. It returns the principal value arcsin 0.6 ≈ 36.87° and every angle from 0° to 360°, namely 36.87° and 143.13°, together with the general solution and a link to the nearest row of the table.

    Why did old printed tables stop at 90°?

    Because the value at any other angle follows from its reference angle between 0° and 90°, with the sign set by the quadrant, and the identity sin(90° − θ) = cos θ halves the table again. This page lists the full 360° so you can check an answer at once without converting, but it is still worth practising reference angles.

    How do I find the value at an angle between rows, such as 37.4°?

    Use linear interpolation between the two neighbouring rows: sin 37.4° ≈ sin 37° + 0.4(sin 38° − sin 37°) ≈ 0.607354, which differs from the true value 0.607376 only in the fifth decimal place. Or type 37.4 into the lookup to get the exact value.
