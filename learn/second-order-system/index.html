ตำแหน่งขั้วบอกทุกอย่าง

  • ระยะจากจุดกำเนิด คือ ωn ขั้วที่อยู่บนวงกลมเดียวกันมีความเร็วโดยรวมเท่ากัน
  • มุม θ วัดจากแกนจริงลบ กำหนด ζ จึงกำหนด %OS เส้นรัศมีที่มุมเดียวกันให้ %OS เท่ากัน
  • ส่วนจริง σ = ζωn กำหนดอัตราการลดลง เปลือก e−σte^{-\sigma t}e−σt มีค่าคงตัวเวลา τ=1/σ\tau = 1/\sigmaτ=1/σ และเวลาเข้าที่ ts≈4τt_s \approx 4\tauts​≈4τ

คำถามที่พบบ่อย

อัตราส่วนการหน่วง ζ คืออะไร?

เป็นตัวเลขไร้หน่วยที่บอกว่าระบบสูญเสียพลังงานเร็วแค่ไหนเมื่อเทียบกับการแกว่ง ζ เพียงตัวเดียวกำหนดรูปร่างของผลตอบสนอง ได้แก่ ไม่หน่วง (ζ = 0) หน่วงน้อย (0 < ζ < 1) หน่วงวิกฤต (ζ = 1) และหน่วงมาก (ζ > 1) และกำหนดเปอร์เซ็นต์พุ่งเกินโดยตรง

ทำไมนิยมออกแบบให้ ζ ≈ 0.707?

เพราะเป็นค่าที่สมดุลระหว่างความเร็วกับการพุ่งเกิน พุ่งเกินเพียงประมาณ 4.3% ไม่มียอดเรโซแนนซ์ใน Bode plot และขั้วอยู่ที่มุม 45° พอดี

ζ กับ ωn ตัวไหนทำให้ระบบเร็วขึ้น?

ωn ทำหน้าที่ยืดหรือหดแกนเวลาเท่านั้น เพิ่ม ωn เป็นสองเท่า ทุกอย่างเกิดเร็วขึ้นสองเท่าโดยรูปร่างเหมือนเดิม ส่วน ζ เปลี่ยนรูปร่าง เวลาเข้าที่ประมาณ 4/(ζωn)4/(\zeta\omega_n)4/(ζωn​) จึงขึ้นกับผลคูณ ζωn\zeta\omega_nζωn​ ซึ่งคือระยะของขั้วจากแกนจินตภาพ

ωn กับ ωd ต่างกันอย่างไร?

ωn คือความถี่ที่ระบบจะแกว่งถ้าไม่มีการหน่วงเลย ส่วน ωd = ωn1−ζ2\omega_n\sqrt{1-\zeta^2}ωn​1−ζ2​ คือความถี่ที่แกว่งจริงเมื่อมีการหน่วง บนระนาบ s ωn คือระยะจากจุดกำเนิดถึงขั้ว และ ωd คือส่วนจินตภาพของขั้ว
