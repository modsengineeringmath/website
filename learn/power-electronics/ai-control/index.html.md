# AI ช่วยควบคุมและวินิจฉัยคอนเวอร์เตอร์: ปรับจูนอัตโนมัติ RL วินิจฉัยจากรูปคลื่น และ LLM

// บทที่ 15.15 · อิเล็กทรอนิกส์กำลัง · AI-Assisted Control & Diagnosis


แบ่งชั้นให้ปลอดภัย ลูปเร็วต้องเชิงกำหนด AI อยู่ชั้นกำกับ ปรับจูนอัตโนมัติ RL วินิจฉัยความผิดพลาดจากรูปคลื่น บำรุงรักษาเชิงพยากรณ์ และใช้ LLM เป็นผู้ช่วยออกแบบ

สรุปใน 30 วินาที

- ลูปกระแสและ OCP ต้องเชิงกำหนด AI ห้ามแตะ

- AI ปรับพารามิเตอร์ภายในขอบเขตที่ clamp

- คุณลักษณะรูปคลื่นบอก L ESR Rds(on) slope comp และ PM

- ทุกคำตอบของ LLM ต้องคำนวณซ้ำ ซิม และวัดจริง

## หลักความปลอดภัยข้อแรก

ลูปในที่เร็ว (กระแส, OCP) ต้องเป็นอัลกอริทึมเชิงกำหนด (deterministic) ที่พิสูจน์เสถียรภาพได้ AI ทำงานในชั้น กำกับดูแล (supervisory): ปรับพารามิเตอร์ วางแผน ทำนาย วินิจฉัย — ภายใต้ขอบเขตที่ถูก clamp เสมอ

[AI/ML: จูน, ทำนาย, วินิจฉัย] ← ms–ชั่วโมง
│ ปรับ Kp, Ki, Vref, โหมด (มีขอบเขต)
[ลูปแรงดัน PI / Type III] ← 100 µs–ms
[ลูปกระแส + OCP ฮาร์ดแวร์] ← µs (ห้าม AI แตะ)

## ตัวอย่าง: วินิจฉัยจากรูปคลื่น

คุณลักษณะที่วัดได้ง่ายและสื่อความหมาย:

- $\Delta i_L$ เทียบค่าทฤษฎี → L ลดลง (แกนแตก/อิ่มตัว)

- ripple $v_o$ ที่ $f_s$ / $\Delta i_L$ → ESR ตัวเก็บประจุ

- ประสิทธิภาพลดที่โหลดเท่าเดิม → $R_{ds(on)}$/ไดโอดเสื่อม

- ripple ความถี่ $f_s/2$ → subharmonic (slope comp ไม่พอ)

- การแกว่งความถี่ต่ำหลัง step load → phase margin ต่ำ

ใช้ ห้องแลปจำลอง สร้างชุดข้อมูล: เปลี่ยน L, ESR, $R_{on}$ แบบสุ่ม บันทึกค่าที่วัดได้ → ฝึกโมเดลจำแนก — เป็นหัวข้อโครงงาน/วิทยานิพนธ์ที่ดี

## ใช้ LLM (เช่น Claude) เป็นผู้ช่วยวิศวกร

ได้ผลดีเมื่อให้ข้อมูลครบและขอให้แสดงที่มา:

ออกแบบตัวชดเชย Type III สำหรับ buck: Vin 18–30 V, Vo 12 V, Io 0.2–2 A,
L 100 µH ±20%, Cout 100 µF ESR 20 mΩ, fs 100 kHz, ramp 1 V, ตัวแบ่ง 2.5/12
ต้องการ PM ≥ 55° ทุกมุม ให้แสดงสมการ ค่า R C มาตรฐาน E24 และสคริปต์ Python ตรวจ margin
ต้องตรวจทุกครั้ง ด้วยการคำนวณซ้ำ ซิม และวัดจริง — LLM อาจคำนวณผิดหรืออ้างค่าในดาต้าชีตผิด

## แนวทางวิจัยระดับปริญญาโท

- Physics-informed neural network (PINN) เป็นแบบจำลองของคอนเวอร์เตอร์

- Safe RL ที่มี control barrier function รับประกันขอบเขต

- Federated learning สำหรับ fleet ของ EV charger / อินเวอร์เตอร์โซลาร์

- TinyML บน MCU (STM32/ESP32) สำหรับวินิจฉัย ณ หน้างาน
