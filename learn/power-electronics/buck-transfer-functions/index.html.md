# ฟังก์ชันถ่ายโอนของบั๊กทุกคู่อินพุต–เอาต์พุต: Gvd Gvg Zout Zin GiLd พร้อมที่มาและเครื่องวัดสัญญาณเล็กเสมือน

// บทที่ 15.5 · อิเล็กทรอนิกส์กำลัง · Buck Transfer Functions — Gvd, Gvg, Zout, Zin, GiLd


จากเมทริกซ์สเตตสเปซสัญญาณเล็ก เราได้ฟังก์ชันถ่ายโอนครบทุกคู่ — แค่เปลี่ยนว่าจะ "ป้อนอะไร" และ "วัดอะไร" หน้านี้แสดงที่มาของทั้ง 12 รูปแบบด้วยสูตรเดียว พร้อมรูปปิดที่แม่นยำเมื่อมี DCR และ ESR แบบ DCM อันดับหนึ่ง และเครื่องวัดสัญญาณเล็กเสมือนที่ฉีดไซน์ใส่วงจรสวิตชิ่งจริงเพื่อพิสูจน์

สรุปใน 30 วินาที

- $G(s) = C\,(sI-A)^{-1}B + E$ — เลือกคอลัมน์ $B$ ตามอินพุต เลือกแถว $C$ ตามเอาต์พุต

- ตัวส่วนเดียวกันทุกแบบ: $\Delta(s) = LCs^2 + \tfrac LR s + 1$ → $\omega_0 = 1/\sqrt{LC}$, $Q = R\sqrt{C/L}$

- $G_{vd} = V_g/\Delta$ · $G_{vg} = D/\Delta$ · $Z_{out} = sL/\Delta$ · $Z_{in} = \dfrac{R}{D^2}\cdot\dfrac{\Delta}{1+sRC}$

- ใน DCM ลดเหลือขั้วเดียว $G_{vd} = G_{d0}/(1+s/\omega_p)$

## แผนที่: ทำไมมีฟังก์ชันถ่ายโอนหลายรูปแบบ พื้นฐาน

ฟังก์ชันถ่ายโอนคือ อัตราส่วนของเอาต์พุตหนึ่งต่ออินพุตหนึ่ง ขณะที่อินพุตตัวอื่นถูกตรึงเป็นศูนย์ บั๊กมีสามอินพุตที่เราเปลี่ยนได้ (หรือถูกเปลี่ยนโดยโลกภายนอก) และมีเอาต์พุตที่น่าสนใจหลายตัว:

- $\hat d$ ดิวตี้ — ตัวควบคุมสั่งเอง (control input)

- $\hat v_g$ แรงดันอินพุต — แหล่งจ่ายผันผวน (line disturbance)

- $\hat i_x$ กระแสโหลดที่เปลี่ยน — โหลดดึงมากขึ้น (load disturbance) นิยามเป็นแหล่งกระแสขนานกับ R

เอาต์พุตที่ใช้บ่อย: แรงดันขาออก $\hat v_o$ · กระแสตัวเหนี่ยวนำ $\hat i_L$ (ใช้ออกแบบ current mode) · กระแสตัวเก็บประจุ $\hat i_C$ · กระแสอินพุตเฉลี่ย $\hat i_g$ (ใช้ดูปฏิสัมพันธ์กับตัวกรองอินพุต) เพราะระบบเป็นเชิงเส้น จึงใช้หลักการซ้อนทับ:

$$\hat v_o(s) = G_{vd}(s)\,\hat d(s) + G_{vg}(s)\,\hat v_g(s) - Z_{out}(s)\,\hat i_x(s)$$

| เอาต์พุต \ อินพุต | $\hat d$ (ดิวตี้) | $\hat v_g$ (แรงดันอินพุต) | $\hat i_x$ (กระแสโหลด) |

| $\hat v_o$ | $G_{vd}$ ใช้ออกแบบตัวชดเชย | $G_{vg}$ ความไวต่อแรงดันอินพุต (audio susceptibility) | $-Z_{out}$ ผลของโหลดเปลี่ยน (load step) |

| $\hat i_L$ | $G_{iLd}$ current mode · จำกัดกระแส | $G_{iLg}$ | $G_{iLx}$ |

| $\hat i_C$ | $G_{iCd}$ | $G_{iCg}$ | $G_{iCx}$ |

| $\hat i_g$ | $G_{igd}$ | $Y_{in} = 1/Z_{in}$ ปฏิสัมพันธ์กับตัวกรองอินพุต | $G_{igx}$ |

ทั้ง 12 ช่องนี้คำนวณจากเมทริกซ์ชุดเดียวกันที่ได้ในหน้าแบบจำลองเฉลี่ย ตัวส่วน $\Delta(s)$ เหมือนกันทั้งหมด (ขั้วของระบบมีชุดเดียว) ต่างกันที่ตัวเศษซึ่งกำหนดศูนย์และอัตราขยาย

## วิธีหา: สูตรเดียวใช้กับทุกคู่ กลาง

จากสมการสัญญาณเล็ก $\dot{\hat x} = A\hat x + B\hat u$, $\hat y = C\hat x + E\hat u$ แปลง Laplace (ค่าเริ่มต้นศูนย์) ได้ $s\hat x = A\hat x + B\hat u$ → $\hat x = (sI - A)^{-1}B\hat u$ แทนในสมการเอาต์พุต:

T1 Transfer function from state space ฟังก์ชันถ่ายโอนจากสเตตสเปซ

$$G(s) = \frac{\hat y(s)}{\hat u(s)} = C\,(sI - A)^{-1}B + E$$

สำหรับสเตตสเปซขนาด 2×2 ผกผันหาได้ด้วย adjugate: $(sI-A)^{-1} = \dfrac{\operatorname{adj}(sI - A)}{\Delta(s)}$ โดย

T2 Characteristic polynomial and adjugate (2×2) พหุนามลักษณะเฉพาะและ adjugate

$$\Delta(s) = \det(sI - A) = s^2 - \operatorname{tr}(A)\,s + \det A,\qquad \operatorname{adj}(sI-A) = \begin{bmatrix}s - a_{22} & a_{12}\\ a_{21} & s - a_{11}\end{bmatrix}$$

ขั้นตอนทำมือ 4 ขั้น (ใช้ซ้ำได้กับทุกคู่):

- เลือกคอลัมน์อินพุต: $B_d = \begin{bmatrix}V_g/L\\0\end{bmatrix}$ สำหรับ $\hat d$ · $B_g = \begin{bmatrix}D/L\\0\end{bmatrix}$ สำหรับ $\hat v_g$ · $B_x = \begin{bmatrix}0\\-1/C\end{bmatrix}$ สำหรับ $\hat i_x$ (บั๊กอุดมคติ)

- เลือกแถวเอาต์พุต: $C_{v} = [0\ \ 1]$ สำหรับ $\hat v_o$ · $C_{iL} = [1\ \ 0]$ สำหรับ $\hat i_L$

- คำนวณ $\operatorname{adj}(sI-A)\cdot B$ แล้วเลือกแถวตาม $C$

- หารด้วย $\Delta(s)$ แล้วจัดรูปให้พจน์คงที่ของตัวส่วนเป็น 1

## Gvd: จากดิวตี้ไปแรงดันขาออก (ทำให้ดูทีละขั้น) กลาง

บั๊กอุดมคติ: $A = \begin{bmatrix}0 & -1/L\\ 1/C & -1/(RC)\end{bmatrix}$ จาก T2: $\operatorname{tr}A = -\dfrac1{RC}$, $\det A = \dfrac1{LC}$ ดังนั้น

$$\Delta(s) = s^2 + \frac{s}{RC} + \frac1{LC},\qquad \operatorname{adj}(sI-A) = \begin{bmatrix}s + \frac1{RC} & -\frac1L\\ \frac1C & s\end{bmatrix}$$

คูณกับ $B_d = [V_g/L\ \ 0]^T$:

$$\operatorname{adj}(sI-A)\,B_d = \begin{bmatrix}\left(s + \frac1{RC}\right)\frac{V_g}{L}\\[4pt] \frac1C\cdot\frac{V_g}{L}\end{bmatrix}$$

แถวที่สองคือ $\hat v_C$ ($C_v = [0\ 1]$): $G_{vd} = \dfrac{V_g/(LC)}{\Delta(s)}$ คูณบนล่างด้วย $LC$ ให้พจน์คงที่ของตัวส่วนเป็น 1:

T3 Gvd (ideal buck) ฟังก์ชันถ่ายโอนจากดิวตี้ไปแรงดันขาออก

$$G_{vd}(s) = \frac{\hat v_o}{\hat d} = \frac{V_g}{LC\,s^2 + \dfrac{L}{R}\,s + 1}$$

เทียบกับรูปมาตรฐานอันดับสอง $\dfrac{G_0}{1 + \frac{s}{Q\omega_0} + \frac{s^2}{\omega_0^2}}$:

T4 Resonance of the LC filter เรโซแนนซ์ของตัวกรอง LC

$$G_0 = V_g,\qquad \omega_0 = \frac{1}{\sqrt{LC}},\qquad Q = R\sqrt{\frac CL},\qquad \zeta = \frac1{2Q}$$

- DC: $G_{vd}(0) = V_g$ — เพิ่มดิวตี้ 0.01 แรงดันเพิ่ม $0.01V_g$ ตรงกับ $V_o = DV_g$

- ที่ $f_0$: ขนาดเป็น $QV_g$ และเฟส $-90^\circ$ (ยอดเรโซแนนซ์) ถ้า $Q$ สูง (โหลดเบา หรือค่าแฝงน้อย) ยอดสูงแหลม

- เหนือ $f_0$: ขนาดลดลง 40 dB/ทศวรรษ เฟสตกเป็น $-180^\circ$ — เฟสที่หายไปนี้เองที่ทำให้ต้องมีตัวชดเชย (หน้าตัวชดเชย)

- เหตุที่ L,C ไม่หายไปจากแรงดัน DC: ที่ DC $sL = 0$ และ $1/sC = \infty$ จึงไม่เกี่ยวกับ $G_{vd}(0)$ แต่กำหนดตำแหน่ง $f_0$ และความแหลม

## Gvg, GiLd, GiLg, Zout, Zin: เปลี่ยนคอลัมน์ B หรือแถว C กลาง

ใช้ $\operatorname{adj}(sI-A)$ และ $\Delta(s)$ ชุดเดิมจากข้างบน เปลี่ยนเฉพาะ $B$ และ $C$ แล้วจัดรูปโดยคูณบนล่างด้วย $LC$:

(1) $G_{vg} = \hat v_o/\hat v_g$ ใช้ $B_g = [D/L\ \ 0]^T$ ซึ่งต่างจาก $B_d$ แค่ $V_g \to D$:

T5 Gvg (audio susceptibility) ฟังก์ชันถ่ายโอนจากแรงดันอินพุตไปแรงดันขาออก

$$G_{vg}(s) = \frac{D}{LC\,s^2 + \dfrac LR\,s + 1} \;=\; \frac{D}{V_g}\,G_{vd}(s)$$

บอกว่าแรงดันริปเปิลหรือสัญญาณรบกวนบนอินพุตผ่านมาที่เอาต์พุตเท่าไร — ที่ DC เท่ากับ $D$ (ลด $V_g$ เป็นครึ่งหนึ่งที่ D = 0.5 → $V_o$ ลด 25 %) และมีเรโซแนนซ์ที่ $f_0$ เดียวกัน

(2) กระแสตัวเหนี่ยวนำ ใช้แถวแรก $C_{iL} = [1\ \ 0]$ ของ $\operatorname{adj}(sI-A)B$ ซึ่งคือ $(s + \frac1{RC})\cdot\frac{V_g}{L}$ หารด้วย $\Delta$:

T6 GiLd and GiLg ฟังก์ชันถ่ายโอนของกระแสตัวเหนี่ยวนำ

$$G_{iLd} = \frac{\hat i_L}{\hat d} = \frac{V_g}{R}\cdot\frac{1 + sRC}{LC\,s^2 + \frac LRs + 1},\qquad G_{iLg} = \frac{\hat i_L}{\hat v_g} = \frac{D}{R}\cdot\frac{1 + sRC}{LC\,s^2 + \frac LRs + 1}$$

ศูนย์ที่ $f = 1/(2\pi RC)$ (159 Hz ในตัวอย่าง) เกิดจากตัวเก็บประจุกับโหลด ที่ความถี่เหนือศูนย์ กระแสตัวเหนี่ยวนำตอบสนอง $\hat d$ แบบ 1 ขั้ว ซึ่งเป็นเหตุผลที่ current mode ลดปัญหาของขั้วคู่ LC

(3) อิมพีแดนซ์ขาออก $Z_{out}$ ใช้อินพุตกระแสโหลด $B_x = [0\ \ -1/C]^T$ (กระแสที่เพิ่มขึ้นดึงประจุออกจาก C) เอาต์พุต $\hat v_C$:

$$\operatorname{adj}(sI-A)\,B_x = \begin{bmatrix}-\frac1L\cdot\left(-\frac1C\right)\\[2pt] s\cdot\left(-\frac1C\right)\end{bmatrix} \;\Rightarrow\; \frac{\hat v_o}{\hat i_x} = \frac{-s/C}{\Delta(s)} = -\frac{sL}{LC\,s^2 + \frac LRs + 1}$$

T7 Output impedance Zout อิมพีแดนซ์ขาออก

$$Z_{out}(s) = -\frac{\hat v_o}{\hat i_x} = \frac{sL}{LC\,s^2 + \dfrac LRs + 1} = sL\,\Big\|\,\frac{1}{sC}\,\Big\|\,R$$

ตรวจด้วยวงจร: ตัวเหนี่ยวนำ ตัวเก็บประจุ และโหลด ขนานกัน (แหล่งอินพุตถูกลดเป็นศูนย์ จึงต่อ SW ลงกราวด์ผ่านไดโอด/สวิตช์) ได้ $\dfrac1Z = \dfrac1{sL} + sC + \dfrac1R$ แล้วจัดรูปก็ได้สูตรเดียวกัน ที่ DC $Z_{out} = 0$ (L ลัดวงจร) ที่ $f_0$ L และ C ตัดกัน เหลือ $Z_{out} = R$ (ยอดสูงสุด) เหนือ $f_0$ เป็น $1/(sC)$ ตามตัวเก็บประจุ ดังนั้นการตอบสนองต่อโหลดกระชากสูงสุดบริเวณ $f_0$

(4) อิมพีแดนซ์ขาเข้า $Z_{in}$ เอาต์พุตคือกระแสอินพุตเฉลี่ย $\hat i_g = D\hat i_L + I_L\hat d$ (X9) เมื่อ $\hat d = 0$ ได้ $\hat i_g = D\hat i_L$ ดังนั้น $Y_{in} = D\,G_{iLg}$

T8 Input impedance Zin (open loop) อิมพีแดนซ์ขาเข้าขณะเปิดวง

$$Y_{in} = \frac{\hat i_g}{\hat v_g} = D\,G_{iLg} = \frac{D^2}{R}\cdot\frac{1+sRC}{LC\,s^2+\frac LRs+1},\qquad Z_{in} = \frac{R}{D^2}\cdot\frac{LC\,s^2+\frac LRs+1}{1+sRC}$$

ที่ DC $Z_{in} = R/D^2$ (ความต้านทานโหลดสะท้อนผ่านหม้อแปลง 1:D) เป็นบวก — สำหรับบั๊กที่ ปิดวงป้อนกลับแรงดัน พฤติกรรมช่วงความถี่ต่ำเปลี่ยนเป็นความต้านทาน ลบ $-V_g^2/P$ ตามหน้าเกณฑ์ตัวกรองอินพุต เพราะวงป้อนกลับรักษากำลังให้คงที่

(5) กระแสตัวเก็บประจุ $\hat i_C$ และกระแสอินพุต $\hat i_g$ จากดิวตี้: $\hat i_C = \hat i_L - \hat v_o/R - \hat i_x$ และ $\hat i_g = D\hat i_L + I_L\hat d$ นำ $G_{iLd}$ และ $G_{vd}$ มาประกอบ (ตารางในแล็บคำนวณให้ครบ): ตัวอย่าง $G_{igd}(0) = D\,\dfrac{V_g}{R} + I_L = 2.4$ A ที่ตัวอย่าง D = 0.5

| ฟังก์ชัน | สูตร (ตัวส่วน $\Delta = LCs^2 + \frac LRs + 1$) | DC (24 V, D = 0.5, R = 10 Ω) | ศูนย์ |

| $G_{vd}$ | $V_g/\Delta$ | 24 V | ไม่มี |

| $G_{vg}$ | $D/\Delta$ | 0.5 | ไม่มี |

| $G_{iLd}$ | $\dfrac{V_g}{R}(1+sRC)/\Delta$ | 2.4 A | 159 Hz |

| $G_{iLg}$ | $\dfrac DR(1+sRC)/\Delta$ | 0.05 S | 159 Hz |

| $Z_{out}$ | $sL/\Delta$ | 0 Ω | 0 (ที่ DC) |

| $Y_{in}$ | $\dfrac{D^2}{R}(1+sRC)/\Delta$ | 0.025 S ($Z_{in} = 40\ \Omega$) | 159 Hz |

## เมื่อมี DCR และ ESR: รูปปิดที่แม่นยำ ขั้นสูง

ใช้วิธีเดียวกัน (T1–T2) กับเมทริกซ์ที่มี $R_l = r_L + DR_{on} + D'R_d$ และ $r_C$ (หน้าแบบจำลองเฉลี่ย X6–X7) ผลที่ได้เป็นรูปปิดที่แม่นยำ (ตรวจกับการคำนวณเมทริกซ์ตัวเลขทั้งหกฟังก์ชันด้านล่างที่ความคลาดเคลื่อนระดับ $10^{-15}$):

T9 Exact denominator with parasitics ตัวส่วนที่แม่นยำเมื่อมีค่าแฝง

$$\Delta(s) = 1 + a_1 s + \frac{s^2}{\omega_0^2}$$

$$\omega_0^2 = \frac{R + R_l}{LC\,(R + r_C)},\qquad a_1 = \frac{L + C\,\big[R_l(R+r_C) + R\,r_C\big]}{R + R_l}$$

$$Q = \frac{1}{\omega_0 a_1}\;\approx\; \frac{R\sqrt{C/L}}{1 + RC\,(R_l + r_C)/L}\qquad (R_l,\ r_C \ll R)$$

T10 Exact transfer functions with parasitics ฟังก์ชันถ่ายโอนรูปปิดเมื่อมีค่าแฝง

$$\beta = V_g + V_F - (R_{on}-R_d)I_L$$

$$G_{vd} = \frac{\beta R}{R + R_l}\cdot\frac{1 + s\,r_CC}{\Delta(s)},\qquad G_{vg} = \frac{DR}{R+R_l}\cdot\frac{1 + s\,r_CC}{\Delta(s)}$$

$$G_{iLd} = \frac{\beta}{R+R_l}\cdot\frac{1 + sC(R+r_C)}{\Delta(s)},\qquad G_{iLg} = \frac{D}{R+R_l}\cdot\frac{1 + sC(R+r_C)}{\Delta(s)}$$

$$Z_{out} = \frac{R\,(R_l + sL)(1 + s\,r_CC)}{(R+R_l)\,\Delta(s)},\qquad Z_{in} = \frac{R+R_l}{D^2}\cdot\frac{\Delta(s)}{1 + sC(R+r_C)}$$

เมื่อ $R_l, r_C \to 0$ กลับเป็นผลของอุดมคติ T3–T8 ผลของแต่ละค่า:

- ESR $r_C$ เติมศูนย์ $f_z = 1/(2\pi r_CC)$ ใน $G_{vd}$, $G_{vg}$, $Z_{out}$ (เป็นศูนย์ในซีกซ้าย ให้เฟสเพิ่ม +90° และอัตราลดลงเหลือ −20 dB/dec เหนือ $f_z$) · ตัวอย่าง $r_C = 50$ mΩ, $C = 100\ \mu$F → $f_z = 31.8$ kHz

- ความต้านทานอนุกรม $R_l$ เพิ่มการหน่วง ($a_1$ เพิ่ม) ลด $Q$ และทำให้ $Z_{out}(0) = R\|R_l$ ไม่เป็นศูนย์ และลดอัตราขยาย DC ของ $G_{vd}$ ลง $\dfrac{R}{R+R_l}$

- $V_F$ และ $R_{on}-R_d$ เปลี่ยนเฉพาะอัตราขยายของ $G_{vd}$ ผ่าน $\beta$ (ใหญ่ขึ้นด้วย $V_F$ เล็กลงด้วย $R_{on}I_L$)

- เป็นสาเหตุที่ในทางปฏิบัติ $Q$ ของบั๊กอยู่ที่ 2–6 แทนที่จะสูงเป็นร้อย

ตัวเลข (D = 0.5144, $R_{on} = 50$ mΩ, $r_L = 0.1\ \Omega$, $V_F = 0.4$ V, ESR 50 mΩ ที่ R = 10 Ω): $R_l = 0.1257\ \Omega$, $\beta = 24.34$ V → DC $G_{vd}(0) = 24.04$ V (27.6 dB) · $f_0 = 922.3$ Hz · $Q = 3.67$ (อุดมคติ 5.77) · ยอด $|G_{vd}| = 89.0$ V = 39.0 dB ที่ประมาณ 906 Hz · $Z_{out}(0) = 0.124\ \Omega$ = $R\|R_l$ · ยอด $Z_{out} = 6.32\ \Omega$ ที่ 922 Hz · $Z_{in}(0) = 38.3\ \Omega$

## ฟังก์ชันถ่ายโอนใน DCM: ลดเหลืออันดับหนึ่ง ขั้นสูง

ใน DCM กระแส $i_L$ กลับเป็นศูนย์ทุกคาบ ค่าเฉลี่ยของมันถูกกำหนดทันทีจาก $d, v_g, v$ ไม่ใช่ตัวแปรสถานะอิสระ เหลือสถานะเดียวคือ $v_C$ จากหน้า DCM กระแสเฉลี่ย (แทน $D_2 = D_1(v_g - v)/v$ และ $i_{pk}$):

$$\langle i_L\rangle = \tfrac12\,i_{pk}\,(D_1 + D_2) = \frac{d^2\,T_s\,v_g\,(v_g - v)}{2L\,v} \equiv f(d, v_g, v)$$

สมการเดียวของระบบ $C\,\dot v = f(d,v_g,v) - v/R$ เป็นไม่เชิงเส้น ใช้การรบกวนเหมือนเดิม: $sC\hat v = \dfrac{\partial f}{\partial d}\hat d + \dfrac{\partial f}{\partial v_g}\hat v_g + \dfrac{\partial f}{\partial v}\hat v - \dfrac{\hat v}{R}$ คำนวณอนุพันธ์ย่อยที่จุดทำงาน (ใช้ $D^2/K = M^2/(1-M)$ จากหน้า DCM):

$$\frac{\partial f}{\partial d} = \frac{2V}{RD},\qquad \frac{\partial f}{\partial v_g} = \frac{M(2-M)}{(1-M)R},\qquad \frac{\partial f}{\partial v} = -\frac{1}{(1-M)R}$$

รวม $\dfrac1R + \dfrac1{(1-M)R} = \dfrac{2-M}{(1-M)R}$ แล้วแก้หา $\hat v$:

T11 DCM transfer functions (first order) ฟังก์ชันถ่ายโอนใน DCM (อันดับหนึ่ง)

$$G_{vd} = \frac{G_{d0}}{1 + s/\omega_p},\qquad G_{d0} = \frac{2V_o}{D}\cdot\frac{1-M}{2-M}$$

$$G_{vg} = \frac{M}{1 + s/\omega_p},\qquad \omega_p = \frac{2-M}{(1-M)\,RC}$$

$$Z_{out} = \frac{R_{eq}}{1 + sR_{eq}C},\qquad R_{eq} = R\,\frac{1-M}{2-M}$$

เทียบกับ CCM ($\Delta$ อันดับสอง): ไม่มีขั้วคู่ LC และไม่มียอดเรโซแนนซ์ ขั้วเดียว $f_p = \omega_p/2\pi$ ต่ำมาก (หลักสิบ Hz) เพราะขึ้นกับ RC ของโหลดเบา อัตราขยาย DC $G_{d0}$ และขั้ว $f_p$ เปลี่ยนตามโหลดและ $M$ ตัวอย่าง R = 100 Ω, D = 0.3873 ($M = 0.5$): $G_{d0} = \dfrac{2(12)}{0.3873}\cdot\dfrac{0.5}{1.5} = 20.66$ V (26.3 dB), $\omega_p = \dfrac{1.5}{0.5\times100\times100\mu} = 300$ rad/s ($f_p = 47.7$ Hz), $R_{eq} = 33.3\ \Omega$ เทียบกับ CCM ที่ R = 10 Ω มี $f_0 = 919$ Hz แบบสองขั้ว — ตัวชดเชยที่ออกแบบให้ CCM จึงต้องปรับสำหรับ DCM (ดูหน้าตัวชดเชย) ข้อจำกัด: แบบจำลองนี้ไม่รวมขั้วความถี่สูงใกล้ $f_s$ ที่เกิดจากกระแส $i_L$ ในแต่ละคาบ จึงใช้ได้ที่ความถี่ต่ำกว่าประมาณ $f_s/3$

## ต่อกับตัวควบคุม: PWM และลูปเกน กลาง

ตัวมอดูเลเตอร์ PWM เปรียบเทียบแรงดันควบคุม $v_c$ กับสัญญาณฟันเลื่อย (สูง $V_M$) ได้ $d = v_c/V_M$ → $\hat d = \hat v_c/V_M$ ดังนั้นฟังก์ชันถ่ายโอนจาก $\hat v_c$ ไปเอาต์พุตคือ $G_{vd}/V_M$ ลูปเกนของแรงดันป้อนกลับ $T(s) = G_c(s)\,\dfrac{G_{vd}(s)}{V_M}\,H$ เมื่อปิดวงแล้วฟังก์ชันอื่นๆ ที่ได้ในหน้านี้เปลี่ยนเป็น:

T12 Loop gain and closed-loop functions ลูปเกนและฟังก์ชันตอนปิดวง

$$T(s) = G_c(s)\,\frac{G_{vd}(s)}{V_M}\,H$$

$$Z_{out,cl} = \frac{Z_{out}}{1 + T},\qquad G_{vg,cl} = \frac{G_{vg}}{1 + T},\qquad \frac{\hat v_o}{\hat v_{ref}} = \frac{1}{H}\cdot\frac{T}{1+T}$$

ตัวอย่างความหมาย: ลูปเกนที่ $f$ = 100 Hz ขนาด 30 dB (≈ 32 เท่า) ลดผลของโหลดกระชากและของริปเปิลบนอินพุตลง 33 เท่า ที่ความถี่นั้น — นี่คือเหตุผลหลักของการป้อนกลับ และเป็นที่มาของโจทย์ออกแบบ $G_c$ ให้ $T$ มีครอสโอเวอร์สูงพอแต่ยังมีเฟสมาร์จิน

## ตัวอย่างวิธีทำ (ตรวจตัวเลขแล้ว)

โจทย์ฐาน: $V_g = 24$ V, $D = 0.5$, $R = 10\ \Omega$, $L = 300\ \mu$H, $C = 100\ \mu$F (อุดมคติ ยกเว้นระบุ)

ตัวอย่าง T-1

### หา Gvd ของบั๊กอุดมคติเป็นตัวเลข

- $LC = 3\times10^{-8}$ s², $L/R = 3\times10^{-5}$ s → $G_{vd} = \dfrac{24}{3\times10^{-8}s^2 + 3\times10^{-5}s + 1}$

- $\omega_0 = 1/\sqrt{3\times10^{-8}} = 5774$ rad/s → $f_0 = 918.9$ Hz · $Q = 10\sqrt{100\mu/300\mu} = 5.77$ → $\zeta = 0.0866$

- DC $= 24$ V = 27.6 dB · ที่ $f_0$: $|G_{vd}| = QV_g = 138.6$ V = 42.8 dB (สูงกว่า DC 15.2 dB = 20log Q) เฟส $-90^\circ$

- ตรวจด้วยเครื่องวัดเสมือนในแล็บ (ฉีดไซน์เข้าวงจรสวิตชิ่งจริง): ที่ 926 Hz วัดได้ 42.73 dB เฟส −95.0° ตรงกับทฤษฎี 42.73 dB, −95.0° · ที่ 20 Hz วัด 27.61 dB (ทฤษฎี 27.61 dB) ✓

ตัวอย่าง T-2

### แรงดันอินพุตกระโดด +2.4 V (10 %): Vo เปลี่ยนเท่าไรถ้าเปิดวง (Gvg)

- $G_{vg} = D/\Delta$ → ค่าสุดท้าย $\Delta V_o = D\Delta V_g = 0.5\times2.4 = 1.2$ V

- ระบบอันดับสอง $\zeta = 0.0866$ → overshoot $= e^{-\pi\zeta/\sqrt{1-\zeta^2}} = e^{-0.273} = 0.761$ (76 %)

- ค่ายอด $\Delta V_{o,pk} = 1.2\times1.761 = 2.11$ V ที่เวลา $t_p = \pi/\omega_d = 0.546$ ms · จำลองสวิตชิ่งจริง (เปลี่ยน $V_g$ จาก 24 เป็น 26.4 V ที่ D = 0.5 คงที่) ได้ยอด +2.11 V ที่ 0.55 ms และค่าสุดท้าย +1.20 V ✓ — ใหญ่กว่าค่าสุดท้ายเกือบเท่าตัว → ต้องป้อนกลับหรือเพิ่มการหน่วง (ลด Q)

ตัวอย่าง T-3

### กระแสโหลดเปลี่ยน 1 A: Zout บอกอะไร (ค่าแฝงจริง)

- ใช้ค่าแฝงจริงตามหัวข้อก่อนหน้า ($R_l = 0.1257\ \Omega$, ESR 50 mΩ): $Z_{out}(0) = R\|R_l = 0.124\ \Omega$ → ค่าสุดท้ายหลังเปลี่ยนกระแส 1 A ลดแรงดัน $0.124$ V (ความต้านทานในวงจร)

- แต่ช่วงชั่วคราว $Z_{out}$ สูงสุดที่ $f_0$: $|Z_{out}| = 6.32\ \Omega$ → ปลายทางสั่นด้วยแอมพลิจูดสูง การตอบสนองต่อสเต็ปของ $-Z_{out}$ ให้ยอดตก $\approx 1.51$ V ต่อกระแส 1 A ก่อนจะนิ่งที่ −0.125 V

- สำหรับโหลดกระโดด 1.2 A (เต็มพิกัด): $\Delta V \approx 1.2\times1.51 = 1.8$ V ตกชั่วคราว (15 % ของ 12 V) — เปิดวงรับไม่ได้ ต้องใช้วงป้อนกลับที่ลด $Z_{out}$ ลง $1+T$ เท่า (T12) และตัวเก็บประจุที่ใหญ่ขึ้นหรือ ESR ต่ำ

ตัวอย่าง T-4

### โหลดเบาเข้า DCM: ฟังก์ชันถ่ายโอนเปลี่ยนจากสองขั้วเป็นหนึ่งขั้ว

- R = 100 Ω, L = 300 µH, fs = 50 kHz: $K = 0.3$; ต้องการ 12 V → D = 0.3873 ($M = 0.5$) ตามหน้า DCM

- T11: $G_{d0} = 20.66$ V (26.3 dB), $f_p = 47.7$ Hz, $G_{vg}(0) = M = 0.5$ (เท่า CCM), $R_{eq} = 33.3\ \Omega$

- ตรวจด้วยเครื่องวัดเสมือนบนวงจรสวิตชิ่งใน DCM: ที่ 20 Hz วัด 25.60 dB, ที่ 104 Hz 18.74 dB ขณะที่ทฤษฎี DCM ให้ 25.60 และ 18.73 dB (ขั้วเดียว −20 dB/dec หลัง 48 Hz) · ที่ 926 Hz วัด 0.54 dB — ไม่มียอดเรโซแนนซ์ ในขณะที่แบบจำลอง CCM ที่ R = 100 Ω ทำนายยอด 62.8 dB ที่ความถี่นั้น ซึ่งผิดอย่างมาก

- บทเรียน: ตัวชดเชยของโหลดหนัก (ขั้วคู่ที่ ~1 kHz) ใช้กับโหลดเบา (ขั้วเดียวที่ ~50 Hz) ไม่ได้ครอสโอเวอร์เปลี่ยนมาก

## แล็บ: สำรวจฟังก์ชันถ่ายโอนทั้ง 12 แบบ และวัดด้วยสวิตชิ่งจริง กลาง

เลือก อินพุต (สิ่งที่เปลี่ยน) และ เอาต์พุต (สิ่งที่วัด) แล้วเครื่องมือแสดงตัวเศษ ตัวส่วน DC ขั้ว ศูนย์ โบเด และการตอบสนองต่อสเต็ป ตารางล่างสุดสรุปทั้ง 12 ฟังก์ชันที่จุดทำงานนั้น ปุ่ม "วัดด้วยสวิตชิ่งจริง" ฉีดไซน์เล็กที่ความถี่ต่างๆ เข้าวงจรสวิตชิ่ง (ไม่ใช้สูตรใดๆ) แล้ววัดเอาต์พุตด้วยสหสัมพันธ์ จุดสีส้มควรตกบนเส้นทฤษฎี

### ใบงานทดลอง

ใบงาน T1 — พิสูจน์ Gvd: โหลดอุดมคติ เลือก d̂ → v̂o กด "วัดด้วยสวิตชิ่งจริง" จดความต่าง (dB, องศา) ที่ 5 ความถี่ แล้วหาความถี่ที่เริ่มต่างเกิน 0.1 dB (ควรเป็นราว fs/20) ทำไมจึงเริ่มต่าง

ใบงาน T2 — Gvg: เลือก v̂g → v̂o ตรวจว่า DC = D = 0.5 แล้วเปลี่ยน D เป็น 0.3 DC ต้องเป็น 0.3 · ยอดเรโซแนนซ์เหมือน Gvd หรือไม่

ใบงาน T3 — Zout: เลือก îx → v̂o ตรวจยอดที่ f0 = R = 10 Ω แล้วเปิดค่าแฝงจริงดูว่ายอดลดเหลือ 6.3 Ω

ใบงาน T4 — ESR zero: เลือก "มี ESR เท่านั้น" ใน Gvd ดูว่าเฟสที่ความถี่สูงดีขึ้นเพียงใด (เฟสไม่ถึง −180° เพราะศูนย์ที่ 31.8 kHz) ปรับ ESR จาก 0 → 50 → 200 mΩ แล้วดูว่าศูนย์เลื่อนไปที่ใด

ใบงาน T5 — DCM: โหลดตัวอย่างโหลดเบา (R = 100 Ω, D = 0.5) ดูโบเดทฤษฎี DCM (ขั้วเดียว เส้นฟ้า) เทียบกับเส้น CCM (ประเทา) และจุดวัดจากสวิตชิ่งจริง จุดตกบนเส้นไหน

ใบงาน T6 — เอาต์พุตอื่น: เลือก d̂ → îL (ศูนย์ที่ 159 Hz) แล้ว d̂ → îg ตรวจ DC ของ Gigd ว่าเป็น 2.4 A และลองขนาดสัญญาณรบกวน 16× (ใหญ่) ดูว่าจุดวัดเริ่มเบี่ยงเมื่อใด (ความไม่เชิงเส้น)

## สรุปและก้าวต่อไป

- ฟังก์ชันถ่ายโอนมีหลายแบบเพราะเลือก (อินพุต, เอาต์พุต) ต่างกัน — สูตรเดียว $C(sI-A)^{-1}B + E$ ครอบคลุมทุกแบบ ตัวส่วนร่วม $\Delta(s)$ = ขั้วของระบบ

- $G_{vd}$ ใช้ออกแบบตัวชดเชย · $G_{vg}$ ใช้ดูการรบกวนจากอินพุต · $Z_{out}$ ใช้ดูโหลดกระชาก · $Z_{in}$ ใช้ดูการอยู่ร่วมกับตัวกรองอินพุต · $G_{iLd}$ ใช้ออกแบบ current mode

- CCM มีขั้วคู่ LC (ยอดแหลม ขึ้นกับ Q) · DCM มีขั้วเดียว · ค่าแฝงลด Q และ ESR เติมศูนย์

ต่อไป: ออกแบบบั๊กครบวงจรและทดสอบโหลดหลายสภาวะ · ออกแบบตัวชดเชย Type II/III จาก $G_{vd}$ ที่ได้ · ภาพรวมแบบจำลองสัญญาณเล็กของบูสต์และบั๊ก-บูสต์ · Bode plot

## คำถามที่พบบ่อย

ทำไมบั๊กคอนเวอร์เตอร์ถึงมีฟังก์ชันถ่ายโอนหลายแบบ?
เพราะระบบมีหลายอินพุต (ดิวตี้ แรงดันอินพุต กระแสโหลด) และหลายเอาต์พุต (แรงดันขาออก กระแสตัวเหนี่ยวนำ กระแสอินพุต) ฟังก์ชันถ่ายโอนแต่ละแบบคืออัตราส่วนของเอาต์พุตหนึ่งต่ออินพุตหนึ่งขณะที่อินพุตอื่นเป็นศูนย์ ทุกแบบมีตัวส่วนเดียวกัน (ขั้วเดียวกัน) ต่างกันที่ตัวเศษ

Gvd ของบั๊กคืออะไรและใช้ทำอะไร?
Gvd = v̂o/d̂ คือฟังก์ชันถ่ายโอนจากดิวตี้ไปแรงดันขาออก ในบั๊กอุดมคติเท่ากับ Vin/(LC·s² + (L/R)·s + 1) มีขั้วคู่ที่ f0 = 1/(2π√LC) ใช้ออกแบบตัวชดเชยของวงป้อนกลับแบบ voltage mode

Zout ของบั๊กบอกอะไร?
Zout คืออิมพีแดนซ์ที่โหลดมองเข้าไปในวงจร ใช้ประเมินว่าแรงดันขาออกตกเท่าไรเมื่อกระแสโหลดเปลี่ยน ΔVo ≈ ΔIo·|Zout| ในบั๊กเปิดวงเท่ากับ sL ∥ 1/(sC) ∥ R เมื่อปิดวงป้อนกลับจะเล็กลงเป็น Zout/(1+T)

ใน DCM ฟังก์ชันถ่ายโอนต่างจาก CCM อย่างไร?
ใน DCM กระแสตัวเหนี่ยวนำไม่ใช่ตัวแปรสถานะอิสระ ระบบลดเหลืออันดับหนึ่ง Gvd = Gd0/(1 + s/ωp) โดย Gd0 = (2Vo/D)(1−M)/(2−M) และ ωp = (2−M)/((1−M)RC) ไม่มีขั้วคู่ LC และไม่มียอดเรโซแนนซ์ ตัวชดเชยที่ออกแบบสำหรับ CCM จึงผิดทันทีที่เข้า DCM

## คำถามที่พบบ่อย (FAQ)

**ทำไมบั๊กคอนเวอร์เตอร์ถึงมีฟังก์ชันถ่ายโอนหลายแบบ?**
เพราะระบบมีหลายอินพุต (ดิวตี้ แรงดันอินพุต กระแสโหลด) และหลายเอาต์พุต (แรงดันขาออก กระแสตัวเหนี่ยวนำ กระแสอินพุต) ฟังก์ชันถ่ายโอนแต่ละแบบคืออัตราส่วนของเอาต์พุตหนึ่งต่ออินพุตหนึ่งขณะที่อินพุตอื่นเป็นศูนย์ ทุกแบบมีตัวส่วนเดียวกัน (ขั้วเดียวกัน) ต่างกันที่ตัวเศษ

**Gvd ของบั๊กคืออะไรและใช้ทำอะไร?**
Gvd = v̂o/d̂ คือฟังก์ชันถ่ายโอนจากดิวตี้ไปแรงดันขาออก ในบั๊กอุดมคติเท่ากับ Vin/(LC·s² + (L/R)·s + 1) มีขั้วคู่ที่ f0 = 1/(2π√LC) ใช้ออกแบบตัวชดเชยของวงป้อนกลับแบบ voltage mode

**Zout ของบั๊กบอกอะไร?**
Zout คืออิมพีแดนซ์ที่โหลดมองเข้าไปในวงจร ใช้ประเมินว่าแรงดันขาออกตกเท่าไรเมื่อกระแสโหลดเปลี่ยน ΔVo ≈ ΔIo·|Zout| ในบั๊กเปิดวงเท่ากับ sL ∥ 1/(sC) ∥ R เมื่อปิดวงป้อนกลับจะเล็กลงเป็น Zout/(1+T)

**ใน DCM ฟังก์ชันถ่ายโอนต่างจาก CCM อย่างไร?**
ใน DCM กระแสตัวเหนี่ยวนำไม่ใช่ตัวแปรสถานะอิสระ ระบบลดเหลืออันดับหนึ่ง Gvd = Gd0/(1 + s/ωp) โดย Gd0 = (2Vo/D)(1−M)/(2−M) และ ωp = (2−M)/((1−M)RC) ไม่มีขั้วคู่ LC และไม่มียอดเรโซแนนซ์ ตัวชดเชยที่ออกแบบสำหรับ CCM จึงผิดทันทีที่เข้า DCM
