# บั๊ก-บูสต์คอนเวอร์เตอร์: แบบกลับขั้ว แบบ 4 สวิตช์ และการเลือกโทโพโลยี

// บทที่ 15.8 · อิเล็กทรอนิกส์กำลัง · Buck-Boost Converter


บั๊ก-บูสต์กลับขั้ว −D/(1−D) ความเค้น Vin + |Vo| RHP zero บั๊ก-บูสต์ 4 สวิตช์แบบไม่กลับขั้ว และตารางเลือกระหว่าง SEPIC Ćuk และ flyback

สรุปใน 30 วินาที

- $V_o/V_{in} = -D/(1-D)$ — D น้อยกว่า 0.5 ลด มากกว่า 0.5 เพิ่ม

- สวิตช์และไดโอดรับ $V_{in}+|V_o|$

- RHP zero ต่ำกว่าบูสต์ด้วยปัจจัย 1/D

- ต้องการขั้วบวกประสิทธิภาพสูง → 4-switch buck-boost

## Inverting buck-boost

- ON: $v_L = V_{in}$, ไดโอดกลับไบแอส — โหลดได้พลังงานจาก C

- OFF: $v_L = V_o$ (ซึ่งเป็นลบ) — L ปล่อยพลังงานทั้งหมดไปขาออก (ไม่มี เส้นทางตรงจาก Vin สู่ Vout)

W1 Volt-second balance (buck-boost) อัตราส่วนแปลงผัน

$$V_{in}D + V_o(1-D) = 0 \;\Rightarrow\; \boxed{\frac{V_o}{V_{in}} = -\frac{D}{1-D}},\qquad I_L = \frac{I_o}{1-D} = I_{in}+I_o$$

$D \lt 0.5$ ลดแรงดัน, $D \gt 0.5$ เพิ่มแรงดัน — นี่คือ flyback ที่ไม่มีหม้อแปลง ($L$ เป็นตัวเก็บพลังงานล้วน)

## แบบจำลองสัญญาณเล็ก

W2 Buck-boost Gvd with RHP zero ฟังก์ชันถ่ายโอนและ RHP zero

$$G_{vd}(s) = -\frac{V_{in}}{(1-D)^2}\cdot\frac{1 - s\dfrac{DL}{R(1-D)^2}}{\dfrac{LC}{(1-D)^2}s^2 + \dfrac{L}{R(1-D)^2}s + 1},
\qquad \omega_{RHPZ} = \frac{R(1-D)^2}{DL}$$

RHP zero ต่ำกว่า boost ด้วยปัจจัย $1/D$ — ยิ่งเพิ่มแรงดันมาก ยิ่งต้องจำกัดแบนด์วิดท์

เรื่องสัญญาณป้อนกลับขั้วลบ Vout เป็นลบเทียบกับกราวด์ร่วม ต้องใช้ op-amp แบบ inverting (หรือวงจร level-shift) ป้อนกลับให้คอนโทรลเลอร์ ซิมูเลเตอร์บนเว็บนี้แสดงขนาด $\lvert V_o\rvert$

## Non-inverting 4-switch buck-boost

ใช้สองขาสวิตช์ (buck leg + boost leg) กับ L ตัวเดียว ทำงาน 3 โหมด: buck ($V_{in} \gt V_o$), boost ($V_{in} \lt V_o$) และ buck-boost ช่วงเปลี่ยนผ่าน ข้อดี: ขั้วบวก, ความเค้น = $\max(V_{in},V_o)$, ประสิทธิภาพ 95–98% เหมาะกับแบตเตอรี่ Li-ion ที่แรงดันคร่อมค่าเป้าหมาย, USB-PD, ระบบ 12 V รถยนต์ (cold crank) ตัวอย่างชิปควบคุมดู การเลือกตัวควบคุม
