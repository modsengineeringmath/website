# วิเคราะห์อาการเสียของคอนเวอร์เตอร์และแหล่งจ่ายไฟสวิตชิ่ง: อาการ สาเหตุ วิธีตรวจ

// บทที่ 13.16 · อิเล็กทรอนิกส์กำลัง · Troubleshooting


วิธีคิดแบบเป็นระบบ ตาราง 17 อาการ เช่น ไม่มีเอาต์พุต hiccup แกว่ง เสียงหอน MOSFET ระเบิด แกนอิ่มตัว ริปเปิลสูง EMI และวิธีฝึกด้วยซิมูเลเตอร์

สรุปใน 30 วินาที

- สังเกตก่อนแตะ แยกส่วน วัดเทียบค่าที่คาด หาสาเหตุราก

- MOSFET ไหม้มักเป็นผล ไม่ใช่เหตุ

- แกว่งที่ $f_s/2$ = subharmonic → เพิ่ม slope comp

- iL หางยกขึ้น = แกนอิ่มตัว

## วิธีคิดแบบเป็นระบบ

- สังเกตก่อนแตะ — อาการ เสียง กลิ่น รอยไหม้ เกิดเมื่อไร (เปิดเครื่อง/โหลดเปลี่ยน/ร้อน)

- แยกส่วน: ไฟเลี้ยงคอนโทรลเลอร์ → สัญญาณเกต → ภาคกำลัง → ลูปป้อนกลับ

- วัดเทียบค่าที่คาด (คำนวณจากสูตรในแต่ละบท) — ความต่างคือเบาะแส

- หาสาเหตุราก ไม่ใช่แค่เปลี่ยนชิ้นที่ไหม้ (MOSFET ไหม้มักเป็น ผล ไม่ใช่ เหตุ)

## ใช้ซิมูเลเตอร์ฝึกวิเคราะห์

ใน ห้องแลปจำลอง สร้าง "ความเสีย" แล้วดูผล:

- ลด L ลง 5 เท่า (จำลองแกนแตก) → ΔiL เพิ่ม, เข้า DCM

- เพิ่ม ESR (C) เป็น 0.5 Ω (ตัวเก็บประจุเสื่อม) → ripple ขาออกเป็นรูปเหลี่ยม

- เพิ่ม Rds(on) → ประสิทธิภาพตก

- PCMC slope = 0 กับ boost → subharmonic

- Boost + เปลี่ยนเป็นโหลด 1 kΩ แบบ open loop → แรงดันพุ่ง (เหตุผลที่ต้องมี OVP)

## คำถามที่พบบ่อย

MOSFET ในคอนเวอร์เตอร์ระเบิดตอนเปิดเครื่องเกิดจากอะไร?
สาเหตุที่พบบ่อยคือ shoot-through จาก dead-time ไม่พอ เกตลอยตอนไฟเลี้ยงยังไม่ขึ้น แรงดันกระชากเกินพิกัดเพราะ layout หรือไม่มี snubber และแรงดันเกตเกินพิกัด ควรใส่ตัวต้านทาน pull-down ที่เกต ตรวจ dead-time และวัดแรงดัน drain ด้วยโพรบที่ถูกวิธี
