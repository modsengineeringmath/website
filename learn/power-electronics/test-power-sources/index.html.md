# แหล่งจ่ายไฟสำหรับทดสอบวงจร: แบตเตอรี่ ไฟบ้าน 220 V ผ่านเรกติไฟเออร์ และโซลาร์เซลล์

// บทที่ 13.12 · อิเล็กทรอนิกส์กำลัง · Test Power Sources


กฎทองของการทดสอบ แบตเตอรี่ 3 ชนิด คำนวณตัวเก็บประจุหลังบริดจ์ inrush ฟิวส์ หม้อแปลงแยกขด แบบจำลองแผงโซลาร์ MPPT และตารางเลือกแหล่งจ่าย

สรุปใน 30 วินาที

- เริ่มจาก bench supply จำกัดกระแสเสมอ

- $C_{bulk} \ge 2P_{in}t_d/(V_{pk}^2 - V_{min}^2)$

- ripple หลังบริดจ์เป็น 100 Hz

- แผงโซลาร์ไม่ใช่แหล่งแรงดัน MPP ≈ 0.76–0.8 $V_{oc}$

ซิมูเลเตอร์ใน ห้องแลป เลือกแหล่งจ่ายทั้ง 3 แบบได้ พร้อมจำลองความต้านทานภายในและตัวเก็บประจุขาเข้า

## กฎทองของการทดสอบ

- เริ่มจากแหล่งจ่ายจำกัดกระแส (bench supply ตั้ง current limit ต่ำ) ก่อนเสมอ — วงจรใหม่ที่ผิดจะไม่ระเบิด

- เพิ่มแรงดันทีละขั้น สังเกตกระแสนิ่ง ($I_q$) และอุณหภูมิ

- ค่อยเปลี่ยนเป็นแหล่งจ่ายจริง (แบต/ไฟบ้าน/โซลาร์) ที่จ่ายกระแสลัดวงจรได้มหาศาล → ต้องมีฟิวส์

## ไฟบ้าน 220 V 50 Hz ผ่านหม้อแปลง + บริดจ์เรกติไฟเออร์

V1 Bridge peak and bulk capacitor แรงดันยอดและตัวเก็บประจุ

$$V_{pk} = \sqrt2\,V_{sec} - 2V_F,\qquad
C_{bulk} \ge \frac{2P_{in}\,t_d}{V_{pk}^2 - V_{min}^2},\quad t_d \approx 8\text{–}9\ \text{ms (50 Hz)}$$

ตัวอย่าง: หม้อแปลง 24 Vrms, $P_{in}$ = 15 W, ยอมให้ตกถึง 25 V → $V_{pk}$ = 32.1 V, $C \ge \dfrac{2(15)(0.009)}{32.1^2-25^2} = 667\ \mu$F → ใช้ 1000 µF 50 V

- Ripple ความถี่ 100 Hz (สองเท่าของไลน์) ปรากฏที่ $V_{in}$ → ดูได้ในซิม (ตั้ง time/div = 5 ms, CH2 = Vin)

- กระแสชาร์จ C เป็นพัลส์แคบ พีกสูง 5–10 เท่าของกระแสเฉลี่ย → ไดโอด/หม้อแปลงต้องรองรับ RMS

- Inrush: ตอนเสียบปลั๊ก C ว่าง → ใส่ NTC thermistor หรือ relay bypass

- ความปลอดภัย: ใช้หม้อแปลงแยกขด (isolation transformer) เสมอ ห้ามวัดวงจร off-line ด้วยสโคปที่กราวด์ต่อดิน ถ้าไม่มี differential probe ฟิวส์ด้าน primary + MOV ป้องกันแรงดันกระชาก

- ถ้าต่อ 220 V ตรง (ไม่ใช้หม้อแปลง) แรงดัน bus ≈ 311 V — เป็นงาน SMPS เต็มรูปแบบ ดู Switching Power Supply

## โซลาร์เซลล์ (PV)

เรียนต่อแบบละเอียด เส้นโค้ง I-V แล็บเงาบัง การออกแบบสตริง MPPT และอินเวอร์เตอร์ของระบบโซลาร์จริงอยู่ในชุด ออกแบบระบบโซลาร์เซลล์ (เริ่มที่ เซลล์และเส้นโค้ง I-V และ MPPT)

แบบจำลองไดโอดเดี่ยว:

V2 Single-diode PV model แบบจำลองแผงโซลาร์

$$I = I_{ph} - I_0\left(e^{V/(nN_sV_t)} - 1\right),\qquad I_{ph}\approx I_{sc}\frac{G}{1000}$$

- แผงไม่ใช่แหล่งแรงดัน: แรงดันตกมากเมื่อดึงกระแสเกิน $I_{mpp}$ — คอนเวอร์เตอร์คุมแรงดันขาออกแบบปกติจะ "ดึงจนแผงยุบ" ได้

- MPPT: Perturb & Observe (ซิมมีโหมดนี้), Incremental Conductance; จุด MPP ≈ 0.76–0.8 $V_{oc}$

- แผง 36 เซลล์ ($V_{oc}$ ≈ 22 V) เหมาะกับแลป buck ชาร์จแบต 12 V

- ทดลองในซิม: เลือกแหล่ง = โซลาร์, ตัวควบคุม = MPPT, ลด G จาก 1000 → 400 W/m² ดูว่า Vin เลื่อนจุดทำงานอย่างไร
