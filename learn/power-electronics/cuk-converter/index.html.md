# ชุคคอนเวอร์เตอร์ (Ćuk Converter): ตัวเก็บประจุคัปปลิ้ง การออกแบบ การหน่วง และ zero ripple

// บทที่ 13.4 · อิเล็กทรอนิกส์กำลัง · Ćuk Converter


ถ่ายโอนพลังงานผ่านตัวเก็บประจุ C1 สมการออกแบบ L1 L2 C1 ไดนามิกอันดับสี่และการหน่วง coupled inductor กับกระแสริปเปิลเกือบศูนย์

สรุปใน 30 วินาที

- $V_{C1} = V_{in}+|V_o|$, $V_o/V_{in} = -D/(1-D)$

- กระแสทั้งขาเข้าและขาออกต่อเนื่อง → EMI ต่ำ

- C1 ต้องเป็นฟิล์มหรือเซรามิก รับ RMS สูง

- อันดับสี่ → ต้องหน่วงเรโซแนนซ์ก่อนปิดลูป

คิดค้นโดย Slobodan Ćuk (Caltech, 1976) — เป็น boost ต่ออนุกรมกับ buck โดยใช้ตัวเก็บประจุ $C_1$ เป็นตัวถ่ายโอนพลังงานแทนตัวเหนี่ยวนำ

## การทำงาน

- ON (Q นำ): $L_1$ รับพลังงานจาก $V_{in}$; $C_1$ คายประจุผ่าน Q ไปยัง $L_2$ และโหลด

- OFF (D นำ): $L_1$ ชาร์จ $C_1$ ผ่านไดโอด; $L_2$ ปล่อยพลังงานให้โหลดผ่านไดโอด

Volt-second บน $L_1$ และ $L_2$:

K1 Coupling-capacitor voltage แรงดันบน C1

$$V_{in}D + (V_{in}-V_{C1})(1-D)=0 \Rightarrow V_{C1}=\frac{V_{in}}{1-D} = V_{in}+\lvert V_o\rvert$$

K2 Ćuk conversion ratio อัตราส่วนแปลงผัน

$$(V_{C1}+V_o)D + V_o(1-D)=0 \Rightarrow \boxed{\frac{V_o}{V_{in}} = -\frac{D}{1-D}}$$

Charge balance บน $C_1$: $I_{L1}(1-D) = I_{L2}D$ → $I_{L1} = I_{in}$, $I_{L2}=I_o$

## สมการออกแบบ

K3 Ćuk design ripples สมการออกแบบ

$$\Delta i_{L1} = \frac{V_{in}D}{L_1 f_s},\quad
\Delta i_{L2} = \frac{V_{in}D}{L_2 f_s},\quad
\Delta v_{C1} = \frac{I_o D}{C_1 f_s},\quad
\Delta v_o = \frac{\Delta i_{L2}}{8C_2 f_s}$$

$C_1$ รับ RMS current สูง: $I_{C1,rms}=\sqrt{I_{L1}^2(1-D)+I_{L2}^2D}$ → ใช้ฟิล์ม (PP) หรือเซรามิกแรงดันสูง ห้ามใช้อิเล็กโตรไลต์ ต้องทนแรงดัน $\ge 1.5(V_{in}+\lvert V_o\rvert)$

@@H2 damping|ไดนามิกอันดับสี่และการหน่วง@@
สถานะ 4 ตัว ($i_{L1}, i_{L2}, v_{C1}, v_{C2}$) ทำให้มีขั้วคู่ซับซ้อนสองคู่ เรโซแนนซ์ $L_1$–$C_1$ และ $L_2$–$C_1$ มักมี Q สูง และ $G_{vd}$ มีคู่ศูนย์ (บางกรณีอยู่ครึ่งขวา) ทำให้เฟสตกถึง −360°

วิธีแก้เชิงวิศวกรรม:

- เพิ่ม $R_d$–$C_d$ damping ขนาน $C_1$ โดย $C_d \approx 4C_1$, $R_d \approx \sqrt{L_{eq}/C_1}$

- ใช้ current-mode ที่วัดผลรวม $i_{L1}+i_{L2}$ (= กระแสสวิตช์)

- จำกัด $f_c$ ให้ต่ำกว่าเรโซแนนซ์ต่ำสุดอย่างน้อย 3–5 เท่า

@@H2 coupled-inductor|Coupled inductor และ zero-ripple@@
พัน $L_1$, $L_2$ บนแกนเดียวกัน (แรงดันบนทั้งสองเท่ากันทุกช่วงเวลา) เลือก coupling $k = n$ (อัตราส่วนรอบ) ทำให้ ripple ย้ายไปอยู่ขดเดียว — อีกขดได้กระแส ripple เกือบศูนย์ (ripple steering) ลด EMI ขาเข้าหรือขาออกได้มาก เป็นจุดเด่นที่ทำให้ Ćuk ใช้ในงานเซนเซอร์, LED และโซลาร์
