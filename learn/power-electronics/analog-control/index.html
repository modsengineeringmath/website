Error amplifier

  • ใช้สูตร Type II/III จาก การออกแบบตัวชดเชย
  • ต้องเลือก op-amp ให้ GBW ≥ 10× ของ gain ที่ต้องการ ณ ความถี่ขั้วสูงสุด ไม่งั้นขั้วของ op-amp จะกินเฟส
  • ตัวต้านทาน R1R_1R1​ (บนของตัวแบ่ง) เป็นส่วนของตัวชดเชย; RbottomR_{bottom}Rbottom​ ไม่มีผลกับ AC (ขา inverting เป็น virtual ground) จึงตั้ง DC ได้อิสระ

การวัดกระแส

วิธี ข้อดี ข้อควรระวัง
Shunt + amp (INA240, INA181) แม่น ราคาถูก สูญเสีย I2RI^2RI2R, common-mode สูงต้องใช้ amp ที่ทน PWM
DCR sensing (RsCs=L/rLR_sC_s = L/r_LRs​Cs​=L/rL​) ไม่มีการสูญเสียเพิ่ม DCR เปลี่ยนตามอุณหภูมิ ~0.39%/°C
Hall/magnetic (ACS7xx, TMCS) มีฉนวน แบนด์วิดท์/offset
Current transformer ใช้ใน off-line SMPS วัดได้เฉพาะ AC/พัลส์ ต้อง reset แกน

สำหรับ PCMC ต้องมี leading-edge blanking (100–300 ns) หรือ RC กรองหนามจากการคืนตัวของไดโอด

ชิปควบคุมคลาสสิกที่ยังไม่ตกยุค

  • TL494 / KA7500 — voltage mode, มี error amp 2 ตัว (แรงดัน+กระแสจำกัด), dead-time ปรับได้, push-pull output ใช้สอนได้ดีมาก
  • UC3842/3/4/5 (UC384x) — peak current mode, มี error amp + LEB ภายใน, ทนทาน ใช้แพร่หลายใน flyback/forward
  • TL431 + optocoupler (PC817) — error amp แบบแยกฉนวนมาตรฐาน: ลูปมีสองเส้นทาง (fast lane ผ่านตัวต้านทาน LED) ต้องคิด CTR และขั้วของ opto (~5–20 kHz)
  • ชิปรุ่นปัจจุบันดู การเลือกตัวควบคุม

Checklist วงจรอนาล็อก

  1. Soft-start: ค่อยๆ ยก VrefV_{ref}Vref​ (RC บน ref หรือ SS pin) ป้องกันกระแสพุ่งและ overshoot
  2. Anti-windup: clamp เอาต์พุต error amp (Zener/diode) ตอนจำกัดกระแส
  3. ต่อ VrefV_{ref}Vref​ ด้วย 100 nF ใกล้ขา; กราวด์สัญญาณแยกจากกราวด์กำลังแล้วรวมจุดเดียว
  4. ตรวจด้วยการฉีดสัญญาณวัด Bode จริง — ดู เทคนิคเชิงช่าง

ใช้ LM358 ทำ error amplifier ได้ไหม?

ได้สำหรับลูปช้า GBW ราว 1 MHz พอสำหรับครอสโอเวอร์ไม่กี่กิโลเฮิรตซ์ ถ้าต้องการลูปเร็วหรือ Type III ที่มีขั้วที่ความถี่สูง ควรใช้ออปแอมป์ GBW 3–10 MHz ขึ้นไป ไม่งั้นขั้วของออปแอมป์จะกินเฟสมาร์จิน

เว็บไซต์ หน้าแรก คลังความรู้ สูตรและตารางตรีโกณมิติ สูตรอินทิเกรตและวิธีทำ พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ เครื่องคิดเลขเมทริกซ์แสดงวิธีทำ แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
