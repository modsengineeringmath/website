# เลือกชิปควบคุมและไมโครคอนโทรลเลอร์สำหรับคอนเวอร์เตอร์: รุ่นปัจจุบันและรุ่นที่ไม่ตกยุค

// บทที่ 13.13 · อิเล็กทรอนิกส์กำลัง · Controller & MCU Selection


กรอบการตัดสินใจ ชิปอนาล็อกคลาสสิก TL494 SG3525 UC3843 TL431 ชิปรุ่นปัจจุบัน MCU C2000 STM32G4 dsPIC33 gate driver และคำเตือนเรื่องของปลอม

สรุปใน 30 วินาที

- สอน: ออปแอมป์ล้วนหรือ TL494

- ผลิตจริง: ชิปควบคุมเฉพาะทาง + MCU กำกับ

- ลูปเร็วดิจิทัล: C2000, STM32G474 HRTIM, dsPIC33

- ESP32 เหมาะลูปช้า (MPPT, monitor)

ก่อนสั่งซื้อ ตรวจ สถานะผลิตภัณฑ์ (Active/NRND), ดาต้าชีตฉบับล่าสุด และแหล่งจำหน่ายที่เชื่อถือได้ — ชิปยอดนิยม (LM2596, UC3843, IR2110) มี ของปลอม จำนวนมากในตลาดออนไลน์

## Op-amp และ comparator

ดูตารางใน การควบคุมแบบอนาล็อก — หลัก: GBW ≥ 10× ความต้องการ, rail-to-rail ถ้าแหล่งจ่ายต่ำ, ทน common-mode ของการวัดกระแส

## คำถามที่พบบ่อย

ห้องแล็บมหาวิทยาลัยควรเลือก MCU ตัวไหนสอนควบคุมดิจิทัล?
STM32G474 บนบอร์ด Nucleo ราคาถูกและมี HRTIM ความละเอียดสูง หรือ C2000 LaunchPad ที่ใช้มากในอุตสาหกรรมและมีเอกสารการสอนจำนวนมาก ทั้งสองมี comparator ในตัวสำหรับป้องกันกระแสเกินแบบรอบต่อรอบ
