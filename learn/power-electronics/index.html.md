# อิเล็กทรอนิกส์กำลัง (Power Electronics)

// บทที่ 15 · Power Electronics · ป.ตรี → ป.โท


อิเล็กทรอนิกส์กำลังคือการแปลงและควบคุมพลังงานไฟฟ้าด้วยสวิตช์สารกึ่งตัวนำให้มีประสิทธิภาพสูงสุด ตั้งแต่ที่ชาร์จโทรศัพท์จนถึงอินเวอร์เตอร์รถยนต์ไฟฟ้า หัวใจของวิชาไม่ใช่การจำวงจร แต่คือคณิตศาสตร์ของการสวิตช์ — volt-second balance การเฉลี่ยสถานะ Laplace และ z-transform — แล้วนำไปออกแบบ วัด และแก้ปัญหาของจริง ชุดนี้มี 23 หน้า 84 สูตรที่มีรหัสอ้างอิงถาวร 20 ตัวอย่างวิธีทำ และแล็บจำลองที่ใช้ได้ทันทีในเบราว์เซอร์

สรุปใน 30 วินาที

- สถานะคงตัว: $\langle v_L\rangle = 0$ (volt-second) และ $\langle i_C\rangle = 0$ (charge) ให้อัตราส่วนแปลงผันของทุกวงจร

- บั๊ก $D$ · บูสต์ $\frac{1}{1-D}$ · บั๊ก-บูสต์และชุค $-\frac{D}{1-D}$

- เฉลี่ยตลอดคาบแล้ว linearize ได้ $G_{vd}(s)$ → ออกแบบตัวชดเชยด้วย Bode

- ของจริงพังที่ layout การวัด และแม่เหล็ก มากกว่าที่สมการ — ดูหมวดภาคปฏิบัติ

ระดับพื้นฐาน ปวส. · ป.ตรี ปี 2–3กลาง ป.ตรี ปี 3–4ขั้นสูง ป.โท · งานวิจัย

## สมการที่ต้องรู้ตั้งแต่วันแรก พื้นฐาน

ในสถานะคงตัว แรงดันเฉลี่ยบนตัวเหนี่ยวนำและกระแสเฉลี่ยของตัวเก็บประจุเป็นศูนย์ สองบรรทัดนี้ให้อัตราส่วนแปลงผัน $M(D)$ ของทุกวงจร

$$\langle v_L\rangle = \frac{1}{T_s}\int_0^{T_s} v_L\,dt = 0 \qquad \langle i_C\rangle = \frac{1}{T_s}\int_0^{T_s} i_C\,dt = 0$$

| วงจร | $V_o/V_{in}$ (CCM) | แรงดันบนสวิตช์ | กระแสขาเข้า | ข้อสังเกตด้านควบคุม |

| บั๊ก | $D$ | $V_{in}$ | เป็นพัลส์ | ไม่มี RHP zero ควบคุมง่าย |

| บูสต์ | $\dfrac{1}{1-D}$ | $V_o$ | ต่อเนื่อง | มี RHP zero |

| บั๊ก-บูสต์ | $-\dfrac{D}{1-D}$ | $V_{in}+|V_o|$ | เป็นพัลส์ | มี RHP zero กลับขั้ว |

| ชุค | $-\dfrac{D}{1-D}$ | $V_{in}+|V_o|$ | ต่อเนื่อง (เข้าและออก) | อันดับสี่ ต้องหน่วง |

## เริ่มตามระดับของคุณ

พื้นฐาน

ปวส. ป.ตรี ปีแรก ๆ หรือช่างที่อยากเข้าใจว่าวงจรทำงานอย่างไร

บั๊ก → CCM · หาดิวตี้ → DCM → แล็บจำลอง → แหล่งจ่ายทดสอบ → เทคนิคหน้างาน

กลาง

ป.ตรี ปี 3–4 ที่ต้องออกแบบวงจรและลูปควบคุมจริง

แบบจำลองเฉลี่ย → ฟังก์ชันถ่ายโอนบั๊ก → ออกแบบ + โปรแกรมโหลด → บูสต์ → แบบจำลองสัญญาณเล็ก → ตัวชดเชย → ออปแอมป์ → ตัวเหนี่ยวนำ

ขั้นสูง

ป.โท งานวิจัย และวิศวกรออกแบบผลิตภัณฑ์

ชุค → ควบคุมดิจิทัล → ตัวสังเกต → AI ช่วยควบคุม

## บั๊กเชิงลึก: ไล่วงจร → แบบจำลองทางคณิตศาสตร์ → ออกแบบและทดสอบ กลาง

ชุดห้าหน้าที่พาตั้งแต่ "ตั้งดิวตี้เท่าไร" ไปจนถึง "ออกแบบแล้วจ่ายกระแสได้เท่าไร" ทุกหน้ามีที่มาครบ ตัวอย่างตรวจตัวเลขกับการจำลองสวิตชิ่ง แล็บโต้ตอบ และใบงาน

- CCM: ไล่วงจรหาดิวตี้KVL/KCL → volt-second → $D = V_o/V_g$ → ค่าแฝง (สูตร H1–H9)

- DCM: ดิวตี้ตามโหลดD₁ D₂ D₃ → $M(D,K)$ → $D = M\sqrt{K/(1-M)}$ (สูตร J1–J10)

- แบบจำลองเฉลี่ยและสเตตสเปซเฉลี่ยกระแส/แรงดัน → สัญญาณเล็ก → A, B, C, E (สูตร X1–X10)

- ฟังก์ชันถ่ายโอนทุกคู่$G_{vd}, G_{vg}, Z_{out}, Z_{in}, G_{iLd}$ + DCM + เครื่องวัดเสมือน (T1–T12)

- ออกแบบ + โปรแกรมโหลด48 ชิ้นส่วน · ความเค้น · โหลดหลายสภาวะ · load line (D1–D9)

## หัวข้อที่จะเพิ่มต่อไป

ชุดนี้ออกแบบให้ขยายได้ บทถัดไปตามลำดับ: SEPIC และ Zeta · synchronous และ interleaved converter · วงจรเรียงกระแสและ PFC · LLC resonant และ soft switching · Dual Active Bridge · อินเวอร์เตอร์ SPWM/SVPWM และการควบคุมแบบ dq · SiC/GaN · EV charger

การนำคอนเวอร์เตอร์ไปใช้กับระบบโซลาร์ (MPPT อินเวอร์เตอร์เชื่อมกริด PLL anti-islanding และการเลือกตัวควบคุม) อยู่ในชุดใหม่ ออกแบบระบบโซลาร์เซลล์ — ดู MPPT · อินเวอร์เตอร์โซลาร์ · เลือกตัวควบคุมโซลาร์
