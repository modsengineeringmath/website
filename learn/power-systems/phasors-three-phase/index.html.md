# เฟสเซอร์ อิมพีแดนซ์ กำลังเชิงซ้อน และระบบสามเฟส: Y กับ Δ, √3 และกำลังสามเฟส

// บทที่ 16.2 · ระบบไฟฟ้ากำลังและระบบป้องกัน · Phasors, Complex Power & Three-Phase


ทุกบทของวิชาระบบไฟฟ้ากำลังเขียนด้วยภาษาเฟสเซอร์ ถ้าคล่องสามอย่างในหน้านี้ — เฟสเซอร์ กำลังเชิงซ้อน และการลดระบบสามเฟสสมดุลเหลือวงจรเฟสเดียว — บทที่เหลือจะง่ายขึ้นมาก

สรุปใน 30 วินาที

- $v(t) = V_m\cos(\omega t+\theta)\ \leftrightarrow\ \mathbf V = \tfrac{V_m}{\sqrt2}\angle\theta$ (ค่า rms)

- $S = \mathbf V\mathbf I^* = P + jQ$ · ตัวเหนี่ยวนำ Q > 0 · ตัวเก็บประจุ Q < 0

- Y: $V_L = \sqrt3 V_{ph}\angle 30^\circ$, $I_L = I_{ph}$ · Δ: $V_L = V_{ph}$, $I_L = \sqrt3 I_{ph}\angle -30^\circ$

- $S_{3\varphi} = \sqrt3 V_L I_L$ · ระบบสมดุลคิดเฟสเดียวแล้วคูณ 3

## เฟสเซอร์และอิมพีแดนซ์ พื้นฐาน

A1 Phasor (rms) เฟสเซอร์ค่า rms

$$v(t) = \sqrt{2}\,V\cos(\omega t + \theta) \;\longleftrightarrow\; \mathbf V = V\angle\theta = V\cos\theta + jV\sin\theta$$

ระบบไฟฟ้ากำลังใช้เฟสเซอร์ค่า rms (ไม่ใช่ค่ายอด) เพราะกำลังคำนวณได้ตรงโดยไม่ต้องหาร 2 แรงดัน 230 V คือค่า rms ค่ายอดคือ 325 V อ่านทฤษฎีเฟสเซอร์และการหมุนเชิงภาพใน เพาเวอร์แฟกเตอร์ในรูปคลื่น

A2 Impedance อิมพีแดนซ์

$$\mathbf Z = R + jX = |Z|\angle\varphi \qquad X_L = \omega L \qquad X_C = -\frac{1}{\omega C} \qquad \mathbf I = \frac{\mathbf V}{\mathbf Z}$$

## กำลังเชิงซ้อน S = VI* พื้นฐาน

A3 Complex power กำลังเชิงซ้อน

$$\mathbf S = \mathbf V\,\mathbf I^* = P + jQ = |V||I|\angle(\theta_v - \theta_i) \qquad P = |V||I|\cos\varphi,\ \ Q = |V||I|\sin\varphi$$

A4 Power absorbed by an impedance กำลังที่อิมพีแดนซ์ดูดกลืน

$$\mathbf S = |I|^2\mathbf Z = |I|^2R + j|I|^2X = \frac{|V|^2}{\mathbf Z^*}$$

ตัวอย่าง A-1

### 230∠0° V จ่ายโหลด 8 + j6 Ω

- A2: $\mathbf Z = 10\angle 36.87^\circ$ → $\mathbf I = 230/10\angle 36.87^\circ = 23\angle -36.87^\circ$ A (ตามหลัง)

- A3: $\mathbf S = 230 \times 23\angle(0 + 36.87^\circ) = 5290\angle 36.87^\circ = 4232 + j3174$ VA

- A4 ตรวจ: $|I|^2R = 529 \times 8 = 4232$ W ✓ $|I|^2X = 529 \times 6 = 3174$ var ✓ PF = 0.8 ตามหลัง

## ระบบสามเฟสสมดุล: Y และ Δ พื้นฐาน

เครื่องกำเนิดสามเฟสสร้างแรงดันสามชุดขนาดเท่ากัน ห่างกัน 120° ลำดับเฟส a-b-c (ลำดับบวก) ในไทยเรียกเฟส L1 L2 L3 (หรือ R S T) ข้อดี: กำลังรวมขณะหนึ่งคงที่ (มอเตอร์ไม่สั่น) และใช้ทองแดงน้อยกว่าระบบเฟสเดียวที่ส่งกำลังเท่ากัน

A5 Wye (Y) connection การต่อแบบ Y

$$\mathbf V_{ab} = \mathbf V_{an} - \mathbf V_{bn} = \sqrt3\,V_{ph}\angle(\theta + 30^\circ) \qquad \mathbf I_L = \mathbf I_{ph}$$

A6 Three-phase power กำลังสามเฟส (ทั้ง Y และ Δ)

$$\mathbf S_{3\varphi} = 3\,\mathbf V_{ph}\mathbf I_{ph}^* \qquad |S_{3\varphi}| = \sqrt3\,V_L I_L \qquad P_{3\varphi} = \sqrt3\,V_L I_L\cos\varphi$$

A7 Delta (Δ) connection การต่อแบบ Δ

$$\mathbf V_L = \mathbf V_{ph} \qquad \mathbf I_a = \mathbf I_{ab} - \mathbf I_{ca} = \sqrt3\,I_{ph}\angle(\theta - 30^\circ)$$

A8 Balanced Δ → Y conversion แปลงโหลด Δ สมดุลเป็น Y

$$\mathbf Z_Y = \frac{\mathbf Z_\Delta}{3} \qquad \mathbf I_a + \mathbf I_b + \mathbf I_c = 0\ \ (\text{สมดุล: ไม่มีกระแสนิวทรัล})$$

ตัวอย่าง A-2

### มอเตอร์ 3 เฟส 400 V 30 kW PF 0.85 ตามหลัง

- A6: $I_L = 30{,}000/(\sqrt3 \times 400 \times 0.85) = 50.9$ A

- $S = 30/0.85 = 35.3$ kVA → $Q = \sqrt{35.3^2 - 30^2} = 18.6$ kvar

- ถ้ามอเตอร์ต่อ Δ: กระแสในขดลวด $50.9/\sqrt3 = 29.4$ A แรงดันคร่อมขด 400 V · ต่อ Y: กระแสขด 50.9 A แรงดัน 231 V — กำลังเท่ากัน

ตัวอย่าง A-3

### ฮีตเตอร์ Δ ตัวละ 48 Ω ต่อกับ 400 V

- กระแสต่อตัว $400/48 = 8.33$ A → กำลังรวม $3 \times 400 \times 8.33 = 10$ kW

- A8: เทียบเท่า Y ตัวละ 16 Ω: $I_L = 230.9/16 = 14.4$ A $= \sqrt3 \times 8.33$ ✓

- ถ้านำฮีตเตอร์ชุดเดิมไปต่อ Y: แรงดันต่อตัว 230.9 V กระแส 4.81 A กำลังรวม 3.33 kW — Y ได้กำลังเป็น 1/3 ของ Δ (หลักของการสตาร์ตมอเตอร์แบบ Y-Δ)

## วงจรสมมูลเฟสเดียว (per-phase equivalent) กลาง

- แปลงทุกอย่างที่ต่อ Δ เป็น Y เทียบเท่า (A8) แหล่งจ่าย Δ ใช้แรงดันเฟส $V_L/\sqrt3$

- วาดเฉพาะเฟส a กับสายนิวทรัลสมมติ (ไม่มีกระแสในระบบสมดุล)

- แก้วงจรเฟสเดียวด้วยเฟสเซอร์ แล้วเฟส b c ได้จากการหมุน −120° และ +120°

- กำลังรวม = 3 เท่าของเฟสเดียว

วิธีนี้ใช้ได้เฉพาะระบบสมดุล เมื่อไม่สมดุล (เช่น ลัดลงดินเฟสเดียว) ต้องใช้ องค์ประกอบสมมาตร ซึ่งแยกระบบไม่สมดุลออกเป็นระบบสมดุลสามชุด แล้วใช้วงจรเฟสเดียวได้อีกครั้ง

## ฝึกคิดด้วยเครื่องคำนวณ

หม้อแปลงจ่ายโหลด 700 kW PF 0.8 แรงดันด้านโหลดตกเท่าไร (ใช้ P Q และ %R %X — ทฤษฎีอยู่ในบทถัดไป)

## คำถามที่พบบ่อย

ทำไมกำลังเชิงซ้อนใช้ S = VI* (กระแสคอนจูเกต)?
เพื่อให้มุมของ S เท่ากับมุมของแรงดันลบมุมของกระแส ซึ่งคือมุมเพาเวอร์แฟกเตอร์ φ ถ้าใช้ VI ตรง ๆ มุมจะเป็นผลบวกของสองมุมซึ่งไม่มีความหมายทางกายภาพ ด้วยนิยามนี้ โหลดตัวเหนี่ยวนำ (กระแสตามหลัง) ได้ Q เป็นบวก

ทำไมกำลังสามเฟสมี √3?
เพราะ V_L = √3 V_ph ในการต่อ Y และ I_L = √3 I_ph ในการต่อ Δ กำลังรวม 3 V_ph I_ph cosφ จึงเขียนในรูปค่าสายได้เป็น √3 V_L I_L cosφ ทั้งสองแบบการต่อ ค่า √3 มาจากผลต่างของเฟสเซอร์สองตัวที่ห่างกัน 120°
