# คำนวณกระแสลัดวงจร: ลัดวงจรสามเฟสด้วย %Z และวิธี MVA, X/R ค่ายอด และพิกัดตัดกระแสของเบรกเกอร์

// บทที่ 16.5 · ระบบไฟฟ้ากำลังและระบบป้องกัน · Short-Circuit Calculation


กระแสลัดวงจรเป็นตัวเลขที่สำคัญที่สุดตัวหนึ่งในงานไฟฟ้า ใช้เลือกพิกัดตัดกระแส (kA) ของเบรกเกอร์ทุกตัว ขนาดบัสบาร์ ขนาดสายให้ทนความร้อนช่วงสั้น และตั้งค่ารีเลย์ หน้านี้ใช้วิธีที่วิศวกรใช้จริง: รวมอิมพีแดนซ์ตั้งแต่ต้นทางถึงจุดเกิดเหตุ แล้วหารแรงดันด้วยอิมพีแดนซ์

สรุปใน 30 วินาที

- $I_k'' = c\,U_n/(\sqrt3\,|Z_k|)$ โดย $Z_k$ = ต้นทาง + หม้อแปลง + สาย (อ้างอิงแรงดันเดียวกัน)

- หม้อแปลงอย่างเดียว: $I_k \approx I_n/Z_{pu}$ → 1,000 kVA 6 % ≈ 24 kA

- ค่ายอดแรก $i_p = \kappa\sqrt2\,I_k''$, $\kappa = 1.02 + 0.98e^{-3R/X}$

- เบรกเกอร์ต้องมี Icu (และควร Ics) ≥ กระแสลัดวงจรสูงสุด ณ จุดติดตั้ง

## วิธีอิมพีแดนซ์ (%Z / โอห์ม) ตาม IEC 60909 กลาง

หลักการ: ที่จุดลัดวงจรวางแหล่งจ่ายเทียบเท่า $cU_n/\sqrt3$ แล้วหารด้วยอิมพีแดนซ์ลำดับบวกรวมจากทุกแหล่งถึงจุดนั้น ทุกค่าต้องอ้างอิงที่แรงดันเดียวกัน (ปกติคือแรงดันที่จุดเกิดเหตุ) ตัวคูณ $c$ ชดเชยแรงดันจริงที่อาจสูงกว่าพิกัด ($c_{max} = 1.05$ สำหรับแรงต่ำ, 1.10 สำหรับแรงสูง)

F1 Initial symmetrical short-circuit current กระแสลัดวงจรสามเฟสเริ่มต้น

$$I_k'' = \frac{c\,U_n}{\sqrt3\,|Z_k|} \qquad Z_k = Z_Q + Z_T + Z_L$$

F2 Network (source) impedance อิมพีแดนซ์ต้นทางจากกำลังลัดวงจร

$$Z_Q = \frac{c\,U_n^2}{S_{kQ}''} \quad (\text{อ้างอิงแรงดัน } U_n)$$

F3 Transformer impedance อิมพีแดนซ์หม้อแปลง

$$Z_T = \frac{u_k}{100}\,\frac{U_{rT}^2}{S_{rT}} \qquad I_k \approx \frac{I_{rT}}{u_k/100}\ \ (\text{ต้นทางแข็งแรงมาก})$$

F4 Cable impedance อิมพีแดนซ์สายเคเบิล

$$Z_L = \frac{1}{n}\left(\frac{\rho\,\ell}{A} + j\,x'\ell\right) \qquad \rho_{Cu,20^\circ} = 0.018\ \Omega\,\text{mm}^2/\text{m},\ x' \approx 0.08\ \text{m}\Omega/\text{m}$$

ตัวอย่าง F-1

### ระบบ 22 kV (500 MVA) → หม้อแปลง 1,000 kVA 6 % → MDB 400 V → สาย 2 × 240 mm² ยาว 30 m

- F2 (อ้างอิง 400 V): $Z_Q = 1.05 \times 400^2/500\text{e}6 = 0.336\ \text{m}\Omega$ (X/R = 10)

- F3: $Z_T = 0.06 \times 400^2/1\text{e}6 = 9.60\ \text{m}\Omega$ X/R = 6 → $R_T = 1.58,\ X_T = 9.47\ \text{m}\Omega$

- ที่ MDB: $R = 1.61,\ X = 9.80\ \text{m}\Omega$ → $|Z| = 9.93\ \text{m}\Omega$ → F1: $I_k'' = 1.05 \times 400/(\sqrt3 \times 9.93\text{e-}3) = 24.4$ kA

- F4 สาย: $R_L = 0.018(30)/240/2 = 1.13\ \text{m}\Omega$ · $X_L = 0.08(30)/2 = 1.20\ \text{m}\Omega$ → ปลายสาย $|Z| = \sqrt{2.74^2 + 11.0^2} = 11.3\ \text{m}\Omega$ → 21.4 kA

- สาย 30 m ลดกระแสได้เพียง 12 % — ตู้ย่อยที่อยู่ใกล้ MDB ยังต้องใช้เบรกเกอร์พิกัดสูง

## วิธี MVA: คิดในใจได้ พื้นฐาน

F7 MVA method วิธี MVA (ต่ออนุกรมรวมแบบส่วนกลับ ขนานรวมแบบบวก)

$$S_{sc,i} = \frac{S_{r,i}}{Z_{pu,i}} \qquad \frac{1}{S_{sc,series}} = \sum_i \frac{1}{S_{sc,i}} \qquad S_{sc,parallel} = \sum_i S_{sc,i} \qquad I_k = \frac{S_{sc}}{\sqrt3\,U_n}$$

ตัวอย่าง F-2

### ตรวจตัวอย่าง F-1 ด้วยวิธี MVA

- หม้อแปลง: $1/0.06 = 16.67$ MVA · ต้นทาง 500 MVA

- อนุกรม: $1/(1/500 + 1/16.67) = 16.13$ MVA → $I_k = 16.13\text{e}6/(\sqrt3 \times 400) = 23.3$ kA

- ต่างจาก F-1 (24.4 kA) ราว 5 % เพราะวิธี MVA ไม่คิดตัวคูณ c และรวมขนาดโดยไม่สนมุม — ใช้ตรวจคำตอบเร็ว ๆ ได้ดี

- มอเตอร์ 200 kW ในโรงงานช่วยป้อนกระแสช่วงแรก ≈ 5–6 เท่าของพิกัดของมันเอง ($S_{sc} \approx 5.5 \times 0.25 = 1.4$ MVA ขนานเข้าไป) — IEC 60909 ให้รวมด้วย

## X/R, DC offset และค่ายอด กลาง

F9 Asymmetrical fault current กระแสลัดวงจรไม่สมมาตร

$$i(t) = \sqrt2\,I_k''\left[\sin(\omega t + \alpha - \theta) - \sin(\alpha - \theta)\,e^{-t/\tau}\right] \qquad \tau = \frac{X}{\omega R}$$

F5 Peak factor κ ตัวคูณค่ายอด (IEC 60909)

$$\kappa = 1.02 + 0.98\,e^{-3R/X}$$

F6 Peak short-circuit current ค่ายอดกระแสลัดวงจร

$$i_p = \kappa\,\sqrt2\,I_k''$$

เทอม DC มาจากความจริงที่ว่ากระแสในตัวเหนี่ยวนำเปลี่ยนทันทีไม่ได้ (เหมือน ระบบอันดับหนึ่ง) ถ้าลัดวงจรเกิดขณะ $\alpha - \theta = -90^\circ$ เทอม DC ใหญ่สุด X/R ยิ่งสูง τ ยิ่งยาว ยอดแรกยิ่งใกล้ $2\sqrt2 I_k''$

ตัวอย่าง F-3

### ค่ายอดที่ MDB (X/R = 6.08)

- F5: $\kappa = 1.02 + 0.98e^{-3/6.08} = 1.02 + 0.98(0.611) = 1.62$

- F6: $i_p = 1.62 \times \sqrt2 \times 24.4 = 55.9$ kA — ค่ายอดนี้กำหนดความแข็งแรงทางกลของบัสบาร์และพิกัด making capacity (Icm) ของเบรกเกอร์

- τ = $6.08/314.16 = 19$ ms — เทอม DC หายไปเกือบหมดภายในราว 3τ ≈ 60 ms

## เครื่องคำนวณกระแสลัดวงจร

## นำไปใช้: เลือกพิกัดเบรกเกอร์และตรวจสาย กลาง

F8 Breaker duty check เงื่อนไขพิกัดเบรกเกอร์

$$I_{cu}\ (\text{และควร } I_{cs}) \ge I_{k,max}'' \qquad I_{cm} \ge i_p \qquad k^2S^2 \ge I^2t\ \ (\text{สายทนความร้อน})$$

- ค่าสูงสุด (c = 1.05, สายเย็น 20 °C, มอเตอร์ทุกตัวทำงาน) ใช้เลือกพิกัดตัดกระแสและความแข็งแรง

- ค่าต่ำสุด (c = 0.95, สายร้อน, ลัดลงดินที่ปลายสาย) ใช้ตรวจว่าอุปกรณ์ป้องกัน ตัดทัน — เชื่อมกับ การตัดวงจรอัตโนมัติ

- เงื่อนไขความร้อนของสาย $I^2t \le k^2S^2$ (k ≈ 115 สำหรับทองแดง PVC) — ตรวจว่าสายไม่เสียหายก่อนอุปกรณ์ตัด

- การป้องกันแบบ cascading/back-up: เบรกเกอร์ต้นทางช่วยจำกัดกระแสให้เบรกเกอร์ปลายทางที่พิกัดต่ำกว่าได้ เฉพาะคู่ที่ผู้ผลิตรับรอง

## คำถามที่พบบ่อย

กระแสลัดวงจรของหม้อแปลงคำนวณเร็ว ๆ อย่างไร?
ถ้าต้นทางแข็งแรงมาก กระแสลัดวงจรสามเฟสที่ขั้วแรงต่ำประมาณเท่ากับกระแสพิกัดหารด้วย Z ในหน่วย pu เช่น หม้อแปลง 1,000 kVA 400 V มีกระแสพิกัด 1,443 A ถ้า %Z = 6 % กระแสลัดวงจรประมาณ 1,443/0.06 = 24 kA ค่าจริงต่ำกว่านี้เล็กน้อยเพราะต้นทางมีอิมพีแดนซ์ และสูงขึ้นถ้ามีมอเตอร์ช่วยป้อนกระแส

Icu กับ Ics ของเบรกเกอร์ต่างกันอย่างไร?
Icu (ultimate breaking capacity) คือกระแสลัดวงจรสูงสุดที่เบรกเกอร์ตัดได้โดยไม่ระเบิด แต่อาจใช้ต่อไม่ได้ Ics (service breaking capacity) คือกระแสที่ตัดได้แล้วยังใช้งานต่อได้ตามปกติ เป็นเปอร์เซ็นต์ของ Icu เช่น 50 75 หรือ 100 % จุดที่สำคัญควรเลือกให้ Ics ไม่น้อยกว่ากระแสลัดวงจรที่คำนวณได้

ทำไมกระแสลัดวงจรช่วงแรกสูงกว่าค่าสมมาตร?
เพราะวงจรมีตัวเหนี่ยวนำ กระแสเปลี่ยนทันทีไม่ได้ ถ้าลัดวงจรเกิดขณะแรงดันผ่านศูนย์ กระแสจะมีส่วน DC ซ้อนอยู่และลดลงแบบเอกซ์โพเนนเชียลด้วยค่าคงที่เวลา L/R ยอดแรกจึงสูงได้เกือบสองเท่าของค่ายอดสมมาตรเมื่อ X/R สูง เบรกเกอร์ต้องทนแรงแม่เหล็กไฟฟ้าจากค่ายอดนี้
