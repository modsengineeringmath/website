# การประยุกต์อินทิกรัลทางวิศวกรรมไฟฟ้า เครื่องกล และโยธา

// บทที่ 5.2 · อินทิกรัล · Engineering Applications


ถ้าอนุพันธ์ถามว่า “เปลี่ยนเร็วแค่ไหน” อินทิกรัลถามว่า “สะสมได้เท่าไร” วิศวกรไฟฟ้าใช้นับประจุ พลังงาน และค่า RMS วิศวกรเครื่องกลใช้หางาน จุดศูนย์ถ่วง และโมเมนต์ความเฉื่อย วิศวกรโยธาใช้หาแรงดันน้ำบนเขื่อน คุณสมบัติหน้าตัด การโก่งของคาน และปริมาตรดินขุด-ถม ทุกตัวอย่างมีตัวเลขจริง และมีแล็บคานให้เห็นสายอินทิกรัลจากน้ำหนักถึงการโก่ง สูตรใช้รหัส A

สรุปใน 30 วินาที

- ทุกปัญหาใช้ความคิดเดียว: แบ่งเป็นชิ้นเล็ก $dQ = (\text{ความหนาแน่น})\,dx$ แล้วรวมด้วย $\int$

- ไฟฟ้า: $q = \int i\,dt$, $W = \int p\,dt$, $V_{\text{rms}} = \sqrt{\frac1T\int v^2dt}$

- เครื่องกล: $W = \int F\,dx$, $\bar x = \frac{\int x\,dA}{\int dA}$, $I = \int r^2dm$

- โยธา: $F = \int\rho gh\,dA$, $I = \int y^2dA$, $EIy'' = M$ อินทิเกรตสองครั้งได้การโก่ง

## ความคิดเดียวที่ใช้ทุกสาขา: แบ่งแล้วรวม พื้นฐาน

A1 Element method แบ่งเป็นชิ้นเล็กแล้วรวม

$$Q = \lim_{n\to\infty}\sum_{k=1}^{n}\rho(x_k)\,\Delta x = \int_a^b\rho(x)\,dx$$

ขั้นตอน: (1) เลือกตัวแปรที่ปริมาณเปลี่ยนตาม (2) เขียนชิ้นเล็ก $dQ$ ในรูปที่ “คงที่ภายในชิ้น” (3) อินทิเกรตตลอดช่วง · ทบทวนอินทิกรัลจำกัดเขตและผลบวกรีมันน์

## วิศวกรรมไฟฟ้า: ประจุ พลังงาน ค่าเฉลี่ย และ RMS พื้นฐาน

A2 Charge ประจุ

$$q = \int_{t_1}^{t_2}i(t)\,dt$$

A3 Capacitor voltage แรงดันตัวเก็บประจุ

$$v_C(t) = v_C(0) + \frac1C\int_0^t i(\tau)\,d\tau$$

A4 Energy พลังงาน

$$W = \int p\,dt,\qquad W_C = \int_0^V Cv\,dv = \tfrac12CV^2,\qquad W_L = \tfrac12LI^2$$

A5 Average & RMS ค่าเฉลี่ยและค่าประสิทธิผล

$$V_{\text{avg}} = \frac1T\int_0^Tv\,dt,\qquad V_{\text{rms}} = \sqrt{\frac1T\int_0^Tv^2\,dt}$$

ตัวอย่าง A-1 · ประจุจากกระแสลดลง

### กระแส $i(t) = 2e^{-3t}$ A ไหลเข้าตัวเก็บประจุ หาประจุที่สะสมใน 1 s แรก และทั้งหมด

-
$$q(1) = \int_0^1 2e^{-3t}dt = \left[-\tfrac23e^{-3t}\right]_0^1 = \tfrac23\left(1 - e^{-3}\right) = 0.6335\ \text{C}$$

-
$$q(\infty) = \int_0^\infty 2e^{-3t}dt = \tfrac23\ \text{C}$$

0.634 C ใน 1 วินาที (95% ของทั้งหมด เพราะ 1 s = 3τ) ทั้งหมด 0.667 C

ตัวอย่าง A-2 · ชาร์จด้วยกระแสคงที่ และพลังงานในขดลวด

### (ก) $C = 100\ \mu$F เริ่ม 0 V ป้อนกระแสคงที่ 5 mA นาน 2 s (ข) $L = 0.2$ H มีกระแส 3 A

- (ก) $v = \dfrac{1}{C}\int_0^2 0.005\,dt = \dfrac{0.01}{10^{-4}} = 100$ V แรงดันขึ้นเป็นเส้นตรง (หลักของวงจรสร้างคลื่นฟันเลื่อย)

- (ข) $W = \int_0^{3} L\,i\,di = \tfrac12(0.2)(9) = 0.9$ J

(ก) 100 V · (ข) 0.9 J ตัวเลขนี้คือพลังงานที่ไดโอดฟรีวีลต้องรับเมื่อตัดกระแส

ตัวอย่าง A-3 · เรียงกระแสครึ่งคลื่น

### หาค่าเฉลี่ยและ RMS ของ $v = V_m\sin\omega t$ ช่วงครึ่งบวก และ 0 ช่วงครึ่งลบ เมื่อ $V_m = 311$ V

- ใช้ $\theta = \omega t$ คาบ $2\pi$

$$V_{\text{avg}} = \frac{1}{2\pi}\int_0^\pi V_m\sin\theta\,d\theta = \frac{V_m}{2\pi}\left[-\cos\theta\right]_0^\pi = \frac{V_m}{\pi}$$

-
$$V_{\text{rms}}^2 = \frac{1}{2\pi}\int_0^\pi V_m^2\sin^2\theta\,d\theta = \frac{V_m^2}{2\pi}\cdot\frac{\pi}{2} = \frac{V_m^2}{4} \Rightarrow V_{\text{rms}} = \frac{V_m}{2}$$

$V_{\text{avg}} = 311/\pi = 99.0$ V, $V_{\text{rms}} = 155.5$ V เลือกรูปคลื่นในแล็บด้านล่างแล้วเทียบได้ทันที

## วิศวกรรมเครื่องกล: งาน จุดศูนย์ถ่วง ความเฉื่อย และอิมพัลส์ กลาง

A6 Work งานของแรงที่เปลี่ยนค่า

$$W = \int_a^bF(x)\,dx,\qquad W_{\text{spring}} = \int_{x_1}^{x_2}kx\,dx = \tfrac12k\left(x_2^2 - x_1^2\right)$$

A7 Centroid of an area เซนทรอยด์

$$\bar x = \frac{\int x\,dA}{\int dA},\qquad \bar y = \frac{\int \tfrac{y}{2}\,y\,dx}{\int y\,dx}\ (\text{แถบแนวตั้งใต้ } y = f(x))$$

A8 Mass moment of inertia โมเมนต์ความเฉื่อยของมวล

$$I = \int r^2\,dm,\quad I_{\text{rod, end}} = \tfrac13mL^2,\quad I_{\text{disk}} = \tfrac12mR^2$$

A9 Impulse อิมพัลส์

$$J = \int F\,dt = \Delta p$$

ตัวอย่าง A-4 · งานยืดสปริง

### สปริง $k = 2000$ N/m ยืดจาก 5 cm เป็น 15 cm ต้องใช้งานเท่าใด

-
$$W = \int_{0.05}^{0.15}2000x\,dx = 1000\left(0.15^2 - 0.05^2\right) = 1000(0.02) = 20\ \text{J}$$

20 J (ไม่ใช่ $kx\cdot\Delta x = 2000(0.1)(0.1)$ เพราะแรงไม่คงที่)

ตัวอย่าง A-5 · เซนทรอยด์ของพื้นที่ใต้พาราโบลา

### พื้นที่ใต้ $y = x^2$ จาก $x = 0$ ถึง 2

-
$$A = \int_0^2x^2dx = \tfrac83$$

-
$$\bar x = \frac{\int_0^2 x\cdot x^2dx}{A} = \frac{4}{8/3} = 1.5,\qquad \bar y = \frac{\int_0^2\tfrac12(x^2)^2dx}{A} = \frac{32/10}{8/3} = 1.2$$

$(\bar x, \bar y) = (1.5, 1.2)$ เอียงไปทางขวาเพราะพื้นที่ส่วนใหญ่อยู่ที่ x มาก

ตัวอย่าง A-6 · ความเฉื่อยของแกนหมุน และอิมพัลส์

### (ก) แท่งยาว L มวล m หมุนรอบปลาย (ข) แรงกระแทก $F = 500\sin(\pi t/0.01)$ N นาน 0.01 s

- (ก) $dm = \tfrac mL dx$: $I = \int_0^L x^2\tfrac mL dx = \tfrac13mL^2$

- (ข) $J = \int_0^{0.01}500\sin\dfrac{\pi t}{0.01}dt = 500\cdot\dfrac{0.01}{\pi}\left[-\cos\dfrac{\pi t}{0.01}\right]_0^{0.01} = \dfrac{10}{\pi} = 3.18$ N·s

(ก) $\tfrac13mL^2$ (มากกว่ารอบจุดกึ่งกลาง $\tfrac1{12}mL^2$ ถึง 4 เท่า) · (ข) 3.18 N·s

ตัวอย่าง A-7 · งานสูบน้ำออกจากถัง

### ถังทรงกระบอกรัศมี 1 m สูง 3 m เต็มน้ำ สูบออกทางขอบบนทั้งหมด ($\rho = 1000$ kg/m³)

- ชิ้นน้ำบางที่ความสูง y หนา dy: น้ำหนัก $\rho g\pi(1)^2dy$ ต้องยกขึ้น $3 - y$

-
$$W = \int_0^3 1000(9.81)\pi(3 - y)\,dy = 9810\pi\left[3y - \tfrac{y^2}{2}\right]_0^3 = 9810\pi(4.5) = 138.7\ \text{kJ}$$

138.7 kJ ปั๊ม 1 kW ที่ประสิทธิภาพ 60% ใช้เวลาราว 231 s

## วิศวกรรมโยธา: เขื่อน หน้าตัด น้ำหนักแผ่ และคาน กลาง

A10 Hydrostatic force แรงดันน้ำ

$$F = \int_0^H\rho g h\,w(h)\,dh,\qquad h_{cp} = \frac{\int h\,dF}{\int dF}$$

A11 Second moment of area โมเมนต์ความเฉื่อยของหน้าตัด

$$I_x = \int y^2\,dA,\qquad I_{\text{rect}} = \int_{-h/2}^{h/2}y^2b\,dy = \frac{bh^3}{12}$$

A12 Distributed load resultant แรงลัพธ์ของน้ำหนักแผ่

$$R = \int_0^Lw(x)\,dx,\qquad \bar x = \frac{\int_0^Lx\,w(x)\,dx}{R}$$

A13 Double integration การโก่งด้วยการอินทิเกรตสองครั้ง

$$EI\,y' = \int M\,dx + C_1,\qquad EI\,y = \iint M\,dx\,dx + C_1x + C_2$$

ตัวอย่าง A-8 · แรงดันน้ำบนเขื่อน

### หน้าเขื่อนแนวตั้งกว้าง 20 m น้ำลึก 10 m หาแรงลัพธ์และตำแหน่ง

-
$$F = \int_0^{10}1000(9.81)h(20)\,dh = 196{,}200\left[\tfrac{h^2}{2}\right]_0^{10} = 9.81\times10^6\ \text{N}$$

-
$$h_{cp} = \frac{\int_0^{10}h\cdot h\,dh}{\int_0^{10}h\,dh} = \frac{1000/3}{50} = 6.67\ \text{m}$$

9.81 MN กระทำที่ลึก 6.67 m (2/3 ของความลึก) เป็นจุดที่ใช้คำนวณโมเมนต์พลิกคว่ำของเขื่อน

ตัวอย่าง A-9 · หน้าตัดคานและน้ำหนักแผ่สามเหลี่ยม

### (ก) $I$ ของหน้าตัด 20 × 40 cm (ข) น้ำหนักแผ่ $w = 12x/6$ kN/m บนคานยาว 6 m

- (ก) $I = \dfrac{bh^3}{12} = \dfrac{0.2(0.4)^3}{12} = 1.067\times10^{-3}$ m⁴ (วางด้านยาวตั้งแข็งกว่าวางนอน 4 เท่า เพราะ h ยกกำลัง 3)

- (ข) $R = \int_0^6 2x\,dx = 36$ kN · $\bar x = \dfrac{\int_0^6 2x^2dx}{36} = \dfrac{144}{36} = 4$ m (2/3 ของความยาวจากปลายที่ศูนย์)

(ก) $1.067\times10^{-3}$ m⁴ · (ข) 36 kN ที่ x = 4 m

ตัวอย่าง A-10 · การโก่งของคานยื่น

### คานยื่นยาว L ยึดแน่นที่ x = 0 รับแรง P ที่ปลาย หาการโก่งที่ปลาย

- $M(x) = -P(L - x)$ A13

$$EIy' = -P\left(Lx - \tfrac{x^2}{2}\right) + C_1,\quad y'(0) = 0 \Rightarrow C_1 = 0$$

-
$$EIy = -P\left(\tfrac{Lx^2}{2} - \tfrac{x^3}{6}\right) + C_2,\quad y(0) = 0 \Rightarrow C_2 = 0$$

-
$$y(L) = -\frac{P}{EI}\left(\frac{L^3}{2} - \frac{L^3}{6}\right) = -\frac{PL^3}{3EI}$$

$\delta = PL^3/(3EI)$ เช่น P = 10 kN, L = 3 m, EI = 20,000 kN·m² ได้ 4.5 mm · ตรวจด้วยแล็บด้านล่าง (เลือกคานยื่น ตั้ง w = 0)

## แล็บคาน: น้ำหนัก → แรงเฉือน → โมเมนต์ → ความชัน → การโก่ง

ห้ากราฟนี้คือสายอินทิกรัลที่สวยที่สุดในวิศวกรรม: อินทิเกรตน้ำหนักได้แรงเฉือน อินทิเกรตแรงเฉือนได้โมเมนต์ อินทิเกรตโมเมนต์ (หาร EI) ได้ความชัน อินทิเกรตอีกครั้งได้การโก่ง ย้อนกลับขึ้นไปคือการหาอนุพันธ์ ลองเลื่อนตำแหน่งแรงแล้วดูว่าโมเมนต์สูงสุดตามแรงเฉือนที่เปลี่ยนเครื่องหมายเสมอ และการโก่งสูงสุดอยู่ตรงที่ความชันเป็นศูนย์

## อินทิเกรตเชิงตัวเลข: งานดินและข้อมูลสนาม กลาง

ในงานสนามเรามีแต่ตัวเลขที่วัดได้เป็นช่วง ๆ ไม่มีสูตร เช่น พื้นที่หน้าตัดดินทุก 20 m หรือกระแสที่บันทึกทุก 1 ms จึงอินทิเกรตด้วยกฎสี่เหลี่ยมคางหมูหรือซิมป์สัน

A14 Trapezoidal rule สี่เหลี่ยมคางหมู

$$\int_a^bf\,dx \approx h\left[\tfrac{f_0}{2} + f_1 + \cdots + f_{n-1} + \tfrac{f_n}{2}\right]$$

ในงานทางเรียกว่าวิธีพื้นที่ปลายเฉลี่ย (average end area)

A15 Simpson's rule ซิมป์สัน (n คู่)

$$\int_a^bf\,dx \approx \frac h3\left[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 4f_{n-1} + f_n\right]$$

แม่นตรงกับพหุนามถึงดีกรีสาม ใกล้สูตรปริซมอยด์ (prismoidal formula) ของงานดิน

ตัวอย่าง A-11 · ปริมาตรงานดินขุด

### พื้นที่หน้าตัดดินขุดทุก 20 m: 12, 18, 25, 21, 15 m² หาปริมาตรรวม 80 m

- สี่เหลี่ยมคางหมู

$$V \approx 20\left[\tfrac{12}{2} + 18 + 25 + 21 + \tfrac{15}{2}\right] = 20(77.5) = 1550\ \text{m}^3$$

- ซิมป์สัน (4 ช่วง)

$$V \approx \frac{20}{3}\left[12 + 4(18) + 2(25) + 4(21) + 15\right] = \frac{20}{3}(233) = 1553.3\ \text{m}^3$$

ประมาณ 1,550 m³ สองวิธีต่างกันเพียง 0.2% ใช้คำนวณค่าขนส่งดินและค่าจ้างเหมา

## อ่านต่อ

- ด้านกลับ (อัตราการเปลี่ยนแปลง): การประยุกต์อนุพันธ์

## คำถามที่พบบ่อย

ทำไม RMS ของไฟบ้านจึงเป็นค่ายอดหาร √2?
เพราะ RMS คือรากที่สองของค่าเฉลี่ยของกำลังสอง $\sqrt{\frac1T\int v^2dt}$ และค่าเฉลี่ยของ $\sin^2$ ในหนึ่งคาบเท่ากับ 1/2 จึงได้ $V_m/\sqrt2$ ใช้ได้เฉพาะคลื่นไซน์ คลื่นรูปอื่นต้องอินทิเกรตใหม่

แรงดันน้ำบนเขื่อนกระทำที่จุดใด?
แรงดันเพิ่มขึ้นเชิงเส้นตามความลึก แรงลัพธ์บนผนังแนวตั้งสี่เหลี่ยมจึงกระทำที่ 2/3 ของความลึกจากผิวน้ำ (จุดศูนย์กลางของแรงดัน) ไม่ใช่ที่ครึ่งความลึก หาได้จาก $\int h\,dF / \int dF$

การโก่งของคานหาด้วยอินทิกรัลอย่างไร?
เริ่มจาก $EI\,y'' = M(x)$ อินทิเกรตครั้งแรกได้ความชัน อินทิเกรตครั้งที่สองได้การโก่ง แล้วหาค่าคงที่สองตัวจากเงื่อนไขที่ฐานรองรับ เช่น คานช่วงเดียว y(0) = y(L) = 0 คานยื่น y(0) = y′(0) = 0 เรียกว่าวิธีอินทิเกรตสองครั้ง

## คำถามที่พบบ่อย (FAQ)

**ทำไม RMS ของไฟบ้านจึงเป็นค่ายอดหาร √2?**
เพราะ RMS คือรากที่สองของค่าเฉลี่ยของกำลังสอง $\sqrt{\frac1T\int v^2dt}$ และค่าเฉลี่ยของ $\sin^2$ ในหนึ่งคาบเท่ากับ 1/2 จึงได้ $V_m/\sqrt2$ ใช้ได้เฉพาะคลื่นไซน์ คลื่นรูปอื่นต้องอินทิเกรตใหม่

**แรงดันน้ำบนเขื่อนกระทำที่จุดใด?**
แรงดันเพิ่มขึ้นเชิงเส้นตามความลึก แรงลัพธ์บนผนังแนวตั้งสี่เหลี่ยมจึงกระทำที่ 2/3 ของความลึกจากผิวน้ำ (จุดศูนย์กลางของแรงดัน) ไม่ใช่ที่ครึ่งความลึก หาได้จาก $\int h\,dF / \int dF$

**การโก่งของคานหาด้วยอินทิกรัลอย่างไร?**
เริ่มจาก $EI\,y'' = M(x)$ อินทิเกรตครั้งแรกได้ความชัน อินทิเกรตครั้งที่สองได้การโก่ง แล้วหาค่าคงที่สองตัวจากเงื่อนไขที่ฐานรองรับ เช่น คานช่วงเดียว y(0) = y(L) = 0 คานยื่น y(0) = y′(0) = 0 เรียกว่าวิธีอินทิเกรตสองครั้ง
