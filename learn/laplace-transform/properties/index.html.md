# คุณสมบัติของการแปลงลาปลาซครบทุกข้อ พร้อมพิสูจน์และตัวอย่าง

// บทที่ 8.3 · การแปลงลาปลาซ · Properties


ตารางคู่การแปลงมีไม่กี่สิบบรรทัด แต่ด้วยคุณสมบัติในหน้านี้ เราสร้างการแปลงของฟังก์ชันได้แทบไม่จำกัดโดยไม่ต้องอินทิเกรตจากนิยามอีกเลย ทุกข้อมีชื่อภาษาอังกฤษ พิสูจน์สั้น ข้อควรระวัง และตัวอย่าง ท้ายหน้ามีแล็บที่คำนวณ $g(t)$ จากนิยามในโดเมนเวลาเทียบกับ $\mathcal L^{-1}\{G(s)\}$ ให้เห็นว่าสูตรถูกจริง สูตรใช้รหัส P

สรุปใน 30 วินาที

- เวลา “เลื่อน” → คูณ $e^{-sT}$ · คูณ $e^{-at}$ → เลื่อน $s$ ไปเป็น $s + a$

- อนุพันธ์ → คูณ $s$ ลบค่าเริ่มต้น · ปริพันธ์ → หาร $s$

- คูณ $t$ → $-d/ds$ · คอนโวลูชัน → คูณกัน

- $f(0^+) = \lim_{s\to\infty}sF(s)$ · $f(\infty) = \lim_{s\to 0}sF(s)$ ใช้ได้เมื่อโพลของ $sF(s)$ อยู่ครึ่งซ้ายทั้งหมด

ระดับพื้นฐาน ปี 2กลาง ป.ตรี วิศวกรรมขั้นสูง ป.โท

## ตารางสรุปคุณสมบัติทั้งหมด

| รหัส | ชื่อ (English) | $f(t)$ | $F(s)$ |

| P1 | เชิงเส้น (Linearity) | $af(t) + bg(t)$ | $aF(s) + bG(s)$ |

| P2 | เลื่อนทางเวลา (Time shifting) | $f(t-T)u(t-T)$ | $e^{-sT}F(s)$ |

| P3 | เลื่อนทางความถี่ (Frequency / s-shifting) | $e^{-at}f(t)$ | $F(s+a)$ |

| P4 | สเกลเวลา (Time scaling) | $f(at),\ a>0$ | $\tfrac{1}{a}F(\tfrac{s}{a})$ |

| P5 | กลับเวลา (Time reversal, สองด้าน) | $f(-t)$ | $F(-s)$ |

| P6 | อนุพันธ์ (Differentiation in t) | $f'(t)$ | $sF(s) - f(0^-)$ |

| P7 | อนุพันธ์อันดับ n | $f^{(n)}(t)$ | $s^nF - s^{n-1}f(0^-) - \cdots - f^{(n-1)}(0^-)$ |

| P8 | ปริพันธ์ (Integration in t) | $\int_{0^-}^t f(\tau)d\tau$ | $\dfrac{F(s)}{s}$ |

| P9 | คูณด้วย t (Differentiation in s) | $t\,f(t)$ | $-F'(s)$ |

| P10 | คูณด้วย $t^n$ | $t^nf(t)$ | $(-1)^nF^{(n)}(s)$ |

| P11 | หารด้วย t (Integration in s) | $f(t)/t$ | $\int_s^\infty F(u)\,du$ |

| P12 | คอนโวลูชัน (Convolution) | $(f*g)(t)$ | $F(s)G(s)$ |

| P13 | การคูณ (Complex convolution) | $f(t)g(t)$ | $\tfrac{1}{2\pi j}\int F(p)G(s-p)dp$ |

| P14 | ฟังก์ชันคาบ (Periodic function) | $f(t + T) = f(t)$ | $\dfrac{\int_0^T f e^{-st}dt}{1 - e^{-sT}}$ |

| P15 | ทฤษฎีบทค่าเริ่มต้น (Initial value) | $f(0^+)$ | $\lim_{s\to\infty}sF(s)$ |

| P16 | ทฤษฎีบทค่าสุดท้าย (Final value) | $f(\infty)$ | $\lim_{s\to 0}sF(s)$ |

| P17 | สังยุค (Conjugation) | $\overline{f(t)}$ | $\overline{F(\bar s)}$ |

## เชิงเส้น (Linearity) พื้นฐาน

P1 Linearity เชิงเส้น

$$\mathcal L\{af(t) + bg(t)\} = aF(s) + bG(s),\qquad \text{ROC} \supseteq R_f \cap R_g$$

พิสูจน์: อินทิกรัลเป็นตัวดำเนินการเชิงเส้น · ทำให้ใช้ตารางกับผลรวมทีละพจน์ได้ และเป็นฐานของการแยกเศษส่วนย่อย

ตัวอย่าง P-1

### $\mathcal L\{3 - 2e^{-4t} + 5\cos 2t\}$

-
$$= \frac{3}{s} - \frac{2}{s+4} + \frac{5s}{s^2+4},\quad \operatorname{Re}s > 0$$

ROC คือส่วนร่วม $\sigma > 0$ ∩ $\sigma > -4$ ∩ $\sigma > 0$ = $\sigma > 0$

## การเลื่อนทางเวลา (Time Shifting / Second Shifting Theorem) พื้นฐาน

P2 Time shifting เลื่อนทางเวลา (หน่วงเวลา)

$$\mathcal L\{f(t - T)\,u(t - T)\} = e^{-sT}F(s),\quad T \ge 0$$

พิสูจน์: แทน $\tau = t - T$ ใน $\int_T^\infty f(t-T)e^{-st}dt = e^{-sT}\int_0^\infty f(\tau)e^{-s\tau}d\tau$ · ROC เท่าเดิม · ต้องอยู่ในรูป “ฟังก์ชันของ $(t - T)$ คูณ $u(t - T)$” เท่านั้น

ตัวอย่าง P-2 · กับดักที่เจอบ่อยที่สุด

### $\mathcal L\{t\,u(t-2)\}$

- $t$ ยังไม่อยู่ในรูปของ $(t-2)$ จัดรูปก่อน: $t = (t - 2) + 2$

$$t\,u(t-2) = (t-2)u(t-2) + 2u(t-2)$$

- ใช้ P2 กับ $f(t) = t$ และ $f(t) = 2$

$$\mathcal L = e^{-2s}\left(\frac{1}{s^2} + \frac{2}{s}\right) = \frac{e^{-2s}(1 + 2s)}{s^2}$$

$\dfrac{(1+2s)e^{-2s}}{s^2}$ · ถ้าตอบ $e^{-2s}/s^2$ แปลว่าแปลง $(t-2)u(t-2)$ ไม่ใช่ $t\,u(t-2)$

ตัวอย่าง P-3 · พัลส์และสัญญาณเป็นช่วง

### $f(t) = 5$ เมื่อ $1 \le t < 3$ และเป็น 0 นอกช่วงนี้

-
$$f(t) = 5\left[u(t-1) - u(t-3)\right]$$

-
$$F(s) = \frac{5\left(e^{-s} - e^{-3s}\right)}{s}$$

$F(s) = \dfrac{5(e^{-s} - e^{-3s})}{s}$ แปลงกลับในเครื่องคิดเลขได้

## การเลื่อนทางความถี่ (Frequency Shifting / First Shifting Theorem) พื้นฐาน

P3 s-shifting เลื่อนทางความถี่

$$\mathcal L\{e^{-at}f(t)\} = F(s + a),\qquad \text{ROC เลื่อนไป } -\operatorname{Re}a$$

พิสูจน์: $\int e^{-at}f(t)e^{-st}dt = \int f(t)e^{-(s+a)t}dt$ · ในระนาบ s ทุกโพลและซีโร่เลื่อนไปทางซ้าย $a$ หน่วย: คูณการหน่วงในเวลา = ย้ายโพลไปซ้าย

ตัวอย่าง P-4

### $\mathcal L\{t^2e^{-3t}\}$ และ $\mathcal L\{e^{-2t}\sin 5t\}$

- $\mathcal L\{t^2\} = 2/s^3$ แล้วแทน $s \to s + 3$

$$\mathcal L\{t^2e^{-3t}\} = \frac{2}{(s+3)^3}$$

- $\mathcal L\{\sin 5t\} = 5/(s^2+25)$ แล้วแทน $s \to s + 2$

$$\mathcal L\{e^{-2t}\sin 5t\} = \frac{5}{(s+2)^2 + 25} = \frac{5}{s^2 + 4s + 29}$$

ในทางกลับกัน เมื่อเห็นตัวส่วน $s^2 + 4s + 29$ ให้ เติมกำลังสองสมบูรณ์ เป็น $(s+2)^2 + 5^2$ แล้วอ่านกลับได้ทันที ซึ่งเป็นเทคนิคหลักของโพลเชิงซ้อนในหน้า 8.5

## สเกลเวลาและการกลับเวลา กลาง

P4 Time scaling สเกลเวลา

$$\mathcal L\{f(at)\} = \frac{1}{a}F\!\left(\frac{s}{a}\right),\quad a > 0$$

บีบเวลาให้เร็วขึ้น $a$ เท่า = โพลทุกตัวคูณ $a$ (ไกลจุดกำเนิดขึ้น)

P5 Time reversal กลับเวลา (การแปลงสองด้าน)

$$\mathcal L\{f(-t)\} = F(-s),\quad \text{ROC} \to -\text{ROC}$$

ใช้ไม่ได้กับการแปลงด้านเดียว เพราะ $f(-t)$ อยู่ในเวลาติดลบ

ตัวอย่าง P-5

### จาก $\mathcal L\{\sin t\} = \dfrac{1}{s^2+1}$ หา $\mathcal L\{\sin 3t\}$ ด้วย P4

-
$$\mathcal L\{\sin 3t\} = \frac{1}{3}\cdot\frac{1}{(s/3)^2 + 1} = \frac{1}{3}\cdot\frac{9}{s^2 + 9} = \frac{3}{s^2+9}$$

ตรงกับตาราง $\omega/(s^2+\omega^2)$ ที่ $\omega = 3$ ✓

## การหาอนุพันธ์ในโดเมนเวลา (Differentiation) พื้นฐาน

นี่คือคุณสมบัติที่ทำให้ลาปลาซมีค่าที่สุด: แคลคูลัสกลายเป็นพีชคณิต และเงื่อนไขเริ่มต้นเข้ามาเองในสมการ

P6 Differentiation in t อนุพันธ์อันดับหนึ่ง

$$\mathcal L\{f'(t)\} = sF(s) - f(0^-)$$

พิสูจน์ด้วยอินทิเกรตทีละส่วน ($u = e^{-st},\ dv = f'dt$): $\int_{0^-}^\infty f'e^{-st}dt = \left[fe^{-st}\right]_{0^-}^\infty + s\int_{0^-}^\infty fe^{-st}dt = -f(0^-) + sF(s)$ (ขอบบนเป็นศูนย์ใน ROC) ทบทวนการอินทิเกรตทีละส่วน

P7 Higher derivatives อนุพันธ์อันดับสองและอันดับ n

$$\mathcal L\{f''\} = s^2F(s) - sf(0^-) - f'(0^-),\qquad \mathcal L\{f^{(n)}\} = s^nF(s) - \sum_{k=1}^{n}s^{n-k}f^{(k-1)}(0^-)$$

ตัวอย่าง P-6 · ได้ cos มาฟรีจาก sin

### ใช้ P6 หา $\mathcal L\{\cos\omega t\}$ จาก $\mathcal L\{\sin\omega t\} = \dfrac{\omega}{s^2+\omega^2}$

- $f = \sin\omega t,\ f' = \omega\cos\omega t,\ f(0) = 0$

$$\mathcal L\{\omega\cos\omega t\} = s\cdot\frac{\omega}{s^2+\omega^2} - 0$$

$\mathcal L\{\cos\omega t\} = \dfrac{s}{s^2+\omega^2}$

ตัวอย่าง P-7 · แบบจำลองวงจรในโดเมน s

### เขียนความสัมพันธ์ของตัวเหนี่ยวนำและตัวเก็บประจุในโดเมน s รวมค่าเริ่มต้น

- ตัวเหนี่ยวนำ $v = L\,di/dt$:

$$V(s) = sL\,I(s) - L\,i(0^-)$$
อิมพีแดนซ์ $sL$ อนุกรมกับแหล่งแรงดัน $L\,i(0^-)$ (ขั้วต้านกระแสเดิม)

- ตัวเก็บประจุ $i = C\,dv/dt$:

$$I(s) = sC\,V(s) - C\,v(0^-)\ \Rightarrow\ V(s) = \frac{1}{sC}I(s) + \frac{v(0^-)}{s}$$
อิมพีแดนซ์ $1/(sC)$ อนุกรมกับแหล่งแรงดัน $v(0^-)/s$

วงจรที่มีค่าเริ่มต้นจึงวิเคราะห์ด้วย KVL/KCL แบบพีชคณิตได้ทันทีในโดเมน s ใช้ต่อในหน้าแก้สมการเชิงอนุพันธ์

## การหาปริพันธ์ในโดเมนเวลา (Integration) พื้นฐาน

P8 Integration in t ปริพันธ์

$$\mathcal L\left\{\int_{0^-}^{t}f(\tau)\,d\tau\right\} = \frac{F(s)}{s}$$

พิสูจน์: ให้ $g = \int_0^t f$ แล้ว $g' = f,\ g(0) = 0$ ใช้ P6: $F = sG - 0$ · ตรงข้ามกับอนุพันธ์: หารด้วย $s$ = เพิ่มโพลที่จุดกำเนิด

ตัวอย่าง P-8

### $\mathcal L^{-1}\left\{\dfrac{1}{s(s^2+1)}\right\}$ โดยไม่ใช้เศษส่วนย่อย

- มองเป็น $\dfrac{1}{s}\cdot\dfrac{1}{s^2+1}$ โดย $\mathcal L^{-1}\{1/(s^2+1)\} = \sin t$ ใช้ P8

$$\mathcal L^{-1} = \int_0^t \sin\tau\,d\tau = 1 - \cos t$$

$1 - \cos t,\ t \ge 0$

## คูณด้วย t และหารด้วย t (อนุพันธ์และปริพันธ์ในโดเมน s) กลาง

P9 Multiplication by t คูณด้วย t

$$\mathcal L\{t\,f(t)\} = -\frac{dF(s)}{ds}$$

พิสูจน์: $\frac{d}{ds}\int fe^{-st}dt = \int f\,(-t)e^{-st}dt$ · เป็นที่มาของพจน์ $t\,e^{pt}$ จากโพลซ้ำ

P10 Multiplication by tⁿ คูณด้วย tⁿ

$$\mathcal L\{t^nf(t)\} = (-1)^n\frac{d^nF(s)}{ds^n}$$

P11 Division by t หารด้วย t

$$\mathcal L\left\{\frac{f(t)}{t}\right\} = \int_s^\infty F(u)\,du,\quad \text{ถ้า } \lim_{t\to 0^+}f(t)/t \text{ มีค่า}$$

ตัวอย่าง P-9 · เรโซแนนซ์

### $\mathcal L\{t\sin\omega t\}$

-
$$-\frac{d}{ds}\frac{\omega}{s^2+\omega^2} = -\omega\cdot\frac{-2s}{(s^2+\omega^2)^2} = \frac{2\omega s}{(s^2+\omega^2)^2}$$

$\dfrac{2\omega s}{(s^2+\omega^2)^2}$ โพลซ้ำบนแกน jω ให้แอมพลิจูดโตเชิงเส้นตามเวลา คือเรโซแนนซ์เมื่อป้อนความถี่ตรงกับความถี่ธรรมชาติ

ตัวอย่าง P-10 · อินทิกรัลดิริชเลต์ด้วยลาปลาซ

### หา $\mathcal L\left\{\dfrac{\sin t}{t}\right\}$ แล้วสรุปค่า $\int_0^\infty\dfrac{\sin t}{t}dt$

-
$$\mathcal L\left\{\frac{\sin t}{t}\right\} = \int_s^\infty\frac{du}{u^2+1} = \frac{\pi}{2} - \tan^{-1}s = \tan^{-1}\frac{1}{s}$$

- อินทิกรัลที่ต้องการคือค่าของการแปลงที่ $s \to 0^+$

$$\int_0^\infty\frac{\sin t}{t}dt = \lim_{s\to0^+}\tan^{-1}\frac1s = \frac{\pi}{2}$$

$\pi/2$ — อินทิกรัลที่หาด้วยวิธีปกติไม่ได้ แต่ลาปลาซหาได้ในสองบรรทัด

## คอนโวลูชันและการคูณ (Convolution Theorem) กลาง

P12 Convolution คอนโวลูชัน → คูณ

$$\mathcal L\{(f*g)(t)\} = F(s)\,G(s),\qquad (f*g)(t) = \int_0^t f(\tau)\,g(t - \tau)\,d\tau$$

เอาต์พุตของระบบ LTI $y = h * x$ จึงหาได้จาก $Y(s) = H(s)X(s)$ เป็นเหตุผลที่ฟังก์ชันถ่ายโอนนิยามเป็นอัตราส่วน

P13 Multiplication การคูณในเวลา (คอนโวลูชันเชิงซ้อน)

$$\mathcal L\{f(t)g(t)\} = \frac{1}{2\pi j}\int_{c-j\infty}^{c+j\infty}F(p)\,G(s - p)\,dp$$

ใช้น้อยในงานวงจร พบในการมอดูเลชันและการวิเคราะห์สัญญาณสุ่ม

ตัวอย่าง P-11 · แปลงกลับด้วยคอนโวลูชัน

### $\mathcal L^{-1}\left\{\dfrac{1}{(s^2+1)^2}\right\}$

- เป็นผลคูณ $\dfrac{1}{s^2+1}\cdot\dfrac{1}{s^2+1}$ ซึ่งแต่ละตัวคือ $\sin t$

$$f(t) = \int_0^t\sin\tau\,\sin(t - \tau)\,d\tau$$

- ใช้ผลคูณเป็นผลบวก $\sin A\sin B = \tfrac12[\cos(A-B) - \cos(A+B)]$

$$= \frac12\int_0^t\left[\cos(2\tau - t) - \cos t\right]d\tau = \frac12\left[\frac{\sin(2\tau - t)}{2}\right]_0^t - \frac{t\cos t}{2} = \frac{\sin t}{2} - \frac{t\cos t}{2}$$

$f(t) = \tfrac12(\sin t - t\cos t)$ ตรงกับตารางแถว 20 บนหน้าภาพรวม

## ฟังก์ชันคาบ (Periodic Functions) กลาง

P14 Periodic function ฟังก์ชันคาบ $T$

$$\mathcal L\{f(t)\} = \frac{F_1(s)}{1 - e^{-sT}},\qquad F_1(s) = \int_0^T f(t)\,e^{-st}\,dt$$

พิสูจน์: $f = f_1(t) + f_1(t-T)u(t-T) + f_1(t-2T)u(t-2T) + \cdots$ ใช้ P2 ได้อนุกรมเรขาคณิต $F_1(1 + e^{-sT} + e^{-2sT} + \cdots)$ · ตัวส่วนมีรากที่ $s = j2\pi k/T$ คือฮาร์มอนิกของอนุกรมฟูเรียร์

ตัวอย่าง P-12 · คลื่นสี่เหลี่ยม PWM 50%

### $f = 1$ เมื่อ $0 < t < a$, $f = 0$ เมื่อ $a < t < 2a$ และซ้ำทุก $T = 2a$

-
$$F_1(s) = \int_0^a e^{-st}dt = \frac{1 - e^{-as}}{s}$$

-
$$F(s) = \frac{1 - e^{-as}}{s\left(1 - e^{-2as}\right)} = \frac{1 - e^{-as}}{s(1 - e^{-as})(1 + e^{-as})} = \frac{1}{s\left(1 + e^{-as}\right)}$$

$F(s) = \dfrac{1}{s(1 + e^{-as})}$ ใช้กับวงจรที่ป้อนด้วย PWM เช่นบั๊กคอนเวอร์เตอร์

ตัวอย่าง P-13 · เรกติไฟเออร์เต็มคลื่น

### $f(t) = |\sin t|$ คาบ $T = \pi$

- $F_1(s) = \int_0^\pi\sin t\,e^{-st}dt = \dfrac{1 + e^{-\pi s}}{s^2 + 1}$ (อินทิเกรตทีละส่วนสองครั้ง)

-
$$F(s) = \frac{1 + e^{-\pi s}}{(s^2+1)(1 - e^{-\pi s})} = \frac{1}{s^2+1}\coth\frac{\pi s}{2}$$

$\dfrac{\coth(\pi s/2)}{s^2+1}$ ฮาร์มอนิกของแรงดันเรกติไฟเออร์ดูต่อได้ในอนุกรมฟูเรียร์ของเรกติไฟเออร์

## ทฤษฎีบทค่าเริ่มต้นและค่าสุดท้าย กลาง

สองทฤษฎีบทนี้หาค่า $f(0^+)$ และ $f(\infty)$ โดยไม่ต้องแปลงกลับ ใช้ตรวจคำตอบและหาความผิดพลาดอยู่ตัวในระบบควบคุม แต่ทฤษฎีบทค่าสุดท้ายมีเงื่อนไขที่ต้องตรวจทุกครั้ง

P15 Initial value theorem ทฤษฎีบทค่าเริ่มต้น

$$f(0^+) = \lim_{s\to\infty}sF(s)$$

ใช้ได้เมื่อ $F(s)$ เป็นตรรกยะแท้อย่างเข้ม (ไม่มีอิมพัลส์ที่ t = 0) · หา $f'(0^+)$ ได้จาก $\lim_{s\to\infty}s[sF(s) - f(0^+)]$

P16 Final value theorem ทฤษฎีบทค่าสุดท้าย

$$f(\infty) = \lim_{s\to 0}sF(s)$$

ใช้ได้เฉพาะเมื่อโพลทุกตัวของ $sF(s)$ อยู่ครึ่งซ้าย (F มีโพลเดี่ยวที่ 0 ได้) ถ้ามีโพลบนแกน jω (นอกจาก 0) หรือครึ่งขวา $f(\infty)$ ไม่มี

P17 Conjugation สังยุค

$$\mathcal L\{\overline{f(t)}\} = \overline{F(\bar s)}$$

ผลที่ตามมา: $f$ จริง ⇒ $F(\bar s) = \overline{F(s)}$ โพลและเรซิดิวจึงมาเป็นคู่สังยุค

ตัวอย่าง P-14 · ใช้ได้

### $F(s) = \dfrac{s+2}{s(s+1)(s+4)}$ หา $f(0^+)$ และ $f(\infty)$

-
$$f(0^+) = \lim_{s\to\infty}\frac{s+2}{(s+1)(s+4)} = 0$$

- โพลของ $sF(s) = \dfrac{s+2}{(s+1)(s+4)}$ คือ −1, −4 อยู่ครึ่งซ้ายทั้งหมด ✓ ใช้ทฤษฎีบทได้

$$f(\infty) = \lim_{s\to 0}\frac{s+2}{(s+1)(s+4)} = \frac{2}{4} = \frac12$$

$f(0^+) = 0,\ f(\infty) = \tfrac12$ ตรงกับ $f(t) = \tfrac12 - \tfrac13e^{-t} - \tfrac16e^{-4t}$ ซึ่งที่ $t = 0$ ได้ $\tfrac12 - \tfrac13 - \tfrac16 = 0$ ✓

ตัวอย่าง P-15 · ใช้ไม่ได้ (กับดัก)

### ลองใช้ทฤษฎีบทค่าสุดท้ายกับ $F_1 = \dfrac{1}{s^2+4}$ และ $F_2 = \dfrac{1}{s-1}$

- $\lim_{s\to 0}sF_1 = 0$ แต่ $f_1 = \tfrac12\sin 2t$ แกว่งตลอด ไม่มีค่าสุดท้าย (โพล $\pm 2j$ บนแกน jω ✗)

- $\lim_{s\to 0}sF_2 = 0$ แต่ $f_2 = e^{t} \to \infty$ (โพล +1 ครึ่งขวา ✗)

สูตรให้ “0” ทั้งสองกรณีโดยไม่เตือนเลย ตรวจตำแหน่งโพลก่อนใช้ทุกครั้ง

## แล็บพิสูจน์คุณสมบัติด้วยตัวเลข

เลือกสัญญาณตั้งต้นและคุณสมบัติ แล็บจะคำนวณ $g(t)$ สองทาง: เส้นสีส้มคำนวณจากนิยามในโดเมนเวลา (เลื่อน คูณ อินทิเกรตเชิงตัวเลข หรือคอนโวลูชันเชิงตัวเลข) ส่วนจุดสีน้ำเงินมาจากการแปลงกลับ $G(s)$ ที่ได้จากสูตรคุณสมบัติด้วยเศษส่วนย่อย ถ้าสูตรถูก จุดต้องอยู่บนเส้นทุกจุด สังเกต G(s) ที่เปลี่ยนไปด้วย

## คำถามที่พบบ่อย

ℒ{t·u(t−2)} ใช้การเลื่อนเวลาได้เลยไหม?
ไม่ได้ทันที เพราะสมบัติการเลื่อนเวลาต้องการรูป $f(t-T)u(t-T)$ ต้องเขียน $t = (t-2) + 2$ ก่อน ได้ $\mathcal L\{t\,u(t-2)\} = e^{-2s}\left(\frac{1}{s^2} + \frac{2}{s}\right)$

ใช้ทฤษฎีบทค่าสุดท้ายได้เมื่อไร?
เมื่อ $sF(s)$ มีโพลทุกตัวอยู่ครึ่งซ้ายของระนาบ s เท่านั้น (อนุญาตให้ $F(s)$ มีโพลเดี่ยวที่ $s = 0$ ได้) ถ้ามีโพลบนแกน jω อื่นหรือครึ่งขวา $f(t)$ ไม่มีค่าสุดท้าย และสูตรจะให้คำตอบที่ผิดโดยไม่เตือน

ทำไมสมบัติอนุพันธ์ใช้ f(0⁻) ไม่ใช่ f(0⁺)?
เพราะนิยามด้วยขอบล่าง $0^-$ รวมอิมพัลส์ที่ $t = 0$ ไว้ด้วย และ $f(0^-)$ คือสภาวะก่อนสวิตช์ทำงาน ซึ่งเป็นค่าที่วิศวกรรู้จริง (เช่นแรงดันตัวเก็บประจุก่อนปิดสวิตช์) ถ้าสัญญาณต่อเนื่องที่ t = 0 สองค่านี้เท่ากัน

คอนโวลูชันในโดเมนเวลาเป็นการคูณในโดเมน s ใช้ทำอะไร?
ใช้หาเอาต์พุตของระบบ $Y(s) = H(s)X(s)$ โดยไม่ต้องอินทิเกรตคอนโวลูชัน และใช้แปลงกลับผลคูณของสองฟังก์ชันที่รู้ตัวผกผันแต่ละตัว เช่น $\mathcal L^{-1}\{1/(s^2+1)^2\} = \sin t * \sin t$
