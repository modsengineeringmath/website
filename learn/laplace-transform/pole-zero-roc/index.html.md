# แผนภาพโพล-ซีโร่และบริเวณลู่เข้า (ROC) ของการแปลงลาปลาซ

// บทที่ 8.2 · การแปลงลาปลาซ · Poles, Zeros & ROC


$X(s)$ บอกว่าน้ำหนักของ $e^{st}$ แต่ละตัวเป็นเท่าไร แต่บอกไม่ครบ ต้องมี ROC บอกว่าอินทิกรัลลู่เข้าที่ไหน หน้านี้พาหาโพล ซีโร่ และ ROC ทีละขั้นจากนิยาม สรุปสมบัติ 8 ข้อที่ใช้หา ROC โดยไม่ต้องอินทิเกรต และอ่านเสถียรภาพกับรูปคลื่นจากตำแหน่งโพลได้ในพริบตา สูตรใช้รหัส R

สรุปใน 30 วินาที

- โพล = รากของตัวส่วน (× บนระนาบ) ซีโร่ = รากของตัวเศษ (○) อันดับ = จำนวนซ้ำ

- ROC เป็นแถบแนวตั้งเสมอ ไม่มีโพลข้างใน ขอบเขตผ่านโพล

- ด้านขวา → ขวาของโพลขวาสุด · ด้านซ้าย → ซ้ายของโพลซ้ายสุด · สองด้าน → แถบระหว่างโพล

- ROC ครอบแกน jω ⇔ เสถียร · เหตุผล + เสถียร ⇔ โพลทุกตัวอยู่ครึ่งซ้าย

ระดับพื้นฐาน ปี 2กลาง ป.ตรี วิศวกรรมขั้นสูง สัญญาณและระบบ · ป.โท

## โพลและซีโร่คืออะไร พื้นฐาน

ฟังก์ชันตรรกยะใด ๆ แยกตัวประกอบได้เป็นผลคูณของ $(s - z_i)$ บนเศษและ $(s - p_k)$ บนส่วน รู้ตำแหน่งราก + ค่าคงที่หนึ่งตัวก็รู้ฟังก์ชันทั้งหมด แผนภาพโพล-ซีโร่จึงเป็น “ลายมือชื่อ” ของระบบ

R1 Pole–zero–gain form รูปโพล-ซีโร่-เกน

$$X(s) = \frac{N(s)}{D(s)} = K\,\frac{(s - z_1)(s - z_2)\cdots(s - z_m)}{(s - p_1)(s - p_2)\cdots(s - p_n)}$$

ซีโร่ $z_i$: $X(z_i) = 0$ · โพล $p_k$: $|X(s)| \to \infty$ · $K$ = อัตราส่วนสัมประสิทธิ์นำหน้า · ซีโร่ที่ $s = 0$ หรือโพลที่ $s = 0$ มักพิมพ์ว่า $s$ เฉย ๆ

R2 Proper / improper เศษส่วนแท้และไม่แท้

$$m < n:\ \text{แท้อย่างเข้ม},\quad m = n:\ \text{แท้},\quad m > n:\ \text{ไม่แท้}$$

ระบบกายภาพเกือบทั้งหมดเป็นแท้ $m \le n$ ส่วนไม่แท้มีอิมพัลส์และอนุพันธ์ของอิมพัลส์ในคำตอบ

R3 Conjugate symmetry สมมาตรสังยุค

$$\text{สัมประสิทธิ์จริง} \Rightarrow p \text{ เป็นโพล} \iff \bar p \text{ เป็นโพล}$$

แผนภาพโพล-ซีโร่ของระบบจริงจึงสมมาตรกับแกนจริงเสมอ

ตัวอย่าง R-1 · วาดแผนภาพโพล-ซีโร่

### $H(s) = \dfrac{2s + 6}{s^3 + 5s^2 + 12s + 8}$

- เศษ: $2s + 6 = 2(s + 3)$ ซีโร่ $s = -3$ และ $K = 2$

- ส่วน: ลองรากตรรกยะ $s = -1$: $-1 + 5 - 12 + 8 = 0$ ✓ หารสังเคราะห์ได้ $s^2 + 4s + 8$

$$s^2 + 4s + 8 = 0 \Rightarrow s = \frac{-4 \pm \sqrt{16 - 32}}{2} = -2 \pm 2j$$

-
$$H(s) = \frac{2(s+3)}{(s+1)(s+2-2j)(s+2+2j)}$$

ซีโร่ ○ ที่ $-3$ · โพล × ที่ $-1$ และ $-2 \pm 2j$ ทุกโพลอยู่ครึ่งซ้าย ระบบเหตุผลนี้เสถียร

## ROC คืออะไร: หาจากนิยามทีละขั้น พื้นฐาน

อินทิกรัล $\int x(t)e^{-st}dt$ ลู่เข้าหรือไม่ขึ้นกับ $|x(t)e^{-st}| = |x(t)|e^{-\sigma t}$ เท่านั้น ส่วน $\omega$ ไม่มีผลเลย ROC จึงขึ้นกับ $\sigma = \operatorname{Re}s$ อย่างเดียว และเป็นแถบแนวตั้งเสมอ

R4 Region of convergence บริเวณลู่เข้า

$$\text{ROC} = \left\{ s : \int_{-\infty}^{\infty}|x(t)|\,e^{-\sigma t}\,dt < \infty \right\},\quad \sigma = \operatorname{Re}s$$

R5 Right-sided exponential เอกซ์โพเนนเชียลด้านขวา

$$e^{-at}u(t)\ \longleftrightarrow\ \frac{1}{s+a},\quad \operatorname{Re}s > -a$$

R6 Left-sided exponential เอกซ์โพเนนเชียลด้านซ้าย

$$-e^{-at}u(-t)\ \longleftrightarrow\ \frac{1}{s+a},\quad \operatorname{Re}s < -a$$

ตัวอย่าง R-2 · สัญญาณด้านซ้าย

### หาการแปลงสองด้านและ ROC ของ $x(t) = -e^{-at}u(-t)$

- สัญญาณมีค่าเฉพาะ $t < 0$

$$X(s) = \int_{-\infty}^{0}-e^{-at}e^{-st}\,dt = -\int_{-\infty}^{0}e^{-(s+a)t}\,dt$$

- เมื่อ $t \to -\infty$ พจน์ $e^{-(s+a)t} = e^{-(\sigma + a)t}e^{-j\omega t}$ ต้องหายไป ซึ่งเกิดเมื่อ $\sigma + a < 0$

$$X(s) = -\left[\frac{-e^{-(s+a)t}}{s+a}\right]_{-\infty}^{0} = -\left(\frac{-1}{s+a} - 0\right) = \frac{1}{s+a}$$

$X(s) = \dfrac{1}{s+a}$ เหมือนของ $e^{-at}u(t)$ ทุกตัวอักษร แต่ ROC เป็น $\operatorname{Re}s < -a$ (ครึ่งซ้าย) แทน $\operatorname{Re}s > -a$

โพลเดียวกันที่ $s = -a$ ROC ทางขวาให้สัญญาณด้านขวา $e^{-at}u(t)$ ROC ทางซ้ายให้สัญญาณด้านซ้าย $-e^{-at}u(-t)$ — X(s) ตัวเดียวไม่พอ ต้องบอก ROC เสมอ

## สมบัติของ ROC ทั้ง 8 ข้อ กลาง

แปดข้อนี้ทำให้หา ROC ได้โดยไม่ต้องอินทิเกรตเลย แค่รู้ตำแหน่งโพลและรู้ว่าสัญญาณอยู่ด้านไหนของเวลา (เรียงตาม Oppenheim & Willsky)

R7 Property 1 เป็นแถบขนานกับแกน jω

$$\text{ROC} = \{ s : \sigma_1 < \operatorname{Re}s < \sigma_2 \}$$

ขอบอาจเป็น $-\infty$ หรือ $+\infty$ ก็ได้ เพราะการลู่เข้าขึ้นกับ σ เท่านั้น

R8 Property 2 ไม่มีโพลอยู่ใน ROC

$$p \text{ เป็นโพล} \Rightarrow p \notin \text{ROC}$$

ที่โพล $X(s)$ เป็นอนันต์ อินทิกรัลจึงลู่เข้าไม่ได้

R9 Property 3 สัญญาณช่วงจำกัด → ทั้งระนาบ

$$x(t) = 0 \text{ นอก } [T_1, T_2] \text{ และอินทิเกรตได้สัมบูรณ์} \Rightarrow \text{ROC} = \mathbb{C}$$

R10 Property 4 ด้านขวา → ครึ่งระนาบขวา

$$x(t) = 0,\ t < T_1:\ \sigma_0 \in \text{ROC} \Rightarrow \{\operatorname{Re}s > \sigma_0\} \subset \text{ROC}$$

R11 Property 5 ด้านซ้าย → ครึ่งระนาบซ้าย

$$x(t) = 0,\ t > T_2:\ \sigma_0 \in \text{ROC} \Rightarrow \{\operatorname{Re}s < \sigma_0\} \subset \text{ROC}$$

R12 Property 6 สองด้าน → แถบ (หรือว่างเปล่า)

$$\text{ROC} = \text{ROC}_{\text{ขวา}} \cap \text{ROC}_{\text{ซ้าย}}$$

ถ้าส่วนขวาต้องการ $\sigma > \sigma_a$ แต่ส่วนซ้ายต้องการ $\sigma < \sigma_b$ ที่ $\sigma_b \le \sigma_a$ ROC ว่าง: ไม่มีการแปลงลาปลาซ

R13 Property 7 ตรรกยะ + ด้านขวา

$$\text{ROC} = \{\operatorname{Re}s > \operatorname{Re}p_{\text{ขวาสุด}}\}$$

การแปลงด้านเดียวทั้งหมดอยู่ในกรณีนี้

R14 Property 8 ตรรกยะ + ด้านซ้าย

$$\text{ROC} = \{\operatorname{Re}s < \operatorname{Re}p_{\text{ซ้ายสุด}}\}$$

$X(s) = \dfrac{1}{(s+1)(s+2)}$ มี ROC ได้สามแบบ: ขวาของ −1 (ด้านขวา) แถบระหว่าง −2 กับ −1 (สองด้าน) และซ้ายของ −2 (ด้านซ้าย) ไม่มีแบบอื่นเพราะ ROC ห้ามมีโพลข้างใน

ตัวอย่าง R-3 · X(s) เดียว ROC สามแบบ สัญญาณสามตัว

### หา $x(t)$ ของ $X(s) = \dfrac{1}{(s+1)(s+2)}$ สำหรับทั้งสาม ROC

- เศษส่วนย่อย (ไม่ขึ้นกับ ROC): $X(s) = \dfrac{1}{s+1} - \dfrac{1}{s+2}$

- กฎ: โพลที่อยู่ซ้ายของ ROC ให้พจน์ด้านขวา $e^{pt}u(t)$ R5 · โพลที่อยู่ขวาของ ROC ให้พจน์ด้านซ้าย $-e^{pt}u(-t)$ R6

- (ก) $\operatorname{Re}s > -1$: ทั้งสองโพลอยู่ซ้าย

$$x(t) = \left(e^{-t} - e^{-2t}\right)u(t)$$

- (ข) $-2 < \operatorname{Re}s < -1$: โพล −1 อยู่ขวา โพล −2 อยู่ซ้าย

$$x(t) = -e^{-t}u(-t) - e^{-2t}u(t)$$

- (ค) $\operatorname{Re}s < -2$: ทั้งสองโพลอยู่ขวา

$$x(t) = \left(-e^{-t} + e^{-2t}\right)u(-t)$$

สามสัญญาณต่างกันโดยสิ้นเชิง มีเพียง (ก) ที่เป็นเหตุผล และมีเพียง (ก) ที่เสถียร (ROC ครอบ $\sigma = 0$) · ลองเลือก ROC ทั้งสามแบบในแล็บด้านล่างด้วยปุ่ม “สัญญาณสองด้าน”

## สัญญาณสองด้านและสัญญาณช่วงจำกัด กลาง

ตัวอย่าง R-4 · ผลรวมด้านขวา + ด้านซ้าย

### $x(t) = e^{-2t}u(t) + e^{3t}u(-t)$

- ส่วนขวา: $e^{-2t}u(t) \to \dfrac{1}{s+2}$, $\operatorname{Re}s > -2$

- ส่วนซ้าย: $e^{3t}u(-t) = -\left(-e^{3t}u(-t)\right) \to -\dfrac{1}{s-3}$, $\operatorname{Re}s < 3$ R6 ด้วย $a = -3$

- รวมและหาส่วนร่วมของ ROC R12

$$X(s) = \frac{1}{s+2} - \frac{1}{s-3} = \frac{-5}{(s+2)(s-3)},\quad -2 < \operatorname{Re}s < 3$$

ROC เป็นแถบ $-2 < \sigma < 3$ ซึ่งครอบแกน jω จึงมีการแปลงฟูเรียร์ $X(j\omega) = \dfrac{-5}{(j\omega+2)(j\omega-3)}$ แม้จะมีโพลครึ่งขวา (เพราะส่วนที่โตขึ้นอยู่ฝั่ง $t < 0$ ซึ่งลดลงเมื่อย้อนเวลา)

ตัวอย่าง R-5 · เอกซ์โพเนนเชียลสองด้านสมมาตร

### $x(t) = e^{-b|t|},\ b > 0$

-
$$x(t) = e^{-bt}u(t) + e^{bt}u(-t) \ \to\ \frac{1}{s+b} - \frac{1}{s-b}$$

-
$$X(s) = \frac{(s - b) - (s + b)}{s^2 - b^2} = \frac{-2b}{s^2 - b^2},\quad -b < \operatorname{Re}s < b$$

โพลที่ $\pm b$ ROC เป็นแถบระหว่างโพลทั้งสอง ถ้า $b \le 0$ ส่วนขวาต้องการ $\sigma > b$ ส่วนซ้ายต้องการ $\sigma < -b$ ไม่มีส่วนร่วม จึงไม่มีการแปลงลาปลาซ

ตัวอย่าง R-6 · ช่วงจำกัด: ภาวะเอกฐานที่ถอดได้

### พัลส์สี่เหลี่ยม $x(t) = u(t) - u(t - T)$

-
$$X(s) = \int_0^T e^{-st}dt = \frac{1 - e^{-sT}}{s}$$

- ดูเหมือนมีโพลที่ $s = 0$ แต่ $\lim_{s\to 0}\dfrac{1 - e^{-sT}}{s} = T$ (โลปิตาล) จึงเป็นภาวะเอกฐานที่ถอดได้ ไม่ใช่โพล Z19

ROC คือทั้งระนาบ s ตามสมบัติ 3 R9 ซีโร่อยู่ที่ $s = j2\pi k/T,\ k \ne 0$ บนแกน jω ซึ่งคือศูนย์ของฟังก์ชัน sinc ในสเปกตรัมนั่นเอง

## ตารางคู่การแปลงสองด้านพร้อม ROC กลาง

| สัญญาณ $x(t)$ | $X(s)$ | ROC |

| $\delta(t)$ | $1$ | ทุก $s$ |

| $\delta(t - T)$ | $e^{-sT}$ | ทุก $s$ |

| $u(t)$ | $\dfrac{1}{s}$ | $\operatorname{Re}s > 0$ |

| $-u(-t)$ | $\dfrac{1}{s}$ | $\operatorname{Re}s < 0$ |

| $\dfrac{t^{n-1}}{(n-1)!}u(t)$ | $\dfrac{1}{s^n}$ | $\operatorname{Re}s > 0$ |

| $-\dfrac{t^{n-1}}{(n-1)!}u(-t)$ | $\dfrac{1}{s^n}$ | $\operatorname{Re}s < 0$ |

| $e^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\operatorname{Re}s > -a$ |

| $-e^{-at}u(-t)$ | $\dfrac{1}{s+a}$ | $\operatorname{Re}s < -a$ |

| $\dfrac{t^{n-1}}{(n-1)!}e^{-at}u(t)$ | $\dfrac{1}{(s+a)^n}$ | $\operatorname{Re}s > -a$ |

| $-\dfrac{t^{n-1}}{(n-1)!}e^{-at}u(-t)$ | $\dfrac{1}{(s+a)^n}$ | $\operatorname{Re}s < -a$ |

| $\cos(\omega_0t)\,u(t)$ | $\dfrac{s}{s^2+\omega_0^2}$ | $\operatorname{Re}s > 0$ |

| $\sin(\omega_0t)\,u(t)$ | $\dfrac{\omega_0}{s^2+\omega_0^2}$ | $\operatorname{Re}s > 0$ |

| $e^{-at}\cos(\omega_0t)\,u(t)$ | $\dfrac{s+a}{(s+a)^2+\omega_0^2}$ | $\operatorname{Re}s > -a$ |

| $e^{-at}\sin(\omega_0t)\,u(t)$ | $\dfrac{\omega_0}{(s+a)^2+\omega_0^2}$ | $\operatorname{Re}s > -a$ |

| $e^{-a|t|},\ a > 0$ | $\dfrac{-2a}{s^2 - a^2}$ | $-a < \operatorname{Re}s < a$ |

| $u(t) - u(t - T)$ | $\dfrac{1 - e^{-sT}}{s}$ | ทุก $s$ |

ทุกคู่ที่มี $-(\dots)u(-t)$ คือฝาแฝดด้านซ้ายของคู่ด้านขวาบรรทัดบน: X(s) เหมือนกัน ROC อยู่คนละฝั่งของโพล

## ตำแหน่งโพลบอกรูปคลื่น พื้นฐาน

แต่ละโพล $p$ ของระบบเหตุผลให้พจน์ $e^{pt}$ ในผลตอบสนองอิมพัลส์ (คู่เชิงซ้อนรวมกันเป็น $e^{\sigma t}\cos(\omega t + \phi)$) การอ่านแผนภาพโพลจึงคือการอ่านรูปคลื่นโดยไม่ต้องแปลงกลับ

ตำแหน่งโพล (ซ้าย) กับผลตอบสนองอิมพัลส์ (ขวา) ระยะจากแกน jω (|σ|) บอกความเร็วในการลดลง ระยะจากแกนจริง (ω) บอกความถี่ของการแกว่ง โพลที่อยู่ใกล้แกน jω ที่สุดเรียกว่าโพลเด่น (dominant pole) เพราะลดลงช้าที่สุดจึงกำหนดรูปร่างหลัก

R15 Reading a pole pair อ่านคู่โพล $-\sigma \pm j\omega_d$

$$\tau = \frac{1}{\sigma},\quad \omega_n = |p| = \sqrt{\sigma^2 + \omega_d^2},\quad \zeta = \cos\theta = \frac{\sigma}{\omega_n}$$

$\theta$ คือมุมระหว่างเส้นจากจุดกำเนิดไปยังโพลกับแกนจริงลบ เส้นมุมคงที่ = ζ คงที่ (%OS คงที่) วงกลมรัศมีคงที่ = ωn คงที่

R16 What zeros do ซีโร่ทำอะไร

$$\text{เรซิดิวที่โพล } p_k = K\frac{\prod_i (p_k - z_i)}{\prod_{j\ne k}(p_k - p_j)}$$

ซีโร่ไม่สร้างพจน์ใหม่ แต่เปลี่ยน “น้ำหนัก” ของแต่ละโพล ซีโร่ใกล้โพลไหนจะลดพจน์นั้นลง ซีโร่ครึ่งขวาทำให้ผลตอบสนองขั้นบันไดวิ่งสวนทางก่อน (undershoot)

ตัวอย่าง R-7 · อ่านแผนภาพโพล

### ระบบมีโพลที่ $-2 \pm 4j$ และ $-10$ ประมาณรูปผลตอบสนองโดยไม่แปลงกลับ

- โพลเด่นคือ $-2 \pm 4j$ (ใกล้แกน jω กว่า) โพล $-10$ ลดลงเร็วกว่า 5 เท่า ($\tau = 0.1$ s เทียบกับ 0.5 s) แทบไม่มีผลหลังผ่านไปไม่กี่ร้อยมิลลิวินาที

- จาก R15: $\omega_n = \sqrt{4 + 16} = \sqrt{20} \approx 4.47$ rad/s, $\zeta = 2/4.47 \approx 0.447$

- แกว่งที่ $\omega_d = 4$ rad/s (คาบ $\approx 1.57$ s) พุ่งเกิน $\%OS = 100e^{-\zeta\pi/\sqrt{1-\zeta^2}} \approx 100e^{-\pi/2} \approx 20.8\%$ เข้าที่ใน $t_s \approx 4/\sigma = 2$ s

ประมาณได้เป็นระบบอันดับสองที่ $\zeta \approx 0.45$, $\omega_n \approx 4.5$ rad/s พุ่งเกินราว 21% เข้าที่ราว 2 วินาที ดูวิธีเลือกตำแหน่งโพลให้ได้สเปกที่ต้องการในผลตอบสนองทางเวลา

## ROC กับเสถียรภาพ ความเป็นเหตุเป็นผล และการแปลงฟูเรียร์ ขั้นสูง

R17 Causality ความเป็นเหตุเป็นผล

$$h(t) = 0,\ t < 0 \iff \text{ROC ของ } H(s) \text{ เป็นครึ่งระนาบขวา}$$

สำหรับ H(s) ตรรกยะ: ROC อยู่ขวาของโพลขวาสุด

R18 BIBO stability เสถียรภาพ

$$\int_{-\infty}^{\infty}|h(t)|\,dt < \infty \iff j\omega\text{-axis} \subset \text{ROC}$$

R19 Causal and stable ทั้งเหตุผลและเสถียร

$$\operatorname{Re}p_k < 0 \ \text{ทุกโพล}$$

กฎ “โพลครึ่งซ้าย = เสถียร” ในวิชาควบคุมเป็นจริงเพราะระบบจริงเป็นเหตุผลเสมอ

R20 Fourier transform การแปลงฟูเรียร์จากลาปลาซ

$$X(j\omega) = X(s)\big|_{s = j\omega}\quad \text{เมื่อ ROC ครอบแกน } j\omega$$

ตัวอย่าง R-8 · ระบบเดียว สามสมมติฐาน

### $H(s) = \dfrac{s - 1}{(s+1)(s-2)}$ จงหา ROC ถ้า (ก) ระบบเหตุผล (ข) ระบบเสถียร (ค) ทั้งสองอย่างได้ไหม

- โพล $-1$ และ $2$ ROC ที่เป็นไปได้: $\sigma < -1$, $-1 < \sigma < 2$, $\sigma > 2$

- (ก) เหตุผล → ขวาของโพลขวาสุด: $\operatorname{Re}s > 2$ (ไม่ครอบแกน jω → ไม่เสถียร)

- (ข) เสถียร → ต้องครอบ $\sigma = 0$: $-1 < \operatorname{Re}s < 2$ (สองด้าน → ไม่เหตุผล)

- (ค) ต้องเป็นครึ่งระนาบขวาและครอบแกน jω พร้อมกัน แต่โพล $s = 2$ ขวางอยู่

เป็นไปไม่ได้ที่จะทั้งเหตุผลและเสถียร เพราะมีโพลครึ่งขวา ส่วนซีโร่ที่ $s = 1$ (ครึ่งขวา) ไม่มีผลต่อเสถียรภาพ แต่ทำให้เป็นระบบ non-minimum phase

## ROC เปลี่ยนอย่างไรเมื่อใช้คุณสมบัติ ขั้นสูง

| การดำเนินการ | X(s) ใหม่ | ROC ใหม่ (R = ROC เดิม) |

| $ax_1 + bx_2$ | $aX_1 + bX_2$ | อย่างน้อย $R_1 \cap R_2$ (กว้างขึ้นได้ถ้าโพลตัดกับซีโร่) |

| $x(t - T)$ | $e^{-sT}X(s)$ | $R$ เท่าเดิม |

| $e^{s_0t}x(t)$ | $X(s - s_0)$ | $R + \operatorname{Re}s_0$ (เลื่อนทั้งแถบ) |

| $x(at)$ | $\tfrac{1}{|a|}X(s/a)$ | $aR$ (ถ้า $a < 0$ แถบกลับข้าง) |

| $x(-t)$ | $X(-s)$ | $-R$ (สะท้อนข้ามแกน jω) |

| $dx/dt$ | $sX(s)$ | อย่างน้อย $R$ |

| $\int_{-\infty}^t x\,d\tau$ | $X(s)/s$ | อย่างน้อย $R \cap \{\operatorname{Re}s > 0\}$ |

| $x_1 * x_2$ | $X_1X_2$ | อย่างน้อย $R_1 \cap R_2$ |

รายละเอียดและพิสูจน์ของทุกคุณสมบัติอยู่ในหน้า 8.3

## แล็บโพล-ซีโร่-ROC: ลากแล้วดูสัญญาณเปลี่ยน

แล็บนี้ใช้การแปลงสองด้าน เลือก ROC ได้ทุกแถบที่เป็นไปได้ แล้วดูว่าสัญญาณ $x(t)$ เปลี่ยนเป็นด้านขวา ด้านซ้าย หรือสองด้าน พร้อมป้ายบอกความเป็นเหตุเป็นผลและเสถียรภาพ ถ้า ROC ครอบแกน jω จะแสดง $|X(j\omega)|$ ให้ด้วย

ลองสิ่งเหล่านี้: (1) ลากโพลจริงข้ามแกน jω แล้วดูป้ายเสถียรภาพ (2) กด “สัญญาณสองด้าน” แล้วเลือก ROC แต่ละแถบ (3) เพิ่มคู่โพลเชิงซ้อนแล้วลากเข้าใกล้แกน jω ดูยอดของ |X(jω)| สูงขึ้นและการแกว่งช้าลงที่จะหาย (4) วางซีโร่ทับบนโพลเกือบพอดี ดูพจน์นั้นหายไปจากสัญญาณ
