ลอการิทึมตอบคำถามเดียวคือ “ต้องยกกำลังเท่าไร” เช่น $\log_2 8 = 3$ เพราะต้องยก 2 กำลัง 3 จึงได้ 8 เมื่อมองแบบนี้ สมบัติของลอการิทึมทุกข้อก็คือกฎเลขยกกำลังที่เขียนกลับด้าน และกราฟของลอการิทึมก็คือกราฟเอกซ์โพเนนเชียลที่สะท้อนในเส้น $y = x$ หน้านี้ใช้ความเข้าใจนั้นอธิบายสมบัติ การเปลี่ยนฐาน การแก้สมการที่ตัวแปรอยู่บนเลขชี้กำลัง การตรวจคำตอบเกิน และสเกลที่ใช้วัดเสียง ความเป็นกรด และขนาดแผ่นดินไหว

สรุปใน 30 วินาที

- $\log_b x = y \iff b^y = x$ · ต้องมี $b > 0,\ b \ne 1,\ x > 0$

- $\log(MN) = \log M + \log N$ · $\log\tfrac MN = \log M - \log N$ · $\log M^p = p\log M$

- เปลี่ยนฐาน $\log_b x = \dfrac{\ln x}{\ln b} = \dfrac{\log x}{\log b}$

- แก้สมการแล้วต้องตรวจว่าทุก log ในโจทย์เดิมยังนิยาม

- อสมการ: ฐาน > 1 ทิศเดิม · ฐานระหว่าง 0 กับ 1 กลับทิศ

## นิยามและกราฟของลอการิทึม

เพราะ $b^x$ เป็นฟังก์ชันหนึ่งต่อหนึ่ง จึงมีตัวผกผัน และตัวผกผันนั้นคือ $\log_b x$ ทุกสมบัติของกราฟจึงได้จากการสลับ x กับ y ของเอกซ์โพเนนเชียล: โดเมนกลายเป็น $(0, \infty)$ เรนจ์กลายเป็นจำนวนจริงทั้งหมด จุด (0, 1) กลายเป็น (1, 0) และเส้นกำกับแนวนอน $y = 0$ กลายเป็นเส้นกำกับแนวดิ่ง $x = 0$ กราฟของลอการิทึมโตช้ามาก แม้ x จะเพิ่มเป็นล้าน $\log_{10} x$ ก็มีค่าแค่ 6 ซึ่งเป็นเหตุผลที่ใช้มันทำสเกลวัดปริมาณที่มีช่วงกว้าง

L1 Definition นิยามลอการิทึม

$$\log_b x = y \iff b^y = x,\qquad b > 0,\ b \ne 1,\ x > 0$$

$\log x = \log_{10} x$ · $\ln x = \log_e x$ · $\log_2$ ใช้ในวิทยาการคอมพิวเตอร์

L2 Basic values ค่าพื้นฐาน

$$\log_b 1 = 0,\quad \log_b b = 1,\quad \log_b b^x = x,\quad b^{\log_b x} = x$$

L3 Graph กราฟ

$$y = \log_b x:\ D = (0, \infty),\ R = \mathbb R,\ \text{VA } x = 0,\ (1, 0),\ (b, 1)$$

## สมบัติของลอการิทึม (Laws of Logarithms)

สมบัติทั้งสามข้อแปลกฎเลขยกกำลังมาใช้กับ log: การคูณเลขที่ฐานเดียวกันคือการบวกเลขชี้กำลัง log ของผลคูณจึงเท่ากับผลบวกของ log ในยุคก่อนเครื่องคิดเลข วิศวกรใช้สมบัตินี้คูณเลขยาว ๆ ด้วยการบวก log จากตาราง ส่วนสูตรเปลี่ยนฐานทำให้คำนวณ log ฐานใดก็ได้ด้วยปุ่ม log หรือ ln บนเครื่องคิดเลข

L4 Laws สมบัติผลคูณ ผลหาร และกำลัง

$$\log_b(MN) = \log_b M + \log_b N,\quad \log_b\tfrac{M}{N} = \log_b M - \log_b N,\quad \log_b M^p = p\log_b M$$

L5 Change of base การเปลี่ยนฐาน

$$\log_b x = \frac{\log_a x}{\log_a b} = \frac{\ln x}{\ln b}$$

L6 Useful identities สูตรลัด

$$\log_b a \cdot \log_a b = 1,\qquad \log_{b^n} a^m = \frac{m}{n}\log_b a,\qquad a^{\log_b c} = c^{\log_b a}$$

## สมการเอกซ์โพเนนเชียลและสมการลอการิทึม

สมการที่ x อยู่บนเลขชี้กำลังแก้ได้ด้วยการใส่ log ทั้งสองข้างแล้วใช้สมบัติกำลังดึง x ลงมา ส่วนสมการที่ x อยู่ใน log ให้รวม log ให้เหลือตัวเดียวแล้วแปลงเป็นเลขยกกำลังตามนิยาม ทุกครั้งที่รวม log ต้องกลับไปตรวจในโจทย์เดิมว่าค่าที่ได้ทำให้ทุก log นิยาม เพราะการรวมทำให้โดเมนกว้างขึ้นโดยไม่รู้ตัว

L7 Solving with logs ใส่ log ทั้งสองข้าง

$$A\,b^{kx} = C \ \Rightarrow\ x = \frac{\ln(C/A)}{k\ln b},\qquad \frac{C}{A} > 0$$

L8 Log equations สมการลอการิทึม

$$\log_b u = \log_b v \iff u = v\ \ (u, v > 0),\qquad \log_b u = c \iff u = b^c$$

ตัวอย่าง L-3 · ตัดคำตอบเกิน

### แก้ $\log_2 x + \log_2(x - 2) = 3$

- รวม: $\log_2\big(x(x - 2)\big) = 3 \Rightarrow x^2 - 2x = 8$

- $(x - 4)(x + 2) = 0 \Rightarrow x = 4$ หรือ $-2$ · ตัด −2 เพราะอยู่นอกโดเมน

$x = 4$ (ตรวจ: $\log_2 4 + \log_2 2 = 2 + 1 = 3$)

## สเกลลอการิทึม: pH เดซิเบล และริกเตอร์

## คำถามที่พบบ่อย

log ฐาน 10 กับ ln ต่างกันอย่างไร?
log x (ไม่เขียนฐาน) ในหนังสือ ม.ปลายและเครื่องคิดเลขหมายถึงฐาน 10 ส่วน ln x คือลอการิทึมฐาน e ≈ 2.718 ซึ่งใช้ในแคลคูลัสเพราะอนุพันธ์ของ ln x คือ 1/x พอดี ทั้งสองแปลงไปมาด้วยการเปลี่ยนฐาน ln x = log x / log e ≈ 2.3026 log x

ทำไมต้องตรวจคำตอบของสมการลอการิทึม?
เพราะการรวม log หลายตัวเป็นตัวเดียวทำให้โดเมนกว้างขึ้น เช่น log₂x + log₂(x − 2) = 3 กลายเป็น x(x − 2) = 8 ได้ x = 4 และ x = −2 แต่ x = −2 ทำให้ log₂x ไม่นิยาม จึงต้องตัดทิ้ง คำตอบที่ได้จากการคำนวณแต่ไม่อยู่ในโดเมนเรียกว่าคำตอบเกิน

log(a + b) เท่ากับ log a + log b หรือไม่?
ไม่เท่า สมบัติที่ถูกต้องคือ log(ab) = log a + log b ผลคูณกลายเป็นผลบวก ส่วน log(a + b) ไม่มีสูตรแยก ตัวอย่าง log(1 + 1) = log 2 ≈ 0.301 แต่ log 1 + log 1 = 0

สเกลลอการิทึมใช้ทำไม?
ใช้กับปริมาณที่มีช่วงกว้างมาก เช่นความเข้มเสียงที่ต่างกันเป็นล้านล้านเท่า ความเป็นกรดที่ความเข้มข้นไฮโดรเจนไอออนต่างกันหลายสิบเท่าตัว การใช้ log ทำให้ตัวเลขอยู่ในช่วงที่อ่านง่าย และการคูณกลายเป็นการบวก เช่นกำลังเพิ่ม 10 เท่าคือเพิ่ม 10 dB
