    กับดักที่พบบ่อยลืมใส่ 0 แทนดีกรีที่ขาดในการหารสังเคราะห์ เช่น x3−8x^3 - 8x3−8 ต้องเขียน 1, 0, 0, −8 ไม่ใช่ 1, −8 และหารด้วย x+2x + 2x+2 แต่ใช้ c = 2 ซึ่งต้องเป็น c = −2

    คำถามที่พบบ่อย

    ดูพฤติกรรมปลายกราฟของพหุนามอย่างไร?

    ดูแค่พจน์ดีกรีสูงสุด ถ้าดีกรีคู่ ปลายทั้งสองข้างไปทางเดียวกัน (ขึ้นทั้งคู่เมื่อสัมประสิทธิ์นำเป็นบวก ลงทั้งคู่เมื่อเป็นลบ) ถ้าดีกรีคี่ ปลายไปคนละทาง สัมประสิทธิ์นำบวกจะเริ่มล่างซ้ายจบบนขวา ลบจะกลับกัน

    รากซ้ำทำให้กราฟต่างจากรากเดี่ยวอย่างไร?

    รากที่มีภาวะซ้ำเป็นเลขคี่ กราฟตัดผ่านแกน x เพราะเครื่องหมายเปลี่ยน ถ้าซ้ำ 3 ครั้งขึ้นไปจะตัดแบบแบนราบ ส่วนรากที่ซ้ำเป็นเลขคู่ กราฟแค่แตะแกน x แล้ววกกลับเพราะเครื่องหมายไม่เปลี่ยน ตัวอย่าง (x − 1)² แตะแกนที่ x = 1

    การหารสังเคราะห์ใช้เมื่อใด?

    ใช้เมื่อหารพหุนามด้วยตัวหารเชิงเส้น x − c เพราะเร็วกว่าการหารยาวมาก แถวสุดท้ายให้ทั้งสัมประสิทธิ์ของผลหารและเศษในคราวเดียว เศษที่ได้ยังเท่ากับ P(c) ตามทฤษฎีบทเศษเหลือ จึงใช้หาค่าฟังก์ชันและทดสอบรากไปพร้อมกัน

    ทฤษฎีบทรากตรรกยะช่วยอะไร?

    ช่วยให้รู้ว่ารากตรรกยะที่เป็นไปได้มีจำกัด คือ ±p/q โดย p หารพจน์คงที่ลงตัวและ q หารสัมประสิทธิ์นำลงตัว เราจึงไม่ต้องเดาสุ่ม ทดลองแทนเฉพาะค่าเหล่านี้ เจอรากหนึ่งตัวแล้วหารสังเคราะห์ลดดีกรีลงทีละขั้น
