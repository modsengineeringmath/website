## ดีกรี สัมประสิทธิ์นำ และพฤติกรรมปลายกราฟ

เมื่อ x มีขนาดใหญ่มาก พจน์ดีกรีสูงสุดจะโตเร็วกว่าพจน์อื่นจนพจน์อื่นแทบไม่มีผล เช่นที่ x = 100 ค่า $2x^3$ คือ 2,000,000 แต่ $-11x$ คือแค่ −1,100 ดังนั้นปลายกราฟของพหุนามจึงเหมือนปลายกราฟของ $a_n x^n$ เสมอ เหลือให้ดูเพียงว่าดีกรีเป็นคู่หรือคี่ และสัมประสิทธิ์นำเป็นบวกหรือลบ

## รากและภาวะรากซ้ำ (Zeros & Multiplicity)

ถ้า $(x - c)^m$ เป็นตัวประกอบของ P แต่ $(x - c)^{m+1}$ ไม่ใช่ เราเรียกว่า c เป็นรากที่มีภาวะซ้ำ m ใกล้ ๆ x = c กราฟจะหน้าตาเหมือน $k(x - c)^m$ ถ้า m เป็นคี่ ค่า $(x - c)^m$ เปลี่ยนเครื่องหมายเมื่อ x ผ่าน c กราฟจึงตัดผ่านแกน ถ้า m เป็นคู่ เครื่องหมายไม่เปลี่ยน กราฟจึงแค่แตะแล้ววกกลับ ข้อนี้รวมกับพฤติกรรมปลายกราฟก็วาดกราฟคร่าว ๆ ได้แล้ว

P3 Multiplicity ภาวะรากซ้ำ

$$P(x) = (x - c)^m Q(x),\ Q(c) \ne 0:\quad m \text{ คี่ ตัดแกน},\quad m \text{ คู่ แตะแกน}$$

P4 Counting จำนวนรากและจุดวกกลับ

$$\#\{\text{รากจริง}\} \le n,\qquad \#\{\text{จุดวกกลับ}\} \le n - 1$$

P5 Fundamental theorem of algebra

$$P(x) = a_n(x - z_1)(x - z_2)\cdots(x - z_n),\quad z_k \in \mathbb C$$

สัมประสิทธิ์จริง ⇒ รากเชิงซ้อนมาเป็นคู่สังยุค $a \pm bi$

### วิเคราะห์ $P(x) = -2(x - 1)^2(x + 3)$

- ดีกรี $2 + 1 = 3$ (คี่) สัมประสิทธิ์นำ −2 (ลบ) ⇒ ซ้ายบน ขวาล่าง

- x = −3 ภาวะซ้ำ 1 ⇒ ตัดผ่าน · x = 1 ภาวะซ้ำ 2 ⇒ แตะแกนแล้ววกกลับ

- จุดตัดแกน y: $P(0) = -2(1)(3) = -6$

- จากซ้าย: กราฟลงมาตัดแกนที่ −3 ไปถึงจุดต่ำสุดเฉพาะที่ระหว่าง −3 กับ 1 ผ่าน (0, −6) แล้วขึ้นมาแตะ x = 1 และลงต่อ

ปลาย ↖ ↘ · ตัดที่ −3 · แตะที่ 1 · ผ่าน (0, −6)

ตัวอย่าง P-2 · สร้างพหุนามจากราก

### หาพหุนามดีกรี 3 ที่มีราก 2, −1, ½ และ $P(0) = 2$

- เขียน $P(x) = a(x - 2)(x + 1)\left(x - \tfrac12\right)$

- $P(0) = a(-2)(1)\left(-\tfrac12\right) = a = 2$

- $P(x) = (x - 2)(x + 1)(2x - 1) = (x^2 - x - 2)(2x - 1)$ แล้วกระจาย

$P(x) = 2x^3 - 3x^2 - 3x + 2$

## การหารยาวและการหารสังเคราะห์ (Division)

การหารพหุนามทำแบบเดียวกับการหารยาวของจำนวน: หารพจน์หน้าสุด คูณกลับ ลบ แล้วดึงพจน์ถัดไปลงมา เมื่อตัวหารเป็น $x - c$ ขั้นตอนทั้งหมดย่อเหลือแค่ตัวเลขได้ เรียกว่าการหารสังเคราะห์ วิธีคือเขียนสัมประสิทธิ์ครบทุกดีกรี (ดีกรีที่ขาดใส่ 0) ดึงตัวแรกลงมา คูณด้วย c ใส่ไว้ใต้ตัวถัดไป บวกกัน ทำซ้ำจนจบ ตัวเลขสุดท้ายคือเศษ ตัวเลขก่อนหน้าคือสัมประสิทธิ์ของผลหารซึ่งมีดีกรีลดลงหนึ่ง

### หาร $2x^3 - 3x^2 - 11x + 6$ ด้วย $x - 3$ แล้วหารากทั้งหมด

- เขียนสัมประสิทธิ์ 2, −3, −11, 6 และ c = 3 · ดึง 2 ลงมา

- $2 \times 3 = 6$, $-3 + 6 = 3$ · $3 \times 3 = 9$, $-11 + 9 = -2$ · $-2 \times 3 = -6$, $6 - 6 = 0$

- เศษเป็น 0 ⇒ $x - 3$ เป็นตัวประกอบ ผลหาร $2x^2 + 3x - 2 = (2x - 1)(x + 2)$

$2x^3 - 3x^2 - 11x + 6 = (x - 3)(2x - 1)(x + 2)$ รากคือ $3,\ \tfrac12,\ -2$

## ทฤษฎีบทเศษเหลือ ตัวประกอบ และรากตรรกยะ

สามทฤษฎีบทนี้ทำงานต่อกันเป็นสาย ทฤษฎีบทเศษเหลือบอกว่าไม่ต้องหารจริงก็รู้เศษได้ แค่แทนค่า c ลงใน P ทฤษฎีบทตัวประกอบบอกว่าถ้าแทนแล้วได้ศูนย์ ก็ได้ตัวประกอบหนึ่งตัว และทฤษฎีบทรากตรรกยะบอกว่าควรลองแทนค่าอะไรบ้าง เมื่อเจอรากหนึ่งตัวก็หารสังเคราะห์เพื่อลดดีกรี แล้วทำซ้ำจนเหลือกำลังสองซึ่งใช้สูตรได้

P8 Remainder theorem ทฤษฎีบทเศษเหลือ

$$P(x) \div (x - c)\ \Rightarrow\ R = P(c)$$

P9 Factor theorem ทฤษฎีบทตัวประกอบ

$$(x - c) \mid P(x) \iff P(c) = 0$$

P10 Rational root theorem ทฤษฎีบทรากตรรกยะ

$$P(x) \in \mathbb Z[x],\ P\!\left(\tfrac{p}{q}\right) = 0,\ \gcd(p, q) = 1 \Rightarrow p \mid a_0,\ q \mid a_n$$

P11 Vieta (cubic) ผลบวก-ผลคูณรากของกำลังสาม

$$ax^3 + bx^2 + cx + d:\ \ \textstyle\sum r_i = -\tfrac{b}{a},\ \ \sum r_ir_j = \tfrac{c}{a},\ \ r_1r_2r_3 = -\tfrac{d}{a}$$

ตัวอย่าง P-4 · ทฤษฎีบทเศษเหลือ

### หาเศษเมื่อหาร $x^{100} - 3x + 1$ ด้วย $x + 1$

- $x + 1 = x - (-1)$ จึงใช้ $c = -1$ (P8)

- $P(-1) = (-1)^{100} - 3(-1) + 1 = 1 + 3 + 1$

เศษ = 5 (หารยาวจริง ๆ ต้องทำ 100 รอบ)

ตัวอย่าง P-5 · หาค่าคงตัวจากตัวประกอบ

### หาค่า k ที่ทำให้ $x - 2$ เป็นตัวประกอบของ $x^3 + kx^2 - 4x + 4$

- ทฤษฎีบทตัวประกอบ: $P(2) = 0$

- $8 + 4k - 8 + 4 = 4k + 4 = 0$

$k = -1$

ตัวอย่าง P-6 · หารากด้วยทฤษฎีบทรากตรรกยะ

### หารากทั้งหมดของ $x^3 - 4x^2 + x + 6 = 0$

- $a_0 = 6,\ a_n = 1$ ผู้ท้าชิงคือ $\pm1, \pm2, \pm3, \pm6$

- ลอง $x = -1$: $-1 - 4 - 1 + 6 = 0$ ⇒ $x + 1$ เป็นตัวประกอบ

- หารสังเคราะห์ด้วย c = −1 ได้ $x^2 - 5x + 6 = (x - 2)(x - 3)$

$x = -1,\ 2,\ 3$ (ตรวจ Vieta: ผลบวก 4 = −(−4)/1 ✓)

ใช้เมื่อหารพหุนามด้วยตัวหารเชิงเส้น x − c เพราะเร็วกว่าการหารยาวมาก แถวสุดท้ายให้ทั้งสัมประสิทธิ์ของผลหารและเศษในคราวเดียว เศษที่ได้ยังเท่ากับ P(c) ตามทฤษฎีบทเศษเหลือ จึงใช้หาค่าฟังก์ชันและทดสอบรากไปพร้อมกัน

ทฤษฎีบทรากตรรกยะช่วยอะไร?
ช่วยให้รู้ว่ารากตรรกยะที่เป็นไปได้มีจำกัด คือ ±p/q โดย p หารพจน์คงที่ลงตัวและ q หารสัมประสิทธิ์นำลงตัว เราจึงไม่ต้องเดาสุ่ม ทดลองแทนเฉพาะค่าเหล่านี้ เจอรากหนึ่งตัวแล้วหารสังเคราะห์ลดดีกรีลงทีละขั้น
