# ฟังก์ชันผกผัน: ฟังก์ชันหนึ่งต่อหนึ่ง การทดสอบเส้นแนวนอน วิธีหา f⁻¹(x) และกราฟที่สะท้อนเส้น y = x

THภาษาไทยENEnglish

// บทที่ 27.6 · พรีแคลคูลัส · Inverse Functions


ถ้าฟังก์ชันหนึ่งแปลงองศาเซลเซียสเป็นฟาเรนไฮต์ ฟังก์ชันผกผันก็คือสูตรที่แปลงกลับ แนวคิดนี้ฟังดูง่าย แต่มีเงื่อนไขซ่อนอยู่ว่าการแปลงกลับต้องได้คำตอบเดียว ซึ่งไม่จริงกับทุกฟังก์ชัน หน้านี้อธิบายว่าเมื่อไรฟังก์ชันจึงย้อนกลับได้ หาตัวผกผันอย่างเป็นระบบ ตรวจคำตอบด้วยฟังก์ชันประกอบ และใช้การจำกัดโดเมนให้ฟังก์ชันที่ย้อนไม่ได้กลายเป็นย้อนได้ ความรู้นี้จะเป็นพื้นของลอการิทึมในหน้า 27.8 และฟังก์ชันตรีโกณมิติผกผันในหน้า 27.9 โดยตรง

สรุปใน 30 วินาที

- มีตัวผกผันเมื่อเป็นหนึ่งต่อหนึ่ง: เส้นแนวนอนทุกเส้นตัดกราฟไม่เกินหนึ่งจุด

- หา $f^{-1}$: เขียน $y = f(x)$ สลับ x กับ y แล้วแก้หา y

- ตรวจ: $f\big(f^{-1}(x)\big) = x$ และ $f^{-1}\big(f(x)\big) = x$

- $D_{f^{-1}} = R_f$ · $R_{f^{-1}} = D_f$ · กราฟสะท้อนในเส้น $y = x$

- $f^{-1}(x) \ne \dfrac{1}{f(x)}$

## ฟังก์ชันหนึ่งต่อหนึ่งและการทดสอบเส้นแนวนอน

ฟังก์ชันทุกตัวให้ y ค่าเดียวต่อ x หนึ่งค่า แต่การย้อนกลับต้องการเงื่อนไขกลับด้าน คือ y แต่ละค่าต้องมาจาก x เพียงค่าเดียว ฟังก์ชันที่มีสมบัตินี้เรียกว่าฟังก์ชันหนึ่งต่อหนึ่ง (one-to-one หรือ injective) บนกราฟตรวจได้ด้วยเส้นแนวนอน ถ้าเส้น $y = c$ ตัดกราฟสองจุด แปลว่ามี x สองค่าที่ให้ c เหมือนกัน และเมื่อย้อนกลับจะไม่รู้ว่าควรตอบค่าไหน ฟังก์ชันที่เพิ่มตลอดหรือลดตลอดบนโดเมนจึงเป็นหนึ่งต่อหนึ่งเสมอ

I1 One-to-one ฟังก์ชันหนึ่งต่อหนึ่ง

$$f(a) = f(b) \Rightarrow a = b \quad\iff\quad \text{เส้นแนวนอนตัดกราฟไม่เกิน 1 จุด}$$

I2 Inverse นิยามฟังก์ชันผกผัน

$$f^{-1}(y) = x \iff f(x) = y,\qquad f\big(f^{-1}(x)\big) = x,\ \ f^{-1}\big(f(x)\big) = x$$

I3 Swap & reflect สลับโดเมน-เรนจ์

$$D_{f^{-1}} = R_f,\quad R_{f^{-1}} = D_f,\quad (a, b) \in f \iff (b, a) \in f^{-1}$$

## วิธีหาฟังก์ชันผกผันทีละขั้น

ขั้นตอนมาตรฐานมีสี่ขั้น: (1) ตรวจว่าเป็นหนึ่งต่อหนึ่งบนโดเมนที่กำหนด (2) เขียน $y = f(x)$ แล้วสลับ x กับ y (3) แก้สมการหา y (4) เขียนโดเมนของตัวผกผันจากเรนจ์ของ f ขั้นที่ 4 ถูกลืมบ่อยที่สุด ทั้งที่จำเป็นมากเมื่อ f มาจากราก เพราะสูตรที่ได้อาจดูเหมือนนิยามทุก x แต่ความจริงไม่ใช่

I4 Finding f⁻¹ ขั้นตอนหาตัวผกผัน

$$y = f(x)\ \xrightarrow{\ x \leftrightarrow y\ }\ x = f(y)\ \xrightarrow{\ \text{แก้หา } y\ }\ y = f^{-1}(x)$$

I5 Linear fractional เศษส่วนดีกรีหนึ่ง

$$f(x) = \frac{ax + b}{cx + d}\ \Rightarrow\ f^{-1}(x) = \frac{dx - b}{a - cx}$$

สลับตำแหน่ง a กับ d แล้วเปลี่ยนเครื่องหมาย b และ c (เหมือนอินเวอร์สเมทริกซ์ 2×2)

ตัวอย่าง I-1 · ฟังก์ชันเศษส่วน

### หา $f^{-1}$ ของ $f(x) = \dfrac{2x + 1}{x - 3}$ พร้อมโดเมน

- สลับ: $x = \dfrac{2y + 1}{y - 3}$ · คูณไขว้: $xy - 3x = 2y + 1$

- รวบ y ไว้ข้างเดียว: $xy - 2y = 3x + 1 \Rightarrow y(x - 2) = 3x + 1$

- $f^{-1}(x) = \dfrac{3x + 1}{x - 2}$ โดเมน $x \ne 2$ ตรงกับเรนจ์ของ f (HA ของ f คือ y = 2)

$f^{-1}(x) = \dfrac{3x + 1}{x - 2},\ x \ne 2$

ตัวอย่าง I-2 · ตัวผกผันที่มีราก

### หา $f^{-1}$ ของ $f(x) = \sqrt{x - 1}$

- $f$ เพิ่มตลอดบน $[1, \infty)$ เรนจ์คือ $[0, \infty)$

- สลับ: $x = \sqrt{y - 1} \Rightarrow x^2 = y - 1 \Rightarrow y = x^2 + 1$

- โดเมนของ $f^{-1}$ = เรนจ์ของ f = $[0, \infty)$ ต้องเขียนกำกับ

$f^{-1}(x) = x^2 + 1,\ x \ge 0$ (ถ้าไม่เขียน $x \ge 0$ จะกลายเป็นพาราโบลาทั้งตัวซึ่งไม่ใช่ตัวผกผัน)

ตัวอย่าง I-3 · เอกซ์โพเนนเชียลกลับเป็นลอการิทึม

### หา $f^{-1}$ ของ $f(x) = 2^{x - 1} + 3$

- สลับ: $x = 2^{y - 1} + 3 \Rightarrow 2^{y - 1} = x - 3$

- ใช้นิยามลอการิทึม: $y - 1 = \log_2(x - 3)$

$f^{-1}(x) = 1 + \log_2(x - 3),\ x > 3$ — เส้นกำกับ $y = 3$ ของ f กลายเป็น $x = 3$ ของตัวผกผัน

## จำกัดโดเมนให้ฟังก์ชันย้อนกลับได้

ฟังก์ชันที่ไม่เป็นหนึ่งต่อหนึ่งยังมีตัวผกผันได้ ถ้าเราเลือกใช้เพียงส่วนหนึ่งของโดเมนที่ฟังก์ชันเพิ่มตลอดหรือลดตลอด ตัวอย่างที่สำคัญที่สุดคือ $x^2$ บน $x \ge 0$ ซึ่งให้ $\sqrt x$ และ $\sin x$ บน $[-\pi/2, \pi/2]$ ซึ่งให้ $\arcsin x$ การเลือกช่วงไม่ได้เป็นกฎตายตัว แต่ต้องเลือกให้ครอบคลุมเรนจ์ทั้งหมดของฟังก์ชันเดิม

I6 Restricted domains จำกัดโดเมน

$$x^2\big|_{x \ge 0} \leftrightarrow \sqrt{x},\qquad \sin x\big|_{[-\pi/2,\,\pi/2]} \leftrightarrow \arcsin x$$

I7 Inverse of a composition ตัวผกผันของฟังก์ชันประกอบ

$$(f \circ g)^{-1} = g^{-1} \circ f^{-1}$$

เหมือนใส่ถุงเท้าแล้วใส่รองเท้า เวลาถอดต้องถอดรองเท้าก่อน

ตัวอย่าง I-4 · จำกัดโดเมนของกำลังสอง

### หาตัวผกผันของ $f(x) = x^2 - 4x + 1$ เมื่อ $x \ge 2$

- ทำกำลังสองสมบูรณ์: $f(x) = (x - 2)^2 - 3$ จุดยอด (2, −3) บน $x \ge 2$ ฟังก์ชันเพิ่มตลอด เรนจ์ $[-3, \infty)$

- สลับ: $x = (y - 2)^2 - 3 \Rightarrow y - 2 = \pm\sqrt{x + 3}$ เลือกเครื่องหมายบวกเพราะ $y \ge 2$

$f^{-1}(x) = 2 + \sqrt{x + 3},\ x \ge -3$

ตัวอย่าง I-5 · ไม่ต้องหาสูตรก็ได้คำตอบ

### (ก) ถ้า $f(x) = 3x - 5,\ g(x) = x^3$ จงหา $(f \circ g)^{-1}(19)$ (ข) $h(x) = x^3 + x$ จงหา $h^{-1}(10)$

- (ก) $(f \circ g)^{-1}(19)$ คือ x ที่ทำให้ $3x^3 - 5 = 19 \Rightarrow x^3 = 8 \Rightarrow x = 2$

- (ข) h เพิ่มตลอดจึงเป็นหนึ่งต่อหนึ่ง แต่แก้สูตรตัวผกผันยาก ให้หา x ที่ $x^3 + x = 10$ ลอง x = 2 ได้ 8 + 2 = 10

(ก) 2 · (ข) 2 — คำถามเรื่องค่า $f^{-1}(b)$ แค่ถามว่า f ส่งอะไรไปที่ b

## แล็บเงาสะท้อนและเส้นแนวนอน

เส้นสีส้มคือ f เส้นสีน้ำเงินคือภาพสะท้อนในเส้นประ $y = x$ ลากเส้นแนวนอนขึ้นลงเพื่อนับจุดตัด ถ้าเจอตำแหน่งที่ตัดสองจุด จุดจะเป็นสีแดงและแล็บจะบอกว่าตัวผกผันไม่เป็นฟังก์ชัน ลองเลือก “x² (ทุก x)” แล้วเปลี่ยนเป็น “x², x ≥ 0” เพื่อดูว่าการจำกัดโดเมนทำให้เงาสะท้อนกลายเป็นกราฟ $\sqrt x$ อย่างไร เลื่อน t เพื่อดูจุด P กับจุดสะท้อน P′ ที่พิกัดสลับกัน

## คำถามที่พบบ่อย

f⁻¹(x) เท่ากับ 1/f(x) หรือไม่?
ไม่ใช่ เลข −1 ใน f⁻¹ หมายถึงฟังก์ชันผกผัน คือฟังก์ชันที่ย้อนการทำงานของ f ส่วน 1/f(x) คือส่วนกลับของค่าฟังก์ชัน เช่น f(x) = 2x มี f⁻¹(x) = x/2 แต่ 1/f(x) = 1/(2x) ซึ่งต่างกันโดยสิ้นเชิง

ฟังก์ชันแบบไหนมีฟังก์ชันผกผัน?
เฉพาะฟังก์ชันหนึ่งต่อหนึ่ง คือ y แต่ละค่ามาจาก x เพียงค่าเดียว ตรวจบนกราฟด้วยการทดสอบเส้นแนวนอน ถ้ามีเส้นแนวนอนตัดกราฟสองจุดขึ้นไป ตัวผกผันจะไม่เป็นฟังก์ชัน ฟังก์ชันที่เพิ่มตลอดหรือลดตลอดบนโดเมนผ่านการทดสอบนี้เสมอ

ทำไม x² ถึงไม่มีตัวผกผัน แต่ √x ใช้แทนได้?
เพราะ x² ส่ง 2 และ −2 ไปที่ 4 ค่าเดียวกัน ย้อนกลับไม่ได้ว่ามาจากไหน ถ้าจำกัดโดเมนเหลือ x ≥ 0 ฟังก์ชันจะเป็นหนึ่งต่อหนึ่งและมีตัวผกผันคือ √x นี่คือเหตุผลเดียวกับที่ arcsin ให้คำตอบเฉพาะช่วง −π/2 ถึง π/2

ทำไมกราฟของ f กับ f⁻¹ จึงสะท้อนกันในเส้น y = x?
เพราะถ้าจุด (a, b) อยู่บนกราฟ f แปลว่า f(a) = b ซึ่งเท่ากับ f⁻¹(b) = a จุด (b, a) จึงอยู่บนกราฟ f⁻¹ การสลับพิกัดคือการสะท้อนในเส้น y = x พอดี
