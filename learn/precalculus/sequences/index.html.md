// บทที่ 27.12 · พรีแคลคูลัส · Sequences


ลำดับคือฟังก์ชันชนิดพิเศษที่รับเฉพาะจำนวนนับ 1, 2, 3, … เป็นค่าเข้า กราฟของลำดับจึงเป็นจุดเรียงห่าง ๆ แทนที่จะเป็นเส้นต่อเนื่อง เมื่อมองแบบนี้ ลำดับเลขคณิตก็คือฟังก์ชันเชิงเส้นที่ถูกสุ่มตัวอย่างที่จุดจำนวนนับ และลำดับเรขาคณิตก็คือฟังก์ชันเอกซ์โพเนนเชียลแบบเดียวกัน หน้านี้ใช้มุมมองฟังก์ชันอธิบายสูตรพจน์ทั่วไป วิธีหาพจน์จากข้อมูลบางส่วน ค่าเฉลี่ย ลำดับเวียนเกิด และพฤติกรรมเมื่อ n ใหญ่มาก ซึ่งเป็นพื้นของอนุกรมในหน้าถัดไปและลิมิตในแคลคูลัส

## ลำดับคือฟังก์ชันบนจำนวนนับ

ลำดับ $a_1, a_2, a_3, \dots$ กำหนดได้สองแบบ แบบแรกเป็นสูตรพจน์ทั่วไป บอก $a_n$ ตรง ๆ จาก n เช่น $a_n = n^2$ แบบที่สองเป็นความสัมพันธ์เวียนเกิด บอกพจน์แรกกับกฎสร้างพจน์ถัดไป เช่น $a_1 = 1,\ a_{n+1} = a_n + 2n + 1$ ซึ่งก็คือลำดับเดียวกัน การหาสูตรพจน์ทั่วไปจากพจน์แรก ๆ ทำได้โดยดูผลต่างหรืออัตราส่วนของพจน์ที่อยู่ติดกัน ถ้าผลต่างคงที่เป็นเลขคณิต ถ้าอัตราส่วนคงที่เป็นเรขาคณิต ถ้าผลต่างอันดับสองคงที่เป็นพหุนามกำลังสอง

Q1 Sequence ลำดับ

$$a: \{1, 2, 3, \dots\} \to \mathbb R,\quad n \mapsto a_n$$

ลำดับจำกัดมีพจน์สุดท้าย · ลำดับอนันต์ไม่มีพจน์สุดท้าย

## ลำดับเลขคณิต (Arithmetic Sequences)

ลำดับเลขคณิตเพิ่มขึ้นหรือลดลงด้วยค่าคงที่ d ทุกขั้น เหมือนเงินเดือนที่ขึ้นปีละเท่ากัน หรือที่นั่งในโรงละครที่แต่ละแถวมีมากกว่าแถวหน้าสองที่ สูตร $a_n = a_1 + (n - 1)d$ เขียนใหม่ได้เป็น $a_n = dn + (a_1 - d)$ ซึ่งคือสมการเส้นตรงที่มีความชัน d นี่คือเหตุผลที่จุดของลำดับเลขคณิตเรียงเป็นเส้นตรงในแล็บ

Q2 Arithmetic sequence ลำดับเลขคณิต

$$a_n = a_1 + (n - 1)d,\qquad d = a_{n+1} - a_n,\qquad a_n = a_m + (n - m)d$$

Q3 Arithmetic mean ค่าเฉลี่ยเลขคณิต

$$a, b, c \text{ เลขคณิต} \iff b = \frac{a + c}{2}$$

แทรก k จำนวนระหว่าง a กับ b: $d = \tfrac{b - a}{k + 1}$

ตัวอย่าง Q-1 · หาพจน์จากสองพจน์

### ลำดับเลขคณิตมี $a_3 = 11$ และ $a_{10} = 39$ จงหา $a_1,\ d,\ a_{25}$

- จาก $a_{10} = a_3 + 7d$: $39 = 11 + 7d \Rightarrow d = 4$

- $a_1 = a_3 - 2d = 11 - 8 = 3$

- $a_{25} = 3 + 24(4) = 99$

$a_1 = 3,\ d = 4,\ a_{25} = 99$

ตัวอย่าง Q-2 · นับจำนวนพจน์

### ลำดับ 7, 11, 15, …, 403 มีกี่พจน์

- $a_1 = 7,\ d = 4$ ให้ $a_n = 403$: $7 + (n - 1)4 = 403$

- $n - 1 = 99 \Rightarrow n = 100$

100 พจน์

## ลำดับเรขาคณิต (Geometric Sequences)

ลำดับเรขาคณิตคูณด้วยค่าคงที่ r ทุกขั้น เช่น ประชากรที่เพิ่ม 3% ต่อปีคือการคูณด้วย 1.03 ทุกปี ถ้า r อยู่ระหว่าง −1 กับ 1 พจน์จะเล็กลงเข้าใกล้ศูนย์ ถ้า r เป็นลบ เครื่องหมายจะสลับไปมา การเห็นพฤติกรรมเหล่านี้บนกราฟจุดช่วยมากในการตัดสินว่าอนุกรมอนันต์ในหน้าถัดไปจะลู่เข้าหรือไม่

Q4 Geometric sequence ลำดับเรขาคณิต

$$a_n = a_1 r^{n-1},\qquad r = \frac{a_{n+1}}{a_n},\qquad a_n = a_m r^{n - m}$$

Q5 Geometric mean ค่าเฉลี่ยเรขาคณิต

$$a, b, c \text{ เรขาคณิต} \iff b^2 = ac,\qquad \frac{a + c}{2} \ge \sqrt{ac}\ \ (a, c > 0)$$

ตัวอย่าง Q-3 · เรขาคณิตจากสองพจน์

### ลำดับเรขาคณิตมี $a_2 = 6$ และ $a_5 = 162$ จงหา $a_1,\ r,\ a_8$

- $a_5 = a_2 r^3 \Rightarrow r^3 = 27 \Rightarrow r = 3$

- $a_1 = 6/3 = 2$ · $a_8 = 2\cdot3^7 = 2\cdot2187$

$a_1 = 2,\ r = 3,\ a_8 = 4{,}374$

ตัวอย่าง Q-4 · แทรกค่าเฉลี่ยเรขาคณิต

### แทรกค่าเฉลี่ยเรขาคณิต 3 จำนวนระหว่าง 2 กับ 162

- ลำดับมี 5 พจน์ $2, \_, \_, \_, 162$ จึง $162 = 2r^4 \Rightarrow r^4 = 81 \Rightarrow r = \pm3$

6, 18, 54 หรือ −6, 18, −54 (ทั้งสองแบบถูก)

## ลำดับเวียนเกิดและฟีโบนัชชี

ลำดับเวียนเกิดเชิงเส้น $a_{n+1} = pa_n + q$ พบบ่อยมาก เช่น ยอดเงินกู้ที่คิดดอกเบี้ยแล้วหักค่างวดทุกเดือน หรือปริมาณยาในร่างกายที่เหลือบางส่วนแล้วได้รับเพิ่มทุกวัน ลำดับแบบนี้มีจุดตรึง L ที่ทำให้ $L = pL + q$ ถ้า $|p|

Q6 Linear recurrence เวียนเกิดเชิงเส้น

$$a_{n+1} = pa_n + q\ (p \ne 1):\quad L = \frac{q}{1 - p},\qquad a_n = L + (a_1 - L)p^{\,n-1}$$

Q7 Fibonacci ฟีโบนัชชี

$$F_1 = F_2 = 1,\ F_{n+2} = F_{n+1} + F_n,\qquad \frac{F_{n+1}}{F_n} \to \varphi = \frac{1 + \sqrt5}{2}$$

ตัวอย่าง Q-5 · สูตรปิดของเวียนเกิด

### $a_1 = 2,\ a_{n+1} = 3a_n - 2$ จงหาสูตรพจน์ทั่วไป

- จุดตรึง: $L = 3L - 2 \Rightarrow L = 1$

- $a_n = 1 + (2 - 1)3^{n-1} = 1 + 3^{n-1}$

- ตรวจ: $a_2 = 3(2) - 2 = 4 = 1 + 3$ ✓ · $a_3 = 3(4) - 2 = 10 = 1 + 9$ ✓

$a_n = 1 + 3^{n-1}$ (|p| = 3 > 1 ลำดับจึงหนีออกจากจุดตรึง)

ลำดับเวียนเกิดกำหนดพจน์แรกแล้วบอกวิธีสร้างพจน์ถัดไปจากพจน์ก่อนหน้า เช่น a₁ = 2, aₙ₊₁ = 3aₙ − 2 ลำดับเลขคณิตและเรขาคณิตก็เขียนแบบเวียนเกิดได้ ลำดับเวียนเกิดเชิงเส้น aₙ₊₁ = p·aₙ + q มีสูตรปิด aₙ = L + (a₁ − L)pⁿ⁻¹ โดย L = q/(1 − p)

**ถ้าอยากเรียนลำดับลึกกว่านี้ไปต่อที่ไหน?**
บทที่ 26 ลำดับและอนุกรมฉบับเต็มของเว็บนี้ต่อจากหน้านี้ไปถึงนิยาม ε–N ทฤษฎีบทแซนด์วิช ลำดับทางเดียวมีขอบเขต และความสัมพันธ์เวียนเกิดอันดับสอง พร้อมแนวข้อสอบ 60 ข้อ
