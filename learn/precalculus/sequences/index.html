    คำถามที่พบบ่อย

    ลำดับเลขคณิตกับลำดับเรขาคณิตต่างกันอย่างไร?

    ลำดับเลขคณิตได้พจน์ถัดไปจากการบวกค่าคงที่ d เช่น 3, 7, 11, 15 ส่วนลำดับเรขาคณิตได้จากการคูณค่าคงที่ r เช่น 2, 6, 18, 54 เมื่อวาดจุด (n, aₙ) ลำดับเลขคณิตเรียงบนเส้นตรงที่มีความชัน d ลำดับเรขาคณิตเรียงบนกราฟเอกซ์โพเนนเชียล

    ตรวจว่าสามจำนวนเป็นลำดับเลขคณิตหรือเรขาคณิตอย่างไร?

    a, b, c เป็นลำดับเลขคณิตเมื่อ 2b = a + c (ตัวกลางเป็นค่าเฉลี่ยเลขคณิตของสองตัวข้าง) และเป็นลำดับเรขาคณิตเมื่อ b² = ac (ตัวกลางเป็นค่าเฉลี่ยเรขาคณิต) ใช้ตรวจได้เร็วโดยไม่ต้องหา d หรือ r

    ลำดับเวียนเกิดคืออะไร?

    ลำดับเวียนเกิดกำหนดพจน์แรกแล้วบอกวิธีสร้างพจน์ถัดไปจากพจน์ก่อนหน้า เช่น a₁ = 2, aₙ₊₁ = 3aₙ − 2 ลำดับเลขคณิตและเรขาคณิตก็เขียนแบบเวียนเกิดได้ ลำดับเวียนเกิดเชิงเส้น aₙ₊₁ = p·aₙ + q มีสูตรปิด aₙ = L + (a₁ − L)pⁿ⁻¹ โดย L = q/(1 − p)

    ถ้าอยากเรียนลำดับลึกกว่านี้ไปต่อที่ไหน?

    บทที่ 26 ลำดับและอนุกรมฉบับเต็มของเว็บนี้ต่อจากหน้านี้ไปถึงนิยาม ε–N ทฤษฎีบทแซนด์วิช ลำดับทางเดียวมีขอบเขต และความสัมพันธ์เวียนเกิดอันดับสอง พร้อมแนวข้อสอบ 60 ข้อ

ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม เครื่องคิดเลขลำดับและอนุกรม พร้อมวิธีทำ อุปนัยเชิงคณิตศาสตร์ อุปนัยแบบเข้ม (Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ แรงก์ (ค่าลำดับขั้น) ของเมทริกซ์ ผลเฉลยเชิงตัวเลข: LU จาโคบี เกาส์-ไซเดล แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ คราเมอร์ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก
