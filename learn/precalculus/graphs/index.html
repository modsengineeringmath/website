    ทำไม f(x − 2) ถึงเลื่อนไปทางขวา ไม่ใช่ทางซ้าย?

    เพราะ y = f(x − 2) จะให้ค่าเดิมของ f(0) ก็ต่อเมื่อ x − 2 = 0 คือ x = 2 ทุกจุดของกราฟเดิมจึงต้องไปเกิดช้ากว่าเดิม 2 หน่วย หรือเลื่อนไปทางขวา 2 หน่วย การเปลี่ยนที่ทำกับ x ภายในวงเล็บจะทำงาน “กลับด้าน” กับที่ตาเห็นเสมอ ทั้งการเลื่อนและการยืด

    ถ้ามีการแปลงหลายอย่าง ต้องทำอะไรก่อน?

    สำหรับ y = a·f(b(x − h)) + k ให้ทำการเปลี่ยนแปลงแนวนอนจากในออกนอก (ยืด-หดด้วย b แล้วเลื่อนด้วย h) และแนวตั้งตามลำดับปกติ (ยืด-สะท้อนด้วย a แล้วเลื่อนด้วย k) วิธีที่ไม่มีวันผิดคือใช้สูตรย้ายจุด (x, y) ไปที่ (x/b + h, a·y + k) กับจุดสำคัญของกราฟต้นแบบ

    ฟังก์ชันคู่และฟังก์ชันคี่ดูอย่างไร?

    ฟังก์ชันคู่มี f(−x) = f(x) กราฟสมมาตรกับแกน y เช่น x², cos x ฟังก์ชันคี่มี f(−x) = −f(x) กราฟสมมาตรรอบจุดกำเนิด เช่น x³, sin x ถ้าแทน −x แล้วไม่ได้ทั้งสองแบบ แสดงว่าไม่เป็นทั้งคู่และคี่ ฟังก์ชันส่วนใหญ่เป็นแบบหลังนี้
