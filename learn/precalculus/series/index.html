    คำถามที่พบบ่อย

    อนุกรมเรขาคณิตอนันต์หาผลบวกได้เมื่อใด?

    เมื่อ |r| < 1 เท่านั้น เพราะ rⁿ เข้าใกล้ศูนย์ ผลบวกย่อย a₁(1 − rⁿ)/(1 − r) จึงเข้าใกล้ a₁/(1 − r) ถ้า |r| ≥ 1 พจน์ไม่เล็กลงจนเป็นศูนย์ ผลบวกจึงไม่เข้าใกล้ค่าใด (ลู่ออก)

    ทศนิยมซ้ำแปลงเป็นเศษส่วนด้วยอนุกรมได้อย่างไร?

    เขียนทศนิยมซ้ำเป็นอนุกรมเรขาคณิตอนันต์ เช่น 0.454545… = 45/100 + 45/10000 + … มี a₁ = 45/100, r = 1/100 ผลบวก (45/100)/(99/100) = 45/99 = 5/11

    จำสูตร Σk² และ Σk³ อย่างไร?

    Σk = n(n + 1)/2 คือผลบวก 1 ถึง n ส่วน Σk³ = [n(n + 1)/2]² คือกำลังสองของ Σk พอดี ส่วน Σk² = n(n + 1)(2n + 1)/6 จำว่ามีตัวประกอบสามตัวเรียงกัน n, n + 1, 2n + 1 หารด้วย 6 ตรวจได้โดยแทน n = 1 ต้องได้ 1

    สูตรเงินผ่อนรายเดือนมาจากไหน?

    มาจากอนุกรมเรขาคณิต: มูลค่าปัจจุบันของค่างวด R ทุกงวดรวมกันต้องเท่ากับยอดกู้ PV = R[(1 + i)⁻¹ + (1 + i)⁻² + … + (1 + i)⁻ᴺ] ซึ่งรวมได้ R(1 − (1 + i)⁻ᴺ)/i แก้หา R จะได้ค่างวด

engineering บทความแยกหมวด: Python ยุค AI เมทริกซ์ ลำดับและอนุกรม Laplace ฯลฯ Articles in English เฉลยโจทย์ทีละขั้น: อินทิเกรต อนุพันธ์ ลาปลาซ ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม เครื่องคิดเลขลำดับและอนุกรม พร้อมวิธีทำ อุปนัยเชิงคณิตศาสตร์ อุปนัยแบบเข้ม (Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ แรงก์ (ค่าลำดับขั้น) ของเมทริกซ์ ผลเฉลยเชิงตัวเลข: LU จาโคบี เกาส์-ไซเดล แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ คราเมอร์ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก
