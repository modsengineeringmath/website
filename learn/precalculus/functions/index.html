    คำถามที่พบบ่อย

    ความสัมพันธ์กับฟังก์ชันต่างกันอย่างไร?

    ความสัมพันธ์คือเซตของคู่อันดับใด ๆ ส่วนฟังก์ชันเป็นความสัมพันธ์ที่มีเงื่อนไขเพิ่มว่า x แต่ละตัวจับคู่กับ y ได้เพียงค่าเดียว ถ้ามี x ตัวเดียวกันคู่กับ y สองค่า เช่น (2, 3) และ (2, 5) จะไม่เป็นฟังก์ชัน บนกราฟตรวจด้วยการลากเส้นแนวตั้ง ถ้าเส้นใดตัดกราฟมากกว่าหนึ่งจุดแสดงว่าไม่เป็นฟังก์ชัน

    หาโดเมนของฟังก์ชันอย่างไรให้ครบ?

    ไล่ดูสามจุดที่ทำให้ฟังก์ชันไม่นิยามในจำนวนจริง: ตัวส่วนต้องไม่เป็นศูนย์ สิ่งที่อยู่ในรากคู่ต้องไม่ติดลบ และสิ่งที่อยู่ใน log ต้องเป็นบวก แล้วนำเงื่อนไขทั้งหมดมาทำอินเตอร์เซกชัน ถ้าไม่มีสามกรณีนี้เลยโดเมนคือจำนวนจริงทั้งหมด

    f∘g กับ g∘f เท่ากันไหม?

    โดยทั่วไปไม่เท่ากัน f∘g หมายถึงทำ g ก่อนแล้วนำผลไปเข้า f เช่น f(x) = √(x + 2), g(x) = x² − 1 ได้ f∘g = √(x² + 1) แต่ g∘f = x + 1 เมื่อ x ≥ −2 ทั้งสูตรและโดเมนต่างกัน โดเมนของ f∘g คือ x ที่อยู่ในโดเมนของ g และทำให้ g(x) อยู่ในโดเมนของ f

    อัตราการเปลี่ยนแปลงเฉลี่ยเกี่ยวกับแคลคูลัสอย่างไร?

    อัตราการเปลี่ยนแปลงเฉลี่ย (f(b) − f(a))/(b − a) คือความชันของเส้นตัดโค้งที่ลากผ่านสองจุดบนกราฟ เมื่อให้ b เข้าใกล้ a เส้นตัดจะกลายเป็นเส้นสัมผัส และความชันนั้นคืออนุพันธ์ ผลหารเชิงผลต่าง (f(x + h) − f(x))/h ที่ฝึกในหน้านี้จึงเป็นนิยามของอนุพันธ์เมื่อ h → 0
