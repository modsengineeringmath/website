ตารางสถิติคือเครื่องมือที่ทำให้คำถาม “ค่านี้หายากแค่ไหน” ตอบได้โดยไม่ต้องอินทิเกรตฟังก์ชันความหนาแน่นเอง หน้านี้รวบรวมตารางที่ใช้บ่อยที่สุดตั้งแต่ ม.6 จนถึงสถิติวิศวกรรมในมหาวิทยาลัย ได้แก่ ตาราง z สองแบบ ตาราง t ตารางไคกำลังสอง และตาราง F ที่สองระดับนัยสำคัญ ทุกตารางมีวิธีอ่าน ตัวอย่างที่ใช้จริง และช่องค้นหาที่ไฮไลต์ค่าที่ต้องการ หัวตารางค้างอยู่เมื่อเลื่อนบนโทรศัพท์ และด้านบนมีเครื่องคิดค่า p กับค่าวิกฤตสำหรับค่าที่ไม่มีในตาราง

สรุปใน 30 วินาที

- ตาราง Φ(z): พื้นที่ทางซ้ายของ z · $\Phi(-z) = 1 - \Phi(z)$

- ตาราง 0 ถึง z (แบบ ม.6) = $\Phi(z) - 0.5$

- t: ใช้เมื่อประมาณ σ ด้วย s, df = n − 1 · แถว ∞ = ค่า z

- χ²: ทดสอบภาวะสารูปสนิทดีและความเป็นอิสระ · F: เทียบความแปรปรวนและ ANOVA

- ค่าวิกฤตที่ใช้บ่อย: $z_{0.025} = 1.96$, $z_{0.05} = 1.645$, $z_{0.005} = 2.576$

## เครื่องคิดค่า p และค่าวิกฤต

## คำถามที่พบบ่อย

ตาราง z แบบ Φ(z) กับแบบพื้นที่ 0 ถึง z ต่างกันอย่างไร?
ตาราง Φ(z) ให้พื้นที่ทางซ้ายทั้งหมดของ z (ความน่าจะเป็นสะสม) เป็นแบบที่ใช้ในหนังสือสถิติมหาวิทยาลัยและต่างประเทศ ส่วนตารางพื้นที่ 0 ถึง z ให้เฉพาะพื้นที่ระหว่างค่าเฉลี่ยกับ z ซึ่งใช้ในหนังสือ ม.6 ของไทย สองตารางต่างกันอยู่ 0.5 พอดี: Φ(z) = 0.5 + พื้นที่ 0 ถึง z เมื่อ z เป็นบวก

อ่านตาราง z อย่างไร?
แยก z เป็นสองส่วน หลักหน่วยและทศนิยมตำแหน่งแรกอ่านจากแถว ทศนิยมตำแหน่งที่สองอ่านจากคอลัมน์ เช่น z = 1.96 ดูแถว 1.9 คอลัมน์ 0.06 ได้ Φ(1.96) = 0.9750 หรือพิมพ์ 1.96 ในช่องค้นหาเหนือตาราง ค่าจะถูกไฮไลต์ให้

ตาราง t ใช้เมื่อใดแทนตาราง z?
ใช้เมื่อไม่รู้ส่วนเบี่ยงเบนมาตรฐานของประชากรและต้องประมาณด้วย s จากตัวอย่าง โดยเฉพาะตัวอย่างขนาดเล็ก องศาอิสระคือ n − 1 เมื่อ df ใหญ่ขึ้นค่า t จะเข้าใกล้ค่า z แถว ∞ ของตาราง t จึงเท่ากับค่าวิกฤต z
