    คำถามที่พบบ่อย

    จุดเว้น (hole) กับเส้นกำกับแนวดิ่งต่างกันอย่างไร?

    ทั้งสองเกิดจากค่าที่ทำให้ตัวส่วนเป็นศูนย์ ถ้าตัวประกอบนั้นตัดกับตัวเศษได้หมด กราฟจะมีแค่จุดโปร่งหนึ่งจุด (จุดเว้น) เพราะค่าฟังก์ชันรอบ ๆ ยังเข้าใกล้ค่าจำกัด ถ้าตัดแล้วยังเหลือตัวประกอบนั้นในตัวส่วน ค่าฟังก์ชันจะพุ่งไปอนันต์และเกิดเส้นกำกับแนวดิ่ง

    จำกฎเส้นกำกับแนวนอนอย่างไร?

    เทียบดีกรีเศษ n กับดีกรีส่วน m: n < m ได้ y = 0 · n = m ได้ y = อัตราส่วนสัมประสิทธิ์นำ · n > m ไม่มีเส้นกำกับแนวนอน และถ้า n = m + 1 จะมีเส้นกำกับแนวเฉียงจากผลหารของการหารยาว

    กราฟตัดเส้นกำกับแนวนอนได้ไหม?

    ได้ เส้นกำกับแนวนอนบอกพฤติกรรมเมื่อ x ไปอนันต์เท่านั้น ตรงกลางกราฟตัดได้ ตรวจโดยแก้สมการ f(x) = L ถ้ามีคำตอบก็ตัด แต่กราฟไม่มีทางตัดเส้นกำกับแนวดิ่งเพราะ x ตรงนั้นไม่อยู่ในโดเมน

    ทำไมแก้อสมการตรรกยะด้วยการคูณตัวส่วนแล้วผิด?

    ตัวส่วนอาจเป็นบวกหรือลบขึ้นกับ x การคูณด้วยค่าลบทำให้เครื่องหมายอสมการต้องกลับ ให้ย้ายข้างจนอีกข้างเป็นศูนย์ รวมเป็นเศษส่วนเดียว แล้วใช้ตารางเครื่องหมาย ค่าที่ทำให้ตัวส่วนเป็นศูนย์ไม่ใช่คำตอบเสมอ

    คณิตศาสตร์วิศวกรรมที่เข้าใจจริง ไม่ใช่ท่องสูตร

    เว็บไซต์ หน้าแรก คลังความรู้ อัปเดตล่าสุด · บันทึกการปรับปรุง บทความแยกหมวด: Python ยุค AI เมทริกซ์ ลำดับและอนุกรม Laplace ฯลฯ Articles in English เฉลยโจทย์ทีละขั้น: อินทิเกรต อนุพันธ์ ลาปลาซ ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม (ครบชุด) อนุกรมเทย์เลอร์และแมคลอริน อนุกรมโลรองต์และเรซิดิว แนวข้อสอบลำดับและอนุกรม เครื่องคิดเลขลำดับและอนุกรม พร้อมวิธีทำ อุปนัยเชิงคณิตศาสตร์ อุปนัยแบบเข้ม (Strong Induction) อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ แรงก์ (ค่าลำดับขั้น) ของเมทริกซ์ ผลเฉลยเชิงตัวเลข: LU จาโคบี เกาส์-ไซเดล แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ คราเมอร์ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค
