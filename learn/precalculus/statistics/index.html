    คำถามที่พบบ่อย

    ส่วนเบี่ยงเบนมาตรฐานของประชากรกับของตัวอย่างต่างกันอย่างไร?

    ของประชากร (σ) หารด้วย N คือจำนวนข้อมูลทั้งหมด ส่วนของตัวอย่าง (s) หารด้วย n − 1 เพราะใช้ค่าเฉลี่ยตัวอย่างแทนค่าเฉลี่ยจริง ทำให้ผลรวมกำลังสองเล็กไปเล็กน้อย การหาร n − 1 ชดเชยส่วนนี้ ถ้าข้อมูลคือทั้งหมดที่สนใจใช้ σ ถ้าเป็นตัวอย่างที่ใช้ประมาณกลุ่มใหญ่ใช้ s

    หาควอร์ไทล์ของข้อมูลดิบอย่างไร?

    เรียงข้อมูลจากน้อยไปมาก ตำแหน่งของ Q_r คือ r(n + 1)/4 ถ้าเป็นจำนวนเต็มอ่านค่าตรงตำแหน่งนั้น ถ้ามีเศษให้ประมาณค่าระหว่างสองตำแหน่งที่อยู่ติดกัน วิธีนี้ใช้ในหนังสือเรียน สสวท. และในเครื่องคิดเลขของหน้านี้ โปรแกรมบางตัวใช้นิยามอื่นจึงอาจได้ค่าต่างกันเล็กน้อย

    ค่ามาตรฐาน z ใช้ทำอะไร?

    z บอกว่าข้อมูลอยู่ห่างจากค่าเฉลี่ยกี่เท่าของส่วนเบี่ยงเบนมาตรฐาน ใช้เปรียบเทียบข้อมูลต่างชุดที่มีหน่วยหรือการกระจายต่างกัน เช่น คะแนนคณิตกับฟิสิกส์ และใช้เปิดตาราง z หาพื้นที่ใต้เส้นโค้งปกติ

    r ใกล้ 1 แปลว่า x เป็นสาเหตุของ y หรือไม่?

    ไม่ใช่ สหสัมพันธ์วัดเพียงความสัมพันธ์เชิงเส้น ไม่ได้บอกเหตุและผล ตัวแปรสองตัวอาจสัมพันธ์กันเพราะมีตัวแปรที่สามเป็นเหตุร่วม หรือเป็นความบังเอิญ นอกจากนี้ r ใกล้ 0 ไม่ได้แปลว่าไม่สัมพันธ์ อาจสัมพันธ์แบบไม่เป็นเส้นตรงก็ได้
