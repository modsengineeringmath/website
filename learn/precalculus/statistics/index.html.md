# สถิติ: ค่ากลาง การกระจาย ควอร์ไทล์ แผนภาพกล่อง ค่ามาตรฐาน z การแจกแจงปกติ สหสัมพันธ์ และการถดถอยเชิงเส้น

// บทที่ 27.15 · พรีแคลคูลัส · Statistics


สถิติเชิงพรรณนาตอบคำถามสามข้อเกี่ยวกับข้อมูลชุดหนึ่ง: ข้อมูลส่วนใหญ่อยู่แถวไหน (ค่ากลาง) กระจายกว้างแค่ไหน (การกระจาย) และมีรูปร่างอย่างไร (ฮิสโทแกรม แผนภาพกล่อง) จากนั้นการแจกแจงปกติช่วยตอบว่าค่าหนึ่งหายากแค่ไหน และการถดถอยเชิงเส้นช่วยพยากรณ์ตัวแปรหนึ่งจากอีกตัวแปร หน้านี้อธิบายแต่ละค่าว่าวัดอะไร คำนวณอย่างไรทั้งข้อมูลดิบและข้อมูลแจกแจงความถี่ และเลือกใช้ค่าไหนเมื่อใด เครื่องคิดเลขสถิติด้านล่างรับข้อมูลที่วางจากสเปรดชีตได้ทันที

สรุปใน 30 วินาที

- $\bar x = \tfrac{\sum x}{n}$ · มัธยฐานตำแหน่ง $\tfrac{n+1}{2}$ · ฐานนิยมคือค่าที่ซ้ำมากที่สุด

- $\sigma = \sqrt{\tfrac{\sum(x - \mu)^2}{N}}$ · $s = \sqrt{\tfrac{\sum(x - \bar x)^2}{n - 1}}$

- $Q_r$ ตำแหน่ง $\tfrac{r(n+1)}{4}$ · ค่าผิดปกติอยู่นอก $Q_1 - 1.5\,IQR$ ถึง $Q_3 + 1.5\,IQR$

- $z = \tfrac{x - \mu}{\sigma}$ · ปกติ: 68% ใน ±1σ, 95% ใน ±2σ, 99.7% ใน ±3σ

- $\hat y = a + bx$, $b = \tfrac{S_{xy}}{S_{xx}}$, $r = \tfrac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}$

## ค่ากลางของข้อมูล

ค่าเฉลี่ยเลขคณิตใช้ข้อมูลทุกค่าจึงไวต่อค่าสุดโต่ง ถ้าเงินเดือนของพนักงานสิบคนมีผู้บริหารหนึ่งคนที่ได้มากเป็นพิเศษ ค่าเฉลี่ยจะสูงเกินจริง มัธยฐานซึ่งเป็นค่าตรงกลางจะบอกภาพที่ตรงกว่า ฐานนิยมเหมาะกับข้อมูลเชิงคุณภาพ เช่น ไซซ์เสื้อที่ขายดีที่สุด สำหรับข้อมูลที่แจกแจงความถี่เป็นอันตรภาคชั้น เราใช้จุดกึ่งกลางชั้นแทนข้อมูลทุกค่าในชั้นนั้น

D1 Mean ค่าเฉลี่ยเลขคณิต

$$\bar x = \frac{\sum x_i}{n},\qquad \bar x_w = \frac{\sum w_i x_i}{\sum w_i},\qquad \bar x \approx \frac{\sum f_i m_i}{\sum f_i}\ \ (\text{จุดกึ่งกลางชั้น } m_i)$$

D2 Median มัธยฐาน

$$\text{ตำแหน่ง } \frac{n + 1}{2},\qquad \text{แจกแจงความถี่: } L + \left(\frac{N/2 - F}{f}\right)I$$

L ขอบล่างชั้นมัธยฐาน · F ความถี่สะสมก่อนชั้น · f ความถี่ชั้น · I ความกว้างชั้น

## การกระจาย ควอร์ไทล์ และแผนภาพกล่อง

ข้อมูลสองชุดที่มีค่าเฉลี่ยเท่ากันอาจต่างกันมาก เช่น เครื่องจักรที่ผลิตชิ้นงานยาวเฉลี่ย 50 mm ทั้งคู่ แต่เครื่องหนึ่งคลาดเคลื่อน ±0.1 mm อีกเครื่อง ±2 mm ส่วนเบี่ยงเบนมาตรฐานวัดระยะห่างเฉลี่ยจากค่ากลางในหน่วยเดียวกับข้อมูล ส่วนควอร์ไทล์แบ่งข้อมูลที่เรียงแล้วเป็นสี่ส่วนเท่ากัน และแผนภาพกล่องแสดงห้าค่า (ต่ำสุด Q₁ มัธยฐาน Q₃ สูงสุด) ในรูปเดียว ทำให้เห็นความเบ้และค่าผิดปกติทันที

D3 Variance & SD ความแปรปรวนและ SD

$$\sigma^2 = \frac{\sum(x - \mu)^2}{N} = \frac{\sum x^2}{N} - \mu^2,\qquad s^2 = \frac{\sum(x - \bar x)^2}{n - 1}$$

D4 Quartiles ควอร์ไทล์ · เปอร์เซ็นไทล์

$$Q_r:\ \frac{r(n + 1)}{4},\qquad P_r:\ \frac{r(n + 1)}{100},\qquad IQR = Q_3 - Q_1$$

D5 Outliers & box plot ค่าผิดปกติ

$$x Q_3 + 1.5\,IQR$$

D6 CV & transforms สัมประสิทธิ์การแปรผัน

$$CV = \frac{s}{\bar x}\times100\%,\qquad y = ax + b \Rightarrow \bar y = a\bar x + b,\ s_y = |a|s_x$$

## ค่ามาตรฐาน z และการแจกแจงปกติ

## สหสัมพันธ์และการถดถอยเชิงเส้น

เมื่อมีข้อมูลเป็นคู่ เช่น ชั่วโมงอ่านหนังสือกับคะแนน แผนภาพการกระจายช่วยดูว่าสองตัวแปรสัมพันธ์กันแบบเส้นตรงหรือไม่ สัมประสิทธิ์สหสัมพันธ์ r อยู่ระหว่าง −1 ถึง 1 บอกทั้งทิศและความแรง ส่วนเส้นถดถอยแบบกำลังสองน้อยที่สุดคือเส้นตรงที่ทำให้ผลรวมกำลังสองของระยะแนวตั้งจากจุดถึงเส้นน้อยที่สุด ใช้พยากรณ์ y จาก x ภายในช่วงของข้อมูล

D9 Regression & correlation ถดถอยและสหสัมพันธ์

$$S_{xy} = \sum xy - \frac{\sum x\sum y}{n},\ \ b = \frac{S_{xy}}{S_{xx}},\ \ a = \bar y - b\bar x,\ \ r = \frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}$$
