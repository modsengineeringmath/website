- เรียงเป็นวงกลม $(n - 1)!$ · ของซ้ำ $\tfrac{n!}{n_1!n_2!\cdots}$

## กฎการบวก กฎการคูณ และแฟกทอเรียล

กฎการคูณบอกว่าถ้างานหนึ่งทำเป็นขั้น ขั้นแรกมี m วิธี ขั้นถัดมามี n วิธีไม่ว่าขั้นแรกจะเลือกอะไร ทั้งงานมี m × n วิธี กฎการบวกใช้เมื่อเลือกได้ทางเดียวจากหลายทางที่ไม่ซ้อนกัน การเรียงของ n ชิ้นทั้งหมดใช้กฎการคูณซ้ำได้ $n \times (n - 1) \times \cdots \times 1 = n!$ ซึ่งโตเร็วมาก 10! ก็เกินสามล้านแล้ว

C1 Counting principles กฎการคูณและแฟกทอเรียล

$$n(A \text{ แล้ว } B) = n(A)\cdot n(B),\qquad n! = n(n - 1)\cdots 2\cdot 1,\quad 0! = 1$$

- (ก) แต่ละหลักเลือกได้ 10 แบบ: $10^4$

- (ข) หลักแรก 10 หลักที่สอง 9 …: $10\cdot9\cdot8\cdot7 = P(10, 4)$

## การเรียงสับเปลี่ยนและการจัดหมู่

การเรียงสับเปลี่ยนนับแบบที่ลำดับสำคัญ การจัดหมู่นับแบบที่ลำดับไม่สำคัญ ทุกกลุ่ม r ชิ้นเรียงได้ r! แบบ จำนวนการจัดหมู่จึงเท่ากับจำนวนการเรียงสับเปลี่ยนหารด้วย r! การเรียงรอบโต๊ะกลมต้องหารด้วย n เพราะการหมุนทั้งวงไม่ทำให้เกิดแบบใหม่ ส่วนการเรียงของที่มีชิ้นซ้ำต้องหารด้วยจำนวนวิธีสลับชิ้นที่เหมือนกัน

C2 Permutations การเรียงสับเปลี่ยน

$$P(n, r) = {}_nP_r = \frac{n!}{(n - r)!}$$

C3 Circular & repeated วงกลมและของซ้ำ

$$\text{วงกลม: } (n - 1)!,\qquad \text{ของซ้ำ: } \frac{n!}{n_1!\,n_2!\cdots n_k!}$$

C4 Combinations การจัดหมู่

$$\binom{n}{r} = {}_nC_r = \frac{n!}{r!\,(n - r)!},\qquad \binom nr = \binom n{n - r}$$

## ทฤษฎีบททวินามและสามเหลี่ยมปาสกาล

เวลากระจาย $(a + b)^n$ แต่ละพจน์เกิดจากการเลือก b จาก k วงเล็บ และ a จากวงเล็บที่เหลือ จำนวนวิธีเลือกคือ $\binom nk$ สัมประสิทธิ์ทวินามจึงเป็นตัวเลขชุดเดียวกับในสามเหลี่ยมปาสกาล ซึ่งแต่ละตัวเท่ากับผลบวกของสองตัวด้านบน โจทย์มาตรฐานคือหาสัมประสิทธิ์ของพจน์ที่ระบุ โดยใช้พจน์ทั่วไป $T_{k+1}$

C5 Binomial theorem ทฤษฎีบททวินาม

$$(a + b)^n = \sum_{k=0}^{n}\binom nk a^{n-k}b^k,\qquad T_{k+1} = \binom nk a^{n-k}b^k,\qquad \binom nk = \binom{n-1}{k-1} + \binom{n-1}{k}$$

## ความน่าจะเป็นพื้นฐาน

เมื่อผลลัพธ์ทุกแบบมีโอกาสเท่ากัน ความน่าจะเป็นของเหตุการณ์คือจำนวนผลลัพธ์ที่ต้องการหารด้วยจำนวนผลลัพธ์ทั้งหมด การนับในหัวข้อก่อนหน้าจึงถูกใช้ตรงนี้ เหตุการณ์ที่ซับซ้อนมักคำนวณง่ายขึ้นจากส่วนเติมเต็ม เช่น “อย่างน้อยหนึ่งครั้ง” คำนวณจาก 1 ลบ “ไม่เกิดเลย” ส่วนกฎการบวกต้องลบส่วนที่ซ้อนกันออกหนึ่งครั้งเพื่อไม่ให้นับซ้ำ

$$P(E) = \frac{n(E)}{n(S)},\quad 0 \le P(E) \le 1,\quad P(E^c) = 1 - P(E)$$

C7 Addition rule กฎการบวก

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

## ความน่าจะเป็นแบบมีเงื่อนไข เหตุการณ์อิสระ และทฤษฎีบทของเบส์

$P(A \mid B)$ คือโอกาสของ A เมื่อรู้แล้วว่า B เกิด เท่ากับการตัดปริภูมิตัวอย่างให้เหลือเฉพาะ B แล้วดูว่าส่วนไหนเป็น A ด้วย ทฤษฎีบทของเบส์ใช้กลับทิศเงื่อนไข เช่น รู้โอกาสที่ผลตรวจเป็นบวกเมื่อป่วย แต่อยากรู้โอกาสที่ป่วยเมื่อผลตรวจเป็นบวก ซึ่งคำตอบมักต่ำกว่าที่คาดมากเมื่อโรคพบน้อย

C8 Conditional มีเงื่อนไขและอิสระ

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)},\qquad A, B \text{ อิสระ} \iff P(A \cap B) = P(A)P(B)$$

C9 Bayes' theorem ทฤษฎีบทของเบส์

$$P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B \mid A)P(A) + P(B \mid A^c)P(A^c)}$$

ตัวอย่าง C-7 · ผลตรวจบวกแต่ไม่ป่วย

### โรคหนึ่งพบ 1% ของประชากร ชุดตรวจให้ผลบวก 95% เมื่อป่วย และให้ผลบวกผิด 5% เมื่อไม่ป่วย ถ้าผลตรวจเป็นบวก โอกาสป่วยจริงเท่าใด

- บวกและป่วย: $0.95 \times 0.01 = 0.0095$ · บวกแต่ไม่ป่วย: $0.05 \times 0.99 = 0.0495$

- $P(\text{ป่วย} \mid +) = \dfrac{0.0095}{0.0095 + 0.0495} = \dfrac{0.0095}{0.059}$

≈ 0.161 หรือประมาณ 16% — ผลบวกส่วนใหญ่มาจากคนไม่ป่วยจำนวนมากที่ตรวจผิด

## ตัวแปรสุ่ม ค่าคาดหมาย และการแจกแจงทวินาม

ตัวแปรสุ่มคือฟังก์ชันที่แปลงผลการทดลองเป็นตัวเลข เช่น จำนวนข้อที่ตอบถูก ค่าคาดหมายคือค่าเฉลี่ยระยะยาวถ้าทำการทดลองซ้ำมาก ๆ ใช้ตัดสินว่าเกมหรือการลงทุนคุ้มหรือไม่ การแจกแจงทวินามเป็นตัวแปรสุ่มที่พบบ่อยที่สุดในระดับนี้ และเมื่อ n ใหญ่ รูปร่างของมันจะเข้าใกล้เส้นโค้งปกติ ลองติ๊กในกราฟด้านล่างเพื่อดูการซ้อนกันของสองรูป

C10 Expected value ค่าคาดหมาย

$$E(X) = \sum x\,P(X = x),\qquad \operatorname{Var}(X) = E(X^2) - \big(E(X)\big)^2$$

C11 Binomial distribution การแจกแจงทวินาม

$$P(X = k) = \binom nk p^k(1 - p)^{n-k},\qquad \mu = np,\quad \sigma^2 = np(1 - p)$$

ตัวอย่าง C-8 · เดาข้อสอบ

### ข้อสอบปรนัย 10 ข้อ ข้อละ 4 ตัวเลือก เดาทุกข้อ โอกาสถูกอย่างน้อย 6 ข้อเท่าใด และคาดว่าถูกกี่ข้อ

- $E(X) = np = 10(0.25)$

$P(X \ge 6) \approx 0.0197$ (ประมาณ 2%) · คาดว่าถูก 2.5 ข้อ

## คำถามที่พบบ่อย

การเรียงสับเปลี่ยนกับการจัดหมู่ต่างกันอย่างไร?
ถามตัวเองว่าลำดับสำคัญไหม ถ้าสลับลำดับแล้วได้ผลต่างกัน เช่น เลือกประธานและเลขา หรือตั้งรหัสผ่าน ให้ใช้การเรียงสับเปลี่ยน P(n, r) ถ้าสลับแล้วยังเป็นกลุ่มเดิม เช่น เลือกกรรมการ 3 คน หรือเลือกไพ่ 5 ใบ ให้ใช้การจัดหมู่ C(n, r) ซึ่งเท่ากับ P(n, r) หารด้วย r!

ทำไม 0! = 1?
เพราะมีวิธีจัดเรียงของศูนย์ชิ้นได้หนึ่งวิธี (ไม่ทำอะไรเลย) และทำให้สูตรใช้ได้ทุกกรณี เช่น C(n, n) = n!/(n! 0!) = 1 และ n! = n·(n − 1)! เมื่อ n = 1 ได้ 1! = 1·0!

เหตุการณ์อิสระกับเหตุการณ์ที่ไม่เกิดร่วมกันต่างกันอย่างไร?
เหตุการณ์ไม่เกิดร่วมกัน (mutually exclusive) คือเกิดพร้อมกันไม่ได้ P(A ∩ B) = 0 ส่วนเหตุการณ์อิสระ (independent) คือการเกิดของเหตุการณ์หนึ่งไม่เปลี่ยนโอกาสของอีกเหตุการณ์ P(A ∩ B) = P(A)P(B) สองแนวคิดนี้แทบตรงข้ามกัน ถ้า A และ B มีโอกาสเกิดและไม่เกิดร่วมกัน รู้ว่า A เกิดก็รู้ทันทีว่า B ไม่เกิด จึงไม่อิสระ

การแจกแจงทวินามใช้เมื่อใด?
ใช้เมื่อทำการทดลองซ้ำ n ครั้งอย่างอิสระ แต่ละครั้งมีผลสองแบบ (สำเร็จ ไม่สำเร็จ) และโอกาสสำเร็จ p เท่ากันทุกครั้ง เช่น เดาข้อสอบปรนัย โยนเหรียญ หรือนับชิ้นงานเสียในล็อต ความน่าจะเป็นที่สำเร็จ k ครั้งคือ C(n, k)pᵏ(1 − p)ⁿ⁻ᵏ ค่าคาดหมาย np

## คำถามที่พบบ่อย (FAQ)

**การเรียงสับเปลี่ยนกับการจัดหมู่ต่างกันอย่างไร?**
ถามตัวเองว่าลำดับสำคัญไหม ถ้าสลับลำดับแล้วได้ผลต่างกัน เช่น เลือกประธานและเลขา หรือตั้งรหัสผ่าน ให้ใช้การเรียงสับเปลี่ยน P(n, r) ถ้าสลับแล้วยังเป็นกลุ่มเดิม เช่น เลือกกรรมการ 3 คน หรือเลือกไพ่ 5 ใบ ให้ใช้การจัดหมู่ C(n, r) ซึ่งเท่ากับ P(n, r) หารด้วย r!
