# พรีแคลคูลัส (Precalculus): ฟังก์ชันและกราฟ ครบ ม.4–ม.6 ก่อนเรียนแคลคูลัส

THภาษาไทยENEnglish

// บทที่ 27 · Precalculus · 16 หน้า · ม.4–ม.6


พรีแคลคูลัสคือคณิตศาสตร์ช่วงที่นักเรียนต้องเปลี่ยนจากการ “แก้สมการให้ได้คำตอบ” ไปเป็นการ “มองสมการให้เห็นเป็นฟังก์ชันและกราฟ” ถ้าข้ามช่วงนี้ไปเร็วเกินไป พอขึ้นมหาวิทยาลัยแล้วเจอลิมิต อนุพันธ์ และอินทิกรัล ปัญหาที่เจอส่วนใหญ่จะไม่ใช่แคลคูลัส แต่เป็นการแยกตัวประกอบไม่คล่อง หาโดเมนไม่เป็น หรือนึกรูปกราฟของลอการิทึมไม่ออก บทนี้จึงรวมเนื้อหาคณิตศาสตร์เพิ่มเติม ม.4–ม.6 ทั้งหมดไว้ 16 หน้า เรียงตามลำดับที่ควรเรียน มีสูตรพร้อมรหัสอ้างอิง 146 สูตร ตัวอย่างแสดงวิธีทำ 106 ข้อ และแล็บโต้ตอบที่เลื่อนค่าแล้วเห็นกราฟเปลี่ยนทันที ซึ่งใช้งานบนโทรศัพท์ได้สะดวก

สรุปใน 30 วินาที

- ทุกหัวข้อในบทนี้คือ “ฟังก์ชันหนึ่งตระกูล” ที่มีโดเมน เรนจ์ จุดตัดแกน เส้นกำกับ และพฤติกรรมปลายกราฟของตัวเอง

- กราฟ $y = a\,f\big(b(x - h)\big) + k$ คือกราฟต้นแบบที่ถูกเลื่อน ยืด และสะท้อน ใช้ได้กับทุกตระกูลตั้งแต่พาราโบลาถึงไซน์

- เอกซ์โพเนนเชียลกับลอการิทึมเป็นตัวผกผันกัน: $b^y = x \iff y = \log_b x$ กราฟจึงสะท้อนกันในเส้น $y = x$

- ฟังก์ชันตรีโกณมิติอ่านจากวงกลมหนึ่งหน่วย: จุดบนวงกลมคือ $(\cos\theta, \sin\theta)$

- ลำดับคือฟังก์ชันบนจำนวนนับ อนุกรมคือผลบวกของลำดับ และสถิติใช้ฟังก์ชันความหนาแน่นอธิบายข้อมูล

## เส้นทางเรียนตามระดับชั้น

ลำดับหน้าในบทนี้ตั้งใจให้แต่ละหน้าใช้ความรู้จากหน้าก่อนหน้าเท่านั้น ถ้าเรียนในโรงเรียนอยู่แล้วให้เปิดหน้าที่ตรงกับเรื่องที่ครูกำลังสอน แต่ถ้ากำลังเตรียมตัวเรียนแคลคูลัสในมหาวิทยาลัย แนะนำให้อ่านส่วนที่ 1 ถึง 4 ให้ครบก่อน เพราะเป็นเนื้อหาที่แคลคูลัส 1 ใช้ทุกสัปดาห์

ม.4 · ปูพื้น

### พีชคณิตและฟังก์ชัน
เลขยกกำลัง แยกตัวประกอบ สมการ-อสมการ โดเมน เรนจ์ ฟังก์ชันประกอบ และการแปลงกราฟ
พีชคณิต → ฟังก์ชัน → กราฟ

ม.4–ม.5 · ตระกูลฟังก์ชัน

### พหุนาม ตรรกยะ ผกผัน เอกซ์โพเนนเชียล ลอการิทึม
รู้จักหน้าตากราฟของทุกตระกูล และอ่านค่าจากกราฟให้เป็น
พหุนาม → ตรรกยะ → ผกผัน → เอกซ์โพเนนเชียล → ลอการิทึม

ม.5 · ตรีโกณมิติ

### วงกลมหนึ่งหน่วยถึงกฎของโคไซน์
เรเดียน กราฟไซน์ การแก้สามเหลี่ยม และตารางค่าที่ค้นหาได้
ฟังก์ชันตรีโกณมิติ → การประยุกต์ → ตาราง

ม.6 · ข้อมูลและโอกาส

### ลำดับ อนุกรม ความน่าจะเป็น สถิติ
สูตรผลบวก การนับ การแจกแจงทวินาม การแจกแจงปกติ และการอ่านตาราง z
ลำดับ → อนุกรม → ความน่าจะเป็น → สถิติ

เตรียมสอบ TCAS · A-Level คณิตศาสตร์ 1ข้อสอบคณิตศาสตร์ประยุกต์ 1 ส่วนใหญ่มาจากฟังก์ชัน เอกซ์โพเนนเชียล-ลอการิทึม ตรีโกณมิติ ลำดับ-อนุกรม ความน่าจะเป็น และสถิติ ทุกหน้าในบทนี้มีแบบฝึกหัดพร้อมเฉลยในหัวข้อ “ฝึกทำ” ท้ายหน้า และมีกรอบ “กับดักที่พบบ่อย” ที่รวบรวมจุดที่นักเรียนเสียคะแนนบ่อยที่สุด

## ลองเลย: ทุกกราฟเกิดจากการแปลงกราฟต้นแบบ

เลือกฟังก์ชันต้นแบบ แล้วลากสไลเดอร์ a, b, h, k ดูว่ากราฟเลื่อน ยืด และสะท้อนอย่างไร แล็บจะบอกลำดับการแปลงเป็นข้อ ๆ บอกว่าจุดบนกราฟเดิมย้ายไปอยู่ที่ใด พร้อมโดเมนและเรนจ์ใหม่ เมื่อเข้าใจแล็บนี้แล้ว กราฟของฟังก์ชันตรรกยะ เอกซ์โพเนนเชียล ลอการิทึม และไซน์ในหน้าต่อ ๆ ไปจะกลายเป็นเรื่องเดียวกันทั้งหมด
