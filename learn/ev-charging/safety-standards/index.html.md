# ความปลอดภัยการชาร์จรถ EV: RCD Type A กับ Type B, กระแสรั่ว DC 6 mA, การต่อลงดิน มาตรฐาน และอาการเสีย

// บทที่ 17.6 · ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน · EV Charging Safety, RCD & Earthing


รถยนต์ไฟฟ้าเป็นกล่องโลหะขนาดใหญ่ที่จอดบนพื้นเปียกได้ ต่อกับไฟบ้านนานหลายชั่วโมง และข้างในมีไฟ DC แรงดันหลายร้อยโวลต์ การป้องกันไฟดูดของบ้านทั่วไปจึงไม่พอเสมอไป หน้านี้อธิบายตั้งแต่ร่างกายรับกระแสได้เท่าไร RCD ทำงานอย่างไร ทำไมต้องสนใจไฟรั่ว DC จนถึงการต่อลงดินและเช็กลิสต์ก่อนใช้งาน

สรุปใน 30 วินาที

- กระแสผ่านร่างกาย 30 mA เป็นเวลานานอาจทำให้หัวใจเต้นผิดจังหวะ → ใช้ RCD 30 mA ตัดภายใน 0.3 s

- RCD วัดผลต่างระหว่างกระแสที่ไปกับที่กลับ ไม่ใช่กระแสรวม

- เครื่องชาร์จอาจรั่วเป็น DC → ต้องใช้ RCD Type B หรือ Type A + ตรวจจับ DC 6 mA (RDC-DD)

- สายดินคุณภาพดีคือเงื่อนไขของทุกอย่าง: เครื่องชาร์จจะไม่จ่ายไฟถ้าไม่มี PE

## ไฟดูดเกิดอย่างไร: ร่างกายกับกระแส พื้นฐาน

P1 Body current กระแสที่ไหลผ่านร่างกาย

$$I_{body} = \frac{U_{touch}}{Z_{body} + R_{shoe} + R_{floor}} \qquad Z_{body} \approx 1\text{–}2\ \text{k}\Omega\ (\text{มือถึงเท้า ผิวเปียก})$$

| กระแส AC 50 Hz (ผ่านลำตัว) | ผลโดยประมาณ (IEC 60479-1) |

| 0.5 mA | เริ่มรู้สึก |

| 5–10 mA | เจ็บ กล้ามเนื้อกระตุก ยังปล่อยมือได้ |

| 10–30 mA | ปล่อยมือไม่ได้ (let-go) หายใจลำบากถ้านาน |

| > 30–50 mA นานพอ | เสี่ยงหัวใจเต้นแผ่นระรัว (ventricular fibrillation) |

ตัวอย่าง P-1

### จับตัวถังที่มีไฟรั่ว 230 V ขณะยืนเท้าเปล่าบนพื้นเปียก

- P1: $I \approx 230/1000 = 0.23\ \text{A} = 230\ \text{mA}$

- สูงกว่าเกณฑ์อันตราย 30 mA เกือบ 8 เท่า — ต้องตัดไฟให้เร็วมาก หรือไม่ให้ตัวถังมีแรงดันตั้งแต่แรก

- สองชั้นของการป้องกัน: (1) สายดินทำให้ไฟรั่วไหลลงดินและแรงดันสัมผัสต่ำ (2) RCD ตรวจไฟรั่วแล้วตัดภายในเสี้ยววินาที

## RCD (เครื่องตัดไฟรั่ว) ทำงานอย่างไร พื้นฐาน

สายไฟเฟส (L) และนิวทรัล (N) ลอดผ่านแกนเหล็กรูปวงแหวนเดียวกัน ปกติกระแสไปเท่ากับกระแสกลับ สนามแม่เหล็กหักล้างกันเป็นศูนย์ ถ้ามีกระแสส่วนหนึ่งรั่วลงดิน (ผ่านคนหรือสายดิน) กระแสสองเส้นไม่เท่ากัน แกนเหล็กเกิดฟลักซ์ ขดลวดตรวจจับเหนี่ยวนำแรงดันไปปลดกลไกตัดไฟ

P2 Residual current กระแสผลต่างที่ RCD วัด

$$i_{\Delta}(t) = i_L(t) + i_N(t)\ \ (1\varphi) \qquad i_{\Delta} = i_{L1}+i_{L2}+i_{L3}+i_N\ \ (3\varphi) \qquad \text{ตัดเมื่อ } I_{\Delta} \ge (0.5\text{–}1)\,I_{\Delta n}$$

กระแส $i_L$ และ $i_N$ นิยามทิศเข้าหาโหลดทั้งคู่ ผลรวมจึงเป็นศูนย์เมื่อไม่มีไฟรั่ว RCD 30 mA ต้องตัดภายใน 0.3 s ที่ $I_{\Delta n}$ และภายใน 0.04 s ที่ $5I_{\Delta n}$ สังเกตว่า RCD ไม่ป้องกันการแตะ L กับ N พร้อมกัน (กระแสไปกลับเท่ากัน) และไม่ป้องกันกระแสเกิน — ต้องมีเบรกเกอร์ด้วย

## RCD Type AC, A, F, B และ RDC-DD 6 mA กลาง

| ชนิด | ตรวจจับไฟรั่วรูปแบบ | ใช้กับเครื่องชาร์จรถ |

| Type AC | ไซน์ AC เท่านั้น | ✗ ห้ามใช้ |

| Type A | AC + DC เป็นลูก ๆ (pulsating) + DC เรียบไม่เกิน 6 mA | ได้ เมื่อร่วมกับ RDC-DD 6 mA |

| Type F | เหมือน A + ความถี่ผสม (อินเวอร์เตอร์ 1 เฟส) | ได้ เมื่อร่วมกับ RDC-DD 6 mA |

| Type B | ทุกแบบ รวม DC เรียบ และความถี่สูงถึง ~1 kHz | ✓ ใช้เดี่ยวได้ |

| RDC-DD (IEC 62955) | ตรวจเฉพาะ DC เรียบ ตัดที่ 6 mA | มักอยู่ในวอลล์บ็อกซ์/สายพกพา ใช้คู่กับ Type A |

P3 DC blinding limit ขีดกระแสรั่ว DC ที่ RCD Type A ยังทำงานได้

$$I_{\Delta,DC} \le 6\ \text{mA} \;\Rightarrow\; \text{Type A ยังตัด AC ได้} \qquad I_{\Delta,DC} > 6\ \text{mA} \;\Rightarrow\; \text{ต้องตัดด้วย RDC-DD หรือใช้ Type B}$$

ทำไม DC ทำให้ RCD ตาบอด แกนเหล็กของ RCD ถูกออกแบบให้ไวต่อการเปลี่ยนฟลักซ์ กระแส DC สร้างฟลักซ์คงที่ดันแกนให้ใกล้อิ่มตัว ความชัน $dB/dH$ ลดลง เมื่อมีไฟรั่ว AC ซ้อนขึ้นมา ฟลักซ์เปลี่ยนน้อยจนขดตรวจจับเหนี่ยวนำแรงดันไม่พอตัดไฟ เครื่องชาร์จในรถมีวงจรเรียงกระแสและ PFC ถ้าฉนวนเสียฝั่ง DC กระแสรั่วจะเป็น DC เรียบ — นี่คือเหตุที่มาตรฐาน EV ต้องการการตรวจจับ DC เสมอ

อย่าวาง RCD Type A ต้นทางของ RCD Type B ถ้าตู้ไฟบ้านมี RCD Type A คุมทั้งตู้ (กันดูดเมน) แล้ววงจรรถใช้ Type B อยู่ปลายทาง กระแสรั่ว DC ยังไหลผ่าน Type A ต้นทางและทำให้มันตาบอดได้ ให้แยกวงจรรถออกจาก RCD ต้นทางชนิด A หรือใช้ Type B ที่ต้นทาง

## การต่อลงดิน: TN-C-S, TT และปัญหา PEN ขาด กลาง

บ้านในไทยส่วนใหญ่ต่อลงดินแบบ TN-C-S: ระบบจำหน่ายใช้สายนิวทรัลร่วมเป็นสายดิน (PEN) และที่ตู้เมนของบ้านแยกออกเป็น N กับ PE โดยต่อถึงหลักดินที่ตู้เมน ข้อดีคือกระแสลัดลงดินสูง เบรกเกอร์ตัดเร็ว ข้อเสียที่สำคัญกับรถ EV คือ ถ้าสาย PEN ในระบบจำหน่ายขาด PE ในบ้าน (และตัวถังรถที่ต่อกับ PE) อาจลอยขึ้นมามีแรงดันหลายสิบถึงเกือบ 230 V เทียบกับพื้นดินที่ยืน

P4 TT-system touch-voltage condition เงื่อนไขระบบ TT

$$R_A \times I_{\Delta n} \le 50\ \text{V} \qquad (R_A = \text{ความต้านทานหลักดิน + สาย PE ของผู้ใช้ไฟ})$$

มาตรฐาน IEC 60364-7-722 จึงกำหนดมาตรการสำหรับจุดชาร์จกลางแจ้งในระบบ TN เช่น ทำจุดชาร์จเป็นระบบ TT แยกหลักดิน หรือใช้เครื่องชาร์จที่ตรวจจับ PEN ขาด (open-PEN detection) แล้วตัดทุกขั้วรวม PE วอลล์บ็อกซ์หลายรุ่นมีฟังก์ชันนี้ในตัว — เป็นข้อที่ควรถามก่อนซื้อ

P5 Earth-rod resistance (Dwight) ความต้านทานหลักดินแท่งเดียว

$$R_{rod} = \frac{\rho}{2\pi L}\left[\ln\frac{8L}{d} - 1\right] \qquad \rho = \text{สภาพต้านทานดิน } (\Omega\,\text{m})$$

ตัวอย่าง P-2

### หลักดิน 2.4 m เส้นผ่านศูนย์กลาง 16 mm ในดิน 100 Ω·m

- P5: $\dfrac{100}{2\pi(2.4)} = 6.63$ · $\ln\dfrac{8(2.4)}{0.016} - 1 = \ln 1200 - 1 = 6.09$

- $R = 6.63 \times 6.09 = 40\ \Omega$ — สูงกว่าเกณฑ์ 5 Ω ของ วสท. มาก

- วิธีลด: ตอกหลักดินเพิ่มขนานกัน ห่างกันอย่างน้อยความยาวหลัก ตอกลึกขึ้น (R ลดเกือบตาม 1/L) หรือใช้สารปรับปรุงดิน ดินเหนียวชื้น (ρ ≈ 10–30 Ω·m) ทำได้ง่ายกว่าดินทราย (ρ ≈ 200–1000 Ω·m)

ตัวอย่าง P-3

### จุดชาร์จแบบ TT ใช้หลักดิน 40 Ω กับ RCD 30 mA ได้ไหม

- P4: $40 \times 0.03 = 1.2\ \text{V} \le 50\ \text{V}$ ✓ ผ่านเงื่อนไขระบบ TT อย่างสบาย

- แต่ระบบ TT กระแสลัดลงดินมีแค่ราว $230/(40+2) \approx 5.5$ A เบรกเกอร์ 40 A ไม่ตัด — การป้องกันขึ้นกับ RCD ทั้งหมด ต้องทดสอบ RCD เป็นประจำ

- ลองเปรียบเทียบ TN-C-S กับ TT ในเครื่องคำนวณด้านล่าง

อ่านทฤษฎีการต่อลงดินเต็มรูปแบบที่ ระบบการต่อลงดินและการป้องกันไฟดูด

## การป้องกันอื่น: ฟ้าผ่า IP และความร้อน พื้นฐาน

- อุปกรณ์ป้องกันแรงดันเกิน (SPD) Type 2 ที่ตู้ไฟ ปกป้องวอลล์บ็อกซ์และ OBC จากฟ้าผ่าใกล้ ๆ และการสวิตชิ่งในระบบ

- IP อย่างน้อย IP44 สำหรับติดในที่มีหลังคา IP54–IP65 สำหรับกลางแจ้ง หัวชาร์จที่ไม่ได้ใช้ให้เก็บในที่เก็บหัว

- ขั้วต่อ ขันแน่นด้วยแรงบิดตามคู่มือ (torque) ตรวจซ้ำหลังใช้งาน 1 เดือน ขั้วหลวมคือสาเหตุอันดับหนึ่งของความร้อนในตู้

- พื้นที่ติดตั้ง ไม่ติดใกล้วัสดุไวไฟ ระยะสายชาร์จไม่พาดผ่านทางเดินที่รถทับ

| IEC 60364-7-722 | การติดตั้งไฟฟ้าสำหรับจุดชาร์จ: วงจรเฉพาะ RCD ชนิด การป้องกัน PEN ขาด |

| ข้อกำหนด กฟน. / กฟภ. | เงื่อนไขขอใช้ไฟ ขนาดมิเตอร์ อุปกรณ์ที่ยอมรับ |

## เช็กลิสต์ก่อนใช้งานจริง

- วงจรเฉพาะ ขนาดเบรกเกอร์และสายตามการคำนวณ (H5–H9)

- RCD 30 mA ที่ถูกชนิด (Type B หรือ Type A + RDC-DD) กดปุ่ม Test แล้วตัดจริง

- วัดค่าความต้านทานหลักดิน และวัดความต่อเนื่องของ PE ถึงตัวเครื่องชาร์จ

- วัดความต้านทานฉนวนของสายใหม่ (ปลดเครื่องชาร์จก่อน)

- ตรวจขั้ว L–N–PE ถูกต้อง ไม่สลับ

- ทดลองชาร์จเต็มกระแส 1 ชั่วโมง วัดอุณหภูมิขั้วต่อในตู้และในวอลล์บ็อกซ์ (ไม่ควรเกิน ~ 30 °C เหนืออุณหภูมิห้อง)

- ตั้งค่ากระแสสูงสุดของวอลล์บ็อกซ์ให้ตรงกับเบรกเกอร์ (เช่น 32 A กับเบรกเกอร์ 40 A)

- เก็บเอกสาร: ผังวงจร ผลทดสอบ ใบรับรองช่าง

## ตารางอาการเสียที่พบบ่อย

| อาการ | สาเหตุที่น่าจะเป็น | วิธีตรวจ |

| เสียบแล้วเครื่องชาร์จขึ้น “Earth fault / No ground” | เต้ารับไม่มีสายดิน สาย PE หลุด หลักดินสูงมาก | วัดความต่อเนื่อง PE วัดแรงดัน N–PE (ปกติ < 5 V) |

| RCD ตัดทันทีที่เริ่มชาร์จ | ฉนวนสายชื้น โหลดอื่นรั่วสะสมบนวงจรเดียวกัน RCD ไวเกิน | แยกวงจร วัดฉนวน เปลี่ยน RCD ให้ถูกชนิด |

| RCD ตัดเป็นพัก ๆ ตอนฝนตก | น้ำเข้าเต้ารับ/กล่องต่อ IP ไม่พอ | ตรวจซีลและท่อ ร้อยสายเข้ากล่องจากด้านล่าง |

| เมนเบรกเกอร์ทริปหัวค่ำ | รถ + แอร์ + น้ำอุ่น เกินพิกัด | ลดกระแสชาร์จ ตั้งเวลา load balancing (W6) |

| ชาร์จได้กระแสน้อยกว่าที่ตั้ง | OBC ของรถจำกัด สายชาร์จพิกัดต่ำ แรงดันตก อุณหภูมิสูงจนเครื่องลดกำลัง | ดูค่าบนแอปรถ ตรวจ PP วัดแรงดันขณะชาร์จ |

| ปลั๊ก/ขั้วต่อร้อน มีกลิ่น | หน้าสัมผัสหลวม เต้ารับเสื่อม | หยุดใช้ทันที เปลี่ยนเต้ารับ ขันขั้วใหม่ (M3) |

| ไฟบ้านกะพริบขณะชาร์จ | แรงดันตกในสายเมนหรือขั้วต่อหลวม | วัดแรงดันที่มิเตอร์และที่ตู้ขณะชาร์จ เทียบกัน |

## คำถามที่พบบ่อย

ชาร์จรถ EV ต้องใช้ RCD Type B เสมอไหม?
ต้องมีการป้องกันกระแสรั่วแบบ DC แต่ไม่จำเป็นต้องเป็น RCD Type B ที่ตู้เสมอไป ทางเลือกที่มาตรฐาน IEC 60364-7-722 ยอมรับคือ RCD Type B หรือ RCD Type A (หรือ F) ร่วมกับอุปกรณ์ตรวจจับกระแสรั่ว DC 6 mA (RDC-DD ตาม IEC 62955) ซึ่งวอลล์บ็อกซ์รุ่นใหม่ส่วนใหญ่มีในตัว ให้ดูดาต้าชีตของเครื่องชาร์จและข้อกำหนดของการไฟฟ้าในพื้นที่

ทำไม RCD Type AC ใช้กับเครื่องชาร์จรถไม่ได้?
เครื่องชาร์จในรถมีวงจรเรียงกระแส ถ้าฉนวนเสียฝั่ง DC กระแสรั่วจะเป็นไฟ DC เรียบหรือ DC เป็นลูก ๆ RCD Type AC ตรวจได้เฉพาะไฟรั่วรูปไซน์ และกระแส DC ยังทำให้แกนเหล็กของ RCD อิ่มตัวจนตัดไฟรั่ว AC ไม่ได้ด้วย จึงอันตรายแม้มีไฟรั่วจริง

ค่าความต้านทานหลักดินที่บ้านควรเป็นเท่าไร?
มาตรฐานการติดตั้งทางไฟฟ้าของไทย (วสท.) กำหนดความต้านทานระหว่างหลักดินกับดินไว้ไม่เกิน 5 โอห์มสำหรับระบบทั่วไป (มีเงื่อนไขผ่อนผันในพื้นที่ที่ทำได้ยาก) หลักดินแท่งเดียวยาว 2.4 เมตรในดินทั่วไปมักได้ 10–50 โอห์ม จึงมักต้องเพิ่มหลักดินหรือตอกลึกขึ้น วัดด้วยเครื่องวัดความต้านทานดินหลังติดตั้ง
