ความปลอดภัยการชาร์จรถ EV: RCD Type A กับ Type B, กระแสรั่ว DC 6 mA, การต่อลงดิน มาตรฐาน และอาการเสีย

รถยนต์ไฟฟ้าเป็นกล่องโลหะขนาดใหญ่ที่จอดบนพื้นเปียกได้ ต่อกับไฟบ้านนานหลายชั่วโมง และข้างในมีไฟ DC แรงดันหลายร้อยโวลต์ การป้องกันไฟดูดของบ้านทั่วไปจึงไม่พอเสมอไป หน้านี้อธิบายตั้งแต่ร่างกายรับกระแสได้เท่าไร RCD ทำงานอย่างไร ทำไมต้องสนใจไฟรั่ว DC จนถึงการต่อลงดินและเช็กลิสต์ก่อนใช้งาน

เขียนโดย อาจารย์มดอัปเดต 13 ต.ค. 2569
RCD ทำงานอย่างไร Type A · B · RDC-DD การต่อลงดิน เช็กลิสต์ อาการเสีย
สรุปใน 30 วินาที
  • กระแสผ่านร่างกาย 30 mA เป็นเวลานานอาจทำให้หัวใจเต้นผิดจังหวะ → ใช้ RCD 30 mA ตัดภายใน 0.3 s
  • RCD วัดผลต่างระหว่างกระแสที่ไปกับที่กลับ ไม่ใช่กระแสรวม
  • เครื่องชาร์จอาจรั่วเป็น DC → ต้องใช้ RCD Type B หรือ Type A + ตรวจจับ DC 6 mA (RDC-DD)
  • สายดินคุณภาพดีคือเงื่อนไขของทุกอย่าง: เครื่องชาร์จจะไม่จ่ายไฟถ้าไม่มี PE

สายไฟเฟส (L) และนิวทรัล (N) ลอดผ่านแกนเหล็กรูปวงแหวนเดียวกัน ปกติกระแสไปเท่ากับกระแสกลับ สนามแม่เหล็กหักล้างกันเป็นศูนย์ ถ้ามีกระแสส่วนหนึ่งรั่วลงดิน (ผ่านคนหรือสายดิน) กระแสสองเส้นไม่เท่ากัน แกนเหล็กเกิดฟลักซ์ ขดลวดตรวจจับเหนี่ยวนำแรงดันไปปลดกลไกตัดไฟ

P2 Residual current กระแสผลต่างที่ RCD วัด

กระแส iLi_LiL​ และ iNi_NiN​ นิยามทิศเข้าหาโหลดทั้งคู่ ผลรวมจึงเป็นศูนย์เมื่อไม่มีไฟรั่ว RCD 30 mA ต้องตัดภายใน 0.3 s ที่ IΔnI_{\Delta n}IΔn​ และภายใน 0.04 s ที่ 5IΔn5I_{\Delta n}5IΔn​ สังเกตว่า RCD ไม่ป้องกันการแตะ L กับ N พร้อมกัน (กระแสไปกลับเท่ากัน) และไม่ป้องกันกระแสเกิน — ต้องมีเบรกเกอร์ด้วย

RCD Type AC, A, F, B และ RDC-DD 6 mA กลาง

ชนิดตรวจจับไฟรั่วรูปแบบใช้กับเครื่องชาร์จรถ
Type ACไซน์ AC เท่านั้น✗ ห้ามใช้
Type AAC + DC เป็นลูก ๆ (pulsating) + DC เรียบไม่เกิน 6 mAได้ เมื่อร่วมกับ RDC-DD 6 mA
Type Fเหมือน A + ความถี่ผสม (อินเวอร์เตอร์ 1 เฟส)ได้ เมื่อร่วมกับ RDC-DD 6 mA
Type Bทุกแบบ รวม DC เรียบ และความถี่สูงถึง ~1 kHz✓ ใช้เดี่ยวได้
RDC-DD (IEC 62955)ตรวจเฉพาะ DC เรียบ ตัดที่ 6 mAมักอยู่ในวอลล์บ็อกซ์/สายพกพา ใช้คู่กับ Type A

P3 DC blinding limit ขีดกระแสรั่ว DC ที่ RCD Type A ยังทำงานได้

IΔ,DC≤6 mA  ⇒  Type A ยังตัด AC ได้IΔ,DC>6 mA  ⇒  ต้องตัดด้วย RDC-DD หรือใช้ Type BI_{\Delta,DC} \le 6\ \text{mA} \;\Rightarrow\; \text{Type A ยังตัด AC ได้} \qquad I_{\Delta,DC} > 6\ \text{mA} \;\Rightarrow\; \text{ต้องตัดด้วย RDC-DD หรือใช้ Type B}IΔ,DC​≤6 mA⇒Type A ยังตัด AC ได้IΔ,DC​>6 mA⇒ต้องตัดด้วย RDC-DD หรือใช้ Type B

ทำไม DC ทำให้ RCD ตาบอด แกนเหล็กของ RCD ถูกออกแบบให้ไวต่อการเปลี่ยนฟลักซ์ กระแส DC สร้างฟลักซ์คงที่ดันแกนให้ใกล้อิ่มตัว ความชัน dB/dHdB/dHdB/dH ลดลง เมื่อมีไฟรั่ว AC ซ้อนขึ้นมา ฟลักซ์เปลี่ยนน้อยจนขดตรวจจับเหนี่ยวนำแรงดันไม่พอตัดไฟ เครื่องชาร์จในรถมีวงจรเรียงกระแสและ PFC ถ้าฉนวนเสียฝั่ง DC กระแสรั่วจะเป็น DC เรียบ — นี่คือเหตุที่มาตรฐาน EV ต้องการการตรวจจับ DC เสมอ

อย่าวาง RCD Type A ต้นทางของ RCD Type B ถ้าตู้ไฟบ้านมี RCD Type A คุมทั้งตู้ (กันดูดเมน) แล้ววงจรรถใช้ Type B อยู่ปลายทาง กระแสรั่ว DC ยังไหลผ่าน Type A ต้นทางและทำให้มันตาบอดได้ ให้แยกวงจรรถออกจาก RCD ต้นทางชนิด A หรือใช้ Type B ที่ต้นทาง

การต่อลงดิน: TN-C-S, TT และปัญหา PEN ขาด กลาง

บ้านในไทยส่วนใหญ่ต่อลงดินแบบ TN-C-S: ระบบจำหน่ายใช้สายนิวทรัลร่วมเป็นสายดิน (PEN) และที่ตู้เมนของบ้านแยกออกเป็น N กับ PE โดยต่อถึงหลักดินที่ตู้เมน ข้อดีคือกระแสลัดลงดินสูง เบรกเกอร์ตัดเร็ว ข้อเสียที่สำคัญกับรถ EV คือ ถ้าสาย PEN ในระบบจำหน่ายขาด PE ในบ้าน (และตัวถังรถที่ต่อกับ PE) อาจลอยขึ้นมามีแรงดันหลายสิบถึงเกือบ 230 V เทียบกับพื้นดินที่ยืน

P4 TT-system touch-voltage condition เงื่อนไขระบบ TT

RA×IΔn≤50 V(RA=ความต้านทานหลักดิน + สาย PE ของผู้ใช้ไฟ)R_A \times I_{\Delta n} \le 50\ \text{V} \qquad (R_A = \text{ความต้านทานหลักดิน + สาย PE ของผู้ใช้ไฟ})RA​×IΔn​≤50 V(RA​=ความต้านทานหลักดิน + สาย PE ของผู้ใช้ไฟ)

มาตรฐาน IEC 60364-7-722 จึงกำหนดมาตรการสำหรับจุดชาร์จกลางแจ้งในระบบ TN เช่น ทำจุดชาร์จเป็นระบบ TT แยกหลักดิน หรือใช้เครื่องชาร์จที่ตรวจจับ PEN ขาด (open-PEN detection) แล้วตัดทุกขั้วรวม PE วอลล์บ็อกซ์หลายรุ่นมีฟังก์ชันนี้ในตัว — เป็นข้อที่ควรถามก่อนซื้อ

การป้องกันอื่น: ฟ้าผ่า IP และความร้อน พื้นฐาน

  • อุปกรณ์ป้องกันแรงดันเกิน (SPD) Type 2 ที่ตู้ไฟ ปกป้องวอลล์บ็อกซ์และ OBC จากฟ้าผ่าใกล้ ๆ และการสวิตชิ่งในระบบ
  • IP อย่างน้อย IP44 สำหรับติดในที่มีหลังคา IP54–IP65 สำหรับกลางแจ้ง หัวชาร์จที่ไม่ได้ใช้ให้เก็บในที่เก็บหัว
  • ขั้วต่อ ขันแน่นด้วยแรงบิดตามคู่มือ (torque) ตรวจซ้ำหลังใช้งาน 1 เดือน ขั้วหลวมคือสาเหตุอันดับหนึ่งของความร้อนในตู้
  • พื้นที่ติดตั้ง ไม่ติดใกล้วัสดุไวไฟ ระยะสายชาร์จไม่พาดผ่านทางเดินที่รถทับ

  6. ทดลองชาร์จเต็มกระแส 1 ชั่วโมง วัดอุณหภูมิขั้วต่อในตู้และในวอลล์บ็อกซ์ (ไม่ควรเกิน ~ 30 °C เหนืออุณหภูมิห้อง)

ตารางอาการเสียที่พบบ่อย

อาการสาเหตุที่น่าจะเป็นวิธีตรวจ
เสียบแล้วเครื่องชาร์จขึ้น “Earth fault / No ground”เต้ารับไม่มีสายดิน สาย PE หลุด หลักดินสูงมากวัดความต่อเนื่อง PE วัดแรงดัน N–PE (ปกติ < 5 V)

RCD ตัดเป็นพัก ๆ ตอนฝนตกน้ำเข้าเต้ารับ/กล่องต่อ IP ไม่พอตรวจซีลและท่อ ร้อยสายเข้ากล่องจากด้านล่าง

คำถามที่พบบ่อย

ชาร์จรถ EV ต้องใช้ RCD Type B เสมอไหม?

ต้องมีการป้องกันกระแสรั่วแบบ DC แต่ไม่จำเป็นต้องเป็น RCD Type B ที่ตู้เสมอไป ทางเลือกที่มาตรฐาน IEC 60364-7-722 ยอมรับคือ RCD Type B หรือ RCD Type A (หรือ F) ร่วมกับอุปกรณ์ตรวจจับกระแสรั่ว DC 6 mA (RDC-DD ตาม IEC 62955) ซึ่งวอลล์บ็อกซ์รุ่นใหม่ส่วนใหญ่มีในตัว ให้ดูดาต้าชีตของเครื่องชาร์จและข้อกำหนดของการไฟฟ้าในพื้นที่

ทำไม RCD Type AC ใช้กับเครื่องชาร์จรถไม่ได้?

เครื่องชาร์จในรถมีวงจรเรียงกระแส ถ้าฉนวนเสียฝั่ง DC กระแสรั่วจะเป็นไฟ DC เรียบหรือ DC เป็นลูก ๆ RCD Type AC ตรวจได้เฉพาะไฟรั่วรูปไซน์ และกระแส DC ยังทำให้แกนเหล็กของ RCD อิ่มตัวจนตัดไฟรั่ว AC ไม่ได้ด้วย จึงอันตรายแม้มีไฟรั่วจริง

ค่าความต้านทานหลักดินที่บ้านควรเป็นเท่าไร?

มาตรฐานการติดตั้งทางไฟฟ้าของไทย (วสท.) กำหนดความต้านทานระหว่างหลักดินกับดินไว้ไม่เกิน 5 โอห์มสำหรับระบบทั่วไป (มีเงื่อนไขผ่อนผันในพื้นที่ที่ทำได้ยาก) หลักดินแท่งเดียวยาว 2.4 เมตรในดินทั่วไปมักได้ 10–50 โอห์ม จึงมักต้องเพิ่มหลักดินหรือตอกลึกขึ้น วัดด้วยเครื่องวัดความต้านทานดินหลังติดตั้ง

เว็บไซต์ หน้าแรก คลังความรู้ บทความ: Laplace เวกเตอร์ Power Factor ฯลฯ ฟังก์ชันและกราฟ สูตรและตารางตรีโกณมิติ ลิมิตและความต่อเนื่อง ลำดับและอนุกรม · อุปนัย อนุพันธ์: สูตรและวิธีทำ การประยุกต์อนุพันธ์ทางวิศวกรรม สูตรอินทิเกรตและวิธีทำ การประยุกต์อินทิกรัลทางวิศวกรรม เวกเตอร์: แรงลัพธ์ สนาม เฟสเซอร์ สตูดิโอเวกเตอร์ 3 มิติ แรงลัพธ์ด้วยกฎไซน์-โคไซน์ เฟสเซอร์และวงจรไฟฟ้ากระแสสลับ แล็บกลศาสตร์เสมือน (ฟิสิกส์ 1) แล็บสนามไฟฟ้า-แม่เหล็ก (ฟิสิกส์ 2) พีชคณิตเชิงเส้น: เมทริกซ์ ดีเทอร์มิแนนต์ ค่าเฉพาะ แล็บเมทริกซ์: เครื่องคิดเลขแสดงวิธีทำ การประยุกต์พีชคณิตเชิงเส้นทางวิศวกรรม การแปลงลาปลาซ: ตารางและ ROC แผนภาพโพล-ซีโร่และ ROC คุณสมบัติการแปลงลาปลาซ การแปลงลาปลาซผกผัน (Inverse Laplace) แล็บระบบอันดับหนึ่ง แล็บระบบอันดับสอง แล็บสัญญาณเบื้องต้น อนุกรมฟูเรียร์และการวิเคราะห์ฮาร์มอนิก แล็บวิเคราะห์ฮาร์มอนิก: สโคป + เครื่องวิเคราะห์กำลังไฟฟ้า ตารางอนุกรมฟูเรียร์ของรูปคลื่น THD เพาเวอร์แฟกเตอร์ และ IEEE 519 อิเล็กทรอนิกส์กำลัง: บั๊ก บูสต์ ชุค ตัวชดเชย แล็บจำลองคอนเวอร์เตอร์ DC-DC ออนไลน์ แบบจำลองเฉลี่ยและสเตตสเปซของบั๊กคอนเวอร์เตอร์ แล็บออกแบบบั๊ก: เลือกชิ้นส่วนและโปรแกรมโหลด ออกแบบระบบโซลาร์เซลล์: แผง สตริง แบตเตอรี่ MPPT อินเวอร์เตอร์ เครื่องมือออกแบบโซลาร์เซลล์ออนไลน์ โซลาร์เซลล์จ่ายแอร์ ปั๊มน้ำโซลาร์และโซลาร์เพื่อการเกษตร ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน: ชาร์จช้า ชาร์จเร็ว ไฟบ้าน โซลาร์เซลล์ แอร์ และรถ EV ในบ้านเดียว ระบบไฟฟ้ากำลังและระบบป้องกัน (ปูพื้น) ประสานรีเลย์กระแสเกิน TCC เพาเวอร์แฟกเตอร์ เข้าใจได้ทุกระดับ ซิมูเลเตอร์เพาเวอร์แฟกเตอร์ เซนเซอร์และทรานส์ดิวเซอร์: เครื่องมือวัดคุมอุตสาหกรรม แล็บวัดคุมเสมือน 4–20 mA PID 4–20 mA และ HART Modbus RTU และ TCP เครื่องมือแปลงหน่วย แล็บเครื่องกำเนิดสัญญาณและออสซิลโลสโคป ออสซิลโลสโคปจำลองออนไลน์ แล็บออปแอมป์ ระบบควบคุม: ป้อนกลับ เสถียรภาพ รูทโลคัส โบด PID เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน เกี่ยวกับอาจารย์มด
