# ค่าชาร์จรถ EV ที่บ้าน: ค่าไฟอัตราก้าวหน้ากับ TOU, ค่าใช้จ่ายต่อกิโลเมตร และความคุ้มค่าของมิเตอร์ TOU

// บทที่ 17.7 · ระบบชาร์จรถยนต์ไฟฟ้าที่บ้าน · Home Charging Cost


“ชาร์จเต็มหนึ่งครั้งกี่บาท” ตอบไม่ได้ด้วยการคูณราคาต่อหน่วยตัวเดียว เพราะค่าไฟบ้านแบบปกติเป็นอัตราก้าวหน้า ไฟหน่วยที่เพิ่มเพราะรถถูกคิดในขั้นที่แพงที่สุด ส่วนแบบ TOU ราคาขึ้นกับเวลา หน้านี้แยกโครงสร้างบิลออกเป็นส่วน ๆ แล้วคำนวณ “ค่าไฟส่วนเพิ่ม” ที่แท้จริงของรถ

สรุปใน 30 วินาที

- ไฟที่ซื้อเพื่อรถ = km × kWh/100 km ÷ ประสิทธิภาพการชาร์จ

- อัตราปกติ: ไฟส่วนเพิ่มคิดที่ขั้นบน ≈ 4.42 ฿ + Ft แล้ว × 1.07 ≈ 4.9 ฿/หน่วย

- TOU Off-Peak ≈ 2.64 ฿ + Ft แล้ว × 1.07 ≈ 3.0 ฿/หน่วย แต่ On-Peak แพงขึ้นเป็น ≈ 6.4 ฿

- ค่าชาร์จ ≈ 0.65–0.85 ฿/km เทียบรถน้ำมัน ≈ 2.5 ฿/km

## รถใช้ไฟเดือนละกี่หน่วย พื้นฐาน

T1 Monthly charging energy ไฟที่มิเตอร์นับต่อเดือนเพราะรถ

$$E_{EV} = \frac{d \times c/100}{\eta} \qquad d = \text{km/เดือน},\ c = \text{kWh/100 km},\ \eta \approx 0.85\text{–}0.92$$

อัตราสิ้นเปลืองจริงของรถเก๋งไฟฟ้าในเมืองไทยประมาณ 13–17 kWh/100 km (รถ SUV และขับเร็วบนทางด่วนสูงกว่า) ตัวเลขบนหน้าจอรถมักเป็นค่า “จากแบต” ยังไม่รวมการสูญเสียในการชาร์จ

ตัวอย่าง T-1

### วิ่ง 1,500 km/เดือน รถ 15 kWh/100 km

- T1: $E_{EV} = 1500 \times 0.15 / 0.9 = 250\ \text{kWh}$ ต่อเดือน

- ถ้าบ้านเดิมใช้ 400 หน่วย บิลจะกลายเป็น 650 หน่วย — เพิ่มขึ้น 62 %

## โครงสร้างค่าไฟบ้าน (อัตราปกติ ประเภท 1.2) พื้นฐาน

| ส่วนของบิล | ค่า (ปี 2568) | หมายเหตุ |

| ค่าพลังงาน 150 หน่วยแรก | 3.2484 ฿/หน่วย | ใช้มากขึ้น ราคาต่อหน่วยขั้นถัดไปแพงขึ้น |

| หน่วยที่ 151–400 | 4.2218 ฿/หน่วย |

| หน่วยที่ 401 ขึ้นไป | 4.4217 ฿/หน่วย |

| ค่าบริการรายเดือน | 24.62 ฿ | |

| ค่าไฟฟ้าผันแปร (Ft) | ประกาศทุก 4 เดือน เช่น 0.1972 ฿/หน่วย | ตรวจค่างวดปัจจุบันจาก กกพ. |

| ภาษีมูลค่าเพิ่ม | 7 % ของทั้งหมด | |

T2 Progressive (block) tariff bill ค่าไฟอัตราก้าวหน้า

$$B = \Big[\sum_k r_k\,E_k + S + E\,F_t\Big](1 + 0.07) \qquad E_k = \text{หน่วยที่ตกอยู่ในขั้นที่ } k$$

T3 Incremental cost of the EV ค่าไฟส่วนเพิ่มเพราะรถ

$$\Delta B = B(E_{home} + E_{EV}) - B(E_{home}) \qquad \text{฿/km} = \frac{\Delta B}{d}$$

ตัวอย่าง T-2

### บ้าน 400 หน่วย + รถ 250 หน่วย (อัตราปกติ Ft 0.1972)

- บิลเดิม T2: $150(3.2484) + 250(4.2218) = 487.26 + 1055.45 = 1542.71$ + 24.62 + $400(0.1972) = 78.88$ → 1646.21 × 1.07 = 1,761 ฿

- บิลใหม่ 650 หน่วย: $1542.71 + 250(4.4217) = 2648.14$ + 24.62 + $650(0.1972) = 128.18$ → 2800.94 × 1.07 = 2,997 ฿

- T3: $\Delta B = 1{,}236$ ฿ → $1236/1500 = 0.82$ ฿/km · ต่อหน่วยของรถ $1236/250 = 4.94$ ฿

## อัตรา TOU (ประเภท 1.3.2) กลาง

| ช่วงเวลา | เมื่อไร | ค่าพลังงาน (ไม่รวม Ft, VAT) |

| On-Peak | จันทร์–ศุกร์ 09:00–22:00 น. | 5.7982 ฿/หน่วย |

| Off-Peak | จันทร์–ศุกร์ 22:00–09:00 น. · เสาร์ อาทิตย์ วันหยุดราชการตามปกติทั้งวัน | 2.6369 ฿/หน่วย |

| ค่าบริการ | รายเดือน | 24.62 ฿ |

T4 TOU bill ค่าไฟอัตรา TOU

$$B_{TOU} = \Big[5.7982\,E_{on} + 2.6369\,E_{off} + S + (E_{on}+E_{off})F_t\Big](1.07)$$

กุญแจคือ ไฟที่เคยใช้ช่วงกลางวันวันธรรมดาของบ้านเดิม จะแพงขึ้นจาก ~4.2–4.4 เป็น 5.8 ฿ ส่วนไฟของรถที่ชาร์จ Off-Peak ถูกลงจาก 4.42 เป็น 2.64 ฿ TOU คุ้มเมื่อส่วนลดของรถมากกว่าส่วนเพิ่มของบ้าน

T5 TOU break-even (rough) เงื่อนไขคุ้มโดยประมาณ

$$E_{EV,off}\,(r_{top} - 2.64) \;>\; E_{home,on}\,(5.80 - \bar r_{home}) + E_{home,off}\,(2.64 - \bar r_{home})$$

ตัวอย่าง T-3

### บ้านเดิมกับ TOU (บ้านใช้ On-Peak 55 % รถชาร์จ Off-Peak ทั้งหมด)

- ยังไม่มีรถ: On 220 · Off 180 หน่วย → T4: $220(5.7982) + 180(2.6369) = 1750.24$ + 24.62 + 78.88 → × 1.07 = 1,984 ฿ (แพงกว่าอัตราปกติ 223 ฿ — บ้านนี้ยังไม่ควรใช้ TOU)

- มีรถ: Off +250 → $+250(2.6369) + 250(0.1972) = 708.53$ → (1853.74 + 708.53) × 1.07 = 2,742 ฿

- เทียบอัตราปกติเมื่อมีรถ 2,997 ฿ → TOU ถูกกว่า 255 ฿/เดือน ค่ารถจริงเมื่อเทียบบิลเดิม 2,742 − 1,761 = 980 ฿ = 0.65 ฿/km

- ถ้าวิ่งแค่ 1,000 km/เดือน (167 หน่วย) TOU ถูกกว่าเพียง 96 ฿/เดือน — ไม่คุ้มค่าเปลี่ยนมิเตอร์เร็วนักถ้าบ้านใช้ไฟกลางวันมาก ถ้ามีโซลาร์ที่ลดไฟกลางวัน TOU คุ้มขึ้นมาก (ดูหน้าถัดไป)

## ค่าใช้จ่ายต่อกิโลเมตรเทียบรถน้ำมัน พื้นฐาน

T6 Cost per kilometre ค่าใช้จ่ายต่อกิโลเมตร

$$\text{฿/km}_{EV} = \frac{c}{100\,\eta}\,r_{marginal} \qquad \text{฿/km}_{ICE} = \frac{\text{ราคาน้ำมัน}}{\text{km/ลิตร}}$$

| กรณี (15 kWh/100 km, η 0.9) | ราคาส่วนเพิ่มรวม Ft VAT | ฿/km | 1,500 km/เดือน |

| อัตราปกติ ขั้นบน | ≈ 4.94 ฿ | 0.82 | ≈ 1,240 ฿ |

| TOU ชาร์จ Off-Peak | ≈ 3.03 ฿ | 0.51 (เฉพาะรถ) | ≈ 760 ฿ (+ ส่วนต่างบ้าน) |

| ชาร์จจากโซลาร์ส่วนเกิน (เสียโอกาสขายไฟ 2.2 ฿) | ≈ 2.2 ฿ | 0.37 | ≈ 550 ฿ |

| ตู้ชาร์จด่วนสาธารณะ | ≈ 6.5–8 ฿ | 1.1–1.3 | ≈ 1,600–2,000 ฿ |

| รถน้ำมัน 14 km/ลิตร 35 ฿/ลิตร | — | 2.50 | 3,750 ฿ |

## เครื่องคำนวณ: อัตราปกติหรือ TOU คุ้มกว่าสำหรับบ้านคุณ

หมายเหตุ อัตราค่าไฟในหน้านี้เป็นอัตราของ กฟภ./กฟน. ที่ใช้ในปี 2568 สำหรับผู้ใช้ไฟแรงดันต่ำกว่า 22 kV ค่า Ft ใส่เป็นตัวแปรเพราะเปลี่ยนทุก 4 เดือน ไม่รวมค่าใช้จ่ายเปลี่ยนมิเตอร์และอัตราพิเศษสำหรับ EV ที่อาจประกาศเพิ่ม ตรวจประกาศล่าสุดก่อนตัดสินใจ

## คำถามที่พบบ่อย

ชาร์จรถ EV ที่บ้านกิโลเมตรละกี่บาท?
ประมาณ 0.65–0.85 บาทต่อกิโลเมตร สำหรับรถที่ใช้ไฟ 15 kWh ต่อ 100 km และประสิทธิภาพการชาร์จ 90 % ขึ้นกับว่าใช้อัตราปกติ (ไฟส่วนเพิ่มอยู่ขั้นบนสุดราว 4.4 บาทก่อน Ft และ VAT) หรือ TOU ชาร์จช่วง Off-Peak (ราว 2.6 บาทก่อน Ft และ VAT) เทียบกับรถน้ำมัน 14 km/ลิตร ที่ราคา 35 บาท/ลิตร ประมาณ 2.5 บาท/km

มิเตอร์ TOU คุ้มไหมเมื่อมีรถ EV?
คุ้มเมื่อพลังงานที่ย้ายไปช่วง Off-Peak ได้มากพอ อัตรา Off-Peak ถูกกว่าอัตราปกติขั้นบนเกือบครึ่ง แต่ On-Peak แพงกว่า (5.7982 บาท) บ้านที่ใช้ไฟกลางวันวันธรรมดามาก เช่น เปิดแอร์ทั้งวันโดยไม่มีโซลาร์ อาจไม่คุ้ม ให้ใส่ตัวเลขบิลของคุณในเครื่องคำนวณ ระยะทางยิ่งมาก TOU ยิ่งคุ้ม

ช่วงเวลา On-Peak และ Off-Peak ของ TOU คือเมื่อไร?
On-Peak คือวันจันทร์–ศุกร์ เวลา 09:00–22:00 น. Off-Peak คือวันจันทร์–ศุกร์ 22:00–09:00 น. และวันเสาร์ อาทิตย์ วันหยุดราชการตามปกติทั้งวัน ตรวจรายละเอียดวันหยุดที่ใช้กับ TOU จากการไฟฟ้า
