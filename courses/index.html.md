# ห้องเรียนออนไลน์

THภาษาไทยENEnglish
// Courses · ห้องเรียนออนไลน์


รายวิชาที่จัดเป็นหน่วยเรียงตามลำดับการสอนจริงในชั้นเรียน แต่ละหน่วยมีเนื้อหา ตัวอย่างทำทีละขั้น แบบฝึกหัดพร้อมเฉลย วิดีโอจากช่อง YouTube และเอกสารประกอบการสอน เปิดได้ทันทีจากมือถือหรือจอโปรเจกเตอร์ ไม่ต้องสมัครสมาชิก ส่วนเนื้อหาอ้างอิงเชิงลึกทุกหัวข้ออยู่ที่คลังความรู้

## รายวิชาที่เปิดแล้ว

G(s)วิศวกรรมระบบควบคุมControl Engineeringห้องเรียนวิศวกรรมระบบควบคุมระดับปริญญาตรีถึงปริญญาโท เปิดหน่วยแรก: บทนำ วงเปิด วงปิด ชนิดของระบบ ศัพท์ การใช้ในสาขาวิศวกรรมต่าง ๆ และสายงานค่าตอบแทนสูง พร้อมแล็บโต้ตอบ แบบฝึกหัดและเฉลย มีฉบับภาษาอังกฤษแยกลิงก์1 หน่วย · อัปเดต 18 พ.ย. 2569
