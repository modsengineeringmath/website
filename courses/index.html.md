# ห้องเรียนออนไลน์

// Courses · ห้องเรียนออนไลน์


รายวิชาที่จัดเป็นหน่วยเรียงตามลำดับการสอนจริงในชั้นเรียน แต่ละหน่วยมีเนื้อหา ตัวอย่างทำทีละขั้น แบบฝึกหัดพร้อมเฉลย วิดีโอจากช่อง YouTube และเอกสารประกอบการสอน เปิดได้ทันทีจากมือถือหรือจอโปรเจกเตอร์ ไม่ต้องสมัครสมาชิก ส่วนเนื้อหาอ้างอิงเชิงลึกทุกหัวข้ออยู่ที่คลังความรู้

## รายวิชาที่เปิดแล้ว

G(s)วิศวกรรมระบบควบคุมControl Engineeringเรียนวิศวกรรมระบบควบคุมครบ 17 หน่วยตามลำดับการสอนจริง ตั้งแต่ฟังก์ชันถ่ายโอน ผลตอบสนอง เสถียรภาพ รูทโลคัส โบด PID ปริภูมิสถานะ ควบคุมดิจิทัล จนถึงฟัซซีลอจิกและ AI ใช้ตัวอย่างจากงานวิศวกรรมไฟฟ้าทุกหน่วย พร้อมแบบฝึกหัดและเฉลย17 หน่วย · อัปเดต 12 พ.ย. 2569
