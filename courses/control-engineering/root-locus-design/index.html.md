# การออกแบบตัวชดเชยด้วยรูทโลคัส

// หน่วยที่ 10 · Control Engineering · Compensator Design by Root Locus


ออกแบบตัวชดเชยแบบลีดเพื่อย้ายขั้วเด่นไปยังตำแหน่งที่ต้องการ และตัวชดเชยแบบแลกเพื่อลดค่าผิดพลาดในสถานะอยู่ตัว ด้วยเงื่อนไขมุมและเงื่อนไขขนาด พร้อมวงจรออปแอมป์ที่ใช้สร้างตัวชดเชยจริง

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- แปลงข้อกำหนดสมรรถนะเป็นตำแหน่งขั้วเด่นที่ต้องการได้
- ออกแบบตัวชดเชยแบบลีดด้วยเงื่อนไขมุมและเงื่อนไขขนาดได้
- ออกแบบตัวชดเชยแบบแลกเพื่อเพิ่มค่าคงตัวความผิดพลาดโดยไม่ย้ายขั้วเด่นได้
- เลือกค่า R และ C ของวงจรออปแอมป์ที่สร้างตัวชดเชยที่ออกแบบได้

## ภาพในใจก่อนเริ่ม: ถ้าทางเดิมไม่ผ่าน ก็ตัดทางใหม่

หน่วยที่ 9 จบด้วยปัญหา: รูทโลคัสของพลานต์ไม่ผ่านตำแหน่งขั้วที่ต้องการ การปรับเกนเพียงเลื่อนขั้วไปตามเส้นเดิม ไม่ได้ย้ายเส้น

ตัวชดเชย (compensator) คือฟังก์ชันถ่ายโอนที่ใส่เพิ่มในลูป เพื่อเพิ่มขั้วและศูนย์ของตัวเองเข้าไป รูทโลคัสจึงเปลี่ยนรูปร่าง หลักที่ได้จากหน่วยที่ 9 คือ

- ศูนย์ดึงรูทโลคัสไปทางซ้าย ระบบเร็วขึ้นและหน่วงดีขึ้น

- ขั้วผลักรูทโลคัสไปทางขวา แต่ขั้วที่จุดกำเนิดช่วยกำจัดค่าผิดพลาดในสถานะอยู่ตัว

## ขั้นตอนออกแบบตัวชดเชยแบบลีด

- แปลงข้อกำหนด (%OS, $t_s$) เป็น $\zeta$ และ $\omega_n$ แล้วเขียนตำแหน่งขั้วเด่นที่ต้องการ $s_d = -\zeta\omega_n + j\omega_d$

- คำนวณมุมของพลานต์ที่ $s_d$ มุมที่ขาดจาก $-180°$ คือมุมที่ตัวชดเชยต้องเติม $\phi$

- เลือกตำแหน่งศูนย์ของตัวชดเชย แล้วหาตำแหน่งขั้วที่ทำให้ $\angle(s_d + z) - \angle(s_d + p) = \phi$

- หา $K_c$ จากเงื่อนไขขนาด

- ตรวจขั้ววงปิดที่เหลือ และจำลองผลตอบสนอง

ตัวอย่างที่ 10.1 ตัวชดเชยแบบลีดสำหรับเซอร์โว

พลานต์ $G(s) = \dfrac{1}{s(s + 1)}$ ป้อนกลับหนึ่งหน่วย ต้องการ $\zeta = 0.5$ และเวลาเข้าที่ 2 s

ขั้นที่ 1 จาก $t_s = 4/(\zeta\omega_n) = 2$ ได้ $\zeta\omega_n = 2$ ดังนั้น $\omega_n = 4$ rad/s และ $\omega_d = 4\sqrt{0.75} = 3.464$

$$s_d = -2 + j3.464$$

ถ้าใช้เกนอย่างเดียว รูทโลคัสของพลานต์เป็นเส้นตั้งที่ $s = -0.5$ ไม่ผ่าน $s_d$ จึงต้องใช้ตัวชดเชย

ขั้นที่ 2 มุมของพลานต์ที่ $s_d$

- จากขั้วที่ $0$: $\angle s_d = 180° - \tan^{-1}(3.464/2) = 120°$

- จากขั้วที่ $-1$: $\angle(s_d + 1) = 180° - \tan^{-1}(3.464/1) = 106.1°$

$\angle G(s_d) = -(120° + 106.1°) = -226.1°$ ต้องการ $-180°$ ตัวชดเชยจึงต้องเติม $\phi = 46.1°$

ขั้นที่ 3 เลือกศูนย์ที่ $s = -2$ ใต้ขั้วที่ต้องการพอดี มุมจากศูนย์คือ $90°$ มุมจากขั้วของตัวชดเชยต้องเป็น $90° - 46.1° = 43.9°$

$$p = 2 + \frac{3.464}{\tan 43.9°} = 2 + 3.60 = 5.60$$

ขั้นที่ 4 เงื่อนไขขนาด

$$K_c = \frac{\lvert s_d\rvert\,\lvert s_d + 1\rvert\,\lvert s_d + 5.6\rvert}{\lvert s_d + 2\rvert} = \frac{(4)(3.606)(4.996)}{3.464} = 20.8$$

$$C(s) = 20.8\,\frac{s + 2}{s + 5.6}$$

ขั้นที่ 5 สมการลักษณะเฉพาะ $s(s + 1)(s + 5.6) + 20.8(s + 2) = 0$ มีรากที่ $-2 \pm j3.464$ ตามที่ออกแบบ และรากที่สามที่ $s = -2.6$

ขั้วที่สามอยู่ใกล้ศูนย์ที่ $-2$ จึงหักล้างกันได้เพียงบางส่วน ผลจำลองให้การพุ่งเกิน 27 % สูงกว่าค่า 16 % ของระบบอันดับสองล้วน ศูนย์ของวงปิดเป็นสาเหตุ ถ้าต้องการพุ่งเกินน้อยลง ให้ออกแบบซ้ำด้วย $\zeta$ ที่สูงขึ้น หรือย้ายศูนย์ไปทางซ้าย

สูตรของระบบอันดับสองเป็นจุดเริ่ม ไม่ใช่คำตอบสุดท้าย

สูตร %OS และ $t_s$ ในหน่วยที่ 6 ถูกต้องสำหรับระบบอันดับสองที่ไม่มีศูนย์เท่านั้น เมื่อใส่ตัวชดเชย ระบบมีขั้วและศูนย์เพิ่ม ต้องจำลองผลตอบสนองตรวจเสมอ แล้วปรับซ้ำ การออกแบบจริงเป็นการวนรอบ ไม่ใช่การคำนวณครั้งเดียวจบ

## ตัวชดเชยแบบแลก

หลังใส่ตัวชดเชยแบบลีด ค่าคงตัวความผิดพลาดของตัวอย่างที่ 10.1 คือ

$$K_v = \lim_{s \to 0} s\,C(s)G(s) = \frac{20.8 \times 2}{5.6 \times 1} = 7.43\ \text{s}^{-1}$$

ถ้าต้องการ $K_v$ มากกว่านี้ 10 เท่าโดยไม่รบกวนขั้วเด่น ให้เพิ่มตัวชดเชยแบบแลก

$$C_{lag}(s) = \frac{s + z_l}{s + p_l}, \qquad \frac{z_l}{p_l} = 10$$

โดยวางทั้งคู่ใกล้จุดกำเนิด เช่น $z_l = 0.1$ และ $p_l = 0.01$

- ที่ $s \to 0$ ตัวชดเชยมีเกน $z_l/p_l = 10$ จึงได้ $K_v = 74.3$ s⁻¹ ค่าผิดพลาดต่อแรมป์ลดลง 10 เท่า

- ที่ $s = s_d$ ซึ่งอยู่ไกลจากจุดกำเนิด เวกเตอร์จาก $z_l$ และ $p_l$ แทบทับกัน $C_{lag}(s_d) \approx 1\angle{-1.2°}$ รูทโลคัสใกล้ $s_d$ จึงแทบไม่เปลี่ยน

ราคาที่ต้องจ่ายคือขั้ววงปิดอีกตัวหนึ่งใกล้ $s = -0.1$ ซึ่งทำให้ค่าผิดพลาดส่วนสุดท้ายลดลงช้า (เป็นหางยาวในกราฟ) ถ้าย้าย $p_l$ ไปที่จุดกำเนิดพอดี ตัวชดเชยแบบแลกจะกลายเป็นตัวควบคุม PI

## สร้างตัวชดเชยด้วยออปแอมป์

จากหน่วยที่ 3 วงจรออปแอมป์กลับเฟสมี $G(s) = -Z_2/Z_1$ ถ้าให้ $Z_1$ เป็น $R_1$ ขนานกับ $C_1$ และ $Z_2$ เป็น $R_2$ ขนานกับ $C_2$ จะได้

$$\frac{V_o(s)}{V_i(s)} = -\frac{C_1}{C_2}\cdot\frac{s + \dfrac{1}{R_1C_1}}{s + \dfrac{1}{R_2C_2}}$$

ศูนย์อยู่ที่ $1/(R_1C_1)$ ขั้วอยู่ที่ $1/(R_2C_2)$ วงจรเดียวกันเป็นลีดเมื่อ $R_1C_1 > R_2C_2$ และเป็นแลกเมื่อกลับกัน เครื่องหมายลบแก้ได้ด้วยวงจรกลับเฟสอีกหนึ่งภาค

ตัวอย่างที่ 10.2 ค่าอุปกรณ์ของตัวชดเชยแบบลีด

จงเลือกค่าอุปกรณ์สำหรับ $C(s) = 20.8\,\dfrac{s + 2}{s + 5.6}$ โดยใช้ $C_1 = 10\ \mu\text{F}$

- เกน: $C_1/C_2 = 20.8$ ได้ $C_2 = 0.48\ \mu\text{F}$ (ใช้ 0.47 µF)

- ศูนย์: $R_1 = \dfrac{1}{2 \times 10 \times 10^{-6}} = 50\ \text{k}\Omega$

- ขั้ว: $R_2 = \dfrac{1}{5.6 \times 0.48 \times 10^{-6}} = 372\ \text{k}\Omega$

ตรวจเกน DC: $R_2/R_1 = 7.43$ ตรงกับ $20.8 \times 2/5.6$ ตัวเก็บประจุจริงมีความคลาดเคลื่อน 5–10 % ตำแหน่งขั้วและศูนย์จึงคลาดไปด้วย ซึ่งเป็นเหตุผลหนึ่งที่งานสมัยใหม่ย้ายตัวชดเชยไปคำนวณในไมโครคอนโทรลเลอร์ (หน่วยที่ 15)

ตัวชดเชยในแหล่งจ่ายไฟสวิตชิง

วงจรชดเชยแบบ Type II และ Type III รอบตัวขยายค่าผิดพลาดของบักคอนเวอร์เตอร์คือตัวชดเชยลีด-แลกที่มีอินทิเกรเตอร์ วงจร Type III มีศูนย์สองตัวไว้เติมเฟสให้ตัวกรอง LC ซึ่งมี $\zeta$ ต่ำ (ตัวอย่างที่ 6.2) หลักการออกแบบเหมือนหน่วยนี้ เพียงแต่ในงานนั้นนิยมทำบนโบดไดอะแกรม ซึ่งเป็นเรื่องของหน่วยที่ 11 และ 12

## แบบฝึกหัด

แบบฝึกหัด 10.1

ต้องการพุ่งเกินไม่เกิน 4.3 % และเวลาเข้าที่ 1 s จงหาตำแหน่งขั้วเด่นที่ต้องการ

ดูเฉลย

%OS = 4.3 % ตรงกับ $\zeta = 0.707$ และ $\zeta\omega_n = 4/t_s = 4$ จึงได้ $\omega_n = 5.66$ rad/s, $\omega_d = \omega_n\sqrt{1 - 0.5} = 4$

$$s_d = -4 \pm j4$$

แบบฝึกหัด 10.2

พลานต์ $G(s) = \dfrac{1}{s^2}$ (มวลล้วน เช่น แกนเลื่อนที่ไม่มีแรงเสียดทาน) ต้องการขั้วเด่นที่ $s_d = -1 + j1$ โดยวางศูนย์ของตัวชดเชยแบบลีดที่ $s = -1$ จงหาขั้วและเกนของตัวชดเชย

ดูเฉลย

มุมของพลานต์: $-2 \times 135° = -270°$ ต้องเติม $\phi = 90°$

ศูนย์ที่ $-1$ ให้มุม $90°$ ขั้วของตัวชดเชยจึงต้องให้มุม $0°$ ซึ่งเป็นไปได้เมื่อขั้วอยู่ที่ $-\infty$ เท่านั้น นั่นคือตัวชดเชยที่ต้องใช้คือ PD ล้วน $C(s) = K_c(s + 1)$

เงื่อนไขขนาด: $K_c = \dfrac{\lvert s_d\rvert^2}{\lvert s_d + 1\rvert} = \dfrac{2}{1} = 2$ ตรวจ: $s^2 + 2s + 2 = 0$ มีราก $-1 \pm j1$

ในทางปฏิบัติ PD ล้วนขยายสัญญาณรบกวนความถี่สูง จึงเลือกศูนย์ให้ใกล้จุดกำเนิดกว่านี้ (เช่น $-0.5$) เพื่อให้ขั้วของตัวชดเชยอยู่ที่ตำแหน่งจำกัด

แบบฝึกหัด 10.3

ระบบมี $K_v = 5$ s⁻¹ ต้องการให้ค่าผิดพลาดต่อแรมป์หนึ่งหน่วยไม่เกิน 0.02 จงออกแบบตัวชดเชยแบบแลก

ดูเฉลย

ต้องการ $K_v \ge 1/0.02 = 50$ s⁻¹ คือเพิ่ม 10 เท่า เลือก $z_l/p_l = 10$ และวางใกล้จุดกำเนิดเมื่อเทียบกับขั้วเด่น เช่น

$$C_{lag}(s) = \frac{s + 0.1}{s + 0.01}$$

## สรุปหน่วยที่ 10

- ตัวชดเชยเปลี่ยนรูปร่างของรูทโลคัสด้วยการเพิ่มขั้วและศูนย์

- ลีดเติมมุมบวกที่ $s_d$ เพื่อดึงรูทโลคัสไปทางซ้าย ออกแบบด้วยเงื่อนไขมุมแล้วตามด้วยเงื่อนไขขนาด

- แลกเพิ่มเกนที่ความถี่ต่ำเป็น $z_l/p_l$ เท่า โดยแทบไม่ย้ายขั้วเด่น

- ต้องจำลองผลตอบสนองตรวจทุกครั้ง เพราะขั้วและศูนย์ที่เพิ่มทำให้สูตรของระบบอันดับสองคลาดเคลื่อน

- วงจรออปแอมป์หนึ่งภาคสร้างได้ทั้งลีดและแลก
