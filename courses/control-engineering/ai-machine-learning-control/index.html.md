# พื้นฐาน AI และ Machine Learning สำหรับวิศวกรควบคุม

// หน่วยที่ 17 · Control Engineering · AI and Machine Learning Fundamentals for Control Engineers


machine learning คืออะไรในภาษาของวิศวกรควบคุม การระบุระบบจากข้อมูลด้วยกำลังสองน้อยที่สุด การลดตามเกรเดียนต์ โครงข่ายประสาทเทียม การเรียนรู้แบบเสริมกำลัง ดัชนีสมรรถนะ IAE ISE ITAE สำหรับวิเคราะห์ลูป และข้อจำกัดด้านเสถียรภาพและความปลอดภัย

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- อธิบาย machine learning ว่าเป็นการหาฟังก์ชันจากข้อมูล และจำแนกการเรียนรู้สามแบบได้
- หาแบบจำลองอันดับหนึ่งของพลานต์จากข้อมูลที่บันทึกไว้ด้วยวิธีกำลังสองน้อยที่สุดได้
- อธิบายการลดตามเกรเดียนต์และโครงสร้างของนิวรอนโดยเทียบกับลูปป้อนกลับและวงจรออปแอมป์ได้
- คำนวณดัชนีสมรรถนะ IAE และ ISE และบอกได้ว่า AI ช่วยวิเคราะห์สมรรถนะของลูปและสภาพเครื่องจักรอย่างไร
- ระบุข้อจำกัดของตัวควบคุมที่เรียนรู้จากข้อมูลในด้านเสถียรภาพและความปลอดภัยได้

## ภาพในใจก่อนเริ่ม: จากเขียนกฎเอง สู่ให้ข้อมูลเขียนกฎ

ตลอด 15 หน่วยแรก เราสร้างแบบจำลองจากกฎทางฟิสิกส์ (เคอร์ชอฟฟ์ นิวตัน) แล้วออกแบบตัวควบคุมจากแบบจำลองนั้น หน่วยที่ 16 ใช้กฎของผู้เชี่ยวชาญ หน่วยนี้แนะนำแหล่งความรู้ที่สาม คือข้อมูล

Machine learning (ML) คือการให้คอมพิวเตอร์หาฟังก์ชัน $y = f(x)$ จากตัวอย่างของ $x$ และ $y$ จำนวนมาก แทนที่มนุษย์จะเขียนฟังก์ชันนั้นเอง ปัญญาประดิษฐ์ (AI) เป็นคำที่กว้างกว่า หมายถึงระบบที่ทำงานซึ่งปกติต้องใช้สติปัญญาของมนุษย์ และ ML เป็นวิธีหลักที่ใช้สร้าง AI ในปัจจุบัน

ข่าวดีสำหรับผู้เรียนวิชานี้: แนวคิดหลักของ ML หลายข้อเป็นสิ่งที่วิศวกรควบคุมรู้จักอยู่แล้วในชื่ออื่น

## ระบุแบบจำลองของพลานต์จากข้อมูล

หน่วยที่ 5 หา $K$ และ $\tau$ จากกราฟด้วยการอ่านจุด 63.2 % วิธีนั้นใช้ข้อมูลเพียงจุดเดียวและไวต่อสัญญาณรบกวน วิธีกำลังสองน้อยที่สุด (least squares) ใช้ข้อมูลทุกจุด

จากหน่วยที่ 15 พลานต์อันดับหนึ่งที่ชักตัวอย่างแล้วเป็นไปตาม

$$y[k+1] = a\,y[k] + b\,u[k]$$

สมการนี้เป็นเชิงเส้นในพารามิเตอร์ $a$ และ $b$ เมื่อมีข้อมูล $N$ คู่ เขียนเป็นเมทริกซ์ได้ $\mathbf{y} = \Phi\boldsymbol{\theta}$ โดยแต่ละแถวของ $\Phi$ คือ $\begin{bmatrix}y[k] & u[k]\end{bmatrix}$ และ $\boldsymbol{\theta} = \begin{bmatrix}a & b\end{bmatrix}^T$ ค่าที่ทำให้ผลรวมกำลังสองของค่าผิดพลาดน้อยที่สุดคือ

$$\hat{\boldsymbol{\theta}} = (\Phi^T\Phi)^{-1}\Phi^T\mathbf{y}$$

จากนั้นแปลงกลับเป็นพารามิเตอร์ทางกายภาพด้วยสูตรของหน่วยที่ 15

$$\tau = -\frac{T}{\ln a}, \qquad K = \frac{b}{1 - a}$$

ตัวอย่างที่ 17.1 หาแบบจำลองจากข้อมูลที่บันทึก

ป้อนอินพุตขั้นบันได $u = 1$ ให้พลานต์ บันทึกเอาต์พุตทุก $T = 0.1$ s ได้ $y = 0,\ 0.200,\ 0.360,\ 0.488$ จงหา $a$, $b$, $\tau$ และ $K$

ขั้นที่ 1 เขียนสมการจากข้อมูลแต่ละคู่

|
$k$ |
$y[k+1] = a\,y[k] + b\,u[k]$ |

|
0 |
$0.200 = a(0) + b$ |

|
1 |
$0.360 = a(0.200) + b$ |

|
2 |
$0.488 = a(0.360) + b$ |

ขั้นที่ 2 จากแถวแรก $b = 0.200$ แทนในแถวที่สอง $a = \dfrac{0.360 - 0.200}{0.200} = 0.800$

ขั้นที่ 3 ตรวจกับแถวที่สาม: $0.800 \times 0.360 + 0.200 = 0.488$ ตรงพอดี ข้อมูลชุดนี้ไม่มีสัญญาณรบกวน สมการทั้งสามจึงให้คำตอบเดียวกัน กับข้อมูลจริงซึ่งมีสัญญาณรบกวน สมการจะขัดกันเล็กน้อย และสูตรกำลังสองน้อยที่สุดจะให้ค่าที่ประนีประนอมดีที่สุด

ขั้นที่ 4 แปลงเป็นพารามิเตอร์ทางกายภาพ

$$\tau = -\frac{0.1}{\ln 0.8} = 0.448\ \text{s}, \qquad K = \frac{0.200}{1 - 0.800} = 1.00$$

แบบจำลองคือ $G(s) = \dfrac{1}{0.448s + 1}$ ซึ่งนำไปจูน PI ด้วยวิธีในหน่วยที่ 13 ได้ทันที

นี่คือ machine learning ในรูปที่ง่ายที่สุด: เลือกโครงสร้างของแบบจำลอง เก็บข้อมูล แล้วหาพารามิเตอร์ที่ทำให้ค่าผิดพลาดของการทำนายน้อยที่สุด ฟังก์ชันจูนอัตโนมัติของไดรฟ์และตัวควบคุมอุณหภูมิทำขั้นตอนนี้อยู่เบื้องหลัง

ข้อมูลต้องมีการกระตุ้นเพียงพอ

ถ้าบันทึกข้อมูลขณะที่พลานต์อยู่นิ่งที่จุดทำงานเดียว ข้อมูลจะไม่บอกอะไรเกี่ยวกับพลวัตของพลานต์เลย ไม่ว่าจะมีกี่ล้านจุดก็ตาม อินพุตต้องเปลี่ยนแปลงมากพอให้พลานต์แสดงพฤติกรรมออกมา (persistent excitation) หลักข้อนี้ใช้กับ ML ทุกแบบ: แบบจำลองรู้ได้เฉพาะสิ่งที่ข้อมูลครอบคลุม

## การลดตามเกรเดียนต์

เมื่อแบบจำลองไม่เป็นเชิงเส้นในพารามิเตอร์ จะไม่มีสูตรสำเร็จ ต้องปรับพารามิเตอร์ทีละน้อยในทิศที่ทำให้ฟังก์ชันสูญเสีย $J$ ลดลง

$$w \leftarrow w - \eta\,\frac{\partial J}{\partial w}$$

โดย $\eta$ คืออัตราการเรียนรู้ มองเป็นลูปป้อนกลับได้: วัดค่าผิดพลาด แล้วปรับพารามิเตอร์สวนทางกับค่าผิดพลาดซ้ำไปเรื่อย ๆ เหมือนตัวควบคุมแบบอินทิกรัล และมีปัญหาเดียวกัน คือถ้า $\eta$ (เกน) สูงเกินไป การปรับจะแกว่งและลู่ออก

ตัวอย่างที่ 17.2 ลดตามเกรเดียนต์ด้วยมือ

ต้องการหา $w$ ของแบบจำลอง $y = wx$ จากข้อมูลสองจุด $(x, y) = (1, 2)$ และ $(2, 4)$ ใช้ฟังก์ชันสูญเสีย $J = \dfrac{1}{2}\sum (y_i - wx_i)^2$ เริ่มที่ $w = 0$ และ $\eta = 0.1$

เกรเดียนต์คือ $\dfrac{\partial J}{\partial w} = -\sum x_i(y_i - wx_i)$

## โครงข่ายประสาทเทียม

นิวรอนหนึ่งตัวคำนวณผลรวมถ่วงน้ำหนักของอินพุต แล้วส่งผ่านฟังก์ชันไม่เชิงเส้น

$$y = \sigma\!\left(\sum_i w_ix_i + b\right)$$

นักศึกษาไฟฟ้าเคยต่อวงจรนี้แล้ว: วงจรรวมสัญญาณด้วยออปแอมป์ (summing amplifier) ให้ผลรวมถ่วงน้ำหนักโดยน้ำหนักกำหนดด้วยอัตราส่วนตัวต้านทาน และเมื่อเอาต์พุตชนแรงดันของแหล่งจ่าย ออปแอมป์จะอิ่มตัว ซึ่งเป็นฟังก์ชันไม่เชิงเส้นแบบเดียวกับฟังก์ชันกระตุ้น (activation function) นิวรอนจึงเป็นวงจรรวมสัญญาณที่มีการอิ่มตัว ซึ่งน้ำหนักถูกปรับด้วยการลดตามเกรเดียนต์แทนการเลือกตัวต้านทาน

ตัวอย่างที่ 17.3 ดัชนีของลูปอันดับหนึ่ง

วงปิดในตัวอย่างที่ 13.1 เป็นระบบอันดับหนึ่งที่มี $\tau_c = 20$ ms ค่าผิดพลาดหลังอินพุตขั้นบันไดหนึ่งหน่วยคือ $e(t) = e^{-t/\tau_c}$ จงหา IAE และ ISE

$$\text{IAE} = \int_0^\infty e^{-t/\tau_c}\,dt = \tau_c = 0.020, \qquad \text{ISE} = \int_0^\infty e^{-2t/\tau_c}\,dt = \frac{\tau_c}{2} = 0.010$$

ทั้งสองดัชนีแปรตาม $\tau_c$ โดยตรง ลูปที่เร็วขึ้นเท่าตัวมีดัชนีลดลงครึ่งหนึ่ง ถ้าค่าที่คำนวณจากข้อมูลจริงสูงกว่านี้มาก แปลว่าลูปไม่ได้ทำงานตามที่ออกแบบ

เมื่อมีตัวเลขแล้ว AI เข้ามาช่วยในสามระดับ

- เฝ้าติดตามสมรรถนะของลูป (control loop performance monitoring) โรงงานกระบวนการมีลูป PID หลายพันลูป ซอฟต์แวร์คำนวณดัชนีจากข้อมูลใน DCS ต่อเนื่อง และใช้การจำแนกรูปแบบระบุสาเหตุ เช่น จูนไม่เหมาะ วาล์วฝืด (stiction) หรือเซนเซอร์เสื่อม วิศวกรจึงรู้ว่าต้องไปดูลูปใดก่อน

- การบำรุงรักษาเชิงพยากรณ์ (predictive maintenance) แบบจำลองเรียนรู้รูปแบบปกติของการสั่นสะเทือน อุณหภูมิ และสเปกตรัมของกระแสมอเตอร์ (motor current signature analysis) แล้วแจ้งเตือนเมื่อข้อมูลเริ่มเบี่ยงออก ซึ่งชี้ถึงตลับลูกปืนสึก โรเตอร์บาร์แตก หรือฉนวนเสื่อม ก่อนที่เครื่องจะหยุด

- การหาค่าเหมาะที่สุด ใช้อัลกอริทึมค้นหา เช่น ขั้นตอนวิธีเชิงพันธุกรรม หาค่า PID ที่ทำให้ ITAE ต่ำสุดบนแบบจำลอง หรือพยากรณ์โหลดและกำลังผลิตจากแสงอาทิตย์เพื่อวางแผนการเดินเครื่องในระบบไฟฟ้ากำลัง

## แบบฝึกหัด

แบบฝึกหัด 17.1

ข้อมูลจากการทดสอบขั้นบันได $u = 2$ ที่ $T = 0.5$ s คือ $y = 0,\ 3.0,\ 4.5,\ 5.25$ จงหา $a$, $b$, $\tau$ และ $K$

ดูเฉลย

แถวแรก: $3.0 = 2b$ ได้ $b = 1.5$ แถวที่สอง: $4.5 = 3.0a + 3.0$ ได้ $a = 0.5$ ตรวจ: $0.5 \times 4.5 + 3.0 = 5.25$

$\tau = -\dfrac{0.5}{\ln 0.5} = 0.721$ s และ $K = \dfrac{1.5}{1 - 0.5} = 3.0$ (ค่าสุดท้ายคือ $3 \times 2 = 6$)

แบบฝึกหัด 17.2

ในตัวอย่างที่ 17.2 ถ้าใช้ $\eta = 0.5$ จงคำนวณ $w$ สามรอบแรก แล้วอธิบายผล

ดูเฉลย

รอบ 1: $w = 0 + 0.5(10) = 5$ รอบ 2: ค่าผิดพลาดคือ $-3, -6$ เกรเดียนต์ $= -(1 \cdot (-3) + 2 \cdot (-6)) = 15$ ได้ $w = 5 - 7.5 = -2.5$ รอบ 3: ค่าผิดพลาดคือ $4.5, 9$ เกรเดียนต์ $= -22.5$ ได้ $w = 8.75$

ค่า $w$ แกว่งรอบ 2 ด้วยขนาดที่โตขึ้น ($3, -4.5, 6.75$) เพราะขั้วอยู่ที่ $z = 1 - 0.5 \times 5 = -1.5$ นอกวงกลมหนึ่งหน่วย การเรียนรู้ไม่เสถียร

แบบฝึกหัด 17.3

ลูปสองลูปมีค่าผิดพลาดหลังอินพุตขั้นบันไดเป็น $e_1(t) = e^{-t}$ และ $e_2(t) = e^{-4t}$ จงเทียบ IAE และ ISE

ดูเฉลย

ลูปที่ 1 ($\tau = 1$): IAE = 1, ISE = 0.5 ลูปที่ 2 ($\tau = 0.25$): IAE = 0.25, ISE = 0.125

ลูปที่ 2 ดีกว่า 4 เท่าในทั้งสองดัชนี

## สรุปหน่วยที่ 17 และสรุปรายวิชา

- Machine learning คือการหาฟังก์ชันจากข้อมูล การระบุระบบด้วยกำลังสองน้อยที่สุดคือรูปที่ง่ายที่สุดและใช้งานได้ทันที

- การลดตามเกรเดียนต์เป็นลูปป้อนกลับในปริภูมิของพารามิเตอร์ อัตราการเรียนรู้คือเกน และมีขีดจำกัดเสถียรภาพเช่นเดียวกัน

- นิวรอนคือผลรวมถ่วงน้ำหนักตามด้วยฟังก์ชันไม่เชิงเส้น เทียบได้กับวงจรรวมสัญญาณที่มีการอิ่มตัว

- ดัชนี IAE, ISE, ITAE ทำให้สมรรถนะของลูปเป็นตัวเลข ซึ่งเป็นฐานของการเฝ้าติดตามลูปและการบำรุงรักษาเชิงพยากรณ์ด้วย AI

- ในระบบจริง AI ทำงานชั้นบน ส่วนลูปเรียลไทม์และระบบป้องกันยังต้องวิเคราะห์เสถียรภาพและความปลอดภัยได้

ทั้งรายวิชาเดินตามคำถามสามข้อจากหน่วยที่ 1: ระบบมีพฤติกรรมอย่างไร (ภาคที่ 1) เอาต์พุตเปลี่ยนอย่างไรและเสถียรหรือไม่ (ภาคที่ 2) และจะออกแบบตัวควบคุมอย่างไร (ภาคที่ 3–5) เครื่องมือเปลี่ยนจากออปแอมป์เป็นไมโครคอนโทรลเลอร์ และจากสมการเป็นข้อมูล แต่คำถามสามข้อนี้ยังเป็นคำถามเดิม
