# การควบคุมด้วยฟัซซีลอจิก

// หน่วยที่ 16 · Control Engineering · Fuzzy Logic Control


หลักการของฟัซซีลอจิกสำหรับผู้เริ่มต้น เซตฟัซซีและฟังก์ชันภาวะสมาชิก ขั้นตอนฟัซซิฟิเคชัน ฐานกฎ การอนุมาน และดีฟัซซิฟิเคชัน ตัวอย่างคำนวณด้วยมือทีละขั้น ตัวควบคุมฟัซซีแบบ PD และการเทียบกับ PID

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- อธิบายความต่างระหว่างเซตแบบดั้งเดิมกับเซตฟัซซี และคำนวณค่าภาวะสมาชิกจากฟังก์ชันรูปสามเหลี่ยมได้
- อธิบายสี่ขั้นตอนของตัวควบคุมฟัซซี ได้แก่ ฟัซซิฟิเคชัน ฐานกฎ การอนุมาน และดีฟัซซิฟิเคชัน
- คำนวณเอาต์พุตของตัวควบคุมฟัซซีที่มีหนึ่งและสองอินพุตด้วยมือได้
- บอกได้ว่างานแบบใดเหมาะกับฟัซซี และงานแบบใดควรใช้ PID

## ภาพในใจก่อนเริ่ม: ช่างที่ชำนาญไม่ได้แก้สมการ

ช่างคุมเตาที่มีประสบการณ์รักษาอุณหภูมิได้ดีโดยไม่เคยเขียนฟังก์ชันถ่ายโอน เขาใช้กฎในใจ: "ถ้าอุณหภูมิต่ำกว่าเป้ามาก ให้เร่งไฟแรง" "ถ้าใกล้ถึงแล้วและกำลังขึ้นเร็ว ให้ผ่อนไฟ" คำว่า มาก ใกล้ เร็ว แรง ไม่มีเส้นแบ่งที่ชัดเจน แต่ใช้งานได้จริง

ฟัซซีลอจิก (fuzzy logic) ซึ่งลอตฟี ซาเดห์ (Lotfi Zadeh) เสนอในปี ค.ศ. 1965 เป็นคณิตศาสตร์ที่ทำให้คำกำกวมเหล่านี้คำนวณได้ ตัวควบคุมฟัซซีจึงเป็นวิธีถ่ายความรู้ของผู้เชี่ยวชาญลงในตัวควบคุมโดยตรง เหมาะกับพลานต์ที่ไม่เชิงเส้นหรือสร้างแบบจำลองได้ยาก

เทียบกับสิ่งที่นักศึกษาไฟฟ้ารู้จัก: วงจรคอนโทรลของแมกเนติกคอนแทคเตอร์และโปรแกรมแลดเดอร์ใช้ตรรกะแบบบูล หน้าสัมผัสมีสองสถานะคือเปิดหรือปิด ฟัซซีลอจิกขยายแนวคิดเดียวกันให้ "จริง" มีระดับได้ตั้งแต่ 0 ถึง 1

## เซตฟัซซีและฟังก์ชันภาวะสมาชิก

ในเซตแบบดั้งเดิม อุณหภูมิ 59.9 °C "ไม่ร้อน" และ 60.0 °C "ร้อน" ถ้าเส้นแบ่งอยู่ที่ 60 ในเซตฟัซซี สมาชิกแต่ละตัวมีระดับภาวะสมาชิก (degree of membership) $\mu$ ระหว่าง 0 ถึง 1 อุณหภูมิ 55 °C อาจ "ร้อน" ด้วยระดับ 0.5 และ "อุ่น" ด้วยระดับ 0.5 พร้อมกัน

ฟังก์ชันภาวะสมาชิก (membership function) กำหนดระดับนี้ รูปที่ใช้มากที่สุดคือสามเหลี่ยมที่มีฐานจาก $a$ ถึง $c$ และยอดที่ $b$

$$\mu(x) = \begin{cases} \dfrac{x - a}{b - a} & a \le x \le b \\[2mm] \dfrac{c - x}{c - b} & b < x \le c \\[2mm] 0 & \text{กรณีอื่น} \end{cases}$$

ตัวแปรที่มีค่าเป็นคำ เช่น "ค่าผิดพลาด" มีค่าได้เป็น ลบ ศูนย์ บวก เรียกว่าตัวแปรภาษา (linguistic variable)

การกระทำทางตรรกะกับเซตฟัซซีที่ใช้ในตัวควบคุม

|
ตรรกะ |
การคำนวณที่นิยม |

|
A และ B (AND) |
$\min(\mu_A, \mu_B)$ |

|
A หรือ B (OR) |
$\max(\mu_A, \mu_B)$ |

|
ไม่ใช่ A (NOT) |
$1 - \mu_A$ |

เมื่อ $\mu$ มีค่าเพียง 0 กับ 1 ตารางนี้ให้ผลเหมือนตรรกะบูลทุกประการ

ตัวควบคุมมีสองแบบหลัก แบบมัมดานี (Mamdani) ให้เอาต์พุตของกฎเป็นเซตฟัซซี แล้วหาจุดศูนย์ถ่วงของพื้นที่รวม แบบซูเกโน (Sugeno) ให้เอาต์พุตของกฎเป็นค่าคงที่หรือฟังก์ชันเชิงเส้น แล้วหาค่าเฉลี่ยถ่วงน้ำหนัก

$$u = \frac{\sum_i w_i\,u_i}{\sum_i w_i}$$

โดย $w_i$ คือน้ำหนักของกฎข้อที่ $i$ และ $u_i$ คือเอาต์พุตของกฎข้อนั้น แบบซูเกโนคำนวณเร็ว จึงนิยมใช้ในไมโครคอนโทรลเลอร์และ PLC หน่วยนี้ใช้แบบซูเกโนอันดับศูนย์ในตัวอย่าง

ตัวอย่างที่ 16.1 ตัวควบคุมฮีตเตอร์อินพุตเดียว

ตัวควบคุมอุณหภูมิใช้ค่าผิดพลาด $e$ = ค่าที่ตั้ง − ค่าที่วัด (°C) มีฟังก์ชันภาวะสมาชิก N, Z, P ตามรูป และกฎสามข้อ

- ถ้า $e$ เป็น N (ร้อนเกินเป้า) แล้วกำลังฮีตเตอร์ = 0 %

- ถ้า $e$ เป็น Z (ถึงเป้า) แล้วกำลังฮีตเตอร์ = 50 %

- ถ้า $e$ เป็น P (ต่ำกว่าเป้า) แล้วกำลังฮีตเตอร์ = 100 %

จงหากำลังฮีตเตอร์เมื่อ $e = 4$ °C

ขั้นที่ 1 ฟัซซิฟิเคชัน จากสมการของเส้นตรงแต่ละด้าน

$$\mu_N(4) = 0, \qquad \mu_Z(4) = 1 - \frac{4}{10} = 0.6, \qquad \mu_P(4) = \frac{4}{10} = 0.4$$

ขั้นที่ 2–3 การอนุมาน กฎแต่ละข้อมีเงื่อนไขเดียว น้ำหนักจึงเท่ากับระดับภาวะสมาชิก: $w_N = 0$, $w_Z = 0.6$, $w_P = 0.4$

ขั้นที่ 4 ดีฟัซซิฟิเคชัน

$$u = \frac{(0)(0) + (0.6)(50) + (0.4)(100)}{0 + 0.6 + 0.4} = 70\ \%$$

ถ้าคำนวณซ้ำที่ค่า $e$ อื่นจะพบว่า $u = 50 + 5e$ ในช่วง $-10 \le e \le 10$ และอิ่มตัวที่ 0 % กับ 100 % นอกช่วง ตัวควบคุมฟัซซีที่ง่ายที่สุดนี้จึงเป็นตัวควบคุม P ที่มีการอิ่มตัว ความสามารถที่เกินกว่า PID ปรากฏเมื่อปรับรูปของฟังก์ชันภาวะสมาชิกหรือกฎให้ไม่สมมาตร เช่น ให้เกนสูงเมื่ออยู่ไกลเป้าและเกนต่ำเมื่อใกล้เป้า

อ่านตารางตามสามัญสำนึก: มุมซ้ายบน ค่าผิดพลาดเป็นลบและยังลดลงอีก ต้องสั่งลบเต็มที่ มุมขวาบน ค่าผิดพลาดเป็นลบแต่กำลังกลับขึ้นมาเอง ไม่ต้องสั่งเพิ่ม กฎลักษณะนี้คือสิ่งที่ส่วน D ของ PID ทำ แต่เขียนเป็นภาษาที่ช่างเข้าใจและแก้ไขทีละช่องได้

ตัวอย่างที่ 16.2 คำนวณตัวควบคุมฟัซซีสองอินพุต

ใช้ตารางกฎด้านบน ค่าผิดพลาด $e$ ใช้ฟังก์ชันภาวะสมาชิกช่วง ±10 เหมือนเดิม ส่วน $\Delta e$ ใช้รูปเดียวกันในช่วง ±5 จงหาเอาต์พุตเมื่อ $e = 4$ และ $\Delta e = -1$

ขั้นที่ 1 ฟัซซิฟิเคชัน

- $e = 4$: $\mu_Z = 0.6$, $\mu_P = 0.4$

- $\Delta e = -1$: $\mu_N = \dfrac{1}{5} = 0.2$, $\mu_Z = 1 - \dfrac{1}{5} = 0.8$

ขั้นที่ 2–3 การอนุมาน กฎที่ทำงานมีสี่ข้อ ใช้ $\min$ สำหรับคำว่า "และ"

ขั้นที่ 4 ดีฟัซซิฟิเคชัน

$$u = \frac{(0.2)(-1) + (0.6)(0) + (0.2)(0) + (0.4)(1)}{0.2 + 0.6 + 0.2 + 0.4} = \frac{0.2}{1.4} = 0.143$$

เอาต์พุตเป็นบวกเล็กน้อย: ยังต่ำกว่าเป้าอยู่จึงสั่งเพิ่ม แต่เพราะค่าผิดพลาดกำลังลดลงเอง ($\Delta e < 0$) จึงสั่งน้อยกว่ากรณีที่ $\Delta e = 0$ ซึ่งจะได้ $u = 0.4$

## แบบฝึกหัด

แบบฝึกหัด 16.1

ฟังก์ชันภาวะสมาชิกรูปสามเหลี่ยม "อุ่น" มี $a = 30$, $b = 50$, $c = 70$ °C จงหา $\mu$ ที่ 35, 50 และ 62 °C

ดูเฉลย

$\mu(35) = \dfrac{35 - 30}{50 - 30} = 0.25$, $\mu(50) = 1$, $\mu(62) = \dfrac{70 - 62}{70 - 50} = 0.4$

แบบฝึกหัด 16.2

ใช้ตัวควบคุมในตัวอย่างที่ 16.1 จงหากำลังฮีตเตอร์เมื่อ $e = -3$ °C

ดูเฉลย

$\mu_N = 0.3$, $\mu_Z = 0.7$, $\mu_P = 0$

$u = \dfrac{(0.3)(0) + (0.7)(50)}{1.0} = 35\ \%$ ตรงกับ $50 + 5(-3)$

แบบฝึกหัด 16.3

ใช้ตัวควบคุมในตัวอย่างที่ 16.2 จงหาเอาต์พุตเมื่อ $e = -2$ และ $\Delta e = 3$

ดูเฉลย

$e = -2$: $\mu_N = 0.2$, $\mu_Z = 0.8$ และ $\Delta e = 3$: $\mu_Z = 0.4$, $\mu_P = 0.6$

กฎ (N, Z) → N: $w = \min(0.2, 0.4) = 0.2$; กฎ (N, P) → Z: $w = 0.2$; กฎ (Z, Z) → Z: $w = 0.4$; กฎ (Z, P) → P: $w = 0.6$

$u = \dfrac{(0.2)(-1) + 0 + 0 + (0.6)(1)}{0.2 + 0.2 + 0.4 + 0.6} = \dfrac{0.4}{1.4} = 0.286$

## สรุปหน่วยที่ 16

- เซตฟัซซีให้สมาชิกมีระดับภาวะสมาชิกระหว่าง 0 ถึง 1 ทำให้คำอย่าง "มาก" หรือ "ใกล้" คำนวณได้
