# ตัวแปรเชิงซ้อน ฟังก์ชันเชิงซ้อน การส่งภาพ (mapping) และระนาบ s

// หน่วยที่ 2 · Control Engineering · Complex Variables, Complex Functions, Mapping and the s-Plane


ปูพื้นตัวแปรเชิงซ้อนสำหรับระบบควบคุม ฟังก์ชันวิเคราะห์ เงื่อนไขโคชี–รีมันน์ การส่งภาพแบบคอนฟอร์มัล ระนาบ s ขั้วและศูนย์ และหลักการของมุม พร้อมแล็บ mapping โต้ตอบและแบบฝึกหัด

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- คำนวณกับจำนวนเชิงซ้อนทั้งรูปสี่เหลี่ยมและรูปเชิงขั้ว และคำนวณค่าของ F(s) ที่จุดเชิงซ้อนได้
- บอกได้ว่าฟังก์ชันเชิงซ้อนเป็นฟังก์ชันวิเคราะห์หรือไม่ด้วยเงื่อนไขโคชี–รีมันน์
- อธิบายสมบัติ conformal และหาภาพของเส้นตรงภายใต้ฟังก์ชันง่ายๆ ได้
- อ่านตำแหน่งขั้วบนระนาบ s แล้วบอกพฤติกรรมของผลตอบสนองและหา ζ, ωn ได้
- ระบุได้ว่าผลตอบสนองความถี่ F(jω) คือภาพของแกนจินตภาพ และเข้าใจที่มาของหลักการของมุม

## ทำไมวิชาควบคุมต้องใช้จำนวนเชิงซ้อน

ระบบเชิงเส้นไม่แปรตามเวลาทุกระบบมีคำตอบอยู่ในรูป $e^{st}$ ที่ $s$ เป็นค่าคงที่

ลองแทน $y = e^{st}$ ลงใน $\dot y + 3y = 0$

$$s e^{st} + 3 e^{st} = 0 \;\Longrightarrow\; s = -3$$

กรณีนี้ $s$ เป็นจำนวนจริง แต่สมการอันดับสอง $\ddot y + 2\dot y + 5y = 0$ ให้

$$s^2 + 2s + 5 = 0 \;\Longrightarrow\; s = -1 \pm j2$$

ตัวเลข $s$ กลายเป็นจำนวนเชิงซ้อน และ $e^{(-1+j2)t} = e^{-t}(\cos 2t + j\sin 2t)$ คือการแกว่งที่ค่อยๆ ลดลง

ดังนั้น $s$ ตัวเดียวบอกได้ทั้งอัตราการลด (ส่วนจริง) และความถี่การแกว่ง (ส่วนจินตภาพ) หน่วยนี้สร้างภาษาที่เราจะใช้ตลอดวิชา

## จำนวนเชิงซ้อน

เขียน $s = \sigma + j\omega$ โดย $\sigma = \operatorname{Re}\,s$ และ $\omega = \operatorname{Im}\,s$ ในงานวิศวกรรมใช้ $j$ แทน $i$ เพื่อไม่ชนกับกระแส

รูปเชิงขั้ว ใช้ขนาดและมุม

$$s = \lvert s\rvert\, e^{j\theta}, \qquad \lvert s \rvert = \sqrt{\sigma^2 + \omega^2}, \qquad \theta = \arg s = \operatorname{atan2}(\omega,\sigma)$$

สูตรออยเลอร์เชื่อมสองรูปเข้าด้วยกัน

$$e^{j\theta} = \cos\theta + j\sin\theta$$

คอนจูเกต ของ $s$ คือ $\bar s = \sigma - j\omega$ และ $s\bar s = \lvert s\rvert^2$

การดำเนินการที่ใช้บ่อย

- คูณ ขนาดคูณกัน มุมบวกกัน $\;\lvert s_1 s_2\rvert = \lvert s_1\rvert\lvert s_2\rvert,\ \arg(s_1 s_2) = \arg s_1 + \arg s_2$

- หาร ขนาดหารกัน มุมลบกัน

- หารในรูปสี่เหลี่ยม คูณทั้งเศษและส่วนด้วยคอนจูเกตของตัวส่วน

ตัวอย่างที่ 2.1

เขียน $s = -3 + j4$ ในรูปเชิงขั้ว

ขนาด $\lvert s \rvert = \sqrt{9 + 16} = 5$

มุม $\theta = \operatorname{atan2}(4, -3) = 126.87^\circ$ (อยู่ในจตุภาคที่สอง ห้ามใช้ $\tan^{-1}(4/(-3)) = -53.13^\circ$ ตรงๆ เพราะจะผิดจตุภาค)

$$s = 5\,e^{j\,126.87^\circ}$$

## ฟังก์ชันเชิงซ้อน

ฟังก์ชันเชิงซ้อน $F(s)$ รับจำนวนเชิงซ้อนแล้วคืนจำนวนเชิงซ้อน แยกส่วนจริงและส่วนจินตภาพได้เป็น

$$F(s) = u(\sigma,\omega) + j\,v(\sigma,\omega)$$

ฟังก์ชันถ่ายโอนเป็นตัวอย่างโดยตรง การหาค่าที่จุดเชิงซ้อนก็คือการแทนค่าแล้วคำนวณพีชคณิต

ตัวอย่างที่ 2.2

หา $F(s) = \dfrac{s + 1}{s^2 + 2s + 5}$ ที่ $s = j2$

เศษ: $1 + j2$

ส่วน: $(j2)^2 + 2(j2) + 5 = -4 + j4 + 5 = 1 + j4$

$$F(j2) = \frac{1 + j2}{1 + j4}\cdot\frac{1 - j4}{1 - j4} = \frac{1 - j4 + j2 + 8}{17} = \frac{9 - j2}{17} = 0.529 - j\,0.118$$

ขนาด $\lvert F\rvert = 0.542$ มุม $\arg F = -12.5^\circ$

ค่า $F(j\omega)$ ที่เปลี่ยน $\omega$ คือผลตอบสนองความถี่ เราจะกลับมาที่ข้อนี้ท้ายหน่วย

## การส่งภาพ (mapping)

เพราะอินพุตกับเอาต์พุตต่างเป็นจำนวนเชิงซ้อน เราจึงวาดกราฟ $F$ แบบปกติไม่ได้ (ต้องใช้สี่มิติ)

วิธีที่ใช้แทนคือวาดสองระนาบ ระนาบ $s$ เป็นโดเมน ระนาบ $w$ ที่ $w = F(s)$ เป็นพิสัย แล้วดูว่า ภาพ ของจุดและเส้นในระนาบ $s$ ไปอยู่ที่ใดในระนาบ $w$

ตัวอย่างที่ 2.3

หาภาพของเส้นดิ่ง $\operatorname{Re}\,s = 1$ ภายใต้ $w = s^2$

เส้นนี้คือ $s = 1 + j\omega$ ดังนั้น

$$w = (1 + j\omega)^2 = (1 - \omega^2) + j\,2\omega$$

ให้ $u = 1 - \omega^2$ และ $v = 2\omega$ กำจัด $\omega = v/2$

$$u = 1 - \frac{v^2}{4}$$

ภาพเป็นพาราโบลาเปิดไปทางซ้าย มียอดที่ $w = 1$

## ฟังก์ชันวิเคราะห์และเงื่อนไขโคชี–รีมันน์

อนุพันธ์เชิงซ้อนนิยามเหมือนอนุพันธ์จริง

$$F'(s_0) = \lim_{\Delta s \to 0}\frac{F(s_0 + \Delta s) - F(s_0)}{\Delta s}$$

ข้อแตกต่างสำคัญคือ $\Delta s$ เป็นจำนวนเชิงซ้อน จึงเข้าหาศูนย์ได้ จากทุกทิศทางในระนาบ และลิมิตต้องได้ค่าเดียวกันทุกทิศ

ฟังก์ชันที่มีอนุพันธ์ในบริเวณหนึ่งเรียกว่า ฟังก์ชันวิเคราะห์ (analytic function)

ถ้าเข้าหาตามแนวนอน $\Delta s = \Delta\sigma$ และตามแนวดิ่ง $\Delta s = j\Delta\omega$ แล้วบังคับให้ได้ค่าเท่ากัน จะได้

$$\frac{\partial u}{\partial \sigma} = \frac{\partial v}{\partial \omega}, \qquad \frac{\partial u}{\partial \omega} = -\frac{\partial v}{\partial \sigma}$$

นี่คือ เงื่อนไขโคชี–รีมันน์ และเมื่อเป็นฟังก์ชันวิเคราะห์ อนุพันธ์คือ

$$F'(s) = \frac{\partial u}{\partial \sigma} + j\,\frac{\partial v}{\partial \sigma}$$

ตัวอย่างที่ 2.4

(ก) $F = s^2 + s$ วิเคราะห์หรือไม่ และ $F'(1+j)$ เป็นเท่าใด

แยกส่วน: $u = \sigma^2 - \omega^2 + \sigma$ และ $v = 2\sigma\omega + \omega$

$u_\sigma = 2\sigma + 1 = v_\omega$ ✓ และ $u_\omega = -2\omega = -v_\sigma$ ✓ เป็นฟังก์ชันวิเคราะห์

$F' = u_\sigma + j v_\sigma = (2\sigma+1) + j\,2\omega$ ที่ $\sigma = 1,\ \omega = 1$ ได้ $3 + j2$ ซึ่งตรงกับสูตร $F' = 2s + 1 = 3 + j2$

(ข) $F = \bar s$ (คอนจูเกต) ได้ $u = \sigma,\ v = -\omega$

$u_\sigma = 1$ แต่ $v_\omega = -1$ ไม่เท่ากัน จึงไม่เป็นฟังก์ชันวิเคราะห์ที่จุดใดเลย

ฟังก์ชันตรรกยะ ($F = N(s)/D(s)$) เป็นฟังก์ชันวิเคราะห์ทุกจุด ยกเว้นที่รากของตัวส่วน

- ศูนย์ (zero) คือจุดที่ $F(s) = 0$ คือรากของเศษ

- ขั้ว (pole) คือจุดที่ $F(s) \to \infty$ คือรากของตัวส่วน (ตัวส่วนไม่หักล้างกับเศษ)

ในระบบควบคุม ขั้วและศูนย์ของฟังก์ชันถ่ายโอนมีความหมายทางกายภาพโดยตรง และเป็นตัวกำหนดผลตอบสนองทั้งหมด

## การส่งภาพแบบคอนฟอร์มัล (conformal mapping)

ถ้า $F$ วิเคราะห์ที่ $s_0$ การเคลื่อนที่เล็กๆ รอบ $s_0$ ให้

$$F(s_0 + \Delta s) \approx F(s_0) + F'(s_0)\,\Delta s$$

เพราะ $F'(s_0)$ เป็นจำนวนเชิงซ้อนตัวเดียวสำหรับทุกทิศทาง เขียนเป็น $F'(s_0) = \lvert F'\rvert e^{j\varphi}$ ได้

ผลคือ ทุกการเคลื่อนที่เล็กๆ ถูกหมุนด้วยมุม $\varphi$ เท่ากัน และถูกขยายด้วยตัวคูณ $\lvert F' \rvert$ เท่ากัน

ดังนั้นเส้นโค้งสองเส้นที่ตัดกันที่ $s_0$ จะหมุนไปด้วยกัน มุมระหว่างเส้นจึงไม่เปลี่ยน นี่คือสมบัติ conformal

สมบัติ conformal

ถ้า $F'(s_0) \ne 0$ การส่งภาพ $w = F(s)$ รักษามุม (ทั้งขนาดและทิศ) ที่ $s_0$ ภาพของเส้นกริดตั้งฉากจึงยังตั้งฉากกัน

ความยาวถูกขยาย $\lvert F'\rvert$ เท่า และพื้นที่ถูกขยาย $\lvert F'\rvert^2$ เท่า

ที่ จุดวิกฤต (critical point) ซึ่ง $F'(s_0) = 0$ สมบัตินี้เสียไป ถ้า $F(s) - F(s_0)$ มีศูนย์อันดับ $m$ ที่ $s_0$ มุมจะถูกคูณด้วย $m$

ตัวอย่างคือ $w = s^2$ ที่ $s = 0$ ซึ่ง $F' = 2s = 0$ เส้นครึ่งเส้นที่ทำมุม $\alpha$ กับแกนจริงถูกส่งเป็นเส้นที่มุม $2\alpha$ จตุภาคที่หนึ่งถูกกางออกเป็นครึ่งระนาบบน

## ตัวอย่างการส่งภาพที่ต้องรู้

1) การเลื่อนและการหมุนขยาย $w = s + a$ เลื่อนทุกจุดเท่ากัน $w = bs$ หมุนด้วย $\arg b$ และขยายด้วย $\lvert b\rvert$

2) การผกผัน $w = 1/s$ ส่งเส้นดิ่งเป็นวงกลม

ตัวอย่างที่ 2.5

แสดงว่า $w = 1/s$ ส่งเส้น $\operatorname{Re}\,s = c$ (ที่ $c > 0$) เป็นวงกลม

$s = c + j\omega$ ได้

$$w = \frac{c - j\omega}{c^2 + \omega^2}, \qquad u = \frac{c}{c^2 + \omega^2},\quad v = \frac{-\omega}{c^2 + \omega^2}$$

คำนวณ $u^2 + v^2 = \dfrac{c^2 + \omega^2}{(c^2+\omega^2)^2} = \dfrac{1}{c^2 + \omega^2} = \dfrac{u}{c}$

ย้ายข้างได้ $\left(u - \dfrac{1}{2c}\right)^2 + v^2 = \left(\dfrac{1}{2c}\right)^2$

เป็นวงกลมรัศมี $\dfrac{1}{2c}$ ศูนย์กลางที่ $\dfrac{1}{2c}$ ผ่านจุดกำเนิดของระนาบ $w$ (ซึ่งเป็นภาพของ $s = \infty$)

3) การแปลงแบบบิลิเนียร์ (bilinear) $w = \dfrac{1 + s}{1 - s}$

เส้น $s = j\omega$ ให้ $\lvert 1 + j\omega\rvert = \lvert 1 - j\omega\rvert$ ดังนั้น $\lvert w\rvert = 1$ แกนจินตภาพถูกส่งเป็นวงกลมหนึ่งหน่วย

ครึ่งซ้ายของระนาบ $s$ มี $\lvert 1 + s\rvert < \lvert 1 - s\rvert$ (จุดอยู่ใกล้ $-1$ มากกว่า $+1$) จึงให้ $\lvert w\rvert < 1$ คือภายในวงกลม

เชื่อมไปยังระบบดิจิทัล

การแปลง Tustin ที่ใช้แปลงตัวควบคุมต่อเนื่องเป็นดิจิทัลคือ $z = \dfrac{1 + sT/2}{1 - sT/2}$ ซึ่งเป็นแบบบิลิเนียร์ตัวนี้เอง

จึงส่งครึ่งซ้ายของระนาบ $s$ เป็นภายในวงกลมหนึ่งหน่วยของระนาบ $z$ และรักษาเสถียรภาพไว้ เรื่องนี้จะกลับมาในหน่วยที่ 26

4) เอ็กซ์โพเนนเชียล $w = e^s$ ส่งเส้นดิ่ง $\operatorname{Re}\,s = c$ เป็นวงกลมรัศมี $e^c$ และส่งเส้นนอน $\operatorname{Im}\,s = y$ เป็นเส้นครึ่งเส้นที่มุม $y$ จึงเป็นการส่งภาพที่พบในการสุ่มสัญญาณ $z = e^{sT}$

## แล็บ: ส่งภาพระนาบ s

กริดสีน้ำเงินและสีเทาคือเส้น $\sigma$ คงที่และ $\omega$ คงที่ในระนาบ $s$ ด้านขวาคือภาพของมัน เส้นสีส้มหนาคือแกน $j\omega$ และภาพของมัน จุดสีเขียวคือกากบาทเล็กๆ ที่จุด $s_0$ และภาพของมัน

ลองตามนี้

- เลือก $s^2$ ลาก $s_0$ ไปใกล้ 0 ดูว่ากากบาทบิดไปอย่างไร และข้อความจุดวิกฤตขึ้นเมื่อใด

- เลือก $1/s$ ดูว่าเส้นดิ่งกลายเป็นวงกลมตามตัวอย่างที่ 2.5

- เลือกบิลิเนียร์ ดูว่าครึ่งซ้ายของระนาบอยู่ในหรือนอกวงกลมหนึ่งหน่วย

- เลือก $e^s$ ดูว่ากริดกลายเป็นวงกลมและรัศมี

- ที่ทุกฟังก์ชัน ตรวจว่ามุมระหว่างภาพของเส้นนอนกับเส้นดิ่งเป็น 90° เสมอ ยกเว้นที่จุดวิกฤต

### เส้นคงที่บนระนาบ s

เขียนขั้วคู่เชิงซ้อนในรูปมาตรฐานอันดับสอง

$$p = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}$$

ตรงนี้ $\omega_n$ คือความถี่ธรรมชาติ และ $\zeta$ คืออัตราส่วนความหน่วง จากสมการนี้

- เส้นดิ่ง $\sigma = \zeta\omega_n$ คงที่ คือเวลาเข้าที่คงที่ ($t_s \approx 4/\sigma$)

- เส้นนอน $\omega_d = \omega_n\sqrt{1-\zeta^2}$ คงที่ คือความถี่การแกว่งคงที่

- วงกลมรอบจุดกำเนิด $\lvert p\rvert = \omega_n$ คงที่ เพราะ $\lvert p \rvert^2 = \zeta^2\omega_n^2 + \omega_n^2(1-\zeta^2) = \omega_n^2$

- เส้นครึ่งเส้นจากจุดกำเนิด $\zeta$ คงที่ เพราะมุมจากแกนจริงลบคือ $\theta = \cos^{-1}\zeta$ (จาก $\cos\theta = \sigma/\lvert p\rvert = \zeta$)

ตัวอย่างที่ 2.6

ขั้วคู่หนึ่งอยู่ที่ $s = -3 \pm j4$ หาพารามิเตอร์ของมัน

$\omega_n = \lvert p\rvert = \sqrt{9+16} = 5$ rad/s

$\zeta = \sigma/\omega_n = 3/5 = 0.6$

มุมจากแกนจริงลบ $\theta = \cos^{-1}0.6 = 53.13^\circ$

เวลาเข้าที่ $t_s \approx 4/\sigma = 4/3 = 1.33$ s

เปอร์เซ็นต์พุ่งเกิน $M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} = e^{-0.6\pi/0.8} = 9.48\%$

เราได้เกือบทุกอย่างของผลตอบสนองชั่วครู่จากตำแหน่งเดียวบนระนาบ ซึ่งเป็นเหตุผลที่รูทโลคัสและการออกแบบด้วยขั้วจึงทรงพลัง

## ผลตอบสนองความถี่คือภาพของแกน jω

ใส่อินพุตไซน์ $e^{j\omega t}$ ให้ระบบเชิงเส้น เอาต์พุตสถานะอยู่ตัวคือ $F(j\omega)\,e^{j\omega t}$ นั่นคือถูกคูณด้วยจำนวนเชิงซ้อน $F(j\omega)$ ที่เปลี่ยนขนาดด้วย $\lvert F(j\omega)\rvert$ และเลื่อนเฟสด้วย $\arg F(j\omega)$

ดังนั้นผลตอบสนองความถี่ทั้งหมดก็คือ ภาพของแกนจินตภาพ $s = j\omega$ ภายใต้ $F$ นั่นคือเส้นสีส้มในแล็บ

ลองใช้ฟังก์ชันถ่ายโอนอันดับสองในแล็บนี้ และลากจุด $s_0$ ไปตามแกน $j\omega$ (ให้ σ = 0) ดูภาพที่วิ่งไปตามเส้นหนา ซึ่งเป็นแผนภาพของผลตอบสนองความถี่ในระนาบเชิงซ้อน

กราฟโบดแยกเส้นโค้งนี้เป็นสองกราฟ (ขนาดกับมุม) ส่วนแผนภาพไนควิสต์วาดมันในระนาบเดียว ทั้งสองมีรากที่เดียวกันคือการส่งภาพนี้

## หลักการของมุม (argument principle)

เรื่องนี้ใช้ในหน่วยไนควิสต์ ใส่ไว้ที่นี่เพราะเป็นผลโดยตรงของการส่งภาพ

ให้ $F$ วิเคราะห์ในบริเวณหนึ่งและมีขั้วศูนย์จำกัด ลากเส้นโค้งปิดง่ายๆ $\Gamma$ ที่ไม่ผ่านขั้วหรือศูนย์ใด ทิศทวนเข็มนาฬิกา ภาพของ $\Gamma$ คือเส้นโค้งปิดใน $w$-plane

ถ้า $\Gamma$ ล้อม $Z$ ศูนย์และ $P$ ขั้ว (นับตามอันดับ) แล้ว

$$N = \text{จำนวนรอบที่ภาพล้อมจุดกำเนิดทวนเข็มนาฬิกา} = Z - P$$

เหตุผลโดยย่อ ใกล้ศูนย์อันดับ $m$ ที่ $z_0$ เขียน $F \approx a(s - z_0)^m$ ได้ มุมของ $F$ เปลี่ยน $m$ เท่าของมุมของ $(s - z_0)$ เมื่อ $s$ เดินครบรอบ $z_0$ มุมของ $(s-z_0)$ เพิ่ม $2\pi$ มุมของ $F$ จึงเพิ่ม $2\pi m$ ขั้วทำตรงกันข้ามคือลด $2\pi m$ ส่วนศูนย์หรือขั้วที่อยู่นอก $\Gamma$ ไม่ทำให้มุมเปลี่ยนสุทธิ

พูดอีกแบบ $\oint_\Gamma \dfrac{F'(s)}{F(s)}\,ds = j\,\Delta_\Gamma \arg F = 2\pi j\,(Z - P)$

ตัวอย่างที่ 2.7

$F(s) = \dfrac{s+1}{(s+2)(s-1)(s+5)}$ และ $\Gamma$ คือวงกลม $\lvert s\rvert = 3$ ทวนเข็ม ภาพ $F(\Gamma)$ ล้อมจุดกำเนิดกี่รอบ

ศูนย์ที่ $s = -1$ อยู่ภายใน $(Z = 1)$

ขั้วที่ $s = -2$ และ $s = +1$ อยู่ภายใน ส่วน $s = -5$ อยู่ภายนอก $(P = 2)$

$N = Z - P = -1$ นั่นคือภาพล้อมจุดกำเนิดหนึ่งรอบ ตามเข็มนาฬิกา ตรวจด้วยการคำนวณเชิงตัวเลขได้ค่า $-1.00$ ตรงกัน

เมื่อเลือก $\Gamma$ เป็นเส้นขอบครึ่งขวาของระนาบ $s$ ทั้งหมด หลักการนี้นับขั้วที่ไม่เสถียรได้ ซึ่งคือเกณฑ์ไนควิสต์ในหน่วยที่ 18

หลักการเดียวกันเป็นฐานของทฤษฎีเรซิดิว $\oint F\,ds = 2\pi j\sum \text{Res}$ ซึ่งเป็นวิธีหาการแปลงลาปลาซผกผันในหน่วยที่ 4

## แบบฝึกหัด

แบบฝึกหัด 2.1 ผลตอบสนองความถี่ที่ความถี่หนึ่ง

$F(s) = \dfrac{10}{s + 5}$ หา $\lvert F(j5)\rvert$ และ $\arg F(j5)$

ดูเฉลย

$$F(j5) = \frac{10}{5 + j5} = \frac{10(5 - j5)}{50} = 1 - j1$$

$\lvert F\rvert = \sqrt{2} = 1.414$ และ $\arg F = -45^\circ$

ที่ความถี่มุม ($\omega = 5$ rad/s) เฟสเป็น $-45^\circ$ เสมอสำหรับระบบอันดับหนึ่ง

แบบฝึกหัด 2.2 ภาพของเส้นนอน

หาภาพของเส้นนอน $\operatorname{Im}\,s = 1$ ภายใต้ $w = s^2$

ดูเฉลย

$s = \sigma + j$ ดังนั้น $w = \sigma^2 - 1 + j\,2\sigma$ ได้ $u = \sigma^2 - 1,\ v = 2\sigma$

$$u = \frac{v^2}{4} - 1$$

พาราโบลาเปิดไปทางขวา ยอดที่ $w = -1$ ภาพนี้ตัดกับพาราโบลาของตัวอย่างที่ 2.3 เป็นมุมฉาก ตามสมบัติ conformal

แบบฝึกหัด 2.3 แกน jω และครึ่งซ้ายของระนาบ

ฟังก์ชัน $F(s) = \dfrac{s - 2}{s + 2}$ ส่งแกน $j\omega$ ไปที่ใด และส่งครึ่งซ้ายของระนาบ $s$ ไปอยู่ภายในหรือภายนอกวงกลมนั้น

ดูเฉลย

$\lvert F(j\omega)\rvert = \dfrac{\lvert j\omega - 2\rvert}{\lvert j\omega + 2\rvert} = 1$ แกน $j\omega$ ถูกส่งเป็นวงกลมหนึ่งหน่วย

ถ้า $\operatorname{Re}\,s < 0$ จุด $s$ อยู่ใกล้ $-2$ มากกว่า $+2$ จึง $\lvert s + 2\rvert < \lvert s - 2\rvert$ ได้ $\lvert F\rvert > 1$ คือ ภายนอก วงกลม ตรวจที่ $s = -3$ ได้ $F = 5$ ✓

แบบฝึกหัด 2.4 อ่านขั้ว

ขั้วที่ $s = -1 \pm j\sqrt3$ หา $\omega_n,\ \zeta$ มุมจากแกนจริงลบ เวลาเข้าที่ $4/\sigma$ และ $M_p$

ดูเฉลย

$\omega_n = \sqrt{1 + 3} = 2$ rad/s และ $\zeta = 1/2 = 0.5$

มุม $\cos^{-1}0.5 = 60^\circ$

$t_s \approx 4/1 = 4$ s

$M_p = e^{-\pi \cdot 0.5/\sqrt{0.75}} = 16.3\%$

แบบฝึกหัด 2.5 โคชี–รีมันน์

ตรวจว่า $F(s) = s^3$ เป็นฟังก์ชันวิเคราะห์ และหา $F'(s)$ จากเงื่อนไขโคชี–รีมันน์ที่จุด $s = j$

ดูเฉลย

$s^3 = (\sigma + j\omega)^3 = (\sigma^3 - 3\sigma\omega^2) + j(3\sigma^2\omega - \omega^3)$

$u_\sigma = 3\sigma^2 - 3\omega^2 = v_\omega$ ✓ และ $u_\omega = -6\sigma\omega = -v_\sigma$ ✓ เป็นฟังก์ชันวิเคราะห์

$F' = u_\sigma + j v_\sigma = (3\sigma^2 - 3\omega^2) + j\,6\sigma\omega$ ที่ $s = j$ ($\sigma=0,\omega=1$) ได้ $-3$ ตรงกับ $3s^2 = 3j^2 = -3$

แบบฝึกหัด 2.6 การส่งภาพของ 1/s (ระดับสูง)

แสดงว่า $w = 1/s$ ส่งเส้น $\operatorname{Re}\,s = 1$ เป็นวงกลม $\lvert w - \tfrac12\rvert = \tfrac12$ แล้วหาภาพของ $s = 1 + j$ และแสดงว่าอยู่บนวงกลมนั้น

ดูเฉลย

จากตัวอย่างที่ 2.5 เมื่อ $c = 1$ ได้วงกลมศูนย์กลาง $\tfrac12$ รัศมี $\tfrac12$

$w(1+j) = \dfrac{1}{1+j} = \dfrac{1 - j}{2} = 0.5 - j0.5$

$\lvert w - 0.5\rvert = \lvert -j0.5\rvert = 0.5$ ✓ อยู่บนวงกลม

แบบฝึกหัด 2.7 หลักการของมุม (ระดับสูง)

$F(s) = \dfrac{(s+1)(s+3)}{s(s-2)}$ และ $\Gamma$ คือวงกลม $\lvert s\rvert = 1.5$ ทวนเข็ม ภาพล้อมจุดกำเนิดกี่รอบและทิศใด

ดูเฉลย

ภายในวงกลมรัศมี 1.5 ศูนย์ $s=-1$ อยู่ภายใน ส่วน $s=-3$ อยู่ภายนอก ($Z = 1$) ขั้ว $s = 0$ อยู่ภายใน ส่วน $s = 2$ อยู่ภายนอก ($P = 1$)

$N = Z - P = 0$ ภาพไม่ล้อมจุดกำเนิดสุทธิ

แบบฝึกหัด 2.8 แปลง Tustin (ระดับสูง)

$z = \dfrac{1 + sT/2}{1 - sT/2}$ ที่ $T = 0.5$ s หา $z$ ของ $s = j4$ และบอกว่าอยู่ตรงไหนของระนาบ $z$ แล้วหาภาพของ $s = -2$

ดูเฉลย

$sT/2 = j4 \times 0.25 = j1$ ได้ $z = \dfrac{1 + j}{1 - j} = j$ ซึ่ง $\lvert z\rvert = 1$ และมุม $90^\circ$ อยู่บนวงกลมหนึ่งหน่วย (แกน $j\omega$ ถูกส่งเป็นวงกลมหนึ่งหน่วย)

$s = -2$: $sT/2 = -0.5$ ได้ $z = \dfrac{0.5}{1.5} = 0.333$ อยู่ภายในวงกลม ตรงตามที่ครึ่งซ้ายถูกส่งเข้าภายใน

## สรุป

- $s = \sigma + j\omega$ รวมอัตราการลดและความถี่ไว้ในจำนวนเดียว

- ฟังก์ชันวิเคราะห์ต้องผ่านเงื่อนไขโคชี–รีมันน์ และอนุพันธ์เชิงซ้อนไม่ขึ้นกับทิศ

- การส่งภาพ $w = F(s)$ เป็น conformal (รักษามุม) ทุกที่ที่ $F' \ne 0$

- ตำแหน่งขั้วบนระนาบ $s$ บอกผลตอบสนองและเสถียรภาพ เส้น $\sigma$, $\omega_d$, $\zeta$ และ $\omega_n$ คงที่เป็นเส้นตรง เส้นครึ่งเส้น และวงกลม

- ผลตอบสนองความถี่คือภาพของแกน $j\omega$ และหลักการของมุมคือฐานของเกณฑ์ไนควิสต์

หน่วยถัดไป การแปลงลาปลาซ ใช้ระนาบ $s$ ที่เราเพิ่งสร้างเพื่อเปลี่ยนสมการเชิงอนุพันธ์เป็นพีชคณิต
