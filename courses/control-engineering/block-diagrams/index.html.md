# บล็อกไดอะแกรมและกราฟการไหลของสัญญาณ

// หน่วยที่ 4 · Control Engineering · Block Diagrams and Signal-Flow Graphs


กฎการลดรูปบล็อกไดอะแกรมแบบอนุกรม ขนาน และป้อนกลับ ฟังก์ชันถ่ายโอนจากการรบกวน และสูตรเกนของเมสัน พร้อมตัวอย่างลูปความเร็วมอเตอร์กับแทโคมิเตอร์และระบบที่มีลูปซ้อน

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- ลดรูปบล็อกที่ต่ออนุกรม ขนาน และป้อนกลับให้เหลือฟังก์ชันถ่ายโอนเดียวได้
- หาฟังก์ชันถ่ายโอนจากการรบกวนถึงเอาต์พุตได้
- ใช้สูตรเกนของเมสันกับระบบที่มีหลายลูปได้
- อธิบายได้ว่าการป้อนกลับเปลี่ยนเกนและค่าคงตัวเวลาของระบบอันดับหนึ่งอย่างไร

## ภาพในใจก่อนเริ่ม: บล็อกไดอะแกรมคือแบบวงจรของสัญญาณ

ช่างไฟฟ้าอ่านวงจรควบคุมมอเตอร์จากแบบ single-line และแบบวงจรคอนโทรล วิศวกรควบคุมอ่านระบบจากบล็อกไดอะแกรม ต่างกันตรงที่เส้นในบล็อกไดอะแกรมไม่ใช่สายไฟ แต่เป็นสัญญาณที่ไหลทางเดียวตามหัวลูกศร แต่ละบล็อกคูณสัญญาณขาเข้าด้วยฟังก์ชันถ่ายโอนของมัน

## การป้อนกลับเปลี่ยนระบบอันดับหนึ่งอย่างไร

ตัวอย่างที่ 4.1 ลูปความเร็วมอเตอร์กับแทโคมิเตอร์

มอเตอร์พร้อมโหลดมี $G(s) = \dfrac{20}{0.1s + 1}$ (rad/s ต่อ V) ขับด้วยตัวขยายเกน $K = 5$ และป้อนกลับความเร็วด้วยแทโคมิเตอร์ $H = 0.05$ V ต่อ rad/s จงหาฟังก์ชันถ่ายโอนวงปิด

ขั้นที่ 1 ทางตรงคือ $KG = \dfrac{100}{0.1s + 1}$ ผลคูณรอบวงคือ $KGH = \dfrac{5}{0.1s + 1}$

ขั้นที่ 2 ใช้สูตรป้อนกลับ

$$T(s) = \frac{KG}{1 + KGH} = \frac{100}{0.1s + 1 + 5} = \frac{100}{0.1s + 6}$$

ขั้นที่ 3 จัดเป็นรูปมาตรฐานโดยหารด้วย 6

$$T(s) = \frac{16.67}{0.0167s + 1}$$

ค่าคงตัวเวลาลดจาก 100 ms เหลือ 16.7 ms คือเร็วขึ้น 6 เท่า ซึ่งเท่ากับ $1 + KGH(0) = 6$ พอดี

ผลของการป้อนกลับต่อระบบอันดับหนึ่ง

เมื่อปิดลูปรอบ $\dfrac{K_0}{\tau s + 1}$ ด้วยเกนรอบวง $L_0$ ทั้งเกนและค่าคงตัวเวลาจะถูกหารด้วย $1 + L_0$ ระบบตอบสนองเร็วขึ้น โดยแลกกับเกนที่ลดลง เหมือนวงจรออปแอมป์ที่ยอมลดเกนเพื่อให้ได้แบนด์วิดท์กว้างขึ้น

## ฟังก์ชันถ่ายโอนจากการรบกวน

มอเตอร์จริงมีแรงบิดโหลดเข้ามารบกวน ในบล็อกไดอะแกรม การรบกวน $D(s)$ เข้าที่จุดรวมสัญญาณระหว่างตัวควบคุม $C(s)$ กับพลานต์ $G(s)$ เนื่องจากระบบเป็นเชิงเส้น จึงใช้หลักการซ้อนทับ หาผลของ $R$ และ $D$ ทีละตัวแล้วบวกกัน

$$Y(s) = \underbrace{\frac{CG}{1 + CGH}}_{\text{ตามค่าอ้างอิง}} R(s) + \underbrace{\frac{G}{1 + CGH}}_{\text{จากการรบกวน}} D(s)$$

ทั้งสองพจน์มีตัวส่วนเดียวกัน คือ $1 + L(s)$ ต่างกันที่ตัวเศษ ซึ่งเป็นผลคูณของบล็อกบนทางตรงจากจุดที่สัญญาณเข้าถึงเอาต์พุต เมื่อเกนของตัวควบคุม $C$ สูง พจน์แรกเข้าใกล้ $1/H$ และพจน์หลังเข้าใกล้ศูนย์ ระบบจึงตามค่าอ้างอิงได้ดีและหักล้างการรบกวนได้พร้อมกัน

## สูตรเกนของเมสัน

เมื่อมีหลายลูปซ้อนกัน การย้ายบล็อกทีละขั้นใช้เวลามาก สูตรเกนของเมสัน (Mason's gain formula) ให้คำตอบในขั้นเดียว

$$T = \frac{1}{\Delta}\sum_k P_k\,\Delta_k$$

- $P_k$ คือเกนของทางตรง (forward path) เส้นที่ $k$

- $\Delta = 1 - \sum(\text{เกนของแต่ละลูป}) + \sum(\text{ผลคูณเกนของลูปสองลูปที่ไม่แตะกัน}) - \cdots$

- $\Delta_k$ คือ $\Delta$ ที่คิดเฉพาะลูปซึ่งไม่แตะทางตรงเส้นที่ $k$

ลูปที่ "ไม่แตะกัน" คือลูปที่ไม่มีสัญญาณหรือบล็อกร่วมกันเลย

ตัวอย่างที่ 4.2 ระบบสามลูป

ระบบมีทางตรง $G_1G_2G_3$ โดย $G_1 = 2$, $G_2 = \dfrac{1}{s + 1}$, $G_3 = \dfrac{1}{s}$ มีลูปป้อนกลับลบสามลูป: รอบ $G_2$ ด้วยเกน 1, รอบ $G_2G_3$ ด้วยเกน $H_2 = 0.5$ และลูปนอกสุดรอบ $G_1G_2G_3$ ด้วยเกน 1 จงหา $T(s)$

ขั้นที่ 1 ทางตรงมีเส้นเดียว $P_1 = G_1G_2G_3 = \dfrac{2}{s(s + 1)}$

ขั้นที่ 2 เกนของลูป (ติดลบเพราะป้อนกลับแบบลบ)

$$L_1 = -G_2 = -\frac{1}{s + 1}, \qquad L_2 = -G_2G_3H_2 = -\frac{0.5}{s(s + 1)}, \qquad L_3 = -G_1G_2G_3 = -\frac{2}{s(s + 1)}$$

ขั้นที่ 3 ทุกลูปผ่าน $G_2$ จึงแตะกันทั้งหมด และแตะทางตรงด้วย ดังนั้น $\Delta = 1 - (L_1 + L_2 + L_3)$ และ $\Delta_1 = 1$

$$T(s) = \frac{\dfrac{2}{s(s + 1)}}{1 + \dfrac{1}{s + 1} + \dfrac{0.5}{s(s + 1)} + \dfrac{2}{s(s + 1)}}$$

ขั้นที่ 4 คูณเศษและส่วนด้วย $s(s + 1)$

$$T(s) = \frac{2}{s(s + 1) + s + 0.5 + 2} = \frac{2}{s^2 + 2s + 2.5}$$

ตรวจคำตอบ: เกน DC เท่ากับ $2/2.5 = 0.8$

ลูปซ้อนในไดรฟ์มอเตอร์

ไดรฟ์อุตสาหกรรมใช้โครงสร้างแบบแคสเคด: ลูปกระแส (แรงบิด) อยู่ในสุดและเร็วที่สุด ลูปความเร็วอยู่ชั้นกลาง ลูปตำแหน่งอยู่นอกสุด เมื่อออกแบบให้ลูปในเร็วกว่าลูปนอกประมาณ 5–10 เท่า ลูปนอกจะมองลูปในเป็นเกนคงที่ได้ ทำให้ออกแบบทีละชั้นได้โดยไม่ต้องใช้สูตรเมสันกับทั้งระบบ

## แบบฝึกหัด

แบบฝึกหัด 4.1

พลานต์ $G(s) = \dfrac{4}{2s + 1}$ ต่อกับตัวควบคุมเกน $K = 6$ และป้อนกลับหนึ่งหน่วย ($H = 1$) จงหาฟังก์ชันถ่ายโอนวงปิดในรูปมาตรฐาน พร้อมเกน DC และค่าคงตัวเวลา

ดูเฉลย

$$T(s) = \frac{24}{2s + 1 + 24} = \frac{24}{2s + 25} = \frac{0.96}{0.08s + 1}$$

เกน DC เท่ากับ 0.96 และค่าคงตัวเวลา 0.08 s ซึ่งเท่ากับ $2/25$ คือลดลง $1 + KG(0) = 25$ เท่า

แบบฝึกหัด 4.2

จากตัวอย่างที่ 4.1 สมมติว่าการรบกวน $D$ (หน่วยเป็นโวลต์เทียบเท่า) เข้าที่อินพุตของมอเตอร์ จงหาฟังก์ชันถ่ายโอน $Y/D$ และความเร็วที่เปลี่ยนไปในสถานะอยู่ตัวเมื่อ $D = -1$ V

ดูเฉลย

$$\frac{Y(s)}{D(s)} = \frac{G}{1 + KGH} = \frac{20}{0.1s + 6}$$

เกน DC เท่ากับ $20/6 = 3.33$ rad/s ต่อ V ความเร็วจึงลดลง 3.33 rad/s ถ้าเป็นวงเปิด ความเร็วจะลดลง 20 rad/s การป้อนกลับลดผลของการรบกวนลง 6 เท่า

แบบฝึกหัด 4.3

ระบบป้อนกลับหนึ่งหน่วยมีลูปใน: $G_2 = \dfrac{10}{s}$ ป้อนกลับลบด้วยเกน 1 และมี $G_1 = 5$ อยู่หน้าลูปใน จงหา $T(s)$

ดูเฉลย

ลดรูปลูปในก่อน: $\dfrac{10/s}{1 + 10/s} = \dfrac{10}{s + 10}$ ทางตรงของลูปนอกคือ $\dfrac{50}{s + 10}$

$$T(s) = \frac{50}{s + 10 + 50} = \frac{50}{s + 60}$$

## สรุปหน่วยที่ 4

- อนุกรมคูณกัน ขนานบวกกัน ป้อนกลับแบบลบได้ $\dfrac{G}{1 + GH}$

- ฟังก์ชันถ่ายโอนทุกคู่อินพุต-เอาต์พุตของลูปเดียวกันมีตัวส่วน $1 + L(s)$ ร่วมกัน

- การป้อนกลับรอบระบบอันดับหนึ่งหารทั้งเกนและค่าคงตัวเวลาด้วย $1 + L_0$

- สูตรเมสัน $T = \dfrac{1}{\Delta}\sum P_k\Delta_k$ ใช้กับระบบหลายลูปได้ในขั้นเดียว

หน่วยถัดไปเริ่มภาคที่ 2 โดยศึกษาผลตอบสนองเชิงเวลาของระบบอันดับหนึ่งอย่างละเอียด
