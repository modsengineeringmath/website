# เสถียรภาพและเกณฑ์เราท์–เฮอร์วิตซ์

// หน่วยที่ 8 · Control Engineering · Stability and the Routh–Hurwitz Criterion


นิยามเสถียรภาพแบบ BIBO ความสัมพันธ์กับตำแหน่งขั้วบนระนาบ s การสร้างตารางเราท์ กรณีพิเศษ และการหาช่วงเกนที่ระบบเสถียร พร้อมตัวอย่างเซอร์โวและลูป AVR ของเครื่องกำเนิดไฟฟ้า

## เรียนจบหน่วยนี้แล้วทำอะไรได้

- บอกได้ว่าระบบเสถียรหรือไม่จากตำแหน่งขั้ว
- สร้างตารางเราท์และนับจำนวนขั้วในครึ่งขวาของระนาบ s ได้
- หาช่วงของเกนที่ทำให้ระบบวงปิดเสถียร และความถี่ของการแกว่งที่ขอบเสถียรภาพได้
- จัดการกรณีพิเศษที่มีศูนย์ในคอลัมน์แรกหรือทั้งแถวเป็นศูนย์ได้

## ภาพในใจก่อนเริ่ม: ไมโครโฟนหอน

เมื่อยื่นไมโครโฟนเข้าใกล้ลำโพง เสียงจากลำโพงกลับเข้าไมโครโฟน ถูกขยายซ้ำแล้วออกลำโพงอีก วนไปจนเกิดเสียงหอน ถ้าหรี่เสียงลง เสียงหอนหยุด ลูปเดิม อุปกรณ์เดิม ต่างกันที่เกน

ระบบควบคุมป้อนกลับทุกระบบมีความเสี่ยงนี้ หน่วยที่ 7 บอกว่าเกนสูงทำให้ค่าผิดพลาดน้อย หน่วยนี้หาขีดจำกัดของเกนนั้น

## นิยามและเงื่อนไข

ระบบเสถียรแบบ BIBO (bounded-input bounded-output) เมื่ออินพุตที่มีขอบเขตทุกรูปแบบให้เอาต์พุตที่มีขอบเขต สำหรับระบบเชิงเส้นไม่แปรตามเวลา เงื่อนไขนี้เทียบเท่ากับ

เงื่อนไขของเสถียรภาพ

ระบบเสถียรก็ต่อเมื่อขั้วทุกตัวอยู่ในครึ่งซ้ายของระนาบ $s$ นั่นคือมีส่วนจริงเป็นลบ

ขั้วของระบบวงปิดคือรากของสมการลักษณะเฉพาะ $1 + L(s) = 0$ ปัญหาคือเมื่ออันดับสูงกว่าสอง การหารากด้วยมือทำได้ยาก เกณฑ์เราท์–เฮอร์วิตซ์บอกจำนวนรากในครึ่งขวาโดยไม่ต้องหาราก

## เงื่อนไขจำเป็น

ให้สมการลักษณะเฉพาะคือ

$$a_ns^n + a_{n-1}s^{n-1} + \cdots + a_1s + a_0 = 0, \qquad a_n > 0$$

ถ้าสัมประสิทธิ์ตัวใดเป็นศูนย์หรือติดลบ ระบบไม่เสถียร (หรืออย่างดีเป็นเสถียรแบบขอบ) สรุปได้ทันทีโดยไม่ต้องสร้างตาราง แต่ถ้าสัมประสิทธิ์เป็นบวกครบทุกตัว ยังสรุปไม่ได้ว่าเสถียร ต้องสร้างตารางเราท์ ยกเว้นอันดับหนึ่งและอันดับสองซึ่งสัมประสิทธิ์บวกครบก็เพียงพอ

เกณฑ์เราท์–เฮอร์วิตซ์

จำนวนรากในครึ่งขวาของระนาบ $s$ เท่ากับจำนวนครั้งที่เครื่องหมายเปลี่ยนในคอลัมน์แรก ระบบเสถียรก็ต่อเมื่อคอลัมน์แรกเป็นบวกทั้งหมด

ตัวอย่างที่ 8.1 เซอร์โวอันดับสาม: หาช่วงเกน

เซอร์โวตำแหน่งที่คิดทั้งค่าคงตัวเวลาทางกลและทางไฟฟ้ามี $L(s) = \dfrac{K}{s(s + 1)(s + 5)}$ ป้อนกลับหนึ่งหน่วย จงหาช่วงของ $K$ ที่ระบบเสถียร

ขั้นที่ 4 ที่ $K = 30$ แถว $s^1$ เป็นศูนย์ทั้งแถว ใช้แถวเหนือขึ้นไปสร้างสมการช่วย $6s^2 + 30 = 0$ ได้ $s = \pm j\sqrt{5} = \pm j2.24$ ระบบแกว่งด้วยขนาดคงที่ที่ความถี่ 2.24 rad/s คาบ $2\pi/2.24 = 2.81$ s

ค่า $K = 30$ เรียกว่าเกนวิกฤต (ultimate gain) และคาบ 2.81 s เรียกว่าคาบวิกฤต ทั้งสองค่าจะกลับมาใช้ในการจูน PID ด้วยวิธีซีเกลอร์–นิโคลส์ในหน่วยที่ 13

ตัวอย่างที่ 8.2 ลูป AVR ของเครื่องกำเนิดไฟฟ้า

แบบฝึกหัด 8.2

ระบบป้อนกลับหนึ่งหน่วยมี $L(s) = \dfrac{K}{s(s + 2)(s + 4)}$ จงหาช่วง $K$ ที่เสถียร และความถี่ของการแกว่งที่เกนวิกฤต

ดูเฉลย

สมการลักษณะเฉพาะ $s^3 + 6s^2 + 8s + K = 0$ แถว $s^1$ คือ $\dfrac{48 - K}{6}$ จึงได้ $0 < K < 48$

ที่ $K = 48$: $6s^2 + 48 = 0$ ได้ $s = \pm j\sqrt{8} = \pm j2.83$ rad/s

แบบฝึกหัด 8.3

สำหรับระบบอันดับสาม $s^3 + a_2s^2 + a_1s + a_0 = 0$ ที่สัมประสิทธิ์เป็นบวกทุกตัว จงแสดงว่าเงื่อนไขของเสถียรภาพคือ $a_2a_1 > a_0$

ดูเฉลย

ตารางเราท์มีคอลัมน์แรกเป็น $1,\ a_2,\ \dfrac{a_2a_1 - a_0}{a_2},\ a_0$ เมื่อ $a_2 > 0$ และ $a_0 > 0$ เงื่อนไขที่เหลือคือ $a_2a_1 - a_0 > 0$

สูตรนี้ใช้ตรวจตัวอย่างที่ 8.1 ได้ทันที: $6 \times 5 > K$

## สรุปหน่วยที่ 8

- ระบบเสถียรก็ต่อเมื่อขั้ววงปิดทุกตัวอยู่ในครึ่งซ้ายของระนาบ $s$

- สัมประสิทธิ์ที่เป็นศูนย์หรือติดลบแปลว่าไม่เสถียร แต่สัมประสิทธิ์บวกครบยังไม่รับประกันเสถียรภาพเมื่ออันดับตั้งแต่สามขึ้นไป

- จำนวนครั้งที่เครื่องหมายเปลี่ยนในคอลัมน์แรกของตารางเราท์เท่ากับจำนวนขั้วในครึ่งขวา

- ตารางเราท์ที่มีเกน $K$ เป็นตัวแปรให้ช่วงเกนที่เสถียร เกนวิกฤต และความถี่ของการแกว่งที่ขอบเสถียรภาพ

เกณฑ์เราท์บอกเพียงว่าเสถียรหรือไม่ หน่วยถัดไปเริ่มภาคที่ 3 ด้วยรูทโลคัส ซึ่งแสดงว่าขั้วเคลื่อนที่อย่างไรเมื่อเกนเปลี่ยน
