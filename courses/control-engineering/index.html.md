## แผนการเรียนรายหน่วย

### ภาคที่ 1 · แบบจำลองทางคณิตศาสตร์ของระบบ

- 01ระบบควบคุมคืออะไร วงเปิด วงปิด และการป้อนกลับIntroduction to Feedback Controlเรียนแล้ว ✓
- 02การแปลงลาปลาซและฟังก์ชันถ่ายโอนLaplace Transform and Transfer Functionsเรียนแล้ว ✓
- 03แบบจำลองของระบบไฟฟ้า ออปแอมป์ ระบบกล และมอเตอร์กระแสตรงModelling Electrical, Op-Amp, Mechanical and DC Motor Systemsเรียนแล้ว ✓
- 04บล็อกไดอะแกรมและกราฟการไหลของสัญญาณBlock Diagrams and Signal-Flow Graphsเรียนแล้ว ✓

### ภาคที่ 2 · ผลตอบสนองและเสถียรภาพ

- 05ผลตอบสนองเชิงเวลาของระบบอันดับหนึ่งTime Response of First-Order Systemsเรียนแล้ว ✓
- 06ผลตอบสนองเชิงเวลาของระบบอันดับสองและข้อกำหนดสมรรถนะSecond-Order Response and Specificationsเรียนแล้ว ✓
- 07ค่าผิดพลาดในสถานะอยู่ตัวและชนิดของระบบSteady-State Error and System Typeเรียนแล้ว ✓
- 08เสถียรภาพและเกณฑ์เราท์–เฮอร์วิตซ์Stability and the Routh–Hurwitz Criterionเรียนแล้ว ✓

### ภาคที่ 3 · การวิเคราะห์และออกแบบตัวควบคุม

- 09รูทโลคัส: หลักการและการวาดด้วยมือRoot Locusเรียนแล้ว ✓
- 10การออกแบบตัวชดเชยด้วยรูทโลคัสCompensator Design by Root Locusเรียนแล้ว ✓
- 11ผลตอบสนองเชิงความถี่และโบดไดอะแกรมFrequency Response and Bode Plotsเรียนแล้ว ✓
- 12เกณฑ์ไนควิสต์ เกนมาร์จิน และเฟสมาร์จินNyquist Criterion and Stability Marginsเรียนแล้ว ✓
- 13ตัวควบคุม PID การจูน และการใช้งานใน PLC ไดรฟ์ และ DCSPID Control, Tuning and Industrial Implementationเรียนแล้ว ✓

### ภาคที่ 4 · ปริภูมิสถานะและระบบควบคุมดิจิทัล

- 14แบบจำลองปริภูมิสถานะState-Space Modelsเรียนแล้ว ✓
- 15ระบบควบคุมดิจิทัล: ไมโครคอนโทรลเลอร์ การชักตัวอย่าง และ PID แบบดิจิทัลDigital Control: Sampling, Microcontrollers and Digital PIDเรียนแล้ว ✓

### ภาคที่ 5 · การควบคุมอัจฉริยะ: ฟัซซีลอจิกและ AI

- 16การควบคุมด้วยฟัซซีลอจิกFuzzy Logic Controlเรียนแล้ว ✓
- 17พื้นฐาน AI และ Machine Learning สำหรับวิศวกรควบคุมAI and Machine Learning Fundamentals for Control Engineersเรียนแล้ว ✓

## วิธีใช้แต่ละหน่วย

- อ่านจุดประสงค์ ที่ต้นหน่วยก่อน จะรู้ว่าเรียนจบแล้วต้องทำอะไรได้

- ทำตัวอย่างตามทีละขั้น ด้วยกระดาษและดินสอ อย่าอ่านผ่านอย่างเดียว

- ทำแบบฝึกหัดก่อนเปิดเฉลย เฉลยถูกพับไว้ กดเปิดเมื่อทำเสร็จ

- กด ทำเครื่องหมายว่าเรียนแล้ว หน้านี้จะแสดงความคืบหน้าให้ ข้อมูลนี้เก็บในเบราว์เซอร์ของผู้เรียนเท่านั้น ไม่ได้ส่งไปที่ใด
