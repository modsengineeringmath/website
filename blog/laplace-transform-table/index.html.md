# ตารางการแปลงลาปลาซ (Laplace Transform Table) ที่ใช้บ่อย

THภาษาไทยENEnglish
// บทความ · Laplace Transform Table


หน้าสรุปคู่การแปลงและคุณสมบัติที่ใช้ในโจทย์วงจรและระบบควบคุมเกือบทั้งหมด ทุกคู่เป็นลาปลาซด้านเดียว ($t \ge 0$) พร้อมเคล็ดลับที่ทำให้ไม่ต้องท่องทั้งตาราง

## ตารางคู่การแปลงพื้นฐาน

ในตาราง $a$ และ $\omega$ เป็นค่าคงที่จริง $n$ เป็นจำนวนเต็มบวก และทุกฟังก์ชันของเวลาถือว่ามี $u(t)$ คูณอยู่

| # | $f(t)$, $t \ge 0$ | $F(s)$ |

| 1 | $\delta(t)$ (แรงกระตุ้นหนึ่งหน่วย) | $1$ |

| 2 | $1$ หรือ $u(t)$ | $\dfrac{1}{s}$ |

| 3 | $t$ | $\dfrac{1}{s^2}$ |

| 4 | $t^n$ | $\dfrac{n!}{s^{n+1}}$ |

| 5 | $e^{-at}$ | $\dfrac{1}{s+a}$ |

| 6 | $t\,e^{-at}$ | $\dfrac{1}{(s+a)^2}$ |

| 7 | $t^n e^{-at}$ | $\dfrac{n!}{(s+a)^{n+1}}$ |

| 8 | $\sin\omega t$ | $\dfrac{\omega}{s^2+\omega^2}$ |

| 9 | $\cos\omega t$ | $\dfrac{s}{s^2+\omega^2}$ |

| 10 | $e^{-at}\sin\omega t$ | $\dfrac{\omega}{(s+a)^2+\omega^2}$ |

| 11 | $e^{-at}\cos\omega t$ | $\dfrac{s+a}{(s+a)^2+\omega^2}$ |

| 12 | $\sinh at$ | $\dfrac{a}{s^2-a^2}$ |

| 13 | $\cosh at$ | $\dfrac{s}{s^2-a^2}$ |

| 14 | $t\sin\omega t$ | $\dfrac{2\omega s}{(s^2+\omega^2)^2}$ |

| 15 | $t\cos\omega t$ | $\dfrac{s^2-\omega^2}{(s^2+\omega^2)^2}$ |

## ตารางคุณสมบัติที่ใช้บ่อย

ให้ $\mathcal{L}\{f(t)\}=F(s)$ และ $\mathcal{L}\{g(t)\}=G(s)$

| คุณสมบัติ | โดเมนเวลา | โดเมน $s$ |

| เชิงเส้น | $af(t)+bg(t)$ | $aF(s)+bG(s)$ |

| เลื่อนความถี่ (คูณเอกซ์โพเนนเชียล) | $e^{-at}f(t)$ | $F(s+a)$ |

| เลื่อนเวลา (หน่วงเวลา) | $f(t-T)\,u(t-T)$, $T>0$ | $e^{-sT}F(s)$ |

| อนุพันธ์อันดับหนึ่ง | $f'(t)$ | $sF(s)-f(0)$ |

| อนุพันธ์อันดับสอง | $f''(t)$ | $s^2F(s)-sf(0)-f'(0)$ |

| ปริพันธ์ | $\displaystyle\int_0^t f(\tau)\,d\tau$ | $\dfrac{F(s)}{s}$ |

| คูณด้วย $t$ | $t\,f(t)$ | $-\dfrac{dF}{ds}$ |

| คอนโวลูชัน | $(f*g)(t)$ | $F(s)\,G(s)$ |

| ค่าเริ่มต้น | $f(0^+)$ | $\displaystyle\lim_{s\to\infty}sF(s)$ |

| ค่าสุดท้าย | $f(\infty)$ | $\displaystyle\lim_{s\to0}sF(s)$ (เมื่อโพลของ $sF$ อยู่ซีกซ้ายทั้งหมด) |

## เคล็ดลับจำตารางแบบไม่ท่อง

- จำสามคู่แรกพอ: $1/s$, $1/(s+a)$, $\omega/(s^2+\omega^2)$ ที่เหลือสร้างได้

- เห็น $(s+a)$ แทนที่ $s$ แปลว่าในโดเมนเวลาคูณด้วย $e^{-at}$ เช่น จาก $\omega/(s^2+\omega^2)$ แทน $s \to s+a$ ได้คู่ที่ 10

- sin กับ cos: sin มี $\omega$ อยู่ตัวเศษ (เพราะ $\sin 0 = 0$ จึงไม่มีเทอม $s$) ส่วน cos มี $s$ อยู่ตัวเศษ (เพราะ $\cos 0 = 1$)

- คูณ $t$ คือหาอนุพันธ์เทียบ $s$ แล้วใส่เครื่องหมายลบ เช่น $-\dfrac{d}{ds}\dfrac{1}{s+a}=\dfrac{1}{(s+a)^2}$ ได้คู่ที่ 6

ตัวอย่างการใช้เคล็ดลับ

### หา $\mathcal{L}\{t\cos\omega t\}$ จากคู่ที่ 9

- คูณด้วย $t$ คือ $-\dfrac{d}{ds}$

$$-\frac{d}{ds}\frac{s}{s^2+\omega^2} = -\frac{(s^2+\omega^2) - s(2s)}{(s^2+\omega^2)^2} = \frac{s^2-\omega^2}{(s^2+\omega^2)^2}$$

ตรงกับคู่ที่ 15 ในตาราง ✓

## เรียนต่อในคลังความรู้

- ตารางคู่การแปลง 22 คู่ พร้อมบริเวณลู่เข้า (ROC) และดัชนีสูตรค้นหาได้

- พิสูจน์คุณสมบัติทุกข้อ พร้อมแล็บทดลอง

- นำตารางไปแก้สมการเชิงอนุพันธ์ RC RL RLC (มีตัวแก้โต้ตอบ)

- ใช้ตารางนี้แปลงกลับด้วยเศษส่วนย่อย

## คำถามที่พบบ่อย

ทฤษฎีบทค่าสุดท้ายใช้ได้เมื่อไร?
$f(\infty)=\lim_{s\to0}sF(s)$ ใช้ได้เมื่อ $sF(s)$ มีโพลทั้งหมดอยู่ซีกซ้ายของระนาบ $s$ เท่านั้น ถ้ามีโพลบนแกนจินตภาพหรือซีกขวา (เช่นสัญญาณ sin ที่แกว่งไม่หยุด) สูตรนี้ให้คำตอบที่ผิด

ตารางนี้ใช้ได้กับ t น้อยกว่า 0 ไหม?
ไม่ได้ ตารางนี้เป็นของลาปลาซด้านเดียว ซึ่งถือว่าฟังก์ชันเป็นศูนย์เมื่อเวลาติดลบ ทุกฟังก์ชันในตารางจึงต้องมีตัวคูณ $u(t)$ อยู่ในใจเสมอ

จำตารางทั้งหมดได้อย่างไร?
จำสามคู่หลักก่อน คือ $1/s$, $1/(s+a)$ และ $\omega/(s^2+\omega^2)$ ที่เหลือหาได้จากสมบัติ เช่น เติม $e^{-at}$ เท่ากับแทน $s$ ด้วย $s+a$ และคูณ $t$ เท่ากับหาอนุพันธ์เทียบ $s$ แล้วใส่เครื่องหมายลบ
