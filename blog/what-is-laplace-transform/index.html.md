# การแปลงลาปลาซ (Laplace Transform) คืออะไร ใช้ทำอะไร

THภาษาไทยENEnglish
// บทความ · Laplace Transform


การแปลงลาปลาซคือเครื่องมือที่เปลี่ยนสมการเชิงอนุพันธ์ซึ่งแก้ยาก ให้เป็นสมการพีชคณิตซึ่งแก้ง่าย แล้วแปลงคำตอบกลับมาเป็นฟังก์ชันของเวลา บทความนี้อธิบายแนวคิด นิยาม และตัวอย่างวงจร RC ที่คำนวณตามได้ทุกบรรทัด

สรุปใน 30 วินาที

- นิยาม $F(s)=\mathcal{L}\{f(t)\}=\int_0^{\infty} f(t)e^{-st}\,dt$

- การหาอนุพันธ์ในโดเมนเวลา กลายเป็นการคูณด้วย $s$ ในโดเมน $s$

- ขั้นตอน: แปลง → แก้สมการพีชคณิต → แปลงกลับ

- ตำแหน่งโพลของ $F(s)$ บอกความเสถียรของระบบโดยไม่ต้องแก้สมการ

## แนวคิด: ทำไมต้องแปลง

สมมติวงจรหรือระบบกลไกหนึ่งอธิบายด้วยสมการเชิงอนุพันธ์ เช่น $y' + 3y = 6$ การแก้ตรง ๆ ต้องใช้ตัวประกอบอินทิเกรตหรือเดาคำตอบ แต่ถ้าเราย้ายสมการไปอยู่ในโดเมน $s$ อนุพันธ์จะหายไป เหลือเพียงการคูณและการบวก แก้เสร็จแล้วค่อยย้ายกลับ

เปรียบเทียบกับการใช้ลอการิทึมคูณเลขใหญ่ในสมัยก่อน: เปลี่ยนการคูณเป็นการบวก คำนวณให้เสร็จ แล้วเปลี่ยนกลับ ลาปลาซทำเช่นเดียวกันกับการหาอนุพันธ์และอินทิกรัล

## นิยามของการแปลงลาปลาซ

สำหรับฟังก์ชัน $f(t)$ ที่กำหนดสำหรับ $t \ge 0$ การแปลงลาปลาซด้านเดียวคือ

$$F(s) = \mathcal{L}\{f(t)\} = \int_0^{\infty} f(t)\,e^{-st}\,dt, \qquad s = \sigma + j\omega$$

ตัวคูณ $e^{-st}$ ทำหน้าที่เหมือนตัวกรอง: $f(t)$ ที่โตช้ากว่าเอกซ์โพเนนเชียลจะทำให้อินทิกรัลลู่เข้า ตัวอย่างพื้นฐานที่สุดคือ

$$\mathcal{L}\{e^{-at}\} = \int_0^{\infty} e^{-(s+a)t}\,dt = \frac{1}{s+a}, \qquad \operatorname{Re}(s) > -a$$

จากสูตรนี้ ถ้า $a=0$ จะได้ $\mathcal{L}\{u(t)\}=1/s$ ส่วนสูตรอื่นที่ใช้บ่อยรวมไว้ใน ตารางการแปลงลาปลาซ แล้ว

## กุญแจสำคัญ: อนุพันธ์กลายเป็นการคูณ

เมื่ออินทิเกรตทีละส่วน จะได้สมบัติที่ทำให้ลาปลาซมีประโยชน์ที่สุด

$$\mathcal{L}\{y'(t)\} = sY(s) - y(0), \qquad \mathcal{L}\{y''(t)\} = s^2Y(s) - s\,y(0) - y'(0)$$

สังเกตว่าเงื่อนไขเริ่มต้น $y(0)$, $y'(0)$ ถูกใส่เข้าไปในสมการตั้งแต่ต้น ไม่ต้องหาค่าคงที่ทีหลังเหมือนวิธีแก้สมการเชิงอนุพันธ์แบบดั้งเดิม

## ขั้นตอนแก้สมการด้วยลาปลาซ 3 ขั้น

- แปลง ทั้งสองข้างของสมการเชิงอนุพันธ์ไปเป็นโดเมน $s$ โดยใส่เงื่อนไขเริ่มต้น

- แก้ หา $Y(s)$ ด้วยพีชคณิต

- แปลงกลับ เป็น $y(t)$ ด้วยเศษส่วนย่อยและตาราง (ดู วิธี Inverse Laplace ด้วยเศษส่วนย่อย)

## ตัวอย่างที่ 1: แก้ y′ + 3y = 6 เมื่อ y(0) = 0

- แปลงสมการ

$$sY(s) - 0 + 3Y(s) = \frac{6}{s}$$

- แก้หา $Y(s)$

$$Y(s)\,(s+3) = \frac{6}{s} \;\Rightarrow\; Y(s) = \frac{6}{s(s+3)}$$

- แยกเศษส่วนย่อย

$$\frac{6}{s(s+3)} = \frac{2}{s} - \frac{2}{s+3}$$

- แปลงกลับด้วย $\mathcal{L}^{-1}\{1/s\}=1$ และ $\mathcal{L}^{-1}\{1/(s+3)\}=e^{-3t}$

$$y(t) = 2 - 2e^{-3t}, \quad t \ge 0$$

ตรวจคำตอบ: $y' = 6e^{-3t}$ ดังนั้น $y' + 3y = 6e^{-3t} + 6 - 6e^{-3t} = 6$ ✓ และ $y(0)=2-2=0$ ✓

## ตัวอย่างที่ 2: วงจร RC รับแรงดันขั้นบันได 5 V

ตัวต้านทาน $R = 1\,\text{k}\Omega$ ต่ออนุกรมกับตัวเก็บประจุ $C = 100\,\mu\text{F}$ ป้อนแรงดัน $v_{in}(t) = 5\,u(t)$ โวลต์ ตัวเก็บประจุเริ่มต้นว่าง ค่าคงที่เวลา $\tau = RC = 1000 \times 100\times10^{-6} = 0.1$ วินาที

- สมการวงจร $RC\,\dfrac{dv_c}{dt} + v_c = v_{in}$ แปลงเป็นโดเมน $s$ ด้วย $v_c(0)=0$

$$(RCs + 1)V_c(s) = \frac{5}{s} \;\Rightarrow\; V_c(s) = \frac{5}{s(0.1s+1)} = \frac{50}{s(s+10)}$$

- เศษส่วนย่อย

$$\frac{50}{s(s+10)} = \frac{5}{s} - \frac{5}{s+10}$$

- แปลงกลับ

$$v_c(t) = 5\left(1 - e^{-10t}\right)\ \text{V}$$

ที่ $t = \tau = 0.1$ s แรงดันคร่อมตัวเก็บประจุ $= 5(1 - e^{-1}) \approx 3.16$ V (ประมาณ 63.2 % ของ 5 V) ตรงกับนิยามของค่าคงที่เวลา โพลอยู่ที่ $s=-10 = -1/\tau$

## ลาปลาซใช้ทำอะไรในงานวิศวกรรม

- วิเคราะห์วงจรไฟฟ้า RC, RL, RLC ที่มีสวิตช์หรือแหล่งจ่ายขั้นบันได ได้ทั้งผลตอบสนองชั่วครู่และสภาวะคงตัว

- ฟังก์ชันถ่ายโอน $G(s)=Y(s)/U(s)$ ใช้อธิบายระบบเชิงเส้นไม่แปรตามเวลาทุกชนิด ตั้งแต่มอเตอร์ถึงตัวกรอง

- ความเสถียร ถ้าโพลทุกตัวอยู่ซีกซ้ายของระนาบ $s$ ระบบเสถียร (ใช้ต่อในเกณฑ์ Routh–Hurwitz และรูทโลคัส)

- ระบบควบคุม ออกแบบตัวควบคุม PID ชดเชย และวิเคราะห์ผลตอบสนองความถี่

## ข้อผิดพลาดที่พบบ่อย

- ลืมเงื่อนไขเริ่มต้นตอนแปลงอนุพันธ์ ทำให้คำตอบผิดทั้งข้อ

- ลืมว่าลาปลาซด้านเดียวสนใจเฉพาะ $t \ge 0$ คำตอบที่ได้จึงต้องเขียนกำกับว่า $t \ge 0$ หรือคูณ $u(t)$

- สับสนระหว่าง $s$ กับ $\omega$ ในโดเมนเวลาไม่ต้องมี $j$ แต่ในโดเมน $s$ ความถี่แกว่งอยู่ที่ส่วนจินตภาพของโพล

## เรียนต่อในคลังความรู้

- การแปลงลาปลาซ: นิยาม ตารางคู่การแปลงพร้อม ROC

- คุณสมบัติของการแปลงลาปลาซครบทุกข้อ

- แก้สมการเชิงอนุพันธ์อันดับหนึ่งและสองด้วยลาปลาซ (มีตัวแก้โต้ตอบ)

- แล็บระบบอันดับหนึ่ง: ค่าคงที่เวลาของ RC และ RL

## คำถามที่พบบ่อย

การแปลงลาปลาซกับการแปลงฟูเรียร์ต่างกันอย่างไร?
ลาปลาซใช้ตัวแปรเชิงซ้อน $s = \sigma + j\omega$ จึงจัดการกับสัญญาณที่โตขึ้นหรือลดลงแบบเอกซ์โพเนนเชียลและเงื่อนไขเริ่มต้นได้ ส่วนฟูเรียร์ใช้เฉพาะ $j\omega$ ถ้าบริเวณลู่เข้า (ROC) รวมแกน $j\omega$ การแปลงฟูเรียร์คือลาปลาซที่แทน $s = j\omega$

ลาปลาซด้านเดียว (unilateral) คืออะไร ทำไมอินทิเกรตจาก 0?
ในงานวงจรและระบบควบคุมเรามักสนใจเหตุการณ์ตั้งแต่ $t = 0$ เป็นต้นไป และใส่ผลของสภาวะก่อนหน้าไว้ในเงื่อนไขเริ่มต้น ลาปลาซด้านเดียวจึงอินทิเกรตจาก 0 ไปถึงอนันต์ ส่วนแบบสองด้านอินทิเกรตจาก $-\infty$ ใช้ในวิชาสัญญาณและระบบเมื่อต้องวิเคราะห์ ROC อย่างเต็มรูปแบบ

ต้องแปลงกลับเป็นฟังก์ชันของเวลาเสมอไหม?
ไม่เสมอไป ถ้าต้องการแค่ความเสถียรหรือรูปแบบการตอบสนอง ดูตำแหน่งโพลของ $F(s)$ ก็บอกได้เลย แต่ถ้าต้องการค่า $y(t)$ ที่เวลาใดเวลาหนึ่งต้องทำการแปลงกลับ ซึ่งมักใช้วิธีเศษส่วนย่อยร่วมกับตาราง

ตัวแปร s มีหน่วยหรือความหมายอย่างไร?
$s$ มีหน่วยเป็นความถี่ (1/วินาที) ส่วนจริง $\sigma$ บอกอัตราการโตหรือลดแบบเอกซ์โพเนนเชียล ส่วนจินตภาพ $\omega$ คือความถี่การแกว่ง เช่น โพลที่ $s = -10$ หมายถึงสัญญาณลดลงแบบ $e^{-10t}$
