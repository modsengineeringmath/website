# ตั้งไทเมอร์สตาร์-เดลต้ากี่วินาที: ผลการทดลองเชิงตัวเลขของมอเตอร์เหนี่ยวนำกรงกระรอก เรื่องเวลาเปลี่ยนจังหวะ ช่วงตาย กระแส และพลังงาน

## 2. ทฤษฎีที่เกี่ยวข้อง

ที่ความเร็วเดียวกัน การต่อสตาร์ให้กระแสสายและแรงบิด 1/3 ของเดลต้า และแรงบิดสูงสุดก็เหลือ 1/3 ด้วย มอเตอร์จึงเร่งได้ถึงเพียง ความเร็วสมดุลในสตาร์ $n_Y$ ที่แรงบิดสตาร์เท่ากับแรงบิดโหลด เวลาเร่งหาได้จากกฎข้อสองของนิวตันสำหรับการหมุน

$$t(\omega_1) = J\int_0^{\omega_1}\frac{d\omega}{T_Y(\omega) - T_L(\omega)} \qquad \tau_m = \frac{J\,\omega_s}{T_n}$$

ค่าคงตัวเวลาทางกล $\tau_m$ คือเวลาที่แรงบิดพิกัดใช้เร่งมวลหมุนจากนิ่งถึงความเร็วซิงโครนัส เมื่อวัดเวลาเป็นหน่วย $\tau_m$ และแรงบิดเป็นหน่วย $T_n$ สมการข้างบนไม่มีขนาดมอเตอร์อยู่เลย ผลจึงนำไปใช้กับมอเตอร์ขนาดอื่นที่มีกราฟแรงบิดรูปร่างคล้ายกันได้

ระหว่างช่วงตาย (dead time) ที่มอเตอร์หลุดจากไฟ ฟลักซ์ในโรเตอร์ยังค้างและสร้าง แรงดันค้าง $\underline e$ ที่ขั้ว ซึ่งหมุนช้ากว่าไฟและเลื่อนมุมไป $\delta$ เมื่อ KM3 ต่อ ทรานเซียนต์ถูกขับด้วยผลต่างเวกเตอร์

$$\delta \approx s_{ch}\,\omega_s t_d + \frac{p\,T_L}{2J}t_d^2 \qquad |\Delta\underline V| = |\underline V_\Delta - \underline e| \qquad I_{pk} \approx k_a\,\frac{|\Delta\underline V|}{V_\Delta}\,I_{LR}$$

โดย $k_a \approx 1.35\text{–}1.45$ คือตัวคูณความไม่สมมาตรของไซเคิลแรก รายละเอียดการพิสูจน์และสูตรทั้งหมด (E1–E24) อยู่ใน สตาร์-เดลต้าเชิงลึก และพื้นฐานกราฟแรงบิด-ความเร็วอยู่ใน คู่มือมอเตอร์ไฟฟ้ากระแสสลับ

## 3. วิธีการวิจัย

3.1 แบบจำลอง มอเตอร์ 7.5 kW 4 ขั้ว 400 V Δ 50 Hz โรเตอร์กรงคู่ (In 14.0 A, Tn 49.3 N·m, 1471 rpm, Is/In 6.53, Ts/Tn 2.15, Tk/Tn 3.0, J มอเตอร์ 0.045 kg·m²) เขียนเป็นสมการเวกเตอร์อวกาศในปริมาณจริงของขดลวด สถานะคือฟลักซ์ลิงเกจของสเตเตอร์ กรงนอก กรงใน และความเร็ว แก้ด้วย Runge–Kutta อันดับ 4 ทุก 0.1 ms ระหว่างช่วงตายกระแสสเตเตอร์เป็นศูนย์และคำนวณเฉพาะกรงโรเตอร์ทั้งสอง (ฟลักซ์ต่อเนื่องข้ามการสวิตช์)

3.2 การตรวจสอบ สถานะคงตัว 12 จุดตรงกับวงจรสมมูลถึง 10⁻¹⁶ และทรานเซียนต์ตอนเปลี่ยนจังหวะ (ยอดกระแส แรงบิดสูงสุด-ต่ำสุด ความเร็ว) ตรงกับตัวแก้สมการ LSODA ของ scipy ภายใน 0.3 %

3.3 โหลดและการทดลอง ปั๊มหอยโข่ง 80 % ($T_L \propto n^2$, J รวม 0.105 kg·m², τm 0.33 s) พัดลมใหญ่ (J รวม 2.245 kg·m², τm 7.15 s) และสายพานแรงบิดคงที่ 50 % (J รวม 0.395 kg·m², τm 1.26 s) ทำการทดลอง 14 ชุด:

| ชุด | ตัวแปรต้น | ตัวแปรตาม |

| E1, E7, E13 | ชนิดและขนาดโหลด | ความเร็วสมดุลสตาร์ เวลา t95 t98 สัมประสิทธิ์ c |

| E2, E5 | เวลาไทเมอร์ · วิธีสั่งเปลี่ยน (ไทเมอร์ รีเลย์กระแส ความเร็ว) | ยอดกระแส เวลากระแส > 3·In I²t ความร้อนโรเตอร์ |

| E3, E11 | ช่วงตาย 5–800 ms · ลำดับเฟส KM3 · มุมไฟตอนต่อ | ยอดกระแส แรงบิด แรงดันค้างและมุม |

| E4 | ตัวต้านทานแบบปิดวงจร Rt/Zb | ยอดกระแส แรงบิด พลังงานในตัวต้านทาน |

| E6, E8 | แรงดัน 80–105 % · ความเฉื่อย 0.1–8 kg·m² | เวลาเร่ง เทียบสูตรคลอสส์และแรงบิดเฉลี่ย |

| E9, E10, E12, E14 | วิธีสตาร์ท · โหลดขณะเดิน · ขนาดแหล่งจ่าย | พลังงาน I²t แรงดันตก งบความร้อนโอเวอร์โหลด การเดินสตาร์ถาวร |

3.4 เกณฑ์ตั้งไทเมอร์ที่เสนอ $t_{set} = \max\big(1.2\,t_{98}(V_n),\ t_{95}(0.9V_n)\big)$ คือรอให้ถึง 98 % ของความเร็วสมดุลพร้อมเผื่อ 20 % และต้องไม่สั้นกว่าเวลาถึง 95 % เมื่อไฟตก 10 %

## 4. ผลการทดลอง

### 4.1 เวลาไทเมอร์ (RQ1)

เมื่อวัดเป็นหน่วย τm โค้งการเร่งของปั๊มและพัดลมแทบซ้อนกัน และการเพิ่ม J เป็นสี่เท่าไม่เปลี่ยนค่า t98/τm เลย ผลที่ได้คือตารางสัมประสิทธิ์ที่ใช้กับมอเตอร์ทุกขนาด:

| โหลด (k = แรงบิดที่ความเร็วพิกัด/Tn) | nY/nN | t98/τm | t95/τm ที่ไฟ 90 % | c |

| ปั๊ม T ∝ n² · k 0.6 | 98.2 % | 1.63 | 2.08 | 2.1 |

| ปั๊ม T ∝ n² · k 0.8 | 96.5 % | 1.89 | 2.56 | 2.6 |

| ปั๊ม T ∝ n² · k 1.0 | 94.1 % | 2.31 | 3.44 | 3.4 |

| พัดลม · k 1.0 | 94.2 % | 2.10 | 2.94 | 2.9 |

| T ∝ n · k 0.8 | 96.2 % | 2.37 | 3.96 | 4.0 |

| แรงบิดคงที่ · k 0.5 | 98.8 % | 3.10 | ออกตัวไม่ได้ | 3.7 |

รูป 1 · การเร่งในช่วงสตาร์ของสามโหลดเทียบเวลาในหน่วย τm

ตัวอย่าง: ปั๊ม 37 kW 1480 rpm J รวม 0.87 kg·m² → $T_n = 238.8$ N·m, $\tau_m = 0.87 \times 157.08/238.8 = 0.572$ s → $t_{set} = 2.6 \times 0.572 \approx 1.5$ s (ตั้งจริง 2–3 s) ส่วนพัดลม 7.5 kW J รวม 2.245 kg·m² → $\tau_m = 7.15$ s → $t_{set} = 2.94 \times 7.15 \approx 21$ s ค่า “5–10 s สำหรับทุกงาน” จึงนานเกินจำเป็นสำหรับปั๊มเล็ก และสั้นเกินไปมากสำหรับพัดลมความเฉื่อยสูง สูตรคลอสส์แบบปิดซึ่งนิยมในตำราประเมินเวลาของมอเตอร์กรงคู่สูงเกินราว 74 % (เพราะให้แรงบิดเริ่มเพียง 0.79·Tn แทน 2.15·Tn) ขณะที่วิธีแรงบิดเฉลี่ยคลาดเพียง 2 %

### 4.2 ยอดกระแสตอนเปลี่ยน ช่วงตาย และลำดับเฟส (RQ2)

ผลที่ขัดกับความเชื่อทั่วไปที่สุดของงานนี้คือ ยอดกระแส 1–3 ไซเคิลตอนเปลี่ยนของปั๊มและพัดลมไม่ลดลงตามเวลาไทเมอร์ การกวาดไทเมอร์ของพัดลมจาก 1 ถึง 30 s ได้ยอด 7.6–10.4·In และของปั๊ม 7.7–10.5·In เทียบกับ DOL 8.9·In สิ่งที่ไทเมอร์ที่ถูกต้องลดได้คือ เวลาที่กระแสสูงกว่า 3·In หลังเปลี่ยน: พัดลมตั้ง 8 s (เปลี่ยนที่ 66 % ความเร็ว) ค้าง 0.96 s ตั้ง 20 s เหลือ 0.05 s ส่วนโหลดที่สลิปในสตาร์ต่ำ (สายพาน 50 %) เมื่อเปลี่ยนที่ความเร็วสมดุลได้ยอดเพียง 5.6·In

รูป 2 · การกวาดเวลาไทเมอร์ของพัดลม: ความเร็วตอนเปลี่ยน ยอดกระแส เวลากระแสสูง I²t และความร้อนโรเตอร์

ยอดอธิบายได้ด้วยแรงดันค้าง ตัวอย่างปั๊ม (ช่วงตาย 50 ms): ก่อนเปิด n = 1419 rpm สลิป 0.054 แรงบิดโหลด 37.1 N·m J = 0.105 → $\delta = 0.848 + 0.883 = 1.73$ rad (99°) ครึ่งหนึ่งมาจากการชะลอของโหลดความเฉื่อยต่ำ แรงดันค้าง 134 V ที่มุม −87° เทียบแรงดันเดลต้าใหม่ → $|\Delta V| = 415$ V = 1.04 เท่าของ DOL → $I_{pk} \approx 1.36 \times 1.04 \times 6.53 = 9.2\,I_n$ (จำลอง 9.7·In) ถ้าต่อ KM3 แบบมาตรฐาน มุมเป็น −147° → $|\Delta V| = 518$ V → 11.5·In (จำลอง 11.5·In) และแรงบิดต่ำสุดเป็น −4.4·Tn แทน −0.55·Tn

รูป 3 · เฟสเซอร์ของแรงดันขับทรานเซียนต์ |VΔ − e| ของปั๊มเมื่อต่อ KM3 แบบตามหลังและแบบมาตรฐาน

ช่วงตายมีผลแบบคลื่น (“ลอตเตอรีเฟส”) ในช่วง 5–60 ms ยิ่งสั้นยิ่งดี (ปั๊ม: 5.0·In ที่ 10 ms, 6.8·In ที่ 30 ms, 9.7·In ที่ 50 ms) และแบบตามหลังชนะแบบมาตรฐาน 10–40 % หลังจากนั้นยอดขึ้นลงตามมุมและไม่มีค่าใดดีกับทุกโหลด แบบปิดวงจรที่ Rt = 0.1–0.3·Zb ลดยอดเหลือ 2.9–3.8·In (ปั๊ม) และ 5.6–6.7·In (พัดลม) โดยไม่มีแรงบิดติดลบ

### 4.3 กระแส พลังงาน และความร้อน (RQ3)

| วิธี (พัดลม) | ยอดกระแส | เวลา | I²t สายจ่าย | ความร้อนโรเตอร์ |

| สตาร์ทตรง | 8.9·In | 3.3 s | 100 % | 100 % (30.8 kJ) |

| สตาร์-เดลต้า | 3.0 → 10.4·In | 12.7 s | 51 % | 130 % |

| ซอฟต์สตาร์ท 3·In | 3.0·In | 16.3 s | 140 % | 135 % |

| VFD | 1.2·In | 29.2 s | 17 % | 6 % |

รูป 4 · I²t ของสายจ่ายและความร้อนโรเตอร์ของแต่ละวิธีสตาร์ทเทียบ DOL

พลังงานไฟฟ้าต่อการสตาร์ทหนึ่งครั้งไม่เกินราวร้อยกว่ากิโลจูล (≤ 0.04 kWh ในทุกกรณีของงานนี้) จึง ไม่มีวิธีสตาร์ทใดประหยัดพลังงาน อย่างมีนัยสำคัญ ทฤษฎีบอกว่าถ้าไม่มีโหลด ความร้อนในโรเตอร์เท่ากับ $\tfrac12 J\omega_s^2$ ไม่ว่าจะใช้แรงดันเท่าไร แต่เมื่อมีโหลด แรงดันที่ต่ำทำให้เร่งช้าและสลิปสูงนานขึ้น โรเตอร์จึงร้อนกว่า DOL ประโยชน์จริงของสตาร์-เดลต้าคือ I²t และแรงดันตกระยะยาวที่ลดลง บนหม้อแปลง 250 kVA ปั๊ม 37 kW ทำแรงดันตก 4.8 % (DOL) 1.6 % (ช่วงสตาร์) และ 6.9 % เพียง 1–2 ไซเคิลตอนเปลี่ยน แต่บนเครื่องกำเนิดไฟฟ้า 100 kVA ตัวเลขเป็น 32 %, 13.5 % และ 41 % ตามลำดับ

การทดลองเพิ่มเติม (E9) พบว่าการ เดินสตาร์ถาวร ที่โหลดเบาประหยัดพลังงานได้จริง: 188 W ต่อมอเตอร์ 7.5 kW ที่โหลด 25 % และ cos φ ดีขึ้นจาก 0.46 เป็น 0.79 จุดคุ้มทุนราว 53 % แต่ขอบเผื่อแรงบิด (Tk,Y/TL ≥ 2.5) จำกัดการใช้งานจริงไว้ที่ราว 35–40 % ของพิกัด

รูป 5 · ประสิทธิภาพ ตัวประกอบกำลัง และกำลังที่ประหยัดเมื่อเดินสตาร์เทียบเดลต้า

## 5. อภิปรายผลและกรณีศึกษา

เทียบกับแนวปฏิบัติเดิม คำแนะนำ “เปลี่ยนที่ 85–90 % ความเร็ว” ถูกต้องในหลักการ แต่ช่างวัดความเร็วไม่ได้ เกณฑ์ c·τm แปลงหลักการนี้เป็นตัวเลขจากแคตตาล็อก (J มอเตอร์ J โหลด Pn nN) ส่วนความเชื่อว่า “ยืดช่วงตายให้นานจะลดกระชาก” ไม่ได้รับการสนับสนุนจากผลการทดลอง และ “ไทเมอร์นานไว้ก่อนปลอดภัย” จริงเพียงบางส่วน เพราะขณะค้างที่ความเร็วสมดุล ขดลวดของพัดลมรับกระแส 1.68 เท่าของพิกัดขดลวด (0.97·In ในสตาร์ เทียบพิกัด 0.58·In) ไทเมอร์ 30 s ใช้งบความร้อนของโอเวอร์โหลดคลาส 10 ไป 36 % ต่อครั้ง

กรณีศึกษา (กรณีจำลองจากอาการที่พบบ่อย ตัวเลขจากแบบจำลอง):

- พัดลมดูดอากาศ ไฟกระพริบเกือบวินาที — ตั้ง 8 s เหมือนปั๊ม เปลี่ยนที่ 66 % ความเร็ว กระแสเกิน 3·In ค้าง 0.96 s → ตั้งใหม่ 21 s หรือใช้รีเลย์กระแส เหลือ 0.05–0.22 s

- ปั๊มทริปเป็นครั้งคราวตอนเปลี่ยน — ยอด rms 9.7–11.5·In อยู่ในช่วงปลดทันทีของ MCB แบบ C → ใช้ MPCB/MCCB ปลดทันที ≥ 12–13·In ต่อ KM3 แบบตามหลัง หรือแบบปิดวงจร

- คัปปลิ้งเสียหายหลังซ่อมบำรุง — KM3 ถูกต่อกลับเป็นแบบมาตรฐาน แรงบิดกระชาก −4.4·Tn → ต่อ L1→V2 L2→W2 L3→U2

- ปั๊มบนเครื่องกำเนิดไฟฟ้า ทำให้คอนแทกเตอร์ตัวอื่นหลุด — ยอดตอนเปลี่ยนทำแรงดันตก 41 % → แบบปิดวงจร (≈ 17 %) ซอฟต์สตาร์ท (≈ 18 %) หรือ VFD (≈ 9 %)

ข้อจำกัด แบบจำลองเป็นแม่เหล็กเชิงเส้น คอนแทกเตอร์เปิดสามเฟสพร้อมกันในอุดมคติ แหล่งจ่ายไม่มีอิมพีแดนซ์ในพลวัต และขยายผลไปขนาดอื่นแบบต่อหน่วย ผลจึงเป็นแนวโน้มเชิงปริมาณที่ควรยืนยันด้วยการวัดหน้างาน

## 6. อดีต ปัจจุบัน และอนาคต

- 1889–1891Dolivo-Dobrovolsky (AEG) สร้างมอเตอร์สามเฟสโรเตอร์กรงกระรอกและระบบสามเฟสที่ใช้การต่อสตาร์และเดลต้า

- ต้น–กลางศตวรรษที่ 20จากสวิตช์สตาร์-เดลต้าแบบมือโยก สู่คอนแทกเตอร์กับไทเมอร์ลมและกลไก การไฟฟ้าหลายประเทศจำกัดกระแสสตาร์ท สตาร์-เดลต้าจึงเป็นมาตรฐานในยุโรปและเอเชีย

- 1970–1990ไทเมอร์อิเล็กทรอนิกส์ที่ล็อกช่วงตาย ซอฟต์สตาร์ทไทริสเตอร์ และอินเวอร์เตอร์ IGBT

- ปัจจุบันมอเตอร์ IE3/IE4 (IEC 60034-30-1) มีกระแสสตาร์ทสูงขึ้น คอนแทกเตอร์ประเภท AC-3e (IEC 60947-4-1:2018) รีเลย์วัดกระแส และสตาร์ทเตอร์อัจฉริยะ แบบจำลองแบบในบทความนี้ใช้ออกแบบก่อนติดตั้งได้

- อนาคต (คาดการณ์)การเปลี่ยนจังหวะตามสถานะมอเตอร์และแบบซิงโครนัสที่วัดแรงดันค้าง ไมโครกริดและอินเวอร์เตอร์แบตเตอรี่ที่ทำให้ยอดตอนเปลี่ยนสำคัญขึ้น มอเตอร์ IE4/IE5 ที่ส่วนใหญ่ใช้ VFD และดิจิทัลทวินสำหรับการตั้งค่าหน้างาน

## 7. สรุปและข้อเสนอแนะ

- ตั้งไทเมอร์ $t_{set} = c\,\tau_m$ จากตาราง c (2.1–4.0) และยืนยันด้วยแคลมป์มิเตอร์ว่ากระแสช่วงสตาร์นิ่งก่อนเปลี่ยน

- ถ้าแรงดันหรือโหลดเปลี่ยนบ่อย ใช้รีเลย์กระแสหรือความเร็วแทนไทเมอร์คงที่ (ลดเวลากระแสสูง 3–4 เท่า)

- ใช้ช่วงตายสั้นที่สุดที่ผู้ผลิตรับรอง และต่อ KM3 แบบตามหลัง L1→V2 L2→W2 L3→U2

- บนเครื่องกำเนิดไฟฟ้าหรือไฟอ่อน พิจารณาแบบปิดวงจร ซอฟต์สตาร์ท หรือ VFD

- อุปกรณ์ป้องกันต้องทนยอดตอนเปลี่ยน ~10·In ได้ และสตาร์ทนานกว่า 10 s ใช้โอเวอร์โหลดคลาส 20

- มอเตอร์ที่เดินโหลดเบาคงที่ต่ำกว่า 35–40 % ประเมินการเดินสตาร์ถาวรเพื่อประหยัดไฟ

ลองเปลี่ยนไทเมอร์ ช่วงตาย และลำดับเฟสเองในแล็บจำลองพลวัตที่ สตาร์-เดลต้าเชิงลึก · ห้องทดลอง ผลทุกตัวในบทความทำซ้ำได้ด้วย node scripts/yd_research.mjs และ python3 scripts/yd_check.py ในคลังโค้ดของเว็บไซต์

## คำถามที่พบบ่อย

ตั้งไทเมอร์สตาร์-เดลต้ากี่วินาที?
คำนวณค่าคงตัวเวลาทางกล τm = J·ωs/Tn แล้วคูณด้วย c ≈ 2–4 ตามชนิดโหลด (ปั๊มหอยโข่ง 80 % ≈ 2.6 พัดลม ≈ 2.9 รวมเผื่อไฟตก 10 %) เช่น ปั๊ม 37 kW ที่ J รวม 0.87 kg·m² ได้ราว 1.5 s (ตั้ง 2–3 s) ส่วนพัดลม 7.5 kW ที่ J รวม 2.245 kg·m² ได้ราว 21 s แล้วยืนยันด้วยแคลมป์มิเตอร์ว่ากระแสช่วงสตาร์นิ่งก่อนเปลี่ยน

ตั้งไทเมอร์นานขึ้นแล้วกระแสกระชากตอนเปลี่ยนจะลดลงไหม?
ลดเฉพาะส่วนที่ค้างนาน ผลจำลองปั๊มและพัดลมให้ยอด 1–3 ไซเคิลราว 7.6–10.5·In ไม่ว่าตั้งเท่าไร (DOL 8.9·In) เพราะยอดถูกกำหนดโดยผลต่างระหว่างแรงดันเดลต้ากับแรงดันค้างในมอเตอร์ สิ่งที่ไทเมอร์ที่ถูกต้องลดได้คือเวลาที่กระแสสูงกว่า 3·In หลังเปลี่ยน เช่น พัดลมจาก 0.96 s (ตั้ง 8 s) เหลือ 0.05 s (ตั้ง 20 s)

ช่วงตายระหว่าง KM2 กับ KM3 ยิ่งนานยิ่งดีไหม?
ไม่ ช่วงตายต้องนานพอให้อาร์กใน KM2 ดับก่อน KM3 ต่อ (ไทเมอร์สำเร็จรูปมักใช้ราว 30–80 ms) แต่การยืดให้นานขึ้นไม่ได้ลดกระชาก เพราะมุมของแรงดันค้างหมุนไปเรื่อยๆ ผลจำลองชี้ว่าใช้ค่าสั้นที่สุดที่ปลอดภัย และต่อ KM3 แบบตามหลัง L1→V2 L2→W2 L3→U2 ดีกว่า

สตาร์-เดลต้าดีกว่าสตาร์ทตรงในเรื่องใดจริงๆ?
ลดกระแสช่วงเร่งเหลือ 1/3 แรงดันตกระยะยาวเหลือ 1/3 และ I²t ของสายจ่าย 25–50 % แต่ไม่ประหยัดพลังงาน และโรเตอร์ร้อนกว่า DOL 30–55 % บนเครื่องกำเนิดไฟฟ้า ยอดตอนเปลี่ยนอาจทำแรงดันตกมากกว่า DOL ด้วยซ้ำ

ทำซ้ำผลการทดลองในบทความนี้ได้อย่างไร?
เปิดแล็บจำลองในหน้า สตาร์-เดลต้าเชิงลึก ของคลังความรู้ หรือรัน node scripts/yd_research.mjs และ python3 scripts/yd_check.py ในคลังโค้ดของเว็บไซต์ ซึ่งใช้แบบจำลองเดียวกับที่ใช้เขียนบทความนี้
