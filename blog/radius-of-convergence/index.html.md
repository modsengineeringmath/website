# รัศมีการลู่เข้าของอนุกรมกำลังหาอย่างไร: 3 วิธี ตรวจปลายช่วง และเหตุผลจากระนาบเชิงซ้อน

// บทความ · ลำดับและอนุกรม


อนุกรมกำลังเหมือนพหุนามที่ยาวไม่สิ้นสุด มันแทนฟังก์ชันได้เฉพาะในช่วงหนึ่งรอบจุดศูนย์กลาง ความกว้างครึ่งหนึ่งของช่วงนั้นคือรัศมีการลู่เข้า R บทความนี้สอนสามวิธีหา R ขั้นตอนตรวจปลายช่วงที่ข้อสอบเก็บคะแนน และคำอธิบายที่ตำราไม่ค่อยบอกว่าทำไม R จึงมีค่าเท่านั้น

สรุปใน 30 วินาที

- วิธี 1 อัตราส่วน: $R = \lim\left|\dfrac{c_n}{c_{n+1}}\right|$ · วิธี 2 ราก: $\dfrac1R = \lim\sqrt[n]{|c_n|}$

- วิธี 3 ระนาบเชิงซ้อน: R = ระยะจาก a ถึงจุดเอกฐานที่ใกล้ที่สุดของฟังก์ชัน

- ปลายช่วง $x = a \pm R$ ต้องแทนค่าแล้วทดสอบแยกเสมอ

## รัศมีการลู่เข้าคืออะไร

ในช่วง |x − a| < R อนุกรมลู่เข้าแบบสัมบูรณ์ นอกช่วงลู่ออก ส่วนที่ปลายทั้งสองต้องตรวจเอง

ทฤษฎีบทสำคัญบอกว่าอนุกรมกำลัง $\sum c_n(x-a)^n$ มีพฤติกรรมได้แบบเดียว: มีจำนวน R (อาจเป็น 0 หรือ ∞) ที่ข้างในลู่เข้า ข้างนอกลู่ออก ไม่มีทางที่จะลู่เข้าเป็นหย่อม ๆ หรือลู่เข้าเฉพาะด้านขวาของ a งานของเราจึงเหลือแค่หา R แล้วตรวจสองจุดที่ขอบ

## วิธีที่ 1: การทดสอบอัตราส่วน (ใช้บ่อยที่สุด)

ใช้ ratio test กับค่าสัมบูรณ์ของพจน์เต็ม แล้วแก้อสมการ “ลิมิต < 1” จะได้ R โดยไม่ต้องจำว่า $c_n$ อยู่บนหรือล่าง

ตัวอย่าง 1

### หาช่วงการลู่เข้าของ $\displaystyle\sum_{n=1}^{\infty}\frac{(x-3)^n}{n\,2^n}$

- $\left|\dfrac{a_{n+1}}{a_n}\right| = \dfrac{|x-3|}{2}\cdot\dfrac{n}{n+1} \to \dfrac{|x-3|}{2} < 1 \iff |x - 3| < 2$ ⇒ $R = 2$

- ปลาย x = 1: $\sum\dfrac{(-1)^n}{n}$ ลู่เข้า (ไลบ์นิซ) · ปลาย x = 5: $\sum\dfrac{1}{n}$ ลู่ออก

$R = 2$ · ช่วงการลู่เข้า $[1, 5)$

ตัวอย่าง 2 · R เป็น e

### หาช่วงการลู่เข้าของ $\sum\dfrac{n!\,x^n}{n^n}$

- $\left|\dfrac{a_{n+1}}{a_n}\right| = |x|\left(\dfrac{n}{n+1}\right)^n \to \dfrac{|x|}{e}$ ⇒ $R = e$

- ที่ $x = \pm e$: ขนาดพจน์ $\dfrac{n!\,e^n}{n^n} \approx \sqrt{2\pi n} \to \infty$ (สเตอร์ลิง) ลู่ออกทั้งสองปลาย

$(-e, e)$

## วิธีที่ 2: การทดสอบราก (เมื่อมีกำลัง n ซ้อน)

สูตรโคชี-อาดามาร์ $\dfrac{1}{R} = \limsup\sqrt[n]{|c_n|}$ ใช้ได้เสมอ และสะดวกเมื่อสัมประสิทธิ์ยกกำลัง n หรือมีช่องว่าง (สัมประสิทธิ์เป็นศูนย์สลับ) ที่วิธีอัตราส่วนใช้ไม่ได้

ตัวอย่าง 3

### หารัศมีการลู่เข้าของ $\displaystyle\sum_{n=1}^{\infty}\left(\frac{n}{n+1}\right)^{n^2}x^n$

- $\sqrt[n]{|c_n|} = \left(\dfrac{n}{n+1}\right)^{n} \to \dfrac1e$ ⇒ $R = e$

- ที่ $x = \pm e$: $\left(\dfrac{n}{n+1}\right)^{n^2}e^n \to e^{1/2} \ne 0$ ลู่ออกทั้งสองปลาย

$(-e, e)$ — วิธีอัตราส่วนกับข้อนี้ยุ่งกว่ามาก

## วิธีที่ 3: มองจากระนาบเชิงซ้อน (เข้าใจว่าทำไม)

ลองดูอนุกรม $\dfrac{1}{1+x^2} = 1 - x^2 + x^4 - \cdots$ บนเส้นจำนวนจริงฟังก์ชันนี้เรียบทุกจุด ไม่มีจุดไหนระเบิด แต่อนุกรมลู่เข้าแค่ $|x| < 1$ ทำไม? คำตอบคืออนุกรมกำลังลู่เข้าเป็นดิสก์ในระนาบเชิงซ้อน และดิสก์ขยายได้จนชนจุดเอกฐานแรก ซึ่งสำหรับ $\tfrac{1}{1+z^2}$ อยู่ที่ $z = \pm i$ ห่างจากศูนย์กลาง 1 หน่วยพอดี

ดิสก์การลู่เข้ารอบ 0 ของ 1/(1+z²) ชนโพล ±i ที่ระยะ 1 สิ่งที่เห็นบนแกนจริงคือรอยตัด (−1, 1)

ตัวอย่าง 4 · ไม่ต้องคำนวณสัมประสิทธิ์

### อนุกรมเทย์เลอร์ของ $f(x) = \dfrac{1}{x^2 - 4x + 13}$ รอบ (ก) 0 (ข) 2 มีรัศมีการลู่เข้าเท่าไร

- โพลของ f: $z^2 - 4z + 13 = 0 \Rightarrow z = 2 \pm 3i$

- (ก) ระยะจาก 0: $|2 \pm 3i| = \sqrt{13}$ · (ข) ระยะจาก 2: $|\pm 3i| = 3$

(ก) $R = \sqrt{13} \approx 3.61$ · (ข) $R = 3$

วิธีนี้ใช้ตรวจคำตอบของวิธีที่ 1–2 ได้ดีมาก และอธิบายว่าทำไม $\tan x$ มีรัศมี $\pi/2$ (เพราะ $\cos z = 0$ ที่ $z = \pm\pi/2$) ส่วน $e^x, \sin x, \cos x$ ไม่มีจุดเอกฐานเลยจึงมี $R = \infty$

## ตรวจปลายช่วง: เช็กลิสต์

- แทน $x = a + R$ และ $x = a - R$ ลงในอนุกรม ได้อนุกรมตัวเลขสองตัว

- ถ้าพจน์ไม่เข้าใกล้ 0 ⇒ ลู่ออกที่ปลายนั้น

- ถ้าเป็นรูป $\sum\tfrac{1}{n^p}$ ใช้อนุกรม p · ถ้าสลับเครื่องหมายใช้ไลบ์นิซ (และตรวจค่าสัมบูรณ์ถ้าโจทย์ถามชนิดการลู่เข้า)

- เขียนช่วงด้วยวงเล็บที่ถูก: ( ) ไม่รวม · [ ] รวม

จำตัวอย่างมาตรฐานนี้ไว้เทียบ: $\sum x^n$ ได้ $(-1, 1)$ · $\sum\tfrac{x^n}{n}$ ได้ $[-1, 1)$ · $\sum\tfrac{x^n}{n^2}$ ได้ $[-1, 1]$ — รัศมีเท่ากัน แต่ปลายช่วงต่างกันหมด

## ลองเองในแล็บ

แล็บรัศมีการลู่เข้า แสดงผลบวกย่อยเทียบกับฟังก์ชันบนเส้นจำนวน พร้อมดิสก์ในระนาบเชิงซ้อนข้างกัน เลื่อนดีกรีแล้วจะเห็นว่าในช่วงลู่เข้าผลบวกย่อยเกาะฟังก์ชันแน่นขึ้น นอกช่วงแกว่งหนีออกไป และพิมพ์ $c_n$ เองได้

## เรียนต่อในคลังความรู้

- อนุกรมกำลังฉบับเต็ม: อนุพันธ์-อินทิกรัลทีละพจน์ ทฤษฎีบทอาเบล แก้สมการเชิงอนุพันธ์

- อนุกรมเทย์เลอร์และแมคลอริน: ตารางที่ต้องจำ เศษเหลือ

- อนุกรมโลรองต์: เมื่อจุดศูนย์กลางเป็นจุดเอกฐาน

- โจทย์ช่วงการลู่เข้า B7–B10 พร้อมเฉลย
