    รัศมีการลู่เข้าคืออะไร?

    อนุกรมกำลัง ∑cn(x−a)n\sum c_n(x-a)^n∑cn​(x−a)n จะลู่เข้าเมื่อ ∣x−a∣<R|x - a| < R∣x−a∣<R และลู่ออกเมื่อ ∣x−a∣>R|x - a| > R∣x−a∣>R ค่า R นี้คือรัศมีการลู่เข้า อาจเป็น 0 (ลู่เข้าแค่ที่ x = a) หรือ ∞ (ลู่เข้าทุก x)

    รัศมีการลู่เข้ากับช่วงการลู่เข้าต่างกันอย่างไร?

    รัศมีเป็นตัวเลขตัวเดียว ส่วนช่วงการลู่เข้าคือช่วง (a−R,a+R)(a - R, a + R)(a−R,a+R) รวมปลายช่วงที่ลู่เข้า ซึ่งต้องตรวจแยกที่ x = a − R และ x = a + R ช่วงจึงอาจเป็นแบบเปิด ปิด หรือครึ่งเปิด

    ทำไม ratio test ใช้ตรวจปลายช่วงไม่ได้?

    เพราะที่ ∣x−a∣=R|x - a| = R∣x−a∣=R ลิมิตของอัตราส่วนเท่ากับ 1 พอดีทุกครั้ง ซึ่งเป็นกรณีที่ ratio test สรุปไม่ได้ ต้องแทนค่า x แล้วใช้การทดสอบอื่น เช่น อนุกรม p ไลบ์นิซ หรือพจน์ที่ n

เกณฑ์เสถียรภาพของเราท์–เฮอร์วิตซ์ วาดรูทโลคัสด้วยมือ ตัวควบคุม PID และการจูน เมคาทรอนิกส์และโรโบติกส์ เครื่องมือเขียนบทเรียน ดูดวงไพ่ทาโรต์ Celtic Cross อ่านไพ่ทาโรต์จากภาพถ่าย เกี่ยวกับอาจารย์มด
