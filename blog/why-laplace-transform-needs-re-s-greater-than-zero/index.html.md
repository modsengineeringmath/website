# ทำไม ℒ{1} = 1/s ต้องมีเงื่อนไข Re(s) > 0 ต่อท้าย

THภาษาไทยENEnglish
// บทความ · Laplace Transform


คำถามนี้ผมเจอแทบทุกเทอม นักศึกษาจำสูตร $\mathcal{L}\{1\} = 1/s$ ได้ตั้งแต่สัปดาห์แรก แต่พอถามว่าวงเล็บท้ายสูตรที่เขียนว่า $\operatorname{Re}(s) > 0$ มาจากไหน ห้องจะเงียบไปพักหนึ่ง บทความนี้ตอบให้สั้นที่สุดเท่าที่ทำได้ ส่วนใครอยากเห็นทุกขั้นพร้อมแล็บ ตามไปที่บทเรียนฉบับเต็มได้เลย

สรุปใน 30 วินาที

- นิยามเป็นอินทิกรัลถึงอนันต์ คำตอบ $1/s$ จะออกมาได้ก็ต่อเมื่อ $e^{-sT}$ หายไปตอน $T$ โตมาก ๆ

- สูตรออยเลอร์แยก $e^{-st}$ เป็นส่วนหด $e^{-\sigma t}$ กับส่วนหมุน $e^{-j\omega t}$ ซึ่งขนาดเป็น 1 เสมอ

- ดังนั้นตัวตัดสินคือ σ อย่างเดียว ต้องได้ $\sigma = \operatorname{Re}(s) > 0$ ส่วน ω จะเป็นเท่าไรก็ได้

## เริ่มจากนิยามตรง ๆ

อินทิกรัลที่ขอบบนเป็นอนันต์ ความหมายจริง ๆ คืออินทิเกรตถึง $T$ ก่อน แล้วค่อยดูว่าพอ $T$ ใหญ่ขึ้นเรื่อย ๆ ค่ามันนิ่งหรือเปล่า ลองทำกับค่าคงที่ $c$ (หรือ $c\,u(t)$ ซึ่งในการแปลงด้านเดียวให้ผลเท่ากัน):

$$\int_0^{T} c\,e^{-st}\,dt = \frac{c}{s} - \frac{c}{s}\,e^{-sT}$$

พจน์แรกคือคำตอบที่เราจำกันได้ พจน์ที่สองคือส่วนเกินที่ต้องหายไป ถ้ามันไม่หาย เราก็ไม่มีสิทธิ์เขียนว่าผลลัพธ์คือ $c/s$ เรื่องทั้งหมดจึงเหลือคำถามเดียว: $e^{-sT}$ ไปที่ศูนย์เมื่อไร

ถ้า $s$ เป็นจำนวนจริงก็ตอบง่าย $s > 0$ หดลง $s = 0$ ได้ 1 ตลอด (พื้นที่เป็น $cT$ โตไม่หยุด) ส่วน $s < 0$ โตแบบเอกซ์โพเนนเชียล ตำราปีหนึ่งหลายเล่มจึงเขียนว่า $s > 0$ และจบแค่นั้น

## พอ s เป็นจำนวนเชิงซ้อน ออยเลอร์ช่วยได้

ปัญหาคือในลาปลาซจริง $s = \sigma + j\omega$ และจำนวนเชิงซ้อนเอาไปเทียบว่ามากกว่าศูนย์ไม่ได้ ใครถามว่า $2 + 3j > 0$ ไหม คำตอบคือคำถามนี้ไม่มีความหมาย เราจึงต้องแยก $e^{-st}$ ออกมาดูทีละส่วน ด้วยสูตรออยเลอร์ $e^{-j\theta} = \cos\theta - j\sin\theta$:

$$e^{-st} = e^{-\sigma t}\,e^{-j\omega t},\qquad |e^{-j\omega t}| = \sqrt{\cos^2\omega t + \sin^2\omega t} = 1$$

บรรทัดนี้สำคัญที่สุด ส่วน $e^{-j\omega t}$ แค่หมุนอยู่บนวงกลมหนึ่งหน่วย ไม่เคยหดไม่เคยโต ขนาดของ $e^{-sT}$ จึงเหลือ $e^{-\sigma T}$ ตัวเดียว ซึ่งไปที่ศูนย์ก็ต่อเมื่อ $\sigma > 0$ นั่นคือที่มาของ $\operatorname{Re}(s) > 0$ และเป็นเหตุผลที่ ROC เป็นครึ่งระนาบขวา ขอบเป็นเส้นตั้ง เพราะขยับ ω ขึ้นลงเท่าไรผลก็ไม่เปลี่ยน

เช็กด้วยตัวเลขสักหน่อย: ที่ $s = 2 + 3j$ ได้ $\mathcal{L}\{5\} = 5/(2+3j) = \tfrac{10}{13} - \tfrac{15}{13}j$ ถ้าแยกเป็นอินทิกรัลของ $e^{-2t}\cos 3t$ กับ $e^{-2t}\sin 3t$ แล้วอินทิเกรตทีละส่วนก็ได้ตัวเลขเดียวกันพอดี

## แล้วบนเส้น Re(s) = 0 ล่ะ

ข้อนี้คนพลาดบ่อย เพราะที่ $s = j\omega$ ค่าไม่ได้ระเบิดเป็นอนันต์ อินทิกรัลถึง $T$ คือ $(1 - e^{-j\omega T})/(j\omega)$ ซึ่งวนอยู่บนวงกลมรัศมี $1/|\omega|$ ไปเรื่อย ๆ ไม่หยุดที่ไหนเลย มีขอบเขตแต่ไม่มีลิมิต ส่วนที่ $s = 0$ ก็โตเป็นเส้นตรง เงื่อนไขจึงต้องเป็น “มากกว่า” ไม่ใช่ “มากกว่าหรือเท่ากับ” ภาพด้านล่างคือเส้นทางของอินทิกรัลบางส่วน $I(T)$ บนระนาบเชิงซ้อนทั้งสามกรณี

σ > 0 เกลียวเข้าหา 1/s · σ = 0 วนเป็นวงกลม · σ < 0 เกลียวออก

## รู้ไปทำไม ในเมื่อสอบก็แค่เขียนสูตร

เพราะเงื่อนไขนี้กลับมาหาเราอีกหลายรอบ ตอนแปลงกลับด้วยอินทิกรัลบรอมวิช เส้นที่อินทิเกรตต้องอยู่ใน ROC พอดี ตอนใช้ทฤษฎีบทค่าสุดท้ายในระบบควบคุม การให้ $s \to 0$ ก็คือการเข้าหาศูนย์จากด้านในของ ROC ถ้าระบบไม่เสถียร ROC ถูกดันไปทางขวา ทฤษฎีบทนี้จะให้ตัวเลขที่ผิดทันที และในวิชาสัญญาณและระบบ $1/s$ ตัวเดียวอาจหมายถึง $u(t)$ หรือ $-u(-t)$ ก็ได้ ขึ้นกับ ROC

ใครอยากลองลากค่า $s$ บนระนาบแล้วดูเกลียวออยเลอร์หมุนจริง ๆ แล็บอยู่ในบทเรียน 8.6 และถ้าพื้นจำนวนเชิงซ้อนยังไม่แน่น แนะนำอ่านจำนวนเชิงซ้อนและฟังก์ชันวิเคราะห์ก่อน

## เรียนต่อในคลังความรู้

- ทำไม s > 0 และ Re{s} > 0: บทเรียนเต็มพร้อมพิสูจน์และแล็บ

- การแปลงลาปลาซ: นิยาม ตารางคู่การแปลงพร้อม ROC

- แผนภาพโพล-ซีโร่และบริเวณลู่เข้า (ROC)

- คลิป: การแปลงลาปลาซของฟังก์ชันค่าคงที่

## คำถามที่พบบ่อย

s > 0 กับ Re(s) > 0 ต่างกันอย่างไร?
ถ้า s เป็นจำนวนจริง สองเงื่อนไขนี้คือเรื่องเดียวกัน แต่ในการแปลงลาปลาซ s เป็นจำนวนเชิงซ้อน σ + jω ซึ่งเทียบมากกว่าน้อยกว่ากับศูนย์ไม่ได้ เงื่อนไขที่เขียนได้ถูกต้องจึงเป็น Re(s) = σ > 0

ทำไม ω ไม่มีผลกับการลู่เข้า?
เพราะ $e^{-st} = e^{-\sigma t}e^{-j\omega t}$ และ $|e^{-j\omega t}| = 1$ เสมอ ขนาดของ $e^{-st}$ จึงเหลือ $e^{-\sigma t}$ ω ทำให้หมุนอย่างเดียว ไม่ทำให้หด

ทำไม Re(s) = 0 ใช้ไม่ได้ ทั้งที่ค่ายังไม่เป็นอนันต์?
ที่ s = jω อินทิกรัลถึง T วนเป็นวงกลมไปเรื่อย ๆ ไม่หยุดที่ค่าใด จึงไม่มีลิมิต ส่วนที่ s = 0 พื้นที่เป็น cT ซึ่งโตไม่สิ้นสุด เงื่อนไขจึงต้องเป็นมากกว่าศูนย์แท้
