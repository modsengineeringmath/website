# เรียนเมทริกซ์และดีเทอร์มิแนนต์ให้จบ: แผนที่ 7 ขั้นจาก ม.ปลาย สอบเข้ามหาวิทยาลัย ถึงคณิตศาสตร์วิศวกรรม

// บทความ · พีชคณิตเชิงเส้น


เมทริกซ์เป็นหัวข้อที่นักเรียนจำนวนมากรู้สึกว่า “คำนวณได้แต่ไม่เห็นภาพ” เพราะเรียนเป็นสูตรแยกกัน บทความนี้จัดทุกเรื่องให้เป็นเส้นทางเดียว ตั้งแต่การคูณเมทริกซ์ใน ม.5 ไปจนถึงวิธีที่โปรแกรมจำลองวงจรใช้แก้สมการนับล้านตัวแปร พร้อมบอกว่าเป้าหมายแต่ละแบบต้องไปถึงขั้นไหน

สรุปใน 30 วินาที

- ทุกหัวข้อตอบคำถามเดียวกัน: แก้ $A\mathbf x = \mathbf b$ อย่างไร มีคำตอบไหม และคำตอบเชื่อได้แค่ไหน

- สอบเข้า: ขั้น 1–3 (เมทริกซ์ ดีเทอร์มิแนนต์ อินเวอร์ส คราเมอร์) · ป.ตรี: เพิ่มขั้น 4–5 (ลดแถว แรงก์) · วิศวกรรม: ขั้น 6–7

- ฝึกด้วยแนวข้อสอบ 45 ข้อและโจทย์สุ่ม ตรวจการบ้านด้วยแล็บเมทริกซ์

## ทำไมต้องเรียนเมทริกซ์: ระบบสมการอยู่ทุกที่

วงจรไฟฟ้าสามลูปให้สมการกระแสสามสมการ โครงหลังคาเหล็กให้สมการสมดุลแรงที่ทุกข้อต่อ แบบจำลองความร้อนให้หนึ่งสมการต่อหนึ่งจุด ทั้งหมดเขียนสั้น ๆ ได้เป็น

$$A\mathbf x = \mathbf b$$

โดย $A$ เก็บสัมประสิทธิ์ $\mathbf x$ คือสิ่งที่ไม่รู้ และ $\mathbf b$ คือค่าที่กำหนด เมทริกซ์จึงไม่ใช่ตารางตัวเลขเฉย ๆ แต่เป็นภาษาที่ทำให้ระบบหลายร้อยสมการจัดการได้เหมือนสมการเดียว

## แผนที่ 7 ขั้น

เส้นทางจาก ม.ปลาย ถึงงานวิศวกรรม สีบอกระดับ: ส้ม = สอบเข้า · น้ำเงิน = ป.ตรี · เขียว = งานวิศวกรรม

| ขั้น | ตอบคำถาม | บทเรียน |

| 1 เมทริกซ์ | เขียนระบบเป็น $A\mathbf x = \mathbf b$ และคูณอย่างไร | 7.1 |

| 2 ดีเทอร์มิแนนต์ | มีคำตอบเดียวไหม ($\det A \ne 0$) | 7.2 |

| 3 อินเวอร์ส · คราเมอร์ | คำตอบคืออะไร (ระบบเล็ก) | 7.4 · 7.5 |

| 4 ลดแถว | แก้ได้ทุกกรณี แม้ $\det = 0$ | 7.3 |

| 5 แรงก์ | คำตอบเดียว ไม่จำกัด หรือไม่มี | 7.10 |

| 6 วิธีเชิงตัวเลข | แก้ระบบใหญ่ให้เร็วและแม่น | 7.11 |

| 7 ค่าเฉพาะ · การประยุกต์ | ระบบตอบสนองอย่างไร (ขั้ว โหมด) | 7.6 · 7.7 |

## ถ้าเป้าหมายคือสอบเข้ามหาวิทยาลัย

- คูณเมทริกซ์ให้คล่อง และจำว่า $AB \ne BA$ แต่ $(AB)^T = B^TA^T$

- ดีเทอร์มิแนนต์ 2×2 และ 3×3 (ซาร์รัสหรือโคแฟกเตอร์)

- สมบัติดีเทอร์มิแนนต์ทั้งหมด โดยเฉพาะ $\det(kA) = k^n\det A$ และ $\det(\operatorname{adj}A) = (\det A)^{n-1}$ — สรุปไว้ในบทความสมบัติดีเทอร์มิแนนต์ 12 ข้อ

- อินเวอร์ส 2×2 และสมการ $AX = B$ (คูณ $A^{-1}$ ทางซ้าย)

- คราเมอร์หาตัวแปรเดียว และระบบมีพารามิเตอร์ ($\Delta = 0$ แยกไม่มีคำตอบกับไม่จำกัด) — ดูบทความกฎของคราเมอร์

## ถ้าเรียน ป.ตรี และคณิตศาสตร์วิศวกรรม

- การลดแถวแบบเกาส์และเกาส์-จอร์แดน ใช้หาทั้งคำตอบ อินเวอร์ส และแรงก์

- แรงก์และทฤษฎีบทรูเช-กาเปลลี โจทย์ “แรงก์สำหรับทุกค่า $k$” ปริภูมิศูนย์ — ดูบทความแรงก์ของเมทริกซ์

- ค่าเฉพาะ เวกเตอร์เฉพาะ และการทำให้เป็นเมทริกซ์ทแยงมุม ซึ่งต่อไปยังระบบควบคุมและสมการเชิงอนุพันธ์

- วิธีเชิงตัวเลข LU จาโคบี เกาส์-ไซเดล และเลขเงื่อนไข — ดูบทความเปรียบเทียบวิธีเชิงตัวเลข

## แผนฝึก 7 วัน (วันละ 45–60 นาที)

- วันที่ 1: อ่าน เมทริกซ์ ใช้ ตัวช่วยดูการคูณทีละช่อง

- วันที่ 2: ดีเทอร์มิแนนต์ จนถึงสูตรลัดออกสอบ ทำชุด A ข้อ 1–6

- วันที่ 3: อินเวอร์ส และ คราเมอร์ ทำชุด A ข้อ 7–12

- วันที่ 4: ลดแถว ทำชุด A ข้อ 13–18

- วันที่ 5: แรงก์ เล่นแล็บสามระนาบ ทำชุด B ข้อ 1–8

- วันที่ 6: วิธีเชิงตัวเลข ทำชุด C

- วันที่ 7: โจทย์สุ่ม ทุกระดับจนถูกติดกัน 10 ข้อ ข้อที่ผิดกลับไปอ่านสูตรตามรหัสในเฉลย

## อ่านต่อในคลังความรู้

- พีชคณิตเชิงเส้นทั้งชุด 12 หน้า พร้อมค้นหาสูตร

- แนวข้อสอบเมทริกซ์ ดีเทอร์มิแนนต์ แรงก์ คราเมอร์ 45 ข้อ

- เมทริกซ์ในวงจรไฟฟ้าและระบบไฟฟ้ากำลัง

- บทความ: วิธีหา Determinant และ Inverse Matrix

## คำถามที่พบบ่อย

เรียนเมทริกซ์ควรเริ่มจากอะไร?
เริ่มจากขนาด การบวก การคูณ และทรานสโพสของเมทริกซ์ ต่อด้วยดีเทอร์มิแนนต์ 2×2 และ 3×3 กับสมบัติของมัน แล้วจึงไปที่อินเวอร์ส กฎของคราเมอร์ และการลดแถวแก้ระบบสมการ หัวข้อหลังทุกเรื่องใช้การคูณเมทริกซ์และดีเทอร์มิแนนต์เป็นพื้นฐาน

สอบเข้ามหาวิทยาลัยต้องรู้เรื่องเมทริกซ์แค่ไหน?
ต้องคล่องการคูณ ทรานสโพส ดีเทอร์มิแนนต์ 2×2 และ 3×3 สมบัติของดีเทอร์มิแนนต์ (det(kA), det(AB), det(A⁻¹), det(adj A)) อินเวอร์ส 2×2 สมการเมทริกซ์ กฎของคราเมอร์ และระบบสมการที่มีพารามิเตอร์ เรื่องแรงก์และวิธีเชิงตัวเลขเป็นของระดับมหาวิทยาลัย

วิศวกรใช้เมทริกซ์ทำอะไร?
ใช้แก้ระบบสมการของวงจรไฟฟ้า (วิเคราะห์โนดและเมช) ระบบไฟฟ้ากำลัง โครงสร้าง และการสั่น ใช้หาขั้วของระบบควบคุมจากค่าเฉพาะ และใช้วิธีเชิงตัวเลขอย่าง LU หรือเกาส์-ไซเดลในโปรแกรมจำลองที่มีตัวแปรนับพันนับล้าน

ฝึกโจทย์เมทริกซ์ได้ที่ไหน?
หน้าแนวข้อสอบในคลังความรู้มี 45 ข้อพร้อมเฉลยทีละขั้น 3 ระดับ (สอบเข้า ป.ตรี และวิธีเชิงตัวเลข) และมีเครื่องสุ่มโจทย์ที่ตรวจคำตอบให้ทันที ฝึกได้ไม่จำกัด
