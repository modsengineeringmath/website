# สูตรอนุกรมเลขคณิต (Arithmetic Series): ผลบวก n พจน์ พจน์ทั่วไป ที่มาของสูตร และตัวอย่าง

อนุกรมเลขคณิตคือการบวกตัวเลขที่เพิ่มขึ้นทีละเท่ากัน เช่น $3 + 7 + 11 + 15$ มีสูตรเดียวที่ต้องจำ และที่มาของสูตรเข้าใจได้ในบรรทัดเดียวด้วยวิธีที่เด็กชายเกาส์ใช้บวก 1 ถึง 100 บทความนี้สรุปสูตร ที่มา ตัวอย่างที่ออกสอบบ่อย และศัพท์ภาษาอังกฤษ

สรุปใน 30 วินาที

- พจน์ทั่วไป: $a_n = a_1 + (n-1)d$ โดย $d$ คือผลต่างร่วม (common difference) $= a_{n+1} - a_n$

- ผลบวก n พจน์: $S_n = \dfrac{n}{2}(a_1 + a_n) = \dfrac{n}{2}\big[2a_1 + (n-1)d\big]$

- จำนวนพจน์: $n = \dfrac{a_n - a_1}{d} + 1$ (อย่าลืม +1)

- คำนวณเองพร้อมวิธีทำ: เครื่องคิดเลขอนุกรมเลขคณิต

## อนุกรมเลขคณิตคืออะไร

ลำดับเลขคณิต (arithmetic sequence) คือลำดับที่พจน์ถัดไปได้จากการบวกค่าคงที่ $d$ เข้ากับพจน์ก่อนหน้า เช่น $3, 7, 11, 15, \dots$ มี $d = 4$ ส่วนอนุกรมเลขคณิต (arithmetic series) คือผลบวกของพจน์เหล่านั้น $3 + 7 + 11 + 15 + \cdots$

วิธีหา $d$: เอาพจน์ใดลบด้วยพจน์ก่อนหน้า ถ้าได้ค่าเท่ากันทุกคู่ก็เป็นลำดับเลขคณิต $d$ เป็นลบได้ (ค่าลดลง) และเป็นศูนย์ได้ (ทุกพจน์เท่ากัน)

$$a_n = a_1 + (n-1)d$$

เหตุผลของ $(n-1)$: จากพจน์ที่ 1 ไปถึงพจน์ที่ n ต้องก้าว $n-1$ ก้าว ก้าวละ $d$ เหมือนนับรั้วระหว่างเสา 10 ต้นมีช่อง 9 ช่อง

## สูตรผลบวก n พจน์ และที่มาแบบเกาส์

$$S_n = a_1 + a_2 + \cdots + a_n = \frac{n}{2}\,(a_1 + a_n) = \frac{n}{2}\big[2a_1 + (n-1)d\big]$$

ที่มา: เขียนผลบวกสองครั้ง ครั้งแรกเรียงจากหน้าไปหลัง ครั้งที่สองเรียงจากหลังมาหน้า แล้วบวกกันเป็นคู่ตามแนวตั้ง

$$\begin{array}{rcl} S_n &=& a_1 + (a_1 + d) + \cdots + (a_n - d) + a_n \\ S_n &=& a_n + (a_n - d) + \cdots + (a_1 + d) + a_1 \\ \hline 2S_n &=& \underbrace{(a_1 + a_n) + (a_1 + a_n) + \cdots + (a_1 + a_n)}_{n\ \text{คู่}} \end{array}$$

ทุกคู่มีผลบวกเท่ากันคือ $a_1 + a_n$ เพราะคู่ถัดไปตัวหน้าเพิ่ม $d$ ตัวหลังลด $d$ หักล้างกันพอดี จึงได้ $2S_n = n(a_1 + a_n)$ ความหมายที่จำง่ายที่สุด: ผลบวก = จำนวนพจน์ × ค่าเฉลี่ยของพจน์แรกกับพจน์สุดท้าย

ตัวอย่าง 1 · ปัญหาของเกาส์

### หา $1 + 2 + 3 + \cdots + 100$

- $a_1 = 1,\ a_n = 100,\ n = 100$ จับคู่หน้า-หลังได้ 50 คู่ คู่ละ 101

$$S_{100} = \frac{100}{2}(1 + 100) = 50 \times 101$$

$5050$ · สูตรทั่วไป $1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$ เป็นกรณีพิเศษของสูตรนี้

ตัวอย่าง 2 · หาจำนวนพจน์ก่อน

### หาผลบวก $7 + 11 + 15 + \cdots + 203$

- $a_1 = 7,\ d = 4$ จำนวนพจน์ $n = \dfrac{203 - 7}{4} + 1 = 49 + 1 = 50$

- $S_{50} = \dfrac{50}{2}(7 + 203) = 25 \times 210$

$5250$ · ความผิดพลาดที่พบบ่อยที่สุดคือลืม +1 ได้ n = 49

## ตัวอย่างที่ออกสอบบ่อย

ตัวอย่าง 3 · รู้ Sₙ หา aₙ

### ผลบวก n พจน์แรกของลำดับคือ $S_n = 3n^2 + 2n$ จงหา $a_n$

- พจน์ที่ n คือผลบวก n พจน์ลบด้วยผลบวก n − 1 พจน์

$$a_n = S_n - S_{n-1} = (3n^2 + 2n) - \big[3(n-1)^2 + 2(n-1)\big] = 6n - 1$$

- ตรวจพจน์แรกแยก: $a_1 = S_1 = 5$ ตรงกับ $6(1) - 1 = 5$ ✓

$a_n = 6n - 1$ เป็นลำดับเลขคณิตที่มี $d = 6$ · ข้อสังเกต: ถ้า $S_n$ เป็นพหุนามกำลังสองที่ไม่มีพจน์ค่าคงที่ ลำดับจะเป็นเลขคณิตเสมอ

ตัวอย่าง 4 · สามพจน์เรียงกัน

### สามจำนวนเป็นลำดับเลขคณิต ผลบวก 27 ผลคูณ 585 จงหาจำนวนทั้งสาม

- ตั้งตัวกลางเป็น $x$ ให้สมมาตร: $x - d,\ x,\ x + d$ ผลบวก $3x = 27 \Rightarrow x = 9$

- ผลคูณ $(9 - d)\cdot 9 \cdot (9 + d) = 9(81 - d^2) = 585 \Rightarrow d^2 = 16 \Rightarrow d = \pm 4$

$5, 9, 13$ (หรือเรียงกลับ $13, 9, 5$) · เทคนิคตั้งตัวกลางเป็น $x$ ทำให้ $d$ หายไปจากผลบวกทันที

ตัวอย่าง 5 · โจทย์ประยุกต์

### หอประชุมมี 25 แถว แถวแรก 20 ที่นั่ง แถวถัดไปเพิ่มแถวละ 2 ที่นั่ง มีที่นั่งทั้งหมดเท่าไร

- แถวสุดท้าย $a_{25} = 20 + 24(2) = 68$

- $S_{25} = \dfrac{25}{2}(20 + 68) = 12.5 \times 88$

$1{,}100$ ที่นั่ง

## เทียบอนุกรมเลขคณิตกับอนุกรมเรขาคณิต

| | เลขคณิต (arithmetic) | เรขาคณิต (geometric) |

| พจน์ถัดไป | บวก $d$ | คูณ $r$ |

| พจน์ทั่วไป | $a_1 + (n-1)d$ | $a_1r^{n-1}$ |

| ผลบวก n พจน์ | $\tfrac{n}{2}(a_1 + a_n)$ | $a_1\tfrac{1 - r^n}{1 - r}$ |

| บวกไม่สิ้นสุด | ลู่ออกเสมอ (ยกเว้นทุกพจน์เป็น 0) | ลู่เข้า $\tfrac{a_1}{1 - r}$ เมื่อ $|r| < 1$ |

| กราฟของ $a_n$ | จุดบนเส้นตรง | จุดบนเส้นโค้งเลขชี้กำลัง |

สูตรฝั่งเรขาคณิตพร้อมที่มาและตัวอย่าง อ่านต่อที่สูตรอนุกรมเรขาคณิต

## ศัพท์ภาษาอังกฤษที่ต้องรู้

| ภาษาไทย | ภาษาอังกฤษ | สัญลักษณ์ |

| ลำดับเลขคณิต | arithmetic sequence, arithmetic progression (AP) | $a_n$ |

| อนุกรมเลขคณิต | arithmetic series | $S_n$ |

| ผลต่างร่วม | common difference | $d$ |

| พจน์แรก · พจน์ทั่วไป | first term · general term (nth term) | $a_1$ · $a_n$ |

| ผลบวก n พจน์แรก | sum of the first n terms, partial sum | $S_n$ |

| ค่าเฉลี่ยเลขคณิต | arithmetic mean | $\tfrac{a + b}{2}$ |

ศัพท์ครบทั้งบทลำดับและอนุกรมอยู่ที่ศัพท์ลำดับและอนุกรมภาษาอังกฤษ

## เครื่องคิดเลขอนุกรมเลขคณิต (แสดงวิธีทำ)

กรอกค่าที่รู้อย่างน้อย 3 ช่องจาก $a_1,\ d,\ n,\ a_n$ หรือ $S_n$ แล้วเว้นช่องที่ต้องการหาไว้ เครื่องคิดเลขตอบเป็นเศษส่วนแบบแม่นตรงพร้อมวิธีทำทุกขั้น และมีโหมดฝึกให้ลองทำเองก่อนดูเฉลย

ต้องการซิกมา หาสูตรจากพจน์ หรือความสัมพันธ์เวียนเกิด ดูเครื่องคิดเลขลำดับและอนุกรมครบ 6 ชุด

## ใช้ในงานวิศวกรรม

- กองท่อหรือม้วนสายไฟซ้อนเป็นสามเหลี่ยม ชั้นล่าง 10 ท่อ ชั้นบนลดชั้นละ 1 รวม $\tfrac{10}{2}(10 + 1) = 55$ ท่อ ใช้ประเมินน้ำหนักบนพื้นคลังสินค้า

- ค่าเสื่อมราคาแบบเส้นตรง เครื่องจักรราคา 500,000 บาท เสื่อมปีละ 40,000 บาท มูลค่าปลายปีที่ n คือ $500{,}000 - 40{,}000n$ เป็นลำดับเลขคณิตที่ $d = -40{,}000$

- การเคลื่อนที่ด้วยความเร่งคงที่ ระยะทางที่วัตถุเคลื่อนที่ได้ในวินาทีที่ 1, 2, 3, … คือ $u + a(n - \tfrac12)$ เป็นลำดับเลขคณิตที่มีผลต่างร่วมเท่ากับความเร่ง $a$ บวก t วินาทีแรกได้ $s = ut + \tfrac12at^2$ พอดี

## ข้อผิดพลาดที่พบบ่อย

- นับจำนวนพจน์ด้วย $\tfrac{a_n - a_1}{d}$ แล้วลืม +1

- ใช้ $a_n = a_1 + nd$ แทน $a_1 + (n-1)d$ ได้พจน์เกินไปหนึ่งตำแหน่ง

- สับสนว่าโจทย์ถาม “พจน์ที่ n” ($a_n$) หรือ “ผลบวก n พจน์” ($S_n$)

- หา $a_n$ จาก $S_n$ แล้วลืมตรวจพจน์แรกแยก กรณี $S_n$ มีพจน์ค่าคงที่ $a_1$ จะไม่ตรงกับสูตร $S_n - S_{n-1}$

## เรียนต่อในคลังความรู้

- ลำดับเลขคณิต เรขาคณิต และลำดับเวียนเกิดฉบับเต็ม

- สูตรผลบวก Σk, Σk², Σk³ และอนุกรมเลขคณิต-เรขาคณิต

- ลำดับและอนุกรมฉบับสรุปในบทลิมิต

- แนวข้อสอบลำดับและอนุกรมชุด A (เข้ามหาวิทยาลัย)

- บทความต่อ: สูตรอนุกรมเรขาคณิต
